**5.1 微分中值定理**

-   **费马定理**：极值点处若可导，则导数为 0。
-   **罗尔定理**：端点值相等的光滑曲线内必有导数为 0 的点。
-   **拉格朗日中值定理**：\( f(b) - f(a) = f'(\xi)(b - a) \)。
-   **柯西中值定理**：\( \frac{f(b)-f(a)}{g(b)-g(a)} = \frac{f'(\xi)}{g'(\xi)} \)。

**5.2 洛必达法则**

-   用于解决 \( \frac{0}{0} \) 或 \( \frac{\infty}{\infty} \) 型不定式极限。其他类型（\( 0 \cdot \infty, \infty - \infty, 0^0, 1^\infty, \infty^0 \)）需先化为基本型。

**5.3 函数极值及其应用**

-   **极值**：可导函数的极值点必为驻点 (\( f'(x)=0 \))。
-   **判定**：第一充分条件（左右侧导数符号改变）；第二充分条件（利用二阶导数）。
-   **最值**：比较区间内极值与端点值。
-   **证明不等式**：构造辅助函数，利用单调性或极值。

**5.4 函数图形的描绘**

-   **凸性**：上凸函数 \( f''(x) \leq 0 \)，下凸函数 \( f''(x) \geq 0 \)。琴生不等式。
-   **拐点**：二阶导数变号的点。
-   **渐近线**：水平渐近线 (\( \lim_{x\to\infty} f(x) = b \))、垂直渐近线、斜渐近线 (\( \lim_{x\to\infty} \frac{f(x)}{x}=a,\quad \lim_{x\to\infty}(f(x)-ax)=b \))。

**5.5 泰勒公式及其应用**

-   用多项式逼近函数。
-   **带佩亚诺余项**：\( f(x) = P_n(x) + o((x-x_0)^n) \)（定性，局部）。
-   **带拉格朗日余项**：\( f(x) = P_n(x) + \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1} \)（定量，给出误差）。
-   **常用麦克劳林展开** (\( x_0=0 \))：\( e^x, \sin x, \cos x, \ln(1+x), (1+x)^\alpha \)。
