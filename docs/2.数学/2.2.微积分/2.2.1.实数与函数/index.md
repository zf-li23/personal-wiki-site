**1.1 集合与符号**

-   **集合概念和运算**：实数集 \( \mathbb{R} \) 具有连续性，此为微积分的基础。
-   **邻域**：
    -   邻域：\( N(x_{0}, \delta) \triangleq \{ x \mid x_{0} - \delta < x < x_{0} + \delta \} = (x_{0} - \delta, x_{0} + \delta), \quad \delta > 0 \)
    -   去心邻域：\( N^{*}(x_{0}, \delta) \triangleq \{ x \mid 0 < |x - x_{0}| < \delta \} = (x_{0} - \delta, x_{0}) \cup (x_{0}, x_{0} + \delta), \quad \delta > 0 \)
-   **符号**：
    \( \in \) 属于，\( \forall \) 任取，\( \exists \) 存在，\( \exists! \) 存在唯一，\( \triangleq \) 定义，\( \rightarrow \) 推出，\( \leftrightarrow \) 等价，\( \equiv \) 恒等于
-   **绝对值的性质**：
    \[
    \bigl| |a| - |b| \bigr| \leq |a + b| \leq |a| + |b|
    \]
    \[
    |a - b| \leq |c - a| + |c - b|
    \]

**1.2 实数和实数集**

-   **实数**：有理数可表示为 \( \frac{m}{n} \) (\(m,n\) 为正整数)。\( \sqrt{2} \) 是无理数（反证法）。阿基米德公理：\( \forall p, q > 0, \exists N \in \mathbb{Z}^{+} \) 使 \( N p > q \geq (N-1) p \)。有理数在实数中稠密。
-   **实数集的界与确界**：
    -   上/下界、最大值/最小值
    -   上确界 \( \sup E \)：上界的最小值；下确界 \( \inf E \)：下界的最大值。
    -   确界存在性定理：有上界必有上确界；有下界必有下确界。
    -   确界的刻画定理：\( b = \sup E \leftrightarrow b \) 为上界，且 \( \forall c < b, \exists x \in E \) 使 \( x > c \)。

**1.3 函数**

-   **映射**：映射、值域、单射、满射、双射、复合与逆映射。
-   **函数的概念**：定义域 \( D(f) \)、值域 \( R(f) \)。
-   **函数的重要属性**：
    -   **奇偶性**：前提为定义域关于原点对称。偶函数 \( f(-x) = f(x) \)，奇函数 \( f(-x) = -f(x) \)。任意函数可表示为奇偶函数之和。
    -   **单调性**：严格单调递增/递减，单调非减/非增。
    -   **周期性**：\( f(x+T) = f(x) \)，通常指最小正周期。
    -   **有界性**：\( \exists M > 0, \forall x \in D, |f(x)| \leq M \)。
-   **反函数**：双射才存在反函数，图像关于 \( y=x \) 对称。
-   **复合函数**：\( f \circ g(x) = f(g(x)) \)。

**1.4 初等函数**

基本初等函数经有限次四则运算和复合形成初等函数。

-   **常函数**：\( f(x) = C \)
-   **幂函数**：\( f(x) = x^{\mu} \)
-   **指数函数与对数函数**：\( f(x) = a^{x} \) 与 \( f(x) = \log_a x \) 互为反函数。
-   **三角函数**：
    | 名称 | 符号 | 表达式 | 奇偶性 |
    | :--- | :--- | :--- | :--- |
    | 正弦 | \( \sin x \) | 对边/斜边 | 奇函数 |
    | 余弦 | \( \cos x \) | 邻边/斜边 | 偶函数 |
    | 正切 | \( \tan x \) | 对边/邻边 | 奇函数 |
    | 余切 | \( \cot x \) | 邻边/对边 | 奇函数 |
    | 正割 | \( \sec x \) | 斜边/邻边 | 偶函数 |
    | 余割 | \( \csc x \) | 斜边/对边 | 奇函数 |

    -   基本关系：\( \sin x \csc x = 1 \)，\( \cos x \sec x = 1 \)，\( \tan x \cot x = 1 \)；\( \sin^2 x + \cos^2 x = 1 \)，\( 1+\tan^2 x = \sec^2 x \)，\( 1+\cot^2 x = \csc^2 x \)。
    -   和角公式、倍角公式、半角公式、积化和差、和差化积、辅助角公式（略，见原笔记）。
-   **反三角函数**：
    | 名称 | 符号 | 定义域 | 值域 | 奇偶性 |
    | :--- | :--- | :--- | :--- | :--- |
    | 反正弦 | \( \arcsin x \) | \([-1,1]\) | \([-\frac{\pi}{2},\frac{\pi}{2}]\) | 奇函数 |
    | 反余弦 | \( \arccos x \) | \([-1,1]\) | \([0,\pi]\) | 非奇非偶 |
    | 反正切 | \( \arctan x \) | \((-\infty,\infty)\) | \((-\frac{\pi}{2},\frac{\pi}{2})\) | 奇函数 |
    | 反余切 | \( \operatorname{arccot} x \) | \((-\infty,\infty)\) | \((0,\pi)\) | 非奇非偶 |
    -   性质：\( \arcsin x + \arccos x = \frac{\pi}{2} \)，\( \arctan x + \operatorname{arccot} x = \frac{\pi}{2} \)。\( |x| \leq 1 \) 时，\( \arcsin x \sim x \)；\( \arctan x \sim x \)。
-   **双曲函数**：双曲正弦 \( \sinh x = \frac{e^x - e^{-x}}{2} \)，双曲余弦 \( \cosh x = \frac{e^x + e^{-x}}{2} \)，双曲正切 \( \tanh x = \frac{\sinh x}{\cosh x} \) 等。满足 \( \cosh^2 x - \sinh^2 x = 1 \)。

**1.5 非初等函数**

-   **分段函数**：符号函数 \( \operatorname{sgn} x \)、取整函数 \( [x] \)。
-   **隐函数**：由方程 \( F(x,y)=0 \) 确定。
-   **参数方程表示的函数**：\( \begin{cases} x = x(t) \\ y = y(t) \end{cases} \)
