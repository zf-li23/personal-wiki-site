**4.1 导数的概念**

-   **定义**：\( f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0+\Delta x) - f(x_0)}{\Delta x} \)。
-   **可导与连续**：可导必连续，连续不一定可导。
-   **基本初等函数的导数**：\( (C)'=0 \)，\( (x^\mu)'=\mu x^{\mu-1} \)，\( (a^x)'=a^x \ln a \)，\( (\log_a x)' = 1/(x\ln a ) \)，\( (\sin x)'=\cos x \)，\( (\cos x)'=-\sin x \)，\( (\tan x)'=\sec^2 x \)，\( (\arcsin x)'=1/\sqrt{1-x^2} \)，\( (\arctan x)'=1/(1+x^2) \) 等。

**4.2 导数的运算法则**

-   **四则运算**：\( (u \pm v)' = u' \pm v' \)；\( (uv)' = u'v + uv' \)；\( (u/v)' = (u'v - uv')/v^2 \)。
-   **复合函数求导**：链式法则 \( \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} \)。
-   **对数求导法**：用于幂指函数 \( u(x)^{v(x)} \)。
-   **反函数求导**：\( \frac{dx}{dy} = \frac{1}{dy/dx} \)。

**4.3 特殊的求导法则**

-   **参数方程求导**：\( \frac{dy}{dx} = \frac{y'(t)}{x'(t)} \)。
-   **隐函数求导**：方程两边同时对 \( x \) 求导，解出 \( y' \)。

**4.4 高阶导数**

-   **概念**：\( f^{(n)}(x) = \frac{d^n f}{dx^n} \)。
-   **常见高阶导数**：\( (\sin x)^{(n)} = \sin(x + n\pi/2) \)；\( (\ln x)^{(n)} = (-1)^{n-1}(n-1)!/x^n \)。
-   **莱布尼茨公式**：\( (uv)^{(n)} = \sum_{k=0}^{n} \binom{n}{k} u^{(k)} v^{(n-k)} \)。

**4.5 微分**

-   **概念**：\( dy = f'(x) dx \)。
-   **一阶微分形式不变性**：无论 \( x \) 是自变量还是中间变量，\( dy = f'(u) du \) 的形式不变。
-   **近似计算**：\( f(x_0 + \Delta x) \approx f(x_0) + f'(x_0) \Delta x \)。
