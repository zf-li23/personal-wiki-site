## 5.1. 基本概念

### 5.1.1. 特征值与特征向量

对$n$阶方阵$A$，若存在$\lambda \in C$和非零向量$\mathbf{x} \in C^{n}$使 $A\mathbf{x} = \lambda\mathbf{x}$，则$\lambda$为$A$的**特征值**，$\mathbf{x}$为对应的**特征向量**。

$\lambda_{0}$是特征值当且仅当 $\det(\lambda_{0}I_{n} - A) = 0$。特别地，$0$是特征值当且仅当$A$不可逆。

**特征多项式**：$p_{A}(\lambda) = \det(\lambda I_{n} - A)$是$\lambda$的$n$次多项式。$n$阶方阵恰有$n$个特征值（重根按重数计算）。特征多项式具有形式：
$$p_{A}(\lambda) = \lambda^{n} - \text{trace}(A)\lambda^{n-1} + \cdots + (-1)^{n}\det(A)$$

由此可得：$\sum_{i=1}^{n}\lambda_{i} = \text{trace}(A)$，$\prod_{i=1}^{n}\lambda_{i} = \det(A)$。

### 5.1.2. 特征值的性质

**盖尔斯哥利圆盘定理**：任意特征值$\lambda$一定落在某个圆盘 $G_{i}(A) = \{z \in C \mid |z - a_{ii}| \leq \sum_{j \neq i} |a_{ij}|\}$ 中。

实方阵若存在非实数特征值，则其共轭也是特征值，且代数重数相等，特征向量互为共轭。

## 5.2. 对角化和谱分解

### 5.2.1. 可对角化条件

方阵$A$**可对角化**当且仅当存在可逆矩阵$X$使 $X^{-1}AX = \Lambda$ 为对角矩阵，即$A$有$n$个线性无关的特征向量。谱分解：$A = X\Lambda X^{-1}$。

属于不同特征值的特征向量线性无关，因此有$n$个不同特征值的$n$阶方阵一定可对角化。

### 5.2.2. 代数重数与几何重数

- **代数重数**：特征值作为特征多项式根的重数
- **几何重数**：特征子空间$\mathcal{N}(\lambda I_{n} - A)$的维数，不超过代数重数

**半单特征值**的代数重数等于几何重数；**亏损特征值**的几何重数小于代数重数。方阵可对角化当且仅当所有特征值都是半单的。

## 5.3. 相似关系与标准形

### 5.3.1. 相似关系

$A$与$B$**相似**当且仅当存在可逆矩阵$X$使 $B = X^{-1}AX$。相似关系保持秩、特征多项式、特征值及其重数、迹、行列式不变。$A$可对角化等价于$A$与对角矩阵相似。

任意方阵可通过相似变换化为上三角矩阵，对角元素为特征值的任意排列。

### 5.3.2. Hamilton-Cayley定理与Jordan分解

**Hamilton-Cayley定理**：设$A$的特征多项式为$p_{A}(\lambda)$，则 $p_{A}(A) = O$。

**Jordan分解**：对任意$n$阶方阵$A$，存在可逆矩阵$X$使 $X^{-1}AX = J$ 为Jordan标准形。当$A$可对角化时，Jordan标准形就是对角矩阵。

**同时对角化**：两个可对角化矩阵$A,B$可同时对角化当且仅当 $AB = BA$。
