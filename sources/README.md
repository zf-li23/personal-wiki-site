# sources/：当前课程的资料

这个目录放**正在撰写的那一门课程**的原始资料。除本文件外，目录里的一切都不被 git 追踪（见 `.gitignore`），因为资料多有版权，而仓库是公开的。一门课程写完、审查完之后清空，再放下一门课程的资料。

```
sources/
  README.md        本文件（唯一被追踪的文件）
  slides/          课件（PDF、PPT/PPTX）——范围、术语、编号的依据
  notes/           梳理（自己或别人的笔记、提纲）——格式与重点的参考，内容需要核实
  textbooks/       教材（PDF 等）——查证、补全证明与例题、缺少课件时的主材料
  text/            编排者用 scripts/prep_sources.py 生成：资料的文字版与 INDEX.md
  pages/           同上：文字不够用的页面的低分辨率图片
  REQUEST.md       可选：作者对这门课程的说明（想写成什么样、哪些重要、已知的问题）
  PLAN.md          章节规划（编排者写，作者确认后执行；随资料一起删除）
```

- 文件名随意，中英文都可以；放错类别也没关系，盘点时会重新分类。
- 一次只放一门课程（二级页面，例如 2.1 线性代数）。
- 三类资料不必齐全，有什么放什么；只有教材也可以。

怎样使用这些资料、一门课程从上传到完成的步骤，见 [AUTHORING.md](../AUTHORING.md) §2–§4。
