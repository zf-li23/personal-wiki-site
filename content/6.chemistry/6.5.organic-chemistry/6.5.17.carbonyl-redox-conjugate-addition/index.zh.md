title: 醛酮的还原、氧化与共轭加成
---

上一章 [6.5.16](/6.5.16) 按亲核原子讨论了醛酮的**亲核加成**。本章先讲其中最常用的一类——负氢的加成，即醛酮还原为醇，以及把羰基还原为亚甲基、还原偶联为邻二醇或烯烃的其他方法；再讲醛酮的氧化（醛的鉴定反应、$\ce{SeO2}$ 的 α 氧化与 Baeyer–Villiger 氧化）与无 α-H 醛的歧化；最后讨论羰基与 C=C 共轭时的新问题：**亲核试剂**加到羰基碳上（**1,2-加成**）还是加到 β 碳上（共轭加成），以及醌与烯酮这两类特殊的不饱和羰基化合物。判断氧化与还原要用 [6.5.1](/6.5.1#sec-1.3.2) 的碳的氧化态；单电子还原生成的羰游基是 [6.5.7](/6.5.7#sec-7.2.3) 中**自由基离子**化学的延续；醌–氢醌电对把有机化学与 [6.1.11](/6.1.11) 的电化学联系起来，也是生物体内电子传递链的化学基础。羰基 α 位的烯醇与**烯醇负离子**化学见 [6.5.21](/6.5.21#sec-21.2)，Michael 加成在 **Robinson 环化**中的应用见 [6.5.22](/6.5.22#sec-22.5.2)。

## 17.1. 负氢还原剂

### 17.1.1. 氢化铝锂与硼氢化钠

醛酮被金属氢化物还原为醇，本质上是负氢（$\ce{H-}$）对羰基的**亲核加成**：醛给出伯醇，酮给出仲醇。最常用的两种试剂是氢化铝锂 $\ce{LiAlH4}$（LAH）与硼氢化钠 $\ce{NaBH4}$。它们不是游离的 $\ce{H-}$ 的来源（NaH 的 $\ce{H-}$ 只作碱，不作**亲核试剂**），而是通过 Al–H、B–H 键把负氢转移给羰基碳：四面体的 $\ce{AlH4-}$、$\ce{BH4-}$ 中 H 带部分负电荷，与羰基碳成键的同时，金属阳离子（$\ce{Li+}$、$\ce{Na+}$）或溶剂的质子与羰基氧结合。每个 $\ce{AlH4-}$ 或 $\ce{BH4-}$ 原则上可以依次转移四个负氢，生成四烷氧基铝（硼）酸盐，水解后得到醇。

![硼氢化钠在甲醇中还原丙酮：B–H 键的电子对加到羰基碳上，同时甲醇的 O–H 质子转移到羰基氧上，得到异丙醇与甲氧基硼氢化物；后者继续转移剩下的 B–H](./plots/borohydride.py)

![氢化铝锂在无水乙醚中还原环己酮：$\ce{Li+}$ 与羰基氧配位（虚线）使其活化，Al–H 键的电子对转移到羰基碳上，生成烷氧基铝酸盐；剩下的三个 Al–H 继续还原三分子酮，水解后得到环己醇](./plots/lialh4-ketone.py)

两种试剂的差别在于活性与使用条件：

| | $\ce{LiAlH4}$ | $\ce{NaBH4}$ |
|---|---|---|
| 溶剂 | 无水乙醚、THF；与水、醇剧烈反应放出 $\ce{H2}$ | 甲醇、乙醇、水（碱性下稳定；在酸中迅速分解） |
| 醛、酮 → 醇 | 是 | 是（室温即可） |
| 酰氯 → 醇 | 是 | 是 |
| 酯、内酯 → 醇 | 是 | 慢或不反应（选择性还原酮的依据） |
| 羧酸 → 伯醇 | 是 | 否（生成羧酸盐） |
| 酰胺 → 胺，腈 → 伯胺 | 是 | 否 |
| 环氧化合物开环、卤代烷 → 烷烃 | 是 | 一般否 |
| 孤立的 C=C、C≡C | 否 | 否 |
| 硝基 | 脂肪族硝基 → 胺 | 否 |
| 后处理 | 小心地依次加水、NaOH 水溶液、水（Fieser 法）分解铝盐 | 加稀酸或水 |

$\ce{LiAlH4}$ 活性高、选择性差；$\ce{NaBH4}$ 温和，能在酯、酰胺、腈、硝基、卤素存在下只还原醛酮。例如 4-硝基苯甲醛用 $\ce{NaBH4}$ 在乙醇中还原，得到 4-硝基苄醇；3-氧亚基丁酸乙酯（乙酰乙酸乙酯）用 $\ce{NaBH4}$ 只还原酮羰基，用 $\ce{LiAlH4}$ 则酮与酯都被还原，得到丁-1,3-二醇：

```smiles
CCOC(=O)CC(C)=O>>CCOC(=O)CC(C)O
CCOC(=O)CC(C)=O>>CC(O)CCO
```

用烷氧基部分取代 Al–H 可以调节活性与选择性：三叔丁氧基氢化铝锂 $\ce{LiAlH(OtBu)3}$ 活性低，能把酰氯还原到醛；二异丁基氢化铝（DIBAL，$\ce{(i-Bu)2AlH}$）是中性的 Lewis 酸性还原剂，溶于甲苯、己烷，先与羰基氧配位再转移负氢，在低温下把酯还原到醛（[6.5.19](/6.5.19#sec-19.7)），也把 α,β-不饱和酮干净地 1,2-还原为烯丙醇（17.7）。

硼烷（$\ce{BH3*THF}$ 或 $\ce{BH3*SMe2}$）是亲电的还原剂：它是 **Lewis 酸**，先与富电子的羰基氧配位。所以它的选择性与 $\ce{NaBH4}$ 相反：硼烷迅速还原羧酸（羧酸先与 $\ce{BH3}$ 生成酰氧基硼烷并放出 $\ce{H2}$，再被还原）与酰胺，却较慢地还原酯。硼烷也与孤立的 C=C 发生**硼氢化**（[6.5.11](/6.5.11#sec-11.4.6)），生成的是有机硼烷而不是烷烃；要得到烷烃，还需要用羧酸使 C–B 键质子解。

### 17.1.2. 环己酮还原的立体化学

取代环己酮的羰基两个面不等价，负氢可以从直立方向进攻（得到平伏的 OH）或从平伏方向进攻（得到直立的 OH）。以构象被叔丁基锁定的 4-叔丁基环己酮为例（**椅式构象**与 **A 值**见 [6.5.4](/6.5.4#sec-4.6.1)）：

```smiles
CC(C)(C)C1CCC(=O)CC1>>CC(C)(C)[C@H]1CC[C@H](O)CC1
CC(C)(C)C1CCC(=O)CC1>>CC(C)(C)[C@H]1CC[C@@H](O)CC1
```

| 还原剂 | 反式（OH 平伏）: 顺式（OH 直立） | 主要进攻方向 |
|---|---|---|
| $\ce{LiAlH4}$ | 约 90:10 | 直立 |
| $\ce{NaBH4}$ | 约 85:15 | 直立 |
| L-Selectride（$\ce{LiBH(\mathit{s}-Bu)3}$） | 约 7:93 | 平伏 |
| $\ce{Al(O\mathit{i}Pr)3}$/异丙醇（MPV，平衡） | 约 80:20 | **热力学控制** |

小的负氢试剂优先从直立方向进攻，生成热力学上较稳定的平伏醇。直立进攻的方向与环上 C3、C5 的直立 H 靠近，似乎更拥挤；它之所以有利，是因为沿 **Bürgi–Dunitz 角**从平伏方向进攻时，形成中的 C–H 键与 C2、C6 上直立的 C–H 键接近重叠，产生**扭转张力**（Felkin 1968），而直立进攻时这种重叠不存在。Cieplak 等还提出了轨道上的解释（形成中的键与**反式共平面**的 C–H σ 轨道的作用），至今仍有争论，但都指向同一个实验事实。大位阻的三仲丁基硼氢化锂（L-Selectride）从直立方向进攻时与 C3、C5 的直立 H 冲突严重，于是从平伏方向进攻，生成直立的醇（**动力学控制**下的较不稳定产物）。硫**叶立德**的直立进攻（[6.5.16](/6.5.16#sec-16.8.3)）也是同一原因。

![4-叔丁基环己酮椅式构象上的两种进攻方向：小的负氢试剂（$\ce{LiAlH4}$、$\ce{NaBH4}$）从直立方向（下方）进攻，避免与 C2、C6 的直立 C–H 重叠，得到平伏醇；大位阻的 L-Selectride 避开 C3、C5 的直立 H（图中画出 C3 上的一个，C5 上的在其正后方），从平伏方向（上方）进攻，得到直立醇](./plots/axial-attack.py)

刚性的双环酮由空间位阻决定：樟脑的 C7 上有偕二甲基，挡住了羰基的 exo 面，$\ce{LiAlH4}$ 只能从 endo 面进攻，主产物是 exo-OH 的异冰片醇（约 90%），而不是 endo-OH 的冰片醇；降冰片酮没有 C7 甲基，负氢从较开放的 exo 面进攻，主要得到 endo 醇。

### 17.1.3. Luche 还原与软硬选择

α,β-不饱和酮的 β 碳与羰基碳都是亲电中心（17.6）。$\ce{NaBH4}$ 单独使用时常得到 1,2-还原（烯丙醇）与 1,4-还原（饱和酮，可再还原为饱和醇）的混合物；在甲醇中加入 $\ce{CeCl3*7H2O}$，几乎只得到烯丙醇。

**定义 17.1.1（Luche 还原）** α,β-不饱和醛酮在 $\ce{CeCl3}$ 存在下用 $\ce{NaBH4}$ 在甲醇中还原，选择性地生成烯丙醇（1,2-还原）的反应称为 **Luche 还原**（Luche reduction）。

```smiles
O=C1C=CCCC1>>OC1C=CCCC1
```

![Luche 还原：$\ce{Ce^3+}$ 催化生成的甲氧基硼氢化物 $\ce{HB(OMe)3-}$ 是较硬的负氢给体；与 $\ce{Ce^3+}$ 配位的甲醇酸性增强，与羰基氧形成氢键（虚线）。负氢加到羰基碳（硬位置）上，羰基氧从活化的甲醇得到质子，生成烯丙醇](./plots/luche.py)

$\ce{Ce^3+}$ 的作用有两方面（Luche 1978—1981 的研究）：(1) 它催化 $\ce{BH4-}$ 与甲醇反应，生成甲氧基硼氢化物 $\ce{HB(OMe)3-}$ 等，这些试剂按**软硬酸碱原理**比 $\ce{BH4-}$ 更"硬"，更倾向于进攻电荷集中的羰基碳（硬位置），而不是轨道系数大的 β 碳（软位置）；(2) 镧系离子是硬的 Lewis 酸，NMR 研究表明它优先与溶剂甲醇配位而不是与羰基配位，配位的甲醇酸性增强，通过**氢键**活化羰基氧。Luche 条件还有另一种**化学选择性**：醛在 $\ce{Ce^3+}$ 催化下迅速与甲醇生成**缩醛**，不被还原，所以同一分子中的酮可以在醛存在下被选择性还原（与通常的活性次序相反）。

## 17.2. 不对称还原与 MPV 还原

### 17.2.1. CBS 还原

**前手性**酮还原为**手性**仲醇，羰基的 **Re 面**与 Si 面（[6.5.5](/6.5.5#sec-5.9.2)）必须被区分开。Corey、Bakshi 与 Shibata（1987）发展的手性噁唑硼烷催化剂能做到这一点。

**定义 17.2.1（CBS 还原）** 以由脯氨酸衍生的手性噁唑硼烷为催化剂、硼烷为负氢来源，把前手性酮对映选择性地还原为仲醇的反应称为 **CBS 还原**（Corey–Bakshi–Shibata reduction）。

催化剂由 (S)-α,α-二苯基脯氨醇与硼烷或甲基硼酸缩合得到。机理是双功能的：$\ce{BH3}$ 与噁唑硼烷环上 N 的孤对电子配位，被活化为更强的负氢给体，同时环上 B 的 Lewis 酸性增强；酮的羰基氧再与环上 B 配位，配位方向使酮的大基团 $\mathrm{R_L}$ 远离催化剂的取代基；负氢经六元环**过渡态**从 N 上的 $\ce{BH3}$ 转移到羰基碳。由于酮只能以一种朝向结合，负氢只从一个面进攻，产物构型可以预测，**对映体过量**（[6.5.5](/6.5.5#sec-5.7.3)）通常高于 95%。例如用 (S)-CBS 催化剂还原 2-氯-1-(4-氟苯基)乙酮，得到 (S)-2-氯-1-(4-氟苯基)乙醇（75%，ee 90%；$\ce{CH2Cl}$ 的优先级高于芳基，所以与苯乙酮还原得到 (R)-1-苯乙醇是同一个面选择性）。

```smiles
O=C(CCl)c1ccc(F)cc1>>O[C@H](CCl)c1ccc(F)cc1
```

![CBS 还原（以苯乙酮为例）：$\ce{BH3}$ 与噁唑硼烷环上的 N 配位，环上的 B 与酮的羰基氧配位（虚线），配位时酮的小基团（甲基）靠近 B-甲基、大基团（苯基）远离催化剂；B–H 的负氢经六元环转移到羰基碳上，后处理得到 (R)-1-苯乙醇](./plots/cbs.py)

不对称还原的其他重要方法有 Noyori 的手性 Ru–BINAP–二胺催化氢化与转移氢化（Noyori 与 Knowles 因**不对称催化**氢化获 2001 年诺贝尔化学奖，[6.5.29](/6.5.29#sec-29.2.2)），以及工业上越来越普遍的酶法：经定向进化改造的酮还原酶（KRED）以 NADPH 为负氢来源，在水中把酮还原为单一**对映体**的醇，ee 常大于 99.5%。酶的面选择性与 [6.5.5](/6.5.5#sec-5.9.2) 中醇脱氢酶对 pro-R 氢的专一性是同一回事：辅酶 NAD(P)H 的二氢吡啶环把 C4 上的一个特定氢以负氢形式转移给底物羰基的一个特定的面。

### 17.2.2. Meerwein–Ponndorf–Verley 还原与 Oppenauer 氧化

异丙醇铝能把醛酮还原为醇，同时自身被氧化为丙酮；反应是可逆的。

**定义 17.2.2（Meerwein–Ponndorf–Verley 还原）** 在异丙醇铝（或其他金属醇盐）催化下，用异丙醇作负氢来源把醛酮还原为醇、同时生成丙酮的可逆反应称为 **Meerwein–Ponndorf–Verley 还原**（Meerwein–Ponndorf–Verley reduction），简称 MPV 还原；它的逆反应——用丙酮或环己酮作氢受体、在铝醇盐催化下把仲醇氧化为酮——称为 **Oppenauer 氧化**（Oppenauer oxidation）。

$$
\ce{R2C=O + (CH3)2CHOH <=>[Al(O\mathit{i}Pr)3] R2CHOH + (CH3)2C=O}
$$
机理是负氢在铝上的六元环过渡态中转移：底物的羰基氧与 Al 配位，同一个 Al 上的异丙氧基的 C–H 以负氢的形式转移到羰基碳上，异丙氧基变为丙酮离去；底物的烷氧基与溶剂异丙醇交换，再生催化剂。

![MPV 还原的六元环过渡态：羰基氧与铝配位，铝上异丙氧基的 α-H 以负氢形式转移到羰基碳上，生成新的烷氧基铝与丙酮](./plots/mpv.py)

它是一个平衡，方向由 **Le Chatelier 原理**控制：MPV 还原用大量异丙醇作溶剂并不断蒸出低沸点的丙酮（沸点 $56\,^\circ\mathrm{C}$），推动还原完全；Oppenauer 氧化用大量丙酮（或氧化电势更高的环己酮、苯醌）作氢受体，并常用叔丁醇铝。由于平衡控制，产物是热力学上更稳定的醇（取代环己醇中以平伏醇为主）。MPV 还原的**化学选择性**极好：C=C、C≡C、硝基、卤素、酯都不受影响，例如 2-硝基苯甲醛被还原为 2-硝基苄醇，肉桂醛被还原为肉桂醇。Oppenauer 氧化曾是甾体工业中把 3-羟基-Δ⁵-甾体氧化为 Δ⁴-3-酮（如由胆固醇型前体制备孕酮、睾酮）的标准方法，反应中双键移入共轭位置。**Grignard 试剂**的还原副反应（[6.5.16](/6.5.16#sec-16.7.3)）与下面的 Cannizzaro 反应也是同类的负氢转移。

## 17.3. 其他还原方法

### 17.3.1. 催化氢化

醛酮在 Pt、Pd、Ni（Raney Ni）、Ru 等催化剂上加氢还原为醇，例如苯甲醛在 Pt 上、$0.2\,\mathrm{MPa}$ 的氢气中定量还原为苄醇，丙酮在 Raney Ni 上还原为异丙醇。羰基的氢化通常比 C=C 慢：在 Pd 上，孤立或共轭的 C=C 几乎总是先于醛酮羰基被还原（17.7）；还原羰基宜用 Pt、Ru、Raney Ni 或较高的压力，醛比酮容易。非共轭体系中醛基、C=C 与酮羰基的相对活性随催化剂与条件而变，没有普适的次序。工业上大量的醇（如由醛氢甲酰化产物得到的 1-丁醇、2-乙基己醇，由葡萄糖得到的山梨醇）是用催化氢化生产的。

### 17.3.2. 溶解金属还原与羰游基

活泼金属（Na、Li、K、Mg、Zn）可以把电子转移给羰基的 π* 轨道，生成**自由基负离子**——羰游基。

**定义 17.3.1（羰游基）** 羰基化合物得到一个电子生成的自由基负离子 $\ce{R2C^{.}-O-}$ 称为**羰游基**（ketyl）。

羰游基是一种**自由基离子**（[6.5.7](/6.5.7#sec-7.2.3)），未成对电子主要在碳上，负电荷主要在氧上。二苯甲酮的羰游基（钠与二苯甲酮在 THF 中生成）呈深蓝色，相当稳定，可以用**电子顺磁共振**观察；它与水和氧迅速反应，所以实验室用"钠–二苯甲酮"蒸馏 THF、乙醚等溶剂，蓝色是溶剂已无水无氧的指示。羰游基的去向取决于溶剂：

- **质子性溶剂**（醇、液氨中加醇）中，羰游基被质子化为中性的羟烷基**自由基**，再得到一个电子成为**碳负离子**，质子化后得到醇（单分子还原）。经碳负离子中间体、在平衡条件下进行，取代环己酮主要得到热力学稳定的平伏醇。这种方法现在已很少用于醛酮，但钠–乙醇还原酯（Bouveault–Blanc 还原，[6.5.19](/6.5.19#sec-19.7)）与 **Birch 还原**（定义 15.2.1）是同一类反应。
- 非质子性溶剂（苯、THF）中，羰游基浓度较高，两个自由基在碳上偶联，生成邻二醇的双负离子，水解后得到邻二醇（双分子还原）——频哪醇偶联。

### 17.3.3. 频哪醇偶联与 McMurry 反应

**定义 17.3.2（频哪醇偶联）** 醛或酮在活泼金属或低价金属试剂作用下经单电子还原生成羰游基，两个羰游基在碳上偶联，水解后得到邻二醇的反应称为**频哪醇偶联**（pinacol coupling）。

丙酮与镁汞齐在苯中反应，经镁的双羰游基螯合物偶联，水解后得到频哪醇（2,3-二甲基丁-2,3-二醇），它在酸中的**频哪醇重排**见 [6.5.10](/6.5.10#sec-10.8)；二苯甲酮在钠作用下给出四苯基乙二醇。现代方法中，二碘化钐（$\ce{SmI2}$，Kagan 试剂）在 THF 中、室温下就能温和地进行分子内与分子间的频哪醇偶联与羰游基–烯烃环化，广泛用于天然产物的全合成。

![频哪醇偶联：钠把一个电子转移给二苯甲酮，生成羰游基（自由基负离子）；两个羰游基的碳自由基用各自的单电子成键（鱼钩箭头），得到邻二醇的双负离子](./plots/pinacol.py)

用更强的亲氧还原剂——低价钛（$\ce{TiCl3}$ 或 $\ce{TiCl4}$ 与 $\ce{LiAlH4}$、Zn、Zn–Cu 等原位生成）——偶联不停在邻二醇：在加热下，钛表面的频哪醇钛盐继续脱氧，生成烯烃与钛的氧化物（Ti–O 键很强，是驱动力）。

**定义 17.3.3（McMurry 反应）** 两分子醛酮（或一个分子中的两个羰基）在低价钛作用下还原偶联，生成烯烃的反应称为 **McMurry 反应**（McMurry reaction）。

```smiles
O=C(c1ccccc1)c1ccccc1>>c1ccc(cc1)C(c1ccccc1)=C(c1ccccc1)c1ccccc1
```

McMurry 反应能合成用其他方法很难得到的高度拥挤的四取代烯烃（四苯乙烯，以及聚集诱导发光材料中的四苯乙烯骨架、分子马达中的过度拥挤烯烃，[6.5.5](/6.5.5#sec-5.1.4)），它的分子内形式可以闭合大环与小环。两种不同的酮一起偶联时得到三种烯烃的混合物，除非其中一种大大过量（或一种是二芳基酮）。

### 17.3.4. Clemmensen 还原

**定义 17.3.4（Clemmensen 还原）** 醛酮在锌汞齐与浓盐酸中加热，羰基被还原为亚甲基的反应称为 **Clemmensen 还原**（Clemmensen reduction）。

锌汞齐由锌粒与 $\ce{HgCl2}$ 的稀盐酸溶液作用制得，汞在锌表面形成汞齐，抑制了锌与酸直接放出氢气的副反应。机理至今不完全清楚：不经过醇（醇在此条件下不被还原为烷烃），一般认为是锌表面上的**单电子转移**，经有机锌的卡宾类中间体。它适合对酸稳定的底物，特别是芳基烷基酮：**Friedel–Crafts 酰基化**（[6.5.14](/6.5.14#sec-14.9.3)）后接 Clemmensen 还原，是在芳环上引入直链烷基而不发生重排的标准路线。

```smiles
O=C(O)CCC(=O)c1ccccc1>>O=C(O)CCCc1ccccc1
```

![Clemmensen 还原的一种常见机理设想（机理尚无定论，醇不是中间体）：质子化的酮从锌表面得到两个电子，生成 α-羟基烷基锌；OH 质子化后，C–Zn 键的电子推动水离去，生成锌卡宾类中间体，再经两次质子化（及电子转移）变为 $\ce{CH2}$](./plots/clemmensen.py)

把羰基还原为亚甲基的三种方法互补：

| 方法 | 条件 | 适用 | 不适用 |
|---|---|---|---|
| Clemmensen 还原 | Zn(Hg)，浓 HCl，加热 | 对酸稳定的底物，芳基酮 | **缩醛**、叔醇、对酸敏感的基团 |
| **Wolff–Kishner–黄鸣龙还原**（[6.5.16](/6.5.16#sec-16.9.4)） | $\ce{N2H4}$，KOH，二甘醇，约 200 °C | 对碱稳定的底物 | 酯、卤代烷、对碱敏感的基团 |
| **硫缩醛**–Raney Ni 脱硫（[6.5.16](/6.5.16#sec-16.6.2)） | 二硫醇/$\ce{BF3}$；Raney Ni，乙醇 | 中性条件，多数官能团 | 含其他硫原子、能被 Ni 氢化的 C=C |

## 17.4. Cannizzaro 反应

没有 α-H 的醛（甲醛、苯甲醛、2,2-二甲基丙醛、糠醛）不能**烯醇化**，在浓碱中发生歧化：一分子醛被氧化为羧酸盐，另一分子被还原为醇。

**定义 17.4.1（Cannizzaro 反应）** 无 α-H 的醛在浓的强碱中歧化，一半转化为羧酸盐、一半转化为伯醇的反应称为 **Cannizzaro 反应**（Cannizzaro reaction）。

```smiles
O=Cc1ccccc1.O=Cc1ccccc1>>O=C([O-])c1ccccc1.OCc1ccccc1
```

机理：$\ce{HO-}$ 加到醛上生成四面体的烷氧负离子（浓碱中进一步失去质子成为双负离子），它的 C–H 以负氢的形式转移到第二分子醛的羰基碳上，自身变为羧酸；羧酸与烷氧负离子之间的质子转移生成羧酸盐与醇，使反应不可逆。负氢转移是速率决定步骤，速率方程为 $v = k_3[\ce{RCHO}]^2[\ce{HO-}] + k_4[\ce{RCHO}]^2[\ce{HO-}]^2$，分别对应单负离子与双负离子作为负氢给体；在 $\ce{D2O}$ 中进行时，生成的醇的 $\ce{CH2}$ 上不含 D，说明转移的 H 来自另一分子醛，而不是溶剂。

![Cannizzaro 反应：氢氧根加到苯甲醛上，四面体烷氧负离子的 C–H 以负氢形式转移到第二分子苯甲醛的羰基碳上，得到苯甲酸与苄氧负离子，二者质子交换生成苯甲酸根与苄醇](./plots/cannizzaro.py)

交叉 Cannizzaro 反应： 两种不同的无 α-H 的醛一起反应时产物复杂；但若其中一种是甲醛，由于甲醛最容易被 $\ce{HO-}$ 加成，它优先成为负氢给体被氧化为甲酸盐，另一种醛被还原为醇。季戊四醇（醇酸树脂、炸药 PETN 的原料）的工业合成就是三次**羟醛反应**加一次交叉 Cannizzaro 反应：乙醛的三个 α-H 依次与甲醛发生羟醛加成，生成的 3-羟基-2,2-双(羟甲基)丙醛没有 α-H，再被过量甲醛还原：

```smiles
CC=O.C=O>>OCC(CO)(CO)C=O
OCC(CO)(CO)C=O.C=O>>OCC(CO)(CO)CO.O=C[O-]
```

Cannizzaro 反应的分子内形式见于 1,2-二羰基化合物：乙二醛在碱中得到乙醇酸盐，二苯乙二酮的类似反应伴随苯基迁移，就是**二苯乙醇酸重排**（定义 30.4.1）。

## 17.5. 醛酮的氧化

### 17.5.1. 醛氧化为羧酸

醛的羰基碳上有一个 H，很容易被氧化为羧酸（碳的氧化态由 +1 升到 +3），常用的氧化剂有 $\ce{CrO3}$/$\ce{H2SO4}$（Jones 试剂）、$\ce{KMnO4}$、$\ce{Ag2O}$、$\ce{H2O2}$ 与过氧酸。现代合成中最常用的是 Pinnick 氧化：$\ce{NaClO2}$ 在弱酸性缓冲液中氧化醛，用 2-甲基丁-2-烯清除副产物 HOCl，条件温和，不影响 C=C 与多数官能团。醛的氧化大多经过醛的水合物（偕二醇）或类似的加成物，再像醇一样被氧化（[6.5.10](/6.5.10#sec-10.6)）；所以水合程度大的醛更容易被氧化。苯甲醛在空气中放置会慢慢变为苯甲酸，这是经过酰基**自由基**与过氧酸的自由基链反应（**自氧化**，[6.5.7](/6.5.7#sec-7.3.3)）。

![Pinnick 氧化：亚氯酸加成到醛基上；加成物经五元环的周环过程断裂——Cl=O 端的氧夺取醛基 H，C–H 键的电子形成新的 C=O，O–Cl 键的电子随氯离去，生成羧酸与 HOCl；2-甲基丁-2-烯清除 HOCl](./plots/pinnick.py)

酮的羰基碳上没有 H，不易被氧化；强氧化剂（热的浓 $\ce{HNO3}$、$\ce{KMnO4}$）使 C–C 键断裂，环己酮被硝酸氧化为己二酸，这是尼龙-66 单体的工业路线。

### 17.5.2. Tollens 试剂与 Fehling 试剂

两种弱氧化剂只氧化醛基，不氧化醇羟基与 C=C，用于区分醛与酮：

- Tollens 试剂（Tollens' reagent）：硝酸银的氨水溶液，含无色的 $\ce{[Ag(NH3)2]+}$。醛被氧化为羧酸铵，$\ce{Ag+}$ 被还原为金属银，在洁净的玻璃壁上形成银镜（"银镜反应"），否则为黑色沉淀：
$$
\ce{RCHO + 2[Ag(NH3)2]+ + 3HO- -> RCOO- + 2Ag v + 4NH3 + 2H2O}
$$
- Fehling 试剂（Fehling's solution）：硫酸铜与酒石酸钾钠的碱性溶液，$\ce{Cu^2+}$ 与酒石酸根形成深蓝色的配离子（防止生成 $\ce{Cu(OH)2}$ 沉淀）。脂肪醛把 $\ce{Cu^2+}$ 还原为砖红色的 $\ce{Cu2O}$ 沉淀；芳香醛反应很慢，一般不显正反应。以柠檬酸钠代替酒石酸盐的 Benedict 试剂更稳定。
$$
\ce{RCHO + 2Cu^2+ + 5HO- -> RCOO- + Cu2O v + 3H2O}
$$

这两种试剂（与 Benedict 试剂）也用于检出糖：葡萄糖等醛糖与果糖等 α-羟基酮都呈正反应（后者在碱中经烯二醇互变为醛糖），称为还原糖（[6.5.32](/6.5.32)）。它们历史上也用于检测尿糖；现在的尿糖与血糖检测用葡萄糖氧化酶（GOx）的酶法——试纸中 GOx 把葡萄糖氧化为葡萄糖酸并生成 $\ce{H2O2}$，过氧化物酶再用 $\ce{H2O2}$ 氧化显色剂；血糖仪用 GOx 或葡萄糖脱氢酶的电化学传感器（[6.4.6](/6.4.6)）。酶法只对葡萄糖专一，不受其他还原性物质的干扰。

### 17.5.3. 二氧化硒的 α 氧化

$\ce{SeO2}$ 把醛酮中与羰基相邻的 $\ce{CH2}$ 或 $\ce{CH3}$ 氧化为羰基，生成 1,2-二羰基化合物（Riley 氧化，1932），常在含水二氧六环或乙酸中回流：

```smiles
O=C1CCCCC1>>O=C1CCCCC1=O
CC(=O)c1ccccc1>>O=CC(=O)c1ccccc1
```

机理：醛酮的**烯醇式**进攻亲电的 Se=O，生成 α-酮基亚硒酸 $\ce{RCOCH(R')Se(O)OH}$；后者经 [2,3]-**σ 迁移反应**或直接的消除（失去 $\ce{H2O}$ 与 Se(II)），在 α 碳上形成 C=O，硒被还原为红色的单质硒。$\ce{SeO2}$ 对烯烃的烯丙位氧化（[6.5.11](/6.5.11#sec-11.8.4)）是同一试剂的另一种反应；硒化合物有毒，现在常用催化量的 $\ce{SeO2}$ 与共氧化剂。

![$\ce{SeO2}$ 的 α 氧化（Riley 氧化）：环己酮的烯醇式进攻亲电的 Se，Se=O 的 π 电子移到氧上，质子转移得到 α-酮基亚硒酸；经 [2,3]-σ 迁移生成 Se(II) 酯，再消除水与单质硒，得到环己-1,2-二酮](./plots/riley.py)

### 17.5.4. Baeyer–Villiger 氧化

酮与过氧酸作用，一个碳上的取代基迁移到氧上，在羰基与该基团之间插入一个氧原子，生成酯；环酮生成内酯。

**定义 17.5.1（Baeyer–Villiger 氧化）** 酮（或醛）在过氧酸（或过氧化氢与 Lewis 酸）作用下，与羰基相连的一个基团从碳迁移到氧上，生成酯（环酮生成内酯）的反应称为 **Baeyer–Villiger 氧化**（Baeyer–Villiger oxidation）。

常用的过氧酸是间氯过氧苯甲酸（mCPBA，商品约含 70%–80%，其余为间氯苯甲酸与水，较安全）、三氟过氧乙酸（$\ce{CF3CO3H}$，活性最高）与过氧乙酸。

```smiles
CC(=O)c1ccccc1>>CC(=O)Oc1ccccc1
O=C1CCCCC1>>O=C1CCCCCO1
CC1CCCCC1=O>>CC1CCCCC(=O)O1
CC(=O)[C@@H](C)c1ccccc1>>CC(=O)O[C@@H](C)c1ccccc1
```

机理： (1) 过氧酸加到（被酸活化的）羰基上，生成四面体的过氧**半缩酮**，称为 Criegee 中间体；(2) 速率决定步骤：与 O–O 键**反式共平面**的一个 C–R 键的电子推动 R 带着成键电子对迁移到相邻的氧上，同时 O–O 键**异裂**，羧酸根离去；(3) 生成的质子化酯失去质子。迁移是协同的分子内过程，所以迁移基团若是**手性中心**，构型保持（上面第四式：(S)-3-苯基丁-2-酮给出构型保持的 (S)-乙酸 1-苯乙酯）。

![Baeyer–Villiger 氧化：过氧酸加到环己酮的羰基上生成 Criegee 中间体；与 O–O 键反式共平面的环上 C–C 键迁移到氧上，羧酸根离去，脱质子得到 ε-己内酯](./plots/baeyer-villiger.py)

迁移的选择性： 两个基团中，能更好地容纳正电荷的那个优先迁移（迁移**过渡态**中迁移基团带部分正电荷），**迁移倾向**的大致次序为

$$
\text{叔烷基} > \text{环己基} > \text{仲烷基} > \text{苄基} > \text{苯基} > \text{乙烯基} > \text{伯烷基} > \text{甲基}
$$
（Krow 1993 的综述；芳基上的给电子取代基使它迁移得更快，如 4-甲氧基苯基 > 苯基 > 4-硝基苯基；苄基、苯基与仲烷基的相对次序随底物和条件变化。）醛中的 H 迁移最快，所以醛通常被氧化为羧酸；但富电子的芳香醛（如 4-羟基苯甲醛）主要是芳基迁移，生成甲酸酯，水解后得到酚（Dakin 氧化）。于是苯乙酮给出乙酸苯酯，2-甲基环己酮的氧插入在取代较多的一侧，生成 7-甲基氧杂环庚-2-酮。环己酮的 Baeyer–Villiger 氧化生成 ε-己内酯，是聚己内酯（可生物降解的医用高分子）单体的工业来源。生物体内的 Baeyer–Villiger 单加氧酶（BVMO）以黄素–过氧化物为氧化剂、NADPH 为还原剂，能对映选择性地氧化**前手性**环酮，被用于制备**手性**内酯。Baeyer–Villiger 氧化作为 1,2-迁移到缺电子氧上的重排，与其他重排反应一起在 [6.5.30](/6.5.30#sec-30.2.2) 中比较。

![Dakin 氧化：过氧氢根加成到 4-羟基苯甲醛的羰基上；四面体加成物中氧负离子推动，富电子的芳基带着成键电子对迁移到近端氧上，O–O 键断裂、$\ce{HO-}$ 离去，生成甲酸芳基酯，碱中水解得到对苯二酚与甲酸根](./plots/dakin.py)

异丙苯法： 工业上苯酚与丙酮的联产（异丙苯法，Hock 法）包含同类的迁移：苯与丙烯经 **Friedel–Crafts 烷基化**得到异丙苯；异丙苯的叔 C–H 被空气自氧化为异丙苯过氧化氢（自由基链，[6.5.7](/6.5.7#sec-7.3.3)）；过氧化氢在酸催化下失去水时，苯基从碳迁移到缺电子的氧上（Hock 重排），生成的氧鎓离子水解为苯酚与丙酮。

```smiles
CC(C)c1ccccc1>>CC(C)(OO)c1ccccc1
CC(C)(OO)c1ccccc1>>Oc1ccccc1.CC(C)=O
```

![Hock 重排：异丙苯过氧化氢末端 OH 质子化后，苯基带着成键电子对从碳迁移到缺电子的近端氧上，同时水离去；生成的氧鎓离子与水加成得到半缩酮，后者分解为苯酚与丙酮](./plots/hock.py)

## 17.6. α,β-不饱和醛酮的加成

### 17.6.1. 结构与两种亲电位置

不饱和醛酮按 C=C 与羰基的相对位置分为三类：C=C 与羰基碳直接相连（烯酮 $\ce{R2C=C=O}$，17.9），C=C 与羰基共轭（α,β-不饱和醛酮），二者被饱和碳隔开（性质与单独的烯烃、醛酮相同）。α,β-不饱和醛酮的 C=C 与 C=O 构成一个共轭的**离域 π 键**，**共振式**把正电荷放在羰基碳（C1）与 β 碳（C3）上：

```smiles
C=CC=O.[CH2+]C=C[O-]
```

所以**亲核试剂**有两个进攻位置：加到羰基碳上的 **1,2-加成**，与加到 β 碳上的共轭加成（**1,4-加成**）。用 [6.5.2](/6.5.2#sec-2.2) 的 **Hückel 方法**计算丙烯醛的 π 轨道（氧的参数 $h_{\mathrm{O}} = 1$，$k_{\mathrm{CO}} = 1$），LUMO 在 β 碳上的系数最大、在羰基碳上次之；而电荷（静电作用）集中在羰基碳上。这正是两种加成之间竞争的轨道根源。

![用 Hückel 方法计算的丙烯醛 π 分子轨道（O 的库仑积分取 α + β，C=O 的共振积分取 β）：左为能级，右为 LUMO 的原子系数。LUMO 在 β 碳（C3）上的系数最大，软亲核试剂在此进攻](./plots/acrolein-huckel.py)

**定义 17.6.1（共轭加成）** 亲核试剂加到 α,β-不饱和羰基化合物（或其他与吸电子基团共轭的烯烃）的 β 碳上，负电荷经共轭转移到羰基氧上生成烯醇负离子，再在 α 碳上质子化（或与其他亲电试剂结合）的反应称为**共轭加成**（conjugate addition）。

共轭加成的产物形式上是 C3、C4 上的"3,4-加成"（Nu 与 H 加到 C=C 上），但机理上是 1,4-加成：Nu 加到 C4（按 O=C–C=C 从氧数起）、质子加到 O1，得到**烯醇**，烯醇再**互变异构**为酮（[6.5.21](/6.5.21#sec-21.2)）。

![共轭加成的一般机理：亲核试剂进攻 β 碳，C=C 的 π 电子移到 α 碳与羰基碳之间，C=O 的 π 电子移到氧上，生成烯醇负离子；氧（或 α 碳）质子化后，烯醇互变为饱和酮](./plots/conjugate-addition.py)

### 17.6.2. 1,2-加成与 1,4-加成的选择

| 倾向 | 亲核试剂 | 原因 |
|---|---|---|
| 1,2-加成 | RLi、$\ce{LiAlH4}$、Luche 条件、多数 **Grignard 试剂**与醛 | 硬、反应快而不可逆，进攻电荷大的羰基碳（**动力学控制**） |
| 1,2-加成 | $\ce{NH2OH}$、$\ce{H2NNH2}$、氨基脲 | 生成结晶的肟、腙从溶液中析出，平衡被拉向 1,2-产物 |
| 1,4-加成 | 胺、硫醇、$\ce{CN-}$、醇（碱催化）、稳定**碳负离子**（丙二酸酯、乙酰乙酸酯的负离子） | 软，或加成可逆：1,2-加成物回到原料，最终流向保留强 C=O 的 1,4-产物（**热力学控制**） |
| 1,4-加成 | **二烷基铜锂** $\ce{R2CuLi}$，Grignard 试剂 + 催化量 Cu(I) | 软的有机铜试剂，经铜的 π 配合物进行 |
| 视位阻而定 | Grignard 试剂与酮 | 羰基旁位阻大时 1,4，位阻小时 1,2 |

1,4-产物保留了强的 C=O 键而牺牲了较弱的 C=C 键，热力学上总是更稳定；所以 1,2 与 1,4 的竞争与 [6.5.11](/6.5.11#sec-11.6.2) 中共轭二烯的加成一样，是动力学控制与热力学控制的问题。

### 17.6.3. Michael 加成

**定义 17.6.2（Michael 加成）** 稳定的碳负离子（Michael 给体，如丙二酸酯、乙酰乙酸酯、硝基烷烃与氰基乙酸酯的负离子）在碱催化下与 α,β-不饱和羰基化合物、腈、硝基烯烃等（Michael 受体）发生的共轭加成称为 **Michael 加成**（Michael addition）。

```smiles
CCOC(=O)CC(=O)OCC.C=CC(C)=O>>CCOC(=O)C(CCC(C)=O)C(=O)OCC
```

上式是丙二酸二乙酯与丁-3-烯-2-酮（甲基乙烯基酮）在乙醇钠催化下的 Michael 加成。Michael 给体的 $\mathrm{p}K_{\mathrm{a}}$ 在 9–13（[6.5.3 表 3.2](/6.5.3#sec-3.1.4)：乙酰丙酮 8.9，乙酰乙酸乙酯 10.7，丙二酸二乙酯约 13），用醇钠、胺或 DBU 就能在催化量下生成足够的负离子；加成后生成的**烯醇负离子**（羰基的 α-H，$\mathrm{p}K_{\mathrm{a}}$ 约 19–25）碱性更强，从溶剂或另一分子给体夺取质子，再生催化用的碱。Michael（1887）最早的例子是丙二酸酯与肉桂酸乙酯的加成；产物中新生成的 C–C 键位于给体与受体的 β 碳之间，常产生新的**手性中心**。Michael 加成与随后的分子内羟醛缩合组成 **Robinson 环化**（定义 22.5.1），在合成甾体与萜类的六元环时极为重要。

![Michael 加成：丙二酸二乙酯的烯醇负离子进攻甲基乙烯基酮的 β 碳，C=C 的 π 电子移到 α 碳与羰基碳之间，C=O 的 π 电子移到氧上，生成新的烯醇负离子；它从乙醇夺取质子，再生乙氧负离子](./plots/michael.py)

Michael 加成在生物与药物化学中同样重要：谷胱甘肽的巯基对 α,β-不饱和羰基化合物（如丙烯醛、对乙酰氨基酚的代谢物 NAPQI）的共轭加成是细胞解毒的主要途径；许多"共价药物"在分子中设计一个弱的 Michael 受体（丙烯酰胺"弹头"），与靶蛋白活性位点附近的半胱氨酸巯基不可逆地共价结合，如治疗淋巴瘤的伊布替尼和治疗肺癌的奥希替尼。**有机小分子催化**的不对称 Michael 加成（经亚胺正离子或**烯胺**中间体，[6.5.16](/6.5.16#sec-16.9.3)）是 MacMillan 与 List 获 2021 年诺贝尔化学奖的工作的核心反应之一。

### 17.6.4. 有机铜试剂的共轭加成

二烷基铜锂（**Gilman 试剂**，$\ce{R2CuLi}$，由两当量 RLi 与 CuI 生成，[6.5.10](/6.5.10#sec-10.4.2)）几乎只发生共轭加成，是向 β 位引入烷基、芳基与烯基的标准方法；Grignard 试剂在 1–5 mol% CuI 或 $\ce{CuBr*SMe2}$ 存在下也转为 1,4-加成。

```smiles
CC1=CC(=O)CCC1>>CC1(C)CCCC(=O)C1
```

（3-甲基环己-2-烯-1-酮与 $\ce{(CH3)2CuLi}$ 反应，在季碳上引入甲基，得到 3,3-二甲基环己酮。）机理不是简单的"软碳负离子"加成：d¹⁰ 的 Cu(I) 先与 α,β-不饱和酮的 C=C 形成 π 配合物（$\ce{Li+}$ 同时活化羰基），再经**氧化加成**生成 β-铜(III) 的烯醇盐，最后**还原消除**形成 C–C 键（这些基元反应见 [6.5.28](/6.5.28#sec-28.4.2)）。共轭加成生成的烯醇锂可以原位被卤代烷、醛捕获，在 α 与 β 位一次引入两个基团（串联共轭加成–烷基化）；Noyori 的前列腺素"三组分偶联"就是这样把两条侧链装到环戊烯酮上的。用**手性**膦配体的铜催化剂，Grignard 或有机锌试剂的共轭加成可以高度对映选择地进行（Feringa 等）。

![二甲基铜锂与 3-甲基环己-2-烯-1-酮的共轭加成：Cu(I) 与 C=C 形成 π 配合物后经氧化加成生成 β-铜(III) 烯醇锂；还原消除时 Cu–$\ce{CH3}$ 键的电子形成新的 C–C 键，Cu–C 键的电子回到铜上，放出 MeCu；烯醇锂质子化得到 3,3-二甲基环己酮](./plots/cuprate.py)

硫**叶立德**与 α,β-不饱和酮的**环丙烷化**（[6.5.16](/6.5.16#sec-16.8.3)）是另一种重要的共轭加成：可逆加成的稳定叶立德最终进入 1,4-途径。

## 17.7. 不饱和醛酮的选择性还原

α,β-不饱和醛酮有 C=C 与 C=O 两个可还原的位置，选择不同的还原剂可以得到三种产物：

| 产物 | 方法 | 说明 |
|---|---|---|
| 烯丙醇（只还原 C=O） | Luche 还原（17.1.3）；DIBAL；$\ce{LiAlH4}$ 低温；MPV 还原；9-BBN | 1,2-还原 |
| 饱和醛酮（只还原 C=C） | $\ce{H2}$，Pd/C（控制 $\ce{H2}$ 的量）；Li/液氨；L-Selectride 或 K-Selectride（多数环状 α,β-不饱和酮）；Stryker 试剂（铜氢化物） | 共轭还原（1,4-还原） |
| 饱和醇（都还原） | 过量 $\ce{H2}$，Pt 或 Ni；过量 $\ce{LiAlH4}$ 加热（肉桂醛） | — |

例如肉桂醛：$\ce{NaBH4}$ 或 $\ce{LiAlH4}$ 在 $-10\,^\circ\mathrm{C}$ 下给出肉桂醇；过量 $\ce{LiAlH4}$ 在回流的乙醚中给出 3-苯基丙醇——先 1,2-还原，生成的烯丙基烷氧铝再对邻近的 C=C 进行分子内的氢铝化，这是苯基与烯丙醇共同造成的特例，一般的 C=C 不被 $\ce{LiAlH4}$ 还原。丙烯醛在 Ni 上依次加氢，先得到丙醛，再得到丙醇；共轭体系中 C=C 比 C=O 更容易被催化氢化。

```smiles
O=C/C=C/c1ccccc1>>OC/C=C/c1ccccc1
O=C/C=C/c1ccccc1>>OCCCc1ccccc1
```

Li/液氨还原环状 α,β-不饱和酮（Birch 型）先把电子加到 LUMO 上生成**自由基负离子**，在 β 碳上质子化后再得一个电子，生成烯醇锂；它在没有质子源时保持为**烯醇负离子**，可以原位烷基化，并以热力学上更稳定的立体化学生成反式稠环（Stork 的甾体合成）。生物体内的烯还原酶（ene reductase，"老黄酶"家族）以黄素与 NADPH **立体选择性**地共轭还原 C=C，是生物催化的又一例。

## 17.8. 醌

### 17.8.1. 结构与命名

醌是环状的共轭二酮：两个羰基位于同一个六元环上，环内有两个（或与稠环共用的）C=C，整个分子与对应的芳香二酚（氢醌）只差两个氢。

**定义 17.8.1（醌）** 由芳香化合物衍生、把芳环上偶数个 CH 换成 C=O 并使双键重排成共轭的非芳香环状二酮（如环己-2,5-二烯-1,4-二酮）称为**醌**（quinone）。

```smiles
O=C1C=CC(=O)C=C1 1
O=C1C=CC=CC1=O 2
O=C1C=CC(=O)c2ccccc21 3
O=C1c2ccccc2C(=O)c2ccccc12 4
O=C1C(=O)c2ccccc2-c2ccccc21 5
```

| 序号 | 名称 | 系统名 |
|---|---|---|
| 1 | 对苯醌（1,4-苯醌） | 环己-2,5-二烯-1,4-二酮 |
| 2 | 邻苯醌（1,2-苯醌） | 环己-3,5-二烯-1,2-二酮 |
| 3 | 1,4-萘醌 | 萘-1,4-二酮 |
| 4 | 9,10-蒽醌 | 蒽-9,10-二酮 |
| 5 | 9,10-菲醌 | 菲-9,10-二酮 |

醌环中没有**芳香性**，键长明显地单双键交替（对苯醌 C=C $134\,\mathrm{pm}$、C–C $148\,\mathrm{pm}$）。醌都有颜色：对苯醌黄色，邻苯醌红色，它们的 n→π* 吸收与 C=C–C=O 共轭的 π→π* 吸收延伸到可见区（[6.4.9](/6.4.9)）。蒽醌骨架是茜素等天然染料与许多合成染料的母体，也是工业上生产过氧化氢的蒽醌法的载体（2-乙基蒽醌被 $\ce{H2}$ 还原为蒽氢醌，后者被空气氧化回蒽醌并放出 $\ce{H2O2}$）。

### 17.8.2. 醌的加成反应

醌是 α,β-不饱和酮，也是活泼的亲二烯体：

- C=C 的加成：对苯醌与 $\ce{Br2}$ 加成生成二溴或四溴化物；作为缺电子的亲二烯体，与 1,3-丁二烯在室温下就发生 **Diels–Alder 反应**（[6.5.12](/6.5.12#sec-12.4.3)），这是 Woodward 合成甾体（1951）与利血平（1956）时构建稠环的经典步骤。
- C=O 的加成：与羟胺生成单肟与双肟。对苯醌单肟与 4-亚硝基苯酚是同一化合物的两种**互变异构体**（在溶液中以醌肟式为主）。有机金属试剂加到羰基上生成醌醇（4-烃基-4-羟基环己-2,5-二烯酮），它在酸中经二烯酮–酚重排（烃基迁移到相邻碳上）变为烃基取代的苯二酚：芳香性的恢复是驱动力。
- 共轭加成后芳构化：HCl、HCN、胺、硫醇与醌发生 **1,4-加成**，生成的**烯醇**互变为芳香的氢醌，例如对苯醌与 HCl 得到 2-氯苯-1,4-二酚。产物（取代氢醌）可以被未反应的醌再氧化为取代醌，所以胺与醌反应常得到 2,5-二氨基醌。在生物体内，许多毒物与药物代谢产物中的醌通过这种方式与蛋白质的半胱氨酸、赖氨酸共价结合，是其毒性的来源。

```smiles
O=C1C=CC(=O)C=C1.Cl>>Oc1ccc(O)c(Cl)c1
```

![对苯醌与 HCl 的共轭加成：一个羰基氧质子化后，$\ce{Cl-}$ 进攻 β 碳（C3），C2=C3 的 π 电子移到 C1–C2 之间，C=O 的 π 电子移到质子化的氧上，生成烯醇；剩下的酮羰基互变（C3–H 的质子转移到 C4 的氧上），恢复芳香性，得到 2-氯苯-1,4-二酚](./plots/quinone-hcl.py)

### 17.8.3. 醌–氢醌电对与半醌

对苯醌（Q）与对苯二酚（氢醌，$\ce{H2Q}$）组成一个可逆的二电子、二质子**氧化还原电对**：

$$
\ce{Q + 2H+ + 2e- <=> H2Q}, \qquad E^\circ = +0.699\,\mathrm{V}
$$
（25 °C，相对于标准氢电极，CRC）。按 **Nernst 方程**（[6.1.11](/6.1.11)），在 $\mathrm{pH} < \mathrm{p}K_{\mathrm{a1}}$ 时，$E = E^\circ - 0.0592\,\mathrm{V}\times\mathrm{pH} - \frac{0.0592\,\mathrm{V}}{2}\lg\frac{[\ce{H2Q}]}{[\ce{Q}]}$，电势随 pH 每单位下降 $59\,\mathrm{mV}$；在氢醌两级酸解离的 $\mathrm{p}K_{\mathrm{a}}$（约 9.9 与 11.4）以上，参加反应的质子数减少，斜率依次变为 $-29.6\,\mathrm{mV}$ 与 0。等物质的量的醌与氢醌形成深绿色的电荷转移复合物——醌氢醌，它的饱和溶液中 $[\ce{Q}] = [\ce{H2Q}]$，铂电极的电势只取决于 pH，这就是醌氢醌电极（**氧化还原电极**的一种，[6.3.13](/6.3.13#sec-13.1.4)），曾用于测定 pH。

![对苯醌/氢醌电对的条件电势随 pH 的变化（等浓度的醌与全部还原型）：pH 9.9 以下斜率 −59 mV/pH，两个酸解离常数之间 −30 mV/pH，pH 11.4 以上与 pH 无关](./plots/quinone-potential.py)

二电子还原是分两步进行的：醌先得到一个电子生成半醌**自由基负离子**（在碱性溶液或非质子性溶剂中可以用**电子顺磁共振**观察），再得到一个电子和两个质子成为氢醌；在中性水溶液中，半醌质子化为中性的半醌**自由基**。

**定义 17.8.2（半醌）** 醌得到一个电子（及质子）生成的自由基中间体（$\ce{Q^{.-}}$ 或 $\ce{QH^{.}}$）称为**半醌**（semiquinone）。

```smiles
O=C1C=CC(=O)C=C1>>[O-]c1ccc([O])cc1
[O-]c1ccc([O])cc1>>Oc1ccc(O)cc1
```

醌–氢醌–半醌的化学是生物能量转换的核心：线粒体呼吸链中的泛醌（辅酶 Q₁₀）与光合作用中的质体醌作为脂溶性的电子与质子载体，在膜内两侧之间往返，每次二电子还原都要从膜的一侧摄取两个质子、在另一侧放出（Q 循环），由此建立质子梯度；维生素 K（一种 1,4-萘醌）是凝血因子 γ-羧化的辅因子。氧化电势高的醌是有机合成中常用的脱氢氧化剂：2,3-二氯-5,6-二氰基苯醌（DDQ）与四氯苯醌（氯醌）能使氢化芳烃芳构化，DDQ 还用于除去对甲氧基苄基（PMB）**保护基**。

## 17.9. 烯酮

**定义 17.9.1（烯酮）** 含有累积的 C=C=O 结构的化合物 $\ce{R2C=C=O}$ 称为**烯酮**（ketene）；最简单的是乙烯酮 $\ce{H2C=C=O}$。

（注意中文"烯酮"有时也用来泛指 α,β-不饱和酮，如"环己烯酮"；本站把 C=C=O 化合物称为烯酮，把 α,β-不饱和酮写全。）烯酮的中心碳为 sp 杂化，与联烯一样，C=C 与 C=O 的两个 π 体系互相垂直；羰基的 π* 轨道位于分子平面内，在中心碳上系数大，所以**亲核试剂**在分子平面内进攻中心碳。乙烯酮是有剧毒、刺激性气味的气体（沸点 $-56\,^\circ\mathrm{C}$），不稳定，室温下即二聚为双烯酮。制法：

- 丙酮或乙酸在 $700$–$850\,^\circ\mathrm{C}$ 热解（乙酸在 $\ce{AlPO4}$ 上脱水），工业上用于生产乙酸酐；
- 酰氯与三乙胺在低温下脱去 HCl（**E1cb** 型消除，生成的烯酮原位使用）；
- α-重氮酮的 **Wolff 重排**（光照或 Ag(I) 催化，定义 24.5.2）。

![酰氯与三乙胺生成烯酮（E1cb）：三乙胺夺去被羰基活化的 α-H，生成烯醇负离子；氧负离子的电子对推回形成 C=O，同一个碳上的氯离子离去，得到甲基烯酮](./plots/ketene-e1cb.py)

与含活泼氢的化合物加成： 烯酮是强的酰化剂：水、醇、胺、羧酸、HCl 都加到 C=O 上（亲核原子与中心碳成键，H 加到氧上），生成的**烯醇**再**互变异构**为乙酸、乙酸酯、乙酰胺、乙酸酐与乙酰氯。整体相当于引入一个乙酰基。

![醇对乙烯酮的加成：醇氧的孤对电子在分子平面内进攻中心碳，C=O 的 π 电子移到氧上，得到烯醇负离子与质子化的醇；质子转移得到烯醇，烯醇互变异构为乙酸甲酯](./plots/ketene-addition.py)

```smiles
C=C=O.OC(C)=O>>CC(=O)OC(C)=O
C=C=O.CC[Mg]Br>>CCC(C)=O
```

与 **Grignard 试剂**加成后，生成的烯醇镁盐水解得到甲基酮。烯酮的 [2+2] **环加成**生成环丁酮（[6.5.12](/6.5.12#sec-12.4.6)），与**亚胺**的 [2+2] 加成生成 β-内酰胺（Staudinger 反应，[6.5.25](/6.5.25#sec-25.9.2)）。

双烯酮： 乙烯酮的二聚体是 4-亚甲基氧杂环丁-2-酮（β-内酯），称为双烯酮（diketene）。它与醇、胺等发生开环的酰化，得到乙酰乙酸酯与乙酰乙酰胺，相当于引入一个四碳的乙酰乙酰基；工业上的乙酰乙酸乙酯（[6.5.22](/6.5.22#sec-22.8)）就是用双烯酮与乙醇生产的。

```smiles
C=C1CC(=O)O1.CCO>>CCOC(=O)CC(C)=O
```

## 小结

- 负氢还原：$\ce{LiAlH4}$ 活性高、还原大多数羰基化合物；$\ce{NaBH4}$ 温和，只还原醛酮（与酰氯）；DIBAL 是 Lewis 酸性的；硼烷是亲电的，迅速还原羧酸，并与 C=C 发生**硼氢化**。小试剂从直立方向进攻环己酮（避开扭转张力），给出平伏醇；L-Selectride 从平伏方向进攻，给出直立醇。
- 选择性还原：Luche 还原（定义 17.1.1）只还原 C=O；CBS 还原（定义 17.2.1）用**手性**噁唑硼烷区分 Re/**Si 面**；MPV 还原与 Oppenauer 氧化（定义 17.2.2）是平衡控制的负氢转移，**化学选择性**极好。

| 转化 | 方法 |
|---|---|
| C=O → CH–OH | $\ce{NaBH4}$、$\ce{LiAlH4}$、DIBAL、$\ce{BH3}$、催化氢化、MPV、CBS（不对称） |
| 2 C=O → 邻二醇 | 频哪醇偶联（定义 17.3.2）：Mg(Hg)、Na（非质子性溶剂）、$\ce{SmI2}$；经羰游基（定义 17.3.1） |
| 2 C=O → C=C | McMurry 反应（定义 17.3.3）：低价钛 |
| C=O → $\ce{CH2}$ | Clemmensen（定义 17.3.4，酸）、Wolff–Kishner–黄鸣龙（碱）、**硫缩醛**/Raney Ni（中性） |
| 2 ArCHO → $\ce{ArCOO-}$ + $\ce{ArCH2OH}$ | Cannizzaro 反应（定义 17.4.1）：无 α-H 的醛，浓碱；与甲醛交叉 |
| RCHO → RCOOH | Jones、$\ce{KMnO4}$、$\ce{Ag2O}$、Pinnick（$\ce{NaClO2}$）；鉴定：Tollens（银镜）、Fehling（$\ce{Cu2O}$） |
| $\ce{RCOCH2R'}$ → $\ce{RCOCOR'}$ | $\ce{SeO2}$（Riley） |
| $\ce{RCOR'}$ → $\ce{RCOOR'}$ | Baeyer–Villiger 氧化（定义 17.5.1）：叔烷基 > 环己基 > 仲烷基 > 苄基 > 苯基 > 乙烯基 > 伯烷基 > 甲基，构型保持 |

- α,β-不饱和醛酮：LUMO 在 β 碳上系数最大，电荷集中在羰基碳上；硬而不可逆的**亲核试剂** **1,2-加成**（**动力学控制**），软或可逆的亲核试剂共轭加成（定义 17.6.1，**热力学控制**）；Michael 加成（定义 17.6.2）由稳定**碳负离子**进行；铜试剂专一地 **1,4-加成**。
- 醌（定义 17.8.1）：非芳香的共轭二酮，有色；C=C 加成、亲二烯体、共轭加成后芳构化；$\ce{Q/H2Q}$ 的 $E^\circ = 0.699\,\mathrm{V}$，每 pH 单位 $-59\,\mathrm{mV}$；单电子还原生成半醌（定义 17.8.2）；泛醌与质体醌是生物膜中的电子–质子载体。
- 烯酮（定义 17.9.1）：亲核试剂在分子平面内进攻中心碳，是乙酰化剂；双烯酮是乙酰乙酰化剂。

## 思考题

1. 樟脑用 $\ce{LiAlH4}$ 在乙醚中 0 °C 还原，得到 84.5% 的异冰片醇（exo-OH）与 9.5% 的冰片醇（endo-OH）。说明选择性的来源；若改用降冰片酮（无 C7 甲基），主产物是什么？

   **答** 樟脑的羰基在 C2，exo 面朝向一碳桥 C7，而 C7 上有两个甲基，其中与羰基同侧的那个挡住了 exo 方向的 **Bürgi–Dunitz 轨迹**；endo 面朝向两碳桥 C5–C6，只有 endo-H，位阻较小。负氢从 endo 面进攻，OH 留在 exo 面，得到异冰片醇。降冰片酮的 C7 上只有 H，exo 面反而比 endo 面（受 C5、C6 的 endo-H 阻挡）开放，负氢从 exo 面进攻，主要得到 endo-降冰片醇。两例都是空间位阻控制，方向相反。

2. 写出合成路线：(a) 由 4-氧亚基戊酸乙酯得到 4-羟基戊酸乙酯（不还原酯）；(b) 由 4-氧亚基戊酸乙酯得到戊-1,4-二醇；(c) 由环己-2-烯-1-酮得到环己-2-烯-1-醇；(d) 由环己-2-烯-1-酮得到环己酮。

   **答** (a) $\ce{NaBH4}$，乙醇，0 °C：只还原酮（产物在酸中易内酯化为 γ-戊内酯，后处理要避免强酸）。(b) $\ce{LiAlH4}$，THF，再水解：酮与酯都被还原。(c) Luche 还原：$\ce{NaBH4}$/$\ce{CeCl3*7H2O}$，甲醇（或 DIBAL，$-78\,^\circ\mathrm{C}$）。(d) $\ce{H2}$（1 当量），Pd/C；或 Li/液氨后用 $\ce{NH4Cl}$ 淬灭；或 L-Selectride 共轭还原。

3. MPV 还原是可逆的。怎样使它向还原方向进行完全？Oppenauer 氧化又怎样进行完全？为什么 MPV 还原 4-叔丁基环己酮主要得到反式醇？

   **答** MPV 还原用大量异丙醇作溶剂（反应物过量），并在反应过程中不断蒸出生成的丙酮（沸点 $56\,^\circ\mathrm{C}$，是体系中最易挥发的组分），按 **Le Chatelier 原理**使平衡右移。Oppenauer 氧化反过来使用大量丙酮或环己酮（以及氧化性更强的苯醌）作氢受体。由于 MPV 体系中醇与酮在铝催化下不断地互相转化，产物比例由平衡决定（**热力学控制**），反式-4-叔丁基环己醇的 OH 在平伏键上，比顺式（OH 直立，有 1,3-双直立作用）稳定，所以为主。

4. 甲醛与苯甲醛的混合物在浓 NaOH 中反应，主要得到什么？说明为什么是甲醛被氧化。写出由乙醛与甲醛合成季戊四醇的各步反应。

   **答** 主要得到苄醇与甲酸钠。甲醛的羰基没有烷基或芳基给电子与位阻，最容易与 $\ce{HO-}$ 加成，生成的四面体负离子 $\ce{H2C(OH)O-}$ 浓度最大，它作为负氢给体把 H 转移给苯甲醛，自身成为甲酸。季戊四醇：在碱中，乙醛的**烯醇负离子**依次与三分子甲醛进行羟醛加成，得到 $\ce{(HOCH2)3C-CHO}$（3-羟基-2,2-双(羟甲基)丙醛，没有 α-H）；它与第四分子甲醛发生交叉 Cannizzaro 反应，被还原为 $\ce{C(CH2OH)4}$，甲醛被氧化为甲酸盐。总反应 $\ce{CH3CHO + 4HCHO + NaOH -> C(CH2OH)4 + HCOONa}$。

5. 预测下列 Baeyer–Villiger 氧化（mCPBA）的主产物：(a) 环丁酮；(b) 1-环己基乙-1-酮；(c) 4-甲氧基苯乙酮；(d) 1-[(1R,2S)-2-甲基环戊基]乙-1-酮（只问迁移的基团与构型）。

   **答** (a) γ-丁内酯（氧杂环戊-2-酮）；环丁酮的张力使反应特别快，甚至 $\ce{H2O2}$ 就能氧化。(b) 乙酸环己酯：仲烷基（环己基）比甲基易迁移得多。(c) 乙酸 4-甲氧基苯酯：富电子的芳基优先于甲基迁移。(d) 仲烷基（环戊基）迁移，生成乙酸 (1R,2S)-2-甲基环戊酯：迁移碳的构型保持（原来连接乙酰基的**手性**碳，空间排列不变；新连接的 O 与原来的乙酰基都是该碳上优先级最高的基团，所以 CIP 标记不变）。

6. 画出异丙苯过氧化氢在酸催化下生成苯酚与丙酮的机理，并指出它与 Baeyer–Villiger 氧化的共同点。

   **答** (1) 过氧化氢末端的 OH 质子化；(2) 失去水的同时，苯基带着成键电子对从碳迁移到缺电子的氧上（协同，避免生成不稳定的氧正离子），生成被氧孤对电子稳定的氧鎓离子 $\ce{(CH3)2C=O+-Ph}$；(3) 水进攻氧鎓离子碳，生成**半缩酮**；(4) 半缩酮分解为苯酚与丙酮。与 Baeyer–Villiger 氧化相同，关键步骤都是基团向缺电子氧（O–O 键断裂时**离去基团**带走电子）的 1,2-迁移，**迁移倾向**都由迁移基团容纳正电荷的能力决定（苯基迁移远比甲基快）。

7. 下列试剂与 3-甲基丁-3-烯-2-酮（$\ce{CH2=C(CH3)COCH3}$）或环己-2-烯-1-酮反应，主要发生 **1,2-加成**还是 **1,4-加成**？(a) $\ce{CH3Li}$；(b) $\ce{(CH3)2CuLi}$；(c) $\ce{CH3MgBr}$ + 5 mol% CuI；(d) $\ce{PhSH}$/$\ce{Et3N}$；(e) $\ce{NaBH4}$/$\ce{CeCl3}$；(f) 二乙胺。

   **答** (a) 1,2-加成，生成叔烯丙醇（硬、快、不可逆）。(b) 1,4-加成（铜试剂）。(c) 1,4-加成（催化量铜使 **Grignard 试剂**转为有机铜物种）。(d) 1,4-加成（软的硫**亲核试剂**，硫–Michael 加成，可逆而热力学控制）。(e) 1,2-还原，生成烯丙醇（Luche）。(f) 1,4-加成（氮–Michael 加成，可逆；1,2-加成生成的半缩醛胺回到原料）。

8. 由环己-2-烯-1-酮与丙二酸二乙酯出发，经 Michael 加成、水解与**脱羧**，得到什么化合物？说明碱只需催化量的原因。

   **答** 丙二酸二乙酯负离子加到环己烯酮的 β 碳上，得到 2-(3-氧亚基环己基)丙二酸二乙酯；酸性水解两个酯基后，加热使取代丙二酸脱羧（[6.5.18](/6.5.18#sec-18.4.1)），得到 (3-氧亚基环己基)乙酸。加成生成的烯醇负离子是比丙二酸酯负离子更强的碱（其共轭酸为酮的 α-H，$\mathrm{p}K_{\mathrm{a}}$ 约 19–20，而丙二酸二乙酯约 13），它从另一分子丙二酸二乙酯或溶剂乙醇夺取质子，生成产物并再生丙二酸酯负离子或乙氧负离子，所以碱在循环中不被消耗。

9. 用电极电势说明：为什么在 pH 7 时，对苯醌能氧化抗坏血酸（维生素 C），而在强碱中这种氧化能力减弱？计算 pH 7、$[\ce{Q}] = [\ce{H2Q}]$ 时醌–氢醌电对的电势。

   **答** pH 7 低于氢醌的 $\mathrm{p}K_{\mathrm{a1}}$（约 9.9），$E = 0.699 - 0.0592 \times 7 = 0.285\,\mathrm{V}$。抗坏血酸的脱氢抗坏血酸/抗坏血酸电对在 pH 7 的条件电势约为 $+0.06\,\mathrm{V}$，比 $0.285\,\mathrm{V}$ 低，所以醌能把抗坏血酸氧化为脱氢抗坏血酸。醌电对的电势随 pH 升高而下降（每单位 59 mV，pH 9.9 以上斜率减小），在强碱中醌的氧化能力明显减弱。生物体内正是通过质子的摄取与释放调节醌类的电势。

10. 乙烯酮分别与水、甲醇、氨、乙酸、HCl 和 $\ce{CH3MgBr}$（后水解）反应，各得到什么？双烯酮与乙醇呢？为什么称烯酮为"乙酰化剂"？

    **答** 乙酸、乙酸甲酯、乙酰胺、乙酸酐、乙酰氯、丙酮（经烯醇镁盐水解为甲基酮）。双烯酮与乙醇开环得到乙酰乙酸乙酯。在这些反应中，烯酮的 $\ce{CH2=C=O}$ 单元与 H–Nu 结合成 $\ce{CH3C(=O)-Nu}$，即把一个乙酰基连到亲核原子上，与乙酰氯、乙酸酐作用相同，而且不产生副产物（加成而非取代），所以称为乙酰化剂；双烯酮则引入乙酰乙酰基 $\ce{CH3COCH2CO-}$。
