环中含有碳以外的原子（N、O、S 等）的环状化合物是有机化合物中最大的一类。核酸的碱基、组氨酸与色氨酸的侧链、叶绿素与血红素的卟啉、维生素 B1、B2、B6 与 B12、绝大多数生物碱，以及约六成的小分子药物，都含有杂环。本章先讲杂环的分类与命名，然后以芳香杂环为主：它们的电子结构与**芳香性**已在 [6.5.13 的 13.8 节](/6.5.13#sec-13.8) 讨论过，这里在此基础上讲碱性、亲电与**亲核取代**、自由基取代、还原与**环加成**、合成方法，再专门讨论核酸中的嘌呤与嘧啶。最后一节讲饱和杂环：环氧化合物与氮杂环丙烷、内酯与内酰胺。**芳香亲电取代**与**芳香亲核取代**的一般机理见 [6.5.14](/6.5.14#sec-14.2)，胺的结构与碱性见 [6.5.23](/6.5.23#sec-23.4)；核苷与核酸的化学见 [6.5.33](/6.5.33#sec-33.9)。

## 25.1. 分类与命名

### 25.1.1. 分类

**定义 25.1.1（杂环化合物）** 成环原子中除碳外还含有一个或几个其他原子（杂原子，最常见的是 N、O、S）的环状化合物称为**杂环化合物**（heterocyclic compound）。

杂环化合物分为两类。非芳香杂环（饱和或部分不饱和的杂环）的性质与相应的开链化合物相似：四氢呋喃像醚，哌啶像仲胺，内酯与内酰胺像酯与酰胺，只是小环的张力使环氧化合物与氮杂环丙烷特别活泼。芳香杂环满足 **Hückel 规则**，有芳香稳定化，性质与苯相似又有重要的区别，主要有两类：五元的"杂环戊二烯"（吡咯、呋喃、噻吩，杂原子提供一对电子）与六元的"氮杂苯"（吡啶、嘧啶，N 提供一个电子）。

天然产物与药物中的杂环无处不在。必需氨基酸组氨酸（咪唑）与色氨酸（吲哚）的侧链是芳香杂环；脯氨酸的侧链与 $\alpha$-氨基组成吡咯烷环，但脯氨酸不是必需氨基酸。吗啡、可卡因、尼古丁等生物碱（[6.5.23](/6.5.23#sec-23.1.3)）的氮都在杂环中。青蒿素是含过氧桥的倍半萜内酯（1,2,4-三氧杂环己烷），屠呦呦因发现青蒿素治疗疟疾获 2015 年诺贝尔生理学或医学奖。

### 25.1.2. 命名

常见的芳香杂环都有保留的俗名，IUPAC 2013 推荐与中国化学会 2017 规则都沿用它们；中文名多是"口"字旁加音译字。

**定义 25.1.2（吡咯、吡啶与吲哚）** 含一个氮原子的五元芳香杂环 $\ce{C4H4NH}$ 称为**吡咯**（pyrrole）；含一个氮原子的六元芳香杂环 $\ce{C5H5N}$ 称为**吡啶**（pyridine）；苯环与吡咯环共用吡咯的 C2–C3 键稠合而成的双环芳香化合物称为**吲哚**（indole）。

几点说明：

- 吡喃（pyran）本身是含一个 $\mathrm{sp^3}$ 碳的非芳香化合物（2H-吡喃、4H-吡喃）；与吡啶等电子的芳香体系是吡喃鎓离子 $\ce{C5H5O+}$。
- "二嗪"（diazine）是三种含两个 N 的六元环的总称，1,2-二嗪的名称是哒嗪（pyridazine）。
- 编号：单杂原子的环从杂原子开始编为 1，使取代基位次尽量低；吲哚与喹啉保持固定的编号（吲哚 N1、C2、C3，苯环 C4–C7；异喹啉的 N 在 2 位）。含几个杂原子时，按 O > S > N 的次序使优先的杂原子编为 1，并使杂原子的位次尽量低：噁唑 O1、N3，噻唑 S1、N3；咪唑中连 H 的 N 为 1 位。嘌呤的编号是历史上沿用的特殊编号（25.8.1）。
- 饱和杂环可以用俗名（四氢呋喃、吡咯烷、哌啶、吗啉），也可以用置换命名（在碳环名前加 oxa-、aza-、thia-，即"氧杂""氮杂""硫杂"：3-甲基氧杂环己烷，即 3-甲基四氢吡喃）或 Hantzsch–Widman 名（环大小与饱和度由词尾表示，如三元环 oxirane 环氧乙烷、aziridine 氮杂环丙烷，四元环 oxetane 氧杂环丁烷、azetidine 氮杂环丁烷）。
- 稠环用"苯并"加杂环名，方括号中的字母标明杂环中参与稠合的键：杂环的 1–2 键为 a、2–3 键为 b，依次类推。苯并呋喃的苯环稠合在呋喃的 2,3-键上，全名为苯并[b]呋喃（benzo[b]furan，通常简称苯并呋喃）；稠合在 3,4-键上的是苯并[c]呋喃（异苯并呋喃）。

## 25.2. 芳香杂环的电子结构与芳香性

[6.5.13 的 13.8 节](/6.5.13#sec-13.8) 说明了判断芳香杂环电子结构的规律：参与形成环内双键的杂原子（吡啶的 N、咪唑的 N3）用一个 p 电子参加 π 体系，孤对电子在环平面内的 sp² 轨道中；不参与双键的杂原子（吡咯的 NH、呋喃的 O、噻吩的 S、咪唑的 N1）用一对 p 电子参加 π 体系。于是：

- 五元杂环的 6 个 π 电子分布在 5 个原子上，环上碳的电子密度比苯高，称为富 π（π-excessive）杂环，容易发生亲电取代；
- 吡啶的 6 个 π 电子分布在 6 个原子上，**电负性**大的 N 把电子拉向自己，环上碳的电子密度比苯低，称为缺 π（π-deficient）杂环，亲电取代困难，**亲核取代**容易。

**芳香性**的强弱可以用几种互相独立的指标衡量，它们给出的次序大体一致：

| 指标 | 苯 | 噻吩 | 吡咯 | 呋喃 |
|---|---|---|---|---|
| 经验共振能 / $(\mathrm{kJ\,mol^{-1}})$ | 约 150 | 约 121 | 约 88 | 约 67 |
| C2–C3 / C3–C4 键长 / pm | 139 / 139 | 137 / 142 | 138 / 142 | 136 / 143 |
| 键长平均化程度 | 完全 | 较高 | 中等 | 较低 |

（前三者的共振能取 [6.5.13](/6.5.13#sec-13.8) 的数值；吡啶约 117，与苯接近。）杂原子的电负性越大（O > N > S），它的孤对电子越不愿意离域到环上，芳香性越弱。另一个常用的指标是 **核独立化学位移**（NICS，[6.5.13 的定义 13.4.2](/6.5.13#def-13.4.2)），它度量**环电流**产生的磁屏蔽：五元杂环的 NICS 都是较大的负值，说明有显著的环电流；不过 NICS(0) 受 σ 键的干扰，不同的指标给出的细节次序不尽相同，芳香性不是一个可以用单一数字完全刻画的性质。¹H NMR 中五元杂环的环上 H 在 $\delta$ 6.2–7.4（吡咯 C2–H 6.7、C3–H 6.2；呋喃 7.4 与 6.4），吡啶的在 $\delta$ 7.3–8.6，都在芳香区。

芳香性与反应性的关系值得注意：芳香性越弱，环越容易发生破坏芳香性的反应（加成、**Diels–Alder 反应**）。呋喃的芳香性最弱，它的亲电取代常常"中断"为加成（25.4.4），也是五元杂环中最好的双烯体（25.6.2）。但亲电取代的速率主要由杂原子稳定 **σ 络合物**正电荷的能力决定（N > O > S），所以速率次序是 吡咯 > 呋喃 > 噻吩，与芳香性的次序并不相同（25.4.1）。

## 25.3. 碱性与酸性

### 25.3.1. 含氮芳香杂环的碱性

含氮杂环的碱性取决于 N 的孤对电子是否属于芳香 π 体系（[6.5.3 的统一 pKa 表](/6.5.3#sec-3.1.4)；带 * 的为表外的 CRC 补充数据）：

| 共轭酸 | $\mathrm{p}K_{\mathrm{a}}$（水，25 °C） | 质子化的位置与原因 |
|---|---|---|
| 哌啶鎓 | 11.12 | sp³ N，参照 |
| 咪唑鎓 | 6.99 | N3（吡啶型 N）；正电荷在两个 N 上对称离域（脒型共振） |
| 吡啶鎓 | 5.23 | sp² 孤对电子，s 成分 33%，碱性比 sp³ 胺弱 $10^6$ 倍 |
| 异喹啉鎓* | 5.4 | 同吡啶 |
| 喹啉鎓* | 4.9 | 同吡啶，稠合的苯环略有吸电子作用 |
| 噻唑鎓* | 2.5 | S 的吸电子诱导 |
| 嘧啶鎓* | 1.3 | 第二个 N 的强吸电子作用 |
| 噁唑鎓* | 0.8 | O 的电负性更大 |
| 吡咯（C2 上质子化） | $-3.8$ | N 的孤对电子属于 6π 体系，N 上质子化会破坏**芳香性** |

咪唑的碱性比吡啶强约 50 倍：质子化后的咪唑鎓离子中，正电荷可以由两个等价的共振式分散在两个 N 上，而 N1 的孤对电子正好推向 N3。咪唑鎓的 $\mathrm{p}K_{\mathrm{a}}$（约 7；组氨酸侧链在游离氨基酸中约 6.0，在蛋白质中随环境在 6–7 之间变化）接近生理 pH，咪唑在中性条件下同时以质子化与未质子化的形式存在，既能给出质子、也能接受质子，所以组氨酸是酶活性中心最常见的广义**酸碱催化**基团。在丝氨酸蛋白酶的催化三联体（Ser–His–Asp）中，His 的咪唑接受丝氨酸羟基的质子、使后者成为强**亲核试剂**，随后又把质子交给**离去基团**（[6.5.33](/6.5.33#sec-33.8.3)）。咪唑的两个 N 之间的质子转移（**互变异构**）使 4-取代与 5-取代咪唑互相转化，通常写作 4(5)-取代咪唑。

![咪唑的两性：咪唑的 N3 接受质子，生成对称的咪唑鎓离子（两个共振式等价，正电荷离域在两个 N 上）；N1–H 失去质子生成咪唑负离子，负电荷同样离域在两个 N 上](./plots/imidazole.py)

### 25.3.2. N–H 的酸性

吡咯、吲哚与咪唑的 N–H 有弱酸性：水中吡咯约 17.5、咪唑 14.5；DMSO 中吡咯 23.0、吲哚 21.0、咪唑 18.6（表 3.2、3.3）。比二苯胺（DMSO 中 25.0）稍强，因为 N 上的负电荷可以离域到整个芳环上。用 NaH、$\ce{KOH}$/DMSO 或 $n$-BuLi 去质子化后，得到的氮负离子是好的**亲核试剂**，与卤代烷、酰氯反应生成 $N$-取代产物（离子性强的钠、钾盐在**非质子极性溶剂**中以 N-烷基化为主；共价性较强的 Mg 盐则倾向于在 C 上反应）。

```smiles
c1cc[nH]c1>>c1cc[n-]c1
c1cc[n-]c1.CI>>Cn1cccc1
```

## 25.4. 五元杂环与吲哚的亲电取代

### 25.4.1. 反应性与条件

吡咯、呋喃、噻吩都比苯活泼得多，次序为 吡咯 > 呋喃 > 噻吩 ≫ 苯。例如三氟乙酰化的相对速率约为 吡咯 $5\times10^7$ : 呋喃 $1.4\times10^2$ : 噻吩 1。这一次序反映杂原子在 **σ 络合物**中提供电子、稳定正电荷的能力：N 的**电负性**比 O 小，更容易带正电荷；S 的 3p 轨道与碳的 2p 轨道重叠较差。苯的亲电取代需要的强**亲电试剂**与强酸，在这里不但不必要，而且有害：吡咯与呋喃在强酸中质子化后发生聚合（形成黑色树脂），所以要换用温和的试剂：

| 反应 | 苯（[6.5.14](/6.5.14)） | 五元杂环 |
|---|---|---|
| 溴化 | $\ce{Br2}$/$\ce{FeBr3}$ | $\ce{Br2}$ 在 $0\,^\circ\mathrm{C}$ 下，不需催化剂（吡咯易多溴代，一溴代用 NBS） |
| 硝化 | 浓 $\ce{HNO3}$/浓 $\ce{H2SO4}$ | 乙酰硝酸酯（$\ce{HNO3}$/$\ce{Ac2O}$），低温 |
| 磺化 | 发烟硫酸 | 吡啶–$\ce{SO3}$ 复合物 |
| 酰基化 | $\ce{RCOCl}$/$\ce{AlCl3}$ | 酸酐加弱的 **Lewis 酸**（$\ce{BF3.OEt2}$、$\ce{SnCl4}$）；吡咯甚至可以不加催化剂 |
| 甲酰化 | Gattermann–Koch（[6.5.14](/6.5.14#sec-14.10)） | Vilsmeier–Haack（DMF/$\ce{POCl3}$） |

足够富电子的杂环还能与较弱的亲电试剂反应：吲哚与甲醛、二甲胺发生 **Mannich 反应**，生成芽子碱（gramine）；吡咯、呋喃、吲哚与 $\alpha$,$\beta$-不饱和酮发生**共轭加成**（芳环作为**亲核试剂**进攻 $\beta$ 碳，相当于 Friedel–Crafts 型的 **Michael 加成**，[6.5.17](/6.5.17#sec-17.6.3)），在手性催化剂作用下可以不对称地进行。

### 25.4.2. 五元杂环：C2 取代

吡咯、呋喃、噻吩的亲电取代主要发生在 C2（杂原子的邻位，又称 $\alpha$ 位）。比较两种进攻的 **σ 络合物**：进攻 C2 时正电荷可以分布在 C3、C5 与杂原子上，有三个共振式；进攻 C3 时只能分布在 C2 与杂原子上，只有两个共振式（C4=C5 双键是交叉共轭的，不能参与）。两种情况都有一个"鎓"式共振式（杂原子带正电荷、所有原子都满足**八隅律**），它是主要的贡献者；C2 进攻的正电荷离域范围更大，σ 络合物与它前面的过渡态更稳定（**Hammond 假说**，[6.5.3](/6.5.3#sec-3.10)）。

![吡咯亲电取代（以溴化为例）的位置选择性。上：进攻 C2，σ 络合物有三个共振式，正电荷分布在 C3、C5 与 N 上；下：进攻 C3，只有两个共振式（正电荷在 C2 与 N 上）。两行中带正电荷的 N 的共振式（亚胺鎓离子，每个原子都是八隅体）贡献最大](./plots/pyrrole-sear.py)

两个 $\alpha$ 位都被占据时，取代发生在 $\beta$ 位（C3）。环上已有的取代基与环本身的定位作用叠加：给电子取代基强化原有的选择性；2-位的吸电子基团（如 2-乙酰基呋喃、2-噻吩甲酸）使新基团主要进入 C5（另一个 $\alpha$ 位），对吡咯则常得到 C4 与 C5 产物的混合物，选择性下降。

### 25.4.3. 吲哚：C3 取代

吲哚的亲电取代发生在 C3，与吡咯相反。进攻 C3 时，正电荷落在 C2 上，由相邻的 N 的孤对电子直接稳定（亚胺鎓离子），苯环的**芳香性**保持完整；进攻 C2 时，正电荷落在 C3 上，要靠 N 稳定就必须让苯环参与共振，写出的鎓式共振式破坏了苯环的芳香性。吲哚的 C3 活泼到可以与很弱的**亲电试剂**反应，速率约为苯的 $10^{13}$ 倍；色氨酸侧链、5-羟色胺与许多吲哚生物碱的生物合成都利用了 C3 的**亲核性**。C3 被占据时取代发生在 C2（常经过 C3 进攻、再 1,2-迁移）。

![吲哚亲电取代的位置选择性。上：进攻 C3，正电荷在 C2，由 N 的孤对电子稳定为亚胺鎓离子，苯环保持完整；下：进攻 C2，正电荷在 C3，只有苯环参与共振（破坏苯环的芳香性）时 N 才能分担正电荷](./plots/indole-sear.py)

苯并呋喃的情况不同，亲电取代主要发生在 C2：O 稳定正电荷的能力比 N 差，进攻 C3 生成的氧鎓式共振式贡献较小，而进攻 C2 生成的 C3 正离子是被苯环稳定的苄基型正离子，两者相当，实验上以 C2 产物为主；苯并噻吩则以 C3 为主。

### 25.4.4. 中断的亲电取代

呋喃的芳香稳定化能小，**σ 络合物**失去质子恢复**芳香性**的推动力较弱。若反应体系中有**亲核试剂**，它会先捕获 σ 络合物的另一端，得到加成产物：呋喃与 $\ce{Br2}$ 在甲醇中反应得到 2,5-二甲氧基-2,5-二氢呋喃，这是一个 1,4-加成，而不是取代。这个产物是被保护的丁烯二醛，是有用的合成中间体。

```smiles
c1ccoc1.CO>>COC1OC(OC)C=C1
```

## 25.5. 吡啶的反应

吡啶的反应可以概括为一句话：环像缺电子的芳烃（硝基苯），N 像叔胺。N 上的孤对电子与环的 π 体系正交，表现出胺的性质：接受质子（25.3）、与卤代烷生成 $N$-烷基吡啶鎓盐、被过氧酸氧化为吡啶 $N$-氧化物、作为配体与金属配位、作为亲核催化剂（DMAP，[6.5.23](/6.5.23#sec-23.4.4)）。环上的碳则难以接受**亲电试剂**、容易接受**亲核试剂**。

### 25.5.1. 亲电取代

吡啶的亲电取代比苯慢得多，主要有两个原因：N 的吸电子作用使环缺电子；更重要的是，亲电取代所用的酸性条件（或 **Lewis 酸**）首先与 N 结合，得到带正电荷的吡啶鎓离子，它比吡啶还要难进攻得多。估计的相对活性（硝化）约为：

| 苯 | 硝基苯 | 吡啶 | $\ce{C6H5NMe3+}$ | 吡啶鎓离子 |
|---|---|---|---|---|
| 1 | 约 $10^{-6}$ | 约 $10^{-6}$ | 约 $10^{-8}$ | 约 $10^{-20}$ |

（后两项为由动力学数据外推的数量级估计，文献值相差可达几个数量级。）所以吡啶只有在非常剧烈的条件下才能亲电取代，并且只得到 3-取代产物：

```smiles
c1ccncc1>>O=[N+]([O-])c1cccnc1
c1ccncc1>>OS(=O)(=O)c1cccnc1
c1ccncc1>>Brc1cccnc1
```

（硝化：$\ce{KNO3}$/发烟硫酸，$300\,^\circ\mathrm{C}$，产率很低；磺化：发烟硫酸、$\ce{HgSO4}$ 催化，$230\,^\circ\mathrm{C}$；溴化：$\ce{Br2}$/发烟硫酸，$130\,^\circ\mathrm{C}$。）

C3 选择性来自 **σ 络合物**：进攻 C2 或 C4 时，有一个共振式把正电荷放在 N 上，而此时 N 只有六个价电子（不是亚胺鎓离子那样的八隅体，而是**电负性**大的原子上的"氮正离子"），极不稳定；进攻 C3 则没有这样的共振式。同一原理在五元杂环中起相反的作用：那里杂原子带正电荷的共振式（鎓离子）中 N 有孤对电子参与成键，是八隅体，因而是稳定的。环上有强给电子基团（$\ce{-NH2}$、$\ce{-OH}$、$\ce{-OCH3}$）时，亲电取代变得容易，位置由给电子基团与环 N 共同决定。

吡啶 $N$-氧化物提供了一条迂回的路线。$N$-氧化物的 O 负离子可以把电子推到环的 2、4 位（$\ce{N+-O-}$ 的共振），使 C4 成为亲电进攻的位置：吡啶 $N$-氧化物用 $\ce{HNO3}$/$\ce{H2SO4}$ 在 $100\,^\circ\mathrm{C}$ 左右硝化，以良好产率得到 4-硝基吡啶 $N$-氧化物，再用 $\ce{PCl3}$ 脱氧，得到 4-硝基吡啶；4-硝基又容易被**亲核试剂**取代，于是可以得到各种 4-取代吡啶。

```smiles
[O-][n+]1ccccc1>>[O-][n+]1ccc(cc1)[N+](=O)[O-]
[O-][n+]1ccc(cc1)[N+](=O)[O-]>>[O-][N+](=O)c1ccncc1
```

### 25.5.2. 芳香亲核取代

吡啶是缺电子的芳环，2-卤代吡啶与 4-卤代吡啶在较温和的条件下就能与醇盐、胺、硫醇盐发生 **芳香亲核取代**（SNAr，[6.5.14 的 14.11 节](/6.5.14#sec-14.11)），环 N 起的作用相当于苯环上处于邻位或对位的硝基：**亲核试剂**加到 C2 或 C4 上时，Meisenheimer 型中间体的负电荷可以落在**电负性**大的 N 上。3-卤代吡啶的负电荷不能分配到 N 上，反应要慢得多。2-氯嘧啶有两个 N 同时活化 C2，比 2-氯吡啶活泼得多，这是嘧啶类药物与核碱基类似物合成中常用的反应。

![2-氯吡啶的芳香亲核取代：甲氧负离子加到 C2 上（慢），生成的负离子中间体的负电荷离域到 C3、C5 与环 N 上（负电荷在 N 上的共振式贡献最大）；随后氯离子离去，恢复芳香性，得到 2-甲氧基吡啶](./plots/pyridine-snar.py)

### 25.5.3. Chichibabin 反应

**定义 25.5.1（Chichibabin 反应）** 吡啶（或其他缺电子的含氮芳杂环）与氨基钠在加热下反应，氨基取代 C2 上的氢、生成 2-氨基吡啶并放出氢气的反应称为 **Chichibabin 反应**（Chichibabin reaction，Chichibabin 1914）。

这是一个直接取代 H 的 **SNAr**：$\ce{NH2-}$ 加到 C2 上，生成负电荷在 N 上的 σ 加合物；加合物失去负氢离子 $\ce{H-}$ 恢复**芳香性**。负氢本身是很差的**离去基团**，它能离去是因为与产物的 N–H（或体系中的 $\ce{NH3}$）立即反应放出 $\ce{H2}$，使反应不可逆；产物以 2-氨基吡啶钠盐的形式存在，水处理后得到 2-氨基吡啶。

![Chichibabin 反应的机理：氨基负离子加到吡啶的 C2 上，π 电子移到环 N 上；负电荷回到环上、C2–H 键的电子对以负氢的形式离去，恢复芳香性；负氢夺取氨基上的质子，放出 H₂](./plots/chichibabin.py)

**有机锂试剂**也按同样的方式加到吡啶的 C2 上（C2 的电子效应最有利、离 N 上配位的 Li 最近），得到 1,2-二氢吡啶锂盐，加热消除 LiH 或经空气氧化后得到 2-烷基（芳基）吡啶；4 位的加成是次要的。Chichibabin 反应只适用于**亲核性**极强的试剂（氨基负离子、有机锂），因为要克服加成时芳香性的损失。

### 25.5.4. 活化后的取代

更一般的策略是先"活化"吡啶的 N：让 N 与一个**亲电试剂** $\ce{LG+}$ 结合（酰化、磺酰化、成 $N$-氧化物后再用亲电试剂活化），得到吡啶鎓离子。吡啶鎓离子是强得多的亲电试剂，**亲核试剂**在温和条件下就能加到 C2 或 C4 上，得到二氢吡啶；然后 LG 带着 N–LG 键的电子对以负离子 $\ce{LG-}$ 的形式离去，同时 C–H 上的质子被夺去，恢复**芳香性**。整个过程中 LG 由 $\ce{LG+}$ 变为 $\ce{LG-}$，即**活化基团**被还原了两个电子，这两个电子来自原来的 C–H 键（底物被氧化），所以总的结果是 C–H 键被氧化性地取代。近年发展的三氟甲磺酰（Tf）活化、$N$-氧化物与磺酰肟活化、杂环鏻盐（McNally）等方法都基于这一思路，可以在复杂药物分子的吡啶环上进行后期官能团化。

### 25.5.5. Minisci 反应

**定义 25.5.2（Minisci 反应）** 亲核性的碳自由基（由羧酸氧化脱羧等方式产生）加到质子化的缺电子含氮芳杂环（吡啶、喹啉、吡嗪等）的 C2 或 C4 上，再经氧化失去质子恢复芳香性，净结果是 C–H 键被烷基取代的反应称为 **Minisci 反应**（Minisci reaction，Minisci 1968–1971）。

经典条件是羧酸、$\ce{AgNO3}$（催化）与过硫酸铵在酸性水溶液中加热：$\ce{Ag+}$ 被过硫酸根氧化为 $\ce{Ag^2+}$，$\ce{Ag^2+}$ 把羧酸根氧化为羧基自由基，后者失去 $\ce{CO2}$ 得到烷基自由基（自由基**脱羧**，[6.5.18](/6.5.18#sec-18.4.2)）。质子化的杂环 LUMO 很低，与烷基自由基的 SOMO（能量较高、**亲核性**的自由基）匹配良好，加成发生在 C2 与 C4（正电荷密度高的位置）；加成生成的**自由基正离子**被氧化剂氧化并失去质子，恢复**芳香性**。

![Minisci 反应：叔丁基自由基（由特戊酸经银催化的氧化脱羧产生）加到质子化的 4-甲基喹啉的 C2 上，生成的自由基正离子被氧化、失去质子，得到 2-叔丁基-4-甲基喹啉](./plots/minisci.py)

Minisci 反应与 **Friedel–Crafts 烷基化**恰好互补：后者是亲电的**碳正离子**进攻富电子芳环，不能用于吡啶；前者是亲核的自由基进攻缺电子芳环。它不需要预先官能团化（不需要卤代吡啶），适合在药物分子的后期引入烷基，已广泛用于药物化学。现代版本用**光氧化还原催化**在室温下从羧酸、醇、烷基卤化物、烷基硼酸等产生自由基（[6.5.31](/6.5.31#sec-31.5)）；用手性磷酸作为质子化与**氢键**导向的催化剂，还可以进行对映选择性的 Minisci 反应（Phipps，*Science* 2018）。**区域选择性**受溶剂、酸与自由基的影响：在强酸中 C2 与 C4 都可能被进攻，C2、C4 都被占据时进攻其余的缺电子位置。

## 25.6. 还原与环加成

### 25.6.1. 还原

芳香杂环的**芳香性**比苯弱，催化氢化比苯容易：吡啶在酸中用 $\ce{H2}$/Pt 或 Rh、或用 Na/乙醇还原为哌啶；呋喃用 Ni 催化氢化得到四氢呋喃（工业上 THF 的来源之一）；吡咯比较难还原；噻吩使贵金属**催化剂中毒**，用 Raney Ni 处理则发生脱硫，得到烷烃（[6.5.16](/6.5.16#sec-16.6.2)）。苯并杂环氢化时杂环部分先被还原、苯环保持不变：喹啉得到 1,2,3,4-四氢喹啉，吲哚在酸中用 $\ce{NaBH3CN}$ 还原为吲哚啉（2,3-二氢吲哚）。后一个反应说明吲哚的吡咯环部分像**烯胺**（[6.5.16](/6.5.16#sec-16.9.3)）：吲哚在 C3 上质子化生成 3H-吲哚鎓离子（亚胺鎓离子），$\ce{NaBH3CN}$ 只还原亚胺鎓离子（[6.5.23 的 23.5.4 节](/6.5.23#sec-23.5.4)）。

```smiles
c1ccc2ncccc2c1>>c1ccc2NCCCc2c1
c1ccc2[nH]ccc2c1>>c1ccc2NCCc2c1
```

吡啶环的部分还原产物 1,4-二氢吡啶是生物体中最重要的负氢供体之一：烟酰胺腺嘌呤二核苷酸（NADH、NADPH）的活性部分是 1,4-二氢烟酰胺，它把 C4 上的一个氢以负氢的形式交给底物（如醛酮），自身被氧化为芳香的吡啶鎓离子 $\ce{NAD+}$，芳构化是负氢转移的推动力。合成中常用的 Hantzsch 酯（25.7.3 的 1,4-二氢吡啶二羧酸酯）是 NADH 的类似物，在**有机催化**或光催化中作为温和的负氢（或氢原子）供体，用于亚胺与烯烃的不对称转移氢化。

### 25.6.2. 环加成

呋喃的**芳香性**弱，是活泼的双烯体：与马来酸酐在室温下发生 **Diels–Alder 反应**（[6.5.12](/6.5.12#sec-12.4.3)），生成 7-氧杂双环[2.2.1]庚烯（氧杂降冰片烯）。这个反应是可逆的：动力学产物是 endo 加合物，长时间放置后转变为热力学上更稳定的 exo 加合物，与一般 Diels–Alder 反应的 **endo 规则** 相反。呋喃也能捕获**苯炔**（[6.5.15](/6.5.15#sec-15.1.4)）。吡咯的芳香性强，一般不作为双烯体（N-酰基吡咯可以）；噻吩更不活泼。

```smiles
c1ccoc1.O=C1OC(=O)C=C1>>O=C1OC(=O)C2C1C1OC2C=C1
```

缺电子的含氮杂环可以作为逆电子需求 Diels–Alder 反应（IEDDA）的双烯体：1,2,4,5-四嗪的 LUMO 很低，与富电子或张力大的烯烃（烯醇醚、反式环辛烯）迅速反应，生成的双环加合物放出 $\ce{N2}$（逆 Diels–Alder），得到二氢哒嗪，进而氧化为哒嗪。四嗪与反式环辛烯的反应速率常数可达 $10^3\text{–}10^6\,\mathrm{L\,mol^{-1}\,s^{-1}}$，是速度最快的**生物正交反应**（[6.5.12 的 12.4.4 节](/6.5.12#sec-12.4.4)）。噁唑也能作为双烯体与烯烃反应，经加成–消除得到吡啶，维生素 B6（吡哆醇）的工业合成就用这一反应。

## 25.7. 芳香杂环的合成

简单的芳香杂环由工业方法大量生产：糠醛由玉米芯、甘蔗渣中的戊聚糖经酸水解与脱水得到，糠醛脱羰得到呋喃；吡咯由呋喃与氨在 $\ce{Al2O3}$ 上加热得到，或由吡咯烷脱氢；噻吩由丁烷与硫在高温下脱氢环化；吡啶主要由醛与氨在催化剂上缩合（Chichibabin 吡啶合成）。实验室中，取代的芳香杂环大多由开链的羰基化合物缩合成环：杂原子作为**亲核试剂**进攻羰基，再脱水芳构化。下面是三个最重要的人名反应。

### 25.7.1. Paal–Knorr 合成

**定义 25.7.1（Paal–Knorr 合成）** 1,4-二羰基化合物与氨或伯胺在弱酸中缩合生成吡咯，在酸催化脱水下生成呋喃，与硫化试剂（$\ce{P4S10}$、Lawesson 试剂）作用生成噻吩的方法称为 **Paal–Knorr 合成**（Paal–Knorr synthesis，Paal 与 Knorr 1884）。

吡咯的 Paal–Knorr 合成可以看作两次胺与羰基的缩合：胺进攻一个羰基生成半缩醛胺，半缩醛胺的 N 再进攻另一个羰基，形成 2,5-二羟基吡咯烷，两次脱水后芳构化为吡咯。动力学研究（Amarnath 1991）表明，成环发生在半缩醛胺阶段，并且是**速控步**；先生成**烯胺**、再成环的写法虽然常见，却与实验不符。

![Paal–Knorr 吡咯合成（己-2,5-二酮与甲胺）。甲胺加到一个羰基上，质子转移后得到半缩醛胺；半缩醛胺的 N 进攻另一个羰基，形成五元环（速控步）；二醇经两次失水，得到 1,2,5-三甲基吡咯](./plots/paal-knorr.py)

呋喃的合成机理相似：一个羰基的烯醇形式进攻另一个质子化的羰基，生成环状**半缩酮**，再脱水。噻吩的合成先由硫化试剂把羰基 O 换成 S，再经相似的成环与脱水。Paal–Knorr 合成的限制在于 1,4-二羰基化合物本身的制备，常用 Stetter 反应或**烯醇负离子**的 $\alpha$-卤代酮烷基化得到（[6.5.21](/6.5.21#sec-21.7)）。

```smiles
CC(=O)CCC(C)=O>>Cc1ccc(C)o1
CC(=O)CCC(C)=O>>Cc1ccc(C)s1
```

### 25.7.2. Fischer 吲哚合成

**定义 25.7.2（Fischer 吲哚合成）** 芳肼与醛或酮缩合生成芳腙，芳腙在酸（$\ce{ZnCl2}$、多聚磷酸、HCl 或 $\ce{H2SO4}$）作用下加热，经 [3,3]-σ 迁移与失去氨生成吲哚的方法称为 **Fischer 吲哚合成**（Fischer indole synthesis，E. Fischer 1883）。

机理（Robinson 1918 年提出）：

1. 苯肼与酮缩合生成苯腙（[6.5.16](/6.5.16)），苯腙**互变异构**为烯肼（ene-hydrazine，与亚胺–**烯胺**互变相同）；
2. 质子化的烯肼发生 [3,3]-**σ 迁移反应**（[6.5.12 的 12.5 节](/6.5.12#sec-12.5)）：较弱的 N–N 键断裂，同时形成新的 C–C 键（C 与苯环的邻位碳相连），得到二亚胺；
3. 苯环部分互变异构恢复**芳香性**，生成苯胺；苯胺的 N 进攻亚胺碳，形成五元环的环状缩醛胺（2-氨基吲哚啉）；
4. 失去 $\ce{NH3}$ 并芳构化，得到吲哚。

![Fischer 吲哚合成（苯肼与丙酮）。上：苯腙互变为烯肼，质子化后发生 [3,3]-σ 迁移（N–N 键断裂、C–C 键形成），得到二亚胺。下：芳环互变异构恢复芳香性，苯胺的 N 进攻亚胺碳成环，失去 NH₃，得到 2-甲基吲哚](./plots/fischer-indole.py)

$^{15}\mathrm{N}$ 标记实验（Allen 与 Wilson 1943）证明，产物吲哚中的 N 来自与苯环相连的 N，另一个 N 以氨的形式离去，与这一机理一致。不对称的酮可能生成两种烯肼，产物的**区域选择性**取决于烯肼生成的方向：常用的酸性条件下以取代较多的烯肼为主，酸性很强时（如多聚磷酸、$\ce{P2O5}$/$\ce{H3PO4}$）经取代较少的烯肼生成的产物比例增大。Fischer 吲哚合成是最常用的吲哚合成法，抗偏头痛药曲坦类（如舒马曲坦）与吲哚美辛的工业合成都用它。苯肼由重氮盐还原得到（[6.5.24](/6.5.24#sec-24.4.4)）。

```smiles
NNc1ccccc1.CC(C)=O>>Cc1cc2ccccc2[nH]1
NNc1ccccc1.O=C1CCCCC1>>c1ccc2c(c1)[nH]c1CCCCc12
```

### 25.7.3. Hantzsch 吡啶合成与噻唑合成

**定义 25.7.3（Hantzsch 吡啶合成）** 两分子 $\beta$-酮酸酯（或其他 1,3-二羰基化合物）、一分子醛与一分子氨缩合生成 1,4-二氢吡啶，再经氧化得到吡啶的四组分反应称为 **Hantzsch 吡啶合成**（Hantzsch pyridine synthesis，Hantzsch 1881）。

机理由几个已知的反应拼成：一分子乙酰乙酸乙酯与醛发生 **Knoevenagel 缩合**（[6.5.22](/6.5.22#sec-22.4.2)），得到 $\alpha$,$\beta$-不饱和羰基化合物；另一分子乙酰乙酸乙酯与氨生成**烯胺**（$\beta$-氨基巴豆酸乙酯）；烯胺的 $\alpha$ 碳对不饱和酮进行 **Michael 加成**；最后 N 进攻酮羰基成环并脱水，得到 1,4-二氢吡啶（Hantzsch 酯）。1,4-二氢吡啶用 $\ce{HNO3}$、DDQ 或 $\ce{MnO2}$ 氧化为吡啶，芳构化的推动力很大。

```smiles
CCOC(=O)CC(C)=O.O=Cc1ccccc1>>CCOC(=O)C(=Cc1ccccc1)C(C)=O
CCOC(=O)CC(C)=O.N>>CCOC(=O)C=C(C)N
CCOC(=O)C1=C(C)NC(C)=C(C(=O)OCC)C1c1ccccc1>>CCOC(=O)c1c(C)nc(C)c(C(=O)OCC)c1-c1ccccc1
```

1,4-二氢吡啶本身就是一类重要的药物：硝苯地平（2,6-二甲基-4-(2-硝基苯基)-1,4-二氢吡啶-3,5-二甲酸二甲酯）等钙通道阻滞剂用于治疗高血压与心绞痛，都由 Hantzsch 合成制备。

Hantzsch 还发展了吡咯与噻唑的合成。Hantzsch 噻唑合成用 $\alpha$-卤代酮与硫代酰胺（或硫脲）：硫代酰胺的 S 进攻卤代碳（**SN2**），N 再进攻酮羰基成环，脱水得到噻唑。维生素 B1（硫胺素）中的噻唑鎓环（[6.5.16](/6.5.16#sec-16.10.4)）与许多药物中的 2-氨基噻唑都可以这样构建。Hantzsch 吡咯合成则用 $\alpha$-卤代酮、$\beta$-酮酸酯与氨（或伯胺）。

```smiles
CC(=O)CCl.NC(C)=S>>Cc1csc(C)n1
```

### 25.7.4. 其他成环方法

1,3-偶极**环加成**（[6.5.12](/6.5.12#sec-12.4.5)）是合成五元含氮杂环的通用方法：叠氮与炔得到 1,2,3-三唑（[6.5.24](/6.5.24#sec-24.8.5)），腈氧化物与炔得到异噁唑，重氮化合物与炔得到吡唑。过渡金属催化的环化与多组分环化反应则能由简单原料一步构建高度取代的吡咯与吡啶。

## 25.8. 嘌呤与嘧啶

嘌呤与嘧啶是核酸碱基的母体结构。本节只讲它们作为杂环的化学性质：结构与编号、**互变异构**、**氢键**给体与受体的分布、酸碱性与几类化学反应；核苷与核苷酸的化学见 [6.5.33](/6.5.33#sec-33.9)，碱基配对在复制、转录与突变中的生物学意义留给生物化学与分子生物学。

### 25.8.1. 结构与编号

**定义 25.8.1（嘧啶与嘌呤）** 两个 N 处于间位（1,3 位）的六元芳香杂环 $\ce{C4H4N2}$ 称为**嘧啶**（pyrimidine）；嘧啶环与咪唑环稠合（共用嘧啶的 C4–C5 键）而成的双环芳香杂环 $\ce{C5H4N4}$ 称为**嘌呤**（purine）。

嘧啶按一般规则编号（N1、C2、N3、C4、C5、C6）。嘌呤沿用历史编号：嘧啶环部分为 1–6，咪唑环部分为 7–9，两个稠合碳是 C4 与 C5；在核苷中，嘌呤以 N9、嘧啶以 N1 与核糖的 C1′ 形成 N-**糖苷键**。

核酸的五种碱基：

| 碱基 | 母体 | 结构 | 在核酸中 |
|---|---|---|---|
| 腺嘌呤（A） | 嘌呤 | 6-氨基嘌呤 | DNA、RNA |
| 鸟嘌呤（G） | 嘌呤 | 2-氨基-1,9-二氢-6H-嘌呤-6-酮 | DNA、RNA |
| 胞嘧啶（C） | 嘧啶 | 4-氨基嘧啶-2(1H)-酮 | DNA、RNA |
| 胸腺嘧啶（T） | 嘧啶 | 5-甲基嘧啶-2,4(1H,3H)-二酮 | DNA |
| 尿嘧啶（U） | 嘧啶 | 嘧啶-2,4(1H,3H)-二酮 | RNA |

```smiles
Nc1ncnc2[nH]cnc12 A
Nc1nc2[nH]cnc2c(=O)[nH]1 G
Nc1cc[nH]c(=O)n1 C
Cc1c[nH]c(=O)[nH]c1=O T
O=c1cc[nH]c(=O)[nH]1 U
```

其他重要的嘌呤有次黄嘌呤、黄嘌呤、尿酸（嘌呤代谢的终产物，痛风时以尿酸钠结晶沉积在关节中）以及咖啡因（1,3,7-三甲基黄嘌呤）、可可碱等嘌呤类生物碱；碱基类似物 5-氟尿嘧啶、6-巯基嘌呤是抗癌药，阿昔洛韦、齐多夫定（AZT）是抗病毒药。

嘧啶与嘌呤本身是芳香的。带羰基的碱基（G、C、T、U）是环状的酰胺（内酰胺），它们的环通过酰胺共振（$\ce{N-C=O <-> N+=C-O-}$）仍有相当的**芳香性**，可以看作 2-吡啶酮的类似物：2-吡啶酮的偶极共振式 $\ce{N+=C-O-}$ 是一个 6π 的吡啶鎓氧负离子。

### 25.8.2. 互变异构

带 $\ce{C=O}$ 与 $\ce{-NH2}$ 的含氮杂环存在两类**互变异构**：内酰胺–内酰亚胺互变（$\ce{-NH-C(=O)- <=> -N=C(OH)-}$，相当于酮–烯醇互变）与氨基–亚氨基互变（$\ce{-N=C(NH2)- <=> -NH-C(=NH)-}$）。以最简单的模型 2-吡啶酮为例：在气相中两种形式几乎等量（2-羟基吡啶略多），在水中内酰胺形式占绝对优势（约 $10^3 : 1$），因为它的极性大得多、能与水形成更强的**氢键**；4-吡啶酮在水中也以内酰胺形式为主。

```smiles
O=c1cccc[nH]1 lactam
Oc1ccccn1 lactim
```

核酸碱基在水中以内酰胺（酮式）与氨基形式为主，稀有的内酰亚胺（烯醇式）与亚氨基互变异构体只占 $10^{-4}\text{–}10^{-5}$ 左右。这一点是碱基配对的化学基础：

![Watson–Crick 碱基对中的氢键（糖用甲基代替，连在嘌呤的 N9 与嘧啶的 N1 上；虚线连接氢键的给体与受体原子）。上：腺嘌呤–胸腺嘧啶（A–T），两个氢键：T 的 N3–H 给 A 的 N1，A 的 6-氨基 N–H 给 T 的 C4=O。下：鸟嘌呤–胞嘧啶（G–C），三个氢键：C 的 4-氨基给 G 的 C6=O，G 的 N1–H 给 C 的 N3，G 的 2-氨基给 C 的 C2=O](./plots/base-pairs.py)

- 每个碱基在配对的一侧有确定的**氢键**给体（N–H）与受体（N 的孤对电子、C=O 的氧）排列：A 为"受体–给体"（N1、N6–H），T 为"给体–受体"（N3–H、O4），二者互补，形成两个氢键；G 为"受体–给体–给体"（O6、N1–H、N2–H），C 为"给体–受体–受体"（N4–H、N3、O2），形成三个氢键。G–C 对因此比 A–T 对更稳定，富含 G–C 的 DNA 熔解温度更高。
- 两个碱基对的几何尺寸几乎相同（两个糖的 C1′ 之间约 $1.05\,\mathrm{nm}$），所以双螺旋的直径均一，这一点是 Watson 与 Crick 1953 年构建模型的关键。Watson 与 Crick 最初的推测还依赖 Chargaff 规则与 Donohue 指出的碱基主要以酮式存在，若取烯醇式，配对方式会完全不同。
- 互变异构改变了给体与受体的排列。稀有互变异构体（如烯醇式的 G 或 T）可以形成与 Watson–Crick 对几何相似的错配（G–T、A–C），这是 Watson 与 Crick 当年提出的自发突变机理之一，近年已用 NMR 直接观察到这种瞬态的互变异构碱基对。

### 25.8.3. 酸碱性

核碱基既有碱性的 N，也有酸性的 N–H（下列为核苷中的近似值，表外补充数据）：

| 位置 | 性质 | $\mathrm{p}K_{\mathrm{a}}$（约） |
|---|---|---|
| 腺苷 N1 | 质子化（共轭酸） | 3.5 |
| 胞苷 N3 | 质子化（共轭酸） | 4.2 |
| 鸟苷 N7 | 质子化（共轭酸） | 2.2 |
| 鸟苷 N1–H | 去质子化 | 9.2 |
| 尿苷 N3–H | 去质子化 | 9.3 |
| 胸苷 N3–H | 去质子化 | 9.8 |

所以在生理 pH 下碱基几乎都是中性的，**氢键**的给体与受体保持上述排列。碱基的碱性比吡啶弱，因为环上的羰基与其他 N 吸电子；酸性的 N–H 都处在两个羰基或一个羰基与一个环 N 之间（类似酰亚胺，[6.5.23](/6.5.23#sec-23.5.2) 中邻苯二甲酰亚胺的 8.3），所以 $\mathrm{p}K_{\mathrm{a}}$ 约 9–10。在酸性（如 pH 5 以下）中胞嘧啶 N3 质子化，可以形成 C⁺–G 的 Hoogsteen 配对与三链 DNA、i-motif 等非经典结构。

### 25.8.4. 化学反应

碱基的化学反应决定了 DNA 的化学损伤类型，也是许多药物与诱变剂的作用方式：

- 烷基化。碱基中**亲核性**最强的位置是鸟嘌呤的 N7（位于双螺旋大沟中，暴露在外），其次是腺嘌呤的 N3 与 N1；甲磺酸甲酯、硫酸二甲酯等 **SN2** 型烷化剂主要烷基化 N7。$N$-亚硝胺代谢产生的烷基重氮离子（[6.5.24](/6.5.24#sec-24.2.2)）等 **SN1** 型烷化剂则较多地进攻氧原子，生成 $O^6$-甲基鸟嘌呤，后者与 T 配对，造成 G→A 突变。N7 烷基化后咪唑环带正电荷，N-**糖苷键**变弱，碱基易于脱落（脱嘌呤）。氮芥类抗癌药是双功能的烷化剂，在两条链的 G 的 N7 之间形成交联。
- 脱氨基。胞嘧啶的 4-氨基可以水解为羰基，变为尿嘧啶（这是一个加成–消除过程：水加到 C4 上、再失去 $\ce{NH3}$），这种自发的脱氨在每个细胞中每天发生约百次，亚硝酸经**重氮化**（[6.5.24](/6.5.24#sec-24.2.1)）大大加速它；腺嘌呤脱氨得到次黄嘌呤。5-甲基胞嘧啶脱氨直接得到胸腺嘧啶，修复系统无法区分 T 是"错误"的还是原有的，所以甲基化的 CpG 位点是突变热点。DNA 用 T 而不用 U，被认为与此有关：U 在 DNA 中只能来自 C 的脱氨，可以被专一地识别与切除。
- 光化学反应。相邻的两个胸腺嘧啶在紫外光（UV-B、UV-C）照射下发生 C5=C6 双键之间的 [2+2] **光环加成**（[6.5.12 的 12.4.2 节](/6.5.12#sec-12.4.2)），生成环丁烷嘧啶二聚体，它使 DNA 螺旋变形、阻碍复制，是日光致皮肤癌的主要分子原因；另一类产物是 (6-4) 光产物。光裂合酶利用可见光，通过向二聚体转移一个电子使环丁烷开环，修复这种损伤。

```smiles
Cc1c[nH]c(=O)[nH]c1=O.Cc1c[nH]c(=O)[nH]c1=O>>CC12C(NC(=O)NC1=O)C1NC(=O)NC(=O)C21C
Nc1cc[nH]c(=O)n1>>O=c1cc[nH]c(=O)[nH]1
```

## 25.9. 非芳香杂环

### 25.9.1. 环氧化合物与氮杂环丙烷

**环氧化合物** 的制备与开环见 [6.5.10 的 10.9 节](/6.5.10#sec-10.9) 与 [6.5.11](/6.5.11#sec-11.8.1)：碱性或中性条件下**亲核试剂**按 **SN2** 进攻位阻小的碳，酸性条件下进攻较能稳定正电荷的碳，两种情况都是反式开环。环氧化合物还可以经自由基开环：低价钛试剂 $\ce{Cp2TiCl}$（Nugent–RajanBabu，1994）把一个电子转移给环氧的 C–O 键，Ti–O 键形成的同时 C–O 键**均裂**，生成取代较多的碳自由基（较稳定的自由基），后者可以被氢原子供体（如 1,4-环己二烯）还原，羟基留在取代较少的碳上，**区域选择性**与 $\ce{LiAlH4}$ 的负氢开环（负氢进攻位阻小的碳、得到叔醇）相反，或与分子内的烯烃环化；用一个已知速率的自由基重排作"**自由基钟**"，可以证明中间体是自由基。

```smiles
CC1(C)OC1C>>CC(C)C(C)O
```

氮杂环丙烷（aziridine）是含一个 N 的三元环，与环氧化合物相似，有约 $110\,\mathrm{kJ\,mol^{-1}}$ 的**环张力**，容易被亲核试剂开环，生成 $\beta$-取代的胺；N 上连有吸电子基团（磺酰基、酰基）的"活化"氮杂环丙烷开环更快，在酸或 **Lewis 酸**的作用下 N 被质子化或配位后也被活化。它的制备方法有：烯烃与氮宾或其等价物（如 $\ce{PhI=NTs}$ 在 Cu、Rh 催化下）的加成，类比烯烃的环氧化；$\beta$-氨基醇的分子内取代。三元环使 N 的翻转很慢（[6.5.23 的 23.3.2 节](/6.5.23#sec-23.3.2)）。天然的抗癌抗生素丝裂霉素 C 含有氮杂环丙烷，它在细胞内被还原活化后开环，使 DNA 的两条链交联。手性催化剂可以使内消旋氮杂环丙烷对映选择性地开环。

### 25.9.2. 内酯与内酰胺

内酯与内酰胺是环状的酯与酰胺，按环的大小用希腊字母标明羟基或氨基原来所在的碳：$\beta$-丙内酯（四元环）、$\gamma$-丁内酯（五元环）、$\delta$-戊内酯（六元环）、$\varepsilon$-己内酯（七元环）；内酰胺同理。

**定义 25.9.1（内酰胺）** 分子内的氨基与羧基脱水形成的环状酰胺称为**内酰胺**（lactam）。

五元、六元环的内酯与内酰胺在羟基酸或氨基酸中自发生成，较大的环（大环内酯）要在高度稀释下用 DCC/DMAP、EDCI 或 Yamaguchi 试剂等缩合剂活化羧基才能有效地分子内环化，避免分子间的聚合。内酯与内酰胺发生羧酸衍生物的一般反应：酸性或碱性水解开环、氨解、用 $\ce{LiAlH4}$ 还原为二醇或环胺（[6.5.19](/6.5.19#sec-19.7)）。

$\beta$-内酯与 $\beta$-内酰胺最常用的合成方法是烯酮的 [2+2] **环加成**（[6.5.12 的 12.4.6 节](/6.5.12#sec-12.4.6)）：烯酮与醛在 **Lewis 酸**催化下生成 $\beta$-内酯；烯酮与亚胺生成 $\beta$-内酰胺，这是 Staudinger $\beta$-内酰胺合成（Staudinger 1907；注意与叠氮的 **Staudinger 还原**相区别，[6.5.26](/6.5.26#sec-26.5.5)）。后者实际上分步进行：亚胺的 N 先进攻烯酮的羰基碳，生成**两性离子**中间体，再由**烯醇负离子**的碳进攻亚胺鎓离子的碳闭环。

```smiles
C=C=O.C(=Nc1ccccc1)c1ccccc1>>O=C1CC(c2ccccc2)N1c1ccccc1
```

$\beta$-内酯的**环张力**大，**亲核试剂**可以从两个位置开环：硬的亲核试剂（醇盐、胺）进攻羰基，酰氧键断裂，得到 $\beta$-羟基羧酸衍生物；软的亲核试剂（硫醇盐、卤离子、有机铜试剂）在 $\beta$ 碳上进行 **SN2**，烷氧键断裂，得到 $\beta$-取代的羧酸。

$\beta$-内酰胺是青霉素、头孢菌素等抗生素的核心结构。青霉素（Fleming 1928 年发现，Hodgkin 1945 年用 **X 射线衍射**确定结构）由 $\beta$-内酰胺环与噻唑烷环稠合而成；氨苄西林、阿莫西林是侧链不同的半合成青霉素。它们的作用机理是一个**酰基转移**反应：细菌合成细胞壁肽聚糖时，转肽酶（青霉素结合蛋白）用活性中心丝氨酸的羟基进攻肽链末端的 D-Ala–D-Ala，青霉素的构象与 D-Ala–D-Ala 相似，丝氨酸转而进攻 $\beta$-内酰胺的羰基，开环生成稳定的酰基–酶，酶被不可逆地抑制，细胞壁无法交联，细菌破裂死亡。$\beta$-内酰胺之所以是好的酰化试剂，一是四元环的张力，二是双环骨架使 N 呈角锥形、孤对电子不能与羰基共轭，酰胺共振的稳定作用基本消失。细菌的耐药性主要来自 $\beta$-内酰胺酶，它水解 $\beta$-内酰胺环；克拉维酸等 $\beta$-内酰胺酶抑制剂与青霉素合用可以克服这种耐药。

```smiles
CC1([C@@H](N2[C@H](S1)[C@@H](C2=O)NC(=O)CC3=CC=CC=C3)C(=O)O)C penicillin G
```

$\varepsilon$-己内酰胺由环己酮肟经 **Beckmann 重排**（[6.5.30](/6.5.30#sec-30.5.3)）工业生产，它的开环聚合得到尼龙 6（聚己内酰胺），年产量数百万吨，用于纤维与工程塑料。

```smiles
ON=C1CCCCC1>>O=C1CCCCCN1
```

## 25.10. 研究前沿

杂环化学的前沿与药物化学紧密相连。一个方向是对现成的药物分子直接进行"后期官能团化"：Minisci 型反应、吡啶鏻盐、吡啶的临时去芳构化（如经 Zincke 亚胺或氧杂氮杂环中间体）使人们第一次能够选择性地官能团化吡啶的间位（C3）C–H 键，这在过去只有亲电取代的剧烈条件才能做到。另一个方向是"骨架编辑"：在芳香杂环中插入、删除或替换一个原子，例如把吲哚扩环为喹啉、把吡啶的 N 换成 C，从而在不重新合成的情况下改变药物分子的核心骨架（Levin、Sarpong 等，2021 年以来）。

## 小结

- 杂环化合物（定义 25.1.1）分为非芳香杂环（性质同开链的醚、胺、酯、酰胺，小环活泼）与芳香杂环；常见芳香杂环用俗名（定义 25.1.2），编号从杂原子开始，O > S > N。
- 电子结构：参与环内双键的杂原子出一个 p 电子（孤对电子在平面内，有碱性），不参与的出一对 p 电子。五元杂环富 π，吡啶缺 π；**芳香性** 苯 > 噻吩 > 吡咯 > 呋喃。
- 碱性（共轭酸 $\mathrm{p}K_{\mathrm{a}}$）：哌啶 11.12 > 咪唑 6.99 > 吡啶 5.23 > 嘧啶 1.3 > 吡咯 $-3.8$；咪唑的两性与接近 7 的 $\mathrm{p}K_{\mathrm{a}}$ 使组氨酸成为酶的广义**酸碱催化**基团；吡咯、吲哚、咪唑的 N–H 有弱酸性。
- 反应性的对照：

  | | 五元杂环、吲哚 | 吡啶 |
  |---|---|---|
  | **SEAr** | 快（吡咯 > 呋喃 > 噻吩 ≫ 苯），温和试剂；吡咯、呋喃、噻吩在 C2，吲哚在 C3，苯并呋喃在 C2 | 极慢，剧烈条件，C3；$N$-氧化物在 C4 |
  | **亲核取代** | 一般不发生 | 2-、4-卤代吡啶的 **SNAr**；Chichibabin 反应（定义 25.5.1）；活化后取代 |
  | 自由基取代 | — | Minisci 反应（定义 25.5.2），质子化杂环 + 亲核自由基，C2/C4 |
  | 还原 | 呋喃 → THF；吲哚 → 吲哚啉（$\ce{NaBH3CN}$/酸） | 吡啶 → 哌啶；1,4-二氢吡啶（NADH、Hantzsch 酯）是负氢供体 |
  | **环加成** | 呋喃是好的双烯体（exo 为热力学产物） | 四嗪的 IEDDA（生物正交） |

- 合成：Paal–Knorr 合成（定义 25.7.1，1,4-二羰基 → 吡咯、呋喃、噻吩，成环在半缩醛胺阶段）；Fischer 吲哚合成（定义 25.7.2，芳腙 → 烯肼 → [3,3]-**σ 迁移** → 失 $\ce{NH3}$）；Hantzsch 吡啶合成（定义 25.7.3，Knoevenagel + **烯胺** + Michael + 成环，1,4-二氢吡啶再氧化）与噻唑合成。
- 嘧啶与嘌呤（定义 25.8.1）：嘌呤的特殊编号，N9/N1 连糖；含羰基的碱基是内酰胺，在水中以酮式、氨基式为主，确定了 A–T（2 个**氢键**）、G–C（3 个氢键）的给体–受体互补；稀有互变异构体导致错配；碱基在生理 pH 下为中性；N7 烷基化、脱氨基（C → U，5-甲基 C → T）与胸腺嘧啶 [2+2] 光二聚是 DNA 化学损伤的主要类型。
- 非芳香杂环：环氧化合物与氮杂环丙烷的开环；内酰胺（定义 25.9.1）与内酯；烯酮–亚胺的 Staudinger $\beta$-内酰胺合成；$\beta$-内酰胺抗生素靠**环张力**与失去共振的酰胺酰化转肽酶的丝氨酸；$\varepsilon$-己内酰胺开环聚合得尼龙 6。

## 思考题

1. 判断下列化合物是否有**芳香性**，并指出每个杂原子的孤对电子在哪种轨道中：(a) 噻唑；(b) 吡喃鎓离子；(c) 4H-吡喃；(d) 嘌呤。

   **答** (a) 有。S 用一对 p 电子、N 用一个 p 电子参与，共 6 个 π 电子；S 的另一对孤对电子与 N 的孤对电子都在环平面内的 sp² 轨道中。(b) 有。$\ce{O+}$ 与吡啶的 N 等电子，用一个 p 电子参与 6π 体系，剩下的一对孤对电子在平面内的 sp² 轨道中。(c) 没有。C4 是 sp³ 碳，共轭被打断（非芳香）。(d) 有。共 10 个 π 电子（4n+2，n = 2）：N9–H 的 N 出一对 p 电子，N1、N3、N7 各出一个 p 电子，它们的孤对电子在平面内，是碱性的位置。

2. 解释：(a) 吡咯的碱性比吡啶弱约 $10^9$ 倍，酸性却比吡啶强得多；(b) 咪唑的碱性比吡啶强；(c) 吡啶的亲电取代发生在 C3，而**亲核取代**发生在 C2 与 C4。

   **答** (a) 吡咯 N 的孤对电子是 6π 芳香体系的一部分，在 N 上质子化会破坏芳香性，质子化只能发生在 C2 上（共轭酸 $\mathrm{p}K_{\mathrm{a}}$ $-3.8$），而吡啶的孤对电子在平面内的 sp² 轨道中，质子化不影响芳香性（5.23）。吡咯的 N–H 解离后，负电荷离域到整个芳环上（水中 $\mathrm{p}K_{\mathrm{a}}$ 约 17.5），而吡啶没有 N–H。(b) 咪唑鎓离子的正电荷由两个等价的共振式分散在两个 N 上（脒型共振），而 N1 的孤对电子推向 N3，使 N3 的电子密度增大。(c) 亲电进攻 C2 或 C4 时，**σ 络合物**有一个共振式把正电荷放在只有六个价电子的 N 上，极不稳定，所以只能进攻 C3；亲核进攻 C2 或 C4 时，负离子中间体有一个共振式把负电荷放在电负性大的 N 上，稳定，进攻 C3 则没有这样的共振式。

3. 写出主要产物：(a) 2-甲基呋喃与乙酸酐、$\ce{BF3.OEt2}$；(b) 吲哚与 DMF、$\ce{POCl3}$，再水解；(c) 4-氯吡啶与哌啶加热；(d) 3-甲基吡啶与 $\ce{NaNH2}$ 加热；(e) 吡啶 $N$-氧化物与 $\ce{HNO3}$/$\ce{H2SO4}$，再与 $\ce{PCl3}$。

   **答** (a) 2-乙酰基-5-甲基呋喃（取代在另一个 $\alpha$ 位 C5）。(b) 吲哚-3-甲醛（Vilsmeier–Haack 反应，在 C3）。(c) 4-(哌啶-1-基)吡啶（**SNAr**，负电荷可以落在 N 上）。(d) Chichibabin 反应，主要得 2-氨基-3-甲基吡啶，伴有 2-氨基-5-甲基吡啶（两个 $\alpha$ 位都可以被进攻，比例取决于条件）。(e) 4-硝基吡啶 $N$-氧化物，脱氧后得到 4-硝基吡啶。

4. 用 Paal–Knorr、Fischer 或 Hantzsch 方法，由合适的原料合成：(a) 1-苯基-2,5-二甲基吡咯；(b) 2,3-二甲基吲哚；(c) 2,6-二甲基-4-苯基吡啶-3,5-二甲酸二乙酯；(d) 2-氨基-4-甲基噻唑。

   **答** (a) 己-2,5-二酮与苯胺，乙酸催化加热（Paal–Knorr）。(b) 苯肼与丁-2-酮，在 $\ce{ZnCl2}$ 或乙酸中加热；在这类常用条件下烯肼主要朝取代较多的一侧生成（$\ce{CH3C(=CHCH3)-NHNHPh}$），[3,3]-迁移后得到 2,3-二甲基吲哚（另一方向得到 2-乙基吲哚，为次要产物）。(c) 两分子乙酰乙酸乙酯、苯甲醛与氨（或乙酸铵）缩合得到 1,4-二氢吡啶，再用 $\ce{HNO3}$ 或 DDQ 氧化（Hantzsch）。(d) 氯丙酮与硫脲（Hantzsch 噻唑合成）：S 对 $\ce{CH2Cl}$ 进行 **SN2**，N 进攻羰基成环，脱水。

5. 吡咯在稀盐酸中迅速变成红色的树脂，而噻吩在同样条件下稳定。解释原因。为什么吡咯硝化不用混酸，而用乙酰硝酸酯？

   **答** 吡咯在 C2（或 C3）上质子化，得到失去芳香性的 2H-吡咯鎓离子，它是活泼的**亲电试剂**（亚胺鎓离子），被另一分子富电子的吡咯进攻，反复进行就得到聚合物。噻吩的芳香性更强，碱性极弱，在稀酸中几乎不质子化。混酸中的强酸会使吡咯聚合或氧化分解，硝鎓离子又过于活泼；乙酰硝酸酯在低温下提供温和的亲电硝化试剂，不需要强酸，得到 2-硝基吡咯为主。

6. 吡啶鎓离子经"活化–**亲核加成**–消除"实现 C–H 取代时，**活化基团** $\ce{LG+}$ 最后以 $\ce{LG-}$ 的形式离开。以 $\ce{Tf2O}$ 活化、**亲核试剂** $\ce{Nu-}$ 加到 C4 为例，写出各步，并说明这是一个什么样的氧化还原过程。

   **答** (1) 吡啶的 N 进攻 $\ce{Tf2O}$，得到 $N$-三氟甲磺酰吡啶鎓离子（Tf 带正电荷的等价物 $\ce{Tf+}$）与 $\ce{TfO-}$。(2) $\ce{Nu-}$ 加到 C4 上，得到 $N$-Tf-1,4-二氢吡啶。(3) 碱夺去 C4–H 的质子，电子对经环推向 N，N–S 键断裂，Tf 以亚磺酸根 $\ce{CF3SO2-}$（$\ce{Tf-}$）离去，环恢复芳香性，得到 4-取代吡啶。硫由 $\ce{Tf+}$（磺酰基，S(VI)）变为三氟甲亚磺酸根（S(IV)），活化基团得到两个电子被还原；这两个电子来自原来 C4–H 键的电子对，底物的 C4 被氧化（C–H 变为 C–Nu）。所以整体是一个以活化试剂为氧化剂的氧化性 C–H 取代。

7. 胞嘧啶的稀有互变异构体（亚氨基形式，4-亚氨基）能与腺嘌呤形成两个**氢键**。用氢键给体与受体的排列说明这种错配，并说明为什么亚硝酸处理 DNA 会诱发 C→T 突变。

   **答** 正常的胞嘧啶在配对面上的排列是 N4–H（给体）、N3（受体）、O2（受体），与 G 的 O6（受体）、N1–H（给体）、N2–H（给体）互补。亚氨基互变异构体中 H 从 N4 移到 N3：配对面变为 N4（受体，=NH 的孤对电子）、N3–H（给体），正好与腺嘌呤的 N6–H（给体）、N1（受体）互补，形成两个氢键，几何上与 A–T 对相似，所以复制时可能在 C 的对面插入 A。亚硝酸使胞嘧啶的 4-氨基**重氮化**并被水取代（脱氨），C 变为 U；U 与 A 配对，复制后原来的 G–C 对变为 A–T 对，即 C→T（G→A）转换突变。

8. 解释青霉素的 $\beta$-内酰胺为什么比普通酰胺容易被丝氨酸的羟基进攻；若把青霉素的 $\beta$-内酰胺换成五元的 $\gamma$-内酰胺，预期抗菌活性如何变化？

   **答** 普通酰胺的 N 孤对电子与羰基共轭（共振稳定约 $70\text{–}80\,\mathrm{kJ\,mol^{-1}}$），C–N 有部分双键性质，羰基碳的亲电性低。青霉素的双环骨架使 $\beta$-内酰胺的 N 呈角锥形，孤对电子不能与羰基共平面共轭，共振稳定基本消失；四元环的张力（约 $100\,\mathrm{kJ\,mol^{-1}}$）在开环时释放，进一步提高了反应的推动力。$\gamma$-内酰胺的张力小得多、N 也较容易平面化，酰化活性大大降低，预期抗菌活性显著下降或消失（虽然近年也设计出了某些有活性的 $\gamma$-内酰胺类似物，但需要其他的活化方式）。
