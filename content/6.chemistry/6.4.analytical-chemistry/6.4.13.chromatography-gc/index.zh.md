实际样品几乎总是混合物：血液中有上千种代谢物，汽油中有数百种烃，一滴香精油中有几十种萜类与酯。光谱法和质谱法面对这样的样品，信号互相重叠，必须先分离、再测定。色谱法利用各组分在两相之间分配的差异，让它们在流动中逐渐拉开距离，依次进入检测器，把分离与测定在一台仪器中连续完成。它是现代分析化学中应用最广的方法，也是有机合成中纯化产物的基本手段（[6.5](/6.5)）。本章先定义描述色谱图的参数（13.1 节），再用两种理论解释组分为什么分开、色谱峰为什么展宽：塔板理论把色谱柱看作一系列分配平衡（13.2 节），速率理论从扩散与传质出发给出板高与流速的关系，并由此得到分离方程（13.3 节）。然后以气相色谱为例讲仪器（13.4 节）、检测器（13.5 节）与定性定量方法（13.6 节）。组分在两相间分配的热力学是 [6.3.6](/6.3.6#sec-6.5) 的 **分配系数**，峰展宽的统计基础是 **中心极限定理** 与随机游走（[6.3.21](/6.3.21#sec-21.3.1)）；液相色谱与电泳在下一章（[6.4.14](/6.4.14)），色谱与质谱的联用在 [6.4.15](/6.4.15)。

## 13.1. 色谱法概述与基本参数

### 13.1.1. 色谱法及其分类

**定义 13.1.1（色谱法）** 使试样中各组分在互不相溶的两相之间反复分配（吸附、溶解、离子交换或其他作用），由于各组分与两相作用的强弱不同，在一相相对于另一相流动时以不同的速度移动而彼此分离，并依次检测的分离分析方法称为**色谱法**。

**定义 13.1.2** 色谱体系中固定不动的一相（装在柱内的固体或涂在载体上的液体）称为**固定相**；携带试样流过固定相的一相（气体、液体或超临界流体）称为**流动相**。在柱色谱中，用流动相把组分从柱中冲出的过程称为洗脱，流动相也称洗脱剂。

色谱法的历史是一部不断提高分离效率与速度的历史：

- 1903–1906 年，俄国植物学家 Tswett 用碳酸钙柱分离植物叶片的石油醚提取液，色素在柱上分成不同颜色的谱带，他把这种方法称为 chromatography（希腊文"颜色"与"书写"）。方法的本质与颜色无关，名称却沿用至今。
- 1941 年，Martin 与 Synge 提出液–液分配色谱（以吸附了水的硅胶为固定相分离乙酰化氨基酸），并引入塔板的概念，预言了用气体作流动相的可能性；两人因此获得 1952 年诺贝尔化学奖。纸色谱也由他们发展起来，成为 Sanger 测定胰岛素序列时分离肽段的工具。
- 1952 年，James 与 Martin 发表气–液色谱，分离脂肪酸；1956 年 van Deemter 等提出速率理论；1958 年 Golay 提出开管柱（毛细管柱）；1979 年出现熔融石英毛细管柱，气相色谱进入现代形态。
- 1960 年代末，小粒径填料与高压泵催生了高效液相色谱（Horváth、Kirkland、Huber 等）；1980 年代出现毛细管电泳与毛细管电动色谱，2000 年代出现亚 2 μm 填料的超高效液相色谱（[6.4.14](/6.4.14#def-14.1.3)）。

色谱法可以按三种方式分类：

| 分类依据 | 类别 |
|---|---|
| 流动相的状态 | 气相色谱（GC，再按固定相分为气–固与气–液色谱）、液相色谱（LC）、超临界流体色谱（SFC） |
| 分离机理 | 吸附色谱、分配色谱、离子交换色谱、体积排阻色谱、亲和色谱（[6.4.14](/6.4.14#sec-14.2)） |
| 固定相的形态 | 柱色谱（填充柱、开管柱）、平板色谱（纸色谱、薄层色谱） |

按分离效率还可以分为经典液相色谱（常压、粒径约 100 μm 的填料，有机实验室的柱层析）与高效液相色谱。

### 13.1.2. 色谱图与保留值

**定义 13.1.3（色谱图）** 试样注入色谱柱后，检测器的响应信号随时间（或流出的流动相体积）变化的曲线称为**色谱图**，也称色谱流出曲线。

只有流动相通过检测器时的信号曲线称为基线，它的短时起伏是噪声，缓慢的漂移是基线漂移。理想的色谱峰是 Gauss 曲线，即 **正态分布** 的密度形状，以标准差 $\sigma$ 描述峰宽：拐点处（峰高的 0.607 倍）的峰宽为 $2\sigma$，半峰宽

$$
W_{1/2} = 2\sqrt{2\ln 2}\,\sigma = 2.355\sigma,
$$
过拐点作切线与基线相交，所截得的峰底宽 $W_{\mathrm{b}} = 4\sigma$。峰面积 $A = \sqrt{2\pi}\,\sigma h \approx 1.065\,W_{1/2}h$（$h$ 为峰高）是定量的依据（13.6 节）。

**定义 13.1.4（保留时间）** 从进样到某组分的色谱峰极大出现的时间称为该组分的**保留时间** $t_{\mathrm{R}}$；保留时间减去死时间 $t_{\mathrm{M}}$ 称为**调整保留时间** $t'_{\mathrm{R}} = t_{\mathrm{R}} - t_{\mathrm{M}}$，它是组分停留在固定相中的总时间。在保留时间内流过色谱柱的流动相体积称为**保留体积** $V_{\mathrm{R}} = t_{\mathrm{R}}F_{\mathrm{c}}$，$F_{\mathrm{c}}$ 为流动相的体积流量（气相色谱中要校正到柱温与柱内平均压力）。

**定义 13.1.5（死时间）** 不与固定相作用的组分（如气相色谱中的空气或甲烷，反相液相色谱中的尿嘧啶）从进样到出峰的时间称为**死时间** $t_{\mathrm{M}}$（教材常记作 $t_0$）；相应的流动相体积 $V_{\mathrm{M}} = t_{\mathrm{M}}F_{\mathrm{c}}$ 称为**死体积**，它是柱内流动相所占的体积加上进样器与检测器之间的管路体积。

若柱长为 $L$，流动相的平均线速度 $u = L/t_{\mathrm{M}}$。保留值在色谱条件（固定相、柱温、流动相组成）一定时只与组分的性质有关，是定性的依据；但它也与柱长、流量有关，所以文献中更常用下面与柱尺寸无关的相对量。

### 13.1.3. 分配系数与保留因子

组分 A 在固定相与流动相之间达到分配平衡时，两相中的浓度之比就是 **分配系数**（[6.3.6](/6.3.6#sec-6.5.1)）：

$$
K = \frac{c_{\mathrm{S}}}{c_{\mathrm{M}}}.
$$
$K$ 由组分与两相的热力学性质和温度决定：$\ln K = -\Delta_{\operatorname{tr}}G^\circ/(RT)$，$\Delta_{\operatorname{tr}}G^\circ$ 是组分从流动相转移到固定相的标准 Gibbs 自由能变。各组分的 $K$ 不同，是色谱分离的前提。

**定义 13.1.6（保留因子）** 平衡时组分在固定相中的物质的量与在流动相中的物质的量之比称为**保留因子**（旧称**容量因子**）：

$$
k = \frac{n_{\mathrm{S}}}{n_{\mathrm{M}}} = \frac{c_{\mathrm{S}}V_{\mathrm{S}}}{c_{\mathrm{M}}V_{\mathrm{M}}} = K\frac{V_{\mathrm{S}}}{V_{\mathrm{M}}} = K\beta^{-1},
$$
$V_{\mathrm{S}}$、$V_{\mathrm{M}}$ 为柱内固定相与流动相的体积，$\beta = V_{\mathrm{M}}/V_{\mathrm{S}}$ 称为相比。

$k$ 既与组分有关（通过 $K$），又与柱的构造有关（通过相比）：开管柱的固定液膜很薄，$\beta$ 为 100–500，填充柱为 5–35。萃取中的分配比 $D$（[6.3.6](/6.3.6#sec-6.5.2)）是总浓度之比，不要与这里的 $k$ 混淆。

**定理 13.1.1（基本保留方程）** 设分配平衡瞬间建立，则

$$
t_{\mathrm{R}} = t_{\mathrm{M}}(1 + k), \qquad k = \frac{t_{\mathrm{R}} - t_{\mathrm{M}}}{t_{\mathrm{M}}} = \frac{t'_{\mathrm{R}}}{t_{\mathrm{M}}}, \qquad V_{\mathrm{R}} = V_{\mathrm{M}} + KV_{\mathrm{S}}. \tag{13.1}
$$

**证明** 组分分子只有在流动相中才随流动相移动。任一时刻处在流动相中的分子所占的分数为 $n_{\mathrm{M}}/(n_{\mathrm{M}} + n_{\mathrm{S}}) = 1/(1 + k)$；按各态历经的观点，这也是一个分子在流动相中度过的时间分数。所以谱带中心的平均移动速度 $u_{\mathrm{A}} = u/(1 + k)$，通过柱长 $L$ 所需的时间 $t_{\mathrm{R}} = L/u_{\mathrm{A}} = t_{\mathrm{M}}(1 + k)$。乘以 $F_{\mathrm{c}}$，并用 $kV_{\mathrm{M}} = KV_{\mathrm{S}}$，即得保留体积的式子。$\square$

所以 $k$ 可以直接从色谱图读出：它是组分在固定相中停留的时间与在流动相中停留的时间之比。$k = 0$ 的组分随死时间流出，$k$ 很大的组分出峰太晚、峰太宽。

### 13.1.4. 选择因子与分离度

**定义 13.1.7（选择因子）** 两个组分（后出峰者为 2）的保留因子之比

$$
\alpha = \frac{k_2}{k_1} = \frac{t'_{\mathrm{R2}}}{t'_{\mathrm{R1}}} = \frac{K_2}{K_1} \ge 1
$$
称为**选择因子**，也称**相对保留值**。

$\alpha$ 只由两种组分在两相中的热力学性质决定，与柱长、柱径、流速无关，是固定相（以及液相色谱中流动相）对这对组分的选择性的度量；$\alpha = 1$ 时，无论柱多长都不能分离。它是方法的 **选择性**（定义 1.8.4）在色谱中的具体形式。

两个峰能否分开，不仅取决于峰间距（热力学），还取决于峰宽（动力学）：

**定义 13.1.8（分离度）** 相邻两峰保留时间之差与两峰峰底宽平均值之比

$$
R_{\mathrm{s}} = \frac{t_{\mathrm{R2}} - t_{\mathrm{R1}}}{(W_{\mathrm{b1}} + W_{\mathrm{b2}})/2} = \frac{2(t_{\mathrm{R2}} - t_{\mathrm{R1}})}{W_{\mathrm{b1}} + W_{\mathrm{b2}}}
$$
称为**分离度**（有些教材记作 $R$，这里加下标以免与摩尔气体常量混淆）。

两峰等高等宽时，$R_{\mathrm{s}} = 1$ 表示峰顶相距 $4\sigma$。在两峰中点处切割收集，每个峰越过中点的部分是 **正态分布** 的尾部概率 $\Phi(-2R_{\mathrm{s}})$：$R_{\mathrm{s}} = 1$ 时约 2.3%（常说的"97.7% 分离"），$R_{\mathrm{s}} = 1.5$ 时约 0.13%，通常把 $R_{\mathrm{s}} \ge 1.5$ 作为完全分离（基线分离）的标准。两峰高度相差很大或峰形拖尾时，需要更大的 $R_{\mathrm{s}}$。

![分离度为 0.75、1.0、1.5 的两个等面积 Gauss 峰（峰顶相距 3σ、4σ、6σ），标题中的数字是每个峰越过两峰中点的部分 Φ(−2Rs)](./plots/resolution-overlap.py)

**例 13.1.1** 在一根色谱柱上，死时间 $t_{\mathrm{M}} = 1.20\,\mathrm{min}$，两组分的保留时间为 $10.20$ 与 $10.80\,\mathrm{min}$，峰底宽为 $0.60$ 与 $0.64\,\mathrm{min}$。求 $k_1$、$k_2$、$\alpha$ 与 $R_{\mathrm{s}}$。

**解** $k_1 = (10.20 - 1.20)/1.20 = 7.50$，$k_2 = 8.00$，$\alpha = 8.00/7.50 = 1.067$；$R_{\mathrm{s}} = 2 \times 0.60/(0.60 + 0.64) = 0.97$，两峰没有完全分开。例 13.3.2 将求出要达到 $R_{\mathrm{s}} = 1.5$ 所需的柱长。$\square$

## 13.2. 塔板理论

### 13.2.1. Craig 模型

**定义 13.2.1（塔板理论）** 把色谱柱看作由一系列连续的、高度相等的小段（塔板）组成，假定组分在每一块塔板上的两相间迅速达到分配平衡、流动相间歇地从一块塔板进入下一块、纵向扩散可以忽略、分配系数与浓度无关，从而计算组分沿柱的分布与流出曲线的理论称为**塔板理论**。

塔板与平衡的概念借自精馏（[6.3.9](/6.3.9)），最直观的模型是 Craig 的逆流分配装置：一排分液管（塔板 $r = 0, 1, 2, \dots$）各盛等体积的固定相，开始时把组分全部放入第 0 号管并加入流动相；平衡后把每管中的流动相转移到下一管，再在第 0 号管中加入新的流动相，如此反复。每次平衡后，组分在流动相中的分数 $p = 1/(1 + k)$，在固定相中的分数 $q = k/(1 + k)$。

**定理 13.2.1** 经过 $n$ 次转移后，第 $r$ 号塔板上的组分分数为

$$
f_{n,r} = \binom{n}{r}p^rq^{n-r}, \qquad r = 0, 1, \dots, n,
$$
即组分在各塔板上的分布服从 **二项分布** $\mathrm{Bin}(n, p)$（[3.1.4](/3.1.4)）。

**证明** 对 $n$ 用归纳法。$n = 0$ 时组分全部在第 0 号管中，成立。设第 $n$ 次转移后成立；第 $n + 1$ 次转移后，第 $r$ 号管中的组分来自两部分：原在第 $r$ 号管、留在固定相中的 $qf_{n,r}$，以及原在第 $r - 1$ 号管、随流动相转入的 $pf_{n,r-1}$。由 Pascal 恒等式 $\binom{n}{r} + \binom{n}{r-1} = \binom{n+1}{r}$，$qf_{n,r} + pf_{n,r-1} = \binom{n+1}{r}p^rq^{n+1-r}$。从概率的角度看更简单：一个分子每次转移时独立地以概率 $p$ 前进一格，$n$ 次后前进的格数就是 $n$ 次独立 Bernoulli 试验中成功的次数。$\square$

于是谱带中心位于 $r = np$ 处，即谱带以流动相速度的 $1/(1 + k)$ 前进，与定理 13.1.1 一致；谱带的方差 $npq$ 与转移次数成正比。$n$ 很大时，由 **中心极限定理**（[3.1.13](/3.1.13)），二项分布趋于正态分布 $\mathcal{N}(np, npq)$：塔板理论解释了色谱峰为什么是 Gauss 形，为什么 $k$ 不同的组分会分开（中心距离 $\propto n$，峰宽只 $\propto \sqrt n$）。

### 13.2.2. 流出曲线方程与理论塔板数

色谱柱的最后一块塔板（第 $N$ 块）的流出物进入检测器，以其中的浓度对流出的流动相体积作图就是流出曲线。转移次数 $n$ 很大时，用正态近似并把转移次数换成流出体积 $V$，得到流出曲线方程

$$
c = \frac{m}{\sigma_V\sqrt{2\pi}}\exp\left[-\frac{(V - V_{\mathrm{R}})^2}{2\sigma_V^2}\right], \qquad \sigma_V = \frac{V_{\mathrm{R}}}{\sqrt N},
$$
$m$ 是组分的量，$N$ 是柱的塔板数。浓度极大出现在 $V = V_{\mathrm{R}}$ 处，峰的相对宽度 $\sigma_V/V_{\mathrm{R}} = 1/\sqrt N$ 只由塔板数决定。

这个结果可以从两种模型得到。在 Craig 的间歇模型中，组分到达第 $N$ 块塔板所需的转移次数是取得 $N$ 次"前进"所需的 Bernoulli 试验次数，均值为 $N/p = N(1 + k)$，方差为 $Nq/p^2$，所以相对标准差为 $\sqrt{q/N} = \sqrt{k/(1 + k)}/\sqrt N$；在流动相连续流动的 Martin–Synge 模型中，流出曲线是 Poisson 型，相对标准差恰为 $1/\sqrt N$。$k \gg 1$ 时两者一致，$N$ 很大时流出曲线都趋于正态。实际工作中不必依赖哪一种模型，而是由色谱峰直接定义 $N$：

**定义 13.2.2（理论塔板数）** 由色谱峰的保留时间与峰宽按

$$
N = \left(\frac{t_{\mathrm{R}}}{\sigma}\right)^2 = 16\left(\frac{t_{\mathrm{R}}}{W_{\mathrm{b}}}\right)^2 = 5.54\left(\frac{t_{\mathrm{R}}}{W_{1/2}}\right)^2 \tag{13.2}
$$
计算的量称为**理论塔板数**；柱长 $L$ 除以 $N$ 称为**塔板高度**（理论塔板高度，HETP）：

$$
H = \frac{L}{N} = \frac{\sigma_L^2}{L},
$$
$\sigma_L$ 是谱带在柱出口处以长度表示的标准差。用调整保留时间计算的 $N_{\mathrm{eff}} = 16(t'_{\mathrm{R}}/W_{\mathrm{b}})^2$ 称为**有效塔板数**。

$N$ 与 $H$ 是柱效（色谱柱的效能）的指标：$N$ 越大、$H$ 越小，峰越窄。$H = \sigma_L^2/L$ 的意义是"每单位柱长产生的谱带方差"，它不依赖于塔板的假想图像，下一节的速率理论就从这里出发。由 $t_{\mathrm{R}} = t_{\mathrm{M}}(1 + k)$ 可得

$$
N_{\mathrm{eff}} = N\left(\frac{k}{1 + k}\right)^2:
$$
$k$ 很小的组分（接近死时间出峰）即使 $N$ 很大，$N_{\mathrm{eff}}$ 也很小，说明对这种组分柱子并没有发挥分离作用。所以比较柱效时要注明所用的组分与 $k$。典型数值：2 m 填充柱 $N$ 约 $10^3$–$10^4$（$H$ 约 0.5–1 mm）；30 m、内径 0.25 mm 的毛细管柱 $N$ 约 $10^5$（$H$ 约 0.2–0.3 mm，与柱内径相当）；15 cm、5 μm 填料的液相色谱柱 $N$ 约 $10^4$（$H$ 约 10 μm）。

### 13.2.3. 塔板理论的成就与不足

塔板理论用二项分布与中心极限定理解释了色谱峰的 Gauss 形状、保留时间与分配系数的关系，给出了评价柱效的指标 $N$ 与 $H$。它的两相并不限于固–液：对气体组分，可以是气–固或气–液，对液体组分可以是液–液或液–固，所以同一理论适用于各种色谱法。

它的不足在于假设本身：真实色谱柱中流动相是连续流动的，两相间不可能每一段都达到平衡，组分在流动相中也有纵向扩散。塔板理论因此不能说明塔板高度由什么因素决定，也不能解释同一根柱在不同流速下柱效不同的实验事实，无法指导怎样制备与操作色谱柱以提高柱效。回答这些问题的是速率理论。

## 13.3. 速率理论与分离方程

### 13.3.1. 谱带展宽的随机游走图像

谱带在柱中移动时不断展宽，原因是各个分子的运动并不相同：有的走了较短的通道，有的向前或向后扩散了一段，有的在固定相中多停留了一会儿。每个分子的位置是许多独立的随机位移之和，按 **中心极限定理** 谱带趋于正态分布；按 **Einstein–Smoluchowski 关系**（[6.3.21](/6.3.21#thm-21.3.1)）的思路，独立的展宽过程的方差相加：

$$
\sigma_L^2 = \sum_i\sigma_i^2, \qquad H = \frac{\sigma_L^2}{L} = \sum_i H_i.
$$
于是只要分别算出每个过程贡献的方差，再除以柱长，就得到各项板高。1956 年，van Deemter、Zuiderweg 与 Klinkenberg 对填充柱气相色谱做了这样的分析。

### 13.3.2. van Deemter 方程

**定义 13.3.1（van Deemter 方程）** 描述塔板高度与流动相线速度 $u$ 关系的方程

$$
H = A + \frac{B}{u} + Cu \tag{13.3}
$$
称为 **van Deemter 方程**（速率理论方程）。三项分别是：

1. **涡流扩散**项 $A = 2\lambda d_{\mathrm{p}}$：流动相携带组分分子在填料颗粒之间沿长短不同的曲折通道前进，有的分子先到、有的后到而引起的展宽。$d_{\mathrm{p}}$ 是填料的平均粒径，$\lambda$ 是填充不规则因子（填充越均匀，$\lambda$ 越小，约 0.5–1）。
2. **纵向扩散**项 $B/u$，$B = 2\gamma D_{\mathrm{m}}$：组分分子在流动相中沿柱轴方向由浓处向稀处扩散引起的展宽。$D_{\mathrm{m}}$ 是组分在流动相中的扩散系数，$\gamma$ 是填料使扩散路径弯曲的弯曲因子（填充柱 $\gamma$ 约 0.6–0.8，开管柱 $\gamma = 1$）。
3. **传质阻力**项 $Cu$，$C = C_{\mathrm{s}} + C_{\mathrm{m}}$：组分在两相之间的传质需要时间，两相间来不及达到平衡，在流动相中的分子被带到前面，在固定相中的分子落在后面，引起展宽。固定相传质阻力系数与流动相传质阻力系数分别为

$$
C_{\mathrm{s}} = \frac{qk}{(1 + k)^2}\cdot\frac{d_{\mathrm{f}}^2}{D_{\mathrm{s}}}, \qquad C_{\mathrm{m}} = \frac{\omega d_{\mathrm{p}}^2}{D_{\mathrm{m}}},
$$
$d_{\mathrm{f}}$ 是固定液膜的厚度，$D_{\mathrm{s}}$ 是组分在固定相中的扩散系数，$q$ 是与固定相形状有关的常数（均匀液膜为 $8/\pi^2$），$\omega$ 是与填充情况和 $k$ 有关的常数。

各项的来历可以用随机游走粗略估计：

- 纵向扩散：组分在流动相中停留的时间是 $t_{\mathrm{M}} = L/u$，在这段时间内按 Einstein–Smoluchowski 关系产生的方差 $\sigma^2 = 2\gamma D_{\mathrm{m}}L/u$，除以 $L$ 得 $H_B = 2\gamma D_{\mathrm{m}}/u$。流速越慢，分子在柱中停留越久，扩散越严重。（组分在固定相中也会扩散，但 $D_{\mathrm{s}}$ 很小，一般忽略。）
- 涡流扩散：分子每经过约一个颗粒直径的距离就随机地改变一次通道，柱长 $L$ 上有约 $L/d_{\mathrm{p}}$ 步，每步引起与 $d_{\mathrm{p}}$ 同数量级的位移偏差，方差 $\propto (L/d_{\mathrm{p}})d_{\mathrm{p}}^2 = Ld_{\mathrm{p}}$，所以 $H_A \propto d_{\mathrm{p}}$，与流速无关。
- 传质阻力：分子扩散穿过液膜（或颗粒内的停滞流动相）所需的时间约 $d^2/D$；在这段时间内流动相前进的距离 $\propto u\,d^2/D$，相当于随机游走的步长，所以 $H_C \propto u\,d^2/D$，与流速成正比。$C_{\mathrm{s}}$ 中的因子 $k/(1 + k)^2$ 在 $k = 1$ 时最大：$k$ 很大时组分几乎总在固定相中，$k$ 很小时几乎不进入固定相，两种情况下两相间的交换都不是主要的展宽来源。

方程 (13.3) 指出了提高柱效的途径：用粒度小而均匀的填料并填充均匀（减小 $A$ 与 $C_{\mathrm{m}}$）；用薄而均匀的固定液膜（减小 $C_{\mathrm{s}}$）；选择适当的流动相与流速。在气相色谱中，固定液膜越薄、柱温越高（$D_{\mathrm{s}}$ 增大），传质越快；但液膜太薄柱容量就小。

### 13.3.3. 最佳流速

**定理 13.3.1** 在 van Deemter 方程中，塔板高度在

$$
u_{\mathrm{opt}} = \sqrt{\frac{B}{C}}
$$
处取极小值 $H_{\min} = A + 2\sqrt{BC}$。

**证明** $\mathrm{d}H/\mathrm{d}u = -B/u^2 + C = 0$ 得 $u_{\mathrm{opt}} = \sqrt{B/C}$；$\mathrm{d}^2H/\mathrm{d}u^2 = 2B/u^3 > 0$，是极小值。代入得 $H_{\min} = A + B\sqrt{C/B} + C\sqrt{B/C} = A + 2\sqrt{BC}$。$\square$

流速低于 $u_{\mathrm{opt}}$ 时纵向扩散占主导，高于 $u_{\mathrm{opt}}$ 时传质阻力占主导。实际工作中常用略高于 $u_{\mathrm{opt}}$ 的流速：$H$–$u$ 曲线在极小值右侧较平坦，柱效损失不多，分析时间却明显缩短。

开管柱没有填料，$A = 0$，流动相传质项由柱内径 $d_{\mathrm{c}}$ 决定，Golay（1958）给出

$$
H = \frac{2D_{\mathrm{m}}}{u} + \frac{1 + 6k + 11k^2}{96(1 + k)^2}\cdot\frac{d_{\mathrm{c}}^2}{D_{\mathrm{m}}}u + \frac{2k}{3(1 + k)^2}\cdot\frac{d_{\mathrm{f}}^2}{D_{\mathrm{s}}}u.
$$
没有涡流扩散，柱又可以做得很长（几十米而压降不大），所以毛细管柱的总塔板数远高于填充柱。载气的影响也由此看出：组分在 $\ce{H2}$、$\ce{He}$ 中的扩散系数比在 $\ce{N2}$ 中大（气体的扩散系数随分子质量减小而增大，[5.2.2](/5.2.2)），$D_{\mathrm{m}}$ 增大使 $B$ 增大、$C_{\mathrm{m}}$ 减小，$u_{\mathrm{opt}}$ 移向高流速而曲线右侧变平坦。所以用 $\ce{N2}$ 作载气时 $H_{\min}$ 稍小，但只能低速操作；用 $\ce{H2}$ 或 $\ce{He}$ 可以在高流速下保持柱效，分析快得多。

![左：填充柱的 van Deemter 曲线及其三项分解（示意数值 A = 0.30 mm、B = 6.0 mm·cm/s、C = 0.030 mm·s/cm），最低点 u_opt = 14.1 cm/s、H_min = 1.15 mm。右：内径 0.25 mm 开管柱在 N₂、He、H₂ 载气中的 Golay 曲线（k = 5），扩散系数越大，最佳流速越高、曲线越平坦](./plots/van-deemter.py)

**例 13.3.1** 用左图的数值：$u_{\mathrm{opt}} = \sqrt{6.0/0.030}\,\mathrm{cm\,s^{-1}} = 14.1\,\mathrm{cm\,s^{-1}}$，$H_{\min} = 0.30 + 2\sqrt{6.0 \times 0.030} = 1.15\,\mathrm{mm}$。2 m 长的柱在最佳流速下 $N = 2000/1.15 \approx 1700$。若把流速提高到 $28\,\mathrm{cm\,s^{-1}}$，$H = 0.30 + 0.21 + 0.84 = 1.35\,\mathrm{mm}$，柱效降低约 15%，分析时间减半。$\square$

液相色谱中 $D_{\mathrm{m}}$ 约为气相中的 $10^{-4}$–$10^{-5}$ 倍，纵向扩散项可以忽略，传质阻力项占主导，提高柱效的关键是减小填料粒径（[6.4.14](/6.4.14#sec-14.1.3)）。

### 13.3.4. 柱外效应

**定义 13.3.2（柱外效应）** 色谱柱以外的因素——进样塞的宽度、进样器与连接管和检测池的死体积、检测器与数据系统的响应时间——造成的谱带展宽称为**柱外效应**（柱外展宽）。

柱外的方差与柱内的方差相加：$\sigma_{\mathrm{obs}}^2 = \sigma_{\mathrm{col}}^2 + \sigma_{\mathrm{inj}}^2 + \sigma_{\mathrm{tube}}^2 + \sigma_{\mathrm{det}}^2$。宽度为 $\tau$ 的矩形进样塞贡献 $\tau^2/12$；长为 $l$、内径为 $d$ 的连接管中层流贡献的体积方差约为 $\pi d^4 lF_{\mathrm{c}}/(384D_{\mathrm{m}})$，与内径的四次方成正比。柱效越高、柱体积越小（细径柱、短柱、早出峰的组分），柱外效应的影响越大。所以毛细管气相色谱要用分流进样或很小的进样量，超高效液相色谱要用内径很细的连接管与微升级以下的检测池。

### 13.3.5. 分离方程与分离条件的选择

分离度把热力学（$\alpha$）与动力学（$N$）结合在一起，下面把它写成三个可以分别调节的因子之积。

**定理 13.3.2（分离方程）** 设相邻两峰的塔板数相同、峰宽近似相等，则

$$
R_{\mathrm{s}} = \frac{\sqrt N}{4}\cdot\frac{\alpha - 1}{\alpha}\cdot\frac{k_2}{1 + k_2}, \tag{13.4}
$$
$k_2$ 是后出峰组分的保留因子。

**证明** 两峰宽度相近时，$R_{\mathrm{s}} \approx (t_{\mathrm{R2}} - t_{\mathrm{R1}})/W_{\mathrm{b2}}$。由式 (13.2)，$W_{\mathrm{b2}} = 4t_{\mathrm{R2}}/\sqrt N$；由式 (13.1)，$t_{\mathrm{R2}} - t_{\mathrm{R1}} = t_{\mathrm{M}}(k_2 - k_1)$，$t_{\mathrm{R2}} = t_{\mathrm{M}}(1 + k_2)$。于是

$$
R_{\mathrm{s}} = \frac{\sqrt N}{4}\cdot\frac{k_2 - k_1}{1 + k_2} = \frac{\sqrt N}{4}\cdot\frac{k_2 - k_1}{k_2}\cdot\frac{k_2}{1 + k_2},
$$
而 $(k_2 - k_1)/k_2 = 1 - 1/\alpha = (\alpha - 1)/\alpha$。$\square$

式 (13.4) 中三个因子分别称为柱效项、选择性项与保留项。解出 $N$，得到达到指定分离度所需的塔板数

$$
N_{\mathrm{req}} = 16R_{\mathrm{s}}^2\left(\frac{\alpha}{\alpha - 1}\right)^2\left(\frac{1 + k_2}{k_2}\right)^2.
$$
再由 $t_{\mathrm{R}} = N_{\mathrm{req}}H(1 + k_2)/u$，分析时间

$$
t_{\mathrm{R}} = \frac{16R_{\mathrm{s}}^2H}{u}\left(\frac{\alpha}{\alpha - 1}\right)^2\frac{(1 + k_2)^3}{k_2^2}.
$$

![分离方程：分别改变 N、α、k，其余两项固定为 N = 10 000、α = 1.05、k = 5；虚线为 Rs = 1.5](./plots/resolution-equation.py)

由图与上面两式可以得出选择分离条件的原则：

- 柱效项：$R_{\mathrm{s}} \propto \sqrt N$。柱长加倍，$N$ 加倍，$R_{\mathrm{s}}$ 只提高到 $\sqrt 2$ 倍，分析时间却加倍；提高 $N$ 更好的办法是减小 $H$（小粒径、薄液膜、合适的流速，13.3.2）。
- 选择性项：最有效的手段。$\alpha$ 从 1.05 增大到 1.10，$(\alpha - 1)/\alpha$ 几乎加倍，所需塔板数降为约 $1/4$。气相色谱主要靠换固定液与改变柱温来改变 $\alpha$，液相色谱还可以改变流动相的组成（[6.4.14](/6.4.14#sec-14.2.3)）。$\alpha = 1.01$ 的难分离物质对，即使 $k$ 很大（保留项趋于 1），也至少需要约 $3.7 \times 10^5$ 块塔板，只有长毛细管柱能做到。
- 保留项：$k$ 从 0 增大时 $k/(1 + k)$ 迅速增大，$k > 10$ 以后几乎不再变化，而分析时间与峰宽却随 $1 + k$ 增大；上面的时间公式在 $k_2 = 2$ 时取极小。所以一般把 $k$ 控制在 1–10 之间（最好 2–5）；在气相色谱中调节柱温，在液相色谱中调节流动相强度。

**例 13.3.2** 对例 13.1.1 的两组分，由第二个峰 $N = 16 \times (10.80/0.64)^2 = 4.56 \times 10^3$，按式 (13.4) 计算 $R_{\mathrm{s}} = 0.94$（与直接计算的 0.97 的差别来自"两峰等宽"的近似）。要使 $R_{\mathrm{s}} = 1.5$，在其他条件不变时 $N$ 须增大到 $(1.5/0.97)^2 = 2.40$ 倍，即约 $1.1 \times 10^4$ 块塔板：柱长增大到 2.4 倍，分析时间也增大到 2.4 倍（约 26 min）。若改用 $\alpha = 1.10$ 的固定液而 $k_2$ 不变，原来的柱就能给出 $R_{\mathrm{s}} = \frac{\sqrt{4560}}{4}\cdot\frac{0.10}{1.10}\cdot\frac{8}{9} = 1.36$，接近完全分离。$\square$

## 13.4. 气相色谱仪

### 13.4.1. 仪器的组成与载气

**定义 13.4.1（气相色谱）** 以气体为流动相（载气）的色谱法称为**气相色谱**。固定相为固体吸附剂的称为气–固色谱，为涂在载体或柱壁上的高沸点液体的称为气–液色谱。

气相色谱适用于在柱温下能气化而不分解的物质：永久气体、低分子烃、挥发性有机物（溶剂、香料、农药、脂肪酸甲酯）。估计约 20% 的已知有机化合物可以直接用气相色谱分析；难挥发或极性强的物质（糖、氨基酸、有机酸）可以先衍生化（硅烷化、甲酯化）再分析，热不稳定、不挥发的物质（蛋白质、无机盐）则要用液相色谱。

```mermaid
flowchart LR
  G["载气钢瓶<br/>（减压阀）"] --> P["净化器<br/>（分子筛、脱氧剂）"]
  P --> F["稳压阀、稳流阀<br/>与流量计"]
  F --> I["进样器与汽化室"]
  I --> C["色谱柱<br/>（柱温箱）"]
  C --> D["检测器"]
  D --> S["放大器与数据系统"]
```

气相色谱仪由载气系统、进样系统、分离系统（色谱柱与柱温箱）、检测系统和数据处理系统组成。对载气的要求是：

1. 纯净：用 **分子筛**、活性炭与脱氧剂除去水、氧与烃类，否则会使固定液氧化、基线噪声增大，并降低电子捕获检测器的灵敏度。
2. 稳定：流速的波动会改变保留时间，并使浓度型检测器的基线漂移（13.5.1 节），所以要用稳压阀、稳流阀或电子压力控制。程序升温时柱内气体黏度增大，恒压操作会使流速下降，现代仪器多采用恒流操作。
3. 种类：常用 $\ce{N2}$、$\ce{He}$、$\ce{H2}$（13.3.3 节）。$\ce{N2}$ 便宜，但最佳流速低；$\ce{He}$ 惰性、安全，是气相色谱–质谱联用的标准载气，但价格高、供应受限；$\ce{H2}$ 分析最快、柱效随流速下降最慢，但易燃，可能与不饱和组分反应。载气还要与检测器匹配：热导检测器要用热导率高的 $\ce{He}$ 或 $\ce{H2}$（13.5.2 节）。

### 13.4.2. 进样系统

液体试样用微量注射器穿过硅橡胶垫注入汽化室，在 $200$–$300\,{}^\circ\mathrm{C}$ 下瞬间汽化后被载气带入柱中；气体试样用六通阀定量进样。对汽化室的要求是体积小（减小柱外展宽）、热容量大（保证瞬间汽化）、内壁惰性（不使试样催化分解，常衬以去活的玻璃衬管）。

毛细管柱的柱容量很小（每个组分纳克级），进样有专门的方式：

- 分流进样：汽化后的试样只有一小部分（分流比 1:10–1:500）进入色谱柱，其余放空，保证进样窄、不超载，用于浓度较高的试样。
- 不分流进样：进样时关闭分流阀约 30–60 s，几乎全部试样进入柱中，靠低柱温下溶剂在柱头的冷凝把谱带重新聚焦，然后再升温分离，用于痕量分析。
- 顶空进样与固相微萃取：只取试样上方的蒸气，或用涂有固定相的纤维从试样中吸附挥发性组分再在汽化室中热解吸，避免不挥发的基体进入色谱柱，常用于血液中的乙醇、水中的挥发性有机物与食品的香气成分。

**定义 13.4.2（裂解气相色谱）** 把不挥发的高分子试样在惰性气氛中瞬间加热到 $500$–$1000\,{}^\circ\mathrm{C}$，使其裂解为可挥发的小分子碎片，再用气相色谱分离，以所得的特征色谱图（裂解图）鉴定与研究高分子的方法称为**裂解气相色谱**。

裂解器有管式炉、热丝与居里点裂解器（铁磁性丝在高频磁场中迅速加热到其 Curie 温度后不再升温，温度准确、重现）。裂解碎片反映高分子的结构单元：例如尼龙 6 裂解主要生成 ε-己内酰胺，尼龙 66 生成环戊酮等由己二酸单元来的产物，所以尼龙 6/66 共聚物的裂解图中两类峰的面积比可以估计两种单元的组成。裂解气相色谱也用于微生物、涂料、文物与法庭物证的鉴定。

### 13.4.3. 色谱柱与固定相

| 柱型 | 内径 | 长度 | 固定相 | 塔板数 |
|---|---|---|---|---|
| 填充柱 | 2–6 mm | 1–6 m | 吸附剂颗粒，或涂有固定液的载体颗粒 | $10^3$–$10^4$ |
| 开管柱（毛细管柱） | 0.10–0.53 mm | 10–100 m | 涂在柱内壁上的固定液膜（0.1–5 μm）或吸附剂层 | $10^5$ 左右 |

现代开管柱用熔融石英拉制，外涂聚酰亚胺保护层，柔韧而内壁惰性。固定液直接涂在内壁上的称为壁涂开管柱（WCOT），最常用；内壁上附着多孔吸附层的称为多孔层开管柱（PLOT），用于永久气体与低分子烃。毛细管柱已经取代填充柱成为分析的主流，填充柱仍用于气体分析与制备。

固定相有两类：

1. 固体固定相：活性炭、硅胶、氧化铝、分子筛与多孔高分子小球（如苯乙烯–二乙烯苯共聚物）等 **吸附剂**，依靠 **物理吸附** 的差异分离 $\ce{H2}$、$\ce{O2}$、$\ce{N2}$、$\ce{CO}$、$\ce{CO2}$ 与 $\mathrm{C}_1$–$\mathrm{C}_4$ 烃等永久气体与低沸点物质。吸附等温线在浓度稍大时就偏离线性（[6.3.20](/6.3.20#sec-20.3)），峰容易拖尾，所以只用于这些在液体中溶解度很小的组分。
2. 液体固定相：固定液涂在载体上（填充柱）或柱壁上（开管柱）。

**定义 13.4.3（固定液）** 气–液色谱中作固定相的高沸点有机物称为**固定液**；支撑固定液、使其以薄膜形式铺开的多孔惰性固体颗粒称为载体（担体）。

固定液应当在柱温下蒸气压低（否则流失，使基线升高并污染检测器）、热稳定与化学惰性好、黏度低（传质快）、对待分离的组分有选择性。载体多为经酸洗与硅烷化处理的硅藻土，要求比表面积适中、表面惰性、颗粒均匀。

### 13.4.4. 固定液的选择与相对极性

组分在固定液中的溶解度取决于两者分子间作用力：**色散力**、偶极之间的作用、诱导作用与 **氢键**（[6.1.4](/6.1.4)）。由此得出"相似相溶"的选择原则：

| 待分离组分 | 固定液 | 出峰顺序 |
|---|---|---|
| 非极性（烃类） | 非极性 | 主要按沸点（蒸气压），低沸点先出峰 |
| 中等极性 | 中等极性 | 沸点与分子间作用力共同决定 |
| 强极性 | 强极性 | 按极性，极性小者先出峰 |
| 能形成氢键 | 极性或氢键型 | 按形成氢键能力，能力弱者先出峰 |
| 极性与非极性混合 | 极性 | 非极性组分先出峰 |

在非极性固定液上，组分的保留主要取决于它的 **饱和蒸气压**：由 Raoult 定律的推广，$K \propto 1/(\gamma_{\infty}p^*)$（$\gamma_\infty$ 是组分在固定液中的无限稀释 **活度因子**，[6.3.6](/6.3.6)），而 $p^*$ 随沸点升高而降低。苯（沸点 $80.1\,{}^\circ\mathrm{C}$）与环己烷（$80.7\,{}^\circ\mathrm{C}$）沸点几乎相同，在非极性固定液上分不开；但苯的 π 电子容易被极化，在极性固定液中受到较强的诱导作用而保留更久，两者保留时间之比 $t_{\mathrm{R}}(\text{苯})/t_{\mathrm{R}}(\text{环己烷})$ 在弱极性的邻苯二甲酸二辛酯上约 1.5，在极性的聚乙二醇-400 上约 3.9，在强极性的 β,β′-氧二丙腈上约 6.3。

怎样定量地比较固定液的极性？Rohrschneider（1959）规定强极性的 β,β′-氧二丙腈（1）的相对极性为 100、非极性的角鲨烷（2，2,6,10,15,19,23-六甲基二十四烷）为 0：

```smiles
N#CCCOCCC#N 1
CC(C)CCCC(C)CCCC(C)CCCCC(C)CCCC(C)CCCC(C)C 2
```

用丁二烯与正丁烷这一对物质在三根柱上测定 $q = \lg[t'_{\mathrm{R}}(\text{丁二烯})/t'_{\mathrm{R}}(\text{正丁烷})]$，被测固定液 $x$ 的相对极性

$$
P_x = 100 - 100\,\frac{q_1 - q_x}{q_1 - q_2},
$$
下标 1、2 分别指 β,β′-氧二丙腈与角鲨烷。$P_x$ 每 20 个单位为一级，从 0 到 100 分为非极性与 +1 到 +5 级。一对探针只反映一种作用，后来发展为 McReynolds 常数：用苯、正丁醇、2-戊酮、硝基丙烷、吡啶五种探针，分别测定它们在被测固定液与角鲨烷上的保留指数之差 $\Delta I$（13.6.1 节），分别反映色散与 π 作用、给质子、偶极、受质子等作用，五个 $\Delta I$ 之和表示总极性。

现代毛细管柱常用的固定液是少数几种：

| 固定液 | 极性 | 最高使用温度（约） | 用途 |
|---|---|---|---|
| 聚二甲基硅氧烷 | 非极性 | $325\,{}^\circ\mathrm{C}$ | 烃类、通用，按沸点分离 |
| 5% 二苯基–95% 二甲基聚硅氧烷 | 弱极性 | $325\,{}^\circ\mathrm{C}$ | 最常用的通用柱，GC-MS、农药、环境样品 |
| 50% 苯基聚硅氧烷 | 中等极性 | $300\,{}^\circ\mathrm{C}$ | 药物、甾体 |
| 氰丙基苯基聚硅氧烷 | 中等至强极性 | $250\,{}^\circ\mathrm{C}$ | 脂肪酸甲酯的顺反异构体、农药 |
| 聚乙二醇 | 强极性 | $250\,{}^\circ\mathrm{C}$ | 醇、醛、酯、香料、溶剂残留 |
| 手性环糊精衍生物 | — | $230\,{}^\circ\mathrm{C}$ | 对映体（香料、药物中间体） |

聚硅氧烷耐高温、流失少，通过改变苯基、氰丙基的比例连续调节极性；它们还可以交联并键合在柱壁上，耐溶剂冲洗。

### 13.4.5. 柱温与程序升温

柱温是气相色谱中最重要的操作条件。由 $\ln K = -\Delta_{\operatorname{tr}}H^\circ/(RT) + \Delta_{\operatorname{tr}}S^\circ/R$，组分由气相溶入固定液是放热过程，$K$ 与 $k$ 随柱温升高而指数地减小：在通常条件下，柱温升高约 $20\,{}^\circ\mathrm{C}$，$k$ 约减为一半。柱温升高使分析加快、$D_{\mathrm{s}}$ 增大而传质加快，但一般使 $\alpha$ 减小、分离变差；柱温不能超过固定液的最高使用温度。

同系物的 $\lg k$ 随碳原子数线性增大（每增加一个 $\ce{CH2}$，$k$ 增大到约 2 倍），所以沸程很宽的试样在恒温下无法兼顾：低柱温下早出峰的组分分得开，但高沸点组分出峰极慢、峰低而宽；高柱温下高沸点组分出峰快，低沸点组分却挤在死时间附近分不开。这就是所谓的一般洗脱问题。

**定义 13.4.4（程序升温）** 在一次分析中，柱温按预定的程序（通常是线性）随时间升高的操作方式称为**程序升温**。

程序升温时，每个组分在较低温度下停留在柱头附近几乎不动，直到柱温升到使它的 $k$ 足够小时才迅速移动并流出。于是各组分大致在各自"合适的"温度下洗脱，同系物几乎等间距出峰、峰宽相近，分析时间缩短，后出峰组分的检出限也降低。液相色谱中与之对应的是梯度洗脱（[6.4.14](/6.4.14#def-14.1.2)）。

![正构烷烃 C6–C14（等量）在毛细管柱上的模拟色谱图（死时间 1 min，N = 50 000）。80 °C 恒温：后出峰组分慢而宽，C10 以后要 50 min 以上；180 °C 恒温：前几个组分挤在死时间附近；50 °C 起以 10 °C/min 程序升温：各组分几乎等间距出峰、峰宽相近](./plots/temperature-programming.py)

## 13.5. 检测器

### 13.5.1. 性能指标与检测器的类型

检测器把流出组分的量转变为电信号。评价它的指标与方法的性能指标（[6.4.1](/6.4.1#sec-1.8)）相同，只是对象换成了检测器：

- **灵敏度**（定义 1.8.2）：单位量的组分通过检测器时产生的信号，$S = \Delta R/\Delta Q$，$R$ 为信号（峰高 mV 或峰面积 mV·s），$Q$ 为组分在载气中的浓度（$\mathrm{mg\,mL^{-1}}$）或单位时间进入检测器的质量（$\mathrm{g\,s^{-1}}$）。
- **检出限**（定义 1.8.5）：按 3 倍噪声的约定，信号等于基线噪声（标准差）$N_{\mathrm{d}}$ 的 3 倍时对应的组分量，$D = 3N_{\mathrm{d}}/S$。灵敏度高而噪声也大的检测器，检出限未必低。
- **线性范围**（定义 1.8.3）：信号与组分量成正比的范围，以最大与最小进样量之比表示。
- 此外还要求响应快（毛细管柱的峰宽只有零点几秒到几秒）、稳定、死体积小，以及按需要具有通用性或选择性。

按响应原理，检测器分为两类：

**定义 13.5.1** 响应信号正比于组分在载气中的浓度的检测器称为**浓度型检测器**（如热导、电子捕获检测器）；响应信号正比于单位时间内进入检测器的组分质量的检测器称为**质量型检测器**（如氢火焰离子化、火焰光度检测器、质谱）。

区别在于载气流速的影响：对浓度型检测器，同样的组分量流速越大，峰越窄，峰高不变而峰面积与流速成反比，所以用峰面积定量时要保持流速恒定；对质量型检测器，峰面积与流速无关，峰高随流速增大而增大。

### 13.5.2. 热导检测器

**定义 13.5.2（热导检测器）** 利用被测组分与载气的热导率不同，使通电加热的热敏元件的温度与电阻改变，经 Wheatstone 电桥转变为电压信号的检测器称为**热导检测器**（TCD，热导池）。

热导池的金属块中有参比池与测量池，各装一根钨铼合金热丝，组成电桥的两臂；参比池只通纯载气，测量池通柱后的载气与组分。热丝在恒定电流下被加热，所产生的热量由周围气体传导给池壁。只有载气时两池散热相同，电桥平衡；组分进入测量池后，混合气体的 **热导率** 降低，热丝温度升高、**电阻** 增大，电桥失去平衡，输出与组分浓度成正比的信号。

常见气体在 $300\,\mathrm{K}$ 的热导率 $\kappa/(\mathrm{mW\,m^{-1}\,K^{-1}})$（CRC Handbook）：

| 气体 | $\ce{H2}$ | $\ce{He}$ | $\ce{CH4}$ | $\ce{N2}$ | 空气 | $\ce{O2}$ | $\ce{C2H6}$ | $\ce{C3H8}$ | $\ce{Ar}$ | $\ce{CO2}$ | $n$-$\ce{C4H10}$ |
|---|---|---|---|---|---|---|---|---|---|---|---|
| $\kappa$ | 187 | 156 | 34 | 26 | 26 | 26 | 21 | 18 | 18 | 17 | 16 |

$\ce{H2}$ 与 $\ce{He}$ 的热导率比其他气体大一个数量级（分子质量小、平均速度大，[5.2.1](/5.2.1)），所以热导检测器用它们作载气时信号大、而且所有组分都给出同向的峰；用 $\ce{N2}$ 作载气时灵敏度低，测 $\ce{H2}$ 时还会出现倒峰。

热导检测器结构简单、稳定，对无机物与有机物都有响应，不破坏试样（可串联其他检测器或收集馏分），是永久气体、水与有机元素分析（13.6.4 节）中的通用检测器；缺点是灵敏度较低，检出限约 $10^{-9}\,\mathrm{g\,mL^{-1}}$。热丝电流越大灵敏度越高（约与电流的三次方成正比），但噪声增大、热丝寿命缩短，并且通电前必须先通载气，否则热丝会烧断或氧化。

### 13.5.3. 氢火焰离子化检测器

**定义 13.5.3（氢火焰离子化检测器）** 以氢气与空气燃烧的火焰为能源，使有机物在火焰中发生化学电离，在外加电场中收集所产生的离子流而检测的检测器称为**氢火焰离子化检测器**（FID）。

柱后的载气与 $\ce{H2}$ 混合，从喷嘴喷出，在空气中燃烧；喷嘴与其上方的收集极之间加 $200$–$300\,\mathrm{V}$ 电压。纯载气与氢气燃烧几乎不产生离子，背景电流只有约 $10^{-14}\,\mathrm{A}$。有机物在火焰的还原区裂解为 $\cdot\mathrm{CH}$ 等碎片，再与氧反应发生化学电离：

$$
\ce{CH + O -> CHO+ + e-},
$$
$\ce{CHO+}$ 与水反应生成 $\ce{H3O+}$，离子被收集形成 $10^{-12}$–$10^{-8}\,\mathrm{A}$ 的电流。电离效率很低（约 $10^5$ 个碳原子产生 1 个离子），但背景极低，所以灵敏度很高。

FID 的响应近似与进入火焰的、与氢相连的碳原子数成正比（"有效碳数"），烃类的相对校正因子都接近 1；已被氧化的碳原子（羰基、羧基中的碳）响应很小，卤素、氮使响应降低。它对永久气体、$\ce{H2O}$、$\ce{CO}$、$\ce{CO2}$、$\ce{CS2}$、$\ce{NH3}$、氮的氧化物、$\ce{SO2}$、$\ce{H2S}$ 等几乎没有响应，所以水溶液中的有机物可以直接测定。FID 是质量型检测器，检出限约 $10^{-12}\,\mathrm{g\,s^{-1}}$（以碳计），线性范围达 $10^7$，是有机物分析最常用的检测器；缺点是破坏试样，需要 $\ce{H2}$ 与空气两路辅助气体。

### 13.5.4. 电子捕获检测器与火焰光度检测器

**定义 13.5.4（电子捕获检测器）** 用放射源发出的 β 射线使载气电离产生低能电子，在电场中形成稳定的基流；电负性组分捕获电子使基流减小，以基流的减小量检测组分的检测器称为**电子捕获检测器**（ECD）。

检测池内壁镀有 $^{63}\mathrm{Ni}$（β 放射源，半衰期约 100 a）。载气（$\ce{N2}$ 或 $\ce{Ar}$–$\ce{CH4}$）被电离：$\ce{N2 ->[\beta] N2+ + e-}$，所产生的大量热电子在电场中形成约 $10^{-8}\,\mathrm{A}$ 的基流。含强电负性基团的组分 AB 捕获电子生成负离子，负离子的迁移速度远小于电子，又容易与正离子复合：

$$
\ce{AB + e- -> AB-}, \qquad \ce{AB- + N2+ -> AB + N2},
$$
基流因此下降，记录到的是倒峰（通常反相后显示为正峰）。

ECD 是选择性最高、灵敏度最高的气相色谱检测器之一，检出限可达 $10^{-14}\,\mathrm{g\,s^{-1}}$。它的响应取决于组分的电子亲和性：对多卤代物（尤其是多氯、多溴化合物）、硝基化合物、共轭羰基化合物、有机金属化合物响应很强，对烃、醇、胺、一般的含氧与含氮化合物响应很弱。它是有机氯农药（滴滴涕、六六六）、多氯联苯与卤代消毒副产物等环境痕量分析的经典检测器。缺点是线性范围较窄（约 $10^4$），载气必须高纯，使用放射源需要许可。

**定义 13.5.5（火焰光度检测器）** 使含硫、含磷化合物在富氢火焰中燃烧，生成激发态的 $\ce{S2^*}$ 与 $\ce{HPO^*}$，经滤光片选出它们发射的特征光，用光电倍增管检测的检测器称为**火焰光度检测器**（FPD）。

在富氢的还原性火焰中，含硫化合物分解为硫原子，两个硫原子复合为激发态的 $\ce{S2^*}$，退激时发射 $320$–$460\,\mathrm{nm}$ 的带状光谱（最大约 $394\,\mathrm{nm}$）；含磷化合物生成 $\ce{HPO^*}$，发射约 $526\,\mathrm{nm}$ 的光：

$$
\ce{S + S -> S2^*}, \quad \ce{S2^*} \to \ce{S2} + h\nu; \qquad \ce{HPO^*} \to \ce{HPO} + h\nu.
$$
由于 $\ce{S2^*}$ 由两个硫原子生成，硫的响应近似与硫的质量流量的平方成正比（指数在 1.5–2 之间），定量时要取对数作校准曲线；磷的响应是线性的。FPD 用于有机磷农药、硫醇与硫醚、天然气与石油中的含硫化合物，对硫、磷的选择性比对碳高 $10^4$–$10^6$ 倍。光谱发射的原理与原子发射光谱相同，所用的 **光电倍增管** 见 [6.4.7](/6.4.7#sec-7.5.2)。

### 13.5.5. 其他检测器

- 氮磷检测器（NPD）：火焰中放一颗加热的铷盐珠，含氮、含磷化合物在珠表面生成负离子，选择性检测含氮药物与有机磷农药，检出限比 FID 低约一个数量级。
- 质谱检测器（GC-MS）：既定量又给出每个峰的质谱，是最强的定性手段，见 [6.4.15](/6.4.15#sec-15.5.1)。
- 红外检测器（GC-FTIR）：给出每个组分的红外光谱，能区分质谱难以区分的异构体（[6.4.11](/6.4.11#sec-11.3.2)）。
- 原子发射检测器：用微波等离子体激发流出物中的元素，按元素选择性地检测（[6.4.7](/6.4.7#sec-7.3.4)）。

| 检测器 | 类型 | 选择性 | 检出限（数量级） | 线性范围 | 载气 |
|---|---|---|---|---|---|
| TCD | 浓度型 | 通用 | $10^{-9}\,\mathrm{g\,mL^{-1}}$ | $10^5$ | $\ce{He}$、$\ce{H2}$ |
| FID | 质量型 | 含 C–H 的有机物 | $10^{-12}\,\mathrm{g\,s^{-1}}$ | $10^7$ | $\ce{N2}$、$\ce{He}$、$\ce{H2}$ |
| ECD | 浓度型 | 电负性化合物 | $10^{-14}\,\mathrm{g\,s^{-1}}$ | $10^4$ | 高纯 $\ce{N2}$、$\ce{Ar}$–$\ce{CH4}$ |
| FPD | 质量型 | 含 S、P 化合物 | $10^{-11}$（S）、$10^{-12}$（P）$\mathrm{g\,s^{-1}}$ | $10^3$（S）、$10^4$（P） | $\ce{N2}$、$\ce{He}$ |
| NPD | 质量型 | 含 N、P 化合物 | $10^{-13}\,\mathrm{g\,s^{-1}}$ | $10^4$ | $\ce{N2}$、$\ce{He}$ |
| MS | 质量型 | 通用或选择性（选择离子） | 全扫描 $10^{-9}$ g，选择离子 $10^{-12}$ g | $10^5$ | $\ce{He}$、$\ce{H2}$ |

## 13.6. 定性与定量分析

### 13.6.1. 保留值定性与保留指数

在色谱条件严格一致时，同一种物质的保留时间相同，这是色谱定性的基础：

1. 已知物对照：未知峰与标准物质的保留时间相同，可以初步认为是同一物质；在试样中加入标准物质，若该峰增高而不出现新峰，结论更可靠。保留时间相同只是必要条件：不同物质可能在一根柱上恰好同时流出。
2. 双柱定性：在两根极性不同的柱上保留值都与标准物质一致，同时流出的偶然性就小得多。
3. 保留值随温度、流速变化，在不同实验室之间难以比较，所以要用相对的、标准化的保留值。

**定义 13.6.1（保留指数）** 以正构烷烃为参照，规定碳数为 $z$ 的正构烷烃的保留指数为 $100z$，组分 $x$ 在某固定液上、某温度下的保留行为用与它相邻的两个正构烷烃（碳数 $z$ 与 $z + 1$，$t'_{\mathrm{R}}(z) < t'_{\mathrm{R}}(x) < t'_{\mathrm{R}}(z+1)$）按调整保留时间的对数内插：

$$
I_x = 100\left[z + \frac{\lg t'_{\mathrm{R}}(x) - \lg t'_{\mathrm{R}}(z)}{\lg t'_{\mathrm{R}}(z+1) - \lg t'_{\mathrm{R}}(z)}\right], \tag{13.5}
$$
称为**保留指数**（Kováts 指数，Kováts 1958）。

用对数内插的根据是：恒温下同系物的 $\lg t'_{\mathrm{R}}$ 与碳数成直线关系。程序升温时，同系物的保留时间（而不是其对数）近似与碳数成直线关系（13.4.5 的图），这时用线性内插的保留指数（van den Dool–Kratz 式）$I_x = 100[z + (t_{\mathrm{R}}(x) - t_{\mathrm{R}}(z))/(t_{\mathrm{R}}(z+1) - t_{\mathrm{R}}(z))]$。保留指数只与固定液和温度有关，重现性可达 $\pm 1$ 个单位，文献与谱库（如 NIST 谱库）收录了大量化合物在常用固定液上的保留指数，与质谱联用可以大大提高定性的可靠性。

**例 13.6.1** 在某中等极性柱上，正庚烷、苯、正辛烷的调整保留时间分别为 $174.0$、$230.0$、$373.4\,\mathrm{s}$。求苯的保留指数。

**解** $I = 100\left[7 + \frac{\lg 230.0 - \lg 174.0}{\lg 373.4 - \lg 174.0}\right] = 100\left[7 + \frac{0.1212}{0.3316}\right] = 737$。苯在该柱上的保留相当于一个含 7.37 个碳原子的"正构烷烃"。苯在非极性的角鲨烷上的保留指数约为 650（比它的沸点所对应的碳数还小），两者之差 $\Delta I \approx 87$ 就是该固定液的苯的 McReynolds 常数，反映它与 π 电子体系的作用。$\square$

最可靠的定性方法是把色谱与具有结构鉴定能力的仪器联用：质谱（[6.4.15](/6.4.15)）、红外（[6.4.11](/6.4.11)）、核磁（[6.4.12](/6.4.12)），或以原子光谱作元素选择性的检测器。

### 13.6.2. 定量校正因子

色谱定量的依据是：在检测器的 **线性范围** 内，组分的量 $m_i$ 与其峰面积 $A_i$（或峰高）成正比，$m_i = f_iA_i$。

**定义 13.6.2（定量校正因子）** 单位峰面积所对应的组分的量 $f_i = m_i/A_i$ 称为组分 $i$ 的绝对校正因子；它与某一标准物质 s 的绝对校正因子之比

$$
f'_i = \frac{f_i}{f_{\mathrm{s}}} = \frac{m_iA_{\mathrm{s}}}{m_{\mathrm{s}}A_i}
$$
称为**相对校正因子**；两者统称**定量校正因子**。$m$ 以质量表示时称为质量校正因子，以物质的量表示时称为摩尔校正因子。

校正因子是 **灵敏度** 的倒数。同一检测器对不同物质的灵敏度不同（热导检测器取决于组分与载气的热导率之差，FID 取决于有效碳数），所以峰面积不能直接比较，要乘以校正因子。绝对校正因子与进样量、检测器的操作条件、载气流速都有关，必须与试样在完全相同的条件下测定。相对校正因子由同一次进样中的两个峰求得，这些因素的影响大部分抵消，受色谱条件的影响较小，文献值可以近似借用；但它并非与条件无关：热导检测器的相对校正因子与载气种类有关，FID 的与氢气、空气的流量比和检测器温度有关，准确定量时仍应在本实验条件下用标准物质测定。常用的标准物质是苯（热导检测器）与正庚烷（FID）。

### 13.6.3. 归一化法、外标法与内标法

**定义 13.6.3（归一化法）** 试样中所有组分都能流出色谱柱并产生信号时，把各组分的峰面积乘以各自的相对校正因子，按

$$
w_i = \frac{f'_iA_i}{\sum_j f'_jA_j} \times 100\%
$$
计算各组分质量分数的方法称为**归一化法**。

归一化法的优点是不需要准确的进样量，进样量与操作条件的波动对结果影响小；前提是所有组分都流出并被检测，且都知道校正因子。试样中有不挥发组分、或某些组分在所用检测器上没有响应（如 FID 不响应水）时不能使用。各组分校正因子相近（如同分异构体）时，可以直接用面积百分比。

**例 13.6.2** 用 FID 分析 $\mathrm{C}_8$ 芳烃混合物，乙苯、对二甲苯、间二甲苯、邻二甲苯的峰面积为 120、75、140、105（任意单位），以对二甲苯为标准的相对质量校正因子为 0.97、1.00、0.96、0.98。求各组分的质量分数。

**解** $\sum f'_jA_j = 116.4 + 75.0 + 134.4 + 102.9 = 428.7$。乙苯 $w = 116.4/428.7 = 27.2\%$，对二甲苯 $17.5\%$，间二甲苯 $31.4\%$，邻二甲苯 $24.0\%$。对二甲苯与间二甲苯沸点相差不到 $1\,{}^\circ\mathrm{C}$，在非极性柱上很难分开，需要强极性或液晶类固定液。$\square$

**外标法**（[6.4.1](/6.4.1#sec-1.8.4)）在色谱中就是用标准溶液作 **校准曲线**，或在相同条件下与已知浓度的单一标准比较峰面积。它简单，适合大批量的常规分析，但要求每次进样量准确、色谱条件稳定，自动进样器使这一点容易做到。

**内标法**（[6.4.1](/6.4.1#sec-1.8.4)）是色谱中最准确的定量方法：称取质量为 $m$ 的试样，加入质量为 $m_{\mathrm{s}}$ 的内标物，测得被测组分与内标物的峰面积 $A_i$、$A_{\mathrm{s}}$，则

$$
w_i = \frac{f'_iA_im_{\mathrm{s}}}{A_{\mathrm{s}}m} \times 100\%,
$$
$f'_i$ 是以内标物为标准的相对校正因子。结果只取决于两个峰的面积比，进样量与仪器参数的波动、前处理中的部分损失对两者影响相同而抵消。在色谱中，内标物还要求：试样中不含有；化学性质稳定，不与试样反应；纯度高；在被测组分附近出峰并与所有峰基线分离；加入量与被测组分相近；校正因子已知或可以测定。

**例 13.6.3** 测定某药物中的残留溶剂乙酸乙酯。称取试样 $1.500\,\mathrm{g}$，加入内标物正丙醇 $0.1200\,\mathrm{g}$，溶解后进样，乙酸乙酯与正丙醇的峰面积为 86.4 与 112.0；以正丙醇为标准，乙酸乙酯的相对质量校正因子为 1.08。求乙酸乙酯的质量分数。

**解** $w = \frac{1.08 \times 86.4 \times 0.1200}{112.0 \times 1.500} \times 100\% = 6.67\%$。$\square$

### 13.6.4. 应用与有机元素分析

| 领域 | 分析对象举例 |
|---|---|
| 环境 | 水与土壤中的苯系物、多环芳烃、有机氯与有机磷农药、多氯联苯、二噁英（高分辨 GC-MS） |
| 石油化工 | 天然气组成、汽油的详细烃组成、炼厂气 |
| 食品与香料 | 脂肪酸组成（甲酯化后）、香精油中的萜类与酯、农药残留、亚硝胺 |
| 生物与临床 | 代谢组学（衍生化后 GC-MS）、微生物的脂肪酸谱、呼气中的挥发性标志物 |
| 医药 | 残留溶剂（顶空 GC）、挥发油、手性中间体 |
| 法庭科学 | 血液中的乙醇（顶空 GC）、毒品与兴奋剂、纵火残留物中的汽油 |

气相色谱也是现代有机元素分析的核心。确定一个新化合物的分子式，先要知道它的 C、H、N、S、O 的质量分数。19 世纪 30 年代，Liebig 建立燃烧法：把有机物在氧化铜上充分燃烧，生成的水用氯化钙管吸收，二氧化碳用氢氧化钾溶液（Liebig 的"钾球"）吸收，由吸收管的增重计算 C 与 H 的含量；Dumas（1831）用测定 $\ce{N2}$ 体积的方法测氮，Pregl 把燃烧法微量化（1923 年诺贝尔化学奖）。

现行的 CHNS/O 元素分析仪是自动化的燃烧–气相色谱仪：

1. 试样（1–3 mg）包在锡囊中落入约 $1000\,{}^\circ\mathrm{C}$ 的燃烧管，同时通入一脉冲纯氧；锡剧烈氧化放热，使局部温度瞬间升到约 $1800\,{}^\circ\mathrm{C}$（动态闪燃），保证完全燃烧。燃烧管中的氧化催化剂（$\ce{WO3}$、$\ce{CuO}$）使燃烧完全，银丝除去卤素。
2. 燃烧气由氦载气带过约 $650\,{}^\circ\mathrm{C}$ 的还原铜，氮的氧化物还原为 $\ce{N2}$，过量的氧被除去；C、H、S 分别转变为 $\ce{CO2}$、$\ce{H2O}$、$\ce{SO2}$。
3. $\ce{N2}$、$\ce{CO2}$、$\ce{H2O}$、$\ce{SO2}$ 经色谱柱分离（或吸附–逐个解吸），由热导检测器检测，以标准物质（如乙酰苯胺、磺胺）校准后算出各元素含量。
4. 测氧时，试样在约 $1100\,{}^\circ\mathrm{C}$ 下于氦气中热解，热解产物通过活性炭层，氧全部转化为 $\ce{CO}$，分离后用热导检测器测定。

一次测定只需几分钟，绝对误差一般在 $0.3\%$ 以内；有机化学期刊通常要求新化合物的实测值与计算值之差不超过 $0.4\%$，作为纯度的证据。由元素分析与质谱（[6.4.15](/6.4.15#sec-15.4.2)）得到分子式后，就可以计算不饱和度（[6.4.11](/6.4.11#def-11.2.3)），开始波谱解析。

此外，便携式与微型气相色谱仪（微加工的色谱柱与检测器）已用于现场的环境监测与应急检测。

## 思考题

1. 怎样提高色谱柱的理论塔板数？

   **答** 由 van Deemter 方程，用粒度小而均匀的填料并填充均匀（减小 $A$、$C_{\mathrm{m}}$），减薄固定液膜（减小 $C_{\mathrm{s}}$），在最佳流速附近操作；对开管柱，减小柱内径；在 $H$ 一定时增加柱长。同时要减小柱外展宽，否则柱内的高柱效显示不出来。
2. 怎样装柱才能使柱效提高？没有填料的空心柱能用于色谱分离吗？

   **答** 填料粒度要小而均匀、填充要紧密均匀，使涡流扩散项与流动相传质项减小。空心柱（开管柱）把固定液涂在柱壁上，没有涡流扩散项，阻力小、可以做得很长，柱效反而远高于填充柱，这正是毛细管气相色谱的原理；但柱内径必须很小（流动相传质项与 $d_{\mathrm{c}}^2$ 成正比），柱容量因而很小。
3. 如何由实验求最佳流速？

   **答** 在几种流速下测定同一组分的 $N$，算出 $H = L/N$，作 $H$–$u$ 图，用最小二乘法拟合 $H = A + B/u + Cu$（[4.4.4](/4.4.4)），由 $u_{\mathrm{opt}} = \sqrt{B/C}$ 求得；实际选用略高于 $u_{\mathrm{opt}}$ 的流速。
4. 怎样判断一种固定液的极性大小？

   **答** 用 Rohrschneider 法，以丁二烯–正丁烷的相对保留值与 β,β′-氧二丙腈（100）、角鲨烷（0）比较得相对极性；或测五种探针在该固定液与角鲨烷上的保留指数之差（McReynolds 常数），其和表示总极性，各项反映不同的分子间作用。
5. 为什么热导检测器要先通载气后通电，而且用 $\ce{He}$ 或 $\ce{H2}$ 作载气？

   **答** 无载气时热丝散热很差，通电会使其过热烧断或氧化。$\ce{He}$、$\ce{H2}$ 的热导率比一般组分大得多，组分进入时热导率变化大，灵敏度高，且各组分都给出正峰。
