---
title: 氧化还原滴定
---

氧化还原滴定以电子转移反应为基础，可以直接测定具有氧化性或还原性的物质（铁、铜、过氧化氢、维生素 C、葡萄糖、水中的有机污染物），也可以通过定量的化学转化间接测定本身没有氧化还原性的物质（经草酸钙测钙、经 8-羟基喹啉测镁）。[6.1.11](/6.1.11) 给出了**电极电势**与 **Nernst 方程**，[6.1.12](/6.1.12#sec-12.1) 用标准电极电势判断反应的方向与限度。但实际滴定溶液中存在较大的离子强度和各种副反应（生成沉淀、配合物、质子化），标准电极电势常常给出错误的结论，例如按标准电极电势 $\ce{Cu^2+}$ 不能氧化 $\ce{I-}$，实际上反应定量进行。本章把 [6.4.3](/6.4.3) 的"副反应系数 + 条件常数"方法用于电子转移反应：先引入条件电极电势（5.1）与条件平衡常数，讨论反应的完全程度与速率（5.2），再计算滴定曲线、选择指示剂（5.3），最后介绍滴定前的预处理（5.4）与高锰酸钾法、重铬酸钾法、碘量法（5.5）。本章也是 [6.4.6](/6.4.6) 电位分析的直接前置：电位滴定（[6.4.6](/6.4.6#sec-6.4.5)）就是用指示电极测出本章的滴定曲线。

本章的电势都是相对于标准氢电极的还原电势，标准电极电势取自 CRC Handbook（$25\,^\circ\mathrm{C}$），与 [6.1.11](/6.1.11#sec-11.4.3) 的表一致；$z$ 为半反应转移的电子数，$\frac{RT\ln10}{F} = 0.0592\,\mathrm{V}$（$25\,^\circ\mathrm{C}$）。终点误差记作 $E_{\mathrm{t}}$，与电极电势 $E$ 靠下标区分。

## 5.1. 条件电极电势

### 5.1.1. 氧化还原滴定的特点

**定义 5.1.1（氧化还原滴定）** 以氧化还原反应为基础的滴定分析方法称为**氧化还原滴定**。

与酸碱、配位反应相比，氧化还原反应的机理复杂：许多反应分多步进行，有的平衡常数很大却进行得很慢，有的伴有副反应而没有确定的计量关系。所以判断一个氧化还原反应能否用于滴定，除了平衡常数，还要考虑反应速率、反应机理与反应条件（酸度、温度、催化剂）。

### 5.1.2. 条件电极电势

可逆电对 $\mathrm{Ox} + z\ce{e-} \ce{<=>} \mathrm{Red}$ 的电极电势由 **Nernst 方程**（[6.1.11](/6.1.11#sec-11.5.1)）给出：

$$
E = E^\circ + \frac{RT}{zF}\ln\frac{a_{\mathrm{Ox}}}{a_{\mathrm{Red}}}.
$$
（只有可逆电对，即电极反应足够快、能迅速建立平衡的电对，其实测电势才符合 Nernst 方程；$\ce{MnO4-}/\ce{Mn^2+}$、$\ce{Cr2O7^2-}/\ce{Cr^3+}$、$\ce{S4O6^2-}/\ce{S2O3^2-}$ 等不可逆电对的实测电势与计算值有偏差，但计算仍可用于判断平衡。）

实际工作中知道的是氧化态与还原态的分析浓度 $c_{\mathrm{Ox}}$、$c_{\mathrm{Red}}$，而不是活度。两者之间隔着两层关系：离子强度使**活度**不等于浓度，$a = \gamma[\mathrm{Ox}]$；副反应使游离的 Ox 只是其总浓度的一部分，$[\mathrm{Ox}] = c_{\mathrm{Ox}}/\alpha_{\mathrm{Ox}}$（**副反应系数**，[6.4.3](/6.4.3#sec-3.2.1)）。代入 Nernst 方程：

$$
E = E^\circ + \frac{RT}{zF}\ln\frac{\gamma_{\mathrm{Ox}}\alpha_{\mathrm{Red}}}{\gamma_{\mathrm{Red}}\alpha_{\mathrm{Ox}}} + \frac{RT}{zF}\ln\frac{c_{\mathrm{Ox}}}{c_{\mathrm{Red}}}.
$$
在一定条件下，前两项是常数。

**定义 5.1.2（条件电极电势）** 在一定的介质条件（离子强度、酸度、配位剂与沉淀剂的浓度一定）下，氧化态与还原态的分析浓度都等于 $1\,\mathrm{mol\,L^{-1}}$（或两者之比为 1）时电对的实际电极电势

$$
E^{\circ\prime} = E^\circ + \frac{RT}{zF}\ln\frac{\gamma_{\mathrm{Ox}}\alpha_{\mathrm{Red}}}{\gamma_{\mathrm{Red}}\alpha_{\mathrm{Ox}}} \tag{5.1}
$$
称为该电对的**条件电极电势**（IUPAC：formal potential，也译为式量电势）。于是

$$
E = E^{\circ\prime} + \frac{0.0592\,\mathrm{V}}{z}\lg\frac{c_{\mathrm{Ox}}}{c_{\mathrm{Red}}} \qquad (25\,^\circ\mathrm{C}). \tag{5.2}
$$

半反应中有 $\ce{H+}$ 或 $\ce{OH-}$ 参加时，它们的浓度项也并入 $E^{\circ\prime}$。条件电极电势与标准电极电势的关系，正如 [6.4.3](/6.4.3#sec-3.2.4) 中**条件稳定常数**与稳定常数的关系：它把已知的副反应吸收进一个表观常数，只在给定条件下才是常数，但比标准电极电势更准确地反映实际溶液中电对的氧化还原能力。$E^{\circ\prime}$ 一般由实验测定；没有实验值时，可以用相近条件下的值，或用 $E^\circ$ 与副反应系数按式 (5.1) 估算。常用的条件电极电势（$25\,^\circ\mathrm{C}$）：

| 电对 | $E^\circ/\mathrm{V}$ | 介质 | $E^{\circ\prime}/\mathrm{V}$ |
|---|---|---|---|
| $\ce{Ce^4+}/\ce{Ce^3+}$ | — | $1\,\mathrm{mol\,L^{-1}}$ $\ce{HClO4}$ / $\ce{HNO3}$ / $\ce{H2SO4}$ / HCl | 1.70 / 1.61 / 1.44 / 1.28 |
| $\ce{Fe^3+}/\ce{Fe^2+}$ | 0.771 | $1\,\mathrm{mol\,L^{-1}}$ $\ce{HClO4}$ / HCl / $\ce{H2SO4}$；$2\,\mathrm{mol\,L^{-1}}$ $\ce{H3PO4}$ | 0.73 / 0.70 / 0.68；0.46 |
| $\ce{Cr2O7^2-}/\ce{Cr^3+}$ | 1.36 | $1\,\mathrm{mol\,L^{-1}}$ HCl / $3\,\mathrm{mol\,L^{-1}}$ HCl | 1.00 / 1.08 |
| $\ce{MnO4-}/\ce{Mn^2+}$ | 1.507 | $1\,\mathrm{mol\,L^{-1}}$ $\ce{HClO4}$ | 1.45 |
| $\ce{I3-}/\ce{I-}$ | 0.536 | $0.5\,\mathrm{mol\,L^{-1}}$ $\ce{H2SO4}$ | 0.545 |
| $\ce{Sn^4+}/\ce{Sn^2+}$ | 0.151 | $1\,\mathrm{mol\,L^{-1}}$ HCl | 0.14 |

$\ce{Ce^4+}$ 在水中强烈水解并与 $\ce{SO4^2-}$、$\ce{Cl-}$ 配位，"标准电极电势"没有明确意义，只用条件电极电势；它随介质的变化达 0.4 V，说明不同阴离子与 Ce(IV) 配位的强弱：$\ce{ClO4-}$ 几乎不配位，$\ce{SO4^2-}$ 配位很强。

### 5.1.3. 影响条件电极电势的因素

1. 离子强度。由式 (5.1)，离子强度改变 $\gamma_{\mathrm{Ox}}/\gamma_{\mathrm{Red}}$。氧化态与还原态电荷不同时，电荷高的一方的活度因子随离子强度下降得更快（Debye–Hückel 理论），例如 $\ce{[Fe(CN)6]^3-}/\ce{[Fe(CN)6]^4-}$ 的条件电极电势随离子强度增大而明显升高。但滴定溶液中副反应的影响一般远大于离子强度，所以离子强度的影响常被忽略，式 (5.1) 中只计副反应系数。

2. 生成沉淀。氧化态生成沉淀，$\alpha_{\mathrm{Ox}}$ 增大，电势降低；还原态生成沉淀，电势升高。

**例 5.1.1** 判断 $\ce{Cu^2+}$ 能否氧化 $\ce{I-}$。$E^\circ(\ce{Cu^2+}/\ce{Cu+}) = 0.153\,\mathrm{V}$，$E^\circ(\ce{I2}/\ce{I-}) = 0.536\,\mathrm{V}$，$K_{\mathrm{sp}}(\ce{CuI}) = 1.27\times10^{-12}$。

**解** 只看标准电极电势，$0.153 < 0.536$，应当是 $\ce{I2}$ 氧化 $\ce{Cu+}$。但还原态 $\ce{Cu+}$ 与 $\ce{I-}$ 生成 CuI 沉淀，$[\ce{Cu+}] = K_{\mathrm{sp}}/[\ce{I-}]$：

$$
E = 0.153 + 0.0592\lg\frac{[\ce{Cu^2+}][\ce{I-}]}{K_{\mathrm{sp}}(\ce{CuI})}.
$$
$[\ce{Cu^2+}] = [\ce{I-}] = 1\,\mathrm{mol\,L^{-1}}$ 时，$E^{\circ\prime}(\ce{Cu^2+}/\ce{CuI}) = 0.153 + 0.0592\lg(1/1.27\times10^{-12}) = 0.857\,\mathrm{V}$，比 0.536 V 高得多。所以 $\ce{2Cu^2+ + 4I- -> 2CuI v + I2}$ 定量进行，这是碘量法测铜的基础（5.5.3）。这也就是 [6.1.11](/6.1.11#sec-11.5.4) 中"生成沉淀改变电极电势"的一个定量例子。

3. 生成配合物。氧化态生成的配合物比还原态的稳定时，电势降低；反之升高。

**例 5.1.2** 用碘量法测定 $\ce{Cu^2+}$ 时，试样中的 $\ce{Fe^3+}$ 也能氧化 $\ce{I-}$（$E^\circ = 0.771\,\mathrm{V} > 0.536\,\mathrm{V}$），使结果偏高。加入 $\ce{F-}$ 使 $[\ce{F-}] = 0.10\,\mathrm{mol\,L^{-1}}$，求 $E^{\circ\prime}(\ce{Fe^3+}/\ce{Fe^2+})$。$\ce{Fe^3+}$–$\ce{F-}$ 的 $\lg\beta_1, \lg\beta_2, \lg\beta_3 = 5.28, 9.30, 12.06$，$\ce{Fe^2+}$ 与 $\ce{F-}$ 几乎不配位。

**解** $\alpha_{\mathrm{Fe(III)}} = 1 + 10^{5.28 - 1} + 10^{9.30 - 2} + 10^{12.06 - 3} = 10^{9.07}$，$\alpha_{\mathrm{Fe(II)}} \approx 1$。由式 (5.1)（忽略活度因子）

$$
E^{\circ\prime} = 0.771 + 0.0592\lg\frac{1}{10^{9.07}} = 0.771 - 0.537 = 0.23\,\mathrm{V} < 0.536\,\mathrm{V},
$$
$\ce{Fe^3+}$ 不再能氧化 $\ce{I-}$，干扰消除。$\ce{Fe^3+}$ 与 $\ce{PO4^3-}$ 生成无色的配合物，作用相同；在 $\ce{H3PO4}$ 介质中 $E^{\circ\prime}(\ce{Fe^3+}/\ce{Fe^2+})$ 降到约 0.46 V，这在重铬酸钾法测铁中很重要（5.3.4）。

4. 酸度。半反应中有 $\ce{H+}$ 或 $\ce{OH-}$ 参加时，酸度直接出现在 Nernst 方程中；氧化态或还原态是弱酸（碱）时，酸度还通过酸效应改变 $\alpha$。

**例 5.1.3** $\ce{H3AsO4 + 2H+ + 2e- <=> HAsO2 + 2H2O}$，$E^\circ = 0.560\,\mathrm{V}$；$\ce{I3- + 2e- <=> 3I-}$，$E^\circ = 0.536\,\mathrm{V}$。讨论反应 $\ce{H3AsO4 + 3I- + 2H+ <=> HAsO2 + I3- + 2H2O}$ 的方向与 pH 的关系。

**解** 砷电对的条件电极电势（把 $[\ce{H+}]$ 与两种含砷弱酸的分布系数 $\delta$ 并入）

$$
E^{\circ\prime}(\mathrm{As(V)/As(III)}) = 0.560 - 0.0592\,\mathrm{pH} + \frac{0.0592}{2}\lg\frac{\delta_{\ce{H3AsO4}}}{\delta_{\ce{HAsO2}}}.
$$
$\ce{I3-}/\ce{I-}$ 电对与 pH 无关（直到 pH 约 9 以上 $\ce{I2}$ 开始歧化）。两者在 pH ≈ 0.4 相等：更强的酸性溶液中（如 $4\,\mathrm{mol\,L^{-1}}$ HCl）As(V) 把 $\ce{I-}$ 氧化为 $\ce{I3-}$；pH 8 时（$\ce{NaHCO3}$ 缓冲）$\ce{H3AsO4}$ 主要以 $\ce{HAsO4^2-}$ 存在，$\delta_{\ce{H3AsO4}} \approx 10^{-6.8}$，$E^{\circ\prime} \approx -0.11\,\mathrm{V}$，反应完全向左，$\ce{I3-}$ 定量氧化 As(III)：这是过去用 $\ce{As2O3}$ 作基准物质标定碘溶液的原理（$\ce{As2O3}$ 剧毒，现已少用）。同一反应在不同 pH 下方向相反，这一点在[电势–pH 图](/6.1.12#sec-12.3)上一目了然。

## 5.2. 反应的完全程度与速率

### 5.2.1. 条件平衡常数

设滴定反应由两个电对组成：

$$
\mathrm{Ox_1} + z_1\ce{e-} \ce{<=>} \mathrm{Red_1}\ (E^{\circ\prime}_1), \qquad \mathrm{Ox_2} + z_2\ce{e-} \ce{<=>} \mathrm{Red_2}\ (E^{\circ\prime}_2),
$$
$z$ 取 $z_1$、$z_2$ 的最小公倍数，$p_1 = z/z_1$、$p_2 = z/z_2$，总反应为

$$
p_1\mathrm{Ox_1} + p_2\mathrm{Red_2} \ce{<=>} p_1\mathrm{Red_1} + p_2\mathrm{Ox_2}.
$$
平衡时两个电对的电势相等：

$$
E^{\circ\prime}_1 + \frac{0.0592}{z_1}\lg\frac{c_{\mathrm{Ox_1}}}{c_{\mathrm{Red_1}}} = E^{\circ\prime}_2 + \frac{0.0592}{z_2}\lg\frac{c_{\mathrm{Ox_2}}}{c_{\mathrm{Red_2}}}.
$$
两边乘以 $z$ 并整理，得到

**定义 5.2.1（条件平衡常数）** 在一定条件下，用反应物与产物的分析浓度表示的氧化还原反应的平衡常数

$$
K' = \frac{c_{\mathrm{Red_1}}^{p_1}c_{\mathrm{Ox_2}}^{p_2}}{c_{\mathrm{Ox_1}}^{p_1}c_{\mathrm{Red_2}}^{p_2}}, \qquad \lg K' = \frac{z\,(E^{\circ\prime}_1 - E^{\circ\prime}_2)}{0.0592\,\mathrm{V}} \tag{5.3}
$$
称为该反应的**条件平衡常数**。

它与 [6.1.12](/6.1.12#sec-12.1.2) 中由标准电极电势求平衡常数的公式形式相同，只是把 $E^\circ$ 换成了 $E^{\circ\prime}$。条件电极电势之差 $\Delta E^{\circ\prime}$ 越大，反应越完全。例如 $\ce{Ce^4+}$ 滴定 $\ce{Fe^2+}$（$1\,\mathrm{mol\,L^{-1}}$ $\ce{H2SO4}$），$\lg K' = (1.44 - 0.68)/0.0592 = 12.8$。

### 5.2.2. 反应完全的条件

滴定分析要求在计量点时反应完全程度达 99.9% 以上：$\mathrm{Ox_1}$ 至少 99.9% 转化为 $\mathrm{Red_1}$，$\mathrm{Red_2}$ 至少 99.9% 转化为 $\mathrm{Ox_2}$，即 $c_{\mathrm{Red_1}}/c_{\mathrm{Ox_1}} \ge 10^3$，$c_{\mathrm{Ox_2}}/c_{\mathrm{Red_2}} \ge 10^3$。代入式 (5.3)：

$$
\lg K' \ge 3(p_1 + p_2), \qquad \Delta E^{\circ\prime} \ge \frac{3(p_1 + p_2)\times0.0592\,\mathrm{V}}{z}. \tag{5.4}
$$
- $z_1 = z_2 = 1$（$p_1 = p_2 = 1$，$z = 1$）：$\lg K' \ge 6$，$\Delta E^{\circ\prime} \ge 0.36\,\mathrm{V}$。
- $z_1 = 1$、$z_2 = 2$（如 $\ce{2Fe^3+ + Sn^2+ -> 2Fe^2+ + Sn^4+}$，$p_1 = 2$，$p_2 = 1$，$z = 2$）：$\lg K' \ge 9$，$\Delta E^{\circ\prime} \ge 0.27\,\mathrm{V}$。
- $z_1 = z_2 = 2$（$p_1 = p_2 = 1$，$z = 2$）：$\lg K' \ge 6$，$\Delta E^{\circ\prime} \ge 0.18\,\mathrm{V}$。

注意式 (5.4) 中的 $p_1$、$p_2$ 是最简反应式中的计量数，而不是电子数：$z_1$、$z_2$ 互质时 $p_1 = z_2$、$p_2 = z_1$，判据可写成 $3(z_1 + z_2)$；但 $z_1 = z_2 = 2$ 时这样写会得到错误的 12。通常说"两电对的条件电极电势差大于 0.4 V 的反应可用于滴定"，是把 0.36 V 取整，并对各种电子数的情况都留出了余量。$\Delta E^{\circ\prime}$ 满足要求只说明反应能够进行完全，能否用于滴定还要看速率与有无副反应。

### 5.2.3. 影响反应速率的因素

许多氧化还原反应在热力学上进行得很完全，速率却很慢。例如 $\ce{O2 + 4H+ + 4e- <=> 2H2O}$ 的 $E^\circ = 1.229\,\mathrm{V}$，按电势水溶液中的 $\ce{Sn^2+}$、$\ce{Fe^2+}$、$\ce{I-}$ 都应被溶解的氧迅速氧化，实际上它们的溶液可以保存一段时间。速率首先取决于反应物本身（内因）：

- 只转移电子的反应快（$\ce{Ce^4+ + Fe^2+}$）；需要断开化学键、转移原子的反应慢（$\ce{MnO4-}$、$\ce{Cr2O7^2-}$ 被还原时要脱去氧，$\ce{O2}$ 被还原时要断开 O=O 键）；
- 含氧酸根中元素的氧化数越高，配位的氧越多，反应往往越慢；
- 带同种电荷的离子之间的静电排斥减慢反应；
- 多步反应的总速率由最慢的一步决定。

外界条件的影响：

1. 反应物浓度：一般浓度越大，速率越快。例如间接碘量法标定 $\ce{Na2S2O3}$ 时，$\ce{Cr2O7^2- + 6I- + 14H+ -> 2Cr^3+ + 3I2 + 7H2O}$ 较慢，要加入过量 KI、保持 $[\ce{H+}] = 0.2$–$0.4\,\mathrm{mol\,L^{-1}}$，并在暗处放置约 5 min 待反应完全。
2. 温度：一般温度每升高 10 K，速率增大到原来的 2–4 倍（**Arrhenius 方程**，[6.1.7](/6.1.7)）。$\ce{KMnO4}$ 与 $\ce{C2O4^2-}$ 的反应在室温下很慢，要加热到 $75$–$85\,^\circ\mathrm{C}$；但温度超过 $90\,^\circ\mathrm{C}$ 时草酸部分分解，结果偏高。易挥发（$\ce{I2}$）或易被空气氧化（$\ce{Fe^2+}$、$\ce{Sn^2+}$）的物质则不能加热。
3. **催化剂**：改变反应历程，降低活化能。例如 $\ce{Ag+}$ 催化 $\ce{S2O8^2-}$ 把 $\ce{Mn^2+}$ 氧化为 $\ce{MnO4-}$（5.4）。

$\ce{MnO4-}$ 与 $\ce{C2O4^2-}$ 的反应

$$
\ce{2MnO4- + 5C2O4^2- + 16H+ -> 2Mn^2+ + 10CO2 ^ + 8H2O}
$$
被产物 $\ce{Mn^2+}$ 催化：$\ce{Mn^2+}$ 与 $\ce{MnO4-}$ 先生成 Mn(III)，Mn(III) 与草酸根生成的配合物再迅速分解为 $\ce{CO2}$ 与 $\ce{Mn^2+}$。这种反应产物本身对反应起催化作用的现象就是**自催化**。自催化反应的速率曲线是 S 形的：开始时 $\ce{Mn^2+}$ 极少，反应很慢（滴入的第一滴 $\ce{KMnO4}$ 要好一会儿才褪色），生成的 $\ce{Mn^2+}$ 积累后反应迅速加快，最后反应物耗尽而减慢。滴定时不必另加 $\ce{Mn^2+}$，只要开始时滴得慢一些，等前几滴褪色后再加快。（自催化步骤形成的正反馈也是化学振荡的根源，见 [6.3.18](/6.3.18#sec-18.3.2)。）

### 5.2.4. 诱导反应

在 HCl 介质中用 $\ce{KMnO4}$ 滴定 $\ce{Fe^2+}$，消耗的 $\ce{KMnO4}$ 偏多，结果偏高；而没有 $\ce{Fe^2+}$ 时，$\ce{KMnO4}$ 与稀 HCl 中的 $\ce{Cl-}$ 反应极慢。原因是 $\ce{MnO4-}$ 与 $\ce{Fe^2+}$ 的反应

$$
\ce{MnO4- + 5Fe^2+ + 8H+ -> Mn^2+ + 5Fe^3+ + 4H2O}
$$
促进了本来很慢的 $\ce{2MnO4- + 10Cl- + 16H+ -> 2Mn^2+ + 5Cl2 + 8H2O}$。

**定义 5.2.2（诱导反应）** 一个氧化还原反应的进行促使另一个在同样条件下本来很慢或不能发生的氧化还原反应加速进行，这种现象称为诱导作用，被促进的反应称为**诱导反应**（受诱反应）。

上例中 $\ce{MnO4-}$ 称为作用体，$\ce{Fe^2+}$ 称为诱导体，$\ce{Cl-}$ 称为受诱体。诱导作用的机理是诱导反应产生的不稳定中间价态（这里是 Mn(V)、Mn(IV)、Mn(III)）氧化了受诱体。诱导作用与催化作用不同：催化剂在反应前后不变，诱导体则参加反应并被消耗。消除这一误差的方法是加入 $\ce{MnSO4}$–$\ce{H3PO4}$–$\ce{H2SO4}$ 混合溶液（Zimmermann–Reinhardt 试剂）：大量的 $\ce{Mn^2+}$ 使 Mn(III)/Mn(II) 电对的电势降低，Mn(III) 不再能氧化 $\ce{Cl-}$；$\ce{H3PO4}$ 与 Mn(III) 配位使其稳定，同时与 $\ce{Fe^3+}$ 生成无色配合物，便于观察终点。

## 5.3. 滴定曲线与指示剂

### 5.3.1. 滴定曲线

氧化还原滴定中，随着滴定剂的加入，两个电对的氧化态与还原态的浓度不断变化，溶液的电势随之改变。以电势为纵坐标、滴定分数为横坐标作**滴定曲线**。每加入一份滴定剂，反应迅速达到平衡，两个电对的电势相等，可以用任意一个电对计算；计量点前用被滴定物的电对（它的两种形式浓度都较大），计量点后用滴定剂的电对。滴定曲线也可以用电位滴定法（[6.4.6](/6.4.6#sec-6.4.5)）直接测得。

以 $0.1000\,\mathrm{mol\,L^{-1}}$ $\ce{Ce(SO4)2}$ 滴定 $20.00\,\mathrm{mL}$ $0.1000\,\mathrm{mol\,L^{-1}}$ $\ce{Fe^2+}$（$1\,\mathrm{mol\,L^{-1}}$ $\ce{H2SO4}$）为例，$\ce{Ce^4+ + Fe^2+ -> Ce^3+ + Fe^3+}$，$E^{\circ\prime}(\ce{Ce^4+}/\ce{Ce^3+}) = 1.44\,\mathrm{V}$，$E^{\circ\prime}(\ce{Fe^3+}/\ce{Fe^2+}) = 0.68\,\mathrm{V}$，$\lg K' = 12.8$，反应非常完全。

1. 计量点前：加入的 $\ce{Ce^4+}$ 几乎全部被还原，$c_{\ce{Ce^4+}}$ 极小，用铁电对计算。滴定分数为 $a$ 时 $c_{\ce{Fe^3+}}/c_{\ce{Fe^2+}} = a/(1 - a)$，

$$
E = 0.68 + 0.0592\lg\frac{c_{\ce{Fe^3+}}}{c_{\ce{Fe^2+}}}.
$$
滴定 50% 时 $E = E^{\circ\prime}_{\ce{Fe}} = 0.68\,\mathrm{V}$；99.9% 时 $E = 0.68 + 0.0592\times3 = 0.86\,\mathrm{V}$。注意电势只取决于浓度之比，与浓度本身和稀释无关。

2. 计量点：两个电对的电势相等，$E_{\mathrm{sp}} = 1.44 + 0.0592\lg(c_{\ce{Ce^4+}}/c_{\ce{Ce^3+}}) = 0.68 + 0.0592\lg(c_{\ce{Fe^3+}}/c_{\ce{Fe^2+}})$。两式相加，计量点时 $c_{\ce{Ce^4+}} = c_{\ce{Fe^2+}}$、$c_{\ce{Ce^3+}} = c_{\ce{Fe^3+}}$，对数项相互抵消，$E_{\mathrm{sp}} = (1.44 + 0.68)/2 = 1.06\,\mathrm{V}$。

3. 计量点后：$\ce{Fe^2+}$ 几乎全部被氧化，用铈电对计算。$\ce{Ce^4+}$ 过量 0.1% 时 $c_{\ce{Ce^4+}}/c_{\ce{Ce^3+}} = 10^{-3}$，$E = 1.44 - 0.0592\times3 = 1.26\,\mathrm{V}$；过量 100% 时 $E = E^{\circ\prime}_{\ce{Ce}} = 1.44\,\mathrm{V}$。

| 滴定分数/% | 9 | 50 | 91 | 99 | 99.9 | 100 | 100.1 | 101 | 110 | 200 |
|---|---|---|---|---|---|---|---|---|---|---|
| 计算所用的比值 | $c_{\ce{Fe^3+}}/c_{\ce{Fe^2+}} = 10^{-1}$ | $10^0$ | $10^1$ | $10^2$ | $10^3$ | — | $c_{\ce{Ce^4+}}/c_{\ce{Ce^3+}} = 10^{-3}$ | $10^{-2}$ | $10^{-1}$ | $10^0$ |
| $E/\mathrm{V}$ | 0.62 | 0.68 | 0.74 | 0.80 | 0.86 | 1.06 | 1.26 | 1.32 | 1.38 | 1.44 |

突跃范围（计量点前后 ±0.1%）为 0.86–1.26 V，即从 $E^{\circ\prime}_2 + 3\times0.0592/z_2$ 到 $E^{\circ\prime}_1 - 3\times0.0592/z_1$；$\Delta E^{\circ\prime}$ 越大，突跃越大。

### 5.3.2. 计量点电势与不对称滴定

一般地，对于 5.2.1 中的反应，把两个电对的 Nernst 方程分别乘以 $z_1$、$z_2$ 后相加：

$$
(z_1 + z_2)E = z_1E^{\circ\prime}_1 + z_2E^{\circ\prime}_2 + 0.0592\lg\frac{c_{\mathrm{Ox_1}}c_{\mathrm{Ox_2}}}{c_{\mathrm{Red_1}}c_{\mathrm{Red_2}}}.
$$
计量点时 $c_{\mathrm{Ox_1}}/c_{\mathrm{Red_2}} = c_{\mathrm{Red_1}}/c_{\mathrm{Ox_2}} = p_1/p_2$，对数项为零：

$$
E_{\mathrm{sp}} = \frac{z_1E^{\circ\prime}_1 + z_2E^{\circ\prime}_2}{z_1 + z_2}. \tag{5.5}
$$
式 (5.5) 只适用于对称电对，即半反应中氧化态与还原态的计量数相等的电对（如 $\ce{Fe^3+}/\ce{Fe^2+}$、$\ce{Ce^4+}/\ce{Ce^3+}$、$\ce{MnO4-}/\ce{Mn^2+}$）；有 $\ce{H+}$ 参加时 $[\ce{H+}]$ 应已并入 $E^{\circ\prime}$。对 $\ce{Cr2O7^2-}/\ce{Cr^3+}$、$\ce{I3-}/\ce{I-}$ 这样两边计量数不等的不对称电对，$E_{\mathrm{sp}}$ 还与浓度有关。

$z_1 = z_2$ 时，计量点在突跃的正中；$z_1 \ne z_2$ 时，计量点偏向电子数大的电对一侧。例如 $\ce{KMnO4}$ 滴定 $\ce{Fe^2+}$（$z_1 = 5$，$z_2 = 1$，$\ce{MnO4- + 5Fe^2+ + 8H+ -> Mn^2+ + 5Fe^3+ + 4H2O}$），$E_{\mathrm{sp}} = (5E^{\circ\prime}_{\ce{Mn}} + E^{\circ\prime}_{\ce{Fe}})/6$，靠近高锰酸根的电势。这时滴定曲线在计量点两侧不对称，用电位法确定终点时，不能简单地取突跃的中点。

介质对滴定曲线的影响可以由条件电极电势直接读出。计量点前的曲线位置由 $E^{\circ\prime}(\ce{Fe^3+}/\ce{Fe^2+})$ 决定：在 $\ce{H3PO4}$ 介质中 $\ce{Fe^3+}$ 生成稳定的磷酸配合物，$E^{\circ\prime}$ 降到 0.46 V，曲线前半段下移，突跃起点降低，突跃变大；计量点后的曲线位置由滴定剂电对决定。

### 5.3.3. 氧化还原滴定的指示剂

1. 氧化还原指示剂。

**定义 5.3.1（氧化还原指示剂）** 本身具有氧化还原性质、其氧化态与还原态颜色不同的有机化合物，在滴定中随溶液电势的变化被氧化或还原而改变颜色，从而指示终点，称为**氧化还原指示剂**。

对于 $\mathrm{In(Ox)} + z\ce{e-} \ce{<=>} \mathrm{In(Red)}$，$E = E^{\circ\prime}_{\mathrm{In}} + \frac{0.0592}{z}\lg\frac{c_{\mathrm{In(Ox)}}}{c_{\mathrm{In(Red)}}}$。与**酸碱指示剂**的**变色范围** $\mathrm{p}K_{\mathrm{a}} \pm 1$ 相对应，两种形式的浓度比从 1/10 变到 10 时人眼才能看出颜色变化，所以变色的电势范围为

$$
E^{\circ\prime}_{\mathrm{In}} \pm \frac{0.0592\,\mathrm{V}}{z}. \tag{5.6}
$$
选择指示剂的原则：变色范围全部或部分落在突跃范围内，$E^{\circ\prime}_{\mathrm{In}}$ 尽量接近 $E_{\mathrm{sp}}$。常用的两种：

| 指示剂 | $E^{\circ\prime}_{\mathrm{In}}/\mathrm{V}$（$[\ce{H+}] = 1\,\mathrm{mol\,L^{-1}}$） | 还原态 → 氧化态 | 用途 |
|---|---|---|---|
| 二苯胺磺酸钠 | 0.85 | 无色 → 紫红 | $\ce{K2Cr2O7}$ 滴定 $\ce{Fe^2+}$（加 $\ce{H3PO4}$） |
| 邻二氮菲–亚铁（ferroin） | 1.06 | 红 → 浅蓝 | $\ce{Ce^4+}$ 滴定 $\ce{Fe^2+}$；COD 的返滴定 |

```smiles
OS(=O)(=O)c1ccc(Nc2ccccc2)cc1 HIn
c1cnc2c(c1)ccc1cccnc12 phen
```

二苯胺磺酸被氧化时先生成无色的二苯联苯胺磺酸（不可逆），再可逆地氧化为紫红色的醌式产物，指示剂本身消耗的氧化剂很少，可以忽略。邻二氮菲–亚铁即 $\ce{[Fe(phen)3]^2+}$，它的电势比 $\ce{Fe^3+}/\ce{Fe^2+}$ 高得多，正是 5.1.3 所说的配位效应：邻二氮菲与 $\ce{Fe^2+}$ 的配合物比与 $\ce{Fe^3+}$ 的更稳定（低自旋 $\mathrm{d}^6$ 的强场配合物，[6.1.5](/6.1.5#sec-5.5.5)），使电势升高。ferroin 变色可逆、敏锐，是 $\ce{Ce^4+}$ 滴定 $\ce{Fe^2+}$ 的理想指示剂：$E^{\circ\prime}_{\mathrm{In}}$ 恰好等于 $E_{\mathrm{sp}}$。

2. 自身指示剂。

**定义 5.3.2（自身指示剂）** 滴定剂或被测物本身有颜色，而反应产物无色或颜色很浅，滴定时不必另加指示剂，利用其自身的颜色变化指示终点，这种物质称为**自身指示剂**。

例如 $\ce{KMnO4}$ 溶液呈紫红色，还原产物 $\ce{Mn^2+}$ 几乎无色；$\ce{MnO4-}$ 的浓度约达 $2\times10^{-6}\,\mathrm{mol\,L^{-1}}$ 即可看出粉红色，所以高锰酸钾法通常不另加指示剂。

3. 专属指示剂。

**定义 5.3.3（专属指示剂）** 本身没有氧化还原性质，但能与滴定剂或被测物的某一种氧化态（或还原态）特征地生成有色化合物，从而指示终点的物质，称为**专属指示剂**。

最重要的是碘量法所用的淀粉：直链淀粉的螺旋空腔中嵌入 $\ce{I5-}$ 等多碘离子链，生成深蓝色的包合物，在有 $\ce{I-}$ 存在时 $\ce{I2}$ 浓度约 $10^{-5}\,\mathrm{mol\,L^{-1}}$ 即显蓝色，反应可逆、灵敏。又如 $\ce{SCN-}$ 与 $\ce{Fe^3+}$ 生成红色配合物，可用于以 $\ce{Fe^3+}$ 滴定 $\ce{Ti^3+}$。

### 5.3.4. 终点误差

对称电对、$z_1 = z_2 = 1$ 的滴定（如 $\ce{Ce^4+}$ 滴定 $\ce{Fe^2+}$），设终点电势与计量点电势之差为 $\Delta E = E_{\mathrm{ep}} - E_{\mathrm{sp}}$。终点时过量滴定剂的分数为 $c_{\mathrm{Ox_1}}/c_{\mathrm{Red_1}} = 10^{(E_{\mathrm{ep}} - E^{\circ\prime}_1)/0.0592}$，剩余被测物的分数为 $c_{\mathrm{Red_2}}/c_{\mathrm{Ox_2}} = 10^{(E^{\circ\prime}_2 - E_{\mathrm{ep}})/0.0592}$，两者之差就是终点误差。代入 $E_{\mathrm{sp}} = (E^{\circ\prime}_1 + E^{\circ\prime}_2)/2$，得到与定理 2.7.1 的**终点误差公式**同一形式的结果：

**公式 5.3.1（氧化还原滴定的终点误差公式）** $z_1 = z_2 = 1$ 时，

$$
E_{\mathrm{t}} = \frac{10^{\Delta E/0.0592} - 10^{-\Delta E/0.0592}}{10^{\Delta E^{\circ\prime}/(2\times0.0592)}}. \tag{5.7}
$$

分母 $10^{\Delta E^{\circ\prime}/(2\times0.0592)} = \sqrt{K'}$，与式 (3.9) 的 $\sqrt{c_{\mathrm{M,sp}}K'_{\mathrm{MY}}}$ 地位相同；不同的是氧化还原滴定的终点误差与浓度无关，因为电势只取决于浓度之比。

**例 5.3.1** 在 $1\,\mathrm{mol\,L^{-1}}$ $\ce{H2SO4}$ 中用 $\ce{Ce^4+}$ 滴定 $\ce{Fe^2+}$，分别以邻二氮菲–亚铁（$1.06\,\mathrm{V}$）与二苯胺磺酸钠（$0.85\,\mathrm{V}$）为指示剂，计算终点误差。

**解** $E_{\mathrm{sp}} = 1.06\,\mathrm{V}$，$\Delta E^{\circ\prime} = 0.76\,\mathrm{V}$，$10^{0.76/0.1184} = 10^{6.42}$。用邻二氮菲–亚铁时 $\Delta E = 0$，$E_{\mathrm{t}} = 0$。用二苯胺磺酸钠时 $\Delta E = -0.21\,\mathrm{V}$，

$$
E_{\mathrm{t}} = \frac{10^{-3.55} - 10^{3.55}}{10^{6.42}} = -0.13\%,
$$
终点提前，误差超过 0.1%。

**例 5.3.2** 用 $\ce{K2Cr2O7}$ 滴定 $\ce{Fe^2+}$，以二苯胺磺酸钠（$E^{\circ\prime}_{\mathrm{In}} = 0.85\,\mathrm{V}$）为指示剂。比较只有 $\ce{H2SO4}$（$E^{\circ\prime}_{\ce{Fe}} = 0.68\,\mathrm{V}$）与加入 $\ce{H3PO4}$（$E^{\circ\prime}_{\ce{Fe}} = 0.46\,\mathrm{V}$）时的终点误差。

**解** 计量点电势约 0.95 V 以上，指示剂在计量点前变色，终点电势由铁电对决定：剩余的 $\ce{Fe^2+}$ 分数为 $c_{\ce{Fe^2+}}/c_{\ce{Fe^3+}} = 10^{-(0.85 - E^{\circ\prime}_{\ce{Fe}})/0.0592}$。只有 $\ce{H2SO4}$ 时为 $10^{-2.87} = 0.13\%$，$E_{\mathrm{t}} = -0.13\%$：滴定到 99.9% 时电势才 0.86 V，指示剂已经变色，终点过早。加入 $\ce{H3PO4}$ 后为 $10^{-6.59}$，误差可以忽略。$\ce{H3PO4}$ 的另一个作用是与黄色的 $\ce{Fe^3+}$ 生成无色的配合物，消除它对终点颜色的干扰。

## 5.4. 滴定前的预处理

### 5.4.1. 预氧化与预还原

被测组分在试样溶液中常以多种价态存在，如铁矿溶解后同时有 $\ce{Fe^3+}$ 与 $\ce{Fe^2+}$，而一次滴定只能测定其中一种价态。

**定义 5.4.1（预氧化）** 滴定前把被测组分定量地氧化为高价态（以便用还原剂滴定），或定量地还原为低价态（以便用氧化剂滴定）的步骤，称为**预氧化**或**预还原**。

例如测全铁：用 $\ce{SnCl2}$ 把 $\ce{Fe^3+}$ 全部预还原为 $\ce{Fe^2+}$，再用 $\ce{K2Cr2O7}$ 一次滴定。预处理所用的试剂必须满足：

1. 反应迅速，能把被测组分定量地氧化或还原；
2. 有一定的选择性。例如金属锌（$E^\circ(\ce{Zn^2+}/\ce{Zn}) = -0.762\,\mathrm{V}$）还原能力太强，会把 Ti(IV) 等也还原；$\ce{SnCl2}$（$E^\circ(\ce{Sn^4+}/\ce{Sn^2+}) = 0.151\,\mathrm{V}$）只还原 $\ce{Fe^3+}$ 等较强的氧化剂，选择性高；
3. 过量的试剂易于除去：$\ce{H2O2}$、$\ce{(NH4)2S2O8}$ 煮沸分解；$\ce{NaBiO3}$ 不溶于水，过滤除去；过量的 $\ce{SnCl2}$ 用 $\ce{HgCl2}$ 除去，$\ce{SnCl2 + 2HgCl2 -> SnCl4 + Hg2Cl2 v}$（生成丝状白色沉淀；若出现灰黑色的 Hg，说明 $\ce{SnCl2}$ 过量太多，Hg 会还原滴定剂，试样应弃去）。

常用的预氧化剂有 $\ce{(NH4)2S2O8}$（$\ce{Ag+}$ 催化下把 $\ce{Mn^2+}$ 氧化为 $\ce{MnO4-}$、$\ce{Cr^3+}$ 氧化为 $\ce{Cr2O7^2-}$）、$\ce{NaBiO3}$、$\ce{H2O2}$（碱性中把 Cr(III) 氧化为 $\ce{CrO4^2-}$）、$\ce{KMnO4}$；预还原剂有 $\ce{SnCl2}$、$\ce{TiCl3}$、金属锌或锌汞齐还原柱（Jones 还原器）、银还原柱（Walden 还原器，在 HCl 中 $E \approx 0.22\,\mathrm{V}$，选择性更好）、$\ce{SO2}$。

$\ce{HgCl2}$ 与 $\ce{Hg2Cl2}$ 有毒，含汞废液污染环境。现行的无汞测铁方法是 $\ce{SnCl2}$–$\ce{TiCl3}$ 联合预还原：先用 $\ce{SnCl2}$ 还原大部分 $\ce{Fe^3+}$，再用 $\ce{TiCl3}$ 还原剩余部分，以钨酸钠为指示剂（$\ce{Fe^3+}$ 还原完全后稍过量的 $\ce{Ti^3+}$ 把 W(VI) 还原为蓝色的"钨蓝"），然后滴加稀 $\ce{K2Cr2O7}$ 至蓝色恰好消失，氧化掉过量的 $\ce{Ti^3+}$。

### 5.4.2. 有机物的破坏

测定有机试样（生物组织、食品、药物）中的金属元素时，有机物会与滴定剂反应或与金属离子配位，必须先破坏：

1. 干法灰化：在马弗炉中 $400$–$700\,^\circ\mathrm{C}$ 高温下，使有机物被空气中的氧氧化分解，残渣用酸溶解；或在充满氧气的密闭烧瓶中燃烧（氧瓶燃烧法，用于测有机物中的卤素与硫）。操作简单、试剂用量少，但易挥发的元素（Hg、As、Se、Pb 的部分）会损失。
2. 湿法消解：用氧化性的酸（$\ce{HNO3}$–$\ce{H2SO4}$、$\ce{HNO3}$–$\ce{HClO4}$，有时加 $\ce{H2O2}$）在加热下分解有机物。浓热的 $\ce{HClO4}$ 遇有机物会剧烈爆炸，必须先用 $\ce{HNO3}$ 把大部分有机物氧化，再加 $\ce{HClO4}$，并在专用的通风橱中操作。
3. 微波消解：把试样与酸放在聚四氟乙烯密闭罐中用微波加热，罐内的高温高压使消解在几十分钟内完成，挥发损失与污染都很小，是目前生物与环境样品消解的常规方法，后续多用原子光谱（[6.4.8](/6.4.8)）或电感耦合等离子体质谱测定。

## 5.5. 常用的氧化还原滴定法

### 5.5.1. 高锰酸钾法

**定义 5.5.1（高锰酸钾法）** 以 $\ce{KMnO4}$ 为滴定剂的氧化还原滴定法称为**高锰酸钾法**。

$\ce{KMnO4}$ 是强氧化剂，其氧化能力与还原产物随酸度而变：

| 介质 | 半反应 | $E^\circ/\mathrm{V}$ |
|---|---|---|
| 强酸性 | $\ce{MnO4- + 8H+ + 5e- <=> Mn^2+ + 4H2O}$ | 1.507 |
| 中性、弱碱性 | $\ce{MnO4- + 2H2O + 3e- <=> MnO2 + 4OH-}$ | 0.595 |
| 强碱性（$[\ce{OH-}] > 2\,\mathrm{mol\,L^{-1}}$） | $\ce{MnO4- + e- <=> MnO4^2-}$ | 0.558 |

滴定一般在 $0.5$–$1\,\mathrm{mol\,L^{-1}}$ $\ce{H2SO4}$ 中进行：酸度不够时生成棕色的 $\ce{MnO2}$ 沉淀，计量关系改变。不用 HCl（$\ce{Cl-}$ 被氧化，且有诱导作用，5.2.4）和 $\ce{HNO3}$（本身是氧化剂）。碱性溶液中 $\ce{KMnO4}$ 氧化有机物的速度比在酸性中快，用于测定有机物。

标准溶液。$\ce{KMnO4}$ 试剂常含少量 $\ce{MnO2}$ 等杂质，蒸馏水中也有微量还原性物质；$\ce{KMnO4}$ 溶液不稳定，自身分解 $\ce{4MnO4- + 2H2O -> 4MnO2 v + 3O2 ^ + 4OH-}$，而且这一分解被 $\ce{MnO2}$ 与光催化。所以只能间接配制：称取稍多于计算量的 $\ce{KMnO4}$ 溶于水，加热微沸约 1 h（或在暗处放置一周以上）使还原性物质完全氧化，用微孔玻璃漏斗（不能用滤纸）滤去 $\ce{MnO2}$，储存于棕色瓶中，再标定。

标定常用的**基准物质**是 $\ce{Na2C2O4}$（易提纯、稳定、不含结晶水），也可用 $\ce{H2C2O4*2H2O}$、纯铁丝等。标定反应即 5.2.3 中的 $\ce{2MnO4- + 5C2O4^2- + 16H+ -> 2Mn^2+ + 10CO2 + 8H2O}$，条件可以概括为"三度一点"：

1. 速度：开始时反应很慢，要等第一滴 $\ce{KMnO4}$ 褪色后再滴第二滴；$\ce{Mn^2+}$ 生成后自催化使反应加快，可以适当加快滴定；
2. 温度：加热到 $75$–$85\,^\circ\mathrm{C}$，终点时不低于 $60\,^\circ\mathrm{C}$；超过 $90\,^\circ\mathrm{C}$ 草酸会部分分解；
3. 酸度：$0.5$–$1\,\mathrm{mol\,L^{-1}}$ $\ce{H2SO4}$；
4. 终点：以 $\ce{KMnO4}$ 自身为指示剂，溶液出现粉红色并保持 30 s 不褪即为终点（放置较久后粉红色会因空气中的还原性物质而褪去）。

应用：

1. 直接滴定还原剂：$\ce{H2O2}$ 在 $\ce{H2SO4}$ 介质中室温下直接滴定，$\ce{5H2O2 + 2MnO4- + 6H+ -> 2Mn^2+ + 5O2 ^ + 8H2O}$（$E^\circ(\ce{O2}/\ce{H2O2}) = 0.695\,\mathrm{V}$）；开始时反应也慢，$\ce{Mn^2+}$ 生成后加快。生物化学中过氧化氢酶活力的经典测定，就是用 $\ce{KMnO4}$ 滴定酶作用后剩余的 $\ce{H2O2}$。$\ce{Fe^2+}$、$\ce{NO2-}$、As(III)、Sb(III) 等也可以直接滴定。
2. 测铁：试样用 HCl 溶解，$\ce{SnCl2}$ 预还原，加 Zimmermann–Reinhardt 试剂后滴定（5.2.4）。
3. 间接测定非氧化还原性物质：例如测钙，在酸性溶液中加入 $\ce{(NH4)2C2O4}$，再用氨水缓慢中和至 pH 4 左右，使 $\ce{CaC2O4}$ 在低相对过饱和度下析出（均匀沉淀的思路，[6.4.4](/6.4.4#sec-4.3.3)），陈化、过滤，用冷水洗去过量的草酸盐，沉淀溶于稀 $\ce{H2SO4}$，用 $\ce{KMnO4}$ 滴定释出的 $\ce{H2C2O4}$，$n(\ce{Ca}) = \frac52 n(\ce{KMnO4})$。血清钙的经典测定（Kramer–Tisdall 法）就是这样做的。$\ce{Sr^2+}$、$\ce{Ba^2+}$、$\ce{Zn^2+}$、$\ce{Cd^2+}$、$\ce{Pb^2+}$、稀土等能定量生成草酸盐沉淀的离子都可以这样测定。
4. 返滴定测氧化剂：$\ce{MnO2}$、$\ce{PbO2}$、$\ce{K2Cr2O7}$、$\ce{KClO3}$ 等与已知过量的 $\ce{Na2C2O4}$ 作用后，用 $\ce{KMnO4}$ 滴定剩余的草酸根。
5. 测定有机物：在强碱性溶液中加入过量 $\ce{KMnO4}$，甘油、甲醇、甲醛、甲酸、苯酚、葡萄糖等被定量氧化。例如甲酸：$\ce{2MnO4- + HCOO- + 3OH- -> CO3^2- + 2MnO4^2- + 2H2O}$。反应完成后酸化，$\ce{MnO4^2-}$ 歧化为 $\ce{MnO4-}$ 与 $\ce{MnO2}$，加入过量的 $\ce{Fe^2+}$ 标准溶液把所有高价锰还原为 $\ce{Mn^2+}$，再用 $\ce{KMnO4}$ 滴定剩余的 $\ce{Fe^2+}$。环境监测中的高锰酸盐指数就是在规定条件下用 $\ce{KMnO4}$ 氧化水样所消耗的量，用来衡量地表水中有机物与还原性物质的污染程度。

高锰酸钾法的优点是氧化能力强、应用广，一般不需另加指示剂；缺点是试剂含杂质、溶液不够稳定，反应历程复杂、副反应多，选择性较差，不能在 HCl 介质中进行。

### 5.5.2. 重铬酸钾法

**定义 5.5.2（重铬酸钾法）** 以 $\ce{K2Cr2O7}$ 为滴定剂的氧化还原滴定法称为**重铬酸钾法**。

$\ce{Cr2O7^2- + 14H+ + 6e- <=> 2Cr^3+ + 7H2O}$，$E^\circ = 1.36\,\mathrm{V}$。与 $\ce{KMnO4}$ 相比，$\ce{K2Cr2O7}$ 的氧化能力稍弱，但有几个突出的优点：容易提纯，在 $140$–$150\,^\circ\mathrm{C}$ 干燥后可作基准物质直接配制标准溶液；溶液非常稳定，可长期保存；在 $1\,\mathrm{mol\,L^{-1}}$ HCl 中 $E^{\circ\prime} = 1.00\,\mathrm{V}$，低于 $E^\circ(\ce{Cl2}/\ce{Cl-}) = 1.358\,\mathrm{V}$，室温下不氧化 $\ce{Cl-}$，可以在 HCl 介质中滴定。缺点是还原产物 $\ce{Cr^3+}$ 呈绿色，须用指示剂（二苯胺磺酸钠）；Cr(VI) 有毒且致癌，废液必须还原为 Cr(III) 后处理。

1. 测铁：这是重铬酸钾法最重要的应用，也是铁矿全铁的标准方法。试样用 HCl 溶解，$\ce{SnCl2}$ 预还原（或无汞的 $\ce{SnCl2}$–$\ce{TiCl3}$ 法），加入 $\ce{H2SO4}$–$\ce{H3PO4}$ 混合酸，以二苯胺磺酸钠为指示剂，用 $\ce{K2Cr2O7}$ 标准溶液滴定至溶液由绿色变为紫色：

$$
\ce{6Fe^2+ + Cr2O7^2- + 14H+ -> 6Fe^3+ + 2Cr^3+ + 7H2O}.
$$
加 $\ce{H3PO4}$ 的作用见例 5.3.2：降低 $E^{\circ\prime}(\ce{Fe^3+}/\ce{Fe^2+})$，使指示剂的变色点落入突跃之内；与黄色的 $\ce{Fe^3+}$ 配位，便于观察终点。
2. 化学需氧量（chemical oxygen demand），简称 COD：在强酸性溶液中，以 $\ce{Ag2SO4}$ 为催化剂、$\ce{HgSO4}$ 掩蔽 $\ce{Cl-}$，用过量的 $\ce{K2Cr2O7}$ 回流氧化水样中的有机物，再以邻二氮菲–亚铁为指示剂，用硫酸亚铁铵标准溶液返滴定剩余的 $\ce{K2Cr2O7}$，换算为氧化同样多的有机物所需的 $\ce{O2}$ 的质量浓度（$\mathrm{mg\,L^{-1}}$）。它是衡量污水有机污染的主要指标。
3. 利用 $\ce{Cr2O7^2-}$ 与 $\ce{Fe^2+}$ 的反应，还可以间接测定 $\ce{NO3-}$ 等氧化剂（加入过量 $\ce{Fe^2+}$，返滴定剩余部分）。

### 5.5.3. 碘量法

**定义 5.5.3（碘量法）** 利用 $\ce{I2}$ 的氧化性和 $\ce{I-}$ 的还原性进行测定的氧化还原滴定法称为**碘量法**。

$\ce{I2}$ 在水中的溶解度很小（约 $1.3\times10^{-3}\,\mathrm{mol\,L^{-1}}$），实际使用的是溶于 KI 溶液生成的 $\ce{I3-}$：

$$
\ce{I3- + 2e- <=> 3I-}, \qquad E^\circ = 0.536\,\mathrm{V}.
$$
（为简便，常写作 $\ce{I2}$。）$\ce{I2}$ 是较弱的氧化剂，$\ce{I-}$ 是中等强度的还原剂，所以碘量法有两种方式。

**定义 5.5.4（直接碘量法）** 用 $\ce{I2}$ 标准溶液直接滴定电势低于 $E^\circ(\ce{I3-}/\ce{I-})$ 的还原性物质的方法称为**直接碘量法**（碘滴定法）。

**定义 5.5.5（间接碘量法）** 使氧化性物质与过量的 $\ce{I-}$ 作用定量地析出 $\ce{I2}$（或使还原性物质与过量的 $\ce{I2}$ 作用），再用 $\ce{Na2S2O3}$ 标准溶液滴定析出的（或剩余的）$\ce{I2}$ 的方法称为**间接碘量法**（滴定碘法）。

间接碘量法的滴定反应是

$$
\ce{I2 + 2S2O3^2- -> 2I- + S4O6^2-}.
$$

直接碘量法只能在中性或弱酸性溶液中进行：碱性溶液中 $\ce{I2}$ 歧化（$\ce{3I2 + 6OH- -> IO3- + 5I- + 3H2O}$）。可以直接滴定的有 $\ce{S^2-}$、$\ce{SO3^2-}$、$\ce{S2O3^2-}$、As(III)、Sn(II)、维生素 C 等。

间接碘量法的应用范围大得多：凡是能定量地把 $\ce{I-}$ 氧化为 $\ce{I2}$ 的氧化剂（$\ce{Cu^2+}$、$\ce{Cr2O7^2-}$、$\ce{IO3-}$、$\ce{BrO3-}$、$\ce{ClO-}$、$\ce{H2O2}$、$\ce{O2}$ 等）都可以测定。它的条件：

1. 在中性或弱酸性溶液中滴定。强碱性溶液中 $\ce{S2O3^2-}$ 被 $\ce{I2}$ 部分氧化为 $\ce{SO4^2-}$（$\ce{S2O3^2- + 4I2 + 10OH- -> 2SO4^2- + 8I- + 5H2O}$），计量关系改变，$\ce{I2}$ 也会歧化；强酸性溶液中 $\ce{S2O3^2-}$ 分解（$\ce{S2O3^2- + 2H+ -> S v + SO2 + H2O}$），$\ce{I-}$ 也容易被空气氧化。
2. 防止 $\ce{I2}$ 挥发：加入过量 KI（一般为理论量的 2–3 倍）使 $\ce{I2}$ 生成 $\ce{I3-}$；在室温下进行，在碘量瓶中反应，滴定时不要剧烈摇动。
3. 防止 $\ce{I-}$ 被空气氧化（$\ce{4I- + O2 + 4H+ -> 2I2 + 2H2O}$，被光、$\ce{Cu^2+}$、$\ce{NO2-}$ 催化）：溶液酸度不宜太高，避免阳光直射，析出 $\ce{I2}$ 后立即滴定。
4. 淀粉指示剂应在近终点（溶液呈浅黄色）时加入：$\ce{I2}$ 浓度大时淀粉吸附大量 $\ce{I2}$，释放缓慢，使终点推迟。直接碘量法则可以在滴定开始时加入淀粉，终点由无色变为蓝色。

$\ce{Na2S2O3}$ 标准溶液。$\ce{Na2S2O3*5H2O}$ 易风化、潮解，常含少量杂质，不能直接配制标准溶液。它的溶液也不稳定：溶解的 $\ce{CO2}$ 使之分解，空气中的 $\ce{O2}$ 使之氧化，嗜硫细菌使之分解析出硫。配制时用新煮沸并冷却的蒸馏水（除去 $\ce{CO2}$、$\ce{O2}$，杀灭细菌），加入少量 $\ce{Na2CO3}$ 使溶液呈弱碱性（pH 9–10，抑制细菌），储存于棕色瓶中，放置 1–2 周待浓度稳定后再标定。

标定用基准物质 $\ce{K2Cr2O7}$ 或 $\ce{KIO3}$，按间接碘量法进行：

$$
\ce{Cr2O7^2- + 6I- + 14H+ -> 2Cr^3+ + 3I2 + 7H2O}, \qquad \ce{IO3- + 5I- + 6H+ -> 3I2 + 3H2O},
$$
1 mol $\ce{K2Cr2O7}$ 或 1 mol $\ce{KIO3}$ 都相当于 6 mol $\ce{Na2S2O3}$。用 $\ce{K2Cr2O7}$ 时，在 $0.2$–$0.4\,\mathrm{mol\,L^{-1}}$ 酸度下加入过量 KI，暗处放置 5 min 使反应完全，然后加水稀释（降低酸度，减少 $\ce{I-}$ 的空气氧化，并冲淡 $\ce{Cr^3+}$ 的绿色），用 $\ce{Na2S2O3}$ 滴定至浅黄色，加淀粉，继续滴定至蓝色消失、溶液呈 $\ce{Cr^3+}$ 的亮绿色。滴定后放置 5 min 以上溶液又变蓝，是 $\ce{I-}$ 被空气氧化所致，属正常；若很快变蓝，说明 $\ce{Cr2O7^2-}$ 与 $\ce{I-}$ 的反应尚未完全，应重新标定。

**例 5.5.1** 称取基准 $\ce{K2Cr2O7}$ $0.1226\,\mathrm{g}$，按上述方法标定 $\ce{Na2S2O3}$ 溶液，消耗 $25.00\,\mathrm{mL}$。求 $c(\ce{Na2S2O3})$。$M(\ce{K2Cr2O7}) = 294.18\,\mathrm{g\,mol^{-1}}$。

**解** $n(\ce{Na2S2O3}) = 6n(\ce{K2Cr2O7}) = 6\times0.1226/294.18 = 2.501\times10^{-3}\,\mathrm{mol}$，$c = 2.501\times10^{-3}/0.02500 = 0.1000\,\mathrm{mol\,L^{-1}}$。

碘量法的应用：

1. 铜的测定：在 pH 3–4（用 $\ce{NH4HF2}$ 控制酸度，同时以 $\ce{FeF6^3-}$ 的形式掩蔽 $\ce{Fe^3+}$，例 5.1.2）的溶液中加入过量 KI，$\ce{2Cu^2+ + 4I- -> 2CuI v + I2}$，用 $\ce{Na2S2O3}$ 滴定析出的 $\ce{I2}$，$n(\ce{Cu^2+}) = n(\ce{S2O3^2-})$。KI 必须过量，既作还原剂、沉淀剂，又使 $\ce{I2}$ 生成 $\ce{I3-}$，保证反应完全。CuI 沉淀表面强烈吸附 $\ce{I2}$，使结果偏低；近终点时加入 KSCN，使 CuI 转化为溶解度更小、吸附 $\ce{I2}$ 少的 CuSCN，释放出被吸附的 $\ce{I2}$。KSCN 不能过早加入，否则 $\ce{SCN-}$ 会还原 $\ce{I2}$，使结果偏低。
2. 硫化物与含硫气体：在弱酸性溶液中 $\ce{H2S + I2 -> S v + 2H+ + 2I-}$。为防止 $\ce{H2S}$ 逸出，把试液加入过量的酸性碘溶液中，再用 $\ce{Na2S2O3}$ 返滴定剩余的 $\ce{I2}$。有机硫化物等可先转化为 $\ce{H2S}$，用锌盐的氨溶液吸收后测定。
3. 漂白粉中的有效氯：漂白粉的主要成分是 $\ce{CaCl(OCl)}$，其质量以能释放出的氯量（有效氯，以 Cl 的质量分数表示）衡量。试样溶于稀 $\ce{H2SO4}$，加过量 KI：$\ce{ClO- + 2I- + 2H+ -> I2 + Cl- + H2O}$（$\ce{ClO2-}$ 也同样反应：$\ce{ClO2- + 4I- + 4H+ -> 2I2 + Cl- + 2H2O}$），用 $\ce{Na2S2O3}$ 滴定析出的 $\ce{I2}$。
4. 维生素 C（抗坏血酸）：烯二醇结构有较强的还原性，被 $\ce{I2}$ 定量氧化为脱氢抗坏血酸，$\ce{C6H8O6 + I2 -> C6H6O6 + 2HI}$，用直接碘量法滴定。抗坏血酸在空气中，尤其是碱性溶液中极易被氧化，所以在稀乙酸溶液中溶样并立即滴定。这是药物与果汁中维生素 C 的常用测定法。

```smiles
OC[C@H](O)[C@H]1OC(=O)C(O)=C1O>>OC[C@H](O)[C@H]1OC(=O)C(=O)C1=O
```

5. 葡萄糖等醛糖：在碱性溶液中加入一定量过量的 $\ce{I2}$ 标准溶液，$\ce{I2}$ 歧化生成的 $\ce{IO-}$ 把醛基氧化为羧基：

$$
\begin{aligned}
&\ce{I2 + 2OH- -> IO- + I- + H2O},\\
&\ce{CH2OH(CHOH)4CHO + IO- + OH- -> CH2OH(CHOH)4COO- + I- + H2O}.
\end{aligned}
$$
剩余的 $\ce{IO-}$ 在碱性溶液中歧化为 $\ce{IO3-}$ 与 $\ce{I-}$（$\ce{3IO- -> IO3- + 2I-}$），酸化后又全部转化为 $\ce{I2}$（$\ce{IO3- + 5I- + 6H+ -> 3I2 + 3H2O}$），用 $\ce{Na2S2O3}$ 滴定。1 mol 葡萄糖相当于 1 mol $\ce{I2}$。酮糖（果糖）在此条件下不被氧化，可借此测定醛糖与酮糖混合物中的醛糖。
6. 经 8-羟基喹啉测镁（溴量法）：$\ce{Mg^2+}$ 与 8-羟基喹啉（HOx，[6.4.4](/6.4.4#sec-4.3.4)）生成 $\ce{Mg(Ox)2}$ 沉淀，过滤、洗净后溶于 HCl，加入一定量过量的 $\ce{KBrO3}$–KBr 标准溶液，酸性中生成的 $\ce{Br2}$（$\ce{BrO3- + 5Br- + 6H+ -> 3Br2 + 3H2O}$）与 8-羟基喹啉发生取代反应生成 5,7-二溴-8-羟基喹啉（每个 HOx 消耗 2 个 $\ce{Br2}$）；剩余的 $\ce{Br2}$ 加 KI 置换为 $\ce{I2}$，再用 $\ce{Na2S2O3}$ 滴定。计量关系为

$$
1\,\ce{Mg^2+} \;\hat{=}\; 2\,\mathrm{HOx} \;\hat{=}\; 4\,\ce{Br2} \;\hat{=}\; \tfrac{4}{3}\,\ce{KBrO3} \;\hat{=}\; 8\,\ce{S2O3^2-},
$$
1 个 $\ce{Mg^2+}$ 对应 8 个 $\ce{S2O3^2-}$，放大了计量关系，适合测定少量的镁。同样的方法也用于测定苯酚（生成三溴苯酚）。
7. 水分的测定（Karl Fischer 法）：在甲醇与有机碱（吡啶或咪唑）介质中，$\ce{I2}$ 氧化 $\ce{SO2}$ 的反应需要定量地消耗水，$\ce{H2O + I2 + SO2 + CH3OH + 3RN -> [RNH]SO4CH3 + 2[RNH]I}$，用碘的消耗量测定试样中的微量水。它是药品、食品、溶剂中水分测定的标准方法；现行的库仑法以电解产生 $\ce{I2}$，见 [6.4.6](/6.4.6#sec-6.5.4)。
