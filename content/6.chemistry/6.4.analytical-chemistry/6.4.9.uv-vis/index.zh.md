分子中价电子的跃迁能量在 $1.5$–$6\,\mathrm{eV}$ 左右，对应 $200$–$800\,\mathrm{nm}$ 的紫外–可见光。测量溶液对这一波段光的吸收，既能根据吸收带的位置与形状推断分子中的共轭体系与生色基团（这是 6.5 有机化学中波谱解析的第一步），又能根据吸收的强弱测定浓度——分光光度计是化学与生物实验室中最常用的仪器，测蛋白质与核酸的浓度、跟踪酶反应、测平衡常数都离不开它。**Lambert–Beer 定律**、**吸光度**与**摩尔吸收系数**已在 [6.3.17](/6.3.17#def-17.2.3) 中定义，本章讲它的物理来源、适用条件与测量误差；分子能级与**带状光谱**的物理见 [5.5.5](/5.5.5#sec-5.3)，光谱仪器的光源、单色器与检测器的原理见 [6.4.7](/6.4.7#sec-7.1.3)。本章最后介绍生物分析中常用的两种光学方法：测量分子相互作用的表面等离子体共振，与测定蛋白质二级结构的圆二色谱。下一章（[6.4.10](/6.4.10)）讲吸收光子之后分子怎样发光。

## 9.1. 分子能级与电子光谱

### 9.1.1. 分子的能级与带状光谱

分子的能量由电子运动、原子核的振动与分子的转动三部分组成，$E = E_{\mathrm{e}} + E_{\mathrm{v}} + E_{\mathrm{r}}$，三者都是量子化的（[5.5.5](/5.5.5#sec-5.3.1)）。相邻能级的间隔相差约一个数量级：

| 跃迁 | 能级间隔 | 光谱区 | 光谱 |
|---|---|---|---|
| 电子能级 | $1$–$20\,\mathrm{eV}$ | 紫外–可见（$60$–$1200\,\mathrm{nm}$） | 电子光谱（本章） |
| 振动能级 | $0.05$–$1\,\mathrm{eV}$ | 红外（$1$–$25\,\mu\mathrm{m}$） | 振动光谱（[6.4.11](/6.4.11)） |
| 转动能级 | $0.005$–$0.05\,\mathrm{eV}$ | 远红外与微波 | 转动光谱 |

电子跃迁时振动与转动状态也同时改变，所以一个电子跃迁不是一条谱线，而是许多振动–转动谱线组成的谱带；溶液中分子与溶剂不断碰撞，转动谱线变宽并连成一片，振动结构也往往模糊，最后只剩一个宽的吸收带，即**分子光谱**中的**带状光谱**。对称四嗪（1,2,4,5-四嗪）在 $500$–$550\,\mathrm{nm}$ 的 $\mathrm{n}\to\pi^*$ 吸收是一个典型的例子：在蒸气中能看到振动与转动的精细结构，在非极性的环己烷中只剩振动结构，在水中（溶剂与氮原子的孤对电子形成**氢键**）则成为一个光滑的宽带。

```smiles
c1nncnn1
```

溶液中的紫外–可见光谱因此信息量有限：它主要反映分子中共轭体系与生色基团的性质，不能像红外或核磁共振那样给出完整的结构，但它的灵敏度高、测量快、仪器便宜。

### 9.1.2. 紫外–可见吸收光谱法

**定义 9.1.1** 根据物质分子对紫外–可见光（约 $190$–$800\,\mathrm{nm}$）的选择性吸收进行定性、定量分析和结构研究的方法称为**紫外–可见吸收光谱法**（又称紫外–可见分光光度法）。以波长为横坐标、吸光度（或摩尔吸收系数）为纵坐标作图得到吸收光谱（吸收曲线），吸收最强处的波长记作 $\lambda_{\max}$，对应的摩尔吸收系数记作 $\varepsilon_{\max}$。

它的特点是：

- 可以做定性分析（吸收带的位置与形状）和定量分析（吸光度与浓度成正比），检出浓度一般为 $10^{-6}$–$10^{-5}\,\mathrm{mol\,L^{-1}}$，借助显色反应可达 $10^{-7}\,\mathrm{mol\,L^{-1}}$ 量级；
- 可以测定解离常数、配合物的组成与稳定常数、反应速率等物理化学常数（9.5）；
- 仪器结构简单、价格便宜、操作方便，测量相对误差约 $1\%$–$2\%$；
- 应用范围广：无机离子（多数经显色反应）、有机化合物、药物，以及蛋白质、核酸等生物大分子。

物质的颜色来自对可见光的选择性吸收：溶液呈现的是被吸收光的互补色。

| 吸收光的波长 / nm | 吸收光的颜色 | 溶液的颜色（互补色） |
|---|---|---|
| $400$–$435$ | 紫 | 黄绿 |
| $435$–$480$ | 蓝 | 黄 |
| $480$–$490$ | 绿蓝 | 橙 |
| $490$–$500$ | 蓝绿 | 红 |
| $500$–$560$ | 绿 | 紫红 |
| $560$–$580$ | 黄绿 | 紫 |
| $580$–$595$ | 黄 | 蓝 |
| $595$–$650$ | 橙 | 绿蓝 |
| $650$–$780$ | 红 | 蓝绿 |

$\ce{MnO4-}$ 吸收 $525\,\mathrm{nm}$ 附近的绿光而呈紫红色，$\ce{[Cu(NH3)4]^2+}$ 吸收橙黄光而呈深蓝色。分光光度法的历史就是检测手段的进步：目视比色（人眼比较颜色深浅）→ 光电比色（滤光片 + 光电池）→ 分光光度法（棱镜或光栅分光 + 光电检测，可以在任意波长测量）。

## 9.2. 吸收光谱与分子结构

### 9.2.1. 有机分子的电子跃迁

按**分子轨道理论**，有机分子中与紫外–可见吸收有关的价电子有三种：形成单键的 σ 电子、形成双键与三键的 π 电子，以及 O、N、S、卤素等杂原子上未成键的孤对电子（n 电子）。它们占据成键轨道 σ、π 与非键轨道 n；空的反键轨道 $\sigma^*$、$\pi^*$ 能量较高。能量次序一般是 $\sigma < \pi < \mathrm{n} < \pi^* < \sigma^*$，可能的跃迁有四类：

| 跃迁 | 所需能量 | 典型 $\lambda_{\max}$ | 典型 $\varepsilon_{\max}$ / ($\mathrm{L\,mol^{-1}\,cm^{-1}}$) | 例子 |
|---|---|---|---|---|
| $\sigma\to\sigma^*$ | 最大 | $< 150\,\mathrm{nm}$（真空紫外） | — | 甲烷 $122\,\mathrm{nm}$，乙烷 $135\,\mathrm{nm}$ |
| $\mathrm{n}\to\sigma^*$ | 较大 | $150$–$250\,\mathrm{nm}$ | $10^2$–$3\times10^3$ | $\ce{H2O}$ $167$（1480），$\ce{CH3OH}$ $184$（150），$\ce{CH3Cl}$ $173$（200），$\ce{CH3I}$ $258$（365），$\ce{(CH3)3N}$ $227$（900） |
| $\pi\to\pi^*$ | 较小 | 孤立双键约 $170$–$190\,\mathrm{nm}$，共轭后移向长波 | $10^3$–$10^5$ | 乙烯 $171$（15 000），1,3-丁二烯 $217$（21 000） |
| $\mathrm{n}\to\pi^*$ | 最小 | $250$–$600\,\mathrm{nm}$ | $10$–$10^2$ | 丙酮 $279$（15），对称四嗪约 $540$ |

数据为饱和烃或醇类溶剂中的近似值，括号中为 $\varepsilon_{\max}$。由此得到几条规律：

- 饱和烃只有 $\sigma\to\sigma^*$ 跃迁，在近紫外区透明，所以正己烷、环己烷可以作紫外光谱的溶剂；含杂原子的饱和化合物（水、醇、醚、卤代烷）在 $200\,\mathrm{nm}$ 附近才开始吸收，溶剂的透明下限（截止波长）约为：水 $190\,\mathrm{nm}$，乙腈 $190\,\mathrm{nm}$，甲醇 $205\,\mathrm{nm}$，乙醇 $210\,\mathrm{nm}$，二氯甲烷 $233\,\mathrm{nm}$，三氯甲烷 $245\,\mathrm{nm}$，丙酮 $330\,\mathrm{nm}$。
- 有机化合物的紫外–可见光谱分析主要以 $\pi\to\pi^*$ 与 $\mathrm{n}\to\pi^*$ 跃迁为基础，它们落在仪器可测的 $200\,\mathrm{nm}$ 以上。
- $\pi\to\pi^*$ 跃迁是对称性允许的，吸收强（$\varepsilon \ge 10^4$）；$\mathrm{n}\to\pi^*$ 跃迁的 n 轨道与 $\pi^*$ 轨道几乎正交，跃迁概率小 2–3 个数量级，吸收弱（$\varepsilon < 10^3$，常为几十）。吸收带的强弱因此是判断跃迁类型的依据。

### 9.2.2. 生色团与助色团

**定义 9.2.1** 分子中能在紫外–可见区产生吸收的不饱和基团（含 π 电子的基团，如 $\ce{C=C}$、$\ce{C=O}$、$\ce{N=N}$、$\ce{-NO2}$、$\ce{C#N}$、苯环）称为**生色团**（又称发色团）。本身在近紫外区不吸收、但与生色团相连后使吸收带移向长波并增强的含 n 电子的饱和基团（$\ce{-OH}$、$\ce{-OR}$、$\ce{-NH2}$、$\ce{-NR2}$、$\ce{-SH}$、$\ce{-Cl}$、$\ce{-Br}$ 等）称为**助色团**。

助色团的 n 电子与生色团的 π 电子共轭（n–π 共轭），使 π 体系扩大、$\pi\to\pi^*$ 的能隙减小。描述吸收带的移动与强度变化有四个术语：

**定义 9.2.2** 由于取代基、溶剂或结构的改变，吸收带的 $\lambda_{\max}$ 移向长波的现象称为**红移**（长移），移向短波称为**蓝移**（短移）；吸收强度（$\varepsilon_{\max}$）增大称为**增色效应**，减小称为**减色效应**。

苯的三个吸收带都来自 $\pi\to\pi^*$ 跃迁：$184\,\mathrm{nm}$（$\varepsilon \approx 6\times10^4$）、$204\,\mathrm{nm}$（$\varepsilon \approx 7900$）与 $254\,\mathrm{nm}$ 附近的弱带（$\varepsilon \approx 200$，对称性禁阻，在非极性溶剂中显出振动精细结构，是芳环的特征）。$\ce{-OH}$、$\ce{-NH2}$ 作为助色团使后两个吸收带红移并增色：

```smiles
c1ccccc1 1
Oc1ccccc1 2
[O-]c1ccccc1 3
Nc1ccccc1 4
```

| 化合物 | 吸收带（$\lambda_{\max}$ / nm，括号内为 $\varepsilon_{\max}$） |
|---|---|
| 苯 1 | $204$（7900），$256$（200） |
| 苯酚 2 | $210$（6200），$270$（1450） |
| 苯酚阴离子 3 | $235$（9400），$287$（2600） |
| 苯胺 4 | $230$（8600），$280$（1430） |
| 苯胺盐酸盐 | $203$（7500），$254$（160） |

苯酚解离成阴离子后，氧上多了一对可以参与共轭的电子，吸收进一步红移并增色；苯胺质子化后氮的孤对电子被 $\ce{H+}$ 占据，不再与苯环共轭，光谱几乎回到苯的样子。比较酸性与碱性溶液中的光谱就能判断分子中是否有酚羟基或芳胺，这也是 9.5.4 中光度法测 $\mathrm{p}K_{\mathrm{a}}$ 的依据。

### 9.2.3. 影响吸收带的因素

共轭效应：共轭体系越大，最高占据轨道与最低空轨道（**前线轨道**）的能隙越小，$\pi\to\pi^*$ 吸收红移，强度增大。线型多烯是最清楚的例子：

| 化合物 | 共轭双键数 | $\lambda_{\max}$ / nm | $\varepsilon_{\max}$ | 颜色 |
|---|---|---|---|---|
| 乙烯 | 1 | $171$ | $15\,000$ | 无色 |
| 1,3-丁二烯 | 2 | $217$ | $21\,000$ | 无色 |
| 1,3,5-己三烯 | 3 | $258$ | $35\,000$ | 无色 |
| β-胡萝卜素 | 11 | $451$ | $1.4\times10^5$ | 橙 |

β-胡萝卜素吸收蓝光，所以胡萝卜呈橙色；视网膜中视黄醛的质子化 Schiff 碱（11 个共轭键加上蛋白质环境）吸收约 $500\,\mathrm{nm}$，是视觉的分子基础。由结构估算 $\lambda_{\max}$ 的经验规则（Woodward–Fieser 规则）在 6.5 有机化学中结合结构解析讲。

```smiles
CC1=C(C(C)(C)CCC1)/C=C/C(C)=C/C=C/C(C)=C/C=C/C=C(C)/C=C/C=C(C)/C=C/C2=C(C)CCCC2(C)C
```

取代基效应：助色团（给电子的 n 电子基团）与吸电子的生色团（$\ce{-NO2}$、$\ce{C=O}$）连在同一共轭体系的两端时，形成"推–拉"体系，激发态带有分子内电荷转移的性质，吸收大幅红移。对硝基苯酚在酸性溶液中 $\lambda_{\max} = 317\,\mathrm{nm}$（无色），解离成阴离子后 $\lambda_{\max} = 400\,\mathrm{nm}$（$\varepsilon \approx 1.8\times10^4$，黄色），它因此可以作酸碱指示剂，也是磷酸酶等水解酶活性测定中常用的显色产物（对硝基苯磷酸酯水解后释放对硝基苯酚，在碱性溶液中测 $405\,\mathrm{nm}$ 的吸光度）。

```smiles
Oc1ccc(cc1)[N+](=O)[O-] 1
[O-]c1ccc(cc1)[N+](=O)[O-] 2
```

**溶剂效应**：溶剂极性对两类跃迁的影响方向相反。

- $\pi\to\pi^*$ 跃迁：多数分子的 $\pi^*$ 激发态比基态极性大，极性溶剂对激发态的稳定作用更强，能隙减小，吸收**红移**（通常 $10$–$20\,\mathrm{nm}$ 以内）。
- $\mathrm{n}\to\pi^*$ 跃迁：基态的 n 电子能与极性溶剂（尤其是质子性溶剂）形成氢键而被稳定，激发后 n 轨道只剩一个电子，氢键被削弱，所以基态降低得比激发态多，吸收**蓝移**。丙酮的 $\mathrm{n}\to\pi^*$ 带在正己烷中为 $279\,\mathrm{nm}$，在水中为 $264.5\,\mathrm{nm}$。

溶剂由非极性换为极性时吸收带红移还是蓝移，因此可以帮助判断跃迁类型。极性溶剂还会抹去振动精细结构（9.1.1 的四嗪）。比较光谱时要注明溶剂，测定时选择对试样溶解度好、在测定波长透明、不与试样作用的溶剂。

### 9.2.4. 无机化合物的吸收光谱

d–d 跃迁与 f–f 跃迁：按**晶体场理论**（[6.1.5](/6.1.5#sec-5.5)），过渡金属离子与配体形成配合物时，五个 d 轨道分裂为能量不同的几组；d 电子在分裂后的轨道之间跃迁吸收可见光，吸收波长对应**晶体场分裂能**：配体场越强，分裂能越大，吸收波长越短（**光谱化学序列**）。$\ce{[Cu(H2O)6]^2+}$ 的吸收峰约在 $800\,\mathrm{nm}$（浅蓝色），换成配位场更强的 $\ce{NH3}$ 后，$\ce{[Cu(NH3)4(H2O)2]^2+}$ 的吸收峰移到约 $600\,\mathrm{nm}$（深蓝色）。中心对称的配合物中 d–d 跃迁是宇称禁阻的（Laporte 规则），只能借振动破坏对称性而微弱地发生，$\varepsilon$ 通常只有 $1$–$10^2\,\mathrm{L\,mol^{-1}\,cm^{-1}}$，用于定量分析不够灵敏。镧系离子的 f–f 跃迁被外层 5s、5p 电子屏蔽，吸收带窄而尖锐；氧化钬溶液或钬玻璃的尖锐吸收峰被用作校准分光光度计波长的标准。

电荷转移跃迁：

**定义 9.2.3** 配合物（或离子对、分子复合物）吸收光子时，电子从主要属于电子给予体的轨道跃迁到主要属于电子接受体的轨道，这种跃迁称为**电荷转移跃迁**。按方向分为配体到金属（LMCT）、金属到配体（MLCT）等。

电荷转移跃迁是自旋与宇称都允许的，吸收很强，$\varepsilon$ 一般为 $10^3$–$10^5\,\mathrm{L\,mol^{-1}\,cm^{-1}}$，是灵敏的无机显色反应的主要基础：

- LMCT：$\ce{MnO4-}$（$525\,\mathrm{nm}$，$\varepsilon \approx 2.4\times10^3$）、$\ce{CrO4^2-}$（$372\,\mathrm{nm}$，$\varepsilon \approx 4.8\times10^3$），以及 $\ce{Fe^3+}$ 与 $\ce{SCN-}$ 生成的血红色配合物（约 $480\,\mathrm{nm}$）。氧化态高的金属与易被氧化的配体之间最容易发生。
- MLCT：$\ce{Fe^2+}$ 与邻二氮菲的橙红色配合物 $\ce{[Fe(phen)3]^2+}$（$510\,\mathrm{nm}$，$\varepsilon = 1.1\times10^4$），是测铁的经典方法；$\ce{[Ru(bpy)3]^2+}$ 的 MLCT 激发态还会发光（[6.4.10](/6.4.10#sec-10.6.2)）。

金属离子影响下配体的 $\pi\to\pi^*$ 跃迁：许多有机显色剂本身有颜色，与金属离子配位后共轭体系的电子分布改变，吸收带红移或蓝移、强度改变。偶氮类显色剂（偶氮胂 III、偶氮氯膦 III 等）与 $\ce{Ca^2+}$、稀土、$\ce{U(VI)}$ 等的配合物 $\varepsilon$ 可达 $10^4$–$10^5$；这与**金属指示剂**（[6.4.3](/6.4.3#def-3.4.1)）的变色原理相同，区别只在于这里测吸光度而不是看颜色突变。

### 9.2.5. 生物大分子的紫外吸收

生物化学实验中最常做的分光光度测定是蛋白质与核酸的浓度和纯度。

蛋白质：肽键在 $190$–$220\,\mathrm{nm}$ 有强吸收（$\pi\to\pi^*$ 约 $190\,\mathrm{nm}$，$\mathrm{n}\to\pi^*$ 约 $210$–$220\,\mathrm{nm}$），但许多缓冲成分在此也吸收；常用的是芳香氨基酸侧链在 $280\,\mathrm{nm}$ 附近的吸收：色氨酸（$\varepsilon_{280} \approx 5500$）、酪氨酸（$\approx 1490$）以及胱氨酸的二硫键（$\approx 125$），苯丙氨酸在 $280\,\mathrm{nm}$ 几乎不吸收。由氨基酸序列可以估算变性蛋白的摩尔吸收系数：

$$
\varepsilon_{280} \approx 5500\,n_{\mathrm{Trp}} + 1490\,n_{\mathrm{Tyr}} + 125\,n_{\mathrm{cystine}} \quad (\mathrm{L\,mol^{-1}\,cm^{-1}}),
$$
天然蛋白通常与此相差不超过 $5\%$ 左右。不含色氨酸与酪氨酸的蛋白（或需要更高灵敏度时）改用显色法：Bradford 法利用考马斯亮蓝 G-250 与蛋白质（主要是碱性与芳香残基）结合后吸收峰由约 $465\,\mathrm{nm}$ 红移到 $595\,\mathrm{nm}$；BCA 法与 Lowry 法则基于蛋白质把 $\ce{Cu^2+}$ 还原为 $\ce{Cu+}$ 后的显色反应。

```smiles
c1ccc2c(c1)c(c[nH]2)C[C@H](N)C(=O)O Trp
Oc1ccc(cc1)C[C@H](N)C(=O)O Tyr
```

核酸：碱基的芳杂环在 $260\,\mathrm{nm}$ 附近强烈吸收。在 $1\,\mathrm{cm}$ 吸收池中 $A_{260} = 1$ 大约相当于双链 DNA $50\,\mu\mathrm{g\,mL^{-1}}$、单链 RNA $40\,\mu\mathrm{g\,mL^{-1}}$、单链寡核苷酸约 $33\,\mu\mathrm{g\,mL^{-1}}$（后者随序列变化，精确工作按碱基组成计算 $\varepsilon_{260}$）。纯净 DNA 的 $A_{260}/A_{280} \approx 1.8$，RNA 约 $2.0$；比值明显偏低说明有蛋白质或酚污染，$A_{260}/A_{230}$ 偏低说明有盐、胍或糖类残留。微量分光光度计用液滴的表面张力在两个光纤端面之间形成 $0.05$–$1\,\mathrm{mm}$ 的光程，只需 $1$–$2\,\mu\mathrm{L}$ 样品，就是为了测核酸与蛋白质而设计的。

DNA 解链：双螺旋中碱基相互堆积，π 电子之间的耦合使吸收强度比游离碱基低（减色效应）。加热使双链解开、堆积破坏，$A_{260}$ 增大约 $30\%$–$40\%$，这就是 DNA 变性的**增色效应**。以 $A_{260}$ 对温度作图得到 S 形的解链曲线，增色变化一半处的温度称为熔解温度 $T_{\mathrm{m}}$；$T_{\mathrm{m}}$ 随 GC 含量（GC 对有三个氢键、堆积作用更强）与离子强度增大而升高，是 PCR 引物设计和核酸杂交条件选择的依据。

## 9.3. 吸收定律及其偏离

### 9.3.1. 吸收定律的推导

**定义 9.3.1** 透过试样的光强 $I$ 与入射光强 $I_0$ 之比 $\tau = I/I_0$ 称为**透射比**（透光率），常用百分数表示。吸光度与透射比的关系为 $A = \lg(I_0/I) = -\lg\tau$。

透射比在教材中常记作 $T$；本站为避免与热力学温度、周期混淆，按 IUPAC 与 ISO 80000-7 的另一种写法记作 $\tau$。

[6.3.17](/6.3.17#def-17.2.3) 由"薄层吸收的分数正比于吸光分子数"直接得到了 **Lambert–Beer 定律**。从单个分子的角度看，比例系数有明确的物理意义。设平行单色光垂直通过截面积为 $S$、厚度为 $\mathrm{d}x$ 的薄层，层内吸光分子数为 $\mathrm{d}n$。每个分子可以看成一个能"俘获"光子的小靶，其有效面积 $\sigma$ 称为吸收截面（它等于分子的几何截面乘以跃迁概率，单位 $\mathrm{cm^2}$）。薄层中所有靶的总面积为 $\sigma\,\mathrm{d}n$（层很薄，靶互不遮挡），光子被俘获的概率等于这一面积占截面的分数：

$$
-\frac{\mathrm{d}I_x}{I_x} = \frac{\sigma\,\mathrm{d}n}{S}.
$$
浓度为 $c$（$\mathrm{mol\,L^{-1}}$）时，体积 $S\,\mathrm{d}x$（$\mathrm{cm^3}$）中的分子数 $\mathrm{d}n = N_{\mathrm{A}}cS\,\mathrm{d}x/1000$，代入并对光程 $0$ 到 $b$ 积分：

$$
\ln\frac{I_0}{I} = \frac{\sigma N_{\mathrm{A}}}{1000}\,bc, \qquad A = \lg\frac{I_0}{I} = \varepsilon bc, \qquad \varepsilon = \frac{N_{\mathrm{A}}\sigma}{1000\ln 10} \approx 2.6\times10^{20}\,\sigma. \tag{9.1}
$$
这里光程记作 $b$（$\mathrm{cm}$；6.3.17 记作 $l$），$\sigma$ 以 $\mathrm{cm^2}$ 为单位时 $\varepsilon$ 的单位是 $\mathrm{L\,mol^{-1}\,cm^{-1}}$。浓度用质量浓度 $\rho$（$\mathrm{g\,L^{-1}}$）时写作 $A = abc$，$a = \varepsilon/M$ 称为质量吸收系数；生物化学中还常用 $A^{1\%}_{1\,\mathrm{cm}}$（$1\%$ 溶液在 $1\,\mathrm{cm}$ 光程下的吸光度）。式 (9.1) 说明 $\varepsilon$ 是分子吸光能力的度量：对完全允许的跃迁，分子的吸收截面约为 $10^{-15}\,\mathrm{cm^2}$（$0.1\,\mathrm{nm^2}$，与生色团的大小相当），对应 $\varepsilon \sim 10^5$；禁阻跃迁的跃迁概率小，$\varepsilon$ 相应小几个数量级。

**性质 9.3.1（加和性）** 溶液中有几种互不作用的吸光物质时，总吸光度等于各组分吸光度之和：

$$
A = \sum_i A_i = b\sum_i \varepsilon_i c_i. \tag{9.2}
$$
加和性是多组分同时测定（9.5.2）和用空白溶液扣除背景的依据：用只含溶剂与试剂的参比溶液调零，测得的就是被测物的吸光度。

### 9.3.2. 对吸收定律的偏离

式 (9.1) 的推导隐含了几个条件：入射光是单色的；吸光分子互不作用且只以一种形式存在；介质均匀、不散射；除吸收外没有其他光到达检测器。实际测量中校准曲线在高浓度时常向浓度轴弯曲（负偏离），原因分为三类。

非单色光：单色器给出的是有一定宽度（光谱带宽）的波段。设入射光由强度相等的两个波长 $\lambda_1$、$\lambda_2$ 组成，摩尔吸收系数分别为 $\varepsilon_1$、$\varepsilon_2$。检测器测的是总光强：

$$
A = \lg\frac{I_{01} + I_{02}}{I_{01}\cdot 10^{-\varepsilon_1 bc} + I_{02}\cdot 10^{-\varepsilon_2 bc}} = \lg\frac{2}{10^{-\varepsilon_1 bc} + 10^{-\varepsilon_2 bc}}.
$$
只有 $\varepsilon_1 = \varepsilon_2$ 时 $A$ 才与 $c$ 成正比。$\varepsilon_1 \ne \varepsilon_2$ 时，低浓度下 $A \approx \frac{1}{2}(\varepsilon_1 + \varepsilon_2)bc$；高浓度下吸收较强的波长几乎全被吸收，透过的主要是吸收较弱的光，$A$ 趋于 $\varepsilon_{\min}bc + \lg 2$，校准曲线的斜率下降（下图左）。因此应在吸收峰顶测量（峰顶附近 $\varepsilon$ 随波长变化最慢），并使光谱带宽远小于吸收带的宽度（通常不超过其 1/10）。

杂散光：杂散光是单色器中由散射、反射而到达检测器的、不在所选波段内的光，它通常不被试样吸收。设杂散光强为 $I_{\mathrm{s}}$，测得的吸光度

$$
A_{\mathrm{obs}} = \lg\frac{I_0 + I_{\mathrm{s}}}{I + I_{\mathrm{s}}},
$$
当试样吸收很强（$I \ll I_{\mathrm{s}}$）时趋于常数 $\lg(1 + I_0/I_{\mathrm{s}})$。杂散光占 $0.1\%$ 时，仪器能测的吸光度不超过约 $3$；在光源能量低、检测器灵敏度差的波段端点（如 $200\,\mathrm{nm}$ 以下），杂散光的比例更大，偏离更严重。

![吸收定律的负偏离。左：入射光含强度相等、摩尔吸收系数不同的两个波长时，吸光度与浓度的关系；只有两者相等时为直线。右：杂散光使测得的吸光度在高吸光度时趋于饱和](./plots/beer-deviations.py)

化学因素：被测物发生解离、缔合、互变或与溶剂作用，各种形式的 $\varepsilon$ 不同，且比例随浓度改变，$A$ 与总浓度就不再成正比。重铬酸盐溶液中存在平衡

$$
\ce{Cr2O7^2- + H2O <=> 2HCrO4- <=> 2CrO4^2- + 2H+},
$$
稀释使平衡右移；$\ce{CrO4^2-}$ 的吸收峰在 $372\,\mathrm{nm}$，$\ce{Cr2O7^2-}$ 在 $350\,\mathrm{nm}$ 与 $450\,\mathrm{nm}$ 附近，在未缓冲的溶液中以总铬浓度作校准曲线就会弯曲。控制 pH（使铬全部以一种形式存在）就能消除这种偏离。

两种可以相互转化的吸光物质处于平衡时，它们的吸收曲线往往在某些波长相交：

**定义 9.3.2** 两种（或几种按固定计量关系相互转化的）吸光物质的摩尔吸收系数相等的波长称为**等吸收点**。在等吸收点，体系的吸光度只与总浓度有关，而与两者之间的比例无关。

在不同 pH 测一个酸碱指示剂的系列光谱，所有曲线都通过同一点（9.5.4 的图）。一组光谱有清晰的等吸收点，是"体系中只有两种吸光物质相互转化"的有力证据；等吸收点漂移说明存在第三种物质（中间体、副产物或沉淀）。等吸收点的吸光度不随转化程度改变，可以用作测量总浓度的波长或内部参比。

高浓度与其他因素：浓度高于约 $0.01\,\mathrm{mol\,L^{-1}}$ 时，分子间距离缩短，相邻分子的电荷分布相互影响，$\varepsilon$ 本身随浓度改变；溶液的折射率也随浓度改变，严格地说 $\varepsilon$ 中含有因子 $n/(n^2+2)^2$。浑浊试样中光被散射而不是被吸收，表观吸光度偏高；试样发荧光则使透射光偏强。所以吸收定律是一个稀溶液的极限定律，定量分析应在校准曲线的线性范围内进行。

### 9.3.3. 可测浓度的下限

由式 (9.1)，$\varepsilon$ 的上限约为 $10^5\,\mathrm{L\,mol^{-1}\,cm^{-1}}$（取 $\sigma \approx 10^{-15}\,\mathrm{cm^2}$ 得 $2.6\times10^5$，实际很少超过 $2\times10^5$）。

**例 9.3.1** 若仪器能可靠测出 $1\%$ 的吸收（$\tau = 0.99$，$A = -\lg 0.99 = 0.0044$），$b = 1\,\mathrm{cm}$，$\varepsilon = 1\times10^5\,\mathrm{L\,mol^{-1}\,cm^{-1}}$，则可测的最低浓度

$$
c_{\min} = \frac{A}{\varepsilon b} = \frac{0.0044}{1\times10^5 \times 1} = 4.4\times10^{-8}\,\mathrm{mol\,L^{-1}}.
$$

这一数值是方法**检出限**的数量级估计（它由最低可测吸光度决定，常被称为"理论灵敏度"，但与 [6.4.1](/6.4.1#def-1.8.2) 中作为校准曲线斜率的**灵敏度**不是一回事），它说明普通吸收光度法很难测定 $10^{-8}\,\mathrm{mol\,L^{-1}}$ 以下的物质。原因是吸收测量要从两个大的光强 $I_0$、$I$ 中分辨出一个小的差值，光源的波动直接成为噪声；**荧光**测量则是在暗背景上检测发射光，所以检出限低得多（[6.4.10](/6.4.10#sec-10.2.1)）。怎样突破这一限制，见本章思考题 1。

## 9.4. 分光光度计与测量误差

### 9.4.1. 仪器的组成

紫外–可见分光光度计由光源、单色器、吸收池、检测器与信号处理系统组成，各部件的一般原理见 [6.4.7](/6.4.7#sec-7.1.3)。

- 光源：可见与近红外区用钨灯或卤钨灯（约 $320$–$2500\,\mathrm{nm}$；卤钨灯中的碘或溴使蒸发的钨重新沉积到灯丝上，寿命更长、亮度更高）；紫外区用氘灯（约 $160$–$380\,\mathrm{nm}$，连续光谱由 $\ce{D2}$ 分子的电激发与解离产生，氘灯比早期的氢灯亮 3–5 倍）。两灯在 $320$–$360\,\mathrm{nm}$ 之间自动切换。一些仪器用脉冲氙灯（$190$–$1100\,\mathrm{nm}$），只在测量瞬间发光，寿命长、试样不受持续照射。
- 单色器：光栅为主（棱镜已少用）。光谱带宽一般为 $0.5$–$2\,\mathrm{nm}$，应小于吸收带半宽度的 1/10（9.3.2）。
- 吸收池（比色皿）：紫外区必须用石英（熔融石英，透明到约 $190\,\mathrm{nm}$），可见区可用光学玻璃（$\ge 350\,\mathrm{nm}$）或塑料；标准光程 $1\,\mathrm{cm}$，另有 $0.1$–$10\,\mathrm{cm}$ 的规格。一对吸收池的透射比应匹配，使用时注意光学面的清洁与方向。
- 检测器：**光电倍增管**（灵敏，用于扫描型仪器）、硅光电二极管，以及由数百至上千个光电二极管组成的光电二极管阵列（PDA）或**电荷耦合器件**（多道检测，同时测量整个光谱）。

### 9.4.2. 单光束、双光束与二极管阵列仪器

单光束分光光度计：一束光依次通过参比溶液（调 $\tau = 100\%$，即测 $I_0$）与试样溶液（测 $I$）。结构简单、能量高，但每换一个波长都要重新用参比调零，难以自动扫描光谱；光源与检测器在两次测量之间的漂移直接成为误差。

双光束分光光度计：单色光被旋转的扇形镜（斩光器）或分束器分成两束，交替（或同时）通过参比池与样品池，检测器测量两束光强的比值。它不需要来回更换吸收池，光源强度与检测器灵敏度的缓慢漂移被同时补偿，可以快速自动扫描吸收光谱，是通用仪器的主流。但它和单光束仪器一样，不能消除试液本身的背景吸收（浑浊、共存物的吸收），这需要双波长法（9.4.3）。

二极管阵列分光光度计：采用"倒置光路"——复合光先通过试样，再由光栅色散到阵列检测器上，各波长同时测量，一秒内得到整个光谱。它没有运动部件，适合快速反应动力学、流动体系，以及高效液相色谱的二极管阵列检测器（[6.4.14](/6.4.14#sec-14.1.4)）。

### 9.4.3. 双波长分光光度法

**定义 9.4.1** 用两个单色器分别得到波长 $\lambda_1$、$\lambda_2$ 的单色光，由斩光器使它们交替通过同一吸收池，测量两波长吸光度之差 $\Delta A = A_{\lambda_2} - A_{\lambda_1}$ 进行定量的方法称为**双波长分光光度法**。

它只用一个吸收池，不需要参比溶液。设被测组分 a 与干扰组分 i 的吸收光谱重叠：

$$
A_{\lambda_1} = \varepsilon^{\mathrm{a}}_{\lambda_1}bc_{\mathrm{a}} + A^{\mathrm{i}}_{\lambda_1}, \qquad A_{\lambda_2} = \varepsilon^{\mathrm{a}}_{\lambda_2}bc_{\mathrm{a}} + A^{\mathrm{i}}_{\lambda_2}.
$$
选择两个对干扰组分为等吸收的波长（$A^{\mathrm{i}}_{\lambda_1} = A^{\mathrm{i}}_{\lambda_2}$），而被测组分在两波长的吸收差别尽可能大（通常 $\lambda_2$ 取被测组分的吸收峰），则

$$
\Delta A = (\varepsilon^{\mathrm{a}}_{\lambda_2} - \varepsilon^{\mathrm{a}}_{\lambda_1})bc_{\mathrm{a}} \propto c_{\mathrm{a}}, \tag{9.3}
$$
干扰组分的影响被完全扣除。同理，浑浊试样的散射、吸收池与试液的背景吸收 $A_{\mathrm{b}}$ 在两个相近的波长上近似相等，$\Delta A$ 中也被消去：双波长法适合测定混浊液（全血、悬浮细胞、组织匀浆）和有背景吸收的试样。

### 9.4.4. 导数光谱

**定义 9.4.2** 吸光度对波长的导数 $\mathrm{d}^nA/\mathrm{d}\lambda^n$ 随波长变化的曲线称为（$n$ 阶）**导数光谱**，用它进行定性、定量分析的方法称为导数分光光度法。

由 $A = \varepsilon bc$，$\frac{\mathrm{d}^nA}{\mathrm{d}\lambda^n} = \frac{\mathrm{d}^n\varepsilon}{\mathrm{d}\lambda^n}bc$，导数值仍与浓度成正比。它的性质是：

1. 零阶光谱的吸收峰对应一阶导数的零点、二阶导数的极小值；肩峰在零阶光谱中不明显，在导数光谱中变成清晰的极值，可以用来确定重叠峰的位置。
2. 灵敏度取决于 $\mathrm{d}^n\varepsilon/\mathrm{d}\lambda^n$：一阶导数在吸收曲线的拐点（斜率最大处）绝对值最大。
3. 宽度为 $w$ 的吸收带，其 $n$ 阶导数的幅度约正比于 $1/w^n$：导数运算放大窄带、压低宽带。缓慢变化的背景（散射、宽的干扰吸收）在高阶导数中几乎消失，两个严重重叠的吸收带也有可能分开。

导数由仪器电路或对数字化光谱做数值微分得到。微分会放大高频噪声，实际中先平滑再求导（Savitzky–Golay 滤波，即对滑动窗口内的点做多项式**最小二乘法**拟合后求导，`scipy.signal.savgol_filter`）。二阶、四阶导数光谱常用于药物制剂中主成分与辅料的分离测定，以及蛋白质中苯丙氨酸、酪氨酸与色氨酸吸收带的区分。

### 9.4.5. 测量误差与适宜的吸光度范围

即使仪器与试剂都理想，吸光度读数本身也有误差。若仪器的主要误差是透射比读数的绝对误差 $\Delta\tau$ 恒定（光电管、检流计式仪器的读数误差，或暗电流、放大器噪声为主时），由 $c = -\lg\tau/(\varepsilon b)$ 求微分：

$$
\mathrm{d}c = -\frac{0.4343}{\varepsilon b}\frac{\mathrm{d}\tau}{\tau}, \qquad \frac{\Delta c}{c} = \frac{0.4343\,\Delta\tau}{\tau\lg\tau}. \tag{9.4}
$$
浓度的相对误差在 $\tau$ 很大（吸收太少）和 $\tau$ 很小（几乎不透光）时都很大。令 $\frac{\mathrm{d}}{\mathrm{d}\tau}(\tau\lg\tau) = \lg\tau + \lg\mathrm{e} = 0$，得 $\tau = 1/\mathrm{e} = 0.368$，即

$$
A = \lg\mathrm{e} = 0.434
$$
时相对误差最小。

**例 9.4.1** 设 $\Delta\tau = \pm 0.005$。$A = 0.434$ 时 $|\Delta c/c| = \frac{0.4343\times0.005}{0.368\times0.434} = 1.36\%$；$A = 0.2$（$\tau = 0.631$）与 $A = 0.8$（$\tau = 0.158$）时均约为 $1.7\%$；而 $A = 1.5$ 时增大到 $4.6\%$。所以测量时通过调节试样浓度或吸收池光程，使吸光度落在 $0.2$–$0.8$ 之间。

$A = 0.434$ 的结论依赖于"$\Delta\tau$ 恒定"的前提。现代仪器的光电倍增管或光电二极管常受光子散粒噪声限制，透射比的标准差约正比于 $\sqrt{\tau^2 + \tau}$，此时最佳吸光度移到约 $0.96$，在 $A$ 达到 $1.5$–$2$ 时误差仍不大；在高吸光度端，最终限制测量的是杂散光（9.3.2）。对浓度高、吸光度超出范围的试样，可以用浓度稍低的标准溶液代替空白作参比（示差分光光度法），相当于把透射比标尺放大。

## 9.5. 定量方法与应用

### 9.5.1. 单组分测定与显色反应

单组分定量用**校准曲线**（[6.4.1](/6.4.1#sec-1.8.1)）：配制一系列标准溶液，在选定波长测吸光度，对浓度作图并用**最小二乘法**拟合，由试样的吸光度求浓度。校准曲线的斜率 $\varepsilon b$ 就是方法的**灵敏度**（[6.4.1](/6.4.1#def-1.8.2)），光程一定时由摩尔吸收系数决定。测量条件的选择：

- **波长**：一般选 $\lambda_{\max}$（灵敏度最高，且 $\varepsilon$ 随波长变化最慢，对非单色光的偏离最小）；若 $\lambda_{\max}$ 处有共存物干扰，按"吸收最大、干扰最小"的原则另选波长。
- 参比溶液：试样与显色剂均无色时用溶剂（蒸馏水）作参比；显色剂有色时用试剂空白（不加试样、其余相同）；试样本身有色时用试样空白（不加显色剂）。参比溶液的作用是扣除吸收池、溶剂、试剂与基体的吸收，相当于**空白试验**。
- 显色反应：多数无机离子在紫外–可见区吸收弱，先用显色剂转化为 $\varepsilon$ 大的有色化合物。显色反应要求选择性好、灵敏（$\varepsilon \ge 10^4$）、产物组成恒定且稳定、与显色剂的颜色差别大（$\Delta\lambda_{\max} \ge 60\,\mathrm{nm}$）；要控制显色剂用量、酸度（影响配合物的形成与显色剂本身的颜色，与 [6.4.3](/6.4.3#def-3.2.3) 的酸效应同理）、温度与显色时间，并用掩蔽剂消除干扰离子。例如 $\ce{Fe^2+}$ 与邻二氮菲在 pH 2–9 生成 $\ce{[Fe(phen)3]^2+}$（$510\,\mathrm{nm}$），先用盐酸羟胺把 $\ce{Fe^3+}$ 还原为 $\ce{Fe^2+}$，可测总铁。

### 9.5.2. 多组分同时测定

几种组分的吸收光谱相互重叠时，由吸光度的加和性 (9.2)，在 $m$ 个波长测量混合物的吸光度 $A_i$，得到线性方程组

$$
A_i = b\sum_{j=1}^{k}\varepsilon_{ij}c_j, \quad i = 1, \dots, m, \qquad \text{即} \quad \boldsymbol{A} = bE\boldsymbol{c},
$$
其中 $\varepsilon_{ij}$ 是组分 $j$ 在波长 $\lambda_i$ 的摩尔吸收系数，由纯组分的标准溶液测定。$m = k$ 时直接解这个**线性方程组**；为了减小测量误差的影响，通常在更多的波长（$m > k$）测量，用**最小二乘法**求 $\boldsymbol{c} = (E^{\mathsf T}E)^{-1}E^{\mathsf T}\boldsymbol{A}/b$（[3.3.7](/3.3.7#sec-7.3.1) 的矩阵方法）。波长应选在各组分吸收差别大的地方，否则矩阵 $E$ 接近奇异，误差被放大。

**例 9.5.1** 在 $1\,\mathrm{mol\,L^{-1}}$ $\ce{H2SO4}$ 中，$\ce{Cr2O7^2-}$ 与 $\ce{MnO4-}$ 在 $440\,\mathrm{nm}$ 的摩尔吸收系数分别为 $369$ 与 $95\,\mathrm{L\,mol^{-1}\,cm^{-1}}$，在 $545\,\mathrm{nm}$ 分别为 $11$ 与 $2350\,\mathrm{L\,mol^{-1}\,cm^{-1}}$。某混合液在 $1\,\mathrm{cm}$ 吸收池中测得 $A_{440} = 0.393$、$A_{545} = 0.598$，求两者浓度。

```python
import numpy as np

# rows: 440 nm, 545 nm; columns: Cr2O7(2-), MnO4(-); units L mol^-1 cm^-1
E = np.array([[369.0, 95.0],
              [11.0, 2350.0]])
A = np.array([0.393, 0.598])      # b = 1 cm
c = np.linalg.solve(E, A)
print(c)                          # [1.0007e-03 2.4978e-04] mol/L

# with more wavelengths than components, use least squares instead:
# c, *_ = np.linalg.lstsq(E_many, A_many, rcond=None)
```

得 $c(\ce{Cr2O7^2-}) = 1.00\times10^{-3}\,\mathrm{mol\,L^{-1}}$，$c(\ce{MnO4-}) = 2.50\times10^{-4}\,\mathrm{mol\,L^{-1}}$。现代仪器记录整个光谱，用全光谱的多元校准（经典最小二乘、偏最小二乘）同时测定多个组分，原理相同，只是方程数远多于未知数。

### 9.5.3. 配合物组成的测定

分光光度法是测定溶液中配合物组成（配位比）与稳定常数的经典方法。设反应为 $m\ce{M} + n\ce{R} \ce{<=>} \ce{M_mR_n}$，在测定波长只有配合物吸收（或扣除 M、R 的吸收）。

**定义 9.5.1** 固定金属离子浓度 $c_{\mathrm{M}}$，逐渐增大配体浓度 $c_{\mathrm{R}}$，测量吸光度 $A$ 对 $c_{\mathrm{R}}/c_{\mathrm{M}}$ 作图，由曲线转折点对应的浓度比求配位比的方法称为**摩尔比法**。

$c_{\mathrm{R}}/c_{\mathrm{M}} < n/m$ 时 M 未被完全配位，$A$ 随 R 的加入线性增大；超过 $n/m$ 后 M 已全部转化，$A$ 不再增加。两段直线外推的交点就是配位比。配合物稳定性好时转折尖锐；稳定性较差时，配合物在计量点附近部分解离，转折变圆，这一偏离正好可以用来求稳定常数。设在转折点（$c_{\mathrm{R}}/c_{\mathrm{M}} = n/m$），配合物完全不解离时的浓度为 $c$、吸光度为 $A_0$（由两段直线外推得到），实测吸光度为 $A'$，则配合物的解离度 $\alpha = (A_0 - A')/A_0$，平衡浓度为 $[\ce{M_mR_n}] = (1-\alpha)c$、$[\ce{M}] = m\alpha c$、$[\ce{R}] = n\alpha c$，配合物的解离常数（不稳定常数）为

$$
K_{\mathrm{d}} = \frac{1}{\beta} = \frac{[\ce{M}]^m[\ce{R}]^n}{[\ce{M_mR_n}]} = \frac{(m\alpha c)^m(n\alpha c)^n}{(1-\alpha)c} = \frac{m^mn^n\alpha^{m+n}c^{m+n-1}}{1-\alpha}. \tag{9.5}
$$

**例 9.5.2** 1:1 配合物在转折点 $c = 1.0\times10^{-4}\,\mathrm{mol\,L^{-1}}$，外推得 $A_0 = 0.500$，实测 $A' = 0.450$。则 $\alpha = 0.10$，$K_{\mathrm{d}} = \alpha^2c/(1-\alpha) = 1.1\times10^{-6}$，**稳定常数** $\beta = 9.0\times10^5$（$\lg\beta = 5.95$）。

**定义 9.5.2** 保持金属离子与配体的总浓度 $c_{\mathrm{M}} + c_{\mathrm{L}}$ 不变，改变两者的比例（配体的摩尔分数 $x = c_{\mathrm{L}}/(c_{\mathrm{M}} + c_{\mathrm{L}})$），以吸光度对 $x$ 作图，由极大值的位置求配位比的方法称为**连续变化法**（等摩尔连续变化法，Job 法）。

对配合物 $\ce{ML_n}$，若配合物完全形成，其浓度为 $\min(c_{\mathrm{M}}, c_{\mathrm{L}}/n)$，在 $c_{\mathrm{L}} = nc_{\mathrm{M}}$ 即

$$
x_{\max} = \frac{n}{n+1}
$$
处最大（1:1 配合物在 $x = 0.5$，1:2 在 $x = 2/3$）；可以证明配合物不完全形成时极大值仍在这一位置，只是峰顶变圆，此时由两侧切线的交点确定。连续变化法要求溶液中只有一种配合物占优势；对逐级稳定常数相近、同时存在几种配合物的体系，两种方法都只能给出平均的结果，要用多波长数据的全局拟合。此外还有斜率比法（分别在金属或配体大大过量时作两条校准曲线，由斜率之比求配位比）与平衡移动法（以 $\lg\frac{A}{A_{\max} - A}$ 对 $\lg c_{\mathrm{L}}$ 作图，斜率为配位数）原理相近。

![连续变化法（Job 法）：总浓度 1.0×10⁻³ mol/L，只有配合物吸收；ML 的极大值在 x = 1/2，ML₂ 在 x = 2/3；稳定常数较小时峰顶变圆但位置不变](./plots/job-plot.py)

### 9.5.4. 酸碱解离常数的测定

酸 HB 与其共轭碱 $\ce{B-}$ 的吸收光谱不同时（如 9.2.3 的对硝基苯酚），可以用分光光度法测 $\mathrm{p}K_{\mathrm{a}}$。配制总浓度 $c$ 相同、pH 不同的一系列溶液，在某一波长（通常选 $\ce{B-}$ 或 HB 的吸收峰）测吸光度（$b = 1\,\mathrm{cm}$）：

$$
A = \varepsilon_{\mathrm{HB}}[\ce{HB}] + \varepsilon_{\mathrm{B}}[\ce{B-}], \qquad c = [\ce{HB}] + [\ce{B-}].
$$
在强酸性溶液中酸全部以 HB 存在，测得 $A_{\mathrm{HB}} = \varepsilon_{\mathrm{HB}}c$；在强碱性溶液中全部以 $\ce{B-}$ 存在，测得 $A_{\mathrm{B}} = \varepsilon_{\mathrm{B}}c$。由上两式解出

$$
[\ce{HB}] = \frac{A_{\mathrm{B}} - A}{\varepsilon_{\mathrm{B}} - \varepsilon_{\mathrm{HB}}}, \qquad [\ce{B-}] = \frac{A - A_{\mathrm{HB}}}{\varepsilon_{\mathrm{B}} - \varepsilon_{\mathrm{HB}}},
$$
代入 $K_{\mathrm{a}} = [\ce{H+}][\ce{B-}]/[\ce{HB}]$ 得

$$
\mathrm{p}K_{\mathrm{a}} = \mathrm{pH} + \lg\frac{A_{\mathrm{B}} - A}{A - A_{\mathrm{HB}}}. \tag{9.6}
$$
这就是吸光度形式的 **Henderson–Hasselbalch 方程**。测一个 pH 就能算出 $\mathrm{p}K_{\mathrm{a}}$，更可靠的做法是测一系列 pH，以 $\lg\frac{A - A_{\mathrm{HB}}}{A_{\mathrm{B}} - A}$ 对 pH 作图（直线，斜率 1，截距 $-\mathrm{p}K_{\mathrm{a}}$），或直接用非线性**最小二乘法**拟合 $A$–pH 的 S 形曲线（`scipy.optimize.curve_fit`，[4.4.4](/4.4.4#sec-4.2.3)）。这样测得的是一定离子强度下的**浓度常数**（[6.4.2](/6.4.2#sec-2.2.2)），需要时用活度因子换算为热力学常数。该方法只需 $10^{-5}\,\mathrm{mol\,L^{-1}}$ 量级的物质，适合难溶或昂贵的化合物（药物、蛋白质中的发色基团），也用于测定酸碱指示剂的 $\mathrm{p}K_{\mathrm{a}}$。

![对硝基苯酚（pKa = 7.15，c = 5.0×10⁻⁵ mol/L）的光度法测定（模拟数据）。左：不同 pH 的吸收光谱，酸式 317 nm、碱式 400 nm，所有曲线通过约 348 nm 的等吸收点；右：400 nm 的吸光度对 pH 作图并用 curve_fit 拟合式 (9.6)](./plots/pka-isosbestic.py)

### 9.5.5. 光声光谱与长光程吸收

两种扩展吸收测量范围的技术：

- 光声光谱：用强度调制的光（斩光的光束或脉冲激光）照射密闭池中的试样，试样吸收光能后经无辐射弛豫转化为热，周期性的热膨胀产生声波，由灵敏的传声器（或压电换能器）检测。信号正比于吸收的光能，与透射光无关，所以能测粉末、固体、浑浊液、生物组织等无法测透射的试样，也能测极弱的吸收（光声效应由 Bell 于 1880 年发现）。生物医学中的光声成像用组织中血红蛋白等的吸收产生超声信号，可以对数厘米深处的血管成像。
- 长光程吸收池：由式 (9.1)，吸光度与光程成正比。用内壁反射率高的液芯波导毛细管（管壁材料的折射率低于水，光在液芯中全反射传播），光程可达数米，配合激光光源，可测海水中 $\mathrm{nmol\,L^{-1}}$ 级的营养盐与痕量金属；气体分析中的多次反射池与光腔衰荡光谱把有效光程延长到千米量级。

## 9.6. 表面等离子体共振与圆二色谱

### 9.6.1. 表面等离子体共振

金属中自由电子的集体振荡称为等离子体振荡。在金属与电介质（玻璃、水）的界面上，电子密度的振荡可以与电磁波耦合，形成沿界面传播、在垂直于界面的方向上指数衰减的表面电磁波——表面等离激元。它的波矢

$$
k_{\mathrm{sp}} = \frac{\omega}{c}\sqrt{\frac{\varepsilon_{\mathrm{m}}n_{\mathrm{s}}^2}{\varepsilon_{\mathrm{m}} + n_{\mathrm{s}}^2}}
$$
（$\varepsilon_{\mathrm{m}}$ 是金属的相对电容率，可见光区金、银的 $\varepsilon_{\mathrm{m}}$ 为绝对值较大的负数；$n_{\mathrm{s}}$ 是电介质的**折射率**；$c$ 是真空中的光速）大于同一频率的光在该电介质中的波矢 $n_{\mathrm{s}}\omega/c$，所以光从电介质一侧直接照射金属表面不能激发它，需要用棱镜或光栅提供额外的波矢。

最常用的是 Kretschmann 构型：在高折射率（$n_{\mathrm{p}}$）棱镜的底面镀约 $50\,\mathrm{nm}$ 的金膜，金膜的另一面接触试样溶液。p 偏振光在棱镜内以大于临界角的角度 $\theta$ 入射到底面，发生**全反射**；界面处的倏逝波穿过很薄的金膜，其平行于界面的波矢分量为 $k_x = \frac{\omega}{c}n_{\mathrm{p}}\sin\theta$。当 $k_x = \operatorname{Re}k_{\mathrm{sp}}$ 时，光的能量转移给表面等离激元，反射光强急剧下降。

**定义 9.6.1** 满足波矢匹配条件的入射光在金属–电介质界面激发表面等离激元、使反射光强在某一入射角（或波长）出现尖锐极小的共振现象称为**表面等离子体共振**（SPR），反射率最小时的入射角称为共振角（SPR 角）。金属纳米颗粒中被光直接激发的局域电子振荡称为局域表面等离子体共振（LSPR，9.6.3）。

表面等离激元的电场从金膜表面向溶液一侧指数衰减，衰减长度约 $200\,\mathrm{nm}$，所以共振角只对金膜表面附近一薄层的折射率敏感。生物分子结合到表面后，这一薄层的折射率增大，共振角随之移动；对蛋白质，共振角的移动近似正比于表面上结合物的质量浓度。商品仪器把共振信号表示为响应单位 RU，$1\,\mathrm{RU}$ 约相当于折射率变化 $10^{-6}$，即约 $1\,\mathrm{pg\,mm^{-2}}$ 的蛋白质。

这一现象的研究历程：Wood 1902 年观察到金属光栅反射光谱中的异常暗带；Ritchie 1957 年从理论上提出表面等离激元；Otto 与 Kretschmann 1968 年提出用棱镜的衰减全反射激发；Liedberg 等 1983 年首次把 SPR 用于免疫传感，1990 年出现商品化的 SPR 生物传感器。

### 9.6.2. SPR 生物传感与结合动力学

SPR 是最常用的无标记分子相互作用分析方法。把一种分子（配体，如抗体、受体蛋白、DNA）固定在金膜表面的葡聚糖或自组装单层上，另一种分子（分析物，如抗原、药物分子）随缓冲液流过表面，实时记录响应随时间的变化——传感图。一个循环包括基线、结合（注入分析物）、解离（换回缓冲液）与再生（用酸、碱或高盐洗去结合物）。它不需要荧光或放射性标记，不需要分离游离与结合的分子，能直接给出结合与解离的速率常数，在抗体筛选、药物–靶标相互作用（[6.6](/6.6)）和片段药物发现中被广泛使用；作为**生物传感器**（[6.4.6](/6.4.6#def-6.7.2)），它的识别元件是固定的配体，换能器是 SPR 光学系统。

对最简单的 1:1 结合 $\ce{A + B <=> AB}$（A 为浓度 $c$ 保持恒定的分析物，B 为表面上的配体），响应 $R$ 正比于 $[\ce{AB}]$，最大响应 $R_{\max}$ 对应全部配体被占据：

$$
\frac{\mathrm{d}R}{\mathrm{d}t} = k_{\mathrm{a}}c(R_{\max} - R) - k_{\mathrm{d}}R. \tag{9.7}
$$
由于分析物不断流入、浓度恒定，结合阶段是**准一级反应**，从 $R(0) = 0$ 积分得

$$
R(t) = R_{\mathrm{eq}}\left(1 - \mathrm{e}^{-k_{\mathrm{obs}}t}\right), \qquad k_{\mathrm{obs}} = k_{\mathrm{a}}c + k_{\mathrm{d}}, \qquad R_{\mathrm{eq}} = \frac{R_{\max}c}{c + K_{\mathrm{D}}};
$$
解离阶段（$c = 0$）$R(t) = R_0\mathrm{e}^{-k_{\mathrm{d}}(t - t_0)}$。平衡解离常数 $K_{\mathrm{D}} = k_{\mathrm{d}}/k_{\mathrm{a}}$。测几个浓度，由 $k_{\mathrm{obs}}$ 对 $c$ 作直线（斜率 $k_{\mathrm{a}}$、截距 $k_{\mathrm{d}}$），或对全部传感图做全局非线性拟合，就同时得到 $k_{\mathrm{a}}$、$k_{\mathrm{d}}$ 与 $K_{\mathrm{D}}$；由不同浓度的 $R_{\mathrm{eq}}$ 拟合 Langmuir 型的结合等温式，也能独立求 $K_{\mathrm{D}}$。$K_{\mathrm{D}}$ 相同的两个药物，解离慢（$k_{\mathrm{d}}$ 小、停留时间 $1/k_{\mathrm{d}}$ 长）的那个在体内往往作用更持久，这是平衡测定得不到的信息。实际数据还要考虑分析物向表面的传质限制、非特异性吸附与多价结合，它们使传感图偏离单指数形式。

![SPR 传感图（模拟数据）：1:1 结合，ka = 1.0×10⁵ L mol⁻¹ s⁻¹、kd = 1.0×10⁻³ s⁻¹（KD = 10 nmol/L）；0–300 s 注入五个浓度的分析物，之后换回缓冲液解离；曲线为五条传感图的全局最小二乘拟合](./plots/spr-sensorgram.py)

### 9.6.3. 局域表面等离子体共振

尺寸远小于光波长的金、银纳米颗粒中，光的电场直接驱动整个颗粒中的自由电子相对于正离子骨架集体振荡，在共振频率处产生很强的吸收与散射。直径约 $10$–$20\,\mathrm{nm}$ 的球形金纳米颗粒的 LSPR 吸收峰在约 $520\,\mathrm{nm}$，$\varepsilon$ 可达 $10^8$–$10^9\,\mathrm{L\,mol^{-1}\,cm^{-1}}$（按颗粒计），所以金溶胶呈酒红色。共振波长随颗粒的大小、形状（纳米棒有横向与纵向两个共振峰，后者可调到近红外）、周围介质的折射率与颗粒间距而变：

- 颗粒聚集时相邻颗粒的等离激元耦合，吸收峰红移、展宽，溶液由红变紫蓝。用寡核苷酸修饰的金纳米颗粒与目标 DNA 杂交而聚集，就是颜色可以直接看出的核酸检测；侧向层析试纸（早孕试纸、抗原快速检测试剂）上的红线也是被抗体捕获的金纳米颗粒。
- 颗粒附近的局域电场被极大增强，这是**表面增强 Raman 散射**的基础（[6.4.11](/6.4.11#def-11.5.8)）。

古罗马的 Lycurgus 杯（公元 4 世纪）含有金银合金纳米颗粒，在反射光下呈绿色，透射光下呈红色，是人类最早（不自觉地）利用 LSPR 的例子；中世纪教堂彩色玻璃的红色也来自金纳米颗粒。

### 9.6.4. 圆二色谱

**线偏振光**可以分解为振幅相等、旋转方向相反的左旋与右旋**圆偏振光**（[5.4.3](/5.4.3#sec-3.1.3)）。**手性**分子对两者的折射率不同（这就是**旋光性**，[5.4.3](/5.4.3#sec-3.9)），在吸收带内对两者的吸收也不同。

**定义 9.6.2** 手性物质对左旋与右旋圆偏振光的摩尔吸收系数不相等的性质称为圆二色性；以 $\Delta\varepsilon = \varepsilon_{\mathrm{L}} - \varepsilon_{\mathrm{R}}$（或与之成正比的椭圆度）对波长作图得到的光谱称为**圆二色谱**（CD 光谱）。

由于两个圆偏振分量被吸收的程度不同，透射光的两个分量振幅不再相等，合成的是**椭圆偏振光**。椭圆的短轴与长轴之比的反正切称为椭圆度 $\theta$。对很小的 $\Delta A = A_{\mathrm{L}} - A_{\mathrm{R}}$，$\theta = \frac{\ln 10}{4}\Delta A$（弧度），即 $\theta/\mathrm{deg} = 32.98\,\Delta A$。

**定义 9.6.3** 以物质的量浓度归一化的椭圆度称为**摩尔椭圆度**：

$$
[\theta] = \frac{100\,\theta}{cb}, \qquad [\theta] = 3298\,\Delta\varepsilon, \tag{9.8}
$$
其中 $\theta$ 以度为单位，$c$ 以 $\mathrm{mol\,L^{-1}}$、光程 $b$ 以 $\mathrm{cm}$ 为单位，$[\theta]$ 的单位为 $\mathrm{deg\,cm^2\,dmol^{-1}}$（$\Delta\varepsilon$ 以 $\mathrm{L\,mol^{-1}\,cm^{-1}}$ 为单位）。

$\Delta\varepsilon$ 可正可负，所以圆二色谱有正峰也有负峰；一对**对映体**的 CD 谱互为镜像。CD 只出现在手性分子的吸收带内，比通常的吸收光谱更能反映生色团所处的不对称环境，用来推断有机分子的绝对构型与构象。旋光度随波长的变化（旋光色散，ORD）在吸收带附近出现 S 形的异常（Cotton 效应），它与 CD 是同一现象的色散与吸收两面，二者由 Kramers–Kronig 关系相联系；现代工作主要用 CD。

圆二色光谱仪用光弹调制器以约 $50\,\mathrm{kHz}$ 的频率在左旋与右旋圆偏振光之间切换，检测透射光强的交变分量。$\Delta A$ 通常只有 $10^{-5}$–$10^{-3}$，比 $A$ 小三四个数量级，所以要求高光通量：远紫外测量要通氮气（氧气在 $200\,\mathrm{nm}$ 以下吸收），用短光程（$0.1$–$1\,\mathrm{mm}$）与低吸收的缓冲液（磷酸盐、氟化物，避免高浓度的氯离子、咪唑与 Tris）。

### 9.6.5. 蛋白质与核酸的圆二色谱

在远紫外区（$180$–$250\,\mathrm{nm}$），蛋白质的 CD 来自肽键的 $\mathrm{n}\to\pi^*$ 与 $\pi\to\pi^*$ 跃迁。肽键本身不是手性的，但在规则的二级结构中，许多肽键按一定的手性几何排列，它们的跃迁相互耦合，产生特征的 CD 谱（按平均残基浓度计算的摩尔椭圆度）：

| 二级结构 | 正峰 | 负峰 |
|---|---|---|
| α 螺旋 | $192\,\mathrm{nm}$（强） | $208\,\mathrm{nm}$ 与 $222\,\mathrm{nm}$（双负峰，$[\theta]_{222} \approx -3.5\times10^4\,\mathrm{deg\,cm^2\,dmol^{-1}}$） |
| β 折叠 | $195$–$198\,\mathrm{nm}$ | $215$–$218\,\mathrm{nm}$（较弱） |
| 无规卷曲 | 约 $218\,\mathrm{nm}$（很弱） | 约 $198\,\mathrm{nm}$（强） |

![三种基本二级结构的远紫外 CD 谱（按特征峰位置示意）：α 螺旋在 208 与 222 nm 有双负峰、192 nm 有强正峰；β 折叠在约 217 nm 有负峰；无规卷曲在约 198 nm 有强负峰](./plots/cd-secondary-structure.py)

一个蛋白质的 CD 谱近似是各种二级结构参考谱按其含量的线性组合，用**最小二乘法**（或带约束的拟合算法，如 CONTIN、BeStSel）分解，就得到 α 螺旋、β 折叠等的含量；α 螺旋含量的估计较准，β 折叠与转角较粗。CD 只需几十微克蛋白、几分钟测量、不要求结晶，因此常用于：确认重组蛋白是否正确折叠、比较突变体与野生型、监测 $222\,\mathrm{nm}$ 处 $[\theta]$ 随温度或变性剂浓度的变化以得到解折叠曲线与热稳定性。近紫外区（$250$–$320\,\mathrm{nm}$）的 CD 来自芳香侧链与二硫键所处的不对称环境，反映三级结构。

核酸的 CD 来自碱基的螺旋堆积：B 型 DNA 在约 $275\,\mathrm{nm}$ 有正峰、$245\,\mathrm{nm}$ 有负峰；A 型（RNA 双链）在 $260\,\mathrm{nm}$ 有强正峰、$210\,\mathrm{nm}$ 有负峰；左手螺旋的 Z 型 DNA 的谱近似反转。平行 G-四链体在约 $264\,\mathrm{nm}$ 有正峰、$240\,\mathrm{nm}$ 有负峰。CD 因此是判断核酸构象转变与药物–核酸结合方式的简便手段。

## 小结

| 内容 | 要点 |
|---|---|
| 跃迁类型 | $\sigma\to\sigma^*$（真空紫外）、$\mathrm{n}\to\sigma^*$、$\pi\to\pi^*$（强，$\varepsilon \ge 10^4$）、$\mathrm{n}\to\pi^*$（弱，$\varepsilon < 10^3$）；d–d（弱）、电荷转移（强，$10^3$–$10^5$） |
| 结构与光谱 | 共轭越大越红移增色；助色团 n–π 共轭；极性溶剂使 $\pi\to\pi^*$ 红移、$\mathrm{n}\to\pi^*$ 蓝移 |
| 生物大分子 | 蛋白质 $280\,\mathrm{nm}$（Trp、Tyr），核酸 $260\,\mathrm{nm}$，$A_{260}/A_{280} \approx 1.8$；DNA 解链的增色效应 |
| 吸收定律 | $A = -\lg\tau = \varepsilon bc$，$\varepsilon = N_{\mathrm{A}}\sigma/(1000\ln10)$，$\varepsilon_{\max} \sim 10^5$；具有加和性 |
| 偏离 | 非单色光、杂散光、化学平衡（等吸收点）、高浓度、散射 |
| 仪器 | 氘灯 + 钨灯，光栅，石英池，PMT 或二极管阵列；单光束、双光束、双波长 |
| 测量误差 | $\Delta c/c = 0.434\Delta\tau/(\tau\lg\tau)$，$\Delta\tau$ 恒定时最佳 $A = 0.434$，适宜范围 $0.2$–$0.8$ |
| 应用 | 多组分（线性方程组 / 最小二乘），摩尔比法与 Job 法（$x_{\max} = n/(n+1)$），$\mathrm{p}K_{\mathrm{a}} = \mathrm{pH} + \lg\frac{A_{\mathrm{B}} - A}{A - A_{\mathrm{HB}}}$ |
| SPR | 倏逝波激发表面等离激元，共振角反映表面折射率；$\mathrm{d}R/\mathrm{d}t = k_{\mathrm{a}}c(R_{\max} - R) - k_{\mathrm{d}}R$，$K_{\mathrm{D}} = k_{\mathrm{d}}/k_{\mathrm{a}}$ |
| CD | $\Delta\varepsilon = \varepsilon_{\mathrm{L}} - \varepsilon_{\mathrm{R}}$，$[\theta] = 3298\Delta\varepsilon$；α 螺旋 $208$、$222\,\mathrm{nm}$ 双负峰 |

紫外–可见光谱在有机结构解析中的作用（由吸收带判断共轭体系与生色团、Woodward–Fieser 规则）在 6.5 有机化学的波谱一章中结合红外、核磁与质谱综合讲解。

## 思考题

1. 例 9.3.1 估计普通分光光度法可测浓度的下限约为 $4.4\times10^{-8}\,\mathrm{mol\,L^{-1}}$。可以从哪些方面突破这一限制？

   **答** 由 $c_{\min} = A_{\min}/(\varepsilon b)$，(1) 增大 $\varepsilon$：选用灵敏的显色剂或多元配合物，用金纳米颗粒等摩尔吸收系数极大的标记物，或用酶催化把一个被测分子放大为大量有色产物（酶联免疫吸附分析）；(2) 增大光程：长光程液芯波导、多次反射池、光腔衰荡（9.5.5）；(3) 减小 $A_{\min}$：稳定光源、双光束补偿、锁相检测降低噪声，或改测吸收产生的热（光声、热透镜）；(4) 预先富集：萃取、离子交换、固相萃取使浓度提高几个数量级；(5) 改用在暗背景上检测的方法，如荧光与化学发光（[6.4.10](/6.4.10)）。
2. 为什么紫外区测定要用石英吸收池？用乙醇作溶剂时能否测 $205\,\mathrm{nm}$ 的吸收？

   **答** 普通玻璃在约 $350\,\mathrm{nm}$ 以下强烈吸收，石英透明到约 $190\,\mathrm{nm}$。乙醇的截止波长约 $210\,\mathrm{nm}$，在 $205\,\mathrm{nm}$ 吸收已很强，参比与试样的透射光都很弱，杂散光与噪声使测量不可靠；应改用水或乙腈。
3. 一个化合物在正己烷中 $\lambda_{\max} = 300\,\mathrm{nm}$（$\varepsilon = 40$），在乙醇中移到 $290\,\mathrm{nm}$。这是什么类型的跃迁？

   **答** $\varepsilon$ 很小且极性质子性溶剂使吸收蓝移，是羰基等含杂原子生色团的 $\mathrm{n}\to\pi^*$ 跃迁。
4. 用双光束仪器能否消除浑浊试样的背景？双波长法为什么能？

   **答** 双光束仪器的参比光束只通过参比池，不能补偿试样本身的散射；双波长法让两个波长通过同一试样，散射在相近波长上近似相等，在 $\Delta A$ 中相消。
