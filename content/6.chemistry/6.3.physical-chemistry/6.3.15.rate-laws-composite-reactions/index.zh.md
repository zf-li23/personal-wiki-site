title: 速率方程与复合反应
---

[6.1.7](/6.1.7) 给出了化学动力学的框架：**反应速率**、**速率方程**、**基元反应**与**反应机理**、一级与二级反应的积分式、**Arrhenius 方程**与**前平衡近似**。本章把这个框架系统化、定量化。一个反应机理就是一组关于各物种浓度的常微分方程，化学动力学的"唯象"部分归根到底是求解与近似求解这组方程（[2.4](/2.4)）：简单级数反应的积分式（15.2）与由实验数据反求级数（15.3）是最简单的情形；对峙、平行、连续三类典型复合反应（15.4）是线性方程组，可以用**矩阵指数**统一处理；温度的影响与**微观可逆性原理**（15.5）把动力学与 [6.3.7](/6.3.7) 的化学平衡联系起来；当方程组非线性、无法求出解析解时，速控步、**稳态近似**与前平衡近似（15.6）利用时间尺度的悬殊消去中间物，这正是机理推导（15.7 链反应、15.8 机理的拟定）的主要工具；最后，快速反应的弛豫方法（15.9）是平衡点附近线性化的直接应用。

下一章（[6.3.16](/6.3.16)）从分子性质计算速率常数，[6.3.17](/6.3.17) 讨论溶剂、光与催化剂的影响，[6.3.18](/6.3.18) 的化学振荡与耗散结构则建立在本章的非线性速率方程之上。本章沿用站内记号：反应速率 $v$（不少教材写 $r$），速率常数 $k$，逆反应的速率常数一律写 $k_{-1}$，$[\ce{B}]$ 与 $c_{\mathrm{B}}$ 都表示浓度。

## 15.1. 基本概念

### 15.1.1. 反应速率的表示

对反应 $0 = \sum_{\mathrm{B}}\nu_{\mathrm{B}}\mathrm{B}$，单位时间内**反应进度**的变化 $\dot\xi = \mathrm{d}\xi/\mathrm{d}t$ 称为转化速率；恒容时除以体积得到**反应速率**（[6.1.7](/6.1.7#def-7.1.2)）

$$
v = \frac{1}{V}\frac{\mathrm{d}\xi}{\mathrm{d}t} = \frac{1}{\nu_{\mathrm{B}}}\frac{\mathrm{d}c_{\mathrm{B}}}{\mathrm{d}t}.
$$

它与选用哪种物质无关，但与计量方程的写法有关。对复杂反应，这一关系只在中间物的浓度可以忽略时成立：若中间物积累，各物质的 $\frac{1}{\nu_{\mathrm{B}}}\frac{\mathrm{d}c_{\mathrm{B}}}{\mathrm{d}t}$ 在某一时刻并不相等。实验上常用某一物质的消耗速率 $-\mathrm{d}c_{\mathrm{A}}/\mathrm{d}t = \lvert\nu_{\mathrm{A}}\rvert v$ 写速率方程，由此定义的速率常数 $k_{\mathrm{A}} = \lvert\nu_{\mathrm{A}}\rvert k$；看到一个速率常数时要先弄清它对应哪种定义。

气相反应也可以用分压表示，$v_p = \frac{1}{\nu_{\mathrm{B}}}\frac{\mathrm{d}p_{\mathrm{B}}}{\mathrm{d}t}$。理想气体 $p_{\mathrm{B}} = c_{\mathrm{B}}RT$，等温下 $v_p = vRT$；对 $n$ 级反应 $v = k_cc^n$、$v_p = k_pp^n$，代入得

$$
k_p = k_c(RT)^{1-n}.
$$

一级反应 $k_p = k_c$，二级反应 $k_c = k_pRT$。多相催化反应的速率与催化剂的用量成正比，常以单位质量、单位体积或单位表面积的催化剂表示：$\frac{1}{m}\dot\xi$、$\frac{1}{V}\dot\xi$、$\frac{1}{A_{\mathrm{s}}}\dot\xi$（[6.3.20](/6.3.20)）。

### 15.1.2. 动力学曲线的测定

反应物或产物的浓度随时间变化的曲线称为动力学曲线，速率是它的切线斜率（除以计量数）。测定方法有两类：

- 化学方法：定时取样，用骤冷、稀释、加入阻化剂或除去催化剂等办法使反应停止，再做化学分析。简单，但难以连续、快速。
- 物理方法：测定与浓度有定量关系的物理量（旋光度、折射率、电导率、电动势、介电常数、黏度、吸光度，或 IR、UV-Vis、EPR、NMR、XPS 等谱学信号）随时间的变化。可以连续、原位测量，不干扰反应。

测定反应开始时的速率（初始速率）时，产物与副反应的干扰最小，这是**初始速率法**的依据。混合需要时间（常规操作约 $1\,\mathrm{s}$），半衰期短于此的快速反应要用特殊方法（15.9）。

### 15.1.3. 基元反应与总反应

[6.1.7](/6.1.7#def-7.3.2) 定义了**基元反应**、**复杂反应**、**反应机理**与**反应分子数**。只包含一个基元反应的反应称为简单反应，如丁二烯与乙烯的 Diels–Alder 加成生成环己烯；一般的化学计量方程只是总反应（总包反应），表示参与反应的物质之间量的关系，不表示反应怎样发生。三个计量式相似的反应

$$
\ce{H2 + I2 -> 2HI}, \qquad \ce{H2 + Cl2 -> 2HCl}, \qquad \ce{H2 + Br2 -> 2HBr}
$$
的机理与速率方程完全不同（M 是只传递能量的第三体，可以是任何分子或器壁）：

| 反应 | 机理 | 实验速率方程 |
|---|---|---|
| $\ce{H2 + I2}$ | $\ce{I2 + M <=> 2I + M}$（快）；$\ce{H2 + 2I -> 2HI}$（慢） | $v = k[\ce{H2}][\ce{I2}]$ |
| $\ce{H2 + Cl2}$ | $\ce{Cl2 + M -> 2Cl + M}$；$\ce{Cl + H2 -> HCl + H}$；$\ce{H + Cl2 -> HCl + Cl}$；$\ce{2Cl + M -> Cl2 + M}$ | $v = k[\ce{H2}][\ce{Cl2}]^{1/2}$ |
| $\ce{H2 + Br2}$ | 同上，另有 $\ce{H + HBr -> H2 + Br}$ | $v = \dfrac{k[\ce{H2}][\ce{Br2}]^{1/2}}{1 + k'[\ce{HBr}]/[\ce{Br2}]}$ |

后两个是链反应，它们的速率方程将在 15.7 中由机理推出。基元反应的写法是唯一的（$\ce{2I -> I2}$ 不能写成 $\ce{I -> 1/2I2}$），双分子反应最常见，三分子反应很少，四分子以上的基元反应尚未发现。

## 15.2. 简单级数反应

### 15.2.1. 速率方程与级数

[6.1.7](/6.1.7#def-7.3.1) 定义了幂函数形式的速率方程 $v = kc_{\mathrm{A}}^{\alpha}c_{\mathrm{B}}^{\beta}\cdots$、**反应级数** $n = \alpha + \beta + \cdots$ 与**速率常数**；对基元反应，**质量作用定律**给出级数等于计量系数。两点补充：

1. 质量作用定律对理想体系成立；非理想溶液中更准确的形式是 $v = ka_{\mathrm{A}}^{\alpha}a_{\mathrm{B}}^{\beta}$（**活度**），或者把活度因子并入速率常数（[6.3.17](/6.3.17) 的原盐效应就是这样处理的）。
2. 级数是经验量，可以是整数、分数、零或负数，也可以根本不存在（如 $\ce{H2 + Br2}$）。级数与反应分子数是两个概念：前者针对速率方程，后者针对基元反应，只对基元反应两者在数值上相等。

速率常数的单位由级数决定：$n$ 级反应的 $k$ 的单位是 $(\mathrm{mol\,L^{-1}})^{1-n}\,\mathrm{s^{-1}}$。

### 15.2.2. $n$ 级反应的积分式

只有一种反应物（或各反应物的浓度按计量比配料）时，速率方程为 $-\frac{\mathrm{d}c}{\mathrm{d}t} = kc^n$。零级、一级、二级的积分式见 [6.1.7](/6.1.7#sec-7.3.2)，一般情形如下。

**公式 15.2.1（$n$ 级反应）** 设 $-\frac{\mathrm{d}c}{\mathrm{d}t} = kc^n$，$c(0) = c_0$，$n \ne 1$。分离变量积分得

$$
\frac{1}{c^{n-1}} - \frac{1}{c_0^{n-1}} = (n-1)kt, \qquad t_{1/2} = \frac{2^{n-1} - 1}{(n-1)kc_0^{n-1}}.
$$

$n \to 1$ 时 $\frac{2^{n-1}-1}{n-1} \to \ln 2$，回到一级反应 $t_{1/2} = \ln 2/k$。半衰期与初始浓度的关系 $t_{1/2} \propto c_0^{1-n}$ 是判断级数的简便依据：一级反应与 $c_0$ 无关，二级反应与 $c_0$ 成反比，零级反应与 $c_0$ 成正比。

二级反应 $\ce{A + B -> P}$ 的初始浓度 $a \ne b$ 时，$\frac{\mathrm{d}x}{\mathrm{d}t} = k(a-x)(b-x)$，用部分分式积分得

$$
\frac{1}{a-b}\ln\frac{b(a-x)}{a(b-x)} = kt,
$$
即 $\ln\frac{c_{\mathrm{A}}}{c_{\mathrm{B}}}$ 对 $t$ 是斜率为 $(a-b)k$ 的直线。这时不存在对整个反应统一的半衰期，A 与 B 各有自己的半衰期。

**定义 15.2.1（三级反应）** 速率与浓度的三次方成正比的反应称为**三级反应**。气相中典型的例子是 NO 参与的反应 $\ce{2NO + O2 -> 2NO2}$、$\ce{2NO + Cl2 -> 2NOCl}$，以及原子在第三体参与下的复合 $\ce{I + I + M -> I2 + M}$。

三种反应物初始浓度相同时，$-\frac{\mathrm{d}c}{\mathrm{d}t} = kc^3$，由公式 15.2.1（$n = 3$）得

$$
\frac{1}{2c^2} - \frac{1}{2c_0^2} = kt, \qquad t_{1/2} = \frac{3}{2kc_0^2}.
$$

$\ce{2NO + O2}$ 的速率常数随温度升高而减小，它不是基元的三分子反应，15.5.4 将用前平衡解释这一点。

### 15.2.3. 例题

**例 15.2.1（用总压跟踪的一级反应）** 恒容容器中进行气相一级反应 $\ce{A(g) -> B(g) + C(g)}$，开始时只有 A，压力 $p_0 = 101.325\,\mathrm{kPa}$。求总压 $p$ 随时间的变化。

**解** $t$ 时刻 $p_{\mathrm{A}} = p_0 - x$，$p_{\mathrm{B}} = p_{\mathrm{C}} = x$，总压 $p = p_0 + x$，所以 $p_{\mathrm{A}} = 2p_0 - p$。一级反应 $k_p = k_c = k$，$\ln\frac{p_{\mathrm{A}}}{p_0} = -kt$，即

$$
\ln\frac{2p_0 - p}{p_0} = -kt, \qquad p = p_0\left(2 - \mathrm{e}^{-kt}\right).
$$
以 $\ln(2p_0 - p)$ 对 $t$ 作图得直线，斜率为 $-k$。用总压跟踪反应的前提是反应前后气体分子数不同，且没有副反应。

**例 15.2.2（$\ce{N2O}$ 的热分解）** $\ce{2N2O(g) -> 2N2(g) + O2(g)}$ 的半衰期与初始压力成反比。$970\,\mathrm{K}$ 时 $p_0 = 39.2\,\mathrm{kPa}$，$t_{1/2} = 1529\,\mathrm{s}$；$1030\,\mathrm{K}$ 时 $p_0 = 48.0\,\mathrm{kPa}$，$t_{1/2} = 212\,\mathrm{s}$。(1) 求两温度下的 $k_p$（以 $-\mathrm{d}p_{\ce{N2O}}/\mathrm{d}t = k_pp_{\ce{N2O}}^2$ 定义）；(2) 求活化能；(3) $1030\,\mathrm{K}$、$p_0 = 53.3\,\mathrm{kPa}$ 时，总压达到 $64.0\,\mathrm{kPa}$ 需要多长时间？

**解** (1) $t_{1/2} \propto 1/p_0$ 说明是二级反应，$t_{1/2} = 1/(k_pp_0)$：

$$
k_p(970\,\mathrm{K}) = \frac{1}{1529 \times 39.2 \times 10^3}\,\mathrm{Pa^{-1}\,s^{-1}} = 1.67 \times 10^{-8}\,\mathrm{Pa^{-1}\,s^{-1}}, \qquad k_p(1030\,\mathrm{K}) = 9.83 \times 10^{-8}\,\mathrm{Pa^{-1}\,s^{-1}}.
$$
换成浓度表示，$k_c = k_pRT = 9.83 \times 10^{-8} \times 8.314 \times 1030\,\mathrm{m^3\,mol^{-1}\,s^{-1}} = 0.84\,\mathrm{L\,mol^{-1}\,s^{-1}}$（$1030\,\mathrm{K}$）。

(2) $k_c = k_pRT$ 中的因子 $T$ 使两种速率常数的活化能相差 $RT$；按 $k_p$ 计算，

$$
E_{\mathrm{a}} \approx R\,\frac{\ln(k_2/k_1)}{1/T_1 - 1/T_2} = 8.314 \times \frac{\ln(9.83/1.67)}{1/970 - 1/1030}\,\mathrm{J\,mol^{-1}} = 245\,\mathrm{kJ\,mol^{-1}},
$$
与 [6.1.7](/6.1.7#sec-7.3.4) 表中非催化 $\ce{N2O}$ 分解的活化能一致（按 $k_c$ 计算再加约 $RT \approx 8\,\mathrm{kJ\,mol^{-1}}$，在数据精度之内）。

(3) 消耗 $\ce{N2O}$ 的分压为 $y$ 时，生成 $\ce{N2}$ $y$、$\ce{O2}$ $y/2$，总压 $p = p_0 + y/2$。$p = 64.0\,\mathrm{kPa}$ 时 $y = 21.4\,\mathrm{kPa}$，$p_{\ce{N2O}} = 31.9\,\mathrm{kPa}$。由二级反应的积分式

$$
t = \frac{1}{k_p}\left(\frac{1}{p_{\ce{N2O}}} - \frac{1}{p_0}\right) = \frac{1}{9.83 \times 10^{-8}}\left(\frac{1}{31.9 \times 10^3} - \frac{1}{53.3 \times 10^3}\right)\,\mathrm{s} = 128\,\mathrm{s}.
$$

### 15.2.4. 总结

| 级数 | 微分式 | 积分式 | 线性关系 | $t_{1/2}$ | $k$ 的单位 |
|---|---|---|---|---|---|
| 0 | $-\dot c = k$ | $c = c_0 - kt$ | $c$–$t$ | $\frac{c_0}{2k}$ | $\mathrm{mol\,L^{-1}\,s^{-1}}$ |
| 1 | $-\dot c = kc$ | $\ln\frac{c_0}{c} = kt$ | $\ln c$–$t$ | $\frac{\ln 2}{k}$ | $\mathrm{s^{-1}}$ |
| 2 | $-\dot c = kc^2$ | $\frac1c - \frac1{c_0} = kt$ | $\frac1c$–$t$ | $\frac{1}{kc_0}$ | $\mathrm{L\,mol^{-1}\,s^{-1}}$ |
| 3 | $-\dot c = kc^3$ | $\frac{1}{2c^2} - \frac{1}{2c_0^2} = kt$ | $\frac{1}{c^2}$–$t$ | $\frac{3}{2kc_0^2}$ | $\mathrm{L^2\,mol^{-2}\,s^{-1}}$ |
| $n$ | $-\dot c = kc^n$ | $\frac{1}{c^{n-1}} - \frac{1}{c_0^{n-1}} = (n-1)kt$ | $\frac{1}{c^{n-1}}$–$t$ | $\frac{2^{n-1}-1}{(n-1)kc_0^{n-1}}$ | $(\mathrm{mol\,L^{-1}})^{1-n}\,\mathrm{s^{-1}}$ |

零级反应在 $t = c_0/k$ 时结束，其余各级反应在有限时间内都不能进行到底。

## 15.3. 反应级数的测定

确定速率方程就是确定级数与速率常数。实验方案有两种：用一个样品测 $c$–$t$ 曲线，或用一组初始浓度不同的样品；数据处理也有两种：用积分式或用微分式。

### 15.3.1. 积分法与半衰期法

**定义 15.3.1** 以速率方程的积分式为依据确定级数的方法称为**积分法**：作图法把数据按表中各级的线性关系作图，得到直线的那一级即为所求，斜率给出 $k$；尝试法把数据代入各级积分式计算 $k$，$k$ 为常数的那一级即为所求（两者实质相同）。利用半衰期与初始浓度的关系 $t_{1/2} = Bc_0^{1-n}$ 确定级数的方法称为**半衰期法**：

$$
\lg t_{1/2} = (1-n)\lg c_0 + \lg B,
$$
$\lg t_{1/2}$ 对 $\lg c_0$ 作图，斜率为 $1-n$；只有两组数据时 $n = 1 + \frac{\lg(t_{1/2}/t_{1/2}')}{\lg(c_0'/c_0)}$。

积分法要求先猜出级数，数据范围不宽时几种级数可能都"近似成直线"，分数级数也难以判断。半衰期法不必猜，而且可以用同一条 $c$–$t$ 曲线：从不同的起点读出浓度降到一半、再降到一半……所需的时间，每段都可以看作一个初始浓度不同的实验。

### 15.3.2. 微分法与初始速率法

**定义 15.3.2** 以速率方程的微分式为依据确定级数的方法称为**微分法**：由 $c$–$t$ 曲线求出各时刻的速率 $v$，按

$$
\lg v = n\lg c + \lg k
$$
作 $\lg v$–$\lg c$ 图，斜率为 $n$，截距为 $\lg k$。

在一条曲线的不同点上求切线得到的是对时间的级数；若产物有阻滞或加速作用，它与按初始速率求得的对浓度的级数不同，后者才是"真"的级数。**初始速率法**（[6.1.7](/6.1.7#sec-7.3.1)）测一组初始浓度不同的样品的初始速率 $v_0 = kc_0^n$，由 $\lg v_0$–$\lg c_0$ 的斜率得 $n$；初始浓度成倍递增（"加倍法"）时，$v_0$ 不变、加倍、增至 4 倍分别对应 $n = 0, 1, 2$。微分法的困难在于求导会放大噪声，现在一般用平滑或拟合后的曲线求导，或直接拟合积分式（见 15.3.4 节）。

### 15.3.3. 孤立法

速率方程含几种反应物时，$v = kc_{\mathrm{A}}^{\alpha}c_{\mathrm{B}}^{\beta}c_{\mathrm{C}}^{\gamma}$ 是多元函数，要设法化为一元函数逐个测定分级数。

**定义 15.3.3** 使除 A 以外的反应物都大大过量（$c_{\mathrm{B},0}, c_{\mathrm{C},0} \gg c_{\mathrm{A},0}$），反应过程中它们的浓度近似不变，速率方程化为 $v = k'c_{\mathrm{A}}^{\alpha}$，$k' = kc_{\mathrm{B},0}^{\beta}c_{\mathrm{C},0}^{\gamma}$，从而单独测定 $\alpha$ 的方法称为**孤立法**（Ostwald 孤立法）。$\alpha = 1$ 时，这样得到的一级反应称为**准一级反应**。

蔗糖在大量水中的酸催化水解、酯在大量过量碱中的皂化都是准一级反应。改变过量物质 B 的浓度再测 $k'$，由 $\lg k'$–$\lg c_{\mathrm{B},0}$ 的斜率得 $\beta$。

**例 15.3.1** $298\,\mathrm{K}$ 时反应 $\ce{A + 2B -> P}$ 的两组实验：(1) $c_{\mathrm{A},0} = c_{\mathrm{B},0}/2 = 40\,\mathrm{mol\,m^{-3}}$，$c_{\mathrm{A}}$ 随时间线性下降，$t = 0, 2.5, 5.0, 7.5, 10\,\mathrm{min}$ 时 $c_{\mathrm{A}} = 40, 35, 30, 25, 20\,\mathrm{mol\,m^{-3}}$；(2) $c_{\mathrm{A},0} = c_{\mathrm{B},0}/200 = 40\,\mathrm{mol\,m^{-3}}$，A 每消耗一半所需的时间恒定。求速率方程 $-\frac{\mathrm{d}c_{\mathrm{A}}}{\mathrm{d}t} = kc_{\mathrm{A}}^{\alpha}c_{\mathrm{B}}^{\beta}$。

**解** 实验 (1) 按计量比配料，反应中始终有 $c_{\mathrm{B}} = 2c_{\mathrm{A}}$，速率方程化为 $-\frac{\mathrm{d}c_{\mathrm{A}}}{\mathrm{d}t} = 2^{\beta}kc_{\mathrm{A}}^{\alpha+\beta}$。$c_{\mathrm{A}}$–$t$ 为直线，所以 $\alpha + \beta = 0$，且 $2^{\beta}k = 2\,\mathrm{mol\,m^{-3}\,min^{-1}}$。实验 (2) 中 B 大大过量，$c_{\mathrm{B}} \approx 8000\,\mathrm{mol\,m^{-3}}$，是对 A 的孤立法；半衰期与浓度无关，$\alpha = 1$，于是 $\beta = -1$，$k = 4\,\mathrm{mol\,m^{-3}\,min^{-1}}$：

$$
-\frac{\mathrm{d}c_{\mathrm{A}}}{\mathrm{d}t} = (4\,\mathrm{mol\,m^{-3}\,min^{-1}})\,\frac{c_{\mathrm{A}}}{c_{\mathrm{B}}}.
$$
B 的级数为负，它对反应有阻滞作用；这样的速率方程说明反应不是基元反应。

### 15.3.4. 用拟合确定速率参数

线性化作图直观，但统计上并不理想。设测得的浓度带有大小大致恒定的绝对误差 $\sigma$，取对数后 $\ln c$ 的误差约为 $\sigma/c$：反应后期浓度小、误差被放大的点，在 $\ln c$–$t$ 的普通**最小二乘法**拟合中却与早期的点权重相同。$1/c$ 的变换更甚。更好的做法是直接对积分式 $c(t; k, n, c_0)$ 做**非线性回归**（[3.3](/3.3)），在 Python 中用 `scipy.optimize.curve_fit`（[4.4.4](/4.4.4#sec-4.2.3)），它同时给出参数的标准误；级数本身也可以作为一个待估参数。机理复杂、没有解析积分式时，把数值求解常微分方程（`solve_ivp`）嵌入拟合的目标函数即可，这是现代动力学数据处理的一般方法。15.6 与 [6.3.17](/6.3.17) 的 Michaelis–Menten 拟合是两个例子。

## 15.4. 典型复合反应

复杂反应的机理千差万别，但基元反应只有三种基本的组合方式：对峙、平行、连续。以下都以一级（1-1 级）反应为例，此时速率方程是线性的，可以严格求解。

### 15.4.1. 对峙反应

**定义 15.4.1** 正、逆两个方向都以显著速率进行的反应称为**对峙反应**（对行反应）。

1-1 级对峙反应 $\ce{A <=>[k_1][k_{-1}] B}$，$t = 0$ 时 $[\ce{A}] = a$、$[\ce{B}] = 0$，B 的浓度为 $x$：

$$
\frac{\mathrm{d}x}{\mathrm{d}t} = k_1(a - x) - k_{-1}x.
$$
平衡时 $\frac{\mathrm{d}x}{\mathrm{d}t} = 0$，$k_1(a - x_{\mathrm{eq}}) = k_{-1}x_{\mathrm{eq}}$，即 $x_{\mathrm{eq}} = \frac{k_1a}{k_1 + k_{-1}}$，于是速率方程可以写成 $\frac{\mathrm{d}x}{\mathrm{d}t} = (k_1 + k_{-1})(x_{\mathrm{eq}} - x)$，积分得

$$
\ln\frac{x_{\mathrm{eq}}}{x_{\mathrm{eq}} - x} = (k_1 + k_{-1})t. \tag{15.1}
$$

对峙反应趋向平衡的方式与一级反应相同，但"速率常数"是正、逆速率常数之和：偏离平衡的量 $x_{\mathrm{eq}} - x$ 以 $k_1 + k_{-1}$ 衰减。由 $\ln(x_{\mathrm{eq}} - x)$–$t$ 的斜率得 $k_1 + k_{-1}$，由平衡组成得 $\frac{k_1}{k_{-1}} = \frac{x_{\mathrm{eq}}}{a - x_{\mathrm{eq}}} = K$，两式联立解出 $k_1$、$k_{-1}$。当 $k_1 \gg k_{-1}$ 时，$x_{\mathrm{eq}} \approx a$，式 (15.1) 回到单向一级反应。

对峙反应 $\frac{k_1}{k_{-1}} = K$ 的关系（15.5.2 将一般地证明）把温度的影响也联系起来：$\frac{\mathrm{d}\ln(k_1/k_{-1})}{\mathrm{d}T} = \frac{\Delta_{\mathrm{r}}H^\circ_{\mathrm{m}}}{RT^2}$（溶液反应；气相反应把 $H$ 换成 $U$，见 15.5.2）。吸热反应升温时 $k_1$ 增加得比 $k_{-1}$ 多，平衡与速率都对正反应有利；放热反应升温虽然加快了反应，却使平衡转化率下降。

### 15.4.2. 平行反应

**定义 15.4.2** 反应物同时进行两个或两个以上不同的反应、生成不同的产物，称为**平行反应**（竞争反应）；生成所需产物的称为主反应，其余的称为副反应。

1-1 级平行反应 $\ce{A ->[k_1] B}$、$\ce{A ->[k_2] C}$，设 $[\ce{B}] = x$、$[\ce{C}] = y$：

$$
\frac{\mathrm{d}x}{\mathrm{d}t} = k_1(a - x - y), \qquad \frac{\mathrm{d}y}{\mathrm{d}t} = k_2(a - x - y), \qquad -\frac{\mathrm{d}(a - x - y)}{\mathrm{d}t} = (k_1 + k_2)(a - x - y).
$$
第三式说明 A 的消耗是速率常数为 $k_1 + k_2$ 的一级反应：$\ln\frac{a}{a - x - y} = (k_1 + k_2)t$。前两式相除得 $\frac{\mathrm{d}x}{\mathrm{d}y} = \frac{k_1}{k_2}$，积分得

$$
\frac{x}{y} = \frac{k_1}{k_2},
$$
即级数相同的平行反应在任何时刻产物浓度之比都等于速率常数之比。由 $\ln[\ce{A}]$–$t$ 的斜率得 $k_1 + k_2$，由产物比得 $k_1/k_2$。

要改变产物比，只能改变 $k_1/k_2$：$\frac{\mathrm{d}\ln(k_1/k_2)}{\mathrm{d}T} = \frac{E_{\mathrm{a},1} - E_{\mathrm{a},2}}{RT^2}$，升温有利于活化能大的反应（[6.1.7](/6.1.7#sec-7.3.3)）；或者用选择性的催化剂（[6.3.17](/6.3.17)）改变其中一个反应的速率常数。两个平行反应的级数不同时，反应物浓度也会影响产物比。

### 15.4.3. 连续反应

**定义 15.4.3** 前一步的产物是后一步的反应物、依次进行的反应称为**连续反应**（连串反应）。

1-1 级连续反应 $\ce{A ->[k_1] B ->[k_2] C}$，$t = 0$ 时只有 A（浓度 $a$），$[\ce{A}] = x$、$[\ce{B}] = y$、$[\ce{C}] = z$，$x + y + z = a$：

$$
-\frac{\mathrm{d}x}{\mathrm{d}t} = k_1x, \qquad \frac{\mathrm{d}y}{\mathrm{d}t} = k_1x - k_2y, \qquad \frac{\mathrm{d}z}{\mathrm{d}t} = k_2y.
$$
第一式给出 $x = a\mathrm{e}^{-k_1t}$；代入第二式得一阶线性方程 $\dot y + k_2y = k_1a\mathrm{e}^{-k_1t}$，用常数变易法（[2.4.3](/2.4.3)）解得（$k_1 \ne k_2$）

$$
y = \frac{k_1a}{k_2 - k_1}\left(\mathrm{e}^{-k_1t} - \mathrm{e}^{-k_2t}\right), \qquad z = a\left(1 - \frac{k_2}{k_2 - k_1}\mathrm{e}^{-k_1t} + \frac{k_1}{k_2 - k_1}\mathrm{e}^{-k_2t}\right).
$$

中间物 B 的浓度先增后减。令 $\frac{\mathrm{d}y}{\mathrm{d}t} = 0$，得到它的极大值：

$$
t_{\max} = \frac{\ln(k_2/k_1)}{k_2 - k_1}, \qquad y_{\max} = a\left(\frac{k_1}{k_2}\right)^{k_2/(k_2 - k_1)}.
$$
$k_1 = k_2$ 时取极限，$y = k_1at\,\mathrm{e}^{-k_1t}$，$t_{\max} = 1/k_1$，$y_{\max} = a/\mathrm{e}$。若 B 是所需产物，应在 $t_{\max}$ 附近终止反应。产物 C 的生成曲线在开始时有一段诱导期：B 积累起来之前 C 几乎不生成。

![1-1 级连续反应 A → B → C 的浓度曲线（用矩阵指数计算），k2/k1 = 0.2、1、5、50，圆点标出中间物的极大值；k2 ≫ k1 时 B 始终很少，其浓度近似处于稳态](./plots/consecutive-reactions.py)

两步速率常数相差悬殊时：

- $k_1 \ll k_2$：$y \approx \frac{k_1}{k_2}a\mathrm{e}^{-k_1t}$，产物的生成速率 $k_2y \approx k_1a\mathrm{e}^{-k_1t}$，由第一步决定；
- $k_2 \ll k_1$：A 很快全部变成 B，此后 $\frac{\mathrm{d}z}{\mathrm{d}t} \approx k_2a\mathrm{e}^{-k_2t}$，由第二步决定。

总速率由最慢的一步决定，这一步就是**速控步**（[6.1.7](/6.1.7#sec-7.3.1)），如同管道中的"瓶颈"。

### 15.4.4. 统一处理：线性方程组与矩阵指数

三类反应以及任何由一级反应组成的网络，都可以写成浓度向量 $\boldsymbol{c}$ 的线性常系数方程组 $\dot{\boldsymbol{c}} = K\boldsymbol{c}$，其解为 $\boldsymbol{c}(t) = \mathrm{e}^{tK}\boldsymbol{c}(0)$（**矩阵指数**，[2.4.8](/2.4.8#def-8.4.1)）。例如连续反应

$$
\frac{\mathrm{d}}{\mathrm{d}t}\begin{bmatrix}x\\y\\z\end{bmatrix} = \begin{bmatrix}-k_1&0&0\\k_1&-k_2&0\\0&k_2&0\end{bmatrix}\begin{bmatrix}x\\y\\z\end{bmatrix},
$$
速率矩阵 $K$ 的**特征值**为 $0, -k_1, -k_2$，所以解是 $1$、$\mathrm{e}^{-k_1t}$、$\mathrm{e}^{-k_2t}$ 的线性组合（[2.4.8](/2.4.8#sec-8.5)），这正是上面的结果；$k_1 = k_2$ 时特征值重合、矩阵不可对角化，解中出现 $t\mathrm{e}^{-k_1t}$。一般地，$K$ 的每一列之和为零（物质守恒），因而 0 总是特征值，对应的特征向量是平衡组成；其余特征值的实部为负（满足 15.5.2 的细致平衡时还都是实数），它们的倒数给出系统趋向平衡的各个时间尺度。对峙反应的 $K = \begin{bmatrix}-k_1&k_{-1}\\k_1&-k_{-1}\end{bmatrix}$ 的非零特征值 $-(k_1 + k_{-1})$ 就是式 (15.1) 的衰减速率。这一观点在 15.6（时间尺度分离）与 15.9（弛豫）中还要用到。数值上，`scipy.linalg.expm` 直接计算矩阵指数（上图即如此）。

## 15.5. 温度的影响与活化能

### 15.5.1. 速率与温度关系的几种类型

**van 't Hoff 规则**、**Arrhenius 方程**、**活化能**与 Tolman 对活化能的统计解释见 [6.1.7](/6.1.7#sec-7.3.3)。Arrhenius 方程在不太宽的温度范围内适用于大多数反应；碰撞理论与过渡态理论都表明指前因子本身随温度缓慢变化，温度范围很宽时 $\ln k$–$1/T$ 弯曲，常改写为 $k = AT^m\mathrm{e}^{-E_0/RT}$。实验中速率随温度的变化大致有以下几类：

| 类型 | 特征 | 例 |
|---|---|---|
| Arrhenius 型 | $k$ 随 $T$ 按指数增大 | 大多数反应 |
| 爆炸型 | 达到某一温度时速率急剧增大 | 支链反应、热爆炸（15.7） |
| 先增后减 | 有一个最适温度 | 多相催化（吸附随温度下降）、酶催化（高温变性，[6.3.17](/6.3.17)） |
| 复杂型 | 升温时速率先增、后减、再增 | 碳的氧化（中间有副反应参与） |
| 反常型 | $k$ 随 $T$ 升高而减小 | $\ce{2NO + O2 -> 2NO2}$（15.5.4） |

### 15.5.2. 微观可逆性原理与细致平衡

力学方程在时间反演 $t \to -t$、$\boldsymbol{v} \to -\boldsymbol{v}$ 下不变：每一个力学过程都有一个完全逆转的过程。把它用于基元反应：

**定理 15.5.1（微观可逆性原理）** 一个基元反应的逆过程也是基元反应，正、逆反应经过相同的中间状态（过渡态），沿同一条反应路径反向进行。

由它在宏观上得到下面的原理，它是统计力学的结论，在热力学平衡下普遍成立。

**定理 15.5.2（细致平衡原理）** 系统处于平衡时，每一个基元反应的正向速率都与其逆向速率相等，而不仅仅是各物种的净生成速率为零。

**推论 15.5.1** 对基元反应 $0 = \sum_{\mathrm{B}}\nu_{\mathrm{B}}\mathrm{B}$，正、逆速率常数之比等于以浓度表示的平衡常数：

$$
\frac{k_1}{k_{-1}} = \prod_{\mathrm{B}}(c_{\mathrm{B}}^{\mathrm{eq}})^{\nu_{\mathrm{B}}} = K^\circ(c^\circ)^{\sum\nu_{\mathrm{B}}} \quad\text{（理想溶液）}, \qquad \frac{k_1}{k_{-1}} = K^\circ\left(\frac{p^\circ}{RT}\right)^{\sum\nu_{\mathrm{B}}} \quad\text{（理想气体）}.
$$

**证明** 由细致平衡，平衡时 $k_1\prod_{\nu_{\mathrm{B}}<0}(c_{\mathrm{B}}^{\mathrm{eq}})^{\lvert\nu_{\mathrm{B}}\rvert} = k_{-1}\prod_{\nu_{\mathrm{B}}>0}(c_{\mathrm{B}}^{\mathrm{eq}})^{\nu_{\mathrm{B}}}$（质量作用定律），移项即得第一个等号。理想溶液中 $K^\circ = \prod(c_{\mathrm{B}}^{\mathrm{eq}}/c^\circ)^{\nu_{\mathrm{B}}}$；理想气体中 $K^\circ = \prod(p_{\mathrm{B}}^{\mathrm{eq}}/p^\circ)^{\nu_{\mathrm{B}}}$，代入 $p_{\mathrm{B}} = c_{\mathrm{B}}RT$ 即得（[6.3.7](/6.3.7)）。$\square$

**推论 15.5.2** 基元反应的正、逆活化能之差：$E_{\mathrm{a},1} - E_{\mathrm{a},-1} = \Delta_{\mathrm{r}}U_{\mathrm{m}}$；对凝聚相反应 $\Delta_{\mathrm{r}}U_{\mathrm{m}} \approx \Delta_{\mathrm{r}}H_{\mathrm{m}}$，对理想气体反应 $\Delta_{\mathrm{r}}U_{\mathrm{m}} = \Delta_{\mathrm{r}}H_{\mathrm{m}} - \sum\nu_{\mathrm{B}}RT$。

**证明** 对推论 15.5.1 取对数、对 $T$ 求导，用活化能的定义 $E_{\mathrm{a}} = RT^2\frac{\mathrm{d}\ln k}{\mathrm{d}T}$ 与 **van 't Hoff 方程** $\frac{\mathrm{d}\ln K^\circ}{\mathrm{d}T} = \frac{\Delta_{\mathrm{r}}H^\circ_{\mathrm{m}}}{RT^2}$。溶液中 $c^\circ$ 不随温度变化，得 $E_{\mathrm{a},1} - E_{\mathrm{a},-1} = \Delta_{\mathrm{r}}H^\circ_{\mathrm{m}}$；气相中多出一项 $-\sum\nu_{\mathrm{B}}\frac{\mathrm{d}\ln T}{\mathrm{d}T} = -\frac{\sum\nu_{\mathrm{B}}}{T}$，

$$
\frac{E_{\mathrm{a},1} - E_{\mathrm{a},-1}}{RT^2} = \frac{\Delta_{\mathrm{r}}H^\circ_{\mathrm{m}} - \sum\nu_{\mathrm{B}}RT}{RT^2} = \frac{\Delta_{\mathrm{r}}U^\circ_{\mathrm{m}}}{RT^2}. \qquad \square
$$

这就是 [6.1.7](/6.1.7#sec-7.2.2) 中"$\Delta_{\mathrm{r}}H_{\mathrm{m}} \approx E_{\mathrm{a}} - E_{\mathrm{a}}'$"的准确形式。细致平衡还有一个不那么显然的推论：对一个循环 $\ce{A <=> B <=> C <=> A}$，平衡时各步分别平衡要求 $k_{\mathrm{AB}}k_{\mathrm{BC}}k_{\mathrm{CA}} = k_{\mathrm{BA}}k_{\mathrm{CB}}k_{\mathrm{AC}}$（Wegscheider 条件），否则系统中会存在一个永不停息的循环流，这与热力学第二定律矛盾。循环流在非平衡稳态中确实存在，例如由 ATP 水解驱动的分子马达与离子泵，那时细致平衡被外界的化学势差打破；**Onsager 倒易关系**的推导同样以微观可逆性为基础（[6.3.18](/6.3.18)）。

### 15.5.3. 热力学与动力学对温度的不同要求

对放热反应，$K^\circ$ 随温度升高而减小（van 't Hoff 方程），平衡转化率下降；但活化能总是正的，升温总能加快反应。实际生产要兼顾两者：合成氨 $\ce{N2 + 3H2 <=> 2NH3}$ 放热，低温有利于平衡，但低温下即使有铁催化剂速率也太慢，工业上在 $400$–$500\,^\circ\mathrm{C}$、$15$–$30\,\mathrm{MPa}$ 下操作，用高压补偿平衡的损失，并把氨冷凝分离、未反应气循环。对可逆放热反应，转化率一定时速率随温度有一个极大值（最适温度），反应器常按逐段降温设计。吸热反应则升温对平衡与速率都有利。

### 15.5.4. 复合反应的表观活化能

**定义 15.5.1** 由复合反应的表观速率常数按 $E_{\mathrm{a}} = RT^2\frac{\mathrm{d}\ln k}{\mathrm{d}T}$ 求得的活化能称为**表观活化能**（实验活化能）。

若表观速率常数是各基元反应速率常数的幂乘积 $k = \prod_ik_i^{m_i}$，则 $E_{\mathrm{a}} = \sum_im_iE_{\mathrm{a},i}$，$A = \prod_iA_i^{m_i}$。$\ce{H2 + I2}$ 的前平衡机理（[6.1.7](/6.1.7#sec-7.3.1)）给出 $k = k_1k_2/k_{-1}$，于是

$$
E_{\mathrm{a}} = E_{\mathrm{a},1} + E_{\mathrm{a},2} - E_{\mathrm{a},-1}, \qquad A = \frac{A_1A_2}{A_{-1}}.
$$

表观活化能是各基元步骤活化能的代数和，不再有能垒的含义，甚至可以为负。$\ce{2NO + O2 -> 2NO2}$ 的一种机理是 $\ce{2NO <=> N2O2}$（快速平衡，$\Delta_{\mathrm{r}}H < 0$），$\ce{N2O2 + O2 -> 2NO2}$（慢），$k = K_1k_2$，$E_{\mathrm{a}} = \Delta_{\mathrm{r}}H_1 + E_{\mathrm{a},2}$；放热的预平衡使 $E_{\mathrm{a}} < 0$，这就是 15.5.1 表中的反常型：升温使二聚体的平衡浓度下降得比 $k_2$ 增加得快。

### 15.5.5. 活化能的测定

测定一系列温度下的 $k$，对 $\ln k$–$1/T$ 作最小二乘直线，斜率为 $-E_{\mathrm{a}}/R$（[6.1.7](/6.1.7#sec-7.3.3)）。只用两个温度时（例 15.2.2）误差难以估计。与 15.3.4 节同理，更好的做法是对 $k(T)$ 直接做非线性拟合，或者把全部温度下的 $c(t, T)$ 数据与 Arrhenius 参数一起拟合；拟合 $\ln A$ 与 $E_{\mathrm{a}}$ 时两者高度相关，常把温度中心化为 $1/T - 1/\bar T$ 以减小相关。基元反应的活化能可以由键能粗略估计（如 Hirschfelder 规则：自由基与分子的放热反应 $E_{\mathrm{a}} \approx 0.055$ 倍被断键的键能），精确的值要由量子化学计算势能面（[6.3.16](/6.3.16)）。

**例 15.5.1** 两个反应的活化能分别为 $60$ 与 $150\,\mathrm{kJ\,mol^{-1}}$，温度从 $373\,\mathrm{K}$ 升到 $473\,\mathrm{K}$，速率常数各增大多少倍？

**解** 由 $\ln\frac{k(T_2)}{k(T_1)} = \frac{E_{\mathrm{a}}}{R}\left(\frac{1}{T_1} - \frac{1}{T_2}\right)$，$\frac{1}{373} - \frac{1}{473} = 5.67 \times 10^{-4}\,\mathrm{K^{-1}}$：$E_{\mathrm{a}} = 60\,\mathrm{kJ\,mol^{-1}}$ 时增大 $\mathrm{e}^{4.09} \approx 60$ 倍，$150\,\mathrm{kJ\,mol^{-1}}$ 时增大 $\mathrm{e}^{10.2} \approx 2.8 \times 10^4$ 倍。若主反应的活化能大于副反应，升温可以抑制副反应，反之应降温。

## 15.6. 近似方法

机理中只要有一步是二级以上，速率方程组一般就没有解析解。但机理中的各步速率常数往往相差几个数量级，利用这一点可以把方程组化简。

### 15.6.1. 速控步近似与稳态近似

连续反应中若某一步远慢于其他各步，总速率就等于这一步的速率，其后的快步骤不影响速率（**速控步**近似，15.4.3）。例如 $\ce{A + B -> C}$（慢）、$\ce{C -> D}$（快）、$\ce{D -> E}$（快），$v \approx k_1[\ce{A}][\ce{B}]$。

连续反应的图中，$k_2 \gg k_1$ 时中间物 B 的浓度始终很小，而且在一段很短的初始期之后，它的生成速率与消耗速率几乎相等：$y \approx \frac{k_1}{k_2}x$，$\frac{\mathrm{d}y}{\mathrm{d}t} = -k_1y$，比生成速率 $k_1x$ 与消耗速率 $k_2y$ 小 $k_2/k_1$ 倍。把这一观察推广，就得到动力学中最重要的近似。

**定义 15.6.1（稳态近似）** 对机理中活泼的中间物（自由基、原子、激发态分子、酶–底物复合物等），在初始的短暂诱导期之后，令其浓度对时间的导数为零：

$$
\frac{\mathrm{d}[\mathrm{I}]}{\mathrm{d}t} \approx 0,
$$
从而用代数方程把中间物的浓度表示为反应物与产物浓度的函数，这种处理称为**稳态近似**（准稳态近似）。

稳态近似并不是说中间物的浓度不变（它随反应物的消耗而变化），而是说它的变化速率远小于它的生成速率与消耗速率，它"跟随"反应物的浓度变化。适用条件是中间物的寿命 $\tau_{\mathrm{I}}$（其消耗速率常数之和的倒数）远短于反应物浓度变化的时间尺度；由此中间物的浓度也必然很小。

### 15.6.2. 稳态近似与前平衡近似的关系

以机理

$$
\ce{A <=>[k_1][k_{-1}] C}, \qquad \ce{C + B ->[k_2] P}
$$
为例，$v = \frac{\mathrm{d}[\ce{P}]}{\mathrm{d}t} = k_2[\ce{C}][\ce{B}]$。

稳态近似：$\frac{\mathrm{d}[\ce{C}]}{\mathrm{d}t} = k_1[\ce{A}] - k_{-1}[\ce{C}] - k_2[\ce{C}][\ce{B}] = 0$，

$$
[\ce{C}] = \frac{k_1[\ce{A}]}{k_{-1} + k_2[\ce{B}]}, \qquad v_{\mathrm{SS}} = \frac{k_1k_2[\ce{A}][\ce{B}]}{k_{-1} + k_2[\ce{B}]}. \tag{15.2}
$$

**前平衡近似**（[6.1.7](/6.1.7#sec-7.3.1)，又称平衡假设）：第一步正、逆反应都远快于第二步，近似处于平衡，$[\ce{C}] = K[\ce{A}]$，$K = k_1/k_{-1}$，

$$
v_{\mathrm{PE}} = \frac{k_1k_2}{k_{-1}}[\ce{A}][\ce{B}]. \tag{15.3}
$$

比较两式：

- $k_{-1} \gg k_2[\ce{B}]$（中间物返回反应物远快于生成产物）时，式 (15.2) 化为式 (15.3)；第二步是速控步，前平衡成立。
- $k_{-1} \ll k_2[\ce{B}]$ 时，式 (15.2) 化为 $v = k_1[\ce{A}]$：第一步是速控步，此后的快反应都不必考虑，速率与 B 无关。
- 两者相当时，只有稳态近似给出正确的结果，速率对 B 的级数在 0 与 1 之间变化。

常见的说法是"稳态假设是根本，平衡假设是稳态假设的特例"。这在中间物浓度很小时（$K \ll 1$）成立，但并不普遍：若 $k_1$ 与 $k_{-1}$ 都远大于 $k_2[\ce{B}]$ 而 $K = k_1/k_{-1}$ 并不小，中间物会大量积累，稳态近似不再适用，前平衡近似却仍然成立，只是此时应计入守恒关系 $[\ce{A}] + [\ce{C}] = [\ce{A}]_{\mathrm{tot}}$，得 $v = \frac{k_2K}{1 + K}[\ce{A}]_{\mathrm{tot}}[\ce{B}]$。两种近似的适用条件不同：稳态近似要求中间物寿命短，前平衡近似要求前一步的弛豫远快于后一步。两者都能用时，前平衡近似的推导更简单；选用哪一物质表示速率时，优先考虑出现在速控步中、在机理中出现次数最少的物质。

![机理 A ⇌ C、C + B → P（k2' = k2[B]）的完整方程（隐式 Radau 方法数值求解）与两种近似的比较。左：k−1 ≫ k2'，两种近似都接近准确解；中：k−1 ≪ k2'，前平衡近似完全失效，稳态近似仍然准确；右：第一种情形下中间物浓度在约 1/(k−1 + k2') 的诱导期后进入准稳态，随后跟随 [A] 下降](./plots/steady-state-vs-full.py)

### 15.6.3. 时间尺度分离与刚性

稳态近似的数学实质是快慢变量的分离。中间物的浓度以 $k_{-1} + k_2[\ce{B}]$ 的速率趋向它的准稳态值，反应物以 $v_{\mathrm{SS}}/[\ce{A}]$ 的速率消耗；两个速率之比就是线性化方程组 Jacobi 矩阵的两个**特征值**之比。比值很大时，方程组是**刚性**的（[4.4.4](/4.4.4#sec-4.3.3)）：显式方法（如 `solve_ivp` 默认的 RK45）为了稳定必须取远小于快时间尺度的步长，计算量与刚性比成正比；隐式方法（Radau、BDF、LSODA）则能以慢时间尺度的步长积分。稳态近似把快变量"消去"，使方程组变得不刚性、往往可以解析求解，代价是丢掉诱导期内的细节。上图是用 `solve_ivp(..., method="Radau")` 求解的。燃烧化学与大气化学的机理包含成百上千个基元反应，刚性比可达 $10^{10}$，数值求解完整方程组与有选择地使用稳态近似是这些领域的日常工作。

## 15.7. 链反应

### 15.7.1. 链反应的特点

**定义 15.7.1** 由热、光、辐射或引发剂产生的活性组分（自由基或原子）使反应物分子相继发生一系列反应，而活性组分在反应中不断再生、使反应像链条一样自动进行下去的反应称为**链反应**；链反应中传递反应的活性组分称为**链载体**。链反应包括三个阶段：

1. **链引发**：稳定分子吸收能量（加热、光照或引发剂）分解为链载体，如 $\ce{Cl2 + M -> 2Cl + M}$。这一步要断裂化学键，活化能最大，与断裂的键能相当。
2. **链传递**：链载体与稳定分子作用，在生成产物的同时又生成新的链载体，如 $\ce{Cl + H2 -> HCl + H}$、$\ce{H + Cl2 -> HCl + Cl}$。自由基与分子的反应活化能很小，这一步很快，反复进行很多次。
3. **链终止**：两个链载体相碰结合成稳定分子（需要第三体带走能量），或与器壁碰撞而失活，如 $\ce{2Cl + M -> Cl2 + M}$。

**定义 15.7.2** 带有未成对电子的原子或原子团称为**自由基**（游离基），如 $\ce{Cl.}$、$\ce{H.}$、$\ce{CH3.}$、$\ce{.OH}$。它们活性高、寿命短，是链反应的链载体。

一次链引发所引起的链传递次数称为链长。链载体对器壁、杂质很敏感：改变容器的形状、材料，加入少量自由基捕获剂（如 NO、酚类抗氧化剂），都可能显著改变速率，这是链反应的实验特征。

**定义 15.7.3** 链传递过程中每消耗一个链载体只生成一个新链载体、链载体的数目保持不变的链反应称为**直链反应**；每消耗一个链载体生成两个或两个以上新链载体的链反应称为**支链反应**。

### 15.7.2. 直链反应：$\ce{H2 + Cl2}$

实验得 $-\frac{\mathrm{d}[\ce{H2}]}{\mathrm{d}t} = k[\ce{H2}][\ce{Cl2}]^{1/2}$。机理与各步活化能（$\mathrm{kJ\,mol^{-1}}$）：

$$
\begin{aligned}
&(1)\ \ce{Cl2 + M ->[k_1] 2Cl + M} && E_1 = 243\\
&(2)\ \ce{Cl + H2 ->[k_2] HCl + H} && E_2 = 24\\
&(3)\ \ce{H + Cl2 ->[k_3] HCl + Cl} && E_3 = 13\\
&(4)\ \ce{2Cl + M ->[k_4] Cl2 + M} && E_4 = 0
\end{aligned}
$$

对 Cl 与 H 用稳态近似（M 的浓度在速率常数中，略去不写）：

$$
\frac{\mathrm{d}[\ce{Cl}]}{\mathrm{d}t} = 2k_1[\ce{Cl2}] - k_2[\ce{Cl}][\ce{H2}] + k_3[\ce{H}][\ce{Cl2}] - 2k_4[\ce{Cl}]^2 = 0, \qquad \frac{\mathrm{d}[\ce{H}]}{\mathrm{d}t} = k_2[\ce{Cl}][\ce{H2}] - k_3[\ce{H}][\ce{Cl2}] = 0.
$$
两式相加，链传递的两项抵消：$k_1[\ce{Cl2}] = k_4[\ce{Cl}]^2$，即引发速率等于终止速率，这是直链反应稳态的普遍特点。于是 $[\ce{Cl}] = (k_1/k_4)^{1/2}[\ce{Cl2}]^{1/2}$，

$$
-\frac{\mathrm{d}[\ce{H2}]}{\mathrm{d}t} = k_2[\ce{Cl}][\ce{H2}] = k_2\left(\frac{k_1}{k_4}\right)^{1/2}[\ce{H2}][\ce{Cl2}]^{1/2},
$$
与实验一致。表观活化能 $E_{\mathrm{a}} = E_2 + \frac12(E_1 - E_4) = 145\,\mathrm{kJ\,mol^{-1}}$，比 $\ce{Cl2}$ 的键能小得多。若 $\ce{H2}$ 与 $\ce{Cl2}$ 按四中心的分子机理直接反应，估计 $E_{\mathrm{a}} \approx 200\,\mathrm{kJ\,mol^{-1}}$；若链从 $\ce{H2}$ 的解离开始，引发步骤需要 $435\,\mathrm{kJ\,mol^{-1}}$。键能最小的 $\ce{Cl2}$ 解离开始的链反应途径活化能最低，因此反应按它进行。$\ce{H2 + Cl2}$ 在光照下可以爆炸，因为光引发产生大量 Cl 原子，链长可达 $10^6$（[6.3.17](/6.3.17)）。

### 15.7.3. 直链反应：$\ce{H2 + Br2}$

Bodenstein 与 Lind 在 1907 年测得的速率方程是

$$
\frac{\mathrm{d}[\ce{HBr}]}{\mathrm{d}t} = \frac{k[\ce{H2}][\ce{Br2}]^{1/2}}{1 + k'[\ce{HBr}]/[\ce{Br2}]},
$$
产物 HBr 抑制反应，而 $\ce{Br2}$ 减弱这种抑制；12 年后才由 Christiansen、Herzfeld 与 Polanyi 各自提出机理：

$$
\begin{aligned}
&(1)\ \ce{Br2 + M ->[k_1] 2Br + M} &&\text{链引发}\\
&(2)\ \ce{Br + H2 ->[k_2] HBr + H} &&\text{链传递}\\
&(3)\ \ce{H + Br2 ->[k_3] HBr + Br} &&\text{链传递}\\
&(4)\ \ce{H + HBr ->[k_4] H2 + Br} &&\text{抑制}\\
&(5)\ \ce{2Br + M ->[k_5] Br2 + M} &&\text{链终止}
\end{aligned}
$$

对 H 与 Br 用稳态近似：

$$
\frac{\mathrm{d}[\ce{H}]}{\mathrm{d}t} = k_2[\ce{Br}][\ce{H2}] - k_3[\ce{H}][\ce{Br2}] - k_4[\ce{H}][\ce{HBr}] = 0, \tag{15.4}
$$

$$
\frac{\mathrm{d}[\ce{Br}]}{\mathrm{d}t} = 2k_1[\ce{Br2}][\ce{M}] - k_2[\ce{Br}][\ce{H2}] + k_3[\ce{H}][\ce{Br2}] + k_4[\ce{H}][\ce{HBr}] - 2k_5[\ce{Br}]^2[\ce{M}] = 0. \tag{15.5}
$$

式 (15.4) 与 (15.5) 相加，链传递与抑制的各项全部抵消，$k_1[\ce{Br2}] = k_5[\ce{Br}]^2$，第三体的浓度也消去了：

$$
[\ce{Br}] = \left(\frac{k_1}{k_5}\right)^{1/2}[\ce{Br2}]^{1/2}.
$$
由式 (15.4)，

$$
[\ce{H}] = \frac{k_2[\ce{Br}][\ce{H2}]}{k_3[\ce{Br2}] + k_4[\ce{HBr}]}.
$$
HBr 由步骤 (2)、(3) 生成，由步骤 (4) 消耗：$\frac{\mathrm{d}[\ce{HBr}]}{\mathrm{d}t} = k_2[\ce{Br}][\ce{H2}] + k_3[\ce{H}][\ce{Br2}] - k_4[\ce{H}][\ce{HBr}]$。用式 (15.4) 把第一项换成 $k_3[\ce{H}][\ce{Br2}] + k_4[\ce{H}][\ce{HBr}]$，得 $\frac{\mathrm{d}[\ce{HBr}]}{\mathrm{d}t} = 2k_3[\ce{H}][\ce{Br2}]$，代入 $[\ce{H}]$ 与 $[\ce{Br}]$：

$$
\frac{\mathrm{d}[\ce{HBr}]}{\mathrm{d}t} = \frac{2k_2k_3[\ce{Br}][\ce{H2}][\ce{Br2}]}{k_3[\ce{Br2}] + k_4[\ce{HBr}]} = \frac{2k_2(k_1/k_5)^{1/2}[\ce{H2}][\ce{Br2}]^{1/2}}{1 + \dfrac{k_4[\ce{HBr}]}{k_3[\ce{Br2}]}},
$$
与实验式相同，$k = 2k_2(k_1/k_5)^{1/2}$，$k' = k_4/k_3$（实验值约 $0.12$，与温度几乎无关，说明 $E_3 \approx E_4$）。

机理中各步的取舍有化学上的理由（键能 $D(\ce{H-H}) = 436$、$D(\ce{H-Br}) = 366$、$D(\ce{Br-Br}) = 193\,\mathrm{kJ\,mol^{-1}}$）：

- 引发只考虑 $\ce{Br2}$ 的解离，$\ce{H2}$ 的键能大得多，$\ce{H2 + M -> 2H + M}$ 可以忽略。
- 步骤 (2) 吸热约 $70\,\mathrm{kJ\,mol^{-1}}$，是链中最慢的一步，所以 Br 是浓度最高的链载体，终止只考虑 $\ce{2Br}$ 的复合。$\ce{Br + HBr -> Br2 + H}$ 吸热 $173\,\mathrm{kJ\,mol^{-1}}$，可以忽略。
- H 原子很活泼，与 $\ce{Br2}$ 和 HBr 都能放热反应：步骤 (4) 与 (3) 竞争 H 原子，把 H 变回活性较低的 Br，这就是 HBr 抑制作用的来源；比值 $k_4[\ce{HBr}]/(k_3[\ce{Br2}])$ 表示两种竞争的相对快慢，所以 $\ce{Br2}$ 能抵消 HBr 的抑制。
- 反应初期 $[\ce{HBr}] \approx 0$，速率对 $\ce{Br2}$ 是 $\frac12$ 级，与 $\ce{H2 + Cl2}$ 形式相同。

$\ce{H2 + I2}$ 的情形与此不同：I 原子与 $\ce{H2}$ 的反应吸热太多，链不能传递，反应按 15.1.3 表中的机理进行。用稳态近似处理 I 原子：$\frac{\mathrm{d}[\ce{I}]}{\mathrm{d}t} = 2k_1[\ce{I2}] - 2k_{-1}[\ce{I}]^2 - 2k_2[\ce{I}]^2[\ce{H2}] = 0$，得 $\frac12\frac{\mathrm{d}[\ce{HI}]}{\mathrm{d}t} = \frac{k_1k_2[\ce{I2}][\ce{H2}]}{k_{-1} + k_2[\ce{H2}]}$；当 $k_{-1} \gg k_2[\ce{H2}]$ 时化为前平衡的结果 $\frac{k_1k_2}{k_{-1}}[\ce{H2}][\ce{I2}]$。

### 15.7.4. 支链反应与爆炸界限

$\ce{H2 + O2}$ 的反应是支链反应的典型。在链引发产生 H 原子之后，

$$
\ce{H + O2 -> OH + O}, \qquad \ce{O + H2 -> OH + H}, \qquad \ce{OH + H2 -> H2O + H},
$$
前两步各消耗一个链载体、生成两个：第三步进行两次，与前两步合起来，一个 H 原子变成三个，即 $\ce{H + O2 + 3H2 -> 2H2O + 3H}$。链载体的数目按几何级数增长，若终止跟不上，反应速率在极短时间内无限增大，发生支链爆炸。

设链载体的数密度为 $n$，引发速率为 $w_0$，每个链载体单位时间内发生支化的概率为 $f$、被终止的概率为 $g$，则 $\frac{\mathrm{d}n}{\mathrm{d}t} = w_0 + (f - g)n$：

- $g > f$：$n$ 趋于稳态值 $\frac{w_0}{g - f}$，反应平稳进行；
- $f > g$：$n \propto \mathrm{e}^{(f-g)t}$ 指数增长，发生爆炸。

$f = g$ 是爆炸的临界条件。支化概率主要随温度增大（$\ce{H + O2 -> OH + O}$ 吸热，活化能约 $70\,\mathrm{kJ\,mol^{-1}}$），终止概率则随压力有复杂的变化，因此能否爆炸取决于温度与压力。

**定义 15.7.4** 一定温度下，发生爆炸的压力区间的边界称为**爆炸界限**。

![化学计量比的 H2 + O2 混合物的爆炸界限示意图（对数压力–温度）：第一、第二界限之间的"爆炸半岛"是支链爆炸区，第三界限以上是热爆炸区；只示意形状，不代表测量数据](./plots/explosion-limits.py)

1. 第一界限（爆炸下限）：压力很低时，链载体在与分子碰撞而支化之前就扩散到器壁上而失活（器壁终止，速率与扩散系数成正比、与压力成反比），$g > f$，不爆炸。下限与容器的大小、材料有关。
2. 第一、第二界限之间：器壁终止减弱，支化超过终止，发生爆炸。
3. 第二界限（爆炸上限）：压力增大后，三体复合 $\ce{H + O2 + M -> HO2 + M}$ 加快（速率与压力的平方成正比，比支化 $\ce{H + O2}$ 多一个压力因子），生成的 $\ce{HO2}$ 不活泼，链被终止，又不爆炸。上限随温度升高而升高，与容器无关。
4. 第三界限：压力更高时，$\ce{HO2}$ 也参与链传递，反应放热增多，发生热爆炸。

化学计量比的混合物在约 $730\,\mathrm{K}$ 以下，无论压力多大都不发生支链爆炸（具体温度与容器有关）。

**定义 15.7.5** 放热反应在有限空间中进行，放出的热来不及散失，使温度升高、速率进一步加快、放热更多，最终速率无限增大，这种爆炸称为**热爆炸**。

Semenov 的热平衡分析：放热速率按 Arrhenius 规律 $\propto \mathrm{e}^{-E_{\mathrm{a}}/RT}$ 随温度增大，散热速率与温差 $T - T_0$ 成正比。两条曲线有交点时系统停在稳定的定态，两曲线恰好相切时达到临界，此时温升约为 $RT_0^2/E_{\mathrm{a}}$（对 $E_{\mathrm{a}} = 150\,\mathrm{kJ\,mol^{-1}}$、$T_0 = 600\,\mathrm{K}$，只有约 $20\,\mathrm{K}$）。这是一个鞍结分岔：参数（器壁温度、压力）越过临界值时，稳定的定态消失（[2.4.11](/2.4.11)）。与此类似的热失控也是锂离子电池安全问题的根源。

## 15.8. 反应机理的拟定

### 15.8.1. 一般步骤

1. 写出反应的计量方程，确定产物（包括副产物）。
2. 实验测定速率方程，确定各物质的级数。
3. 测定活化能。
4. 用电子顺磁共振（EPR，检测自由基）、核磁共振、质谱、闪光光解中的瞬态光谱等手段检测中间物，确定其组成；自由基寿命太短时，加入自旋捕获剂使之成为稳定的自由基加合物再检测，或用同位素标记追踪原子的去向。
5. 根据化学知识（键能、反应分子数、空间因素）拟定机理。
6. 由机理用速控步、稳态、前平衡等近似推导速率方程，与实验比较。
7. 由各基元步骤的活化能计算表观活化能，与实验比较。
8. 二者都一致时，机理基本合理；否则修改。一致只说明机理"可能"正确：同一个速率方程可以由不同的机理得到（[6.1.7](/6.1.7#sec-7.3.1) 思考题 4），机理永远只能被否定、不能被最终证明。

### 15.8.2. 例：乙烷的热分解

$\ce{C2H6 -> C2H4 + H2}$ 是一级反应，$E_{\mathrm{a}} = 284.5\,\mathrm{kJ\,mol^{-1}}$，检测到 $\ce{CH3}$ 与 $\ce{C2H5}$ 自由基。

**定义 15.8.1（Rice–Herzfeld 机理）** 有机物热分解的自由基链机理：分子中最弱的键断裂产生自由基（引发），自由基夺取分子中的氢原子、生成的自由基再分解出产物与新的自由基（传递），自由基复合（终止）。这种机理称为 **Rice–Herzfeld 机理**（1934 年）。

乙烷的 Rice–Herzfeld 机理与各步活化能（$\mathrm{kJ\,mol^{-1}}$）：

$$
\begin{aligned}
&(1)\ \ce{C2H6 ->[k_1] 2CH3} && 351.5\\
&(2)\ \ce{CH3 + C2H6 ->[k_2] CH4 + C2H5} && 33.5\\
&(3)\ \ce{C2H5 ->[k_3] C2H4 + H} && 167\\
&(4)\ \ce{H + C2H6 ->[k_4] H2 + C2H5} && 29.3\\
&(5)\ \ce{H + C2H5 ->[k_5] C2H6} && 0
\end{aligned}
$$

对三种自由基用稳态近似（记 $[\ce{C2H6}] = c$）：$\ce{CH3}$ 只由 (1) 生成、由 (2) 消耗，$[\ce{CH3}] = 2k_1/k_2$。$\ce{C2H5}$ 与 H 的稳态方程

$$
k_2[\ce{CH3}]c - k_3[\ce{C2H5}] + k_4[\ce{H}]c - k_5[\ce{H}][\ce{C2H5}] = 0, \qquad k_3[\ce{C2H5}] - k_4[\ce{H}]c - k_5[\ce{H}][\ce{C2H5}] = 0
$$
相加得 $2k_1c = 2k_5[\ce{H}][\ce{C2H5}]$（引发 = 终止）。把 $[\ce{H}] = \frac{k_1c}{k_5[\ce{C2H5}]}$ 代入第二式，得 $[\ce{C2H5}]$ 的二次方程

$$
k_3k_5[\ce{C2H5}]^2 - k_1k_5c[\ce{C2H5}] - k_1k_4c^2 = 0.
$$
引发远慢于传递（$k_1$ 很小，链很长），一次项可以略去，$[\ce{C2H5}] \approx \left(\frac{k_1k_4}{k_3k_5}\right)^{1/2}c$。乙烯的生成速率

$$
v = k_3[\ce{C2H5}] = \left(\frac{k_1k_3k_4}{k_5}\right)^{1/2}[\ce{C2H6}],
$$
是一级反应，表观活化能 $E_{\mathrm{a}} = \frac12(E_1 + E_3 + E_4 - E_5) = 274\,\mathrm{kJ\,mol^{-1}}$，与实验值 $284.5\,\mathrm{kJ\,mol^{-1}}$ 基本相符。

### 15.8.3. 例：苯胺的重氮化

$\ce{Br-}$ 催化下 $\ce{H+ + HNO2 + C6H5NH2 -> C6H5N2+ + 2H2O}$：

```smiles
Nc1ccccc1 C6H5NH2
N#[N+]c1ccccc1 C6H5N2+
```

实验速率方程为 $v = k[\ce{H+}][\ce{HNO2}][\ce{Br-}]$，与苯胺的浓度无关。可能的机理：

$$
\begin{aligned}
&(1)\ \ce{H+ + HNO2 <=>[k_1][k_{-1}] H2NO2+} &&\text{快速平衡}\\
&(2)\ \ce{H2NO2+ + Br- ->[k_2] ONBr + H2O} &&\text{慢}\\
&(3)\ \ce{ONBr + C6H5NH2 ->[k_3] C6H5N2+ + H2O + Br-} &&\text{快}
\end{aligned}
$$

速控步 (2) 给出 $v = k_2[\ce{H2NO2+}][\ce{Br-}]$；由前平衡 $[\ce{H2NO2+}] = \frac{k_1}{k_{-1}}[\ce{H+}][\ce{HNO2}]$，

$$
v = \frac{k_1k_2}{k_{-1}}[\ce{H+}][\ce{HNO2}][\ce{Br-}].
$$
苯胺只出现在速控步之后的快反应中，所以不出现在速率方程里；$\ce{Br-}$ 在 (2) 中消耗、在 (3) 中再生，是催化剂，却出现在速率方程中。

## 15.9. 快速反应与弛豫方法

### 15.9.1. 混合的限制

常规方法"混合—反应—测定 $c$–$t$"要求反应时间远长于混合时间。酸碱中和、电子转移、酶与底物的结合等反应的半衰期在毫秒以下，混合尚未完成反应已经结束。测定这类反应有两条途径：缩短混合时间，或者根本不混合。

**定义 15.9.1** 把两种反应物溶液用驱动注射器快速压入混合室、在数毫秒内混合，随即使流动突然停止，用光谱等方法监测停流后浓度随时间变化的方法称为**停流法**。死时间约 $1\,\mathrm{ms}$，适用于半衰期在毫秒以上的反应，是酶动力学的常规手段。

### 15.9.2. 弛豫方法

**定义 15.9.2** 使已达平衡的快速对峙反应受到一个突然的微小扰动（温度、压力或电场的跃变），系统偏离新条件下的平衡，再测定它趋向新平衡的过程（弛豫），由弛豫的快慢求速率常数的方法称为**弛豫法**（化学弛豫）。用电容放电或激光脉冲使溶液温度在微秒或纳秒内升高几开的方法称为**温度跳跃法**。

弛豫法不需要混合，时间分辨只受扰动本身的快慢限制。扰动很小时，系统的方程可以在新平衡点附近线性化（[2.4.11](/2.4.11#sec-11.3)），偏离量按指数衰减。

**公式 15.9.1（1-1 级对峙反应的弛豫时间）** 对 $\ce{A <=>[k_1][k_{-1}] B}$，设扰动后新平衡时 B 的浓度为 $x_{\mathrm{eq}}$，偏离量 $\Delta x = x - x_{\mathrm{eq}}$。由 $\frac{\mathrm{d}x}{\mathrm{d}t} = k_1(a - x) - k_{-1}x$ 与平衡条件 $k_1(a - x_{\mathrm{eq}}) = k_{-1}x_{\mathrm{eq}}$，

$$
\frac{\mathrm{d}\Delta x}{\mathrm{d}t} = -(k_1 + k_{-1})\Delta x, \qquad \Delta x = \Delta x_0\,\mathrm{e}^{-t/\tau}, \qquad \frac{1}{\tau} = k_1 + k_{-1}.
$$
偏离量降到初值的 $1/\mathrm{e}$ 所需的时间 $\tau$ 称为**弛豫时间**。

由 $\tau$ 得 $k_1 + k_{-1}$，再由平衡常数 $K = k_1/k_{-1}$（可以用常规方法测定）分别求出 $k_1$ 与 $k_{-1}$。这个结果与式 (15.1) 相同，只不过那里的"扰动"是从纯 A 开始。

对 $\ce{A + B <=>[k_1][k_{-1}] C}$，设 $[\ce{C}] = [\ce{C}]_{\mathrm{eq}} + \Delta x$，则 $[\ce{A}] = [\ce{A}]_{\mathrm{eq}} - \Delta x$，$[\ce{B}] = [\ce{B}]_{\mathrm{eq}} - \Delta x$：

$$
\frac{\mathrm{d}\Delta x}{\mathrm{d}t} = k_1([\ce{A}]_{\mathrm{eq}} - \Delta x)([\ce{B}]_{\mathrm{eq}} - \Delta x) - k_{-1}([\ce{C}]_{\mathrm{eq}} + \Delta x) \approx -\left[k_1([\ce{A}]_{\mathrm{eq}} + [\ce{B}]_{\mathrm{eq}}) + k_{-1}\right]\Delta x,
$$
其中用了平衡条件并略去 $(\Delta x)^2$ 项，所以 $\frac{1}{\tau} = k_1([\ce{A}]_{\mathrm{eq}} + [\ce{B}]_{\mathrm{eq}}) + k_{-1}$。在不同的总浓度下测 $\tau$，$1/\tau$ 对 $[\ce{A}]_{\mathrm{eq}} + [\ce{B}]_{\mathrm{eq}}$ 作图，斜率为 $k_1$，截距为 $k_{-1}$。不同级数的对峙反应，$\tau$ 与速率常数的关系不同，要具体推导；机理包含几步时有几个弛豫时间，对应线性化矩阵的几个特征值（15.4.4）。

![A + B ⇌ C 的温度跳跃实验（k1 = 1.0 × 10⁹ L mol⁻¹ s⁻¹，k−1 = 1.0 × 10⁴ s⁻¹）：左为跳跃后 [C] 向新平衡的弛豫，右为偏离量的对数衰减，完整的非线性方程与线性化给出的 exp(−t/τ) 几乎重合](./plots/temperature-jump.py)

**例 15.9.1** Eigen 用电场跳跃法测得 $25\,^\circ\mathrm{C}$ 时 $\ce{H+ + OH- -> H2O}$ 的速率常数 $k_1 = 1.4 \times 10^{11}\,\mathrm{L\,mol^{-1}\,s^{-1}}$。纯水的弛豫时间是多少？

**解** 逆反应（水的解离）的速率常数 $k_{-1} = k_1K_{\mathrm{w}}/[\ce{H2O}] \approx 1.4 \times 10^{11} \times 10^{-14}/55.3\,\mathrm{s^{-1}} \approx 2.5 \times 10^{-5}\,\mathrm{s^{-1}}$，可以忽略。$[\ce{H+}]_{\mathrm{eq}} = [\ce{OH-}]_{\mathrm{eq}} = 1.0 \times 10^{-7}\,\mathrm{mol\,L^{-1}}$，

$$
\tau = \frac{1}{k_1([\ce{H+}] + [\ce{OH-}])} = \frac{1}{1.4 \times 10^{11} \times 2.0 \times 10^{-7}}\,\mathrm{s} \approx 36\,\mu\mathrm{s}.
$$
这是已知最快的溶液中的双分子反应之一，比 [6.3.17](/6.3.17) 的扩散控制速率常数的一般估计还大一个数量级，原因是两离子相互吸引，且质子可以沿氢键网络以 Grotthuss 机理"接力"传递。

### 15.9.3. 闪光光解

**定义 15.9.3** 用一次强而短的闪光（现在用脉冲激光）使分子光解，产生高浓度的自由基、原子或激发态分子，随即用吸收光谱等方法监测这些瞬态物种的浓度随时间衰减的方法称为**闪光光解**。

闪光光解由 Norrish 与 Porter 在 1949 年发展；Eigen（弛豫法）与 Norrish、Porter（闪光光解）分享了 1967 年 Nobel 化学奖。闪光的强度很高，可以产生比常规反应中高许多倍的瞬态物种浓度，使许多从未被观察到的中间物第一次被直接检测。最初用闪光灯，时间分辨为微秒；纳秒、皮秒激光把它推进到分子振动的时间尺度，即 [6.3.16](/6.3.16) 提到的飞秒化学。闪光光解与光化学的联系见 [6.3.17](/6.3.17)。

| 方法 | 时间范围 | 原理 |
|---|---|---|
| 常规混合 | $> 10\,\mathrm{s}$ | 混合后取样或连续监测 |
| 停流法 | $10^{-3}$–$10\,\mathrm{s}$ | 快速混合后停流 |
| 温度跳跃、压力跳跃 | $10^{-8}$–$1\,\mathrm{s}$ | 扰动平衡后观察弛豫 |
| 闪光光解 | $10^{-12}$–$10^{-3}\,\mathrm{s}$（激光可达 $10^{-14}\,\mathrm{s}$） | 光脉冲产生瞬态物种 |

|---|---|
| $n$ 级反应 | $\frac{1}{c^{n-1}} - \frac{1}{c_0^{n-1}} = (n-1)kt$，$t_{1/2} \propto c_0^{1-n}$；$k_p = k_c(RT)^{1-n}$ |

| 平行反应 | 同级数时产物比 $= k_1/k_2$，靠温度与催化剂调节 |
| 连续反应 | 中间物有极大值 $t_{\max} = \frac{\ln(k_2/k_1)}{k_2 - k_1}$；最慢一步为速控步 |
| 线性网络 | $\dot{\boldsymbol{c}} = K\boldsymbol{c}$，$\boldsymbol{c}(t) = \mathrm{e}^{tK}\boldsymbol{c}(0)$，特征值给出时间尺度 |
| 细致平衡 | 平衡时每一基元步正逆速率相等；$k_1/k_{-1} = K_c$，$E_{\mathrm{a},1} - E_{\mathrm{a},-1} = \Delta_{\mathrm{r}}U_{\mathrm{m}}$ |
| 表观活化能 | 各步活化能的代数和，可以为负 |
| 近似方法 | 速控步；稳态近似（中间物寿命短）；前平衡近似（前一步快速平衡）；数学上是快慢变量分离，对应刚性方程组 |

| 支链与爆炸 | $\dot n = w_0 + (f - g)n$；三个爆炸界限；热爆炸 |
| 快速反应 | 停流法；弛豫法 $1/\tau = k_1 + k_{-1}$（线性化）；闪光光解 |

## 思考题

1. 2-2 级平行反应 $\ce{A ->[k_1] B}$、$\ce{A ->[k_2] C}$（对 A 都是二级），$E_{\mathrm{a},1} > E_{\mathrm{a},2}$，从纯 A 开始。下列哪些措施能改变产物 B 与 C 的比例？(1) 升高温度；(2) 延长反应时间；(3) 加入适当的催化剂；(4) 降低温度；(5) 提高 A 的初始浓度。

   **答** (1)、(3)、(4)。两反应级数相同，$[\ce{B}]/[\ce{C}] = k_1/k_2$，只与温度和催化剂有关；时间和初始浓度不改变这一比值。

2. 对给定的反应，加入催化剂会不会改变反应级数？

   **答** 可能会。催化剂改变了机理，速率方程可以完全不同，催化剂本身也常出现在速率方程中（15.8.3 的 $\ce{Br-}$）。

3. 为什么链反应的速率对容器的形状和器壁材料敏感？

   **答** 链载体可以在器壁上失活，器壁终止的速率与比表面积和器壁性质有关；对支链反应，第一爆炸界限就是由器壁终止决定的。

4. 一个反应的表观活化能为负值，是否违反了"活化能是能垒"的说法？

   **答** 不违反。基元反应的活化能为正；表观活化能是各步活化能的代数和，前平衡放热时可以为负（15.5.4）。
