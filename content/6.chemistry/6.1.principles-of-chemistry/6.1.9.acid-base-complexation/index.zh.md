title: 酸碱平衡与配位平衡
---

无机化学反应大多在水溶液中进行，参与反应的酸、碱、盐在水中解离成离子，离子之间的反应构成溶液中的四大平衡：酸碱平衡、配位平衡（本章）、沉淀溶解平衡（[6.1.10](/6.1.10)）与氧化还原平衡（[6.1.11](/6.1.11)）。它们都是 [6.1.8](/6.1.8) 的**化学平衡**在溶液中的具体形式：平衡常数都是**标准平衡常数**，方向都由**反应商**与平衡常数的比较决定，平衡常数都可以由 $\Delta_{\mathrm{r}}G^\circ_{\mathrm{m}} = -RT\ln K^\circ$ 与热力学数据联系起来。本章先比较三种酸碱理论（9.1），再讨论水的解离与 pH（9.2）、弱酸弱碱（9.3）、盐溶液（9.4）与缓冲溶液（9.5）的平衡计算，简要介绍酸碱滴定（9.6），最后讨论配合物在溶液中的解离平衡（9.7）。计算的共同方法是：写出所有平衡，找出起主导作用的一个，作合理的近似，最后检验近似是否成立；近似不成立时，用电荷平衡与物料平衡列出方程，数值求解。质子条件与分布系数的系统处理、滴定曲线与终点误差、EDTA 与条件稳定常数见[分析化学](/6.4)；活度系数与离子强度见[物理化学](/6.3)。

本章平衡常数表达式中的 $[\mathrm{B}]$ 一律表示物种 B 的平衡浓度除以 $c^\circ = 1\,\mathrm{mol\,L^{-1}}$ 所得的相对浓度（数值上等于以 $\mathrm{mol\,L^{-1}}$ 为单位的浓度），因此 $K_{\mathrm{a}}$、$K_{\mathrm{b}}$、$K_{\mathrm{w}}$、$\beta_n$ 等都是量纲一的标准平衡常数；严格地说，其中的浓度应为**活度**（[6.1.8](/6.1.8)），本章按理想稀溶液处理。除特别说明外，数据都是 $25\,^\circ\mathrm{C}$（$298.15\,\mathrm{K}$）的值，酸碱常数取自 CRC Handbook of Chemistry and Physics。

## 9.1. 酸碱理论

酸类与碱类物质为什么各有一些共同的性质？早期认为酸的共性来自氧（Lavoisier），19 世纪初改为来自氢；19 世纪末的电离理论给出了第一个定量的近代酸碱理论，此后又发展出质子理论与电子理论。三种理论的适用范围依次扩大。

### 9.1.1. 酸碱电离理论

**定义 9.1.1（电离理论）** Arrhenius（1884）的**电离理论**认为：在水溶液中电离出的阳离子全部是 $\ce{H+}$ 的物质是酸，电离出的阴离子全部是 $\ce{OH-}$ 的物质是碱，酸碱中和反应的实质是 $\ce{H+ + OH- -> H2O}$。

例如 $\ce{H2SO4 -> H+ + HSO4-}$，$\ce{NaOH -> Na+ + OH-}$。酸碱的强弱用电离的程度衡量。

**定义 9.1.2** 电离平衡时，弱电解质已电离的分子数占原有分子总数的百分数称为**电离度**（解离度），记作 $\alpha$。

电离理论第一次从物质的组成解释了酸碱的性质，并且可以用电离度与平衡常数定量地比较酸碱强弱，Arrhenius 因此获得 1903 年 Nobel 化学奖。它的局限是把酸碱限制在水溶液中，把碱限制为氢氧化物：$\ce{NH3}$ 的水溶液呈碱性，但溶液中并不存在 $\ce{NH4OH}$ 分子；气相中 $\ce{HCl}$ 与 $\ce{NH3}$ 直接生成 $\ce{NH4Cl}$ 的反应也无法归入酸碱反应。（中文教材常把氨水写作 $\ce{NH3*H2O}$，溶液中实际是被水合的 $\ce{NH3}$ 分子，本站写作 $\ce{NH3(aq)}$。）

### 9.1.2. 酸碱质子理论

**定义 9.1.3（酸碱质子理论）** Brønsted 与 Lowry（1923）的**酸碱质子理论**认为：凡是能给出质子（$\ce{H+}$）的分子或离子都是酸（质子给予体），凡是能接受质子的分子或离子都是碱（质子接受体）。

酸给出质子后变成碱，碱接受质子后变成酸，两者在对质子的关系上统一起来：

$$
\text{酸} \ce{<=>} \text{碱} + \ce{H+}: \qquad \ce{HAc <=> Ac- + H+}, \quad \ce{NH4+ <=> NH3 + H+}, \quad \ce{H2PO4- <=> HPO4^2- + H+}.
$$

**定义 9.1.4（共轭酸碱对）** 只相差一个质子、可以通过给出或接受质子相互转化的一对酸和碱称为**共轭酸碱对**，其中的酸称为该碱的共轭酸，碱称为该酸的共轭碱。

**定义 9.1.5（两性物质）** 在一定条件下能给出质子、在另一条件下又能接受质子的物质称为**两性物质**，如 $\ce{H2O}$、$\ce{HCO3-}$、$\ce{H2PO4-}$、$\ce{HS-}$。

质子理论中的酸和碱可以是分子、阳离子或阴离子；没有"盐"的概念，盐的组成离子分别是离子酸或离子碱，如 $\ce{NH4Cl}$ 中 $\ce{NH4+}$ 是离子酸、$\ce{Cl-}$ 是（极弱的）离子碱。

半反应"酸 ⇌ 碱 + H⁺"不能单独发生，因为溶液中不存在游离的质子；实际的酸碱反应是两个共轭酸碱对之间的质子传递：

$$
\text{酸}_1 + \text{碱}_2 \ce{<=>} \text{碱}_1 + \text{酸}_2.
$$

电离理论中的各种反应都统一为质子传递：

| 电离理论的说法 | 质子传递反应 | 酸$_1$ / 碱$_1$ | 碱$_2$ / 酸$_2$ |
|---|---|---|---|
| 酸的电离 | $\ce{HAc + H2O <=> H3O+ + Ac-}$ | $\ce{HAc}$ / $\ce{Ac-}$ | $\ce{H2O}$ / $\ce{H3O+}$ |
| 碱的电离 | $\ce{H2O + NH3 <=> NH4+ + OH-}$ | $\ce{H2O}$ / $\ce{OH-}$ | $\ce{NH3}$ / $\ce{NH4+}$ |
| 中和 | $\ce{H3O+ + OH- <=> H2O + H2O}$ | $\ce{H3O+}$ / $\ce{H2O}$ | $\ce{OH-}$ / $\ce{H2O}$ |
| 中和 | $\ce{HAc + OH- <=> H2O + Ac-}$ | $\ce{HAc}$ / $\ce{Ac-}$ | $\ce{OH-}$ / $\ce{H2O}$ |
| 盐的水解 | $\ce{Ac- + H2O <=> HAc + OH-}$ | $\ce{H2O}$ / $\ce{OH-}$ | $\ce{Ac-}$ / $\ce{HAc}$ |
| 盐的水解 | $\ce{NH4+ + H2O <=> NH3 + H3O+}$ | $\ce{NH4+}$ / $\ce{NH3}$ | $\ce{H2O}$ / $\ce{H3O+}$ |
| 水合离子的水解 | $\ce{[Cu(H2O)4]^2+ + H2O <=> [Cu(OH)(H2O)3]+ + H3O+}$ | $\ce{[Cu(H2O)4]^2+}$ / $\ce{[Cu(OH)(H2O)3]+}$ | $\ce{H2O}$ / $\ce{H3O+}$ |
| 气相反应 | $\ce{HCl(g) + NH3(g) -> NH4Cl(s)}$ | $\ce{HCl}$ / $\ce{Cl-}$ | $\ce{NH3}$ / $\ce{NH4+}$ |

水在这里既作酸又作碱，是最重要的两性物质。下文为简洁，常把 $\ce{H3O+}$ 写作 $\ce{H+}$。

下面讨论酸碱的强弱与溶剂的关系。酸越强，它的共轭碱越弱；碱越强，它的共轭酸越弱（9.3.1 给出定量关系 $K_{\mathrm{a}}K_{\mathrm{b}} = K_{\mathrm{w}}$）：

$$
\text{酸性：}\ce{HClO4} > \ce{H2SO4} > \ce{H3PO4} > \ce{HAc} > \ce{H2CO3} > \ce{NH4+} > \ce{H2O}; \qquad \text{碱性：}\ce{ClO4-} < \ce{HSO4-} < \ce{H2PO4-} < \ce{Ac-} < \ce{HCO3-} < \ce{NH3} < \ce{OH-}.
$$

质子传递反应总是由较强的酸与较强的碱向生成较弱的酸与较弱的碱的方向进行。酸碱的强度首先取决于物质本身给出或接受质子的能力，其次与溶剂接受或给出质子的能力有关：同一种酸在碱性越强的溶剂中显得越强。

**定义 9.1.6** 溶剂把不同强度的酸（或碱）都转化为溶剂化质子 $\ce{H3O+}$（或溶剂的共轭碱），使它们的强度看起来相同的作用称为溶剂的**拉平效应**；能把酸（或碱）的相对强弱区分开来的作用称为溶剂的**区分效应**。

$\ce{HClO4}$、$\ce{HCl}$、$\ce{HNO3}$、$\ce{H2SO4}$（第一步）在水中都完全转化为 $\ce{H3O+}$：水中能存在的最强的酸就是 $\ce{H3O+}$，水是这些强酸的拉平溶剂。以碱性比水弱的冰醋酸为溶剂，它们只部分解离，可以区分出强弱顺序 $\ce{HClO4} > \ce{H2SO4} > \ce{HCl} > \ce{HNO3}$，冰醋酸是它们的区分溶剂。反过来，在碱性很强的液氨中，$\ce{HCl}$ 和 $\ce{HAc}$ 都完全转化为 $\ce{NH4+}$，都是强酸；在水中 $\ce{HCl}$ 是强酸而 $\ce{HAc}$ 是弱酸，水对这两种酸是区分溶剂。对大多数弱酸，水是很好的区分溶剂。

质子理论扩大了酸碱的范围（包括非水体系与气相反应），揭示了酸碱反应的实质是质子传递，又沿用了电离理论中定量衡量酸碱强度的常数，并解释了强酸强度的溶剂依赖性。它的局限是：不含氢的物质之间的反应（如 $\ce{BF3 + F- -> BF4-}$、$\ce{CaO + SO3 -> CaSO4}$）无法归入酸碱反应。

### 9.1.3. 酸碱电子理论

**定义 9.1.7（Lewis 酸碱）** Lewis（1923）提出：凡是能接受电子对的分子、离子或原子称为 **Lewis 酸**（电子对接受体），如 $\ce{H+}$、$\ce{Fe^3+}$、$\ce{Ag+}$、$\ce{BF3}$；凡是能给出电子对的分子或离子称为 **Lewis 碱**（电子对给予体），如 $\ce{NH3}$、$\ce{H2O}$、$\ce{CO}$、$\ce{F-}$、$\ce{OH-}$。

Lewis 酸碱反应的实质是生成**配位键**（[6.1.3](/6.1.3)），产物称为酸碱加合物。**配位化合物**（[6.1.5](/6.1.5)）就是典型的酸碱加合物：$\ce{Cu^2+ + 4NH3 -> [Cu(NH3)4]^2+}$ 中 $\ce{Cu^2+}$ 是酸，$\ce{NH3}$ 是碱。质子理论中的碱都是 Lewis 碱（它们用**孤对电子**接受质子），$\ce{H+}$ 是 Lewis 酸，所以质子理论是电子理论的特例。一种物质是酸还是碱，要在具体反应中确定：$\ce{H2O}$ 与 $\ce{H+}$ 结合时是碱，与 $\ce{NH3}$ 作用时提供 $\ce{H+}$，相当于酸。

**例 9.1.1** 指出下列反应中的 Lewis 酸和碱：(1) $\ce{BrF3 + F- -> [BrF4]-}$；(2) $\ce{(CH3)2CO + I2 -> (CH3)2CO*I2}$；(3) $\ce{KH + H2O -> KOH + H2}$。

**解** (1) $\ce{BrF3}$ 是酸，$\ce{F-}$ 是碱。(2) 丙酮是碱，$\ce{I2}$ 是酸：丙酮羰基 O 上的孤对电子进入 $\ce{I2}$ 空的 σ* 反键轨道，形成电荷转移配合物（$\ce{I2}$ 在丙酮中呈棕色而在 $\ce{CCl4}$ 中呈紫色，就是这个原因）。(3) 离子型氢化物提供碱 $\ce{H-}$，与水中的酸 $\ce{H+}$ 结合成 $\ce{H2}$。

电子理论摆脱了酸碱必须含某种元素、必须在某种溶剂中的限制，从电子对的给出与接受揭示了酸碱的本质，范围最广。它的局限是过于笼统：几乎所有化合物都可以看作酸碱加合物，而且没有统一的定量强度标度，同一个 Lewis 碱对不同的 Lewis 酸的强弱顺序可以不同。软硬酸碱原理部分弥补了这一不足。

### 9.1.4. 软硬酸碱原理

Lewis 酸与 Lewis 碱都可以分为硬、软两类，划分依据是接受或给出电子对的原子的**极化率**（[6.1.4](/6.1.4)）：

- 硬碱：配位原子电负性大、半径小、难被氧化、不易变形，如 $\ce{F-}$、$\ce{OH-}$、$\ce{H2O}$；软碱：配位原子电负性小、半径大、易被氧化、容易变形，如 $\ce{I-}$、$\ce{S^2-}$、$\ce{CN-}$。
- 硬酸：电荷高、半径小、外层电子被束缚得紧、不易变形的阳离子，如 $\ce{H+}$、$\ce{Al^3+}$、$\ce{Fe^3+}$；软酸：电荷低、半径大、外层电子（尤其 d 电子）束缚得松、易变形的阳离子，如 $\ce{Cu+}$、$\ce{Ag+}$、$\ce{Hg^2+}$。
- 介于两者之间的称为交界酸、交界碱。

| | 硬 | 交界 | 软 |
|---|---|---|---|
| 酸 | $\ce{H+}$、$\ce{Li+}$、$\ce{Na+}$、$\ce{K+}$、$\ce{Be^2+}$、$\ce{Mg^2+}$、$\ce{Ca^2+}$、$\ce{Al^3+}$、$\ce{Cr^3+}$、$\ce{Fe^3+}$、$\ce{Ti^4+}$、$\ce{BF3}$、$\ce{SO3}$ | $\ce{Fe^2+}$、$\ce{Co^2+}$、$\ce{Ni^2+}$、$\ce{Cu^2+}$、$\ce{Zn^2+}$、$\ce{Pb^2+}$、$\ce{SO2}$、$\ce{BBr3}$ | $\ce{Cu+}$、$\ce{Ag+}$、$\ce{Au+}$、$\ce{Tl+}$、$\ce{Hg2^2+}$、$\ce{Hg^2+}$、$\ce{Cd^2+}$、$\ce{Pd^2+}$、$\ce{Pt^2+}$、$\ce{BH3}$ |
| 碱 | $\ce{F-}$、$\ce{OH-}$、$\ce{H2O}$、$\ce{O^2-}$、$\ce{NH3}$、$\ce{CO3^2-}$、$\ce{NO3-}$、$\ce{SO4^2-}$、$\ce{ClO4-}$、$\ce{NCS-}$（N 端） | $\ce{NO2-}$、$\ce{SO3^2-}$、$\ce{Br-}$、$\ce{N3-}$、$\ce{N2}$、$\ce{C5H5N}$ | $\ce{H-}$、$\ce{I-}$、$\ce{S^2-}$、$\ce{CN-}$、$\ce{CO}$、$\ce{SCN-}$（S 端）、$\ce{R2S}$、$\ce{R3P}$、$\ce{C6H6}$ |

（硫氰酸根是两可配体：以 N 原子配位时是硬碱，以 S 原子配位时是软碱，表中分列两处。一价汞以双核离子 $\ce{Hg2^2+}$ 存在。）

**定义 9.1.8（软硬酸碱原理）** Pearson（1963）总结的**软硬酸碱原理**（HSAB）：硬酸优先与硬碱结合，软酸优先与软碱结合，即"硬亲硬、软亲软"，由此生成的加合物较稳定；交界酸碱与软、硬酸碱结合的倾向相差不大。

大体上，硬酸与硬碱之间以静电作用（离子键）为主，软酸与软碱之间以共价作用为主。它是定性的经验规则，但能解释许多现象：

- $\ce{NCS-}$ 与硬酸 $\ce{Fe^3+}$ 结合时以 N 配位（$\ce{[Fe(NCS)]^2+}$，血红色），与软酸 $\ce{Hg^2+}$ 结合时以 S 配位（$\ce{[Hg(SCN)4]^2-}$）。
- $\ce{AgF}$ 易溶而 $\ce{AgI}$ 极难溶（[6.1.4](/6.1.4) 用**离子极化**解释了同一现象）；$\ce{Ag+}$ 与 $\ce{I-}$、$\ce{CN-}$ 的配合物远比与 $\ce{F-}$ 的稳定。

**例 9.1.2** Ni、Cu 的常见矿物是硫化物（镍黄铁矿、黄铜矿），而 Al、Ca 的矿物是氧化物与碳酸盐（铝土矿、石灰石）。用软硬酸碱原理解释。

**解** $\ce{O^2-}$ 与 $\ce{CO3^2-}$ 是硬碱，$\ce{S^2-}$ 是软碱；$\ce{Al^3+}$、$\ce{Ca^2+}$ 是硬酸，$\ce{Ni^2+}$、$\ce{Cu^2+}$ 是交界酸，比它们软得多（$\ce{Cu+}$ 更是软酸）。硬酸与硬碱结合成氧化物与碳酸盐，较软的酸与软碱结合成硫化物。地球化学中据此把元素分为亲石元素与亲铜元素。

## 9.2. 溶液的酸碱性

### 9.2.1. 水的解离平衡

纯水有微弱的导电性，说明水能发生自耦解离（质子自递）：

$$
\ce{H2O(l) + H2O(l) <=> H3O+(aq) + OH-(aq)}, \qquad \text{简写为} \quad \ce{H2O <=> H+ + OH-}.
$$

**定义 9.2.1** 水的自耦解离反应的标准平衡常数

$$
K_{\mathrm{w}} = [\ce{H+}][\ce{OH-}]
$$
称为**水的离子积**（水的离子积常数）。

纯水作溶剂，活度为 1，不写入表达式。$25\,^\circ\mathrm{C}$ 时 $K_{\mathrm{w}} = 1.0 \times 10^{-14}$（$\mathrm{p}K_{\mathrm{w}} = 14.00$），纯水中 $[\ce{H+}] = [\ce{OH-}] = 1.0 \times 10^{-7}$。这个数值可以由热力学数据算出：由 $\Delta_{\mathrm{f}}G^\circ(\ce{H2O}, \mathrm{l}) = -237.1\,\mathrm{kJ\,mol^{-1}}$、$\Delta_{\mathrm{f}}G^\circ(\ce{OH-}, \mathrm{aq}) = -157.2\,\mathrm{kJ\,mol^{-1}}$（约定 $\Delta_{\mathrm{f}}G^\circ(\ce{H+}, \mathrm{aq}) = 0$），$\Delta_{\mathrm{r}}G^\circ_{\mathrm{m}} = 79.9\,\mathrm{kJ\,mol^{-1}}$，按式 (8.3)

$$
K_{\mathrm{w}} = \exp\left(-\frac{79.9 \times 10^3}{8.314 \times 298.15}\right) = 1.0 \times 10^{-14}.
$$

水的解离是中和反应的逆反应，是吸热的（$\Delta_{\mathrm{r}}H^\circ_{\mathrm{m}} = 55.8\,\mathrm{kJ\,mol^{-1}}$），由 **van 't Hoff 方程**，温度升高 $K_{\mathrm{w}}$ 增大：

| $t/{}^\circ\mathrm{C}$ | 0 | 10 | 25 | 37 | 50 | 100 |
|---|---|---|---|---|---|---|
| $\mathrm{p}K_{\mathrm{w}}$ | 14.94 | 14.53 | 14.00 | 13.62 | 13.26 | 12.26 |
| 中性溶液的 pH | 7.47 | 7.27 | 7.00 | 6.81 | 6.63 | 6.13 |

$K_{\mathrm{w}}$ 是 $[\ce{H+}]$ 与 $[\ce{OH-}]$ 之间的约束：任何水溶液中两者的乘积都等于 $K_{\mathrm{w}}$，知道一个就能求另一个。溶液的酸碱性由两者的相对大小决定：$[\ce{H+}] > [\ce{OH-}]$ 为酸性，$[\ce{H+}] = [\ce{OH-}]$ 为中性，$[\ce{H+}] < [\ce{OH-}]$ 为碱性。"中性即 $[\ce{H+}] = 10^{-7}$、pH = 7"只在 $25\,^\circ\mathrm{C}$ 成立：体温 $37\,^\circ\mathrm{C}$ 时中性溶液的 pH 是 6.81，pH 7.4 的血液是弱碱性的。

### 9.2.2. pH

$[\ce{H+}]$ 的变化范围很宽（$1$ 到 $10^{-14}$ 量级），用对数标度更方便。

**定义 9.2.2（pH）** 溶液的 **pH** 定义为氢离子活度的负常用对数：

$$
\mathrm{pH} = -\lg a_{\ce{H+}} \approx -\lg\frac{[\ce{H+}]}{c^\circ}.
$$
类似地，$\mathrm{pOH} = -\lg a_{\ce{OH-}}$，$\mathrm{p}K = -\lg K$。

后一个近似式（Sørensen 1909 年的原始定义）在稀溶液中成立；单个离子的活度无法严格测定，实际的 pH 由标准缓冲溶液与 pH 计按操作定义测得（[分析化学](/6.4)）。由 $K_{\mathrm{w}} = [\ce{H+}][\ce{OH-}]$ 取对数，

$$
\mathrm{pH} + \mathrm{pOH} = \mathrm{p}K_{\mathrm{w}} = 14.00 \quad (25\,^\circ\mathrm{C}).
$$
pH 每减小 1，$[\ce{H+}]$ 增大到 10 倍。pH 的常用范围是 0–14，但并不以此为限：$1\,\mathrm{mol\,L^{-1}}$ 强酸的 pH 约为 0，更浓的强酸 pH 为负值；浓溶液中活度与浓度相差很大，近似式已不适用。

### 9.2.3. 酸碱指示剂

**定义 9.2.3** 在一定 pH 范围内因自身的酸式与碱式结构不同而显示不同颜色、可以用来指示溶液 pH 的有机弱酸或弱碱称为**酸碱指示剂**。

以 HIn 表示指示剂的酸式，$\ce{In-}$ 表示碱式：

$$
\ce{HIn <=> H+ + In-}, \qquad K_{\mathrm{a}}(\ce{HIn}) = \frac{[\ce{H+}][\ce{In-}]}{[\ce{HIn}]}, \qquad \frac{[\ce{In-}]}{[\ce{HIn}]} = \frac{K_{\mathrm{a}}(\ce{HIn})}{[\ce{H+}]}.
$$
溶液的颜色取决于 $[\ce{In-}]/[\ce{HIn}]$，即取决于 pH。人眼一般在一种形式的浓度达到另一种的 10 倍左右时，才能只看到该形式的颜色：$[\ce{In-}]/[\ce{HIn}] \le 1/10$ 时显酸式色，$\ge 10$ 时显碱式色，两者之间显混合色。

**定义 9.2.4** 指示剂由酸式色变为碱式色的 pH 区间称为**变色范围**，理论上为 $\mathrm{pH} = \mathrm{p}K_{\mathrm{a}}(\ce{HIn}) \pm 1$；$\mathrm{pH} = \mathrm{p}K_{\mathrm{a}}(\ce{HIn})$ 处称为理论变色点。

实际的变色范围由目测确定，由于人眼对不同颜色的敏感程度不同，往往不正好是 $\mathrm{p}K_{\mathrm{a}} \pm 1$，宽度也多小于 2 个 pH 单位：

| 指示剂 | 变色范围 | 酸式色 → 碱式色 |
|---|---|---|
| 甲基橙 | 3.1–4.4 | 红 → 黄 |
| 甲基红 | 4.4–6.2 | 红 → 黄 |
| 石蕊 | 5.0–8.0 | 红 → 蓝 |
| 溴百里酚蓝 | 6.0–7.6 | 黄 → 蓝 |
| 酚酞 | 8.0–10.0 | 无色 → 红 |

颜色的改变来自结构的改变。酚酞在酸性与中性溶液中是无色的内酯式（1），三个苯环之间没有共轭；在碱性溶液中开环成醌式二价阴离子（2），形成贯穿整个分子的共轭体系，吸收移到可见光区而显红色。甲基橙的碱式（3）是黄色的偶氮化合物，在酸中偶氮基上的 N 质子化，得到共轭更长的醌式结构（4），显红色：

```smiles
O=C1OC(c2ccccc12)(c1ccc(O)cc1)c1ccc(O)cc1 1
[O-]C(=O)c1ccccc1C(=C1C=CC(=O)C=C1)c1ccc([O-])cc1 2
```

```smiles
CN(C)c1ccc(cc1)N=Nc1ccc(cc1)S(=O)(=O)[O-] 3
C[N+](C)=C1C=CC(C=C1)=NNc1ccc(cc1)S(=O)(=O)[O-] 4
```

把几种变色范围不同的指示剂混合，制成在不同 pH 显示不同颜色的混合指示剂，浸在纸上就是 pH 试纸。

## 9.3. 弱酸弱碱的解离平衡

### 9.3.1. 解离常数

**定义 9.3.1** 弱酸 HA 在水中的解离 $\ce{HA + H2O <=> H3O+ + A-}$（简写 $\ce{HA <=> H+ + A-}$）的标准平衡常数

$$
K_{\mathrm{a}} = \frac{[\ce{H+}][\ce{A-}]}{[\ce{HA}]}
$$
称为**酸解离常数**；弱碱 B 的解离 $\ce{B + H2O <=> BH+ + OH-}$ 的标准平衡常数

$$
K_{\mathrm{b}} = \frac{[\ce{BH+}][\ce{OH-}]}{[\ce{B}]}
$$
称为**碱解离常数**。

例如 $K_{\mathrm{a}}(\ce{HAc}) = 1.75 \times 10^{-5}$，$K_{\mathrm{b}}(\ce{NH3}) = 1.8 \times 10^{-5}$。解离常数与 $K^\circ$ 一样只与温度有关，与浓度无关。同温度下 $K_{\mathrm{a}}$ 越大，酸越强。一般把 $K_{\mathrm{a}}$ 在 $10^{-2}$–$10^{-7}$ 的酸称为弱酸，$K_{\mathrm{a}} < 10^{-7}$ 的称为极弱酸。

**定理 9.3.1** 共轭酸碱对 HA–$\ce{A-}$ 的解离常数满足

$$
K_{\mathrm{a}}(\ce{HA})\,K_{\mathrm{b}}(\ce{A-}) = K_{\mathrm{w}}, \qquad \mathrm{p}K_{\mathrm{a}} + \mathrm{p}K_{\mathrm{b}} = \mathrm{p}K_{\mathrm{w}}. \tag{9.1}
$$

**证明** $\ce{A-}$ 作为碱的解离是 $\ce{A- + H2O <=> HA + OH-}$，$K_{\mathrm{b}} = \frac{[\ce{HA}][\ce{OH-}]}{[\ce{A-}]}$。它与 $\ce{HA <=> H+ + A-}$ 相加得 $\ce{H2O <=> H+ + OH-}$，由**多重平衡规则**（定理 8.2.1），$K_{\mathrm{a}}K_{\mathrm{b}} = K_{\mathrm{w}}$。直接把两个表达式相乘也得到同一结果。$\square$

式 (9.1) 把"酸越强，共轭碱越弱"定量化了，所以表中只需列出 $K_{\mathrm{a}}$ 或 $\mathrm{p}K_{\mathrm{a}}$：

| 酸 | $\mathrm{p}K_{\mathrm{a}}$ | $K_{\mathrm{a}}$ | 酸 | $\mathrm{p}K_{\mathrm{a}}$ | $K_{\mathrm{a}}$ |
|---|---|---|---|---|---|
| $\ce{H2C2O4}$ | 1.25，3.81 | $5.6\times10^{-2}$，$1.5\times10^{-4}$ | $\ce{H2CO3}$ | 6.35，10.33 | $4.5\times10^{-7}$，$4.7\times10^{-11}$ |
| $\ce{H3PO4}$ | 2.16，7.21，12.32 | $6.9\times10^{-3}$，$6.2\times10^{-8}$，$4.8\times10^{-13}$ | $\ce{H2S}$ | 7.05，约 19 | $8.9\times10^{-8}$，约 $10^{-19}$ |
| HF | 3.20 | $6.3\times10^{-4}$ | $\ce{HCN}$ | 9.21 | $6.2\times10^{-10}$ |
| $\ce{HNO2}$ | 3.25 | $5.6\times10^{-4}$ | $\ce{NH4+}$ | 9.25 | $5.6\times10^{-10}$ |
| HCOOH | 3.75 | $1.8\times10^{-4}$ | $\ce{H3BO3}$ | 9.27 | $5.4\times10^{-10}$ |
| $\ce{HAc}$ | 4.76 | $1.75\times10^{-5}$ | $\ce{H2O}$ | 14.00 | $1.0\times10^{-14}$（即 $K_{\mathrm{w}}$） |

（HAc 即乙酸 $\ce{CH3COOH}$，Ac 代表乙酸根；$\ce{NH4+}$ 的 $K_{\mathrm{a}} = K_{\mathrm{w}}/K_{\mathrm{b}}(\ce{NH3})$。）乙酸与乙酸根、磷酸的结构如下（解离的是与电负性大的 O 相连的 H，甲基上的 H 不解离）：

```smiles
CC(=O)O HAc
CC(=O)[O-] Ac-
OP(=O)(O)O H3PO4
```

### 9.3.2. 一元弱酸弱碱溶液的 pH

**例 9.3.1** 计算 $0.10\,\mathrm{mol\,L^{-1}}$ HAc 溶液的 $[\ce{H+}]$、pH 与解离度。

**解** 溶液中有两个平衡：$\ce{HAc <=> H+ + Ac-}$（$K_{\mathrm{a}} = 1.75 \times 10^{-5}$）与 $\ce{H2O <=> H+ + OH-}$（$K_{\mathrm{w}} = 10^{-14}$）。$K_{\mathrm{a}}c \gg K_{\mathrm{w}}$，水解离产生的 $\ce{H+}$ 可以忽略。设 $[\ce{H+}] = x$：

| | $\ce{HAc}$ | $\ce{H+}$ | $\ce{Ac-}$ |
|---|---|---|---|
| 初始 | 0.10 | 0 | 0 |
| 平衡 | $0.10 - x$ | $x$ | $x$ |

$$
K_{\mathrm{a}} = \frac{x^2}{0.10 - x} = 1.75 \times 10^{-5}.
$$
解一元二次方程 $x^2 + K_{\mathrm{a}}x - K_{\mathrm{a}}c = 0$，得 $x = 1.31 \times 10^{-3}$。若认为 $x \ll 0.10$、$0.10 - x \approx 0.10$，则 $x = \sqrt{K_{\mathrm{a}}c} = 1.32 \times 10^{-3}$，两者只差 0.7%。$\mathrm{pH} = 2.88$，解离度 $\alpha = x/c = 1.3\%$。

一般地，浓度为 $c$ 的一元弱酸，在可以忽略水的解离时

$$
[\ce{H+}] = \frac{-K_{\mathrm{a}} + \sqrt{K_{\mathrm{a}}^2 + 4K_{\mathrm{a}}c}}{2} \approx \sqrt{K_{\mathrm{a}}c}; \qquad \text{一元弱碱：}\ [\ce{OH-}] \approx \sqrt{K_{\mathrm{b}}c}. \tag{9.2}
$$

近似式在什么条件下可用？记 $r = c/K_{\mathrm{a}}$，精确解为 $[\ce{H+}]/K_{\mathrm{a}} = \frac{1}{2}(\sqrt{1 + 4r} - 1)$，近似解为 $\sqrt r$。对大的 $r$，$\sqrt{1 + 4r} = 2\sqrt r\sqrt{1 + 1/(4r)} \approx 2\sqrt r + \frac{1}{4\sqrt r}$，于是精确解 $\approx \sqrt r - \frac{1}{2}$，近似式的相对误差

$$
\varepsilon = \frac{\sqrt r}{\sqrt r - 1/2} - 1 \approx \frac{1}{2\sqrt r} \approx \frac{\alpha}{2}.
$$
近似式总是偏大，误差约为解离度的一半。教材中的判据 $c/K_{\mathrm{a}} \ge 400$ 对应 $\sqrt r \ge 20$：误差约 2.5%（相当于 pH 只差 0.01），解离度约 5%。所以"$c/K_{\mathrm{a}} \ge 400$"与"解离度小于 5%"是同一个条件。不满足时应解一元二次方程。

![一元弱酸用 √(Ka c) 近似时 [H⁺] 的相对误差与解离度随 c/Ka 的变化：误差约为解离度的一半，c/Ka = 400 时误差 2.5%、解离度 4.9%](./plots/weak-acid-approximation.py)

忽略水的解离也有条件。由溶液的电中性，$[\ce{H+}] = [\ce{A-}] + [\ce{OH-}]$；酸解离很少时 $[\ce{A-}] \approx K_{\mathrm{a}}c/[\ce{H+}]$，代入得 $[\ce{H+}] \approx \sqrt{K_{\mathrm{a}}c + K_{\mathrm{w}}}$。当 $K_{\mathrm{a}}c \ge 20K_{\mathrm{w}}$ 时，略去 $K_{\mathrm{w}}$ 的误差不超过 2.5%。极稀或极弱的酸（如 $10^{-6}\,\mathrm{mol\,L^{-1}}$ 的 $\ce{HCN}$）不满足这一条件，必须同时考虑水的解离。

### 9.3.3. 解离度与稀释定律

解离度 $\alpha$ 与 $K_{\mathrm{a}}$ 都能表示弱酸解离的程度，但 $K_{\mathrm{a}}$ 只与温度有关，$\alpha$ 还随浓度变化。由 $K_{\mathrm{a}} = \frac{c\alpha^2}{1 - \alpha}$，$\alpha$ 很小时：

**定理 9.3.2（稀释定律）** 一元弱酸（弱碱）的解离度与浓度的平方根成反比、与解离常数的平方根成正比：

$$
\alpha \approx \sqrt{\frac{K_{\mathrm{a}}}{c}} \qquad \left(\text{弱碱：}\ \alpha \approx \sqrt{\frac{K_{\mathrm{b}}}{c}}\right).
$$

这是 Ostwald（1888）由质量作用定律导出的，它也是电离理论的早期验证。溶液越稀，解离度越大；但 $[\ce{H+}] = c\alpha \approx \sqrt{K_{\mathrm{a}}c}$ 仍随稀释而减小。所以"浓度越大，解离度越小"并不意味着 $[\ce{H+}]$ 越小。

### 9.3.4. 同离子效应

在 HAc 溶液中加入 NaAc，$[\ce{Ac-}]$ 增大，$Q > K_{\mathrm{a}}$，平衡 $\ce{HAc <=> H+ + Ac-}$ 向左移动，HAc 的解离度减小。

**定义 9.3.2（同离子效应）** 在已建立解离平衡的弱电解质溶液中，加入含有相同离子的强电解质，使弱电解质的解离度降低的作用称为**同离子效应**。

**例 9.3.2** 在 $0.10\,\mathrm{mol\,L^{-1}}$ HAc 溶液中加入固体 NaAc，使 NaAc 的浓度为 $0.10\,\mathrm{mol\,L^{-1}}$（体积变化忽略）。求溶液的 $[\ce{H+}]$ 与 HAc 的解离度。

**解** 设 $[\ce{H+}] = x$，则 $[\ce{HAc}] = 0.10 - x \approx 0.10$，$[\ce{Ac-}] = 0.10 + x \approx 0.10$（同离子效应使 $x$ 更小，近似更好）：

$$
K_{\mathrm{a}} = \frac{x \times 0.10}{0.10} \quad\Longrightarrow\quad x = K_{\mathrm{a}} = 1.75 \times 10^{-5}, \qquad \alpha = \frac{x}{0.10} = 0.018\%.
$$
与例 9.3.1 相比，$[\ce{H+}]$ 从 $1.3 \times 10^{-3}$ 降到 $1.75 \times 10^{-5}$，解离度降到原来的约 1/75；加入的 NaAc 越多，降低越多。这个溶液就是 9.5 的缓冲溶液。同离子效应同样使难溶电解质的溶解度降低（[6.1.10](/6.1.10)）。

### 9.3.5. 多元弱酸

能给出两个或更多质子的弱酸分步解离。

**定义 9.3.3** 一个分子能给出两个或两个以上质子的弱酸称为**多元弱酸**，它的质子是逐级解离的，各级解离常数记作 $K_{\mathrm{a1}}, K_{\mathrm{a2}}, \dots$。

以 $\ce{H2S}$ 为例：

$$
\ce{H2S <=> H+ + HS-}, \quad K_{\mathrm{a1}} = \frac{[\ce{H+}][\ce{HS-}]}{[\ce{H2S}]}; \qquad \ce{HS- <=> H+ + S^2-}, \quad K_{\mathrm{a2}} = \frac{[\ce{H+}][\ce{S^2-}]}{[\ce{HS-}]}.
$$
两式相加得 $\ce{H2S <=> 2H+ + S^2-}$，$K = K_{\mathrm{a1}}K_{\mathrm{a2}} = \frac{[\ce{H+}]^2[\ce{S^2-}]}{[\ce{H2S}]}$。各级解离常数逐级显著减小：从带负电的 $\ce{HS-}$ 上再拿走一个质子比从中性分子上拿走难得多。溶液中各物种的浓度必须同时满足所有平衡（包括水的解离），但通常一个平衡占主导。

**例 9.3.3** 室温下饱和 $\ce{H2S}$ 水溶液中 $[\ce{H2S}] \approx 0.10\,\mathrm{mol\,L^{-1}}$。计算溶液中的 $[\ce{H+}]$、$[\ce{HS-}]$、$[\ce{S^2-}]$ 与 $[\ce{OH-}]$。$K_{\mathrm{a1}} = 8.9 \times 10^{-8}$。

**解** $K_{\mathrm{a1}} \gg K_{\mathrm{a2}}$，二级解离产生的 $\ce{H+}$ 可以忽略，按一元弱酸处理；$c/K_{\mathrm{a1}} > 400$，

$$
[\ce{H+}] \approx [\ce{HS-}] \approx \sqrt{K_{\mathrm{a1}}c} = \sqrt{8.9 \times 10^{-8} \times 0.10} = 9.4 \times 10^{-5}, \qquad \mathrm{pH} = 4.02.
$$
由二级解离 $K_{\mathrm{a2}} = [\ce{H+}][\ce{S^2-}]/[\ce{HS-}]$ 与 $[\ce{H+}] \approx [\ce{HS-}]$，得 $[\ce{S^2-}] \approx K_{\mathrm{a2}}$；$[\ce{OH-}] = K_{\mathrm{w}}/[\ce{H+}] = 1.1 \times 10^{-10}$。

由此得到两条一般规律：

1. 多元弱酸的 $K_{\mathrm{a1}} \gg K_{\mathrm{a2}} \gg \cdots$（相差 $10^3$ 倍以上）时，计算 $[\ce{H+}]$ 可以当作一元弱酸处理，$K_{\mathrm{a1}}$ 可以作为衡量其酸性强弱的标志。
2. 二元弱酸溶液中，酸根的浓度近似等于 $K_{\mathrm{a2}}$，与酸的浓度无关。

**注 9.3.1** $\ce{H2S}$ 的 $K_{\mathrm{a2}}$ 很难测定。许多教材至今沿用 $K_{\mathrm{a2}} \approx 10^{-13}$–$10^{-14}$，这些数值已经过时：$\ce{S^2-}$ 是极强的碱，在水中几乎完全转化为 $\ce{HS-}$，近几十年的 Raman 光谱与紫外光谱测定给出 $\mathrm{p}K_{\mathrm{a2}} \approx 17$–$19$，CRC Handbook 取 19。按此，例 9.3.3 中 $[\ce{S^2-}] \approx 10^{-19}\,\mathrm{mol\,L^{-1}}$，一升溶液中只有约 $6 \times 10^4$ 个 $\ce{S^2-}$ 离子：在水溶液中，$\ce{S^2-}$ 实际上不是一个有意义的物种。因此 [6.1.10](/6.1.10) 处理硫化物的溶解与沉淀时不经过 $[\ce{S^2-}]$，而用与 $K_{\mathrm{a2}}$ 无关的平衡常数。

由总反应的平衡常数还可以看出 pH 对酸根浓度的控制作用。对任意二元弱酸 $\ce{H2A}$，

$$
[\ce{A^2-}] = \frac{K_{\mathrm{a1}}K_{\mathrm{a2}}[\ce{H2A}]}{[\ce{H+}]^2}: \tag{9.3}
$$
在 $[\ce{H2A}]$ 一定时，酸根浓度与 $[\ce{H+}]^2$ 成反比，调节 pH 就能控制 $[\ce{A^2-}]$，进而控制 $\ce{CO3^2-}$、$\ce{C2O4^2-}$、$\ce{PO4^3-}$ 一类沉淀剂的有效浓度（[6.1.10](/6.1.10)）。

### 9.3.6. 分布系数

**定义 9.3.4** 弱酸溶液中某一物种的平衡浓度占该弱酸总浓度 $c$ 的分数称为该物种的**分布系数**，记作 $\delta$。

一元弱酸中 $c = [\ce{HA}] + [\ce{A-}]$，由 $K_{\mathrm{a}}$ 的表达式，

$$
\delta(\ce{HA}) = \frac{[\ce{H+}]}{[\ce{H+}] + K_{\mathrm{a}}}, \qquad \delta(\ce{A-}) = \frac{K_{\mathrm{a}}}{[\ce{H+}] + K_{\mathrm{a}}}.
$$
二元弱酸中，记 $D = [\ce{H+}]^2 + K_{\mathrm{a1}}[\ce{H+}] + K_{\mathrm{a1}}K_{\mathrm{a2}}$，

$$
\delta(\ce{H2A}) = \frac{[\ce{H+}]^2}{D}, \qquad \delta(\ce{HA-}) = \frac{K_{\mathrm{a1}}[\ce{H+}]}{D}, \qquad \delta(\ce{A^2-}) = \frac{K_{\mathrm{a1}}K_{\mathrm{a2}}}{D}.
$$
分布系数只是 pH 的函数，与总浓度无关。$\mathrm{pH} = \mathrm{p}K_{\mathrm{a}}$ 时共轭酸碱对的两种形式各占一半；pH 比 $\mathrm{p}K_{\mathrm{a}}$ 小 1，酸式占 91%；小 2，占 99%。

![乙酸、碳酸、磷酸各物种的分布系数随 pH 的变化：相邻两种形式的曲线在 pH = pKa 处相交](./plots/distribution-fractions.py)

从图中可以直接读出：血液的 pH 7.4 下，碳酸主要以 $\ce{HCO3-}$ 存在，磷酸以 $\ce{H2PO4-}$ 与 $\ce{HPO4^2-}$ 为主（这两点 9.5 要用到）；$\ce{PO4^3-}$ 只在强碱性溶液中才显著。多元酸的分布系数与多元酸、两性物质的系统处理见[分析化学](/6.4)。

## 9.4. 盐溶液的酸碱平衡

### 9.4.1. 盐的水解

$\ce{NaAc}$ 溶液呈碱性，$\ce{NH4Cl}$ 溶液呈酸性，而 $\ce{NaCl}$ 溶液呈中性。电离理论把它称为盐的水解。

**定义 9.4.1** 盐溶于水后，其组成离子与水发生质子传递、生成弱酸或弱碱，使水的解离平衡移动、溶液的 $[\ce{H+}]$ 与 $[\ce{OH-}]$ 不再相等的反应称为**盐的水解**。

在质子理论中，盐的水解就是离子酸或离子碱的解离，不需要另立理论：

- $\ce{Ac- + H2O <=> HAc + OH-}$ 是碱 $\ce{Ac-}$ 的解离，平衡常数就是 $K_{\mathrm{b}}(\ce{Ac-}) = K_{\mathrm{w}}/K_{\mathrm{a}}(\ce{HAc})$；
- $\ce{NH4+ + H2O <=> NH3 + H3O+}$ 是酸 $\ce{NH4+}$ 的解离，平衡常数是 $K_{\mathrm{a}}(\ce{NH4+}) = K_{\mathrm{w}}/K_{\mathrm{b}}(\ce{NH3})$。

中文教材常另设"水解常数 $K_{\mathrm{h}}$"，它就是共轭碱的 $K_{\mathrm{b}}$（或共轭酸的 $K_{\mathrm{a}}$），本站不另用这个符号。由式 (9.1)，原来的酸（碱）越弱，水解越强。强酸强碱盐（碱金属、碱土金属与 $\ce{HClO4}$、$\ce{HCl}$、$\ce{HNO3}$、$\ce{H2SO4}$ 形成的盐）的阴阳离子都是极弱的酸碱，不水解，溶液呈中性。水解程度可以用水解度 $h$（已水解的盐占盐的初始浓度的百分数）表示，它就是离子酸碱的解离度，$h \approx \sqrt{K_{\mathrm{b}}/c}$。

### 9.4.2. 弱酸强碱盐与强酸弱碱盐

**例 9.4.1** 计算 $0.10\,\mathrm{mol\,L^{-1}}$ NaAc 溶液的 pH。

**解** $K_{\mathrm{b}}(\ce{Ac-}) = \frac{K_{\mathrm{w}}}{K_{\mathrm{a}}(\ce{HAc})} = \frac{1.0 \times 10^{-14}}{1.75 \times 10^{-5}} = 5.7 \times 10^{-10}$。$c/K_{\mathrm{b}} > 400$，由式 (9.2)，

$$
[\ce{OH-}] = \sqrt{K_{\mathrm{b}}c} = \sqrt{5.7 \times 10^{-10} \times 0.10} = 7.6 \times 10^{-6}, \qquad \mathrm{pOH} = 5.12, \quad \mathrm{pH} = 8.88.
$$

**例 9.4.2** 计算 $0.10\,\mathrm{mol\,L^{-1}}$ $\ce{NH4Cl}$ 溶液的 pH 与 $\ce{NH4+}$ 的解离度（水解度）。

**解** $K_{\mathrm{a}}(\ce{NH4+}) = \frac{K_{\mathrm{w}}}{K_{\mathrm{b}}(\ce{NH3})} = 5.6 \times 10^{-10}$，$c/K_{\mathrm{a}} > 400$，$[\ce{H+}] = \sqrt{5.6 \times 10^{-10} \times 0.10} = 7.5 \times 10^{-6}$，$\mathrm{pH} = 5.13$；$h = 7.5 \times 10^{-6}/0.10 = 0.0075\%$。

多元弱酸强碱盐（$\ce{Na2CO3}$、$\ce{Na3PO4}$、$\ce{Na2S}$）的水解分级进行。以 $\ce{PO4^3-}$ 为例，三级 $K_{\mathrm{b}}$ 由式 (9.1) 与磷酸的三个 $K_{\mathrm{a}}$ 逆序配对：

$$
K_{\mathrm{b1}} = \frac{K_{\mathrm{w}}}{K_{\mathrm{a3}}} = 2.1 \times 10^{-2}, \qquad K_{\mathrm{b2}} = \frac{K_{\mathrm{w}}}{K_{\mathrm{a2}}} = 1.6 \times 10^{-7}, \qquad K_{\mathrm{b3}} = \frac{K_{\mathrm{w}}}{K_{\mathrm{a1}}} = 1.4 \times 10^{-12}.
$$
$K_{\mathrm{b1}} \gg K_{\mathrm{b2}}$，一般只考虑第一级。

**例 9.4.3** 计算 $0.10\,\mathrm{mol\,L^{-1}}$ $\ce{Na3PO4}$ 溶液的 pH。

**解** $c/K_{\mathrm{b1}} = 4.8 < 400$，$\ce{PO4^3-}$ 是相当强的碱，不能用近似式。设 $[\ce{OH-}] = x$：

$$
\frac{x^2}{0.10 - x} = 2.1 \times 10^{-2}, \qquad x^2 + 0.021x - 2.1 \times 10^{-3} = 0, \qquad x = 0.036.
$$
$\mathrm{pOH} = 1.44$，$\mathrm{pH} = 12.56$。约 36% 的 $\ce{PO4^3-}$ 转化为 $\ce{HPO4^2-}$；若误用 $\sqrt{K_{\mathrm{b1}}c}$，会得到 $x = 0.046$，偏大约 25%。$\ce{Na3PO4}$ 溶液的强碱性使它可用作洗涤剂与锅炉水处理剂。

### 9.4.3. 两性物质：电荷平衡、物料平衡与质子条件

$\ce{NaHCO3}$、$\ce{NaH2PO4}$、$\ce{Na2HPO4}$ 等酸式盐的阴离子既能给出质子又能接受质子：

$$
\ce{HCO3- <=> H+ + CO3^2-}\quad (K_{\mathrm{a2}} = 4.7 \times 10^{-11}), \qquad \ce{HCO3- + H2O <=> H2CO3 + OH-}\quad \left(K_{\mathrm{b}} = \frac{K_{\mathrm{w}}}{K_{\mathrm{a1}}} = 2.2 \times 10^{-8}\right).
$$
两个平衡同时进行、程度相近，不能只取一个。处理这类问题的一般方法是列出溶液必须满足的守恒关系。

**定义 9.4.2** 溶液中某一组分的分析浓度（总浓度）等于它在溶液中各种存在形式的平衡浓度之和，这一关系称为**物料平衡**；溶液保持电中性，阳离子所带正电荷的总浓度等于阴离子所带负电荷的总浓度，这一关系称为**电荷平衡**（每种离子的浓度乘以其电荷数）。

**定义 9.4.3** 酸碱反应达到平衡时，得到质子的物种所得质子的总量等于失去质子的物种所失质子的总量，这一关系式称为**质子条件**。写法：选择溶液中大量存在并参与质子传递的原始物种（及溶剂水）作为参考水准，比参考水准多质子的物种写在一边，少质子的物种写在另一边，浓度乘以得失质子的数目。

对浓度为 $c$ 的 $\ce{NaHCO3}$ 溶液：

- 物料平衡：$c = [\ce{H2CO3}] + [\ce{HCO3-}] + [\ce{CO3^2-}]$，且 $[\ce{Na+}] = c$；
- 电荷平衡：$[\ce{Na+}] + [\ce{H+}] = [\ce{HCO3-}] + 2[\ce{CO3^2-}] + [\ce{OH-}]$；
- 两式相减，消去 $[\ce{Na+}]$ 与 $[\ce{HCO3-}]$，得质子条件

$$
[\ce{H+}] + [\ce{H2CO3}] = [\ce{CO3^2-}] + [\ce{OH-}].
$$
以 $\ce{HCO3-}$ 和 $\ce{H2O}$ 为参考水准，可以直接写出同一结果：$\ce{H2CO3}$ 与 $\ce{H3O+}$ 比参考水准各多一个质子，$\ce{CO3^2-}$ 与 $\ce{OH-}$ 各少一个。

把 $[\ce{H2CO3}] = \frac{[\ce{H+}][\ce{HCO3-}]}{K_{\mathrm{a1}}}$、$[\ce{CO3^2-}] = \frac{K_{\mathrm{a2}}[\ce{HCO3-}]}{[\ce{H+}]}$、$[\ce{OH-}] = \frac{K_{\mathrm{w}}}{[\ce{H+}]}$ 代入质子条件，整理得

$$
[\ce{H+}] = \sqrt{\frac{K_{\mathrm{a2}}[\ce{HCO3-}] + K_{\mathrm{w}}}{1 + [\ce{HCO3-}]/K_{\mathrm{a1}}}}.
$$
这一步没有近似。$\ce{HCO3-}$ 两个方向的反应程度都很小，$[\ce{HCO3-}] \approx c$；若又有 $K_{\mathrm{a2}}c \gg K_{\mathrm{w}}$、$c \gg K_{\mathrm{a1}}$（浓度不太稀时成立），则

$$
[\ce{H+}] \approx \sqrt{K_{\mathrm{a1}}K_{\mathrm{a2}}}, \qquad \mathrm{pH} \approx \tfrac{1}{2}(\mathrm{p}K_{\mathrm{a1}} + \mathrm{p}K_{\mathrm{a2}}). \tag{9.4}
$$

**例 9.4.4** 估算 $0.10\,\mathrm{mol\,L^{-1}}$ $\ce{NaHCO3}$、$\ce{NaH2PO4}$、$\ce{Na2HPO4}$ 溶液的 pH。

**解** 由式 (9.4)：$\ce{NaHCO3}$，$\mathrm{pH} = \frac{1}{2}(6.35 + 10.33) = 8.34$（不作近似的式子给出同一值）；$\ce{NaH2PO4}$ 中 $\ce{H2PO4-}$ 介于 $\ce{H3PO4}$ 与 $\ce{HPO4^2-}$ 之间，$\mathrm{pH} = \frac{1}{2}(2.16 + 7.21) = 4.69$；$\ce{Na2HPO4}$，$\mathrm{pH} = \frac{1}{2}(7.21 + 12.32) = 9.77$。两性物质的酸碱性取决于它作为酸与作为碱的倾向哪个大：$\ce{H2PO4-}$ 的 $K_{\mathrm{a2}} = 6.2 \times 10^{-8}$ 大于其 $K_{\mathrm{b}} = K_{\mathrm{w}}/K_{\mathrm{a1}} = 1.4 \times 10^{-12}$，溶液呈酸性；$\ce{HCO3-}$ 与 $\ce{HPO4^2-}$ 则相反。（$\ce{NaH2PO4}$ 的浓度对 $K_{\mathrm{a1}}$ 不够大，更精确的结果约为 4.7，差别很小。）

### 9.4.4. 弱酸弱碱盐

$\ce{NH4Ac}$、$\ce{NH4CN}$ 中阳离子是弱酸、阴离子是弱碱，两者都与水作用。以 $\ce{NH4+}$、$\ce{A-}$、$\ce{H2O}$ 为参考水准，质子条件为 $[\ce{H+}] + [\ce{HA}] = [\ce{NH3}] + [\ce{OH-}]$。与两性物质的推导完全相同，在通常浓度下得到

$$
[\ce{H+}] \approx \sqrt{K_{\mathrm{a}}(\ce{HA})K_{\mathrm{a}}(\ce{NH4+})} = \sqrt{\frac{K_{\mathrm{w}}K_{\mathrm{a}}(\ce{HA})}{K_{\mathrm{b}}(\ce{NH3})}}.
$$
溶液的 pH 近似与盐的浓度无关，只取决于弱酸与弱碱的解离常数：$K_{\mathrm{a}}(\ce{HA}) = K_{\mathrm{b}}(\ce{NH3})$ 时呈中性（$\ce{NH4Ac}$，pH 7.0），$K_{\mathrm{a}} > K_{\mathrm{b}}$ 时呈酸性（$\ce{NH4F}$、$\ce{HCOONH4}$），$K_{\mathrm{a}} < K_{\mathrm{b}}$ 时呈碱性（$\ce{NH4CN}$、$\ce{(NH4)2CO3}$）。

### 9.4.5. 盐溶液酸碱性的规律与影响因素

| 溶液 | 盐的类型 | 判据 | 例子 |
|---|---|---|---|
| 中性 | 强酸强碱盐 | 不水解 | $\ce{NaCl}$、$\ce{KNO3}$、$\ce{BaI2}$ |
| | 弱酸弱碱盐 | $K_{\mathrm{a}} \approx K_{\mathrm{b}}$ | $\ce{NH4Ac}$ |
| 酸性 | 强酸弱碱盐 | 阳离子是弱酸 | $\ce{NH4Cl}$、$\ce{AlCl3}$、$\ce{FeCl3}$ |
| | 酸式盐 | 阴离子 $K_{\mathrm{a}} > K_{\mathrm{b}}$ | $\ce{NaH2PO4}$、$\ce{NaHSO4}$ |
| | 弱酸弱碱盐 | $K_{\mathrm{a}} > K_{\mathrm{b}}$ | $\ce{NH4F}$、$\ce{HCOONH4}$ |
| 碱性 | 弱酸强碱盐 | 阴离子是弱碱 | $\ce{NaAc}$、$\ce{NaCN}$、$\ce{Na2CO3}$ |
| | 酸式盐 | 阴离子 $K_{\mathrm{a}} < K_{\mathrm{b}}$ | $\ce{Na2HPO4}$、$\ce{NaHCO3}$ |
| | 弱酸弱碱盐 | $K_{\mathrm{a}} < K_{\mathrm{b}}$ | $\ce{NH4CN}$、$\ce{(NH4)2CO3}$ |

$\ce{Al^3+}$、$\ce{Fe^3+}$ 等高电荷金属离子的水合离子是相当强的酸（$\ce{[Fe(H2O)6]^3+}$ 的 $\mathrm{p}K_{\mathrm{a}} \approx 2.2$，与磷酸的第一级相当）：中心离子的电荷越高、半径越小，对配位水分子的极化越强，O–H 键中的质子越容易离去。

影响水解程度的因素：

1. 浓度：由 $h \approx \sqrt{K_{\mathrm{b}}/c}$，稀释使水解度增大。
2. 温度：水解是中和反应的逆反应，吸热，升高温度使水解常数增大（**van 't Hoff 方程**），水解度增大。$\ce{FeCl3}$ 溶液加热后颜色加深、析出氢氧化物就是这个原因。
3. 溶液的 pH：水解产生 $\ce{H+}$（或 $\ce{OH-}$），加入酸（或碱）使水解平衡逆向移动。配制 $\ce{FeCl3}$、$\ce{SnCl2}$、$\ce{Bi(NO3)3}$ 溶液时要先溶于相应的酸中，以抑制水解与沉淀。
4. 相互促进（双水解）：弱碱阳离子与弱酸阴离子相遇，一个产生 $\ce{H+}$、一个消耗 $\ce{H+}$，若产物是沉淀或气体，水解可以进行完全。泡沫灭火器利用 $\ce{Al^3+ + 3HCO3- -> Al(OH)3 v + 3CO2 ^}$；$\ce{Al2S3}$ 在水中不能存在，$\ce{2Al^3+ + 3S^2- + 6H2O -> 2Al(OH)3 v + 3H2S ^}$。

## 9.5. 缓冲溶液

### 9.5.1. 缓冲作用与原理

向 $50\,\mathrm{mL}$ 纯水中加入一滴（约 $0.05\,\mathrm{mL}$）$1\,\mathrm{mol\,L^{-1}}$ HCl 或 NaOH，pH 从 7 变为 3 或 11；而向 $50\,\mathrm{mL}$ 含 $0.10\,\mathrm{mol\,L^{-1}}$ HAc 与 $0.10\,\mathrm{mol\,L^{-1}}$ NaAc 的溶液中加入同样一滴，pH 只从 4.76 变为 4.75 或 4.77。

**定义 9.5.1** 能抵抗外加少量强酸、强碱或适当稀释，而保持 pH 基本不变的溶液称为**缓冲溶液**，这种作用称为缓冲作用。

缓冲溶液一般由浓度都较大的共轭酸碱对组成，如 HAc–NaAc、$\ce{NH3}$–$\ce{NH4Cl}$、$\ce{NaH2PO4}$–$\ce{Na2HPO4}$、$\ce{H2CO3}$–$\ce{NaHCO3}$。以 HAc–$\ce{Ac-}$ 为例，由

$$
[\ce{H+}] = K_{\mathrm{a}}\frac{[\ce{HAc}]}{[\ce{Ac-}]},
$$
$[\ce{H+}]$ 由两者的浓度比决定。溶液中大量的 $\ce{Ac-}$ 是抗酸成分：加入的少量 $\ce{H+}$ 与它结合成 HAc，$[\ce{HAc}]$ 略增、$[\ce{Ac-}]$ 略减，比值变化很小；大量的 HAc 是抗碱成分：加入的 $\ce{OH-}$ 被 HAc 中和。由于两者的浓度都远大于加入的酸碱，比值几乎不变，pH 也就几乎不变。稀释时比值不变，pH 也基本不变。

### 9.5.2. 缓冲溶液的 pH

设弱酸 HA 的浓度为 $c_{\mathrm{a}}$，共轭碱 $\ce{A-}$ 的浓度为 $c_{\mathrm{b}}$。由同离子效应，HA 的解离与 $\ce{A-}$ 的水解都被相互抑制，当 $c_{\mathrm{a}}$、$c_{\mathrm{b}}$ 都远大于 $[\ce{H+}]$ 与 $[\ce{OH-}]$ 时，$[\ce{HA}] \approx c_{\mathrm{a}}$，$[\ce{A-}] \approx c_{\mathrm{b}}$。

**定理 9.5.1（Henderson–Hasselbalch 方程）** 由弱酸 HA（浓度 $c_{\mathrm{a}}$）与其共轭碱 $\ce{A-}$（浓度 $c_{\mathrm{b}}$）组成的缓冲溶液，在 $c_{\mathrm{a}}, c_{\mathrm{b}} \gg [\ce{H+}], [\ce{OH-}]$ 时

$$
\mathrm{pH} = \mathrm{p}K_{\mathrm{a}} + \lg\frac{c_{\mathrm{b}}}{c_{\mathrm{a}}}. \tag{9.5}
$$

**证明** 对 $K_{\mathrm{a}} = [\ce{H+}][\ce{A-}]/[\ce{HA}]$ 取负对数，得 $\mathrm{pH} = \mathrm{p}K_{\mathrm{a}} + \lg([\ce{A-}]/[\ce{HA}])$，再代入上述近似。$\square$

由弱碱 B 与其共轭酸 $\ce{BH+}$ 组成的缓冲溶液（如 $\ce{NH3}$–$\ce{NH4Cl}$）可以同样处理：$\mathrm{pOH} = \mathrm{p}K_{\mathrm{b}} + \lg(c_{\mathrm{BH^+}}/c_{\mathrm{B}})$，或者直接以 $\ce{BH+}$ 为酸用式 (9.5)，$\mathrm{p}K_{\mathrm{a}}(\ce{NH4+}) = 9.25$，两者等价。$K_{\mathrm{a}}$ 太大（$\gtrsim 10^{-2}$）或浓度太稀时，近似条件不成立，要解精确的平衡方程。

**例 9.5.1** $50.00\,\mathrm{mL}$ 含 $0.150\,\mathrm{mol\,L^{-1}}$ $\ce{NH3}$ 与 $0.200\,\mathrm{mol\,L^{-1}}$ $\ce{NH4Cl}$ 的缓冲溶液中加入 $0.100\,\mathrm{mL}$ $1.00\,\mathrm{mol\,L^{-1}}$ HCl。计算加入前后的 pH。

**解** 加入前：$\mathrm{pOH} = \mathrm{p}K_{\mathrm{b}} + \lg\frac{0.200}{0.150} = 4.74 + 0.12 = 4.87$，$\mathrm{pH} = 9.13$。

加入的 $\ce{H+}$ 为 $1.00 \times 10^{-4}\,\mathrm{mol}$，可以认为它与 $\ce{NH3}$ 完全反应生成 $\ce{NH4+}$，然后在新的组成下重新建立平衡。$\ce{NH3}$ 由 $7.50 \times 10^{-3}$ 变为 $7.40 \times 10^{-3}\,\mathrm{mol}$，$\ce{NH4+}$ 由 $1.000 \times 10^{-2}$ 变为 $1.010 \times 10^{-2}\,\mathrm{mol}$。两者在同一溶液中，浓度比等于物质的量之比，

$$
\mathrm{pOH} = 4.74 + \lg\frac{1.010 \times 10^{-2}}{7.40 \times 10^{-3}} = 4.88, \qquad \mathrm{pH} = 9.12.
$$
pH 只降低 0.01。同样的 HCl 加入 $50\,\mathrm{mL}$ 纯水，pH 将从 7.00 降到 2.70。

### 9.5.3. 缓冲容量与缓冲范围

缓冲溶液抵抗酸碱的能力是有限的。

**定义 9.5.2** 使 $1\,\mathrm{L}$ 缓冲溶液的 pH 改变一个单位所需加入的强碱（或强酸）的物质的量，称为**缓冲容量**：$\beta = \frac{\mathrm{d}c_{\mathrm{B}}}{\mathrm{d}\,\mathrm{pH}} = -\frac{\mathrm{d}c_{\mathrm{A}}}{\mathrm{d}\,\mathrm{pH}}$，$c_{\mathrm{B}}$、$c_{\mathrm{A}}$ 为加入的强碱、强酸的浓度。

对总浓度 $c = [\ce{HA}] + [\ce{A-}]$ 的 HA–$\ce{A-}$ 体系加入强碱 NaOH（浓度 $c_{\mathrm{B}}$），电荷平衡 $c_{\mathrm{B}} + [\ce{H+}] = [\ce{A-}] + [\ce{OH-}]$ 给出

$$
c_{\mathrm{B}} = \frac{cK_{\mathrm{a}}}{K_{\mathrm{a}} + [\ce{H+}]} + \frac{K_{\mathrm{w}}}{[\ce{H+}]} - [\ce{H+}].
$$
记 $h = [\ce{H+}]$，$\mathrm{d}\,\mathrm{pH} = -\frac{\mathrm{d}h}{h\ln 10}$，对 $h$ 求导得

$$
\beta = \ln 10\left(h + \frac{K_{\mathrm{w}}}{h} + \frac{cK_{\mathrm{a}}h}{(K_{\mathrm{a}} + h)^2}\right).
$$
前两项是水本身的贡献，只在强酸性、强碱性区才显著；第三项是缓冲对的贡献，在 $h = K_{\mathrm{a}}$（即 $\mathrm{pH} = \mathrm{p}K_{\mathrm{a}}$、$c_{\mathrm{a}} = c_{\mathrm{b}}$）时取极大值 $\beta_{\max} = \frac{\ln 10}{4}c = 0.576c$。由此可知：

1. 缓冲容量与缓冲对的总浓度成正比，总浓度越大，缓冲能力越强（常用 $0.05$–$0.5\,\mathrm{mol\,L^{-1}}$）；
2. 浓度比 $c_{\mathrm{b}}/c_{\mathrm{a}} = 1$ 时缓冲容量最大；比值为 10 或 1/10（$\mathrm{pH} = \mathrm{p}K_{\mathrm{a}} \pm 1$）时，第三项降为最大值的 $\frac{4 \times 10}{11^2} = 33\%$。因此缓冲溶液的有效缓冲范围是 $\mathrm{pH} = \mathrm{p}K_{\mathrm{a}} \pm 1$。

![HAc–Ac⁻ 体系（总浓度 0.10 与 0.05 mol/L）的缓冲容量随 pH 的变化：在 pH = pKa 处最大，约为 0.576c，有效范围为 pKa ± 1；两端的上升来自水本身（强酸、强碱也有"缓冲作用"）](./plots/buffer-capacity.py)

### 9.5.4. 缓冲溶液的选择与生物体中的缓冲体系

配制一定 pH 的缓冲溶液，应选择 $\mathrm{p}K_{\mathrm{a}}$ 尽量接近所需 pH 的弱酸，再按式 (9.5) 调整浓度比；缓冲物质还不应与体系中的其他物质反应。常用的缓冲体系：

| 弱酸 | 共轭碱 | $\mathrm{p}K_{\mathrm{a}}$ | 缓冲范围（pH） |
|---|---|---|---|
| 邻苯二甲酸 | 邻苯二甲酸氢钾 | 2.94 | 1.9–3.9 |
| HAc | NaAc | 4.76 | 3.8–5.8 |
| $\ce{NaH2PO4}$ | $\ce{Na2HPO4}$ | 7.21 | 6.2–8.2 |
| $\ce{NH4Cl}$ | $\ce{NH3}$ | 9.25 | 8.3–10.3 |
| $\ce{Na2HPO4}$ | $\ce{Na3PO4}$ | 12.32 | 11.3–13.3 |

生物化学实验中还常用 Tris（三羟甲基氨基甲烷，$\mathrm{p}K_{\mathrm{a}} = 8.07$）与 HEPES（$\mathrm{p}K_{\mathrm{a}} \approx 7.5$）等有机缓冲剂，它们与金属离子的配位弱，不像磷酸盐那样易生成沉淀。

**例 9.5.2** 人体血液的 pH 维持在 $7.35$–$7.45$，主要的缓冲体系是 $\ce{CO2(aq)}$–$\ce{HCO3-}$。$37\,^\circ\mathrm{C}$ 时把溶解的 $\ce{CO2}$ 与少量 $\ce{H2CO3}$ 合并计算的表观 $\mathrm{p}K_{\mathrm{a}}$ 为 6.1。动脉血中 $[\ce{HCO3-}] = 24\,\mathrm{mmol\,L^{-1}}$，$\ce{CO2}$ 分压 $5.3\,\mathrm{kPa}$，$\ce{CO2}$ 在血浆中的溶解度为 $0.23\,\mathrm{mmol\,L^{-1}\,kPa^{-1}}$。求血液的 pH。

**解** $[\ce{CO2(aq)}] = 0.23 \times 5.3 = 1.2\,\mathrm{mmol\,L^{-1}}$，由式 (9.5)，

$$
\mathrm{pH} = 6.1 + \lg\frac{24}{1.2} = 6.1 + 1.30 = 7.40.
$$
浓度比为 20，远离缓冲容量最大的比值 1，按 9.5.3 的分析这个缓冲对的效率并不高。它之所以有效，是因为它是开放体系：代谢产生的酸使 $\ce{CO2}$ 增多，多余的 $\ce{CO2}$ 由肺呼出；$\ce{HCO3-}$ 的浓度由肾脏调节。所以 pH 由呼吸与肾功能共同维持，呼吸过度或不足会引起呼吸性碱中毒或酸中毒。细胞内则以磷酸盐（$\mathrm{p}K_{\mathrm{a2}} = 7.21$，9.3.6 的分布图中 $\ce{H2PO4-}$ 与 $\ce{HPO4^2-}$ 在 pH 7.4 附近各占可观的比例）和蛋白质为主要缓冲体系。（见[生物化学](/7.1)、[动物生理学](/7.15)。）

## 9.6. 酸碱滴定简介

### 9.6.1. 滴定分析的基本概念

**定义 9.6.1** 把已知准确浓度的试剂溶液（**标准溶液**）逐滴加入被测物质的溶液中，直到两者按化学计量关系恰好反应完全，由消耗的标准溶液的体积与浓度计算被测物质含量的方法称为**滴定**（滴定分析）。

按反应类型分为酸碱滴定、配位滴定、氧化还原滴定与沉淀滴定。

**定义 9.6.2** 滴定剂与被测物质按反应方程式的化学计量关系恰好完全反应的一点称为**化学计量点**；实际滴定中根据指示剂颜色的突变而停止滴定的一点称为**滴定终点**；滴定终点与化学计量点不一致所造成的误差称为**滴定误差**（终点误差）。

用于滴定分析的反应必须满足：反应按确定的方程式定量进行，完全程度达到 99.9% 以上；反应速率快，或能用加热、催化剂等简便地加快；有简便可靠的确定终点的方法（如指示剂）；共存物质的干扰可以消除。

标准溶液有两种配制方法。

**定义 9.6.3** 可以直接用来配制标准溶液或标定溶液浓度的物质称为**基准物质**。它必须纯度高（99.9% 以上）；组成与化学式完全相符（包括结晶水）；性质稳定，不分解、不吸湿、不风化、不吸收 $\ce{CO2}$；最好有较大的摩尔质量，以减小称量的相对误差。

**定义 9.6.4** 先配成近似浓度的溶液，再用基准物质或另一种标准溶液通过滴定确定其准确浓度的操作称为**标定**。

- 直接法：准确称取基准物质，溶解后定容到容量瓶中，由质量与体积直接算出浓度。
- 间接法（标定法）：不符合基准物质条件的试剂先粗配，再标定。NaOH 易吸湿并吸收 $\ce{CO2}$，用基准物质邻苯二甲酸氢钾（$\ce{KHC8H4O4}$）标定；浓盐酸易挥发，HCl 溶液用无水 $\ce{Na2CO3}$ 或硼砂（$\ce{Na2B4O7*10H2O}$）标定。氧化还原滴定中，$\ce{Na2S2O3}$ 溶液用 $\ce{KIO3}$ 或 $\ce{K2Cr2O7}$ 标定（[6.1.12](/6.1.12)）。

### 9.6.2. 滴定曲线与滴定突跃

**定义 9.6.5** 以加入的滴定剂的体积（或滴定分数）为横坐标、溶液的 pH 为纵坐标画出的曲线称为酸碱**滴定曲线**。

**定义 9.6.6** 在化学计量点前后 $\pm 0.1\%$（相对误差）范围内，溶液 pH 的急剧变化称为**滴定突跃**，突跃所在的 pH 区间称为突跃范围。

**例 9.6.1** 用 $0.1000\,\mathrm{mol\,L^{-1}}$ NaOH 滴定 $20.00\,\mathrm{mL}$ $0.1000\,\mathrm{mol\,L^{-1}}$ HCl。求滴定突跃范围；若两者浓度都是 $0.01000\,\mathrm{mol\,L^{-1}}$ 呢？

**解** 化学计量点前 0.1%：加入 $19.98\,\mathrm{mL}$ NaOH，剩余 HCl $0.02\,\mathrm{mL} \times 0.1000\,\mathrm{mol\,L^{-1}}$，总体积 $39.98\,\mathrm{mL}$，

$$
[\ce{H+}] = \frac{0.02 \times 0.1000}{39.98} = 5.0 \times 10^{-5}, \qquad \mathrm{pH} = 4.30.
$$
化学计量点时 pH = 7.00。计量点后 0.1%：加入 $20.02\,\mathrm{mL}$，过量 NaOH 使 $[\ce{OH-}] = 5.0 \times 10^{-5}$，$\mathrm{pH} = 9.70$。突跃范围为 4.30–9.70：滴定剂只多加约半滴（$0.04\,\mathrm{mL}$），pH 就变化了 5.4 个单位。浓度为 $0.01000\,\mathrm{mol\,L^{-1}}$ 时，计量点前后的 $[\ce{H+}]$、$[\ce{OH-}]$ 都缩小到 1/10，突跃范围为 5.30–8.70，缩小了 2 个 pH 单位。

突跃的意义在于：只要指示剂在突跃范围内变色，终点与化学计量点相差不超过 0.1%。由此得到选择指示剂的原则：指示剂的变色范围应全部或部分落在滴定突跃范围之内。$0.1\,\mathrm{mol\,L^{-1}}$ 的强酸强碱滴定可以用甲基红、酚酞（甲基橙也可，但误差稍大）；$0.01\,\mathrm{mol\,L^{-1}}$ 时甲基橙已不适用。

整条滴定曲线可以由电荷平衡逐点计算。用 NaOH（浓度 $c$，加入体积 $V$）滴定 HCl（浓度 $c$，体积 $V_0$）时，$[\ce{Na+}] + [\ce{H+}] = [\ce{Cl-}] + [\ce{OH-}]$，即

$$
f(h) = h - \frac{K_{\mathrm{w}}}{h} + \frac{c(V - V_0)}{V + V_0} = 0.
$$
$f$ 是 $h$ 的单调增函数，在 $(0, 1)$ 内有唯一的根，可以用**二分法**（[3.5.4](/3.5.4)）或 Brent 法（`scipy.optimize.brentq`，[4.4.4](/4.4.4#sec-4.2.2)）求解。用 NaOH 滴定弱酸 HA 时，电荷平衡变为 $[\ce{Na+}] + [\ce{H+}] = [\ce{A-}] + [\ce{OH-}]$，其中 $[\ce{A-}] = c_{\mathrm{HA}}\,\delta(\ce{A-})$（9.3.6），方法相同。由于 $h$ 跨越十几个数量级，以 pH 而不是 $h$ 为未知量求根，数值上更稳定。

![左：0.1000 与 0.01000 mol/L NaOH 滴定同浓度 HCl 的滴定曲线，左侧色带为三种指示剂的变色范围；右：0.1000 mol/L NaOH 滴定 HAc 与 HCl 的比较](./plots/titration-curves.py)

滴定弱酸与滴定强酸有三点不同（右图）：起点 pH 较高（HAc 为 2.88）；计量点前溶液是 HAc–$\ce{Ac-}$ 缓冲溶液，曲线平缓，滴定一半时 $\mathrm{pH} = \mathrm{p}K_{\mathrm{a}}$（这是测定 $\mathrm{p}K_{\mathrm{a}}$ 的一种方法）；计量点时溶液是 $0.05000\,\mathrm{mol\,L^{-1}}$ NaAc，呈碱性（$\mathrm{pH} = 8.73$），突跃范围缩小为 7.76–9.70，只能用在碱性区变色的酚酞。弱酸越弱、浓度越稀，突跃越小；一般要求 $cK_{\mathrm{a}} \ge 10^{-8}$ 才能准确滴定。多元酸的分步滴定、终点误差的计算与指示剂的选择理论见[分析化学](/6.4)。

## 9.7. 配位平衡

### 9.7.1. 稳定常数

向 $\ce{CuSO4}$ 溶液中加入过量氨水，生成深蓝色的 $\ce{[Cu(NH3)4]^2+}$（[6.1.5](/6.1.5)）。这个溶液中加入少量 NaOH 并不产生 $\ce{Cu(OH)2}$ 沉淀，加入 $\ce{Na2S}$ 却生成黑色的 CuS 沉淀：说明溶液中仍有少量游离的 $\ce{Cu^2+}$，配离子的生成与解离处于平衡。

**定义 9.7.1（配位平衡）** 溶液中中心离子与配体生成配离子的反应和配离子解离的反应之间的平衡称为**配位平衡**。

**定义 9.7.2** 中心离子 M 与配体 L 生成配离子 $\ce{ML_n}$ 的反应 $\mathrm{M} + n\mathrm{L} \ce{<=>} \mathrm{ML}_n$ 的标准平衡常数

$$
\beta_n = \frac{[\mathrm{ML}_n]}{[\mathrm{M}][\mathrm{L}]^n}
$$
称为配离子的**稳定常数**（生成常数、累积稳定常数）；它的倒数 $1/\beta_n$，即配离子解离反应 $\mathrm{ML}_n \ce{<=>} \mathrm{M} + n\mathrm{L}$ 的平衡常数，称为**不稳定常数**（解离常数）。

例如 $\ce{Cu^2+ + 4NH3 <=> [Cu(NH3)4]^2+}$，$\beta_4 = \frac{[\ce{[Cu(NH3)4]^2+}]}{[\ce{Cu^2+}][\ce{NH3}]^4} = 2.1 \times 10^{13}$（$\lg\beta_4 = 13.32$）。（中文教材常把 $\beta_n$ 记作 $K_{\mathrm{f}}$ 或 $K_{\text{稳}}$，把不稳定常数记作 $K_{\mathrm{d}}$ 或 $K_{\text{不稳}}$，本站按 IUPAC 写 $\beta_n$。）同类型（配体数相同）的配离子，$\beta_n$ 越大越稳定：

| 配离子 | $\lg\beta_n$ | 配离子 | $\lg\beta_n$ |
|---|---|---|---|
| $\ce{[Ag(NH3)2]+}$ | 7.22 | $\ce{[Cu(NH3)4]^2+}$ | 13.32 |
| $\ce{[Ag(S2O3)2]^3-}$ | 13.46 | $\ce{[Zn(NH3)4]^2+}$ | 9.46 |
| $\ce{[Ag(CN)2]-}$ | 21.1 | $\ce{[Cd(NH3)4]^2+}$ | 7.12 |

$\ce{Ag+}$ 的三种配离子的稳定性顺序 $\ce{NH3} < \ce{S2O3^2-} < \ce{CN-}$ 正是"软亲软"（9.1.4）：$\ce{CN-}$ 与 $\ce{S2O3^2-}$（以 S 配位）比 $\ce{NH3}$ 软。

配离子的生成与解离是分步进行的。

**定义 9.7.3** 配离子逐个结合配体的每一步反应 $\mathrm{ML}_{k-1} + \mathrm{L} \ce{<=>} \mathrm{ML}_k$ 的平衡常数

$$
K_k = \frac{[\mathrm{ML}_k]}{[\mathrm{ML}_{k-1}][\mathrm{L}]}, \qquad k = 1, 2, \dots, n
$$
称为**逐级稳定常数**。

由**多重平衡规则**，累积稳定常数等于逐级稳定常数之积：

$$
\beta_k = K_1K_2\cdots K_k, \qquad \lg\beta_k = \sum_{j=1}^{k}\lg K_j.
$$
逐级不稳定常数是逐级稳定常数的倒数，次序相反：第一步解离 $\ce{[Cu(NH3)4]^2+ <=> [Cu(NH3)3]^2+ + NH3}$ 的常数是 $1/K_4$。$\ce{Cu^2+}$–$\ce{NH3}$ 体系的 $\lg K_1, \dots, \lg K_4 = 4.31, 3.67, 3.04, 2.30$：逐级稳定常数一般依次减小，原因是统计因素（已结合的配体越多，可被取代的水分子越少、可解离的配体越多）与已结合配体的静电与空间排斥。

各物种的分布与多元弱酸的分布系数（9.3.6）完全类似，只是 $[\ce{H+}]$ 换成了游离配体浓度 $[\mathrm{L}]$：$\mathrm{ML}_k$ 所占的分数为 $\beta_k[\mathrm{L}]^k\big/\sum_{j=0}^{n}\beta_j[\mathrm{L}]^j$（$\beta_0 = 1$）。

![Cu(II)–NH₃ 体系中各配离子所占分数随游离氨浓度的变化（横轴为 −lg[NH₃]，向右氨浓度增大；虚线为 lg K₁…lg K₄）：逐级常数相差不大，中间几种配离子在很宽的范围内共存，只有氨大大过量时才几乎全部是 [Cu(NH₃)₄]²⁺](./plots/copper-ammine-distribution.py)

### 9.7.2. 稳定常数的应用

稳定常数首先可以用来判断配离子之间转化的方向。

**例 9.7.1** 判断反应 $\ce{[Ag(NH3)2]+ + 2CN- <=> [Ag(CN)2]- + 2NH3}$ 进行的方向。

**解** 由多重平衡规则（分子分母同乘 $[\ce{Ag+}]$），

$$
K^\circ = \frac{[\ce{[Ag(CN)2]-}][\ce{NH3}]^2}{[\ce{[Ag(NH3)2]+}][\ce{CN-}]^2} = \frac{\beta_2(\ce{[Ag(CN)2]-})}{\beta_2(\ce{[Ag(NH3)2]+})} = \frac{1.3 \times 10^{21}}{1.7 \times 10^{7}} = 7.6 \times 10^{13}.
$$
$K^\circ$ 很大，反应向右进行得很完全：配离子总是向更稳定的配离子转化。

稳定常数还可以用来计算溶液中游离金属离子的浓度。

**例 9.7.2** 在 $1\,\mathrm{mL}$ $0.040\,\mathrm{mol\,L^{-1}}$ $\ce{AgNO3}$ 溶液中加入 $1\,\mathrm{mL}$ $2.0\,\mathrm{mol\,L^{-1}}$ 氨水，计算平衡后的 $[\ce{Ag+}]$ 与 $[\ce{[Ag(NH3)]+}]$。$\beta_2 = 1.7 \times 10^{7}$，$K_1 = 2.0 \times 10^{3}$。

**解** 混合后 $c(\ce{Ag+}) = 0.020$，$c(\ce{NH3}) = 1.0\,\mathrm{mol\,L^{-1}}$。$\beta_2$ 很大且氨大大过量，可以先设 $\ce{Ag+}$ 全部转化为 $\ce{[Ag(NH3)2]+}$（0.020），消耗 0.040 的 $\ce{NH3}$，剩余 0.96；再由少量配离子的解离求 $[\ce{Ag+}] = x$：

| | $\ce{Ag+}$ | $\ce{NH3}$ | $\ce{[Ag(NH3)2]+}$ |
|---|---|---|---|
| 完全反应后 | 0 | 0.96 | 0.020 |
| 平衡 | $x$ | $0.96 + 2x$ | $0.020 - x$ |

$$
\beta_2 = \frac{0.020 - x}{x(0.96 + 2x)^2} \approx \frac{0.020}{x \times 0.96^2} = 1.7 \times 10^{7}, \qquad x = 1.3 \times 10^{-9}\,\mathrm{mol\,L^{-1}}.
$$
$[\ce{[Ag(NH3)]+}] = K_1[\ce{Ag+}][\ce{NH3}] = 2.0 \times 10^{3} \times 1.3 \times 10^{-9} \times 0.96 = 2.5 \times 10^{-6}\,\mathrm{mol\,L^{-1}}$，只占银总量的 0.013%，"全部生成 $\ce{[Ag(NH3)2]+}$"的假设成立。游离 $\ce{Ag+}$ 的浓度被降低了七个数量级：这就是配位能够溶解沉淀、改变电极电势的原因。

最后，配位平衡常与其他平衡同时存在，总反应的平衡常数由多重平衡规则组合：

- 与酸碱平衡：配体多是弱碱（$\ce{NH3}$、$\ce{CN-}$、$\ce{F-}$、EDTA），加酸使配体质子化，游离配体浓度降低，配离子解离。$\ce{[Cu(NH3)4]^2+}$ 溶液中加酸，深蓝色褪去，就是 $\ce{NH3 + H+ -> NH4+}$ 夺走了配体。反之，金属离子的水解也与配位竞争。这类副反应的定量处理（副反应系数、条件稳定常数）见[分析化学](/6.4)。
- 与沉淀平衡：配位使难溶盐溶解（如 $\ce{AgCl + 2NH3 <=> [Ag(NH3)2]+ + Cl-}$，$K = K_{\mathrm{sp}}\beta_2$），沉淀剂又可以破坏配离子（$\ce{[Cu(NH3)4]^2+}$ 加 $\ce{Na2S}$ 生成 CuS），见 [6.1.10](/6.1.10)。
- 与氧化还原平衡：配位降低金属离子的浓度，从而改变电对的电极电势，如 $\ce{Au}$ 在 $\ce{CN-}$ 存在时能被 $\ce{O2}$ 氧化溶解，见 [6.1.11](/6.1.11)。

## 思考题

1. 在液氨中，HAc 是强酸还是弱酸？在冰醋酸中，$\ce{NH3}$ 是强碱还是弱碱？
   答：液氨的碱性比水强，HAc 在液氨中完全把质子交给 $\ce{NH3}$，是强酸（液氨是拉平溶剂）。冰醋酸的酸性比水强，$\ce{NH3}$ 在其中完全接受质子，是强碱。
2. $10^{-8}\,\mathrm{mol\,L^{-1}}$ HCl 溶液的 pH 是 8 吗？
   答：不是。此时水的解离不能忽略。电荷平衡 $[\ce{H+}] = 10^{-8} + K_{\mathrm{w}}/[\ce{H+}]$，解得 $[\ce{H+}] = 1.05 \times 10^{-7}$，$\mathrm{pH} = 6.98$：再稀的酸溶液也是酸性的。
3. 为什么配制 $\ce{SnCl2}$ 溶液时要加入盐酸并放入锡粒？
   答：盐酸抑制水解（$\ce{SnCl2 + H2O <=> Sn(OH)Cl v + HCl}$）；锡粒把被空气氧化生成的 $\ce{Sn^4+}$ 还原回 $\ce{Sn^2+}$（[6.1.11](/6.1.11)）。
4. HAc–NaAc 缓冲溶液用水稀释 10 倍，pH 是否改变？缓冲容量是否改变？
   答：浓度比不变，由式 (9.5) pH 基本不变（极稀时近似失效才有变化）；缓冲容量与总浓度成正比，降为约 1/10。

## 小结

| 内容 | 要点 |
|---|---|
| 酸碱理论 | 电离理论：水中电离出 $\ce{H+}$ / $\ce{OH-}$；质子理论：质子给予体 / 接受体，共轭酸碱对，酸碱反应是质子传递，强弱与溶剂有关（拉平效应与区分效应）；电子理论：电子对接受体 / 给予体，反应生成配位键 |
| 软硬酸碱 | 按极化率分软硬；硬亲硬、软亲软 |
| 水与 pH | $K_{\mathrm{w}} = [\ce{H+}][\ce{OH-}] = 1.0\times10^{-14}$（25 °C，随温度升高而增大）；$\mathrm{pH} = -\lg a_{\ce{H+}}$；指示剂变色范围约 $\mathrm{p}K_{\mathrm{a}} \pm 1$ |
| 弱酸弱碱 | $K_{\mathrm{a}}K_{\mathrm{b}} = K_{\mathrm{w}}$；$[\ce{H+}] \approx \sqrt{K_{\mathrm{a}}c}$（$c/K_{\mathrm{a}} \ge 400$，误差约 $\alpha/2$；$K_{\mathrm{a}}c \ge 20K_{\mathrm{w}}$）；稀释定律 $\alpha \approx \sqrt{K_{\mathrm{a}}/c}$；同离子效应；多元弱酸按一元处理，$[\ce{A^2-}] \approx K_{\mathrm{a2}}$ |
| 盐溶液 | 水解即离子酸碱的解离；两性物质 $\mathrm{pH} \approx \frac{1}{2}(\mathrm{p}K_{\mathrm{a1}} + \mathrm{p}K_{\mathrm{a2}})$，由电荷平衡、物料平衡得质子条件 |
| 缓冲溶液 | $\mathrm{pH} = \mathrm{p}K_{\mathrm{a}} + \lg(c_{\mathrm{b}}/c_{\mathrm{a}})$；缓冲容量在 $c_{\mathrm{a}} = c_{\mathrm{b}}$ 时最大（$0.576c$），有效范围 $\mathrm{p}K_{\mathrm{a}} \pm 1$ |
| 酸碱滴定 | 计量点前后 ±0.1% 的 pH 突变为滴定突跃（0.1 mol/L 强酸强碱：4.30–9.70）；指示剂变色范围应落在突跃范围内 |
| 配位平衡 | 累积稳定常数 $\beta_n = K_1\cdots K_n$，不稳定常数 $1/\beta_n$；配离子向更稳定的方向转化；与酸碱、沉淀、氧化还原平衡竞争 |
