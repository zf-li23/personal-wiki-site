程序处理的是数据。本章讨论数据在程序中怎样被命名（变量）、怎样被解读（数据类型）、怎样参与计算（表达式与运算符），以及怎样进出程序（输入输出）。很多初学者的"灵异"错误，如 `5/9` 等于 $0$、两个正数相乘得到负数、`0.1 + 0.2 != 0.3`，都源于没有意识到计算机中的数与数学中的数不同：它们有固定的位数和确定的编码。整数与浮点数的编码已在 [3.5.1](/3.5.1) 中详细讨论，本章只从写程序的角度说明它们的后果。下一章 [4.1.3](/4.1.3) 用本章的表达式构造分支和循环；变量的地址与指针留到 [4.1.8](/4.1.8)。

## 2.1. 变量

### 2.1.1. 变量的定义与赋值

先看一个例子：把华氏温度换算为摄氏温度，$C = \frac{5}{9}(F - 32)$，华氏温度由用户输入。

```cpp tab
#include <iostream>

int main() {
    double fahrenheit;                  // define a variable
    std::cout << "Fahrenheit: ";
    std::cin >> fahrenheit;             // read a value into it
    double celsius = 5.0 / 9 * (fahrenheit - 32);   // define and initialize
    std::cout << fahrenheit << " F = " << celsius << " C\n";
    return 0;
}
```

```python tab
fahrenheit = float(input("Fahrenheit: "))   # input() returns a string
celsius = 5 / 9 * (fahrenheit - 32)
print(f"{fahrenheit} F = {celsius} C")
```

输入 `98.6`，两个程序都输出 `37` 左右的结果。程序中能够保存、并在运行过程中改变的量就是变量。

**定义 2.1.1（变量）** **变量**（variable）是程序中有名字的存储单元。在 C++ 中，一个变量有四个属性：名字、类型、所占的内存位置，以及当前存放的值；类型在定义时确定，此后不变。

C++ 中变量必须先定义后使用：

```cpp
double d;              // definition: type name, then variable name
int count = 0;         // definition with initialization
int n{10};             // brace initialization (C++11), rejects narrowing such as int n{3.7}
const double pi = 3.141592653589793;   // a named constant: cannot be assigned later
constexpr int days_per_week = 7;       // a compile-time constant
```

变量名（标识符）由字母、数字和下划线组成，不能以数字开头，区分大小写，不能使用 `int`、`if`、`for` 等关键字。给反复出现的数值（如精度、数组大小）起一个常量名，既便于阅读，又保证修改时只改一处。

赋值 `x = e` 的含义是：计算右边表达式 $e$ 的值，用它覆盖变量 `x` 中原来的值。右边用到的变量只是被读取，值不变。因此 `a = a + 1` 不是方程，而是"把 `a` 的值加 $1$ 后存回 `a`"：

```cpp
int a = 0, b = 0, c = 0;
a = 7;        // a is 7 (the old 0 is overwritten)
b = a;        // b is 7, a is unchanged
c = a + b;    // c is 14
a = a + 1;    // a is 8
```

C++ 中局部变量若只定义不初始化，它的值是不确定的，读取它是错误的（**编译器**加 `-Wall` 时通常会警告）。养成定义时就初始化的习惯。

### 2.1.2. Python 对照：名字与对象

Python 的变量模型不同。Python 中一切数据都是对象，每个对象有自己的类型和值；变量只是绑定到对象上的名字，赋值 `x = e` 是让名字 `x` 指向表达式 $e$ 的结果对象。名字本身没有类型：

```python
x = 42            # x refers to an int object
print(type(x))    # <class 'int'>
x = "forty-two"   # now x refers to a str object; this is allowed
print(type(x))    # <class 'str'>
```

类型检查发生的时机是两种语言的重要区别。在静态类型（static typing）语言中，每个变量和表达式的类型在编译时确定，类型错误在编译时就被报告，C++ 属于此类；在动态类型（dynamic typing）语言中，类型属于运行时的值而不属于变量，类型错误在执行到那一行时才被发现，Python 属于此类。例如把字符串与整数相加，`std::string("1") + 2` 在 C++ 中编译失败，`"1" + 2` 在 Python 中要到运行时才抛出 `TypeError`。Python 允许写类型标注 `count: int = 0`，**解释器**不检查它，但 mypy 等工具可以据此做静态检查（[4.2.9](/4.2.9)、[4.4.1](/4.4.1)）。

名字与对象分离的后果在函数参数传递（[4.1.4](/4.1.4)）和列表（[4.1.6](/4.1.6)）中会显现出来。

## 2.2. 基本数据类型

### 2.2.1. 类型、取值范围与大小

**定义 2.2.1（数据类型）** **数据类型**（data type）规定了一类数据的取值集合、可以进行的运算，以及这些值在内存中的表示方式。同样的一串比特，按整数解读和按浮点数解读，得到的是完全不同的值。

C++ 的基本类型（在 64 位 Linux 上用 GCC 编译时的典型情况）：

| 类型 | 字节数 | 取值范围或精度 | 用途 |
|---|---|---|---|
| `bool` | 1 | `true`、`false` | 逻辑值 |
| `char` | 1 | 通常 $-128 \sim 127$ | 字符（存放字符的编码） |
| `short` | 2 | $-2^{15} \sim 2^{15}-1$ | |
| `int` | 4 | $-2^{31} \sim 2^{31}-1$，约 $\pm 2.1 \times 10^9$ | 默认的整数类型 |
| `long` | 8（Windows 上为 4） | 与平台有关 | 尽量不用 |
| `long long` | 8 | $-2^{63} \sim 2^{63}-1$，约 $\pm 9.2 \times 10^{18}$ | 大整数 |
| `unsigned int` | 4 | $0 \sim 2^{32}-1$ | 非负整数、位运算 |
| `float` | 4 | 约 7 位有效数字 | 单精度浮点数 |
| `double` | 8 | 约 15～16 位有效数字 | 默认的浮点类型 |
| `long double` | 16（x86-64 GCC，实为 80 位扩展精度；MSVC 上为 8） | 与平台有关 | |

C++ 标准只规定各类型的最小范围和大小关系（`sizeof(short) <= sizeof(int) <= sizeof(long) <= sizeof(long long)`），具体大小由平台决定。需要确定位数时，使用 `<cstdint>` 中的定宽类型 `std::int32_t`、`std::int64_t`、`std::uint8_t` 等；表示大小和下标时用 `std::size_t`。运算符 `sizeof` 给出类型或变量所占的字节数，`<limits>` 中的 `std::numeric_limits<T>` 给出类型的范围，如 `std::numeric_limits<int>::max()`。

Python 的基本类型只有 `int`（任意大小的整数）、`float`（即 IEEE 754 双精度，相当于 C++ 的 `double`）、`complex`、`bool`（`True`、`False`，是 `int` 的子类）和 `str`（字符串，没有单独的字符类型）。

### 2.2.2. 整数的表示与溢出

整数在内存中以二进制存放。一个直观的例子是"猜数卡片"：把 $1 \sim 63$ 中第 $k$ 个二进制位为 $1$ 的数写在第 $k$ 张卡片上（$k = 0, 1, \dots, 5$），对方只要说出他想的数出现在哪几张卡片上，把这些卡片的 $2^k$ 相加就得到这个数。例如 $37 = (100101)_2 = 2^5 + 2^2 + 2^0$，它恰好出现在第 0、2、5 张卡片上。卡片的生成程序见 [4.1.3](/4.1.3)。

有符号整数用**补码**表示，$N$ 位有符号整数的范围是 $-2^{N-1} \sim 2^{N-1}-1$；无符号整数的 $N$ 位都是数值位，范围是 $0 \sim 2^N - 1$。位、字节与字长，原码与补码的编码方式，见[统计计算与软件 1.1.2 与 1.2.1 节](/3.5.1#sec-1.1.2)，这里只讨论编程时必须知道的后果。范围是有限的，运算结果可能超出它，这在 [3.5.1](/3.5.1#sec-1.2.1) 中一般地称为**溢出**；对整数运算，后果取决于类型。

**定义 2.2.2（整数溢出）** 整数运算的数学结果超出了结果类型所能表示的范围，称为**整数溢出**（integer overflow）。在 C++ 中，无符号整数的运算按模 $2^N$ 进行，溢出时"回绕"，结果是确定的；有符号整数溢出是未定义行为。

**定义 2.2.3（未定义行为）** C++ 标准对其结果不作任何规定的程序行为称为**未定义行为**（undefined behavior，UB）。程序一旦发生未定义行为，标准对整个程序的执行不再提供任何保证：它可能输出看似合理的值、崩溃，或者在打开优化后表现得完全不同。常见的未定义行为有有符号整数溢出、数组越界、读取未初始化的变量、除以零。

```cpp
#include <climits>
#include <iostream>

int main() {
    int a = 50000;
    int square = a * a;                       // overflow: undefined behavior
    long long wide = 1LL * a * a;             // compute in a 64-bit type
    unsigned int u = 0;
    u = u - 1;                                // well defined: wraps to 2^32 - 1
    std::cout << square << '\n' << wide << '\n' << u << '\n';
    std::cout << INT_MAX << ' ' << INT_MIN << '\n';
    return 0;
}
```

在 x86-64 上，`square` 通常输出 `-1794967296`（即 $2.5 \times 10^9 - 2^{32}$），但这不是可以依赖的结果。编译时加 `-fsanitize=undefined`，程序在运行到溢出处时会报告 `signed integer overflow: 50000 * 50000 cannot be represented in type 'int'`。注意 `1LL * a * a` 的写法：先把一个操作数变成 `long long`，乘法才在 64 位中进行；写成 `long long wide = a * a;` 仍然先在 `int` 中相乘，已经溢出了。

估计数量级是避免溢出的基本功：$12! \approx 4.8 \times 10^8$ 还在 `int` 范围内，$13! \approx 6.2 \times 10^9$ 就超出了；$10^5$ 个不超过 $10^5$ 的数之和可达 $10^{10}$，要用 `long long`。

Python 对照：Python 的 `int` 没有固定位数，按需要分配内存，因此整数运算永远不会溢出：`2**100` 精确地得到 `1267650600228229401496703205376`。代价是速度：每个整数都是一个对象，大整数的运算时间随位数增长。Python 的 `float` 仍是 64 位浮点数，乘法等运算的结果过大时得到 `inf`（`math.exp` 等函数则抛出 `OverflowError`）；第三方库 NumPy 的整数数组也是定宽的，会回绕（[4.4.2](/4.4.2)）。

### 2.2.3. 浮点数与舍入误差

`float` 与 `double` 是 IEEE 754 标准的单精度与双精度**浮点数**。它们的格式（符号、指数、尾数）、规格化数与非规格化数、十进制与二进制的转换，在[统计计算与软件 1.2 节](/3.5.1#sec-1.2)中有详细的讨论；编程时要记住的是：浮点数只能精确表示形如 $\pm m \times 2^e$ 的有限个数，其他实数都要舍入。$0.1$ 的二进制表示是无限循环小数，所以：

```cpp tab
#include <iostream>

int main() {
    std::cout << (0.1 + 0.2 == 0.3) << '\n';   // prints 0 (false)
    float f1 = 34.6f, f2 = 34.0f;
    std::cout << f1 - f2 << '\n';              // prints 0.599998
    return 0;
}
```

```python tab
print(0.1 + 0.2 == 0.3)   # False
print(0.1 + 0.2)          # 0.30000000000000004
```

相邻浮点数的相对间隔由**机器精度**决定（[3.5.1 节 1.2.5](/3.5.1#sec-1.2.5)）：`double` 约为 $2.2 \times 10^{-16}$（`std::numeric_limits<double>::epsilon()`，Python 中为 `sys.float_info.epsilon`），`float` 约为 $1.2 \times 10^{-7}$。由此得到两条编程规则：

- 默认使用 `double`，只有在内存或速度确有需要时才用 `float`；
- 不要用 `==` 比较两个计算得到的浮点数，而是判断它们的差是否足够小，如 `std::abs(x - y) <= 1e-9 * std::max(std::abs(x), std::abs(y))`；Python 中用 `math.isclose(x, y)`。

金额等要求精确的十进制量不应使用浮点数，而应以"分"为单位用整数存储（Python 还有标准库 `decimal`）。舍入误差怎样在计算中传播、浮点运算为什么不满足结合律、什么样的算法是稳定的，见[统计计算与软件 1.3 节](/3.5.1#sec-1.3)。

### 2.2.4. 字符与布尔值

`char` 存放的是字符的编码，即一个小整数；字符与编码的对应规则就是**字符编码**。英文字母、数字和常用符号使用 ASCII 编码，例如 `'A'` 是 $65$，`'a'` 是 $97$，`'0'` 是 $48$，大小写字母相差 $32$。因此字符可以参与算术运算和比较：`'A' + 2` 的值是整数 $67$，`char('A' + 2)` 是字符 `'C'`；`'0' <= c && c <= '9'` 判断 `c` 是否为数字字符，`c - '0'` 得到它代表的数值。汉字等非 ASCII 字符不能放进一个 `char`，字符串与 Unicode 的问题见 [4.1.7](/4.1.7)。

字符常量用单引号（`'A'`），字符串常量用双引号（`"A"`），两者类型不同。特殊字符用转义序列（escape sequence）表示：`'\n'` 换行，`'\t'` 制表符，`'\\'` 反斜杠，`'\''` 和 `'\"'` 引号，`'\0'` 编码为 $0$ 的空字符。

`bool` 只有 `true` 和 `false` 两个值。它与整数可以互相转换：`true` 转为 $1$，`false` 转为 $0$；整数转为 `bool` 时，$0$ 为 `false`，非零为 `true`。`std::cout` 默认把布尔值输出为 `1`、`0`，先输出 `std::boolalpha` 后输出为 `true`、`false`。

## 2.3. 表达式与运算符

表达式（expression）由运算对象（变量、常量、函数调用）和运算符组成，计算后得到一个值。

### 2.3.1. 算术运算

| 运算符 | 含义 | 注意 |
|---|---|---|
| `+ - *` | 加、减、乘 | 整数可能溢出 |
| `/` | 除 | 两个整数相除得到整数，小数部分舍去 |
| `%` | 取余 | 只用于整数 |

C++ 中整数除法向零截断，余数与被除数同号，满足 `(a / b) * b + a % b == a`；Python 中 `/` 总是得到浮点数，整数除法写 `//`，它向下取整，`%` 的结果与除数同号。两者在负数上的结果不同：

| 表达式 | C++ | Python |
|---|---|---|
| `7 / 2` | `3` | `3.5` |
| `7 // 2` | — | `3` |
| `-7 / 2`（C++）、`-7 // 2`（Python） | `-3` | `-4` |
| `-7 % 2` | `-1` | `1` |

整数除法和取余是处理数位的基本工具：对三位数 `n`，个位是 `n % 10`，十位是 `n / 10 % 10`，百位是 `n / 100`。判断奇偶写 `n % 2 == 0`（对负数，`n % 2 == 1` 在 C++ 中不能判断奇数，因为 `-3 % 2` 是 `-1`；应写 `n % 2 != 0`）。

### 2.3.2. 赋值与自增

复合赋值是常用的简写：`x += 2` 即 `x = x + 2`，类似地有 `-=`、`*=`、`/=`、`%=`。C++ 还有自增和自减运算符：

| 写法 | 效果 | 表达式的值 |
|---|---|---|
| `++i` | `i` 增加 1 | 增加后的值 |
| `i++` | `i` 增加 1 | 增加前的值 |
| `--i`、`i--` | `i` 减少 1 | 同上 |

单独成句时 `++i;` 与 `i++;` 效果相同，习惯上写 `++i`。不要在同一个表达式中多次修改同一个变量，也不要在修改它的同时又读取它：`i = i++ + ++i` 是未定义行为；`std::cout << i << i++ << ++i` 在 C++17 以前结果未规定，C++17 起规定 `<<` 的操作数从左到右求值，输出 `23 23 25`（`i` 初值为 23），但编译器仍可能给出警告，这样的代码也不易读。Python 没有 `++`，写 `i += 1`。

### 2.3.3. 关系运算

关系运算符 `>`、`<`、`>=`、`<=`、`==`（相等）、`!=`（不等）比较两个值，结果是 `bool`。最常见的错误是把 `==` 写成 `=`：`if (x = 0)` 是把 $0$ 赋给 `x`，条件永远为假；`-Wall` 会对此警告。Python 中在条件里写赋值是语法错误，而且支持连写 `0 <= x < 10`；C++ 中 `0 <= x < 10` 能编译，却是先比较 `0 <= x` 得到 $0$ 或 $1$，再与 $10$ 比较，结果恒为真，应写 `0 <= x && x < 10`。逻辑运算 `&&`、`||`、`!` 见 [4.1.3](/4.1.3)。

### 2.3.4. 优先级、结合性与求值次序

一个表达式中有多个运算符时，按优先级和结合性决定运算对象怎样结合。常用运算符的优先级从高到低大致是：

1. 后缀 `x++`、函数调用 `f(x)`、下标 `a[i]`；
2. 前缀 `++x`、`!`、一元 `-`、类型转换；
3. `* / %`；
4. `+ -`；
5. `<< >>`（移位，也用于输入输出）；
6. `< <= > >=`；
7. `== !=`；
8. `&`、`^`、`|`（位运算，依次降低）；
9. `&&`，再是 `||`；
10. `?:` 与赋值 `= += …`（右结合）。

二元算术运算是左结合的：`a - b - c` 即 `(a - b) - c`；赋值是右结合的：`a = b = 0` 即 `a = (b = 0)`。优先级只决定结合方式，不决定求值的先后：`f() + g()` 中先调用哪个函数是未规定的。记不清优先级时就加括号，例如 `(x & 1) == 0`（不加括号会被解析为 `x & (1 == 0)`）。

### 2.3.5. 类型转换

不同类型的数据一起运算时，会发生隐式类型转换（implicit conversion）：

- 算术运算中，较"窄"的类型转为较"宽"的类型再计算：`int` 与 `double` 运算时，`int` 先转为 `double`；`char`、`bool`、`short` 先提升为 `int`。
- 赋值和初始化时，右边的值转为左边变量的类型。`double` 转为 `int` 时小数部分被截去（向零取整），这种可能丢失信息的转换称为窄化转换（narrowing conversion）。
- 有符号与无符号整数混合运算时，有符号数转为无符号数，`-1 < 1u` 的结果是 `false`。编译选项 `-Wsign-compare`（包含在 `-Wall` 中）会对此警告。

本章开头的温度转换若写成 `5 / 9 * (fahrenheit - 32)`，`5 / 9` 是整数除法，结果为 $0$，不论输入什么都输出 $0$；写成 `5.0 / 9` 后，$9$ 被转为 `double`，才得到 $0.555\ldots$。

需要转换时应当显式写出。C++ 推荐的写法是 `static_cast<目标类型>(表达式)`：

```cpp
double length = 3.7;
int n = static_cast<int>(length);       // 3: truncates toward zero
double ratio = static_cast<double>(n) / 2;   // 1.5 instead of 1
char next = static_cast<char>('A' + 1);      // 'B'
```

C 语言风格的 `(int)length` 和函数风格的 `int(length)` 也能用，但它们不区分转换的种类，在代码中也难以搜索。四舍五入用 `std::round`（`<cmath>`），向下取整用 `std::floor`。

Python 对照：Python 不会隐式地把字符串转为数，`"3" + 4` 抛出 `TypeError`，转换必须显式写 `int("3")`、`float("2.5")`、`str(4)`。`int(-3.7)` 向零截断得到 `-3`，`math.floor` 向下取整；内置的 `round` 采用"四舍六入五成双"，`round(2.5)` 是 `2`、`round(3.5)` 是 `4`，这是为了减少统计上的累积偏差。

## 2.4. 输入与输出

C++ 用流进行输入输出：`std::cin >> x` 从标准输入读取一个值存入 `x`，读取时跳过空格和换行，所以多个数据可以写在一行或多行中；`std::cout << e` 输出表达式的值，`<<` 可以连写。

```cpp tab
#include <format>     // std::format (C++20)
#include <iomanip>    // std::setprecision, std::fixed
#include <iostream>

int main() {
    int n;
    double x;
    std::cin >> n >> x;                                   // e.g. "3 2.5"
    std::cout << std::fixed << std::setprecision(2) << n * x << '\n';   // 7.50
    std::cout << std::format("{} * {:.3f} = {:8.2f}\n", n, x, n * x); // aligned output
    return 0;
}
```

```python tab
n, x = input().split()          # e.g. "3 2.5"
n, x = int(n), float(x)
print(f"{n * x:.2f}")           # 7.50
print(f"{n} * {x:.3f} = {n * x:8.2f}")
```

格式说明的含义在两种语言中相同：`.2f` 表示定点格式、保留 2 位小数，`8.2f` 再要求总宽度为 8 个字符（右对齐）。C++20 的 `std::format` 和 C++23 的 `std::print`（`std::print("{}\n", x)`，需要较新的编译器，如 GCC 14）采用的就是 Python 的格式语法，比用 `std::setprecision` 等操纵符或 C 语言的 `printf` 更清晰，也更安全（`printf` 的格式串与参数类型不符时是未定义行为）。字符串的格式化与文件流见 [4.2.11](/4.2.11)。

Python 的 `input()` 读取一整行并返回字符串，需要自己拆分和转换；读入一行中的多个整数常写作 `a, b = map(int, input().split())`。

## 小结

- 变量是有名字的存储单元；C++ 变量的类型在定义时固定（静态类型），Python 的名字只是对象的标签，类型属于对象（动态类型）。
- 数据类型决定取值范围与内存表示。整数有固定位数：有符号整数溢出是未定义行为，估计数量级，必要时用 `long long`；Python 的 `int` 不会溢出。
- 浮点数有舍入误差，默认用 `double`，不要用 `==` 比较浮点数。
- 注意整数除法截断、C++ 与 Python 对负数除法和取余的不同约定、`=` 与 `==`、运算符优先级；不在一个表达式中多次修改同一变量。
- 混合类型运算会隐式转换；需要转换时用 `static_cast` 显式写出。输出格式化优先用 `std::format`（C++）和 f-string（Python）。
