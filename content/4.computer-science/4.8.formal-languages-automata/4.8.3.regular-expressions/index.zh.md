第 2 章最简单的一类**文法**（3 型）生成的是正规语言。本章从另一个角度描述这类语言：从单个符号出发，只用并、连接、**Kleene 闭包**三种运算构造语言，写成的代数式子就是正规表达式。它是有限自动机之外描述正规语言最常用的方式，也是程序员熟悉的**正则表达式**（[4.2.11](/4.2.11)）的数学核心；实用正则表达式的大部分写法都可以化归为这三种运算。本章定义正规表达式及其语言，练习为给定语言设计表达式，再讨论正规表达式的代数定律。第 4 章引入有限自动机，第 5 章证明两者描述的是同一族语言。

## 3.1. 正规表达式

[§1.3](/4.8.1#sec-1.3) 定义了语言的三种运算：并 $L \cup M$、连接 $LM$、**Kleene 闭包** $L^*$。从最简单的语言 $\varnothing$、$\{\varepsilon\}$、$\{a\}$ 出发，反复使用这三种运算，就能写出许多语言。正规表达式就是记录这种构造过程的式子，它有语法（式子怎么写）与语义（式子表示哪个语言）两面。

**定义 3.1.1（正规表达式）** 字母表 $\Sigma$ 上的**正规表达式**归纳定义如下：

1. 基础：$\varepsilon$ 和 $\varnothing$ 是正规表达式；对每个 $a \in \Sigma$，$a$ 是正规表达式。
2. 归纳：若 $E$、$F$ 是正规表达式，则 $E + F$、$EF$、$E^*$、$(E)$ 都是正规表达式。

**定义 3.1.2（正规表达式的语言）** 正规表达式 $E$ 表示的语言 $L(E)$ 按 $E$ 的结构归纳定义：

$$
\begin{gathered}
L(\varepsilon) = \{\varepsilon\}, \qquad L(\varnothing) = \varnothing, \qquad L(a) = \{a\},\\
L(E + F) = L(E) \cup L(F), \qquad L(EF) = L(E)L(F), \qquad L(E^*) = L(E)^*, \qquad L((E)) = L(E).
\end{gathered}
$$

为减少括号，规定运算的优先级从高到低为：闭包 $^*$、连接、并 $+$；同一运算从左到右结合。例如 $01^* + 1$ 是 $(0(1^*)) + 1$，表示 $\{1, 0, 01, 011, \dots\}$；而 $(01)^* + 1$ 表示 $\{1, \varepsilon, 01, 0101, \dots\}$。

常用的派生记号：$E^+ = EE^*$（一次或多次），$E^? = \varepsilon + E$（可选），$E^n = EE \cdots E$（$n$ 个 $E$ 连接，$E^0 = \varepsilon$）。它们都不增加表达能力，只是缩写。

**例 3.1.1** 设 $\Sigma = \{0, 1\}$。

- $(0 + 1)^*$ 表示 $\Sigma^*$，$(0 + 1)^n$ 表示 $\Sigma^n$。
- $1^*0(0 + 1)^*$ 表示至少含一个 0 的串：第一个 0 之前全是 1，之后任意。
- $(0 + 1)^*00(0 + 1)^*$ 表示含子串 00 的串。
- $\varnothing^*$ 表示 $\{\varepsilon\}$；$0\varnothing$ 表示 $\varnothing$。

实用的正则表达式（[4.2.11](/4.2.11) 中 C++ `<regex>`、Python `re` 等库的写法）与这里的形式定义有如下对应：

- 并：形式定义写 $E + F$，实用写法用竖线 `a|b`。注意实用写法中的 `+` 表示"一次或多次"，即这里的 $E^+$，两者不可混淆。
- 连接与闭包：写法相同，`ab`、`a*`。
- 字符类 `[abc]`、`[0-9]`、通配符 `.` 都是有限个符号的并，如 `[0-9]` 即 $0 + 1 + \cdots + 9$；计数重复 `a{2,4}` 即 $aa(\varepsilon + a)(\varepsilon + a)$；`?` 即 $\varepsilon + E$。这些都可以化归为三种基本运算，表达能力不变。
- 锚点 `^`、`$` 表示匹配的位置；形式定义讨论的是整个串是否属于语言，相当于总是加上两端的锚点（Python 的 `re.fullmatch`）。
- 反向引用（如 `(a*)b\1` 要求两段 $a$ 一样长）超出了正规语言的范围：`(a*)b\1` 描述的 $\{a^n b a^n\}$ 不是正规语言（第 6 章）。带反向引用的匹配是 NP 完全问题，这也是实用引擎普遍采用回溯算法的原因之一（第 5 章再讨论匹配算法）。

## 3.2. 正规语言

**定义 3.2.1（正规语言）** 字母表 $\Sigma$ 上的**正规语言**归纳定义为：$\varnothing$、$\{\varepsilon\}$ 以及每个 $\{a\}$（$a \in \Sigma$）是正规语言；若 $L$、$M$ 是正规语言，则 $L \cup M$、$LM$、$L^*$ 也是正规语言；只有这样得到的语言是正规语言。

比较定义 3.1.1 与 3.1.2 立即可知：$L$ 是正规语言，当且仅当存在**正规表达式** $E$ 使 $L = L(E)$。每个有限语言都是正规语言：$\{w_1, \dots, w_k\} = L(w_1 + \cdots + w_k)$，其中每个 $w_i$ 是符号的连接（空语言用 $\varnothing$）。

正规语言的名字来自 Kleene 在 1951 年研究神经网络模型时提出的 regular events。第 4、5 章将证明它们恰好是有限自动机能识别的语言，第 2 章的 **3 型文法**生成的也恰好是这类语言；三种描述的等价是正规语言理论的核心。

## 3.3. 正规表达式的设计

为一个语言写**正规表达式**，常用的思路是：找出必须出现的"骨架"，再用 $(0 + 1)^*$ 之类的闭包填充骨架之间的任意部分；条件复杂时按情况分别写出再取并；位置条件（倒数第几位）用定长的 $(0 + 1)^n$ 表达。下面各例的**字母表**都是 $\{0, 1\}$，每个表达式都对长度不超过 10 的全部串用程序逐一核对过。

**例 3.3.1** 含有子串 000 的串：骨架是 000，两侧任意，$(0 + 1)^*000(0 + 1)^*$。以 01 结尾的串：$(0 + 1)^*01$。

**例 3.3.2** 首尾符号相同的非空串：分首尾都是 0、都是 1、长度为 1 三种情况，

$$
0(0 + 1)^*0 + 1(0 + 1)^*1 + 0 + 1.
$$
首尾符号不同的串则是 $0(0 + 1)^*1 + 1(0 + 1)^*0$，它的长度自然至少为 2。

**例 3.3.3（位置条件）** 倒数第 5 位是 1 的串：$(0 + 1)^*1(0 + 1)^4$。前 5 位中至少有一个 1 的串：第一个 1 出现在第 $k \le 5$ 位，前面是 $k - 1 \le 4$ 个 0，用 $(\varepsilon + 0)$ 表示"可有可无的一个 0"：

$$
(\varepsilon + 0)^4 1 (0 + 1)^*.
$$
这里 $(\varepsilon + 0)^4$ 表示 $\{\varepsilon, 0, 00, 000, 0000\}$，这种借助 $\varepsilon$ 表达"至多 $k$ 个"的技巧很常用。

**例 3.3.4（禁止的子串）** 不含子串 11 的串：每个 1 后面必须紧跟 0，除非它是最后一个符号。因此串由 0 和 10 拼成，末尾可能多一个 1：

$$
(0 + 10)^*(\varepsilon + 1).
$$

**例 3.3.5（计数的奇偶）** 含偶数个 0 的串：把串在每第二个 0 之后切开，每段形如 $1^*01^*0$，最后剩下一段 $1^*$，于是表达式为 $(1^*01^*0)^*1^*$。

**例 3.3.6** 每一对相邻的 00 都出现在任何一对相邻的 11 之前的串。技巧是把串分成两部分：左部允许 00 而不含 11，右部允许 11 而不含 00。由例 3.3.4，左部为 $(0 + 10)^*(\varepsilon + 1)$，对称地右部为 $(1 + 01)^*(\varepsilon + 0)$，于是

$$
(0 + 10)^*(\varepsilon + 1)(1 + 01)^*(\varepsilon + 0).
$$
对任一满足条件的串，在第一个 11 的第一个 1 之前切开即得这样的分解（没有 11 时整个串都放在左部）；反之，两部分接缝处可能新出现 00 或 11，但新出现的 00 必在右部的所有 11 之前，新出现的 11 必在左部的所有 00 之后，条件仍然满足。

正规表达式的设计没有万能的套路，条件交错时（例如"含奇数个子串 01"）先画有限自动机、再用第 5 章的算法转换往往更可靠。

## 3.4. 正规表达式的代数定律

两个**正规表达式** $E$、$F$ 称为等价的，记作 $E = F$，如果 $L(E) = L(F)$。等价的表达式可以互相替换，代数定律就是对其中出现的子表达式（看作变量）作任何替换都成立的等式。

**定理 3.4.1** 对任意正规表达式 $L, M, N$：

| 名称 | 定律 |
|---|---|
| 并的交换律、结合律 | $L + M = M + L$，$(L + M) + N = L + (M + N)$ |
| 连接的结合律 | $(LM)N = L(MN)$ |
| 单位元 | $\varnothing + L = L$，$\varepsilon L = L\varepsilon = L$ |
| 零元 | $\varnothing L = L\varnothing = \varnothing$ |
| 分配律 | $L(M + N) = LM + LN$，$(M + N)L = ML + NL$ |
| 幂等律 | $L + L = L$ |
| 闭包 | $(L^*)^* = L^*$，$\varnothing^* = \varepsilon$，$\varepsilon^* = \varepsilon$，$L^+ = LL^* = L^*L$，$L^* = L^+ + \varepsilon$ |

连接一般不满足交换律：$01 \ne 10$。这些定律有的直接来自集合运算的性质（并的交换律、结合律、幂等律），有的来自串的连接（单位元、结合律）。以分配律为例：

**证明**（左分配律）$w \in L(L(M + N))$ 当且仅当 $w = xy$，$x \in L(L)$，$y \in L(M) \cup L(N)$；当且仅当 $w = xy$，$x \in L(L)$ 且 $y \in L(M)$，或者 $x \in L(L)$ 且 $y \in L(N)$；当且仅当 $w \in L(LM) \cup L(LN)$。$\square$

逐条这样证明很繁琐，而且对一个猜想的等式，往往要先判断它对不对。下面的定理把"对一切语言成立"化归为"对一个具体的表达式成立"。

**定理 3.4.2（具体化检验）** 设 $E$、$F$ 是以 $L_1, \dots, L_m$ 为变量的正规表达式。把每个 $L_i$ 换成互不相同的新符号 $a_i$，得到不含变量的具体表达式 $C$、$D$。则 $E = F$ 对所有语言 $L_1, \dots, L_m$ 都成立，当且仅当 $L(C) = L(D)$。

**证明** 任取一组语言 $S_1, \dots, S_m$ 代入变量。定义 $\sigma(a_i) = S_i$，并按 $\sigma(\varepsilon) = \{\varepsilon\}$、$\sigma(xy) = \sigma(x)\sigma(y)$ 推广到串，再按 $\sigma(K) = \bigcup_{x \in K}\sigma(x)$ 推广到语言。先证明：代入后 $E$ 的语言等于 $\sigma(L(C))$。对 $E$ 的结构归纳。$E$ 为 $\varepsilon$、$\varnothing$ 时显然；$E = L_i$ 时两边都是 $S_i$。$E = E_1 + E_2$ 时，$\sigma$ 保持并，$\sigma(L(C_1) \cup L(C_2)) = \sigma(L(C_1)) \cup \sigma(L(C_2))$；$E = E_1E_2$ 时，由 $\sigma(xy) = \sigma(x)\sigma(y)$ 得 $\sigma(L(C_1)L(C_2)) = \sigma(L(C_1))\sigma(L(C_2))$；$E = E_1^*$ 时同理有 $\sigma(L(C_1)^*) = \sigma(L(C_1))^*$。由归纳假设即得。

于是若 $L(C) = L(D)$，则对任意代入，$E$ 与 $F$ 的语言都等于 $\sigma(L(C)) = \sigma(L(D))$，定律成立。反之，若定律对一切语言成立，取 $S_i = \{a_i\}$，$\sigma$ 是恒等的，得 $L(C) = L(D)$。$\square$

**例 3.4.1** 

- 验证 $(L + M)^* = (L^*M^*)^*$：具体化为 $(a + b)^* = (a^*b^*)^*$，两边都是 $\{a, b\}$ 上的全体串，定律成立。
- 验证 $LL^* = L^*L$：$aa^*$ 与 $a^*a$ 都表示 $\{a^n \mid n \ge 1\}$，成立。
- 检验 $L + ML = (L + M)L$：具体化为 $a + ba$ 与 $(a + b)a$，$aa \in L((a + b)a)$ 而 $aa \notin L(a + ba)$，所以这不是定律。

由第 6 章，两个不含变量的正规表达式是否等价是可判定的，因此定理 3.4.2 给出了判定任一候选定律的算法。需要注意，这个方法只适用于由并、连接、闭包构成的表达式；若引入交运算，具体化检验会失效，例如 $L \cap M \cap N = L \cap M$ 具体化后两边都是 $\varnothing$，但它显然不是定律。

**定理 3.4.3（Arden 引理）** 设 $A$、$B$ 是语言，$\varepsilon \notin A$。则方程 $X = AX \cup B$ 有唯一解 $X = A^*B$。

**证明** $A^*B$ 是解：$A(A^*B) \cup B = (A^+ \cup \{\varepsilon\})B = A^*B$。设 $X$ 是任一解。反复代入得 $X = A^{n+1}X \cup (A^n \cup \cdots \cup A \cup \{\varepsilon\})B$ 对一切 $n$ 成立，所以 $A^*B \subseteq X$。反之任取 $w \in X$，令 $n = \lvert w\rvert$：由 $\varepsilon \notin A$，$A^{n+1}X$ 中的串长度至少为 $n + 1$，$w$ 不在其中，只能属于 $(A^n \cup \cdots \cup \{\varepsilon\})B \subseteq A^*B$。$\square$

Arden 引理是把有限自动机化为正规表达式的另一种方法的基础：为每个状态 $q$ 设未知语言 $X_q$（从 $q$ 出发能到达接受状态的串），按转移列出线性方程组，再用 Arden 引理逐个消元（第 5 章）。
