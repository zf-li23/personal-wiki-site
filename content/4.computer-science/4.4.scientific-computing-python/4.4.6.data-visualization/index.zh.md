在计算工作中，图往往是对数据做的第一件事，也是最后一件事：第一件，是因为画出原始测量值能揭示异常值、批次效应、饱和的检测器和标错的样本，这些是任何汇总统计量都显示不出来的；最后一件，是因为论文的结论在很大程度上通过图来传达和评判。本章同时处理这两种用途。先讲 Matplotlib，几乎所有 Python 绘图都建立在这个库之上，以及它的面向对象接口；再转向使图诚实而易读的各项决定（什么数据用什么图、用什么颜色、怎样安排许多面板、要避免哪些错误）；最后介绍两个更高层的库：用于统计图形的 seaborn 和用于交互式图形的 Plotly。数据来自 [4.4.5](/4.4.5) 的表格；统计图（直方图、**箱线图**、**核密度估计**、**散点图矩阵**）在统计学课程中定义，R 的图形系统见 [3.5.2](/3.5.2)。

本章的图均由 Matplotlib 3.10 用合成数据绘制，每张图由其下方给出的脚本生成。seaborn 与 Plotly 的示例分别用 seaborn 0.13.2 和 Plotly 7.1.0 运行（Matplotlib 3.11.2，pandas 3.0.6）。

## 6.1. Matplotlib：Figure 与 Axes

### 6.1.1. 两种接口

Matplotlib 有两种绘图方式。*pyplot* 接口（`plt.plot`、`plt.xlabel` 等）模仿 MATLAB：它维护一个隐藏的“当前图形”和“当前坐标系”，并把每个调用导向它们。在 **Jupyter 笔记本**中随手看一眼时很方便，但在有多个面板的脚本中，隐含的状态使人难以知道一个调用画在哪里。*面向对象*接口则显式地创建对象并调用它们的方法；凡是要保存下来的图，都推荐这种风格。

这些对象构成一棵树：

| 对象 | 含义 | 典型方法 |
|---|---|---|
| `Figure` | 整幅图像：大小、分辨率、背景；包含一个或多个 Axes | `subplots`、`subplot_mosaic`、`subfigures`、`colorbar`、`suptitle`、`savefig` |
| `Axes` | 带坐标系的一个绘图区：两个 `Axis` 对象、标题、图例 | `plot`、`scatter`、`bar`、`hist`、`imshow`、`fill_between`、`set_xlabel`、`set_xscale`、`legend` |
| `Axis` | Axes 的一条坐标轴：范围、刻度类型、刻度、刻度标签 | `set_major_locator`、`set_major_formatter`（通常通过 Axes 的方法访问） |
| `Artist` | 画出来的一切：`Line2D`、`Text`、`Patch`、`AxesImage` 等 | `set_color`、`set_linewidth`、`set_visible` |

Axes 的每个绘图方法都会返回它创建的 artist，因此之后还可以修改它们。这种风格的一个最小脚本：

```python
import numpy as np
import matplotlib.pyplot as plt

t = np.linspace(0, 24, 49)
od = 1.2 / (1 + 29 * np.exp(-0.45 * t))          # logistic growth curve

fig, ax = plt.subplots(figsize=(4, 3), layout="constrained")
(line,) = ax.plot(t, od, linewidth=2, label="WT")
ax.set_xlabel("Time (h)")
ax.set_ylabel("OD600")
ax.set_yscale("log")
ax.legend(frameon=False)
fig.savefig("growth.pdf")
```

`plt.subplots` 是唯一需要用到的 pyplot 调用：它创建 Figure 和 Axes 并返回它们，此后代码都点名要修改的对象。这条曲线是**逻辑斯谛增长**（[2.2.15](/2.2.15)）模型；在对数坐标轴上，它的指数阶段变成一条直线，斜率就是生长速率，这正是生长曲线习惯上用对数刻度显示的原因。

### 6.1.2. 多面板图形

论文中的一幅图通常由若干面板组合而成。`fig.subplots(nrows, ncols, sharex=..., sharey=..., width_ratios=...)` 创建规则网格；`fig.subplot_mosaic("AAB;CCB")` 依据文本布局创建大小不同的面板，返回以字母为键的 Axes 字典；`fig.subfigures` 把图拆分为各有自己布局的独立区域。`layout="constrained"` 使 Matplotlib 为标签、标题和颜色条预留空间，使它们互不重叠，从而取代用 `subplots_adjust` 或较旧的 `tight_layout` 手工调整。

![用面向对象接口绘制的三面板图。（A）三个菌株的生长曲线，为四个重复的均值与一个标准差的带，使用对数刻度，并直接在曲线旁标注而不用图例。（B）12 h 时各个重复及其均值。（C）六个样本中十二个基因按行计算的 z 分数热图，使用以零为中心的发散颜色映射；线条把对照样本与处理样本分开。](./plots/multi-panel-figure.py)

这幅图的脚本展示了几个值得效仿的习惯：所有 Axes 一次创建并命名（`ax_a`、`ax_b`、`ax_c`）；面板字母用 `set_title(loc="left")` 放置；每个菌株的分类颜色只指定一次，并在所有面板中沿用；曲线直接在末端标注，省去读者去看图例的往返；颜色映射的上下界关于零对称，使白色表示“无变化”。

### 6.1.3. 导出图形

| 输出 | 格式 | 说明 |
|---|---|---|
| 线条图、折线图、文字 | PDF、SVG、EPS（矢量） | 缩放无损；文字仍可编辑；把 `pdf.fonttype` 设为 `42`，使期刊和 Illustrator 得到 TrueType 字体而不是 Type 3 |
| 图像、有数百万单元格的热图、密集散点图 | PNG、TIFF（栅格），300–600 dpi | 对单个密集的 artist 使用 `rasterized=True`，使 PDF 的其余部分保持矢量 |
| 网页、幻灯片 | PNG、SVG | 有损的 JPEG 不适合用于图表 |

要按最终印刷的尺寸制图（`figsize` 以英寸计：期刊单栏约 3.5 in，通栏 7 in），字号 7–9 pt，而不是按屏幕尺寸绘制再缩小：缩小会使文字和线条过细，且各面板之间不一致。要使整个项目的图外观一致，应把设置收集在样式表（`plt.style.use("paper.mplstyle")`）或 `with plt.rc_context({...}):` 块中，而不是在每个调用中重复关键字参数。

## 6.2. 选择图表

图表的类型取决于图要回答的问题和所涉变量的种类：

| 问题 | 变量 | 图表 |
|---|---|---|
| 一个量如何分布？ | 一个数值变量 | 直方图、**核密度估计**、ECDF；多个组：带状图或蜂群图（所有点）、**箱线图**、小提琴图 |
| 两个量有什么关系？ | 两个数值变量 | 散点图；点重叠严重时用 hexbin 或二维直方图；多个变量用**散点图矩阵** |
| 一个量沿有序变量如何变化？ | 数值对时间、剂量、位置 | 折线图，用带或误差棒表示不确定性 |
| 各组如何比较？ | 数值对分类 | 带区间的估计值点图；叠在**箱线图**上的点；条形图只用于计数和其他从零开始的量 |
| 整体的各部分有多大？ | 计数或比例 | 堆叠条形图；饼图只用于两三个部分 |
| 矩阵的结构是什么？ | 数值矩阵 | 热图，行列按**层次聚类**排序；二元光滑函数用**等高线图** |
| 许多序列的行为如何？ | 许多线或组 | 小多图（§6.4） |

带误差棒的组均值条形图在生物学中仍然常见，但对测量数据是糟糕的选择：条形的面积不编码任何信息（条形从零开始是出于惯例，而不是因为零有意义），误差棒隐藏了样本量和分布的形状，而差别很大的数据会产生同样的图。

![三个各含 30 个细胞的样本，均值和标准差完全相同。画成带标准误的均值条形图（左）时无法区分；画成叠在箱线图上的点（右）时，样本 A 是单峰的，样本 B 由两个亚群组成，样本 C 中的两个离群点造成了全部的离散。](./plots/bar-of-means.py)

只要观测数量适中（每组至多几百个），就应当显示观测值本身。使用误差棒时要说明它们是什么：**标准差**描述数据的离散程度，均值的**标准误**描述均值的精度并按 $1/\sqrt{n}$ 缩小，95 % **置信区间**大致是标准误的两倍。没有这个说明，读者无法解读这幅图，因为三者之间相差一个依赖于 $n$ 的因子。

## 6.3. 颜色

### 6.3.1. 颜色映射

**定义 6.3.1（颜色映射）** **颜色映射**（colormap）是从数据值的区间（归一化到 $[0, 1]$）到颜色的函数。**顺序颜色映射**的亮度单调变化，编码量的大小；**发散颜色映射**由在中性色处相接的两段顺序颜色映射组成，编码对有意义的中心（零，或比值为一）的偏离；**定性颜色映射**是一组没有次序的互异颜色，编码类别。

眼睛判断亮度差异远比判断色相差异可靠。若数据的等距变化引起的感知颜色差异也相等，则称该颜色映射为感知均匀颜色映射（perceptually uniform colormap）；特别地，此时它的亮度呈线性、单调的变化。“彩虹”颜色映射（`jet`、`hsv`）长期是 MATLAB 以及 2.0 版以前 Matplotlib 的默认选择，但它们不是感知均匀的：其亮度时升时降，于是明亮的青色带和黄色带看起来像是数据的特征，而且两个不同的值可能有相同的亮度。

![同一个光滑的场（一个宽峰、一个较弱的肩部和一个线性趋势）用三种颜色映射显示，下方是各颜色映射的亮度 L*。jet 的亮度上升到平台后又下降，在数据光滑处的青色和黄色边界产生了明显的假边缘；viridis 和 cividis 的亮度线性增加，显示的场没有伪影。](./plots/colormaps.py)

自 2.0 版起 Matplotlib 的默认颜色映射是 `viridis`，它被设计成感知均匀，灰度打印效果好，并且对常见的色觉缺陷保持可读；`cividis` 是针对后一点进一步优化的变体。实际的选择如下：

| 数据 | Matplotlib 中的颜色映射 |
|---|---|
| 量的大小（表达水平、密度、强度） | 顺序：`viridis`、`cividis`、`magma`；单色相的 `Blues`、`Greys` |
| 有符号的偏离（对数倍数变化、z 分数、相关系数） | 发散：`RdBu_r`、`PuOr`、`berlin`、`vanimo`，上下界关于中心对称（`vmin=-m, vmax=m`，或 `matplotlib.colors.TwoSlopeNorm`） |
| 角度、相位、一天中的时刻 | 循环：`twilight` |
| 类别 | 定性：`tab10`，或 Okabe–Ito 这样的固定列表；`petroff10` 样式表（Matplotlib 3.10）提供了一个无障碍的颜色循环 |

还有两点。跨越多个数量级的对数量需要对数归一化（`norm=LogNorm()`），而不是换一个颜色映射。其次，超过大约七种颜色的定性调色板已不可读：此时应对序列分组、有选择地突出，或拆成小多图。

### 6.3.2. 色觉缺陷

北欧血统的男性约有 8 %、女性约有 0.5 % 患有红绿色觉缺陷（以绿色弱最为常见）。因此，把红色和绿色用作热图的两极或图中的两条线，相当一部分读者将无法区分。补救办法有：

- 使用专为此设计的调色板：类别用 Okabe–Ito，大小用 `viridis` 和 `cividis`，发散数据用蓝–橙或蓝–红而不是红–绿；
- 冗余地编码身份：直接标注、标记形状、线型、面板位置；
- 用色觉缺陷的模拟（图像编辑器和浏览器的开发者工具都提供）以及灰度检查图形。

## 6.4. 小多图

当一幅图要显示许多序列时，把它们都画在一个面板里会纠缠成一团，其中任何一条序列都无法追踪。另一种做法由 Edward Tufte 称为小多图（small multiples），即由坐标轴和刻度完全相同的小面板构成的网格，每个面板显示一个序列或数据的一个子集；由于刻度一致，眼睛只凭位置就能比较各个面板。

![八条合成的表达时间过程。画在一个有八种颜色的面板中（左）时，各种模式难以分开。画成共享坐标轴的小多图（右）时，每个基因相对于灰色的其他基因被突出显示，昼夜节律型、诱导型、抑制型、瞬时型和平坦型的曲线一眼就能认出。](./plots/small-multiples.py)

在 Matplotlib 中，小多图是用 `sharex=True, sharey=True` 创建的网格；seaborn 用一个参数（`col="gene", col_wrap=4`）从长格式表创建它们，ggplot2 则称之为分面。共享坐标轴是必不可少的：各自独立缩放坐标轴的面板，恰恰会引出那些它们使之无效的比较。像上面那样把其他序列用浅灰色显示在被突出的序列后面，既保留了背景，又不显杂乱。

## 6.5. 常见错误

大多数误导性的图并非有意为之，而是源于默认设置和习惯。下面的列表涵盖常见的情形。

![坐标轴误导读者的两种方式。从 95 % 开始的条形图坐标轴使存活率 4 % 的差别看起来成了五倍；用从零开始的坐标轴，差别才按比例呈现。双纵轴上的两个基因似乎沿着同一条曲线变化，但这只是因为每条坐标轴都按各自的数据缩放；在同一条坐标轴上按 0 h 时的值作指数化，基因 A 增为三倍，而基因 B 的增长不到一半。](./plots/misleading-axes.py)

| 错误 | 为何误导 | 更好的做法 |
|---|---|---|
| 条形图坐标轴不从零开始 | 条形的长度被当作量的大小，截断的坐标轴会夸大差别 | 条形从零开始，或改用点，点的位置不必与零比较 |
| 双纵轴 | 两个刻度是任意的，所以任何两个递增序列都可以被做成在任意处重合或相交 | 共用横轴的两个面板，或指数化到共同基线后把两个序列画在同一条坐标轴上 |
| 彩虹颜色映射 | 非单调的亮度制造假边界、掩盖真边界；色觉缺陷者无法阅读 | 感知均匀的颜色映射（§6.3） |
| 要比较的面板使用独立刻度 | 相同的高度看起来像相同的值 | `sharey=True`，或明确说明刻度不同 |
| 三维条形图、透视饼图、阴影 | 透视扭曲长度和面积 | 朴素的二维标记 |
| 过度绘制（把成千上万个点画成不透明的圆点） | 密集区域饱和，离群点占主导 | 透明度、更小的标记、hexbin 或二维直方图、密度等高线 |
| 未标注的误差棒、缺少单位、未解释的缩写 | 图无法独立解读 | 带单位的坐标轴标签；图注说明 $n$ 和误差棒的含义 |
| 使用对数刻度却不加说明，或对乘性数据使用线性刻度 | 比值和增长率变得不可读 | 浓度、倍数变化和增长使用对数坐标轴，并加以标明 |

发表图形之前一个有用的检验，是问一问读者十秒钟内会从中得出什么结论，以及该结论是否为数据所支持。

## 6.6. 用 seaborn 绘制统计图形

seaborn 建立在 Matplotlib 和 pandas 之上：它的函数接受长格式的**数据框**（[4.4.5](/4.4.5)），把列映射到视觉属性（位置、颜色、大小、面板），并在过程中计算所需的统计量（均值、置信区间、密度估计、回归拟合）。它的经典 API 有两个层次：

- *坐标系级*函数（`scatterplot`、`lineplot`、`histplot`、`kdeplot`、`boxplot`、`violinplot`、`stripplot`、`heatmap`）画在一个以 `ax=` 传入的 Matplotlib Axes 中，因此可以在自定义布局中与 Matplotlib 代码混用；
- *图形级*函数（`relplot`、`displot`、`catplot`、`lmplot`，以及用于**散点图矩阵**的 `pairplot`、用于聚类热图的 `clustermap`）创建整幅图，包括通过 `row=` 和 `col=` 得到的小多图，并返回一个网格对象。

```python
import numpy as np
import pandas as pd
import seaborn as sns

rng = np.random.default_rng(0)
t = np.tile(np.arange(0, 25, 2.0), 6)
strain = np.repeat(["WT", "mutA", "mutB"], 26)
rep = np.tile(np.repeat([1, 2], 13), 3)
rate = {"WT": 0.45, "mutA": 0.35, "mutB": 0.25}
od = np.array([1.2 / (1 + 30 * np.exp(-rate[s] * x)) for s, x in zip(strain, t)])
growth = pd.DataFrame({"time_h": t, "strain": strain, "replicate": rep,
                       "od600": od * rng.lognormal(0, 0.05, t.size)})

g = sns.relplot(data=growth, x="time_h", y="od600", hue="strain",
                kind="line", errorbar="sd")
g.set(yscale="log", xlabel="Time (h)", ylabel="OD600")
g.savefig("growth.pdf")
```

自 0.12 版起，seaborn 还有一个 *objects 接口*（`seaborn.objects`），仿照 Leland Wilkinson 的图形语法（grammar of graphics）（R 中的 ggplot2 也以它为基础）：一幅图由数据、变量到视觉属性的映射、标记（`Dot`、`Line`、`Bar`、`Area`）、统计变换（`Agg`、`Est`、`Hist`、`KDE`、`PolyFit`）和刻度组合而成，每一项作为单独的一层添加。同一幅图的这种写法：

```python
import seaborn.objects as so

(so.Plot(growth, x="time_h", y="od600", color="strain")
   .add(so.Dots(alpha=0.4))            # every measurement
   .add(so.Line(), so.Agg())           # mean at each time point
   .scale(y="log")
   .label(x="Time (h)", y="OD600")
   .save("growth-objects.pdf"))
```

objects 接口在 seaborn 0.13（当前版本）中仍被标为实验性的，但它的分层结构比经典函数更容易扩展。两种风格得到的都是普通的 Matplotlib 图形，保存之前可以用 §6.1 的方法调整。

## 6.7. 用 Plotly 制作交互式图形

探索数据时，能显示光标下的数值、放大某个区域、点击即可隐藏序列的交互式图形，可能比任何静态图都更有用：哪个样本是离群点，火山图中的那个点是哪个基因。Plotly 用 JavaScript 在浏览器中渲染图形；它的高层模块 `plotly.express` 像 seaborn 一样接受长格式的 DataFrame：

```python
import plotly.express as px

fig = px.line(growth, x="time_h", y="od600", color="strain",
              line_group="replicate", log_y=True,
              hover_data=["replicate"],
              labels={"time_h": "Time (h)", "od600": "OD600"})
fig.write_html("growth.html", include_plotlyjs="cdn")
```

得到的 HTML 文件（这里约 13 kB，Plotly 库从 CDN 加载）可以在任何浏览器中打开，可以分享或嵌入报告；在 Jupyter 中图形直接显示。`plotly.graph_objects` 提供对轨迹和布局的完全控制，Dash 则围绕 Plotly 图形构建网络应用。基于 plotly.js 4 的 Plotly 7.0（2026 年 8 月）移除了旧的基于 Mapbox 的地图轨迹，改用基于 MapLibre 的轨迹，并移除了若干早已弃用的图形工厂，因此较旧的示例可能需要调整。用途相近的替代品有 Bokeh 和 Altair，显微成像中的大图像和体数据则可用 napari。

交互式图形是静态图形的补充而不是替代：期刊印刷的是静态图，交互式图形把信息藏在光标之后，而且它的外观取决于查看者的软件。常见的工作流程是用交互式图形做探索，用 Matplotlib 或 seaborn 生成最终的图。

## 6.8. 出版级图形检查清单

1. 内容：每幅图一个信息；图表类型与问题相符（§6.2）；$n$ 较小时显示原始数据。
2. 文字：每条坐标轴都有带单位的标签；字体在印刷尺寸下清晰可辨（7–9 pt），且各面板一致；缩写在图注中解释。
3. 不确定性：误差棒和带在图注中说明（标准差、标准误或置信区间），并给出 $n$ 以及重复的含义。
4. 刻度：条形从零开始；要比较的面板共享刻度；乘性的量使用对数坐标轴并加以标明。
5. 颜色：按情形使用感知均匀或发散的颜色映射，发散时以中心对齐；避免红绿；身份同时用标签或形状编码；图在灰度下仍然可用。
6. 布局：面板对齐并标注字母；尽可能用直接标注代替图例；没有三维效果、阴影和不必要的网格线与边框。
7. 导出：最终尺寸，线条图用矢量格式，图像用 300–600 dpi 的栅格格式，字体嵌入。
8. 可复现性：图由脚本根据数据生成，并固定**随机种子**，使数据或审稿人的要求变化时可以重新生成。

## 小结

- 使用 Matplotlib 的面向对象接口：用 `plt.subplots` 或 `subplot_mosaic` 创建 Figure 和 Axes，再对它们调用方法；使用 `layout="constrained"`。
- 依问题选择图表：分布、关系、趋势、比较、矩阵；点数不多时显示数据点，测量数据避免使用均值条形图。
- 大小用感知均匀的顺序颜色映射，偏离用以有意义的值为中心的发散颜色映射，类别用少数几种互异的颜色；绝不使用彩虹颜色映射；为色觉缺陷着想。
- 共享坐标轴的小多图比一个拥挤的面板更能显示许多序列。
- 截断的条形图坐标轴、双纵轴、不一致的刻度和未标注的误差棒都会误导读者。
- seaborn 把长格式表转换成统计图形，具有小多图和图形语法式的 objects 接口；Plotly 生成用于探索的交互式 HTML 图形。
- 用脚本、按最终尺寸生成图形，尽可能使用矢量格式。
