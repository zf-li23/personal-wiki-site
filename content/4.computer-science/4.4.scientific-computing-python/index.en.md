The core problem of scientific computing is to obtain, in a high-level language that is convenient to write, a speed close to that of compiled code. Python's own **interpreter** executes operations one by one and is very slow; it has become the standard language of scientific computing because the heavy numerical work is handed to libraries written in C, C++ and Fortran and tested over decades, while Python only organizes and dispatches. This course covers that ecosystem: what layers it consists of, what data structures and algorithms each layer provides, and how to use them correctly, efficiently and reproducibly. Three threads run through the course: expressing computation as operations on whole blocks of data, that is, **vectorization**; when calling an existing library, choosing the right function, observing the conventions of its interface and knowing how accurate the result should be; and making the computing environment and the results reproducible on another machine and a year later.

The chapters proceed through the ecosystem from the bottom up. The course first sets up the environment: it explains the layers of the scientific Python ecosystem, and how packages, **virtual environments** and lock files make the dependencies of a project reproducible. NumPy is the foundation of the whole ecosystem; it provides only one data structure, the **n-dimensional array**, together with fast operations on whole arrays. Understanding how an array is laid out in memory explains almost every surprising behavior of NumPy, and universal functions, reductions and **broadcasting** support the vectorized style of programming. On top of arrays, the linear algebra and random number modules of NumPy are interfaces to BLAS, LAPACK and modern pseudorandom number generators, while SciPy supplies numerical algorithms for optimization, integration and differential equations, interpolation, statistics, sparse matrices and signal processing. Real data often form tables with row and column labels and columns of different types, which are handled by the **data frame** of pandas; tables are then turned into honest, readable graphics by Matplotlib, seaborn and Plotly. The last chapter discusses the cases where vectorization is not enough: first measure and use **profiling** to find the bottleneck, then speed things up with the **just-in-time compilation** of Numba and with multiprocess and multithreaded parallel execution.

This course presupposes the Python parts of [Programming Fundamentals](/4.1) and [Object-Oriented Programming](/4.2), in particular modules and packages and the object model of Python variables. It complements [Statistical Computing and Software](/3.5): there the principles of floating-point arithmetic, numerical linear algebra, optimization and random number generation are explained, and here we see how to call the libraries that implement them from Python; the vectors and data frames of R also correspond exactly to NumPy arrays and pandas data frames. For the theory of differential equations see [ordinary differential equations](/2.4), for the statistical methods used to process tables see [linear regression analysis](/3.3) and [multivariate statistical analysis](/3.4), and for processes and threads as objects of the operating system see [Operating Systems](/4.11). This ecosystem is also the tool basis of [Introduction to Machine Learning](/4.6) and [Artificial Neural Networks](/4.7): libraries such as scikit-learn and PyTorch use NumPy arrays, or arrays compatible with them, as the format for exchanging data.

I have not actually taken a course like this; this part is a summary based on what I have accumulated in daily practice. When working with data, we really cannot do without the packages and data structures defined in the Python ecosystem. They serve efficient computation: NumPy arrays require elements of one type stored in one contiguous block of memory at a fixed stride, and pandas columns are likewise stored whole by type, so they are not as flexible as the linked lists and search trees of [Data Structures and Algorithms](/4.3), where elements can be freely inserted, deleted and joined; they are more like the vectors and data frames of R that we met in [Statistical Computing and Software](/3.5). Understanding these data structures and the libraries built on them also helps explain why Python has become the core language of artificial intelligence and machine learning: the language itself is easy to learn and write, while the efficiency of computation is guaranteed by the libraries underneath.

It makes good sense for this course to be a restricted elective in computing for students of the biological sciences: reading in sequencing and experimental data, cleaning and organizing tables, running statistical analyses and drawing figures all require these tools almost every day.
