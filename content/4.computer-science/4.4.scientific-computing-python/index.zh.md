科学计算的核心问题，是在一种写起来方便的高级语言里，获得接近编译代码的计算速度。Python 本身的**解释器**逐条执行操作，速度很慢；它之所以成为科学计算的标准语言，是因为繁重的数值运算都交给了用 C、C++ 和 Fortran 写成、经过几十年检验的库，Python 只负责组织和调度。本课程讲的就是这个生态系统：它由哪些层次组成，各层提供什么数据结构与算法，以及怎样正确、高效、可重复地使用它们。贯穿全课程的有三条线索：一是把计算表达为对整块数据的操作，即**向量化**；二是调用现成的库时，选对函数、遵守接口的约定、知道结果应有多高的精度；三是让计算环境和结果能在另一台机器上、一年之后被重现。

各章沿着这个生态系统自下而上展开。课程先搭建环境：说明科学 Python 生态系统的分层，以及包、**虚拟环境**与锁文件怎样让一个项目的依赖可以重现。NumPy 是整个生态的地基，它只提供一种数据结构，即 **N 维数组**，以及对整块数组的快速运算；理解数组在内存中的布局，几乎就能解释 NumPy 中所有出人意料的行为，通用函数、归约与**广播**则支撑起向量化的编程风格。在数组之上，NumPy 的线性代数与随机数模块是 BLAS、LAPACK 和现代伪随机数生成器的接口，SciPy 则提供优化、积分与微分方程、插值、统计、稀疏矩阵与信号处理等数值算法。真实的数据往往是带有行列标签、各列类型不同的表格，这由 pandas 的**数据框**处理；表格再由 Matplotlib、seaborn 与 Plotly 变成诚实、易读的图形。最后一章讨论向量化不够用的情形：先测量、做**性能分析**找出瓶颈，再用 Numba 的**即时编译**和多进程、多线程的并行执行加速。

本课程以[程序设计基础](/4.1)和[面向对象程序设计基础](/4.2)中的 Python 部分为前提，特别是模块与包、Python 变量的对象模型。它与[统计计算与软件](/3.5)互为表里：那里讲浮点运算、数值线性代数、优化与随机数生成的原理，这里讲怎样在 Python 中调用实现了这些原理的库；R 的向量与数据框也恰好对应 NumPy 的数组与 pandas 的数据框。微分方程的理论见[常微分方程](/2.4)，处理表格所用的统计方法见[线性回归分析](/3.3)与[多元统计分析](/3.4)，进程与线程作为操作系统的对象见[操作系统](/4.11)。这个生态系统也是[机器学习](/4.6)和[人工神经网络](/4.7)的工具基础：scikit-learn、PyTorch 等库都以 NumPy 数组或与之兼容的数组为数据交换的格式。

我其实并没有修过这样一门课，这一部分是根据我在日常实践中的积累写成的总结。在处理数据时，我们确实离不开 Python 生态系统中定义的这些包和数据结构。它们是为高效的计算服务的：NumPy 数组要求元素类型相同、在一整块内存中按固定步长存放，pandas 的列也按类型整列存储，因此不如[数据结构与算法](/4.3)中的链表、搜索树那样灵活，可以随意插入、删除和联接；它们更像我们在[统计计算与软件](/3.5)中接触过的 R 的向量和数据框。理解这些数据结构和建立在它们之上的库，也有助于理解 Python 为什么能够发展成为人工智能与机器学习领域的核心语言：语言本身易学易写，而计算的效率由底层的库来保证。

这门课作为生物科学专业学生的计算机限选课是很有道理的：读入测序与实验数据、清洗和整理表格、做统计分析和作图，几乎每天都要用到这些工具。我希望这门课能够稳定地开设下去。
