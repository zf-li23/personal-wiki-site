本章离开随机化实验，转向观察性研究：研究者不控制分配，也不知道分配机制。不对机制加以限制，关于因果效应就什么也说不了，所以我们处理最易处理的一类：[3.9.2](/3.9.2) 中的**正则分配机制**，它是个体化、概率性、无混杂的，但倾向评分未知。这样的机制表现得像**分层随机化实验**（[3.9.7](/3.9.7)），只是每层中接受处理的概率未知，且层由协变量定义。关键工具是**倾向评分**：它是协变量的函数中使协变量在处理组之间达到平衡的最粗者，针对正则分配机制的几乎所有方法都要用到它。本章陈述假设及其局限（8.1 节），证明倾向评分的平衡性质（8.2 节），概述各种估计策略（8.3 节），并说明如何估计倾向评分（8.4 节）。用估计出的评分设计研究是 [3.9.9](/3.9.9) 的内容，处理效应的估计量见 [3.9.10](/3.9.10)。当无混杂性因存在未观测的混杂变量而失效时，需要不同的工具：工具变量（[3.9.14](/3.9.14)）或 [3.9.12](/3.9.12) 的图准则。

本章始终采用**超总体**的观点：单元是一个随机样本，$(Y_i(0), Y_i(1), W_i, X_i)$ 独立同分布，不带下标的 $\mathbb{E}$ 对这一联合分布取期望，$X_i$ 是处理前协变量组成的 $1 \times K$ 行向量，倾向评分为 $e(x) = \mathbb{P}(W_i = 1 \mid X_i = x)$。

## 8.1. 观察性研究中的假设

### 8.1.1. 巴比妥类药物暴露数据

**例 8.1.1（产前暴露于巴比妥类药物）** Reinisch、Sanders、Mortensen 与 Rubin（1995）研究了产前暴露于巴比妥类药物（一类作用于中枢神经系统的镇静剂）对儿童认知发育的影响。处理单元是在子宫内大量暴露于巴比妥类药物的儿童，对照是未暴露的儿童；结果是成年后认知发育的各项度量。每个儿童记录了十七个协变量，描述母亲（如年龄与社会经济地位）、孕期经过和孩子本身（如性别）。在下面使用的样本中，暴露儿童 $N_{\mathrm{t}} = 742$ 名，未暴露儿童 $N_{\mathrm{c}} = 4462$ 名。

:::

没有人会把孕妇随机分配去服用镇静剂，所以这一效应只能通过观察来研究。处理是医生和母亲根据母亲的健康状况与处境选择的，而这些因素同样影响孩子的发育：暴露儿童与未暴露儿童在协变量上存在系统差异，简单比较结果会把药物的效应与这些差异混在一起。这些数据展示了整个设计阶段：在这里和 8.4 节中估计倾向评分，[3.9.9](/3.9.9) 则用它来评估并改善协变量的平衡。

### 8.1.2. 正则分配机制

回顾 [3.9.2](/3.9.2) 的分类。随机化实验是概率性的，其函数形式已知，并由研究者控制；经典随机化实验还是个体化的，并且是**无混杂分配**。**观察性研究**是函数形式未知的分配机制。它与实验的区别不在于有无随机性，而在于我们不了解机制。正则分配机制是经典随机化实验在观察性研究中的对应物，它满足：

1. 个体化：单元 $i$ 的分配概率只依赖于它自己的协变量与潜在结果；
2. 概率性：$0 < \mathbb{P}(W_i = 1 \mid X_i, Y_i(0), Y_i(1)) < 1$；
3. 无混杂：$\mathbb{P}(\boldsymbol{W} \mid \boldsymbol{X}, \boldsymbol{Y}(0), \boldsymbol{Y}(1)) = \mathbb{P}(\boldsymbol{W} \mid \boldsymbol{X})$。

在这三个条件下，分配机制是倾向评分之积（至多相差一个允许的分配集合与一个常数），

$$
\mathbb{P}\bigl(\boldsymbol{W} \mid \boldsymbol{X}, \boldsymbol{Y}(0), \boldsymbol{Y}(1)\bigr) = c \cdot \prod_{i=1}^{N} e(X_i)^{W_i}\bigl(1 - e(X_i)\bigr)^{1 - W_i}, \qquad 0 < e(x) < 1,
$$
而在超总体中，这些条件化为**强可忽略性**：$W_i \perp (Y_i(0), Y_i(1)) \mid X_i$ 且 $0 < e(x) < 1$。第一部分是一个**条件独立**的陈述：在协变量相同的单元中，接受了处理的与没有接受处理的单元具有相同的潜在结果分布。流行病学家把同一条件称为条件可交换性，因为处理单元与未处理单元可以互换而不改变潜在结果的分布；换句话说，它就是本课程所说的无混杂性。第二部分是**正值性**：每一类单元都可能接受任一种处理。

### 8.1.3. 无混杂性无法检验

**注 8.1.1（无混杂性不可检验）** 无混杂性限制的是给定 $X_i$ 时 $W_i$ 与 $(Y_i(0), Y_i(1))$ 的联合分布。每个单元都缺失两个潜在结果之一，所以这一限制涉及 $Y_i^{\mathrm{mis}}$，无论观察到多少单元，数据中都没有能揭示违背的信息。事实上，对观测数据 $(Y_i^{\mathrm{obs}}, W_i, X_i)$ 的任何分布，我们都能构造出一个 $(Y_i(0), Y_i(1), W_i, X_i)$ 的联合分布，它复现该观测分布并满足无混杂性：对所有单元，令给定 $X_i = x$ 时 $Y_i(1)$ 的分布取为给定 $W_i = 1$、$X_i = x$ 时 $Y_i^{\mathrm{obs}}$ 的观测分布，$Y_i(0)$ 同理。我们同样能构造出复现该观测分布而违背无混杂性的联合分布。因此，任何关于无混杂性不成立的论断都必须依赖额外信息：实质性的专业知识、第二个对照组，或已知不受处理影响的伪结果。

由此可见，协变量的选取是观察性研究中至关重要的科学决策。当协变量包含了所有驱动分配并与结果相关的因素时，无混杂性就更为可信；它只能论证，永远无法验证。

### 8.1.4. 为什么无混杂性被如此广泛地假定

这一假设被使用的次数远多于被明说的次数，因为它通常隐藏在函数形式之中。在线性模型

$$
Y_i^{\mathrm{obs}} = \alpha + \tau W_i + X_i\boldsymbol{\beta} + \varepsilon_i, \qquad \mathbb{E}[\varepsilon_i \mid W_i, X_i] = 0
$$
中，第二个条件，即回归变量的外生性，看上去是关于误差项的陈述，而不是关于潜在结果的陈述。但若模型要有因果含义，则潜在结果为 $Y_i(w) = \alpha + \tau w + X_i\boldsymbol{\beta} + \varepsilon_i$，对两个 $w$ 取相同的 $\varepsilon_i$（常数的个体效应 $\tau$），于是 $\varepsilon_i = Y_i(0) - \alpha - X_i\boldsymbol{\beta}$ 是 $Y_i(0)$ 与 $X_i$ 的函数。外生性说的是，给定 $X_i$ 时 $W_i$ 不含关于 $Y_i(0)$ 均值的信息，这就是无混杂性（的均值版本）。因此，对观察数据的回归分析假定了无混杂性，同时还假定线性与效应为常数；本章及接下来两章的方法保留第一个假设，放弃另外两个。

### 8.1.5. 正则分配机制与分层实验

正则分配机制与分层随机化实验具有相同的结构。两者都基于协变量取值相同（$X_i = x$）的单元所构成的层作推断，层内的分配是随机的，所以层水平的因果效应可识别，并可通过比较该层的处理单元与对照单元来估计。差别在于已知的内容：

| | 分层随机化实验 | 正则分配机制 |
|---|---|---|
| 层 | 由设计选定 | 由协变量取值定义 |
| 层内的分配 | 完全随机化 | 个体化、无混杂、概率性 |
| 层的倾向评分 $e(j)$ | 已知，为 $N_{\mathrm{t}}(j)/N(j)$ | 未知，用 $\hat e(j) = N_{\mathrm{t}}(j)/N(j)$ 估计 |
| 层数 | 较少，事先固定 | 协变量不同取值的个数 |

因此，正则分配机制可以当作每层倾向评分未知的分层随机化实验来分析。若 $X_i$ 只取很少几个值，这样做是直接可行的：用均值差估计各层内的效应，再以层比例为权对估计作平均。障碍在于样本量。含 $K$ 个二值协变量时有 $2^K$ 层，当 $K = 17$ 时超过 $10^5$，远多于例 8.1.1 的单元数；只有一个连续协变量时，层数与单元数一样多。于是大多数层中只含处理单元或只含对照单元，饱和分层不可行。本章其余部分说明倾向评分如何把问题的维数从 $K$ 降到一。

## 8.2. 平衡得分与倾向评分

### 8.2.1. 平衡得分

思路是不按 $X_i$ 本身分层，而按它的一个维数更低、却仍能使处理单元与对照单元可比的函数分层。

**定义 8.2.1（平衡得分）** **平衡得分**是协变量的函数 $b(x)$，满足

$$
W_i \perp X_i \mid b(X_i).
$$
用话说，在平衡得分取值相同的单元中，协变量在处理组与对照组中的分布相同。

协变量本身 $b(x) = x$ 是一个平凡的平衡得分，它的任何一一函数也是。问题在于平衡得分可以粗到什么程度。

**定理 8.2.1（倾向评分的平衡性质）** 倾向评分是平衡得分：$W_i \perp X_i \mid e(X_i)$。

**证明** 由于 $W_i$ 是二值的，只需证明 $\mathbb{P}(W_i = 1 \mid X_i, e(X_i))$ 不依赖于 $X_i$。因为 $e(X_i)$ 是 $X_i$ 的函数，同时以两者为条件与以 $X_i$ 为条件相同，所以由倾向评分的定义，$\mathbb{P}(W_i = 1 \mid X_i, e(X_i)) = \mathbb{P}(W_i = 1 \mid X_i) = e(X_i)$。另一方面，由全期望公式（[3.1.9](/3.1.9)），

$$
\mathbb{P}(W_i = 1 \mid e(X_i)) = \mathbb{E}[W_i \mid e(X_i)] = \mathbb{E}\bigl[\mathbb{E}[W_i \mid X_i, e(X_i)] \bigm| e(X_i)\bigr] = \mathbb{E}\bigl[e(X_i) \mid e(X_i)\bigr] = e(X_i).
$$
所以 $\mathbb{P}(W_i = 1 \mid X_i, e(X_i)) = \mathbb{P}(W_i = 1 \mid e(X_i))$，这就是条件独立 $W_i \perp X_i \mid e(X_i)$。$\square$

证明中没有用到任何关于潜在结果的内容：不论分配是否无混杂，平衡性质由倾向评分的定义即得。它只是 $W_i$ 与 $X_i$ 联合分布的性质，因此可以在数据中检查，[3.9.9](/3.9.9) 正是这样做的。

**定理 8.2.2（倾向评分是最粗的平衡得分）** 函数 $b(x)$ 是平衡得分，当且仅当倾向评分是它的函数，即对某个函数 $g$ 有 $e(x) = g(b(x))$。

**证明** 若 $e(x) = g(b(x))$，则由定理 8.2.1 的论证，$\mathbb{P}(W_i = 1 \mid b(X_i)) = \mathbb{E}[e(X_i) \mid b(X_i)] = g(b(X_i)) = e(X_i) = \mathbb{P}(W_i = 1 \mid X_i, b(X_i))$，所以 $b$ 是平衡得分。

反之，设 $b$ 是平衡得分但 $e$ 不是 $b$ 的函数。则存在协变量取值 $x$ 与 $x'$，使 $b(x) = b(x')$ 而 $e(x) \ne e(x')$。在 $b(X_i) = b(x)$ 的单元中，

$$
\mathbb{P}(W_i = 1 \mid X_i = x) = e(x) \ne e(x') = \mathbb{P}(W_i = 1 \mid X_i = x'),
$$
所以给定 $b(X_i) = b(x)$ 时，接受处理的概率依赖于 $X_i$，$W_i$ 与 $X_i$ 在给定 $b(X_i)$ 时并不独立。这与 $b$ 是平衡得分的假设矛盾。$\square$

因此，每个平衡得分所含的信息至少有 $e(x)$ 那么多，而 $e(x)$ 本身是最粗的一个，无论协变量有多少，它都是标量。这就是 8.1.5 节所承诺的降维。

### 8.2.2. 给定平衡得分下的无混杂性

协变量的平衡之所以有用，只是因为它能传递到潜在结果上。

**定理 8.2.3（给定平衡得分下的无混杂性）** 设分配是无混杂的，$W_i \perp (Y_i(0), Y_i(1)) \mid X_i$。则给定任何平衡得分，分配也是无混杂的：

$$
W_i \perp \bigl(Y_i(0), Y_i(1)\bigr) \mid b(X_i).
$$
特别地，$W_i \perp (Y_i(0), Y_i(1)) \mid e(X_i)$。

**证明** 我们证明 $\mathbb{P}(W_i = 1 \mid Y_i(0), Y_i(1), b(X_i))$ 不依赖于潜在结果。由全期望公式，再对 $X_i$ 取条件，

$$
\begin{aligned}
\mathbb{P}\bigl(W_i = 1 \mid Y_i(0), Y_i(1), b(X_i)\bigr) &= \mathbb{E}\Bigl[\mathbb{E}\bigl[W_i \mid Y_i(0), Y_i(1), X_i\bigr] \Bigm| Y_i(0), Y_i(1), b(X_i)\Bigr] \\
&= \mathbb{E}\Bigl[\mathbb{E}[W_i \mid X_i] \Bigm| Y_i(0), Y_i(1), b(X_i)\Bigr] \\
&= \mathbb{E}\Bigl[\mathbb{E}[W_i \mid b(X_i)] \Bigm| Y_i(0), Y_i(1), b(X_i)\Bigr] = \mathbb{E}[W_i \mid b(X_i)].
\end{aligned}
$$
第一步用到 $b(X_i)$ 是 $X_i$ 的函数；第二步用到无混杂性；第三步用到平衡性质，由它 $\mathbb{E}[W_i \mid X_i] = \mathbb{E}[W_i \mid X_i, b(X_i)] = \mathbb{E}[W_i \mid b(X_i)]$；最后一步用到 $\mathbb{E}[W_i \mid b(X_i)]$ 是 $b(X_i)$ 的函数。结果为 $\mathbb{P}(W_i = 1 \mid b(X_i))$，与潜在结果无关。$\square$

**推论 8.2.1（通过倾向评分识别）** 在强可忽略性下，

$$
\tau_{\mathrm{sp}} = \mathbb{E}\Bigl[\mathbb{E}\bigl[Y_i^{\mathrm{obs}} \mid W_i = 1, e(X_i)\bigr] - \mathbb{E}\bigl[Y_i^{\mathrm{obs}} \mid W_i = 0, e(X_i)\bigr]\Bigr].
$$

**证明** 由定理 8.2.3，$\mathbb{E}[Y_i^{\mathrm{obs}} \mid W_i = 1, e(X_i)] = \mathbb{E}[Y_i(1) \mid W_i = 1, e(X_i)] = \mathbb{E}[Y_i(1) \mid e(X_i)]$，且正值性保证两个条件期望都有定义。$W_i = 0$ 的情形同理，对 $e(X_i)$ 的分布平均 $\mathbb{E}[Y_i(1) - Y_i(0) \mid e(X_i)]$ 即得 $\tau_{\mathrm{sp}}$。$\square$

推论是按倾向评分分层与匹配的理论基础：倾向评分相同的单元实际上构成一个完全随机化实验，无论其协变量如何。比较具有相近 $e(X_i)$ 的处理单元与对照单元，就消除了由已观测协变量引起的全部偏差，而无需对结果如何依赖于协变量建模。它并不消除由未观测协变量引起的偏差：定理 8.2.3 是继承了无混杂性，而不是创造了无混杂性。

### 8.2.3. 倾向评分与协变量平衡

定理 8.2.1 说明，平衡在给定倾向评分的条件下成立。下一个定理把两组之间的边际差异与倾向评分的变异联系起来；[3.9.9](/3.9.9) 把倾向评分用作不平衡的概括度量，其依据就在于此。设 $f_{\mathrm{t}}(x)$ 与 $f_{\mathrm{c}}(x)$ 分别是处理子总体与对照子总体中 $X_i$ 的密度（或概率函数），$p = \mathbb{P}(W_i = 1) = \mathbb{E}[e(X_i)]$。

**定理 8.2.4（倾向评分与协变量平衡）** 设分配机制是无混杂的、个体化的，且 $0 < p < 1$。则

$$
\mathbb{E}[e(X_i) \mid W_i = 1] - \mathbb{E}[e(X_i) \mid W_i = 0] = \frac{\operatorname{Var}(e(X_i))}{p(1 - p)},
$$
且

$$
\operatorname{Var}(e(X_i)) = \mathbb{E}\left[\left(\frac{f_{\mathrm{t}}(X_i) - f_{\mathrm{c}}(X_i)}{f_{\mathrm{t}}(X_i)\,p + f_{\mathrm{c}}(X_i)(1 - p)}\right)^2\right] p^2(1 - p)^2.
$$

**证明** 对第一个等式，$\mathbb{E}[e(X_i)W_i] = \mathbb{E}[e(X_i)\,\mathbb{E}[W_i \mid X_i]] = \mathbb{E}[e(X_i)^2] = \operatorname{Var}(e(X_i)) + p^2$，所以

$$
\mathbb{E}[e(X_i) \mid W_i = 1] = \frac{\mathbb{E}[e(X_i)W_i]}{p} = \frac{\operatorname{Var}(e(X_i))}{p} + p.
$$
由于 $p = \mathbb{E}[e(X_i)] = p\,\mathbb{E}[e(X_i) \mid W_i = 1] + (1 - p)\,\mathbb{E}[e(X_i) \mid W_i = 0]$，

$$
\mathbb{E}[e(X_i) \mid W_i = 0] = \frac{p - p\,\mathbb{E}[e(X_i) \mid W_i = 1]}{1 - p} = p - \frac{\operatorname{Var}(e(X_i))}{1 - p},
$$
差为 $\operatorname{Var}(e(X_i))\bigl(\frac{1}{p} + \frac{1}{1 - p}\bigr) = \frac{\operatorname{Var}(e(X_i))}{p(1 - p)}$。

对第二个等式，由 Bayes 定理

$$
e(x) = \mathbb{P}(W_i = 1 \mid X_i = x) = \frac{f_{\mathrm{t}}(x)\,p}{f_{\mathrm{t}}(x)\,p + f_{\mathrm{c}}(x)(1 - p)}, \qquad e(x) - p = \frac{f_{\mathrm{t}}(x) - f_{\mathrm{c}}(x)}{f_{\mathrm{t}}(x)\,p + f_{\mathrm{c}}(x)(1 - p)}\,p(1 - p),
$$
而 $\operatorname{Var}(e(X_i)) = \mathbb{E}[(e(X_i) - p)^2]$。$\square$

该定理联系起三个陈述。两组之间平均倾向评分之差为零，当且仅当 $\operatorname{Var}(e(X_i)) = 0$，即倾向评分为常数；由第二个等式，这当且仅当对（几乎）所有 $x$ 有 $f_{\mathrm{t}}(x) = f_{\mathrm{c}}(x)$，也就是整个协变量分布完全平衡。于是，对单个数（倾向评分）的均值之差，能检测出两个多元协变量分布之间的任何差异，而差异很小则表明两个分布接近。实际中我们使用线性化倾向评分 $\ell(x) = \log\frac{e(x)}{1 - e(x)}$，它是一个单调变换，更接近正态分布；[3.9.9](/3.9.9) 用它在两组之间的标准化均差来度量平衡。

## 8.3. 估计策略概览

在强可忽略性下，平均效应是可识别的（推论 8.2.1），但估计它的方法很多。它们分为六组，区别在于对什么建模：结果、分配，或两者都不建模。

| 策略 | 建模对象 | 主要思想 | 弱点 |
|---|---|---|---|
| 1. 基于模型的插补 | $\mathbb{P}(Y \mid W, X)$ | 由模型预测缺失的潜在结果 | 协变量很多时对模型敏感 |
| 2. 回归估计量 | $\mathbb{E}[Y \mid W, X]$ | 用线性回归调整 | 两组不同时会外推 |
| 3. 加权 | $\mathbb{P}(W \mid X)$ | 按倾向评分的倒数加权 | $\hat e$ 接近 0 或 1 时不稳定 |
| 4. 分块（子类化） | $\mathbb{P}(W \mid X)$ | 把 $\hat e$ 相近的层当作 CRE 分析 | 块内残余偏差 |
| 5. 匹配 | $X$ 上的距离 | 把每个单元与另一组中相近的单元比较 | 不精确匹配带来的偏差 |
| 6. 混合方法 | 两者 | 把 3–5 与回归调整结合 | 需要做更多选择 |

### 8.3.1. 基于模型的插补

与 [3.9.6](/3.9.6) 一样，我们为缺失的潜在结果建立模型，并用它进行插补。工作模型是单元水平的联合模型 $f(Y_i(0), Y_i(1) \mid X_i, \theta)$，并对 $\theta$ 取先验；其依据是 **de Finetti 定理**（[3.7.6](/3.7.6)）意义下各单元的[可交换性](/3.7.6#def-6.3.1)，而无混杂性使得分配机制可以从似然中略去，与随机化实验中完全一样。没有协变量或协变量很少时，容易为结果的条件分布设定一个灵活的模型。协变量很多时，设定是困难的；而当两组的协变量分布不同时，对一组的插补要依赖于远离另一组数据处的模型，所以结果可能对数据无法决定的选择很敏感。在完全随机化实验中，这种敏感性很小，因为按设计两个协变量分布是相似的。因此，**基于模型的插补**不推荐作为一般观察性研究的主要方法。

### 8.3.2. 回归估计量

设潜在结果服从各自的线性模型，对 $w = 0, 1$ 有 $\mathbb{E}[Y_i(w) \mid X_i] = X_i\boldsymbol{\beta}_w$，这里 $X_i$ 含常数项。在各组内用最小二乘估计两个系数向量，

$$
\hat{\boldsymbol{\beta}}_{\mathrm{c}} = \arg\min_{\boldsymbol{\beta}} \sum_{i:W_i = 0}(Y_i^{\mathrm{obs}} - X_i\boldsymbol{\beta})^2, \qquad \hat{\boldsymbol{\beta}}_{\mathrm{t}} = \arg\min_{\boldsymbol{\beta}} \sum_{i:W_i = 1}(Y_i^{\mathrm{obs}} - X_i\boldsymbol{\beta})^2,
$$
并以预测值插补每个缺失的结果：

$$
\hat\tau^{\mathrm{ols}} = \frac{1}{N}\sum_{i=1}^{N}\Bigl(W_i\bigl(Y_i^{\mathrm{obs}} - X_i\hat{\boldsymbol{\beta}}_{\mathrm{c}}\bigr) + (1 - W_i)\bigl(X_i\hat{\boldsymbol{\beta}}_{\mathrm{t}} - Y_i^{\mathrm{obs}}\bigr)\Bigr) = \frac{N_{\mathrm{t}}}{N}\hat\tau_{\mathrm{t}}^{\mathrm{ols}} + \frac{N_{\mathrm{c}}}{N}\hat\tau_{\mathrm{c}}^{\mathrm{ols}}.
$$
由于含截距的最小二乘拟合经过均值点，$\bar X_{\mathrm{t}}\hat{\boldsymbol{\beta}}_{\mathrm{t}} = \bar Y_{\mathrm{t}}^{\mathrm{obs}}$，$\bar X_{\mathrm{c}}\hat{\boldsymbol{\beta}}_{\mathrm{c}} = \bar Y_{\mathrm{c}}^{\mathrm{obs}}$，所以两个分量为

$$
\hat\tau_{\mathrm{t}}^{\mathrm{ols}} = \bar Y_{\mathrm{t}}^{\mathrm{obs}} - \bar X_{\mathrm{t}}\hat{\boldsymbol{\beta}}_{\mathrm{c}} = \bar Y_{\mathrm{t}}^{\mathrm{obs}} - \bar Y_{\mathrm{c}}^{\mathrm{obs}} - (\bar X_{\mathrm{t}} - \bar X_{\mathrm{c}})\hat{\boldsymbol{\beta}}_{\mathrm{c}}, \qquad \hat\tau_{\mathrm{c}}^{\mathrm{ols}} = \bar Y_{\mathrm{t}}^{\mathrm{obs}} - \bar Y_{\mathrm{c}}^{\mathrm{obs}} - (\bar X_{\mathrm{t}} - \bar X_{\mathrm{c}})\hat{\boldsymbol{\beta}}_{\mathrm{t}}.
$$

回归用项 $(\bar X_{\mathrm{t}} - \bar X_{\mathrm{c}})\hat{\boldsymbol{\beta}}$ 来调整均值差。在完全随机化或配对随机化实验中，$\bar X_{\mathrm{t}} - \bar X_{\mathrm{c}}$ 接近零，调整量很小，其确切形式无关紧要（[3.9.5](/3.9.5)）。在观察性研究中，协变量均值之差可以很大；此时调整是在协变量取值处很少有对照单元的地方，为处理单元预测对照结果，答案依赖于线性外推而不是数据。两个对观测数据拟合得同样好的设定，可以给出差别很大的估计。因此，不经重大修改就不推荐使用回归；在设计阶段消除了大部分不平衡之后，它才变得有价值，作为在块内或匹配对内的局部调整（[3.9.10](/3.9.10)）。

### 8.3.3. 加权估计量

加权是对分配而不是对结果建模。关键的恒等式是

$$
\mathbb{E}\left[\frac{W_iY_i^{\mathrm{obs}}}{e(X_i)}\right] = \mathbb{E}\left[\frac{\mathbb{E}[W_iY_i(1) \mid X_i]}{e(X_i)}\right] = \mathbb{E}\left[\frac{\mathbb{E}[W_i \mid X_i]\,\mathbb{E}[Y_i(1) \mid X_i]}{e(X_i)}\right] = \mathbb{E}\bigl[\mathbb{E}[Y_i(1) \mid X_i]\bigr] = \mathbb{E}[Y_i(1)],
$$
其中第一步用到 $W_iY_i^{\mathrm{obs}} = W_iY_i(1)$，第二步用到无混杂性，第三步用到 $\mathbb{E}[W_i \mid X_i] = e(X_i) > 0$。同理 $\mathbb{E}[(1 - W_i)Y_i^{\mathrm{obs}}/(1 - e(X_i))] = \mathbb{E}[Y_i(0)]$。倾向评分很小的处理单元代表许多与它相似却没有接受处理的单元，因而被赋予较大的权重。

**定义 8.3.1（Horvitz–Thompson 估计量）** 倾向评分已知时，平均处理效应的 **Horvitz–Thompson 估计量**为

$$
\hat\tau^{\mathrm{ht}} = \frac{1}{N}\sum_{i=1}^{N}\frac{W_iY_i^{\mathrm{obs}}}{e(X_i)} - \frac{1}{N}\sum_{i=1}^{N}\frac{(1 - W_i)Y_i^{\mathrm{obs}}}{1 - e(X_i)} = \frac{1}{N}\sum_{i:W_i = 1}\lambda_iY_i^{\mathrm{obs}} - \frac{1}{N}\sum_{i:W_i = 0}\lambda_iY_i^{\mathrm{obs}},
$$
其权重为 $\lambda_i = 1/\bigl(e(X_i)^{W_i}(1 - e(X_i))^{1 - W_i}\bigr)$，即处理单元的权为 $1/e(X_i)$，对照单元的权为 $1/(1 - e(X_i))$。用每个单元所接受的处理的概率之倒数给它加权来估计因果效应，称为**逆概率加权**（IPW）。

这一名称来自抽样调查，Horvitz 与 Thompson（1952）用入样概率的倒数给被抽中的单元加权。由上面的恒等式，只要权重是协变量的已知函数，$\hat\tau^{\mathrm{ht}}$ 就是 $\tau_{\mathrm{sp}}$ 的**无偏估计**。在观察性研究中，$e(x)$ 必须用估计 $\hat e(x)$ 代替，权重通常归一化为在每一组内平均为一，

$$
\hat\lambda_i = \begin{cases} N_{\mathrm{t}}\,\hat e(X_i)^{-1} \Big/ \sum_{j:W_j = 1}\hat e(X_j)^{-1}, & W_i = 1, \\ N_{\mathrm{c}}\,(1 - \hat e(X_i))^{-1} \Big/ \sum_{j:W_j = 0}(1 - \hat e(X_j))^{-1}, & W_i = 0, \end{cases}
$$
并用 $\frac{1}{N_{\mathrm{t}}}\sum_{W_i = 1}\hat\lambda_iY_i^{\mathrm{obs}} - \frac{1}{N_{\mathrm{c}}}\sum_{W_i = 0}\hat\lambda_iY_i^{\mathrm{obs}}$ 计算 $\hat\tau$；归一化使估计量对全部结果同加一个常数保持不变。加权的弱点是它依赖于边界附近的估计倾向评分：当处理单元的 $\hat e(X_i)$ 接近零，或对照单元的 $\hat e(X_i)$ 接近一时，单个单元会得到巨大的权重，倾向评分模型设定的微小改变就会使估计发生显著变化。

### 8.3.4. 按倾向评分分块

分块（子类化）按估计的倾向评分把样本划分为 $J$ 块，边界为 $0 = b_0 < b_1 < \dots < b_J = 1$，块指示变量为

$$
B_i(j) = \boldsymbol{1}\{b_{j-1} \le \hat e(X_i) < b_j\}, \qquad j = 1, \dots, J.
$$
块内的单元具有相近的倾向评分，所以由推论 8.2.1，一个块的数据近似地像来自完全随机化实验的数据，块水平的效应可用均值差估计，并像在分层随机化实验中那样加以合并。分块比加权更能容忍估计倾向评分极端的单元，因为评分只决定块的归属，而不决定权重的大小。块内仍残留一些不平衡，分块在与块内回归调整结合之后才成为推荐的方法（[3.9.10](/3.9.10)）。

### 8.3.5. 匹配

匹配为每个单元找出另一处理组中协变量相近的一个或多个单元，并直接比较它们的结果。若存在精确匹配，这是所有策略中最透明的：每一次比较都在所有已观测方面都相同的单元之间进行。协变量较多时精确匹配很少见，必须决定偏离精确匹配多少是可以接受的，这就需要在协变量空间上定义距离。

**例 8.3.1（选择匹配对象）** 在对一个职业培训项目的评估中，目标单元是一位接受了培训的女性，有两个潜在的对照可用，均非精确匹配：

| | 年龄 | 6 岁以下子女数 | 教育程度 | 过去 12 个月的工作月数 | 培训 |
|---|---|---|---|---|---|
| 目标单元 | 30 | 2 | 高中 | 4 | 是 |
| 精确匹配（假想） | 30 | 2 | 高中 | 4 | 否 |
| 匹配 I | 34 | 2 | 高中 | 6 | 否 |
| 匹配 II | 28 | 1 | 高中 | 2 | 否 |

匹配 I 在年龄上相差四岁、工作经历相差两个月，匹配 II 则相差两岁、一个孩子和两个月。哪个更好，取决于每个协变量与结果（收入）及与培训决策的关联强度，而像**马氏距离**（[3.4.1](/3.4.1)）或估计倾向评分之差这样的距离，使这种权衡变得明确。[3.9.9](/3.9.9) 定义这些距离与匹配算法。

### 8.3.6. 混合方法；设计与分析

混合方法把加权、分块或匹配与回归结合起来：第一步消除大部分不平衡，再在块内或匹配对内作回归，以不作远距离外推的方式消除残余偏差。这些就是实践中推荐的方法。

有两个区分把这六种策略组织起来。第一个是对什么建模。插补与回归对结果 $\mathbb{P}(Y \mid \cdot)$ 建模；加权、分块与匹配对分配 $\mathbb{P}(W \mid \cdot)$ 建模，或只使用协变量，其目的是使协变量平衡。第二个是何时使用结果。估计倾向评分、分块、匹配与评估平衡都只用 $(W_i, X_i)$；它们可以也应当在看到结果之前完成，正如实验要在实施之前设计好一样。设计与分析的这种分离，可以防止（无论有意还是无意地）选择能给出所期望答案的设定。设计阶段是 [3.9.9](/3.9.9) 的主题，分析阶段是 [3.9.10](/3.9.10) 的主题。几乎所有这些程序都涉及倾向评分，所以对它的估计，即本章的最后一节，是每一项分析的第一步。

## 8.4. 倾向评分的估计

### 8.4.1. 已知与未知的倾向评分

在随机化实验中倾向评分是已知的：完全随机化实验中对所有 $x$ 有 $e(x) = N_{\mathrm{t}}/N$，分层随机化实验中对第 $j$ 层的 $x$ 有 $e(x) = N_{\mathrm{t}}(j)/N(j)$，配对随机化实验中 $e(x) = 1/2$。在其他情形下它很少是已知的。典型的情形是：给定可用的处理前变量，研究者认为无混杂性是对实际分配机制的合理近似，但对倾向评分如何依赖于协变量只有模糊的先验信息。例如在医学中，治疗决策基于医生观察到并记入病历的、与临床相关的患者特征，但并没有明确的规则要求对这些特征的特定取值采用特定的治疗。

若 $X_i$ 只取很少几个值，估计是直接的：把样本划分为协变量同质的子样本，在每个子样本中用处理单元的比例估计倾向评分。若 $X_i$ 取很多值，大多数单元格只含一个单元，这种饱和估计毫无用处，必须作某种形式的平滑，无论是参数模型还是灵活的非参数模型。

### 8.4.2. 需要多高的精度

$\hat e(x)$ 的精度有多重要，取决于使用它的方法。按估计倾向评分的倒数加权，依赖于对真实评分的精确逼近：它原则上能消除协变量分布差异造成的全部偏差，但接近零或一处估计评分的微小误差会使权重的方差膨胀。按估计倾向评分分块、再在块内作回归调整，则不那么敏感：评分只用来把真实倾向评分相近的单元分到一组，其余的差异由回归消除。

更重要的是，目标并不是在均方误差或任何其他衡量 $\hat e$ 与 $e$ 之间距离的指标意义下把倾向评分估计得尽可能好。目标是得到一个在样本中使协变量平衡的评分：在估计倾向评分取值相近的子样本内，处理单元与对照单元的协变量分布应当相似。为此目的，估计的评分往往比真实评分更可取。

**例 8.4.1（估计评分比真实评分平衡得更好）** 在只有一个二值协变量（比如性别）的完全随机化实验中，真实倾向评分对两个取值都是 $e(x) = N_{\mathrm{t}}/N$，按它分层会把所有单元放在同一层。由于偶然性，处理组与对照组中女性的比例会略有不同，所以这一层在样本中并不平衡。估计的倾向评分 $\hat e(x) = N_{\mathrm{t}}(x)/N(x)$ 取两个值，每种性别一个，按它分层得到两层，即女性与男性，每一层在该协变量上都完全平衡。

:::

关于估计的精神，还有三点说明。第一，任何时候都不使用结果数据，所以倾向评分的设定不会（无论有意还是无意）被调整得对处理效应给出某个特定估计。第二，很难给出完全自动的程序：若了解哪些协变量驱动治疗决策、哪些与结果相关，设定可以大为改进。第三，倾向评分模型是用于平衡的工具，而不是行为模型：我们对其系数的结构性或因果解释不感兴趣，只要平衡得到改善，共线性或无法解释的项都无妨。

### 8.4.3. 倾向评分的 logistic 回归

标准的模型是 $W_i$ 对协变量的函数的 **logistic 回归**（[3.4.12](/3.4.12)），

$$
\mathbb{P}(W_i = 1 \mid X_i = x; \boldsymbol{\phi}) = \frac{\exp(h(x)\boldsymbol{\phi})}{1 + \exp(h(x)\boldsymbol{\phi})},
$$
其中 $h(x)$ 是 $x$ 的函数组成的行向量，含常数项、线性项以及选定的二次项与交互项；最简单的选择是 $h(x) = (1, x)$。似然函数为

$$
\mathcal{L}(\boldsymbol{\phi} \mid \boldsymbol{W}, \boldsymbol{X}) = \prod_{i=1}^{N}e(X_i; \boldsymbol{\phi})^{W_i}\bigl(1 - e(X_i; \boldsymbol{\phi})\bigr)^{1 - W_i} = \prod_{i=1}^{N}\frac{\exp(W_i\,h(X_i)\boldsymbol{\phi})}{1 + \exp(h(X_i)\boldsymbol{\phi})},
$$
对数似然为

$$
L(\boldsymbol{\phi}) = \sum_{i=1}^{N}\Bigl(W_i\,h(X_i)\boldsymbol{\phi} - \log\bigl(1 + \exp(h(X_i)\boldsymbol{\phi})\bigr)\Bigr).
$$
其梯度与 Hessian 矩阵为

$$
\frac{\partial L}{\partial\boldsymbol{\phi}} = \sum_{i=1}^{N}h(X_i)^{\mathsf T}\bigl(W_i - e(X_i; \boldsymbol{\phi})\bigr), \qquad \frac{\partial^2 L}{\partial\boldsymbol{\phi}\,\partial\boldsymbol{\phi}^{\mathsf T}} = -\sum_{i=1}^{N}e(X_i; \boldsymbol{\phi})\bigl(1 - e(X_i; \boldsymbol{\phi})\bigr)h(X_i)^{\mathsf T}h(X_i).
$$
对每个 $\boldsymbol{\phi}$，Hessian 矩阵都是半负定的，所以 $L$ 是凹函数，当 $\sum_i h(X_i)^{\mathsf T}h(X_i)$ 正定时它是严格凹的。此时极大似然估计 $\hat{\boldsymbol{\phi}}$ 若存在则唯一，可用**牛顿法**（[3.5.4](/3.5.4)）求得。

**算法 8.4.1（求倾向评分的 Newton–Raphson 法）** 从 $\boldsymbol{\phi}^{(0)} = (\log(N_{\mathrm{t}}/N_{\mathrm{c}}), 0, \dots, 0)^{\mathsf T}$ 出发，即只含常数项且拟合得恰好吻合的模型。迭代

$$
\boldsymbol{\phi}^{(k+1)} = \boldsymbol{\phi}^{(k)} - \left(\frac{\partial^2 L}{\partial\boldsymbol{\phi}\,\partial\boldsymbol{\phi}^{\mathsf T}}(\boldsymbol{\phi}^{(k)})\right)^{-1}\frac{\partial L}{\partial\boldsymbol{\phi}}(\boldsymbol{\phi}^{(k)})
$$
直至变化可以忽略。$\hat{\boldsymbol{\phi}}$ 的估计协方差矩阵是 $\hat{\boldsymbol{\phi}}$ 处负 Hessian 矩阵的逆。

:::

当 $h(x)$ 中各项的某个线性组合能把处理单元与对照单元完全分开时，估计不存在（某些系数发散）。这不仅是数值上的麻烦：它意味着协变量空间的某个区域只含一组的单元，因而正值性在样本中不成立。例 8.4.2 给出了这样一个情形。

### 8.4.4. 协变量与交互项的选择

协变量很多时，含全部线性项、二次项与交互项的模型所含参数多于数据所能支持的，而只含线性项的模型可能平衡得很差。基于**似然比检验**（[3.2.5](/3.2.5)）的逐步程序来选择设定。

**算法 8.4.2（倾向评分的三步设定）** 设 $K$ 为协变量个数。

1. 凭先验理由选取 $K_{\mathrm{B}}$ 个基本协变量：被认为对解释分配很重要的协变量，或被认为可能或强烈地与结果相关的协变量。无论数据怎么说，它们总是被纳入。
2. 加入线性项。在尚未纳入的 $K - K_{\mathrm{B}}$ 个协变量中，依次把每一个作为附加的线性项拟合，计算含它的模型相对于不含它的模型的似然比统计量。若最大的统计量超过阈值 $C_{\mathrm{L}}$，就加入该协变量并重复；否则停止。令 $K_{\mathrm{L}}$ 为最终的线性项个数。
3. 加入二阶项。在所选 $K_{\mathrm{L}}$ 个协变量的 $K_{\mathrm{L}}(K_{\mathrm{L}} + 1)/2$ 个平方项与两两交互项中，以同样的前向方式逐个加入，阈值为 $C_{\mathrm{Q}}$，直到剩余各项的似然比统计量都不超过它。

:::

阈值是调节常数。常见的选择如 $C_{\mathrm{L}} = 1$ 与 $C_{\mathrm{Q}} = 2.71$（$\chi^2_1$ 的上 $0.10$ 分位数）；线性项的阈值取得低，反映了遗漏相关协变量比纳入无关协变量更糟的看法。该程序是前向选择，一种贪心搜索：目的不是找到真实模型，而只是找到一个适当的设定，其适当与否由它所达到的平衡来判断（[3.9.9](/3.9.9)）。若平衡不能令人满意，就修改设定，例如为仍不平衡的协变量添加项，仍然不看结果。

**例 8.4.2（巴比妥类药物数据的倾向评分）** 对例 8.1.1 的数据，按实质性理由选取三个基本协变量：孩子的性别、母亲的年龄（取对数）与母亲的社会经济地位。性别与母亲的年龄很可能与结果相关，母亲的年龄与社会经济地位则与巴比妥类药物暴露相关。在第 2 步中，取 $C_{\mathrm{L}} = 1$，首先加入的协变量（数据中记为 `lpbc420`）的似然比统计量为 $1308$：单个协变量就主导了分配。第二个的统计量为 $66.1$，其后统计量迅速下降；该程序共加入十个协变量，最后一个的统计量为 $1.3$，另有四个未被纳入，所以最终模型含 13 个线性项。第 3 步加入 17 个二次项与交互项。两个指示变量之间的一个交互项的估计系数为 $-\infty$：它们所定义的四个单元格之一不含暴露儿童，所以其估计倾向评分为零，这些单元根本没有可比的处理单元。它们将在 [3.9.9](/3.9.9) 中通过修剪去除。

## 小结

- **正则分配机制**（个体化、概率性、无混杂，$e(x)$ 未知）：是观察性研究中与分层随机化实验对应的情形，层未知且由协变量定义。在超总体中它就是强可忽略性，$W_i \perp (Y_i(0), Y_i(1)) \mid X_i$ 且 $0 < e(x) < 1$。
- 无混杂性涉及缺失的潜在结果，无法检验（注 8.1.1）；它隐藏在每个因果回归的外生性假设中。协变量很多或连续时，对 $X_i$ 的饱和分层不可行。
- 平衡得分与倾向评分：

  | 结果 | 陈述 | 需要无混杂性？ |
  |---|---|---|
  | 定理 8.2.1 | $W_i \perp X_i \mid e(X_i)$ | 否 |
  | 定理 8.2.2 | $b$ 是平衡得分当且仅当 $e = g(b)$；$e$ 最粗 | 否 |
  | 定理 8.2.3 | $W_i \perp (Y_i(0), Y_i(1)) \mid b(X_i)$ | 是 |
  | 推论 8.2.1 | $\tau_{\mathrm{sp}} = \mathbb{E}[\mathbb{E}[Y^{\mathrm{obs}} \mid W = 1, e] - \mathbb{E}[Y^{\mathrm{obs}} \mid W = 0, e]]$ | 是，且需正值性 |
  | 定理 8.2.4 | $\mathbb{E}[e \mid W = 1] - \mathbb{E}[e \mid W = 0] = \operatorname{Var}(e)/(p(1 - p))$，为零当且仅当 $f_{\mathrm{t}} = f_{\mathrm{c}}$ | — |

- 六种策略（8.3 节）：插补与回归对结果建模，两组不同时会外推；Horvitz–Thompson（IPW）估计量按 $1/e$ 与 $1/(1 - e)$ 加权，评分真实时无偏，但在 0 和 1 附近不稳定；分块与匹配使协变量平衡；混合方法在块内或对内再加回归。设计（只用 $W$ 与 $X$）先于分析。
- 估计 $e(x)$：目的在平衡而非精度（例 8.4.1）；用 logistic 回归，对数似然为凹函数，用 Newton–Raphson 法拟合（算法 8.4.1）；先取基本协变量，再按似然比统计量前向选择线性项（$C_{\mathrm{L}}$）与二阶项（$C_{\mathrm{Q}}$）（算法 8.4.2）；从不使用结果。

## 思考题

1. 证明：没有无混杂性时，恒等式 $\mathbb{E}[W_iY_i^{\mathrm{obs}}/e(X_i)] = \mathbb{E}[Y_i(1)]$ 可能失效。构造一个没有协变量、而处理单元的 $Y_i(1)$ 系统地偏大的例子。

   **答** 没有协变量时 $e = p$ 为常数，$\mathbb{E}[W_iY_i(1)]/p = \mathbb{E}[Y_i(1) \mid W_i = 1]$。令 $Y_i(1) \in \{0, 1\}$，$\mathbb{P}(Y_i(1) = 1) = 1/2$，并令 $Y_i(1) = 1$ 的单元以概率 $0.8$ 接受处理，其余单元以概率 $0.2$ 接受处理。则 $p = 0.5$，$\mathbb{E}[Y_i(1) \mid W_i = 1] = 0.4/0.5 = 0.8 \ne 0.5 = \mathbb{E}[Y_i(1)]$。步骤 $\mathbb{E}[W_iY_i(1) \mid X_i] = \mathbb{E}[W_i \mid X_i]\,\mathbb{E}[Y_i(1) \mid X_i]$ 要求 $W_i \perp Y_i(1) \mid X_i$。
2. 不用定理 8.2.2，直接证明 $b(x) = (e(x), x_1)$（倾向评分连同第一个协变量）是平衡得分。$b(x) = x_1$ 一般是平衡得分吗？

   **答** $\mathbb{P}(W_i = 1 \mid b(X_i)) = \mathbb{E}[e(X_i) \mid e(X_i), X_{i1}] = e(X_i)$，它等于 $\mathbb{P}(W_i = 1 \mid X_i)$，所以 $W_i \perp X_i \mid b(X_i)$。一般地，仅 $x_1$ 不是：由定理 8.2.2，只有当 $e(x)$ 仅通过 $x_1$ 依赖于 $x$ 时它才是平衡得分。
3. 某研究有一个协变量 $X_i \in \{0, 1, 2\}$，$\mathbb{P}(X_i = x) = 1/3$，$e(x) = 0.2, 0.5, 0.8$。计算 $p$、$\operatorname{Var}(e(X_i))$、$\mathbb{E}[e(X_i) \mid W_i = 1]$ 与 $\mathbb{E}[e(X_i) \mid W_i = 0]$，并验证定理 8.2.4 的第一个等式。

   **答** $p = 0.5$；$\operatorname{Var}(e) = \frac{1}{3}(0.09 + 0 + 0.09) = 0.06$。$\mathbb{E}[e \mid W = 1] = \mathbb{E}[\mathrm{e}^2]/p = \frac{1}{3}(0.04 + 0.25 + 0.64)/0.5 = 0.62$，$\mathbb{E}[e \mid W = 0] = \mathbb{E}[e(1 - e)]/(1 - p) = \frac{1}{3}(0.16 + 0.25 + 0.16)/0.5 = 0.38$。差 $0.24$ 等于 $0.06/(0.5 \times 0.5) = 0.24$。
4. 证明：以真实倾向评分计算的 Horvitz–Thompson 估计量对全部结果同加常数 $c$ 不具有不变性，而归一化的版本具有。这在有限样本中为什么重要？

   **答** 加上 $c$ 使 $\hat\tau^{\mathrm{ht}}$ 改变 $c\bigl(\frac{1}{N}\sum_i W_i/e(X_i) - \frac{1}{N}\sum_i(1 - W_i)/(1 - e(X_i))\bigr)$，它的期望为零，但在给定样本中不为零。对归一化的权重，$\frac{1}{N_{\mathrm{t}}}\sum_{W_i = 1}\hat\lambda_i = \frac{1}{N_{\mathrm{c}}}\sum_{W_i = 0}\hat\lambda_i = 1$，所以 $c$ 被消去。依赖于结果尺度的任意原点的估计含有可避免的方差成分，当某些权重很大时，这一成分也很大。
5. 在例 8.4.1 中，设 $N = 20$，$N_{\mathrm{t}} = 10$，处理组中有 6 名女性，对照组中有 4 名。比较按真实与按估计倾向评分分层所得的协变量平衡。

   **答** 真实评分对每个人都是 $1/2$，所以只有一层，处理组中女性的比例为 $0.6$，对照组中为 $0.4$，明显不平衡。估计的评分对女性为 $6/10 = 0.6$，对男性为 $4/10 = 0.4$；按它分层得到由 10 名女性（6 名处理、4 名对照）构成的一层和由 10 名男性（4 名处理、6 名对照）构成的一层，每层在性别上都完全平衡。
6. 推导 logistic 对数似然 $L(\boldsymbol{\phi})$ 的梯度与 Hessian 矩阵，并证明 Newton–Raphson 更新是一个加权最小二乘拟合。

   **答** 令 $\eta_i = h(X_i)\boldsymbol{\phi}$，$e_i = \mathrm{e}^{\eta_i}/(1 + \mathrm{e}^{\eta_i})$，则 $\partial\log(1 + \mathrm{e}^{\eta_i})/\partial\boldsymbol{\phi} = e_ih(X_i)^{\mathsf T}$，所以梯度为 $H^{\mathsf T}(\boldsymbol{W} - \boldsymbol{e})$，其中 $H$ 是以 $h(X_i)$ 为各行的矩阵；又因 $\partial e_i/\partial\eta_i = e_i(1 - e_i)$，Hessian 矩阵为 $-H^{\mathsf T}DH$，$D = \operatorname{diag}(e_i(1 - e_i))$。更新为 $\boldsymbol{\phi}^{(k+1)} = \boldsymbol{\phi}^{(k)} + (H^{\mathsf T}DH)^{-1}H^{\mathsf T}(\boldsymbol{W} - \boldsymbol{e}) = (H^{\mathsf T}DH)^{-1}H^{\mathsf T}D\boldsymbol{z}$，其中工作响应 $z_i = \eta_i + (W_i - e_i)/(e_i(1 - e_i))$：即 $\boldsymbol{z}$ 对 $H$、以 $e_i(1 - e_i)$ 为权的加权最小二乘，这就是迭代重加权最小二乘。
7. 解释为什么选择倾向评分模型的协变量时不得使用结果，以及为什么一个强烈预测结果、却只微弱预测分配的协变量仍应纳入。

   **答** 若使用结果，分析者可能（即使是无意地）尝试各种设定，直到估计的效应看上去合意，而所报告的不确定性忽略了这一搜索；如同在实验中那样让设计对结果保持盲态，就排除了这种情况。与结果强烈相关的协变量，即使其不平衡很小也会造成偏差，因为偏差大致等于不平衡量乘以该协变量对结果的效应；使它平衡在方差上代价很小，却可以消除很大的偏差。这就是此类协变量属于第 1 步基本协变量的原因。
8. 一位同事论证说，因为倾向评分是平衡得分，按 $\hat e(X_i)$ 匹配就使处理单元与对照单元在所有方面都可比，无论已观测还是未观测。这一说法错在哪里？

   **答** 定理 8.2.1 只涉及已观测的协变量 $X_i$：倾向评分相同的单元在两组中具有相同的 $X_i$ 分布。同时影响处理与结果的未观测变量并不平衡，除非它们是 $X_i$ 的函数，或在给定 $X_i$ 时与分配独立，而这恰恰是不可检验的无混杂性假设。定理 8.2.3 把无混杂性从 $X_i$ 传递给 $e(X_i)$，并没有创造它。
