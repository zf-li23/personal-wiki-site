一个典型的回归分析有四步：建立模型、估计模型、评价模型、使用模型。[3.3.3](/3.3.3) 与 [3.3.4](/3.3.4) 的推断（$t$ 检验与 $F$ 检验、置信区间与预测区间）属于最后一步，它的每一个 $p$ 值和覆盖概率都是在模型假设下算出来的。本章讨论第三步：**简单线性回归模型**作了哪些假设，可能出现什么问题，以及如何用图形和正式检验发现它们。我们先考察预测变量 $X$：模型对它没有任何假设，但它的"分布"即设计很重要；然后考察**残差**，它代替了观测不到的误差。本章发现的问题如何补救是 [3.3.6](/3.3.6) 的内容；同样的工具的矩阵形式及其多元回归版本见 [3.3.7](/3.3.7) 与 [3.3.11](/3.3.11)。

## 5.1. 模型及其假设

### 5.1.1. 简单线性正态误差回归模型

观测 $n$ 个个体 $(X_i, Y_i)$，$Y_i$ 是第 $i$ 个响应变量（结果变量），$X_i$ 是第 $i$ 个解释变量（预测变量），假设

$$
Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i, \qquad i = 1, \dots, n,
$$
其中 $\beta_0$ 是截距，$\beta_1$ 是斜率，随机误差 $\varepsilon_1, \dots, \varepsilon_n$ 相互独立、服从正态分布，$\mathbb{E}(\varepsilon_i) = 0$，方差恒定 $\operatorname{Var}(\varepsilon_i) = \sigma^2$（[3.3.2](/3.3.2)）。于是对每个 $X_i$，响应服从以回归直线为中心的正态分布 $\mathcal{N}(\beta_0 + \beta_1 X_i, \sigma^2)$。

记**最小二乘**估计为 $b_0$（截距）与 $b_1$（斜率），**拟合值**与**残差**为

$$
\hat Y_i = b_0 + b_1 X_i, \qquad e_i = Y_i - \hat Y_i = Y_i - (b_0 + b_1 X_i).
$$

### 5.1.2. LINE 假设

模型由四条假设组成，可用缩写 LINE 记忆：

| 假设 | 内容 | 名称 |
|---|---|---|
| L | $Y_i$ 的均值是 $X_i$ 的线性函数：$\mathbb{E}(Y_i) = \beta_0 + \beta_1 X_i$ | 线性 |
| I | $\varepsilon_1, \dots, \varepsilon_n$ 相互独立 | 独立性 |
| N | $\varepsilon_1, \dots, \varepsilon_n \sim \mathcal{N}(0, \sigma^2)$ | 正态性 |
| E | $\operatorname{Var}(Y_i) = \sigma^2$ 不依赖于 $X_i$ | 方差相等（方差恒定） |

三条概率假设（I、N、E）说的是误差，也就是给定 $X$ 时 $Y$ 的条件分布。因此不宜把观测到的 $Y_1, \dots, Y_n$ 当作一个样本来检查它们：各 $Y_i$ 的均值 $\beta_0 + \beta_1 X_i$ 不同，它们的直方图是中心各异的正态分布的混合，即使模型正确也未必像正态分布。这些假设要在残差上检查，残差的均值为零，近似于误差。

### 5.1.3. 诊断与补救措施

**定义 5.1.1（回归诊断）** 检查回归模型的假设是否被违反的图形工具和正式方法称为**回归诊断**。假设被违反时所用的方法称为**补救措施**：用变换或其他调整来修正问题，或改用能够容纳这种违反的其他模型与分析策略。

假设被违反时，推断就不可信：$t$ 检验、$F$ 检验及其 $p$ 值不再正确，置信区间达不到名义覆盖率。因此诊断应当先于推断，并由诊断的结果决定是否需要以及需要哪种补救（[3.3.6](/3.3.6)）。

## 5.2. 预测变量的诊断

### 5.2.1. 为什么要考察预测变量

在描述响应变量 $Y$ 与预测变量 $X$ 的关系之前，先看看这些变量的分布。预测变量总是应当考察的。单看响应变量则信息少得多：如果 $Y$ 依赖于 $X$，它的边缘分布混合了不同 $X$ 处的条件分布，只看 $Y$ 的边缘分布是一种常见的错误。

模型对 $X$ 不作任何分布假设：它可以服从任何分布，也可以干脆看作固定的（不是随机变量）。尽管如此，$X_i$ 的"分布"即设计仍然重要：

- $X_i$ 的离散程度决定斜率的精度，$\operatorname{Var}(b_1) = \sigma^2 / \sum_{i}(X_i - \bar X)^2$（[3.3.3](/3.3.3)）。好的设计不仅使推断有更大的功效，还保证整个分析过程的有效性；坏的设计则相反。
- $X_i$ 偏斜或含有极端值时，会放大估计的方差，或支配拟合出的趋势（[3.3.6](/3.3.6) 的杠杆值）。

$X$ 取值很多时，用数值概括量（均值、中位数、四分位数；R 的 `summary`）描述它；只取少数几个值时，频数表（R 的 `table`）就够了。

序列图（sequence plot）把观测按收集的先后顺序画出来。序列图中的趋势是对独立性的警示，提示时间或其他排序变量可能是改变 $X$ 与 $Y$ 关系的混杂因素。一个经典的例子：冰淇淋销量和鲨鱼袭击次数在一年的各月间同升同降，因为二者都受气温驱动，而不是一个导致另一个。同样，还应当追问模型是否遗漏了重要的预测变量；混杂在因果推断（[3.9](/3.9)）中有系统的讨论。

```r
plot(lotsize)                         # sequence plot of the predictor
lines(lowess(lotsize), col = "red")   # smoothed trend over the order of collection
```

### 5.2.2. 位置、离散程度、偏度与峰度

描述一个分布的数值概括量有四类：

| 统计量 | 度量 |
|---|---|
| 均值 | 位置 |
| 标准差；极差 $X_{(n)} - X_{(1)}$ | 变异性、离散程度 |
| 偏度 | 不对称程度 |
| 峰度 | 相对于正态分布尾部的轻重 |

记样本中心矩 $m_k = \frac1n\sum_{i=1}^n (X_i - \bar X)^k$，**样本偏度**与**样本峰度**（[3.2.1](/3.2.1)）为

$$
g_1 = \frac{m_3}{m_2^{3/2}} = \frac{\frac1n\sum_{i=1}^n(X_i - \bar X)^3}{\Big(\frac1n\sum_{i=1}^n(X_i - \bar X)^2\Big)^{3/2}}, \qquad g_2 = \frac{m_4}{m_2^2} - 3 = \frac{\frac1n\sum_{i=1}^n(X_i - \bar X)^4}{\Big(\frac1n\sum_{i=1}^n(X_i - \bar X)^2\Big)^2} - 3,
$$
它们是 [3.1.8](/3.1.8) 中**偏度**与**峰度**的样本版本。

偏度。$g_1 < 0$ 时分布左偏：左尾比右尾长（例如死亡年龄的分布）。$g_1 > 0$ 时分布右偏（例如一次难度较大的考试的分数，或收入）。符号给出偏斜的方向，偏斜可以有不同的程度；大小则是把样本与对称（正态）分布相比，远离零的值提示总体非正态、有偏斜。正态分布和其他对称分布的均值、中位数、众数相同；一般而言（并非总是如此），右偏分布有 众数 < 中位数 < 均值，左偏分布顺序相反。数据多峰时，各个峰会影响偏度的符号，单个数字就不能很好地描述形状了。

峰度。$g_2$ 度量稀有观测离均值散布得多远，正态分布的 $g_2 = 0$。$g_2$ 有时称为超额峰度，而峰度一词留给 $G_2 = m_4 / m_2^2 = g_2 + 3$；软件报告样本峰度时，要查明它遵循哪种约定。

**定义 5.2.1（尖峰分布与低峰分布）** 峰度大于 $0$（尾部比正态分布重）的分布称为**尖峰分布**（"lepto-"意为细长）；峰度小于 $0$（尾部较轻）的分布称为**低峰分布**（"platy-"意为宽阔）。峰度为 $0$ 的分布称为常峰分布。

关于峰度有三种常见的误解。第一，峰度不只是陡峭程度：尾部的轻重和峰的陡峭都是峰度的组成部分，而且尾部起主导作用。第二，正峰度对应较尖的峰和重尾，负峰度对应较平的顶和轻尾。第三，峰度不是方差：它由标准化的数据计算，与尺度无关，描述的是除方差以外的分布形状；尖峰分布的方差可以比低峰分布的小，也可以比它大。

| 分布（标准化） | 峰度 |
|---|---|
| Laplace 分布（双指数分布） | $3$ |
| 双曲正割分布 | $2$ |
| logistic 分布 | $1.2$ |
| 正态分布 | $0$ |
| 升余弦分布 | $-0.594$ |
| Wigner 半圆分布 | $-1$ |
| 均匀分布 | $-1.2$ |

尖峰（"超高斯"）分布包括 Student $t$ 分布、Laplace 分布、指数分布、Poisson 分布和 logistic 分布；低峰（"亚高斯"）分布包括连续与离散均匀分布、升余弦分布。最"低峰"的分布是 $\mathrm{Ber}(1/2)$，即掷一枚均匀硬币，峰度为 $-2$；任何分布的峰度都不会更小，因为对标准化的 $Z$ 有 $\mathbb{E}Z^4 \ge (\mathbb{E}Z^2)^2 = 1$。金融中的峰度风险说的就是这一点：两种资产的收益均值与方差相同时，收益分布为尖峰分布的那一种出现极端收益和极端损失的机会更大。

简言之，偏度区分一侧尾部与另一侧尾部的极端值，峰度则度量任一侧尾部的极端值：尖峰数据的尾部比正态分布更极端，低峰数据出现极端事件的可能性比正态分布小。

为什么要与正态分布相比？回归模型并不假设 $X$ 来自正态分布（它可以服从任何分布，或是固定的），也不假设 $Y$ 来自单个正态分布；它假设给定 $X_i$ 时 $Y$ 服从正态分布。不过在某些情形下 $X$ 或 $Y$ 本身可能是正态的，了解这一点会有用处。

**例 5.2.1（Toluca 批量）** 在 Toluca 公司的数据中，$n = 25$ 次生产记录了批量 $X$ 与工时 $Y$。批量的概括量为

| 最小值 | $Q_1$ | 中位数 | 均值 | $Q_3$ | 最大值 |
|---|---|---|---|---|---|
| $20$ | $50$ | $70$ | $70$ | $90$ | $120$ |

标准差 $28.72$（方差 $825$，$\sum(X_i - \bar X)^2 = 19800$），众数 $90$，极差 $100$，四分位距 $\mathrm{IQR} = Q_3 - Q_1 = 40$；四分位数把排好序的数据分成四个相等的部分。样本偏度 $g_1 = -0.097$，样本峰度 $g_2 = -1.106$。批量几乎对称、尾部较轻，这正是一个计划好的设计所应有的：取值是 $10$ 的倍数，均匀地分布在 $20$ 到 $120$ 之间。

### 5.2.3. 图形概括

茎叶图（R 的 `stem`）按前几位数字紧凑地列出数据，既显示分布的形状，又保留各个数值。

**箱线图**（[3.4.1](/3.4.1)）显示中位数、四分位数和须，须延伸到箱外 $1.5\,\mathrm{IQR}$ 以内最极端的观测，须以外的点单独画出，是可能的离群值（R 的 `boxplot`；`range = 0` 使须延伸到最值）。箱的各部分之间的间距反映离散程度和偏斜。对正态分布，$Q_1$、$Q_3$ 为 $\mu \mp 0.6745\sigma$，须的界限 $Q_1 - 1.5\,\mathrm{IQR}$ 与 $Q_3 + 1.5\,\mathrm{IQR}$ 为 $\mu \mp 2.698\sigma$，落在界限以外的观测只占 $0.7\%$。箱线图不能显示一切：截然不同的分布，例如四分位数相同的单峰分布和双峰分布，可以有完全相同的箱线图。

直方图（R 的 `hist`）显示密度的形状，包括多峰性；取 `freq = FALSE` 时纵轴为密度，可以叠加一条光滑的密度估计（R 的 `density`）。直方图的外观依赖于分组的选择。

分位数–分位数图（QQ 图）通过分位数比较两个分布。设 $F$、$G$ 是两个分布函数，

$$
F^{-1}(q) = \inf\{y \colon F(y) \ge q\}, \qquad 0 < q < 1
$$
是相应的**分位数**函数。QQ 图对 $0 < q < 1$ 画出 $F^{-1}(q)$ 对 $G^{-1}(q)$ 的图：每个点配对两个值，各自分布中都有同样比例 $q$（比如 $10\%$、$50\%$、$80\%$）的概率落在它下方。若 $F$ 与 $G$ 只差位置和尺度，这些点落在一条直线上。

**正态 QQ 图**（正态概率图）把样本与正态分布相比。对样本 $X_1, \dots, X_n$ 及其**次序统计量** $X_{(1)} \le X_{(2)} \le \cdots \le X_{(n)}$，第 $i$ 个次序统计量是阶约为 $i/n$ 的实现分位数；相应的正态得分为

$$
Z_i = \Phi^{-1}(p_i), \qquad p_i = \frac{i - 0.5}{n}, \qquad i = 1, \dots, n,
$$
图中画出 $X_{(i)}$ 对 $Z_i$ 的点。若样本来自正态分布，这些点大致沿直线

$$
X_{(i)} = \mu + \sigma Z_i
$$
分布，偏离直线表示偏离正态性。有的教材改画 $X_{(i)}$ 对 $sZ_i$ 的图，或用稍有不同的 $p_i$，这不改变图的性质。偏离的形状也揭示了背后分布的形状：

| 点的形态 | 分布 |
|---|---|
| 贴近直线 | 正态 |
| S 形：中间平缓，两端向水平方向弯 | 轻尾（低峰） |
| 反 S 形：下端在直线下方，上端在直线上方 | 重尾（尖峰） |
| 下凸曲线，两端都在直线上方 | 右偏 |
| 上凸曲线，两端都在直线下方 | 左偏 |
| 两团点，中间有跳跃 | 双峰 |

![Normal Q-Q plots of samples of size 60 from a normal, a uniform (light-tailed), a t distribution with 2 degrees of freedom (heavy-tailed), an exponential (right-skewed), a negative exponential (left-skewed) and a bimodal normal mixture distribution; the reference line passes through the quartiles](./plots/qq-patterns.py)

对 Toluca 的批量，茎叶图、箱线图（箱从 $50$ 到 $90$，须到 $20$ 与 $120$，没有离群值）、直方图和正态 QQ 图都与数值概括量一致：对称、平坦、没有极端值。

```r
stem(lotsize)                        # stem-and-leaf plot
boxplot(lotsize)
hist(lotsize, freq = FALSE)          # histogram on the density scale

qqline(lotsize, col = "red")         # line through the quartiles
```

## 5.3. 用残差诊断

回顾残差 $e_i = Y_i - \hat Y_i = Y_i - (b_0 + b_1 X_i)$：它显示模型拟合得如何，并近似于误差项 $\varepsilon_i$。残差可用于多种诊断目的：

- 线性模型是否合适？
- 误差方差是否恒定？
- 误差是否服从正态分布？
- 误差是否独立？
- 是否有离群值？

**定义 5.3.1（残差图）** 残差 $e_i$ 对预测变量 $X_i$、对拟合值 $\hat Y_i$ 或对其他变量（如观测的时间顺序）的散点图称为**残差图**。

模型合适时，残差图显示围绕零的一条水平带，没有任何系统性的模式。下图是四类违反的典型模式，后面各小节逐一讨论。

![Four residual plots: (a) a horizontal band without pattern, (b) a U-shaped curve when a quadratic relation is fitted by a straight line, (c) a funnel when the error standard deviation grows with X, (d) long runs of positive and negative residuals in time order when the errors are autocorrelated](./plots/residual-patterns.py)

### 5.3.1. 关系是线性的吗？

回答这个问题有两种图：$Y_i$ 对 $X_i$ 的散点图，以及 $e_i$ 对 $X_i$ 或 $\hat Y_i$ 的残差图。残差图更能突出对线性模式的偏离，因为支配散点图的线性趋势已经被去掉了。

**例 5.3.1（二次关系）** 由 $Y = X^2 - 10X + 30 + \varepsilon$ 生成正态误差、$\sigma = 25$ 的数据，再拟合一条直线。

```r
x <- seq(1, 30, by = 1)
n <- length(x)
y <- x^2 - 10 * x + 30 + 25 * rnorm(n)
a100 <- data.frame(x, y)
fit1 <- lm(y ~ x, data = a100)
anova(fit1)
summary(fit1)
```

某一次运行的输出如下：

| 来源 | 自由度 | 平方和 | 均方 | $F$ | $p$ 值 |
|---|---|---|---|---|---|
| x | $1$ | $1016230$ | $1016230$ | $182.52$ | $8.7 \times 10^{-14}$ |
| 残差 | $28$ | $155898$ | $5568$ | | |

| | 估计 | 标准误 | $t$ 值 | $p$ 值 |
|---|---|---|---|---|
| (Intercept) | $-138.179$ | $27.942$ | $-4.945$ | $3.2 \times 10^{-5}$ |
| x | $21.264$ | $1.574$ | $13.510$ | $8.7 \times 10^{-14}$ |

一切看上去都高度显著，$R^2 = 1016230 / 1172128 = 0.867$ 也很大。然而带拟合直线的散点图（`plot(y ~ x); abline(fit1)`）显示两端的点在直线上方、中间的点在直线下方，光滑曲线（`scatter.smooth(x, y)`）显然是一条抛物线，残差图（`scatter.smooth(x, fit1$residuals); abline(h = 0)`）呈现上图 (b) 的 U 形。斜率显著和 $R^2$ 很大都不能说明关系是线性的。

### 5.3.2. 误差方差恒定吗？

同样画 $Y_i$ 对 $X_i$ 的图，以及 $e_i$ 对 $X_i$ 或 $\hat Y_i$ 的图。$e_i$ 对 $X_i$ 的残差图更能突出方差假设的问题：漏斗形或喇叭形意味着误差的散布随 $X$ 变化。

**定义 5.3.2（同方差性与异方差性）** 若回归模型的误差方差全都相同，即对所有 $i$ 有 $\operatorname{Var}(\varepsilon_i) = \sigma^2$，称误差是同方差的，这一性质称为**同方差性**。否则，若方差依赖于 $i$（通常依赖于 $X_i$），称误差是异方差的，这一性质称为**异方差性**。

**例 5.3.2（方差随 $X$ 增大）** 由 $Y = 30 + 100X + 10X\varepsilon$ 生成数据，误差标准差 $10X$ 随 $X$ 增大：

```r
x <- seq(1, 100, by = 1)
n <- length(x)
y <- 30 + 100 * x + 10 * x * rnorm(n)
a100a <- data.frame(x, y)
fit2 <- lm(y ~ x, data = a100a)
anova(fit2)
summary(fit2)
```

| 来源 | 自由度 | 平方和 | 均方 | $F$ | $p$ 值 |
|---|---|---|---|---|---|
| x | $1$ | $845726258$ | $845726258$ | $2431.1$ | $< 2.2 \times 10^{-16}$ |
| 残差 | $98$ | $34091704$ | $347875$ | | |

| | 估计 | 标准误 | $t$ 值 | $p$ 值 |
|---|---|---|---|---|
| (Intercept) | $71.299$ | $118.852$ | $0.60$ | $0.55$ |
| x | $100.746$ | $2.043$ | $49.31$ | $< 2 \times 10^{-16}$ |

趋势看起来是线性的，斜率估计也接近真值，但残差图像上图 (c) 那样呈扇形散开。方差不恒定为什么是个问题？最小二乘仍然是无偏的，因为无偏性只用到 $\mathbb{E}(\varepsilon_i) = 0$；但 **Gauss–Markov 定理**（[3.2.3](/3.2.3)）要求方差相同，所以最小二乘不再是方差最小的线性无偏估计。估计不是最有效的，推断（检验、置信区间、预测区间）也可能偏离、出错或难以进行，因为报告的标准误是按方差恒定计算的。

截距估计 $71.3$ 看上去离 $\beta_0 = 30$ 很远，尽管 $b_0$ 是无偏的。这并不奇怪：截距是外推到 $X = 0$ 的结果，$b_0 = \bar Y - b_1 \bar X$ 且 $\bar X = 50.5$，$X$ 较大的观测的大误差通过 $b_1$ 进入 $b_0$，它的标准差很大（对这一设计做模拟约为 $75$；报告的 $118.9$ 本身也被异方差扭曲了）。偏差 $41.3$ 远在一个标准差之内。在这里加权最小二乘（[3.3.6](/3.3.6)）给出的估计要精确得多。

方差相等有几种正式检验。前三种检验 $k$ 个样本是否来自方差相等的总体；在回归中把观测按 $X$ 的值分组后使用（例如 $X$ 较小的一组与 $X$ 较大的一组）。

- Bartlett 检验（Bartlett's test）是正态总体方差相等的**似然比检验**，近似服从 $\chi^2$ 分布；它对偏离正态很敏感。
- Levene 检验（Levene's test）计算观测与组均值的绝对偏差 $Z_{ij} = \lvert Y_{ij} - \bar Y_i\rvert$，再用两样本 $t$ 检验或对 $Z_{ij}$ 做**方差分析**比较各组：离散程度较大的组，观测与中心的绝对偏差也较大。
- Brown–Forsythe 检验（Brown–Forsythe test）是用与组中位数的偏差 $Z_{ij} = \lvert Y_{ij} - \tilde Y_i\rvert$ 的 Levene 检验，因而更稳健。用截尾均值的 Levene 检验对对称的重尾分布效果较好，中位数版本对偏斜分布效果较好。
- Breusch–Pagan 检验（Breusch–Pagan test）把误差方差建模为 $\sigma_i^2 = h(\boldsymbol{z}_i^{\mathsf T}\boldsymbol{\alpha})$，$\boldsymbol{z}_i^{\mathsf T}\boldsymbol{\alpha} = \alpha_0 + \alpha_1 Z_{i1} + \cdots + \alpha_q Z_{iq}$，其中函数 $h$ 有一阶和二阶导数。在 $H_0\colon \alpha_1 = \cdots = \alpha_q = 0$ 下方差 $\sigma_i^2 = h(\alpha_0) = \sigma^2$ 恒定。记 $\mathrm{SSR}^*$ 为 $e_i^2$ 对 $Z_{i1}, \dots, Z_{iq}$ 回归的回归平方和，检验统计量为

  $$
  \chi^2_{\mathrm{BP}} = \frac{\mathrm{SSR}^*/2}{(\mathrm{SSE}/n)^2} \overset{H_0}{\approx} \chi^2_q.
  $$
  在简单线性回归中通常取 $Z = X$、$h = \exp$（$q = 1$），即 $\log\sigma_i^2 = \alpha_0 + \alpha_1 X_i$。这一检验假设误差正态且样本量大。

### 5.3.3. 误差服从正态分布吗？

我们考察残差的分布。与各 $Y_i$ 不同，残差可以作为一个样本放在一起考察，因为它们估计的都是 $\mathbb{E}(\varepsilon) = 0$ 的误差。常用的"目测"方法是残差图中的散布、残差的箱线图、直方图和正态 QQ 图。

**例 5.3.3（Toluca 残差）** 对工时关于批量的回归，

```r
reg <- lm(hours ~ lotsize, data = toluca)
resid <- resid(reg)
hist(resid, freq = FALSE)   # compare with the normal density N(0, MSE)
qqp <- qqnorm(resid)
qqline(resid)
cor(qqp$x, qqp$y)           # correlation between residuals and normal scores
shapiro.test(resid)
```

直方图大致呈钟形且对称，叠加在上面的均值为 $0$、方差为 $\mathrm{MSE}$ 的正态曲线与光滑密度估计相当吻合；正态 QQ 图接近一条直线。Shapiro–Wilk 检验给出 $W = 0.9789$，$p = 0.8626$：$p$ 值大于 $0.05$，没有明显偏离正态。

正态性的正式检验检验

$$
H_0\colon \text{数据是来自正态总体的 iid 样本} \quad\text{vs}\quad H_1\colon \text{不是}.
$$

- 相关系数检验利用排序后的残差与其在正态性下的期望值（QQ 图中的正态得分）之间的相关系数；相关系数小于查表得到的临界值时拒绝 $H_0$。
- **Shapiro–Wilk 检验**（[3.2.6](/3.2.6)）同样基于次序统计量与正态得分的相关。它在常用检验中功效最好，也是最常用的选择。与所有检验一样，$n$ 很大时它会对细小的、实际上无关紧要的偏离变得敏感。
- **Kolmogorov–Smirnov 检验**利用**经验分布函数** $F_n$ 与假设的 $F$ 之间的最大距离 $D_n = \sup_x\lvert F_n(x) - F(x)\rvert$。
- Cramér–von Mises 检验（Cramér–von Mises test）利用积分平方距离 $T = n\int_{-\infty}^{\infty}\big(F_n(x) - F(x)\big)^2\,\mathrm{d}F(x)$。
- Anderson–Darling 检验（Anderson–Darling test）用 $w(x) = 1/\big(F(x)(1 - F(x))\big)$ 给平方距离加权，$A^2 = n\int_{-\infty}^{\infty}\big(F_n(x) - F(x)\big)^2 w(x)\,\mathrm{d}F(x)$，更重视尾部。

正态分布的均值和方差由数据估计时（对残差总是如此），后三个统计量的零分布会改变，必须使用修正的临界值。此外残差之间略有相关；[3.3.7](/3.3.7) 说明当 $n$ 远大于参数个数时这几乎没有影响。

总之，真正的问题是：误差的分布是否偏离正态到足以使置信区间、显著性检验等失效的程度。考察残差的分布，使用正态 QQ 图，并对正态性检验保持警惕：大样本时它们会拒绝无关紧要的偏离，小样本时又会漏掉重要的偏离。

### 5.3.4. 误差独立吗？

相依性通常在残差对观测时间顺序的图中看出。典型的模式是线性或二次趋势，或周期性模式；这些模式意味着观测不独立。例如把焊点的剪切强度（$Y$）对焊点直径（$X$）回归，按焊接先后顺序画出的残差可能稳定地向上漂移，或呈波浪状起伏。

- Durbin–Watson 检验（Durbin–Watson test）检验误差是否序列相关。它假设一阶自回归模型 $\varepsilon_i = \rho\varepsilon_{i-1} + u_i$，$-1 < \rho < 1$，$u_i \overset{\text{iid}}{\sim} \mathcal{N}(0, \sigma_u^2)$，检验 $H_0\colon \rho = 0$，使用

  $$
  d = \frac{\sum_{i=2}^n (e_i - e_{i-1})^2}{\sum_{i=1}^n e_i^2} \approx 2(1 - \hat\rho) \in [0, 4],
  $$
  其中 $\hat\rho$ 是残差的一阶样本自相关系数。精确的临界值需要查表。经验上，$d \in (1.5, 2.5)$ 尚可，而 $d < 1$ 或 $d > 3$ 无疑值得担心。
- Ljung–Box 检验（Ljung–Box test）来自时间序列分析，它检验一个序列"整体"的随机性，同时考虑若干个滞后，而不是逐个滞后检验：

  $$
  Q = n(n + 2)\sum_{k=1}^{h}\frac{\hat\rho_k^2}{n - k} \overset{H_0}{\approx} \chi^2_h,
  $$
  其中 $\hat\rho_k$ 是滞后 $k$ 的样本自相关系数，$h$ 是所检验的滞后个数。

### 5.3.5. 有离群值吗？

最小二乘估计基于均值和平方和，这些数值概括量对离群值不稳健：一个不服从其他观测模式的观测就能显著改变拟合。离群值可以在 $Y_i$ 对 $X_i$ 的散点图中，以及 $e_i$ 对 $X_i$ 或 $\hat Y_i$ 的残差图中看到；$e_i$ 对 $X_i$ 的残差图显示得最清楚。它们的精确分类（离群值、高杠杆点、强影响点）见 [3.3.6](/3.3.6)。

**例 5.3.4（靠近中心的离群值）** 在 $X = 1, 6, \dots, 96$ 处由 $Y = 30 + 50X + \varepsilon$、$\sigma = 200$ 生成 $20$ 个观测，再在 $X = 50$ 处加一个离群值：

```r
x <- seq(1, 100, by = 5)
n <- length(x)
y <- 30 + 50 * x + 200 * rnorm(n)
x <- c(x, 50)
y <- c(y, 30 + 50 * 50 + 10000)       # the last pair is the outlier
a100b1 <- data.frame(x, y)
fit3 <- lm(y ~ x, data = a100b1)              # with the outlier
fit4 <- lm(y ~ x, data = a100b1[-(n + 1), ])  # without the outlier
```

**例 5.3.5（位于极端 $X$ 处的离群值）** 数据相同，但加入的离群值是 $(100,\ 30 + 50 \cdot 100 - 10000)$；`fit5` 与 `fit6` 分别是含与不含它的拟合。

| 拟合 | $b_0$（标准误） | $b_1$（标准误） | $s = \sqrt{\mathrm{MSE}}$ | $F$（$p$ 值） |
|---|---|---|---|---|
| 不含离群值 | $26.2$（$81.3$） | $50.86$（$1.44$） | $185.8$ | $1245.7$（$< 10^{-15}$） |
| 离群值在 $X = 50$ | $459.0$（$973.9$） | $51.72$（$17.35$） | $2237$ | $8.89$（$0.0077$） |
| 离群值在 $X = 100$ | $861.8$（$903.5$） | $25.04$（$15.25$） | $2111$ | $2.69$（$0.117$） |

$X = 50$ 处的离群值靠近 $\bar X = 48.5$，它把整条直线向上平移，因而改变了截距，却几乎不改变斜率；它使 $s$ 增大十倍以上，所有标准误也随之增大。位于极端值 $X = 100$ 处的离群值还使直线倾斜：斜率减半，在 $0.05$ 水平下不再显著。在第一个拟合的残差图中，离群值以约 $9500$ 的残差突显出来；在第二个拟合中直线被拉向离群值，其余残差呈现出虚假的递增趋势。离群值的 $X$ 值远离 $\bar X$ 时对斜率影响大，靠近 $\bar X$ 时影响小：这就是 [3.3.6](/3.3.6) 的杠杆值。

## 小结

| 假设 | 图形检查 | 正式检验 |
|---|---|---|
| 线性 | 带光滑曲线的散点图；残差对 $X$ 或 $\hat Y$ | 失拟检验（[3.3.6](/3.3.6)） |
| 方差恒定 | 残差对 $X$ 或 $\hat Y$（漏斗形） | Bartlett、Levene、Brown–Forsythe、Breusch–Pagan |
| 正态性 | 残差的直方图、箱线图和正态 QQ 图 | 相关系数检验、Shapiro–Wilk、Kolmogorov–Smirnov、Cramér–von Mises、Anderson–Darling |
| 独立性 | 残差对时间顺序 | Durbin–Watson、Ljung–Box |
| 无离群值 | 散点图、残差图 | 学生化残差、Cook 距离（[3.3.6](/3.3.6)） |

- 模型对 $X$ 的分布不作假设，但设计很重要；用数值概括量（位置、离散程度、偏度 $g_1$、峰度 $g_2$）和图形（序列图、茎叶图、箱线图、直方图、QQ 图）考察 $X$。正峰度表示尾部比正态分布重（尖峰），负峰度表示尾部较轻（低峰）；峰度与尺度无关，它不是方差。
- 概率假设针对给定 $X$ 时 $Y$ 的条件分布，所以要在残差上检查，而不是在 $Y$ 的边缘分布上检查。
- $R^2$ 很大、检验显著并不能证明模型正确：遗漏的弯曲（例 5.3.1）和异方差（例 5.3.2）都可以与漂亮的输出并存。异方差下最小二乘仍然无偏，但失去有效性，其标准误也是错的。
- 最小二乘不稳健：靠近 $\bar X$ 的离群值主要使直线平移，位于极端 $X$ 处的离群值使直线倾斜。
