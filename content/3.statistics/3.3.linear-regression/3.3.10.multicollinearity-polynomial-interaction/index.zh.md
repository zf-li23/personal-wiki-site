[3.3.8](/3.3.8) 与 [3.3.9](/3.3.9) 中遇到的种种困难——加入一个变量后系数变号、总体 $F$ 检验显著而没有一个 $t$ 检验显著、序贯平方和依赖于顺序——都有一个共同的来源：解释变量之间的相关。本章系统地分析这个问题。Venn 图直观地说明最小二乘为每个系数使用了哪些信息。零共线性、完全共线性和部分共线性三种情形说明相关对估计、估计的方差和平方和有什么影响。接着讨论补救措施：删除变量——遗漏重要变量会造成偏差（Simpson 悖论是著名的例子）；变换变量——以多项式回归为主要例子，中心化能消除变量与其幂之间的大部分共线性。最后，交互作用模型描述一个变量的作用依赖于另一个变量取值的情形，特别是其中一个是组别示性变量的情形。共线性的数值诊断（方差膨胀因子）见 [3.3.11](/3.3.11)；改变估计量本身的补救方法，如**岭回归**，见 [3.3.12](/3.3.12) 与 [3.4.7](/3.4.7)。

## 10.1. 多重共线性

### 10.1.1. Venn 图

Venn 图用圆表示每个变量的变异，用重叠部分表示共有的变异。在简单回归中，$y$ 与 $X$ 两个圆的重叠部分是最小二乘用来估计 $\beta_X$ 的信息。如果这部分信息是 $y$ 中唯一由 $X$ 的变化解释的变异，估计 $b_X$ 就是无偏的；重叠越大，用到的信息越多，$b_X$ 的方差越小。$y$ 圆的其余部分是 $X$ 不能解释的变异，归于误差项；它越大，$\sigma^2$ 的估计越大。

有两个解释变量 $X$ 和 $W$ 时，$y$ 圆分成四部分：只与 $X$ 共有的部分、只与 $W$ 共有的部分、与二者都共有的部分，以及未被解释的其余部分。$X$ 的偏回归系数（[3.3.8](/3.3.8)）由 $y$ 中唯一归于 $X$ 的变异来估计，$W$ 的则由唯一归于 $W$ 的部分来估计；这正是 $t$ 检验"最后加入变量"的逻辑。$X$ 与 $W$ 共有的部分不用于任何一个系数，因为我们无法分辨 $y$ 在那里的变动是由 $X$ 还是由 $W$ 引起的。但这部分仍计入拟合，而 $y$ 圆的其余部分用来估计 $\sigma^2$。

![回归的 Venn 图。左：简单回归，y 与 X 的重叠部分是估计 beta_X 所用的信息，y 的其余部分是误差。右：两个解释变量 X 与 W，y 中只属于 X 和只属于 W 的部分分别用于估计 b_X 与 b_W，X 与 W 共有的部分不用于任何一个系数，y 中未被解释的部分用于估计 sigma^2](./plots/venn-regression.py)

这幅图只是启发性的。存在**抑制变量**（[3.3.9](/3.3.9)）时它就失效了：那时"共有"部分的面积将不得不为负。

**定义 10.1.1（多重共线性）** 当回归模型的解释变量彼此高度相关，即设计矩阵的某一列接近其他列的线性组合时，称解释变量存在**多重共线性**。

多重共线性是解释变量的性质，与响应无关。两两相关系数能揭示两两之间的共线性，但一个变量可以接近其他几个变量的线性组合，而它与每个变量的两两相关都不高。

**例 10.1.1（体脂，再探）** 在 [3.3.9](/3.3.9) 的体脂模型中，总体 $F$ 检验高度显著（$F^*=21.52$，$p=7.3\times10^{-6}$），而三个 $t$ 检验都不显著。解释变量之间的相关系数为

| | 皮褶 | 大腿 | 上臂 |
|---|---|---|---|
| 皮褶 | $1$ | $0.924$ | $0.458$ |
| 大腿 | | $1$ | $0.085$ |

皮褶与大腿高度相关；上臂与二者各自只是中度相关，但它与皮褶和大腿的最佳线性组合的相关系数达到 $0.995$。皮褶（$X_1$）与大腿（$X_2$）的系数随模型中的其他变量而变：

| 模型中的变量 | $b_1$ | $b_2$ |
|---|---|---|
| $X_1$ | $0.857$ | |
| $X_2$ | | $0.857$ |
| $X_1,X_2$ | $0.222$ | $0.659$ |
| $X_1,X_2,X_3$ | $4.334$ | $-2.857$ |

### 10.1.2. 零共线性

回忆 $\boldsymbol{b}=(X^{\mathsf T}X)^{-1}X^{\mathsf T}\boldsymbol{Y}\sim\mathcal{N}_p\big(\boldsymbol{\beta},\sigma^2(X^{\mathsf T}X)^{-1}\big)$。第一种极端情形是正交设计（orthogonal design）：解释变量互不相关，$j\ne k$ 时 $r_{jk}=0$。

**命题 10.1.1** 若解释变量两两不相关，则对每个 $k$

$$
b_k=\frac{\sum_i(X_{ik}-\bar X_k)(Y_i-\bar Y)}{\sum_i(X_{ik}-\bar X_k)^2}=\frac{s_Y}{s_k}r_{Yk},\qquad\operatorname{Var}(b_k)=\frac{\sigma^2}{\sum_i(X_{ik}-\bar X_k)^2},
$$
与只用 $X_k$ 对 $Y$ 做简单回归的结果相同。

**证明** 把每个 $X_k$ 换成 $X_k-\bar X_k$ 只改变截距，不改变斜率及其方差，因为列空间和斜率的参数化都没有变。中心化之后，各列与截距列正交，又因互不相关而彼此正交，所以 $X^{\mathsf T}X=\operatorname{diag}\big(n,S_{11},\dots,S_{p-1,p-1}\big)$，$S_{kk}=\sum_i(X_{ik}-\bar X_k)^2$。因此 $b_k=\sum_i(X_{ik}-\bar X_k)Y_i/S_{kk}$，$\operatorname{Var}(b_k)=\sigma^2/S_{kk}$；等价地，在 [3.3.9](/3.3.9) 的标准化模型中 $r_{XX}=I_{p-1}$，$b_k^*=r_{Yk}$。$\square$

因此，零共线性时：

- $b_k$ 与模型中还有哪些解释变量无关；
- $X_k$ 对 $\mathrm{SSTO}$ 的贡献界限分明：$\mathrm{SSR}(X_k\mid\text{其他})=\mathrm{SSR}(X_k)$，$X_k$ 的第 I、II、III 类平方和相同；
- 若线性模型成立，正交设计是最优的：解释变量之间没有含糊之处，而且在给定离散程度 $\sum_i(X_{ik}-\bar X_k)^2$ 下，各 $b_k$ 的方差尽可能小，检验的功效高；
- 检验 $\beta_k$ 的 $p$ 值仍随模型而变，因为它们依赖于 $\mathrm{MSE}$，而 $\mathrm{MSE}$ 取决于包含了哪些变量。

### 10.1.3. 完全共线性

另一种极端是退化设计（degenerate design）：某些解释变量（$X$ 的列）线性相关，如 $X_1=2X_2$、$X_2-3X_3+X_4=5$，或一般地 $c_1X_{j_1}+\cdots+c_kX_{j_k}=\text{常数}$。这时 $\operatorname{rank}(X^{\mathsf T}X)=\operatorname{rank}(X)<p$，所以 $(X^{\mathsf T}X)^{-1}$ 不存在，无法计算 $\boldsymbol{b}=(X^{\mathsf T}X)^{-1}X^{\mathsf T}\boldsymbol{Y}$：正规方程有无穷多解，包含全部解释变量的完全模型无法拟合。几何上，当 $aX_1+bX_2=c$ 时，数据位于 $(X_1,X_2)$ 平面中一条直线上方的竖直平面内，而经过该竖直平面内同一条直线的每个响应平面都拟合得一样好。

每个精确的线性关系都使涉及的变量相互混杂，其中至少有一个是多余的。删去其中一个变量，就能在数学上消除冗余，简化模型就可以拟合了。但混杂依然存在：若 $X_1+X_2+X_3=0$，以 $(X_1,X_2)$、$(X_1,X_3)$、$(X_2,X_3)$ 为解释变量的模型给出完全相同的拟合，它们的系数无法分别解释。

**例 10.1.2** 在 [3.3.8](/3.3.8) 的学生数据中加入高中平均成绩 $\mathrm{hs}=(\mathrm{hsm}+\mathrm{hss}+\mathrm{hse})/3$，拟合 gpa $\sim$ hsm + hss + hse + hs。R 报告"1 not defined because of singularities"：hs 的系数为 NA，其他估计与不含 hs 的模型相同。这里 $X$ 不满秩，最小二乘解不唯一，所以有些统计量是误导性的。程序包 car 的 `Anova()` 给出的四个变量的第 II 类平方和都是 $0$，而第 III 类平方和则拒绝计算（"there are aliased coefficients in the model"）。

### 10.1.4. 一般情形

介于两种极端之间的设计既不正交也不退化。少量的相关无伤大雅。相关增强时，$y$ 中唯一属于每个变量的那部分变异缩小，估计每个系数所用的信息减少，估计的方差增大。共线性越强，方差越大，但它不会造成偏差。

相关很强时，问题出现在两个层面。

- 数值上，$X^{\mathsf T}X$ 接近奇异，难以准确求逆，$(X^{\mathsf T}X)^{-1}$ 变得不稳定。
- 统计上，变量之间的含糊增大，系数难以解释；$\operatorname{Cov}(\boldsymbol{b})=\sigma^2(X^{\mathsf T}X)^{-1}$ 的对角元很大，$\operatorname{Var}(b_k)$ 膨胀；第 I 类与第 II 类平方和不同，方差分析的 $F$ 检验与 $t$ 检验结论不一致。

解决了统计问题，数值问题也随之解决。

![在 2000 个模拟数据集上最小二乘估计 (b1, b2) 的抽样分布，真实系数都是 (1, 1)：解释变量不相关时估计构成一团小而圆的点云；相关系数为 0.95 时点云是沿 b1 + b2 = 2 的狭长椭圆，每个系数都很不确定，而二者之和却被很好地确定](./plots/collinearity-sampling.py)

**例 10.1.3** 给例 10.1.2 的精确关系加一点噪声，$\mathrm{hs1}=\mathrm{hs}+0.05\,Z$，$Z$ 服从标准正态分布，拟合 gpa $\sim$ hsm + hss + hse + hs1。

| | 不含 hs1：估计（标准误） | 含 hs1：估计（标准误） |
|---|---|---|
| hsm | $0.169$ $(0.035)$ | $-0.308$ $(0.316)$ |
| hss | $0.034$ $(0.038)$ | $-0.429$ $(0.308)$ |
| hse | $0.045$ $(0.039)$ | $-0.425$ $(0.312)$ |
| hs1 | | $1.410$ $(0.930)$ |
| $R^2$、$R_a^2$ | $0.2046$、$0.1937$ | $0.2128$、$0.1985$ |

三门成绩系数的标准误增大到约九倍，三个系数全部变号，hsm 不再显著。hsm、hss、hse 的序贯平方和不变（$25.81$、$1.24$、$0.67$），hs1 增加 $1.12$；但 hsm、hss、hse 的第 II 类平方和降到 $0.46$、$0.95$、$0.90$。与此同时，$R^2$ 和拟合值几乎不变；加入变量时 $R^2$ 总是增大，这里连 $R_a^2$ 也增大了。

多重共线性的影响可以总结如下：回归系数估计得不好，可能毫无意义，它们的标准误也是如此；第 I 类与第 II 类平方和不同；$R^2$ 和预测值通常没有问题；存在过拟合的风险（[3.3.11](/3.3.11)）。要问一问分析的目的是什么。若是在数据范围内做预测，共线性关系不大，增大样本量是可行的补救办法；若是做解释，共线性就是真正的问题。

**例 10.1.4** 对体脂数据，三个两变量模型为

| 模型 | 系数（$t$） | $R_a^2$ |
|---|---|---|
| 皮褶 + 大腿 | $0.222$ $(0.73)$，$0.659$ $(2.27)$ | $0.752$ |
| 皮褶 + 上臂 | $1.001$ $(7.80)$，$-0.431$ $(-2.44)$ | $0.761$ |
| 大腿 + 上臂 | $0.851$ $(7.57)$，$0.096$ $(0.60)$ | $0.749$ |

从可解释性看，皮褶 + 上臂更好：两个系数都显著，$R_a^2$ 也最大。相关系数达 $0.92$ 的皮褶与大腿不应放在同一个模型中。

## 10.2. 补救措施

### 10.2.1. 删除变量

目标是精简一个解释变量有冗余的模型。可能的做法有：在不同的试验或观测条件下收集更多数据，使变量之间的相关减弱；用变量的不相关组合代替它们（**主成分分析**，[3.4.5](/3.4.5)，以及**主成分回归**，[3.4.7](/3.4.7)）；选择变量，删去一些预测变量（[3.3.11](/3.3.11)）；或者变换变量（10.2.2 节）。删除变量之前必须先问：如果遗漏了一个重要变量，会怎样？

**定理 10.2.1（遗漏变量偏差）** 设真实模型为 $\boldsymbol{Y}=X\boldsymbol{\beta}+W\boldsymbol{\gamma}+\boldsymbol{\varepsilon}$，$\mathbb{E}(\boldsymbol{\varepsilon})=\boldsymbol{0}$，$\operatorname{Cov}(\boldsymbol{\varepsilon})=\sigma^2I_n$，其中 $X$（$n\times p$，含截距）与 $W$（$n\times q$）固定，$(X,W)$ 列满秩；但我们只用 $X$ 拟合 $\boldsymbol{Y}$，得到 $\boldsymbol{b}_X=(X^{\mathsf T}X)^{-1}X^{\mathsf T}\boldsymbol{Y}$ 和 $\mathrm{MSE}_X$。则

1. $\mathbb{E}(\boldsymbol{b}_X)=\boldsymbol{\beta}+(X^{\mathsf T}X)^{-1}X^{\mathsf T}W\boldsymbol{\gamma}$；
2. $\operatorname{Cov}(\boldsymbol{b}_X)=\sigma^2(X^{\mathsf T}X)^{-1}$，它（在半正定序下）小于完全模型中 $X$ 的系数的协方差矩阵 $\sigma^2\big(X^{\mathsf T}(I_n-H_W)X\big)^{-1}$，其中 $H_W$ 是 $W$ 的帽子矩阵；
3. $\mathbb{E}(\mathrm{MSE}_X)=\sigma^2+\dfrac{\boldsymbol{\gamma}^{\mathsf T}W^{\mathsf T}(I_n-H_X)W\boldsymbol{\gamma}}{n-p}\ge\sigma^2$。

**证明** (1) $\mathbb{E}(\boldsymbol{b}_X)=(X^{\mathsf T}X)^{-1}X^{\mathsf T}(X\boldsymbol{\beta}+W\boldsymbol{\gamma})$。(2) 协方差的计算同 [3.3.8](/3.3.8)；由 [3.3.9](/3.3.9) 的定理 9.3.1，完全模型中 $X$ 的系数为 $(X^{\mathsf T}M_WX)^{-1}X^{\mathsf T}M_W\boldsymbol{Y}$（$M_W=I_n-H_W$），其协方差为 $\sigma^2(X^{\mathsf T}M_WX)^{-1}$；而 $X^{\mathsf T}H_WX$ 半正定，故 $X^{\mathsf T}M_WX\preceq X^{\mathsf T}X$。(3) 对 $A=I_n-H_X$ 与 $\boldsymbol{\mu}=X\boldsymbol{\beta}+W\boldsymbol{\gamma}$ 应用 $\mathbb{E}(\boldsymbol{Y}^{\mathsf T}A\boldsymbol{Y})=\operatorname{tr}(A\Sigma)+\boldsymbol{\mu}^{\mathsf T}A\boldsymbol{\mu}$，得 $\mathbb{E}(\mathrm{SSE}_X)=(n-p)\sigma^2+\boldsymbol{\gamma}^{\mathsf T}W^{\mathsf T}(I_n-H_X)W\boldsymbol{\gamma}$。$\square$

所以，遗漏重要变量会使留下的变量的系数产生偏差（除非遗漏的变量与它们正交，$X^{\mathsf T}W=O$），并使 $\sigma^2$ 的估计偏大。若 $W$ 与 $X$ 正交，则 $\boldsymbol{b}_X$ 无偏、方差不变，但 $\sigma^2$ 仍被高估，估计的标准误偏大。另一方面，遗漏一个与 $X$ 高度共线的变量可以大大减小方差。这时相关的准则是**均方误差** $\mathbb{E}\|\boldsymbol{b}_X-\boldsymbol{\beta}\|^2$，即偏差的平方加方差：遗漏一个高度共线的变量*可能*使它减小，这是**偏差–方差权衡**的一个例子。作为偏差的例子：若真实模型为 $Y=X^2-10X+30+\varepsilon$，而 $X$ 的取值远大于 $5$，则只用 $X$ 对 $Y$ 回归会得到正的斜率（比如 $21.3$），尽管真实模型中 $X$ 的系数是 $-10$。

**定义 10.2.1（Simpson 悖论）** **Simpson 悖论**是指：在若干组的每一组内都成立的两个变量之间的关联，在把各组合并之后消失甚至反转。

用回归的语言说，$Y$ 对 $X$ 的回归遗漏了组别变量。如果各组在 $X$ 和 $Y$ 上都有差异，合并后的斜率可能与组内共同的斜率符号相反（下图左）。这个悖论在社会科学和医学统计中屡见不鲜，当频数数据被不恰当地赋予因果解释时尤其成问题。

![一个连续变量 X 与一个组别示性变量。左：Simpson 悖论，每组内的回归直线斜率为正，而忽略分组的合并直线斜率为负。中：可加模型，两条截距不同的平行直线。右：交互作用模型，两条斜率不同的直线](./plots/groups-and-interaction.py)

### 10.2.2. 多项式回归

变换可以减轻共线性，也可能制造共线性。对解释变量最常见的变换就是加入它们的幂。

**定义 10.2.2（多项式回归模型）** **多项式回归**模型把解释变量的幂作为额外的解释变量，例如一个变量的二次模型 $Y_i=\beta_0+\beta_1X_i+\beta_2X_i^2+\varepsilon_i$，或两个变量的二阶模型

$$
Y_i=\beta_0+\beta_1X_{i1}+\beta_2X_{i2}+\beta_{11}X_{i1}^2+\beta_{22}X_{i2}^2+\beta_{12}X_{i1}X_{i2}+\varepsilon_i.
$$

这个模型对参数仍是线性的，所以 [3.3.7](/3.3.7)–[3.3.9](/3.3.9) 的全部理论都适用。问题在于一个变量与它的幂一般高度相关，所以多项式回归会造成多重共线性。

**例 10.2.1（电池）** 在一项设计好的试验中，研究电池寿命 $Y$（直到失效的充放电循环次数）如何依赖于充电速率 $X_1$（三个水平 $0.6$、$1.0$、$1.4$）和温度 $X_2$（三个水平 $10$、$20$、$30$），共 $n=11$ 个电池：$3\times3$ 网格的四个角点和四条边的中点各一次，中心点 $(1.0,20)$ 三次。试验设计在幕后就是回归分析；不简单的是计划时要做的种种选择：检验哪些 $X$、选什么范围、重复多少次、是否需要中心点（[3.8](/3.8)）。我们拟合二阶模型：

```r
b1$chrate2 <- b1$chrate^2
b1$temp2 <- b1$temp^2
b1$ct <- b1$chrate * b1$temp
reg5 <- lm(cycles ~ chrate + temp + chrate2 + temp2 + ct, data = b1)
```

总体 $F$ 检验显著（$F^*=10.57$，自由度 $(5,5)$，$p=0.011$，$R^2=0.914$），但单个 $t$ 检验都不显著（$p$ 值在 $0.10$ 到 $0.62$ 之间）：这是多重共线性问题。确实，$r(X_1,X_1^2)=0.991$，$r(X_2,X_2^2)=0.986$；一个变量的各次幂之间高度相关是常见的。

补救办法是中心化：先减去均值再平方。中心化后的变量有正有负；像这里这样关于均值对称的设计，中心化后的变量与它的平方恰好不相关。做法是：对解释变量做中心化（R 中的 `scale()`；标准化也可以，但关键是减去均值），用中心化后的变量重新计算平方和交叉乘积，再重新做回归。

```r
b1$schrate <- scale(b1$chrate)
b1$stemp <- scale(b1$temp)
reg6 <- lm(cycles ~ schrate + stemp + I(schrate^2) + I(stemp^2) + I(schrate * stemp), data = b1)
```

| 项 | 估计 | 标准误 | $t$ | $p$ 值 |
|---|---|---|---|---|
| 截距 | $162.84$ | $16.61$ | $9.81$ | $0.0002$ |
| 充电速率 | $-43.25$ | $10.24$ | $-4.22$ | $0.008$ |
| 温度 | $58.48$ | $10.24$ | $5.71$ | $0.002$ |
| 充电速率的平方 | $16.44$ | $12.20$ | $1.35$ | $0.236$ |
| 温度的平方 | $-6.36$ | $12.20$ | $-0.52$ | $0.624$ |
| 乘积项 | $6.90$ | $9.71$ | $0.71$ | $0.509$ |

现在一次项明显显著，二阶项不显著。对三个二阶项的一般线性检验给出 $F^*=0.78$（自由度 $(3,5)$），$p=0.553$，所以一阶模型 $\hat Y=160.58-139.58X_1+7.55X_2$（$R^2=0.873$）就足够了。

中心化模型的序贯方差分析表与原来*完全*相同（$18704$、$34201$、$1646$、$285$、$529$，残差 $5240$）。这并非巧合：列空间的序列是相同的。例如 $\{1,X_1\}$ 与 $\{1,X_1-\bar X_1\}$ 张成同一个空间，而 $(X_1-\bar X_1)^2=X_1^2-2\bar X_1X_1+\bar X_1^2$ 位于 $\{1,X_1,X_1^2\}$ 张成的空间中，所以每个序贯额外平方和以及拟合值都不变。最高次项的 $t$ 检验也不变；中心化改变的是低次项的系数和 $t$ 检验。

这一观察解释了试验设计中的一条规则：通常不宜在去掉高次项之前去掉低次项，即使低次项不显著（层次原则，hierarchy principle）。对 $X$ 做平移，会改变除最高次项以外所有项的 $t$ 统计量，因此低次项是否显著取决于任意选定的原点。去掉低次项相当于强加一种特殊结构：正如令截距为零迫使回归线过原点，在 $y=a_0+a_1x+a_2x^2$ 中令 $a_1=0$ 得到 $y=a_0+a_2(x-0)^2$，其极值点在 $x=0$。

对更高次幂，中心化就不够了：$r(X_1,X_1^3)=0.969$；而对三个对称水平 $-a,0,a$ 上中心化的变量，甚至有 $(X_1-\bar X_1)^3=a^2(X_1-\bar X_1)$，这是精确的共线性（只有三个水平时，每个变量至多能拟合二次项）。一般地，R 的 `poly(x, degree)` 或 `polym(x1, x2, degree = 2)` 生成正交多项式（orthogonal polynomials），即各列彼此正交的 $X$ 的多项式，从根本上避免了各次幂之间的共线性；拟合值和序贯平方和同样不变。

## 10.3. 交互作用模型

### 10.3.1. 交互作用

一阶模型假定各解释变量对平均响应的作用是可加的：在 $X_2$ 的每个取值处，$X_1$ 每增加一个单位 $\mathbb{E}(Y)$ 的变化都相同。有多个解释变量时，必须考虑一个变量的作用依赖于另一个变量取值的可能性。

**定义 10.3.1（交互效应）** 若 $X_1$ 对平均响应的作用依赖于 $X_2$ 的取值，则称两个解释变量 $X_1$、$X_2$ 对 $Y$ 有**交互效应**。在回归模型中，它由

$$
Y_i=\beta_0+\beta_1X_{i1}+\beta_2X_{i2}+\beta_3X_{i1}X_{i2}+\varepsilon_i
$$
中的乘积项表示；不含乘积项的模型称为可加模型。

我们考虑两种情形：一个连续变量与一个二值（是/否）变量，以及两个连续变量。

### 10.3.2. 一个连续变量与一个组别示性变量

设 $X_1$ 连续，$X_2$ 对第 1 组取 $0$、对第 2 组取 $1$。交互作用模型对每组给出一条直线：

$$
X_2=0\colon\ \mathbb{E}(Y)=\beta_0+\beta_1X_1,\qquad X_2=1\colon\ \mathbb{E}(Y)=(\beta_0+\beta_2)+(\beta_1+\beta_3)X_1.
$$
因此

- $H_0\colon\beta_2=\beta_3=0$ 检验两组的回归直线是否相同；
- $H_0\colon\beta_3=0$ 检验斜率是否相同，即两条直线是否平行（没有交互作用）；
- $H_0\colon\beta_2=0$ 检验在斜率可能不同时截距是否相同。

每一个都是 [3.3.9](/3.3.9) 的一般线性检验，而 $\beta_3=0$ 的检验就是乘积项的 $t$ 检验。因此交互作用意味着直线不平行：直线的斜率依赖于组别（10.2.1 节图中的中图和右图）。

**例 10.3.1（创新的采用）** 对 $20$ 家保险公司，$Y$ 是公司采用一项创新所用的月数，$X_1$ 是公司规模（连续），$X_2$ 是公司类型（相互保险公司为 $0$，股份公司为 $1$）。不论公司规模大小，股份公司采用创新是更慢还是更快？按类型着色的散点图（`ggplot()` 加 `geom_smooth()`）显示两条截距不同、斜率相近的直线。

```r
a1$sizestock <- a1$size * a1$stock
reg1 <- lm(months ~ size + stock + sizestock, data = a1)
reg2 <- lm(months ~ size, data = a1)
anova(reg2, reg1)    # H0: beta_2 = beta_3 = 0 (same line)
summary(reg1)        # t-test of sizestock: H0: beta_3 = 0 (parallel lines)
```

共同直线的检验中，$\mathrm{SSE}=492.63$（自由度 $18$）对 $176.38$（自由度 $16$），$F^*=14.34$，$p=0.0003$：两组的线性关系不同。在交互作用模型中，乘积项的 $b_3=-0.0004$，$t=-0.02$（$p=0.98$）：没有证据反对平行直线。stock 的系数 $8.13$（$t=2.23$，$p=0.041$）估计的是规模为 $0$ 处两条直线截距之差，这超出了数据范围；把规模中心化后，它变成平均规模处的差 $8.06$，标准误从 $3.65$ 降为 $1.50$（$t=5.36$），比较更精确、也更有意义。

可加模型给出 $\hat Y=33.87-0.1017X_1+8.06X_2$：共同斜率为每单位规模 $-0.10$ 个月（$t=-11.4$），股份公司平均多用 $8.06$ 个月（$t=5.52$，$p=3.7\times10^{-5}$），其截距为 $33.87+8.06=41.93$。

```r
reg5 <- lm(months ~ size + stock, data = a1)
beta <- coef(reg5)
ggplot(a1, aes(size, months, color = as.factor(stock))) +
  geom_point() +
  geom_abline(intercept = beta[1], slope = beta[2]) +              # mutual firms
  geom_abline(intercept = beta[1] + beta[3], slope = beta[2])      # stock firms
```

### 10.3.3. 两个连续变量

有两个连续变量时，交互作用模型可以改写成两种形式：

$$
Y=\beta_0+(\beta_1+\beta_3X_2)X_1+\beta_2X_2+\varepsilon=\beta_0+\beta_1X_1+(\beta_2+\beta_3X_1)X_2+\varepsilon.
$$
$X_1$ 的系数是 $X_2$ 的线性函数，反之亦然：响应曲面不再是平面，而是一张扭曲的曲面，它在固定 $X_2$ 处的截线是斜率为 $\beta_1+\beta_3X_2$ 的直线。特别地，$\beta_1$ 只是 $X_2=0$ 处 $X_1$ 的作用，这是在构造乘积项之前先对变量中心化的又一个理由，与例 10.2.1 一样。组别示性变量与多个连续变量的交互作用，以及多个因子的交互作用，引出 [3.3.12](/3.3.12)–[3.3.14](/3.3.14) 的方差分析。

## 小结

| 设计 | 估计 | 平方和 | 后果 |
|---|---|---|---|
| 正交（$r_{jk}=0$） | $b_k=(s_Y/s_k)r_{Yk}$，与其他变量无关；方差最小 | 第 I、II、III 类相同 | 最优；只有 $p$ 值随模型变化（通过 $\mathrm{MSE}$） |
| 退化（精确线性关系） | $(X^{\mathsf T}X)^{-1}$ 不存在；不唯一 | 无定义（混淆） | 删去多余的变量；混杂依然存在 |
| 一般（强相关） | 无偏但方差膨胀，不稳定，可能变号 | 第 I 类与第 II 类不同 | $F$ 检验与 $t$ 检验不一致；预测无碍，解释困难 |

- 遗漏重要变量 $W$ 使 $\boldsymbol{b}_X$ 产生偏差 $(X^{\mathsf T}X)^{-1}X^{\mathsf T}W\boldsymbol{\gamma}$，并使 $\mathrm{MSE}$ 偏大，但可能减小方差；Simpson 悖论是关联反转的极端情形。
- 多项式项与原变量高度相关；中心化消除大部分相关，而不改变拟合值和序贯平方和；保留高次项时要保留低次项；正交多项式从根本上避免了这个问题。
- 交互效应用乘积项表示；有组别示性变量时它意味着直线不平行，"同一直线""平行直线""截距相同"等假设都是一般线性检验。
