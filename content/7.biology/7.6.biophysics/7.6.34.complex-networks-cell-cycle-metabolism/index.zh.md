上一章的回路只有两三个组分。真实的调控与代谢网络有数百到数千个组分，并产生了小回路中不会出现的两个问题。第一个是统计的：这类网络的整体结构如何，它与随机连线有区别吗？第二个是动力学的：不知道全部速率常数，能否理解大网络的行为？本章对三个已成为范例的体系回答这两个问题。细胞周期（34.2）是理解得最透彻的调控网络；我们用三种分辨率处理它：双变量振子、酵母周期的微分方程模型，以及布尔网络，后者的全局**吸引子**就是细胞的静息状态。果蝇胚胎的缺口基因网络（34.3）在发育中展示同样的思想。代谢（34.4）太大，动力学又了解得太少，不宜用微分方程，因此改用通量平衡分析，它只用化学计量、质量守恒与一个最优化原理。

本章使用图论的词汇，即度、路径、**邻接矩阵**与连通性（[1.4.1](/1.4.1)，[1.4.2](/1.4.2)），[2.4.11](/2.4.11) 的稳定性理论，以及 [7.6.33](/7.6.33) 的工具：**零倾线**、**双稳态**与**滞后**、**弛豫振子**与吸引子。细胞周期控制系统的生物学见 [7.3.20](/7.3.20) 与 [7.3.22](/7.3.22)，胚胎振子的三变量模型见 [7.3.20](/7.3.20#sec-20.6)；果蝇的分节基因见 [7.5.15](/7.5.15)；代谢途径、其调控以及**代谢控制分析**见 [7.1.17](/7.1.17)。*E. coli* 转录网络的统计及其网络基序（前馈环、单输入模块、稠密重叠的**调节子**）、网络的**模块性**与进化以及由组学数据推断网络属于[系统生物学](/7.9)，这里不讨论。细胞周期网络及其他网络对参数与连线扰动的**稳健性**是 [7.6.40](/7.6.40) 的主题，而解释**溢流代谢**的代谢蛋白质组成本见 [7.6.39](/7.6.39)。

## 34.1. 复杂网络的结构

### 34.1.1. 五个特征

由基因、蛋白质、代谢物、细胞与物种构成的生物网络有若干共同特征，使它们区别于工程回路与随机图：

| 特征 | 含义 | 例子 |
|---|---|---|
| 非线性相互作用 | 响应是 S 形的、饱和的或有阈值的，而不是成比例的 | 协同结合、**超敏性**、开关 |
| 自组织 | 有序状态与图案在没有模板的情况下由局部相互作用涌现 | 振荡、空间图案（[7.6.36](/7.6.36)）、集体运动（[7.6.37](/7.6.37)） |
| 异质性 | 少数节点有许多连接，大多数很少；连接聚成模块 | 蛋白质相互作用网络中的枢纽；代谢中的通用货币分子（ATP、NADH） |
| 非平衡动力学 | 网络靠自由能通量维持，从不处于平衡 | 代谢通量、磷酸化循环（[7.6.38](/7.6.38)） |
| 多尺度 | 分子、细胞、组织与群体尺度上的相互作用相互耦合 | 基因表达控制细胞力学，细胞力学控制组织形状 |

异质性可以用图的若干统计量来量化。

### 34.1.2. 度分布

**定义 34.1.1（度分布）** 网络的**度分布** $P(k)$ 是度为 $k$ 的顶点所占的比例（度是顶点上的边数；对有向网络，分别定义入度与出度分布）。

在 Erdős 与 Rényi 的随机图中，$N$ 个顶点的 $\binom{N}{2}$ 个顶点对各自独立地以概率 $p$ 相连。顶点的度服从均值为 $\langle k\rangle = p(N - 1)$ 的二项分布，当 $N$ 很大、$\langle k\rangle$ 固定时是 Poisson 分布：度集中在均值附近，连接数远多于平均的顶点呈指数地稀少。实测的网络不同。在酵母的蛋白质相互作用网络（Jeong、Mason、Barabási 与 Oltvai，2001）、代谢网络（Jeong、Tombor、Albert、Oltvai 与 Barabási，2000）、万维网和引文网络中，度分布有长尾，在一两个数量级上近似为幂律。

**定义 34.1.2（无标度网络）** **无标度网络**是度分布按幂律衰减的网络，即大 $k$ 时 $P(k) \propto k^{-\gamma}$，通常 $2 < \gamma < 3$；它没有特征度，少数高度连接的顶点（枢纽）承载了很大一部分边。

Barabási 与 Albert（1999）表明，两个要素产生这类网络：增长，即随时间加入新顶点；以及偏好连接，即新顶点以正比于现有顶点度的概率与之相连。若每个新顶点带 $m$ 条边，则平稳的度分布为
$$
P(k) = \frac{2m(m + 1)}{k(k + 1)(k + 2)} \sim 2m^2k^{-3}. \tag{34.1}
$$
在生物学中，基因复制后再分化是同类的机制：复制的基因继承其亲本的相互作用伙伴，所以伙伴多的蛋白质获得新伙伴的数目与其已有数目成正比（Vázquez、Flammini、Maritan 与 Vespignani，2003）。

为推导式 (34.1)，设每单位时间加入一个顶点，各带 $m$ 条边，则 $t$ 步后总度为 $2mt$。度为 $k$ 的顶点从每个新顶点获得一条边的概率为 $mk/(2mt) = k/(2t)$。于是度为 $k$ 的顶点的期望数 $N_k(t)$ 对 $k > m$ 满足 $N_k(t + 1) - N_k(t) = \frac{(k-1)N_{k-1} - kN_k}{2t}$，另外还新增一个度为 $m$ 的顶点。在平稳区 $N_k = tP(k)$，所以 $P(k) = \frac12[(k - 1)P(k - 1) - kP(k)]$，即 $P(k)/P(k - 1) = (k - 1)/(k + 2)$，从 $m$ 到 $k$ 连乘，并利用 $k = m$ 的方程得 $P(m) = 2/(m + 2)$，即得式 (34.1)。

对生物网络的幂律描述必须谨慎使用。相互作用图谱是不完整的，且偏向研究充分的蛋白质；在一两个数量级上拟合的幂律很难与其他重尾分布区分；严格的检验表明，只有少数网络有无标度结构的强证据（Broido 与 Clauset，2019）。稳健的结论是异质性：度跨越几个数量级变化，远大于随机图。

### 34.1.3. 聚类与小世界

**定义 34.1.3（聚类系数）** 有 $k \geq 2$ 个邻居的顶点的局部**聚类系数**，是其邻居的 $\binom{k}{2}$ 个对中本身也相邻的比例，$C_i = 2T_i/(k_i(k_i - 1))$，其中 $T_i$ 是经过 $i$ 的三角形数；网络的聚类系数 $C$ 是对顶点的平均。

在无向图中 $T_i = \frac12(A^3)_{ii}$，即从 $i$ 出发的长度为 3 的闭途径数除以 2（[1.4.2](/1.4.2)）。在 Erdős–Rényi 图中 $C = p = \langle k\rangle/(N - 1)$，对大的稀疏网络它趋于零；在生物、社会与技术网络中 $C$ 大几个数量级，因为相互作用的伙伴倾向于彼此相互作用（蛋白质复合物、代谢模块）。同时，顶点之间的平均最短路径长度 $L$ 很小，接近随机图的值 $L \approx \ln N/\ln\langle k\rangle$：任何一个代谢物都可以通过三四步反应转化为几乎任何另一个（Jeong 等，2000）。

**定义 34.1.4（小世界网络）** **小世界网络**是这样的网络：其聚类系数远大于顶点数和边数相同的随机图，而平均最短路径长度与随机图相当，只随顶点数对数增长。

Watts 与 Strogatz（1998）表明所需的随机性是多么少。从每个顶点与其 $k$ 个最近邻相连的环出发（高聚类，路径长度 $L \approx N/2k$，正比于 $N$），他们以概率 $p$ 随机重连每条边。少数捷径就足以把 $L$ 缩小到随机图的值，同时保留大部分三角形，因此在 $p$ 的很宽的范围内网络是小世界（图 B 栏）。在生物学中，短路径意味着扰动可以在几步内传遍整个网络，聚类意味着大多数相互作用是局部的、位于模块之内；二者合起来就是细胞既模块化又整合的组织方式的图论表达。

### 34.1.4. 对失效与攻击的稳健性

度分布决定了移除顶点时网络如何瓦解。从无标度网络中随机移除顶点很少会击中枢纽，最大连通分量缩小得很慢；先移除枢纽（针对性攻击）则会使它迅速碎裂。没有枢纽的随机图对两者的响应相同（Albert、Jeong 与 Barabási，2000）。在酵母中，相互作用伙伴多的蛋白质比连接少的蛋白质更常是必需的（Jeong 等，2001），后来的分析把这种相关性部分归因于枢纽属于必需复合物，而不是其连接度本身（Zotenko、Mestre、O'Leary 与 Przytycka，2008）。图的结构稳健性不同于它所支持的动力学的功能稳健性，后者取决于相互作用的符号与强度；后者在 34.2.3 与 [7.6.40](/7.6.40) 中讨论。

## 34.2. 细胞周期网络

### 34.2.1. 胚胎振子的双变量模型

蛙胚早期的细胞周期自主运行，每 $25$–$30\,\mathrm{min}$ 一次，没有检查点（[7.3.20](/7.3.20#sec-20.6.1)）。核心是周期蛋白 B–Cdk1，它由周期蛋白的持续合成及其通过 **Cdc25** 与 **Wee1** 的自身正反馈激活；以及 APC/C–Cdc20，它被 Cdk1 延迟地激活并降解周期蛋白 B。Ferrell、Tsai 与 Yang（2011）把它简化为 Cdk1 的活性比例 $C$ 与 APC/C 的活性比例 $A$ 的两个方程：
$$
\begin{aligned}
\frac{\mathrm{d}C}{\mathrm{d}t} &= \alpha_1 - \beta_1C\,\frac{A^n}{K^n + A^n} + \alpha_3(1 - C)\frac{C^n}{K^n + C^n}, \\
\frac{\mathrm{d}A}{\mathrm{d}t} &= \alpha_2(1 - A)\frac{C^n}{K^n + C^n} - \beta_2A.
\end{aligned} \tag{34.2}
$$
第一项是周期蛋白合成对 Cdk1 的激活，第二项是 APC/C 降解周期蛋白对它的失活，第三项是被压缩成自激活的正反馈；APC/C 被 Cdk1 激活，并以恒定速率失活。

相平面解释了这些动力学。APC/C 零倾线 $A = \alpha_2H(C)/(\alpha_2H(C) + \beta_2)$（$H$ 为 Hill 函数）是单调的 S 形。由于正反馈，Cdk1 零倾线是 S 形（或 N 形）：在一段 APC/C 活性范围内，Cdk1 有三个稳态，外侧两个稳定，中间一个不稳定，这就是 Cdk1 的双稳开关（[7.3.20](/7.3.20#sec-20.6.3)）。两条零倾线只相交一次，在中间分支上，是一个不稳定不动点。所有轨迹都进入单位正方形 $[0, 1]^2$ 并留在其中，所以由 Poincaré–Bendixson 定理（[2.4.11](/2.4.11#thm-11.6.1)），不动点周围存在极限环：这是弛豫型的振荡，Cdk1 升高、开启、激活 APC/C，然后被关闭（[7.6.33](/7.6.33#sec-33.5.4)）。没有正反馈（$\alpha_3 = 0$）时，Cdk1 零倾线是单调的，对这些参数不动点是稳定的：仅有负反馈只给出阻尼振荡，这就是用不可磷酸化的 Cdk1 所做实验的结果（Pomerening、Kim 与 Ferrell，2005）。正环增加了稳健性：振荡在更宽的参数范围内持续，其振幅几乎与周期无关，周期可由周期蛋白的合成速率调节（Tsai、Byun、Ferrell 等，2008）。

### 34.2.2. 酵母中的拮抗与滞后

体细胞的细胞周期不是自由运行的钟，而是由生长和检查点把关的一系列不可逆转变。在出芽酵母与裂殖酵母中，细胞只有在长到临界大小之后才分裂，大小控制的核心是一种相互拮抗：B 型周期蛋白–Cdk（CycB）磷酸化并使 Cdh1 失活，Cdh1 是 APC/C 的激活因子，靶向周期蛋白 B 使之降解（并抑制化学计量抑制物 Sic1），而 Cdh1 降解周期蛋白 B。Tyson 与 Novák（2001）把这种拮抗写成
$$
\begin{aligned}
\frac{\mathrm{d}[\mathrm{CycB}]}{\mathrm{d}t} &= k_1 - (k_2' + k_2''[\mathrm{Cdh1}])[\mathrm{CycB}], \\
\frac{\mathrm{d}[\mathrm{Cdh1}]}{\mathrm{d}t} &= \frac{(k_3' + k_3''[\mathrm{Cdc20}_{\mathrm{A}}])(1 - [\mathrm{Cdh1}])}{J_3 + 1 - [\mathrm{Cdh1}]} - \frac{k_4\,m\,[\mathrm{CycB}][\mathrm{Cdh1}]}{J_4 + [\mathrm{Cdh1}]},
\end{aligned} \tag{34.3}
$$
其中 $m$ 是细胞质量，它乘在周期蛋白的活性上，因为较大的细胞中每个基因对应更多的周期蛋白–Cdk；Cdh1 被磷酸化而失活、被磷酸酶而激活，二者遵循 Michaelis 常数 $J_3, J_4$ 很小的 Michaelis–Menten 动力学，使响应呈开关式（**零级超敏**，[7.1.9](/7.1.9)）。完整的模型还加入了 Cdc20（它因 CycB 而合成，并通过一个中间酶延迟地被激活），以及质量的生长和分裂时的减半。

当 Cdc20 失活时，式 (34.3) 的稳态随 $m$ 构成 S 形曲线（图 A 栏）：Cdh1 活跃而 CycB 低的 G1 状态，只存在于小细胞；Cdh1 失活而 CycB 高的 S/G2/M 状态，只在更小的临界质量以上存在；以及它们之间的不稳定分支。细胞周期就是对这个**滞后**环的一次遍历。新生的细胞处于 G1；随着生长，$m$ 越过 G1 状态消失的鞍结点（对图中的参数，$m \approx 0.53$），细胞不可逆地跳到高 CycB：这就是**起始点**，即对细胞周期的承诺。由于 S/G2/M 状态在更小的质量下仍然存在，使 $m$ 减半的分裂本身无法使细胞回到 G1。相反，高 CycB 激活 Cdc20，后者激活 Cdh1 并降解 CycB，把系统推回环的另一侧，即结束点（Finish），之后细胞分裂，周期重新开始。因此一个拮抗对的两个**鞍结分岔**同时提供了大小控制与转变的不可逆性，而检查点的作用是把系统保持在开关的一侧（例如阻断 Cdc20，直到所有染色体都已附着）。这一观点的预言，即 Cdk 开关的滞后及其不可逆性，已在酵母和蛙提取物中得到检验（[7.3.20](/7.3.20#sec-20.6.3)），Tyson–Novák 模型也被扩展到几十个变量，重现了出芽酵母一百多个突变体的表型（Chen 等，2004）。

### 34.2.3. 布尔网络及其全局吸引子

微分方程模型需要几十个速率常数，其中大多数未经测量。Li、Long、Lu、Ouyang 与 Tang（2004）问：仅凭连线能否决定基本行为。他们选取出芽酵母周期的十一个关键调控因子，即周期蛋白 Cln3、Cln1,2、Clb5,6 与 Clb1,2，转录因子 SBF、MBF、Mcm1/SFF 与 Swi5，APC/C 的激活因子 Cdh1 与 Cdc20（连同磷酸酶 Cdc14），以及抑制物 Sic1，还有它们之间已知的 29 个激活与抑制相互作用。每个节点是布尔变量 $S_i \in \{0, 1\}$，所有节点按阈值规则同时更新：
$$
S_i(t + 1) = \begin{cases} 1, & \sum_ja_{ij}S_j(t) > 0, \\ 0, & \sum_ja_{ij}S_j(t) < 0, \\ S_i(t), & \sum_ja_{ij}S_j(t) = 0, \end{cases} \tag{34.4}
$$
其中 $j$ 激活 $i$ 时 $a_{ij} = +1$，抑制时 $a_{ij} = -1$，而不被任何其他节点抑制的节点（Cln3、Cln1,2、Swi5、Cdc20/Cdc14、Mcm1/SFF）在输入为零时衰减为 $0$，代表它们的降解。细胞大小作为开启 Cln3 的信号进入。

该网络有 $2^{11} = 2048$ 个状态，可以对所有状态计算其动力学。每条轨迹都终止于七个不动点之一，其中一个吸引 $1764$ 个状态，占状态空间的 $86\,\%$（图 C 栏）：它的状态只有 Cdh1 与 Sic1 开启，是静息细胞的 G1 状态。其他吸引子的吸引域都很小（151、109、9、7、7 与 1 个状态）。从被激发的 G1 状态出发，即 Cln3 被大小信号开启，网络经十二步走过生物学各阶段的序列：SBF 与 MBF 及 Cln1,2 的激活（G1 晚期），Sic1 与 Cdh1 的失活，Clb5,6（S 期），Mcm1 与 Clb1,2（G2 与 M 期），Cdc20 与 Swi5，Sic1 与 Cdh1 的回归以及有丝分裂的退出，最后回到 G1（B 栏）。不仅如此，从任意初始状态出发的大多数轨迹都在早期汇入这一序列并沿之前进：生物学途径是全局吸引的轨迹，是状态空间中的漏斗，所以即使状态受到很大的扰动，周期也能正确完成。

Li 等人随后问这有多特殊。在节点数和激活与抑制连接数相同的随机网络中，很少有网络具有吸引域大到 $86\,\%$ 的不动点，吸引力像生物学序列那样强的序列更少；而对真实网络中连接的几乎所有单个删除或添加，大吸引域与途径都得以保持。因此细胞周期网络的稳健性来自它的结构：其功能不依赖于参数的精确值，在这个意义上，该网络是进化为稳定性而设计的。对这种稳健性的分析，对细胞周期和其他网络，在 [7.6.40](/7.6.40) 中继续，布尔描述与连续描述的关系见 [7.5.10](/7.5.10#sec-10.12)。此后人们为许多其他网络建立了布尔模型，从果蝇的体节极性网络（Albert 与 Othmer，2003）到哺乳动物细胞中生长与凋亡之间的决定，并把它们的吸引子与观察到的细胞类型和状态比较，这就使细胞类型是调控网络吸引子的想法（Kauffman，1969）有了精确的含义。

## 34.3. 一个发育网络：缺口基因

在 *Drosophila* 发育的最初三小时中，胚胎是合胞体：十三次核分裂在共同的细胞质表面产生约 $6000$ 个核，转录因子在其中自由扩散（[7.5.14](/7.5.14)，[7.5.15](/7.5.15)）。前后轴由母体梯度确定：由锚定在前极的 mRNA 翻译出的 Bicoid 蛋白形成指数梯度，其**长度常数**约为胚长的 $20\,\%$；Nanos 蛋白形成后部梯度；母源的 *hunchback* 与 *caudal* mRNA 分别受 Nanos 与 Bicoid 的翻译调控。这些输入激活**缺口基因** *hunchback*（*hb*）、*Krüppel*（*Kr*）、*knirps*（*kni*）与 *giant*（*gt*），它们表达在宽的、部分重叠的区域，其产物调控**成对规则基因**，后者的产物又调控体节极性基因，这一层级把胚胎细分为 14 个副体节。

**缺口基因**构成一个网络：它们相互抑制，最强的抑制发生在区域不重叠的基因之间，即 *hb* 与 *kni*、*gt* 与 *Kr*。这种相互抑制使每一对成为拨动开关（[7.6.33](/7.6.33#sec-33.3)），整个网络把平滑的母体梯度锐化为边界清晰的区域并维持它们。缺口基因回路模型是反应–扩散方程组，其合成项形如 $\sigma(\sum_jW_{ij}x_j + m_iB + h_i)$（调控因子与 Bicoid 的加权和的 S 形函数），用定量表达数据拟合，能重现这些区域及其随时间的移动（Jaeger 等，2004），而在这类模型的相空间中，区域的边界对应于 Bicoid 浓度沿轴变化时吸引子之间的转变（Manu 等，2009）。输出的精度极高：由某个核中四种缺口蛋白的综合水平，可以以约为胚长 $1\,\%$、约一个核间距的误差解码出它沿轴的位置（Dubuis、Tkačik、Wieschaus、Gregor 与 Bialek，2013），接近缺口基因水平的噪声所设定的极限。梯度能携带多少**位置信息**，以及读取它的物理极限，见 [7.5.11](/7.5.11) 与 [7.6.35](/7.6.35)。

## 34.4. 代谢网络与通量平衡分析

### 34.4.1. 为什么需要不同的方法

在目前的基因组规模重建中，*E. coli* 的代谢网络在超过 $1000$ 种代谢物之间有超过 $2000$ 个反应（iML1515：$2712$ 个反应、$1877$ 种代谢物与 $1516$ 个基因；Monk 等，2017）。为它写动力学方程需要数千个酶参数，其中大多数未知，许多还依赖于条件。然而每个反应的化学计量是精确知道的，而且在生长的细胞中，大多数细胞内代谢物在数秒内周转，比细胞生长快得多，所以它们的浓度处于准稳态。通量平衡分析只使用这两个事实，并增加了一个关于网络目的的假设。

### 34.4.2. 化学计量矩阵与质量守恒

**定义 34.4.1（化学计量矩阵）** 含 $M$ 个代谢物与 $R$ 个反应的反应网络的**化学计量矩阵** $S$ 是 $M \times R$ 矩阵，其元素 $S_{ij}$ 是代谢物 $i$ 在反应 $j$ 中的化学计量系数：底物为负，产物为正，不参与则为零。代谢物与环境的交换（摄取、排泄）以及前体流向生物量的消耗写成额外的反应。

例如反应 $\ce{B + 2C -> D}$ 贡献一列，在 B 的行为 $-1$，在 C 的行为 $-2$，在 D 的行为 $+1$。设反应速率（通量，单位为每克干重每小时的 $\mathrm{mmol}$）的向量为 $\boldsymbol{v}$，代谢物浓度 $\boldsymbol{c}$ 的变化为
$$
\frac{\mathrm{d}\boldsymbol{c}}{\mathrm{d}t} = S\boldsymbol{v}, \tag{34.5}
$$
在内部代谢物的准稳态下
$$
S\boldsymbol{v} = \boldsymbol{0}. \tag{34.6}
$$
式 (34.6) 是质量守恒：对每个内部代谢物，产生等于消耗。它定义了 $S$ 的零空间，维数为 $R - \operatorname{rank}(S)$（[2.1](/2.1)），在基因组规模的网络中有数百维：仅靠质量守恒，通量仍高度欠定。进一步的约束是对单个通量的界 $v_j^{\min} \le v_j \le v_j^{\max}$：不可逆反应的下界为零（由热力学决定，[6.3](/6.3)），测得的营养物与氧的最大摄取速率，以及已知时的酶容量。可行的通量构成凸多面体，即零空间与一个盒子的交集。稳态通量分布也是超图中的流，式 (34.6) 是流网络顶点处守恒律的类比（[1.4.5](/1.4.5)）。

### 34.4.3. 最优化

**定义 34.4.2（通量平衡分析）** **通量平衡分析**把代谢网络的稳态通量预测为线性规划的解
$$
\max_{\boldsymbol{v}}\ \boldsymbol{c}^{\mathsf T}\boldsymbol{v} \quad \text{subject to} \quad S\boldsymbol{v} = \boldsymbol{0}, \quad \boldsymbol{v}^{\min} \le \boldsymbol{v} \le \boldsymbol{v}^{\max}, \tag{34.7}
$$
其中目标 $\boldsymbol{c}^{\mathsf T}\boldsymbol{v}$ 是假定细胞要最大化的通量，通常是生物量反应的通量，它按细胞组成中测得的比例消耗前体、辅因子与 ATP。

多面体上的线性目标在顶点（或一个面）上取最大，含数千个变量的线性规划用单纯形法或内点法在几毫秒内即可求解（`scipy.optimize.linprog`，[4.4.4](/4.4.4)）。细菌最大化其生长产率的假设，以它们在所生长条件下的进化为依据，但它是可能失效的假设：在其他条件下，相关的目标可能是 ATP 产率、稳健性，或几者的折中。线性规划的对偶给每个代谢物指定一个影子价格，即每增加一单位供应所带来的目标的增加量，它识别出限制性的资源。

**例 34.4.1（中心代谢的玩具模型）** 考虑八个内部代谢物（葡萄糖、丙酮酸、5-磷酸核糖、乙酰辅酶 A、NADH、NADPH、ATP 与氧）以及十一个反应：葡萄糖摄取（至多 $10$）、**糖酵解**（$\ce{Glc -> 2 Pyr}$，伴随 $2$ 个 ATP 与 $2$ 个 NADH）、氧化型磷酸戊糖途径（$\mathrm{Glc} \to \mathrm{R5P} + 2\,\mathrm{NADPH}$）、丙酮酸脱氢酶（$\mathrm{Pyr} \to \mathrm{AcCoA} + \mathrm{NADH}$）、合并的 TCA 循环（$\mathrm{AcCoA} \to 4\,\mathrm{NADH} + \mathrm{ATP}$）、**氧化磷酸化**（$\mathrm{NADH} + \frac12\ce{O2} \to 2.5\,\mathrm{ATP}$，[7.1.23](/7.1.23)）、氧摄取、乳酸与乙酸的排泄、至少为 $1$ 的维持 ATP 需求，以及每单位消耗 $0.2$ R5P、$1.5$ 丙酮酸、$1$ 乙酰辅酶 A、$0.4$ NADPH、$3.5$ NADH 与 $20$ ATP 的生物量反应。求解式 (34.7) 得（见图）：

- 氧不受限时，生长为每单位时间 $5.08$，没有排泄；最优解用掉 $15.9$ 单位的氧。高于此氧供应时只有葡萄糖限制生长；低于此时二者都限制。这条边界在葡萄糖与氧摄取平面上是过原点的直线，即表型相平面的最优线（A 栏）。
- 在线下方，最优解排泄乙酸，氧更低时还排泄乳酸（B 栏）：当呼吸无法使所有 NADH 重新氧化时，细胞通过发酵使其再生，没有氧时它的生长为 $0.93$，不到有氧速率的五分之一，即单靠糖酵解的产率。
- 敲除通过令某个通量为零来模拟（C 栏）。删除葡萄糖摄取、糖酵解、磷酸戊糖途径或丙酮酸脱氢酶会使生长消失：这些反应在此模型中是必需的。删除氧化磷酸化使生长降到 $22\,\%$（发酵式生长），删除 TCA 循环降到 $87\,\%$，而排泄途径在此氧供应下是可有可无的。

### 34.4.4. 检验与扩展

通量平衡分析在基因组规模上的预测以三种方式得到检验。Edwards 与 Palsson（2000）对 *E. coli* 中心代谢的重建，预测了哪些单基因缺失会使其在葡萄糖上的生长消失；对所检验的突变体，$86\,\%$ 的预测与观察到的表型一致。Ibarra、Edwards 与 Palsson（2002）让 *E. coli* 在甘油上生长，这种碳源上它最初的摄取速率位于表型相平面最优线之下；经过约 700 代的适应性进化，进化后的菌株移到了线上，与生长最大化的预言一致，而且不同的重复群体通过不同的路径到达那里。用 ${}^{13}\mathrm{C}$ 标记底物测得的胞内通量表明，在许多（而非全部）条件下，中心代谢的通量接近预测的最优值（Schuetz、Kuepfer 与 Sauer，2007）。

失败之处有启发性。敲除突变体并没有因其新基因型而被选择，它的通量用代谢调整最小化（MOMA）更好预测，MOMA 寻找与野生型最接近的可行通量分布，而不是重新最优化（Segrè、Vitkup 与 Church，2002）。快速生长的 *E. coli* 即使在氧充足时也排泄乙酸（溢流代谢），纯粹的通量平衡分析预测不出这一点，因为每个葡萄糖用呼吸更高效；解释是，每单位 ATP 通量，呼吸比发酵花费更多的蛋白质，所以在总蛋白质组受限时，较便宜的途径在高生长速率下胜出（Basan 等，2015），这种对酶分配的约束是 [7.6.39](/7.6.39) 的主题。由于最优解通常不唯一，通量变异性分析计算在所有最优或近优解上每个通量的范围。调控型通量平衡分析为酶的表达加入布尔规则（Covert、Schilling 与 Palsson，2001），把本节的方法与 34.2.3 的方法结合起来；动态通量平衡分析在相继的线性规划之间更新外部浓度，以跟踪批量生长。通量平衡分析与 [7.1.17](/7.1.17) 的动力学图像互补：**代谢控制分析**问在给定状态附近，通量如何响应酶活性的小变化，而通量平衡分析问哪些状态是可能的、其中哪个是最优的。

## 小结

- 生物网络是非线性、自组织、异质、非平衡且多尺度的（34.1.1）。其结构由重尾而常近似无标度的**度分布**（定义 34.1.1，定义 34.1.2；偏好连接给出 $P(k) \sim 2m^2k^{-3}$，式 (34.1)）、远高于随机图的**聚类系数**（定义 34.1.3）以及短路径即小世界性质（定义 34.1.4）刻画；枢纽使网络对随机失效稳健、对针对性攻击脆弱。

## 思考题

1. 证明 Erdős–Rényi 图的平均聚类系数为 $p$，并计算 $N = 6000$ 个蛋白质、$\langle k\rangle = 6$ 的随机图的 $C$。与同样大小的蛋白质相互作用网络实测的约 $0.1$ 的聚类系数比较，并解释差别的含义。

   **答** 一个顶点的两个邻居相邻的概率是 $p$，与其他一切无关，所以平均 $C_i = p$。由 $\langle k\rangle = p(N - 1)$，$p = 6/5999 = 0.001$。实测值大一百倍：蛋白质的相互作用伙伴倾向于彼此相互作用，因为蛋白质在复合物与通路中起作用。网络是模块化的，而同样密度的随机图完全没有这一性质；聚类是功能组织的标志，而不是密度的标志。

2. 在 Barabási–Albert 模型中，计算度至少为 $k$ 的顶点所占的比例，以及 $N$ 个顶点的网络中的期望最大度。与平均度相同的 Erdős–Rényi 图比较。

   **答** 由式 (34.1)，$\mathbb{P}(K \geq k) = \sum_{j\geq k}2m(m + 1)/(j(j + 1)(j + 2)) = m(m + 1)/(k(k + 1)) \approx m^2/k^2$（相消求和：$\frac{2}{j(j+1)(j+2)} = \frac{1}{j(j+1)} - \frac{1}{(j+1)(j+2)}$）。最大度出现在 $N\mathbb{P}(K \geq k) \approx 1$ 处，$k_{\max} \approx m\sqrt N$：对 $m = 3$、$N = 20000$，约为 $420$，与图中一致。在均值为 $6$ 的 Erdős–Rényi 图中，Poisson 尾部给出 $N\mathbb{P}(K \geq k) \approx 1$ 的 $k \approx 18$–$20$。重尾产生度随网络大小增长的枢纽。

3. 对式 (34.2)，证明单位正方形 $[0, 1]^2$ 是不变的，且若其中唯一的不动点不稳定，则存在极限环。对三变量模型，Poincaré–Bendixson 定理的哪个假设会失效？

   **答** 考虑稍微放大的正方形的各边：在 $C = 0$ 上，$\dot C = \alpha_1 > 0$；在 $A = 0$ 上，$\dot A \geq 0$；在 $A = 1$ 上，$\dot A = -\beta_2 < 0$。在 $C = 1$ 上，反馈项为零，$\dot C = \alpha_1 - \beta_1H(A)$，在 $A$ 小时为正；但对 $C = 1 + \varepsilon$，反馈项 $\alpha_3(1 - C)H(C) \approx -\alpha_3\varepsilon$ 为负，当 $\varepsilon > \alpha_1/\alpha_3 \approx 0.03$ 时它压过 $\alpha_1$，所以矩形 $[0, 1.04] \times [0, 1]$ 是不变的（模型在 $C = 1$ 稍上方就失去意义，但数学论证只需要一个有界的不变区域）。若其中唯一的不动点不稳定，去掉它周围的一个小圆盘：轨迹进入由此得到的环形区域并留在其中，Poincaré–Bendixson 定理（[2.4.11](/2.4.11#thm-11.6.1)）保证存在闭轨道。该定理只在平面上成立：在三维中，没有不动点的有界轨迹可以是准周期的或混沌的，所以振荡的存在必须另行证明（例如用 Hopf 分岔或模拟）。

4. 用 $[\mathrm{Cdc20}_{\mathrm{A}}] = 0$ 的式 (34.3)，推导稳态曲线 $m([\mathrm{Cdh1}])$ 的参数形式，并解释起始点的大小阈值如何依赖于周期蛋白合成速率 $k_1$。这对过表达周期蛋白 B 的突变体预测了什么？

   **答** 由 $\dot{[\mathrm{CycB}]} = 0$，$[\mathrm{CycB}] = k_1/(k_2' + k_2''H)$，$H = [\mathrm{Cdh1}]$；由 $\dot H = 0$，$m = k_3'(1 - H)(J_4 + H)/[(J_3 + 1 - H)k_4[\mathrm{CycB}]H]$。由于固定 $H$ 时 $m \propto 1/[\mathrm{CycB}] \propto 1/k_1$，整条曲线按 $1/k_1$ 标度，鞍结点处的临界质量也是如此（$k_1 = 0.04$ 时约为 $0.53$）。过表达周期蛋白 B 使 $k_1$ 增大，降低细胞越过起始点的大小，所以突变体在更小的大小分裂（若 S 形曲线的下折点实际上移到 $m < 0$，细胞就无法回到 G1，周期失败，如某些周期蛋白过表达的表型）。这就是经典的预言：分裂时的大小由周期蛋白与其拮抗物之比决定。

6. 写出网络 $\varnothing \xrightarrow{v_1} \mathrm{A}$，$\mathrm{A} \xrightarrow{v_2} \mathrm{B}$，$\mathrm{A} \xrightarrow{v_3} \mathrm{C}$，$\mathrm{B} + \mathrm{C} \xrightarrow{v_4} \mathrm{D}$，$\mathrm{D} \xrightarrow{v_5} \varnothing$（生物量）的化学计量矩阵，其中 $v_1 \le 10$，求零空间，并解最大化 $v_5$ 的通量平衡问题。

   **答** 行为 A、B、C、D，列为 $v_1, \dots, v_5$：
   $$
   S = \begin{bmatrix} 1 & -1 & -1 & 0 & 0 \\ 0 & 1 & 0 & -1 & 0 \\ 0 & 0 & 1 & -1 & 0 \\ 0 & 0 & 0 & 1 & -1 \end{bmatrix}.
   $$
   $S\boldsymbol{v} = \boldsymbol{0}$ 给出 $v_2 = v_4$，$v_3 = v_4$，$v_5 = v_4$，$v_1 = v_2 + v_3 = 2v_4$，所以零空间是一维的，由 $(2, 1, 1, 1, 1)$ 张成（秩为 $4$，共五个反应）。取 $v_1 \le 10$，最优解为 $v_5 = 5$，在顶点 $v_1 = 10$ 处。这里仅质量守恒就确定了通量分布，因为网络没有可以权衡的分支；若有替代途径（例如 $\mathrm{A} \to \mathrm{C}$ 由第二个酶催化），零空间会更大，目标会在各途径之间做出选择。

7. 在例 34.4.1 中，最优解对 $10$ 单位葡萄糖用约 $15.9$ 单位氧。解释为什么在玩具模型中最优线过原点，以及若实测菌株生长时的氧与葡萄糖摄取比低于这条线，意味着什么。

   **答** 除了很小的维持需求，所有约束都是齐次的：把葡萄糖与氧的摄取按同一因子缩放，最优通量分布也随之缩放，所以两种区域之间的边界是（几乎）从原点出发的射线，斜率为每摩尔葡萄糖 $1.59$ 摩尔氧。线下方的菌株用氧比其葡萄糖摄取所对应的最优值少，必须排泄发酵产物；按通量平衡分析，它对其摄取速率而言并未最优地生长。有两种解释：菌株尚未适应这些条件（如 Ibarra 等人的甘油实验，进化后的菌株移到了线上），或模型缺少某个约束，如呼吸容量有限或蛋白质组成本，使排泄成为最优（[7.6.39](/7.6.39)）。

8. 用图中的玩具模型（可重用 `fba.py` 的代码）找出这样的双敲除：二者都致死，而单敲除都不致死（**合成致死**）。从生物学上解释结果。

   **答** 氧上限为 $12$ 时，致死的单敲除是摄取、糖酵解、PPP、PDH 与生物量。在其余的反应（TCA、OxPhos、O₂ 摄取、乳酸、乙酸）中，致死的对只有 OxPhos 与乳酸、O₂ 摄取与乳酸：没有呼吸时，使 NADH 重新氧化的唯一剩余途径是乳酸排泄，二者都没有则细胞无法平衡氧化还原。另外一些对有很强但不完全的有害作用：TCA 与乙酸使生长降到 $0.93$（发酵速率，因为没有 TCA 循环时乙酰辅酶 A 不能再被消耗，多余的 NADH 必须靠发酵清除），而乳酸与乙酸则保留野生型生长的 $90\,\%$。当两条途径各自能执行对方所不能的某个功能（这里是 NAD⁺ 的再生）时，就会产生合成致死，而计算所有双敲除是基因组规模预测合成致死对的基础，用于寻找药物靶标和解释遗传相互作用筛选（[7.4](/7.4)）。

   ```python
   import itertools
   import numpy as np
   from scipy.optimize import linprog
   # S, rxns and col as defined in fba.py

   def growth(knockouts, glc=10.0, o2=12.0):
       bounds = [(0, None)] * len(rxns)
       bounds[col["uptake"]] = (0, glc)
       bounds[col["O2 uptake"]] = (0, o2)
       bounds[col["maintenance"]] = (1, None)
       for r in knockouts:
           bounds[col[r]] = (0, 0)
       c = np.zeros(len(rxns))
       c[col["biomass"]] = -1
       res = linprog(c, A_eq=S, b_eq=np.zeros(S.shape[0]), bounds=bounds, method="highs")
       return -res.fun if res.status == 0 else 0.0

   viable = [r for r in rxns if r not in ("biomass", "maintenance") and growth([r]) > 1e-6]
   for a, b in itertools.combinations(viable, 2):
       print(a, b, round(growth([a, b]), 3))   # 0.0 marks a synthetic lethal pair
   ```

9. （开放题）酵母布尔网络对其连线的大多数单个改变是稳健的。提出一个布尔网络稳健性的定量度量，并设计一个计算实验，检验稳健性是被选择出来的，还是节点数与连接数相同的网络的一般性质。

   **答** 度量：最大吸引域相对于 $2^N$ 的大小；保持生物学不动点以及途径状态序列的单个连接改变（删除、添加、符号反转）所占的比例；轨迹的收敛性（汇入途径的状态的平均数目，或流向它的“流”）。实验：生成一个节点数、激活与抑制连接数以及度序列都相同的随机网络系综（通过交换连接端点来随机化，这保持度不变），计算每种度量，并把真实网络的值与系综分布比较（z 分数或经验 $p$ 值）。这正是 Li 等人所做的；更严格的零模型还保持自降解模式，并要求随机网络有一条同样长的途径。若真实网络远在尾部，它的稳健性就不太可能是一般性质。连续模型在参数空间中的类似做法（产生该功能的随机参数集所占的比例）是 [7.6.40](/7.6.40) 的方法。
