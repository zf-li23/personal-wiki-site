神经、肌肉和许多其他细胞用电来传递信号，但它们的电流是由水中的离子而不是金属中的电子携带的，它们的电池是由泵维持的浓度差。一小片膜可以在一毫秒内使其电势改变十分之一伏，这一变化可以沿轴突以每秒一百米的速度传播。本章自下而上地建立这套机制的物理：细胞带有多少电荷，为什么这样少（30.1 节）；离子如何穿过膜，包括 Nernst–Planck 方程、**Goldman–Hodgkin–Katz 方程**、孔道的速率理论模型以及 K⁺ **选择性过滤器**的结构（30.2 节）；通道如何感受电压，包括**门控电荷**、门控电流及其单通道动力学（30.3 节）；带有电压门控通道的膜如何成为双稳态开关（30.4 节），这样的电缆又如何被动地和主动地传导信号（30.5 节）；Hodgkin–Huxley 模型，及其由电压钳数据的推导和模拟（30.6 节）；髓鞘与跳跃传导（30.7 节）；以及两个器官水平的应用，电器官与心电图（30.8–30.9 节）。

许多背景已经具备。**膜电势**的电化学、**Nernst 方程**与 **Donnan 平衡**见 [6.3.13](/6.3.13) 与 [6.3.21](/6.3.21)；作为分析技术的**膜片钳**见 [6.4.6](/6.4.6)；泵的细胞生物学、**泵–漏模型**、静息电位与 **Goldman–Hodgkin–Katz 方程**见 [7.3.5](/7.3.5#sec-5.6)；通道与转运体的家族及其结构见 [7.1.13](/7.1.13) 与 [7.1.14](/7.1.14#sec-14.5)；由张力和电压使两态门控的统计力学、**门控电荷**以及烟碱型受体的**协同模型**（MWC 模型）见 [7.6.4](/7.6.4)。这里把这些内容推导出来，并组装成关于兴奋性的定量理论。电容与电流见 [5.3.4](/5.3.4) 与 [5.3.5](/5.3.5)；电缆方程是 [2.5](/2.5) 中所研究类型的反应扩散方程。**机械门控通道**在 [7.6.25](/7.6.25) 中处理。简化的神经元模型（FitzHugh–Nagumo、积分发放）、突触动力学与网络属于 [7.16](/7.16)，心脏的电生理属于 [7.14](/7.14)；本章为它们提供物理基础。

## 30.1. 细胞的电荷状态

### 30.1.1. 离子、膜与电容

细胞操纵四种小离子的梯度：$\ce{K+}$、$\ce{Na+}$、$\ce{Ca^2+}$ 与 $\ce{Cl-}$。与胞内 $\ce{K+}$ 平衡的负电荷大部分由不能通透的大分子（核酸、蛋白质、磷酸等代谢物）携带，它们不能离开细胞。静息电位为 $-90\,\mathrm{mV}$ 的哺乳动物骨骼肌纤维的典型数值为（Hille）：

| 离子 | 胞内 / mM | 胞外 / mM | $37\,{}^\circ\mathrm{C}$ 时的 Nernst 电势 / mV |
|---|---|---|---|
| $\ce{K+}$ | 155 | 4 | $-98$ |
| $\ce{Na+}$ | 12 | 145 | $+67$ |
| $\ce{Ca^2+}$ | $10^{-4}$ | 1.5 | $+129$ |
| $\ce{Cl-}$ | 4 | 120 | $-91$ |

质膜用脂双层隔开这些溶液，其烃核厚约 $4\,\mathrm{nm}$，**相对电容率** $\varepsilon_{\mathrm{r}} \approx 2$–$3$，是极好的绝缘体，其上嵌有分离电荷的泵与使电荷流回的通道。从电学上看，一小片膜是与若干电导并联的**电容** $C$，每个电导都与一个电池串联，电池的电压由浓度比决定。

平行板估计 $C/A = \varepsilon_0\varepsilon_{\mathrm{r}}/d = (8.85\times10^{-12})(2.1)/(4\times10^{-9}) \approx 5\times10^{-3}\,\mathrm{F\,m^{-2}}$，即 $0.5\,\mu\mathrm{F\,cm^{-2}}$，与几乎所有生物膜的实测值（约 $0.9$–$1\,\mu\mathrm{F\,cm^{-2}}$）相差不到两倍（极性头基与结合水增加了有效电容率）。我们取 $c_{\mathrm{m}} = 1\,\mu\mathrm{F\,cm^{-2}} = 10^{-2}\,\mathrm{F\,m^{-2}}$。

**例 30.1.1（多少电荷产生膜电势？）** 在 $10^{-2}\,\mathrm{F\,m^{-2}}$ 的**电容**上产生 $70\,\mathrm{mV}$ 的膜电势，需要面电荷密度 $\sigma = c_{\mathrm{m}}V = 7\times10^{-4}\,\mathrm{C\,m^{-2}}$，即每平方米 $4.4\times10^{15}$ 个元电荷：每平方微米约 4400 个离子，每 $(15\,\mathrm{nm})^2$ 一个离子。半径 $5\,\mu\mathrm{m}$ 的球形细胞面积为 $3.1\times10^{-10}\,\mathrm{m^2}$，需要 $1.4\times10^6$ 个未被补偿的离子。它含有 $0.155\,\mathrm{M} \times 5.2\times10^{-13}\,\mathrm{L} \times N_{\mathrm{A}} \approx 4.9\times10^{10}$ 个钾离子，所以电荷分离只涉及其中的 $3\times10^{-5}$。由此得到两个推论。两侧的体溶液高度精确地保持电中性，多余的电荷位于距膜一个 **Debye 长度**（小于 $1\,\mathrm{nm}$）以内；而且膜电势可以建立或反转，而浓度没有可测的变化。然而膜中的场是巨大的：$70\,\mathrm{mV}/4\,\mathrm{nm} \approx 2\times10^7\,\mathrm{V\,m^{-1}}$，是空气**电介质**强度（$3\times10^6\,\mathrm{V\,m^{-1}}$，即每毫米 $3\,\mathrm{kV}$）的六倍。脂双层只在约 $0.5$–$1\,\mathrm{V}$ 的跨膜电压，即高于 $10^8\,\mathrm{V\,m^{-1}}$ 的场下才击穿，电穿孔就利用了这一点。

### 30.1.2. 电化学平衡

考虑只对一种价态为 $z$ 的离子通透的膜。平衡时，在电势为 $\varphi$ 处发现离子的概率正比于 **Boltzmann 分布** $\exp(-ze\varphi/k_{\mathrm{B}}T)$，所以两侧的浓度满足 $c_{\mathrm{in}}/c_{\mathrm{out}} = \exp[-ze(\varphi_{\mathrm{in}} - \varphi_{\mathrm{out}})/k_{\mathrm{B}}T]$，这就是 **Nernst 方程**，
$$
E_{\mathrm{ion}} = \varphi_{\mathrm{in}} - \varphi_{\mathrm{out}} = \frac{k_{\mathrm{B}}T}{ze}\ln\frac{c_{\mathrm{out}}}{c_{\mathrm{in}}}. \tag{30.1}
$$
等价地，**电化学势** $\tilde\mu = \mu^\circ + k_{\mathrm{B}}T\ln c + ze\varphi$ 在两侧相等。标度 $k_{\mathrm{B}}T/e$ 在 $25\,{}^\circ\mathrm{C}$ 为 $25.7\,\mathrm{mV}$，在 $37\,{}^\circ\mathrm{C}$ 为 $26.7\,\mathrm{mV}$：膜电势是热电压的几倍，所以热涨落、熵与电能处于同等地位。对一价离子，$37\,{}^\circ\mathrm{C}$ 时十倍的浓度比对应 $61.5\,\mathrm{mV}$。

若所有可通透的离子都与同一膜电势平衡，而不通透的带电大分子被限制在细胞内，细胞就处于 **Donnan 平衡**（[6.3.21](/6.3.21)）：可扩散的离子这样分布，$[\ce{K+}]_{\mathrm{in}}/[\ce{K+}]_{\mathrm{out}} = [\ce{Cl-}]_{\mathrm{out}}/[\ce{Cl-}]_{\mathrm{in}}$，而内部多出来的可扩散离子使内部呈高渗。处于 Donnan 平衡的动物细胞会膨胀并破裂。表中显示细胞并不处于平衡：肌肉中的 $\ce{K+}$ 与 $\ce{Cl-}$ 接近平衡，但 $\ce{Na+}$ 与 $\ce{Ca^2+}$ 的 Nernst 电势连符号都与膜电势不同。细胞是由泵维持的稳态，即 [7.3.5](/7.3.5) 的**泵–漏模型**。

### 30.1.3. 钠钾泵的能量学

**钠钾泵**每水解一个 ATP，把三个 $\ce{Na+}$ 泵出、两个 $\ce{K+}$ 泵入。由于每个循环向外净移动一个正电荷，它是**生电性**的，直接给静息电位增加几毫伏；它的主要贡献是间接的，即维持通道借以设定电势的梯度。其他离子的梯度由利用泵所建立梯度的次级转运体维持：$\ce{Na+}/\ce{Ca^2+}$ 交换体（每排出一个 $\ce{Ca^2+}$ 进入三个 $\ce{Na+}$，由 $\ce{Na+}$ 梯度驱动）使胞质 $\ce{Ca^2+}$ 保持在 $100\,\mathrm{nM}$ 附近，$\ce{K+}/\ce{Cl-}$ **协同转运体** KCC2（由 $\ce{K+}$ 梯度驱动）降低成熟神经元内的 $\ce{Cl-}$，使 $\mathrm{GABA_A}$ 受体成为抑制性的。

**例 30.1.2（泵的效率高吗？）** 在表中的肌纤维（$V = -90\,\mathrm{mV}$，$37\,{}^\circ\mathrm{C}$）中，泵出三个 $\ce{Na+}$ 顶着浓度梯度耗费 $3k_{\mathrm{B}}T\ln(145/12) = 7.5\,k_{\mathrm{B}}T$，顶着电场耗费 $3e\times90\,\mathrm{mV} = 3 \times 90/26.7\,k_{\mathrm{B}}T = 10.1\,k_{\mathrm{B}}T$。泵入两个 $\ce{K+}$ 顶着梯度耗费 $2\ln(155/4) = 7.3\,k_{\mathrm{B}}T$，但从电场获得 $6.7\,k_{\mathrm{B}}T$。总计 $18.2\,k_{\mathrm{B}}T$，应与胞质中 ATP 水解的自由能 $-\Delta G \approx 50$–$60\,\mathrm{kJ\,mol^{-1}} = 19$–$23\,k_{\mathrm{B}}T$（$37\,{}^\circ\mathrm{C}$，[7.6.3](/7.6.3)）比较。泵在其热力学极限的 80–95 % 处工作，它的功几乎都花在远离平衡的钠上；钾几乎处于其 Nernst 电势。

## 30.2. 通透

### 30.2.1. Nernst–Planck 方程

溶液中的离子沿其浓度梯度向下扩散，并在电场中漂移。在场 $E$ 中它受力 $zeE$；在水中，其惯性在皮秒以上的时间尺度可以忽略（[7.6.22](/7.6.22)），它的平均**漂移速度**是力除以其摩擦系数 $\zeta$。在微观上，碰撞使速度随机化，场在两次碰撞之间使离子加速 $a = zeE/m$，平均漂移速度为 $a\tau_{\mathrm{c}}$，$\tau_{\mathrm{c}}$ 为速度弛豫时间，所以 $\zeta = m/\tau_{\mathrm{c}}$。**Einstein–Smoluchowski 关系** $D = k_{\mathrm{B}}T/\zeta$（[7.6.5](/7.6.5)）把摩擦与**扩散系数**联系起来。

**定义 30.2.1（Nernst–Planck 方程）** 价态为 $z$、浓度为 $c$、扩散系数为 $D$ 的离子，在电势 $\varphi(\boldsymbol{r})$ 中的通量密度由 **Nernst–Planck 方程**给出
$$
\boldsymbol{J} = -D\left(\nabla c + \frac{ze}{k_{\mathrm{B}}T}c\nabla\varphi\right) = -\frac{Dc}{k_{\mathrm{B}}T}\nabla\tilde\mu, \tag{30.2}
$$
它是 Fick 扩散通量与漂移通量 $c\,(zeE)/\zeta$ 之和，其中 $\boldsymbol{E} = -\nabla\varphi$；等价地，通量正比于**电化学势** $\tilde\mu$ 的梯度。

在一维情形令 $\boldsymbol{J} = 0$，得 $\mathrm{d}\ln c/\mathrm{d}x = -(ze/k_{\mathrm{B}}T)\,\mathrm{d}\varphi/\mathrm{d}x$，其跨膜积分就是 Nernst 方程 (30.1)：平衡是没有通量，而不是没有梯度。

### 30.2.2. 恒场理论：GHK 方程

为了计算载有电势 $V = \varphi_{\mathrm{in}} - \varphi_{\mathrm{out}}$ 的膜上的电流，Goldman（1943）与 Hodgkin 和 Katz（1949）假设离子独立运动，膜内的场均匀，并且紧靠膜两面内侧的浓度为 $\beta c_{\mathrm{in}}$ 与 $\beta c_{\mathrm{out}}$，$\beta$ 是进入膜的**分配系数**。

**定理 30.2.1（Goldman–Hodgkin–Katz 电流方程）** 在这些假设下，价态为 $z$ 的离子所携带的向外**电流密度**为
$$
I = P\,\frac{z^2{e}^2V}{k_{\mathrm{B}}T}\,\frac{c_{\mathrm{in}} - c_{\mathrm{out}}\,\mathrm{e}^{-u}}{1 - \mathrm{e}^{-u}}, \qquad u = \frac{zeV}{k_{\mathrm{B}}T}, \tag{30.3}
$$
浓度以单位体积的粒子数计，对厚度为 $d$ 的膜，通透系数 $P = \beta D/d$。电流在 Nernst 电势处为零，对几种一价离子，零电流电势为
$$
V_{\mathrm{rev}} = \frac{k_{\mathrm{B}}T}{e}\ln\frac{P_{\mathrm{K}}[\ce{K+}]_{\mathrm{out}} + P_{\mathrm{Na}}[\ce{Na+}]_{\mathrm{out}} + P_{\mathrm{Cl}}[\ce{Cl-}]_{\mathrm{in}}}{P_{\mathrm{K}}[\ce{K+}]_{\mathrm{in}} + P_{\mathrm{Na}}[\ce{Na+}]_{\mathrm{in}} + P_{\mathrm{Cl}}[\ce{Cl-}]_{\mathrm{out}}}. \tag{30.4}
$$

**证明** 从内表面（$x = 0$）到外表面（$x = d$）测量 $x$。在恒定的场中，相对于外侧 $\varphi(x) = V(1 - x/d)$，式 (30.2) 变为线性常微分方程 $\mathrm{d}c/\mathrm{d}x - (u/d)c = -J/D$，其中 $J$ 是向外的通量，稳态时为常数。乘以**积分因子** $\mathrm{e}^{-ux/d}$，从 $0$ 到 $d$ 积分，
$$
c(d)\,\mathrm{e}^{-u} - c(0) = -\frac{Jd}{Du}\left(1 - \mathrm{e}^{-u}\right).
$$
取 $c(0) = \beta c_{\mathrm{in}}$ 与 $c(d) = \beta c_{\mathrm{out}}$，$J = (\beta D/d)\,u\,(c_{\mathrm{in}} - c_{\mathrm{out}}\mathrm{e}^{-u})/(1 - \mathrm{e}^{-u})$，$I = zeJ$ 给出式 (30.3)。对单一离子，$I = 0$ 要求 $c_{\mathrm{in}} = c_{\mathrm{out}}\mathrm{e}^{-u}$，即 Nernst 方程。对几种离子，当 $\sum_jP_jz_j^2(c_{\mathrm{in},j} - c_{\mathrm{out},j}\mathrm{e}^{-u_j}) = 0$ 时总电流为零（对 $\lvert z\rvert$ 相同的离子，公因子 $V/(1 - \mathrm{e}^{-u})$ 消去，注意对 $\ce{Cl-}$，$u$ 变号）；解出 $\mathrm{e}^{eV/k_{\mathrm{B}}T}$ 得到式 (30.4)。$\square$

式 (30.4)，即 GHK 电压方程，是细胞生物学中所用的方程（[7.3.5](/7.3.5#sec-5.6.2)）：电势最接近最易通透的离子的 Nernst 电势。静息时，枪乌贼轴突中 $P_{\mathrm{K}}:P_{\mathrm{Na}}:P_{\mathrm{Cl}} \approx 1:0.04:0.45$，给出约 $-60$ 到 $-70\,\mathrm{mV}$，骨骼肌的静息氯通透甚至大于钾；在动作电位的峰值，$P_{\mathrm{Na}}$ 上升数百倍，电势趋近 $E_{\mathrm{Na}}$。

电流方程 (30.3) 还有第二个教益。把它在反转电势附近线性化，得到电路模型中所用的欧姆近似，
$$
I = g\,(V - E_{\mathrm{ion}}), \tag{30.5}
$$
斜率电导 $g = \partial I/\partial V$ 在 $E_{\mathrm{ion}}$ 处取值，它既依赖于浓度，也依赖于 $P$。远离 $E_{\mathrm{ion}}$ 时，GHK 电流不是线性的：从浓溶液一侧流出的电流大于线性预言，从稀溶液一侧流入的电流则小。这种 Goldman 整流是浓度不对称的性质，而不是通道的性质。

### 30.2.3. 单通道与膜片钳

**膜片钳**（Neher 与 Sakmann，1976；吉欧姆封接，Hamill 等 1981）记录通过单个通道的电流。把尖端约 $1\,\mu\mathrm{m}$ 的抛光玻璃移液管压在细胞上；轻轻吸吮形成玻璃与膜之间电阻 $10$–$100\,\mathrm{G\Omega}$ 的封接。电阻 $R$ 在带宽 $B$ 内的电流噪声为 $\sqrt{4k_{\mathrm{B}}TB/R}$；对 $R = 10\,\mathrm{G\Omega}$、$B = 1\,\mathrm{kHz}$，为 $0.04\,\mathrm{pA}$，小到足以分辨单通道的皮安台阶。使用四种构型（下图）：细胞贴附式、全细胞式，以及切下的内面向外式与外面向外式，后两者可以控制任一面的溶液。

单个开放的通道通过电流 $i = \gamma(V - E_{\mathrm{rev}})$，其中 $\gamma$ 是其单通道电导。一皮安是每秒 $6.2\times10^6$ 个元电荷。电导的范围从几皮西门子（一些 $\ce{Ca^2+}$ 释放激活的通道，低于 1 pS），到电压门控 $\ce{K+}$ 与 $\ce{Na+}$ 通道的 $10$–$20\,\mathrm{pS}$，再到大电导 $\ce{Ca^2+}$ 激活 $\ce{K+}$ 通道 BK 的 $250\,\mathrm{pS}$；BK 通道在 $100\,\mathrm{mV}$ 驱动力下通过 $25\,\mathrm{pA}$，每秒 $1.6\times10^8$ 个离子。扩散限制速率：离子以 $2\pi Dac$ 的速率到达孔口半径为 $a$ 的捕获半球，取 $D = 2\times10^{-9}\,\mathrm{m^2\,s^{-1}}$、$a = 0.3\,\mathrm{nm}$、$c = 150\,\mathrm{mM}$，约为 $4\times10^8\,\mathrm{s^{-1}}$。最快的通道在这一极限附近工作。

### 30.2.4. 通透的速率理论模型

均匀膜中的电扩散不能解释两个事实：单通道电导随浓度饱和，以及通过某些通道的电流以违反独立性的方式依赖于另一侧的浓度。如果孔道含有被势垒隔开的结合位点，每个势垒上的跃迁由 **Eyring 方程**给出，$k = \nu\exp(-\Delta G^\ddagger/k_{\mathrm{B}}T)$（[6.3.16](/6.3.16)），这两点就都可以得到解释。膜电势使自由能轮廓倾斜：与内侧的电学距离分数为 $\delta$ 处的离子，相对于外侧的电能为 $ze V(1 - \delta)$，所以每个速率通过阱与势垒之间所跨越的场的分数而指数地依赖于 $V$。

**公式 30.2.1（单位点双势垒孔）** 对含有一个至多容纳一个离子的位点的孔道，离子以速率 $k_1c_{\mathrm{in}}$ 从内侧、以速率 $k_{-2}c_{\mathrm{out}}$ 从外侧进入，并以速率 $k_{-1}$ 和 $k_2$ 离开到内侧和外侧，占据概率为 $p = (k_1c_{\mathrm{in}} + k_{-2}c_{\mathrm{out}})/(k_1c_{\mathrm{in}} + k_{-2}c_{\mathrm{out}} + k_{-1} + k_2)$，向外的离子通量为
$$
J = p\,k_2 - (1 - p)\,k_{-2}c_{\mathrm{out}},
$$
每个速率常数都带有由位点与势垒之间的电学距离决定的电压依赖性 $\exp(\pm ze\,\Delta\delta\,V/k_{\mathrm{B}}T)$。

在低浓度下，孔道多半是空的，电导随 $c$ 线性增长；在高浓度下，它多半被占据，电导以 Michaelis–Menten 形式饱和，如 Hille 等对 $\ce{Na+}$ 与 $\ce{K+}$ 通道所测得。不对称的轮廓即使在两侧溶液相同时也会整流。多离子孔道中同时存在两个或更多相互排斥的离子，可以解释反常摩尔分数效应（两种可通透离子的混合物中的电导低于二者中任一单独存在时）以及大于 1 的通量比指数（Hodgkin 与 Keynes，1955），后者揭示了单列运动。

![通透的速率理论模型（公式 30.2.1）。A：两个势垒之间有一个阱的孔道在 0 和 +60 mV 时的自由能轮廓；场使轮廓倾斜。B：两侧均为 100 mM 时的 I–V 曲线，分别为对称孔（近似线性）与位点靠近内侧、外势垒较高的不对称孔，后者虽然溶液相同也发生整流。C：0 mV 时单通道电导随浓度的变化：单位点孔饱和，自由电扩散则不饱和](./plots/barrier-model.py)

### 30.2.5. 选择性：K⁺ 通道的过滤器

$\ce{K+}$ 通道以接近每秒 $10^8$ 个离子的速率传导 $\ce{K+}$，同时以一百倍以上、常常是一千倍的倍数排斥更小的 $\ce{Na+}$。单靠大小不能解释这一点。

第一条线索来自药理学。四乙铵（TEA）阻断 $\ce{K+}$ 通道，Armstrong 在 1960 和 1970 年代表明，它从内侧竞争性地起作用，尽管它在大小和形状上都不像 $\ce{K+}$。他的解释是，$\ce{K+}$ 以水合的形式进入通道的内前庭，而 TEA 的乙基共价固定在氮的周围，模拟了带着第一层水的 $\ce{K+}$ 离子，却是永远无法脱水的。用带有逐渐加长的疏水尾巴的 TEA 衍生物，他推断内孔中有疏水区，并提出孔的窄部剥去水，代之以蛋白质的氧原子。*Drosophila* $\ce{K+}$ 通道 Shaker 的基因于 1987 年被克隆（Jan 等），细菌通道 KcsA 的晶体结构（Doyle、MacKinnon 等，1998）证实并深化了这一图像。

**定义 30.2.2（选择性过滤器）** **选择性过滤器**是通道孔道最窄的部分，通透的离子在那里失去大部分水合水并与蛋白质直接相互作用，其几何与化学决定哪些离子可以通过。

在 $\ce{K+}$ 通道中，过滤器由四个亚基的标志序列 TVGYG 构成，长 $1.2\,\mathrm{nm}$。主链羰基氧（以及底部苏氨酸的羟基）指向孔内，形成四个位点 S1–S4，每个都是由八个氧构成的四方反棱柱，如同水合 $\ce{K+}$ 周围的八个水氧。过滤器被刚性地固定在适合 $\ce{K+}$ 的大小：半径小 $0.4\,\text{Å}$（$0.95$ 对 $1.33\,\text{Å}$）的 $\ce{Na+}$ 不能同时被八个氧接触，所以它在过滤器中获得的能量不足以补偿其较大的脱水代价（严丝合缝；羰基的静电场强度也有影响）。过滤器之下，充满水的空腔和 Armstrong 实验中的疏水内孔使 $\ce{K+}$ 离子在膜的中央保持水合，那里指向空腔的螺旋偶极使它稳定。

传导是协同的。高、低 $\ce{K+}$ 下的晶体结构以及 $\ce{Tl+}$ 与 $\ce{Rb+}$ 的反常散射显示，过滤器中同时有两个离子，处于 S1–S3 与 S2–S4 的构型，与水分子交替（Morais-Cabral、Zhou 与 MacKinnon，2001）。从一侧进入的第三个离子把队列向前推一步（敲击），离子间的相互排斥抵消了它们的强结合，所以过滤器能够选择性地结合 $\ce{K+}$，又能快速释放它。钙通道以不同的机制选择：四个谷氨酸构成的环（$\mathrm{Ca_V}$ 通道中的 EEEE）以微摩尔亲和力结合 $\ce{Ca^2+}$；单个 $\ce{Ca^2+}$ 阻断一价离子的流动，两个 $\ce{Ca^2+}$ 在孔内相互排斥而通过。电压门控 $\ce{Na+}$ 通道有 DEKA 环和较宽的过滤器，让部分水合的 $\ce{Na+}$ 通过。

## 30.3. 门控

### 30.3.1. 电压感受器

通道对电压、配体、机械力或温度作出开启与关闭（门控）。以**门控电荷** $ze$ 作为电压的共轭变量的两态门控的统计力学见 [7.6.4](/7.6.4#sec-4.2.2)：对**两态系统**，开放概率是 $V$ 的 Boltzmann 函数，每 $k_{\mathrm{B}}T/ze$ 变化 $\mathrm{e}$ 倍，Shaker 的门控电荷约为 $13\,e$。

**定义 30.3.1（电压感受器）** 电压门控通道的**电压感受器**（电压感受结构域）是由每个亚基或重复的跨膜螺旋 S1–S4 构成的结构域，其中 S4 螺旋携带带正电的残基（精氨酸，偶尔是赖氨酸，位于每隔三个的位置），膜去极化时它们穿过膜内的场移动，并通过 S4–S5 连接子拉动孔道。

其构架是模块化的。电压门控 $\ce{K+}$ 通道（$\mathrm{K_V}$）是由含六个跨膜螺旋的亚基构成的四聚体；四个亚基的 S5 与 S6 与过滤器一起形成孔结构域，每个亚基的 S1–S4 在外周形成一个感受器。电压门控 $\ce{Na+}$ 与 $\ce{Ca^2+}$ 通道（$\mathrm{Na_V}$、$\mathrm{Ca_V}$）是含四个同源重复（I–IV）的单条多肽，相当于 $\mathrm{K_V}$ 通道的四个亚基融合在一个基因中。静息时，电场把 S4 的精氨酸保持在朝向内侧的位置；由保守残基（S2 中的两个极性或酸性残基与一个苯丙氨酸，S3 中的一个天冬氨酸）构成的门控电荷转移中心形成一个疏水狭窄处，精氨酸一个接一个通过它，交换离子对，同时 S4 向外移动约 $1$–$1.5\,\mathrm{nm}$ 并部分旋转（滑动螺旋，其中有一段 $3_{10}$ 螺旋使精氨酸保持朝向同一方向）。在关闭的孔中，四条 S6 螺旋交叉束处的疏水侧链阻塞内入口；感受器向外的运动拉动 S4–S5 连接子，使 S6 螺旋散开。$\mathrm{K_V}$ 通道的四个感受器各自独立运动，只有当四个都移动之后孔才打开：这是 Hodgkin–Huxley 模型中 $n^4$ 的结构基础（30.6 节）。

$\mathrm{Na_V}$ 通道另有快速失活。开放后 1–2 ms 内，重复 III 与 IV 之间胞内连接子中的一个短的疏水基序（人类通道中是 IFM，其结构首先被展示的电鳗通道 $\mathrm{Na_V1.4}$ 中是 LFM）结合到重复 III 和 IV 的 S6 螺旋与 S4–S5 连接子旁的口袋中，别构地关闭孔（而不像 Armstrong 对 Shaker 失活提出的“球与链”模型那样堵住它）。感受器 I–III 控制激活，感受器 IV 较慢的运动是失活的限速步骤：这就是 Hodgkin 与 Huxley 的三个 $m$ 门与一个 $h$ 门。

### 30.3.2. 门控电流

门控电荷的移动本身就是电流，虽小却可以测量。当离子电流被阻断（对 $\mathrm{Na_V}$ 用河豚毒素，对 $\mathrm{K_V}$ 用内部 $\ce{Cs+}$ 或 TEA），并扣除线性电容电流（通过缩放对小的超极化阶跃的响应，即 P/4 方案）后，去极化时留下一个短暂的向外瞬态，复极化时留下一个向内瞬态（Armstrong 与 Bezanilla，1973；Schneider 与 Chandler，1973）。

**定义 30.3.2（门控电流）** 一群电压门控通道的**门控电流**是其电压感受器的带电基团在膜内场中移动所携带的**位移电流**；它在电压阶跃之后的时间积分是移动的门控电荷 $Q$，曲线 $Q(V)$ 是电荷–电压关系。

门控电流回答了离子电流所不能回答的问题。每个通道的总电荷为 $Q_{\max}/N$，其中通道数 $N$ 由毒素结合或噪声分析计数；对 Shaker 为 $12$–$14\,e$（Schoppa 等 1992；Aggarwal 与 MacKinnon 1996），与四个感受器各携带约 $3.3\,e$ 一致。电荷–电压曲线位于电导–电压曲线的左边，且更平缓，因为大部分电荷在最后的开放步骤之前的关闭态之间的跃迁中移动。因此对电导做单个 Boltzmann 拟合会低估门控电荷（在图的模型中低估一半以上）；可靠的估计是在很负的电势下 $\ln p_{\mathrm{o}}$ 的极限斜率，那里 $p_{\mathrm{o}} \propto \exp(z_{\mathrm{tot}}eV/k_{\mathrm{B}}T)$（Almers 1978）。

![具有四个独立的、各为 3.25 e 的两态感受器，且四个都被激活时孔才打开的模型通道中的门控电荷。A：归一化的 Q–V（∝ n）与 G–V（∝ n⁴）曲线：电导更陡且右移，对其做单个 Boltzmann 拟合得到的表观电荷约为 4 e，而不是实际移动的 13 e。B：从 −100 mV 出发的阶跃之后的门控电流：快速瞬态，其积分就是移动的电荷。C：大部分电荷移动之后，离子电流以 S 形延迟上升](./plots/gating-currents.py)

### 30.3.3. 单通道动力学

单个通道在其构象之间随机切换，其记录是随机的电报信号。具有离散状态与每个跃迁的速率常数时，概率服从**主方程**（[7.6.5](/7.6.5)），$\mathrm{d}\boldsymbol{p}/\mathrm{d}t = \boldsymbol{p}Q$，其中 $Q$ 是跃迁速率矩阵（各行之和为零）。

**定理 30.3.1（停留时间分布）** 把状态分为开放（$\mathcal{O}$）与关闭（$\mathcal{C}$）两类，令 $Q_{\mathcal{CC}}$ 为关闭态之间速率的子矩阵。关闭区间的持续时间具有密度
$$
f_{\mathcal{C}}(t) = \boldsymbol{\pi}_{\mathcal{C}}\,\mathrm{e}^{Q_{\mathcal{CC}}t}\,Q_{\mathcal{CO}}\boldsymbol{1}, \tag{30.6}
$$
其中 $\boldsymbol{\pi}_{\mathcal{C}}$ 是关闭区间开始时在各关闭态上的分布，$Q_{\mathcal{CO}}\boldsymbol{1}$ 是到开放类的离开速率向量；对开放区间同样成立。该密度是 $n_{\mathcal{C}}$ 个指数函数之和，其中 $n_{\mathcal{C}}$ 是关闭态的数目，时间常数等于 $Q_{\mathcal{CC}}$ 的本征值的负倒数。

**证明** 在关闭区间中，通道在 $\mathcal{C}$ 内以生成元 $Q_{\mathcal{CC}}$ 演化（离开 $\mathcal{C}$ 的跃迁使区间结束），所以在时刻 $t$ 尚未离开而处于各关闭态的概率为 $\boldsymbol{\pi}_{\mathcal{C}}\mathrm{e}^{Q_{\mathcal{CC}}t}$；在 $t$ 处离开的密度是它乘以离开速率。把 $Q_{\mathcal{CC}}$ 对角化就得到指数之和。$\square$

因此，对停留时间直方图中的指数分量计数，就是对状态计数（Colquhoun 与 Hawkes）。直方图最好用对数时间区间与平方根纵坐标显示（Sigworth 与 Sine 1987）：每个指数分量于是在其时间常数处表现为一个峰。单通道记录用 **Gillespie 算法**（[4.4.7](/4.4.7)）精确模拟，每个停留时间都由具有当前状态总离开速率的**指数分布**抽取；隐 Markov 方法则把模型直接拟合到有噪声的记录上。

### 30.3.4. 配体门控通道与 NMDA 受体

配体门控通道把化学信号转换为电流。**神经肌肉接头**的**烟碱型乙酰胆碱受体**是结合两个乙酰胆碱分子时打开的五聚体，是 MWC 模型的教科书例子（[7.6.4](/7.6.4#sec-4.5.2)）。谷氨酸受体是通过 $\ce{Na+}$ 与 $\ce{K+}$（有些还通过 $\ce{Ca^2+}$）的四聚体，反转电势接近 $0\,\mathrm{mV}$，所以使静息的神经元去极化。

NMDA 型谷氨酸受体（被 N-甲基-D-天冬氨酸激活）有两个不寻常的性质，Mayer、Westbrook 与 Guthrie（1984）以及 Nowak 等（1984）表明它们是同一个性质：它被外部 $\ce{Mg^2+}$ 阻断，并且即使结合了谷氨酸，在负电势下传导也很少。$\ce{Mg^2+}$ 从外侧进入孔，结合在场中很深处的一个位点，很少从那里通透；超极化把它拉入，去极化把它排出。

**公式 30.3.2（依赖电压的阻断）** 对价态为 $z$ 的阻断剂，它从外侧结合在进入膜内电学距离分数 $\delta$ 的位点上（Woodhull，1973），未被阻断的通道所占的比例为
$$
\frac{1}{1 + [\mathrm{B}]/K(V)}, \qquad K(V) = K(0)\exp\left(\frac{z\delta eV}{k_{\mathrm{B}}T}\right). \tag{30.7}
$$
对 NMDA 受体的 $\ce{Mg^2+}$ 阻断，$K(V) \approx 3.57\,\mathrm{mM}\,\mathrm{e}^{0.062V/\mathrm{mV}}$（Jahr 与 Stevens，1990），对应 $z\delta \approx 1.6$。

因此 NMDA 受体只有在谷氨酸存在（突触前活动）且突触后膜去极化（突触后活动）时才打开：它是分子的符合探测器。其 $\ce{Ca^2+}$ 流入激活 $\ce{Ca^2+}$/钙调蛋白依赖性激酶 CaMKII 并增强突触，这就是 Hebb 假说（“一起发放的细胞连在一起”）与长时程增强背后的机制。这里的电压依赖性并非来自感受器，而是来自一个通透的离子：式 (30.7) 的物理与公式 30.2.1 中势垒倾斜是同一种。

## 30.4. 作为兴奋电路的膜

### 30.4.1. 等效电路

对单位面积电容为 $C$、各离子的电导为 $g_j$、Nernst 电势为 $E_j$，并施加电流 $I_{\mathrm{app}}$（均为单位面积）的一小片膜，电荷守恒给出
$$
C\frac{\mathrm{d}V}{\mathrm{d}t} = -\sum_jg_j(V, t)\,(V - E_j) + I_{\mathrm{app}}. \tag{30.8}
$$
电导恒定时，稳态是各 Nernst 电势按电导加权的平均，$V^* = \sum_jg_jE_j/\sum_jg_j$，是式 (30.4) 的线性对应；小扰动以膜时间常数
$$
\tau_{\mathrm{m}} = \frac{C}{g} = R_{\mathrm{m}}c_{\mathrm{m}} \tag{30.9}
$$
弛豫，其中 $R_{\mathrm{m}} = 1/g$ 是比膜电阻。由于 $c_{\mathrm{m}}$ 几乎是普适的，$\tau_{\mathrm{m}}$ 度量静息电导：枪乌贼轴突的 $R_{\mathrm{m}} \approx 1\,\mathrm{k\Omega\,cm^2}$ 给出 $1\,\mathrm{ms}$，皮层神经元的 $R_{\mathrm{m}} \approx 20\,\mathrm{k\Omega\,cm^2}$ 给出 $20\,\mathrm{ms}$。

### 30.4.2. 双稳态的膜片

设 $\ce{K+}$ 电导恒定，$\ce{Na+}$ 电导遵循 [7.6.4](/7.6.4) 的两态门控，$g_{\mathrm{Na}}(V) = \bar g_{\mathrm{Na}}/[1 + \exp(-z_{\mathrm{g}}e(V - V_{1/2})/k_{\mathrm{B}}T)]$。式 (30.8) 的右边于是是仅依赖于 $V$ 的非线性函数，其零点是稳态。

**命题 30.4.1（双稳态）** 若 $\bar g_{\mathrm{Na}} \gg g_{\mathrm{K}} \gg g_{\mathrm{Na}}(E_{\mathrm{K}})$，且门控中点位于 $E_{\mathrm{K}}$ 与 $E_{\mathrm{Na}}$ 之间，则该膜片有三个稳态：一个靠近 $E_{\mathrm{K}}$ 的稳定态，一个靠近 $E_{\mathrm{Na}}$ 的稳定态，以及介于二者之间的一个不稳定态，它起阈值的作用。

**证明** 写 $\dot V = h(V)/C$，其中 $h = -g_{\mathrm{K}}(V - E_{\mathrm{K}}) - g_{\mathrm{Na}}(V)(V - E_{\mathrm{Na}})$。略高于 $E_{\mathrm{K}}$ 时 $g_{\mathrm{Na}}$ 可忽略，$h < 0$；略低于时 $h > 0$：$E_{\mathrm{K}}$ 附近有一个稳定的零点。在 $E_{\mathrm{Na}}$ 附近，$g_{\mathrm{Na}} \approx \bar g_{\mathrm{Na}} \gg g_{\mathrm{K}}$，同样的论证给出紧靠 $E_{\mathrm{Na}}$ 之下的一个稳定零点。一个在第一个零点之上为负、在第二个零点之下为正的连续函数，必须在两者之间再穿过零点一次，且是向上穿过，这是一个不稳定的不动点。$\square$

越过阈值的去极化使膜片进入钠态；达不到的则以时间常数 $\tau_{\mathrm{m}}$ 衰减回去。这种双稳态，即兴奋的全或无特征，是动作电位的第一个要素。第二个要素是恢复：若 $g_{\mathrm{Na}}$ 失活而 $g_{\mathrm{K}}$ 延迟地增大，钠态就消失，膜片回到静息，于是双稳态开关变成脉冲（30.6 节）。

## 30.5. 电缆方程

### 30.5.1. 推导

轴突或树突是被膜包围的传导胞质细圆柱。设其半径为 $a$，胞质电阻率为 $R_{\mathrm{i}}$，比膜电阻为 $R_{\mathrm{m}}$，电容为 $c_{\mathrm{m}}$，并忽略胞外液的电阻。芯的单位长度电阻为 $r_{\mathrm{i}} = R_{\mathrm{i}}/\pi a^2$，膜的单位长度电阻为 $r_{\mathrm{m}} = R_{\mathrm{m}}/2\pi a$，电容为 $2\pi ac_{\mathrm{m}}$。

**定理 30.5.1（电缆方程）** 设 $V(x, t)$ 是被动圆柱中膜电势相对于静息值的偏离。则
$$
\lambda^2\frac{\partial^2V}{\partial x^2} = \tau_{\mathrm{m}}\frac{\partial V}{\partial t} + V, \qquad \lambda = \sqrt{\frac{r_{\mathrm{m}}}{r_{\mathrm{i}}}} = \sqrt{\frac{aR_{\mathrm{m}}}{2R_{\mathrm{i}}}}, \qquad \tau_{\mathrm{m}} = R_{\mathrm{m}}c_{\mathrm{m}}. \tag{30.10}
$$

**证明** 轴向电流 $I_{\mathrm{a}}$ 的 **Ohm 定律**给出 $\partial V/\partial x = -r_{\mathrm{i}}I_{\mathrm{a}}$。长为 $\mathrm{d}x$ 的一片中的电荷守恒：损失的轴向电流 $-(\partial I_{\mathrm{a}}/\partial x)\mathrm{d}x$ 以电容电流与电阻电流的形式流过膜，$(2\pi ac_{\mathrm{m}}\partial_tV + V/r_{\mathrm{m}})\mathrm{d}x$。消去 $I_{\mathrm{a}}$，$(1/r_{\mathrm{i}})\partial_x^2V = 2\pi ac_{\mathrm{m}}\partial_tV + V/r_{\mathrm{m}}$；乘以 $r_{\mathrm{m}}$，并注意 $2\pi ac_{\mathrm{m}}r_{\mathrm{m}} = R_{\mathrm{m}}c_{\mathrm{m}}$，即得式 (30.10)。$\square$

**定义 30.5.1（电缆方程与长度常数）** 式 (30.10) 是被动神经突的**电缆方程**（Kelvin 为横跨大西洋的电报电缆建立的方程，由 Hermann、Hodgkin 与 Rushton 应用于神经），而 $\lambda$ 是其**长度常数**：稳定电压衰减 $\mathrm{e}$ 倍所经过的距离。

在稳态下，长电缆在 $x = 0$ 处被钳制的电压 $V_0$ 按 $V_0\mathrm{e}^{-x/\lambda}$ 衰减。在时间上，该方程是带衰减项的**热方程**：代入 $V = \mathrm{e}^{-t/\tau_{\mathrm{m}}}U$ 得 $\tau_{\mathrm{m}}\partial_tU = \lambda^2\partial_x^2U$，所以短暂的局部电荷注入扩展为 Gauss 分布，其宽度按 $\lambda\sqrt{2t/\tau_{\mathrm{m}}}$ 增长，面积按 $\mathrm{e}^{-t/\tau_{\mathrm{m}}}$ 衰减。因此被动信号只能传播几个长度常数，其“速度”（峰值约 $2\lambda/\tau_{\mathrm{m}}$）不是波的速度。

**例 30.5.1（长度常数）** 对枪乌贼巨轴突（$a = 250\,\mu\mathrm{m}$，$R_{\mathrm{m}} = 0.1\,\mathrm{\Omega\,m^2}$，$R_{\mathrm{i}} = 0.3\,\mathrm{\Omega\,m}$），$\lambda = \sqrt{(2.5\times10^{-4})(0.1)/0.6} = 6.5\,\mathrm{mm}$。对细树突（$a = 1\,\mu\mathrm{m}$，$R_{\mathrm{m}} = 2\,\mathrm{\Omega\,m^2}$，$R_{\mathrm{i}} = 1\,\mathrm{\Omega\,m}$），$\lambda = 1\,\mathrm{mm}$。信号不可能被动地沿任何轴突传播一米：沿枪乌贼轴突传播 $1\,\mathrm{m} = 150\lambda$ 后，它会衰减 $\mathrm{e}^{-150}$。长距离信号传递需要再生。

### 30.5.2. 再生波

把双稳态膜片的电压门控电导加到电缆上，式 (30.10) 就成为反应扩散方程 $\lambda^2\partial_x^2V = \tau\partial_tV + F(V)$，其中 $F$ 是命题 30.4.1 的无量纲离子电流。被推过阈值的区域通过轴向电流把邻近区域也拉过阈值，钠态就以形状与速度固定的行波前沿入侵静息态（Luther 的自催化波；单稳态 $F$ 对应 Fisher–Kolmogorov 前沿，双稳态 $F$ 对应 [7.6.36](/7.6.36) 的**触发波**）。

**命题 30.5.1（前沿速度）** 对双稳态电缆 $\tau\partial_tV = \lambda^2\partial_x^2V + f(V)$，取三次函数 $f(V) = kV(1 - V)(V - \alpha)$，$0 < \alpha < 1/2$（以电压范围为单位），从静息态到兴奋态的前沿以
$$
v = \frac{\lambda}{\tau}\sqrt{\frac{k}{2}}\,(1 - 2\alpha). \tag{30.11}
$$
传播。一般地，量纲分析给出 $v = (\lambda/\tau)\,\Phi$，其中无量纲的 $\Phi$ 只依赖于 $F$ 的形状；由于 $\lambda \propto \sqrt a$ 而 $\tau$ 与 $a$ 无关，无髓轴突的传导速度按其直径的平方根增长。

**证明** 寻找 $V = U(\xi)$，$\xi = x - vt$：$\lambda^2U'' + v\tau U' + f(U) = 0$。试取 $U' = -BU(1 - U)$（逻辑斯谛前沿，其后 $U \to 1$，前方 $U \to 0$）。则 $U'' = B^2U(1 - U)(1 - 2U)$，代入，$U(1 - U)[\lambda^2B^2(1 - 2U) - v\tau B + k(U - \alpha)] = 0$ 对所有 $U$ 成立，要求 $2\lambda^2B^2 = k$ 与 $\lambda^2B^2 - v\tau B - k\alpha = 0$。因此 $B = \sqrt{k/2}/\lambda$，$v\tau B = k(1/2 - \alpha)$，得到式 (30.11)。$\square$

当 $\alpha < 1/2$（兴奋态“更稳定”）时，前沿推进到静息态中；然而单独的前沿使轴突保持去极化。在轴突中，钠失活与延迟的钾激活在前沿之后恢复静息，把前沿变成脉冲：动作电位。

## 30.6. Hodgkin–Huxley 模型

### 30.6.1. 电压钳

Hodgkin 与 Huxley 对枪乌贼巨轴突的分析（1952 年的五篇论文）是定量细胞生物物理学的奠基范例。轴突宽达 $1\,\mathrm{mm}$，可沿轴线插入银丝，使其内部等电势（空间钳），反馈放大器把膜电势保持在指令值。

**定义 30.6.1（电压钳）** 在**电压钳**中，反馈放大器测量膜电势，并注入把它保持在指令值所需的任何电流；阶跃之后短暂的电容瞬态结束后，所注入的电流等于该固定电势下的总离子电流，于是可以测量它作为时间与电压的函数。

去极化阶跃之后的电流先向内后向外。把大部分外部 $\ce{Na+}$ 换成胆碱消除了早期的内向分量，从而分开了 $I_{\mathrm{Na}}$ 与 $I_{\mathrm{K}}$。把每种电流除以其驱动力得到电导，$g_{\mathrm{Na}} = I_{\mathrm{Na}}/(V - E_{\mathrm{Na}})$ 与 $g_{\mathrm{K}} = I_{\mathrm{K}}/(V - E_{\mathrm{K}})$，简单的是电导而不是电流：$g_{\mathrm{K}}$ 以 S 形延迟上升并保持；$g_{\mathrm{Na}}$ 迅速上升后下降（失活），尽管电压是固定的。

### 30.6.2. 门控变量

**定义 30.6.2（Hodgkin–Huxley 模型）** **Hodgkin–Huxley 模型**把可兴奋膜片的膜电流描述为
$$
C\frac{\mathrm{d}V}{\mathrm{d}t} = -\bar g_{\mathrm{Na}}m^3h\,(V - E_{\mathrm{Na}}) - \bar g_{\mathrm{K}}n^4(V - E_{\mathrm{K}}) - g_{\mathrm{L}}(V - E_{\mathrm{L}}) + I_{\mathrm{app}}, \tag{30.12}
$$
其中每个门控变量 $x \in \{m, h, n\}$ 服从一级动力学
$$
\frac{\mathrm{d}x}{\mathrm{d}t} = \alpha_x(V)(1 - x) - \beta_x(V)x = \frac{x_\infty(V) - x}{\tau_x(V)}, \qquad x_\infty = \frac{\alpha_x}{\alpha_x + \beta_x}, \quad \tau_x = \frac{1}{\alpha_x + \beta_x}, \tag{30.13}
$$
依赖电压的速率常数由电压钳数据拟合。对 $6.3\,{}^\circ\mathrm{C}$ 的枪乌贼轴突，采用现代约定（静息在 $-65\,\mathrm{mV}$；$V$ 以 mV 计，速率以 $\mathrm{ms^{-1}}$ 计）：$\alpha_m = 0.1(V + 40)/[1 - \mathrm{e}^{-(V + 40)/10}]$，$\beta_m = 4\mathrm{e}^{-(V + 65)/18}$，$\alpha_h = 0.07\mathrm{e}^{-(V + 65)/20}$，$\beta_h = 1/[1 + \mathrm{e}^{-(V + 35)/10}]$，$\alpha_n = 0.01(V + 55)/[1 - \mathrm{e}^{-(V + 55)/10}]$，$\beta_n = 0.125\mathrm{e}^{-(V + 65)/80}$；$\bar g_{\mathrm{Na}} = 120$，$\bar g_{\mathrm{K}} = 36$，$g_{\mathrm{L}} = 0.3\,\mathrm{mS\,cm^{-2}}$，$E_{\mathrm{Na}} = 50$，$E_{\mathrm{K}} = -77$，$E_{\mathrm{L}} = -54.4\,\mathrm{mV}$，$C = 1\,\mu\mathrm{F\,cm^{-2}}$。

指数的选择是为了拟合电导曲线的形状：单个一级变量按指数上升，没有观察到的延迟，而 $n^4$ 按 $(1 - \mathrm{e}^{-t/\tau_n})^4$ 上升，呈 S 形。Hodgkin 与 Huxley 把每个变量解释为若干独立门控粒子之一处于允许位置的概率，$\ce{K+}$ 电导有四个，$\ce{Na+}$ 电导有三个激活粒子和一个失活粒子。四十年后，$\mathrm{K_V}$ 通道的四个独立电压感受器，以及 $\mathrm{Na_V}$ 通道的三个激活感受器加上与感受器 IV 耦合的失活（30.3.1 节）赋予这些粒子结构上的意义，这是对一个唯象模型的出色证实。速率常数具有场中越过势垒的跃迁所预期的指数电压依赖性，Hodgkin 与 Huxley 正是据此提出其形式（他们考虑过并否定了带电载体穿过膜的模型）。

### 30.6.3. 模拟动作电位

**算法 30.6.1（Hodgkin–Huxley 方程的积分）** 把状态表示为 $(V, m, h, n)$，用四阶 Runge–Kutta 方法和 $0.01$–$0.02\,\mathrm{ms}$ 的步长积分式 (30.12)–(30.13)，从静息出发，各门取 $x_\infty(-65\,\mathrm{mV})$。对电压钳的模拟，保持 $V$ 固定：每个门于是以时间常数 $\tau_x(V)$ 指数地弛豫到 $x_\infty(V)$，电导随之得到解析形式。对沿轴突的传播，把 $x$ 离散化并加上轴向项 $(a/2R_{\mathrm{i}})\partial_x^2V$（30.6.4 节）。

模拟再现了这些现象：去极化超过几毫伏的阈值时出现全或无的尖峰；过冲到约 $+40\,\mathrm{mV}$，达不到 $E_{\mathrm{Na}}$，因为 $g_{\mathrm{K}}$ 已开始上升而 $g_{\mathrm{Na}}$ 开始失活；$n$ 仍然很高时向 $E_{\mathrm{K}}$ 的后超极化；约 $2\,\mathrm{ms}$ 的绝对不应期，此间 $h$ 太小，任何刺激都不能引起尖峰，随后是相对不应期；以及对高于约 $6\,\mu\mathrm{A\,cm^{-2}}$ 的稳定电流，从非零频率突然开始的重复发放。最后一个性质，即通过 **Hopf 分岔**（[2.4.11](/2.4.11)）出现振荡，把枪乌贼轴突归入“II 型”可兴奋体系；把四维模型约化为二维相平面模型见 [7.16](/7.16)。

**例 30.6.1（一个尖峰的代价）** 使膜去极化 $100\,\mathrm{mV}$ 所必须进入的最小电荷为 $c_{\mathrm{m}}\Delta V = 10^{-3}\,\mathrm{C\,m^{-2}}$，即每平方米 $6.2\times10^{15}$ 个 $\ce{Na+}$，每平方微米约 6000 个。在低温的枪乌贼轴突中，$\ce{Na+}$ 与 $\ce{K+}$ 电流强烈重叠，进入的电荷约为这一最小值的四倍；在哺乳动物的无髓轴突和许多皮层轴突中，重叠很小，多余的只有 30 %（Alle、Roth 与 Geiger 2009；Carter 与 Bean 2009）。每个 $\ce{Na+}$ 被泵出的代价是三分之一个 ATP。对直径 $0.5\,\mu\mathrm{m}$、总长 $4\,\mathrm{cm}$ 的皮层轴突，面积为 $6\times10^{-8}\,\mathrm{m^2}$，一个尖峰耗费 $1.3 \times 6.2\times10^{15} \times 6\times10^{-8}/3 \approx 1.6\times10^8$ 个 ATP。数十亿个神经元每秒发放数次，信号传递消耗了脑的大部分能量，在人类中约占全身静息代谢的 20 %。

### 30.6.4. 传播

把式 (30.12)–(30.13) 与电缆耦合，得到传播的动作电位，
$$
\frac{a}{2R_{\mathrm{i}}}\frac{\partial^2V}{\partial x^2} = C\frac{\partial V}{\partial t} + I_{\mathrm{ion}}(V, m, h, n). \tag{30.14}
$$
Hodgkin 与 Huxley 在机械计算器上求解行波：假设速度 $\theta$ 恒定，$V(x, t) = V(t - x/\theta)$ 把式 (30.14) 变为常微分方程，$\partial_x^2V = \theta^{-2}\partial_t^2V$，只有一个 $\theta$ 的值给出回到静息的解。他们在 $18.5\,{}^\circ\mathrm{C}$ 得到 $18.8\,\mathrm{m\,s^{-1}}$，实测为 $21.2\,\mathrm{m\,s^{-1}}$。脉冲之后 $\ce{Na+}$ 通道的失活使它处于不应期，所以在轴突中部引发的尖峰向两个方向传播而不会折回，两个相撞的尖峰相互湮灭。

## 30.7. 髓鞘与跳跃传导

无髓轴突的传导 $v \propto \sqrt d$；要达到 $25\,\mathrm{m\,s^{-1}}$，枪乌贼需要半毫米粗的轴突，而一个拥有数千条这样的快纤维的人，脊髓需要有数米宽。脊椎动物用髓鞘解决了这个问题：施万细胞（在周围神经中）与少突胶质细胞（在中枢神经系统中）把数十到一百层自己的膜包在轴突周围，每隔 $0.2$–$2\,\mathrm{mm}$（约为纤维直径的 100 倍）留下约 $1\,\mu\mathrm{m}$ 宽的间隙，即郎飞结。

**定义 30.7.1（跳跃传导）** **跳跃传导**是动作电位沿有髓轴突的传播，其中电压门控 $\ce{Na+}$ 通道集中在郎飞结，被绝缘的结间区被动地传导，于是兴奋从一个结跳到下一个结。

含 $N$ 层的髓鞘串联了 $2N$ 层膜：它使结间膜的比电阻乘以约 $2N$，电容除以同样的因子。结间的长度常数增大 $\sqrt{2N}$，所以来自一个活动结的电流使下一个结去极化到阈值以上，使结间区去极化所需的电荷减少为原来的 $1/(2N)$，这节省能量与时间。一个结达到阈值所需的时间约 $20$–$50\,\mu\mathrm{s}$，与直径无关，而结间距离与直径成正比地增长；因此有髓纤维的速度正比于直径，约为每微米外径 $6\,\mathrm{m\,s^{-1}}$（Hursh，1939）。由于无髓传导只按 $\sqrt d$ 增长，髓鞘在约 $1\,\mu\mathrm{m}$ 的交叉直径以上才合算（Rushton，1951），这大致就是哺乳动物中轴突无髓的直径上限。Rushton 还表明，在给定外径下，轴突与纤维直径之比（g 比）约为 $0.6$ 时速度最大，与实测的 $0.6$–$0.7$ 接近。多发性硬化等脱髓鞘疾病使传导变慢或受阻，因为暴露的结间膜上 $\ce{Na+}$ 通道太少，不足以再生尖峰，而且其较高的电容分流了来自结的电流。

## 30.8. 电器官

有几类鱼用由电细胞构成的器官产生放电，电细胞是改造的肌肉（多数物种）或神经细胞。电细胞是一种扁平的细胞，只在一个面上受神经支配。静息时两个面都具有静息电位，其电势沿细胞轴向相互抵消；当受支配的面发放动作电位（或在某些物种中，两个面相继发放）时，跨细胞的电势成为一个面上的动作电位与另一个面上的静息电位之差，约 $0.15\,\mathrm{V}$。数千个电细胞叠成柱，像串联的电池，许多柱并联工作。

**定义 30.8.1（电器官）** **电器官**是由串联与并联排列的电细胞构成的器官，其同步而不对称的兴奋使跨细胞电势叠加，并驱动电流通过周围的水，用于通讯与电定位（弱放电）或捕食与防御（强放电）。

这种排列是阻抗匹配问题。设 $N_{\mathrm{tot}}$ 个电细胞，每个的电动势为 $\varepsilon$，内阻为 $r$，排成 $N$ 个串联、$M = N_{\mathrm{tot}}/N$ 个柱并联，向负载 $R_L$（水与猎物）放电。器官的电动势为 $N\varepsilon$，内阻为 $Nr/M = N^2r/N_{\mathrm{tot}}$，输出功率为
$$
P = \frac{(N\varepsilon)^2R_L}{(R_L + N^2r/N_{\mathrm{tot}})^2},
$$
当内阻等于负载时最大，在 $N^* = \sqrt{N_{\mathrm{tot}}R_L/r}$ 处，此时 $P_{\max} = N_{\mathrm{tot}}\varepsilon^2/(4r)$，与负载无关。淡水是不良导体，电鳗（*Electrophorus*）的每个主要器官中约有 6000 个串联的电细胞，产生高达 $600\,\mathrm{V}$ 的电压（*Electrophorus voltai* 为 $860\,\mathrm{V}$，de Santana 等 2019）；海水导电良好，海洋电鳐（*Torpedo*）的柱很短，只有几百个电细胞，许多柱并联，产生 $50$–$60\,\mathrm{V}$（最大的物种高达约 $200\,\mathrm{V}$），电流达数十安培。非洲电鲶（*Malapterurus*）达到约 $350\,\mathrm{V}$。电鳐（*Torpedo*）的电细胞中密集地排列着烟碱型乙酰胆碱受体，这些受体最初就是从那里纯化出来的。

## 30.9. 作为偶极场的心电图

心脏是可兴奋细胞的合胞体，去极化波从窦房结经心房传播，在房室结处被延迟，并通过 His–Purkinje 系统迅速传遍心室。在每一时刻，去极化组织与静息组织的边界带有一层电流源与电流汇；从比心脏大得多的距离看，它是处于容积导体中的电流偶极子 $\boldsymbol{p}(t)$（单位 $\mathrm{A\,m}$）。

**命题 30.9.1（电流偶极子的电势）** 在电导率为 $\sigma$ 的无限均匀导体中，位于原点的电流偶极子 $\boldsymbol{p}$ 产生的电势为
$$
\varphi(\boldsymbol{r}) = \frac{\boldsymbol{p}\cdot\boldsymbol{r}}{4\pi\sigma r^3}. \tag{30.15}
$$
因此，测量远离源的两个电极之间电势差的导联记录的是 $\boldsymbol{p}(t)\cdot\boldsymbol{l}$，即偶极子在由电极位置与身体几何决定的导联矢量 $\boldsymbol{l}$ 上的投影。

**证明** 在电流源密度为 $s$ 的导体中，电流守恒与 Ohm 定律 $\boldsymbol{j} = -\sigma\nabla\varphi$ 给出 Poisson 方程 $\sigma\nabla^2\varphi = -s$，其解为 $\varphi = \int s(\boldsymbol{r}')/(4\pi\sigma\lvert\boldsymbol{r} - \boldsymbol{r}'\rvert)\,\mathrm{d}V'$。对 $\boldsymbol{d}/2$ 处的源 $+I$ 与 $-\boldsymbol{d}/2$ 处的汇 $-I$，展开到 $d/r$ 的一阶，得到式 (30.15)，其中 $\boldsymbol{p} = I\boldsymbol{d}$，代数与静电学中的**电偶极矩**（[5.3.1](/5.3.1)）相同。电势对 $\boldsymbol{p}$ 是线性的，所以任何导联记录的都是其分量的固定线性组合。$\square$

Einthoven（1903–1912）把电极放在右臂、左臂和左腿上，大致位于额状面内等边三角形的顶点，心脏在其中心。导联 I（左臂减右臂）把偶极子投影到水平轴上，导联 II（左腿减右臂）投影到其下方 $60^\circ$ 的轴上，导联 III（左腿减左臂）投影到 $120^\circ$ 的轴上；由于环路中三个电势差之和为零，每一时刻都有 $\mathrm{II} = \mathrm{I} + \mathrm{III}$（Einthoven 定律）。正常心电图的序列跟随兴奋：P 波（心房去极化，短于 $0.12\,\mathrm{s}$），PR 间期（$0.12$–$0.20\,\mathrm{s}$，主要是房室延迟），QRS 波群（心室去极化，短于 $0.12\,\mathrm{s}$，因心室质量大而幅度大），以及心室复极化的 T 波，在大多数导联中是直立的，尽管复极化与去极化相反，因为心室是从外向内复极化的。平均 QRS 电轴通常在 $-30^\circ$ 与 $+90^\circ$ 之间，给出心脏的取向以及心室肥大的情况。QT 间期随心率缩短，并加以校正，例如 $\mathrm{QT_c} = \mathrm{QT}/\sqrt{\mathrm{RR}}$（Bazett，RR 以秒计），正常上限约为 $0.44$–$0.46\,\mathrm{s}$；静息窦性心率超过每分钟 $100$ 次为心动过速。心脏的生理学是 [7.14](/7.14) 的主题。

## 思考题

1. 以半径 $10\,\mu\mathrm{m}$、$-70\,\mathrm{mV}$、$[\ce{K+}]_{\mathrm{in}} = 140\,\mathrm{mM}$ 的球形神经元为例，说明细胞只需分离其离子的极小一部分就能建立膜电势。若细胞损失其 $\ce{K+}$ 的 $1\,\%$，而没有任何补偿的离子运动，电势会是多少？

   **答** 电荷 $Q = c_{\mathrm{m}}AV = 10^{-2}\times4\pi(10^{-5})^2\times0.07 = 8.8\times10^{-13}\,\mathrm{C}$，$5.5\times10^6$ 个离子。细胞含有 $0.14 \times 4.19\times10^{-12}\,\mathrm{L} \times 6.02\times10^{23} = 3.5\times10^{11}$ 个 $\ce{K+}$，所以比例为 $1.6\times10^{-5}$。若未经补偿地损失 $1\,\%$（$3.5\times10^9$ 个离子，$5.6\times10^{-10}\,\mathrm{C}$），电势将改变 $Q/C = 5.6\times10^{-10}/1.26\times10^{-11}\,\mathrm{F} \approx 45\,\mathrm{V}$，这是不可能的：早在那之前，场就会驱使其他离子来补偿。体相中的电中性在约十万分之一的精度上成立。

2. 由 Nernst–Planck 方程推导 Nernst 方程，并计算表中 $37\,{}^\circ\mathrm{C}$ 时 $\ce{K+}$、$\ce{Na+}$、$\ce{Ca^2+}$ 与 $\ce{Cl-}$ 的 Nernst 电势。

   **答** $J = 0$ 给出 $\mathrm{d}\ln c/\mathrm{d}x = -(ze/k_{\mathrm{B}}T)\mathrm{d}\varphi/\mathrm{d}x$；跨膜积分得 $\varphi_{\mathrm{in}} - \varphi_{\mathrm{out}} = (k_{\mathrm{B}}T/ze)\ln(c_{\mathrm{out}}/c_{\mathrm{in}})$。取 $k_{\mathrm{B}}T/e = 26.7\,\mathrm{mV}$：$E_{\mathrm{K}} = 26.7\ln(4/155) = -98\,\mathrm{mV}$，$E_{\mathrm{Na}} = 26.7\ln(145/12) = +67\,\mathrm{mV}$，$E_{\mathrm{Ca}} = 13.35\ln(1.5/10^{-4}) = +128\,\mathrm{mV}$，$E_{\mathrm{Cl}} = -26.7\ln(120/4) = -91\,\mathrm{mV}$。

3. 用 GHK 电压方程，取 $P_{\mathrm{K}}:P_{\mathrm{Na}}:P_{\mathrm{Cl}} = 1:0.04:0.45$ 与枪乌贼轴突的浓度（胞内 $\ce{K+}$ 400、$\ce{Na+}$ 50、$\ce{Cl-}$ 40 mM；胞外 20、440、560 mM；$20\,{}^\circ\mathrm{C}$ 时 $k_{\mathrm{B}}T/e = 25.2\,\mathrm{mV}$），计算静息电位，以及 $P_{\mathrm{Na}}$ 升到 20 时的峰值电位。

   **答** 静息：分子 $20 + 0.04\times440 + 0.45\times40 = 55.6$，分母 $400 + 0.04\times50 + 0.45\times560 = 654$；$V = 25.2\ln(55.6/654) = -62\,\mathrm{mV}$。峰值：分子 $20 + 8800 + 18 = 8838$，分母 $400 + 1000 + 252 = 1652$；$V = 25.2\ln(5.35) = +42\,\mathrm{mV}$，与观察到的过冲接近。

4. 一个 $\ce{K+}$ 通道的电导为 $20\,\mathrm{pS}$。在 $-40\,\mathrm{mV}$、$E_{\mathrm{K}} = -90\,\mathrm{mV}$ 时，每毫秒开放通过多少离子？这与钠钾泵每秒约 100 个循环的周转相比如何？

   **答** $i = 20\,\mathrm{pS}\times50\,\mathrm{mV} = 1\,\mathrm{pA}$，每秒 $6.2\times10^6$ 个离子，每毫秒 6200 个。一个泵每秒移动 200 个 $\ce{K+}$：一个通道开放一毫秒，就抵消了一个泵 30 s 的工作。通道比载体快 4–5 个数量级，因为它们不需要每个离子一次构象变化。

5. 为什么 K⁺ 通道排斥更小的 Na⁺？设计一个实验，检验是否有两个离子同时占据过滤器。

   **答** 在过滤器中，离子脱去水合，被保持在水合 $\ce{K+}$ 几何构型上的八个羰基氧配位；$\ce{Na+}$ 太小，不能被它们全部接触，所以它从蛋白质获得的能量小于脱水所失去的（$\ce{Na+}$ 比 $\ce{K+}$ 约多 $70\,\mathrm{kJ\,mol^{-1}}$），其转移是不利的。多重占据的检验：用放射性示踪剂测量单向通量比（Ussing 的比值指数 $n' > 1$ 表明几个离子的单列运动，Hodgkin 与 Keynes 发现约为 2.5）；在 $\ce{K+}/\ce{Tl+}$ 混合物中寻找反常摩尔分数效应；在不同浓度下用反常散射体（$\ce{Tl+}$、$\ce{Rb+}$）通过晶体学确定离子位置。

6. 一个通道的 G–V 曲线的 Boltzmann 拟合给出表观电荷 $4\,e$，而门控电流测量给出每个通道 $13\,e$。用一个模型解释这一差异，并说明如何仅由离子电流测得真实电荷。

   **答** 若孔打开之前四个独立感受器必须全部移动，开放概率就是 $n^4$，其中 $n$ 是电荷为 $3.25\,e$ 的 Boltzmann 函数；在 $p_{\mathrm{o}}$ 可观的范围内，$n^4$ 看起来像表观电荷较低的 Boltzmann 函数，因为大部分电荷在关闭态之间移动。然而在很负的电势下，$p_{\mathrm{o}} \approx \exp(4 \times 3.25\,eV/k_{\mathrm{B}}T)$（至一常数）：$\ln p_{\mathrm{o}}$ 对 $V$ 的极限斜率给出总电荷，这要求测量非常小的开放概率，例如在含许多通道的膜片中做单通道记录。

7. 对方案 C1 ⇌ C2 ⇌ O，取图中的速率，计算开放时间常数、两个关闭时间常数，以及每个串的平均开放次数。

   **答** 开放：$1/k_{\mathrm{O}\to\mathrm{C2}} = 2\,\mathrm{ms}$。关闭：$Q_{\mathcal{CC}} = \begin{bmatrix}-0.2 & 0.2\\ 1.0 & -3.0\end{bmatrix}$ 的本征值：$\lambda^2 + 3.2\lambda + 0.4 = 0$，$\lambda = -0.130$ 与 $-3.07\,\mathrm{ms^{-1}}$，时间常数 $7.7\,\mathrm{ms}$ 与 $0.33\,\mathrm{ms}$。从 C2 出发，通道以概率 $2/3$ 开放，以概率 $1/3$ 去 C1（结束一个串），所以每个串的开放次数服从几何分布，平均 $1/(1/3) = 3$。

8. 枪乌贼巨轴突的 $R_{\mathrm{m}} = 1\,\mathrm{k\Omega\,cm^2}$，$c_{\mathrm{m}} = 1\,\mu\mathrm{F\,cm^{-2}}$，$R_{\mathrm{i}} = 30\,\Omega\,\mathrm{cm}$，半径 $250\,\mu\mathrm{m}$。计算 $\tau_{\mathrm{m}}$、$\lambda$ 以及传导速度的标度 $\lambda/\tau_{\mathrm{m}}$。对膜相同的 $1\,\mu\mathrm{m}$ 轴突，$\lambda/\tau_{\mathrm{m}}$ 如何变化？

   **答** $\tau_{\mathrm{m}} = 10^3 \times 10^{-6} = 1\,\mathrm{ms}$。$\lambda = \sqrt{aR_{\mathrm{m}}/2R_{\mathrm{i}}} = \sqrt{0.025\times1000/60}\,\mathrm{cm} = 0.65\,\mathrm{cm}$。$\lambda/\tau_{\mathrm{m}} = 6.5\,\mathrm{m\,s^{-1}}$，与实测的 $21\,\mathrm{m\,s^{-1}}$ 同量级（无量纲因子约为 3，因为上升支期间活动膜电导远大于静息时）。对 $a = 0.5\,\mu\mathrm{m}$（直径 1），$\lambda$ 减小 $\sqrt{500} = 22$ 倍，标度为 $0.29\,\mathrm{m\,s^{-1}}$，与体温下细的无髓 C 纤维的 $\sim 1\,\mathrm{m\,s^{-1}}$ 一致。

9. 数值验证命题 30.5.1：对 $\alpha = 0.2$ 模拟 $\partial_tu = \partial_x^2u + u(1 - u)(u - \alpha)$，并把前沿速度与预言比较。

   **答** 取 $k = 1$，$\lambda = \tau = 1$ 的预言：$v = (1/\sqrt2)(1 - 0.4) = 0.424$。有限差分模拟（网格 $\Delta x = 0.2$，$\Delta t = 0.01$，初始阶跃 $x < 10$ 时 $u = 1$）给出位置线性增长的前沿；在 $t = 20$ 到 $t = 100$ 拟合得 $v \approx 0.42$，在离散化误差之内：

   ```python
   import numpy as np
   dx, dt, a = 0.2, 0.01, 0.2
   x = np.arange(0, 200, dx); u = (x < 10).astype(float)
   pos = []
   for step in range(10001):
       lap = np.roll(u, 1) - 2 * u + np.roll(u, -1); lap[0] = lap[-1] = 0
       u = u + dt * (lap / dx**2 + u * (1 - u) * (u - a))
       if step % 1000 == 0: pos.append(x[np.argmin(np.abs(u - 0.5))])
   print(np.polyfit(np.arange(len(pos))[2:] * 10.0, pos[2:], 1)[0])   # about 0.42
   ```

10. 估计从脚趾到脊髓（$1\,\mathrm{m}$）的传导时间：无髓 C 纤维（$1\,\mathrm{m\,s^{-1}}$）与 $15\,\mu\mathrm{m}$ 的有髓 $\mathrm{A\alpha}$ 纤维。若无髓轴突在 $1\,\mu\mathrm{m}$ 时 $v = 1\,\mathrm{m\,s^{-1}}$ 且 $v \propto \sqrt d$，它需要多粗的直径才能与有髓纤维相当？

    **答** C 纤维：$1\,\mathrm{s}$。$\mathrm{A\alpha}$：$v \approx 6 \times 15 = 90\,\mathrm{m\,s^{-1}}$，$11\,\mathrm{ms}$。无髓轴突需要 $\sqrt{d/1\,\mu\mathrm{m}} = 90$，$d = 8100\,\mu\mathrm{m} \approx 8\,\mathrm{mm}$；髓鞘使直径节省了 500 倍，横截面积节省了 $2.5\times10^5$ 倍。

11. 一条电鳗以 $500\,\mathrm{V}$ 向电阻 $1\,\mathrm{k\Omega}$ 的鱼放电 $2\,\mathrm{ms}$。传递了多少能量？为了恢复梯度，至少须水解多少个 ATP 分子（取 $-\Delta G_{\mathrm{ATP}} = 9\times10^{-20}\,\mathrm{J}$）？为什么电鳗以短脉冲放电？

    **答** 功率 $V^2/R = 250\,\mathrm{W}$，每个脉冲能量 $0.5\,\mathrm{J}$；至少需要 $0.5/(9\times10^{-20}) \approx 6\times10^{18}$ 个 ATP，约 $10\,\mu\mathrm{mol}$，考虑内部损耗则要多好几倍（在阻抗匹配时，一半能量在器官中耗散）。数毫秒的脉冲、以每秒数百赫兹重复，就足以兴奋猎物的运动神经元与肌肉（电鳗的放电像远程电击枪），同时限制所耗费的能量和电细胞梯度的耗竭。

12. 一位患者的平均 QRS 矢量在额状面内指向 $-60^\circ$。QRS 波群在导联 I、II 与 III 中的正负如何？这提示什么？

    **答** 投影：导联 I，$\cos(-60^\circ) = +0.5$（正）；导联 II，$\cos(-120^\circ) = -0.5$（负）；导联 III，$\cos(-180^\circ) = -1$（强烈为负）；验证 II = I + III：$-0.5 = 0.5 - 1$。比 $-30^\circ$ 更负的电轴是左轴偏移，例如见于左前分支阻滞或左心室肥大。
