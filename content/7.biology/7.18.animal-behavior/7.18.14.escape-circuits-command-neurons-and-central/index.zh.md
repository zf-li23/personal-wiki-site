前几章沿着感觉信息向内追踪，从过滤刺激的受体，到识别猎物、捕食者和逼近物体的特征检测器（[7.18.12](/7.18.12)、[7.18.13](/7.18.13)）。本章沿它向外追踪，到把决定转化为协调运动的回路。有两类运动输出教给神经行为学家的最多。逃避反应是动物完成的最快的行为，对速度的选择压力造就了如此简单的回路，具有巨型神经元和电突触，从刺激到肌肉的整条通路都可以追踪。游泳、行走、飞行、呼吸和鸣叫等节律性行为由产生有模式的输出而无需有模式的输入的网络产生：中枢模式发生器。二者之间有一个自 20 世纪 60 年代起一直伴随神经行为学的问题：一种行为是像行为学家的释放机制所暗示的那样由特定神经元“命令”的，还是从分布式回路的动力学中涌现出来的？

细胞层面的构件（动作电位、化学突触与电突触、传导速度）见 [7.14.4](/7.14.4)、[7.14.5](/7.14.5) 与 [7.18.6](/7.18.6)；节律产生的回路机制见 [7.14.6](/7.14.6)，哺乳动物的脊髓回路见 [7.16.30](/7.16.30)。这里我们集中讨论这些回路对行为起什么作用，以及经典实验是如何设计的。

## 14.1. 逃避的设计

### 14.1.1. 三项要求

被捕食者攻击的猎物只有不到一秒的时间作出反应。它的逃避必须满足三项要求，这些要求之间有些冲突：

1. *速度。*反应必须在捕食者攻击之前开始。从刺激到运动的潜伏期常常低于 $10\,\mathrm{ms}$，接近由传导、突触延迟和肌肉激活所决定的物理下限。
2. *方向。*运动必须把动物带离威胁，或至少不朝向它，所以回路必须知道刺激来自何方。
3. *不可预测性。*能够预测逃避轨迹的捕食者可以预先拦截。Humphries 与 Driver（1970）称为*变幻行为*（protean behavior）的杂乱或多变的逃避路径使预期成为不可能。

速度偏好突触少、轴突粗、采用电传递的回路；方向要求对身体两侧进行比较；不可预测性要求变异。下面各节的回路显示了这些要求如何得到满足，以及付出了什么代价。决策的经济学方面，即何时逃、逃多远，属于行为生态学，见 [7.18.24](/7.18.24)。

**定义 14.1.1（逃避反应）** **逃避反应**是使动物离开突然的威胁性刺激（如攻击的捕食者、逼近的物体或突然的机械或声学扰动）的快速运动，通常由专门的神经通路以最短的潜伏期启动。

### 14.1.2. 巨纤维

许多逃避通路含有轴突异常粗大的神经元。无髓轴突的传导速度随直径的平方根增长（[7.18.6](/7.18.6#sec-6.3)），所以必须沿身体迅速传递信号而又没有髓鞘的动物，可以通过加粗轴突来做到这一点。

**定义 14.1.2（巨纤维）** **巨纤维**是中间神经元或运动神经元的一种直径异常大的轴突，远比邻近的轴突粗，沿身体全长快速传导信号并触发逃避反应；例子有乌贼的巨轴突、蚯蚓与螯虾的内侧和外侧巨纤维，以及蝇的巨纤维。

巨纤维通常还具有另外三种性质：它们形成电突触，消除了化学传递的突触延迟；它们同时激活许多运动神经元，使反应所需的所有肌肉一起收缩；它们以全或无的方式放电，往往只有一个脉冲，使反应成为定型的、最大限度的运动。巨纤维在环节动物、软体动物、节肢动物和脊椎动物中独立演化，是由同一物理约束驱动的**趋同演化**的例子（[7.14.4](/7.14.4)）。

## 14.2. Mauthner 细胞与 C 形起跳

### 14.2.1. 解剖与行为

金鱼听到突然的声音或感到水流冲击时，会在约 $10$–$15\,\mathrm{ms}$ 内把身体弯成 C 形，然后用一下尾部划动射出。这种 *C 形起跳*（C-start）包括两个阶段：躯干肌肉快速的单侧收缩，使头部转离刺激（第一阶段），随后是对侧的推进划动（第二阶段）。C 形起跳由一对可辨认的神经元触发。

**定义 14.2.1（Mauthner 细胞）** **Mauthner 细胞**是大多数鱼类和两栖类幼体后脑第 4 菱脑节中的一对巨型网状脊髓神经元，接受听觉、前庭、侧线与视觉输入，它的单个动作电位经一根粗大的交叉轴突沿脊髓下行，兴奋对侧躯干肌肉的运动神经元，启动 C 形起跳逃避。

每个 Mauthner 细胞有两条大的树突：外侧树突接受来自球囊和侧线的第八对脑神经传入纤维，腹侧树突接受来自视顶盖的视觉输入。听觉传入纤维终止为大的“棒状末梢”，形成混合突触，同时具有缝隙连接（电）和谷氨酸能（化学）成分。轴突立即越过中线，沿脊髓全长下行，在那里兴奋对侧的初级运动神经元和中间神经元。大型鱼类中 Mauthner 轴突的传导速度可达约 $80\,\mathrm{m\,s^{-1}}$，从耳到肌肉的通路只含两三个突触，所以在刺激后 $5$–$10\,\mathrm{ms}$ 内，与放电细胞相反的一侧就出现最初的肌肉电位。弯曲背离受刺激的一侧，因为靠近声源一侧的第八对脑神经输入更强。

### 14.2.2. 使反应成为单侧的

只有一个 Mauthner 细胞放电而另一个不放电，C 形起跳才有用：两个同时放电会收缩两侧，使鱼僵直。几种抑制机制保证了这一点：

- *反馈抑制。*放电的 Mauthner 轴突的侧支兴奋抑制性中间神经元（颅中继神经元），后者抑制两个 Mauthner 细胞。抑制在一毫秒之内到达，阻止该细胞再次放电，并阻止对侧细胞放电。
- *前馈抑制。*第八对脑神经传入纤维兴奋抑制性中间神经元，后者经短暂延迟抑制 Mauthner 细胞，所以只有强而突然的刺激才能在抑制到达之前达到阈值；微弱或缓慢上升的刺激被滤除。
- *电抑制。*其中一些中间神经元（被动超极化电位神经元）在 Mauthner 轴突的起始段周围形成致密的轴突帽，它们的同步放电在那里产生胞外正电场，直接使脉冲起始区超极化，无需任何递质（Furukawa 与 Furshpan 1963）。这是已知的少数由电场效应产生抑制的例子之一。
- *脊髓抑制。*在脊髓中，放电的 Mauthner 轴突兴奋连合的甘氨酸能中间神经元，后者抑制对侧运动神经元，使一侧的弯曲不会受到另一侧的对抗。

![为什么只有一个 Mauthner 细胞放电（带示意性参数的漏电积分–发放模型）。两个 Mauthner 细胞（左 M，蓝色；右 M，橙色）在声音开始时（点线）各自从同侧耳接受一个短暂的兴奋性输入，左侧输入强 6 %，另加噪声。A：有反馈抑制时，任一细胞的第一个脉冲触发一次抑制，把两个细胞钳制约 15 ms；只有一个细胞放电，鱼作出背离该细胞输入一侧的单侧 C 形弯曲。两侧输入几乎相等时，由噪声决定哪个细胞放电（左侧试验：右侧细胞获胜）。B：抑制被阻断、输入相同时，两个细胞都放电，并且反复放电；收缩将是双侧的，鱼不会转向。](./plots/mauthner.py)

### 14.2.3. 必要但不充分

Mauthner 细胞对逃避是必要的吗？对斑马鱼幼体 Mauthner 细胞的激光消融回答了这个问题（Liu 与 Fetcho 1999）。消融之后，幼体仍能从突然的刺激中逃脱，但潜伏期更长；只有当相邻菱脑节中两对节段同源的神经元（MiD2cm 与 MiD3cm，小的“Mauthner 同源物”）也被消融时，对头部刺激的逃避才消失。行为分析证实幼体有两种 C 形起跳：短潜伏期的 C 形起跳（$5$–$10\,\mathrm{ms}$），需要 Mauthner 细胞；以及长潜伏期的 C 形起跳（约 $20$–$30\,\mathrm{ms}$），更慢，角度变化更大，由其他网状脊髓神经元控制（Burgess 与 Granato 2007）。因此 Mauthner 细胞对最快的逃避是充分的，但对一般的逃避并非必要：它是逃避神经元网络中最快的成员。

Mauthner 细胞也受到调节。它的反应对重复刺激习惯化，强声之前不久出现的弱声会降低 C 形起跳的概率（前脉冲抑制，这一现象在人类中也被作为感觉运动门控的指标研究）。C 形起跳的概率取决于社会背景：在丽鱼中，优势雄鱼比从属雄鱼更不容易逃避，5-羟色胺与多巴胺调节 Mauthner 细胞的兴奋性。视觉的逼近刺激通过顶盖到达它（[7.18.13](/7.18.13#sec-13.3.3)），使幼鱼从沿碰撞路线逼近的暗物体面前逃脱。因此，即使是最快的逃避，也是权衡了背景之后作出的决定。

## 14.3. 无脊椎动物的逃避回路

### 14.3.1. 螯虾的甩尾

螯虾通过把腹部快速屈到身体下方而逃避，这使它向后穿过水体：甩尾逃避（tail flip）。腹神经索中的两对巨型中间神经元触发不同方向的甩尾（[7.17.21](/7.17.21)）：

| | 外侧巨纤维（LG） | 内侧巨纤维（MG） |
|---|---|---|
| 刺激 | 腹部突然的触碰或水流冲击 | 头部突然的触碰，前方突然的视觉刺激 |
| 结构 | 由电突触耦联的一串节段性神经元 | 每侧一个神经元，胞体在脑中 |
| 运动 | 只有腹部前部屈曲；螯虾向上向前翻转，远离后方 | 整个腹部屈曲；螯虾径直向后射出，远离前方 |

两者中，巨型中间神经元的单个脉冲就触发反应，从刺激到屈曲的潜伏期约为 $10\,\mathrm{ms}$。1959 年，Furshpan 与 Potter 在 LG 轴突与巨型运动神经元之间的突触处发现了第一个被鉴定的电突触：一种整流连接，能让电流从中间神经元传到运动神经元，反向则不行。LG 回路由 Krasne、Wine 及同事绘出：来自尾扇的机械感觉传入纤维既通过电突触直接兴奋 LG，也通过感觉中间神经元间接兴奋它；LG 随后兴奋运动巨神经元和每个节段的其他屈肌运动神经元，并通过一个中间神经元抑制伸肌和 LG 本身（回返抑制），使反应成为单个不间断的屈曲。

LG 回路的三种性质把它与行为联系起来。第一，反应随重复刺激迅速习惯化；习惯化的部位是感觉传入纤维与中间神经元之间的化学突触，它发生抑制，而电通路则不然。第二，螯虾被束缚、进食或另有活动时，回路受到来自脑的下行抑制，使甩尾在无用时被抑制。第三，社会地位对它进行调节：在优势螯虾中，5-羟色胺提高 LG 的兴奋性，而在从属个体中，同一种递质却降低它，因为两类动物表达不同的 5-羟色胺受体（Yeh、Fricke 与 Edwards 1996；[7.18.7](/7.18.7)）。螯虾也有非巨纤维介导的逃避，较慢且可以转向，在攻击不那么突然时使用。

### 14.3.2. 蝇的巨纤维系统

*Drosophila* 通过跳到空中并飞走来躲避逼近的物体（[7.18.13](/7.18.13#sec-13.3.3)）。最快的起飞由巨纤维系统驱动。两条巨纤维（GF）中的每一条，胞体和树突在脑中，在那里接受来自逼近敏感的投射神经元（LC4、LPLC2）的视觉输入和来自触角的机械感觉输入，其轴突下行到胸神经节。在那里它有两个输出：

- 一个混合的电突触与胆碱能突触，连到背转节肌（TTM，中足的跳跃肌）的运动神经元；以及
- 一个电突触，连到外周突触中间神经元（PSI），后者兴奋背纵肌（DLM，使翅下压的间接飞行肌）的运动神经元。

电突触由间隙连接蛋白 Shaking-B（innexin）形成；*shakB* 突变的果蝇巨纤维传递有缺陷。单个 GF 脉冲在约 $1\,\mathrm{ms}$ 内引起 TTM 收缩，几分之一毫秒后引起 DLM 收缩。同一运动神经元池的运动神经元之间的电突触也使它们的放电同步，这是一条一般原理：电耦联的运动神经元一起放电，产生同步的运动，如海兔的喷墨或跳蚤的跳跃。

果蝇以两种方式起飞（von Reyn 等人 2014）。在*长模式*起飞中，果蝇先举起翅，再伸展腿，把自己送入稳定的飞行。在*短模式*起飞中，腿在翅举起之前伸展；跳跃快几毫秒，但果蝇常常翻滚。短模式起飞由 GF 脉冲驱动；长模式起飞则在没有 GF 活动的情况下，经由平行的下行神经元发生。在系住的果蝇观看逼近圆盘时记录 GF，表明 GF 发放一个或几个脉冲，起飞的模式取决于该脉冲的时间：如果 GF 在长模式序列完成之前放电，它触发短模式起飞，压过较慢的程序；如果它较晚放电或根本不放电，果蝇完成其长模式起飞。快速逼近的刺激使 GF 较早放电，主要产生短模式起飞；缓慢逼近的刺激主要产生长模式起飞。因此行为选择是通过两条通路之间的竞赛实现的，由单个脉冲的时间决定，并在威胁最紧迫时以稳定性换取速度。

![脉冲时间选择 *Drosophila* 的逃避模式（依据 von Reyn 等人 2014 的模型；示意性参数）。当逼近的圆盘达到约 20° 时，一条较慢的非巨纤维通路启动长模式起飞，平均 15 ms 后完成；当图像角速度超过阈值（各次试验不同）时，巨纤维发放一个脉冲。A：巨纤维脉冲先到、产生短模式起飞的起飞所占比例，从快速逼近时（l/|v| 小）的几乎 1 降到缓慢逼近时的几乎 0（每点 300 次模拟试验）。B：快速（红色，l/|v| = 20 ms）与缓慢（蓝色，160 ms）逼近时，图像角速度对距碰撞时间的关系，并标出巨纤维阈值的中位数（虚线）以及长模式起飞从启动到完成的时间间隔（条形）。快速逼近中，角速度在长模式起飞完成之前越过阈值；缓慢逼近中，长模式起飞早在达到阈值之前就已结束。](./plots/gf-modes.py)

### 14.3.3. 蟑螂与风

美洲大蠊（*Periplaneta americana*）靠感觉攻击之前的一阵气流，从蟾蜍的舌或人的脚下逃脱。尾须是腹部末端的两个附肢，每个带有约 200 根丝状毛；每根毛有铰链，只能在一个平面内运动，其感觉神经元对某一方向的空气位移放电。毛的传入纤维在末端腹神经节汇聚到七对巨型中间神经元上，后者的粗轴突上行到胸神经节。Camhi 及同事表明，蟑螂在几十毫秒内背离风转身，转身的方向由风的方向决定。

没有哪一个巨型中间神经元单独编码风向。每个腹侧巨型中间神经元对很宽的方向范围反应，具有大致余弦形的调谐，风向由群体的相对活动表征：风向可以恢复为以放电率加权的偏好方向的向量和，即后来在猴运动皮层的手臂运动中发现的那类群体向量。杀死个别巨型中间神经元，会按群体向量所预测的方式使逃避方向发生偏移。逃避本身在细节上是不可预测的：蟑螂沿相对于威胁的几个偏好角度之一逃走（Domenici 等人 2008），在其中似乎随机选择，这是建立在定向反应之上的变幻变异的例子。

## 14.4. 命令神经元

### 14.4.1. 概念

1964 年，Wiersma 与 Ikeda 发现，刺激螯虾神经索连合中的单根纤维，会引起完整的协调行为，例如游泳足的节律性拍动或腹部的某个特定姿势。他们把这些纤维称为*命令纤维*：其活动足以引起整个行为的神经元，行为的细节由其下方的回路产生。这一想法很有吸引力，因为它似乎把行为学家的释放机制与可辨认的细胞联系了起来，这个词迅速传播开来。它也被宽泛地使用：任何刺激后能引起某种行为的神经元很快都被称为命令神经元。

Kupfermann 与 Weiss（1978）提出了使这一概念可检验的标准。

**定义 14.4.1（命令神经元）** **命令神经元**是其活动对于某种特定行为的发生既必要又充分的神经元：神经元在行为之前和期间对其自然刺激放电；以其自然模式刺激神经元使其放电会引发该行为（充分性）；而去除或使它沉默则取消对这些刺激的反应（必要性）。

很少有神经元满足所有标准。螯虾的外侧巨纤维满足：每当腹部刺激引起甩尾时它都放电，其中一个脉冲就引起甩尾，使它超极化则阻止甩尾。蟋蟀的 AN2 中间神经元对飞行中背离超声的转向既必要又充分（[7.18.12](/7.18.12#sec-12.5.3)）。在田蟋蟀的脑中，一对下行中间神经元对召唤鸣声既必要又充分：它们在整个鸣叫期间放电，使它们去极化会引起鸣叫，使它们超极化则使鸣叫停止（Hedwig 2000；[7.18.16](/7.18.16)）。在成年 *Drosophila* 中，一对下行的“月球漫步”神经元经光遗传学激活后使果蝇向后行走，使它们沉默则减少果蝇遇到障碍时的后退行走（Bidaye 等人 2014）。相反，Mauthner 细胞对短潜伏期的 C 形起跳是充分的，但对逃避并非必要（14.2.3 节）。

### 14.4.2. 从命令神经元到命令系统

大多数行为并不由单个神经元命令。更常见的是，一组神经元，其中没有一个单独是必要的，共同启动行为，而每个神经元又参与多种行为。几项观察塑造了这一看法：

- *Roeder 的螳螂。*Roeder 发现，节段神经节与脑隔离的螳螂在神经节受到刺激时仍能作出有力而完整的运动，切断前脑与其余神经系统之间的连接，会得到一只同时行走和抓握的螳螂。被斩首的雄螳螂会作出持续的交配运动，这些运动通常受到脑的抑制；这就是为什么头被雌螳螂吃掉的雄螳螂仍能交配。因此脑主要通过使节段回路摆脱紧张性抑制来在行为之间进行选择，这一去抑制原理也见于脊椎动物的基底神经节。
- *医蛭。*触碰医蛭时，它要么游泳，要么爬行，在离体神经索中二者概率几乎相等。Briggman、Abarbanel 与 Kristan（2005）用电压敏感染料同时对一个神经节中大多数神经元的活动成像，发现一群神经元，其联合活动在行为选择表现出来之前几百毫秒就向其中一种行为分化，早于任何单个神经元所能预测的时间。这一群中有一个神经元，即 208 号细胞，使选择产生偏向：刺激时使它去极化有利于爬行，使它超极化有利于游泳。决定是具有两个吸引子状态的网络中的动态过程，而不是命令神经元中的开关。
- *蟾蜍*（[7.18.13](/7.18.13#sec-13.2.4)）。Ewert 的命令释放系统是顶盖与顶盖前区神经元的组合，其联合活动释放捕食的一个成分。

现代的综合观点区分“类命令”神经元（可以通过光遗传学或电刺激来鉴定）与决定本身（通常取决于许多神经元和内部状态）。在实验中对某一行为充分的神经元，在自然条件下可能只是通向该行为的几条平行路线之一。命令神经元概念作为关于神经系统如何按层级组织的假说仍然有用，Kupfermann–Weiss 标准仍然是检验它的标准。

## 14.5. 中枢模式发生器

### 14.5.1. 没有节律性输入的节律

游泳、行走、飞行、咀嚼、呼吸和鸣叫都是节律性运动，肌肉一个周期接一个周期地以固定的顺序与相位关系收缩。20 世纪初有两种关于其起源的假说在竞争。按 Sherrington 的链式反射假说，运动的每一相产生感觉反馈，触发下一相。按 Thomas Graham Brown（1911）的观点，节律是由脊髓本身产生的：在切断背根、使脊髓得不到任何感觉反馈的去大脑猫中，他仍然观察到后肢屈肌与伸肌交替的节律性收缩。他提出，节律是由两组相互抑制的神经元，即“半中枢”产生的，一组驱动屈肌，另一组驱动伸肌，每一组在一段活动后疲劳，从而使另一组解除抑制。

决定性的实验出现在五十年后。Wilson（1961）去除了蝗虫翅的所有感觉反馈，发现孤立的胸神经节在受到非特异性刺激时，仍能产生飞行的运动模式，升肌与降肌之间的相位关系正确，只是频率低于完整动物。类似的*虚拟*节律（fictive rhythm），即在肌肉被麻痹或被切除的标本中从运动神经记录到的节律，此后已在七鳃鳗、医蛭和蝌蚪的游泳，猫和竹节虫的行走，哺乳动物的呼吸以及蟋蟀的鸣叫中获得。节律由现在称为**中枢模式发生器**（[7.14.6](/7.14.6#sec-6.4.2)）的网络在中枢产生；感觉反馈对它进行调节，而不是创造它。Brown 的两组神经元相互抑制的机制现在称为**半中枢振荡器**（[7.14.6](/7.14.6#sec-6.4.3)）。

### 14.5.2. 非洲爪蟾蝌蚪的游泳回路

在细胞水平上分析得最详细的最简单的脊椎动物中枢模式发生器，是非洲爪蟾（*Xenopus laevis*）刚孵化的蝌蚪的，由 Alan Roberts 及同事自 20 世纪 70 年代起在布里斯托尔研究。两日龄的蝌蚪长约 $5\,\mathrm{mm}$，大部分时间悬挂在头部黏着腺分泌的一缕黏液上。受到触碰或光线变暗时，它以 $10$–$25\,\mathrm{Hz}$ 的身体侧向波动游开：弯曲波以约 $15\,\mathrm{cm\,s^{-1}}$ 从头传到尾，推动蝌蚪以约 $5\,\mathrm{cm\,s^{-1}}$ 向前。蝌蚪的头撞到物体并黏附上去时，游泳停止。游泳就是蝌蚪的逃避行为。

这一标本有不同寻常的优点。脊髓每侧只含约 $1\,000$ 个神经元，约八种解剖类型；整只蝌蚪可以用阻断神经肌肉接头的 α-银环蛇毒素麻痹，这时轻触皮肤即可诱发虚拟游泳，并从腹根记录，同时对可辨认神经元进行细胞内或全细胞记录。三类神经元构成脊髓每一半中枢模式发生器的核心：

| 神经元类型 | 递质与投射 | 在节律中的作用 |
|---|---|---|
| 下行中间神经元（dIN） | 谷氨酸，同侧，下行；也有电耦联 | 兴奋同侧所有 CPG 神经元；其 NMDA 介导的兴奋与电耦联维持背景去极化 |
| 连合中间神经元（cIN） | 甘氨酸，交叉到对侧 | 抑制对侧所有 CPG 神经元 |
| 运动神经元 | 乙酰胆碱作用于肌肉，另有中枢内的谷氨酸与乙酰胆碱 | 驱动躯干肌肉；电耦联，因而同步放电 |

在虚拟游泳期间，一个半中枢的每个神经元每个周期放电一个脉冲，两侧交替。节律产生于兴奋与抑制的相互作用。一侧的神经元放电时，它们的连合中间神经元抑制另一侧 $25$–$40\,\mathrm{ms}$。被抑制的神经元由持续的 NMDA 介导的兴奋保持去极化，在抑制性电位结束时放出一个反弹脉冲（抑制后反弹），这又反过来抑制第一侧。因此，$40$–$100\,\mathrm{ms}$ 的周期近似为两侧抑制性电位持续时间之和，这一定量预测已被实验证实。下行中间神经元延伸到后脑，在那里充当节律的起搏者：它们在自身兴奋与耦联的作用下放电，是每个周期中最先放电的神经元。

波如何从头传到尾？每个节段含有一个半中枢振荡器，各振荡器相互耦联。每个节段的兴奋性中间神经元数目从头到尾递减，对运动神经元的兴奋性驱动随之递减，所以吻侧节段在每个周期中较早达到阈值并领先；用药物减小这一梯度（向尾部脊髓施用 NMDA 激动剂）会减小吻尾延迟，增大它（向尾部施用 NMDA 拮抗剂）则增大延迟。相继节段之间的相位滞后保持为周期的大致恒定的一部分，所以身体上总是含有约一个波长，与游泳速度无关。

![半中枢振荡器与行波（Matsuoka 型的速率模型，示意性参数）。A：两个带慢适应的速率单元，由相互抑制耦联并由恒定的兴奋驱动，交替活动：活动的单元适应，它对另一侧的抑制减弱，另一侧得以逃脱并接替。B：十二个节段，每个有左右半中枢，同侧与相邻节段以弱兴奋耦联，固有频率从头到尾递减。每个节段中左侧爆发（蓝色）与右侧爆发（橙色）交替，每次爆发在下一个尾侧节段开始得稍晚：这是一个头到尾的活动波，相位滞后近乎恒定，如同游泳的蝌蚪。](./plots/half-center.py)

蝌蚪的回路也显示了行为如何启动与停止。触碰皮肤兴奋 Rohon–Beard 感觉神经元，后者兴奋感觉通路中间神经元，再募集后脑中的下行中间神经元；一旦启动，活动即自我维持。对头部或黏着腺的压力，如蝌蚪撞上物体时，兴奋三叉神经传入纤维，激活后脑中的一群 GABA 能神经元，抑制下行中间神经元并使游泳停止。通过松果体眼感受到的光线变暗则启动游泳。因此在脊椎动物中，启动、维持和停止整个行为的回路可以逐个神经元地描述，这就是为什么 Roberts 选择蝌蚪：沿着 Coghill（1929）的思路，他寻找一种最简单的脊椎动物，其自然行为可以在细胞水平上被理解，这是 Krogh 原则（[7.18.6](/7.18.6)）的一个清楚的例子。

### 14.5.3. 其他模式发生器

同样的构件在整个动物界的模式发生器中反复出现（[7.14.6](/7.14.6#sec-6.5)）：

- 海蛞蝓 *Tritonia diomedea* 接触捕食性海星后触发的逃避游泳，由整个身体背腹方向交替的二至二十次屈曲组成。它由三类中间神经元（背侧游泳中间神经元、脑神经元 2 与腹侧游泳中间神经元）产生，兴奋、抑制与延迟兴奋的相互作用产生了这种交替，而它由背侧斜坡中间神经元的持续放电启动（Getting；Frost 与 Katz）。
- 斑光蟾鱼持续数分钟到一小时的嗡鸣歌声，由三个核组成的后脑 CPG 产生：发声前起搏核，其持续去极化决定每次叫声的时长；发声起搏核，决定约 $100\,\mathrm{Hz}$ 的频率；以及发声运动核，其运动神经元每周期使鱼鳔的发声肌收缩一次（Bass）。同一个 CPG 以不同的时间模式产生咕噜声和咆哮声，其输出受类固醇激素调节（[7.18.19](/7.18.19)）。
- 蟋蟀的鸣声由受脑的命令神经元控制的胸腹部 CPG 产生（[7.18.16](/7.18.16)）。
- 昆虫与哺乳动物的行走由每条腿或每个关节的耦联振荡器产生，其协调随速度变化（[7.16.30](/7.16.30#sec-30.5)）。

### 14.5.4. 感觉反馈与运动程序

中枢产生并不意味着感觉反馈不重要。在完整的蝗虫中，翅铰链处每个翅拍放电一次的牵张感受器，把飞行节律的频率提高到正常值，并帮助调整降肌活动的时间；去除它们会降低频率，节律性地刺激它们则能夹带孤立的 CPG（Wendler；Pearson）。在行走中，腿中的负荷感受器决定一条腿何时可以抬起，使动物不会抬起仍在承重的腿。因此反馈使中枢节律适应身体与环境的力学。

CPG 产生的模式是*运动程序*的一个例子：一组在时间上有结构的指令，一旦启动，无需反馈即可运行到底。经典行为学的固定行为型（[7.18.3](/7.18.3)）在这类程序中有其神经上的对应物。灰雁的滚蛋动作即使在蛋被拿走后也会继续，就像虚拟游泳在被麻痹的蝌蚪中继续一样。这两个术语的差别在于层次：行为学家描述行为，神经行为学家描述回路。

一个 CPG 也可以产生不止一种行为。控制海兔摄食的网络，根据特定神经元的活动以及改变其性质的调制性输入，产生摄入或排出，而甲壳动物的口胃神经节在不同的神经调质下产生不同的节律（[7.18.7](/7.18.7)）。受调制而配置成不同模式的多功能网络似乎是常态而非例外。

## 小结

- 逃避行为必须快速、有方向并且不可预测（变幻）；逃避反应（定义 14.1.1）常由具有电突触和全或无输出的巨纤维（定义 14.1.2）驱动。

| 系统 | 触发 | 关键神经元 | 值得注意的机制 |
|---|---|---|---|
| 鱼的 C 形起跳 | 突然的声音、水流冲击、逼近 | Mauthner 细胞（定义 14.2.1） | 混合突触；反馈、前馈与场效应抑制保证只有一个细胞放电；短潜伏期与长潜伏期 C 形起跳 |
| 螯虾甩尾 | 触碰腹部（LG）或头部（MG） | 外侧与内侧巨纤维 | 发现的第一个电突触；化学突触处的习惯化；5-羟色胺与社会地位 |
| 蝇的起飞 | 逼近 | 巨纤维 → TTM 与 PSI → DLM | Shaking-B 缝隙连接；脉冲时间选择短模式或长模式 |
| 蟑螂 | 一阵风 | 尾须巨型中间神经元 | 群体向量；多个偏好逃避角度 |

- 命令神经元（定义 14.4.1，Kupfermann–Weiss）：必要且充分；螯虾 LG、蟋蟀 AN2 与召唤鸣声神经元、果蝇月球漫步神经元满足该标准；大多数决定由分布的群体作出（医蛭的游泳与爬行选择，208 号细胞；Roeder 的螳螂；Ewert 的命令释放系统）。
- **中枢模式发生器**在没有节律性输入的情况下产生节律（Graham Brown 1911；Wilson 1961）；**半中枢振荡器**（相互抑制加反弹或适应）是核心模体。*Xenopus* 蝌蚪：dIN（谷氨酸、NMDA、电耦联）、cIN（甘氨酸）、运动神经元；每周期一个脉冲；周期 ≈ 两个 IPSP 的持续时间；吻尾梯度决定波。
- 感觉反馈使中枢节律适应身体（蝗虫的翅牵张感受器）；运动程序是固定行为型在神经上的对应物；CPG 是多功能的并受到调制。

## 思考题

1. 为什么 Mauthner 系统使用几种抑制，而不是一种？

   **答** 每种抑制解决不同的问题。反馈抑制保证一个 Mauthner 细胞放电后，它本身及其伙伴在几毫秒内都不再放电，使反应成为单个的单侧弯曲。前馈抑制设定了一个时间滤波器：只有突然而强的刺激才能在抑制到达之前使细胞去极化到阈值，所以缓慢上升的刺激和微弱的噪声不会触发逃避。轴突帽的场效应抑制在不到一毫秒内作用于脉冲起始区，快于任何化学突触，当两个细胞几乎同时接受输入时这是必需的。脊髓连合抑制保证与弯曲相反一侧的运动神经元沉默，使弯曲不受对抗。

2. 对 Mauthner 细胞与螯虾外侧巨纤维应用 Kupfermann–Weiss 标准。哪一个是命令神经元？

   **答** 螯虾 LG 在每次腹部刺激引起的甩尾时都放电，它的单个脉冲就引起甩尾，阻止它放电（通过超极化）则取消对这些刺激的甩尾：它是必要且充分的，因而是该行为的命令神经元。Mauthner 细胞在短潜伏期 C 形起跳期间放电，其中的一个脉冲足以产生 C 形弯曲，但消融它之后斑马鱼幼体仍能逃避（潜伏期更长，经由其他网状脊髓神经元），所以它对逃避并非必要；它只是短潜伏期形式的 C 形起跳的命令神经元。

3. 在蝌蚪的游泳 CPG 中，周期近似为相互抑制性电位持续时间的两倍。解释原因，并预测延长甘氨酸能抑制的药物的效应。

   **答** 每个半中枢放电一次，然后抑制另一侧；另一侧只有在抑制结束时才放出一个反弹脉冲。因此一个周期由左侧对右侧的抑制，再加右侧对左侧的抑制组成，周期近似为两个抑制持续时间之和（再加小的突触与传导延迟）。延长甘氨酸能 IPSP 的药物（例如减缓其衰减）应当延长周期并降低游泳频率；如果抑制变得足够长，以至于去极化驱动无法维持反弹，游泳可能停止。

4. 果蝇以短模式或长模式起飞。两者各有什么代价与好处？为什么这一选择是由脉冲时间而不是由单独的“决策神经元”来实现的？

   **答** 短模式起飞快几毫秒，这对非常近的捕食者很重要，但果蝇常常翻滚并失去对飞行的控制；长模式起飞较慢，但把果蝇送入稳定的飞行，时间允许时更好。把选择实现为两条通路之间的竞赛，意味着较快的通路，即巨纤维，只有在刺激紧迫到使 GF 在较慢程序完成之前就达到阈值时，才会压过较慢的通路。因此刺激的紧迫程度决定了选择，而无需任何额外的神经元或延迟：单独的决策阶段会在速度最重要的时刻增加突触延迟。

5. （开放题）设计一个实验，检验医蛭在游泳与爬行之间的选择是由命令神经元还是由分布式网络作出的。

   **答** 在对同一刺激的重复试验中，用电压敏感染料或钙成像同时记录尽可能多的神经元，并（用分类器）确定从每个神经元以及从群体最早何时能预测选择。命令神经元会单独预测选择，并且早于其他神经元，对它的操纵将决定结果；分布式的决定则从群体中能比从任何单个神经元更早地预测，操纵任何一个神经元只会使概率产生偏向。然后操纵候选神经元（使其去极化或超极化，如对 208 号细胞所做的，或使其沉默），测量每种行为概率的变化；必要性可以通过消融来检验。Briggman、Abarbanel 与 Kristan 的结果对应于第二种结局。
