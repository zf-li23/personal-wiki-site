不形成**神经板**或**神经嵴**的**外胚层**构成身体表面，也构成动物感知周围环境的大部分器官。它产生表皮及其附属器（毛发、羽毛、鳞片、牙、腺体），并在前部神经板的边缘形成一组增厚的区域，即基板，它们产生眼的晶状体、内耳、嗅上皮、腺垂体和许多感觉**神经元**。眼由三种组织构成：**神经管**（视网膜）、表面外胚层（晶状体、角膜）和神经嵴（角膜基质），是一连串**相互诱导**的经典例子。附属器则体现了另一个主题：由上皮与其下方间充质的相互作用产生的周期性图案，对此人们提出了反应扩散模型（[7.5.12](/7.5.12)）和力学–化学模型（细胞牵拉其基质）两类解释。本章接续 [7.5.18](/7.5.18)–[7.5.21](/7.5.21) 的外胚层衍生物；眼与耳的功能见 [7.14](/7.14)，皮肤的**干细胞**已在 [7.3.24](/7.3.24) 介绍。

## 22.1. 颅部基板

**定义 22.1.1（基板）** **基板**是胚胎上皮（通常是表面**外胚层**）的局部增厚，其细胞变为柱状，然后形成器官或迁移形成**神经元**。颅部感觉基板形成晶状体、内耳、嗅上皮、腺垂体和颅神经节的感觉神经元；皮肤的基板启动毛囊、羽毛、鳞片、牙和腺体的形成（22.4）。

颅部基板起源于共同的区域，即前基板区（PPR），它是围绕前部**神经板**、位于**神经嵴**之外的马蹄形外胚层，以转录因子 Six1 与 Eya1 以及 Dlx 与 Foxi 家族成员为标志。其**诱导**需要来自头部**中胚层**和**内胚层**的 FGF，以及低水平的 BMP 与 Wnt 信号；神经嵴产生于有 Wnt 和中等水平 BMP 之处，因此对 Wnt 与 BMP 的抑制使同一神经板边界上的基板命运与嵴的命运区分开来（Litsiou、Hanson 与 Streit，2005）。随后 PPR 在局部信号作用下，按从前到后的固定次序分解为各个基板：Otx2 与 Gbx2 把前部基板与后部基板分开，来自后脑的 FGF 与 Wnt 诱导耳基板，Pax6 标记晶状体与嗅基板，Pax3 标记眼支三叉基板，Pax2/8 标记耳与鳃上基板。

头部的许多感觉神经节由基板与嵴共同构成：三叉神经节中，早期出生的大型近端神经元主要来自基板，胶质细胞来自嵴，神经节的凝聚需要二者的相互作用（[7.5.20](/7.5.20) 的追逐与逃离就是二者相互依赖的一例）。*EYA1* 或 *SIX1* 突变引起鳃–耳–肾综合征（听力丧失、鳃裂囊肿和肾畸形），反映了这些基因在基板、咽弓和肾（[7.5.25](/7.5.25)）中的作用；嗅基板与 GnRH 神经元迁移的缺陷引起 Kallmann 综合征（嗅觉缺失伴低促性腺激素性性腺功能减退）。

## 22.2. 眼

### 22.2.1. 眼区与独眼畸形

眼起源于前部**神经板**，在**原肠作用**期间，由一组眼区转录因子（Pax6、Rx、Six3、Lhx2、Six6）特化出单一的、位于中线的眼区，后部受 Otx2 与 Wnt 信号抑制。这个单一的区域被中线下方的脊索前**中胚层**分泌的 Shh 一分为二：Shh 抑制中央的 *Pax6*，并在该处诱导 *Pax2*（将来的视柄与腹侧间脑）。实验结果非常明确。在斑马鱼 *cyclops*（缺乏脊索前中胚层的 Nodal 突变体）和 *Shh* **基因敲除小鼠**中，形成单一的中线眼；在人类中，*SHH*、*SIX3*、*ZIC2* 或 *TGIF* 的突变引起前脑无裂畸形，即前脑不能分成两个半球，最严重时为独眼，较轻时表现为面部中线缺陷（单一的中切牙）。环巴胺（cyclopamine）是玉米百合 *Veratrum californicum* 中的一种甾体生物碱，母羊啃食后，羔羊出现独眼畸形；它阻断 **Smoothened**，由此发现了 Shh 信号的作用，后来也出现了用于治疗基底细胞**癌**的 Smoothened 抑制剂。

### 22.2.2. 视泡、视杯与晶状体诱导

眼区的细胞从间脑向外突出，形成视泡，向表面**外胚层**生长并与之接触。接触之处，外胚层增厚为晶状体基板，随后内陷为晶状体窝，再收缩脱离为晶状体泡。与此同时，视泡自身内折形成两层的视杯：朝向晶状体的内层成为神经视网膜，外层成为视网膜色素上皮（RPE）。视杯与视柄的腹侧只是逐渐闭合，通过沿脉络膜裂的融合进行，血管由此进入、神经节细胞的轴突由此离开；融合失败则留下虹膜、视网膜或视神经的缺口，称为缺损（coloboma）。

![脊椎动物眼的发育（示意切面；脑在左，表面外胚层在右）。(A) 视泡从间脑长出，与表面外胚层接触，后者增厚为晶状体基板。(B) 视泡内折为两层的视杯，内层成为神经视网膜，外层成为视网膜色素上皮（RPE），同时基板内陷为晶状体窝。(C) 晶状体泡脱离，表面外胚层在其上方闭合，将形成角膜上皮。(D) 晶状体泡后部的细胞伸长为晶状体纤维并充满其中，视网膜增厚并分层，神经节细胞的轴突经视柄（视神经）离开，神经嵴间充质形成角膜基质](./plots/eye-development.py)

**定义 22.2.1（晶状体诱导）** **晶状体诱导**是头部表面外胚层在早先信号使之具有感受态之后，被诱导形成晶状体基板与晶状体的过程；其最后一步需要与视泡接触。

晶状体诱导是最早被实验研究的**诱导**，它的历史说明诱导的概念必须不断完善。Spemann（1901）用热针毁坏林蛙 *Rana fusca* 的眼原基，结果没有晶状体形成，提示视泡诱导晶状体。但在 *Rana esculenta* 中，没有视泡也形成了晶状体，移植实验表明外胚层的反应在不同物种和不同阶段是不同的。问题的解决来自对**感受态**的分析（Grainger 及同事）：晶状体诱导是一个多步过程。头部外胚层在原肠作用与**神经胚形成**期间，从前部神经板及其下方的**内胚层**和中胚层获得形成晶状体的倾向；在视泡到来之前，它已被特化为形成晶状体（其外植体此时可形成类晶状体）；与视泡接触则完成决定，并把晶状体定位在正确的位置。不同物种在最后一步之前完成的程度不同，这就是切除视泡在一种蛙中阻止晶状体形成、在另一种蛙中却不能的原因。

分子的情况与这一顺序吻合。外胚层必须表达 Pax6，使其具有感受态：*Pax6* **杂合**的 *Small eye* 小鼠眼睛较小；在由 *Pax6* 突变细胞与**野生型**细胞组成的**嵌合体**中，即使紧邻野生型视泡，突变的外胚层细胞也被排除在晶状体之外，因此 Pax6 在反应组织中**细胞自主**地起作用（Quinn 等，1996）。视泡提供 BMP4 与 FGF；在 BMP 信号参与下，Pax6 与 Sox2 激活晶状体基因（在鸡中，Pax6 与 Sox2 共同结合 δ-晶状体蛋白的**增强子**，Kamachi 等，2001）。诱导是相互的：晶状体反过来向视杯发出信号，来自晶状体与表面外胚层的 FGF 把视杯的内层特化为神经视网膜（表达 Vsx2/Chx10），而外层暴露于周围间充质的 BMP 与 Wnt 以及 Activin，成为 RPE（表达 Mitf 与 Otx2）。Mitf 与 Vsx2 相互抑制；缺乏 Vsx2 时，视网膜转分化为色素上皮，而 FGF 珠可使预定的 RPE 转变为神经视网膜。

### 22.2.3. 晶状体与角膜

晶状体泡后部的细胞伸长为初级晶状体纤维，充满其腔；前部的细胞保留为晶状体上皮，终生在赤道部分裂，并在核心周围添加次级纤维。晶状体纤维合成大量晶状体蛋白（crystallin），这是一些可溶性蛋白，堆积浓度超过 300 mg mL⁻¹（α-晶状体蛋白是防止聚集的小热休克蛋白，另有 β- 与 γ-晶状体蛋白）；纤维降解其细胞核、线粒体和其他细胞器，这一程序性清除涉及 DNase IIβ 和依赖磷脂酶的细胞器分解，使纤维变得透明。晶状体蛋白基因的突变引起先天性白内障。在晶状体上方闭合的表面外胚层成为角膜上皮；**神经嵴**间充质迁入，形成角膜基质与内皮（以及虹膜基质），基质在铺设排列规则的**胶原蛋白**纤维并在甲状腺激素作用下脱水后变得透明。虹膜与睫状体由视杯的边缘形成。

### 22.2.4. 视网膜

神经视网膜是中枢神经系统中分层的一部分。它的七类主要细胞（神经节细胞、无长突细胞、水平细胞与双极细胞，视杆与视锥感光细胞，以及 Müller 胶质细胞）由同一个多潜能的**祖细胞**库按保守的、相互重叠的次序产生：神经节细胞、水平细胞、视锥细胞与无长突细胞最先，视杆细胞、双极细胞与 Müller 胶质细胞最后。用逆转录病毒进行的**谱系示踪**表明，发育晚期的单个祖细胞可以产生同时含有视杆细胞、双极细胞和 Müller 胶质细胞的克隆，所以这些祖细胞是多潜能的（Turner 与 Cepko，1987）。感受态模型解释了这一次序：祖细胞经历一系列感受态状态，每个状态下只能产生某些细胞类型，由时序转录因子调控（早期命运由 Ikzf1，即 *Drosophila* Hunchback 的脊椎动物同源物调控，晚期命运由 Casz1，即 Castor 的同源物调控），这与昆虫**成神经细胞**的时序系列直接平行（[7.5.19](/7.5.19)）。外在因子决定各类细胞的比例：神经节细胞分泌 Shh 与 GDF11，限制神经节细胞的进一步产生。

神经节细胞是最先出生的**神经元**，其轴突沿视网膜内表面伸向视盘，经视柄离开，这就是 [7.5.21](/7.5.21) 中视网膜–顶盖投射的开端。感光细胞位于外层，紧贴 RPE：脊椎动物的视网膜是倒置的，这是它起源于内折的视泡的结果，RPE 用于回收感光色素的发色团，并吞噬脱落的外段。

### 22.2.5. Pax6 与深度同源

*Pax6* 是整个动物界眼发育所必需的。失去一个拷贝，在人类引起无虹膜症（虹膜缺失，伴白内障与角膜缺陷），在小鼠表现为 *Small eye*；两个拷贝都失去则没有眼，也没有鼻。*Drosophila* 的基因 *eyeless* 是它的同源基因，在腿、翅或触角的成虫盘中靶向表达 *eyeless* 或小鼠 *Pax6*，都会在这些附肢上诱导出异位的复眼（Halder、Callaerts 与 Gehring，1995）。可见小鼠的基因可以触发果蝇的眼：Pax6 是一个**主调控因子**，两种眼的下游网络完全不同，尽管有些结构基因（视蛋白、光转导）是共有的。这是**深度同源**（[7.5.39](/7.5.39)）的经典例子：在解剖上不同源的结构（照相机式眼与复眼是分别进化出来的），却是用同源的调控基因构建的，这些基因继承自一个具有受类 Pax6 基因控制的感光细胞的共同祖先。

## 22.3. 表皮

在神经板、嵴和基板形成之后剩下的表面**外胚层**成为表皮。起初是被扁平的周皮覆盖的单层，到妊娠中期变为复层：位于**基膜**上的分裂的基底层细胞产生基底上层细胞，后者停止分裂，向外移动，经棘层和颗粒层分化为角质层中死亡的扁平细胞，其中充满角蛋白，外面包着构成皮肤屏障的角质包膜。转录因子 p63 是复层化所必需的（缺乏它的小鼠与人没有表皮，或有严重的外胚层发育不良），Notch 信号驱动从基底分化到基底上层分化的转换，**角蛋白**由基底细胞中的 K5/K14 变为基底上层细胞中的 K1/K10。*KRT5* 或 *KRT14* 的突变削弱基底细胞，引起单纯型大疱性表皮松解症，皮肤在轻微摩擦下就起水疱。

基底层含有毛囊间表皮的**干细胞**（[7.3.24](/7.3.24)）。对小鼠的**谱系示踪**表明，大多数基底细胞表现为等潜能的**祖细胞**群体，其分裂只在平均意义上保持平衡：每次分裂以固定的概率产生两个分裂细胞、两个分化细胞或各一个，所以克隆的大小发生中性漂变，一些克隆消失而另一些增大（Clayton 等，2007），这是 [7.5.36](/7.5.36) 的随机动力学。人的表皮约每四到八周更新一次。

## 22.4. 外胚层附属器

### 22.4.1. 基板、凝聚体与重组

**定义 22.4.1（外胚层附属器）** **外胚层附属器**是由表面上皮的基板与其下方间充质的凝聚共同发育而成的器官：毛发、羽毛、鳞片、牙、指甲，以及外分泌腺（汗腺、皮脂腺、唾液腺、乳腺与泪腺）。

所有附属器的开端都一样：在真皮凝聚体之上出现增厚上皮的基板，二者相互发出信号，上皮向间充质内生长（芽）或向表面外突，然后才是器官特有的形态发生。所用的信号是共同的：WNT/**β-连环蛋白**（与转录因子 Lef1）启动基板，EDA（ectodysplasin，一种肿瘤坏死因子家族配体）经其受体 EDAR 与 **NF-κB** 起促进作用，FGF20 诱导真皮凝聚体，BMP 抑制附属器之间的基板形成，来自基板的 SHH 驱动向下生长。

形成哪种附属器、在哪里形成，由谁决定？把来自不同区域和不同物种的表皮与真皮重组，这种可追溯到 Saunders、Sengel 与 Dhouailly 的实验设计，给出了一致的答案。

**例 22.4.1（真皮决定类型与图案，表皮决定形态）** 在鸡中，把腿部无羽区的表皮与背部真皮重组，形成羽毛；背部表皮与腿部（形成鳞片的）真皮重组，形成鳞片：真皮决定附属器的类型和区域的图案。在物种之间的重组中（Dhouailly，1973），鸡表皮置于小鼠真皮上，形成按小鼠毛发图案排列的羽芽，小鼠表皮置于鸡真皮上，形成毛发：表皮按其自身的基因组决定它能形成的附属器类别（羽毛或毛发）。在牙方面，小鼠牙间充质与鸡口腔上皮重组，可诱导上皮形成牙样结构，尽管鸟类已丧失牙约 7000 万年（Kollar 与 Fisher，1980），而鸡 *talpid2* 突变体会形成牙原基（Harris 等，2006）：上皮的能力得以保留，鸟类牙的丧失是因为间充质的信号丧失。

EDA 通路体现了临床方面的意义。**X 连锁**的少汗性外胚层发育不良（XLHED）由 *EDA* 突变引起，表现为毛发稀少、牙缺失或呈锥形、没有汗腺，因此患病男孩有高热的风险；*EDAR* 及其衔接蛋白 *EDARADD* 的突变引起类似的**常染色体**形式。给患病胎儿在子宫内（羊膜腔内）注射重组 EDA，使三名男孩恢复了汗腺的形成（Schneider 等，2018）。人类的一个常见变异 *EDAR* V370A 增强受体信号，在东亚与美洲原住民人群中频率很高；携带它的小鼠毛发更粗，外泌汗腺更多（Kamberov 等，2013），这是发育信号变异在人类进化中受到正选择的一个例子。

### 22.4.2. 牙

牙由口腔上皮（成釉细胞形成釉质）和**神经嵴**间充质（成牙本质细胞形成牙本质和牙髓）形成。上皮增厚为牙板，然后经过芽期、帽期和钟期。在帽期，上皮芽的顶端形成一团不分裂的上皮细胞，称为釉结，它是一个信号中心，表达 Shh、FGF4、BMP 与 Wnt，刺激周围上皮的生长，并通过位于未来牙尖处的次级釉结决定牙冠的形状；随后釉结经**细胞凋亡**被清除（Jernvall 等，1998）。沿颌骨的牙的类型（切牙或磨牙）由嵴间充质中的同源框基因决定（磨牙区为 *Dlx1/2* 与 *Barx1*，切牙区为 *Msx1* 与 *Msx2*），因此在切牙区异位表达 *Barx1* 会把切牙转变为磨牙。

相继的磨牙从牙板的后部一个接一个发育，每一个都抑制下一个。Kavanagh、Evans 与 Jernvall（2007）培养小鼠磨牙胚，发现把第二磨牙胚与第一磨牙胚分开会使其变大；他们用一条简单的规则概括了这些观察。

**公式 22.4.1（磨牙大小的抑制级联）** 设每个磨牙胚被间充质以速率 $a$ 激活，被前一个磨牙以速率 $i$ 抑制，于是每个后续磨牙相对于第一个磨牙的大小以固定的步长变化，则第一、第二、第三磨牙的大小 $m_1, m_2, m_3$ 满足

$$
\frac{m_2}{m_1} = 1 + \frac{a - i}{i},
\qquad
\frac{m_3}{m_1} = 1 + 2\,\frac{a - i}{i}
\;\;\Longrightarrow\;\;
\frac{m_3}{m_1} = 2\,\frac{m_2}{m_1} - 1,
\tag{22.1}
$$

因此第二磨牙总是第一与第三磨牙的平均值，占整列磨牙的三分之一。

这条规则预言，平衡 $a/i$ 的变化使各磨牙的相对大小沿一条直线移动，鼠科啮齿动物（以及经过修正后的许多哺乳动物，包括人类第三磨牙的退化）的磨牙比例都落在它附近。可见一个发育参数就限制了可供进化利用的变异，这是 [7.5.39](/7.5.39) 所讨论的发育约束的一个例子。

### 22.4.3. 腺体

汗腺、皮脂腺和乳腺以同样的方式起源于基板。哺乳动物的乳腺由沿躯干的成对乳线形成，小鼠的乳线上出现五对基板（人类为一对；沿乳线的多余乳头很常见），受 Wnt、来自体节的 FGF10 和 Tbx3 的控制（Tbx3 突变引起尺骨–乳腺综合征，表现为乳房与前肢发育不全）。乳腺上皮随后向脂肪垫分支，这一**分支形态发生**在青春期受激素控制而重新启动（[7.5.25](/7.5.25)）。

## 22.5. 附属器的间距

毛发和羽毛不是随机散布的：在一片皮肤上它们形成规则的阵列，相邻者之间有最小距离，羽毛则成行出现，从背中线向外传播。人们提出了三种机制，现在看来它们是共同起作用的。

### 22.5.1. 反应扩散与侧向抑制

在小鼠中，毛囊的间距与 [7.5.12](/7.5.12) 意义上的反应扩散系统（**图灵斑图**）一致，其中 WNT 为激活物，DKK（Dickkopf，一种由 WNT 诱导的分泌型 WNT 抑制物）为抑制物（Sick 等，2006）。证据来自对模型预言的检验，而不是对扩散系数的测量：WNT/β-连环蛋白的活性最初以弥散的低水平图案出现，随后锐化为斑点；在表皮中过表达 DKK 使毛囊密度呈剂量依赖地下降，正如抑制物产生增加时所预言的；WNT 活性的局部变化使毛囊的相对位置按模型预言的方式移动。在鸡中，每个羽原基的 BMP 抑制其周围原基的形成，而 FGF 促进之（Jung 等，1998），这是一种具有相同数学结构的**侧向抑制**。

**公式 22.5.1（附属器间距的激活物–抑制物模型）** 在一片皮肤上，设 $a(\boldsymbol{x}, t)$ 为激活物（WNT 活性），$h(\boldsymbol{x}, t)$ 为抑制物（DKK 或 BMP），组织的**感受态**为 $m(\boldsymbol{x}, t) \in \{0, 1\}$。取 [7.5.12](/7.5.12) 的 Gierer–Meinhardt 形式（**Gierer–Meinhardt 模型**），

$$
\frac{\partial a}{\partial t} = D_a\nabla^{2}a + m\Bigl(\rho\,\frac{a^{2}}{h} + \sigma\Bigr) - \mu a,
\qquad
\frac{\partial h}{\partial t} = D_h\nabla^{2}h + m\,\rho a^{2} - \nu h,
\tag{22.2}
$$

其中 $D_h \gg D_a$。均匀状态对波长在 $2\pi\bigl(D_aD_h/\mu\nu\bigr)^{1/4}$ 量级的一个波段内的扰动是不稳定的（[2.5.7](/2.5.7) 的 Turing 条件），稳定的图案是由激活物峰组成的阵列，即基板，其间距有特征值，与区域的大小无关。

感受态如何到来很重要。在鸡中，形成羽原基的能力以波的形式从背中线扩散，原基逐行出现；每一新行形成于前一行的边缘，与之对齐，结果形成近乎六边形的点阵。在小鼠皮肤中，毛区的大部分同时获得感受态，毛囊同时出现，排列不那么规则。由于这类图案是多稳态的，最终的间距除取决于参数外，还取决于图案是如何形成的：依次形成使每个新的峰有空间成熟并抑制其周围，往往产生比同时形成更宽的间距，后者的间距接近线性理论中增长最快的波长。

### 22.5.2. 力学–化学模型

间充质细胞通过其突起牵拉**细胞外基质**，使之在长距离上变形；若细胞还沿基质密度的梯度向上运动（趋触性），牵拉就可以使细胞和基质都集中起来。Oster、Murray 与 Harris（1983）提出，这种力学反馈无需任何扩散的**形态发生素**，就能产生真皮细胞的周期性凝聚，即羽毛、鳞片和牙的乳头。Percus 与 Childress 给出了他们模型的一个简化版本及其稳定性分析。

**定义 22.5.1（力学–化学模型）** 形态发生的**力学–化学模型**是这样一类模型：细胞产生的力（收缩、对细胞外基质的牵拉）和组织的形变与细胞运动、增殖或化学信号耦合，使力学变量与化学变量共同决定图案。

**公式 22.5.2（真皮凝聚的 Oster–Murray 模型）** 设 $n(\boldsymbol{r}, t)$ 为间充质细胞密度，$\rho(\boldsymbol{r}, t)$ 为细胞外基质密度，$\boldsymbol{u}(\boldsymbol{r}, t)$ 为基质相对于无应力位置的位移，应变为 $\varepsilon = \tfrac12\bigl(\nabla\boldsymbol{u} + (\nabla\boldsymbol{u})^{\mathsf T}\bigr)$，膨胀为 $\theta = \nabla\cdot\boldsymbol{u}$。细胞守恒为 $\dot n = -\nabla\cdot\boldsymbol{j} + M$，流由三部分组成，

$$
\boldsymbol{j} = \underbrace{-D\nabla n + D'\nabla\nabla^{2}n}_{\text{随机运动，长程}} \;+\; \underbrace{\alpha\,n\nabla\rho}_{\text{趋触性}} \;+\; \underbrace{n\,\dot{\boldsymbol{u}}}_{\text{被基质携带}},
\qquad
M = r\,n(N - n),
$$

其中四阶项来自对细胞–细胞相互作用 $\bar n(\boldsymbol{r}) = \int w(\boldsymbol{r}')\,n(\boldsymbol{r} + \boldsymbol{r}')\,\mathrm{d}^{3}r'$ 在核 $w$ 上取平均，核满足 $\int w = 1$、$\int \boldsymbol{r}'w = \boldsymbol{0}$、$\int \boldsymbol{r}'\boldsymbol{r}'w = -\gamma I$，并展开到二阶。基质守恒，$\dot\rho + \nabla\cdot(\rho\dot{\boldsymbol{u}}) = 0$，且处于力学平衡、不计惯性，$\nabla\cdot\sigma - s\rho\,\boldsymbol{u} = \boldsymbol{0}$，其中 $-s\boldsymbol{u}$ 是基质与基底之间的弹性束缚。应力为黏弹性应力加上细胞牵拉，

$$
\sigma = \mu_1\dot\varepsilon + \mu_2\dot\theta I + E'\bigl(\varepsilon + \nu'\theta I\bigr) + \frac{\tau\,n\,(\rho + \beta\nabla^{2}\rho)}{1 + \lambda n^{2}}\,I,
\tag{22.3}
$$

其中 $\mu_1, \mu_2$ 为剪切与体积黏度，$E' = E/(1 + \nu)$（$E$ 为 Young 模量，$\nu$ 为 Poisson 比），$\nu' = \nu/(1 - 2\nu)$，$\tau$ 为牵拉系数，$\beta$ 为长程牵拉，$\lambda$ 为牵拉的接触抑制。

要判断均匀状态 $n = \rho = 1$（标度化后）、$\boldsymbol{u} = \boldsymbol{0}$ 是否稳定，需将方程线性化并简化：令 $\lambda = 0$，略去长程项与趋触项（$D' = \beta = \alpha = 0$）以及**有丝分裂**（$r = 0$），取 $\mu_1 = \mu_2 = \mu$，并把因子 $1 + \nu'$ 吸收到参数中。简化后的线性化系统为

$$
\dot n = D_1\nabla^{2}n - \dot\theta,
\qquad
\nabla\cdot\bigl[\mu(\dot\varepsilon + \dot\theta I) + \varepsilon + \nu'\theta I + \tau(n + \rho)I\bigr] = s\boldsymbol{u},
\qquad
\dot\rho + \dot\theta = 0 .
\tag{22.4}
$$

**定理 22.5.1（色散关系与临界牵拉）** 对正比于 $\mathrm{e}^{\lambda t + \mathrm{i}\boldsymbol{k}\cdot\boldsymbol{r}}$ 的扰动，记 $K = \lvert\boldsymbol{k}\rvert^{2}$，式 (22.4) 的纵模满足 $\lambda\bigl[\mu K\lambda^{2} + b(K)\lambda + c(K)\bigr] = 0$，其中

$$
b(K) = \mu D_1K^{2} + (1 - 2\tau)K + s,
\qquad
c(K) = D_1K\bigl[(1 - \tau)K + s\bigr].
\tag{22.5}
$$

不稳定首先出现在 $\min_K b(K) < 0$ 时，即牵拉

$$
\tau > \tau_{\mathrm{c}} = \tfrac12 + (\mu s D_1)^{1/2},
\qquad
\text{波数为 } k_{\mathrm{c}} = \Bigl(\frac{s}{\mu D_1}\Bigr)^{1/4}.
$$

**证明** 考虑沿 $\boldsymbol{k}$ 的一个 Fourier 模（纵模，$\boldsymbol{u} \parallel \boldsymbol{k}$，在一维中只有这一种），振幅为 $n, \rho, u$。基质守恒给出 $\lambda\rho = -\lambda\,\mathrm{i}ku$，所以 $\lambda \ne 0$ 时 $\rho = -\mathrm{i}ku$。细胞守恒给出 $\lambda n = -D_1Kn - \lambda\,\mathrm{i}ku$，所以 $n = -\mathrm{i}k\lambda u/(\lambda + D_1K)$。在力平衡中，纵模满足 $\varepsilon = \theta = \mathrm{i}ku$，并吸收黏性与弹性因子，应力的散度为 $\mathrm{i}k\bigl[\mu\lambda\,\mathrm{i}ku + \mathrm{i}ku + \tau(n + \rho)\bigr] = -K(\mu\lambda + 1)u + \mathrm{i}k\tau(n + \rho)$。代入 $n$ 与 $\rho$，$\mathrm{i}k\tau(n + \rho) = \tau K u\bigl(\lambda/(\lambda + D_1K) + 1\bigr)$，平衡式 $\nabla\cdot\sigma = su$ 变为

$$
-K(\mu\lambda + 1 - \tau) + \frac{\tau K\lambda}{\lambda + D_1K} - s = 0 .
$$

乘以 $-(\lambda + D_1K)$ 并按 $\lambda$ 的幂次整理，得 $\mu K\lambda^{2} + \bigl[\mu D_1K^{2} + (1 - 2\tau)K + s\bigr]\lambda + D_1K\bigl[(1-\tau)K + s\bigr] = 0$，此外还有上面排除的根 $\lambda = 0$（由基质守恒产生的中性模）。当 $\tau < 1$ 时系数 $c(K)$ 为正，所以二次方程恰在 $b(K) < 0$ 时有正实部的根。作为 $K$ 的函数，$b$ 是抛物线，最小值在 $K^{*} = (2\tau - 1)/(2\mu D_1)$ 处，最小值为 $s - (2\tau - 1)^{2}/(4\mu D_1)$，它为负当且仅当 $2\tau - 1 > 2(\mu sD_1)^{1/2}$。在阈值处 $K^{*} = (s/\mu D_1)^{1/2}$，由此得到 $k_{\mathrm{c}}$。$\square$

有两点说明使这一结果更精确。其一，在阈值处 $b = 0$ 且 $c > 0$（当 $\tau_{\mathrm{c}} < 1$ 时），所以两个临界根是纯虚数：在这个简化模型中，不稳定首先表现为波数 $k_{\mathrm{c}}$ 处振幅增长的振荡，而实的（定态的）根只有在 $c < 0$ 时才变为正，这要求 $\tau > 1 + s/K$，发生在短波长处。观察到的波长固定的定态图案，要在更完整的模型中才能得到，其中长程项 $D'$ 与 $\beta$ 惩罚短波长，趋触性增加了一个失稳耦合。其二，阈值的行为与物理直觉一致：与基底的强束缚（$s$ 大）、大黏度或细胞的快速扩散都使组织稳定，所选择的波长 $2\pi/k_{\mathrm{c}} = 2\pi(\mu D_1/s)^{1/4}$ 只随这些参数的四次方根增长，所以乳头的间距对这些参数的适度变化是稳健的。

**例 22.5.1** 在标度单位中取 $\mu = D_1 = 1$，$s = 0.1$，则 $\tau_{\mathrm{c}} = 0.5 + \sqrt{0.1} = 0.82$，$k_{\mathrm{c}} = 0.1^{1/4} = 0.56$，波长为 $2\pi/0.56 \approx 11$ 个长度单位。把基底刚度加倍到 $s = 0.2$，$\tau_{\mathrm{c}}$ 升至 0.95，波长只缩短 $2^{1/4} \approx 1.19$ 倍。

### 22.5.3. 当前的看法：力学与信号共同作用

二十年来，力学–化学模型被看作一个优美但缺乏实验支持的替代方案。2017 年以来它重新受到重视。在鸡的皮肤中，真皮细胞靠自身的收缩性自组织成聚集体，无需预先的分子图案：阻断肌动球蛋白收缩就阻止聚集体形成，而覆盖其上的表皮在聚集体处受到的压缩激活 β-连环蛋白并启动毛囊程序，这是基板的一种力学**诱导**（Shyer 等，2017）。在小鼠皮肤中，真皮凝聚涉及由**趋化性**驱动的细胞运动，朝向 FGF20 和来自基板的其他信号（Glover 等，2017），真皮细胞及其基质暂时变得类似流体，使聚集成为可能（Palmquist 等，2022）。在羽区中，图案形成的波和间距既依赖 FGF/BMP 信号，也依赖间充质的力学（Ho 等，2019）。因此目前的看法是二者的结合：真皮的力学不稳定性（如 Oster 与 Murray 的模型）与 WNT–DKK、FGF–BMP 一类的激活物–抑制物信号相耦合，彼此加强。

## 22.6. 毛发周期及其干细胞

毛囊是与表皮相连的上皮管，带有皮脂腺、立毛肌，其底部是毛球，其中的基质细胞围绕真皮乳头，后者是特化成纤维细胞的凝聚体。基质细胞快速分裂，产生毛干及其鞘。毛囊终生在生长期（anagen，人的头发为数年）、退行期（catagen，数周，此期下部毛囊经**细胞凋亡**死亡，乳头被向上牵拉）和休止期（telogen，数月）之间循环。

这一周期依赖隆突（bulge）中的**干细胞**，隆突是外根鞘中立毛肌附着处的区域。那里发现了标记滞留细胞（Cotsarelis、Sun 与 Lavker，1990），用隆突标志物（K15、CD34、Lgr5、Sox9）进行的**谱系示踪**表明，隆突细胞在每个周期中再生整个毛囊，也再生皮脂腺，并在受伤后再生毛囊间表皮（Ito 等，2005）。休止期末，来自真皮乳头的信号、WNT 的激活和 BMP 抑制的解除（乳头分泌 BMP 拮抗剂，而周围的真皮和脂肪细胞周期性地释放 BMP）先激活次级毛胚，再激活隆突，开始新的生长期。在男性型秃发中，头皮的隆突干细胞仍然保留，但毛胚**祖细胞**未被激活，部分原因是头皮中依赖雄激素的前列腺素 D2（Garza 等，2012）。成年小鼠的大面积伤口可通过依赖 WNT 的过程由表皮细胞再生出新的毛囊（伤口诱导的毛发新生，Ito 等，2007），这是胚胎程序在成体中再次出现的一例（[7.5.35](/7.5.35)）。

## 小结

| 衍生物 | 起源 | 关键信号与基因 | 疾病 |
|---|---|---|---|
| 颅部基板 | 前基板区（Six1/Eya1），低 BMP 与 Wnt，FGF | Pax6（晶状体、嗅），Pax3，Pax2/8（耳） | 鳃–耳–肾综合征、Kallmann 综合征 |
| 眼区 → 两只眼 | 前部**神经板**（Pax6、Rx、Six3） | 脊索前板的 Shh 把眼区一分为二 | 前脑无裂畸形、独眼畸形 |
| 晶状体 | 表面**外胚层**，多步**诱导** | Pax6（**细胞自主**）、Sox2、BMP4、FGF；晶状体蛋白 | 白内障、无虹膜症 |
| 视网膜 / RPE | 视杯内层 / 外层 | FGF（Vsx2）对 BMP/Wnt（Mitf）；时序因子 | 缺损（coloboma） |
| 表皮 | 表面外胚层 | p63、Notch；K5/K14 → K1/K10 | 单纯型大疱性表皮松解症 |
| 附属器 | 基板 + 真皮凝聚体 | WNT、EDA/EDAR、FGF20、BMP、SHH | XLHED |
| 牙 | 口腔上皮 + 嵴间充质 | 釉结；*Barx1* 对 *Msx1*；抑制级联 | 牙发育不全 |

- 基板（定义 22.1.1）起源于前部神经边界的前基板区，以低 Wnt 与低 BMP 与嵴相区别。
- 眼区是单一的，由 Shh 一分为二；视泡与外胚层经历相互的多步诱导（定义 22.2.1）；Pax6 细胞自主地起作用，是 *eyeless* 的深度同源基因。
- 视网膜的各类细胞由多潜能的**祖细胞**按固定次序产生，祖细胞经历不同的**感受态**状态。
- 附属器（定义 22.4.1）：真皮决定类型与图案，表皮决定附属器的类别（例 22.4.1）；磨牙的大小遵循抑制级联（公式 22.4.1）。
- 间距：激活物–抑制物系统（公式 22.5.1）与力学–化学不稳定性（定义 22.5.1，公式 22.5.2），临界牵拉 $\tau_{\mathrm{c}} = \tfrac12 + (\mu sD_1)^{1/2}$，波数 $k_{\mathrm{c}} = (s/\mu D_1)^{1/4}$（定理 22.5.1，例 22.5.1）；实验现在支持二者共同起作用。
- 毛囊的周期受隆突**干细胞**和真皮乳头信号的控制。

## 思考题

1. Spemann 摘除视泡在一种蛙中阻止了晶状体的形成，在另一种蛙中却不能。说明晶状体诱导的多步模型如何调和这些结果，并设计一个实验来确定头部**外胚层**何时被特化为形成晶状体。

   **答** 在多步模型中，外胚层在视泡到来之前就接收到促进晶状体形成的信号（来自前部**神经板**、**内胚层**和**中胚层**）；在这些早期步骤足以完成特化的物种中，较晚摘除视泡仍可形成晶状体，而在另一些物种中则需要最后一步。要确定特化的时间，可以在连续的阶段把预定晶状体的外胚层外植到中性环境（培养基，或移植到体侧），检查晶状体蛋白的表达和类晶状体的形成；外植体形成晶状体的最早阶段即标志特化，而移植到头部的另一个区域（检验决定）则说明命运何时固定。

2. 在 *Pax6* 突变细胞与野生型小鼠细胞的**嵌合体**中，即使视泡是野生型，突变细胞也被排除在晶状体之外。这说明什么？什么结果会表明 Pax6 作用于**诱导物**中？

   **答** Pax6 在反应的外胚层中**细胞自主**地起作用，决定其**感受态**：野生型的邻近细胞和野生型诱导物都不能挽救突变的外胚层细胞。若 Pax6 作用于视泡（诱导物），晶状体的形成就取决于视泡的基因型：紧邻野生型视泡的突变外胚层细胞应能正常参与形成晶状体，而突变的视泡则不能诱导野生型外胚层。

3. 为什么 *SHH* 的突变既引起前脑无裂畸形又引起独眼畸形？为什么杂合携带者的面部特征常常比脑缺陷轻？

   **答** 来自脊索前中胚层和腹侧前脑的 Shh 是把中线眼区一分为二、把前脑分成两个半球所必需的；Shh 减少时眼区不能分开（独眼，或双眼靠近），前脑保持未分裂。来自前脑和面部外胚层的 Shh 还驱动中线面部的向外生长。杂合性缺失使剂量减半；是否越过阈值取决于其他遗传和环境因素（修饰基因、母体胆固醇、酒精），所以表型从严重的无叶型前脑无裂畸形到仅有单一中切牙，不一而足，这是一种剂量敏感的阈值表型。

4. 鸡的表皮与小鼠真皮结合，形成按小鼠毛发图案排列的羽芽。这一结果的每一部分说明什么？小鼠表皮置于鸡鳞片形成区的真皮上，你预期会得到什么？

   **答** 结构的种类（羽毛）取决于表皮的基因型，所以表皮决定它能构建的附属器类别；排列方式和形成附属器的指令来自真皮。小鼠表皮置于鸡腿（鳞片）真皮上，应当形成毛囊，其排列由鸡真皮所赋予；真皮提供"在此处形成附属器"的信号和区域类型的信号，表皮则按其物种特异的方式解读它们。

5. 用公式 22.4.1 预测：若第二磨牙是第一磨牙大小的 80%，第三磨牙的相对大小是多少？若 $a/i$ 低于 1/2，第三磨牙会怎样？

   **答** $m_3/m_1 = 2(0.8) - 1 = 0.6$。由于 $m_2/m_1 = 1 + (a - i)/i = a/i$，故 $m_3/m_1 = 2a/i - 1$；当 $a/i < 1/2$ 时，$m_3/m_1 < 0$，意味着第三磨牙不形成，如同缺少第三磨牙的哺乳动物（以及许多人）。模型预测 m3 的丧失应与较小的 m2（小于 m1 的一半）相联系，鼠科啮齿动物就是这种模式。

6. 由定理 22.5.1 证明：在简化的力学–化学模型中，$\tau = \tau_{\mathrm{c}}$ 处的不稳定是振荡型的，并对 $\mu = D_1 = 1$、$s = 0.1$ 计算其频率。

   **答** 在 $\tau_{\mathrm{c}}$ 和 $K = K_{\mathrm{c}} = \sqrt{s/\mu D_1} = 0.316$ 处，$b = 0$，所以 $\mu K\lambda^{2} + c = 0$，$\lambda = \pm\mathrm{i}\sqrt{c/(\mu K)}$。取 $\tau_{\mathrm{c}} = 0.816$，$c = D_1K[(1 - \tau_{\mathrm{c}})K + s] = 0.316(0.184\times0.316 + 0.1) = 0.316\times0.158 = 0.050$，所以 $\omega = \sqrt{0.050/0.316} = 0.40$（标度时间单位），周期约 16 个单位；这与图中 C 图在 $k_{\mathrm{c}}$ 附近的频率一致。由于 $c > 0$，两个根都是复数：不稳定是振荡型的。

7. WNT–DKK 模型预测，在表皮中过表达 DKK 会降低毛囊密度。解释原因，并说明如何区分反应扩散机制与毛囊位置由独立网格规定的**预图式**。

   **答** 在激活物–抑制物系统中，更多的抑制物（或更低的激活物与抑制物之比）使每个激活物峰周围的抑制范围增大，所以峰间距拉大，密度下降，且随 DKK 剂量而渐变。预图式则预测毛囊的位置是固定的，DKK 只会把一些毛囊从其位置上去除，使其余的毛囊仍在原来的网格上、留下空缺。而反应扩散预测的是标度改变后的、间距更大的规则图案；此外，局部扰动（去除一个原基，或在一点增强 WNT）会使邻近的原基移位并重排，固定的预图式则不会。Sick 等发现间距呈渐变。

8. 为什么鸡的羽原基是逐行形成的？公式 22.5.1 的模拟对这种依次形成的方式对图案规则性的影响提示了什么？

   **答** 形成原基的感受态以前沿的形式从背中线扩散（由 EDA 与 FGF 等信号的波以及真皮的成熟所驱动），所以每一行形成于已有行的旁边。每个新原基的位置由前一行的抑制所决定，这使它与前一行对齐，图案就像晶体从晶种生长那样，从第一行起以有序的点阵生长；而在大面积上同时形成，如模拟和小鼠毛区那样，则成核出许多取向不同的畴，排列不规则。

9. 秃发的头皮仍保留隆突**干细胞**。说明这对治疗为何重要，以及何种信号操作可能恢复毛发生长。

   **答** 由于干细胞仍然存在，秃发是毛胚和**祖细胞**未被激活，而不是干细胞库的丧失，所以原则上是可逆的。激活毛胚的治疗可以恢复生长期：阻断 PGD2 受体 GPR44（DP2）、抑制雄激素作用（非那雄胺降低 DHT）、激活 WNT 信号或解除 BMP 抑制，以及药理性地激活生长期（米诺地尔作用于毛囊的血供与钾通道）；依赖于干细胞缺失的策略（如移植）并不是唯一的选择。

10. （开放题）*EDAR* V370A **等位基因**在东亚变得常见。概述如何检验它是否受到正选择，以及哪种发育性状可能是选择的目标。

    **答** 群体遗传学：证明该等位基因位于长单倍型中，频率高而多样性低（扩展单倍型纯合度高，iHS），其频率在不同人群之间差异很大（FST 高），并测定选择性清除的年代（根据单倍型长度估计约为 30 000 年前）。发育方面：把该变异敲入小鼠，测量附属器性状（毛发粗细、外泌汗腺数目、乳腺分支），然后在人类中把该变异与同样的性状相关联（毛发粗细、汗腺密度、铲形切牙等牙齿形状）。Kamberov 等（2013）发现带有 V370A 的小鼠毛发更粗、外泌汗腺更多、乳腺有改变；选择的目标可能是炎热潮湿气候中的出汗，也可能是乳腺的特征，这些仍是假说，因为单个等位基因影响多个性状。
