细菌在一级近似下是一个区室：由质膜包围的细胞质。真核细胞则是由区室构成的城市，每个区室有自己的膜、自己的一套蛋白质与脂质，以及自己的化学环境，从氧化性、富钙的**内质网**腔，到**溶酶体**的酸性内部。前两章讲述了使这类区室成为可能的膜（[7.3.4](/7.3.4)），以及使其内容物保持不同的运输（[7.3.5](/7.3.5)）。本章要问的是，细胞如何把自己组织成区室，并为每个区室供应正确的蛋白质，这是一个大规模的物流问题：人的细胞制造约 $10^4$ 种不同的蛋白质，几乎全部在胞质**核糖体**上合成，并且必须把每一种送到十几个目的地之一。我们先概览各个区室（6.1）以及它们的大小如何与细胞的大小相匹配（6.2）。本章其余部分追随蛋白质前往目的地：运输的三种方式及其指引信号（6.3），向内质网的转位（6.4），向**线粒体**（6.5）、**叶绿体**（6.6）与过氧化物酶体（6.7）的输入，最后是例外：不经过内质网而分泌的蛋白质，以及不借助囊泡而移动的脂质（6.8）。**信号识别颗粒**把核糖体靶向内质网的过程见 [7.2.19](/7.2.19#sec-19.9.2)，这里只作概述；向细胞核的输入是 [7.3.16](/7.3.16) 的主题，蛋白质从内质网出发由囊泡作进一步分选则占 [7.3.7](/7.3.7)–[7.3.11](/7.3.11)。线粒体与叶绿体的**细胞器**生物学（动态、基因组、起源）见 [7.3.12](/7.3.12)。

## 6.1. 真核细胞的区室

### 6.1.1. 膜包被的细胞器

**定义 6.1.1（膜包被细胞器）** **膜包被细胞器**是真核细胞中由一层或两层脂双层包围的区室，其膜与内腔中的蛋白质和脂质具有特征性组成，执行一组确定的功能。把细胞分成这类区室，每个区室都由选择性通透的膜与胞质溶胶隔开，称为**区室化**。

区室化做到了单一区室做不到的三件事。它使不相容的反应彼此分开（**脂肪酸**的合成在胞质溶胶中，它们的氧化在线粒体中；一些蛋白质在胞质溶胶中折叠，另一些在溶酶体中被消化）。它提供与胞质溶胶不同的环境（低 pH、氧化条件、高 $\ce{Ca^2+}$），并使酶与**底物**浓缩在小的体积中。它还成倍增加了供**氧化磷酸化**与脂质合成等膜结合过程利用的膜面积。

| 区室 | 在肝细胞中占细胞体积的比例 | 主要功能 |
|---|---|---|
| 胞质溶胶 | $54\,\%$ | 蛋白质合成与降解，大部分中间代谢 |
| 线粒体 | $22\,\%$ | 氧化磷酸化、**柠檬酸循环**、**β 氧化**、Fe–S 簇、**细胞凋亡**信号 |
| **粗面内质网** | $9\,\%$ | 分泌蛋白与膜蛋白的合成 |
| **光面内质网** | $5\,\%$ | 脂质合成、解毒、$\ce{Ca^2+}$ 储存 |
| **高尔基体** | $1\,\%$ | **糖基化**、蛋白质与脂质的分选 |
| 细胞核 | $6\,\%$ | 基因组、DNA 与 RNA 合成、核糖体组装 |
| 过氧化物酶体 | $1\,\%$ | 产生 $\ce{H2O2}$ 的氧化反应、极长链脂肪酸氧化、醚脂 |
| 溶酶体 | $1\,\%$ | 降解 |
| **内体** | $1\,\%$ | 被内吞物质的分选 |

（MBoC 第 7 版，表 12–1。）膜包围了肝细胞近一半的体积，而质膜只是细胞膜的一小部分：在体积约 $5000\,\mu\mathrm{m^3}$、膜面积约 $110\,000\,\mu\mathrm{m^2}$ 的肝细胞中，质膜占 $2\,\%$，粗面与光面内质网合占约一半，线粒体内膜占三分之一；在专门分泌的胰腺腺泡细胞中，仅粗面内质网就占膜的 $60\,\%$。因此各区室的相对大小反映了细胞所做的事。

细胞器也可以按其边界分组，这反映了它们的起源：

| 边界 | 细胞器 | 说明 |
|---|---|---|
| 两层膜 | 细胞核（**核被膜**）、线粒体、**质体** | 核被膜是内质网压扁的囊，所以它的两层膜围出一个内腔；线粒体与质体的两层膜围出两个分开的空间，来自细菌的被膜（6.1.3） |
| 一层膜 | 内质网、高尔基体、内体、溶酶体、植物与真菌的**液泡**、分泌囊泡、过氧化物酶体（及乙醛酸循环体） | 除过氧化物酶体外都属于内膜系统 |
| 无膜 | 核糖体、**中心体**与**中心粒**、**细胞骨架**、**核仁**及其他**生物大分子凝聚体**（6.1.4）、**蛋白酶体** | 胞质溶胶或核质中的大分子组装体或凝聚体 |

### 6.1.2. 胞质溶胶

细胞质是质膜之内除细胞核之外的一切；胞质溶胶是其中的流体部分，位于膜包被细胞器之外（两个术语在 [7.1.1](/7.1.1) 中有定义）。胞质溶胶不是稀溶液：它含有约 $200$–$300\,\mathrm{g\,L^{-1}}$ 的蛋白质，所以**大分子拥挤**提高了**生物大分子**的有效浓度与缔合常数，减慢它们的扩散（GFP 在细胞质中的扩散比在水中慢约四倍），并有利于紧凑的状态。胞质溶胶被细胞骨架的纤维（[7.3.13](/7.3.13)–[7.3.15](/7.3.15)）穿过，后者把它组织起来；它是蛋白质合成的场所、由胞质**分子伴侣**完成的大部分折叠的场所，以及**泛素–蛋白酶体系统**（[7.2.20](/7.2.20)）降解的场所。有些教科书把胞质溶胶连同贯穿其中的细胞骨架称为细胞质基质（cytomatrix），强调它是有结构的凝胶而不是溶液。它的功能很多。

| 功能 | 例子 |
|---|---|
| 代谢 | **糖酵解**、**磷酸戊糖途径**、**糖异生**（大多数步骤）、**糖原**的合成与分解、脂肪酸合成、核苷酸与许多氨基酸的合成（[7.1.18](/7.1.18)–[7.1.28](/7.1.28)） |
| 蛋白质合成与质量控制 | 游离核糖体上的翻译；分子伴侣的折叠；修饰（磷酸化、乙酰化、**泛素**化）；蛋白酶体的选择性降解；**N 端降解决定子**（[7.2.20](/7.2.20)） |
| 离子与化学环境 | 保持在 pH 约 7.2，$\ce{Na+}$ 与 $\ce{Ca^2+}$ 低，$\ce{K+}$ 高（[7.3.5](/7.3.5)），并且是还原性的（谷胱甘肽含量高） |
| 对细胞器的供应 | 细胞器代谢所需的底物、ATP 与**辅因子**；所有核基因编码的细胞器蛋白质（6.3） |
| 信号与基因表达的控制 | **第二信使**、激酶级联、转录因子的胞质滞留与释放（[7.3.18](/7.3.18)）；细胞命运的**细胞质决定子**（[7.3.24](/7.3.24)） |
| 组织与运输 | 细胞器与 **mRNA** 在细胞骨架上的锚定；马达驱动的运输（[7.3.13](/7.3.13)–[7.3.15](/7.3.15)） |

### 6.1.3. 内膜系统及其拓扑

**定义 6.1.2（内膜系统）** **内膜系统**包括通过囊泡运输彼此之间以及与质膜交换膜和腔内容物，或彼此连续的细胞器：内质网与核被膜、高尔基体、内体、溶酶体、运输囊泡与分泌囊泡，以及质膜本身。

线粒体与质体不属于它：它们由内共生产生（**内共生学说**，[7.1.1](/7.1.1)），有自己的基因组，通过从胞质溶胶输入蛋白质而生长并分裂，并且不与其他细胞器交换囊泡。过氧化物酶体处于中间位置：它们从胞质溶胶输入大多数蛋白质，但可以由内质网产生（6.7.3）。

内膜系统的细胞器在拓扑上是相关的。每个区室的腔等价于细胞的外部：从一个膜出芽并与另一个膜融合的囊泡把它的腔内容物从腔运到腔，其膜的胞质面始终朝向胞质溶胶。这就解释了为什么在内质网与高尔基体腔中添加的聚糖出现在质膜的外侧（[7.3.4](/7.3.4#sec-4.6.1)），以及为什么分泌与**内吞作用**互为镜像。核被膜是双层膜，其**核周隙**与内质网腔连续，也符合这一图景，并提示了这一系统如何起源：祖先细胞的质膜围绕其染色体并向细胞质中内陷。因为胞质溶胶与核质通过核孔相通，它们在拓扑上是同一个空间，而**线粒体基质**与叶绿体基质则是分开的空间，来自细菌祖先的细胞质。

### 6.1.4. 无膜区室

细胞也在没有膜的情况下浓缩分子，即在由蛋白质与 RNA 经**液–液相分离**形成、靠**多价性**与**内在无序区**维系的**生物大分子凝聚体**中（[7.2.21](/7.2.21)）：细胞核中的核仁、Cajal 小体与核斑点；细胞质中的**应激颗粒**、P 小体与生殖颗粒。其物理见 [7.2.21](/7.2.21)；对细胞生物学家，有两点重要。第一，凝聚体是与膜细胞器协作的功能区室。在突触前终末，突触囊泡的储备池由突触蛋白（synapsin）与其他蛋白质的凝聚体维系在一起，使数百个囊泡聚集而仍可移动，并在突触蛋白被磷酸化时释放它们；在突触后致密区中，支架蛋白形成凝聚体，使受体与信号酶浓缩。在蓝细菌和某些化能自养生物中，Rubisco 与连接蛋白一起凝聚，并被蛋白质外壳包裹成羧酶体，使 $\ce{CO2}$ 浓缩以供碳固定。第二，凝聚体的物质状态随时间变化，从液体到凝胶再到固体，细胞通过选择性自噬处置它们（[7.3.11](/7.3.11)）。在秀丽隐杆线虫（*Caenorhabditis elegans*）胚胎中，留在体细胞中的 P 颗粒被衔接蛋白 SEPA-1 与 EPG-2 转化为凝胶状的组装体，并被自噬降解；在哺乳动物细胞中，伴侣蛋白亚基 CCT2 作为受体，把固态的蛋白质聚集体而非液态凝聚体靶向自噬体。逃脱这种清除的聚集体在神经退行性疾病中积累。

## 6.2. 细胞器应该多大？

细胞器的大小随细胞的大小而变。在芽殖酵母中，线粒体网络的总体积与细胞体积成正比；在秀丽隐杆线虫和爪蟾（*Xenopus*）的早期胚胎中，细胞在每次卵裂时体积减半，中心体、有丝分裂纺锤体与细胞核按比例变小。在限制于不同大小液滴中的爪蟾卵提取物中，小液滴中组装的纺锤体较小，纺锤体长度随液滴体积而变，直到达到最大值。这些观察提示，大小至少部分不是由每个细胞器内部的某把尺决定的，而是由细胞提供的物质量决定的。

**定义 6.2.1（有限池模型）** 在细胞器大小的**有限池模型**中，细胞器由胞质中的亚基池装配而成，亚基池的总量正比于细胞体积；只要游离亚基浓度超过由装配与解聚的平衡决定的临界值，细胞器就生长，于是生长耗尽亚基池，直到装配与解聚平衡，稳态大小由可用的亚基量决定，而不是由细胞器的内在性质决定。

**命题 6.2.1** 设细胞体积为 $V$ 时亚基总量为 $N = \rho V$，大小为 $S$（以亚基数计）的细胞器以速率 $k_{\mathrm{on}}c$ 获得亚基，其中 $c = (N - S)/V$ 是游离浓度，并以恒定速率 $k_{\mathrm{off}}$ 失去亚基。则只要 $\rho > c^*$，$S$ 就以时间常数 $V/k_{\mathrm{on}}$ 指数地趋于

$$
S^* = N - c^*V = (\rho - c^*)V, \qquad c^* = \frac{k_{\mathrm{off}}}{k_{\mathrm{on}}},
$$
若 $\rho \le c^*$ 则不形成细胞器。

**证明** 大小服从 $\mathrm{d}S/\mathrm{d}t = k_{\mathrm{on}}(N - S)/V - k_{\mathrm{off}}$，这是线性方程，不动点为 $S^* = N - (k_{\mathrm{off}}/k_{\mathrm{on}})V$，弛豫速率为 $k_{\mathrm{on}}/V$；由 $S(0) = 0$ 出发的解为 $S(t) = S^*(1 - \mathrm{e}^{-k_{\mathrm{on}}t/V})$。代入 $N = \rho V$ 即得结果。$\square$

该模型作出可检验的预测：当单位体积的表达量恒定时，细胞器大小正比于细胞体积；亚基耗尽（$\rho$ 降低）时它变小，过表达时变大；稳态时游离亚基浓度在各种大小的细胞中相同。秀丽隐杆线虫胚胎中的中心体就是这样：其大小受每个细胞中支架蛋白 SPD-2 的量限制，去除两个中心体之一时，另一个会长得更大。

![细胞器大小的有限池模型（命题 6.2.1，任意单位，ρ = 1，c* = 0.4）。A：细胞器从其亚基池生长，直到游离浓度降到 c*；在体积为 1、2 和 4 的细胞中，最终大小（点线）正比于体积，而较大的细胞需要更长时间才能达到。B：稳态大小与细胞体积的关系：有限池模型给出过原点的直线，当细胞间的表达量有 8 % 的变异时有散布（点）；降低单位体积的表达量（ρ = 0.7，虚线）会降低斜率。大小由内在标尺决定的细胞器在所有细胞中大小相同（灰色）](./plots/limiting-pool.py)

并非每个细胞器的大小都由一个池决定。当两个细胞器以同样的自催化生长竞争同一个池时，模型使它们的相对大小不确定，细胞用额外的反馈使它们相等。其他控制大小的机制包括依赖长度的装配与不依赖长度的解聚之间的平衡（衣藻 *Chlamydomonas* 鞭毛的长度，由鞭毛内运输把亚基送到顶端的速率决定，[7.3.14](/7.3.14)），以及受输入速率限制的生长（细胞核，其体积以恒定的核质比跟随细胞体积，[7.3.16](/7.3.16)）。细胞各部分如何与整体匹配的问题在 [7.3.22](/7.3.22) 中对细胞大小本身再次出现。

## 6.3. 蛋白质分选的逻辑

### 6.3.1. 三种运输方式

**定义 6.3.1（蛋白质分选）** **蛋白质分选**（蛋白质靶向）是在蛋白质合成之后或合成期间，由其自身序列中的信息指引，把每个蛋白质送到它发挥功能的区室。蛋白质以三种方式在区室之间移动：

- **门控运输**，在拓扑上等价的空间，即胞质溶胶与细胞核之间，通过核孔复合体，核孔复合体选择性地让折叠的蛋白质与大复合物通过，并让小分子扩散；
- **蛋白质跨膜运输**，通过蛋白质转位子，通常以未折叠状态，从胞质溶胶跨过膜进入拓扑上不同的空间（内质网腔、线粒体、质体、过氧化物酶体）；
- **膜泡运输**，在内膜系统拓扑上等价的区室之间，用从一个区室出芽并与下一个区室融合的膜包被运载体。

由此得到的路线图很简单。每个核基因编码的蛋白质都始于胞质核糖体。没有分选信号的蛋白质留在胞质溶胶中。进入内质网的蛋白质随后可以通过囊泡到达高尔基体、质膜、内体与溶酶体，或细胞外部，而无需再穿过另一层膜；要到达线粒体、质体或过氧化物酶体的蛋白质，则必须直接从胞质溶胶输入。因此第一个决定，即是否进入内质网，是最重要的，并且在合成的头几秒就作出。

![蛋白质分选的路线图。所有核基因编码的蛋白质都在胞质溶胶中的核糖体上合成。穿过核孔的门控运输（紫色，虚线）连接胞质溶胶与细胞核；由转位子进行的跨膜运输（红色）把蛋白质从胞质溶胶送入内质网、线粒体、质体与过氧化物酶体；膜泡运输（蓝色）连接分泌途径与内吞途径的各个区室（在虚线框内），其腔在拓扑上等价于细胞的外部](./plots/sorting-road-map.py)

### 6.3.2. 分选信号

**定义 6.3.2（分选信号）** **分选信号**是蛋白质上把它导向特定区室的特征：一段连续的氨基酸（信号序列，常为 15–60 个残基，位于 N 端、C 端或内部），或由序列上相距较远的残基在折叠的蛋白质中形成的信号斑，或某种修饰，如特定的聚糖。信号由分选受体读取，受体把蛋白质送到转位子或囊泡外被；使用后被去除的信号由信号肽酶切除。

## 6.4. 向内质网的转位

### 6.4.1. 信号假说

1972 年，César Milstein 及其同事发现，在无细胞体系中翻译的免疫球蛋白轻链，其 N 端比骨髓瘤细胞分泌的轻链长约 20 个残基，而在翻译体系中加入内质网膜（微粒体）则产生成熟大小的轻链。Günter Blobel 与 David Sabatini（1971）已经提出了这一解释，Blobel 与 Bernhard Dobberstein（1975）则证明了它。

**定义 6.4.1（信号假说）** **信号假说**认为，注定要分泌的蛋白质在其 N 端带有信号序列，当它从核糖体中露出时，把核糖体导向内质网膜，并把延伸的肽链导入内质网腔，信号在腔中被去除；推广的形式（Blobel，1980）则认为，每个蛋白质的序列中都含有决定它在细胞中位置的信息。

机器在 [7.2.19](/7.2.19#sec-19.9.2) 中讲述：信号识别颗粒是由 $300$ 个核苷酸的 7SL RNA 与六条多肽组成的核糖核蛋白（SRP54 结合信号序列，是 GTP 酶；SRP9 与 SRP14 引起延伸的暂停），在信号序列从核糖体中露出时结合它并减慢延伸，停靠到内质网膜上的 SRP 受体，并把核糖体交给转位子；两种 GTP 酶的 GTP 水解释放 SRP，进入下一轮。因此合成内质网蛋白的核糖体只在合成这种蛋白质时才附着在内质网膜上；"膜结合"与"游离"核糖体是同一群体，同一条 mRNA 由内质网结合核糖体的**多聚核糖体**翻译。Blobel 获得了 1999 年诺贝尔生理学或医学奖。

### 6.4.2. Sec61 转位子

**定义 6.4.2（Sec61 转位子）** **Sec61 转位子**是内质网膜的蛋白质传导通道，是 Sec61α（十个跨膜螺旋围绕沙漏形孔排成蛤壳状）、Sec61β 与 Sec61γ 的异源三聚体，与细菌和古菌的 SecYEG 同源。缢缩处的一圈疏水残基与一小段塞状螺旋在静息状态下封住孔；Sec61α 的跨膜螺旋 2 与 7 之间的侧向门朝脂双层打开，让肽链的疏水片段从侧面离开通道进入膜中。

信号序列以螺旋形式结合在侧向门处而打开通道，使塞子移位；肽链随后以环的形式通过，N 端留在通道中，下游部分穿入腔中。在转位期间，腔与胞质溶胶对小分子而言并不相通，因为核糖体封住通道的一侧，疏水孔环紧紧围绕肽链，而 BiP 在通道空闲时结合在腔侧。与转位子相连的信号肽酶在腔侧切除信号，另一个邻居寡糖基转移酶则在肽链露出时添加 N-连接聚糖（[7.3.7](/7.3.7)）。

### 6.4.3. 共翻译转运与翻译后转运

**定义 6.4.3（共翻译与翻译后转运）** 在**共翻译转运**中，多肽在仍由结合在通道上的核糖体合成的同时穿过转位子，延伸中的核糖体本身提供方向性。在**翻译后转运**中，已完成的多肽从核糖体上释放，由胞质分子伴侣保持未折叠状态，再通过转位子输入；在真核生物中，这需要 Sec62–Sec63 复合物与腔内分子伴侣 BiP，后者与露出的肽链的 ATP 依赖性结合防止它滑回。

在哺乳动物中，大多数分泌蛋白与膜蛋白以共翻译方式进入，但短的分泌蛋白（少于约 160 个残基，信号一露出它们几乎就从核糖体释放）与尾锚定蛋白（6.4.5）在翻译后输入。酵母以翻译后方式输入许多蛋白质，而细菌通过 SecYEG 以翻译后方式输出大多数蛋白质，由胞质 ATP 酶 SecA 分步把肽链推过去。

一个只能结合的分子伴侣如何能拉动肽链？BiP 并不拉。肽链靠热运动在通道中前后扩散；每当有足够的一段在腔侧露出，ATP 状态的 BiP 分子就结合，ATP 水解把它锁住。结合的 BiP 太大，无法穿过通道，所以肽链不再能越过该点退回，而仍可自由向前移动。热运动被整流成定向的转位：这是一种 Brown 棘轮，同样的机制也在线粒体输入中起作用（6.5.3）。

### 6.4.4. 信号决定膜蛋白的拓扑结构

同样的机器把整合膜蛋白插入内质网膜，序列中疏水片段的排列决定每个蛋白质将如何跨膜。两类信号合起来起作用。

**定义 6.4.4（起始转移序列与停止转移序列）** **起始转移序列**是打开转位子并启动后续肽链向内质网腔转位的疏水片段：被切除的 N 端信号序列，或内部不被切除的信号锚定序列，后者作为跨膜螺旋留在膜中。**停止转移序列**是在转位开始之后进入转位子的疏水片段，使转位停止，并从侧面离开通道进入脂双层，成为跨膜螺旋，使肽链的其余部分留在胞质溶胶中。

| 类型 | 信号 | 取向 | 例子 |
|---|---|---|---|
| 可溶性腔内蛋白或分泌蛋白 | 被切除的 N 端信号序列 | 整条链在腔中 | 白蛋白、胰岛素、抗体、BiP |
| 单次跨膜 I 型 | 被切除的信号序列 + 停止转移序列 | N 端在腔（外侧），C 端在胞质溶胶 | LDL 受体、胰岛素受体、血型糖蛋白 |
| 单次跨膜 II 型 | 内部信号锚定序列，其 N 端一侧有正电荷 | N 端在胞质溶胶，C 端在腔 | 转铁蛋白受体、高尔基体糖基转移酶 |
| 单次跨膜 III 型 | 内部信号锚定序列，其 C 端一侧有正电荷 | N 端在腔，C 端在胞质溶胶 | 内质网的细胞色素 P-450 |
| 尾锚定 | C 端单个跨膜片段 | N 端在胞质溶胶 | Sec61β、细胞色素 b₅、SNARE、Bcl-2 家族（在线粒体上） |
| 多次跨膜 | 交替的起始与停止转移序列（内部信号锚定序列） | 由第一个片段决定 | GPCR、转运蛋白、通道 |
| GPI 锚定 | 被切除的信号序列 + C 端 GPI 信号 | 整个蛋白质在腔中，连在腔侧小叶上 | 碱性磷酸酶、CD59、朊病毒蛋白 |

信号锚定序列的取向主要由其周围带电残基的分布决定：正电荷较多的一侧留在胞质溶胶中，这就是 [7.1.13](/7.1.13#sec-13.1.5) 的**疏水性图**中所见的"内正"规则（并且在胞质溶胶中迅速折叠的 N 端结构域也不能被转位）。在多次跨膜蛋白中，第一个信号锚定序列决定取向，其后的片段交替作为停止与起始转移序列，所以整个蛋白质的拓扑结构通常可以由其序列预测。实际过程更灵活：片段在插入后可以重新取向，疏水性弱的片段构成的多次跨膜蛋白借助与 Sec61 相连的其他复合物（EMC 与"多次跨膜转位子"）插入，这些复合物屏蔽极性残基，直到螺旋彼此堆积在一起。

**例 6.4.1** 一个 420 个残基的蛋白质，在第 30–50、95–115、160–180 和 300–320 位有疏水片段（各约 20 个残基），没有可切除的信号；残基 1 到 30 之间的环含有五个 Lys 与 Arg，环 51–94 没有，环 116–159 有四个，环 181–299 有一个。预测其拓扑结构。第一个疏水片段起信号锚定序列的作用；带正电的 N 端侧翼留在胞质溶胶中，所以残基 51–94 在腔中。第二个片段起停止转移序列的作用，所以环 116–159（带正电，符合规则）在胞质溶胶中；第三个片段是起始转移序列，所以 181–299 在腔中（有一个带正电的残基，与之一致）；第四个是停止转移序列，C 端（321–420）在胞质溶胶中。该蛋白有四个跨膜螺旋，两端都在胞质溶胶中；其 N-糖基化位点（Asn-X-Ser/Thr）应位于环 51–94 与 181–299 中，这是用实验检验该预测的一种方法（糖基化报告、蛋白酶保护，[7.3.4](/7.3.4#ex-4.3.1)）。

### 6.4.5. 尾锚定蛋白与 GET 途径

**定义 6.4.5（尾锚定蛋白）** **尾锚定蛋白**是整合膜蛋白，在距其 C 端约 30 个残基以内有单个跨膜片段，功能结构域在胞质溶胶中；由于跨膜片段在翻译终止之后才从核糖体中露出，它不能被 SRP 识别，而是在翻译后被靶向并插入。

约 $2$–$5\,\%$ 的膜蛋白，在人细胞中有几百个，是尾锚定的。尾部疏水性强的，在离开核糖体时被一个前靶向复合物（哺乳动物中是 SGTA 与 Bag6 复合物，酵母中是 Sgt2 与 Get4–Get5）捕获，并交给 ATP 酶 Get3（哺乳动物中是 TRC40），其疏水沟在胞质溶胶中屏蔽跨膜螺旋。Get3 停靠到内质网膜上的受体 Get1–Get2（WRB–CAML）上，后者还起插入酶的作用；ATP 水解释放 Get3 进入新一轮循环，这一方案与 SRP 循环平行，只是用 ATP 代替了 GTP。尾部疏水性较弱的尾锚定蛋白由内质网膜蛋白复合物（EMC）插入。线粒体的尾锚定蛋白，如许多 Bcl-2 家族成员与 Tom5，则插入线粒体外膜，其麦角固醇或胆固醇含量低以及特异的插入酶有利于它们；错误靶向的蛋白质被 AAA ATP 酶 Msp1（ATAD1）提取出来。

### 6.4.6. GPI 锚

**定义 6.4.6（GPI 锚）** **GPI 锚**（糖基磷脂酰肌醇锚）是在内质网膜中预先组装好的糖脂（磷脂酰肌醇、葡糖胺、三个甘露糖与磷酸乙醇胺），转酰胺酶切下 15–20 个残基的 C 端疏水信号后，把它连接到蛋白质新的 C 端上；此后蛋白质仅靠锚的脂链固定在内质网膜的腔侧小叶上，后来则固定在质膜的外表面上。

人类约有 150 种蛋白质是 GPI 锚定的，包括酶（碱性磷酸酶）、受体（叶酸受体、CD14）、黏附分子以及补体抑制因子 CD55 与 CD59。GPI 锚定蛋白集中于**脂筏**中，并被分选到许多上皮细胞的顶端表面（[7.3.4](/7.3.4#sec-4.6.2)），并且可被磷脂酶从细胞表面释放。在阵发性夜间血红蛋白尿症中，造血干细胞获得编码 GPI 合成第一步的酶的 *PIGA* 的体细胞突变；其后代红细胞缺乏所有 GPI 锚定蛋白，包括 CD55 与 CD59，因而被补体裂解，说明了单一的锚如何服务于整整一类蛋白质。

在内质网中未能折叠的蛋白质通过由泛素连接酶 Hrd1 形成的通道返回胞质溶胶降解（逆向转位），这是 [7.3.7](/7.3.7) 的主题。

## 6.5. 蛋白质向线粒体的输入

### 6.5.1. 前导序列与四条输入途径

线粒体含有约 1000（酵母）到 1500（人）种不同的蛋白质，其中只有 8 种（酵母）或 13 种（人）由线粒体基因组编码（[7.3.12](/7.3.12)）；其余的在胞质核糖体上合成并输入到四个亚区室：外膜、膜间隙、内膜与基质。

**定义 6.5.1（前导序列）** **前导序列**（线粒体靶向序列，又称导肽）是约 15–50 个残基的 N 端序列，把蛋白质靶向线粒体基质；它形成两亲性的 **α 螺旋**，一面是带正电的残基（Arg、Lys），另一面是疏水残基，没有酸性残基，并在输入后被基质加工肽酶（MPP）切除。

约三分之二的线粒体蛋白质有前导序列；其余的带有把它们导向外膜、内膜或膜间隙的内部信号。它们都通过外膜上的同一个入口，然后分道。

**定义 6.5.2（线粒体蛋白质转位酶）** **TOM 复合体**（外膜转位酶）是一般的入口，由 **β 桶** Tom40 形成，带有受体 Tom20（针对前导序列）与 Tom70（针对疏水的内膜载体）以及中央受体 Tom22。**TIM23 复合体**（内膜转位酶）把带前导序列的蛋白质输入基质，或使它们侧向释放到内膜中，由膜电势与基质输入马达（PAM）驱动。TIM22 复合体插入内膜的多次跨膜载体蛋白。**SAM 复合体**（分选与装配机器，含 β 桶蛋白 Sam50）把 β 桶蛋白从膜间隙插入外膜。

### 6.5.2. 什么驱动输入

穿过两层膜的输入需要三种能量输入。胞质溶胶中的 ATP 被胞质 Hsp70 分子伴侣用来使前体保持未折叠而能输入的状态。内膜两侧的膜电势，内负 $150$–$180\,\mathrm{mV}$，是**质子动力势**（[7.1.23](/7.1.23)）的一个分量，以电泳方式把带正电的前导序列拉过 TIM23；使其崩溃的解偶联剂阻断输入，这一要求就是线粒体生长需要有功能的**呼吸链**或反向运行的 **ATP 合酶**的原因。基质中的 ATP 被 mtHsp70 使用，它在肽链露出时结合它并把它拉入；许多输入的蛋白质随后由伴侣蛋白 Hsp60–Hsp10 在基质中折叠，它是细菌 GroEL–GroES 的线粒体对应物（[7.1.6](/7.1.6)），而有些最先暴露在基质一侧的蛋白质则由 Oxa1 重新分选进入内膜。

**例 6.5.1** 电泳拉力有多强？带 $z = 4$ 个净正电荷的前导序列，处在厚 $d \approx 4\,\mathrm{nm}$、$\Delta\psi = 160\,\mathrm{mV}$ 的内膜中，受力 $F = ze\Delta\psi/d = 4 \times 1.6\times10^{-19}\,\mathrm{C} \times 0.16\,\mathrm{V}/(4\times10^{-9}\,\mathrm{m}) \approx 26\,\mathrm{pN}$，获得能量 $ze\Delta\psi = 0.64\,\mathrm{eV} \approx 24\,k_{\mathrm{B}}T$。这足以把前导序列拉过膜，并使紧随其后的折叠松散的结构域部分展开，但不足以展开稳定的结构域；而且该力只作用在膜中的电荷上，所以不能输入肽链的其余部分。这是由马达完成的。

经典实验确定，肽链是在两层膜靠得很近的位点上，以未折叠的状态同时穿过两层膜的。前导序列与小鼠**二氢叶酸还原酶**（DHFR）的融合蛋白可正常输入；在甲氨蝶呤（它结合 DHFR 并稳定其折叠）存在时，输入停止，前导序列在基质中（被 MPP 切除），而 DHFR 结构域在外膜之外。这种停滞的中间体同时跨越 TOM 与 TIM23：通过两层膜的输入是偶联的。

### 6.5.3. 作为 Brown 棘轮的输入马达

mtHsp70 如何驱动肽链，已经以两个极限模型的形式争论过。在动力冲程模型中，与通道出口处的 Tim44 结合的 mtHsp70 结合肽链，并通过构象变化把它向内拉。在棘轮模型中，mtHsp70 结合已扩散进入基质的任何片段，防止它滑回，恰如 BiP 在内质网中所做的（6.4.3）。棘轮模型有一个简单的定量形式。

**公式 6.5.1（转位棘轮）** 设肽链在通道中以系数 $D$ 扩散，每当又有长度 $\delta$ 的一段露出时，就有一个棘轮分子快速而不可逆地结合（完美棘轮）。在对抗力 $f$ 作用下转位的平均速度为（Simon、Peskin 与 Oster，1992）

$$
v = \frac{2D}{\delta}\cdot\frac{\omega^2/2}{\mathrm{e}^{\omega} - 1 - \omega}, \qquad \omega = \frac{f\delta}{k_{\mathrm{B}}T},
$$
零负载时 $v = 2D/\delta$，大负载时大致按指数下降。

零负载的结果可由在反射壁旁扩散一段距离 $\delta$ 的时间 $\delta^2/(2D)$ 理解。棘轮不需要产生力的步骤：它的能量来自分子伴侣的结合与 ATP 水解，使结合状态不可逆，其失速力取决于这一自由能。这类棘轮，以纤维聚合代替分子伴侣结合，也解释了肌动蛋白如何把膜向前推（[7.3.13](/7.3.13)）。对线粒体输入，证据提示两种机制都有贡献：棘轮足以应付折叠松散的蛋白质，而外膜之外紧密折叠的结构域则需要主动的拉力来展开。输入常常不是受转位限制，而是受外侧结构域自发展开的速率限制，这就是使稳定性降低的突变能加快输入的原因。

![转位棘轮（单位 δ = D = k_B T = 1）。A：在通道中扩散的肽链，有（绿色）与无（灰色）阻止越过每个新结合位点向后运动的棘轮；整流的扩散以平均速度 2D/δ（虚线）前进，而自由扩散平均而言原地不动。B：由 200 条模拟肽链得到的速度与对抗负载 fδ/k_B T 的关系（点）与公式 6.5.1（线）一致](./plots/translocation-ratchet.py)

## 6.6. 蛋白质向叶绿体的输入

叶绿体含有约 3000 种蛋白质，其中由质体基因组编码的不足 100 种。核基因编码的基质蛋白带有 N 端转运肽，长 30–100 个残基，富含羟基残基，酸性残基少，在外被膜处被识别，并由基质加工肽酶去除。

**定义 6.6.1（TOC 与 TIC 复合体）** **TOC 复合体**（叶绿体外被膜转位子）含有 β 桶通道 Toc75（Omp85 家族成员，如同 Sam50）以及识别转运肽的 GTP 酶受体 Toc159 与 Toc34。**TIC 复合体**（内被膜转位子）是约 1 MDa 的大复合体，其通道由 Tic20、Tic214（由叶绿体基因组编码）及其他亚基形成；基质中由 ATP 驱动的马达，包括 AAA 蛋白复合体 Ycf2–FtsHi 与分子伴侣 Hsp93 和 Hsp70，把肽链拉入基质。

向叶绿体的输入与线粒体输入的能量来源不同：被膜两侧没有膜电势，输入由 TOC 受体处的 GTP 与基质中的 ATP 驱动。类囊体膜与腔的蛋白质在转运肽之后带有第二个信号，在基质中被切割后暴露出来（二分信号），并通过四条途径之一把它们导向穿过或进入类囊体膜，其中三条继承自蓝细菌祖先。质体蓝素是类囊体腔中的一种铜蛋白，是经典的例子：其前体带有 N 端转运肽，经 TOC 与 TIC 输入后在基质中被去除，其后是类似细菌信号序列的类囊体信号，把它经 cpSec 转位子导入腔中，在那里被类囊体加工肽酶切割。每个信号由一层膜的机器读取，信号在序列中的顺序重现了蛋白质必须穿过的膜的顺序。

| 途径 | 货物 | 机器 | 能量 | 细菌中的对应物 |
|---|---|---|---|---|
| cpSec | 未折叠的腔内蛋白（质体蓝素、PsbO） | SecA、SecY–SecE | ATP | Sec |
| cpTat | 折叠的腔内蛋白，常带有结合的辅因子；信号带有双精氨酸（RR）基序 | Tha4、Hcf106、cpTatC | 类囊体 $\Delta\mathrm{pH}$ | Tat |
| cpSRP | 膜的捕光叶绿素结合蛋白（LHCP） | cpSRP43–cpSRP54、cpFtsY、插入酶 Alb3 | GTP | SRP、YidC |
| 自发 | 某些单次跨膜蛋白 | 无 | — | — |

类囊体腔是单个细胞器内的第四个空间，Tat 途径的显著之处在于把完全折叠的蛋白质运过膜而不耗散其质子梯度。质体的细胞器生物学（类型及其互相转变、分裂、对细胞核的信号）见 [7.3.12](/7.3.12)。

## 6.7. 过氧化物酶体

### 6.7.1. 过氧化物酶体做什么

过氧化物酶体与植物种子中相关的乙醛酸循环体，最初是在肝与肾的电子显微照片中被描述为微体（Johannes Rhodin，1954），即带颗粒状基质的小囊泡，常含有尿酸氧化酶的结晶核心；de Duve 的分级分离随后依据其酶来确定它们（[7.3.3](/7.3.3)）。

**定义 6.7.1（过氧化物酶体）** **过氧化物酶体**是小的细胞器（通常 $0.1$–$1\,\mu\mathrm{m}$），由单层膜包围，没有基因组，含有利用 $\ce{O2}$ 氧化有机底物并产生过氧化氢的氧化酶，以及分解或利用 $\ce{H2O2}$ 的过氧化氢酶；它从胞质溶胶以折叠状态输入基质蛋白。

名称来自过氧化氢。过氧化物酶体的氧化酶（除人以外大多数哺乳动物中的尿酸氧化酶、D-氨基酸氧化酶、酰基辅酶 A 氧化酶）把氢原子从底物转移给 $\ce{O2}$：

$$
\ce{RH2 + O2 -> R + H2O2}, \qquad \ce{2H2O2 ->[catalase] 2H2O + O2} \quad\text{或}\quad \ce{H2O2 + R'H2 ->[catalase] R' + 2H2O}.
$$
过氧化氢酶用 $\ce{H2O2}$ 氧化酚、甲酸、甲醛与乙醇；在肝与肾中，约四分之一摄入的乙醇以这种方式氧化。过氧化物酶体有五项主要的代谢功能：

| 功能 | 细节 | 链接 |
|---|---|---|
| 极长链脂肪酸的 **β 氧化** | 长于 C₂₂ 的链在过氧化物酶体中被缩短（第一步由酰基辅酶 A 氧化酶催化，产生 $\ce{H2O2}$ 而不是 $\ce{FADH2}$），再在线粒体中完成；在酵母与植物中，所有脂肪酸氧化都在过氧化物酶体中 | [7.1.21](/7.1.21) |
| 醚脂的合成 | **缩醛磷脂**合成的最初几步；缩醛磷脂约占髓鞘磷脂的 $80\,\%$ | [7.1.12](/7.1.12) |
| 胆汁酸与其他脂质 | 胆汁酸合成中胆固醇侧链的缩短；植烷酸的降解（α 氧化） | [7.1.26](/7.1.26) |
| 植物乙醛酸循环体 | 在萌发的油料种子中，β 氧化与**乙醛酸循环**把储存的脂肪转化为琥珀酸与糖 | [7.1.25](/7.1.25) |
| 植物叶过氧化物酶体 | **光呼吸**中的乙醇酸氧化酶，与叶绿体和线粒体合作 | [7.1.25](/7.1.25) |

锥虫甚至在与过氧化物酶体相关的糖体（glycosome）中进行糖酵解。过氧化物酶体的内容随细胞的需要而变：在甲醇或油酸上生长的酵母充满大的过氧化物酶体，含有代谢它们的酶。

### 6.7.2. 折叠蛋白质的输入

**定义 6.7.2（Pex 蛋白与 PTS）** **过氧化物酶体生物发生因子**（Pex 蛋白，由 *PEX* 基因编码）是过氧化物酶体的生物发生及其蛋白质的输入所需的 30 多种蛋白质。大多数过氧化物酶体基质蛋白带有**过氧化物酶体靶向信号 1**（PTS1），即 C 端三肽 Ser-Lys-Leu（SKL）或其保守变体，由胞质受体 Pex5 识别；少数带有**过氧化物酶体靶向信号 2**（PTS2），即由 Pex7 与一个共受体一起识别的 N 端九肽。

受体在胞质溶胶中结合货物，停靠在膜蛋白 Pex13 与 Pex14 上，并成为暂时的输入孔的一部分，货物通过它进入。与内质网和线粒体的转位子不同，这套机器输入折叠的、结合辅因子的甚至寡聚的蛋白质：包被了 PTS1 肽、直径 $9\,\mathrm{nm}$ 的金颗粒就能输入过氧化物酶体。能量不用于货物的转位，而用于受体的回收：Pex5 在一个保守的半胱氨酸上被 RING 泛素连接酶 Pex2–Pex10–Pex12 单泛素化，这些连接酶合起来还形成使其逆向转位的通道，并被 AAA ATP 酶 Pex1 与 Pex6（由 Pex15 锚定在膜上；哺乳动物中为 Pex26）拉回胞质溶胶。在这种"输出驱动的输入"模型中，受体从膜上被移走，使货物在内部释放。过氧化物酶体膜蛋白使用另一条途径，即胞质受体 Pex19 与膜停靠蛋白 Pex3。

### 6.7.3. 生物发生与疾病

过氧化物酶体以两种方式增殖。已有的过氧化物酶体通过输入蛋白质与脂质而生长并分裂：Pex11 使它们伸长，与线粒体共用的发动蛋白相关 GTP 酶 Drp1 及其衔接蛋白把它们切断（[7.3.12](/7.3.12)）。它们也可以从内质网重新形成：缺少 *PEX3* 的酵母突变体没有过氧化物酶体，重新导入该基因后，Pex3 先出现在内质网中，然后出现在成熟为过氧化物酶体的囊泡中。在野生型细胞中两条途径都起作用，各自的相对贡献因生物而异。

过氧化物酶体生物发生的缺陷引起 Zellweger 谱系障碍，其中最严重的是 Zellweger 综合征（Zellweger syndrome），一种新生儿致死性隐性疾病，由十几个 *PEX* 基因中任何一个的突变引起（最常见的是 *PEX1*）。患者的细胞含有空的过氧化物酶体膜（"血影"），而基质酶不能进入，留在胞质溶胶中被降解；血液中极长链脂肪酸积累（诊断试验），缩醛磷脂缺乏，脑、肝与肾严重异常，通常在一岁内死亡。其他疾病只影响一种过氧化物酶体蛋白：X 连锁肾上腺脑白质营养不良由 **ABC 转运体** ABCD1（把极长链酰基辅酶 A 输入过氧化物酶体）的突变引起，破坏脑中的髓鞘和肾上腺皮质的功能。

## 6.8. 规则的例外：非经典分泌与非囊泡的脂质运输

### 6.8.1. 没有信号序列的分泌

长期以来的教条是，分泌蛋白必须带有信号序列并经过内质网与高尔基体。然而有许多蛋白质虽然没有信号序列也离开细胞。

**定义 6.8.1（非经典蛋白分泌）** **非经典蛋白分泌**是蛋白质通过经典途径，即从内质网经高尔基体到质膜之外的途径从细胞中释放：或者是没有信号序列的胞质蛋白（"无前导"蛋白）的分泌，或者是绕过高尔基体把跨膜蛋白递送到质膜。

区分为四种途径。

| 类型 | 途径 | 例子 |
|---|---|---|
| I：直接穿过质膜的转位 | 蛋白质结合内小叶中的 PI(4,5)P₂，寡聚化并形成脂质孔，蛋白质从中通过；硫酸乙酰肝素蛋白聚糖在外侧捕获它；或者它通过蛋白质孔离开 | FGF2（Walter Nickel）；通过活化巨噬细胞中 gasdermin D 孔的白介素-1β（gasdermin D 被邵峰小组鉴定为细胞焦亡的执行者，[7.3.25](/7.3.25)） |
| II：ABC 转运体 | 质膜的 **ABC 转运体**输出一种肽 | 酵母 a 因子（Ste6） |
| III：囊泡中间体 | 蛋白质进入胞内的膜运载体，通过融合到达表面 | IL-1β 与其他无前导货物通过 TMED10 通道进入内质网–高尔基体中间区室（THU 途径，张敏小组，2020）；分泌型自噬；酵母 Acb1 |
| IV：绕过高尔基体 | 跨膜蛋白不经过高尔基体而从内质网运到质膜 | 内质网应激下的 CFTR |

在 THU 途径（TMED10 引导的非经典蛋白分泌）中，货物被 HSP90A 展开，并通过由跨膜蛋白 TMED10 的寡聚体形成的通道转位进入内质网–高尔基体中间区室的腔中，TMED10 识别货物中的一个短基序；货物随后跟随囊泡到达细胞表面。因此该途径类似于向内质网的跨膜运输，只是通过不同的通道进入较后的区室。非经典分泌对炎症信号、半乳糖凝集素以及应激下释放的生长因子特别重要，其途径仍在绘制之中。

### 6.8.2. 脂质在膜接触位点处移动

大多数膜脂在内质网中合成，但它们在不同细胞器中的浓度差别很大：胆固醇约占内质网脂质的 $5\,\%$，却占质膜脂质的 $30$–$40\,\%$；PS 与 PI(4)P 在质膜与高尔基体中富集，心磷脂在线粒体中富集。囊泡运输无法解释这一点，因为囊泡带有其供体的组成，而且根本不到达线粒体；阻断囊泡运输对脂质递送到质膜的减慢远小于对蛋白质递送的减慢。大多数脂质是不借助囊泡而移动的，由脂质转移蛋白在两层膜靠得很近的位点处携带。

**定义 6.8.2（膜接触位点）** **膜接触位点**是两个细胞器的膜，或细胞器与质膜的膜，被拴系蛋白保持在彼此约 $10$–$30\,\mathrm{nm}$ 范围内而不融合、并交换脂质、离子或信号的区域；接触位点的特征是特异的拴系蛋白与驻留蛋白。

内质网与几乎每一种其他膜都有接触。

| 接触 | 拴系蛋白与转移蛋白 | 移动的物质 |
|---|---|---|
| 内质网–质膜 | 扩展突触结合蛋白（E-Syt，SMP 结构域）、ORP5 与 ORP8、STIM1–Orai1 | 甘油脂；内质网的 PS 与质膜的 PI(4)P 交换；内质网的 $\ce{Ca^2+}$ 再填充（储存操纵的进入，[7.3.7](/7.3.7)） |
| 内质网–高尔基体（反面高尔基体） | OSBP、CERT，内质网中带 VAP | 胆固醇与 PI(4)P 交换（OSBP）；用于合成鞘磷脂的**神经酰胺**（CERT） |
| 内质网–线粒体 | 酵母中的 ERMES（含 SMP 结构域蛋白 Mdm12、Mdm34、Mmm1），哺乳动物中的 PDZD8 等 | PS 到线粒体（转化为 PE）、$\ce{Ca^2+}$；线粒体分裂的位点（[7.3.12](/7.3.12)） |
| 内质网–脂滴、内质网–内体、内质网–自噬体 | seipin；VAP–ORP1L；ATG2 | 三酰甘油与固醇酯；胆固醇；供自噬体生长的大量磷脂 |

已经鉴定出两种转移方式。具有疏水腔的穿梭样蛋白（OSBP 相关蛋白、SMP 结构域、CERT 的 START 结构域）一次提取一个脂质分子，把它运过间隙并卸下。杆状的桥样蛋白（VPS13 与 ATG2）以连续的疏水沟跨越间隙，许多脂质沿沟滑动，这种整体流动支持自噬体等膜的快速生长。

只催化交换的转移蛋白如何能产生梯度？OSBP 交换胆固醇与 PI(4)P：它把胆固醇从内质网运到反面高尔基体，把 PI(4)P 运回。PI(4)P 在高尔基体中由 PI 4-激酶用 ATP 合成，并在内质网中被磷酸酶 Sac1 破坏，所以其梯度保持陡峭；PI(4)P 的下坡运输驱动胆固醇的上坡运输，这是一种对向运输，类似于跨膜的继发性主动运输（[7.3.5](/7.3.5#sec-5.1.2)），只不过"载体"是在两层膜之间移动。因此磷酸肌醇代谢为细胞器的脂质身份付出代价，而接触位点与囊泡和转位子一样，是细胞物流的一部分。

## 思考题

1. 一个胞质蛋白分别与（a）N 端内质网信号序列，（b）N 端线粒体前导序列，（c）C 端 SKL，（d）N 端内质网信号序列加 C 端 KDEL，（e）内质网信号序列后接线粒体前导序列融合。每种融合蛋白去向何处？

   **答** （a）进入内质网腔，在没有其他信号的情况下，经默认途径通过高尔基体被分泌。（b）进入线粒体基质，前导序列被切除，只要该蛋白质能被展开以供输入。（c）进入过氧化物酶体基质，即使是折叠的。（d）进入内质网，并通过 KDEL 受体从高尔基体回收而被保留在那里。（e）进入内质网：信号序列一露出就被 SRP 共翻译地识别，那时前导序列还没有完成，内质网的决定最先作出；一旦进入腔中，该蛋白质就不能到达线粒体输入机器。

2. 利用命题 6.2.1，预测一个细胞器的大小在（a）细胞对称分裂之后，（b）亚基表达量加倍的细胞中，（c）一个细胞中有两个这样的细胞器竞争同一个池时会怎样。胚胎中哪些实验检验（a）与（c）？

   **答** （a）每个子细胞得到一半体积，浓度不变时得到一半亚基，所以每个细胞器在一半的大小重新达到平衡（$S^*$ 正比于 $V$）：细胞器在每次卵裂时缩小，如早期胚胎中的中心体与纺锤体。（b）$\rho$ 加倍；若 $c^*$ 是 $\rho$ 的可观部分，则 $S^* = (2\rho - c^*)V$ 的增加多于一倍。（c）二者都消耗同一个游离浓度；稳态确定总量 $S_1 + S_2 = (\rho - c^*)V$，但不确定它如何分配，所以需要额外的机制（例如依赖大小的生长速率）使它们相等。去除秀丽隐杆线虫胚胎中两个中心体之一并观察剩下的一个长得更大，或改变卵提取物液滴的体积并测量纺锤体长度，检验有限池模型的预测。

3. 一个 II 型膜蛋白在其单个疏水片段之前的 20 个残基中有 8 个 Arg 与 Lys，在其后的 20 个残基中有 1 个。一个突变体把 N 端的碱性残基换成 Glu 与 Asp，并在该片段之后加上 6 个 Lys。预测二者的拓扑结构，并说明如何用糖基化报告检验该预测。

   **答** 野生型：按"内正"规则，N 端侧翼留在胞质溶胶中，给出 II 型取向（N 端在内，C 端在腔）。突变体颠倒了电荷差：带正电的 C 端侧翼留在胞质溶胶中，N 端被转位，给出 III 型（N 端在腔，C 端在胞质溶胶）。检验：在 N 端与 C 端各放一个 Asn-X-Thr 位点（各在一段短的报告延伸中），用凝胶迁移率的变化或对内切糖苷酶 H 的敏感性测定糖基化：只有位于腔中的一端被糖基化。微粒体的蛋白酶保护（只有胞质部分被消化）提供独立的检验。

4. 估计完美转位棘轮的速度，取 $\delta = 0.35\,\mathrm{nm}$（伸展链的一个残基），肽链在通道中的有效扩散系数 $D = 10^{-13}\,\mathrm{m^2\,s^{-1}}$。这相当于每秒多少个残基？实测的未折叠前体的输入速率为每秒几十到几百个残基。你得出什么结论？棘轮在多大的负载下减慢到自由速度的十分之一？

   **答** $v = 2D/\delta = 2\times10^{-13}/(3.5\times10^{-10})\,\mathrm{m\,s^{-1}} \approx 5.7\times10^{-4}\,\mathrm{m\,s^{-1}}$，即每秒约 $1.6\times10^6$ 个残基，前提是分子伴侣在每个残基之后立即结合。即使 $D$ 小一百倍，扩散也不会限制输入；观察到的速率由其他步骤决定：分子伴侣的结合速率（需要几个残基才能结合）、外侧结构域的展开，以及通道中的摩擦。当 $(\omega^2/2)/(\mathrm{e}^\omega - 1 - \omega) = 0.1$ 时速度降到 $0.1 \times 2D/\delta$，即 $\omega \approx 4.5$（6.5.3 的图），所以 $f \approx 4.5\,k_{\mathrm{B}}T/\delta = 4.5 \times 4.3\,\mathrm{pN\,nm}/0.35\,\mathrm{nm} \approx 55\,\mathrm{pN}$；需要更大展开力的折叠结构域会使纯棘轮停滞。

5. 用抗过氧化氢酶抗体与抗过氧化物酶体膜蛋白 PMP70 的抗体，对疑似 Zellweger 综合征患者的细胞染色。（a）你预期正常细胞与患者细胞中分别是什么图样？（b）如何用细胞融合找出哪个 *PEX* 基因有缺陷？（c）为什么患者缺乏缩醛磷脂，却有正常水平的大多数线粒体酶？

   **答** （a）在正常细胞中，两种抗体给出相同的过氧化物酶体点状图样。在患者细胞中，PMP70 仍标出点状的膜"血影"（膜蛋白的输入使用 Pex19 与 Pex3，常常是完好的），但过氧化氢酶弥散在胞质溶胶中，因为基质输入（Pex5、停靠、回收）失败了。（b）通过互补：把患者的细胞与已知互补群的细胞融合（或转染单个 *PEX* cDNA）；杂种或转染细胞中点状过氧化氢酶的恢复，确定发生突变的基因（同一基因突变的细胞不能互补）。（c）缩醛磷脂合成的最初几步由过氧化物酶体基质酶催化，它们定位错误并被降解；线粒体用完全不同的机器（TOM、TIM）输入其蛋白质，不受影响，尽管积累的脂质可能引起继发的缺陷。

6. （开放题）以 OSBP 循环为模型，说明一个只交换两种脂质的脂质转移蛋白如何能在内质网与高尔基体之间维持胆固醇梯度，能量由什么提供，如果抑制 Sac1，梯度会怎样。

   **答** OSBP 在同一口袋中结合胆固醇或 PI(4)P 并交换它们：它从内质网提取胆固醇，从高尔基体提取 PI(4)P，并把各自送到另一层膜。如果 PI(4)P 在高尔基体中保持高水平（由 PI 4-激酶用 ATP 合成），在内质网中接近零（被 Sac1 水解），PI(4)P 就顺其梯度从高尔基体流向内质网，每一轮把一个胆固醇从内质网带到高尔基体，即使逆着胆固醇的梯度：自由能来自 PI(4)P 合成中消耗的 ATP 以及其水解释放的能量。这是对向运输，像由离子梯度驱动的反向转运体。如果 Sac1 被抑制，PI(4)P 在内质网中积累，PI(4)P 梯度崩溃，交换逆转或在两个方向上相等，胆固醇不再浓缩在高尔基体与质膜中；在细胞中，Sac1 的缺失确实会扰乱固醇分布与高尔基体功能。
