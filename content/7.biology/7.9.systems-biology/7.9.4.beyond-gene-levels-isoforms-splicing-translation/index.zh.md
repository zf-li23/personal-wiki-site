基因水平的计数（[7.9.2](/7.9.2) 的主题）把一个转录本的一生压缩成了一个数。从转录到成熟的蛋白质之间，RNA 要以多种方式之一被剪接，在多个位点之一被切割并加上多聚腺苷酸尾，被化学修饰与编辑，被蛋白质结合，按其自身序列所决定的速率被翻译，最终被降解；每一步都受调控（[7.2.16](/7.2.16)–[7.2.20](/7.2.20)），每一步都可以用某种测序的变体在全基因组范围内测量。本章把这些测量作为一个家族来讨论。在每种情形中，实验都把一个分子事件转化为读段的某个特征（跨越连接处的剪接读段、核糖体足迹的长度与相位、T 到 C 的错配、交联处的截断），而分析则把这类特征的计数变成带不确定性的比值：包含某外显子的转录本的比例（4.1–4.3）、每个 mRNA 上的核糖体数（4.4）、最近几小时内合成的分子的比例（4.5）、某一位点被修饰、被结合或被编辑的比例（4.6–4.7）。所用的统计学是应用于计数之比的[生物统计学](/7.7)；分子机制属于分子生物学，我们只链接而不重复；其结果为后面各章的网络增添了层次，因为调控因子可以作用于剪接或翻译，而不改变任何转录本的水平。

## 4.1. 可变剪接的定量

### 4.1.1. 事件及测量它们的读段

约 $95\,\%$ 的人类多外显子基因通过**可变剪接**产生不止一种异构体（[7.2.16](/7.2.16#sec-16.7)）。短读段很少跨越整个转录本，所以通常的分析并不估计每个全长异构体的丰度（那是 [7.9.2](/7.9.2) 的做法，它依赖于注释，并且当异构体只相差几个外显子时不确定），而是把变异分解为局部事件，每个事件是穿过基因某一小段的两条路径之间的选择。五类事件涵盖了大多数情形（图的 A 栏）。

| 事件 | 选择 | 支持较长（包含）形式的读段 | 支持较短形式的读段 |
|---|---|---|---|
| 外显子跳跃（SE） | 盒式外显子被包含或被跳过 | 上游外显子–盒式外显子和盒式外显子–下游外显子的连接；盒式外显子内部的读段 | 连接两侧外显子的连接 |
| 互斥外显子（MXE） | 两个外显子中恰好使用一个 | 进出第一个外显子的连接 | 进出第二个外显子的连接 |
| 可变 5′ 剪接位点（A5SS） | 上游外显子中有两个供体位点 | 来自下游供体的连接；延伸部分内的读段 | 来自上游供体的连接 |
| 可变 3′ 剪接位点（A3SS） | 下游外显子中有两个受体位点 | 通向上游受体的连接；延伸部分内的读段 | 通向下游受体的连接 |
| 内含子保留（RI） | 内含子被保留或被去除 | 跨越外显子–内含子边界的读段和内含子内部的读段 | 外显子–外显子连接 |

可变的首外显子和末外显子来自可变启动子和多聚腺苷酸化位点，通常与转录起始位点和 3′ 端一起处理（4.7.1）。关键的读段是*剪接*读段：读段的两个部分比对到两个外显子上，中间的内含子由能识别剪接的比对软件在比对中报告为缺口（[7.8.10](/7.8.10)）。若连接处连接的是已知转录本的位点，则称为*已注释*的，否则称为*新*的；基于内含子簇的方法，如 LeafCutter（Li 等，2018），只使用剪接读段，不需要注释，并能表示有两个以上选择的复杂事件。

### 4.1.2. 剪接百分比

**定义 4.1.1（剪接百分比）** 对样本中的一个可变剪接事件，**剪接百分比** $\psi$ 是经过该事件的转录本中使用其包含形式的比例：
$$
\psi = \frac{n_{\mathrm{inc}}}{n_{\mathrm{inc}} + n_{\mathrm{exc}}},
$$
其中 $n_{\mathrm{inc}}$ 和 $n_{\mathrm{exc}}$ 是两种形式的分子数。它以 $[0, 1]$ 内的分数或百分数报告；两种条件之间的差为 $\Delta\psi$。

$\psi$ 是同一个基因内的比值，所以不依赖于该基因的表达水平、文库大小或样本之间的归一化。其估计取决于每种形式能产生多少读段。一条长为 $L$ 的读段要覆盖某个连接，必须与每个外显子至少重叠 $a$ 个核苷酸的锚定长度，所以一个连接有 $L - 2a + 1$ 个起始位置；外显子跳跃的包含形式有两个连接，跳跃形式有一个。

**公式 4.1.1（由连接读段得到的 PSI）** 设 $I$ 和 $S$ 是事件的包含连接和跳跃连接上的读段数，$l_I$、$l_S$ 是读段能够支持每种形式的位置数（*有效长度*；对按连接读段计数的外显子跳跃，$l_S = L - 2a + 1$，$l_I = 2l_S$）。则
$$
\hat\psi = \frac{I/l_I}{I/l_I + S/l_S}. \tag{4.1}
$$
如果也计入外显子内部的读段，则 $l_I$ 包括盒式外显子内部的位置。

**例 4.1.1** 在 B 栏的对照中，$I = 45 + 39 = 84$ 条包含读段，$S = 12$ 条跳跃读段，$L = 100$，$a = 8$，所以 $l_S = 85$，$l_I = 170$，$\hat\psi = (84/170)/(84/170 + 12/85) = 0.78$；朴素的比值 $I/(I + S) = 0.875$ 高估了 $\psi$，因为包含形式提供的位置多一倍。处理后，$I = 30$、$S = 40$ 给出 $\hat\psi = 0.27$。

$\hat\psi$ 有多精确？给定 $\psi$，每条连接读段是一次独立试验，其支持包含形式的概率为 $p = \psi l_I/(\psi l_I + (1 - \psi)l_S)$，所以给定 $I + S$ 时 $I$ 服从**二项分布**。对 $p$ 取均匀先验，$p$ 的后验是 **Beta 分布** $\mathrm{Beta}(I + 1, S + 1)$（[3.7](/3.7)），而映射 $p \mapsto \psi = pl_S/(pl_S + (1 - p)l_I)$ 是递增的，所以 $p$ 的分位数映射为 $\psi$ 的分位数。对 $I : S = 3 : 1$，$\psi$ 的 $95\,\%$ 后验区间在有 $8$ 条连接读段时为 $[0.25, 0.86]$，有 $80$ 条时为 $[0.48, 0.71]$，有 $800$ 条时为 $[0.56, 0.64]$（下图 A 栏）。典型文库中的大多数事件只有几十条连接读段，所以单个样本只能把 $\psi$ 确定到约 $\pm 0.1$，读段少于约 $10$–$20$ 条的事件通常在检验前被过滤掉。

### 4.1.3. 有重复时的差异剪接

把每种条件下各重复的读段合并，再用 Fisher 精确检验比较两个合并的比例，会忽略 $\psi$ 在生物学重复之间的变异，而这种变异往往大于二项抽样误差：这正是差异表达中计数过度离散的情形（[7.7.20](/7.7.20)），只是现在针对比例。转录本剪接的重复多变量分析（rMATS；Shen 等，2014）把这两种变异来源放进一个层次模型。

**算法 4.1.1（差异剪接的重复模型）** 对一个事件，设 $I_{kj}$ 与 $S_{kj}$ 是第 $k \in \{1, 2\}$ 组第 $j$ 个重复的连接计数。

1. 模型：$\operatorname{logit}\psi_{kj} \sim \mathcal{N}(\mu_k, \sigma^2)$ 相互独立，组均值为 $\mu_k$，两组共享方差 $\sigma^2$；$I_{kj} \mid \psi_{kj} \sim \mathrm{Bin}\bigl(I_{kj} + S_{kj},\ p(\psi_{kj})\bigr)$，其中 $p(\psi) = \psi l_I/(\psi l_I + (1 - \psi)l_S)$。
2. 似然：对每个重复的二项概率，在 $\operatorname{logit}\psi_{kj}$ 的正态分布上积分（用数值积分），再对各重复相乘。
3. 检验：分别在 $\mu_1$、$\mu_2$ 自由和 $\mu_1 = \mu_2$ 的条件下最大化似然；两个最大化对数似然之差的二倍是**似然比检验**的统计量，与 $\chi^2_1$ 比较。rMATS 检验复合零假设 $\lvert\psi_1 - \psi_2\rvert \le c$，$c$ 由用户选择（默认几乎为 $0$；$c = 0.05$ 则要求至少五个百分点的变化）。
4. 多重检验：把所有事件的 p 值转换为**错误发现率**（[7.7.20](/7.7.20)），报告 FDR 低于阈值且 $\lvert\Delta\psi\rvert$ 高于最小值的事件。

代价是每个事件做几次低维的优化，与事件数和重复数成线性关系。rMATS 把结果报告两次，一次只用连接计数（JC），一次用连接与外显子内部的计数（JCEC）；后者读段更多，但更依赖覆盖的均匀性。

**例 4.1.2** 下图 B 栏显示三个对照重复和三个处理重复，各有约 $96$ 条连接读段，其估计值在二项区间内一致；模型给出 $\Delta\psi = 0.47$，似然比为 $13.3$，$p = 3\times10^{-4}$。在 C 栏中，每种条件的各重复散布很宽（对照中 $\psi$ 从 $0.45$ 到 $0.95$）。重复之间估计的方差很大，似然比只有 $3.4$（$p = 0.07$），尽管均值的差异差不多一样大。对合并计数的 Fisher 检验对两个数据集都报告 $p \approx 10^{-21}$：它把读段当作独立的生物学重复，这种错误在单细胞分析中称为伪重复（[7.9.5](/7.9.5#sec-5.6)）。

# (b1.txt, b2.txt: comma-separated BAM files of the replicates; paired-end 150-nt reads)
rmats.py --b1 b1.txt --b2 b2.txt --gtf genes.gtf -t paired --readLength 150 \
         --cstat 0.05 --nthread 8 --od rmats_out --tmp rmats_tmp
# Events with FDR < 0.05 and |dPSI| > 0.1, skipped exons counted by junction reads only
awk -F'\t' 'NR == 1 || ($20 < 0.05 && ($23 > 0.1 || $23 < -0.1))' rmats_out/SE.MATS.JC.txt > SE.sig.txt

剪接的改变在疾病中很常见。在感染、炎症和癌症中，数百个事件一起变化，往往是由于少数剪接调控因子（SR 蛋白、hnRNP、RBFOX、MBNL、ESRP；[7.2.16](/7.2.16#sec-16.7.2)）的水平或活性改变；对 COVID-19 患者血液样本的整体分析（Wang 等，2022）就是一例。一组共调控、调控因子已知的事件，是调控网络中基因水平分析看不到的一个模块（[7.9.11](/7.9.11)）。

### 4.1.4. 作为药物靶点的剪接

剪接也是药物的靶点，而第一个例子显示了单个事件可以被多么精确地操纵。脊髓性肌萎缩症（SMA）是婴儿期最常见的遗传性致死原因，由编码运动神经元存活蛋白的 *SMN1* 纯合缺失引起。一个几乎相同的旁系同源基因 *SMN2*，在外显子 7 的一个位置上与之不同（C 到 T 的改变，c.840C>T），这使一个外显子剪接增强子减弱而一个沉默子增强，所以只有约 $10\,\%$ 的 *SMN2* 转录本包含外显子 7，其余的编码不稳定的蛋白质。因此 *SMN2* 的拷贝数（一到四个或更多）调节疾病的严重程度。Nusinersen 是一种 $18$ 个核苷酸的反义寡核苷酸，带有 $2'$-O-甲氧乙基糖和硫代磷酸骨架，可抵抗核酸酶且不招募 RNase H；它结合外显子 7 下游的内含子剪接沉默子（ISS-N1），置换结合在那里的 hnRNP A1/A2 蛋白，提高外显子 7 的包含率。它由 Adrian Krainer 及其同事与 Ionis Pharmaceuticals 合作研发，2016 年获批，通过鞘内注射给药；risdiplam（2020）是口服的小分子，通过稳定 U1 snRNP 与外显子 7 的 $5'$ 剪接位点的相互作用达到同样的效果。这些疗法改变的量，恰恰就是一个外显子跳跃的 $\psi$。剪接还控制细胞的身份：转录因子基因 *FOXP1* 的一个胚胎干细胞特异的外显子改变了其 DNA 结合特异性，是多能性所必需的（Gabut 等，2011）。

## 4.2. 单细胞中的剪接

单细胞 RNA 测序（[7.9.5](/7.9.5)）显示，细胞类型在剪接上也有差异，不仅是表达上的差异，但在单细胞中测量 $\psi$ 会遇到三重障碍。

1. 覆盖度。液滴法只对转录本的 $3'$ 端测序，看到的连接很少；需要全长的、基于平板的方案（Smart-seq2、Smart-seq3），其每个细胞的成本要高出几十到几百倍。
2. 稀疏性。单个细胞中一种典型 mRNA 只有几个拷贝，而其中只有一部分被捕获。对大多数细胞中的大多数事件，根本没有连接读段：细胞乘事件的 $\psi$ 矩阵中有 $80$–$90\,\%$ 的元素缺失。
3. 离散性。只捕获了一两个分子时，细胞的 $\psi$ 观测值是 $0$、$1$ 或 $1/2$；跨细胞的分布是两极化的，很难区分同时使用两种异构体的细胞与各自只用一种异构体的细胞的混合。

缺失值不能像未观察到的基因计数那样设为零，因为 $\psi = 0$ 是一个明确的生物学陈述（全部跳跃）。因此，方法要由相似的细胞填补它们，这类似于在邻居图上平滑基因表达的操作（[7.9.5](/7.9.5#sec-5.4)），或者直接对计数建模。然后可以按剪接谱对细胞聚类，这可能区分出表达上看似相同的细胞。一般的要点是，异构体之比不同于水平，对细胞间总 mRNA 含量和捕获效率的涨落不敏感，所以能揭示被表达水平模糊掉的状态。

## 4.3. 长读段：全长异构体与环状 RNA

长读段来自 PacBio 对全长 cDNA 的环形一致性测序（Iso-Seq），或来自对 cDNA 或天然 RNA 的**纳米孔测序**（[7.8.9](/7.8.9)），一条读段就能覆盖整个转录本，从而消除了由片段组装异构体时的歧义。分析时用能处理剪接的长读段比对软件（minimap2）把每条读段比对到基因组，把内含子链相同的读段合并为转录本模型，并对照注释对每个模型分类。SQANTI 的分类是标准的：完全剪接匹配（内含子链与已知转录本相同）、不完全剪接匹配（已知转录本的 $5'$ 截短版本，常是降解产物）、目录内新（已知剪接位点的新组合）和目录外新（至少有一个新位点）。定量用与短读段相同的 **EM 算法**（[7.9.2](/7.9.2)）把读段分配给模型，歧义少得多。主要的假象是截短的读段、模板转换，以及 oligo(dT) 在富含 A 的片段上的内部引发，它们会造成虚假的 $3'$ 端；社区基准 LRGASP（2024）发现，当读段准确而且深度足够时，长读段能可靠地鉴定许多新异构体，但对注释良好的基因，短读段的定量仍然更精确。

**环状 RNA** 由反向剪接产生，即下游的 $5'$ 剪接位点与上游的 $3'$ 剪接位点相连（[7.2.16](/7.2.16#sec-16.7.5)）。在短读段中，它唯一的特征是反向剪接连接：一条剪接读段，其两部分以颠倒的顺序比对（基因组上 $3'$ 部分在 $5'$ 部分的上游）。检测软件（CIRI2、CIRCexplorer、find_circ）寻找这样的嵌合比对，用能降解线性 RNA 的 RNase R 处理则可富集环状分子以供验证。环的内部结构不能单从连接处读出；用滚环逆转录得到环状 RNA 的长读段，使一条读段覆盖环数次，结果表明人和小鼠脑中的环状 RNA 常含有其线性对应物所没有的外显子、保留的内含子和微外显子（Rahimi 等，2021）。环是否被翻译是核糖体图谱（4.4.3）的问题：跨越反向剪接连接的足迹只能来自环上的核糖体，少数环状 RNA（如 circ-ZNF609）从内部核糖体进入位点被翻译成蛋白质。

## 4.4. 翻译组

### 4.4.1. 足迹与 P 位点

**核糖体图谱**对受核糖体保护而免遭核酸酶消化的 mRNA 片段测序（[7.2.6](/7.2.6#sec-6.6)；密码子水平的视角见 [7.2.20](/7.2.20#sec-20.8)）。

**定义 4.4.1（翻译组）** 细胞的**翻译组**是正在被翻译的 RNA 的集合，连同其上核糖体的位置与密度；核糖体图谱把它测量为核糖体保护片段（RPF，足迹）。

延伸中的真核核糖体的足迹长 $28$–$30$ nt（另一类较短的 $20$–$22$ nt 来自 A 位点空置的核糖体）。为了把每个核糖体定位到一个密码子，把每条读段归约为 P 位点的位置，对给定的读长，P 位点与 $5'$ 端的距离是固定的；这个距离由数据估计。

**算法 4.4.1（P 位点偏移）** 对每个读长 $\ell$：

1. 对所有已注释的编码序列，画出读段 $5'$ 端相对于起始密码子第一个核苷酸的位置直方图（元基因）。
2. 取偏移 $\delta_\ell$ 为紧邻起始密码子上游的峰到它的距离：刚起始的核糖体的 P 位点上是起始密码子，所以它们的 $5'$ 端在上游 $\delta_\ell$ 个核苷酸处（对 $28$ 和 $29$ nt 的读段通常 $\delta = 12$，对 $30$ nt 为 $13$）。
3. 把每个长度为 $\ell$ 的读段移动 $\delta_\ell$，计算其 P 位点在编码序列中的阅读框，保留 P 位点大多落在框 $0$ 的那些长度。

代价是对读段扫描一遍。结果，即沿每个转录本的 P 位点轨迹，是后面各步的输入。一个好的文库有三个特征，可由上述各步得出（见图）：读段在编码序列中富集而在 $3'$ UTR 中缺少，起始密码子处有一个峰、终止密码子处有一个较小的峰，计数以三个核苷酸为周期重复，$60$–$80\,\%$ 的 P 位点在框 $0$。周期性反映了核糖体每次前进一个密码子，这是区分真正的翻译与其他受保护片段（RNA 与其他蛋白质的复合物，或 rRNA 片段）的依据。

![核糖体图谱的读段与三核苷酸周期性（模拟读段）。A：29 nt 足迹的 5′ 端相对于已注释起始密码子 A 的位置，对各基因求和：上游 12 nt 的峰标记起始密码子在 P 位点的核糖体，下游的计数每三个核苷酸重复一次（深色：编码序列的阅读框）。B：把每种读长按其 P 位点偏移移动之后（算法 4.4.1），各阅读框中的 P 位点比例；相位不好的长度（这里是 30 nt）常被舍弃。C：对候选 ORF 的主动翻译检验，如算法 4.4.2：每个密码子在框 0、+1 和 +2 中的 P 位点计数，用单侧 Wilcoxon 符号秩检验比较并用 Stouffer 方法合并，上图为被翻译的 ORF（合并 p = 9e-21），下图为没有相位的覆盖（p = 0.5）](./plots/ribo_periodicity.py)

### 4.4.2. 翻译效率与差异翻译

编码序列上的足迹数，正比于 mRNA 分子数乘以每个 mRNA 上的核糖体数。除以同一样本 RNA-seq 的 mRNA 丰度，就得到每个分子的度量。

**定义 4.4.2（翻译效率）** 基因在样本中的**翻译效率**（TE）是其编码序列上的核糖体足迹密度与其 mRNA 密度之比，各自按文库大小归一化：
$$
\mathrm{TE} = \frac{\text{每千碱基 CDS 每百万足迹的 RPF 数}}{\text{每千碱基每百万读段的 RNA-seq 读段数}}.
$$
由于 CDS 的长度相互抵消，$\log\mathrm{TE} = \log(\text{归一化的 RPF 计数}) - \log(\text{归一化的 mRNA 计数})$。

当延伸是均匀的、起始限制速率时，TE 正比于起始速率（[公式 20.8.1](/7.2.20#fml-20.8.1)）；一般而言，它度量的是核糖体密度，延伸变慢时核糖体密度也会升高（4.4.5）。两个含噪计数之比是有噪的，最好不要直接检验比值，而是对两种检测一起建模。

**公式 4.4.1（作为交互作用的差异翻译）** 对基因 $g$、检测 $a \in \{0, 1\}$（RNA-seq、核糖体图谱）和条件 $c \in \{0, 1\}$，把计数建模为均值为下式的负二项分布：
$$
\log\mu_{gac} = \log s_{ac} + \beta_{g0} + \beta_{g1}a + \beta_{g2}c + \beta_{g3}\,ac, \tag{4.2}
$$
其中大小因子 $s_{ac}$ 对每种检测分别估计。于是 $\beta_{g2}$ 是 mRNA 水平的变化，$\beta_{g2} + \beta_{g3}$ 是足迹的变化，而交互系数 $\beta_{g3}$ 是 $\log\mathrm{TE}$ 的变化。在公式接口中，设计为 `~ assay + condition + assay:condition`，差异翻译是对交互项的检验（Wald 或似然比，[7.7.20](/7.7.20)）。

这是 deltaTE（Chothani 等，2019）的方法，用 DESeq2 的**广义线性模型**实现；Xtail、RiboDiff、riborex 和 anota2seq 是其变体。比较对 $\beta_{g2}$ 和 $\beta_{g3}$ 的检验，可把基因分成四类（下图 A 栏）：*转送*基因，mRNA 和足迹一起变化（转录调控，TE 不变）；*独占*基因，TE 变化而 mRNA 不变（纯粹的翻译调控）；*缓冲*基因，TE 的变化方向与 mRNA 的变化相反，使蛋白质合成保持不变；*增强*基因，两者向同一方向变化。缓冲在染色体拷贝数不同的细胞系比较中很常见，翻译补偿了部分剂量变化。

**例 4.4.1** 某基因在对照中有 $1000$ 条 mRNA 读段、$500$ 条足迹，处理后有 $2000$ 条 mRNA 读段、$4000$ 条足迹，文库大小相同。mRNA 上升 $2$ 倍，足迹上升 $8$ 倍，所以 $\mathrm{TE}$ 上升 $4$ 倍：在 $\log_2$ 尺度上 $\beta_3 = \log_2 4 = 2$，是增强基因。若处理后的足迹是 $2000$，足迹与 mRNA 都加倍，该基因就是转送基因；若是 $500$，TE 减半，该基因就是缓冲基因。

在 A 栏的模拟中，有 $3000$ 个基因，每种检测和条件有三个重复，交互作用在 BH 调整后 $p < 0.05$ 处检验，$97.5\,\%$ 的基因被指派到其真实的类别。有两点实际问题很重要。两个文库应当来自同一份裂解液，因为 TE 逐基因地比较它们；在裂解前阻止延伸的药物（环己酰亚胺）会扭曲起始密码子附近足迹的位置，所以现在更倾向于不加药物的速冻。

### 4.4.3. 哪些 RNA 被翻译

核糖体图谱还显示翻译发生在何处，包括被注释为非编码的 RNA、$5'$ 前导序列（**上游开放阅读框**，[7.2.20](/7.2.20#sec-20.5.2)）、$3'$ UTR 以及环状 RNA 上。仅有覆盖并不是证据，因为其他复合物也保护 RNA；检验的依据是候选**开放阅读框**内 P 位点的相位。

**算法 4.4.2（由相位检测被翻译的 ORF）**（仿 RiboCode；Xiao 等，2018）

1. 候选：在每个转录本中，列出从起始密码子（AUG，也可选近同源密码子如 CUG 或 GUG）到第一个同框终止密码子、且长于最小长度的 ORF。
2. 计数：对 ORF 的每个密码子 $i$，设 $x_i$、$y_i$、$z_i$ 为其第一、第二、第三个核苷酸上的 P 位点数（框 $0$、$+1$、$+2$）。
3. 检验：用单侧 **Wilcoxon 符号秩检验**对各密码子检验 $x_i > y_i$ 和 $x_i > z_i$，该检验只用配对差的符号与秩，因此能容忍沿 ORF 极不均匀的覆盖。
4. 合并：用 Stouffer 方法合并两个 p 值，$Z = (\Phi^{-1}(1 - p_1) + \Phi^{-1}(1 - p_2))/\sqrt2$，$p = 1 - \Phi(Z)$，其中 $\Phi$ 是标准正态分布函数；在同一框中重叠的候选之间，选择支持最好的起始密码子，并在所有候选上控制错误发现率。

工作量与所有候选的密码子数成线性关系。

**例 4.4.2** 对 $p_1 = 10^{-4}$、$p_2 = 0.02$ 的 ORF，$Z = (3.719 + 2.054)/\sqrt2 = 4.08$，合并的 $p = 2.2\times10^{-5}$：比单独任一检验都强，因为两者指向同一方向。在图的 C 栏中，被翻译的 ORF 的 $60$ 个密码子给出 $p = 9\times10^{-21}$，而同样深度但没有相位的覆盖给出 $p = 0.5$。

:::

把这类方法用于许多组织和肿瘤，发现了数千个被翻译的 uORF 和小 ORF，其中一些编码有已证实功能的肽（例如在肌肉中，myoregulin 和其他调控钙泵 SERCA 的微肽）。大多数被翻译的 uORF 通过调控下游主 ORF 的翻译，而不是通过其肽发挥作用（[7.2.20](/7.2.20#sec-20.5.2)），肿瘤在 uORF 的使用上常与正常组织不同，反映了控制重新起始的应激信号。翻译组还依赖于环境：被翻译的 ORF 的集合随应激、分化和细胞周期而改变，所以来自一种条件的注释是不完整的。

### 4.4.4. mRNA 与蛋白质水平

RNA-seq 既然便宜，为什么还要测量翻译？因为 mRNA 的水平只能解释其蛋白质水平的一部分。在对小鼠成纤维细胞的全基因组研究中（Schwanhäusser 等，2011），mRNA 水平解释了各基因蛋白质水平方差的约 $40\,\%$，而翻译速率常数是最强的单一预测因子。后来校正了测量误差的分析把 mRNA 所能解释的份额提高到一半以上（Li、Bickel 和 Biggin，2014），而且在同一基因的不同条件之间，相关性通常高于不同基因之间。稳态 $p^* = k_{\mathrm{tl}}m^*/k_{\mathrm{deg},p}$ 说明了原因（[7.2.22](/7.2.22)）：蛋白质水平是 mRNA 水平、翻译速率和蛋白质寿命的乘积，后两者在基因之间的变化与第一项差不多一样大。翻译也是基因表达中耗能最多的环节，每个肽键约需四个 ATP 当量。直接测量**蛋白质组**是 [7.9.9](/7.9.9) 的主题；核糖体图谱测量的是乘积中的一个因子。

### 4.4.5. 一项数据驱动的发现：Rocaglamide A

TE 的方法基于两个假设：起始限制翻译的速率，所以核糖体密度度量起始速率；以及核糖体沿转录本的分布模式（其延伸图谱）在所比较的条件中相同，所以只有总量改变。检验第二个假设，需要一个度量核糖体处于编码序列何处的指标。

**公式 4.4.2（极性得分）** 对含 $L$ 个密码子、核糖体密度为 $d_1, \dots, d_L$ 的编码序列，设 $p_i = d_i/\sum_jd_j$，$w_i = (2i - L - 1)/(L - 1)$，它从第一个密码子的 $-1$ 变到最后一个密码子的 $+1$。分布图的极性为
$$
\rho = \sum_{i=1}^{L}p_iw_i \in [-1, 1]. \tag{4.3}
$$
均匀的分布 $\rho = 0$；核糖体堆积在起始附近时 $\rho < 0$，在终止附近时 $\rho > 0$；条件之间的变化 $\Delta\rho$ 检测延伸图谱的改变，与总量无关。

**例 4.4.3** 在含 $300$ 个密码子的编码序列中，前 $30$ 个密码子上的密度高出五倍，给出 $\rho = -0.26$；均匀密度给出 $0$。

:::

对 $49$ 项已发表的核糖体图谱研究的重新分析（Li 等，2023）对每个基因和每种处理计算 $\Delta\rho$，发现某些扰动使核糖体沿编码序列移动，这与第二个假设相反。最明显的是 rocaglamide A（RocA），它是 *Aglaia* 属植物的天然产物，也是一种候选抗癌药，已知它通过把 RNA 解旋酶 eIF4A（帽结合复合物的一个**起始因子**，[7.2.20](/7.2.20#sec-20.4)）夹在 $5'$ 前导序列的多嘌呤序列上来抑制翻译起始，从而阻断扫描的小亚基（Iwasaki、Floor 和 Ingolia，2016）。该研究用 RocA 的剂量系列重新分析这些数据，把显著变化的基因分成两组：$643$ 个基因的编码序列上足迹减少而核糖体在 $5'$ 前导序列中积累，正如起始被阻断所预期的（起始响应基因）；$374$ 个基因的足迹增多，集中在大约前一百个密码子上（延伸响应基因）。第二组之前被漏掉了，因为假设图谱不变的 TE 分析把更多的足迹读作更多的翻译。所提出的解释是：RocA 结合的 eIF4A 在编码序列内的多嘌呤基序上也阻断延伸中的核糖体，其碰撞激活核糖体毒性应激激酶 ZAKα 以及 p38 和 JNK 通路。图中模拟了这两种模式：起始阻断使密度均匀降低而 $\rho$ 不变，延伸阻断使核糖体堆积在起始附近而使 $\rho$ 为负。

![用核糖体图谱测得的翻译变化。A：3000 个模拟基因的 mRNA 与足迹的 log2 倍数变化（每种条件和检测三个重复），用公式 4.4.1 的交互作用模型分析（这里作为对数计数上的线性模型），分类为转送、独占、缓冲或增强，无显著变化的基因为灰色（BH 调整后 p < 0.05）。B、C：沿含 50 个密码子前导序列的 300 密码子编码序列的核糖体密度模型图谱：B，前导序列中的扫描阻断使编码序列上的密度均匀降低而在上游积累核糖体（起始响应模式，极性不变）；C，早期延伸的阻断使核糖体堆积在前 100 个密码子上（延伸响应模式，极性 −0.29）](./plots/te_polarity.py)

这个案例体现了数据驱动发现（[7.9.1](/7.9.1#sec-1.2)）的最佳状态：没有新的实验，只是用旨在检验某个假设的统计量对公共数据做系统的重新分析，在一种条件下得到出人意料的结果，由此得到可以直接检验的机制。它也说明了为什么定量方法的假设应当在每个数据集中加以检查。

## 4.5. 新生转录与 RNA 周转

mRNA 的水平是合成与降解之比（$m^* = k_{\mathrm{syn}}/k_{\mathrm{deg}}$，[公式 18.1.1](/7.2.18#fml-18.1.1)），水平的变化可能来自其中任何一个。有两类方法把它们分开。第一类对仍附着在 RNA 聚合酶 II 上的新生 RNA 测序：NET-seq（Churchman 和 Weissman，2011）免疫沉淀聚合酶复合物，并对其内部 RNA 的 $3'$ 端测序，以单核苷酸分辨率给出每个正在工作的聚合酶的位置；PRO-seq（Kwak 等，2013）让分离的细胞核中正在工作的聚合酶掺入一个生物素化的核苷酸，再对延伸产物测序（全基因组版本的连续转录（run-on）实验，[7.2.6](/7.2.6#sec-6.3.2)）。两者都显示启动子近端的暂停、来自启动子和增强子的双向转录以及延伸速度；它们直接测量转录，在加工与降解之前。

第二类对新生 RNA 做代谢标记。细胞摄取 $4$-硫尿苷（4sU）一段时间 $t$；在 SLAM-seq（Herzog 等，2017）中，对巯基的烷基化使逆转录酶把 4sU 读作 C，所以新 RNA 的读段带有 T 到 C 的错配，无需任何生化分离（[7.2.18](/7.2.18#sec-18.1.2)）。困难在于定量：新 RNA 的尿苷只有百分之几被替换，所以许多新分子的读段不含转换，而测序错误又会在旧分子的读段中引入少量转换。混合模型把二者分开。

**公式 4.5.1（标记读段的二项混合）** 设某基因的读段 $r$ 含有 $n_r$ 个尿苷位置和 $k_r$ 个 T 到 C 转换。令 $\theta$ 为该基因在标记期间合成的分子的比例，$p_{\mathrm{c}}$ 为新 RNA 中每个尿苷的转换概率，$p_{\mathrm{e}}$ 为背景率，则
$$
\mathbb{P}(k_r \mid n_r) = \theta\binom{n_r}{k_r}p_{\mathrm{c}}^{k_r}(1 - p_{\mathrm{c}})^{n_r - k_r} + (1 - \theta)\binom{n_r}{k_r}p_{\mathrm{e}}^{k_r}(1 - p_{\mathrm{e}})^{n_r - k_r}. \tag{4.4}
$$
$p_{\mathrm{e}}$ 由未标记的样本估计，$p_{\mathrm{c}}$ 由所有基因合起来估计；$\theta$ 对每个基因用 **EM 算法**估计，交替地计算每条读段为新读段的后验概率，以及这些概率的均值。对于以速率 $\mu$ 生长的细胞中处于稳态的基因，$\theta = 1 - \mathrm{e}^{-(k_{\mathrm{deg}} + \mu)t}$，所以
$$
k_{\mathrm{deg}} = -\frac{\ln(1 - \theta)}{t} - \mu, \qquad t_{1/2} = \frac{\ln 2}{k_{\mathrm{deg}}}. \tag{4.5}
$$

**例 4.5.1** 取含 $n = 30$ 个尿苷的读段，$p_{\mathrm{c}} = 0.04$，$p_{\mathrm{e}} = 0.001$。新 RNA 的读段没有转换的概率为 $0.96^{30} = 0.29$，旧 RNA 的读段至少有一个转换的概率为 $1 - 0.999^{30} = 0.03$。若 $\theta = 0.3$，则带转换的读段比例为 $0.3 \times 0.71 + 0.7 \times 0.03 = 0.23$。在每 $24\,\mathrm{h}$ 倍增的细胞中标记 $t = 2\,\mathrm{h}$ 后，真实的 $\theta = 0.3$ 给出 $k_{\mathrm{deg}} = 0.149\,\mathrm{h^{-1}}$，$t_{1/2} = 4.6\,\mathrm{h}$；若把带转换读段的份额 $0.23$ 当作 $\theta$，则得到 $t_{1/2} = 6.7\,\mathrm{h}$，高估了 $45\,\%$。在图的模拟中，朴素估计对每个基因都约是真实 $\theta$ 的 $0.65$ 倍，而混合模型每个基因用 $300$ 条读段就能恢复 $\theta$，均方根误差为 $0.04$。

标记的时间进程（以及标记的追踪）给出每个转录本的合成、加工与降解速率；与扰动相结合，则显示调控因子作用于转录还是稳定性。同样的混合思想适用于单细胞（scSLAM-seq、NASC-seq），其中一个细胞的新旧 RNA 直接估计其状态的近期变化，这是 RNA 速度的实验对应（[7.9.7](/7.9.7)）。

## 4.6. 表观转录组与 RNA–蛋白质相互作用

### 4.6.1. RNA 修饰

已知 RNA 核苷有 $150$ 多种化学修饰，大多数在 tRNA 和 rRNA 中。在 mRNA 中，最丰富的内部修饰是 $N^6$-甲基腺苷（m6A），约占腺苷的 $0.1$–$0.4\,\%$，多在共有序列 DRACH 内（$\mathrm{D} = $ A、G 或 U；$\mathrm{R} = $ A 或 G；$\mathrm{H} = $ A、C 或 U），并在终止密码子附近和 $3'$ UTR 中富集。它由 METTL3–METTL14 甲基转移酶复合物共转录地写入，可被去甲基化酶 FTO 和 ALKBH5 去除，并被 YTH 结构域蛋白读取（细胞质中的 YTHDF1–3，细胞核中的 YTHDC1），这些蛋白促进降解、翻译或剪接。mRNA 的其他修饰有假尿苷、$N^1$-甲基腺苷、$5$-甲基胞苷和肌苷。

**定义 4.6.1（表观转录组）** **表观转录组**是细胞中 RNA 化学修饰的集合，连同其位置以及每个位置上被修饰分子的比例（化学计量）。

作图方法在分辨率与偏倚之间折中：

| 方法 | 原理 | 分辨率 | 化学计量 |
|---|---|---|---|
| MeRIP-seq / m6A-seq（2012） | 用抗 m6A 抗体对片段化 RNA 做免疫沉淀；峰与输入对照比较 | $100$–$200$ nt | 否 |
| miCLIP | 抗体经紫外交联到 RNA；交联处的突变与截断 | 单核苷酸 | 否 |
| GLORI（2023） | 化学脱氨使未甲基化的 A 变成 I，读作 G；m6A 抵抗脱氨 | 单核苷酸 | 是 |
| 天然 RNA 纳米孔测序 | 修饰碱基改变离子电流与碱基识别器的错误 | 单核苷酸，每个分子 | 是 |

在天然 RNA 的纳米孔测序（[7.6.12](/7.6.12)）中，RNA 本身穿过纳米孔，所以修饰不会被逆转录抹去。每种修饰都会使含它的 $k$-mer 的电流发生偏移，用有无该修饰的合成 RNA 训练的分类器可以检测到它：EpiNano（2019）利用碱基识别的系统性错误并结合**支持向量机**，后来的工具直接对电流信号建模，目前的碱基识别器则报告每个碱基的修饰概率。因为每条读段是一个分子，该方法还能显示两个修饰是否出现在同一个分子上、在哪种异构体上。Dinopore（2022）把这一方法用于肌苷，逆转录把肌苷读作 G，因此它能区分被编辑的腺苷（A 到 I，4.7.2）与基因组上的 A/G 变异，而短读段做不到这一点。

### 4.6.2. 交联与免疫沉淀

RNA 结合蛋白接触哪些 RNA，接触 RNA 上的哪些位置？从裂解液中把该蛋白免疫沉淀下来，收集到的是与它结合的 RNA，或与它的伙伴结合的 RNA，或在裂解后重新结合的 RNA。在活细胞中做共价交联可以排除后两种问题。

**定义 4.6.2（CLIP）** **交联免疫沉淀**（CLIP）是在全基因组范围内对 RNA 结合蛋白的结合位点作图的方法：在活细胞中把蛋白质–RNA 的接触共价交联（通常用紫外光），使 RNA 部分消化，通过免疫沉淀和变性凝胶电泳纯化蛋白质–RNA 复合物，再对 RNA 片段测序（Ule 等，2003）。

各变体的区别在于如何由序列读出确切的接触点。HITS-CLIP（2008）利用交联诱导的缺失；PAR-CLIP（Hafner 等，2010）把光活性核苷 4-硫尿苷掺入 RNA，在 $365\,\mathrm{nm}$ 交联，并把接触点读作 T 到 C 的转换，以此区分交联读段与背景读段；iCLIP（2010）和 eCLIP（2016）利用逆转录在交联的核苷酸处停止这一事实，所以读段的 $5'$ 端标记了它。ENCODE 计划用 eCLIP 在两个细胞系中对约 $150$ 个 RNA 结合蛋白作了图，并带有大小匹配的输入对照。分析时针对输入对照和 RNA 丰度对交联位点调用峰（稀疏计数问题，类似 [7.9.8](/7.9.8) 中的峰识别），并在其中寻找序列基序（[7.8.8](/7.8.8)）。把 CLIP 与同一蛋白被耗竭之后的剪接变化结合起来，得到一幅 RNA 图：对 NOVA 和 RBFOX 等调控因子，结合在盒式外显子上游往往抑制它，结合在下游则增强它。

### 4.6.3. RNA 结构探测

细胞中 RNA 的结构可用修饰柔性或未配对核苷酸的试剂来探测：SHAPE 试剂酰化柔性核苷酸的 $2'$-羟基，硫酸二甲酯（DMS）使未配对的 A 和 C 甲基化。在突变谱分析（SHAPE-MaP，2014；DMS-MaPseq，2017）中，让逆转录酶在能够读过被修饰核苷酸并掺入错配的条件下工作，于是每个位置的突变率与未处理对照相比，就度量了它的反应性。反应性以伪能量约束的形式进入 [7.8.16](/7.8.16) 的动态规划中的结构预测，而比较细胞内与体外的反应性，则显示蛋白质或其他 RNA 在何处结合。长读段版本（PORE-cupine，2021，用纳米孔检测修饰）可以对每个异构体分别确定结构。

## 4.7. RNA 加工的其他层次

### 4.7.1. 可变多聚腺苷酸化

约 $70\,\%$ 的人类基因有不止一个多聚腺苷酸化位点，大多在 $3'$ UTR 内，所以一个基因产生 $3'$ UTR 长短不同的 mRNA，它们的 microRNA 和 RNA 结合蛋白位点不同（[7.2.17](/7.2.17#sec-17.2.4)、[7.2.18](/7.2.18)）。专门的 $3'$ 端测序（PAS-seq、3′READS、QuantSeq REV）直接对切割位点作图；对普通 RNA-seq，则由近端位点处覆盖的下降来推断远端位点的使用。

**公式 4.7.1（远端多聚腺苷酸化的使用比例）** 如果转录本的 $3'$ UTR 有一个近端和一个远端多聚腺苷酸化位点，读段覆盖在近端位点上游为 $W_{\mathrm{S}} + W_{\mathrm{L}}$，在两个位点之间为 $W_{\mathrm{L}}$，则远端多聚腺苷酸化位点的使用百分比为
$$
\mathrm{PDUI} = \frac{W_{\mathrm{L}}}{W_{\mathrm{L}} + W_{\mathrm{S}}}. \tag{4.6}
$$
DaPars（Xia 等，2014）不依赖注释来寻找近端位点，把它取为覆盖的变化点，使两水平阶梯函数的平方偏差最小。

**例 4.7.1** 近端位点上游的覆盖为 $100$，两个位点之间为 $30$，给出 $W_{\mathrm{L}} = 30$，$W_{\mathrm{S}} = 70$，$\mathrm{PDUI} = 0.3$：$30\,\%$ 的转录本有长的 $3'$ UTR。同一基因在肿瘤中的覆盖为 $100$ 和 $10$，则 $\mathrm{PDUI} = 0.1$，即缩短。

:::

较短的 $3'$ UTR 是增殖细胞（Sandberg 等，2008）和许多癌症（Mayr 和 Bartel，2009）的普遍特征，其中癌基因逃脱了 microRNA 的抑制。由于 PDUI 与 $\psi$ 一样是同一转录本内的比值，可用同样的重复模型分析。

### 4.7.2. RNA 编辑

**RNA 编辑**是由 ADAR 酶作用于双链 RNA，使腺苷脱氨成肌苷（[7.2.17](/7.2.17#sec-17.6.3)）；由于肌苷与 C 配对，在 RNA-seq 中表现为 A 到 G 的错配。检测是一种变异识别（[7.8.12](/7.8.12)），但误差来源不同：位点必须不存在于同一个体的 DNA 中（或至少不在基因组变异数据库中），不能靠近剪接连接处或读段末端（那里比对错误集中），在链特异文库中必须在转录链上表现为 A 到 G。在人类中，一百多万个已知位点大多在 Alu 重复序列中，它们在内含子和 UTR 中形成双链发夹；有几百个位点使蛋白质的编码发生改变，经典的例子是谷氨酸受体亚基 GluA2 的谷氨酰胺到精氨酸位点，在脑中几乎所有转录本都被编辑，使通道不再透过钙。编辑水平同样是比值（位点上的 $G/(A + G)$），因组织而异，在一些疾病中降低；REDIportal 等数据库收集这些位点。

### 4.7.3. 融合转录本

肿瘤中的染色体重排把两个基因的各一部分连接起来，产生融合转录本，其中一些驱动癌症：慢性髓系白血病中的 *BCR*–*ABL1*，约一半前列腺癌中的 *TMPRSS2*–*ERG*，一部分肺癌中的 *EML4*–*ALK*，它们都是特异药物或诊断的靶点（[7.9.13](/7.9.13)）。在 RNA-seq 中，融合表现为两部分分别在两个基因上的剪接读段，以及配对的两端分别比对到两个基因上的读段对。检测软件（STAR-Fusion、Arriba）收集这样的嵌合比对，要求在一致的断点处有多条独立读段的支持（最好在外显子边界），并过滤常见的假象：相邻基因的通读转录本、文库制备中形成的嵌合体，以及旁系同源基因之间的比对。RNA 中发现的融合反映的是可在 DNA 中得到确认的基因组重排；没有重排的转录本之间的反式剪接是存在的，但在哺乳动物中罕见。

- 本章的每个测量都是同一基因或同一位点内的计数之比。其精度由有信息的读段数决定，而不是总深度（例 4.1.1），在条件之间比较时必须像基因计数一样对生物学重复之间的变异建模（例 4.1.2）。
- 方法带有可能失效的假设：外显子内部计数需要覆盖均匀，翻译效率需要延伸均匀（4.4.5），标记需要转换完全（例 4.5.1）。对公共数据的系统性重新分析可以检验它们。
- mRNA 水平、翻译和蛋白质寿命对蛋白质水平的贡献相当（4.4.4）；剪接、翻译和 RNA 稳定性的调控因子可以在不改变转录本计数的情况下改变基因的输出，这些层次是调控网络的一部分。

## 思考题

1. 为什么朴素比值 $I/(I + S)$ 会高估按连接读段计数的外显子跳跃的剪接百分比？什么时候它会低估？

   **答** 包含形式有两个连接，跳跃形式有一个，所以分子数相等时，包含形式产生的连接读段约多一倍：$I/S \approx 2\psi/(1 - \psi)$，而 $I/(I + S) = 2\psi/(1 + \psi)$，在 $0 < \psi < 1$ 时大于 $\psi$（$\psi = 0.6$ 时为 $0.75$）。如果把长盒式外显子内部的读段也加到 $I$ 中，包含形式提供的位置更多，忽略它们会造成更大的高估。只有当跳跃形式提供的位置多于包含形式时，朴素比值才会低估 $\psi$，例如用短内含子内部的读段与一个连接来计数的内含子保留，或延伸部分比所损失的读段位置更短的可变 $3'$ 位点。

2. 某外显子在一个样本中 $I = 6$、$S = 2$ 条连接读段，在另一个样本中 $I = 600$、$S = 200$。两者都给出 $\hat\psi = 0.60$。给出 $95\,\%$ 后验区间，并解释为什么大多数剪接分析按读段数过滤事件。

   **答** 取有效长度 $l_I = 170$、$l_S = 85$ 和均匀先验，$p$ 的后验分别为 $\mathrm{Beta}(7, 3)$ 和 $\mathrm{Beta}(601, 201)$；把分位数映射到 $\psi$，得到 $[0.25, 0.86]$ 和 $[0.56, 0.64]$。只有 $8$ 条读段时，$\psi$ 从四分之一到十分之九几乎都是合理的，所以这样两个样本之间看起来 $\Delta\psi$ 为 $0.3$ 毫无意义；读段很少的事件只会增加没有功效的检验，加重多重检验的负担，所以在检验前被去除（独立过滤，[7.7.20](/7.7.20)）。

3. 在例 4.1.2 中，对数据集 C，合并的 Fisher 检验给出 $p \approx 10^{-21}$，而重复模型给出 $p = 0.07$。哪个是对的？这个差别说明了什么？

   **答** 对于"处理是否改变这类样本中的剪接"这个问题，合适的是重复模型。Fisher 检验把每条读段当作独立的重复，只问两组合并的读段能否来自同一个比例，而它们显然不能；但每组的各重复之间的差异与组间差异一样大，所以组间差异与个体样本间的变异无法区分。这个差别就像单细胞分析中以细胞为重复的检验与伪 bulk 检验之间的差别（7.9.5）：重复的单位必须是生物学样本。

4. 某基因在对照中有 $800$ 条 mRNA 读段和 $400$ 条足迹，用药后有 $400$ 条 mRNA 读段和 $380$ 条足迹，文库大小相同，每组三个重复。计算倍数变化和 TE 的变化，对该基因分类，并解释为什么交互作用模型比对 TE 比值的检验更可取。

   **答** mRNA 变为 $0.5$ 倍（$\log_2 = -1$），足迹变为 $0.95$ 倍（$\log_2 = -0.074$），所以 TE 上升 $1.9$ 倍（$\log_2$ 尺度上 $\beta_3 = 0.926$）。如果 mRNA 变化和交互作用都显著，则 TE 的变化与 mRNA 的变化相反：这是缓冲基因，尽管 mRNA 减半，蛋白质合成几乎不变。交互作用模型使用两种检测的计数，各有自己的负二项方差和大小因子，所以每个计数的不确定性被正确地纳入；每个样本中两个含噪计数之比的分布有偏且重尾，在低计数时尤其如此，对这样的比值做 t 检验，校准很差。

5. 为什么 P 位点的三核苷酸周期性能把翻译与其他受保护的 RNA 片段区分开？某个候选 ORF 位于 $5'$ 前导序列中，并与主 ORF 在不同的框中重叠。如何检测它的翻译？

   **答** 核糖体每次前进一个密码子，所以其 P 位点主要落在所翻译阅读框的密码子的第一个核苷酸上；其他核糖核蛋白复合物保护的片段与密码子的框无关。对相对于主 ORF 处于框 $+1$ 的重叠 uORF，重叠区域的 P 位点来自两者；uORF 位于主起始密码子上游的部分可以单独检验（把算法 4.4.2 限制在这些密码子上），而在重叠区域，可以把框 $+1$ 的过量与由主 ORF 相位分布预期的水平相比较，后者由不重叠的主 ORF 密码子估计。用 harringtonine 或 lactimidomycin 得到的起始特异性足迹，则为 uORF 处有起始密码子提供独立的证据。

6. 标记实验（$t = 1\,\mathrm{h}$，细胞每 $20\,\mathrm{h}$ 倍增）给出基因 A 的新生比例 $\theta = 0.1$，基因 B 的 $\theta = 0.6$。计算它们的半衰期。哪个估计较不精确，为什么？

   **答** $\mu = \ln 2/20 = 0.0347\,\mathrm{h^{-1}}$。对 A，$k_{\mathrm{deg}} = -\ln 0.9 - 0.0347 = 0.1054 - 0.0347 = 0.0707\,\mathrm{h^{-1}}$，$t_{1/2} = 9.8\,\mathrm{h}$。对 B，$k_{\mathrm{deg}} = -\ln 0.4 - 0.0347 = 0.916 - 0.0347 = 0.882\,\mathrm{h^{-1}}$，$t_{1/2} = 0.79\,\mathrm{h}$。A 的估计取决于一个很小的 $\theta$ 以及对稀释速率的扣除，后者约占 $-\ln(1 - \theta)$ 的三分之一；$\theta$ 有 $0.02$ 的误差，会使 $t_{1/2}$ 改变约 $30\,\%$。对 B，$\mathrm{d}k/\mathrm{d}\theta = 1/(1 - \theta) = 2.5$ 适中，$0.02$ 的误差使 $t_{1/2}$ 改变约 $6\,\%$。标记时间与半衰期相当时精度最好；时间进程则覆盖一定范围的稳定性。

7. 为什么用抗体对 m6A 作图（MeRIP-seq）得不到位点的化学计量，而 GLORI 和纳米孔测序可以？

   **答** 免疫沉淀相对于输入对照，富集的是含有至少一个修饰碱基的片段；富集程度取决于抗体的亲和力、片段中修饰位点的数目以及背景结合，所以峰的高度无法转换为某个腺苷上被修饰分子的比例，分辨率则是片段的大小。GLORI 把每个未甲基化的腺苷转换为读作 G 的碱基，所以在每个位点上仍显示 A 的读段比例就是甲基化的比例（在校正不完全转换之后）。在纳米孔测序中，每条读段是一个分子，把每个分子在某位点上分类为被修饰或未被修饰，直接给出比例，其误差由分类器的准确度决定。

8. （设计）设计一个实验和分析，判断一种降低一组基因蛋白质水平的药物是作用于转录、mRNA 稳定性还是翻译。

   **答** 用药物或溶媒处理细胞（各至少三个生物学重复），从同一批培养物收集：RNA-seq（mRNA 水平）；收获前短时间加入 4sU 脉冲做 SLAM-seq（新生比例，进而由公式 4.5.1 与式 (4.5) 得到合成与降解速率），或做时间进程；以及与 RNA-seq 同一份裂解液的核糖体图谱。转录作用表现为合成速率降低而半衰期不变、TE 不变（足迹转送）；稳定性作用表现为半衰期缩短而合成不变；翻译作用表现为交互作用模型（公式 4.4.1）中 TE 改变而 mRNA 不变（独占）。足迹分布的极性（公式 4.4.2）区分起始效应与延伸效应。用靶向蛋白质组学（[7.9.9](/7.9.9)）检查蛋白质的变化及其时间，并对少数基因用报告基因（$5'$ 前导序列与荧光素酶融合）和已知靶点的药物确认机制。

9. 在 $3'$ UTR 上，正常组织中近端多聚腺苷酸化位点上游的覆盖为 $200$，近端与远端位点之间为 $150$；肿瘤中分别为 $200$ 和 $40$。计算 PDUI 并加以解释。

   **答** 正常：$W_{\mathrm{L}} = 150$，$W_{\mathrm{S}} = 50$，$\mathrm{PDUI} = 0.75$。肿瘤：$W_{\mathrm{L}} = 40$，$W_{\mathrm{S}} = 160$，$\mathrm{PDUI} = 0.20$。肿瘤中大多数转录本终止于近端位点，所以 $3'$ UTR 缩短了。如果丢失的区域含有 microRNA 位点，肿瘤的 mRNA 就逃脱了抑制，可能更稳定、翻译更多，这是 UTR 缩短的癌症中癌基因被激活的常见机制。这一解释假设 UTR 上的覆盖是均匀的；文库的 $3'$ 偏倚会人为地降低 $W_{\mathrm{S}}$，所以只有同一方案的文库之间的比较才有效。
