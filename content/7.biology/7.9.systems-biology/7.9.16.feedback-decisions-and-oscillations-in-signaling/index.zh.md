感知转录网络的模体（[7.9.15](/7.9.15)）是为可逆地响应当前环境而构建的，它们避免反馈。细胞还需要做出比引起它们的信号持续更久的决定，一劳永逸地转换命运，并且计时；为完成这些任务，演化使用了反馈环，而发育、信号转导和神经元的网络中反馈环十分丰富。本章沿着含反馈的模体，从转录网络到蛋白质网络再到振荡器，对每一种问它计算什么，以及为什么用这种设计而不是另一种。

动力系统的工具这里不再重复：不动点、**零倾线**、线性稳定性、**鞍结分岔**、**Hopf 分岔**和 Poincaré–Bendixson 定理见 [2.4.11](/2.4.11)，它们在**遗传拨动开关**、*lac* 操纵子、**Goodwin 振子**、**抑制振荡子**和**弛豫振子**上的应用见 [7.6.33](/7.6.33)；作为细胞生物学的正反馈、双稳态、适应和 Ca²⁺ 振荡见 [7.3.18](/7.3.18#sec-18.4)；细胞周期振荡器见 [7.3.20](/7.3.20#sec-20.6) 和 [7.6.34](/7.6.34#sec-34.2.1)；这类网络的一般动力学建模与拟合见 [7.9.14](/7.9.14)。我们从发育转录网络开始（16.1），再讲信号网络（16.2）和神经元（16.3），然后处理振荡器的设计（16.4），最后讲编码在动力学中的信息（16.5）。这些回路中的噪声及其行为的稳健性是 [7.9.17](/7.9.17) 的主题。

## 16.1. 发育网络的模体

### 16.1.1. 感知网络与发育网络

发育转录网络支配着细胞变成另一种细胞类型的近乎不可逆的转变。海胆、果蝇、线虫和哺乳动物的网络含有感知网络的大部分模体，即前馈环（[7.9.15](/7.9.15#def-15.4.1)；主要是 C1 与 I1 型）、自调控和单输入模块，此外还有感知网络所没有的几种模体：多得多的正自调控环、双节点正反馈环、围绕它们构建的较大模体，以及长的转录级联（Milo 及其同事，2004；Levine 与 Davidson，2005）。它们在细胞分裂的时间尺度上工作，所以缓慢的响应不是缺陷；并且它们必须在诱导信号消失之后记住决定。

### 16.1.2. 正自调控：缓慢的响应与记忆

**命题 16.1.1（正自调控使响应变慢）** 设 $\dot X = f(X) - \alpha X$，$f$ 递增，并与清除速率相同、稳态 $X_{\mathrm{st}}$ 相同（$\beta = f(X_{\mathrm{st}})$）的简单调控 $\dot X = \beta - \alpha X$ 比较。从 $X_{\mathrm{st}}$ 的吸引域内的任何初始状态 $X(0) < X_{\mathrm{st}}$ 出发，自调控基因始终低于简单调控的基因，到达每个水平都更晚。

**证明** 对 $X < X_{\mathrm{st}}$，$f(X) < f(X_{\mathrm{st}}) = \beta$，所以自调控的速率在稳态以下的每个水平上都更小。从同一初值出发的两个解不能相交，因为在相交处自调控的解的导数更小；所以它落在后面。$\square$

这是 [7.9.15](/7.9.15#prop-15.3.1) 命题 15.3.1 的镜像：随 $X$ 增大的生成最初缓慢，随 $X$ 积累而加速。缓慢的响应还能平均掉快速涨落的输入（Hornung 与 Barkai，2008）。取 S 形的 $f$ 时，生成曲线可以与清除线相交三次，基因是双稳的：一个低稳态和一个高稳态，由不稳定的阈值隔开（[7.6.33](/7.6.33#sec-33.2.1)；[7.2.22](/7.2.22#sec-22.6) 的公式 22.6.1）。把 $X$ 推到阈值以上的瞬时输入使它锁定在开启状态：长期记忆。胚胎细胞变成肌肉时，因子 MyoD 激活自己的基因，并在所有后代中保持肌肉程序开启。

在一维情形下，$\dot X = F(X)$ 的相邻不动点的稳定性交替出现，因为 $F$ 在每个单根处变号；所以三个不动点意味着稳定–不稳定–稳定，五个不动点（更复杂的输入函数可能出现）意味着三个稳定状态。

### 16.1.3. 双节点正环

两个因子相互调控的环，若两条弧的符号相同，就是正环。

**定义 16.1.1（锁定环与拨动环）** *双正反馈环*（锁定环）是两个转录因子相互激活的双节点环；当它是双稳态时，其稳定状态是两个因子都开启或都关闭。*双负反馈环*是两个因子相互抑制的双节点环；其稳定状态是一个因子开启而另一个关闭，即 [7.6.33 的定义 33.3.1](/7.6.33#def-33.3.1) 的**遗传拨动开关**。

锁定环适合靶标属于同一组织的因子，拨动环适合靶标属于不同命运的因子（PU.1 与 GATA1，Cdx2 与 Oct4；[7.6.33](/7.6.33#sec-33.3.3)）。既然单节点正自调控已能锁定，为什么还要双节点环？原因之一是延迟：锁定环只有在两种蛋白质都积累之后才会转换，因而忽略短暂的输入。两种环都需要非线性。

**命题 16.1.2（没有协同性的双节点环是单稳的）** 设 $\dot X = f(Y) - \alpha_1X$，$\dot Y = g(X) - \alpha_2Y$，其中 $f$ 和 $g$ 同为递增或同为递减的 Michaelis–Menten（Hill 系数 $1$）函数，$f(y) = a + by/(K + y)$ 或 $a + b/(1 + y/K)$，$a, b, K > 0$，$g$ 类似。则系统在正象限中恰有一个不动点，且它是稳定的。

**证明** 不动点满足 $X = \phi(X) := f(g(X)/\alpha_2)/\alpha_1$。$f$、$g$ 各是限制在 $y \ge 0$ 上的 Möbius 变换 $y \mapsto (py + q)/(ry + s)$，它们的复合（带 $\alpha_1$、$\alpha_2$ 的缩放）也是；在两种情形下 $\phi$ 都是递增的（递增函数的递增函数，或递减函数的递减函数）、有界的，而在 $[0, \infty)$ 上递增有界的 Möbius 映射在其上严格凹（$\phi'' = -2r\phi'/(rX + s) < 0$）。$\phi(0) > 0$ 的严格凹函数在 $X > 0$ 上恰好从上方穿过对角线一次，所以在交点处 $\phi'(X^*) < 1$。Jacobi 矩阵为 $\begin{bmatrix}-\alpha_1 & f'\\ g' & -\alpha_2\end{bmatrix}$，迹 $< 0$，行列式 $\alpha_1\alpha_2 - f'g' = \alpha_1\alpha_2(1 - \phi'(X^*)) > 0$，因为 $\phi' = f'g'/(\alpha_1\alpha_2)$：该不动点是稳定的。$\square$

因此双稳态需要至少一条臂上有**协同性**，或者因子的正自调控，许多命运决定因子都有正自调控，它可以使没有协同结合的环成为双稳态（思考题 3）。

### 16.1.4. 噬菌体 λ 的决定

噬菌体 λ 感染*大肠杆菌*时，要么复制并裂解细胞，要么整合为**原噬菌体**并随宿主一起复制（**溶原性**）。分子开关在 [7.2.11](/7.2.11) 中描述：CI 抑制裂解启动子 $P_{\mathrm{R}}$ 并激活自己的启动子 $P_{\mathrm{RM}}$；Cro 抑制 $P_{\mathrm{RM}}$，在较高浓度时抑制自己的启动子。从网络角度看，这是 CI 带正自调控、Cro 带负自调控的拨动开关。要离开溶原状态，原噬菌体读取宿主的损伤信号：单链 DNA 激活 RecA，RecA 刺激 CI 的自我切割（以及 LexA 的切割，启动 **SOS 反应**）。一个最小模型可以把逻辑显示出来。

**例 16.1.1（λ 开关的最小模型）** 在无量纲单位下，设 $c$ 为 CI 浓度，$r$ 为 Cro 浓度，
$$
\frac{\mathrm{d}c}{\mathrm{d}t} = \frac{4(0.05 + c^2)}{1 + c^2 + 4r^2} - (1 + d)\,c, \qquad \frac{\mathrm{d}r}{\mathrm{d}t} = \frac{3}{1 + 4c^2 + (r/3)^2} - r, \tag{16.1}
$$
其中 $d$ 是 RecA 刺激的切割造成的 CI 的额外清除。没有损伤（$d = 0$）时，零倾线相交三次：一个溶原状态（$c = 3.74$，$r = 0.05$）、一个裂解状态（$c = 0.01$，$r = 2.05$）和它们之间的一个鞍点（$c = 0.89$，$r = 0.71$）。随着 $d$ 增大，溶原状态与鞍点相互接近，并在 $d_{\mathrm{c}} = 0.70$ 处的鞍结分岔中湮灭；越过它之后每条轨线都走向裂解状态。裂解状态对所有 $d$ 都存在，所以之后修复损伤并不能恢复溶原性：诱导是不可逆的。该模型没有用数据拟合，但其结构（由带协同性的正环产生双稳态，由使一个状态失稳的信号触发的鞍结分岔而退出）就是真实开关的结构，在没有 RecA 的细胞中，真实开关的自发转换速率低于每代 $10^{-7}$（[7.2.11](/7.2.11)）；感染后随机的最初决定在 [7.9.17](/7.9.17) 讨论。

### 16.1.5. 调节型反馈与施控型反馈：记忆

双节点环出现在发育网络特有的三节点模体之内（Milo 及其同事，2004）。

**定义 16.1.2（施控型反馈与调节型反馈）** 在*施控型反馈*模体中，相互调控的两个因子 $X$ 和 $Y$ 都调控一个靶标 $Z$。在**调节型反馈**模体中，$Y_1$ 与 $Y_2$ 之间的双节点反馈环受上游因子 $X$ 调控。

在常见的符号组合中，两个顶点之间的所有路径具有相同的总符号：两个因子都激活（或都抑制）$Z$ 的双正环，两个因子以相反符号作用于 $Z$ 的拨动环。调节型反馈是一种记忆元件。只在短暂时间内活跃的输入 $X$ 可以把双正环锁定在开启状态，或翻转拨动开关，新的状态在 $X$ 消失之后仍保持（图）：回路记录了 $X$ 过去是否活跃。这样的记忆在指定细胞命运的发育信号消失之后维持细胞命运。它们是网络的性质，而不是染色质的性质（[7.2.15](/7.2.15)），甚至不必涉及转录：在*果蝇*的性别决定中，只在 XX 胚胎中产生的早期 Sxl 蛋白把后来的 *Sxl* 转录本剪接成有功能的形式，所以 Sxl 通过剪接水平的正环维持自身的合成，这个双稳态开关把 X:A 比值的瞬时信号转变成永久状态（[7.4.6](/7.4.6)）。

![调节型反馈模体中的记忆（逻辑输入函数，所有速率为 1，阈值 0.5）。输入 X 在 0 < t < 3 时生成（阴影），然后衰减。A：带 OR 门的双正环（如果 X 或另一个 Y 高于阈值，就生成 Y）：瞬时输入使 Y1 与 Y2 都开启，并保持开启。B：拨动开关：Y1 与 Y2 相互抑制，X 激活 Y1 并抑制 Y2；从 Y2 状态出发，瞬时输入把开关翻转到 Y1 状态，并持续存在](./plots/regulated_feedback.py)

### 16.1.6. 级联与发育定时

转录级联 $X \to Y \to Z \to \cdots$ 在感知网络中很少见，因为每一步都增加约 $\ln 2/\alpha$ 的响应时间，对稳定蛋白质就是一个细胞世代。在发育中，细胞命运是在连续的分裂中被指定的，这正是合适的时间尺度，长级联很常见。抑制因子的级联比激活因子的级联给出的定时对生成速率的涨落更稳健（Rappaport、Winter 与 Barkai，2005）：生成停止的抑制因子每个世代被稀释一个固定的倍数，所以它降到阈值以下的时间只对数地依赖于其初始水平。在*果蝇*神经母细胞中，转录因子的时间级联（Hunchback、Krüppel、Pdm、Castor）指定连续分裂中产生的神经元，其定时已被一个抑制因子衰减计时器所解释（Averbukh 及其同事，2018）。

## 16.2. 信号网络

### 16.2.1. 超敏性与增益的相乘

蛋白质相互作用网络通过对已有蛋白质的结合、修饰和降解，在数秒到数分钟内工作。它们做决定的典型模体，是超敏模块与正反馈的结合。**超敏性**的来源（协同性、多位点修饰、**零级超敏**、级联、化学计量抑制剂）列于 [7.3.18](/7.3.18#sec-18.4.2)，**MAP 激酶级联**的稳态在 [7.1.15](/7.1.15#sec-15.1.4) 中计算。**响应系数**的语言使每个要素的作用变得精确。

**命题 16.2.1（响应系数沿级联相乘）** 设级联的稳态为 $y_1 = f_1(s)$，$y_k = f_k(y_{k-1})$，$k = 2, \dots, m$，并设 $R_k = \mathrm{d}\ln y_k/\mathrm{d}\ln y_{k-1}$ 为第 $k$ 层的局部响应系数（$y_0 = s$）。则整个级联的响应系数为
$$
\frac{\mathrm{d}\ln y_m}{\mathrm{d}\ln s} = \prod_{k=1}^{m}R_k. \tag{16.2}
$$

**证明** 对 $\ln y_m = \ln f_m(\exp\ln y_{m-1})$ 应用链式法则，并沿级联逐层向下。$\square$

Hill 函数 $x^n/(K^n + x^n)$ 的响应系数为 $n/(1 + (x/K)^n)$，低输入时等于 $n$，饱和时降为零；分布式双磷酸化在低输入时 $R = 2$。在图中的级联里，三层在低输入时分别为 $R = 1$、$2$ 和 $2$，级联的 $R = 4$；三层的表观 Hill 系数 $\ln 81/\ln(E_{90}/E_{10})$ 分别为 $1.0$、$1.7$ 和 $3.2$。超敏性本身给出陡峭但可逆的响应。加上正反馈，它给出双稳态，而条件又是关于增益的一个陈述。

**命题 16.2.2（环增益与失稳）** 设 $\dot x = F(x, s) - \gamma x$，$F$ 关于 $x$ 递增（正反馈），$x^* > 0$ 是一个不动点。则 $x^*$ 不稳定当且仅当环的对数增益超过一，
$$
\frac{\partial\ln F}{\partial\ln x}\bigg|_{x^*} > 1. \tag{16.3}
$$
所以只有当反馈在某处是超敏的，系统才可能是双稳的：若 $F(x, s) = s + G(x)$，$G$ 是系数 $n \le 1$ 的 Hill 函数，则它只有一个不动点。

**证明** 线性化为 $\delta\dot x = (\partial_xF - \gamma)\delta x$，不稳定当且仅当 $\partial_xF > \gamma$。在不动点处 $\gamma = F/x^*$，所以条件为 $x^*\partial_xF/F > 1$。对 $G(x) = bx^n/(K^n + x^n)$，$\partial\ln F/\partial\ln x = xG'/(s + G) \le xG'/G = n/(1 + (x/K)^n) < n \le 1$，所以没有不动点是不稳定的；在一维情形，两个稳定不动点之间没有不稳定不动点就不能共存。$\square$

**例 16.2.1（卵母细胞成熟）** 在*非洲爪蟾*（*Xenopus*）卵母细胞中，孕酮触发 MAPKKK Mos 的合成；Mos 激活级联 Mos → MEK → p42 MAPK，而活性 MAPK 促进 Mos 的合成与稳定。单个卵母细胞以全或无的方式响应，并在孕酮被移除之后保持成熟状态（[7.3.18 的例 18.4.1](/7.3.18#ex-18.4.1)；Ferrell 与 Machleder，1998；Xiong 与 Ferrell，2003）。在图中的模型里，$\dot M = s + f\,m_3(M) - M$，级联对输入 $M$ 处于稳态。$f = 0.3$ 时响应陡峭但单值；$f = 0.5$ 时在 $s = 0.085$ 与 $s = 0.141$ 之间是双稳的，并有滞后；$f = 1$ 时下折点位于 $s = -0.20 < 0$，所以一旦开启，卵母细胞即使没有刺激也保持开启，成为不可逆的开关。级联是必需的：只有一层（$R \le 1$）时，命题 16.2.2 对任何 $f$ 都禁止双稳态。

### 16.2.2. 两个正环使双稳态稳健

细胞周期的 Cdk1 开关有两个正环：活性的周期蛋白 B–Cdk1 激活其活化磷酸酶 Cdc25，并抑制其抑制性激酶 Wee1（Wee1 使 Cdk1 的 Tyr15 磷酸化，Cdc25 除去磷酸基团；[7.3.20 的定义 20.3.3](/7.3.20#def-20.3.3)）。为什么是两个？Ferrell（2008）用速率图给出了回答。只有一个环时，活性分数 $a$ 的激活速率 $k_{25}(a)(1 - a)$ 是一个驼峰（随反馈上升，随失活池耗尽而降到零），而失活速率 $w\,a$ 是一条直线，斜率为 Wee1 水平 $w$；只有在很窄的斜率范围内才出现三个交点。有两个环时，失活速率 $w\,k_{\mathrm{wee}}(a)\,a$ 也是驼峰形的，在高 $a$ 处下降，因为活性 Cdk1 抑制 Wee1，两条驼峰曲线在宽得多的 $w$ 范围内相交三次。

**例 16.2.2** 取激活速率 $(0.01 + H(a))(1 - a)$，$H(a) = a^3/(0.3^3 + a^3)$，失活速率 $w\,a$（一个环）或 $w\,(0.01 + 1 - H(a))\,a$（两个环），一个环时开关在 $0.277 < w < 1.19$ 内是双稳的，即 Wee1 活性有 $4.3$ 倍的范围；两个环时在 $0.275 < w < 4.99$ 内是双稳的，范围为 $18$ 倍（图）。因为 Wee1 与 Cdc25 的水平在不同细胞和条件之间变化，更宽的范围使开关及其上构建的弛豫振荡（16.4.4）的存在更稳健。卵提取物中测得的 Cdk1 开关的滞后（[7.3.20 的例 20.6.1](/7.3.20#ex-20.6.1)）是其实验基础；稳健性的具体倍数取决于所选的参数。

### 16.2.3. 混合模体

转录网络与蛋白质网络是耦合的：许多信号通路终止于转录因子，转录又产生信号通路的蛋白质。合并后的网络有两种弧，缓慢的转录弧和快速的蛋白质水平弧，其模体将两者混合（Yeger-Lotem 及其同事，2004）。

**定义 16.2.1（混合模体）** **混合模体**（mixed motif）是含有多种弧的网络中的一种网络模体，这里的弧是转录调控与蛋白质–蛋白质相互作用，模体中的弧并非都是同一类型。

最常见的混合模体是双节点负反馈环，其中转录因子 $X$ 激活蛋白质 $Y$ 的基因，而 $Y$ 在蛋白质水平上抑制 $X$，方式是促进其降解，或者结合并使它失活：p53 与其泛素连接酶 Mdm2，NF-κB 与其抑制因子 IκBα，以及抑制第一个酶同时抑制该途径基因的代谢途径终产物。纯转录的双节点负环很少见。控制工程提示了原因：由快速传感器控制的慢过程，如由恒温器控制的加热器，在其设定点附近是稳定的，而环中有两条慢臂则会产生过冲和振荡，下一节会使之精确（命题 16.4.1：两条臂的时间尺度相近时振荡的倾向最大）。出芽酵母交配通路中的混合前馈环，其中转录因子同时诱导一种激酶及其底物，起持续性检测器的作用，并且因为激酶在其寿命内持续存在，给出对近期信息素暴露的瞬时记忆：最近看到信号的细胞响应更快（Doncic 与 Skotheim，2013）。

前馈环的行为像反馈环的温和版本：一致 FFL 给出延迟和瞬时记忆，正如正反馈给出持久记忆；不一致 FFL 产生脉冲并加速响应，正如负反馈那样。但 FFL 不能振荡。

**命题 16.2.3（前馈网络是稳定的）** 设 $\dot x_i = f_i(x_1, \dots, x_{i-1}) - \alpha_ix_i$，$i = 1, \dots, m$，$\alpha_i > 0$：每个变量只受固定顺序中更早的变量调控（弧构成**有向无环图**的网络，如 FFL 与级联的任意组合），输入为常数。则系统有唯一的稳态，它是全局渐近稳定的；特别是没有周期轨道。

**证明** 稳态可递归求出，$x_1^* = f_1/\alpha_1$，$x_i^* = f_i(x_1^*, \dots, x_{i-1}^*)/\alpha_i$。Jacobi 矩阵是对角元为 $-\alpha_i$ 的下三角矩阵，所以所有特征值为负。在全局上，$x_1(t) \to x_1^*$ 以指数速度收敛；若 $x_1, \dots, x_{i-1}$ 收敛，则 $x_i$ 满足输入收敛的稳定线性方程，并收敛到 $x_i^*$。周期轨道会与收敛矛盾。$\square$

## 16.3. 神经元网络中的模体

只要有合适的随机化系综，在任何网络中都可以寻找网络模体（[7.9.15](/7.9.15#sec-15.2.2)）。*秀丽隐杆线虫*的神经元网络，约 $300$ 个神经元由约 $5000$ 个化学突触连接，由电子显微镜绘出（White、Southgate、Thomson 与 Brenner，1986），与转录网络一样，其最显著的三节点模体是前馈环，三节点反馈环是反模体（Milo 及其同事，2002）。这是令人惊讶的，因为神经元与转录因子的大小相差三个数量级，时间尺度相差四个数量级。一种解释是邻近的神经元倾向于相互连接，空间邻近产生三角形，这预测三节点环应像 FFL 一样富集，而事实并非如此（Itzkovitz 与 Alon，2005）。另一种解释是两种网络都用有噪声的成分处理有噪声的信号，演化对相似的任务趋同于相似的回路。

FFL 的组合方式不同。*秀丽隐杆线虫*的神经元形成的是多输入 FFL，而不是转录网络中的多输出 FFL。

**定义 16.3.1（多输入前馈环）** **多输入前馈环**是这样一种模体：若干输入顶点 $X_1, \dots, X_n$ 各自调控一个中间顶点 $Y$ 和一个输出 $Z$，且 $Y$ 调控 $Z$：一组共享 $Y$ 与 $Z$ 的 FFL。

在逃逸回路中，鼻触觉感觉神经元（FLP）和有害化学物质的感觉神经元（ASH）都兴奋中间神经元 AVD 和驱动后退运动的指令中间神经元 AVA，AVD 又兴奋 AVA。有一致 FFL 且其中间神经元对输入求和时，这样的回路是符合检测器：两个短暂的刺激，各自太弱不足以驱动输出，当它们在时间上接近到达时就能驱动输出，因为它们对 $Y$ 的效应在其积分时间内相加（思考题 6）。Melzack 与 Wall（1965）在疼痛的闸门控制理论中提出了相关的结构：粗纤维传入（触觉）兴奋脊髓投射神经元，也兴奋使其沉默的抑制性中间神经元，这是不一致 FFL；细纤维伤害性传入兴奋投射神经元并抑制中间神经元，这是 2 型一致 FFL。粗纤维的活动关闭闸门，这就是揉搓疼痛部位有帮助的原因；背角的回路比原来的模型复杂得多，但闸门的原理保留了下来。神经元和突触的动力学是[计算神经科学](/7.16)的主题。

## 16.4. 如何构建振荡器

### 16.4.1. 负反馈需要延迟

每个生物振荡器都含有负反馈环，但只有环还不够：负自调控是单变量系统，根本不能振荡（[7.6.33](/7.6.33#sec-33.2.3)）。有两个变量时，负环只能产生阻尼振荡。

**命题 16.4.1（双节点负环）** 设 $X$ 激活 $Y$，$Y$ 抑制 $X$，$\dot X = f(Y) - \alpha_1X$，$\dot Y = g(X) - \alpha_2Y$，$f$ 递减，$g$ 递增，并设在不动点处 $\beta_1 = -f'(Y^*) > 0$，$\beta_2 = g'(X^*) > 0$。则不动点是稳定的，特征值为
$$
\lambda_{1,2} = \frac{-(\alpha_1 + \alpha_2) \pm \sqrt{(\alpha_1 - \alpha_2)^2 - 4\beta_1\beta_2}}{2}, \tag{16.4}
$$
并且向它的趋近是阻尼振荡，当且仅当 $(\alpha_1 - \alpha_2)^2 < 4\beta_1\beta_2$。

**证明** Jacobi 矩阵 $\begin{bmatrix}-\alpha_1 & -\beta_1\\ \beta_2 & -\alpha_2\end{bmatrix}$ 的迹为 $-(\alpha_1 + \alpha_2) < 0$，行列式为 $\alpha_1\alpha_2 + \beta_1\beta_2 > 0$，所以两个特征值的实部都为负；它们恰好在判别式为负时是复数。$\square$

时间尺度相等有利于振荡（$\alpha_1 = \alpha_2$ 时每个负环都有过冲），时间尺度的强烈分离抑制它，这就是 16.2.3 中混合环是稳定的原因。持续振荡需要第三个要素，延迟或正反馈，或者噪声。

### 16.4.2. 噪声可以维持阻尼振荡

Lahav 及其同事（2004）对 γ 射线照射后的单个人类细胞中的 p53 与 Mdm2 成像，看到的不是阻尼振荡，而是 p53 的持续脉冲，Mdm2 与之反相脉冲，大约每 $5.5\,\mathrm{h}$ 一次。脉冲的幅度在脉冲之间、细胞之间差异很大，而它们的时间则较为规则（Geva-Zatorsky 及其同事，2006）。这样的统计是由噪声驱动的阻尼振荡器的特征：随机的冲击不断把系统推离其稳定螺旋，回路放大噪声中靠近其共振频率的部分。用来解释这些脉冲的 p53 模型包含延迟和更多的成分（[7.6.33](/7.6.33#sec-33.5.5)）；这里要说明的是机制：一个在纸面上只会"振铃"的回路，如何能在细胞中脉冲。

**例 16.4.1** 对 $\dot x = 10/(1 + y^8) - x$，$\dot y = x - y$（时间以清除时间为单位），不动点 $x^* = y^* = 1.27$ 的特征值为 $-1 \pm 2.64\mathrm{i}$：确定性的扰动在约一个周期之内衰减。在两个方程中加入强度为 $\sigma$ 的独立白噪声（化学 Langevin 描述，[7.6.32](/7.6.32#sec-32.6.1)），轨线便无限地脉冲。在 $3000$ 个时间单位的模拟中，峰高的变异系数为 $0.51$，峰间隔的变异系数为 $0.36$，功率谱的峰在频率 $0.38$ 附近，即周期 $2.6$，与噪声强度无关：$\sigma$ 加倍使谱乘以四而不改变其形状，这与线性化系统的谱一致（[7.6.32](/7.6.32#sec-32.6.2) 的线性噪声近似）。幅度的变化大于周期的变化，并且随噪声增大，是噪声诱导振荡的诊断特征。

### 16.4.3. 延迟振荡器

有三级或更多级时，如果抑制足够陡峭且各级的时间尺度相近，负环不需要噪声也能振荡：Goodwin 振子的正割条件和抑制振荡子的稳定性边界在 [7.6.33](/7.6.33#sec-33.5.1) 中导出。环越长，需要的协同性越弱，而显式的延迟（转录、剪接、输出和翻译所需的时间）的作用就像许多级；此时周期的量级是环路总延迟的两倍。分节时钟中，Hes 与 Her 因子以延迟抑制自己的基因，在 [7.5.23](/7.5.23#sec-23.3.2) 中作为延迟振荡器分析。延迟振荡器产生近似正弦的波，其幅度与周期都由增益与延迟的同一平衡决定。

### 16.4.4. 正反馈与负反馈的耦合

研究得最充分的生物振荡器，如细胞周期、心脏起搏细胞、神经元，除负环之外还有一个正环：这就是振荡器模体。

**定义 16.4.1（正负反馈耦合振荡器）** **正负反馈耦合振荡器**是这样的振荡器：其核心是激活因子 $X$ 与抑制因子 $Y$ 之间的负反馈环（$X$ 激活 $Y$，$Y$ 抑制 $X$），再加上 $X$ 上的一个正反馈环（$X$ 的正自调控，或者 $X$ 通过它增强自身活性的双节点正环）。

正反馈在两方面起作用。在局部，它使不动点失稳。对 $\dot X = f(X, Y) - \alpha_1X$，$\dot Y = g(X) - \alpha_2Y$，设 $P = \partial f/\partial X > 0$ 是正环的强度，Jacobi 矩阵 $\begin{bmatrix}P - \alpha_1 & -\beta_1\\ \beta_2 & -\alpha_2\end{bmatrix}$ 的迹为 $P - \alpha_1 - \alpha_2$，行列式为 $\alpha_2(\alpha_1 - P) + \beta_1\beta_2$。若行列式保持为正，则当 $P$ 超过 $\alpha_1 + \alpha_2$ 时不动点失去稳定性，若此时 $(\alpha_1 - P - \alpha_2)^2 < 4\beta_1\beta_2$，特征值为复数：这是 Hopf 分岔，之后有界轨线由 Poincaré–Bendixson 定理落在极限环上。即使负环的两条臂的时间尺度相差很大，这也成立，这与命题 16.4.1 的条件正好相反。在全局上，强的正反馈使 $X$ 成为双稳态，缓慢的抑制因子推动它绕滞后环运动：这是**弛豫振子**（[7.6.33 的定义 33.5.3](/7.6.33#def-33.5.3)），其幅度由开关的两个折点固定，周期由慢变量的速度决定。

Tsai 及其同事（2008）指出的结论是，这样的振荡器的频率可以在很宽的范围内调节而不改变其幅度，而只有负反馈的振荡器在频率被推离自然值太远时就失去振荡。

**例 16.4.2** 图中比较了 Hill 系数为 $12$ 的三级 Goodwin 环（通过其最后一级的速率 $g$ 调节）与 [7.6.33](/7.6.33#sec-33.5.4) 的激活因子–抑制因子弛豫振荡器（通过其抑制因子的速率 $e$ 调节）。Goodwin 环只在 $g$ 约在 $0.32$ 与 $3.3$ 之间时振荡，其周期从 $4.96$ 变到 $2.33$（因子 $2.1$），幅度在此范围内从零升起又落回零。弛豫振荡器在 $e$ 从 $0.02$ 变到 $3$ 时，周期从 $187$ 变到 $1.84$，相差 $101$ 倍，而激活因子的幅度保持在 $150$ 与 $166$ 之间。细胞周期时间从早期胚胎中的约 $20\,\mathrm{min}$ 到成体组织中的数天，心率随需求变化三倍；幅度固定的可调性正是这些振荡器所需要的。

### 16.4.5. Ca²⁺ 振荡

许多细胞类型中，细胞质 Ca²⁺ 在产生 IP₃ 的激素刺激下振荡（[7.1.14](/7.1.14)、[7.3.18](/7.3.18#sec-18.4.6)）。振荡器是耦合型的：通过 IP₃ 受体释放的 Ca²⁺ 进一步激活受体（Ca²⁺ 诱导的 Ca²⁺ 释放，快速的正反馈），在较高浓度时又缓慢地使它失活（负反馈）。带 Ca²⁺ 诱导释放的双库模型在 [7.3.18](/7.3.18#fml-18.4.3) 中讨论；这里对受体本身建模，沿用 De Young 与 Keizer（1992）的模型在 Li 与 Rinzel（1994）的双变量约化。

**公式 16.4.1（Li–Rinzel 模型）** 设 $c$ 为细胞质 Ca²⁺ 浓度，$p$ 为 IP₃ 浓度，$h$ 为未被 Ca²⁺ 失活的受体亚基的比例。在 Ca²⁺ 总量固定的封闭细胞中，内质网浓度为 $c_{\mathrm{ER}} = (c_0 - c)/c_1$，并且
$$
\begin{aligned}
\frac{\mathrm{d}c}{\mathrm{d}t} &= c_1v_1\,m_\infty^3n_\infty^3h^3\,(c_{\mathrm{ER}} - c) + c_1v_2\,(c_{\mathrm{ER}} - c) - \frac{v_3c^2}{k_3^2 + c^2}, \qquad m_\infty = \frac{p}{p + d_1},\ n_\infty = \frac{c}{c + d_5},\\
\frac{\mathrm{d}h}{\mathrm{d}t} &= a_2\left[Q_2(1 - h) - ch\right], \qquad Q_2 = d_2\,\frac{p + d_1}{p + d_3},
\end{aligned} \tag{16.5}
$$
其中包括通过开放受体的释放（三个亚基，每个都需要结合 IP₃、结合激活性 Ca²⁺ 且没有失活性 Ca²⁺）、漏出，以及 SERCA 向内质网的泵入。

取标准参数（$c_0 = 2\,\mu\mathrm{M}$，$c_1 = 0.185$，$v_1 = 6\,\mathrm{s^{-1}}$，$v_2 = 0.11\,\mathrm{s^{-1}}$，$v_3 = 0.9\,\mu\mathrm{M\,s^{-1}}$，$k_3 = 0.1\,\mu\mathrm{M}$，$d_1 = 0.13$，$d_2 = 1.049$，$d_3 = 0.9434$，$d_5 = 0.08234\,\mu\mathrm{M}$，$a_2 = 0.2\,\mu\mathrm{M^{-1}\,s^{-1}}$），$(c, h)$ 平面中的 $c$ 零倾线是 N 形的，当 IP₃ 在约 $0.36$ 与 $0.67\,\mu\mathrm{M}$ 之间时，慢的 $h$ 零倾线穿过它的中间分支，系统以 $10$–$13\,\mathrm{s}$ 的周期和最大 $0.37\,\mu\mathrm{M}$ 的幅度振荡（图）。在这个窗口之外，它停在低或高的稳态；窗口以 Hopf 分岔为界，在窗口内频率随刺激升高。

### 16.4.6. 时钟

昼夜节律钟是带有额外稳定环的延迟负反馈环（[7.6.33](/7.6.33#sec-33.6)）。它们的三个性质属于振荡器的数学。其周期有温度补偿，这要求决定周期的速率的温度依赖性相互抵消。它们可以被光重置，因为在给定相位施加的扰动使相位移动的量取决于该相位，即相位响应曲线。它们被每日的周期**牵引**：固有频率为 $\omega$ 的相位振荡器以耦合 $\kappa$ 受到频率 $\Omega$ 的驱动，其相位差遵循 Adler 方程 $\dot\phi = (\omega - \Omega) - \kappa\sin\phi$，当 $\lvert\omega - \Omega\rvert \le \kappa$ 时锁定（[7.5.23 的注 23.5.1](/7.5.23#rem-23.5.1)）。若时钟与一天的频率失配超过它与光的耦合，它就不能锁定，并与环境的相位逐渐漂移。

### 16.4.7. 许多振荡器的同步

组织含有许多振荡器：视交叉上核的神经元、前体节中胚层的细胞、心脏的起搏细胞。如果它们耦合，就可以同步，**Kuramoto 模型**（[7.5.23 的定义 23.5.2](/7.5.23#def-23.5.2)）表明，同步在临界耦合处作为相变出现。那里没有证明就陈述了它的临界耦合；对固有频率服从 Lorentz 分布的情形，可以导出整条分支。

**定理 16.4.1（Kuramoto 模型的自洽性）** 设固有频率具有 Lorentz 密度 $g(\omega) = \gamma/[\pi(\gamma^2 + \omega^2)]$（在旋转坐标系中以 $0$ 为中心），并设 $N \to \infty$。序参量 $r > 0$ 的定态部分同步状态存在当且仅当 $K > K_{\mathrm{c}} = 2\gamma$，并且此时
$$
r = \sqrt{1 - \frac{K_{\mathrm{c}}}{K}}. \tag{16.6}
$$

**证明** 在平均场形式下 $\dot\theta_i = \omega_i - Kr\sin\theta_i$（平均相位设为 $0$）。$\lvert\omega\rvert \le Kr$ 的振荡器锁定在 $\sin\theta = \omega/(Kr)$；其余的漂移，由 $g$ 的对称性，它们的定态分布对 $r = \langle\cos\theta\rangle$ 没有贡献（它们的 $\sin\theta$ 项也抵消）。所以
$$
r = \int_{-Kr}^{Kr}\cos\theta(\omega)\,g(\omega)\,\mathrm{d}\omega = Kr\int_{-\pi/2}^{\pi/2}\cos^2\theta\,g(Kr\sin\theta)\,\mathrm{d}\theta,
$$
这是代换 $\omega = Kr\sin\theta$ 得到的。除以 $r > 0$ 并代入 Lorentz 分布，令 $a = Kr/\gamma$，
$$
1 = \frac{K}{\pi\gamma}\int_{-\pi/2}^{\pi/2}\frac{\cos^2\theta}{1 + a^2\sin^2\theta}\,\mathrm{d}\theta = \frac{K}{\gamma}\,\frac{\sqrt{1 + a^2} - 1}{a^2} = \frac{K}{\gamma\,(\sqrt{1 + a^2} + 1)},
$$
这里用到 $\int_0^{\pi/2}\cos^2\theta/(1 + a^2\sin^2\theta)\,\mathrm{d}\theta = \frac{\pi}{2}(\sqrt{1 + a^2} - 1)/a^2$。于是 $\sqrt{1 + a^2} = K/\gamma - 1$，有解 $a > 0$ 当且仅当 $K > 2\gamma$，并且此时 $a^2 = (K/\gamma - 1)^2 - 1$，所以 $K^2r^2 = K^2 - 2K\gamma$，$r^2 = 1 - 2\gamma/K$。$\square$

在 $K_{\mathrm{c}}$ 附近，$r \approx \sqrt{(K - K_{\mathrm{c}})/K_{\mathrm{c}}}$：同步度按与相变点距离的平方根增长，像超临界 Hopf 分岔处的幅度。在 $\gamma = 0.5$ 的 $2000$ 个振荡器的模拟中（图），$K_{\mathrm{c}} = 1$ 以下 $r$ 为 $0.03$–$0.08$（有限种群的 $N^{-1/2}$ 涨落），$K = 2$ 时为 $0.70$（理论 $0.707$），$K = 4$ 时为 $0.86$（理论 $0.866$）；在 $K_{\mathrm{c}}$ 以上，$\lvert\omega\rvert < Kr$ 的振荡器形成锁定的簇，其余的漂移。

## 16.5. 动力学中的信息

振荡和脉冲不仅是时钟：它们携带信息。有几种转录因子以脉冲方式进出细胞核，其频率而不是幅度随输入变化。酵母因子 Crz1 以约两分钟的爆发进入细胞核，其频率随细胞外 Ca²⁺ 升高（Cai、Dalal 与 Elowitz，2008）；哺乳动物上皮细胞中 ERK 的活性以脉冲出现，其频率随 EGF 增加，并预测增殖（Albeck、Mills 与 Brugge，2013）；NF-κB 通过与 IκBα 的负环在核内外振荡（Hoffmann、Levchenko、Scott 与 Baltimore，2002；Nelson 及其同事，2004）；p53 以脉冲数传达 DNA 损伤的程度（[7.6.33](/7.6.33#sec-33.5.5)）。Ca²⁺ 尖峰以其频率编码激素浓度（[7.6.33](/7.6.33#sec-33.6.3)）。

**定义 16.5.1（频率编码）** 如果信号系统的输入强度由幅度和持续时间几乎固定的信号分子脉冲的频率表示，就称它使用**频率编码**（频率调制）；若由分子的水平表示，则为幅度编码。

频率编码的一个优点是保持具有不同亲和力的靶基因的表达之间的比值。

**例 16.5.1** 两个基因被因子 $X$ 激活，$g_i = \beta_iX/(K_i + X)$，$K_1 = 0.1$，$K_2 = 1$。幅度编码时，$X \propto s$；当 $X$ 从 $0.01$ 变到 $10$ 时，比值 $g_1/g_2 = (\beta_1/\beta_2)(K_2 + X)/(K_1 + X)$ 从 $9.2\,\beta_1/\beta_2$ 变到 $1.09\,\beta_1/\beta_2$：高亲和力的基因先饱和，响应的组成随信号而变。频率编码时，$X$ 要么为 $0$，要么为 $X_{\mathrm{high}} = 10$，处于高值的时间比例与 $s$ 成正比；若靶标的响应比脉冲慢，则每个基因的平均生成是 $s$ 乘以它在 $X_{\mathrm{high}}$ 处的速率，比值 $g_1/g_2 = 1.09\,\beta_1/\beta_2$ 在每个信号水平上都相同。启动子很不相同的 Crz1 靶基因对 Ca²⁺ 的响应是成比例的变化，正如这一论证所预测的（Cai、Dalal 与 Elowitz，2008）。代价是随机性：信号低时，每个响应时间内的脉冲很少，脉冲数有涨落。

:::

脉冲还有第二个用途：恒定因子下游的不一致前馈环会适应并停止响应（[7.9.15](/7.9.15#sec-15.4.4)），而脉冲式的因子则持续激发它。并且靶标对振荡因子的响应取决于它自己的寿命：稳定的蛋白质对脉冲积分，不稳定的蛋白质跟随脉冲（思考题 10）。下游网络对动力学的解码以及这类信道的信息容量（[7.6.35](/7.6.35#sec-35.3)）是活跃的研究课题。

## 思考题

1. 证明 $\dot x = F(x)$（$F$ 光滑，所有根为单根）的相邻不动点的稳定性交替，并为自调控基因 $\dot X = f(X) - X$ 设计一个有五个不动点的输入函数。

   **答** 在相邻的两个单根之间，$F$ 的符号不变；一个根是稳定的当且仅当那里 $F' < 0$，即 $F$ 由正变负。若 $F$ 在某个根左边为正、右边为负，则下一个根（从左边趋近时 $F < 0$）处 $F$ 由负变正，是不稳定的，依此类推：$F'$ 的符号交替。五个不动点需要生成曲线与直线 $X$ 相交五次，例如两个阈值不同的陡峭 S 形函数之和，$f(X) = 0.1 + 2\,\frac{X^8}{1 + X^8} + 6\,\frac{(X/5)^8}{1 + (X/5)^8}$：不动点为 $X = 0.100$（稳定）、$0.967$（不稳定）、$2.10$（稳定）、$4.93$（不稳定）和 $7.96$（稳定），有三个稳定的表达状态。

2. 利用命题 16.1.2，解释为什么由两个各以单体形式结合单个位点的抑制因子构成的拨动开关不是双稳的，并给出天然或合成的拨动开关获得双稳态的两种方式。

   **答** 单个单体位点给出 Hill 系数为 $1$ 的抑制函数 $a + b/(1 + y/K)$；两个这样的函数的复合是凹的 Möbius 映射，与对角线只相交一次，所以拨动开关只有一个稳定不动点，两个基因都处于中间水平。双稳态来自协同性，即抑制因子在结合前二聚化，或协同地结合几个操纵序列（λ CI 在 $O_{\mathrm{R}}1$–$O_{\mathrm{R}}2$，LacI 四聚体与 DNA 成环，Gardner 及其同事所用的接近 $2$ 的 Hill 系数），或者来自因子的额外正自调控，如许多命运决定因子和 CI 本身。

3. 在没有协同结合的双正环中，每个因子被其伙伴和自身激活，二者相乘组合：$\dot X = 4\,\frac{X}{1 + X}\,\frac{Y}{1 + Y} + 0.01 - X$，$Y$ 的方程对称。求对称不动点及其稳定性，并断定该环是否双稳。

   **答** 在对角线 $X = Y = u$ 上，不动点解 $u = 4u^2/(1 + u)^2 + 0.01$：数值解为 $u = 0.0104$、$0.799$ 和 $1.201$。在对称点处，Jacobi 矩阵为 $\begin{bmatrix}a - 1 & a\\ a & a - 1\end{bmatrix}$，$a = 4u/(1 + u)^3$，其特征值为 $-1$（反对称方向）和 $2a - 1$（对称方向）：$-0.92$、$+0.10$ 和 $-0.10$。低态和高态是稳定的，中间的是鞍点：该环是双稳的。在对角线上，两个 Michaelis–Menten 项之积为 $u^2/(1 + u)^2$，实际上是 $2$ 阶的 Hill 函数，所以正自调控提供了没有协同性的交叉调控所缺少的非线性（命题 16.1.2 不适用，因为每个速率依赖于两个变量）。

4. 在 λ 模型 (16.1) 中，为什么裂解状态在所有 $d$ 下都存在而溶原状态消失？如果 Cro 在损伤时也被切割，会有什么变化？

   **答** 参数 $d$ 只增加 CI 的清除。在裂解状态，CI 已经很低（$c \approx 0.01$），它的清除几乎无关紧要，而 Cro 被其自身的启动子保持在高水平，CI 不再抑制该启动子；所以增大 $d$ 只是把本已可以忽略的 CI 压得更低。在溶原状态，CI 必须通过正环维持自身，$4(0.05 + c^2)/(1 + c^2) = (1 + d)c$；当 $d$ 足够大时，清除线升到 S 形生成曲线之上（$c = 0$ 附近除外），该状态在鞍结分岔中消失（$d_{\mathrm{c}} = 0.70$）。如果 Cro 也被切割，裂解状态也会被削弱；强损伤可能只留下两者都低的状态，即"犹豫不决"的状态，向裂解的转换就不再有保证。真实的 λ 避免了这一点：RecA 刺激 CI（和 LexA）的切割，但不刺激 Cro 的切割。

5. 由命题 16.2.1 证明：$m$ 个相同层的级联，每层在其工作点的响应系数为 $R$，则级联的响应系数为 $R^m$，并用它解释为什么 MAPK 级联中超敏性逐层增加但不能无限增长。

   **答** 由 (16.2)，对所有 $k$ 取 $R_k = R$，乘积为 $R^m$。每层的响应系数只有远离饱和时才大；一层的输出是下一层的输入，所以各层的工作点必须对齐在其曲线的陡峭部分。任何一层饱和（$y_k$ 接近最大值）都使 $R_k \to 0$，并破坏乘积；因此长级联的高增益被限制在狭窄的输入窗口内，而输入中的噪声被同一增益放大，限制了有用的陡度。图中级联的 $R$ 在低输入时为 $4$，但一旦第二层饱和就降到接近零。

6. （符合检测）多输入 FFL 有输入 $X_1$ 与 $X_2$，中间变量 $Y$ 满足 $\dot Y = X_1 + X_2 - Y$，输出 $Z$ 满足 $\dot Z = \theta(X_1 + X_2 > 0.5)\,\theta(Y > 0.6) - Z$。每个输入是高度为 $1$、持续时间为 $0.5$ 的脉冲。单个脉冲产生输出吗？两个同时的脉冲呢？相隔 $0.2$ 的两个脉冲呢？

   **答** 一个脉冲：$Y(0.5) = 1 - \mathrm{e}^{-0.5} = 0.39 < 0.6$，脉冲之后 $Y$ 衰减，所以 $Z$ 从不开启。两个同时的脉冲：$\dot Y = 2 - Y$，$Y(t) = 2(1 - \mathrm{e}^{-t})$ 在 $t = \ln(1/0.7) = 0.36 < 0.5$ 时越过 $0.6$，所以 $Z$ 从 $0.36$ 到 $0.5$ 生成（在第二个脉冲持续期间还会继续）。位于 $0$–$0.5$ 与 $0.2$–$0.7$ 的两个脉冲：$Y(0.2) = 1 - \mathrm{e}^{-0.2} = 0.181$；然后从 $0.181$ 起 $\dot Y = 2 - Y$：$Y = 2 - 1.819\,\mathrm{e}^{-(t - 0.2)}$，当 $\mathrm{e}^{-(t - 0.2)} = 0.770$，即 $t = 0.461$ 时到达 $0.6$，仍在两个脉冲之内，所以 $Z$ 从 $0.461$ 起开启，直到 $t = 0.7$ 输入之和降到 $0.5$ 以下。该回路只对在 $Y$ 的积分时间之内大致重合的输入作出响应。

7. 对 $\alpha_1 = 1$ 的双节点负环，计算 $\alpha_2 = 1$、$10$ 和 $0.01$ 时产生阻尼振荡所需的最小反馈强度 $\beta_1\beta_2$，并把答案与混合模体联系起来。

   **答** 由命题 16.4.1，$\beta_1\beta_2 > (\alpha_1 - \alpha_2)^2/4$：$\alpha_2 = 1$ 时任何正强度都够；$\alpha_2 = 10$ 时 $\beta_1\beta_2 > 20.25$；$\alpha_2 = 0.01$ 时 $\beta_1\beta_2 > 0.245$。蛋白质水平的臂比转录臂快得多的混合环，需要强得多的反馈才会过冲，否则是过阻尼的：它平稳地回到其设定点，这正是稳态所要求的性质。

8. 证明正自调控可以把时间尺度相差很大的双节点负环变成振荡器：取 $\alpha_1 = 1$，$\alpha_2 = 0.05$，$\beta_1\beta_2 = 0.2$，求使不动点为不稳定螺旋的 $P$ 的范围。

   **答** Jacobi 矩阵 $\begin{bmatrix}P - 1 & -\beta_1\\ \beta_2 & -0.05\end{bmatrix}$ 的迹为 $P - 1.05$，行列式为 $0.05(1 - P) + 0.2 = 0.25 - 0.05P$，$P < 5$ 时为正。其特征值为复数当且仅当 $(P - 1 + 0.05)^2 < 4\beta_1\beta_2 = 0.8$，即 $0.056 < P < 1.84$。当迹还为正，即 $1.05 < P < 1.84$ 时，不动点是不稳定螺旋，$P = 1.05$ 处有 Hopf 分岔。对 $1.84 < P < 5$，它是不稳定结点，在反馈饱和时有界轨线仍走向极限环（Poincaré–Bendixson），此时是弛豫型的。没有正反馈（$P = 0$）时，环是稳定的，而且因为 $0.95^2 > 0.8$，甚至不振荡。

9. 在 $\gamma = 0.5$ 的 Kuramoto 模型中，耦合取何值时 $r = 0.5$？此时有多大比例的振荡器被锁定？

   **答** $r^2 = 1 - 2\gamma/K$：$0.25 = 1 - 1/K$，$K = 4/3$。锁定的振荡器满足 $\lvert\omega\rvert < Kr = 2/3$；对 Lorentz 分布，$\mathbb{P}(\lvert\omega\rvert < c) = (2/\pi)\arctan(c/\gamma) = (2/\pi)\arctan(4/3) = 0.590$：尽管 $r$ 只有 $0.5$，约 $59\,\%$ 的振荡器被锁定，因为锁定的振荡器分布在相位 $\theta = \arcsin(\omega/Kr)$ 在 $-90^\circ$ 与 $90^\circ$ 之间的范围内。

10. 基因 $Y$ 被因子 $X(t)$ 激活，$X(t)$ 在 $0$ 与 $1$ 之间以周期 $T$ 振荡（每个周期开启一半时间），$\dot Y = X(t) - \alpha Y$。$Y$ 的均值和峰谷幅度如何依赖于 $\alpha T$？这对脉冲式 p53 下游的基因意味着什么？

    **答** $Y$ 的均值总是 $\langle X\rangle/\alpha = 0.5/\alpha$。在每个半周期内，$Y$ 以指数方式弛豫趋向 $1/\alpha$ 或 $0$；在周期状态下，最大值与最小值满足 $Y_{\max} = 1/\alpha - (1/\alpha - Y_{\min})\mathrm{e}^{-\alpha T/2}$ 和 $Y_{\min} = Y_{\max}\mathrm{e}^{-\alpha T/2}$，所以 $Y_{\max} - Y_{\min} = \frac{1}{\alpha}\frac{1 - q}{1 + q}$，$q = \mathrm{e}^{-\alpha T/2}$。对 $\alpha T \ll 1$（稳定的 $Y$），相对幅度 $(Y_{\max} - Y_{\min})/\langle Y\rangle \approx \alpha T/2$ 很小：$Y$ 对脉冲积分。对 $\alpha T \gg 1$（不稳定的 $Y$），它趋近 $2$：$Y$ 跟随每个脉冲。p53 下游产物寿命长的基因报告脉冲的数目（累积剂量），产物寿命短的基因报告脉冲本身，所以同样的 p53 动力学可以产生不同的表达程序，持续的 p53（如紫外线损伤之后或用药物时）与脉冲的读出方式也不同。
