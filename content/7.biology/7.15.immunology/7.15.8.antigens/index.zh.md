固有免疫识别的是一类微生物共有的分子模式（[7.15.6](/7.15.6)）；适应性免疫识别的则是具体的分子结构，而且几乎能识别任何结构。本章回答知识路径上"识别什么"的问题（[7.15.1](/7.15.1)）在适应性免疫一侧的答案：什么样的物质能被 T、B 淋巴细胞识别，什么样的物质能引起应答，二者为什么不是一回事。

**抗原**、**表位**与**半抗原**的基本定义已在 [7.1.7](/7.1.7) 从蛋白质–配体相互作用的角度给出，这里不再重复，而是讨论它们的免疫学含义。本章的几个区分贯穿全课程：B 细胞识别完整分子表面的形状，T 细胞识别被加工后由 MHC 提呈的肽（[7.15.13](/7.15.13)、[7.15.14](/7.15.14)）；大多数抗体应答需要 T 细胞的辅助，少数不需要（[7.15.20](/7.15.20)）；能否引起应答不只取决于分子本身，还取决于固有免疫是否同时给出"危险"信号，这正是佐剂的原理（[7.15.33](/7.15.33)）。与抗原结合的分子，即抗体，是下一章（[7.15.9](/7.15.9)）的主题。

## 8.1. 抗原的两种基本性质

### 8.1.1. 免疫原性与抗原性

一个分子"被免疫系统识别"可以有两层含义：它能被已有的抗体或淋巴细胞结合，或者它能引起新的应答。两者需要的条件不同。

**定义 8.1.1（免疫原性与抗原性）** 物质刺激机体产生适应性免疫应答（使特异性淋巴细胞活化、增殖、分化，产生抗体或效应 T 细胞）的能力称为**免疫原性**；物质与应答产物（抗体、TCR 或 BCR）特异性结合的能力称为**抗原性**（中文教材也称免疫反应性）。同时具有二者的物质称为完全抗原（免疫原），只有抗原性而无免疫原性的称为不完全抗原，即半抗原。

凡有免疫原性的物质都有抗原性，反之不然。二硝基苯基（DNP）这样的小分子能被抗体结合，但单独注射不引起抗体；把它们共价连到牛血清白蛋白等蛋白质上，就能诱导针对它们的抗体，而这些抗体也结合游离的小分子。英文文献常把"能引起应答者"称为 immunogen，把"能被结合者"称为 antigen；日常使用中二者经常混用，本课程在需要区分时写作免疫原与抗原。

### 8.1.2. 半抗原–载体效应

半抗原为什么需要载体？答案在于 B 细胞的活化需要 T 细胞的辅助，而 T 细胞只识别肽。

**定义 8.1.2（半抗原–载体效应）** **半抗原–载体效应**是指针对半抗原的抗体应答（尤其是再次应答）要求半抗原与载体蛋白相连，且机体曾对该载体致敏：识别半抗原的 B 细胞通过 BCR 结合并内吞半抗原–载体偶联物，把载体的肽段提呈在 MHC II 类分子上，由识别载体肽的辅助性 T 细胞提供辅助。

这一机制称为"连锁识别"（linked recognition）：B 细胞与 T 细胞识别的表位可以不同，但必须位于同一个分子（或同一个颗粒）上，这样辅助才会落到识别了该抗原的那个 B 细胞上。经典的载体致敏实验表明：用 DNP–卵清蛋白致敏的小鼠，用 DNP–牛血清白蛋白加强时抗 DNP 的再次应答很弱；只有加强所用的载体与致敏相同，或者另外转输对新载体致敏的 T 细胞，再次应答才出现。

![抗原的识别单位。A：一条多肽链折叠成的蛋白质上的两种 B 细胞表位：线性表位由序列上连续的残基组成（红色），变性后仍可被抗体识别；构象表位由序列上远隔、在折叠结构中彼此靠近的残基组成（蓝色），变性后消失；T 细胞表位（黄色）可以位于分子内部，经加工成短肽后由 MHC 分子提呈。B：半抗原–载体效应：B 细胞以 BCR 结合半抗原（菱形），内吞整个偶联物，把载体蛋白的肽段提呈在 MHC II 类分子上；识别载体肽的辅助性 T 细胞通过 CD40L 与细胞因子提供辅助，B 细胞于是产生抗半抗原的抗体](./plots/epitopes.py)

半抗原–载体效应有两个推论。其一是药物过敏：某些药物或其代谢物与自身蛋白共价结合，自身蛋白成为载体，从而引起针对药物的抗体（[7.15.26](/7.15.26)、[7.15.27](/7.15.27)）。其二是**结合疫苗**的原理：多糖抗原本身不能得到 T 细胞辅助（§8.4.1），把它共价连到蛋白载体上之后，多糖特异的 B 细胞就能通过连锁识别得到载体特异 T 细胞的辅助，产生类别转换的抗体与记忆（[7.15.33](/7.15.33)）。

## 8.2. 表位

### 8.2.1. 表位的大小与数目

**表位**是抗原上被一个抗体或一个 TCR 识别的最小结构单位。一个蛋白质抗原通常有许多表位，一个半抗原相当于一个表位。B 细胞表位一般由 5–15 个氨基酸残基（或 5–7 个单糖残基）组成，抗体结合部位与之接触的面积约 $7$–$9\ \mathrm{nm^2}$（[7.1.7](/7.1.7)）；T 细胞表位是 MHC I 类分子提呈的 8–10 个残基或 MHC II 类分子提呈的 13–25 个残基的肽（核心约 9 个残基位于结合槽中）。

一个抗原虽有许多潜在的表位，应答却往往集中在少数几个上，称为免疫优势表位。对 T 细胞而言，免疫优势取决于肽能否被有效切割产生、能否结合个体所带的 MHC 等位基因、外周是否存在相应的 T 细胞；对 B 细胞而言，取决于表位的可接近性、柔性和与自身分子的差异。

### 8.2.2. 线性表位与构象表位

**定义 8.2.1（线性表位与构象表位）** 由多肽链上序列连续的氨基酸残基构成的表位称为**线性表位**（顺序表位）；由序列上不连续、在折叠后的三维结构中彼此靠近的残基构成的表位称为**构象表位**。

二者可以用变性来区分：构象表位在蛋白质变性后消失，线性表位不受影响，甚至因被暴露而更易结合。天然蛋白质的 B 细胞表位大多是构象表位（结构分析的估计在 90% 左右），所以针对变性蛋白（例如 **Western 印迹**中的条带）的抗体常常不结合天然蛋白，反之亦然。这在病理与空间蛋白组学中很实际：甲醛固定与石蜡包埋改变了蛋白质的构象，一个抗体能否用于**免疫组织化学**，取决于它的表位在固定和抗原修复之后是否仍然存在（[7.15.34](/7.15.34)）。

### 8.2.3. T 细胞表位与 B 细胞表位

**定义 8.2.2（T 细胞表位与 B 细胞表位）** 被 TCR 识别的表位称为 **T 细胞表位**：它是抗原经抗原提呈细胞加工产生、结合在 MHC 分子抗原肽结合槽中的线性肽，TCR 同时识别肽与 MHC。被 BCR 或抗体直接识别的表位称为 **B 细胞表位**：它位于完整抗原分子的表面，无需加工和 MHC，可以是构象表位或线性表位，化学本质可以是蛋白质、多糖、脂类或核酸。

| | T 细胞表位 | B 细胞表位 |
|---|---|---|
| 识别受体 | TCR（并需 CD4 或 CD8 共受体） | BCR、抗体 |
| MHC 分子 | 必需（MHC 限制性） | 不需要 |
| 化学性质 | 几乎都是肽（脂类由 CD1 提呈，是例外） | 蛋白质、多糖、脂多糖、核酸、小分子 |
| 大小 | MHC I：8–10 个残基（CD8⁺ T 细胞）；MHC II：13–25 个残基（CD4⁺ T 细胞） | 5–15 个残基 |
| 类型 | 线性 | 多为构象，也可为线性 |
| 位置 | 分子的任何部位，包括内部 | 分子表面、可接近之处 |
| 是否需要加工 | 需要（[7.15.14](/7.15.14)） | 不需要 |

T 细胞表位必须被 MHC 提呈，原因在于 T 细胞的功能：它要判断的是一个细胞的状态，而不是溶液中有没有某种分子。MHC 把细胞内部（I 类）或细胞摄入物（II 类）的蛋白质片段展示在表面，T 细胞借此"看到"细胞里面；代价是 T 细胞看不到完整分子的形状，也看不到大多数非蛋白质抗原。同一个蛋白质上，B 细胞与 T 细胞因此常常识别完全不同的部位，这也是连锁识别（§8.1.2）能够成立的前提。

### 8.2.4. 共同表位与交叉反应

**定义 8.2.3（交叉反应）** 不同抗原上相同或相似的表位称为共同表位（共同抗原），带有共同表位的不同抗原称为交叉抗原；针对一种抗原产生的抗体或致敏淋巴细胞与另一种带有共同表位的抗原发生的结合称为**交叉反应**。

交叉反应是一个程度问题：抗体与相似表位的结合通常较弱，亲和力随结构的差异逐步下降。它有三方面的意义：

- 保护：针对一种抗原的免疫可以保护机体免受另一种带有共同表位的抗原的侵害，这是历史上用近缘抗原进行免疫的依据。
- 损伤：外来抗原与自身分子有共同表位时，针对外来抗原的应答可能攻击自身组织，称为**分子模拟**，是自身免疫病的一种起因（[7.15.28](/7.15.28)）。
- 检测：免疫学检测中，交叉反应会造成假阳性，诊断用抗原与抗体要尽量选用特异的表位；在实验中，抗体与同一家族的同源蛋白交叉反应是**抗体验证**必须排除的问题（[7.15.34](/7.15.34)）。

不同物种之间广泛存在的共同抗原称为异嗜性抗原（Forssman 抗原），例如某些糖脂表位同时存在于多种动物的组织与微生物表面。人体内天然存在的抗 ABO 血型抗原的抗体，一般认为就是由与血型糖链结构相似的肠道菌糖链诱导的交叉反应抗体。

## 8.3. 影响免疫原性的因素

免疫原性不是分子的固有属性，而是分子、宿主与接触方式三者共同决定的。

| 类别 | 因素 | 规律 |
|---|---|---|
| 抗原分子 | 异物性 | 与宿主的亲缘关系越远，结构差异越大，免疫原性越强；免疫系统在发育中未接触过的自身成分（隔离抗原）也具有异物性 |
| | 化学性质 | 蛋白质最强；多糖次之；脂类与核酸单独时较弱，与蛋白质结合后增强 |
| | 分子量 | 通常大于 $10\ \mathrm{kDa}$ 的分子免疫原性较强，小于 $5\ \mathrm{kDa}$ 的常常是半抗原 |
| | 结构复杂性 | 含芳香族氨基酸、结构复杂者强；单一氨基酸的均聚物很弱 |
| | 构象与可接近性 | 表位须位于分子表面、可被 BCR 接触 |
| | 可降解性 | 必须能被蛋白酶加工才有 T 细胞表位：D-氨基酸构成的多肽不能被降解，免疫原性很差 |
| | 物理状态 | 聚合的、颗粒性的抗原强于可溶的单体，因为更易被吞噬细胞摄取，并能交联 BCR |
| 宿主 | 遗传背景 | 个体所带的 MHC 等位基因决定能否提呈某一抗原的肽（[7.15.13](/7.15.13)）；同一抗原在不同品系动物中可以是高应答或低应答 |
| | 年龄、性别与健康状态 | 新生儿与老年人应答较弱；雌性一般抗体应答更强，自身免疫病也更多见 |
| 接触方式 | 剂量 | 适中的剂量引起应答；过低或过高的剂量可诱导**免疫耐受**（低区与高区耐受） |
| | 途径 | 皮内、皮下强于肌内，肌内强于腹腔与静脉；口服接触常诱导**口服耐受** |
| | 频率 | 间隔适当的重复接触（数周）增强应答（**加强免疫**）；过于频繁可致耐受 |
| | 佐剂 | 与抗原同时给予的佐剂显著增强应答（§8.5.2） |

## 8.4. 抗原的分类

### 8.4.1. 胸腺依赖性抗原与胸腺非依赖性抗原

按刺激 B 细胞产生抗体时是否需要辅助性 T 细胞，抗原分为两类。这一分类最有用，因为它决定了抗体应答的质量。

**定义 8.4.1（胸腺依赖性抗原与胸腺非依赖性抗原）** 刺激 B 细胞产生抗体时必须有辅助性 T 细胞参与的抗原称为**胸腺依赖性抗原**（TD 抗原），绝大多数蛋白质抗原属于此类；不需要 T 细胞辅助即可刺激 B 细胞产生抗体的抗原称为**胸腺非依赖性抗原**（TI 抗原）。TI 抗原又分为两型：TI-1 抗原（如**脂多糖**）在高浓度下通过 **Toll 样受体**等非特异地激活多克隆 B 细胞；TI-2 抗原（如多糖、聚合鞭毛蛋白）带有大量重复排列的相同表位，靠广泛交联 BCR 激活 B 细胞。

"胸腺依赖"一名来自先天无胸腺的裸鼠：它们缺乏 T 细胞，不能产生针对大多数蛋白质的抗体，却仍能对某些多糖产生应答。

| | TD 抗原 | TI 抗原 |
|---|---|---|
| 化学性质 | 主要是蛋白质 | 多糖、脂多糖、聚合蛋白等 |
| 表位 | B 细胞表位与 T 细胞表位兼有 | 重复的 B 细胞表位，无 T 细胞表位 |
| T 细胞辅助 | 必需（连锁识别） | 不需要 |
| 主要应答的 B 细胞 | **滤泡 B 细胞**（B-2） | **边缘区 B 细胞**、**B-1 细胞** |
| 生发中心 | 形成 | 基本不形成 |
| 抗体类别 | IgM，随后类别转换为 IgG、IgA、IgE | 以 IgM 为主，少量 IgG |
| 亲和力成熟 | 有 | 很弱 |
| 免疫记忆 | 有 | 很弱或无 |
| 引起的免疫类型 | 体液免疫，并伴有细胞免疫 | 体液免疫 |

TI-2 应答依赖边缘区 B 细胞，而人的脾边缘区要到 2 岁左右才发育成熟，所以婴幼儿对纯多糖抗原的应答很差；这正是结合疫苗（§8.1.2）要把 TI-2 抗原变成 TD 抗原的原因。

### 8.4.2. 按抗原与宿主的亲缘关系

| 类别 | 含义 | 例子 |
|---|---|---|
| 异种抗原 | 来自另一物种的抗原 | 微生物抗原、异种动物血清、异种移植物 |
| 同种异型抗原 | 同一物种不同个体之间不同的抗原 | 血型抗原、HLA |
| 自身抗原 | 能引起自身免疫应答的自身成分 | 隔离抗原、修饰后的自身分子 |
| 异嗜性抗原 | 不同物种之间的共同抗原 | Forssman 抗原 |
| 独特型抗原 | 抗体、TCR、BCR 可变区特有的结构 | 抗独特型抗体识别的表位（[7.15.9](/7.15.9)） |

**定义 8.4.2（同种异型抗原与自身抗原）** 同一物种内因遗传多态性而在不同个体之间存在差异的抗原称为**同种异型抗原**（同种抗原）；能被自身的免疫系统识别并引起应答的自身成分称为**自身抗原**。

同种异型抗原是输血与移植中免疫反应的对象：ABO 与 Rh **血型**决定输血相容性，HLA 决定器官移植的组织相容性（[7.15.13](/7.15.13)、[7.15.29](/7.15.29)）。正常情况下，自身成分不引起应答，这是**免疫耐受**的结果（[7.15.24](/7.15.24)）；自身成分成为自身抗原有几条途径：在发育中与免疫系统隔离的成分（如眼晶状体蛋白、精子）因外伤而释放；自身分子被化学修饰、发生翻译后修饰改变（如瓜氨酸化）或构象改变，产生新的表位；或者通过分子模拟被交叉识别（[7.15.28](/7.15.28)）。

### 8.4.3. 其他分类

- 按在抗原提呈细胞内的来源：在细胞内合成的**内源性抗原**主要经 MHC I 类分子提呈给 CD8⁺ T 细胞，被摄入的**外源性抗原**主要经 MHC II 类分子提呈给 CD4⁺ T 细胞（[7.15.14](/7.15.14)）。
- 按与疾病的关系：移植抗原、**肿瘤相关抗原**与**肿瘤特异性抗原**（[7.15.30](/7.15.30)）、自身抗原、能引起超敏反应的**过敏原**（变应原）、能诱导耐受的耐受原。
- 按物理性状与来源：颗粒抗原与可溶性抗原，天然抗原与人工合成抗原。

## 8.5. 非特异性免疫刺激剂

抗原只激活带有相应受体的少数克隆。另有一些物质不经过特异性识别，或者绕过表位的识别，就能激活大量淋巴细胞克隆，或放大特异性应答。它们的作用方式不同，但共同点是不依赖抗原特异性：超抗原与丝裂原直接活化大量克隆，佐剂则放大对其他抗原的应答。

### 8.5.1. 超抗原与丝裂原

**超抗原**是一类微生物产物（如金黄色葡萄球菌的肠毒素和毒性休克综合征毒素-1，化脓性链球菌的致热外毒素），它们不经加工，以完整分子同时结合 MHC II 类分子抗原肽结合槽之外的区域和 TCR β 链 V 区的框架部分，把两个细胞桥接起来。这样的结合不依赖肽，也不依赖 TCR 的 CDR3，因此一个超抗原能活化携带某一类 Vβ 家族的全部 T 细胞，约占外周 T 细胞的 2%–20%，而普通肽抗原只活化约 $10^{-5}$–$10^{-4}$。结果是大量 CD4⁺ T 细胞同时释放 IFN-γ、TNF-α 和 IL-2，诱发全身性的炎症反应，如毒性休克综合征与食物中毒中的呕吐（[7.15.11](/7.15.11) 的**细胞因子风暴**）；同时被活化的 T 细胞随后凋亡或失能，造成免疫抑制。

**丝裂原**是能刺激淋巴细胞有丝分裂的物质，不依赖抗原特异性：刀豆蛋白 A（ConA）与植物血凝素（PHA）活化 T 细胞，脂多糖和美洲商陆丝裂原作用于 B 细胞，抗 CD3 抗体则直接交联 TCR 复合体。丝裂原通过交联细胞表面的糖蛋白（或受体）模拟抗原信号，作用对象是整个淋巴细胞群而不是某个克隆，在检测淋巴细胞的增殖能力和做染色体核型分析时用它来刺激 T 细胞。

### 8.5.2. 佐剂

**定义 8.5.1（佐剂）** **佐剂**是与抗原同时或预先给予、能增强机体对该抗原的应答强度或改变应答类型的物质。

佐剂本身没有（或只有很弱的）免疫原性，作用机制可以归为四类：

- 改变抗原的物理性状，形成抗原库：铝盐吸附抗原后在注射部位滞留，缓慢释放；油乳剂有类似效果。抗原停留时间延长，使淋巴细胞有更多机会接触它。
- 激活固有免疫：许多佐剂含有**模式识别受体**的配体，如脂多糖的无毒衍生物（TLR4）、CpG 寡核苷酸（TLR9）、分枝杆菌细胞壁成分（TLR2、NOD2）；铝盐与某些颗粒物激活**炎症小体**（NLRP3），并引起局部组织损伤，释放**损伤相关分子模式**。
- 促进抗原提呈细胞的摄取、成熟与迁移：固有免疫被激活之后，树突状细胞上调 MHC 与共刺激分子（CD80、CD86），分泌细胞因子，这是 T 细胞活化需要的第二、第三信号（[7.15.16](/7.15.16)）。
- 招募并活化抗原提呈细胞与淋巴细胞：局部炎症使趋化因子释放，更多单核细胞和树突状细胞到达注射部位，并进入引流淋巴结。

佐剂的原理回答了一个根本问题：为什么纯化的蛋白质往往免疫原性很弱，而同一个蛋白质连同"危险信号"一起给予就能引起强应答？适应性免疫的启动需要固有免疫提供的第二信号，纯蛋白没有它。这是 [7.15.6](/7.15.6) 的模式识别与适应性免疫之间的联系，也是现代疫苗设计的重点：重组蛋白疫苗要依赖佐剂（[7.15.33](/7.15.33)），而灭活或减毒的完整病原体本身就带着自己的模式。佐剂不但改变应答的强弱，也改变应答的类型：铝盐偏向 Th2 与抗体应答，含 TLR 激动剂的佐剂偏向 Th1 应答，这与激活的固有细胞所分泌的细胞因子有关（[7.15.17](/7.15.17)）。

| | 超抗原 | 丝裂原 | 佐剂 |
|---|---|---|---|
| 作用对象 | T 细胞（Vβ 家族） | T 细胞或 B 细胞 | 抗原提呈细胞、固有细胞 |
| 是否需要抗原特异性 | 否 | 否 | 否，但放大对抗原的特异性应答 |
| MHC 限制性 | 无（结合 MHC II 的保守区域） | 无 | 无 |
| 活化的克隆比例 | 约 2%–20% | 很高（多克隆） | 不直接活化淋巴细胞 |
| 结果 | 大量细胞因子，免疫病理，之后失能 | 多克隆增殖 | 应答增强，类型改变 |

## 8.6. 一个模型：表位的占有与交联

B 细胞的活化要求 BCR 被交联：只有一个抗原分子同时结合两个以上的受体，把它们拉到一起，才能启动信号。这一节用一个简单模型回答：一个抗原要有几个表位，多高的受体浓度，才能有效交联？它为 [7.15.9](/7.15.9) 的亲合力做准备。

设抗原有 $n$ 个相同且相互独立的表位，每个表位以解离常数 $K_\mathrm{D}$ 结合游离受体（浓度为 $c$，$c$ 远大于抗原浓度，因此不被消耗）。按 [7.1.7](/7.1.7) 的结合等温线，每个表位被占据的概率为 $\theta = c/(K_\mathrm{D} + c)$。一个抗原分子要桥接两个受体，至少有两个表位被占据，概率为

$$
p(n, \theta) = 1 - (1 - \theta)^n - n\theta(1 - \theta)^{n-1}. \tag{8.1}
$$

对 $n = 1$（半抗原）有 $p = 0$：单价抗原无论浓度多高都不能交联，这解释了半抗原不引起应答（定义 8.1.1）。

**例 8.6.1** 取 $\theta = 0.1$，即受体浓度为 $K_\mathrm{D}$ 的 $1/9$。$n = 2$ 时 $p = 0.01$；$n = 10$ 时 $p = 1 - 0.9^{10} - 10 \times 0.1 \times 0.9^{9} \approx 0.26$；也就是说，同样的受体占有率，10 价抗原能交联的分子比例是 2 价抗原的 26 倍。

对较大的 $n$，$p \approx 1 - \mathrm{e}^{-n\theta}(1 + n\theta)$，只依赖于 $n\theta$（占据的表位平均数）。取 $p = 1/2$，数值解得 $n\theta \approx 1.7$，所以达到半数交联所需的 $c/K_\mathrm{D} \approx \theta \approx 1.7/n$：价数越高，所需浓度越低。

![表位的占有与交联（式 (8.1)）。A：具有 $n$ 个相同表位的抗原中，至少有两个表位被占据（能桥接两个受体）的分子所占比例 $p$ 随游离受体浓度（以 $K_\mathrm{D}$ 为单位）的变化：$n$ 越大，曲线越向左移；$n = 1$ 的半抗原永远是 0。B：达到 $p = 1/2$ 所需的 $c/K_\mathrm{D}$ 对 $n$（双对数坐标）；虚线为渐近式 $1.7/n$，$n = 2$、10、30 时分别为 2.4、0.19、0.059](./plots/crosslinking.py)

模型的结论与 TI-2 抗原的特点相符：多糖和聚合蛋白带有数十到数百个重复排列的表位，在很低的受体占有率下就能广泛交联 BCR，不需要 T 细胞的辅助（§8.4.1）；单体的蛋白质只有少数几个表位，交联弱，要靠 T 细胞来补足。这个模型只是一阶近似：它假设表位相互独立、间距合适，也忽略了受体的移动和信号阈值；真实的 BCR 簇集还取决于表位的间距（约 $5$–$10\ \mathrm{nm}$ 最有效）和受体的流动性。后续的亲合力（[7.15.9](/7.15.9)）是同一个思想在抗体一侧的版本：二价抗体同时结合两个表位，使有效结合力大大增强。

## 小结

| 主题 | 要点 |
|---|---|
| 两种性质（§8.1） | 免疫原性是引起应答的能力，抗原性是与应答产物结合的能力（定义 8.1.1）；半抗原只有抗原性，连到载体上才有免疫原性（定义 8.1.2） |
| 表位（§8.2） | 表位是抗原被识别的最小单位；线性表位与构象表位（定义 8.2.1）；T 细胞表位与 B 细胞表位的区别（定义 8.2.2）；共同表位引起交叉反应（定义 8.2.3） |
| 免疫原性的决定因素（§8.3） | 异物性、分子量与化学性质、结构复杂性、物理状态；宿主的 MHC 与年龄；剂量、途径、频率与佐剂 |
| 分类（§8.4） | TD 抗原与 TI 抗原（定义 8.4.1）：TD 需 T 细胞辅助，产生类别转换、亲和力成熟与记忆；同种异型抗原与自身抗原（定义 8.4.2） |
| 非特异性刺激剂（§8.5） | 超抗原与丝裂原直接活化大量克隆；佐剂（定义 8.5.1）通过抗原库、固有免疫激活与抗原提呈细胞的成熟增强应答 |
| 模型（§8.6） | 桥接两个受体的抗原比例由式 (8.1) 给出；交联所需浓度约与表位数成反比 |

两条贯穿全课程的线索：B 细胞看分子的形状，T 细胞看被 MHC 提呈的肽，二者通过连锁识别在同一个抗原上相会；而应答能否启动，既取决于抗原，也取决于固有免疫是否同时给出信号。

## 思考题

1. 为什么对半抗原（如二硝基苯基）本身不产生抗体，而偶联载体后可以产生，且产生的抗体又能结合游离的半抗原？

   **答** 半抗原的分子量小，不能被加工成与 MHC 结合的肽，B 细胞即使结合了半抗原也得不到 CD4⁺ T 细胞的辅助。偶联载体蛋白之后，B 细胞通过 BCR 结合半抗原，内吞整个偶联物，把载体肽提呈在 MHC II 类分子上，由载体特异的 T 细胞提供辅助（连锁识别）。抗体应答针对半抗原这一 B 细胞表位，所以产生的抗体的特异性仍是半抗原，当然能结合游离的半抗原。

2. 一个蛋白质被加热变性后，原来结合它的单克隆抗体不再结合。又有另一个抗体，只结合变性后的蛋白质。如何解释？这对用抗体做免疫组织化学有什么提示？

   **答** 前一个抗体识别构象表位，变性使序列上相距很远的残基分开，表位消失；后一个抗体识别线性表位，它在天然蛋白质中埋在内部或被遮挡，变性后暴露。甲醛固定与石蜡包埋改变蛋白质的构象，同时交联邻近的残基，所以要选用已验证在固定组织上有效的抗体（多为识别线性表位的抗体），并经过抗原修复；同一个靶蛋白，不同的抗体克隆在固定组织上的表现可以完全不同。

3. 婴儿接种纯多糖疫苗效果很差，把多糖连到蛋白载体上就能产生持久的 IgG 应答。请解释二者的区别，并说明为什么这与半抗原–载体效应是同一个原理。

   **答** 多糖是 TI-2 抗原，靠交联 BCR 激活边缘区 B 细胞，没有 T 细胞表位，不能得到 T 细胞辅助，因此以 IgM 为主、没有亲和力成熟与记忆；婴幼儿的边缘区发育不全，应答更差。把多糖共价连到蛋白载体上，多糖特异的 B 细胞通过 BCR 内吞偶联物，把载体肽提呈给载体特异的 T 细胞，得到辅助，发生类别转换、形成生发中心与记忆。这里多糖相当于半抗原，蛋白质相当于载体，两者是同一种连锁识别。

4. 在式 (8.1) 的模型中，一个有 $n = 5$ 个表位的抗原要达到 $p = 1/2$，游离受体浓度需要多大？如果受体的 $K_\mathrm{D}$ 提高到原来的 10 倍（亲和力降低），所需浓度怎样变化？

   **答** 解 $p(5, \theta) = 1/2$ 得 $\theta \approx 0.314$，即 $c/K_\mathrm{D} = \theta/(1 - \theta) \approx 0.46$，所需的 $c \approx 0.46K_\mathrm{D}$。浓度与 $K_\mathrm{D}$ 成正比，$K_\mathrm{D}$ 增为 10 倍时所需浓度也增为 10 倍。价数的增加可以补偿亲和力的下降：把 $n$ 从 5 增加到 30，所需的 $c/K_\mathrm{D}$ 从 0.46 降到 0.059。

   *提示：用式 (8.1) 数值求根，如 `scipy.optimize.brentq`。*
5. （开放题）疫苗开发中常常发现，纯化的重组蛋白单独免疫的效果远不如灭活的完整病原体。从本章的概念出发，设计思路来弥补这一差距。

   **答** 思路：重组蛋白缺少固有免疫的第二信号，可以加入含模式识别受体配体的佐剂（TLR 激动剂、铝盐等）；通过缓释、颗粒化或多价展示（如病毒样颗粒、纳米颗粒上排列的重复抗原）同时增加摄取和 BCR 交联（式 (8.1) 中 $n$ 增大）；连到能被多数个体的 MHC 提呈的辅助性 T 细胞表位或载体蛋白上，保证 T 细胞辅助；选择免疫优势表位并保持其天然构象，以诱导针对构象表位的中和抗体。
