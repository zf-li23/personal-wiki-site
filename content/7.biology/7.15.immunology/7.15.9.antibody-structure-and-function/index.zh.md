[7.15.8](/7.15.8) 回答了适应性免疫"识别什么"，本章回答"B 细胞用什么识别，识别之后用什么清除"。抗体是同一个分子的两种形式：膜型的是 B 细胞的抗原受体，分泌型的是体液免疫的效应分子。它的结构把两件事分开：N 端的可变区负责特异性识别，C 端的恒定区决定用哪种效应清除。理解这个分工，就理解了抗体的全部生物学。

蛋白质–配体结合的一般规律和 IgG 的基本结构已在 [7.1.7](/7.1.7) 给出，这里不再重复，而是展开免疫学的内容：五个类别各自的功能，抗原抗体结合的定量（亲和力与亲合力是同一个模型的两个极限），以及人工抗体怎样把这些原理变成工具和药物。抗体的多样性从哪里来是 [7.15.12](/7.15.12) 的问题；B 细胞怎样产生抗体见 [7.15.19](/7.15.19) 与 [7.15.20](/7.15.20)；抗体的效应的细节见 [7.15.21](/7.15.21)，补体见 [7.15.10](/7.15.10)。

## 9.1. 免疫球蛋白的基本结构

### 9.1.1. 四条肽链与 Ig 结构域

所有**抗体**（免疫球蛋白）都由四条多肽链组成，两条长的、两条短的，用链间二硫键与非共价作用连成对称的"Y"形分子。

**定义 9.1.1（重链、轻链、可变区与恒定区）** 抗体分子中相对分子质量较大（约 $50$–$75\ \mathrm{kDa}$）的两条相同的肽链称为**重链**，较小（约 $25\ \mathrm{kDa}$）的两条相同的肽链称为**轻链**。每条链靠近 N 端的约 110 个氨基酸，序列在不同抗体之间差异很大，称为**可变区**（V 区，$\mathrm{V_H}$、$\mathrm{V_L}$）；其余部分在同一类别内序列基本相同，称为**恒定区**（C 区，重链 $\mathrm{C_H}$，轻链 $\mathrm{C_L}$）。

轻链有 κ 与 λ 两种，同一个抗体分子的两条轻链总是同型；人的抗体中 κ 链约占 60%，λ 链约占 40%，小鼠约 95% 为 κ。重链有五种（γ、μ、α、δ、ε），决定抗体的类别（§9.2）。

每条链由若干个约 110 个残基的免疫球蛋白结构域（Ig 折叠）串联而成：每个结构域是两层反平行 β 折叠片夹成的"三明治"，由一个链内二硫键稳定。轻链有两个结构域（$\mathrm{V_L}$、$\mathrm{C_L}$）；重链有四个（$\mathrm{V_H}$、$\mathrm{C_H1}$、$\mathrm{C_H2}$、$\mathrm{C_H3}$），IgM 与 IgE 的重链多一个（$\mathrm{C_H4}$）。$\mathrm{V_H}$ 与 $\mathrm{V_L}$ 配对成抗原结合部位，$\mathrm{C_H1}$ 与 $\mathrm{C_L}$ 配对，两条重链的 $\mathrm{C_H3}$ 配对。Ig 折叠是一个庞大蛋白质超家族的标志：TCR、MHC、CD4、CD8 和许多黏附分子都含有这种结构域（[7.15.4](/7.15.4)）。

### 9.1.2. 可变区与互补决定区

把许多抗体的 V 区序列并列比较，可变性并不是均匀分布的，而集中在三个很短的区段：它们称为**互补决定区**（CDR，也称高变区），夹在四个相对保守的框架区之间。

**定义 9.1.2（互补决定区）** 抗体与 TCR 可变区中序列高度可变、直接接触抗原的三个环（CDR1、CDR2、CDR3）称为**互补决定区**；它们之间序列相对保守、构成 β 折叠片骨架的区段称为框架区。

$\mathrm{V_H}$ 与 $\mathrm{V_L}$ 各有三个 CDR，一个抗体分子的一个结合部位因此由六个环拼成。它们在折叠结构中聚在 $\mathrm{V_H}$/$\mathrm{V_L}$ 界面的顶端，形成一个结合面，面积约 $6$–$9\ \mathrm{nm^2}$，与表位互补（[7.15.8](/7.15.8)，[7.1.7](/7.1.7)）。六个环中以重链的 CDR3 最长、最可变，它由 V、D、J 三个基因片段的连接处编码，位于结合面中央，对特异性贡献最大（[7.15.12](/7.15.12)）。结合面的形状随抗原而异：对半抗原是一个深口袋，对多糖是一个沟槽，对蛋白质则是较平的大界面；表位与 CDR 的结合常伴有双方的局部构象调整（诱导契合）。

### 9.1.3. Fab、Fc 与铰链区

早在抗体的氨基酸序列确定以前，蛋白酶水解就已经揭示了它的结构域组织：木瓜蛋白酶在铰链区把 IgG 切成三段，两个相同的抗原结合片段与一个能结晶的片段；胃蛋白酶则在铰链区二硫键的下方切开，得到一个仍保持二价的 $\mathrm{F(ab')_2}$ 片段和一些小片段。

**定义 9.1.3（Fab 与 Fc 片段、铰链区）** 抗体的 N 端部分，包括一条完整的轻链与重链的 $\mathrm{V_H}$、$\mathrm{C_H1}$，称为 **Fab 片段**（fragment antigen binding），它含一个抗原结合部位；两条重链 C 端的 $\mathrm{C_H2}$、$\mathrm{C_H3}$（IgM 与 IgE 还有 $\mathrm{C_H4}$）部分称为 **Fc 片段**（fragment crystallizable），不结合抗原，但决定抗体的效应功能。位于 $\mathrm{C_H1}$ 与 $\mathrm{C_H2}$ 之间、富含脯氨酸和半胱氨酸的一段柔性序列称为**铰链区**。

铰链区有两个作用：两条重链之间的二硫键把重链锁成对称的二聚体；它的柔性使两个 Fab 臂能在较大角度范围内张开或收拢，使二价抗体能同时结合间距不同的两个表位（§9.5.3）。IgG、IgA 与 IgD 有铰链区，IgM 与 IgE 没有，代之以多出的一个 $\mathrm{C_H}$ 结构域，灵活性来自结构域之间的柔性。IgG3 的铰链区特别长，可以长达 62 个残基，使它最容易接近抗原也最易被蛋白酶切断，半衰期因而较短。

## 9.2. 免疫球蛋白的血清型

抗体分子可以用抗体来识别：用一种动物的免疫球蛋白免疫另一种动物，得到的抗体能分辨出不同的抗原性差别，这些差别按在群体中的分布分为三类，称为血清型。

**定义 9.2.1（同种型）** 同一物种所有个体的抗体共有、由不同的恒定区基因编码的抗原性差异称为**同种型**，包括重链的类别（γ、μ、α、δ、ε）与亚类（人 IgG1–4、IgA1–2）以及轻链的型（κ、λ）。

同种型是物种水平的差异：同一个人体内同时有全部同种型的抗体，用人 IgG 免疫兔得到的抗人 IgG 抗体也能识别所有人的 IgG。同种型决定抗体的类别，也决定它的效应功能；一个 B 细胞可以改变它产生的抗体的同种型而保持 V 区不变，这就是**类别转换重组**（[7.15.12](/7.15.12)）。

**定义 9.2.2（同种异型）** 同一物种不同个体之间，因恒定区基因的等位基因多态性而产生的抗原性差异称为**同种异型**。

同种异型是个体水平的差异，一般由恒定区上一两个氨基酸的差别引起，如人 IgG 重链的 Gm 系统、κ 链的 Km 系统和 IgA2 的 Am 系统。它们的编码基因紧密连锁，作为单倍型整体遗传，曾用于亲子鉴定与人群遗传学研究；在医学上，输入含有受者没有的同种异型的免疫球蛋白，偶可引起抗同种异型的抗体。

**定义 9.2.3（独特型）** 抗体（或 TCR、BCR）可变区上因 CDR 与框架区的序列而具有的独特的抗原性称为**独特型**；独特型上的每一个抗原决定簇称为独特位。

每一个 B 细胞克隆的抗体都有自己的独特型。针对独特型的抗体（抗独特型抗体）可以识别一个克隆；其中一部分抗独特型抗体的结合部位的形状与原抗原相似，称为"内影像"。Jerne 据此提出了免疫网络学说：抗体与抗独特型抗体构成互相调节的网络。这一学说没有被实验支持为免疫应答的主要调节机制，但独特型的概念仍有用：它是肿瘤 B 细胞克隆的标志，也是抗体药物免疫原性的一部分来源。

| | 同种型 | 同种异型 | 独特型 |
|---|---|---|---|
| 位置 | 恒定区（C） | 恒定区（C）的个别位置 | 可变区（V）与 CDR |
| 分布 | 物种内所有个体共有 | 个体之间不同 | 每个克隆不同 |
| 决定于 | 不同的 C 基因 | C 基因的等位基因 | V(D)J 重排与体细胞突变 |
| 例子 | μ、γ、α、δ、ε，κ、λ | Gm、Km、Am | 抗独特型抗体识别的表位 |

## 9.3. 五类抗体

### 9.3.1. 类别与总表

**定义 9.3.1（抗体的五个类别）** 按重链恒定区的类型，人的抗体分为五类：含 γ 链的 **IgG**，含 μ 链的 **IgM**，含 α 链的 **IgA**，含 δ 链的 **IgD** 和含 ε 链的 **IgE**。

### 9.3.2. 各类抗体的特点

IgG 是血清和组织液中最多的抗体，也是再次应答的主要抗体。它能自由地扩散进入组织，因此是组织内抵御感染的主力；它是唯一能通过胎盘的抗体，由胎盘合体滋养层细胞上的**新生儿 Fc 受体**经转胞吞作用主动运送，使新生儿在出生后数月内拥有母亲的保护。IgG 的半衰期（约 3 周）远长于其他类别，同样由 FcRn 决定：IgG 被内皮细胞与吞噬细胞胞饮之后，在酸性的内体中与 FcRn 结合而免于溶酶体降解，被送回细胞表面释放（[7.15.21](/7.15.21)）。四个亚类的 Fc 与补体、Fc 受体的亲和力不同，所以效应各有侧重：IgG1 与 IgG3 激活补体和结合 FcγR 的能力强，IgG2 偏向针对多糖抗原，IgG4 的效应功能很弱。

IgM 是应答中最早出现的抗体，也是系统发生上最古老的抗体类别。分泌型 IgM 由五个 Y 形单体和一条 J 链连成五聚体，有 10 个抗原结合部位；单个结合部位的亲和力常常较低（此时应答尚未发生亲和力成熟），但 10 价的亲合力弥补了这一点（§9.5.3），因此 IgM 特别适合结合多价重复的抗原，如细菌多糖和红细胞上的血型抗原。IgM 激活经典途径的能力是五类中最强的：一个五聚体结合在抗原表面时，即可提供足够靠近的多个 Fc 去结合 C1q（[7.15.10](/7.15.10)）。分子大，主要局限在血管内。膜型 IgM 是单体，与 IgD 一起构成成熟初始 B 细胞的 **B 细胞受体**。

**定义 9.3.2（J 链与分泌型 IgA）** **J 链**是浆细胞合成的一条短的多肽，使 IgM 单体连成五聚体、IgA 单体连成二聚体。**分泌型 IgA**（sIgA）是黏膜表面的 IgA 二聚体：J 链连接的二聚体先与上皮细胞基底侧的多聚免疫球蛋白受体结合，经转胞吞作用运送到管腔面，受体的胞外部分被切下，留在 IgA 上成为分泌片。

IgA 是产量最大的抗体（人每天约 $3$–$5\ \mathrm{g}$），其中的绝大部分以分泌型存在于肠道、呼吸道、泌尿生殖道的黏膜和乳汁、唾液与泪液中。分泌片保护 IgA 免于消化酶的降解。sIgA 以中和与"免疫排除"的方式作用：结合病原体与毒素，阻止它们黏附上皮，使其连同黏液一起被排出，而不引起炎症（[7.15.23](/7.15.23)）。IgA 不激活经典途径，也很少引起炎症，这与它所处的环境——大量共生微生物与食物抗原——相适应。

IgD 在血清中含量极少，其主要功能是作为成熟 B 细胞的表面受体，与 IgM 同时表达；它与 B 细胞成熟和对抗原的反应阈值有关，但分泌型 IgD 的作用还不清楚。

IgE 在血清中的含量最低，但它的亲和力很高：IgE 的 Fc 与肥大细胞、嗜碱性粒细胞表面的高亲和力受体 FcεRI 结合，$K_\mathrm{D}$ 约为 $10^{-10}\ \mathrm{M}$，所以细胞表面的 IgE 保存数周。抗原使细胞表面的 IgE 交联，引起脱颗粒（[7.15.26](/7.15.26)）。这个机制的正常功能是抗蠕虫寄生虫和对昆虫毒液、毒素的防御，在没有寄生虫的环境里，它主要造成过敏症。

## 9.4. V 区与 C 区的功能

抗体的两部分各司其职：

- V 区识别并特异性结合抗原。仅靠这一项就能完成中和：抗体结合毒素，阻止其与细胞受体结合；结合病毒或细菌表面的黏附分子，阻止其感染或定植；结合酶的活性位点，抑制其活性。中和不需要 Fc，Fab 片段即可完成，这也是 Fab 与 scFv 可用作药物的原因。
- C 区，具体说是 Fc，决定抗体结合之后发生什么：

| 效应 | 抗体与 Fc 的位置 | 效果 |
|---|---|---|
| 激活补体 | IgM、IgG（$\mathrm{C_H2}$ 或 $\mathrm{C_H3}$ 结合 C1q） | 溶解、调理与炎症（[7.15.10](/7.15.10)） |
| 调理作用 | IgG 的 Fc 结合吞噬细胞的 **Fc 受体**（FcγR）；与 C3b 协同 | 增强吞噬与杀伤（[7.15.7](/7.15.7)） |
| ADCC | IgG 的 Fc 结合 NK 细胞的 FcγRIII（CD16） | NK 细胞杀伤被抗体包被的靶细胞（[7.15.21](/7.15.21)） |
| 肥大细胞脱颗粒 | IgE 的 Fc 结合 FcεRI | 速发型超敏反应、抗寄生虫（[7.15.26](/7.15.26)） |
| 跨上皮转运 | IgA、IgM 经多聚免疫球蛋白受体；IgG 经 FcRn | 黏膜分泌；母体抗体的传递 |
| 半衰期 | IgG 经 FcRn 的再循环 | 数周的血清持续时间 |

V 区与 C 区的这种分离，是抗体能够同时满足"特异性无限"与"效应有限"的原因：只有少数几种效应，但它们能通过任何一个特异性去调用。**类别转换重组**（[7.15.12](/7.15.12)）只更换 C 区、保留 V 区，使同一个特异性可以先后用 IgM、IgG、IgA 或 IgE 去执行，由 T 细胞分泌的细胞因子决定选哪一种（[7.15.20](/7.15.20)）。

## 9.5. 抗原抗体结合的定量

### 9.5.1. 一个结合部位的亲和力

抗体与抗原的结合与任何蛋白质与配体的结合一样，靠氢键、静电作用、范德华力与疏水作用等非共价作用维持，可逆，服从质量作用定律（[7.1.7](/7.1.7)）。

**定义 9.5.1（亲和力）** 抗体的**一个**抗原结合部位与**一个**表位之间结合的强度称为**亲和力**，用解离常数 $K_\mathrm{D}$ 度量：$K_\mathrm{D}$ 越小，亲和力越高。

设游离抗体浓度为 $c$（抗原的量远小于抗体，使游离浓度基本不变），表位被占据的比例为

$$
\theta = \frac{c}{K_\mathrm{D} + c}, \tag{9.1}
$$

$c = K_\mathrm{D}$ 时恰有一半表位被占据。动力学上，$K_\mathrm{D} = k_\mathrm{off}/k_\mathrm{on}$：抗原抗体结合的 $k_\mathrm{on}$ 通常在 $10^{5}$–$10^{6}\ \mathrm{M^{-1}\,s^{-1}}$ 之间，相差不大，亲和力的差别主要来自 $k_\mathrm{off}$——高亲和力的复合物解离得慢（半衰期 $\ln 2/k_\mathrm{off}$ 可达数小时到数天）。初次应答中产生的抗体的 $K_\mathrm{D}$ 约为 $10^{-6}$–$10^{-7}\ \mathrm{M}$；经过**体细胞高频突变**与选择产生的**亲和力成熟**之后，可达 $10^{-9}$–$10^{-11}\ \mathrm{M}$（[7.15.20](/7.15.20)）。

实验上常用 Scatchard 作图测定结合部位数与亲和力。设一个抗体分子有 $n$ 个相同而独立的结合部位，平均每个抗体结合 $r$ 个抗原，则 $r = nc/(K_\mathrm{D} + c)$，改写成

$$
\frac{r}{c} = \frac{n - r}{K_\mathrm{D}}. \tag{9.2}
$$

以 $r/c$ 对 $r$ 作图应得一条直线，斜率为 $-1/K_\mathrm{D}$，在横轴上的截距为 $n$。多克隆抗体是许多不同亲和力的抗体的混合物，Scatchard 图向上凹（图 B）：高亲和力的抗体在低 $r$ 时占优，低亲和力的抗体在高 $r$ 时才表现出来。

### 9.5.2. 二价抗体的亲合力

天然抗体几乎总是多价的（IgG 有 2 个结合部位，IgM 有 10 个），而细菌与细胞表面的抗原也往往以多个拷贝排布。多价抗体同时结合多个表位时的总体结合强度比单个结合部位强得多。

**定义 9.5.2（亲合力）** 多价抗体与多价抗原之间总的结合强度称为**亲合力**，它既取决于每个结合部位的亲和力，也取决于价数与几何匹配。

中文教材把 affinity 与 avidity 分别译作"亲和力"与"亲合力"，二者读音相近而含义不同，要小心区分：前者是一个部位对一个表位，后者是整个分子对整个抗原。下面用一个简单模型看亲合力怎样产生。设二价抗体的一个臂已经结合抗原表面的一个表位，另一个臂就被束缚在表面附近，它遇到第二个表位的机会，等价于在该臂周围有一个很高的"有效浓度" $c_\mathrm{eff}$，其大小取决于表位的密度与间距和铰链的长度，一般在毫摩尔量级。第二个臂的结合平衡为 $[\text{双臂}]/[\text{单臂}] = c_\mathrm{eff}/K_\mathrm{D}$，所以结合的总量与游离量之比增加了 $1 + c_\mathrm{eff}/K_\mathrm{D}$ 倍，表观解离常数为

$$
K_\mathrm{D}^\text{app} = \frac{K_\mathrm{D}}{1 + c_\mathrm{eff}/K_\mathrm{D}} \approx \frac{K_\mathrm{D}^2}{c_\mathrm{eff}} \qquad (c_\mathrm{eff} \gg K_\mathrm{D}). \tag{9.3}
$$

**例 9.5.1** 取 $K_\mathrm{D} = 10^{-7}\ \mathrm{M}$、$c_\mathrm{eff} = 10^{-3}\ \mathrm{M}$，增强因子为 $1 + 10^{4}$，$K_\mathrm{D}^\text{app} \approx 10^{-11}\ \mathrm{M}$：亲合力比单个部位的亲和力高了四个数量级。若部位的亲和力低 100 倍（$K_\mathrm{D} = 10^{-5}\ \mathrm{M}$），则 $K_\mathrm{D}^\text{app} = 10^{-5}/101 \approx 10^{-7}\ \mathrm{M}$，等于一个高亲和力单价部位。

结论有两点：（1）$K_\mathrm{D}^\text{app}$ 与 $K_\mathrm{D}^2$ 成正比，所以亲合力对亲和力有"平方"的放大：亲和力差 10 倍的两个抗体，二价结合后表观差 100 倍；（2）价数可以补偿亲和力：初次应答中亲和力低的 IgM 靠 10 价的亲合力有效地结合重复抗原。后者也解释了一个常见现象：Fab 片段（单价）比完整的 IgG（二价）结合细胞表面抗原的能力弱得多，而在溶液中结合单价抗原时二者相近。亲合力也使抗体能区分表位的密度：只有表位足够密、间距合适的表面才能被二价抗体"拉紧"。

### 9.5.3. 免疫复合物与等价带

**定义 9.5.3（免疫复合物）** 抗原与抗体结合形成的复合物称为**免疫复合物**。

当抗体与抗原都是多价的，免疫复合物可以长成大的交联网络。早在 20 世纪 30 年代，Heidelberger 与 Kendall 就发现：固定抗体量，逐渐增加抗原量，沉淀物先增加后减少，最大处称为等价带，两侧分别是抗体过剩区与抗原过剩区。用模型可以理解这条沉淀曲线：设二价抗体与 $n$ 价抗原结合很紧，结合部位数之比为 $\rho$（抗体部位数 / 抗原表位数）；抗原过剩（$\rho < 1$）时所有抗体部位都被占据，被占据的表位比例 $p_\mathrm{B} = \rho$，$p_\mathrm{A} = 1$；抗体过剩（$\rho > 1$）时反之，$p_\mathrm{A} = 1/\rho$，$p_\mathrm{B} = 1$。按 Flory–Stockmayer 的聚合物凝胶理论，当

$$
(n-1)\,p_\mathrm{A}\,p_\mathrm{B} > 1 \tag{9.4}
$$

时，网络能无限延伸，形成沉淀。由此得到：抗原过剩时要求 $\rho > 1/(n-1)$，抗体过剩时要求 $\rho < n-1$，$\rho = 1$ 处最大。因此沉淀区是以 $\rho = 1$ 为中心的一段，$n$ 越大越宽；$n \le 2$ 的抗原（如半抗原，或只有两个表位的分子）无论比例如何都不能被二价抗体沉淀成网络，只能形成短链。真实曲线比这个模型平滑，因为分子内成环、构象限制与亲和力有限都使网络受损，但等价带和两侧的"带"这些定性特征是稳固的。

等价带有重要的生物学与医学意义：

- 抗体过剩区与等价带的大型复合物易被补体与吞噬细胞清除；抗原过剩区的复合物小而可溶，不易被清除，长时间在循环中，沉积在血管壁与肾小球基底膜，引起血清病、免疫复合物肾炎和某些自身免疫病的组织损伤（[7.15.27](/7.15.27)）。
- 在免疫学检测中，抗原极度过量时沉淀或凝集反应反而变弱，称为后带（钩状）效应，可以造成假阴性（[7.15.34](/7.15.34)）。

## 9.6. 人工抗体与治疗性抗体

### 9.6.1. 多克隆抗体与单克隆抗体

用抗原免疫动物，血清中的抗体是识别同一抗原不同表位、由许多 B 细胞克隆产生的混合物，即**多克隆抗体**。它对天然抗原的结合强，但批次间有差别，难以大量重复生产。Köhler 与 Milstein（1975；1984 年诺贝尔奖）解决了这个问题：把免疫动物的 B 细胞与骨髓瘤细胞融合，得到既能产生抗体、又能在体外无限增殖的**杂交瘤**（[7.3.3](/7.3.3)），挑选出产生所需抗体的单个克隆，就得到只识别一个表位的**单克隆抗体**（[7.1.7](/7.1.7)）。选择的原理是代谢缺陷：骨髓瘤细胞缺少补救途径中的一个酶，在阻断从头合成途径的培养基中只有与 B 细胞融合的细胞能活，而未融合的 B 细胞自己不能长期增殖。

单克隆抗体特异性单一、均一、可以无限供应，成为免疫学检测、免疫组织化学与流式细胞术的基本工具（[7.15.34](/7.15.34)）。作为药物则有一个问题：小鼠抗体对人是异种蛋白，会引起抗小鼠抗体的应答，既中和药物，又易引起过敏反应，而且小鼠 Fc 在人体内不能有效地激活效应，半衰期也短。

### 9.6.2. 基因工程抗体

克服这个问题的办法是用重组 DNA 技术逐步把抗体"人源化"。抗体的这种可以拆装的结构（V 区与 C 区分离，CDR 与框架区分离）是它们可以被这样改造的基础。

**定义 9.6.1（嵌合抗体与人源化抗体）** 把小鼠抗体的 V 区与人抗体的 C 区连接起来得到的抗体称为**嵌合抗体**；进一步把小鼠抗体的 CDR 移植到人抗体的框架区之中，只保留小鼠序列中直接接触抗原的部分，得到的抗体称为**人源化抗体**。

人源化抗体的小鼠序列只占 5%–10%，免疫原性大大降低。进一步，用带有人免疫球蛋白基因的转基因小鼠免疫，或用噬菌体展示等体外方法从人抗体基因库中按结合能力筛选，可得到全人源抗体。治疗性抗体的名称后缀反映了它的来源：-omab 为小鼠，-ximab 为嵌合，-zumab 为人源化，-umab 为全人源。

**定义 9.6.2（双特异性抗体）** 两个结合部位识别不同抗原（或同一抗原上不同表位）的人工抗体称为**双特异性抗体**。

天然抗体的两个臂是相同的；双特异性抗体通过基因工程使两个臂不同，其中一个用途是桥接两个细胞：一臂结合肿瘤细胞的表面抗原，另一臂结合 T 细胞的 CD3，使 T 细胞靠近并杀伤肿瘤细胞，不需要这个 T 细胞的 TCR 识别肿瘤抗原（[7.15.30](/7.15.30)）；另一个用途是在同一个分子上模拟两个蛋白质的联合作用（例如同时结合凝血因子 FIXa 与 FX 的抗体，替代血友病 A 中缺失的 FVIIIa 的桥接功能）。

**定义 9.6.3（纳米抗体）** 骆驼科动物（和鲨鱼）天然产生的只有重链的抗体，其单个可变区（VHH）可以独立结合抗原，把它单独表达得到的约 $15\ \mathrm{kDa}$ 的片段称为**纳米抗体**（单域抗体）。

纳米抗体体积小、稳定、能结合 IgG 的 CDR 难以进入的凹陷（如酶的活性位点），也容易与其他结构域融合。此外还有单链抗体片段（scFv，把 $\mathrm{V_H}$ 与 $\mathrm{V_L}$ 用一段柔性肽连接）、Fab 与 $\mathrm{F(ab')_2}$ 等片段，用作药物、成像探针、或嵌合抗原受体的识别模块（[7.15.30](/7.15.30)）。

| 类型 | 构成 | 特点与用途 |
|---|---|---|
| 多克隆抗体 | 许多克隆的混合物 | 结合天然抗原好；批次间有差异；多用于检测与被动免疫 |
| 单克隆抗体（小鼠） | 杂交瘤的单个克隆 | 特异性均一；对人有免疫原性 |
| 嵌合抗体 | 小鼠 V + 人 C | 保留 Fc 的效应；免疫原性较低 |
| 人源化抗体 | 小鼠 CDR + 人框架与 C | 免疫原性更低 |
| 全人源抗体 | 转基因小鼠或体外展示 | 免疫原性最低 |
| 双特异性抗体 | 两个不同的结合部位 | 桥接两个细胞或两个分子 |
| 纳米抗体、scFv、Fab | 单个或少数结构域 | 体积小，穿透性好；半衰期短，无 Fc 效应 |

### 9.6.3. 治疗性抗体的作用原理

抗体药物的作用原理可以用 §9.4 的分工来归纳：

- 单纯结合（V 区）：中和细胞因子或其受体（抗 TNF、抗 IL-6 受体、抗 IgE），或阻断受体与配体的相互作用，如阻断**免疫检查点**（抗 PD-1、抗 CTLA-4，[7.15.25](/7.15.25)）与生长因子信号（抗 VEGF、抗 HER2）。
- 清除靶细胞（Fc）：结合肿瘤细胞或 B 细胞表面的抗原（如 CD20、HER2），通过 ADCC、补体依赖的细胞毒作用与抗体依赖的吞噬杀伤清除（[7.15.21](/7.15.21)）；Fc 的糖基化可被改造，增强它与 FcγRIII 的结合。
- 作为载体：抗体偶联细胞毒性药物，把药物带给表达靶抗原的细胞；或与放射性核素偶联。
- 桥接免疫细胞：双特异性抗体（见上）。
- 被动免疫：直接给予针对病原体或毒素的抗体，立即提供保护，不依赖受者自己产生应答（[7.11.28](/7.11.28)）：如抗蛇毒血清、抗破伤风免疫球蛋白，以及对呼吸道合胞病毒的单克隆抗体。
- 延长半衰期：通过改造 Fc 与 FcRn 的结合，使抗体半衰期延长。

## 思考题

1. 为什么一个 B 细胞克隆的抗体可以在保持 V 区不变的情况下从 IgM 变成 IgG 或 IgA？这对抗体应答有什么好处？

   **答** 抗体的结构把 V 区与 C 区分开，二者由不同的基因片段编码；类别转换重组在 DNA 水平上把已重排的 V(D)J 外显子换接到另一个 C 基因上（[7.15.12](/7.15.12)），抗原结合部位不变，效应改变。好处是同一个特异性可以按需要去调用最合适的效应：在血管内用 IgM 激活补体，在组织内用 IgG 调理，在黏膜上用 IgA，对寄生虫用 IgE；选择哪一类由 T 细胞的细胞因子决定。

2. 用木瓜蛋白酶与胃蛋白酶分别处理 IgG，得到的片段在结合抗原的能力上有什么不同？为什么 $\mathrm{F(ab')_2}$ 能沉淀抗原而 Fab 不能？

   **答** 木瓜蛋白酶在铰链区重链链间二硫键的 N 端侧切开，得到两个单价的 Fab 与一个 Fc；胃蛋白酶在二硫键的 C 端侧切开，两个 Fab 仍由二硫键相连，得到二价的 $\mathrm{F(ab')_2}$，保持了交联能力，两者都没有 Fc 的效应功能。沉淀需要形成交联网络，每个抗体至少要有两个结合部位（式 (9.4) 以二价抗体为前提），Fab 是单价的，不能交联，所以不沉淀。

3. 一种抗体的单个部位 $K_\mathrm{D} = 10^{-8}\ \mathrm{M}$。设二价结合时 $c_\mathrm{eff} = 10^{-3}\ \mathrm{M}$，用式 (9.3) 估计二价结合的 $K_\mathrm{D}^\text{app}$。如果 $c_\mathrm{eff}$ 因抗原表位稀疏降低为 $10^{-6}\ \mathrm{M}$，结果怎样？

   **答** 第一种情形，$c_\mathrm{eff}/K_\mathrm{D} = 10^5$，$K_\mathrm{D}^\text{app} = 10^{-8}/(1 + 10^5) \approx 10^{-13}\ \mathrm{M}$。第二种情形，$c_\mathrm{eff}/K_\mathrm{D} = 100$，$K_\mathrm{D}^\text{app} = 10^{-8}/101 \approx 10^{-10}\ \mathrm{M}$。表位稀疏时仍有增益，但小了三个数量级；极端情形是表位间距超过两个臂能跨越的距离，$c_\mathrm{eff} \to 0$，二价结合不可能，亲合力就退回到单价的亲和力。

4. 为什么在免疫检测中，抗原极度过量时沉淀反应反而变弱？如何避免由此造成的假阴性？

   **答** 抗原过剩时每个抗体的两个部位各自结合不同的抗原分子，抗原的表位被占满而没有空余的抗体去搭桥，只形成小而可溶的复合物（$\rho \ll 1$，式 (9.4) 的左端小于 1）。把样品稀释后再测，使抗原量回到等价带附近；同时测多个稀释度，可以发现这种后带效应。

5. （开放题）对比 IgG 与 IgM 作为治疗性抗体可能的应用，说明二者各自的优势与限制。

   **答** 思路：IgG 的半衰期长（FcRn 再循环）、能进入组织、有成熟的人源化与工程改造平台，效应（ADCC、补体、调理）可通过 Fc 改造调整，因此是目前绝大多数抗体药物的形式。IgM 有 10 价，亲合力高，补体激活能力强，适合结合低亲和力、高密度重复的抗原（如聚糖），但分子大（$970\ \mathrm{kDa}$），穿透组织差，半衰期短，难以生产和稳定制剂，目前用得少。设计上可以用 IgG 的 Fc 与多价（如四价）的结合模块折中。
