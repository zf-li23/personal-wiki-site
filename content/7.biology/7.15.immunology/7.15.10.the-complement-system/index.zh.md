[7.15.9](/7.15.9) 说明抗体的 V 区识别、C 区调用效应；补体是被调用的主要效应系统之一，也是固有免疫中最古老的体液效应系统。它回答知识路径上"用什么效应清除"（[7.15.1](/7.15.1)）的又一个答案：一系列血浆蛋白依次被活化，在病原体表面形成酶促放大的级联，结果有三：标记病原体供吞噬细胞清除，产生趋化与炎症信号，在某些靶细胞的膜上打孔。补体沟通了固有免疫（识别糖类模式的凝集素、不依赖抗体的旁路途径）与适应性免疫（抗体激活的经典途径，反过来补体片段又降低 B 细胞的活化阈值），也是[7.15.7](/7.15.7) 中调理作用与炎症的主要执行者。

补体系统由三十余种蛋白质组成，名称纷繁，但骨架只有一条：C3 是中心，三条途径各自产生 C3 转化酶，转化酶切开 C3，C3b 共价沉积到表面，后者既标记表面，又生成更多转化酶，最后一路走到攻膜复合体。这条主线加上调节（宿主表面怎样避免被攻击）就是本章的内容。

## 10.1. 补体的组成与性质

**定义 10.1.1（补体）** **补体**是存在于血浆和组织液中、也有部分表达在细胞膜上的一组蛋白质（三十余种），它们通常以无活性的前体形式存在，在病原体表面或抗原抗体复合物上被依次活化，形成酶促级联，发挥溶解、调理、炎症等效应。

补体最初是 Bordet 在 19 世纪末发现的血清中一种热不稳定（$56\ \mathrm{^\circ C}$、30 min 灭活）、能"补充"抗体溶菌作用的成分，Ehrlich 因此称之为补体。血浆中补体蛋白约占球蛋白的 5%，主要由肝细胞合成，单核细胞、巨噬细胞与上皮细胞也在局部合成。补体成分的血浆浓度相差很大，C3 最多，约 $1\ \mathrm{mg\,mL^{-1}}$。

补体的命名有历史的痕迹：

- 以 C 加数字命名的成分 C1–C9 按发现顺序编号，而不是反应顺序：C4 在 C2 之前反应。
- 活化时蛋白被切开，小片段加 a（C3a、C4a、C5a），大片段加 b（C3b、C4b、C5b）；C2 的片段命名在文献中不统一，现在把大片段称为 C2b（旧称 C2a），由此 C4b2b 即旧称的 C4b2a。
- 旁路途径的成分用字母命名：B 因子、D 因子、P 因子（备解素）、H 因子、I 因子。
- 被切割或结合后获得活性的复合物，在成分编号上加横线或写在一起（C4b2b、C3bBb）。

| 类别 | 成分 | 作用 |
|---|---|---|
| 经典途径 | C1（C1q、C1r、C1s）、C4、C2 | 识别抗体，产生 C3 转化酶 C4b2b |
| 凝集素途径 | 甘露糖结合凝集素（MBL）、纤维胶凝蛋白（ficolin）、MASP-1、MASP-2 | 识别微生物糖类，产生 C4b2b |
| 旁路途径 | C3、B 因子、D 因子、P 因子 | 自发水解与放大，产生 C3bBb |
| 末端通路 | C5、C6、C7、C8、C9 | 形成攻膜复合体 |
| 调节蛋白 | C1 抑制物、C4 结合蛋白、H 因子、I 因子、DAF（CD55）、MCP（CD46）、CR1（CD35）、CD59 | 限制活化与保护自身（§10.5） |
| 受体 | CR1、CR2（CD21）、CR3（CD11b/CD18）、CR4（CD11c/CD18）、CRIg、C3aR、C5aR | 传递补体片段的信号（§10.4） |

## 10.2. 三条激活途径与末端通路

### 10.2.1. 三条途径的启动

三条途径的区别在于怎样识别，以及先由谁产生 C3 转化酶。

**定义 10.2.1（补体的三条激活途径）** 由抗体与抗原结合形成的复合物启动的称为**经典途径**；由微生物表面的糖类被识别分子结合而启动的称为**凝集素途径**；不依赖抗体和凝集素、由 C3 的自发水解与微生物表面的沉积而启动的称为**旁路途径**。凝集素途径中的识别分子主要是**甘露糖结合凝集素**（MBL）与纤维胶凝蛋白。

经典途径从 C1 开始。C1 是一个复合物，由六个头部的 C1q 与两个 C1r、两个 C1s 组成。C1q 的球状头部结合 IgM 或 IgG（以 IgG3、IgG1 为主，IgG2 较弱）Fc 上的 $\mathrm{C_H2}$（IgM 为 $\mathrm{C_H3}$）：单个 IgG 的结合太弱，需要至少两个 IgG 的 Fc 彼此靠近地结合在同一抗原表面，一个 IgM 五聚体结合在表面时本身就提供了这种靠近的 Fc，这就是 IgM 激活补体最强的原因。C1q 也能直接结合 C 反应蛋白（CRP）、凋亡细胞与某些细菌表面。C1q 的构象变化使 C1r 自身激活，激活的 C1r 切割 C1s，C1s 切割 C4 与 C2：C4 被切成 C4a 与 C4b，C4b 暴露的硫酯键与附近表面共价结合；C2 随后与 C4b 结合并被 C1s 切开，大片段 C2b 留在 C4b 上，形成 C4b2b。

凝集素途径与经典途径汇合于 C4 与 C2。MBL 与纤维胶凝蛋白结合微生物表面重复排列的甘露糖、岩藻糖、$N$-乙酰葡糖胺（哺乳动物细胞表面的糖链末端是唾液酸与半乳糖，不被识别），与它们结合的丝氨酸蛋白酶 MASP-2 切割 C4 与 C2，形成同样的 C4b2b。这条途径不需要抗体，在抗体出现之前就起作用，是固有免疫的一部分（模式识别，见 [7.15.6](/7.15.6)）。

旁路途径不需要任何识别分子。血浆中的 C3 含有一个内部的硫酯键，会以很低的速率自发水解（"空转"，tick-over），水解的 C3（$\mathrm{C3(H_2O)}$）与 B 因子结合，D 因子切割 B，形成液相的 C3 转化酶，切割 C3 产生 C3b。C3b 的硫酯键暴露后，能与附近表面上的氨基或羟基共价结合；在表面上它再结合 B 因子，D 因子切割 B，形成表面的 C3bBb，P 因子（备解素）结合并稳定它（半衰期从约 90 s 延长数倍）。在缺少调节蛋白的微生物表面，这一过程一旦开始就自我放大（§10.3.2）；在宿主细胞表面，调节蛋白使它迅速终止。

### 10.2.2. C3 转化酶

**定义 10.2.2（C3 转化酶）** 能把 C3 切割成 C3a 和 C3b 的酶复合物称为 **C3 转化酶**：经典与凝集素途径的 C4b2b，旁路途径的 C3bBb。

两种转化酶的结构类似：都由一个共价结合在表面的大片段（C4b 或 C3b）与一个带蛋白酶活性的片段（C2b 或 Bb）组成，酶活性中心在后者；它们很不稳定（半衰期不到 2 分钟），所以补体活化只发生在转化酶形成的局部，也很快自行终止，除非被稳定。

### 10.2.3. 共同的末端通路与攻膜复合体

C3 转化酶产生大量 C3b，其中一部分结合在转化酶自身上，形成 C4b2b3b 或 C3bBb3b，这就是 C5 转化酶：它们切割 C5，产生 C5a（可溶，是强的过敏毒素与趋化因子）和 C5b。C5b 暂时稳定，结合 C6，再结合 C7，C7 的构象变化使复合物暴露疏水区，插入附近的膜；C8 结合后插入膜得更深；最后 C8 招募多个 C9。

**定义 10.2.3（攻膜复合体）** C5b、C6、C7、C8 与多个（10–16 个）C9 在靶细胞膜上装配成的跨膜孔道称为**攻膜复合体**（MAC，$\mathrm{C5b\text{–}9}$）。

C9 聚合成环，形成内径约 $10\ \mathrm{nm}$ 的中空孔，使离子和水自由通过，细胞因渗透压失衡而裂解。C6–C9 的结构域与穿孔素（[7.15.21](/7.15.21)）和细菌的孔形成毒素同属一个膜攻击蛋白家族。攻膜复合体对革兰氏阴性菌有杀伤作用（孔穿过外膜并损伤内膜），对有包膜的病毒、部分寄生虫和某些肿瘤细胞也有效；革兰氏阳性菌的厚肽聚糖层使孔无法到达膜，补体对它们的作用主要是调理。有核的宿主细胞对攻膜复合体有一定的抵抗：CD59 阻止 C9 的聚合（§10.5），并且孔可被内吞或脱落清除。缺乏末端成分（C5–C9）的人，主要问题是反复的奈瑟菌感染（脑膜炎奈瑟菌与淋病奈瑟菌），说明攻膜复合体的杀菌作用对这类革兰氏阴性球菌特别重要，而对其他细菌，调理作用已经足够（§10.6）。

## 10.3. C3 的核心地位与放大环

### 10.3.1. C3 与 C3b 的命运

三条途径汇聚在 C3，是因为 C3 同时是浓度最高的成分和所有效应的来源。C3 是由 α 与 β 两条链组成的蛋白质（约 $185\ \mathrm{kDa}$），α 链中有一个由半胱氨酸与谷氨酰胺侧链形成的内部硫酯键。被转化酶切割时，α 链的 N 端释放出 C3a（约 $9\ \mathrm{kDa}$），其余部分的构象变化使硫酯键暴露，成为强的亲电试剂：在约 $100\ \mathrm{\mu s}$ 内，它要么与水反应（C3b 失活），要么与附近表面的亲核基团共价结合。这个极短的寿命限制了 C3b 的扩散，使它只沉积在转化酶周围的几十纳米之内，也就是补体被活化的那个表面上。

沉积在表面的 C3b 有三种命运：（1）作为调理素，被吞噬细胞上的 CR1、CR3 等受体识别（§10.4）；（2）与转化酶结合，形成 C5 转化酶，推动末端通路；（3）与 B 因子结合，生成新的 C3bBb，使沉积自我放大。最后，I 因子在 H 因子等辅助因子的帮助下把 C3b 切成无活性的 iC3b，iC3b 仍是 CR3、CR4 的配体，继续促进吞噬，再被降解为 C3dg 与 C3d，后者是 B 细胞上 CR2（CD21）的配体，把补体与适应性免疫联系起来。

### 10.3.2. 一个模型：旁路途径的放大与阈值

放大环使补体成为一个有阈值的系统：微生物表面一旦跨过阈值，C3b 的沉积就快速爆发；宿主表面则被调节蛋白保持在低水平。用一个简单的方程可以说明这一点。设表面上 C3b 的密度为 $x$（以产生半数最大放大时的密度为单位），则

$$
\frac{\mathrm{d}x}{\mathrm{d}t} = s + a\,\frac{x^2}{1 + x^2} - \delta x. \tag{10.1}
$$

三项分别是：$s$，C3 空转提供的基础沉积；$a\,x^2/(1+x^2)$，转化酶驱动的沉积——转化酶的数量随 $x$ 增加，而 C3b 在表面成簇、被备解素稳定使得这一正反馈是协同的（用 Hill 指数 2 表示），并有上限（受表面可用的受体位点与 B 因子限制）；$\delta x$，I 因子与辅助因子（H 因子、CR1、MCP）使 C3b 失活的速率，$\delta$ 的大小取决于表面上调节蛋白的多少。这是 [2.4](/2.4) 中一维自治常微分方程的典型例子，正反馈与失活的竞争在 [7.9.15](/7.9.15) 与 [7.9.16](/7.9.16) 中有一般的讨论。

忽略 $s$（$s \ll a$），非零稳态满足 $\delta x^2 - a x + \delta = 0$，即

$$
x_\pm = \frac{a \pm \sqrt{a^2 - 4\delta^2}}{2\delta}. \tag{10.2}
$$

它们只在 $\delta \le a/2$ 时存在：$x_-$ 是不稳定的阈值，$x_+$ 是稳定的高沉积状态；$x = 0$（实际上是 $x \approx s/\delta$）是稳定的低沉积状态。$\delta > a/2$ 时只剩低状态，任何初始沉积都衰减；$\delta$ 太小时 $x \approx s/\delta$ 的低状态也不再存在（要求 $\delta^2 \ge 4as$，即 $\delta \ge 2\sqrt{as}$），因为基础沉积自己就能引发爆发。因此有三个区域：

| $\delta$ 的范围 | 状态 | 对应的表面 |
|---|---|---|
| $\delta > a/2$ | 只有低沉积态，任何扰动都消退 | 正常宿主细胞（调节蛋白丰富） |
| $2\sqrt{as} < \delta < a/2$ | 双稳：低态与高态共存，初始剂量越过阈值 $x_-$ 就爆发 | 受损的细胞或调节不足的表面 |
| $\delta < 2\sqrt{as}$ | 只有高沉积态，空转即可引发爆发 | 缺乏调节蛋白的微生物 |

取 $a = 3$、$s = 0.02$，两个分界值为 $\delta = 1.5$ 与 $\delta = 2\sqrt{0.06} \approx 0.49$（图 B 中的折点）。$\delta = 1$ 时，由式 (10.2)，阈值 $x_- = (3 - \sqrt{5})/2 \approx 0.38$，高状态 $x_+ = (3 + \sqrt{5})/2 \approx 2.62$：从 $x_0 = 0.3$ 出发的轨迹衰减回低态，从 0.6 出发的则跳到高态（图 A 中的虚线与实线）。

这个模型是一个定性的简化：它把 C3、B 因子的消耗和表面的几何都合并成一个饱和项，没有区分液相与表面反应，也没有 H 因子在宿主表面的选择性结合。但它抓住了本质：补体对表面的"判断"并不是靠识别病原体的分子，而是靠表面上调节蛋白的有无，使正反馈的增益大于或小于失活（§10.5）。

## 10.4. 补体的生物学功能

补体活化的产物各有各的作用，可以按这些产物归纳：

| 产物 | 效应 | 机制 |
|---|---|---|
| 攻膜复合体 | 溶解靶细胞 | 在膜上形成孔道（§10.2.3） |
| C3b、iC3b、C4b | 调理作用 | 被吞噬细胞的补体受体识别，促进吞噬（[7.15.7](/7.15.7)） |
| C3a、C5a（C4a 很弱） | 炎症 | 过敏毒素，激活肥大细胞、内皮细胞、平滑肌；C5a 还是中性粒细胞的趋化因子 |
| C3b 结合在免疫复合物上 | 清除免疫复合物 | 红细胞上的 CR1 携带复合物到肝脾，由巨噬细胞清除 |
| C3d | 增强 B 细胞应答 | 与 CR2（CD21）结合，降低 B 细胞的活化阈值 |
| C1q | 清除凋亡细胞 | 直接识别凋亡细胞表面，促进胞葬 |

**定义 10.4.1（补体受体）** 与补体活化片段结合、介导补体生物学效应的细胞表面分子称为**补体受体**：CR1（CD35）结合 C3b、C4b；CR2（CD21）结合 C3d；CR3（CD11b/CD18）与 CR4（CD11c/CD18）是整联蛋白，结合 iC3b；CRIg 在肝巨噬细胞上结合 C3b；C3aR 与 C5aR 是结合 C3a 与 C5a 的 G 蛋白偶联受体。

**定义 10.4.2（过敏毒素）** 补体活化产生的小片段 C3a、C4a 和 C5a 能引起平滑肌收缩、血管通透性增加和肥大细胞脱颗粒，称为**过敏毒素**，其中 C5a 最强。

调理作用是补体在体内最重要的功能：吞噬细胞表面的 CR1 与 CR3 结合 C3b、iC3b，使被它们包被的微生物容易被摄入（在 CR3 上，整联蛋白的信号还需要其他受体同时作用才触发吞噬）。凝集素与旁路途径产生的 C3b 在抗体出现之前就覆盖病原体，所以补体是固有免疫中调理作用的主要体液成分。C5a 与 C3a 通过 C5aR 与 C3aR 激活内皮和白细胞，是急性炎症的重要参与者；它们的炎症作用过强是休克与器官损伤的原因之一（[7.15.7](/7.15.7)）。免疫复合物沉积时，C3b 通过 CR1 被红细胞携带到肝脾；早期成分（C1q、C2、C4）缺陷的人不能清除免疫复合物，容易发生系统性红斑狼疮，说明这一功能对避免自身免疫的重要性。

补体对适应性免疫也有贡献。B 细胞上的 CR2（CD21）与 CD19、CD81 构成辅助受体复合体，抗原上共价结合的 C3d 同时交联 CR2 与 BCR，使 B 细胞的活化阈值降低约 1000 倍（[7.15.19](/7.15.19)、[7.15.20](/7.15.20)）；C3a、C5a 对树突状细胞与 T 细胞的作用也影响适应性免疫的方向。在神经系统，C1q 与 C3 参与小胶质细胞对突触的修剪，是补体的非免疫功能之一。

## 10.5. 补体的调节

补体系统的杀伤和炎症作用很强，而它的启动没有识别分子的选择性：旁路途径的 C3b 会与它碰到的任何表面共价结合，宿主细胞也不例外。因此必须有严格的调节，使补体只在需要的表面上持续进行。

**定义 10.5.1（补体调节蛋白）** 抑制补体活化各个步骤、使宿主的细胞和组织免受补体损伤的蛋白质称为**补体调节蛋白**。

| 调节蛋白 | 位置 | 作用的步骤 | 机制 |
|---|---|---|---|
| C1 抑制物（C1-INH） | 血浆 | C1、MASP | 丝氨酸蛋白酶抑制物，使 C1r、C1s 与 MASP 失活并从复合物中解离 |
| C4 结合蛋白 | 血浆 | C4b2b | 加速 C4b2b 的解离；I 因子切割 C4b 的辅因子 |
| H 因子 | 血浆，结合宿主表面 | C3bBb | 与 B 因子竞争结合 C3b，加速 C3bBb 解离；I 因子切割 C3b 的辅因子 |
| I 因子 | 血浆 | C3b、C4b | 丝氨酸蛋白酶，在辅因子（H 因子、C4 结合蛋白、MCP、CR1）作用下切割 C3b、C4b |
| DAF（CD55） | 细胞膜 | C3 转化酶 | 加速 C4b2b、C3bBb 的解离 |
| MCP（CD46） | 细胞膜 | C3b、C4b | 作为 I 因子的辅因子 |
| CR1（CD35） | 细胞膜 | C3b、C4b | 加速解离，也是辅因子 |
| CD59 | 细胞膜 | 攻膜复合体 | 结合 C8 与 C9，阻止 C9 聚合 |

调节有三种机制：使酶复合物解离（衰变加速）、使酶底物失活（由 I 因子切割，需要辅因子）、阻止末端复合物装配。宿主细胞靠膜上的 DAF、MCP、CR1 和 CD59 保护自己，同时靠表面的唾液酸与糖胺聚糖结合血浆中的 H 因子；病原体没有这些成分，其表面就是补体活化的靶。这也是旁路途径怎样"区分自我与非我"的答案：它并不识别病原体的某种分子，而是识别表面上缺少保护。式 (10.1) 中 $\delta$ 的大小正是这个意思。

## 10.6. 补体与疾病

### 10.6.1. 缺陷与过度活化

补体的缺陷和过度活化都引起疾病，缺陷的成分指出了它在体内的主要功能：

| 缺陷的成分 | 后果 | 说明 |
|---|---|---|
| C1q、C4、C2（早期成分） | 免疫复合物病、系统性红斑狼疮 | 不能清除免疫复合物与凋亡细胞 |
| C3 | 严重的反复化脓性细菌感染 | 调理作用丧失，最严重 |
| C5–C9、备解素 | 反复奈瑟菌感染 | 攻膜复合体对奈瑟菌的杀伤必不可少 |
| MBL | 轻微，婴幼儿感染增加 | 凝集素途径的缺陷，常见的多态性 |
| C1 抑制物 | 遗传性血管性水肿 | C1-INH 还抑制激肽系统，缓激肽过多使血管通透性增加 |
| H 因子、I 因子，或 MCP 突变 | 非典型溶血尿毒综合征、C3 肾小球病；加速老年黄斑变性 | 宿主表面的 C3 转化酶没有受到调节，损伤内皮与肾小球 |
| DAF、CD59（GPI 锚的缺失） | 阵发性睡眠性血红蛋白尿 | 红细胞失去保护，被补体溶解 |

过度活化出现在免疫复合物病（[7.15.27](/7.15.27)）、缺血再灌注损伤、移植排斥（超急性排斥时受者预存抗体激活补体，[7.15.29](/7.15.29)）与某些感染中的失控炎症。以补体为靶点的药物有：抗 C5 单克隆抗体（阻断 C5 转化酶的底物，用于阵发性睡眠性血红蛋白尿和非典型溶血尿毒综合征，因而需要预防奈瑟菌感染）、C3 抑制剂以及 C1 抑制物替代治疗。

### 10.6.2. 病原体的补体逃逸

补体对病原体是强大的选择压力，许多病原体因而进化出了逃逸的机制，大多是劫持宿主的调节蛋白，或直接抑制补体的酶（[7.11.34](/7.11.34)）：

- 募集宿主的调节蛋白：A 组链球菌的 M 蛋白、脑膜炎奈瑟菌的 H 因子结合蛋白和某些螺旋体的表面蛋白结合 H 因子；一些细菌用唾液酸包被自己（脑膜炎奈瑟菌、B 组链球菌的荚膜），模仿宿主表面的结合位点。
- 抑制补体酶：金黄色葡萄球菌的蛋白质结合并抑制 C3 转化酶，或使 C5a 受体失灵；
- 借用宿主的膜调节蛋白：HIV 与某些病毒在出芽时把 DAF、CD59 带进包膜；痘病毒编码补体调控蛋白的同源物。
- 阻止末端通路：革兰氏阳性菌的细胞壁、革兰氏阴性菌的 LPS 长链都使攻膜复合体不能接触到膜。

### 10.6.3. 进化起源

补体是最古老的体液免疫成分之一。C3 及其蛋白酶 B 因子在刺胞动物与棘皮动物中就已经存在，所以旁路途径（可能连同凝集素途径）是最古老的，而不依赖抗体的补体调理是无脊椎动物与无颌脊椎动物的基本免疫机制；七鳃鳗已有凝集素途径与 C3 调理，但没有抗体。经典途径随着有颌脊椎动物的抗体系统一同出现，使补体获得了特异性的识别：C1q 是胶原凝集素家族的成员，与 MBL 同源。补体的蛋白质家族关系也说明了这一点：C3、C4、C5 属于 α2-巨球蛋白家族，C6–C9 属于膜攻击复合物/穿孔素（MACPF）家族，而 C2 与 B 因子是同源的蛋白酶。

## 小结

| 主题 | 要点 |
|---|---|
| 组成（§10.1） | 三十余种蛋白质，以前体形式存在，按级联活化（定义 10.1.1）；a 为小片段，b 为大片段 |
| 三条途径（§10.2） | 经典（C1q 识别抗体）、凝集素（MBL、纤维胶凝蛋白）、旁路（C3 自发水解）（定义 10.2.1）；经典与凝集素产生 C4b2b，旁路产生 C3bBb，二者都是 C3 转化酶（定义 10.2.2） |
| 末端通路（§10.2.3） | C5 转化酶切割 C5；C5b 与 C6–C9 形成攻膜复合体（定义 10.2.3） |
| C3 的核心地位（§10.3） | C3b 通过硫酯键共价沉积，用于调理，生成 C5 转化酶并放大；旁路途径的正反馈使系统有阈值，式 (10.1)；$\delta$ 由调节蛋白决定 |
| 功能（§10.4） | 溶解、调理、过敏毒素（定义 10.4.2）、免疫复合物清除、C3d 增强 B 细胞应答；补体受体（定义 10.4.1） |
| 调节（§10.5） | 调节蛋白（定义 10.5.1）通过衰变加速、辅因子与阻止 MAC 装配保护宿主；病原体表面缺少保护是补体识别的依据 |
| 疾病（§10.6） | 缺陷（C1q/C4/C2 与自身免疫，C3 与化脓菌，末端成分与奈瑟菌）和过度活化；病原体劫持调节蛋白逃逸；补体是古老的免疫系统 |

## 思考题

1. 为什么补体级联要采用"酶促放大 + 级联"的结构？它带来的好处与风险各是什么？

   **答** 每一个活化的酶分子可以切割许多底物，几个级联步骤相乘，使很少的启动事件在很短的时间内产生大量效应分子；同时 C3b 的共价沉积使效应集中在病原体表面。风险是放大没有选择性：一旦在宿主表面启动，损伤也会放大，所以必须有多层调节：转化酶本身不稳定、C3b 寿命极短，宿主表面富含调节蛋白，旁路途径的识别靠"缺少保护"而非识别病原体分子。

2. 一名男孩反复发生脑膜炎球菌脑膜炎，其他细菌感染并不多。应优先检查补体的哪些成分？这种缺陷为什么不引起其他细菌的严重感染？

   **答** 应检查末端成分 C5–C9 与备解素（总补体活性 CH50 降低而旁路途径可能正常，缺 C3 者感染谱更广）。补体对多数细菌的作用主要靠调理（C3b、iC3b 与吞噬细胞），这条途径在末端成分缺陷时完好；奈瑟菌是革兰氏阴性球菌，主要靠攻膜复合体杀伤，吞噬后又能抵抗胞内杀伤，所以对攻膜复合体缺陷特别敏感。

3. 在式 (10.1) 中取 $a = 3$、$s = 0.02$，求 $\delta$ 在什么范围内系统是双稳的；$\delta = 1.2$ 时不稳定阈值 $x_-$ 与高稳态 $x_+$ 各是多少？这个结果对 H 因子缺陷有什么提示？

   **答** 双稳范围是 $2\sqrt{as} < \delta < a/2$，即约 $0.49 < \delta < 1.5$。$\delta = 1.2$ 时由式 (10.2)，$x_\pm = (3 \pm \sqrt{9 - 5.76})/2.4 = (3 \pm 1.8)/2.4$，即 $x_- = 0.5$、$x_+ = 2.0$。H 因子（或 MCP 等）缺陷使宿主表面的 $\delta$ 下降，系统移向双稳区甚至单稳高态区：原来低于阈值而被抑制的小扰动（感染、缺血）也能引起 C3b 的爆发式沉积，这就是非典型溶血尿毒综合征与 C3 肾小球病的机制。

4. 抗 C5 抗体治疗阵发性睡眠性血红蛋白尿有效，为什么还要给患者接种脑膜炎球菌疫苗？改用抗 C3 药物能否消除这种担心？

   **答** 阵发性睡眠性血红蛋白尿的红细胞溶解由 C5 之后的攻膜复合体造成，阻断 C5 能保护红细胞，但患者失去了 MAC 的杀菌作用，对奈瑟菌的易感性增加，所以要预防。C3 抑制剂阻断更上游，反而影响调理，使对荚膜细菌的易感性更广；但它能同时阻止红细胞表面 C3b 沉积造成的血管外溶血（C3b 调理后被肝脾巨噬细胞清除），所以两类药的适应证与感染风险不同。

5. （开放题）补体系统被称为"固有免疫与适应性免疫的桥梁"，请从本章的机制出发说明。

   **答** 要点：（1）经典途径由抗体启动，适应性免疫借补体获得效应；（2）凝集素途径与旁路途径不依赖抗体，是固有免疫，但它们产生的 C3b 同样可以调理；（3）C3d 与 B 细胞上的 CR2 使抗原与 BCR 共同交联，把补体沉积转化为适应性免疫的"危险信号"；（4）C3a、C5a 影响树突状细胞和 T 细胞；（5）补体清除免疫复合物和凋亡细胞，防止自身免疫，其缺陷与狼疮相关。
