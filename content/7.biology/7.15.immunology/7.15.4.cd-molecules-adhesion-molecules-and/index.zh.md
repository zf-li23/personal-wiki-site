前两章讲了免疫细胞是谁、住在哪里；本章讲它们用什么"认出"彼此、怎样走到该去的地方。这是知识路径中所有问题的公共基础：识别（问题 1）靠表面受体，决策（问题 2）靠共刺激与共抑制分子，效应（问题 3）的前提是效应细胞到达感染部位，而这一切都写在细胞表面的分子上。这些分子绝大多数被编为 CD 号，名字本身看不出功能，这是免疫学"名字多"的主要来源。本章因此先讲 CD 名字是怎样来的，再按功能把它们分组（§4.1）；然后讲两类决定细胞位置的分子——**黏附分子**（§4.2）和**趋化因子**（§4.3）；最后是它们在临床上的用法（§4.4）。按细胞谱系整理的标志物图谱见 [7.15.35](/7.15.35)；**整联蛋白**、**选择素**、**钙黏蛋白**作为细胞黏附分子的一般结构已在 [7.3.5](/7.3.5) 等章讲过，白细胞**渗出**的生理过程见 [7.14.11](/7.14.11)。

## 4.1. 白细胞分化抗原与 CD 命名

### 4.1.1. 分化群

造血干细胞分化为不同谱系、各谱系分化到不同阶段以及成熟细胞被活化时，细胞表面会出现或消失一些分子，它们统称**白细胞分化抗原**。1970 年代杂交瘤技术出现后，各实验室用小鼠单克隆抗体识别人白细胞表面的分子，同一分子被不同实验室的抗体识别、起了不同的名字。1982 年起，人白细胞分化抗原国际研讨会（HLDA）定期比较这些抗体与它们识别的分子，把识别同一分子的抗体归为一群并给一个编号。

**定义 4.1.1（分化群）** 被一组单克隆抗体识别的同一种白细胞表面分子，按国际研讨会的统一编号命名为一个**分化群**（cluster of differentiation，CD），记作 CD 加数字（如 CD4）；由此也用 CD 号指称该分子本身。

到 2014 年第十次研讨会，人 CD 分子已编到 CD371。读 CD 名称时有几个约定：

- 编号只反映被确认的先后，与功能无关：CD4 和 CD8 是 T 细胞的共受体，CD5 和 CD6 却是清道夫受体半胱氨酸富集家族的成员，作用是调节 TCR 信号。这是"名字看不出功能"的根本原因，所以要按功能重新分组（§4.1.3）。
- 同一复合物的不同链加字母：CD3 的 γ、δ、ε 链为 CD3g、CD3d、CD3e；CD79a、CD79b 是 BCR 的 Igα、Igβ。一些分子同时保留了习惯名称：CD25（IL-2 受体 α 链）、CD62L（L-选择素）、CD279（PD-1）。
- 表达情况写作上标：CD4⁺ 表示表达，CD8⁻ 表示不表达，CD56bright 之类表示表达水平（在流式中写作 hi/lo）；"CD45RA⁺CCR7⁺" 这样的组合称为表型（[7.15.35](/7.15.35)）。
- "CD"本来只用于白细胞，但许多 CD 分子也表达在内皮、上皮和基质细胞上（如 CD31、CD34、CD54），今天它已是表面分子的通用编号。

### 4.1.2. 生化特性与结构家族

CD 分子多数是跨膜糖蛋白，有胞外区、跨膜区与胞质区；有的以糖基磷脂酰肌醇（GPI）锚定在膜上（CD14、CD16b、CD55、CD59），可被磷脂酶切下；少数是碳水化合物，如 CD15（Lewis X 三糖，中性粒细胞的经典标志）和 CD15s（唾液酸化的 Lewis X，选择素的配体）。按胞外区的结构，CD 分子分属若干家族：

| 结构家族 | 结构特征 | 例子 |
|---|---|---|
| 免疫球蛋白超家族 | 含 Ig 样结构域（V 样或 C 样） | CD2、CD3、CD4、CD8、CD28、CD80/86、CD54（ICAM-1）、CD106（VCAM-1）、CD279（PD-1） |
| 整联蛋白家族 | α、β 两链非共价连接的异二聚体 | CD11a–c/CD18、CD49d/CD29、CD103 |
| C 型凝集素超家族 | 钙依赖的糖识别结构域 | CD62E/L/P（选择素）、CD69、CD94、CD206（甘露糖受体）、CD209（DC-SIGN） |
| 细胞因子受体家族 | 保守的半胱氨酸与 WSXWS 基序 | CD25、CD122、CD127、CD132 |
| 肿瘤坏死因子超家族 / 受体超家族 | 配体为三聚体；受体富含半胱氨酸 | CD40L（CD154）、FasL（CD178）；CD40、Fas（CD95）、OX40（CD134） |
| 富含亮氨酸重复序列 | 马蹄形的 LRR 结构域 | CD14、Toll 样受体（CD281–CD290） |
| 七次跨膜受体 | G 蛋白偶联受体 | 趋化因子受体 CD183（CXCR3）、CD184（CXCR4）、CD195（CCR5）、CD197（CCR7） |
| 四次跨膜蛋白 | 在膜上组织其他受体 | CD9、CD37、CD81 |

### 4.1.4. 怎样读一个 CD 名称

面对一个陌生的 CD 分子，可以依次问三个问题：它属于哪个结构家族（决定它与谁结合、怎样传递信号）；它在哪些细胞上（谱系标志还是状态标志）；它在应答的哪一步起作用（§4.1.3 表中的哪一行）。例如 CD103：整联蛋白 αE，与 β7 组成异二聚体，配体是上皮的 E-钙黏蛋白，所以它把细胞固定在上皮中，表达在组织驻留记忆 T 细胞和部分树突状细胞上，是"组织驻留"的标志。这样，一个编号就被放回了知识路径中。

## 4.2. 黏附分子

### 4.2.1. 概念

**定义 4.2.1（黏附分子）** 以受体–配体结合的方式介导细胞与细胞、细胞与细胞外基质之间黏附的膜分子称为**黏附分子**。

黏附在免疫系统中有特别的意义。免疫细胞大部分时间是单独游动的细胞，它们必须在需要时迅速、可逆地黏附：在血管中抓住内皮、在淋巴结中与树突状细胞形成持续数小时的接触、在杀伤时与靶细胞紧贴。因此免疫细胞的黏附分子大多处于"可开关"的状态，受化学信号调控其亲和力或表达量。

### 4.2.2. 四个家族

| 家族 | 结构 | 结合方式 | 免疫中的代表 |
|---|---|---|---|
| 免疫球蛋白超家族 | 一个或多个 Ig 样结构域 | 通常与整联蛋白或另一个 IgSF 分子结合 | ICAM-1（CD54）、ICAM-2、VCAM-1（CD106）、MAdCAM-1、CD2、CD58（LFA-3）、PECAM-1（CD31） |
| 整联蛋白（免疫学中常称"整合素"） | α、β 链异二聚体；18 种 α、8 种 β 组成 24 种 | 结合 IgSF 分子或细胞外基质（纤连蛋白、胶原）；需 $\ce{Mg^2+}$ / $\ce{Mn^2+}$ | β2 组：LFA-1（αLβ2）、Mac-1（αMβ2，即 CR3）；β1 组：VLA-4（α4β1）；β7 组：α4β7、αEβ7 |
| 选择素 | C 型凝集素结构域、EGF 样结构域与若干补体调控蛋白重复 | 识别唾液酸化的岩藻糖化糖链（如 sLeX），结合快、解离也快 | L-选择素（CD62L，白细胞）、E-选择素（CD62E，活化内皮）、P-选择素（CD62P，血小板与活化内皮） |
| 钙黏蛋白 | 胞外 5 个钙黏蛋白重复，$\ce{Ca^2+}$ 依赖 | 同型结合（E 与 E） | E-钙黏蛋白（上皮，是 αEβ7 的配体） |

**定义 4.2.2（免疫球蛋白超家族）** 胞外区含有一个或多个与免疫球蛋白 V 区或 C 区相似的结构域（Ig 折叠，约 100 个氨基酸、由两层 β 片层构成的"三明治"并以一个二硫键稳定）的蛋白质统称**免疫球蛋白超家族**（IgSF）。

IgSF 是脊椎动物基因组中最大的蛋白家族之一。抗体、TCR、MHC、CD4、CD8、共刺激分子和许多黏附分子都属于它；它们的共同祖先可能是一个介导细胞识别的黏附分子，Ig 折叠的稳定性和可变环使它特别适合演化出多样的结合表面（Ig 折叠的结构见 [7.1.7](/7.1.7)）。

整联蛋白的特点是由内向外的活化。静息白细胞上的 LFA-1 处于弯折的低亲和力构象；趋化因子受体或 TCR 的信号经小 G 蛋白 Rap1 与胞质蛋白 talin、kindlin 作用于 β 链的胞质尾，使整联蛋白伸展并打开配体结合位点，亲和力在不到一秒内提高约 $10^{3}$–$10^{4}$ 倍；多个分子在接触面聚集又进一步提高亲合力。正是这一机制让白细胞在看到"信号"的那一刻才牢固黏附（§4.2.3）。

下表是免疫中最重要的几对黏附分子：

| 白细胞上 | 配体（所在） | 作用 |
|---|---|---|
| L-选择素（CD62L） | PNAd：GlyCAM-1、CD34 等的硫酸化 sLeX（HEV） | 初始淋巴细胞在 HEV 上滚动 |
| PSGL-1（CD162）上的 sLeX | P-选择素、E-选择素（活化内皮） | 白细胞在炎症血管上滚动 |
| LFA-1（CD11a/CD18） | ICAM-1、ICAM-2（内皮、APC） | 牢固黏附；T 细胞与 APC 的接触 |
| Mac-1（CD11b/CD18） | ICAM-1；补体片段 iC3b | 中性粒细胞与单核细胞的黏附、吞噬 |
| VLA-4（α4β1，CD49d/CD29） | VCAM-1（活化内皮） | 效应 T 细胞、单核细胞进入炎症组织 |
| α4β7 | MAdCAM-1（肠黏膜血管） | 淋巴细胞归巢到肠道 |
| αEβ7（CD103） | E-钙黏蛋白（上皮） | 上皮内淋巴细胞留在上皮中 |
| CD2 | CD58（人）/ CD48（小鼠）（APC、靶细胞） | T 细胞与 APC、NK 细胞与靶细胞的黏附 |

**注 4.2.1** 黏附分子缺陷直接表现为免疫缺陷。白细胞黏附缺陷 I 型由 β2 整联蛋白共同链 CD18 的突变引起：中性粒细胞不能牢固黏附和渗出，血液中性粒细胞计数很高而感染部位没有脓，患者反复发生严重的细菌感染，脐带脱落延迟。II 型是岩藻糖基化缺陷，白细胞上没有选择素配体 sLeX，不能滚动。这两种疾病分别证明了级联中"牢固黏附"与"滚动"两步都不可缺少。

### 4.2.3. 白细胞黏附级联

**定义 4.2.3（白细胞黏附级联）** 血液中的白细胞经内皮进入组织所经历的、由不同黏附分子与趋化因子依次介导的多步过程称为**白细胞黏附级联**：（1）选择素介导的拴系与滚动；（2）内皮表面趋化因子引起的整联蛋白活化；（3）整联蛋白与 IgSF 配体介导的牢固黏附；（4）爬行与跨内皮迁移（渗出）。

![白细胞黏附级联。血流（从左到右）中的白细胞先被内皮上的选择素与其糖配体短暂拴住，沿血管壁滚动减速（1）；内皮表面糖胺聚糖上展示的趋化因子激活白细胞的 G 蛋白偶联受体，由内向外地使整联蛋白转为高亲和力构象（2）；活化的整联蛋白（LFA-1、VLA-4）与内皮的 ICAM-1、VCAM-1 结合，白细胞停住并铺展（3）；随后沿内皮爬行到细胞连接处，从内皮细胞之间（少数穿过内皮细胞）钻出血管，沿组织中的趋化因子梯度移向感染部位（4）。每一步由不同的分子对完成，组合起来决定哪一类白细胞在哪里离开血液](./plots/adhesion-cascade.py)

级联的每一步都是一道"与门"：只有同时具备相应选择素配体、相应趋化因子受体和相应整联蛋白的白细胞，才能在给定的血管段离开血液。选择素与配体的键是"捕获键"（catch bond）：在一定范围内，血流的剪切力越大，键的寿命反而越长，所以白细胞只在流动中才能稳定地滚动。各类白细胞的组合不同，这就是同一处炎症中先来中性粒细胞、后来单核细胞和效应 T 细胞的分子基础（[7.15.7](/7.15.7)）。

### 4.2.4. 淋巴细胞归巢

**定义 4.2.4（淋巴细胞归巢）** 淋巴细胞借助其表面的归巢受体与特定组织血管内皮上的地址素（及相应的趋化因子）选择性地进入并定居于特定的外周淋巴器官或组织的过程称为**淋巴细胞归巢**。

归巢是黏附级联在淋巴细胞上的特化：不同的器官用不同的"地址码"，淋巴细胞在活化时被"写上"要去的地址。

| 目的地 | 内皮上的地址素 | 趋化因子 → 受体 | 淋巴细胞上的归巢受体 | 典型细胞 |
|---|---|---|---|---|
| 外周淋巴结（HEV） | PNAd | CCL21、CCL19 → CCR7 | L-选择素、LFA-1 | 初始 T 与 B 细胞、中央记忆 T 细胞 |
| 派尔集合淋巴结与肠固有层 | MAdCAM-1 | CCL25 → CCR9（小肠）；CCL28 → CCR10（大肠） | α4β7 | 肠道归巢的效应与记忆细胞、IgA 浆细胞 |
| 皮肤 | E-选择素、ICAM-1 | CCL17 → CCR4；CCL27 → CCR10 | 皮肤淋巴细胞相关抗原（CLA，PSGL-1 的糖基化形式） | 皮肤归巢的 T 细胞 |
| 炎症组织 | E/P-选择素、VCAM-1、ICAM-1 | CXCL9、CXCL10 → CXCR3（1 型炎症）；CCL17、CCL22 → CCR4（2 型）；CCL20 → CCR6（3 型） | VLA-4、LFA-1 | 效应 T 细胞 |

地址是怎样被写上的？在肠系膜淋巴结中提呈抗原的树突状细胞能把饮食中的维生素 A 代谢为视黄酸，视黄酸诱导被它活化的 T 细胞表达 α4β7 和 CCR9；在皮肤引流淋巴结中，维生素 D3 的代谢物诱导 CCR10。效应细胞由此回到最初遇到抗原的那类组织，这是黏膜疫苗通常需要在黏膜处接种的原因之一（[7.15.23](/7.15.23)、[7.15.33](/7.15.33)）。

## 4.3. 趋化因子

### 4.3.1. 结构、命名与受体

**定义 4.3.1（趋化因子）** **趋化因子**是一类分子量约 8–12 kDa、结构保守（三股反平行 β 片层加 C 端 α 螺旋，由二硫键稳定）、能诱导表达相应受体的细胞定向迁移的分泌型小分子细胞因子；它们的作用由 G 蛋白偶联的**趋化因子受体**介导。

**定义 4.3.2（趋化因子受体）** 结合趋化因子、经 Gαi 蛋白传递信号并引起细胞极化、整联蛋白活化与定向运动的七次跨膜受体称为**趋化因子受体**。

按 N 端前两个保守半胱氨酸之间间隔的氨基酸数，趋化因子分为四个亚家族；配体写作"L"，受体写作"R"，编号为发现顺序：

| 亚家族 | 半胱氨酸基序 | 人类成员数 | 受体 | 代表 |
|---|---|---|---|---|
| CC | 两个 C 相邻 | 约 27 | CCR1–CCR10 | CCL2（MCP-1）、CCL5（RANTES）、CCL11（eotaxin）、CCL19、CCL21 |
| CXC | 中间隔一个氨基酸 | 约 16 | CXCR1–CXCR6 | CXCL8（IL-8）、CXCL10、CXCL12（SDF-1）、CXCL13 |
| CX3C | 中间隔三个氨基酸 | 1 | CX3CR1 | CX3CL1（fractalkine，膜结合型，可被切下） |
| XC | 只有一个（第二、第四个）半胱氨酸 | 2 | XCR1 | XCL1（lymphotactin） |

CXC 亚家族又按第一个半胱氨酸之前是否有"谷–亮–精"（ELR）三肽分为两组：ELR⁺ 的（如 CXCL8）吸引中性粒细胞并促进血管新生，ELR⁻ 的（如 CXCL9、CXCL10）吸引淋巴细胞并抑制血管新生。人类共有约 45 种趋化因子、18 种传递信号的受体，此外还有 4 种不传递 G 蛋白信号的"非典型趋化因子受体"（ACKR），它们结合并内吞趋化因子，起清除剂或转运体的作用（例如红细胞上的 ACKR1，即 Duffy 抗原）。配体与受体的关系是多对多的：一种受体常结合几种配体，一种配体也常结合几种受体，但最重要的几对相当专一（如 CXCL12–CXCR4、CXCL13–CXCR5）。

趋化因子受体也被病原体利用：HIV-1 进入细胞除 CD4 外还需要共受体 CCR5 或 CXCR4，*CCR5* 基因 32 bp 缺失（Δ32）的纯合者对使用 CCR5 的病毒株有天然抗性（[7.11.27](/7.11.27)）。

### 4.3.2. 稳态与炎症性趋化因子：细胞的"位置码"

按表达方式，趋化因子分为两类：稳态趋化因子由基质细胞组成性表达，维持免疫器官的结构和细胞的日常运输；炎症性趋化因子由受刺激的组织细胞与白细胞在感染时诱导产生，把效应细胞招到现场。下表是读懂组织切片中"细胞为什么在这里"的一把钥匙：

| 趋化因子 → 受体 | 来源 | 吸引的细胞 | 作用 |
|---|---|---|---|
| CCL19、CCL21 → CCR7 | 淋巴结 T 细胞区基质细胞、HEV、淋巴管 | 初始 T 与 B 细胞、成熟树突状细胞 | 进入淋巴结 T 细胞区 |
| CXCL13 → CXCR5 | 滤泡基质细胞、滤泡树突状细胞 | B 细胞、Tfh 细胞 | 进入滤泡 |
| CXCL12 → CXCR4 | 骨髓基质细胞等 | 造血干细胞、浆细胞、B 细胞前体 | 留在骨髓；生发中心暗区 |
| CCL25 → CCR9 | 小肠上皮、胸腺 | 肠道归巢 T 细胞、胸腺细胞 | 肠道与胸腺的定位 |
| CXCL8 → CXCR1、CXCR2 | 巨噬细胞、上皮、内皮 | 中性粒细胞 | 急性炎症的中性粒细胞募集（3 型） |
| CCL2 → CCR2 | 炎症组织 | 经典单核细胞 | 单核细胞离开骨髓与进入组织 |
| CXCL9、CXCL10、CXCL11 → CXCR3 | IFN-γ 刺激的细胞 | Th1、CTL、NK 细胞 | 1 型炎症 |
| CCL11（eotaxin）→ CCR3 | 上皮、成纤维细胞（IL-4、IL-13 诱导） | 嗜酸性粒细胞、Th2 | 2 型炎症 |
| CCL17、CCL22 → CCR4 | 树突状细胞、皮肤 | Th2、Treg、皮肤归巢 T 细胞 | |
| CCL20 → CCR6 | 上皮（派尔集合淋巴结上方、炎症皮肤） | Th17、未成熟树突状细胞、B 细胞 | 3 型炎症；黏膜诱导部位 |
| CX3CL1 → CX3CR1 | 内皮、神经元 | 非经典单核细胞、NK 细胞、小胶质细胞 | 巡逻与黏附 |

树突状细胞的迁移是一个由受体切换驱动的例子：未成熟的树突状细胞表达 CCR6、CCR1 等炎症性受体，留在外周组织；它感知到病原体后成熟，下调这些受体、上调 CCR7，于是沿淋巴管内皮分泌的 CCL21 进入淋巴管，最终到达淋巴结 T 细胞区（[7.15.14](/7.15.14)）。

### 4.3.3. 梯度的形成与读取

趋化因子要引导细胞，必须形成浓度梯度。最简单的模型是：趋化因子在一个点源（比如一段血管旁的发炎组织边界）以恒定速率产生，在组织中以扩散系数 $D$ 扩散，并以速率常数 $k$ 被清除（被受体内吞、被非典型受体清除或被蛋白酶降解）。一维的反应–扩散方程（[2.5](/2.5)；作为网络动力学模型的写法见 [7.9.14](/7.9.14)）为

$$
\frac{\partial c}{\partial t} = D\frac{\partial^2 c}{\partial x^2} - kc .
$$

**例 4.3.1** 稳态时 $D c'' = kc$，在源边界 $c(0) = c_0$、远处 $c \to 0$ 的条件下，解为

$$
c(x) = c_0\,\mathrm{e}^{-x/\ell}, \qquad \ell = \sqrt{D/k} .
$$

$\ell$ 是梯度的特征长度：扩散快则梯度伸得远，清除快则梯度陡而短，这与发育中**形态发生素**梯度的逻辑相同。一个约 8 kDa 的趋化因子在组织间隙中的扩散系数约为 $D \approx 50$–$100\,\mathrm{\mu m^2\,s^{-1}}$；若清除的时间尺度为数分钟到十几分钟（$k \approx 10^{-3}$–$10^{-2}\,\mathrm{s^{-1}}$），则 $\ell \approx 70$–$300\,\mathrm{\mu m}$，即几到几十个细胞直径，与血管到感染灶的距离相当。

细胞怎样"读"梯度？长度为 $L$ 的细胞两端的浓度相对差为 $\Delta c / c = L/\ell$，取 $L = 10\,\mathrm{\mu m}$ 只有约 3%–15%。细胞感知的不是浓度本身，而是受体占有率 $\theta = c/(c + K_{\mathrm{d}})$；两端占有率之差

$$
\Delta\theta \approx \frac{\mathrm{d}\theta}{\mathrm{d}c}\,\Delta c = \theta(1 - \theta)\,\frac{L}{\ell}
$$

在 $c = K_{\mathrm{d}}$（$\theta = 1/2$）处最大，为 $L/(4\ell)$；在远离源处（$c \ll K_{\mathrm{d}}$）受体几乎空着，在靠近源处（$c \gg K_{\mathrm{d}}$）受体饱和，两种情况下细胞都分不出方向。所以一个指数梯度只在 $c$ 与 $K_{\mathrm{d}}$ 相差不到约十倍的一段距离内可读，宽度约为 $2\ell\ln 10 \approx 4.6\ell$。

:::

这个简单的计算解释了免疫系统的几种安排。第一，组织中的趋化因子大多结合在细胞外基质和内皮表面的糖胺聚糖上，形成固定的"表面梯度"，既减少了被血流或组织液冲走，也使细胞可以沿表面爬行读取（触趋性）。第二，细胞常常依次响应几种亲和力不同或来源不同的趋化因子，像接力一样把长距离的导航分段完成；中性粒细胞先响应血管附近的 CXCL8，接近感染灶时转而优先响应细菌的甲酰肽和补体片段 C5a。第三，细胞通过受体脱敏与内吞不断"重置"灵敏度，能在很宽的浓度范围内保持方向感，这是信号转导中适应的一般原理（[7.9.16](/7.9.16)）。

## 4.4. 临床应用

CD 分子和黏附分子是诊断与治疗的现成靶点。

| 应用 | 分子 | 原理 |
|---|---|---|
| 免疫状态的监测 | CD4 | HIV 感染者外周血 CD4⁺ T 细胞绝对计数（正常约 $500$–$1500\,\mathrm{\mu L^{-1}}$）降到 $200\,\mathrm{\mu L^{-1}}$ 以下时，机会性感染风险急剧升高，是艾滋病的定义标准之一 |
| 白血病与淋巴瘤的分型 | CD19、CD20、CD3、CD34、CD117、CD33、CD13 等 | 按 CD 表型判断肿瘤细胞的谱系与分化阶段 |
| 清除 B 细胞 | CD20（利妥昔单抗）；CD19（CAR-T、CD19×CD3 双特异性抗体） | B 细胞淋巴瘤与白血病、自身抗体介导的疾病 |
| 抑制 T 细胞 | CD3（抗 CD3 抗体）、CD25（巴利昔单抗）、CD52（阿仑单抗） | 防治移植排斥；抗 CD3 抗体可推迟 1 型糖尿病的发病 |
| 浆细胞肿瘤 | CD38（达雷妥尤单抗） | 多发性骨髓瘤 |
| 阻断共刺激或共抑制 | CTLA-4–Ig（阿巴西普，阻断 CD28–B7）；抗 PD-1、抗 PD-L1 | 治疗类风湿关节炎；肿瘤免疫治疗（[7.15.25](/7.15.25)） |
| 阻断归巢 | α4 整联蛋白（那他珠单抗）；α4β7（维得利珠单抗） | 那他珠单抗阻止淋巴细胞进入中枢神经系统，治疗**多发性硬化**；维得利珠单抗只阻断肠道归巢，治疗**炎症性肠病** |
| 阻断趋化因子受体 | CCR5（马拉韦罗）；CXCR4（普乐沙福） | 阻止 HIV 进入；动员造血干细胞离开骨髓以便采集 |

那他珠单抗与维得利珠单抗的对比说明了归巢"地址码"的实际意义：前者阻断 α4（同时影响 α4β1 与 α4β7），抑制淋巴细胞进入脑，也削弱了中枢神经系统对病毒的免疫监视，少数患者因潜伏的 JC 病毒再激活而发生进行性多灶性白质脑病；后者只阻断肠道特异的 α4β7–MAdCAM-1，没有这一风险。这些药物的设计都基于本章的分子逻辑，抗体药物本身的结构与改造见 [7.15.9](/7.15.9)。

## 小结

- CD 编号来自单克隆抗体的分群（定义 4.1.1），只反映确认的先后，不反映功能；按功能把 CD 分子分为抗原受体与共受体、模式识别受体、细胞因子受体、补体受体、Fc 受体、NK 受体、共刺激与共抑制、黏附与归巢、死亡受体、酶、谱系与状态标志（§4.1.3）。读一个 CD 名称：结构家族 → 表达细胞 → 在应答中的哪一步。
- **黏附分子**（定义 4.2.1）分为四个家族：

  | 家族 | 结合 | 代表 | 在级联中 |
  |---|---|---|---|
  | **选择素** | 糖链（sLeX），快结合快解离 | L-、E-、P-选择素 | 滚动 |
  | **整联蛋白** | IgSF 配体、基质；由内向外活化 | LFA-1、Mac-1、VLA-4、α4β7、αEβ7 | 牢固黏附 |
  | **免疫球蛋白超家族** | 整联蛋白或 IgSF | ICAM-1、VCAM-1、MAdCAM-1、CD2 | 黏附的内皮一侧；细胞接触 |
  | **钙黏蛋白** | 同型结合 | E-钙黏蛋白 | 上皮中的定居 |

- **白细胞黏附级联**（定义 4.2.3）：滚动 → 趋化因子活化整联蛋白 → 牢固黏附 → 渗出；每一步是一道"与门"。**淋巴细胞归巢**（定义 4.2.4）用"归巢受体 + 地址素 + 趋化因子"的组合编码目的地：淋巴结（L-选择素/PNAd、CCR7）、肠道（α4β7/MAdCAM-1、CCR9）、皮肤（CLA/E-选择素、CCR4、CCR10）。
- **趋化因子**（定义 4.3.1）按半胱氨酸基序分为 CC、CXC、CX3C、XC，经 G 蛋白偶联的**趋化因子受体**（定义 4.3.2）起作用；稳态趋化因子维持器官结构（CCL19/21–CCR7、CXCL13–CXCR5、CXCL12–CXCR4），炎症性趋化因子对应效应模块（CXCR3：1 型；CCR3、CCR4：2 型；CXCR1/2、CCR6：3 型）。
- 反应–扩散模型给出梯度长度 $\ell = \sqrt{D/k}$（数十到数百微米）；细胞两端受体占有率之差 $\theta(1-\theta)L/\ell$ 在 $c \approx K_{\mathrm{d}}$ 处最大，梯度只在约 $4.6\ell$ 的范围内可读（例 4.3.1）。

## 思考题

1. 一种单克隆抗体被国际研讨会归入 CD62L。仅从名字，你能推断出这个分子的哪些性质？还需要查什么？

   **答** "62"本身没有信息，但后缀"L"和这一编号在习惯上对应 L-选择素（CD62E、CD62P 是 E-、P-选择素），由此可推断它属于 C 型凝集素家族、识别 sLeX 类糖链、介导白细胞在内皮上的滚动。还需要查它的表达细胞（初始与中央记忆淋巴细胞、中性粒细胞），以及它在活化后被金属蛋白酶从膜上切下（所以效应 T 细胞多为 CD62L⁻）。这说明 CD 号必须与家族、表达和功能一起记。

2. 白细胞黏附缺陷 I 型患者血液中的中性粒细胞数常比正常人高数倍，感染部位却没有脓。用黏附级联解释这两个现象。

   **答** CD18 缺失使所有 β2 整联蛋白（LFA-1、Mac-1）缺失，中性粒细胞可以滚动但不能牢固黏附和渗出，于是它们停留在血液中（边缘池也减少），血液计数升高；同时它们到不了感染组织，组织中没有中性粒细胞聚集，也就不形成脓。Mac-1 同时是补体受体 CR3，它的缺失还削弱了对 iC3b 包被细菌的吞噬。

3. 用例 4.3.1 的模型：若某种药物使组织中趋化因子的清除速率提高 4 倍，梯度长度与细胞两端占有率差的峰值怎样变化？

   **答** $\ell = \sqrt{D/k}$，$k$ 增至 4 倍时 $\ell$ 减半；峰值 $\Delta\theta_{\max} = L/(4\ell)$ 加倍，即梯度变陡、方向信号更强，但可读范围（约 $4.6\ell$）缩短一半，离源较远的细胞感知不到梯度。所以清除不是单纯"削弱"信号，而是在"传得远"与"读得清"之间改变取舍。

4. 为什么维得利珠单抗被认为比那他珠单抗更"安全"？这对设计针对其他组织的药物有什么启示？

   **答** 那他珠单抗阻断 α4 链，同时抑制 α4β1–VCAM-1（进入脑等多种组织）和 α4β7–MAdCAM-1（进入肠道），削弱了中枢神经系统的免疫监视，可导致 JC 病毒再激活；维得利珠单抗只识别 α4β7 异二聚体，而 MAdCAM-1 主要表达在肠黏膜血管上，所以它只阻断肠道归巢。启示是：利用组织特异的"地址码"（特定整联蛋白异二聚体、特定地址素或趋化因子受体），可以只阻断进入某一器官的淋巴细胞而保留全身的监视。

5. （开放题）在空间蛋白组学中，你在一个肿瘤切片中看到大量 CXCR3⁺ CD8⁺ T 细胞聚集在 CXCL10 高表达的区域，而 CCR7⁺ T 细胞集中在一个三级淋巴结构中。根据本章的"位置码"，这两组细胞可能分别处于什么状态？

   **答** CXCR3 是 1 型炎症的趋化因子受体，其配体 CXCL9、CXCL10 由 IFN-γ 诱导；CXCR3⁺ CD8⁺ T 细胞聚集在 CXCL10 区，提示这些是被招募的效应或效应记忆 T 细胞，局部正在进行 IFN-γ 驱动的应答（常与较好的免疫治疗响应相关）。CCR7 是稳态趋化因子 CCL19/21 的受体，CCR7⁺ T 细胞集中在三级淋巴结构中，提示它们是初始或中央记忆 T 细胞，被结构内基质细胞的 CCL19/21 留住，可能在那里被就地活化。判断时应结合 CD45RA/RO、PD-1、Ki-67 等状态标志（[7.15.35](/7.15.35)）。
