**自由组合定律**只适用于位于不同**染色体**上的**基因**。位于同一条染色体上的基因倾向于一起传递，而例外，即**等位基因**的亲本组合被重新洗牌的后代，来自**减数分裂**中**同源染色体**之间的**交换**（[7.4.5](/7.4.5)）。本章把这一观察变成一件测量工具。重组型后代的比例随两个基因之间距离的增大而增加，所以设计良好的杂交中后代的计数能把基因按线性顺序排列，并给出以厘摩为单位的距离：遗传图。作图是遗传学最古老的定量方法，至今仍是最常用的方法之一；它是概率（交换的数目与位置）、估计（重组率及其标准误，由 F2 数据作极大**似然**估计）与检验（究竟有没有连锁？）的一个小练习。配对、联会与**交叉**的细胞学过程见 [7.3.21](/7.3.21#sec-21.7.2)，减数分裂重组的分子机制见 [7.2.9](/7.2.9#sec-9.5.2)；这里只用它们的遗传学后果。真菌中的**四分子**分析观察一次**减数分裂**的全部四个产物，见 [7.4.9](/7.4.9)；通过接合与转导定位细菌基因见 [7.4.10](/7.4.10)；用 LOD 值定位人类疾病基因见 [7.4.14](/7.4.14)。

## 8.1. 连锁

### 8.1.1. 过多的亲本型

1905 年，Bateson、Saunders 和 Punnett 用花色（紫色 $P$，对红色 $p$ 为**显性**）和花粉形状（长形 $L$，对圆形 $l$ 为显性）不同的香豌豆杂交。$PP\,LL \times pp\,ll$ 杂交的 F2 远远偏离 9:3:3:1：在 6952 株中，4831 株紫花长花粉，390 株紫花圆花粉，393 株红花长花粉，1338 株红花圆花粉。两种亲本组合过多，两种新组合很少。每个性状单独分离是正常的（紫 : 红为 $5221 : 1731$，长 : 圆为 $5224 : 1728$，都接近 $3:1$），所以偏离在于两个**基因座**的组合，而不在其中任何一个。在第二个杂交，即紫花圆花粉与红花长花粉杂交（$PP\,ll \times pp\,LL$）中，419 株的 F2 由 226 株紫花长花粉、95 株紫花圆花粉、97 株红花长花粉和仅 1 株红花圆花粉组成：现在亲本带来的组合（紫花圆花粉、红花长花粉）过多，而双**隐性**几乎缺失（例 8.6.2）。Bateson 把第一个杂交中显性因子的结合称为"相引"，第二个杂交中的称为"相斥"，但无法解释。1911 年，Morgan 在果蝇中用 **X 连锁**的**基因** *white*（$w$，白眼）与 *yellow*（$y$，黄体）发现了同样的模式：对两个基因都**杂合**的雌蝇传给儿子的，主要是它从双亲那里得到的两种**等位基因**组合，不论这两种组合是什么，新组合只有约 $1\,\%$。因为儿子的唯一一条 X 来自母亲，儿子的**表型**直接读出了母亲的配子。

**定义 8.1.1（亲本型与重组型）** 考虑在两个基因座上杂合、从双亲分别得到单倍型 $AB$ 与 $ab$ 的个体。它的配子（以及表现这些配子的后代）带 $AB$ 或 $ab$ 的是**亲本型**；带 $Ab$ 或 $aB$ 的是**重组型**。这一分类由上一代的单倍型而不是由显隐性或等位基因本身决定：在得到 $Ab$ 与 $aB$ 的杂合子中，配子 $Ab$ 与 $aB$ 是亲本型。

**定义 8.1.2（连锁）** 若双杂合子产生亲本型配子比重组型配子更多，即**重组配子**的比例小于 $1/2$，两个基因座就表现出**连锁**。独立分配（比例为 $1/2$）的基因座是不连锁的。

在**自由组合定律**下，双杂合子以相等比例产生四种配子，所以一半的配子是重组的；连锁则是任何向更少方向的偏离。连锁的程度从几乎完全（如 $w$ 与 $y$）到检测不到不等。

### 8.1.2. 相引与相斥

**定义 8.1.3（相引与相斥）** 在两个连锁基因座的双杂合子中，显性（或**野生型**）等位基因位于同一条**染色体**上，$AB/ab$，称为**相引相**（顺式构型）；位于不同的**同源染色体**上，$Ab/aB$，称为**相斥相**（反式构型）。这种排列称为双杂合子的连锁相。

我们在连锁基因座的**基因型**中，用斜线分隔两条同源染色体的单倍型：$AB/ab$，或用基因符号写成 $w\,y^{+}/w^{+}\,y$。连锁相决定哪些配子是亲本型，因而哪些后代频繁出现：$AB/ab$ 的**测交**主要给出 $AB$ 与 $ab$ 表型，$Ab/aB$ 的测交主要给出 $Ab$ 与 $aB$。重组率本身不依赖连锁相（Morgan 对 $w$ 与 $y$ 所作的两个系列杂交得到同样的 $\approx 1\,\%$）。

### 8.1.3. 测交检测连锁

**例 8.1.1** 野生型雄蝇与黑体（$b$）残翅（$vg$）雌蝇杂交所得的果蝇雌蝇为 $b^{+}\,vg^{+}/b\,vg$（相引）。与 $b\,vg/b\,vg$ 雄蝇测交，产生 1000 个后代：405 个野生型，415 个黑体残翅，92 个黑体，88 个残翅。亲本型（野生型、黑体残翅）为 $820$ 个，重组型为 $180$ 个，所以重组型的比例为 $180/1000 = 0.18 < 1/2$：这两个基因是连锁的。在测交中，每个后代的表型都揭示雌蝇的配子，这就是测交成为标准作图设计的原因。

## 8.2. 交换是重组的基础

### 8.2.1. 细胞学证明

Morgan 于 1911 年提出，重组型是由**同源染色体**交换片段产生的，这一想法得益于 Janssens 在减数分裂**前期**看到的**交叉**。遗传重组伴随着物理交换的证明出现于 1931 年。Harriet Creighton 与 Barbara McClintock 使用一条两端都有细胞学标记的玉米 9 号**染色体**，一端有异染色质结节，另一端通过易位连着 8 号染色体的一段，并在两个标记附近带有**显性**的**等位基因** $C$（有色糊粉层）与 $Wx$（淀粉质胚乳）。在这条染色体与带 $c$、$wx$ 的正常同源染色体的**杂合**植株中，$C$ 与 $Wx$ 重组的后代也交换了细胞学标记，亲本型后代则没有。Curt Stern 在果蝇中用两条形状不同的 X 染色体得到同样的结果，其中一条断成两段，另一条带有一段 Y，用 *carnation* 与 *Bar* 作标记。

### 8.2.2. 交换发生在四条染色单体中的两条之间

**交换**发生在减数分裂前期 I、**DNA 复制**之后，这时每个**二价体**由四条染色单体组成；一次交换只涉及其中两条，每条同源染色体各一条（四分子的证据见 [7.4.9](/7.4.9#sec-9.4)）。因此两个**基因座**之间的一次交换产生两条重组染色单体和两条亲本染色单体，一个区间内有一次交换的**减数分裂**以概率 $1/2$ 而不是 $1$ 给出**重组配子**（见图）。这是本章大部分算术的来源。

![四链期的一次与两次交换。每行四条横条是一个二价体：上面两条染色单体（蓝色）是一条同源染色体的姐妹染色单体，下面两条（粉色）属于另一条同源染色体，在着丝粒（灰色椭圆，左）处相连；A/a 与 B/b 是两个基因座，每个 X 标出所连两条染色单体之间的一次交换。(A) 两个基因座之间的一次交换产生两条重组（R）染色单体和两条亲本（P）染色单体。(B) 同样两个基因座之间的四种双交换：二线双交换（两次交换发生在同一对染色单体之间）不产生重组染色单体，两种三线双交换各产生两条，四线双交换产生四条。若第二次交换所涉及的染色单体是随机选取的，则四种类型的概率相等，平均有一半产物是重组的。](./plots/crossovers-four-chromatids.py)

交换的两个特点对作图有影响。第一，每个二价体通常至少有一次交换（必需交换），因为它所形成的交叉使同源染色体在**后期** I 之前保持在一起（[7.3.21](/7.3.21#sec-21.7.2)）；没有交叉的染色体有**不分离**的风险（[7.4.6](/7.4.6)）。第二，同一个二价体上的交换不是独立分布的：一次交换降低附近发生另一次交换的机会（第 8.4.3 节）。交换在分离之外还有一种生物学功能：它在同一条染色体上产生新的等位基因组合，因而产生供选择作用的变异。

## 8.3. 重组率与遗传图

### 8.3.1. 重组率与厘摩

**定义 8.3.1（重组率）** 两个**基因座**之间的**重组率** $r$（重组值，RF）是双**杂合子**的配子对它们为重组型的概率。在每个后代的**基因型**都揭示配子的杂交（如**测交**）中，它估计为重组型后代的比例：$\hat r = R/n$，其中 $R$ 为 $n$ 个后代中的重组型数。

**定义 8.3.2（厘摩）** **厘摩**（cM，图距单位，m.u.）是遗传图距离的单位：当两个基因座之间的距离平均每次**减数分裂**每条染色单体发生 $0.01$ 次**交换**时，二者相距 $1\,\mathrm{cM}$。对于可以忽略多次交换的短距离，$1\,\mathrm{cM}$ 对应 $r = 1\,\%$。一百厘摩为一摩（M），以 T. H. Morgan 命名。

重组率（可观测，至多为 $1/2$）与图距（交换的期望次数，可以超过 $1/2$）的区别是第 8.5 节的主题。在例 8.1.1 中，$\hat r = 0.18$，所以 $b$ 与 $vg$ 相距约 $18\,\mathrm{cM}$（它们的标准图位是 $2$-$48.5$ 与 $2$-$67.0$，相差 $18.5\,\mathrm{cM}$）。

### 8.3.2. 为什么重组率不会超过二分之一

上一节的逻辑给出一个简短的证明。设 $K$ 为二价体上两个基因座之间的区间内的交换数，并设每次交换涉及随机选取的两条非姐妹染色单体，且与其他交换独立（无染色单体干涉）。跟踪一条染色单体：每次交换以概率 $1/2$ 涉及它，若它参与了奇数次交换，它就是重组的。

**公式 8.3.1（Mather 公式）** 无染色单体干涉时，

$$
r = \tfrac12\bigl(1 - \mathbb{P}(K = 0)\bigr),
$$
其中 $\mathbb{P}(K = 0)$ 是二价体在该区间内没有交换的概率。

**证明** 已知 $K = k \ge 1$，涉及该染色单体的交换数服从 $\mathrm{Bin}(k, 1/2)$，而 $p = 1/2$ 的二项变量为奇数的概率是 $\tfrac12\bigl(1 - (1 - 2p)^k\bigr) = \tfrac12$。已知 $K = 0$ 时，染色单体是亲本型。对 $K$ 取平均即得公式。$\square$

所以对任何距离都有 $r \le 1/2$，当区间长到几乎必然含有一次交换时，$r \to 1/2$。同一条**染色体**上相距很远的**基因**，其行为像不同染色体上的基因：它们是同线的（在同一条染色体上），但在遗传上不连锁。连锁是遗传学的陈述（能否表明亲本型过多？），同线性是物理的陈述。

**注 8.3.1（发生交换的性母细胞）** 对于短到决不会有一次以上交换的区间，$\mathbb{P}(K = 0) = 1 - p_{\mathrm{x}}$，其中 $p_{\mathrm{x}}$ 是区间内发生交换的性母细胞（精母细胞、卵母细胞、花粉母细胞或大孢子母细胞）的比例，公式 8.3.1 成为 $r = p_{\mathrm{x}}/2$：两个基因座之间有**交叉**的性母细胞的百分数是重组率的两倍。若 $16\,\%$ 的性母细胞在两个基因座之间有交叉，则 $r = 8\,\%$；反之，即使每个性母细胞在区间内都发生交换，$r$ 也不会超过 $1/2$。较老的教材把重组率称为"交换值"；严格说二者不同，因为只要出现多次交换，每条染色单体的平均交换数（图距，第 8.5 节）就超过重组率，教材中的说法"真实交换值 = 重组值 + 2 × 双交换值"就是算法 8.4.1 的三点校正。

### 8.3.3. 遗传图与连锁群

Alfred Sturtevant 当时是 Morgan 实验室的本科生，他在 1911 年意识到重组率可以用作距离：若它们近似可加，即三个基因座有 $r_{AC} \approx r_{AB} + r_{BC}$，则这些基因必定排成一条线。1913 年，他发表了第一张图，包含果蝇的五个 **X 连锁**基因。

**定义 8.3.3（遗传图）** **遗传图**（连锁图）是由重组率得出的染色体上基因座的线性顺序及其之间以厘摩为单位的距离。位置从一端算起；在果蝇中，位置与染色体一起写出，如 *black* 的 $2$-$48.5$。

![第一张遗传图与今天的遗传图。左：Sturtevant 1913 年依据黄体（*y*）、白眼（*w*）、朱红眼（*v*）、小翅（*m*）与残迹翅（*r*）之间的重组画出的果蝇 X 染色体图，位置以距 *y* 的厘摩数表示。右：这些基因今天的标准图位；虚线连接同一个基因。顺序没有改变；远端基因的位置移动了几个图距单位，主要是因为 Sturtevant 较长的区间低估了距离（双交换，第 8.4.2 节），也因为后来的图增加了许多短区间。](./plots/sturtevant-map.py)

**定义 8.3.4（连锁群）** **连锁群**是一组基因座，其中每一个都与至少另一个成员连锁，或是直接连锁，或是通过一串连锁的基因座。在作图良好的生物中，连锁群的数目等于**单倍体**的染色体数：黑腹果蝇 4 个，玉米 10 个，人类 23 个（计入 X；Y 基本上不重组）。

长染色体两端的两个基因在直接杂交中可以表现出 $r = 1/2$，但仍属于同一个连锁群，因为每一个都与它们之间的基因连锁。染色体的图因此可以超过 $50\,\mathrm{cM}$：果蝇的 $X$ 染色体图长约 $66\,\mathrm{cM}$，2 号染色体约 $107\,\mathrm{cM}$。

经典遗传图逐个基因构建，由此产生两个惯例。位置从最靠近一端的基因算起，该基因置于 $0$；当在它之外发现新基因时，零点移到新基因，所有位置随之移动（上述果蝇的位置保留了历史上位于 X 末端附近的 *yellow* 处的零点）。而在作图不充分的生物中，连锁群的数目可以向两个方向与单倍体数不同：没有找到标记的染色体不在其中，而一条长染色体的标记在它们之间的标记把两者连接起来之前，可以形成两个连锁群。在异配性别中，除**拟常染色体区**（[7.4.6](/7.4.6)）外，X 与 Y 是分开的连锁群。

## 8.4. 两点与三点杂交

### 8.4.1. 两点杂交及其局限

**定义 8.4.1（两点与三点杂交）** **两点测交**在双**杂合子**中测量两个**基因座**之间的重组率；**三点测交**在一次杂交中追踪三个连锁基因座，通常是三杂合子的**测交**，给出八类后代。

两点杂交可以给**基因**排序（距离最大的一对位于第三个基因的两侧），但有两个弱点。较小的差别在抽样误差之内：Sturtevant 的数据给出 $y$–$m$ 为 $34.3\,\%$，$w$–$m$ 为 $33.8\,\%$，除非样本很大，否则不能确定 $y$ 与 $w$ 相对于 $m$ 的顺序（从 1000 只果蝇估计 $\hat r = 0.34$ 的标准误为 $0.015$，第 8.6.1 节）。而且距离不能精确相加：长区间的重组率小于其各部分之和，因为其中的两次**交换**恢复了亲本组合。三点杂交在一个实验中解决这两个问题。

### 8.4.2. 三点测交

**定义 8.4.2（双交换）** 在基因座顺序为 $A$–$B$–$C$ 的三点杂交中，**双交换**（DCO）配子是在 $A$–$B$ 与 $B$–$C$ 两个区间都为重组型的配子；相对于亲本单倍型，它只交换了中间基因座的**等位基因**。

如果两个区间的交换独立发生，双交换配子的概率就是两个重组率之积 $r_1 r_2$；当 $r_1, r_2$ 为百分之几时，这是迄今最罕见的类型。因此八类后代按相互为倒易产物的四对出现，每对大小大致相等：两个亲本类（最大），两对单交换类（各区间一对），以及双交换类（最小）。由于双交换只改变中间的等位基因，把双交换类与亲本类比较，就能确定中间的基因。

**算法 8.4.1（三点测交的分析）**

1. 把八个表型类分成四对倒易类（在三个基因座上等位基因都互补的两个类）。
2. 最大的一对是三杂合子的亲本单倍型；最小的一对是双交换。
3. 找出双交换与它们在其他方面相似的亲本单倍型不同的那个基因座：该基因座在中间。把所有单倍型按基因顺序重写。
4. 只在第一个与中间基因座之间重组的一对是区间 1 的单交换，只在中间与最后一个基因座之间重组的一对是区间 2 的单交换。
5. 计算每个区间的重组率，两个区间的计数都包括双交换：$r_1 = (\mathrm{SCO}_1 + \mathrm{DCO})/n$，$r_2 = (\mathrm{SCO}_2 + \mathrm{DCO})/n$。
6. 外侧基因之间的图距为 $r_1 + r_2$（百分数，cM）。外侧基因的直接重组率 $(\mathrm{SCO}_1 + \mathrm{SCO}_2)/n$ 小 $2\,\mathrm{DCO}/n$。
7. 计算双交换的期望数 $r_1 r_2 n$、**并发系数** $C = \mathrm{DCO}/(r_1 r_2 n)$ 与**干涉** $I = 1 - C$（第 8.4.3 节）。

**注 8.4.1** 该算法假设三个基因座都连锁。应用之前，先把数据归并到每一对基因座上，检查这一对是否连锁（算法 8.7.1）。若某个基因座与另外两个独立分配，则八类后代形成四对大小接近的类，它们只在该基因座上不同；这时两个最小的类不是双交换，数据按连锁的那一对的两点杂交分析。若只出现四个类，则其中两个基因座在杂合亲本中完全连锁（第 8.7.2 节），或靠得太近以致样本中看不到任何重组型。

**例 8.4.1** 对**隐性**的 2 号染色体**突变** $b$（黑体）、$pr$（紫眼）与 $vg$（残翅）杂合的果蝇雌蝇，与 $b\,pr\,vg/b\,pr\,vg$ 雄蝇测交。4000 个后代按雌蝇的配子列于下表：

| 配子 | 数目 | | 配子 | 数目 |
|---|---|---|---|---|
| $b^{+}\,pr\,vg^{+}$ | 1640 | | $b^{+}\,pr\,vg$ | 247 |
| $b\,pr^{+}\,vg$ | 1632 | | $b\,pr^{+}\,vg^{+}$ | 241 |
| $b\,pr\,vg^{+}$ | 118 | | $b^{+}\,pr^{+}\,vg^{+}$ | 5 |
| $b^{+}\,pr^{+}\,vg$ | 110 | | $b\,pr\,vg$ | 7 |

亲本单倍型是 $b^{+}\,pr\,vg^{+}$ 与 $b\,pr^{+}\,vg$（1640、1632）；双交换是 $b^{+}\,pr^{+}\,vg^{+}$ 与 $b\,pr\,vg$（5、7）。双交换 $b^{+}\,pr^{+}\,vg^{+}$ 与亲本 $b^{+}\,pr\,vg^{+}$ 只在 $pr$ 处不同，所以 $pr$ 在中间，按基因顺序的亲本单倍型是 $b^{+}\,pr\,vg^{+}$ 与 $b\,pr^{+}\,vg$（列表的顺序恰好是正确的）。类 $b\,pr\,vg^{+}$ 与 $b^{+}\,pr^{+}\,vg$（118 + 110）相对于 $pr$ 与 $vg$ 改变了 $b$ 等位基因，所以它们是区间 $b$–$pr$ 的单交换；类 $b^{+}\,pr\,vg$ 与 $b\,pr^{+}\,vg^{+}$（247 + 241）是 $pr$–$vg$ 的单交换。于是

$$
r_{b\text{–}pr} = \frac{228 + 12}{4000} = 0.060, \qquad r_{pr\text{–}vg} = \frac{488 + 12}{4000} = 0.125,
$$
图为 $b$ —$6.0\,\mathrm{cM}$— $pr$ —$12.5\,\mathrm{cM}$— $vg$，$b$–$vg$ 为 $18.5\,\mathrm{cM}$。同样数据中 $b$ 与 $vg$ 之间的直接重组率为 $(228 + 488)/4000 = 17.9\,\%$：外侧基因的两点杂交会漏掉其中两次交换相互抵消的 24 条染色单体（12 个配子被计了两次）。

这一过程容易自动化，可以用来核对手算：

```python
def three_point(counts):
    """counts: {haplotype tuple such as ('b+', 'pr', 'vg+'): number}. Returns order, r1, r2, C."""
    n = sum(counts.values())
    hap = sorted(counts, key=counts.get, reverse=True)
    p1, p2, dco = hap[0], hap[1], hap[-1]          # parental classes, one double-crossover class
    near = min((p1, p2), key=lambda p: sum(a != b for a, b in zip(p, dco)))
    mid = next(k for k in range(3) if dco[k] != near[k])   # the locus switched in the DCO
    order = [k for k in range(3) if k != mid]
    order.insert(1, mid)
    def switched(h, i, j):                          # recombinant between loci i and j?
        return (h[i] == p1[i]) != (h[j] == p1[j])
    a, b, c = order
    r1 = sum(m for h, m in counts.items() if switched(h, a, b)) / n
    r2 = sum(m for h, m in counts.items() if switched(h, b, c)) / n
    d = sum(m for h, m in counts.items() if switched(h, a, b) and switched(h, b, c)) / n
    return order, r1, r2, d / (r1 * r2)
```

### 8.4.3. 并发与干涉

在例 8.4.1 中，独立性预测有 $r_1 r_2 n = 0.060 \times 0.125 \times 4000 = 30$ 个双交换，但只看到 12 个。双交换偏少是大多数生物中的通则。

**定义 8.4.3（并发系数与干涉）** 对重组率为 $r_1$ 与 $r_2$ 的两个相邻区间，**并发系数**是双交换的观察数与期望数之比，

$$
C = \frac{\text{observed DCO frequency}}{r_1 r_2},
$$
**干涉**为 $I = 1 - C$。$I = 0$ 表示两个区间的交换独立发生；$I = 1$（完全干涉）表示一个区间的交换阻止另一个区间的交换；$I < 0$（负干涉）表示双交换过多。

在例 8.4.1 中，$C = 12/30 = 0.40$，$I = 0.60$。这里的干涉是交换干涉：它在沿**二价体**的**交叉**之间起作用，在短距离上效应最强；在大多数生物中，$10$–$20\,\mathrm{cM}$ 内它几乎是完全的，并随距离而减弱（图见第 8.5.3 节）。它由**联会复合体**与减数分裂**染色体**的轴介导，这些结构把抑制信号从一个指定的交换处向外传播；一种模型把轴看作缓解机械应力的梁（Kleckner）。第二种干涉是染色单体干涉，即相继交换所涉及的染色单体不是随机选取的；在用四分子分析检验的大多数生物中它很弱或不存在（[7.4.9](/7.4.9#sec-9.4)），本章的公式假设它不存在。在噬菌体和真菌的基因内精细杂交中发现负干涉，其中靠近的双交换的明显过多反映的是单次重组事件中异源双链 DNA 的**错配修复**（基因转换，[7.4.9](/7.4.9#sec-9.4)）。

**例 8.4.2（玉米中的两点与三点数据）** 玉米 9 号染色体上的三个基因，$C$/$c$（有色或无色糊粉层）、$Sh$/$sh$（饱满或皱缩胚乳）与 $Wx$/$wx$（淀粉质或蜡质胚乳），在经典实验中用两种方式作图。三个两点测交给出 $r_{C\text{–}Sh} = 3.6\,\%$、$r_{Wx\text{–}Sh} = 20\,\%$ 与 $r_{Wx\text{–}C} = 22\,\%$，把 $Sh$ 置于中间。三杂合子的一次三点测交给出图 $wx$ —$18.4$— $sh$ —$3.5$— $c$，共 $21.9\,\mathrm{cM}$，双交换占 $0.09\,\%$，而期望为 $0.184 \times 0.035 = 0.64\,\%$：$C = 0.14$，$I = 0.86$。三点距离比两点距离略小，尽管只有它们才包括双交换。原因是这些估计来自不同的杂交：植株的遗传背景、生长条件与杂合亲本的性别各不相同，这些都影响重组（第 8.8.1 节），而且每个估计都有自己的抽样误差（从 1000 粒籽粒估计 $\hat r = 0.2$ 时 $\operatorname{se} = 0.013$）。因此，图应根据同一设计中作出的估计来构建，最好用标记间距很近的一次多点杂交，而不是合并不同实验的距离。

## 8.5. 作图函数

### 8.5.1. 由重组率到图距

图距 $d$（以摩为单位）定义为区间内每条染色单体的**交换**期望数；由于一个**交叉**涉及四条染色单体中的两条，每个二价体在该区间内的交叉期望数为 $2d$。图距按定义是可加的（期望可加），而重组率不可加，因为多次交换可以相互抵消。作图函数把二者互相转换。

**定义 8.5.1（作图函数）** **作图函数**是给出图长为 $d$ 的区间的重组率的函数 $r = M(d)$，由交换如何分布的模型导出；其反函数 $d = M^{-1}(r)$ 把观察到的重组率换算为可加的距离。每个作图函数都满足：$d$ 小时 $M(d) \approx d$，$d \to \infty$ 时 $M(d) \to 1/2$。

**公式 8.5.1（Haldane 作图函数）** 若交换沿**染色体**作为 Poisson 过程发生（无干涉）且无染色单体干涉，则区间内的交叉数 $K \sim \mathrm{Poi}(2d)$，且

$$
r = \tfrac12\bigl(1 - \mathrm{e}^{-2d}\bigr), \qquad d = -\tfrac12\ln(1 - 2r).
$$

**证明** 由公式 8.3.1，$r = \frac12\bigl(1 - \mathbb{P}(K = 0)\bigr)$，而对均值为 $2d$ 的 **Poisson 分布**，$\mathbb{P}(K = 0) = \mathrm{e}^{-2d}$。解出 $d$ 即得反函数。$\square$

Haldane 在 1919 年推出这一函数。它对其模型是精确的，但忽略干涉，所以在干涉强的地方会高估距离。Kosambi（1944）提出一个函数，其中相邻短区间之间的并发随距离按 $C = 2r$ 增大，使很近的区间干涉完全，而在 $r = 1/2$ 处干涉消失；对所得微分方程 $\mathrm{d}r/\mathrm{d}d = 1 - 4r^2$ 积分得到：

**公式 8.5.2（Kosambi 作图函数）**

$$
r = \tfrac12\tanh(2d), \qquad d = \tfrac14\ln\frac{1 + 2r}{1 - 2r}.
$$

**例 8.5.1** 两个**基因座**的 $r = 0.30$。Haldane 距离为 $-\frac12\ln 0.4 = 0.458\,\mathrm{M} = 45.8\,\mathrm{cM}$；Kosambi 距离为 $\frac14\ln(1.6/0.4) = \frac14\ln 4 = 0.347\,\mathrm{M} = 34.7\,\mathrm{cM}$。在 $r = 0.05$ 时二者为 $5.27$ 与 $5.02\,\mathrm{cM}$：只有对长区间，选择才有影响。

| $r$ | 0.05 | 0.10 | 0.20 | 0.30 | 0.40 | 0.45 |
|---|---|---|---|---|---|---|
| Haldane $d$ / cM | 5.3 | 11.2 | 25.5 | 45.8 | 80.5 | 115.1 |
| Kosambi $d$ / cM | 5.0 | 10.1 | 21.2 | 34.7 | 54.9 | 73.6 |

![作图函数。左：线性关系 r = d（适用于短区间）、Haldane 函数（无干涉）与 Kosambi 函数（干涉随距离减弱）的重组率 r 对图距 d 的关系；二者都趋近上限 r = 1/2。右：反函数，用于把观察到的重组率换算为可加的图距；r 大于约 0.3 时，二者给出的距离相差很大。](./plots/mapping-functions.py)

### 8.5.2. 函数的选择

短区间可以避开这一问题：由许多小于 $10\,\mathrm{cM}$ 的区间构建的图，在任何作图函数下距离几乎相同，所以经典遗传学的建议，即用许多间距很近的标记作图，也是现代的做法。Kosambi 函数对大多数高等**真核生物**的描述优于 Haldane 函数，是植物与动物连锁作图软件的默认选项；人类遗传学在多点计算中使用 Haldane 函数，因为它使各区间独立（Markov 性质，简化**似然**）。二者都不是机制模型。$r$ 与概率 $\mathbb{P}(K = 0)$ 的关系（公式 8.3.1）还表明，没有任何作图函数能对所有生物都精确：它取决于交换数如何分布，而这在物种、性别和染色体之间各不相同。

### 8.5.3. 干涉模型

一个能拟合许多物种干涉的模型是 Foss、Stahl 等人的卡方（计数）模型（Zhao、Speed 与 McPeek，1995）：重组中间体沿二价体作为 Poisson 过程分布，只有每第 $(m+1)$ 个成为交叉，其余被解离为非交换。相继交叉之间的距离则服从形状参数 $\nu = m + 1$ 的 **Gamma 分布**（速率为每摩 $2\nu$，均值为 $1/2$ 摩），而不是 Poisson 情形（$\nu = 1$）的指数分布。估计值在果蝇和人类中为 $\nu \approx 4$–$5$，某些真菌中更大；有两条交换途径的生物（芽殖酵母、拟南芥、哺乳动物）除了由 MutLγ 产生的有干涉类交换之外，还有由 MUS81 产生的次要的无干涉类交换（[7.2.9](/7.2.9#sec-9.5.2)）。

![有干涉与无干涉的模拟交换（100 cM 的二价体）。(A) 25 次模拟减数分裂中的交叉位置，左为 Poisson 模型（nu = 1），右为 nu = 4 的 gamma（卡方）模型：有干涉时，交叉均匀分布，几乎从不靠近。(B) 两个 5 cM 区间之间的并发系数 C 随两区间中心距离的变化，由 60 000 条模拟染色单体估计：无干涉时 C 保持在 1 附近，有干涉时靠近的区间 C 接近 0，并在 40 至 50 cM 之外升到约 1。(C) 每个二价体的交叉数：nu = 1 时为 Poisson（均值 2，分布很宽），nu = 4 时变异小得多，所以几乎每个二价体都至少有一个交叉，符合必需交换的要求。](./plots/interference-simulation.py)

## 8.6. 重组率的估计

### 8.6.1. 测交：二项估计

在**测交**中，$n$ 个后代各自独立地以概率 $r$ 为重组型，所以重组型数 $R \sim \mathrm{Bin}(n, r)$（**二项分布**，[3.1.4](/3.1.4#sec-4.1.3)）。

**公式 8.6.1（测交估计）** 由测交得到的 $r$ 的**极大似然估计量**是 $\hat r = R/n$，其**标准误**为

$$
\operatorname{se}(\hat r) = \sqrt{\frac{\hat r(1 - \hat r)}{n}},
$$
近似的 $95\,\%$ **置信区间**为 $\hat r \pm 1.96\operatorname{se}(\hat r)$。

在例 8.1.1 中，$\hat r = 0.18$，$\operatorname{se} = \sqrt{0.18 \times 0.82/1000} = 0.012$，$95\,\%$ 区间为 $0.156$–$0.204$。标准误按 $1/\sqrt n$ 变化：要使其减半需要四倍的后代，这就是为什么用两点杂交给相距 $1\,\mathrm{cM}$ 的**基因**排序需要几千只果蝇，也是为什么三点杂交（顺序是由罕见的双交换类而不是由估计值之间的差别读出的）更有效。

### 8.6.2. F2 数据：自交与平方根法

在自交比测交容易的植物中，重组率常常由 F2 估计。当两个**基因座**都是**完全显性**时，双**杂合子**产生配子 $AB$、$Ab$、$aB$、$ab$，频率取决于连锁相，只有双隐性类 $aabb$ 能毫不含糊地揭示配子：它要求双方都提供 $ab$ 配子。

**公式 8.6.2（平方根法）** 在完全显性的双杂合子的 F2 中，设 $f$ 为 $aabb$ 后代的观察比例。在相引（$AB/ab$）中，$ab$ 配子的频率为 $(1 - r)/2$，所以 $f = \bigl((1 - r)/2\bigr)^2$，且

$$
\hat r = 1 - 2\sqrt{f};
$$
在相斥（$Ab/aB$）中，$ab$ 配子是重组型，$f = (r/2)^2$，$\hat r = 2\sqrt{f}$。

平方根法只用了四类中的一类。极大**似然**法用到全部数据。相引时记 $\varphi = (1 - r)^2$，相斥时记 $\varphi = r^2$。对两个（相同的）配子分布的 **Punnett 方格**的 16 个格子求和，得到四个**表型**类：

$$
\mathbb{P}(A\_B\_) = \frac{2 + \varphi}{4}, \qquad \mathbb{P}(A\_bb) = \mathbb{P}(aaB\_) = \frac{1 - \varphi}{4}, \qquad \mathbb{P}(aabb) = \frac{\varphi}{4},
$$
在 $\varphi = 1/4$（$r = 1/2$）时化为 9:3:3:1。

**公式 8.6.3（由 F2 的极大似然估计）** 设类 $A\_B\_$、$A\_bb$、$aaB\_$、$aabb$ 的计数为 $n_1, n_2, n_3, n_4$（$n = \sum n_i$），则**似然函数**是多项式的，对数似然为

$$
\ell(\varphi) = n_1\ln(2 + \varphi) + (n_2 + n_3)\ln(1 - \varphi) + n_4\ln\varphi + \text{const}.
$$
令 $\ell'(\varphi) = 0$ 得到二次方程

$$
n\varphi^2 - (n_1 - 2n_2 - 2n_3 - n_4)\varphi - 2n_4 = 0,
$$
其正根为 $\hat\varphi$；于是 $\hat r = 1 - \sqrt{\hat\varphi}$（相引）或 $\hat r = \sqrt{\hat\varphi}$（相斥）。每株植物关于 $\varphi$ 的 **Fisher 信息**为 $\sum_i (\partial p_i/\partial\varphi)^2/p_i = \frac{1}{16}\bigl(\frac{4}{2+\varphi} + \frac{8}{1-\varphi} + \frac{4}{\varphi}\bigr)$，且 $\operatorname{se}(\hat r) = \operatorname{se}(\hat\varphi)/\lvert \mathrm{d}\varphi/\mathrm{d}r\rvert = \operatorname{se}(\hat\varphi)/(2\sqrt{\hat\varphi})$。

这个模型是 **EM 算法**的教科书例子，该算法把 $A\_B\_$ 类看作两个未观测格子的混合（[3.5.6](/3.5.6#sec-6.1.4) 的多项式例子，其 $\theta$ 就是这里的 $\varphi$）；在这里二次方程直接给出答案。

**例 8.6.1** Bateson 的香豌豆 F2（第 8.1.1 节）是相引的（$PL/pl$）：$n_1 = 4831$，$n_2 = 390$，$n_3 = 393$，$n_4 = 1338$，$n = 6952$。对 9:3:3:1 的**拟合优度检验**给出 $\chi^2 = 3372$，**自由度**为 3，是压倒性的拒绝。二次方程 $6952\varphi^2 - (4831 - 1566 - 1338)\varphi - 2676 = 0$，即 $6952\varphi^2 - 1927\varphi - 2676 = 0$，的正根为 $\hat\varphi = 0.7743$，所以 $\hat r = 1 - \sqrt{0.7743} = 0.120$，$\operatorname{se}(\hat r) = 0.0042$。平方根法给出 $1 - 2\sqrt{1338/6952} = 0.123$，接近但精度较低。这两个基因相距约 $12\,\mathrm{cM}$（它们位于香豌豆 *Lathyrus odoratus* 的 7 号**染色体**上）。

**例 8.6.2（相斥的 F2）** Bateson 的第二个香豌豆 F2（第 8.1.1 节）来自 $Pl/pL$（相斥）：$n_1 = 226$，$n_2 = 95$，$n_3 = 97$，$n_4 = 1$，$n = 419$。每个基因座都按 $3:1$ 分离（紫 : 红为 $321 : 98$，长 : 圆为 $323 : 96$）。平方根法给出 $\hat r = 2\sqrt{1/419} = 0.098$。对极大似然估计，$n_1 - 2n_2 - 2n_3 - n_4 = -159$，所以 $419\varphi^2 + 159\varphi - 2 = 0$，$\hat\varphi = 0.0122$，$\hat r = \sqrt{\hat\varphi} = 0.110$，$\operatorname{se}(\hat r) = 0.048$。该估计与相引杂交（$0.120$）一致，但样本小十七倍，精度约低十一倍；几乎所有信息都在那一株红花圆花粉植株中（第 8.6.3 节）。

### 8.6.3. 哪种设计的信息最多？

一个后代带有的关于 $r$ 的信息量取决于杂交方式（见图）。对测交，它是 $1/\bigl(r(1 - r)\bigr)$。相引的**显性**标记的 F2 几乎同样有信息（每株 F2 植物取样两次减数分裂，但显性掩盖了许多信息），**共显性**标记（如 DNA 标记，[7.4.14](/7.4.14)）的 F2 在 $r$ 小时的信息约为测交的两倍，而显性标记相斥的 F2 对紧密连锁几乎没有用：在 $r = 0.05$ 时，一株相斥 F2 植物所带的信息约为一个测交后代的 $1/20$，因为揭示重组的类 $aabb$ 的频率是 $r^2/4$。由于 $\hat r$ 的方差为 $1/(n I(r))$，信息为 $I$ 的设计要达到给定的精度需要 $n \propto 1/I$ 个个体。

## 8.7. 连锁的检验

### 8.7.1. 卡方检验

在估计距离之前，我们先问这两个**基因座**到底是否连锁：亲本型过多是否超出偶然？自然的零假设是 $r = 1/2$。一个诱人的检验是对测交的四个类作 1:1:1:1 的拟合优度检验，但它有 3 个自由度，三个原因中任何一个都会导致拒绝：连锁、基因座 $A$ 的不等分离、基因座 $B$ 的不等分离（例如突变体生活力较低）。能分离出连锁的检验，是对两个基因座的**基因型**的 $2 \times 2$ **列联表**作独立性检验（[3.2.6](/3.2.6#sec-6.4)），它不假设 1:1 分离。

**算法 8.7.1（测交中连锁的卡方检验）**

1. 把测交后代排成 $2 \times 2$ 表：行为基因座 $A$ 的基因型（$Aa$ 或 $aa$），列为基因座 $B$ 的基因型。
2. 计算独立性下的期望数，$E_{ij} = (\text{row}_i \text{ total})(\text{column}_j \text{ total})/n$。
3. 计算 $\chi^2 = \sum_{ij}(O_{ij} - E_{ij})^2/E_{ij}$，与自由度为 1 的**卡方分布**比较（$\alpha = 0.05$ 时临界值为 $3.84$，$0.01$ 时为 $6.63$）。
4. 若独立性的**零假设**被拒绝且亲本类过多，则断定两个基因座连锁，并估计 $\hat r$。

**例 8.7.1** 对例 8.1.1，表为：$b^{+}vg^{+}$ 405，$b^{+}vg$ 88，$b\,vg^{+}$ 92，$b\,vg$ 415。边缘合计为 493、507（行）与 497、503（列），例如 $E_{11} = 493 \times 497/1000 = 245.0$。于是 $\chi^2 = 409.6$，自由度为 1，$p \approx 10^{-90}$：连锁的有力证据。样本小时，结论远不明确：40 个后代中有 14 个重组型（$\hat r = 0.35$），给出 $\chi^2 = 3.6$（若边缘合计为 20:20），在 $5\,\%$ 水平不显著，尽管这些**基因**很可能连锁。样本量是任何"不连锁"的结论中必不可少的部分。

$r = \hat r$ 对 $r = 1/2$ 的**似然比**是人类遗传学 LOD 值的基础：LOD 是这一**似然比**（[3.2.5](/3.2.5#sec-5.3)）的 $\log_{10}$，$Z = \log_{10}\bigl[\hat r^{R}(1 - \hat r)^{n - R}/(1/2)^n\bigr]$。对例 8.1.1，$Z = 96.3$。在人类家系中，每次**减数分裂**都很宝贵，证据是跨家系累积的，LOD 为 3 是约定的阈值（[7.4.14](/7.4.14)）。

### 8.7.2. 单一性别中的完全连锁

在果蝇的雄性中根本没有**交换**：雄性减数分裂是无交叉的，**同源染色体**靠特殊的配对**蛋白质**保持在一起。因此同一条**染色体**上的两个基因座由雄性传递时是完全连锁的，相引的雄性双**杂合子**只传递 $AB$ 与 $ab$。家蚕 *Bombyx mori* 的情形相反，雌性减数分裂是无交叉的。在两种情况下，没有交换的性别都是异配性别。这条规律，即只有一种性别没有交换时，它是异配性别，称为 Haldane–Huxley 法则（Haldane–Huxley rule）（Haldane 1922，Huxley 1928），极少有例外；它不同于 Haldane 关于物种杂交中异配性别杂种不育的法则。在其他生物中，两种性别都发生交换，但速率不同（第 8.8.1 节）。这有实用价值：把杂合的雄性与**隐性**雌性回交，若两个基因同线则只有两个类，这是确定基因属于哪条染色体的快速检验；雄性中没有重组，使果蝇遗传学家能让染色体完整地保持许多代。

## 8.8. 重组图景

### 8.8.1. 遗传长度与交换计数

重组率是**减数分裂**的性质，所以同一条**染色体**的图在不同性别和物种之间不同。以摩为单位的染色体遗传长度是每条染色单体的平均**交换**数；必需交换使任何一对染色体臂的下限约为 $50\,\mathrm{cM}$。人类**常染色体**的性别平均总长约 $35\,\mathrm{M}$：**系谱**研究数得，经父方传递的**基因组**约有 27 次交换，经母方传递的约有 42 次，而对粗线期标记交换的 MLH1 位点的细胞学计数，给出每次减数分裂约为这些数字的两倍（精母细胞中约 50，卵母细胞中约 70），这符合预期，因为配子只得到二价体交换的一半。女性图比男性图长约 $1.6$–$1.7$ 倍。常染色体序列约有 $2.9 \times 10^9$ bp，平均速率约为 $1.2\,\mathrm{cM/Mb}$。不同生物的速率差别很大：果蝇约 $2\,\mathrm{cM/Mb}$（$140\,\mathrm{Mb}$ **常染色质**的基因组约 $280\,\mathrm{cM}$），芽殖酵母约 $350\,\mathrm{cM/Mb}$（每厘摩几千碱基），而小麦等大型植物基因组远低于 $1\,\mathrm{cM/Mb}$。由于每条染色体的交换数几乎由必需交换与干涉所固定，小染色体每兆碱基的速率较高。

同一物种内，两个**基因座**之间的重组率也不是常数，这是不同实验测得的距离不一致的原因之一（例 8.4.2）。它取决于**杂合**亲本的性别（见上；哺乳动物中雌性图较长，果蝇和家蚕中有一种性别完全没有，第 8.7.2 节）、年龄（果蝇雌蝇中随母体年龄而变化）、温度（果蝇中在低温和高温下都升高，Plough 1917）、**修饰基因**所在基因座上的**基因型**（第 8.8.2 节的 PRDM9 **等位基因**）以及染色体本身：杂合的倒位或易位抑制其附近回收到的交换（[7.4.15](/7.4.15)），相互易位甚至使两条不同染色体上的基因座表现为连锁（假连锁，[7.4.15](/7.4.15#sec-15.5.3)）。电离辐射和丝裂霉素 C 等损伤 DNA 的试剂会提高交换的频率，对有丝分裂交换尤其如此（[7.4.9](/7.4.9#sec-9.5)）。

### 8.8.2. 热点

在一条染色体内，交换集中在重组热点（recombination hotspot）中，这是 $1$–$2\,\mathrm{kb}$ 的区域，其重组频率比侧翼序列高十倍到一千倍；在人类中，大多数交换落在只占基因组很小一部分的热点内。人类和小鼠中，热点由 PRDM9 决定，这是一种锌指**组蛋白**甲基转移酶，其阵列结合一个简并的基序（最常见的人类等位基因为 13 聚体 CCNCCNTNNCCNC），并用 H3K4me3 与 H3K36me3 标记**核小体**，SPO11 随后在此切割（[7.2.9](/7.2.9#sec-9.5.2)）。锌指阵列进化很快，所以热点在不同的人群之间（不同 PRDM9 等位基因的**携带者**）、人与黑猩猩之间（几乎没有共有的热点）以及小鼠亚种之间都不同；热点还会自我侵蚀，因为断裂的同源染色体用未断裂的那条修复，基序因**基因**转换而丢失。没有功能性 PRDM9 的哺乳动物（如犬）以及酵母和植物，则把断裂放在**启动子**和其他开放的**染色质**处。重组在**着丝粒**附近和**异染色质**中受到抑制，在大的倒位中也常如此（[7.4.15](/7.4.15)）。

### 8.8.3. 遗传图与物理图

**定义 8.8.1（物理图）** **物理图**以 DNA 长度单位（**碱基对**）给出染色体上基因座或标志的位置，或按其相对于细胞学标志（带、克隆片段）的顺序给出；完整的基因组序列是终极的物理图。

遗传图与物理图在顺序上一致，但标度不一致，因为交换分布不均匀。以遗传位置对物理位置作图（Marey 图）得到一条单调曲线，其斜率是以 $\mathrm{cM/Mb}$ 为单位的局部重组率：在着丝粒和异染色质处平坦，在热点丰富的臂上陡峭（见图）。直到 1980 年代，遗传图是定位基因的唯一方法，现在它仍是找出只知道**表型**的基因的方法：与物理位置已知的分子标记连锁，就能指向候选区域，进而找到基因。囊性纤维化基因是经典的例子。1938 年至 1985 年间，对其位置一无所知；后来发现它与**酶**的**多态性** PON 以及 7 号染色体上的 DNA 标记连锁，并由更多的标记缩小范围，直到 1989 年克隆出基因 *CFTR*（[7.4.14](/7.4.14)）。

![模拟的 100 Mb 近中着丝粒染色体的遗传图与物理图。(A) 沿染色体的局部重组率（cM/Mb）：着丝粒周围受到抑制，向端粒方向升高，并有狭窄的热点。(B) Marey 图：累积遗传位置（cM）对物理位置（Mb）；其斜率是局部速率，在着丝粒处平坦，在远端臂上陡峭。虚线是整条染色体的平均值。参数为示意值。](./plots/genetic-physical-map.py)

## 小结

- **连锁**（定义 8.1.2）：亲本型过多，重组率 $r < 1/2$；连锁相（定义 8.1.3）决定哪些类是亲本型（定义 8.1.1）。**测交**后代直接读出配子（例 8.1.1）。
- 重组是四链期非姐妹染色单体之间的**交换**（第 8.2 节）；一次交换使四条染色单体中的两条重组，染色单体随机参与时 $r = \frac12(1 - \mathbb{P}(K = 0)) \le \frac12$（公式 8.3.1）。
- 重组率（定义 8.3.1）、厘摩（定义 8.3.2）、遗传图（定义 8.3.3）与连锁群（定义 8.3.4），连锁群的数目与**单倍体**的**染色体**数一样多。短区间内有**交叉**的性母细胞 $= 2r$（注 8.3.1）。
- 三点测交（算法 8.4.1）：最大的一对是亲本型，最小的一对是双交换（定义 8.4.2），中间的**基因**是在双交换中被换掉的那个；$r_i = (\mathrm{SCO}_i + \mathrm{DCO})/n$；并发 $C = \mathrm{DCO}/(r_1 r_2)$，干涉 $I = 1 - C$（定义 8.4.3；例 8.4.1：图 $6.0 + 12.5\,\mathrm{cM}$，$C = 0.4$）。先检查两两连锁（注 8.4.1）；不同实验的距离不必一致（例 8.4.2）。
- 作图函数（定义 8.5.1）：

  | 模型 | $r(d)$ | $d(r)$ |
  |---|---|---|
  | 短区间 | $r \approx d$ | $d \approx r$ |
  | Haldane（Poisson，公式 8.5.1） | $\frac12(1 - \mathrm{e}^{-2d})$ | $-\frac12\ln(1 - 2r)$ |
  | Kosambi（公式 8.5.2） | $\frac12\tanh 2d$ | $\frac14\ln\frac{1+2r}{1-2r}$ |

  干涉用 gamma（卡方）模型描述，果蝇和人类中 $\nu \approx 4$–$5$（第 8.5.3 节）。
- 估计：测交 $\hat r = R/n$，$\operatorname{se} = \sqrt{\hat r(1 - \hat r)/n}$（公式 8.6.1）；F2 的平方根法，相引 $1 - 2\sqrt f$，相斥 $2\sqrt f$（公式 8.6.2）；F2 的极大似然估计由二次方程 $n\varphi^2 - (n_1 - 2n_2 - 2n_3 - n_4)\varphi - 2n_4 = 0$ 给出（公式 8.6.3；例 8.6.1，香豌豆 $\hat r = 0.120$；相斥例 8.6.2，$0.110 \pm 0.048$）。每个后代的信息：**共显性**标记 F2 > 测交 ≳ 相引的**显性**标记 F2 ≫ 相斥的显性标记 F2。
- 用 $2 \times 2$ 独立性 $\chi^2$（自由度 1）检验连锁，而不用 1:1:1:1 的拟合（算法 8.7.1）；LOD 值是 $r = \hat r$ 对 $1/2$ 的 $\log_{10}$ **似然比**。
- 果蝇雄性与家蚕雌性，即异配性别，没有交换（Haldane–Huxley 法则，第 8.7.2 节）。
- 重组图景：人类**常染色体**约 $35\,\mathrm{M}$，女性图约为男性的 1.6–1.7 倍，约 $1.2\,\mathrm{cM/Mb}$；哺乳动物的热点由 PRDM9 决定；**着丝粒**处受抑制；重组还随年龄、温度、**修饰基因**与重排而变（第 8.8 节）。遗传图与物理图（定义 8.8.1）顺序相同，标度不同。

## 思考题

1. 对 $Aa\,Bb$ 个体的**测交**产生 92 个 $AB$、108 个 $ab$、9 个 $Ab$ 与 11 个 $aB$ 后代（按**杂合子**的配子分类）。杂合子的连锁相是什么？$\hat r$、它的标准误和 95 % 置信区间是多少？

   **答** 频繁的类 $AB$ 与 $ab$ 是亲本型，所以杂合子是相引的，$AB/ab$。$\hat r = 20/220 = 0.0909$，$\operatorname{se} = \sqrt{0.0909 \times 0.9091/220} = 0.0194$，区间为 $0.0909 \pm 0.0380$，即 $0.053$–$0.129$（约 $9\,\mathrm{cM}$）。

2. 在 $Ab/aB$（相斥）与 $ab/ab$ 的杂交中，预期有 1000 个后代。若两个**基因座**相距 $16\,\mathrm{cM}$，并可忽略多次**交换**，每一类预期有多少后代？

   **答** 亲本（相斥）配子 $Ab$ 与 $aB$ 各为 $(1 - 0.16)/2 = 0.42$，重组型 $AB$ 与 $ab$ 各为 $0.08$：420 个 $Ab$、420 个 $aB$、80 个 $AB$、80 个 $ab$。

3. 为什么两个基因座之间的一次交换只产生一半的**重组配子**？为什么这意味着对任何距离都有 $r \le 1/2$？

   **答** 交换发生在四链期，涉及四条染色单体中的两条，所以区间内有一次交换的**二价体**产生两条重组染色单体和两条亲本染色单体。有多次交换且随机选择染色单体时，一条给定的染色单体以概率 $1/2$ 参与每次交换，若参与了奇数次就是重组的；已知 $k \ge 1$ 次交换时，这一概率恰好是 $1/2$（公式 8.3.1）。因此 $r = \frac12\,\mathbb{P}(\text{at least one crossover}) \le \frac12$。

4. **基因** $a$、$b$、$c$ 连锁。两点杂交给出 $r_{ab} = 0.08$、$r_{bc} = 0.15$、$r_{ac} = 0.21$。基因的顺序是什么？为什么 $r_{ac}$ 小于 $0.08 + 0.15$？

   **答** 最大的距离是 $a$–$c$，所以 $b$ 在中间：$a$–$b$–$c$。$r_{ac}$ 比总和 $0.23$ 小，因为 $a$–$c$ 区间内的双交换恢复了 $a$ 与 $c$ 的亲本组合，不被计为重组型；无干涉时，缺少的部分约为 $2 r_{ab} r_{bc} = 0.024$，与观察到的 $0.02$ 接近。

5. 对玉米三杂合子的三点测交给出（杂合子的配子）：$+\,+\,+$ 74、$+\,+\,c$ 382、$+\,b\,+$ 3、$+\,b\,c$ 98、$a\,+\,+$ 106、$a\,+\,c$ 5、$a\,b\,+$ 364、$a\,b\,c$ 66（共 1098）。确定亲本单倍型、基因顺序、图距、并发系数和干涉。

   **答** 亲本型：$+\,+\,c$（382）与 $a\,b\,+$（364）。双交换：$+\,b\,+$（3）与 $a\,+\,c$（5）。双交换 $a\,+\,c$ 与亲本 $+\,+\,c$ 只在 $a$ 处不同，所以 $a$ 是中间基因，顺序为 $b$–$a$–$c$。按此顺序，亲本单倍型是 $+\,+\,c$ 与 $b\,a\,+$。$b$ 与 $a$ 之间的单交换只换掉 $b$：$b\,+\,c$（98）与 $+\,a\,+$（106），共 204。$a$ 与 $c$ 之间的单交换只换掉 $c$：$+\,+\,+$（74）与 $b\,a\,c$（66），共 140。于是 $r_{ba} = (204 + 8)/1098 = 0.193$，$r_{ac} = (140 + 8)/1098 = 0.135$；图为 $b$ —$19.3\,\mathrm{cM}$— $a$ —$13.5\,\mathrm{cM}$— $c$（共 $32.8\,\mathrm{cM}$）。期望的双交换数为 $0.193 \times 0.135 \times 1098 = 28.6$；$C = 8/28.6 = 0.28$，$I = 0.72$。

6. 在思考题 5 的杂交中，若干涉改为 $0.3$，预期有多少双交换后代？

   **答** $C = 0.7$，所以 $0.7 \times 0.193 \times 0.135 \times 1098 = 20$ 个双交换。

7. 用 Haldane 与 Kosambi 函数把重组率 $0.10$ 与 $0.40$ 换算为图距。哪一次换算使结果变化更大，为什么？

   **答** $r = 0.10$：Haldane $-\frac12\ln 0.8 = 11.2\,\mathrm{cM}$，Kosambi $\frac14\ln(1.2/0.8) = 10.1\,\mathrm{cM}$。$r = 0.40$：Haldane $-\frac12\ln 0.2 = 80.5\,\mathrm{cM}$，Kosambi $\frac14\ln 9 = 54.9\,\mathrm{cM}$。长区间变化更大，因为对未检出的多次交换的校正随距离增大，而且两个模型假设的干涉程度不同。

8. 在 Haldane 模型下，相距 $30\,\mathrm{cM}$ 的基因座之间，染色单体为重组型的概率是多少？二价体在该区间内没有**交叉**的概率是多少？

   **答** $\mathbb{P}(K = 0) = \mathrm{e}^{-2 \times 0.3} = \mathrm{e}^{-0.6} = 0.549$；$r = \frac12(1 - 0.549) = 0.226$。

9. 证明 Kosambi 函数满足 $\mathrm{d}r/\mathrm{d}d = 1 - 4r^2$，且 $d$ 小时 $r \approx d - \frac43 d^3$。与 Haldane 的展开比较。

   **答** $r = \frac12\tanh 2d$，所以 $\mathrm{d}r/\mathrm{d}d = \operatorname{sech}^2 2d = 1 - \tanh^2 2d = 1 - 4r^2$。由 $\tanh x = x - x^3/3 + \dots$，$r = \frac12(2d - 8d^3/3) = d - \frac43 d^3$。Haldane：$\frac12(1 - \mathrm{e}^{-2d}) = d - d^2 + \frac23 d^3 - \dots$，在二阶就已偏离 $r = d$；Kosambi 的校正是三阶的，反映短距离上的强干涉。

10. 相引双杂合子（**完全显性**）的 F2 由 1050 株 $A\_B\_$、148 株 $A\_bb$、142 株 $aaB\_$ 与 260 株 $aabb$ 组成。用平方根法和极大**似然**法估计 $r$，并给出极大似然估计的标准误。与同样大小的测交的标准误比较。

    **答** 平方根法：$1 - 2\sqrt{260/1600} = 0.194$。极大似然估计：$1600\varphi^2 - (1050 - 580 - 260)\varphi - 520 = 0$，即 $1600\varphi^2 - 210\varphi - 520 = 0$，$\hat\varphi = 0.6395$，$\hat r = 1 - 0.7997 = 0.200$。在 $\hat\varphi$ 处每株植物的 Fisher 信息：$\frac1{16}(4/2.6395 + 8/0.3605 + 4/0.6395) = 1.871$；$\operatorname{se}(\hat\varphi) = 1/\sqrt{1600 \times 1.871} = 0.01827$，$\operatorname{se}(\hat r) = 0.01827/(2 \times 0.7997) = 0.0114$。在 $r = 0.2$ 时，1600 株的测交 $\operatorname{se} = \sqrt{0.16/1600} = 0.0100$，略好一些。

11. 相斥双杂合子（$Ab/aB$）的 F2 在 1600 株中有 9 株 $aabb$。估计 $r$。为什么这种设计不适合紧密连锁？

    **答** $f = 9/1600$，$\hat r = 2\sqrt f = 2 \times 0.075 = 0.15$。相斥时唯一有信息的类的频率是 $r^2/4$；$r$ 小时它非常罕见，其计数的相对抽样误差很大（这里为 $9 \pm 3$），而其他类几乎不随 $r$ 变化。在 $r = 0.05$ 时，每株的 Fisher 信息约为 $1.0$，而测交为 $21$。

12. 一次测交给出的表为 $AB$ 30、$Ab$ 20、$aB$ 10、$ab$ 40（共 100 个后代）。用合适的 $\chi^2$ 检验检验连锁，并解释为什么 1:1:1:1 的**拟合优度检验**在这里会产生误导。

    **答** 边缘合计：$A$ 50，$a$ 50；$B$ 40，$b$ 60。期望：$AB$ 20，$Ab$ 30，$aB$ 20，$ab$ 30。$\chi^2 = 100/20 + 100/30 + 100/20 + 100/30 = 16.7$，自由度 1，$p = 4 \times 10^{-5}$：连锁，$\hat r = 30/100 = 0.30$。对各为 25 的拟合优度给出 $\chi^2 = (25 + 25 + 225 + 225)/25 = 20$，自由度 3；这一偏离有一部分来自基因座 $B$ 的 40:60 分离（也许 $B$ 的生活力降低），这并不是连锁的证据。

13. 计算思考题 1 中连锁在 $\hat r$ 处的 LOD 值。数据能否通过约定的阈值 3？

    **答** $Z = 20\log_{10}0.0909 + 200\log_{10}0.9091 - 220\log_{10}0.5 = -20.83 - 8.28 + 66.23 = 37.1$，远高于 3。

14. 一只杂合 $b\,vg^{+}/b^{+}\,vg$ 的果蝇雄蝇与 $b\,vg/b\,vg$ 雌蝇杂交。预期有什么后代？与杂合雌蝇（基因相距 $18\,\mathrm{cM}$）的**正反交**会给出什么？

    **答** 雄性不发生交换：只有亲本型配子，一半为黑体（$b\,vg^{+}$），一半为残翅（$b^{+}\,vg$），没有**野生型**或黑体残翅。杂合雌蝇给出 41 % 黑体、41 % 残翅、9 % 野生型与 9 % 黑体残翅。

15. （设计）你可以对 500 个后代计分，以估计一种能自交的植物中预期相距约 $5\,\mathrm{cM}$ 的两个基因的距离，使用**显性**标记。比较测交、相引 F2 与相斥 F2。

    **答** 用 $r = 0.05$ 时每个个体的信息（图见第 8.6.3 节）：测交 $I = 21.1$，相引 F2 $19.8$，相斥 F2 $1.0$。标准误 $1/\sqrt{500 I}$：$0.0097$、$0.0100$ 与 $0.045$。测交或相引 F2 给出 $\hat r = 0.05 \pm 0.01$；相斥 F2 无法区分 $5\,\mathrm{cM}$ 与 $0$ 或 $14\,\mathrm{cM}$。若测交费力，选相引 F2，决不选相斥 F2。

16. （重组图景）一条 $130\,\mathrm{Mb}$ 的人类**染色体**，性别平均遗传长度为 $150\,\mathrm{cM}$，女性图是男性图的 1.65 倍。男性与女性的长度、以 cM/Mb 计的平均速率、女性**减数分裂**中每个二价体的平均交叉数各是多少？

    **答** 由 $(m + f)/2 = 150$ 与 $f = 1.65m$：$m = 300/2.65 = 113\,\mathrm{cM}$，$f = 187\,\mathrm{cM}$。平均 $150/130 = 1.15\,\mathrm{cM/Mb}$。女性遗传长度 $1.87\,\mathrm{M}$ = 每条染色单体的平均交换数；每个二价体的交叉数 $= 2 \times 1.87 = 3.7$。

17. 在果蝇中，基因座 $C$ 与 $D$ 相距 $20\,\mathrm{cM}$。把两种性别的 $CD/cd$ 果蝇互交。后代中 $Cc\,Dd$ 占多少，$cc\,dd$ 占多少，四种**表型**类各是多少？若雄性中的交换速率相同，答案会怎样变化？

    **答** 雌性给出 $CD$ 与 $cd$ 各 $0.4$，$Cd$ 与 $cD$ 各 $0.1$；雄性不交换，给出 $CD$ 与 $cd$ 各 $0.5$。$Cc\,Dd$ 来自 $CD \times cd$ 或 $cd \times CD$：$0.4 \times 0.5 + 0.4 \times 0.5 = 0.40$；雌性的重组配子与亲本型精子结合只给出单杂合子（$CC\,Dd$、$Cc\,dd$、$Cc\,DD$、$cc\,Dd$，各 $0.05$）。$cc\,dd = 0.4 \times 0.5 = 0.20$。表型：$C\_D\_$ $0.70$，$C\_dd$ $0.05$，$ccD\_$ $0.05$，$ccdd$ $0.20$。若两种性别都交换（各自给出 $0.4$、$0.4$、$0.1$、$0.1$），则 $Cc\,Dd$ 为 $2(0.4^2 + 0.1^2) = 0.34$（相引与相斥的双杂合子合计），$cc\,dd$ 为 $0.16$，即公式 8.6.2 的相引 F2。

18. 一株 $Aa\,Bb$ 植物形成配子 $Ab : aB : AB : ab = 4 : 4 : 1 : 1$。它的连锁相与重组率是多少？若让它自交，在两个基因座上都**纯合**的后代占多少，四种表型的频率是多少（完全显性）？

    **答** 频繁的配子 $Ab$ 与 $aB$ 是亲本型：相斥，$Ab/aB$，$r = 0.2$。自交后代在两个基因座上都纯合，要求两次得到相同的单倍型：$0.4^2 + 0.4^2 + 0.1^2 + 0.1^2 = 0.34$。取 $\varphi = r^2 = 0.04$：$A\_B\_ = (2 + 0.04)/4 = 0.51$，$A\_bb = aaB\_ = 0.96/4 = 0.24$，$aabb = 0.01$。

19. （自交）(a) 相引双杂合子的 F2 在 $1000$ 株中有 $160$ 株 $aabb$。估计 $r$ 和其他类的期望数。(b) 相斥双杂合子的 F2 在 10 000 株中有 25 株 $aabb$。估计 $r$。

    **答** (a) $\sqrt{0.16} = 0.4$ 是 $ab$ 配子的频率 $= (1 - r)/2$，所以 $r = 0.2$。取 $\varphi = 0.64$：$A\_B\_$ $660$，$A\_bb$ $90$，$aaB\_$ $90$，$aabb$ $160$。(b) $\sqrt{0.0025} = 0.05 = r/2$，所以 $r = 0.10$。

20. 基因座 $A$ 与 $C$ 在图上相距 $20\,\mathrm{cM}$，该图是经由中间基因座 $B$ 由短区间构建的。对 $AC/ac$ 的测交只显示 $18\,\%$ 的 $A$–$C$ 重组型。这意味着（在区间 $A$–$B$ 与 $B$–$C$ 中）双交换的频率是多少？若 $r_{AB} = 0.12$，$r_{BC} = 0.08$，则 $C$ 与 $I$ 是多少？

    **答** 外侧基因的重组率比各区间之和小两倍的双交换频率（算法 8.4.1，第 6 步）：$0.20 - 0.18 = 2\,\mathrm{DCO}$，所以 $\mathrm{DCO} = 0.01$。独立性下的期望为 $0.12 \times 0.08 = 0.0096$，所以 $C = 0.01/0.0096 = 1.04$，$I = -0.04$，在抽样误差范围内没有干涉。

21. 玉米测交 $C\,Sh/c\,sh \times c\,sh/c\,sh$ 给出 4032 粒有色饱满、149 粒有色皱缩、152 粒无色饱满与 4035 粒无色皱缩的籽粒。计算 $\hat r$ 及其标准误。杂合子的性母细胞中，两个基因座之间有交叉的占百分之几？

    **答** $\hat r = (149 + 152)/8368 = 0.036$，$\operatorname{se} = \sqrt{0.036 \times 0.964/8368} = 0.0020$。对这样短的区间，双交换可以忽略，所以由注 8.3.1，$2 \times 3.6 = 7.2\,\%$ 的性母细胞发生了交叉。

22. $Aa\,Bb\,Cc$ 的测交给出（杂合子的配子）$ABC$ 210、$ABc$ 205、$abC$ 198、$abc$ 202、$AbC$ 44、$Abc$ 46、$aBC$ 47、$aBc$ 48。分析这些数据。

    **答** 归并为两两一对（注 8.4.1）。$A$–$B$：重组型 $Ab$ 与 $aB$ 为 $44 + 46 + 47 + 48 = 185$（共 1000），$\hat r = 0.185$，连锁（亲本型 $AB/ab$）。$A$–$C$：类似亲本型（$AC$ 或 $ac$）为 $210 + 44 + 202 + 48 = 504$，不匹配的为 $496$，$\hat r \approx 0.50$；$B$–$C$：同样为 $0.50$。$C$ 与 $A$–$B$ 所在染色体独立分配：各类成对（$ABC$/$ABc$、$abC$/$abc$ 等）出现，每对大小相等，只在 $C$ 处不同。**基因型**为 $AB/ab\; C/c$，$A$–$B$ 为 $18.5\,\mathrm{cM}$；没有双交换可找，两个最小的类只是 $A$–$B$ 的重组单倍型。

23. 一位四个基因座都杂合的雌性形成 16 种配子：$ABCd$、$ABcD$、$abCd$、$abcD$ 各 $15.75\,\%$；$ABCD$、$ABcd$、$abCD$、$abcd$ 各 $6.75\,\%$；$AbCd$、$AbcD$、$aBCd$、$aBcD$ 各 $1.75\,\%$；$AbCD$、$Abcd$、$aBCD$、$aBcd$ 各 $0.75\,\%$。哪些基因座连锁，处于什么连锁相，相距多远？

    **答** 对每一对基因座，把配子对另外两个基因座求和。$A$–$B$：$AB + ab = 4(15.75 + 6.75)\,\% = 90\,\%$，所以是 $AB/ab$，$r = 0.10$。$C$–$D$：$Cd + cD = 4(15.75 + 1.75)\,\% = 70\,\%$，所以是相斥 $Cd/cD$，$r = 0.30$。其他每一对（$A$–$C$、$A$–$D$、$B$–$C$、$B$–$D$）都给出 $50\,\%$：两个连锁对在不同的染色体上。验算：每种配子的频率是两对频率的乘积，例如 $ABCd = 0.45 \times 0.35 = 0.1575$，$AbCD = 0.05 \times 0.15 = 0.0075$。基因型为 $AB/ab\; Cd/cD$。
