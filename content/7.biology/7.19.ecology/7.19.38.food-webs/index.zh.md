群落的每个物种都吃其他物种或被其他物种所吃，谁吃谁的网络，即食物网，承载着生态系统的能量与物质（[7.19.42](/7.19.42)–[7.19.46](/7.19.46)），并把一个物种的影响传递给其他物种。[7.19.24](/7.19.24)–[7.19.28](/7.19.28) 中的成对相互作用就是它的链接。本章描述食物网，并追问它们的结构对群落的存续意味着什么。第 38.1 节定义食物链、食物网与营养级，并引入定量的描述量和两个结构模型。第 38.2 节追问为什么食物链很短。第 38.3 节区分稳定性的几种含义。第 38.4 节展开 May 的随机群落矩阵理论，它推翻了复杂群落必然稳定的信念，并介绍 Allesina 和 Tang 对它的改进；其数学是大型随机矩阵的特征值，建立在 [7.19.22](/7.19.22) 的[群落矩阵](/7.19.22#sec-22.5.1)与 [2.1.6](/2.1.6) 的**特征值**之上。第 38.5 节解释为什么使种群失稳的同样的复杂性，可以使群落的总体性质稳定，第 38.6 节讨论食物网对物种丧失的鲁棒性。通过食物网传播的间接效应，即营养级联与似然竞争，是 [7.19.39](/7.19.39) 的主题。这里使用的网络科学工具（度分布、对节点移除的鲁棒性）在 [1.4.7](/1.4.7) 中展开，分子网络的情形见 [7.9.12](/7.9.12)。

## 38.1. 食物链、食物网与营养级

### 38.1.1. 食物链

**定义 38.1.1（食物链）** **食物链**是一个物种序列，其中每个物种取食前一个物种，生产者固定的能量与物质沿此经一系列消费者传递：植物 → 食草动物 → 食肉动物 → 顶级食肉动物。它的*长度*是取食链接的数目。

生态系统中有三类食物链。

| 类型 | 起点 | 例 |
|---|---|---|
| 捕食食物链 | 被食草动物取食的活植物 | 草 → 蚱蜢 → 蛙 → 蛇 → 鹰；浮游植物 → 磷虾 → 须鲸 |
| 碎屑食物链 | 死有机物（凋落物、尸体、粪便）及其分解者 | 落叶 → 真菌与细菌 → 跳虫与螨 → 捕食性螨 → 蜘蛛 |
| 寄生食物链 | 宿主及其寄生物，后者比宿主小 | 哺乳动物 → 跳蚤 → 跳蚤携带的细菌（如鼠疫耶尔森菌 *Yersinia pestis*）→ 噬菌体 |

两条主要通道相互联系：森林、草地和湿地的大部分初级生产不是被活着取食，而是进入碎屑食物链，食碎屑者又被取食草食动物的同样的捕食者所吃（第 38.2 节与 [7.19.39](/7.19.39)）。Odum 把生态系统的两个层次描述为：上层的“绿带”，以自养生产为主；下层的“棕带”，即土壤与沉积物，以分解为主；碎屑食物链在 [7.19.44](/7.19.44) 中讨论。食物链是抽象。许多消费者的食性随年龄、季节与猎物的可得性而改变（蝌蚪取食藻类，成蛙吃昆虫），所以食物链往往是暂时的，而群落中多度大的核心物种之间的关系最为恒定。

### 38.1.2. 食物网

**定义 38.1.2（食物网）** **食物网**是群落中物种（或物种类群）之间取食关系的网络：一个有向图，其节点是物种，链接由每种资源指向它的每个消费者。

食物链交织成网，是因为多数消费者吃几种食物，而多数物种被几种消费者所吃。在南大洋，硅藻和其他浮游植物被南极磷虾（*Euphausia superba*）、桡足类和樽海鞘取食；磷虾被须鲸、食蟹海豹、企鹅、飞行海鸟、乌贼和鱼类取食；鱼类和乌贼被豹海豹、威德尔海豹、帝企鹅和齿鲸取食；虎鲸捕食海豹、企鹅和其他鲸。这样的网由第二层的一个物种所主导：磷虾把几乎所有消费者与浮游植物联系起来，磷虾的减少会传到几乎每一种捕食者。第一张画成图的食物网，即北极熊岛的食物网（Summerhayes 和 Elton 1923），已经表明即使物种贫乏的群落也有复杂的取食关系。

具有 $S$ 个物种与 $L$ 条链接的食物网由几个量描述。

- *基位种*没有猎物（生产者，或视为一个节点的碎屑）；*顶位种*没有捕食者；*中间种*两者都有。
- *连接密度* $L/S$ 是每个物种的平均链接数；每条链接对应一个消费者和一个资源，所以猎物的平均数与捕食者的平均数都等于 $L/S$。
- *杂食*：取食多个营养级（第 38.1.3 节）。
- *泛化度*与*易损度*：一个物种的猎物数与捕食者数，它们在真实食物网中的分布是偏斜的：少数物种吃很多物种或被很多物种吃。

**定义 38.1.3（连接度）** 食物网的**连接度**是已实现的取食链接占可能链接的比例，$C = L/S^2$（有向连接度，计入包括同类相食在内的所有有序对）；有些作者使用 $L/[S(S - 1)/2]$，即发生相互作用的物种对的比例。

在分辨率良好的食物网汇编中，连接度在约 0.03 到 0.3 之间，且大致与物种数无关，所以连接密度大致与 $S$ 成正比增加（Martinez 1992；Dunne 等 2002）。早期的汇编曾提示连接密度恒定在约 2（“链接–物种标度”），但这被证明是早期食物网分辨率低造成的假象，当时物种被归并成大的类群。所有食物网统计量都依赖于分类的分辨率，这就是为什么分辨率良好的食物网，如小石湖（182 个分类单元）、伊森河口或加勒比珊瑚礁的食物网，成为现代分析的基础。

### 38.1.3. 营养级

**定义 38.1.4（营养级）** **营养级**是从生产者起算的取食步骤序列中的一个位置：生产者（自养生物）构成第一营养级，食草动物（初级消费者）为第二营养级，吃食草动物的食肉动物（次级消费者）为第三营养级，依此类推。在食物网中，消费者的营养级被定量地定义为 1 加其食物的平均营养级，以各食物占其食谱的比例为权重。

作为一个类别（“所有食草动物”）的营养级是能量流动的概念（Lindeman 1942）：它按食物自光合作用以来经历的转化次数对生物分组，能量在各级之间的传递是 [7.19.43](/7.19.43) 的主题。这些类别并不针对物种：一个物种属于多少个营养级，取决于它有多少条到生产者的不同长度的取食链接，而杂食者很常见。定量的定义给每个物种指定唯一的、一般为分数的值。

**命题 38.1.1（分数营养级）** 设一个食物网有 $S$ 个物种，设 $q_{ij} \ge 0$ 为物种 $i$ 的食谱中由物种 $j$ 提供的比例（消费者有 $\sum_j q_{ij} = 1$，若 $i$ 为基位种则对所有 $j$ 有 $q_{ij} = 0$），$Q = (q_{ij})$。由 $t_i = 1 + \sum_j q_{ij}t_j$ 定义的营养级 $\boldsymbol{t} = (t_1, \dots, t_S)^{\mathsf T}$ 是

$$
(I - Q)\,\boldsymbol{t} = \boldsymbol{1}, \tag{38.1}
$$
的唯一解，只要每个物种都通过一条取食链接链与某个基位种相连。此时 $\boldsymbol{t} = (I + Q + Q^2 + \cdots)\boldsymbol{1}$，$t_i - 1$ 是从物种 $i$ 向下到生产者的链中的平均链接数，其中每一步向下的选择以食谱比例为概率。

**证明** $Q$ 是一个随机游动的转移矩阵，该游动以概率 $q_{ij}$ 从一个物种移到它的一种食物，并在基位种（其行为零）处停止。若每个物种都与某个基位种相连，游动以概率 1 停止，所以 $Q^k \to O$，$Q$ 的谱半径小于 1，Neumann 级数 $\sum_k Q^k$ 收敛到 $(I - Q)^{-1}$（[2.1.11](/2.1.11)）。因此 (38.1) 有唯一解 $\boldsymbol{t} = \sum_k Q^k\boldsymbol{1}$。$Q^k\boldsymbol{1}$ 的第 $i$ 个分量是从 $i$ 出发的游动在 $k$ 步之后尚未停止的概率，而 $\sum_{k\ge0}\mathbb{P}(k\text{ 步后未停止}) = \mathbb{E}[\text{步数}] + 1$。$\square$

**例 38.1.1** 在一个小型草地食物网中，蚱蜢只吃草；小鼠吃草（占食谱的 50 %）和蚱蜢（50 %）；蛇只吃小鼠；鹰吃小鼠（70 %）和蛇（30 %）。营养级依次求得：

| 物种 | 食谱 | 营养级 |
|---|---|---|
| 草 | — | $1$ |
| 蚱蜢 | 草 | $1 + 1 = 2$ |
| 小鼠 | 草 0.5，蚱蜢 0.5 | $1 + 0.5 \cdot 1 + 0.5 \cdot 2 = 2.5$ |
| 蛇 | 小鼠 | $1 + 2.5 = 3.5$ |
| 鹰 | 小鼠 0.7，蛇 0.3 | $1 + 0.7 \cdot 2.5 + 0.3 \cdot 3.5 = 3.8$ |

这里的食物网没有环，可以逐个物种求解；有环时（同类相食、幼体相互捕食）必须联立求解线性方程组。没有食谱数据时，常给每种猎物相同的权重（“猎物平均”营养级）。用稳定氮同位素测得的营养级，其 $\delta^{15}\mathrm{N}$ 每个营养步增加约 3.4 ‰，它在时间上整合了食谱，是标准的野外方法（Post 2002）。

### 38.1.4. 食物网结构的模型

真实食物网的规律性（基位种、中间种与顶位种的比例，连接度，链长，杂食的频率）是否是简单规则的后果？有两个随机模型可以生成具有给定 $S$ 与 $C$ 的食物网。

- *级联模型*（Cohen 和 Newman 1985）：物种按 $1, \dots, S$ 排序，每个物种 $i$ 独立地以概率 $p = 2CS/(S - 1)$ 吃每个排名较低的物种 $j < i$。排序禁止了环：存在一个等级，每个物种只吃它以下的物种。该模型再现了早期食物网中基位种、中间种与顶位种的比例，但低估了食谱相似的物种和杂食的频率。
- *生态位模型*（Williams 和 Martinez 2000）：每个物种 $i$ 得到一个在 $[0, 1]$ 上均匀的生态位值 $n_i$（可设想为体型），一个宽度为 $r_i = xn_i$ 的取食范围，其中 $x$ 取自 Beta$(1, \beta)$ 分布，$\beta = 1/(2C) - 1$（使 $\mathbb{E}[x] = 2C$，期望连接度为 $C$），以及在 $[r_i/2, n_i]$ 上均匀的范围中心 $c_i$。物种 $i$ 吃所有生态位值落在 $[c_i - r_i/2, c_i + r_i/2]$ 内的物种。

生态位模型增加了两个特征：食谱是单一生态位轴上的连续区间（图 1B），所以生态位值相近的物种共享捕食者和猎物，而消费者可以吃生态位值比自己略大的物种，从而允许环与同类相食。只给定 $S$ 与 $C$，它就预测了分辨率最好的食物网的十几种性质：顶位种、中间种与基位种的比例，泛化度与易损度的变异，平均链长，杂食与同类相食的频率，比级联模型更好。食物网几乎是“区间”的（食谱可以沿单一维度排序），是食物网结构最强的规律之一，它在体型上有明显的生物学基础：捕食者吃的猎物处在与自身大小相关的范围内（Cohen 等 2003）。

![生态位模型生成的食物网，30 个物种，目标连接度 0.12（实现的 L = 113 条链接，C = L/S² = 0.126）。A：物种按生态位值和猎物平均营养级（取自式 (38.1)）放置；线连接猎物与消费者；基位种（绿色）与中间种（蓝色）；在这一实现中每个消费者本身都被另一物种所吃，因为生态位值高的物种相互取食。B：取食矩阵，消费者为行、资源为列，都按生态位值排序；每个食谱是生态位轴上的一个区间](./plots/niche-model-web.py)

## 38.2. 食物链长度

几乎所有食物网都有两到五个营养级，多数为三或四个；华盛顿州一个暴露岩岸食物网的平均链长（Briand 1983）约为 2.3 条链接，多数湖泊食物网为 3 到 4.5。为什么这么少？已经提出了五个假说。

1. *能量*（Elton 1927；Lindeman 1942）。一个营养级的能量只有约十分之一到达下一级（[7.19.43](/7.19.43)），所以第五级捕食者的可存活种群需要基部有极大的生产量。在单位面积生产力较高的地方，食物链应当更长。
2. *生产空间*（Schoener 1989）。相关的量是总生产力，即单位面积生产力乘以生态系统的面积，因为顶位捕食者需要的是最低的总供给，而不是最低的密度。
3. *生态系统大小。* 较大的生态系统有更多的物种和生境，使顶位捕食者能以更大的种群存续，并包含庇护所；Post、Pace 和 Hairston（2000）发现，在北美东北部的 25 个湖泊中，以顶位捕食者的 $\delta^{15}\mathrm{N}$ 度量的食物链长度随湖泊体积增加，而不随生产力增加。
4. *动态稳定性*（Pimm 和 Lawton 1977）。在 Lotka–Volterra 模型中，较长的链在受扰动后更缓慢地回到平衡：它们的恢复力较低（第 38.3 节），在频繁受干扰的环境中会被消除。后来采用更现实的功能反应的模型并不总是证实这一点。
5. *设计限制与觅食。* 捕食者通常比其猎物大，体型沿食物链向上增加；能够捕捉并杀死一只鹰的捕食者必须既快又极大。此外，适应性觅食者应当偏好链下部丰富而防御差的猎物：在消费者转向最有利可图的猎物的模型中，食物链较短，且不随生产力而变长（Kondoh 和 Ninomiya 2009）。

极简单系统的实验在生产力很低时支持能量假说：在人工的盛水树洞中，凋落叶输入降低到百分之一，使顶位捕食者摇蚊消失（Jenkins 等 1992）。在自然系统中，对相似生境之间比较的荟萃分析发现，链长随生态系统大小增加，随生产力增加的一致性较差，且与干扰无关，这符合生产空间与生态系统大小假说的预期（Takimoto 和 Post 2013）。在巴哈马群岛，食物链长度随岛屿面积增加，风暴使顶位捕食者（一种蜥蜴）被另一种（一种圆蛛）取代，而没有缩短链长（Takimoto 等 2008）。把通常被省略的寄生物计入，会使链变长并改变其结构（[7.19.28](/7.19.28)）。

## 38.3. 稳定性的概念

“稳定性”有许多含义，“复杂群落是否更稳定？”的答案取决于指的是哪一种。干扰本身有两类：*脉冲*，使群落发生位移的单次事件（火灾、洪水）；*持续*扰动，条件的持续改变（富营养化、变暖）。

**定义 38.3.1（抵抗力与恢复力）** 群落或生态系统的**抵抗力**是它在受到干扰时保持不变的能力，反过来以给定干扰造成的位移大小度量。它的**恢复力**是它在发生位移之后回到先前状态的速度；在稳定平衡附近，它由渐近回复速率度量，即 Jacobi 矩阵主导特征值实部的绝对值 $-\max_k\operatorname{Re}\lambda_k$，其倒数是*回复时间*。

另有一些性质与它们区分开来：

| 性质 | 含义 | 典型度量 |
|---|---|---|
| 局部稳定性 | 小扰动之后回复 | Jacobi 矩阵的所有特征值满足 $\operatorname{Re}\lambda < 0$ |
| 全局稳定性 | 任意大小的扰动之后回复 | Lyapunov 函数；吸引域的大小 |
| 持久性 | 系统在改变（如丧失物种）之前持续多久 | 到首次灭绝的时间，存活物种的比例 |
| 变异性（恒定性的反面） | 随时间的波动幅度 | 多度或生物量的变异系数 |
| 鲁棒性 | 食物网在物种丧失之后抵抗次生灭绝的能力 | 丧失一半物种所需移除的物种比例（第 38.6 节） |

Holling（1973）以不同的方式使用“恢复力”，指系统在转入另一稳定状态之前能够吸收的干扰的大小，这种*生态恢复力*是与稳态转换（[7.19.39](/7.19.39)）有关的概念；上面的定义是 Pimm（1984）的*工程恢复力*。两者可能相反：一个系统可能从小的干扰中迅速恢复，却靠近阈值。

抵抗力和恢复力常常成反比关系（Odum）。红杉林以厚树皮和高树冠抵抗火，但一旦被烧毁，需要几个世纪才能恢复；灌丛林很易燃，却能在几年内由萌生的灌木和种子再生。温和而恒定环境中的生态系统倾向于抵抗，多变环境中的生态系统倾向于恢复。养分与能量流动的模型表明，恢复力随单位现存生物量的能量通量而增加（DeAngelis 1980）：以小型、周转快的生物为主的系统恢复得快。O'Neill（1976）比较了池塘、苔原和森林的模型对同一扰动的响应：池塘的浮游植物以天为周期周转，异养生物的生物量超过自养生物（比值约 5.4），恢复得最快；苔原相对植物而言异养生物的生物量很少（比值约 0.004），植物生长缓慢，恢复得最慢。

## 38.4. 复杂性与稳定性

### 38.4.1. 从 Elton 到 May

直到约 1970 年，由 MacArthur（1955）和 Elton（1958）表述的传统观点是，更复杂的群落更稳定：猎物多的消费者可以在一种猎物减少时转换，有许多路径的网可以重新分配能量，而简单的群落，如作物、岛屿和北极苔原，似乎容易发生暴发和入侵。May（1972、1973）用一个模型检验了这一主张，发现结论相反。

考虑一个处于平衡的 $S$ 个物种的群落及其群落矩阵（[7.19.22](/7.19.22)），即种群动态在平衡点的 Jacobi 矩阵 $A = (a_{ij})$，其中 $a_{ij}$ 是物种 $j$ 的微小变化对物种 $i$ 增长的影响。May 假设每个物种自我调节，$a_{ii} = -d$（把时间标度化使 $d = 1$），非对角元是随机的：以概率 $C$（连接度），$a_{ij}$ 取自均值为 0、标准差为 $\sigma$（相互作用强度）的分布，否则 $a_{ij} = 0$。于是 $A = -dI + M$，其中 $M$ 的元素独立、均值为 0、方差为 $C\sigma^2$，平衡是局部稳定的当且仅当 $M$ 的所有特征值的实部小于 $d$。

### 38.4.2. 圆律与 May 判据

**定理 38.4.1（圆律）** 设 $X_S$ 是 $S \times S$ 矩阵，其元素是独立同分布的随机变量，均值为 0、方差为 1。当 $S \to \infty$ 时，$X_S/\sqrt S$ 的特征值在复平面的单位圆盘 $\{\lvert z\rvert \le 1\}$ 上趋于均匀分布（Girko 1984；Bai 1997；Tao 和 Vu 2010）。若元素还具有有限的四阶矩，则 $X_S/\sqrt S$ 的特征值的最大模几乎必然收敛到 1（Geman 1986；Bai 和 Yin 1986）。

这一定理很深，其证明（通过“厄米化”，把特征值分布与 $X_S - zI$ 的奇异值联系起来）超出本书范围。一个启发式论证使半径变得合理：对任一固定的单位向量 $\boldsymbol{u}$，$\mathbb{E}\lVert X_S\boldsymbol{u}\rVert^2 = \sum_{i}\sum_j u_j^2\operatorname{Var}(x_{ij}) = S$，所以 $X_S/\sqrt S$ 把典型向量拉伸因子 1，而特征向量是典型向量。

**命题 38.4.1（May 稳定性判据）** 对 May 的随机群落矩阵 $A = -dI + M$，设连接度为 $C$、相互作用强度为 $\sigma$，当 $S \to \infty$ 时，$A$ 的特征值充满以 $-d$ 为圆心、半径为 $\sigma\sqrt{SC}$ 的圆盘，且若

$$
\sigma\sqrt{SC} < d \tag{38.2}
$$
则平衡以趋于 1 的概率稳定，若 $\sigma\sqrt{SC} > d$ 则以趋于 1 的概率不稳定。

**证明** $M$ 的元素独立，均值为 0，方差为 $C\sigma^2$（以概率 $C$ 取自相互作用分布的值，否则为零），所以 $M = \sigma\sqrt C\,X_S$，其中 $X_S$ 如定理 38.4.1（零对角线不改变极限），且 $M = \sigma\sqrt{SC}\,(X_S/\sqrt S)$。由该定理，$M$ 的特征值充满半径为 $\sigma\sqrt{SC}$ 的圆盘，而 $M$ 的特征值的最大实部介于 $-\sigma\sqrt{SC}$ 与最大模之间，由于圆盘一直均匀地充满到边缘，它收敛到 $\sigma\sqrt{SC}$。$A = -dI + M$ 的特征值是 $M$ 的特征值平移 $-d$，所以 $A$ 的特征值的最大实部趋于 $\sigma\sqrt{SC} - d$，在 (38.2) 下为负，反之为正。$\square$

May 的结果是，在随机群落中，复杂性的三个成分，物种数 $S$、连接度 $C$ 与相互作用强度 $\sigma$，每一个都降低稳定的概率，并且对大的 $S$ 这一转变是陡峭的（图 2B）：大型随机群落在阈值之下几乎必然稳定，在阈值之上几乎必然不稳定。由此推出，如果真实群落既大又稳定，它们的连接度与相互作用强度必须满足 $\sigma^2SC < d^2$：复杂性必须由每个物种更弱或更少的相互作用来“偿付”，而 $C$ 几乎不随 $S$ 变化这一点表明 $\sigma$ 随丰富度而下降。注意 $\sigma$ 是非零相互作用的均方根强度（即其标准差，均值为零），而不是它们的平均大小。

May 的结论并不表明复杂群落是不稳定的；它表明复杂性本身并不赋予稳定性，稳定的复杂群落必须有特殊的、非随机的结构。1972 年以来的食物网理论，很大一部分就是在寻找这种结构。

![May 的复杂性–稳定性判据。A：一个随机群落矩阵 A = −I + M 的特征值，S = 250 个物种，连接度 C = 0.2，σ√(SC) = 0.8：它们充满以 −1 为圆心、半径为 σ√(SC) 的圆盘（红色），完全在左半平面内，所以平衡稳定（圆律，定理 38.4.1）。B：随机矩阵（C = 0.3）稳定的比例随复杂性 σ√(SC) 的变化，S = 10、40 和 150 个物种：随着 S 增加，转变在 σ√(SC) = 1（虚线）附近变得陡峭（命题 38.4.1）](./plots/may-stability.py)

### 38.4.3. 相互作用类型与椭圆律

真实的相互作用在符号上并不独立。捕食者从猎物受益（$a_{ij} > 0$）同时伤害猎物（$a_{ji} < 0$）；竞争者相互伤害；互利共生者相互受益。这些约束使成对的 $(a_{ij}, a_{ji})$ 相关，圆律得到推广。

**定理 38.4.2（椭圆律）** 设 $S \times S$ 矩阵 $X_S$ 的数对 $(x_{ij}, x_{ji})$，$i < j$，独立同分布，均值为 0，方差为 1，相关系数 $\rho = \mathbb{E}[x_{ij}x_{ji}]$。当 $S \to \infty$ 时，$X_S/\sqrt S$ 的特征值在水平半轴为 $1 + \rho$、垂直半轴为 $1 - \rho$ 的椭圆内趋于均匀分布（Sommers 等 1988；Nguyen 和 O'Rourke 2015）。

$\rho = 0$ 时即圆律；$\rho = 1$（对称矩阵）时椭圆退化为实轴上的线段 $[-2, 2]$，即 Wigner 半圆律；$\rho = -1$（反对称矩阵）时退化为虚轴上的线段 $[-2\mathrm{i}, 2\mathrm{i}]$。

**命题 38.4.2（Allesina–Tang 判据）** 设每对物种以概率 $C$ 相互作用，相互作用的大小为 $\lvert X\rvert$，其中 $X \sim \mathcal{N}(0, \sigma^2)$ 对两个元素独立抽取，自我调节为 $-d$。则当 $S \to \infty$ 时，在下列条件下平衡稳定：

| 相互作用结构 | $(a_{ij}, a_{ji})$ 的符号 | 相关系数 $\rho$ | 稳定性条件 |
|---|---|---|---|
| 随机（May） | 独立 | $0$ | $\sigma\sqrt{SC} < d$ |
| 捕食–被捕食 | $(+, -)$ 或 $(-, +)$ | $-2/\pi$ | $\sigma\sqrt{SC}\,(1 - 2/\pi) < d$ |
| 竞争与互利混合 | $(-, -)$ 或 $(+, +)$ | $+2/\pi$ | $\sigma\sqrt{SC}\,(1 + 2/\pi) < d$ |

所以捕食–被捕食群落能容忍随机群落的 $1/(1 - 2/\pi) \approx 2.75$ 倍的复杂性，而竞争与互利的混合只能容忍 $1/(1 + 2/\pi) \approx 0.61$ 倍（Allesina 和 Tang 2012）。

**证明** 在每种情形中，一对的符号以 $1/2$ 的概率取每个方向，所以元素的均值为 0。其方差为 $C\,\mathbb{E}[X^2] = C\sigma^2$。对捕食–被捕食对，$\mathbb{E}[a_{ij}a_{ji}] = -C\,\mathbb{E}\lvert X\rvert\,\mathbb{E}\lvert Y\rvert = -C\sigma^2\cdot 2/\pi$，因为正态变量有 $\mathbb{E}\lvert X\rvert = \sigma\sqrt{2/\pi}$；所以相关系数为 $\rho = -2/\pi$。对同号的对，乘积为正，$\rho = +2/\pi$；对独立元素，$\rho = 0$。把 $M$ 写成 $M = \sigma\sqrt{SC}\,X_S/\sqrt S$，其中 $X_S$ 满足定理 38.4.2，$M$ 的特征值充满一个椭圆，其最右端点为 $\sigma\sqrt{SC}(1 + \rho)$，而 $A = -dI + M$ 稳定要求它小于 $d$。$\square$

直观上，一个捕食–被捕食对是一个振子：其 $2 \times 2$ 块的特征值为 $\pm\mathrm{i}\sqrt{\lvert a_{ij}a_{ji}\rvert}$，把特征值沿虚轴移动而不把它们推向右侧，而同号的对是正反馈或负反馈环，把特征值沿实轴展开（图 3）。有几点限定。只有竞争者的群落或只有互利共生者的群落，其元素的均值非零；均值使一个孤立的特征值出现在 $(S - 1)C\,\mathbb{E}[a_{ij}]$ 附近，对竞争它是很强的负值（稳定化），对互利共生它是很强的正值（失稳），所以大型互利共生群落需要强的自我调节或饱和的收益（[7.19.29](/7.19.29)）。真实的食物网还有按等级、受体型结构化的捕食–被捕食链接，而且群落矩阵并不独立于平衡多度，后者必须为正（*可行*）；随机矩阵对可行性没有任何说明，可行性在 $S$ 大时变得不可能，除非相互作用很弱（Dougoud 等 2018）。

![相互作用类型与稳定性（Allesina 和 Tang 2012）。随机相互作用矩阵的特征值，S = 400 个物种，连接度 C = 0.25，σ√(SC) = 1，无自我调节，以及椭圆律的椭圆（红色；水平半轴 1 + ρ，垂直半轴 1 − ρ，定理 38.4.2）。A：独立的随机元素（ρ = 0）：May 模型的圆。B：捕食–被捕食对（ρ = −2/π）：点云在水平方向被压缩，所以自我调节 d = 0.36 就足以稳定。C：同号的对，竞争与互利混合（ρ = +2/π）：点云在水平方向被拉伸，需要 d = 1.64](./plots/allesina-tang.py)

### 38.4.4. 是什么使真实食物网稳定

经验食物网比具有相同 $S$、$C$ 和相互作用强度的随机矩阵更稳定，有几个特征解释这一点。

- *许多弱相互作用。* 真实食物网中的相互作用强度高度偏斜：多数链接弱，少数强（Paine 1992；Wootton 1997）。在模型中，强相互作用对之间的弱链接抑制振荡，因为通往替代猎物或竞争消费者的弱链接把能量从一个潜在不稳定的对中分走（McCann、Hastings 和 Huxel 1998）。对多数链接减小 $\sigma$ 正是 (38.2) 所要求的。
- *营养环的组织。* Neutel、Heesterbeek 和 de Ruiter（2002）分析了土壤食物网，其相互作用强度由测得的生物量和能量流计算。每个相互作用的闭合环有一个*环权重*，即其相互作用强度的大小的几何平均。由于生物量沿网向上下降，且捕食者对猎物的人均影响远大于猎物对捕食者的影响，真实食物网中的长环含有弱链接，权重低；在相互作用强度相同的随机化食物网中，长环是重的，稳定性低得多。最大环权重预测了稳定性。
- *分室。* 分成若干子网、子网内部相互作用强而子网之间相互作用弱的食物网更持久，因为扰动被限制在局部（May 1972；Stouffer 和 Bascompte 2011）。真实食物网比随机的更分室化，主要是因为不同生境或不同体型的物种很少相互作用。
- *异速生长与适应性行为。* 捕食者与猎物的体重比为 10–100，使大型捕食者的相互作用相对于其猎物缓慢而微弱，这使大型模型食物网稳定（Brose、Williams 和 Martinez 2006）；适应性的食物选择，即转向丰富的猎物，重新分配捕食并使本来会丧失物种的食物网稳定（Kondoh 2003）。

## 38.5. 多样性与稳定性

### 38.5.1. 种群与总体

May 的分析涉及单个物种多度的稳定性。生态系统服务依赖的却是总体性质：总生物量、初级生产力、产量。即使种群不稳定，多样性也可以通过一种纯统计的机制使这些总体稳定。

**命题 38.5.1（统计平均）** 设有 $S$ 个物种的群落，总多度 $T = \sum_i N_i$ 的均值为 $m$，由各物种均分（$\mathbb{E}[N_i] = m/S$），并设每个物种的方差服从均值–方差标度 $\operatorname{Var}(N_i) = c\,\mathbb{E}[N_i]^z$（Taylor 幂法则；通常 $1 \le z \le 2$）。若各物种独立波动，则

$$
\mathrm{CV}_{\mathrm{pop}} = \sqrt c\left(\frac mS\right)^{z/2 - 1} \propto S^{1 - z/2}, \qquad
\mathrm{CV}_{\mathrm{com}} = \sqrt c\,m^{z/2 - 1}S^{(1 - z)/2} \propto S^{(1 - z)/2}. \tag{38.3}
$$
若所有物种对具有相同的相关系数 $\rho$（方差相等），则

$$
\frac{\mathrm{CV}_{\mathrm{com}}}{\mathrm{CV}_{\mathrm{pop}}} = \sqrt{\rho + \frac{1 - \rho}{S}}. \tag{38.4}
$$

**证明** 一个物种的变异系数为 $\sqrt{c(m/S)^z}/(m/S) = \sqrt c\,(m/S)^{z/2 - 1}$。对独立的物种，$\operatorname{Var}(T) = S\cdot c(m/S)^z$，所以 $\mathrm{CV}_{\mathrm{com}} = \sqrt{Sc(m/S)^z}/m = \sqrt c\,m^{z/2 - 1}S^{(1 - z)/2}$。具有成对相关 $\rho$ 与共同方差 $v$ 时，$\operatorname{Var}(T) = Sv + S(S - 1)\rho v$，把 $\mathrm{CV}_{\mathrm{com}}^2 = \operatorname{Var}(T)/m^2$ 除以 $\mathrm{CV}_{\mathrm{pop}}^2 = v/(m/S)^2$，得 $(1 + (S - 1)\rho)/S = \rho + (1 - \rho)/S$。$\square$

对 $1 < z < 2$，群落总量的变异性随丰富度下降，而每个种群的变异性上升（图 4A）：多样性使总体稳定而使其部分失稳，两种说法对同一个群落可以同时成立（Tilman 1999；Doak 等 1998）。

**定义 38.5.1（组合效应与保险假说）** 组合效应（portfolio effect）是群落的总体性质（总生物量、生产力、产量）的变异性相对于其组分的变异性的减小，它来自对并非完全同步波动的组分求和，类比于多样化的金融投资组合。保险假说（insurance hypothesis），见 Yachi 和 Loreau（1999），认为生物多样性为生态系统功能抵御环境波动提供保险，因为物种对环境的响应不同，使一些物种在另一些失效时维持功能，并且这一效应提高生态系统性质的均值、降低其方差。

组合效应依赖于同步性（图 4B，式 38.4）。物种正相关时，如所有植物对干旱作出相同的响应，平均作用受到限制：$S \to \infty$ 时 $\mathrm{CV}_{\mathrm{com}}/\mathrm{CV}_{\mathrm{pop}} \to \sqrt\rho$。负协方差，即一个物种在其竞争者减少时增加的*补偿动态*，使它增强。因此竞争有所贡献，因为竞争者倾向于向相反方向波动，对环境响应的差异也是如此，这是保险假说的核心；对平均生产力的互补效应与选择效应在这些效应之外还有所增加，在 [7.19.50](/7.19.50) 中讨论。Loreau 和 de Mazancourt（2008）以 $\varphi = \operatorname{Var}(T)/(\sum_i \sigma_i)^2$ 度量同步性，完全同步时为 1，方差相等的独立物种为 $1/S$。

![多样性与种群及群落的变异性。A：群落总量（实线）与单个种群（虚线）的变异系数随多度相等、独立波动的物种数的变化，均值–方差标度指数 z = 1.0、1.5 和 2.0（式 38.3）：对 1 < z < 2，群落变异性下降而种群变异性随丰富度上升；z = 1 时群落变异性不变，z = 2 时种群变异性不变。B：具有成对相关 ρ 的物种的群落与种群变异性之比（式 38.4）：正相关（同步）限制组合效应，负协方差（ρ = −0.03，至多对 1 + 1/0.03 ≈ 34 个物种可能）使它增强](./plots/diversity-stability.py)

### 38.5.2. 证据

最清楚的检验来自明尼苏达州 Cedar Creek 的草地。在 207 块天然草地样方中，11 年间植物总生物量的年际变异性在物种较多的样方中较低，物种较多的样方在 1987–1988 年的严重干旱之后丧失的生物量较少、恢复得较快（Tilman 和 Downing 1994；Tilman 1996）。相反，39 个最常见物种的种群变异性随丰富度略有上升，但这一效应微弱而不一致。在 Cedar Creek 的生物多样性实验中，播种 1–16 个物种的样方在十年间显示，总生物量的时间稳定性（均值/标准差）随丰富度增加，单个物种的则降低（Tilman、Reich 和 Knops 2006）。在 8 个有 1–32 个物种的欧洲草地实验中，丰富度通过超产（更高的平均生产力）和物种之间的异步性两种途径使群落生物量稳定，同时使种群失稳（Hector 等 2010）。

组合效应在经济上也很重要。阿拉斯加 Bristol 湾的红大麻哈鱼（*Oncorhynchus nerka*）在数百条溪流和湖泊中产卵，其种群异步波动；总渔获量的变异性不到渔业依赖单一种群时的一半，渔业关闭的频率会高约十倍（Schindler 等 2010）。在多营养级群落中，丰富度与种群变异性的关系可以不同：在藻类、细菌、原生动物和轮虫的微宇宙中，种群变异性并不随丰富度上升，在由热带岩池组装的微宇宙中它下降（Steiner 等 2005；Vogt 等 2006）。复杂性与稳定性之间不存在单一的关系：它取决于层次（种群或总体）、稳定性的种类和相互作用的结构。

## 38.6. 鲁棒性与次生灭绝

一个物种的丧失可以造成其他物种的丧失：依赖它的消费者、需要它作宿主的寄生物、需要它传粉的植物。这些*次生灭绝*是食物网结构决定物种丧失后果的最直接方式。

Dunne、Williams 和 Martinez（2002）模拟了从 16 个真实食物网中依次移除物种。消费者在失去全部猎物时灭绝；基位种只能通过移除而丧失。鲁棒性以使全部物种的一半丧失（初级灭绝加次生灭绝）所必须移除的物种比例 $R_{50}$ 度量；其最大值为 0.5（没有次生灭绝）。

- 先移除连接最多的物种，造成的崩溃比随机移除快得多。移除连接最多的物种但保护基位种，造成的崩溃并不比随机移除更快，因为破坏性最大的移除是对许多消费者所依赖的生产者的移除。
- 鲁棒性随连接度增加：在消费者有许多猎物的食物网中，失去一个猎物很少使消费者没有食物。
- 也有例外：移除一个连接很少的基位种，如果它唯一的消费者是许多捕食者的主要猎物，就可能造成灭绝的级联，这提醒人们丧失的物种是哪一个很重要，这就是**关键种**（[7.19.33](/7.19.33)）的概念。

用生态位模型食物网进行模拟，再现了这些结果（图 5）。计入寄生物会略微降低鲁棒性，主要是因为许多寄生物需要几个宿主物种来完成生活史（[7.19.28](/7.19.28)）。食物网对连接最多的物种的丧失的脆弱性，与度分布偏斜的网络“稳健而脆弱”的行为相似，这类网络能容忍随机的失效，但在枢纽受攻击时会瓦解（[1.4.7](/1.4.7#sec-7.8.1)；[7.9.12](/7.9.12#sec-12.1.3)）。植物与传粉者的互利网络在结构上不同于食物网：它们是嵌套的（**嵌套性**，[7.19.29](/7.19.29)），这使它们对随机的物种丧失稳健，却对泛化的核心的丧失敏感，而食物网倾向于分室化（Thébault 和 Fontaine 2010）。

## 思考题

1. 在例 38.1.1 中，鹰把食谱改为 40 % 小鼠、40 % 蛇和 20 % 蚱蜢。计算它新的营养级。然后设蛇也吃蚱蜢（占其食谱的 30 %），重新计算蛇与鹰的营养级。

   **答** 取原来的营养级（蚱蜢 2，小鼠 2.5，蛇 3.5）：鹰 $= 1 + 0.4\cdot2.5 + 0.4\cdot3.5 + 0.2\cdot2 = 1 + 1 + 1.4 + 0.4 = 3.8$，巧合地不变。若蛇吃 70 % 小鼠和 30 % 蚱蜢，其营养级为 $1 + 0.7\cdot2.5 + 0.3\cdot2 = 3.35$，鹰的营养级变为 $1 + 0.4\cdot2.5 + 0.4\cdot3.35 + 0.2\cdot2 = 3.74$。

2. 一个群落有 $S = 100$ 个物种，连接度 $C = 0.1$，自我调节 $d = 1$。若相互作用是随机的，按 May 判据，与稳定性相容的最大均方根相互作用强度是多少？若它们全是捕食–被捕食对呢？若 $S$ 加倍而 $C$ 不变，相互作用强度必须下降到几分之几？

   **答** 随机：$\sigma < d/\sqrt{SC} = 1/\sqrt{10} = 0.32$。捕食–被捕食：$\sigma < 1/[\sqrt{10}(1 - 2/\pi)] = 0.316/0.363 = 0.87$。$S$ 加倍使 $\sqrt{SC}$ 乘以 $\sqrt2$，所以 $\sigma$ 必须下降到原来的 $1/\sqrt2 \approx 0.71$ 倍。

3. 证明 $2 \times 2$ 块 $\begin{bmatrix} 0 & a \\ -b & 0 \end{bmatrix}$（$a, b > 0$，没有自我调节的捕食–被捕食对）有纯虚特征值，而 $\begin{bmatrix} 0 & a \\ b & 0\end{bmatrix}$（互利共生）有一个正实特征值。把这与命题 38.4.2 联系起来。

   **答** 特征多项式分别为 $\lambda^2 + ab$ 和 $\lambda^2 - ab$，根为 $\pm\mathrm{i}\sqrt{ab}$ 和 $\pm\sqrt{ab}$。捕食–被捕食对使扰动旋转（中性振荡，如 [7.19.25](/7.19.25) 的 Lotka–Volterra 捕食者–猎物模型），贡献虚部而没有正实部，所以捕食–被捕食群落的特征值点云主要沿虚轴延伸，最右的特征值很小（$1 + \rho$，$\rho < 0$）。同号的对（互利共生，或竞争，其块 $\begin{bmatrix} 0 & -a\\ -b & 0\end{bmatrix}$ 的特征值也是 $\pm\sqrt{ab}$）是具有正实特征值的正反馈环，使点云沿实轴展开，需要更多的自我调节。

4. 十个平均生物量相等的物种独立波动，每个的变异系数为 0.4。总生物量的变异系数是多少？若成对相关为 0.5 呢？

   **答** 均值与方差相等且独立时，$\mathrm{CV}_{\mathrm{com}} = \mathrm{CV}_{\mathrm{pop}}/\sqrt S = 0.4/\sqrt{10} = 0.126$。$\rho = 0.5$ 时，由 (38.4)，$\mathrm{CV}_{\mathrm{com}} = 0.4\sqrt{0.5 + 0.5/10} = 0.4\sqrt{0.55} = 0.30$：同步性抵消了多样性的大部分益处。

5. 为什么一个食物网可能对随机的物种丧失稳健，却对特定物种的丧失脆弱？哪些种类的物种最可能在这一意义上是“特定的”？

   **答** 物种随机丧失时，多数丧失的是链接很少的物种，其消失不会使消费者没有食物，尤其是在连接度高、消费者有替代猎物时。当连接最多的物种丧失时，许多消费者同时失去食谱的很大一部分，次生灭绝随之扩散。丧失造成破坏最大的物种是：(1) 许多消费者所依赖的基位种或多度大的中间种（如南大洋的磷虾）；(2) 关键捕食者，其丧失使竞争优势种得到释放，通过竞争造成其他物种的灭绝，这是简单的拓扑模拟没有涵盖的效应（[7.19.33](/7.19.33)）；(3) 互利共生者，如嵌套网络核心的泛化传粉者。

6. （开放题）设计一项研究，检验一组湖泊中的食物链长度是受生产力、生态系统大小还是干扰所限制。

   **答** 选择 20–30 个湖泊，跨越总磷（生产力）、体积（大小）和干扰（如干涸或冬季鱼类死亡的频率）三个独立的梯度，避免三者相关。以顶位捕食者的营养位置从 $\delta^{15}\mathrm{N}$ 度量食物链长度，用长寿的初级消费者（螺、蚌）校正基线，$\mathrm{TP} = \lambda + (\delta^{15}\mathrm{N}_{\mathrm{top}} - \delta^{15}\mathrm{N}_{\mathrm{base}})/3.4$。把链长对三个变量（及其乘积，因为生产空间是生产力乘以大小）做回归，并用 AIC 比较模型。生产空间假说预测一个交互项或乘积项，生态系统大小假说预测一个独立于生产力的大小效应，动态稳定性假说预测干扰的负效应。再辅以中宇宙实验（施肥、添加捕食者），并考虑大小起作用的机制：更多的猎物物种、生境异质性、顶位捕食者更大的种群。
