许多生物在短暂的季节里一年繁殖一次，其后代与亲代不重叠：一年生植物、一化性昆虫、许多只有一个产卵季的鱼类。它们的种群大小自然是每个世代记录一次，而密度制约在每个世代内起作用的种群，用差分方程 $N_{t+1} = F(N_t)$ 描述。这样的方程看上去像是 7.19.10 的逻辑斯谛方程的离散化，但其行为大不相同。Robert May（1974，1976）表明，其中最简单的一类，只有一个变量而没有随机性，可以光滑地趋近平衡，也可以以周期 2、4、8、… 振荡，还可以表观随机地波动，而这只取决于繁殖率。本章完整地分析这些模型：它们的平衡点与稳定性，倍周期级联，用 Lyapunov 指数度量混沌，以及通向混沌的道路的普适性，它使其定量特征与模型的细节无关。本章最后讨论自然种群是否如此表现的证据。密度制约的模型来自 7.19.11，那里 $k$ 对 $\log N$ 的斜率 $b$ 度量竞争是欠补偿还是过度补偿；这里则看过度补偿对动态有什么作用。同一个 **logistic 映射**在计算神经科学中作为混沌最简单的例子出现（[7.16.31](/7.16.31#sec-31.2)）；微分方程中**分岔**的一般理论见 [2.4.11](/2.4.11#sec-11.6.4)。离散与连续模型中的时滞见 7.19.13。

## 12.1. 世代不重叠的密度制约模型

### 12.1.1. 模型

世代不重叠的单物种模型具有如下形式

$$
N_{t+1} = F(N_t) = N_tg(N_t), \tag{12.1}
$$
其中 $g(N)$ 是个体平均繁殖率（经过密度制约的死亡之后，这一世代每个个体产生的下一世代个体数）。没有密度制约时 $g \equiv \lambda$，增长是几何的（7.19.10）。密度制约使 $g$ 随 $N$ 减小；于是 $F$ 的形状决定动态。函数 $F$ 是*补充曲线*（在渔业中称为亲体–补充曲线）。它在低密度时上升；若它一直上升，密度制约是欠补偿或恰好补偿的；若它呈驼峰形，有一个最大值和下降的一支，则密度制约是过度补偿的（定义 11.2.2）。

**公式 12.1.1（密度制约的离散时间模型）** 设 $\lambda$（或 $\mathrm{e}^r$，或 $1 + r$）为低密度时的个体平均速率，$K$ 或 $N^*$ 为正平衡点：

| 模型 | $N_{t+1} = F(N_t)$ | $F$ 的形状 | 生物学来源 |
|---|---|---|---|
| 离散逻辑斯谛 | $N_t\bigl[1 + r\bigl(1 - N_t/K\bigr)\bigr]$ | 抛物线，$N > K(1 + r)/r$ 时 $F < 0$ | 个体平均增长率线性下降 |
| Ricker（1954） | $N_t\exp\bigl[r\bigl(1 - N_t/K\bigr)\bigr]$ | 驼峰形，恒为正 | 存活率随密度指数下降（同类相食、疾病） |
| Beverton–Holt（1957） | $\lambda N_t/(1 + aN_t)$，$K = (\lambda - 1)/a$ | 饱和型 | 对有限资源的争夺 |
| Hassell（1975） | $\lambda N_t/(1 + aN_t)^b$ | 饱和型（$b \leq 1$）或驼峰形（$b > 1$） | 一般补偿 $b$ |
| Maynard Smith–Slatkin（1973） | $\lambda N_t/[1 + (aN_t)^b]$ | 饱和型（$b \leq 1$）或驼峰形（$b > 1$） | 一般补偿 $b$ |

当每个新生个体独立地以概率 $\mathrm{e}^{-cN}$ 逃脱密度制约的危害时，如卵和幼体被成体吃掉的鱼类，就得到 Ricker 模型；当个体平均存活率按双曲线下降时，如分享固定数量的食物或空间，就得到 Beverton–Holt 模型（7.19.11 的思考题 2 给出其精确解）。离散逻辑斯谛在代数上最简单，也是能映射到数学中所研究的标准形式的一个。

**命题 12.1.1（离散逻辑斯谛模型与 logistic 映射）** 代换 $x = rN/[(1 + r)K]$ 把离散逻辑斯谛模型 $N_{t+1} = N_t[1 + r(1 - N_t/K)]$ 变为 **logistic 映射**（[7.16.31](/7.16.31#def-31.2.1)）

$$
x_{t+1} = \mu x_t(1 - x_t), \qquad \mu = 1 + r. \tag{12.2}
$$
平衡点 $N = K$ 对应于 $x^* = 1 - 1/\mu$。该模型使种群保持在区间 $0 \leq N \leq K(1 + r)/r$（等价地 $0 \leq x \leq 1$）内，当且仅当 $\mu \leq 4$，即 $r \leq 3$。

**证明** $N_{t+1} = (1 + r)N_t - rN_t^2/K = (1 + r)N_t[1 - rN_t/((1 + r)K)]$。乘以 $r/[(1 + r)K]$ 得 $x_{t+1} = (1 + r)x_t(1 - x_t)$。$N = K$ 给出 $x = r/(1 + r) = 1 - 1/\mu$。映射 $x \mapsto \mu x(1 - x)$ 把 $[0, 1]$ 映入 $[0, \mu/4]$，最大值在 $x = 1/2$ 取得；当且仅当 $\mu \leq 4$ 时它位于 $[0, 1]$ 内。对 $\mu > 4$，$1/2$ 附近的点被映到 1 以上，随后映到负值。$\square$

所以，如果密度足够高，离散逻辑斯谛就预测出负的种群，这是该模型的缺陷，而具有指数尾部的 Ricker 模型没有这一缺陷。许多中文教材使用的参数化 $N_{t+1} = N_t[1 - B(N_t - N_{\mathrm{eq}})]$，$L = BN_{\mathrm{eq}}$，是同一个模型：展开得 $N_t[1 + L(1 - N_t/N_{\mathrm{eq}})]$，所以 $L = r$，$N_{\mathrm{eq}} = K$。它那些著名的阈值（$L = 1$、2 和约 2.57）就是下面对 $r$ 导出的那些。

### 12.1.2. 不动点的稳定性

方程 (12.1) 的平衡点是**不动点** $N^* = F(N^*)$（[3.5.4](/3.5.4)）。在它附近，小的偏差 $n_t = N_t - N^*$ 每个世代乘以补充曲线的斜率 $F'(N^*)$，我们称之为不动点的*乘子*。

**定理 12.1.1（映射不动点的稳定性）** 设 $F$ 在不动点 $N^*$ 附近连续可微，乘子为 $m = F'(N^*)$。

(a) 若 $\lvert m\rvert < 1$，则 $N^*$ 渐近稳定：存在 $\delta > 0$，使得 $\lvert N_0 - N^*\rvert < \delta$ 蕴含对某个 $c < 1$ 有 $\lvert N_t - N^*\rvert \leq c^t\lvert N_0 - N^*\rvert$，所以 $N_t$ 几何地趋于 $N^*$。

(b) 若 $\lvert m\rvert > 1$，则 $N^*$ 不稳定：每条从 $N^*$ 附近但不在 $N^*$ 出发的轨道都会离开 $N^*$ 的某个邻域。

(c) $m$ 的符号决定趋近或离开的方式：当 $0 < m < 1$ 时，偏差衰减而不变号（单调阻尼），当 $-1 < m < 0$ 时，偏差交替变号而振幅减小（阻尼振荡）；当 $m > 1$ 时，偏差单调增长，当 $m < -1$ 时，偏差交替变号增长。$m = 0$ 称为超稳定（收敛快于几何速度）。

**证明** (a) 取 $c$ 使 $\lvert m\rvert < c < 1$。由 $F'$ 的连续性，存在 $\delta > 0$，使得 $\lvert N - N^*\rvert < \delta$ 时 $\lvert F'(N)\rvert \leq c$。由中值定理，对这样的 $N$，$\lvert F(N) - N^*\rvert = \lvert F(N) - F(N^*)\rvert = \lvert F'(\xi)\rvert\lvert N - N^*\rvert \leq c\lvert N - N^*\rvert < \delta$，其中 $\xi$ 在 $N$ 与 $N^*$ 之间。所以区间 $(N^* - \delta, N^* + \delta)$ 被映入自身，由归纳法 $\lvert N_t - N^*\rvert \leq c^t\lvert N_0 - N^*\rvert$。

(b) 取 $c$ 使 $1 < c < \lvert m\rvert$，并取 $\delta$ 使得 $\lvert N - N^*\rvert < \delta$ 时 $\lvert F'(N)\rvert \geq c$。只要 $N_t$ 留在这一邻域内，就有 $\lvert N_{t+1} - N^*\rvert \geq c\lvert N_t - N^*\rvert$，所以 $\lvert N_t - N^*\rvert \geq c^t\lvert N_0 - N^*\rvert$，经过有限步后它超过 $\delta$。

(c) 由 Taylor 定理，$n_{t+1} = mn_t + o(n_t)$，所以对小的偏差，$n_t \approx m^tn_0$，其符号交替当且仅当 $m < 0$。$\square$

当 $\lvert m\rvert = 1$ 时，线性项不能决定稳定性；这些恰恰是定性行为发生改变的参数值（分岔）。用补充曲线来说：位于 $F$ 上升的一支（$m > 0$）上的平衡点被单调地趋近；位于下降的一支（$m < 0$）上，种群交替地超越和不足，如果下降的一支比 $-1$ 更陡，平衡点就根本无法维持种群。这是 Begon 关于过度补偿的密度制约与高繁殖率结合会使种群失稳的论断的精确版本。同样的判据，用沿周期的乘子之积，给出周期轨道的稳定性（[7.16.31](/7.16.31#prop-31.2.1)）；我们在 12.3 节为 2 周期导出它。

### 12.1.3. 各模型的阈值

**命题 12.1.2（各模型的乘子）** 各模型在正平衡点的乘子为：

| 模型 | $F'(N^*)$ | 单调阻尼 | 阻尼振荡 | 不稳定（$F' < -1$） |
|---|---|---|---|---|
| 离散逻辑斯谛，Ricker | $1 - r$ | $0 < r \leq 1$ | $1 < r < 2$ | $r > 2$ |
| Beverton–Holt | $1/\lambda$ | 所有 $\lambda > 1$ | 从不 | 从不 |
| Hassell | $1 - b\bigl(1 - \lambda^{-1/b}\bigr)$ | $b(1 - \lambda^{-1/b}) \leq 1$ | 介于两者之间 | $b(1 - \lambda^{-1/b}) > 2$ |
| Maynard Smith–Slatkin | $1 - b(1 - 1/\lambda)$ | $b(1 - 1/\lambda) \leq 1$ | 介于两者之间 | $b(1 - 1/\lambda) > 2$ |

**证明** 离散逻辑斯谛：$F'(N) = 1 + r - 2rN/K$，所以 $F'(K) = 1 - r$。Ricker：$F'(N) = (1 - rN/K)\mathrm{e}^{r(1 - N/K)}$，所以 $F'(K) = 1 - r$。Beverton–Holt：$F'(N) = \lambda/(1 + aN)^2$，且 $1 + aN^* = \lambda$，所以 $F'(N^*) = 1/\lambda$。Hassell：$F'(N) = \lambda(1 + aN)^{-b}[1 - baN/(1 + aN)]$；在 $N^*$ 处，$\lambda(1 + aN^*)^{-b} = 1$，$aN^*/(1 + aN^*) = 1 - \lambda^{-1/b}$。Maynard Smith–Slatkin：$F'(N) = \lambda[1 + (1 - b)(aN)^b]/[1 + (aN)^b]^2$；在 $N^*$ 处，$(aN^*)^b = \lambda - 1$，给出 $[1 + (1 - b)(\lambda - 1)]/\lambda = 1 - b(1 - 1/\lambda)$。分类由定理 12.1.1 得出。$\square$

由此得到几个结论。两个单参数驼峰模型在同一繁殖率 $r = 2$ 处失稳，即 Ricker 模型每世代增长 $\mathrm{e}^2 = 7.4$ 倍，离散逻辑斯谛增长 $1 + r = 3$ 倍。恰好补偿（Beverton–Holt，$b = 1$）无论繁殖率多高都给出单调阻尼：在这一框架内，有争夺竞争的种群不可能振荡。在 Hassell 模型中，$b(1 - \lambda^{-1/b})$ 随 $b$ 和 $\lambda$ 增加，当 $b \to \infty$ 时趋于 $\ln\lambda$，所以若 $\lambda < \mathrm{e}^2$，平衡点对每个 $b$ 都稳定；若 $b \leq 2$（因为 $1 - \lambda^{-1/b} < 1$），平衡点对每个 $\lambda$ 都稳定。振荡既要求高繁殖率，*又*要求强烈的过度补偿的密度制约。

## 12.2. 蛛网图

定理 12.1.1 描述的是平衡点附近的动态；一维映射的全局动态可以在一幅图中看到。

**定义 12.2.1（蛛网图）** 映射 $x_{t+1} = f(x_t)$ 的**蛛网图**是 $f$ 的图像连同对角线 $x_{t+1} = x_t$，从 $x_0$ 出发的轨道在上面画成一条路径：从对角线上的点 $(x_t, x_t)$ 垂直地到图像上的 $(x_t, f(x_t))$，再水平地回到对角线上的 $(x_{t+1}, x_{t+1})$，如此继续。

不动点是图像与对角线的交点，图像在该处的斜率就是乘子。若图像以介于 0 与 1 之间的斜率穿过对角线，路径是收敛到不动点的阶梯；斜率介于 $-1$ 与 0 之间，是收敛到不动点的螺旋；斜率小于 $-1$，是远离它的螺旋。因为路径始终在图像和对角线上，蛛网图也显示轨道在全局上能到哪里：对驼峰形的 $F$，轨道不能超过 $F$ 的最大值，而一旦到达那里，就不能低于 $F(F_{\max})$，所以即使种群混沌地波动，也被限制在这两个界限之间。在这个意义上，即使是混沌的种群也受到调节。

![离散逻辑斯谛模型 x_{t+1} = x_t[1 + r(1 − x_t)]（x = N/K，定义 12.2.1）的蛛网图，起点为 x₀ = 0.1。上：补充曲线（蓝）、对角线和轨道（橙；后三幅中前几步较淡）。r = 0.8：平衡点 x = 1 位于上升的一支，以阶梯方式趋近。r = 1.6：它位于下降的一支，斜率为 −0.6，以向内的螺旋趋近（阻尼振荡）。r = 2.3：斜率为 −1.3，螺旋向外移动，趋于稳定的 2 周期（一个正方形）。r = 2.5：4 周期。r = 2.8：轨道在 F(F_max) 与 F_max 之间的区间上不规则地游荡（混沌）。下：相应的时间序列](./plots/cobweb.py)

## 12.3. 倍周期与分岔图

### 12.3.1. 2 周期

现在来看平衡点失稳时发生什么。用 logistic 映射 (12.2)，$f(x) = \mu x(1 - x)$，比较方便；结果通过 $r = \mu - 1$ 转换到离散逻辑斯谛模型。

$f$ 的不动点为 $0$（乘子 $\mu$）和 $x^* = 1 - 1/\mu$，其乘子为 $f'(x^*) = \mu(1 - 2x^*) = 2 - \mu$，所以 $x^*$ 在 $1 < \mu < 3$ 时稳定。在 $\mu = 3$ 处，乘子穿过 $-1$。

**定义 12.3.1（倍周期分岔）** 当参数变化使映射的不动点（或周期轨道）的乘子穿过 $-1$ 时，发生映射的**倍周期分岔**（翻转分岔）：不动点失去稳定性，并出现（或消失）一条周期为两倍的周期轨道，起初它靠近不动点。

**命题 12.3.1（logistic 映射的 2 周期）** 对 $\mu > 3$，logistic 映射恰有一条周期为 2 的轨道 $\{p, q\}$，其中

$$
p, q = \frac{(\mu + 1) \mp\sqrt{(\mu + 1)(\mu - 3)}}{2\mu}. \tag{12.3}
$$
它在 $3 < \mu < 1 + \sqrt6 \approx 3.449$ 时稳定（在离散逻辑斯谛模型中即 $2 < r < \sqrt6 \approx 2.449$），在 $\mu = 1 + \sqrt6$ 处通过倍周期分岔失稳，变为 4 周期。

**证明** 2 周期由 $f^{(2)} = f\circ f$ 的不是 $f$ 的不动点的不动点组成。由 $q = f(p)$ 和 $p = f(q)$：相减，$q - p = \mu(p - q) - \mu(p^2 - q^2) = \mu(p - q)[1 - (p + q)]$，除以 $q - p \neq 0$ 得 $p + q = (\mu + 1)/\mu$。相加，$p + q = \mu(p + q) - \mu(p^2 + q^2) = \mu(p + q) - \mu[(p + q)^2 - 2pq]$，与上面的和合并得 $pq = (\mu + 1)/\mu^2$。所以 $p$ 和 $q$ 是 $\mu^2x^2 - \mu(\mu + 1)x + (\mu + 1) = 0$ 的根，当且仅当判别式 $\mu^2(\mu + 1)^2 - 4\mu^2(\mu + 1) = \mu^2(\mu + 1)(\mu - 3)$ 为正，即 $\mu > 3$ 时，根为不相等的实数；这给出式 (12.3)。

由链式法则，$(f^{(2)})'(p) = f'(f(p))f'(p) = f'(q)f'(p)$，在 $q$ 处有相同的值：周期的乘子是沿周期各乘子的乘积。由 $f'(x) = \mu(1 - 2x)$，

$$
f'(p)f'(q) = \mu^2[1 - 2(p + q) + 4pq] = \mu^2\Bigl[1 - \frac{2(\mu + 1)}{\mu} + \frac{4(\mu + 1)}{\mu^2}\Bigr] = -\mu^2 + 2\mu + 4.
$$
由定理 12.1.1 用于 $f^{(2)}$，该周期稳定当且仅当 $-1 < -\mu^2 + 2\mu + 4 < 1$。右边的不等式是 $\mu^2 - 2\mu - 3 = (\mu - 3)(\mu + 1) > 0$，对 $\mu > 3$ 成立。左边是 $\mu^2 - 2\mu - 5 < 0$，即 $\mu < 1 + \sqrt6$。在 $\mu = 1 + \sqrt6$ 处，乘子穿过 $-1$。$\square$

在 $\mu = 3$ 处，周期的乘子等于 $+1$，且 $p = q = x^*$：该周期恰如定义 12.3.1 所描述的那样，由不动点诞生。在生物学上，种群在高年和低年之间交替：一个大的世代使其后代的存活降低得如此之多，以致下一世代很小，而这个小世代又产生一个大世代。这样的交替在幼虫竞争强烈的实验室昆虫种群中很常见。

![logistic 映射 f(x) = μx(1 − x) 的 2 周期（命题 12.3.1）。A–C：f（细线）与二次迭代 f(f(x))（粗线）及对角线。在 μ = 2.8 时，唯一的正交点是不动点 x*（空心圆），f(f(x)) 在该处的斜率为 (2 − μ)² = 0.64 < 1。在 μ = 3.2 时，x* 处的斜率为 1.44，出现了两个新的交点 p 和 q（实心），斜率 f′(p)f′(q) = −μ² + 2μ + 4 = 0.16：稳定的 2 周期。在 μ = 3.5 时，该斜率为 −1.25，2 周期已变得不稳定。D：不动点的乘子（2 − μ）与 2 周期的乘子（−μ² + 2μ + 4）；每条轨道在其乘子位于阴影带 (−1, 1) 内时稳定，所以不动点在 μ = 3 处让位于 2 周期，2 周期在 μ = 1 + √6 处让位于 4 周期](./plots/period-2.py)

### 12.3.2. 分岔图

4 周期又依次失稳并产生 8 周期，如此继续。logistic 映射的分岔值为

$$
\mu_1 = 3, \quad \mu_2 = 1 + \sqrt6 = 3.449490, \quad \mu_3 = 3.544090, \quad \mu_4 = 3.564407, \quad \mu_5 = 3.568759, \quad \dots \to \mu_\infty = 3.569946,
$$
它们之间的间隔几何地缩小。整个序列显示在*分岔图*中，其中对每个参数值，画出吸引子（瞬态消失之后访问的值的集合）。对离散逻辑斯谛模型，$r_k = \mu_k - 1$：级联累积于 $r_\infty = 2.5699$；对 Ricker 模型，倍周期从 $r = 2$ 开始，并在 $r = 2.526$、$2.656$、… 继续，直到 $r_\infty = 2.6924$。

超过 $r_\infty$，多数参数值给出**混沌**（[7.16.31](/7.16.31#def-31.2.3)）：有界的非周期波动，且对初始条件敏感依赖。混沌区域被*周期窗口*打断，即存在稳定周期的参数区间。logistic 映射最大的窗口始于 $\mu = 1 + \sqrt8 = 3.8284$（$r = 2.828$），出现稳定的 3 周期，它与一个不稳定的 3 周期一同诞生于 $f^{(3)}$ 的**鞍结分岔**（[7.6.33](/7.6.33)），然后这个 3 周期经历它自己的倍周期级联（6、12、24、…）。Li 与 Yorke（1975）的定理“周期三意味着混沌”指出，具有周期为 3 的点的区间连续映射具有每一种周期的点，并有不可数的非周期轨道集；Sharkovskii 定理（1964）给出了哪些周期蕴含哪些周期的完整排序。因此，在混沌带内，无穷多个不稳定的周期共存，而在窗口中，稳定的周期吸引几乎所有轨道。

## 12.4. Lyapunov 指数与混沌的诊断

混沌轨道不是随机的：它由确定性规则产生，保持在界限之内，且可以作短期预测。它与稳定周期的区别在于，两条起点靠近的轨道以指数速度分离。考虑两个初值 $x_0$ 和 $x_0 + \delta_0$。一步之后，它们的距离为 $\lvert f(x_0 + \delta_0) - f(x_0)\rvert \approx \lvert f'(x_0)\rvert\lvert\delta_0\rvert$，$n$ 步之后，由链式法则，

$$
\lvert\delta_n\rvert \approx \lvert f'(x_{n-1})\cdots f'(x_1)f'(x_0)\rvert\,\lvert\delta_0\rvert, \qquad \frac1n\ln\frac{\lvert\delta_n\rvert}{\lvert\delta_0\rvert} \approx \frac1n\sum_{k=0}^{n-1}\ln\lvert f'(x_k)\rvert.
$$

**定义 12.4.1（映射的 Lyapunov 指数）** 映射 $f$ 下 $x_0$ 的轨道的**李雅普诺夫指数**（[7.16.31](/7.16.31#def-31.2.2)）为

$$
\lambda = \lim_{n\to\infty}\frac1n\sum_{k=0}^{n-1}\ln\lvert f'(x_k)\rvert, \tag{12.4}
$$
即邻近轨道每步分离的平均指数速率。若一条轨道有界，不渐近于周期，且 $\lambda > 0$，则它是混沌的。

**命题 12.4.1（周期的 Lyapunov 指数）** 若 $x_0$ 的轨道收敛到周期轨道 $x_1^*, \dots, x_p^*$（其中没有 $f$ 的临界点），则

$$
\lambda = \frac1p\ln\Bigl\lvert\prod_{i=1}^pf'(x_i^*)\Bigr\rvert.
$$
特别地，稳定周期的 $\lambda < 0$，倍周期分岔处（乘子为 $-1$）$\lambda = 0$，超稳定周期（乘子为 0，周期穿过临界点）的 $\lambda = -\infty$。

**证明** 沿轨道，$\ln\lvert f'(x_k)\rvert$ 收敛到周期序列 $\ln\lvert f'(x_i^*)\rvert$，所以它的 Cesàro 平均收敛到一个周期上的平均，$\frac1p\sum_i\ln\lvert f'(x_i^*)\rvert = \frac1p\ln\lvert\prod_if'(x_i^*)\rvert$。稳定周期有 $\lvert\prod f'\rvert < 1$（把定理 12.1.1 用于 $f^{(p)}$），所以 $\lambda < 0$；乘子的绝对值为 1 给出 $\lambda = 0$；而穿过临界点的周期含有因子 $f' = 0$。（在超稳定参数处，轨道的收敛快于几何速度，和发散到 $-\infty$。）$\square$

对某一个参数值，logistic 映射的 Lyapunov 指数可以精确算出。

**命题 12.4.2（$\mu = 4$ 时的 logistic 映射）** 对 $\mu = 4$，logistic 映射通过 $x = h(\theta) = \sin^2(\pi\theta/2)$ 与 $[0, 1]$ 上的帐篷映射 $T(\theta) = 1 - \lvert1 - 2\theta\rvert$ 共轭，即 $f\circ h = h\circ T$。几乎每条轨道都有不变密度 $\rho(x) = 1/\bigl(\pi\sqrt{x(1 - x)}\bigr)$，且 Lyapunov 指数 $\lambda = \ln 2$。

**证明** $f(h(\theta)) = 4\sin^2(\pi\theta/2)\cos^2(\pi\theta/2) = \sin^2(\pi\theta)$。对 $\theta \leq 1/2$，$h(T(\theta)) = \sin^2(\pi\theta)$；对 $\theta > 1/2$，$h(2 - 2\theta) = \sin^2(\pi - \pi\theta) = \sin^2(\pi\theta)$。所以 $f\circ h = h\circ T$。帐篷映射保持 $[0, 1]$ 上的均匀分布（每个子区间有两个原像，长度各为其一半），并且是遍历的，所以 $T$ 的几乎每条轨道都均匀分布；用 $h$ 映射，$f$ 的几乎每条轨道的分布，具有 $x = h(\Theta)$（$\Theta$ 均匀）的密度：$\rho(x) = \bigl[\frac{\mathrm{d}h}{\mathrm{d}\theta}\bigr]^{-1} = 1/(\pi\sin(\pi\theta/2)\cos(\pi\theta/2)) = 1/\bigl(\pi\sqrt{x(1 - x)}\bigr)$。由 Birkhoff 遍历定理，式 (12.4) 中的时间平均等于空间平均：

$$
\lambda = \int_0^1\ln\lvert f'(x)\rvert\rho(x)\,\mathrm{d}x = \int_0^1\ln\lvert4(1 - 2h(\theta))\rvert\,\mathrm{d}\theta = \int_0^1\ln\lvert4\cos(\pi\theta)\rvert\,\mathrm{d}\theta,
$$
这里用了 $1 - 2\sin^2(\pi\theta/2) = \cos(\pi\theta)$。由于 $\int_0^1\ln\lvert\cos(\pi\theta)\rvert\,\mathrm{d}\theta = \frac{2}{\pi}\int_0^{\pi/2}\ln\cos u\,\mathrm{d}u = \frac2\pi\bigl(-\frac\pi2\ln2\bigr) = -\ln 2$，得 $\lambda = \ln 4 - \ln 2 = \ln 2$。$\square$

所以在 $\mu = 4$ 时，初始的不确定性平均每个世代增加一倍：$10^{-6}$ 的测量误差在约 $\ln(10^6)/\ln 2 \approx 20$ 个世代后增长到吸引子的大小。更一般地，对初始不确定性 $\delta_0$ 和吸引子大小 $L$，正的 Lyapunov 指数确定了量级为 $\lambda^{-1}\ln(L/\delta_0)$ 步的预测视界。在这一视界之内，混沌的种群是可预测的（比随机的更可预测）；超出这一视界，对当前状态的了解就毫无用处。所以，诊断自然界中的混沌不是一个学院式的问题：它决定了对种群大小可以提前预报多远。

由数据估计 $\lambda$ 需要 $F$ 的模型，因为式 (12.4) 中的导数是观测不到的。实践中，$F$ 用非参数方法估计（把 $N_{t+1}$ 对 $N_t$ 回归，种群有隐藏的结构时则对若干滞后值回归，使用 Takens 定理所证明的时滞嵌入），然后由拟合的函数算出 $\lambda$。Ellner 与 Turchin（1995）把这类方法应用于实验室、野外和流行病学的长序列数据，发现多数野外种群的指数为负或近于零：动态接近稳定与混沌的边缘，但很少明确地是混沌的。生态学序列短而有噪声，使任何这样的估计都不确定（Bjørnstad 与 Grenfell 2001）。

## 12.5. 普适性：Feigenbaum 常数

上图中 logistic 和 Ricker 模型的分岔图在标度上不同，但除此之外惊人地相似。这种相似是定量的。Feigenbaum（1978）发现，倍周期分岔序列几何地收敛，其比值对所有具有单个二次极大值的光滑映射都相同。

**定义 12.5.1（Feigenbaum 常数）** 对具有二次极大值的单峰映射的单参数族，设 $\mu_n$ 为第 $n$ 次倍周期分岔（由周期 $2^{n-1}$ 到 $2^n$）的参数，$d_n$ 为在该周期的超稳定参数处，从临界点到 $2^n$ 周期最近的点的距离。**Feigenbaum 常数**为

$$
\delta = \lim_{n\to\infty}\frac{\mu_n - \mu_{n-1}}{\mu_{n+1} - \mu_n} = 4.669201\dots, \qquad \alpha = \lim_{n\to\infty}\frac{d_n}{d_{n+1}} = -2.502907\dots. \tag{12.5}
$$
用超稳定参数 $R_n$（此时 $2^n$ 周期穿过临界点）代替 $\mu_n$，得到同样的极限。

$\delta$ 度量分岔在参数空间中累积的快慢；$\alpha$ 度量吸引子在状态空间中每次倍周期时收缩的程度，其符号记录每次倍周期都使方向翻转。对 logistic 映射，$(\mu_2 - \mu_1)/(\mu_3 - \mu_2) = 0.4495/0.0946 = 4.75$，$(\mu_3 - \mu_2)/(\mu_4 - \mu_3) = 4.66$；对 Ricker 模型，相应的比值从下方趋近同一极限。知道了 $\delta$，就可以由最初几次分岔预测累积点：$\mu_\infty \approx \mu_n + (\mu_n - \mu_{n-1})/(\delta - 1)$，由 $\mu_3$ 和 $\mu_4$ 得到 3.56995。

为什么比值应当是普适的？看二次迭代 $f^{(2)}$ 在最靠近临界点的 2 周期点附近的样子（12.3.1 节的图，面板 B）：它是原来驼峰的一个小的、倒置的副本。$f$ 的倍周期对应于 $f^{(2)}$ 的一个不动点的失稳，它通过同样的机制发生，发生在缩放后的副本看上去像 $f$ 自己的第一次分岔时的参数处。在每一层重复这一论证，倍周期级联由从一层到下一层的映射支配，即*重整化*（倍周期）算子 $\mathcal{T}[g](x) = \alpha\,g(g(x/\alpha))$，它把函数变为其二次迭代，并按 $\alpha$ 缩放。级联的定量特征是这个算子的性质，而不是具体的 $f$ 的性质，因此是普适的。这一论证的粗糙版本可以手工完成。

**命题 12.5.1（近似重整化）** 在每一层都截断到二次项，logistic 映射在其倍周期附近具有正规形式 $\xi_{t+1} = -(1 + \nu)\xi_t - \xi_t^2$（$\nu = \mu - 3$），而最靠近临界点的 2 周期点附近的二次迭代，在按因子 $C(\nu)$ 缩放之后，具有同样的形式，参数为 $\tilde\nu = \nu^2 + 4\nu - 2$。因此：

1. 分岔参数满足 $\nu_k = \nu_{k+1}^2 + 4\nu_{k+1} - 2$，$\nu_1 = 0$，它精确地给出 $\mu_2 = 1 + \sqrt6$，以及 $\mu_3 \approx 3.5396$；
2. 它们累积于不动点 $\nu^* = (\sqrt{17} - 3)/2$，即 $\mu_\infty \approx 3.5616$；
3. $\delta \approx 2\nu^* + 4 = 1 + \sqrt{17} \approx 5.12$，$\alpha \approx C(\nu^*) \approx -2.24$。

**证明** 设 $x^* = 1 - 1/\mu$，$\eta = x - x^*$。因为 $f$ 是二次的，$f(x^* + \eta) = x^* + f'(x^*)\eta + \tfrac12f''\eta^2 = x^* + (2 - \mu)\eta - \mu\eta^2$ 精确成立。令 $\xi = \mu\eta$，$\nu = \mu - 3$，它化为 $\xi_{t+1} = -(1 + \nu)\xi_t - \xi_t^2 =: g_\nu(\xi_t)$，其不动点 0 的乘子为 $-(1 + \nu)$，并在 $\nu = 0$ 处倍周期。

$g_\nu$ 的 2 周期：由 $g(p) = q$，$g(q) = p$，如同命题 12.3.1，得 $p + q = -\nu$，$pq = -\nu$，所以 $p, q = (-\nu \pm\sqrt{\nu^2 + 4\nu})/2$，乘子为 $g'(p)g'(q) = [(1 + \nu) + 2p][(1 + \nu) + 2q] = (1 + \nu)^2 + 2(1 + \nu)(p + q) + 4pq = 1 - 4\nu - \nu^2$。

在 $q$（取负号的根，更靠近 $g$ 的临界点 $-(1 + \nu)/2$）附近展开 $g^{(2)}$。由 $g(q + \eta) = p + g'(q)\eta - \eta^2$ 和 $g(p + \varepsilon) = q + g'(p)\varepsilon - \varepsilon^2$，

$$
g^{(2)}(q + \eta) - q = g'(p)\bigl(g'(q)\eta - \eta^2\bigr) - g'(q)^2\eta^2 + O(\eta^3) = M\eta - C\eta^2 + O(\eta^3),
$$
其中 $M = g'(p)g'(q)$，$C = g'(p) + g'(q)^2$。缩放 $\tilde\xi = C\eta$ 并略去三次项，得 $\tilde\xi_{t+2} = M\tilde\xi_t - \tilde\xi_t^2$，这是正规形式，其中 $-(1 + \tilde\nu) = M = 1 - 4\nu - \nu^2$，即 $\tilde\nu = \nu^2 + 4\nu - 2$。

当 $2^k$ 周期的重整化映射的参数达到上一层的倍周期值时，它就倍周期，由此得到 (1) 中的递推式。取 $\nu_1 = 0$：$\nu_2^2 + 4\nu_2 - 2 = 0$，$\nu_2 = \sqrt6 - 2$，所以 $\mu_2 = 1 + \sqrt6$，即命题 12.3.1 的精确值；而 $\nu_3 = -2 + \sqrt{6 + \nu_2} = 0.5396$。递推式 $\nu_k = \phi(\nu_{k+1})$，其中 $\phi(\nu) = \nu^2 + 4\nu - 2$，有不动点 $\nu^* = \phi(\nu^*)$，$\nu^{*2} + 3\nu^* - 2 = 0$，$\nu^* = (\sqrt{17} - 3)/2 = 0.5616$，逆迭代收敛于它。在它附近，$\nu_k - \nu^* \approx \phi'(\nu^*)(\nu_{k+1} - \nu^*)$，所以相继区间之比趋于 $\phi'(\nu^*) = 2\nu^* + 4 = 1 + \sqrt{17} = 5.12$。在 $\nu^*$ 处，$p = 0.519$，$q = -1.081$，$g'(p) = -2.600$，$g'(q) = 0.600$，每一层长度尺度改变 $C = -2.600 + 0.360 = -2.24$。$\square$

这一近似对 $\delta$ 和 $\alpha$ 的精度约为 10%，并且已经表明了普适性的来源：递推 $\phi$ 不依赖于起始的映射，只依赖于它的二次极大值。Feigenbaum 与 Cvitanović 使这一论证变得精确。普适函数是倍周期算子的不动点，一个满足 $g(0) = 1$ 的偶函数，满足

$$
g(x) = \alpha\,g\bigl(g(x/\alpha)\bigr), \qquad \alpha = 1/g(1), \tag{12.6}
$$
而 $\delta$ 是倍周期算子在 $g$ 处线性化后唯一大于 1 的特征值。方程 (12.6) 可以通过展开 $g(x) = 1 + c_1x^2 + c_2x^4 + \cdots$ 并解出系数（$c_1 = -1.5276$，$c_2 = 0.1048$，…）数值地求解，得到 $\alpha = -2.50291$。Lanford（1982）用计算机辅助证明证明了该不动点的存在。

![倍周期的普适性（定义 12.5.1）。A：在 logistic 映射的累积点，迭代 f^(2ⁿ) 以临界点为中心并缩放，使其在该处的值为 1，n = 0 到 4（蓝，由浅到深）收敛到普适函数 g（红色虚线），它是用 16 次多项式算出的 g(x) = αg(g(x/α)) 的解（式 (12.6)）；α = 1/g(1) = −2.50291。B：logistic 映射 μx(1 − x)、Ricker 映射 x exp(r(1 − x)) 和正弦映射 μ sin(πx) 的相继超稳定参数间隔之比 δₙ：三个序列起点不同，收敛到同一个 δ = 4.6692…，而累积点 R∞（3.56995、2.69237 和 0.86558）则因映射而异](./plots/feigenbaum.py)

这些常数已在液氦对流、非线性电路和激光的实验中测得，它们都通过倍周期进入混沌，比值接近 4.67（Libchaber 及合作者，1982）。对生态学来说，普适性意味着，单物种模型所预测的通向混沌的道路不依赖于用哪个模型：任何补充曲线只有一个光滑驼峰（过度补偿的密度制约）的种群，随着繁殖率增加，都从稳定平衡经倍周期进入混沌，并具有同样的几何比例。依赖于模型的只是这一过程发生在 $r$ 或 $\lambda$ 标度的什么位置。

## 12.6. 生态学中的混沌

### 12.6.1. May 的发现与自然种群的参数

May 的论文（1974 年发表于 *Science*，1976 年发表于 *Nature*）的影响远远超出了生态学，因为它们表明，生物过程中最简单的非线性模型就能产生与噪声无法区分的行为。对生态学家来说，其含义是，自然种群的不规则波动不一定由天气或其他外部因素的波动引起：密度制约的内部动态也可能是原因。密度制约是调节种群的力量（7.19.11），当它过度补偿并作用于繁殖率高的种群时，就变得使种群失稳。

自然种群是否具有这样的参数，是一个经验问题。Hassell、Lawton 与 May（1976）把 Hassell 模型（公式 12.1.1）拟合到一系列昆虫种群的生命表数据，包括野外的和实验室的，并把它们定位在 12.1.3 节图中的 $(\lambda, b)$ 平面上。多数野外种群落在单调阻尼区，少数落在阻尼振荡区，只有一个野外种群，即马铃薯甲虫（*Leptinotarsa decemlineata*），越过了稳定性边界；食物充足而没有天敌的实验室种群，更常常是振荡的。自然单物种动态通常稳定这一结论，后来在几方面受到限制。把单物种模型拟合到嵌入群落中的种群，会把天敌的影响吸收进参数；由含噪声数据估计 $b$ 是有偏的；而且几种重要的昆虫种群的振荡动态是由与天敌的相互作用（7.19.27）而不是种内竞争产生的。

### 12.6.2. 实验室赤拟谷盗种群中的混沌

生物种群中混沌最令人信服的证明，来自 Costantino、Cushing、Dennis 和 Desharnais 研究了十年的赤拟谷盗（*Tribolium castaneum*）。它的动态由同类相食支配：成虫吃卵和蛹，幼虫吃卵。LPA 模型以两周为时间步长，追踪幼虫 $L$、蛹 $P$ 和成虫 $A$：

$$
\begin{aligned}
L_{t+1} &= bA_t\exp(-c_{\mathrm{el}}L_t - c_{\mathrm{ea}}A_t),\\
P_{t+1} &= (1 - \mu_{\mathrm{l}})L_t,\\
A_{t+1} &= P_t\exp(-c_{\mathrm{pa}}A_t) + (1 - \mu_{\mathrm{a}})A_t,
\end{aligned} \tag{12.7}
$$
其中 $b$ 是没有同类相食时每个成虫的幼虫补充数，$\exp(-c_{\mathrm{el}}L)$ 和 $\exp(-c_{\mathrm{ea}}A)$ 是卵逃脱幼虫和成虫同类相食的概率，$\exp(-c_{\mathrm{pa}}A)$ 是蛹逃脱成虫同类相食的概率，$\mu_{\mathrm{l}}$ 和 $\mu_{\mathrm{a}}$ 是幼虫和成虫的死亡率。每个同类相食项都是 Ricker 型的过度补偿。该模型用极大似然拟合到实验室数据，其中含有种群统计噪声和环境噪声的随机项（Dennis 等 1995，1997），得到 $b = 6.598$，$c_{\mathrm{el}} = 0.01209$，$c_{\mathrm{ea}} = 0.01155$，$\mu_{\mathrm{l}} = 0.2055$。

决定性的一步是实验。每次普查时通过移走或添加成虫和蛹，可以操纵成虫死亡率和成虫对蛹的同类相食率。令 $\mu_{\mathrm{a}}$ 为 0.96，模型预测随着 $c_{\mathrm{pa}}$ 增加有一系列动态：$c_{\mathrm{pa}} = 0$ 时为稳定平衡，0.05 时为 8 周期，0.10 时为不变环上的拟周期运动，0.25、0.35 和 0.50 时为混沌（在 0.35 时最大 Lyapunov 指数约为 0.1），1.0 时为 3 周期。Costantino 等（1997）把这些值施加到重复的培养物上，历时约两年。观测到的动态遵循预测的序列，包括混沌吸引子，其特征形状出现在数据中，而且带有所估计噪声的模型定量地解释了观测到的波动。

### 12.6.3. 噪声、混沌与争论的现状

甲虫实验还揭示了是什么使自然界中混沌的检测变得复杂。真实的种群受到噪声的作用，噪声与确定性动态的相互作用，是两者单独都无法预测的。在乘子接近 $-1$ 的稳定平衡点附近，噪声激发持续的振荡；在吸引域边界附近，噪声使种群在共存的吸引子之间切换；而种群由整数个体组成，所以模型的连续状态被整数格点所代替，在格点上确定性的混沌变成长周期（Henson 等 2001）。在这样的条件下，有用的问题与其说是“这个种群是混沌的吗？”，不如说是“它的变异有多少是内部产生的，它对扰动有多敏感？”。拟合的随机模型的 Lyapunov 指数回答的是第二个问题。

人们提出了几种理由，说明为什么在模型中如此容易产生的混沌，在野外种群中似乎很少见。自然种群在空间上有结构，相位相错波动的局域种群之间的扩散使其总数稳定；年龄与阶段结构把密度制约分散到整个生活史；泛化的捕食者和寄生物增加稳定的密度制约；选择可能不利于混沌所要求的很高的繁殖率，或只有当它们受到争夺竞争的制约时才有利。另一方面，一些过度补偿很强的种群，如成体同类相食的鱼类、昆虫暴发，以及疫苗接种前城市中的麻疹之类的疾病，表现出与低维混沌一致或接近的动态。

持久的教训是 Begon 与 Townsend 所总结的：时滞、高繁殖率和过度补偿的密度制约，每一个都可以不借助任何外部原因而产生种群波动；确定性模型可以产生不可预测性；而对模型的分析正是生态学家发现这一点的途径。生态学的目标是成为一门预测性的科学，而内禀混沌动态的可能性，给预测设定了任何测量上的改进都无法克服的限制。

## 小结

- 世代不重叠的种群服从 $N_{t+1} = F(N_t)$（公式 12.1.1）。离散逻辑斯谛模型就是 $\mu = 1 + r$ 的 logistic 映射 $x_{t+1} = \mu x_t(1 - x_t)$（命题 12.1.1）；教材中的参数 $L$ 等于 $r$。
- 若 $\lvert F'(N^*)\rvert < 1$，不动点稳定（定理 12.1.1）；$F'$ 的符号决定是单调趋近还是振荡趋近。阈值（命题 12.1.2）：

| 模型 | 单调 | 阻尼振荡 | 周期开始 | 混沌开始 |
|---|---|---|---|---|
| 离散逻辑斯谛 | $r \leq 1$ | $1 < r < 2$ | $r = 2$ | $r_\infty = 2.5699$ |
| Ricker | $r \leq 1$ | $1 < r < 2$ | $r = 2$ | $r_\infty = 2.6924$ |
| Beverton–Holt | 所有 $\lambda$ | 从不 | 从不 | 从不 |
| Hassell | $b(1 - \lambda^{-1/b}) \leq 1$ | 至 2 | $b(1 - \lambda^{-1/b}) = 2$ | 高 $\lambda$ 与 $b$ |

- 蛛网图（定义 12.2.1）显示全局动态以及种群波动的界限。
- logistic 映射的 2 周期在 $\mu > 3$ 时存在，在 $3 < \mu < 1 + \sqrt6$ 时稳定，乘子为 $-\mu^2 + 2\mu + 4$（命题 12.3.1）；进一步的倍周期（定义 12.3.1）累积于 $\mu_\infty = 3.5699$，其后混沌与周期窗口交替出现（在 $1 + \sqrt8$ 处出现周期 3）。
- Lyapunov 指数 $\lambda = \lim\frac1n\sum\ln\lvert f'(x_k)\rvert$（定义 12.4.1）在稳定周期上为负，在倍周期处为零（命题 12.4.1），在混沌中为正；在 $\mu = 4$ 时等于 $\ln 2$（命题 12.4.2）。它确定预测视界。
- 级联是普适的：对每个光滑的单峰映射，$\delta = 4.6692$，$\alpha = -2.5029$（定义 12.5.1），二次重整化近似地说明了这一点（$\delta \approx 1 + \sqrt{17}$，命题 12.5.1），Feigenbaum–Cvitanović 方程 (12.6) 则精确地说明了。
- 多数用 Hassell 模型拟合的自然昆虫种群位于稳定区；*Tribolium* 的 LPA 实验在真实种群中证明了预测的分岔与混沌；在野外，噪声、空间与年龄结构以及与其他物种的相互作用使混沌难以检测，且可能不常见，但内禀动态确实给预测设定了限制。

## 思考题

1. 证明 Ricker 模型 $N_{t+1} = N_t\exp[r(1 - N_t/K)]$ 的最大补充发生在 $N = K/r$，并用它解释为什么振荡要求 $r > 1$。

   **答** $F'(N) = \mathrm{e}^{r(1 - N/K)}(1 - rN/K) = 0$ 在 $N = K/r$ 处。平衡点 $K$ 位于曲线下降的一支，在那里 $F' < 0$，趋近是振荡的，恰当 $K > K/r$ 时，即 $r > 1$；对 $r < 1$，驼峰位于 $K$ 之外，种群从两侧单调地趋近 $K$。对 $1 < r < 2$，$K$ 处下降的一支比 $-1$ 平缓（阻尼振荡）；对 $r > 2$，则更陡（持续振荡）。

2. 验证 Maynard Smith–Slatkin 模型的不动点的乘子为 $1 - b(1 - 1/\lambda)$，并求 $\lambda = 100$ 时 $b$ 的临界值。当 $\lambda \to \infty$ 时临界的 $b$ 趋于 2，这意味着什么？

   **答** 见命题 12.1.2。当 $b(1 - 1/\lambda) = 2$ 时平衡点失稳，即 $\lambda = 100$ 时 $b = 2/(1 - 1/\lambda) = 2.02$。当 $\lambda \to \infty$ 时，阈值趋于 2：无论繁殖率多高，除非密度制约强烈过度补偿（$k$ 对 $\log N$ 的斜率高于 2），平衡点都保持稳定。在 Maynard Smith–Slatkin 模型中，与 Hassell 模型不同，一旦 $b > 2$，即使中等的 $\lambda$ 也足以使之失稳；两个模型都认为欠补偿或恰好补偿的密度制约（$b \leq 1$）总是起稳定作用。

3. 一个一年生昆虫种群服从 $r = 2.5$ 的离散逻辑斯谛模型。描述它的动态。它的生境得到改善，使 $K$ 加倍而 $r$ 不变；有什么变化？然后引入一种寄生蜂，增加与密度无关的死亡率，使有效的 $r$ 降到 1.5；会发生什么？

   **答** 在 $r = 2.5$（$\mu = 3.5$，介于 $\mu_2 = 3.449$ 与 $\mu_3 = 3.544$ 之间）时，种群稳定在 4 周期上。$K$ 加倍只是重新标度了种群：周期的形状和周期长度不变，所有值加倍，因为动态只取决于 $r$（命题 12.1.1）。把有效增长率降到 $r = 1.5$ 使种群进入阻尼振荡区：它收敛到稳定平衡点（在综合模型新的、较低的 $K$ 处）。与密度无关的死亡率常被认为使系统失稳，但在这里它通过降低繁殖率而使动态稳定，这是过度补偿的一个违反直觉的后果。

4. 由 $\mu = 3.2$ 时 logistic 映射 2 周期的乘子计算 Lyapunov 指数，并解释为什么在 $\mu = 1 + \sqrt5$ 处该指数为 $-\infty$。

   **答** 在 $\mu = 3.2$ 时，2 周期的乘子为 $-\mu^2 + 2\mu + 4 = -10.24 + 6.4 + 4 = 0.16$，所以由命题 12.4.1，$\lambda = \frac12\ln 0.16 = -0.916$。在 $\mu = 1 + \sqrt5$ 处，乘子为 $-(6 + 2\sqrt5) + 2 + 2\sqrt5 + 4 = 0$：2 周期穿过临界点 $x = 1/2$（确实，此时 $p = 1/2$，因为乘积 $f'(p)f'(q)$ 只有当 $p$ 或 $q$ 为 $1/2$ 时才为零）。于是偏差以平方的方式而不是以常数倍减小，该周期是超稳定的，且 $\ln\lvert f'(1/2)\rvert = \ln 0 = -\infty$。

5. 用 Feigenbaum 常数，由 Ricker 模型最初两次倍周期分岔 $r_1 = 2$ 和 $r_2 = 2.526$ 预测其累积点，并与真实值 2.692 比较。为什么预测不好，如何改进？

   **答** 如果间隔从一开始就按因子 $\delta$ 缩小，$r_\infty = r_2 + (r_2 - r_1)/(\delta - 1) = 2.526 + 0.526/3.669 = 2.669$，低估了 0.023。比值 $\delta_n$ 只是渐近地收敛到 4.669，对 Ricker 映射，早期的比值远低于它（第一个对分岔点约为 4.0，对超稳定点约为 3.7，见 12.5 节图的面板 B）：最初的间隔比后面的缩小得更慢，所以外推停得太早。使用较后的分岔（$r_3 = 2.656$，$r_4$，…）可以迅速改进估计：由 $r_2$ 和 $r_3$，$2.656 + 0.130/3.669 = 2.692$。

6. （开放题）在 *Tribolium* 实验中，观测到的种群接近但并不恰好位于预测的吸引子上。讨论种群统计噪声、环境噪声和种群的整数性质如何影响确定性混沌模型与数据的比较，以及需要什么样的证据才能断言某个自然种群是混沌的。

   **答** 要点：确定性模型预测的是吸引子；真实的计数围绕它散布，原因有种群统计噪声（随机的出生与死亡，在小种群中很大）、环境噪声（温度、食物的变化）和测量误差。因此 Dennis 及其同事拟合模型的随机版本，比较预测的与观测的一步预测分布，而不是轨迹，因为混沌使轨迹在几步之后就不可预测。由于甲虫是整数，状态空间是格点：有限格点上的确定性混沌映射最终必须进入循环，所以“格点效应”产生连续模型所没有的重复模式，这些在数据中已经观察到（Henson 等 2001）。要断言某个自然种群是混沌的，需要长时间序列，一个在样本外预测良好的机理模型或非参数模型，一个置信区间明显高于零的 Lyapunov 指数估计，并且理想情况下还要对能使种群可预测地在不同动态区间之间转换的某个参数作实验操纵，如在 *Tribolium* 中那样。没有操纵，就很难排除其他的解释（对稳定但阻尼很弱的系统的随机强迫、与未观测物种的相互作用）。
