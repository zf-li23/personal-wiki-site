## 13.1. 密度制约中的时滞

### 13.1.1. 时滞从何而来

**密度制约**（[7.19.11](/7.19.11)）通过资源、天敌或行为起作用，而这些途径的反应都需要时间。常见的时滞来源有三种：

- 发育时间：时刻 $t$ 补充进入成体阶段的个体，反映的是幼体所经历的条件，而幼体出生于 $t - \tau$，那时的成体密度决定了它们的处境。
- 资源恢复：被啃食的植被、被耗尽的猎物或养分需要时间恢复，因此现在可得的食物取决于过去的消费者密度。
- 天敌的反应：专食性捕食者和拟寄生物只在猎物增加之后才增加，而且在猎物减少之后其影响仍会持续。

**定义 13.1.1（时滞密度制约）** **时滞密度制约**是指：时刻 $t$ 的每员出生率、死亡率或增长率取决于较早时刻 $t - T$ 的种群密度（或过去某一时间段内的密度），而不仅仅取决于当前密度。作用于当前密度的密度制约称为**直接密度制约**。

时滞有一个特征性的表现：种群会越过平衡点而超调，因为刹车踩得太晚；随后又低于平衡点，因为刹车松得太晚。这些振荡是衰减还是持续，取决于时滞相对于反应速度有多长，下面的模型把这一点说得很精确。

### 13.1.2. 时滞逻辑斯谛方程

**定义 13.1.2（时滞逻辑斯谛方程）** **时滞逻辑斯谛方程**（Hutchinson 1948）为

$$
\frac{\mathrm{d}N}{\mathrm{d}t} = rN(t)\left(1 - \frac{N(t - T)}{K}\right),
\tag{13.1}
$$
其中 $r > 0$ 为**内禀增长率**，$K > 0$ 为**环境容纳量**，$T > 0$ 为密度压低每员增长率时的时滞。求解需要在 $[-T, 0]$ 上给定初始函数 $N(t) = \phi(t) > 0$，而不只是一个初值：式 (13.1) 是时滞微分方程，其在时刻 $t$ 的状态是整段历史 $\{N(s) : t - T \le s \le t\}$。

两次尺度变换可以消去两个参数。令 $u = N/K$，并以 $1/r$ 为时间单位（即 $s = rt$），则式 (13.1) 化为 $\mathrm{d}u/\mathrm{d}s = u(s)\bigl(1 - u(s - a)\bigr)$，只剩一个无量纲参数 $a = rT$：以自然反应时间 $1/r$ 为单位度量的时滞。因此全部定性行为都只可能取决于 $rT$。

正性得以保持，因为 $\mathrm{d}\ln N/\mathrm{d}t = r(1 - N(t - T)/K)$ 在有界区间上有界；而 $N^* = K$ 是唯一的正平衡点。为研究它的稳定性，令 $N(t) = K\bigl(1 + x(t)\bigr)$，则 $\dot x = -r\bigl(1 + x(t)\bigr)x(t - T)$，略去二次项即得线性化方程

$$
\dot x(t) = -r\,x(t - T).
\tag{13.2}
$$
取 $x = \mathrm{e}^{\lambda t}$ 得特征方程 $\lambda = -r\mathrm{e}^{-\lambda T}$，或者令 $z = \lambda T$、$a = rT$，

$$
z\,\mathrm{e}^{z} = -a .
\tag{13.3}
$$
与常微分方程的特征多项式（[2.4.11](/2.4.11#sec-11.2)）不同，式 (13.3) 是超越方程，有无穷多个根；其解为 $z = W_k(-a)$，即 Lambert $W$ 函数的各分支。与常微分方程一样，若所有根的实部为负，则平衡点渐近稳定；若有一个根的实部为正，则不稳定（在同样的光滑性条件下，线性化稳定性原理对时滞方程也成立）。

**定理 13.1.1（时滞逻辑斯谛方程的稳定性）** 设 $a = rT > 0$，则：

1. 若 $0 < a \le 1/\mathrm{e}$，式 (13.3) 的主根为负实数：对 $N^* = K$ 的扰动（瞬变之后）无振荡地衰减。
2. 若 $1/\mathrm{e} < a < \pi/2$，式 (13.3) 没有实根，所有根的实部为负，主根为一对复根：扰动以减幅振荡的方式衰减。
3. 在 $a = \pi/2$ 处，一对根 $z = \pm\mathrm{i}\pi/2$ 横截地从左向右穿过虚轴；当 $a > \pi/2$ 时平衡点不稳定。阈值处的振荡角频率为 $\omega = \pi/(2T)$，即周期为 $4T$。

**证明** 记 $g(z) = z\mathrm{e}^z$。

*实根。* 对实数 $z$，$g'(z) = (1 + z)\mathrm{e}^z$，所以 $g$ 在 $(-\infty, -1]$ 上从 $0$ 下降到 $g(-1) = -1/\mathrm{e}$，在 $[-1, \infty)$ 上上升。因此，若 $a < 1/\mathrm{e}$，$g(z) = -a$ 有两个负实根 $z_2 < -1 < z_1 < 0$；若 $a = 1/\mathrm{e}$，有二重根 $z = -1$；若 $a > 1/\mathrm{e}$，没有实根。

*穿越虚轴。* 根 $z = \mathrm{i}y$（$y > 0$，共轭的情形对称）满足 $\mathrm{i}y(\cos y + \mathrm{i}\sin y) = -a$，即 $y\cos y = 0$ 且 $y\sin y = a$。于是 $y = \pi/2 + k\pi$ 且 $\sin y > 0$，得 $y = \pi/2, 5\pi/2, \dots$，相应地 $a = \pi/2, 5\pi/2, \dots$。根连续地依赖于 $a$；当 $a \to 0^+$ 时，每个根或者沿 $z \approx -a$ 趋于 $0$（实根 $z_1$），或者实部趋于 $-\infty$（因为当 $\lvert z\rvert$ 远离 $0$ 时，$\lvert z\rvert\mathrm{e}^{\operatorname{Re}z} = a$ 迫使 $\mathrm{e}^{\operatorname{Re}z} \to 0$）。所以当 $a$ 很小时所有根都在左半平面，并且直到 $a = \pi/2$ 都留在其中。这证明了 1 与 2 中关于稳定性的论断。

*横截性。* 对 $z\mathrm{e}^z = -a$ 求微分，得 $(1 + z)\mathrm{e}^z\,\mathrm{d}z = -\mathrm{d}a$；利用 $\mathrm{e}^{z} = -a/z$，

$$
\frac{\mathrm{d}z}{\mathrm{d}a} = \frac{z}{a(1 + z)} .
$$
在 $z = \mathrm{i}\pi/2$ 处，$z/(1 + z) = (\pi^2/4 + \mathrm{i}\pi/2)/(1 + \pi^2/4)$ 的实部为正，所以当 $a$ 增大并越过 $\pi/2$ 时这对根进入右半平面；这就证明了 3。

*$a < 1/\mathrm{e}$ 时哪个根起主导作用。* 复根 $z = u + \mathrm{i}v$（$v > 0$）由 $z\mathrm{e}^z = -a$ 的虚部与实部给出 $u = -v\cot v$ 与 $a = \mathrm{e}^{u}v/\sin v$，所以 $\sin v > 0$，$v \in (2k\pi, (2k + 1)\pi)$。对 $k \ge 1$，$a \ge \mathrm{e}^{u}v > 2\pi\mathrm{e}^{u}$，故 $u < \ln(a/2\pi) < -1 < z_1$。对 $k = 0$，$a = \varphi(v) = v\,\mathrm{e}^{-v\cot v}/\sin v$，且

$$
\frac{\mathrm{d}\ln\varphi}{\mathrm{d}v} = \frac1v + \frac{v}{\sin^2v} - 2\cot v \ge \frac{2}{\sin v} - 2\cot v > 0
$$
（由**算术–几何平均不等式**），所以 $\varphi$ 从 $v \to 0^+$ 时的极限 $1/\mathrm{e}$ 开始递增：当 $a \le 1/\mathrm{e}$ 时，这一分支上没有根。因此对 $a < 1/\mathrm{e}$，每个复根的实部都小于 $-1$，实根 $z_1 \in (-1, 0)$ 起主导作用。$\square$

这一定理说明了为什么振荡要求时滞相对于反应时间 $1/r$ 足够长。图 1 展示了四种情形：$rT = 0.3$ 时平滑地趋近逻辑斯谛平衡；$rT = 1$ 与 $1.5$ 时超调并减幅振荡；$rT = 2$ 时出现稳定极限环。图 2 则沿着分岔追踪根和长期行为。

![时滞逻辑斯谛方程 (13.1) 在初始区间上取 N(t) = 0.1K、四个 rT 值时的解。A：单调趋近 K（rT < 1/e）。B、C：减幅振荡，随 rT 趋近 π/2 衰减变慢。D：稳定极限环（rT = 2 > π/2），谷值很深，周期约为 4.4T](./plots/delayed-logistic.py)

越过阈值之后，方程有一个由超临界 Hopf 分岔产生的稳定极限环（一般理论见 [2.4.11](/2.4.11#sec-11.6.4)；对时滞方程，此结果归功于 Wright 1955 及后续工作）。其振幅随 $rT$ 迅速增大：$rT = 2.2$ 时最小值降到约 $0.01K$，使真实种群在谷值处有灭绝的风险（见 [7.19.15](/7.19.15) 一章）；周期在阈值处为 $4T$，并随 $rT$ 增大而变长（图 2C）。由此得到两个生物学结论。第一，稳定性的丧失并非由长时滞本身造成，而是由长时滞与快速反应的组合造成：把 $r$ 减半（繁殖较慢）与把 $T$ 减半同样具有稳定作用。第二，由时滞驱动的周期大约是四倍时滞。把这一点用于 Nicholson 的绿蝇（13.1.4 节），其周期约 38 天，意味着时滞约 9 天，而其周期的大振幅要求 $rT$ 远大于 $\pi/2$（May 1973）。

### 13.1.3. 离散时间中的时滞

世代离散的种群同样可以对密度作出延迟反应，例如某一繁殖季节可得的食物取决于上一季节的啃食。Begon 的例子是牧场上的牛群，其春季的生长由去年的啃食状况决定。

**命题 13.1.2（时滞离散逻辑斯谛模型）** 设 $N_{t+1} = N_t\bigl[1 + r(1 - N_{t-1}/K)\bigr]$，$r > 0$。平衡点 $N^* = K$ 在 $0 < r < 1/4$ 时被单调趋近，在 $1/4 < r < 1$ 时经减幅振荡趋近，在 $r > 1$ 时不稳定，此时种群持续振荡。

**证明** 令 $N_t = K(1 + x_t)$；到一阶有 $x_{t+1} = x_t - rx_{t-1}$，其特征方程为 $z^2 - z + r = 0$。当 $r < 1/4$ 时，根 $\tfrac12(1 \pm \sqrt{1 - 4r})$ 为实数，且在 $(0, 1)$ 内。当 $r > 1/4$ 时，它们是共轭复数，$\lvert z\rvert^2 = z\bar z = r$，所以恰在 $r < 1$ 时位于单位圆内。$\square$

在 $r = 1$ 处，复根对以辐角 $\theta = \arccos(1/2) = \pi/3$ 离开单位圆，因此出现的振荡（经由 Neimark–Sacker 分岔，即 Hopf 分岔的离散类比）周期约为 $2\pi/\theta = 6$ 个世代，并且是准周期的而非周期的：种群沿着 $(N_{t-1}, N_t)$ 平面内的不变闭曲线运动。对时滞 Beverton–Holt 模型 $N_{t+1} = RN_t/(1 + aN_{t-1})$（$a = (R - 1)/K$）作同样的推理，得 $x_{t+1} = x_t - c\,x_{t-1}$，其中 $c = (R - 1)/R$。由于对每个 $R > 1$ 都有 $0 < c < 1$，该模型可以出现减幅振荡（当 $R > 4/3$ 时），却从不失去稳定性。没有时滞时，Beverton–Holt 模型对每个 $R$ 都单调趋于平衡（[7.19.12](/7.19.12)）；振荡完全是时滞造成的。一些教材中给出的这类模型的阈值（$0.25$ 与 $1$），是时滞项系数的取值。

![时滞离散逻辑斯谛模型。A：r = 0.2（单调）、0.6（减幅振荡）与 1.05（持续的准周期振荡，周期接近 6 个世代）的轨迹。B：z^2 - z + r = 0 的主根的模：r < 1/4 时为实根，之上为模 √r 的复根对，在 r = 1 处离开单位圆。时滞 Beverton–Holt 模型的特征方程与之相同，其中 c = (R - 1)/R 总是落在阴影区间内，因此它可以振荡，但总是稳定的](./plots/discrete-delay.py)

### 13.1.4. Nicholson 的绿蝇

由时滞驱动的周期的经典实验室演示，是 A. J. Nicholson（1954，1957）对铜绿蝇 *Lucilia cuprina* 的研究。当成虫每天只得到有限的蛋白质配给（产卵所需），而幼虫食物充足时，成虫种群以约 35–40 天的周期循环，几乎崩溃到零，然后回升到数千只。高密度下拥挤的成虫产卵很少；成虫随后死去，两周后新羽化的成虫很少，幸存者有充足的蛋白质，产下大量的卵，如此往复。时滞就是从卵到成虫的发育时间，在培养温度下约 15 天。

Hutchinson 方程再现了这些周期的长度，却无法再现其形状。Gurney、Blythe 与 Nisbet（1980）提出了一个把补充与死亡分开的模型：

$$
\frac{\mathrm{d}A}{\mathrm{d}t} = P\,A(t - \tau)\,\mathrm{e}^{-A(t - \tau)/A_0} - \delta A(t),
\tag{13.4}
$$
其中 $A$ 为成虫数，$\tau$ 为发育时间，$P$ 为每员最大产卵率（乘以到成体的存活率），$A_0$ 为补充最大时的成虫密度，$\delta$ 为成虫死亡率。补充项是一个时滞的 Ricker 函数（[7.19.12](/7.19.12)）：它呈单峰形，因此补充是过度补偿的，成虫的拥挤会使一个发育时间之后的补充减少。正平衡点为 $A^* = A_0\ln(P/\delta)$，在 $P > \delta$ 时存在。如前线性化，令 $A = A^*(1 + x)$，

$$
\dot x(t) = -\delta x(t) + \delta\bigl(1 - \ln(P/\delta)\bigr)x(t - \tau),
$$
其特征方程 $\lambda + \delta = \delta(1 - \ln(P/\delta))\mathrm{e}^{-\lambda\tau}$ 表明稳定性取决于两个无量纲组合：$P/\delta$（补充的过度补偿有多强）与 $\delta\tau$（一个时滞内容得下多少个成虫寿命）。取 Nicholson 培养物中估计值的量级（$\tau \approx 15$ d，$P \approx 8\,\mathrm{d}^{-1}$，$\delta \approx 0.18\,\mathrm{d}^{-1}$），平衡点不稳定，模型稳定在周期约 $2.7\tau \approx 40$ 天的循环上，与观测周期接近（图 4）。深谷来自过度补偿，而不是单靠时滞：$\tau$ 天前成虫数量多，意味着现在补充少。

![Nicholson 绿蝇的 Gurney–Blythe–Nisbet 模型 (13.4)，τ = 15 d，P = 8 每天，δ = 0.175 每天，A0 = 600。A：成虫种群稳定在周期约 40 天（2.7 个发育时间）的循环上，上升支有一个肩部，谷很长。B：延迟坐标中的循环，现在的成虫数对 τ 天前的成虫数](./plots/blowfly-model.py)

## 13.2. 种群调节

### 13.2.1. 调节、限制与决定

没有哪个自然种群会无限增长，也很少有种群稳步下降直至灭绝；多数种群在一定范围内波动。这些界限究竟反映了种群内部的稳定力量，还是仅仅反映环境不规则的作用，是二十世纪中叶种群生态学的核心争论。Nicholson（1933，1954）研究绿蝇与拟寄生物，主张密度制约的生物相互作用（竞争、捕食、寄生）使种群与环境保持平衡，而天气之类非密度制约的因子可以强烈影响密度，却不能单独把密度维持在界限之内。Andrewartha 与 Birch（1954）研究澳大利亚的害虫，则把种群看作不断经历挫折与恢复：例如南澳大利亚玫瑰上的蓟马每年春季增加，夏季在尚未达到食物供应上限之前就被干旱削减，天气的时机与严重程度解释了其数量变化的大部分。他们还反对把环境划分为密度制约和非密度制约的“因子”。

把两个问题分开之后，许多争论就消解了。

**定义 13.2.1（种群调节）** **种群调节**是指种群高于某一水平时趋于减少、低于该水平时趋于增加的倾向；它只能来自作用于出生、死亡或迁移的密度制约过程。**种群限制**指决定种群围绕其波动的水平（平衡密度或平均密度）的那些过程；该水平以及任一时刻的实际数量，则是由影响种群的所有过程（无论是否密度制约）*共同决定*的。

图 6A 展示了这一区分。出生率随密度下降，因此在每个地点都调节着种群；死亡率与密度无关，但由于物理条件的不同，三个地点的死亡率各不相同。每个地点都有一个稳定平衡点，但平衡密度因非密度制约因子而各异。Nicholson 学派关心的是调节，Andrewartha 与 Birch 关心的是决定，两者都有道理。调节不必始终起作用：密度制约可能只是间歇地运作（密度高的年份食物不足时），它也可能把种群拉向一个本身在移动的目标，例如随季节变化。很可能没有哪个自然种群曾处于平衡。

### 13.2.2. 外源性学说

经典学说常按强调种群外部因素还是内部因素来分组。

- 气候学派（Bodenheimer 1928，Uvarov 1931，Andrewartha 与 Birch 1954）多为昆虫学家，认为种群大小主要受限于天气有利于增长的短暂时期：昆虫种群很少有足够时间达到资源的上限，因此食物竞争很少发生。
- 生物学派（Howard 与 Fiske 1911，Nicholson 1933，Smith 1935，后者创造了“密度制约因子”一词）认为，随密度加剧的捕食、寄生、竞争与疾病决定平衡水平。一个变体，即营养恢复假说，把决定性的时滞放在重度啃食后食物质量的恢复上。
- 折中学派（Milne 1957 等）认为，种群处于中等密度时非密度制约因子占主导，种内竞争这一密度制约只在密度极高的极端情形才起作用（在有些版本中，不利生境中非密度制约因子占主导，有利生境中生物因子占主导）。

### 13.2.3. 自我调节学说

内源性学说认为，由密度触发的个体自身变化调节着种群数量。

- 行为调节（Wynne-Edwards 1962）。社群等级与领域性传递着有关种群大小相对于资源的信息。密度上升时，有利的地点都被占有**领域**者占据，从属个体被挤到劣质生境，在那里存活率与繁殖成功率低，或者迁出。这一论证的种群统计部分有充分的支持：领域性可以产生很强的密度制约，因为繁殖者的数量受领域数量所限（[7.18.26](/7.18.26)）。Wynne-Edwards 的进一步主张，即动物为了群体利益而克制繁殖，需要群体选择，已被 Williams（1966）与 Maynard Smith（1964）否定：最大限度繁殖的“作弊”个体会扩散开来。
- 内分泌调节（Christian 1950 年代）。在拥挤的哺乳动物中，社会压力使促肾上腺皮质激素与糖皮质激素的分泌增加，使促性腺激素与生长激素减少，从而降低繁殖力和抗病能力。它被用来解释小型哺乳动物的周期。在峰期和下降期的种群中，应激激素确实升高并抑制生殖力，但在美洲兔中，应激主要由被捕食的风险而非拥挤引起（13.4.4 节）。
- 遗传调节（Chitty 1960，1967）。两类基因型在行为与繁殖上不同：好斗而繁殖力较低的类型在高密度下表现好，温顺而繁殖力高的类型在低密度下表现好。种群增长期选择有利于高繁殖力型，峰期有利于好斗型，这降低了补充，从而造成下降；种群不仅在数量上变化，在质量上也变化，并有一个世代的滞后。“Chitty 效应”，即田鼠周期的增长期与峰期个体较大，确有其事，但尚未发现这类一致的可遗传多态性。

现在，这些内源性机制被视为解释密度制约如何起作用的一部分，而不是外源性因素之外的替代方案：看似内源的现象，如应激，往往由捕食者等外源性原因诱导。

### 13.2.4. 密度制约在何处起作用

对大量生命表的比较（Sinclair 1989）表明，发生密度制约死亡或繁殖力下降的阶段及其主要原因，在不同类群之间有可预见的差异：

| 类群 | 起密度制约作用的阶段 | 主要原因 |
|---|---|---|
| 昆虫 | 幼虫早期；成虫的繁殖力 | 食物竞争、捕食与寄生（社会性昆虫还有社会相互作用） |
| 鱼类 | 幼体早期（仔鱼与稚鱼阶段） | 食物与捕食 |
| 鸟类 | 离巢后的晚期幼鸟；补充进入繁殖种群 | 食物、领域竞争 |
| 小型哺乳动物 | 晚期幼体，即离开母体独立时 | 空间与社会行为（扩散、领域性） |
| 大型哺乳动物 | 早期幼体；雌性的繁殖力 | 食物 |

**关键因子分析**（[7.19.9](/7.19.9)）是在一系列生命表中定位这些阶段的经典方法，而 λ 贡献分析则按增长率的敏感度为各阶段加权（[7.19.14](/7.19.14)）。

### 13.2.5. 多个平衡点

种群可以被不同的过程调节在不同的水平上。经典例子是加拿大东部北方森林中的云杉卷叶蛾 *Choristoneura fumiferana*，它们数十年保持低密度，然后暴发，使整片森林落叶。Ludwig、Jones 与 Holling（1978）把云杉卷叶蛾密度 $B$ 建模为

$$
\frac{\mathrm{d}B}{\mathrm{d}t} = r_BB\left(1 - \frac{B}{K_B}\right) - \beta\frac{B^2}{\alpha^2 + B^2},
$$
即叶量上的逻辑斯谛增长，减去鸟类的捕食，后者具有饱和的 S 形（III 型）**功能反应**（[7.19.25](/7.19.25)）。令 $u = B/\alpha$，$\tau = \beta t/\alpha$，$r = r_B\alpha/\beta$，$q = K_B/\alpha$，则平衡点 $u > 0$ 满足 $r(1 - u/q) = u/(1 + u^2)$：一条直线（每员增长）与一条单峰曲线（每员捕食）相交。当 $q$ 小（幼龄森林）时，只有一个由捕食者维持的低平衡点；当 $q$ 大（叶量丰富的成熟森林）时，只有一个由食物维持的暴发平衡点；$q$ 居中时有三个平衡点，两个稳定，中间一个不稳定（图 6B）。随着森林成熟、$q$ 增大，地方性平衡点在鞍结分岔中消失，种群跳到暴发状态；只有叶量被摧毁之后才会回落。塞伦盖蒂也有类似的格局：迁徙的角马（约 130 万头）受食物调节，而同一物种的常驻种群则被捕食者压在低得多的密度上（Fryxell、Greever 与 Sinclair 1988）：迁徙使迁徙者逃脱了捕食者的调节。替代稳态及其后果在 [7.19.39](/7.19.39) 中讨论。

## 13.3. 自然种群的波动型式

长期的计数显示出一系列型式，可分类如下；同一种群在不同地点或不同时期可以表现出不同型式。

- 季节性波动：一年有若干世代或季节性繁殖的物种，其数量随季节而变化，由季节条件和自身生活周期驱动。温带湖泊中的浮游植物在春季达到高峰，那时光照增强而冬季混合上来的养分尚存，秋季常有第二个高峰；许多昆虫，如华北的棉盲蝽，每年有一到两个高峰，其时间取决于降雨。
- 不规则波动：许多害虫，如松毛虫（*Dendrolimus*）和东亚飞蝗（*Locusta migratoria manilensis*），年际变化不规则，主要响应天气：华东河谷的蝗灾历史上多接续于干旱，干旱使湖底河床裸露而成为产卵地。
- 周期性波动：少数种群以规则的周期波动：北极与北方森林带的旅鼠和田鼠周期为 3–5 年，北美北方森林中的美洲兔及其捕食者约 10 年，英国的红松鸡 4–8 年，阿尔卑斯山的落叶松线小卷蛾（larch budmoth）8–9 年。哈得孙湾公司的毛皮收购记录显示了十九世纪初以来的野兔与猞猁周期；没有猞猁的地方野兔也呈周期波动，所以猞猁不可能是唯一原因。
- 种群暴发：繁殖率高、动态不规则或呈周期性的物种，在条件有利或天敌稀少时偶尔暴发到极高的密度：蝗虫、啮齿动物、食叶昆虫和藻华（赤潮）。入侵物种常在一段滞后之后暴发，如 1959 年卡里巴大坝合拢之后，人厌槐叶蘋 *Salvinia molesta* 在卡里巴湖的暴发（入侵在 [7.19.51](/7.19.51) 中讨论）。
- 相对稳定：有些种群长期保持在几乎相同的水平：许多大型有蹄类和食肉类、一些蜻蜓和有强烈内部调节的社会性昆虫。稳定反映了强烈的直接密度制约、长寿命，以及贮存的储备或年龄结构的缓冲作用。
- 衰退与灭绝：条件恶化或人类影响加剧时种群衰退；曾经存在过的物种中，超过 99 % 已经灭绝。使小种群脆弱的随机过程是 [7.19.15](/7.19.15) 的主题。

一个种群表现出哪种型式，取决于直接与时滞密度制约的平衡、非密度制约变动的强度和种群反应的速度，13.1 节与 13.4 节将对此作出精确的说明。

## 13.4. 在时间序列中检测密度制约

### 13.4.1. 自回归模型

长期的计数序列是最易获得的数量数据，大量工作试图由此推断密度制约的结构（Royama 1992，Turchin 2003）。令 $X_t = \ln N_t$，$r_t = X_t - X_{t-1}$，即对数尺度上实现的每员增长率。

**定义 13.4.1（种群动态的自回归模型）** 在 $d$ 阶线性自回归模型中，增长率线性地依赖于过去的对数数量：

$$
r_t = \beta_0 + \beta_1X_{t-1} + \beta_2X_{t-2} + \cdots + \beta_dX_{t-d} + u_t,
\tag{13.5}
$$
其中 $u_t$ 是均值为 0、方差为 $\sigma^2$ 的独立的非密度制约扰动。系数 $\beta_1$ 度量直接密度制约，$\beta_2, \dots, \beta_d$ 度量滞后 $2, \dots, d$ 的时滞密度制约；调节表现为 $\beta$ 为负，而 $\beta_0$ 决定平均水平而不影响动态。等价地，$X_t = \beta_0 + (1 + \beta_1)X_{t-1} + \beta_2X_{t-2} + \cdots + \beta_dX_{t-d} + u_t$，即 $X_t$ 的自回归过程。滞后数 $d$ 称为动态的*阶*（或维数）。

$d = 1$ 时这是随机 Gompertz 模型：$X_t - X^* = (1 + \beta_1)(X_{t-1} - X^*) + u_t$，当 $-2 < \beta_1 < 0$ 时受到调节（平稳），$\beta_1 < -1$ 时交替地超调并趋近平衡。2 阶是能产生周期的最简单的模型，对许多周期性种群拟合良好。

**命题 13.4.1（Royama 图）** 2 阶模型 $X_t = \beta_0 + (1 + \beta_1)X_{t-1} + \beta_2X_{t-2} + u_t$ 平稳（受调节）当且仅当

$$
\beta_2 > -1, \qquad \beta_1 + \beta_2 < 0, \qquad \beta_2 - \beta_1 < 2 ,
$$
即 $(\beta_1, \beta_2)$ 平面中的一个三角形。在其中，当 $\beta_2 < -\tfrac14(1 + \beta_1)^2$ 时动态是周期性的（自相关函数振荡），周期为

$$
T_{\mathrm{c}} = \frac{2\pi}{\theta}, \qquad \cos\theta = \frac{1 + \beta_1}{2\sqrt{-\beta_2}} .
$$

**证明** 确定性部分的特征方程为 $z^2 - a_1z - a_2 = 0$，其中 $a_1 = 1 + \beta_1$，$a_2 = \beta_2$，过程平稳当且仅当两个根都在单位圆内。若根 $z_1, z_2$ 为复数，$\lvert z_1\rvert^2 = z_1z_2 = -a_2$，所以条件是 $a_2 > -1$。若它们为实数，则两者都在 $(-1, 1)$ 内当且仅当 $p(z) = z^2 - a_1z - a_2$ 在 $z = \pm1$ 处为正，且两根之积 $-a_2$ 小于 1：$p(1) = 1 - a_1 - a_2 > 0$，$p(-1) = 1 + a_1 - a_2 > 0$，$a_2 > -1$。在复根情形下，当 $a_2 > -1$ 时这三个不等式同样成立（此时 $p$ 在整个实轴上为正），所以它们刻画了平稳性；用 $\beta$ 表示即为所述。当判别式 $a_1^2 + 4a_2 < 0$ 时根为复数；此时 $z_{1,2} = \sqrt{-a_2}\,\mathrm{e}^{\pm\mathrm{i}\theta}$，且 $2\sqrt{-a_2}\cos\theta = z_1 + z_2 = a_1$，自相关函数是一条衰减的余弦曲线，每个时间步的角频率为 $\theta$。$\square$

该图（图 7A）传达了一个简单的生物学信息。没有时滞密度制约（$\beta_2 \ge 0$）的种群不会出现周期。$\beta_2$ 为负产生周期，而随着时滞密度制约增强（$\beta_2$ 更负），尤其是随着直接密度制约减弱（$\beta_1$ 更接近 0），周期变长。$\beta_1 = -1$（强直接密度制约）时周期为 4 步；$\beta_1 = -0.2$、$\beta_2 = -0.6$ 时约为 6。

### 13.4.2. 相关函数与动态的阶

序列的分析通常分三步进行。

1. *自相关函数*（ACF）是 $X_t$ 与 $X_{t-k}$ 的相关随滞后 $k$ 的变化，它揭示周期性：滞后 $k$ 处的峰与接近 $k/2$ 处的谷表明周期为 $k$ 的循环。对瑞士 Engadine 山谷的落叶松线小卷蛾 *Zeiraphera diniana*，自相关函数在滞后 9 处出现峰值，即“九年周期”。
2. *偏自相关函数*（PACF）是去除中间各滞后的线性效应之后 $X_t$ 与 $X_{t-k}$ 的相关，它指示阶数：对 $d$ 阶自回归过程，PACF 在滞后 $d$ 之后为零。对这种落叶松线小卷蛾，它在滞后 2 处很大且为负，其后可以忽略。
3. *偏速率相关函数*（PRCF，Berryman 与 Turchin 2001）把增长率 $r_t$ 而不是 $X_t$ 与 $X_{t-k}$ 作相关。在滞后 1 处，几乎任何序列的 $X_t$ 的 PACF 都为正，仅仅因为相邻的值相似；而滞后 1 处的 PRCF 估计的是直接密度制约（$\beta_1$），这才是感兴趣的量。对这种落叶松线小卷蛾，它同时显示出直接与时滞的密度制约。

把这一分析用于来自芬诺斯堪迪亚的 19 个田鼠与旅鼠序列，几乎在每一种情形下都选出 2 阶（Bjørnstad、Falck 与 Stenseth 1995）。时滞密度制约（$\beta_2$）到处都很强，且不随纬度变化，但直接密度制约（$\beta_1$）向北减弱；由命题 13.4.1，这预测周期从芬兰南部的约 3 年变长到芬诺斯堪迪亚北部的约 5 年，与观测一致。对野兔–猞猁系统，Stenseth 等（1997）发现野兔序列的最佳模型有三个滞后（野兔、其食物和其捕食者），猞猁序列有两个（猞猁与野兔），与北方森林食物网的结构一致。因此滞后的个数提示了驱动种群的相互作用成分的个数，不过统计结构本身并不能确定生物学机制。

这一方法自然地推广到协变量。对奇瓦瓦沙漠的两种更格卢鼠，Lima 等（2008）拟合了含直接密度制约、夏季与冬季降雨以及竞争者数量的模型，用 1992 年之前的数据估计，再用其后的年份检验；同时含夏季降雨与种间竞争的模型预测最好。把密度制约与天气合并到一个回归中，使得密度制约因子与非密度制约因子这一旧的二分法变得明确而可检验。

### 13.4.3. 统计陷阱

把 $r_t$ 对 $X_{t-1}$ 回归并检验斜率是否为负，是检验密度制约最简单的方法，但它很容易出错。

- 零假设下的偏差：即使对随机游走（$\beta_1 = 0$，无调节），由短序列估计的最小二乘斜率也向下偏，因为当水平由同一批数据估计时，$X_{t-1}$ 与随后的增长率并不独立；所以普通的 $t$ 检验过于频繁地拒绝零假设。针对这种情形设计的检验使用随机游走下斜率的分布：Bulmer（1975）、Pollard、Lakhani 与 Rothery（1987）的随机化检验，以及 Dennis 与 Taper（1994）的参数自助法似然比检验。这一问题与计量经济学中的单位根检验相同。
- 抽样误差：数量是估计出来的，而不是精确计数。若 $Y_t = X_t + \varepsilon_t$，误差独立，则对 $X_t$ 的高估既造成预测变量偏高，又造成随后的增长率偏低，因此即使完全没有密度制约，观测到的斜率也为负（图 8）。把过程噪声与观测误差分开的状态空间模型是补救之道（Freckleton 等 2006）。
- 序列短而功效低：多数序列只有几十年；真实但较弱的密度制约，或只在高密度下起作用的密度制约，很容易被漏掉，动态的阶也常被低估。
- 相关不等于机制：负斜率说明增长率随密度下降，却不说明原因。时滞密度制约可能来自捕食者、食物或母体效应，同一统计结构与多种机制相容。要确定原因，需要野外实验（添加食物、移除捕食者）。
- 移动的目标：如果环境容纳量随时间变化（生境的趋势、季节性强迫），只对密度作回归会把调节与环境变化混为一谈。

### 13.4.4. 种群周期

规则的周期自 Elton（1924）以来一直吸引着生态学家，部分原因是周期性种群覆盖很宽的密度范围，因而对检测密度制约效应有很好的功效。上述分析一致认为，周期需要直接与时滞密度制约的结合；至于由什么提供时滞，各系统不同，仍有争论。

- 英国的红松鸡（*Lagopus lagopus scoticus*）。一种假说强调寄生线虫毛圆线虫 *Trichostrongylus tenuis*，它降低繁殖成功率；用驱虫药处理松鸡减弱了崩溃的幅度（Hudson、Dobson 与 Newborn 1998），但并非到处都消除了周期。另一种假说强调领域行为：在实验中，睾酮植入增强了已定居雄鸟的攻击性，使当年和次年年轻雄鸟的补充减少，这是一种时滞的密度制约效应（Mougeot 等 2003），可能是由密度上升时有亲缘关系的雄鸟群体的瓦解所介导。寄生物与攻击性相互作用，两者很可能都有贡献。
- 北方森林中的美洲兔（*Lepus americanus*）。多数野兔死于捕食，育空 Kluane 湖的野外实验表明，排除哺乳类捕食者对野兔存活的影响大于添加食物，两者结合时影响最大。即使捕食者已减少而食物充足，繁殖力在峰期之后仍有两年或更久保持低水平。时滞由应激提供：暴露于捕食者使怀孕雌兔的糖皮质激素水平升高，减少窝仔数，这一效应传给其女儿，成为延长低谷期的母体效应（Sheriff、Krebs 与 Boonstra 2009）。猞猁以约一年的滞后跟随野兔。
- 田鼠与旅鼠：在芬诺斯堪迪亚，专食性捕食者假说（Hanski、Turchin 等）认为，在雪下繁殖并对田鼠密度作出延迟反应的鼬类提供了时滞密度制约，而南方更多的广食性捕食者（狐、猛禽）增加直接密度制约，使周期减幅。用野外数据确定参数之后，该模型再现了周期与振幅随纬度增大而增大，以及南方没有周期的现象。在别处它则失效：英格兰北部 Kielder 森林的田野田鼠尽管广食性捕食本应阻止周期，却仍有周期，把鼬类减少约 60 % 也没有使周期停止（Graham 与 Lambin 2002）。对旅鼠，缓慢再生的苔藓被过度啃食可能提供时滞；对食草的田鼠，则有人提出草中硅防御的诱导。

一般的教训是，使种群循环的过程不一定就是决定循环振幅的过程；内源性变化（应激、行为、体型）通常解释种群*如何*反应，而外源性因素（捕食者、食物）解释*为什么*。周期的捕食者–猎物模型在 [7.19.25](/7.19.25) 与 [7.19.26](/7.19.26) 展开，寄主–拟寄生物模型在 [7.19.27](/7.19.27) 展开。

## 小结

- 密度制约常常带有时滞（发育时间、资源恢复、天敌的反应）；时滞密度制约造成超调与低于平衡的下冲（定义 13.1.1）。
- 时滞逻辑斯谛方程 (13.1) 只依赖于 $rT$。线性化给出特征方程 $z\mathrm{e}^z = -rT$，即式 (13.3)，以及定理 13.1.1：

  | $rT$ | 主根 | $K$ 附近的动态 |
  |---|---|---|
  | $(0, 1/\mathrm{e}]$ | 负实根 | 单调趋近 |
  | $(1/\mathrm{e}, \pi/2)$ | 复根，$\operatorname{Re} < 0$ | 减幅振荡 |
  | $\pi/2$ | $\pm\mathrm{i}\pi/2$ | Hopf 分岔，周期 $4T$ |
  | $> \pi/2$ | $\operatorname{Re} > 0$ | 稳定极限环，深谷 |

- 在离散时间中，$N_{t+1} = N_t[1 + r(1 - N_{t-1}/K)]$ 在 $r < 1/4$ 时单调，在 $1/4 < r < 1$ 时减幅，在 $r > 1$ 时持续振荡（命题 13.1.2）；时滞 Beverton–Holt 模型会振荡但从不失去稳定性。Nicholson 的绿蝇以约 2.7 个发育时间为周期循环；Gurney–Blythe–Nisbet 模型 (13.4) 把时滞与过度补偿的补充结合起来。
- 调节（密度制约地回归某一水平）不同于限制与决定（什么设定该水平和实际数量）（定义 13.2.1）。经典学说（气候学派、生物学派、折中学派；行为、内分泌与遗传的自我调节）强调同一过程的不同部分。密度制约起作用的位置在不同类群间有可预见的差异，种群也可以有多个平衡点（云杉卷叶蛾，迁徙与常驻的角马）。
- 自然种群表现出季节性、不规则与周期性的波动、暴发、相对稳定、衰退与灭绝。
- 对数数量的自回归模型（定义 13.4.1）量化了直接（$\beta_1$）与时滞（$\beta_2$）密度制约；Royama 图（命题 13.4.1）表明周期要求 $\beta_2 < -\frac14(1 + \beta_1)^2$，且随直接密度制约减弱而变长，这解释了田鼠周期的纬度梯度。ACF、PACF 与 PRCF 揭示周期与阶。
- 密度制约的回归检验在短序列中、也受抽样误差影响而有偏；需要随机化、自助法与状态空间方法，尤其需要野外实验。
- 松鸡、野兔与田鼠的周期需要直接与时滞的密度制约，而它们由不同的机制提供（寄生物与领域行为，捕食引起的应激及母体效应，专食性捕食者或食物）。

## 思考题

1. 证明时滞逻辑斯谛方程在 Hopf 阈值处的振荡周期为 $4T$，并直观地解释为什么时滞 $T$ 会产生约四倍时滞的周期。

   **答** 在 $rT = \pi/2$ 处，主根为 $\lambda = \pm\mathrm{i}\pi/(2T)$（定理 13.1.1），所以线性化方程的解为 $\cos(\pi t/(2T) + \phi)$，周期为 $2\pi/(\pi/(2T)) = 4T$。直观地说，增长率 $\dot x(t) = -rx(t - T)$ 与一个时滞之前的偏离成正比。在正弦振荡中，增长率比偏离超前四分之一周期；因此 $T$ 之前的偏离必须等于四分之一周期之后的偏离的负值，这在 $T$ 为周期的四分之一时成立。

2. 一种小型哺乳动物的种群，$r = 1.2\,\mathrm{yr}^{-1}$，受限于一种从啃食中恢复需要约 1 年时滞的食用植物。用时滞逻辑斯谛方程预测其动态。对于 $r = 0.2\,\mathrm{yr}^{-1}$、时滞相同的大型食草动物，预测会有什么不同？

   **答** 对小型哺乳动物，$rT = 1.2$，介于 $1/\mathrm{e}$ 与 $\pi/2$ 之间：围绕 $K$ 的减幅振荡，周期为 $2\pi/\operatorname{Im}z$ 个时滞；数值上，$z\mathrm{e}^z = -1.2$ 的主根为 $z \approx -0.19 \pm 1.44\mathrm{i}$，周期为 $2\pi/1.44 \approx 4.4$ 年，振幅每年衰减为原来的 $\mathrm{e}^{-0.19} \approx 0.83$。环境噪声会不断激发这些振荡，因此种群表现为不规则的准周期。对大型食草动物，$rT = 0.2 < 1/\mathrm{e}$：单调趋近，没有振荡。反应慢的物种即使时滞相同，也因其缓慢而得以稳定。

3. 证明对于时滞 Beverton–Holt 模型 $N_{t+1} = RN_t/(1 + aN_{t-1})$，平衡点对每个 $R > 1$ 都局部稳定，并求趋近何时是振荡的。

   **答** 平衡点满足 $1 + aN^* = R$。令 $N_t = N^*(1 + x_t)$，则 $1 + aN^*(1 + x_{t-1}) = R(1 + c\,x_{t-1})$，其中 $c = aN^*/R = (R - 1)/R$，所以 $x_{t+1} \approx x_t - c\,x_{t-1}$。特征方程 $z^2 - z + c = 0$ 在 $c < 1/4$ 即 $R < 4/3$ 时有 $(0, 1)$ 内的实根（单调趋近），在 $R > 4/3$ 时有模为 $\sqrt c < 1$ 的复根（减幅振荡）。由于对所有 $R$ 都有 $c < 1$，平衡点总是稳定的。

4. 一个田鼠种群的 40 年对数计数序列，在模型 (13.5)（$d = 2$）中给出估计 $\hat\beta_1 = -0.3$、$\hat\beta_2 = -0.7$。该种群是周期性的吗？周期多长？更靠南的第二个种群给出 $\hat\beta_1 = -1.1$、$\hat\beta_2 = -0.7$。解释这一差异。

   **答** 第一个种群：$a_1 = 0.7$，$a_2 = -0.7$；三角形条件成立（$\beta_2 > -1$，$\beta_1 + \beta_2 = -1 < 0$，$\beta_2 - \beta_1 = -0.4 < 2$），且 $a_1^2 + 4a_2 = 0.49 - 2.8 < 0$，所以出现周期，$\cos\theta = 0.7/(2\sqrt{0.7}) = 0.418$，$\theta = 1.140$，周期为 $2\pi/1.140 \approx 5.5$ 年。第二个种群：$a_1 = -0.1$，$\cos\theta = -0.1/(2\sqrt{0.7}) = -0.060$，$\theta = 1.631$，周期约 3.9 年。时滞密度制约相同，但南方种群的直接密度制约强得多，使周期缩短：这正是在芬诺斯堪迪亚田鼠中发现、并归因于广食性捕食者的格局。

5. 为什么由逐年计数对 $\ln N_t$ 回归 $\ln(N_{t+1}/N_t)$，可能在不存在密度制约时给出存在密度制约的印象？描述两种防止这一结论的办法。

   **答** 有两个原因：在短序列中，即使对随机游走，最小二乘斜率也向负方向偏；计数的抽样误差使预测变量与随后的增长率之间产生负相关（高估抬高了 $\ln N_t$，压低了 $\ln(N_{t+1}/N_t)$）。防范办法：把观测斜率与随机游走下的分布比较（Pollard 等的随机化检验，Dennis 与 Taper 的参数自助法）；用分开过程误差与观测误差的状态空间模型拟合，并利用对抽样方差的独立估计；而最好的办法是通过实验检验机制，例如操纵密度或资源。

6. （开放题）Andrewartha 与 Birch 认为他们花园里玫瑰上的蓟马从未受到调节。设计一项分析或实验，以区分“没有调节”与“只是偶尔起作用的调节”。

   **答** 要点：偶尔起作用的调节表现为只在高密度或特定季节出现的密度制约，所以对所有年份作单一线性回归可能漏掉它。可以拟合增长率依赖于密度与天气并含交互作用的模型（食物或空间受限时密度制约被“打开”），并与只含天气的模型比较检验。在实验上，可以在季节开始时往一些玫瑰上添加蓟马、从另一些玫瑰上移走，追踪每员的存活与繁殖：调节预测各处理会趋于一致，纯粹的非密度制约则预测差异持续存在。长期有界本身就是证据，说明至少有时必有某种密度制约起作用，因为随机游走终将漂向灭绝或暴发。
