生物生活在特定的时间和地点，周围是具有一定温度的空气或水、一天中不断变化的光、具有一定化学性质的土壤或沉积物，以及以它为食、与它竞争或为它提供条件的其他生物。其中哪些因子重要、它们如何起作用，以及为什么一个物种出现在某些地方而不出现在另一些地方，是个体水平上生态学的首要问题。本章提供贯穿全课程的一般概念：环境及其组成，生态因子及其分类，与 Liebig、Blackman 和 Shelford 相联系的限制与耐受定律，以及生物通过气候驯化和稳态来调整其耐受性的方式。

这里的概念是一般性的；以下各章依次讨论具体的因子：辐射、光与气候（7.19.3）、温度（7.19.4）、水与其他物理因子（7.19.5）、资源及其化学计量（7.19.6）和土壤（7.19.7）。耐受性背后的生理学（体温调节、渗透调节、光合作用）在植物生理学（7.13）和动物生理学（7.14）中讲述；这里强调的是它的生态学后果，即它对物种分布地点的限制。

## 2.1. 环境与生境

### 2.1.1. 环境

**定义 2.1.1（环境）** 生物或生物群体（主体）的**环境**（environment）是其周围一切事物的总和，包括它占据的空间以及所有直接或间接影响其生存、生长、繁殖和分布的因子。

环境是一个相对的概念：它相对于某个主体来定义。对池塘中的一条鲤鱼来说，环境包括其他鲤鱼、其他鱼类、虾、水蚤和水生植物，以及水、沉积物和空气；对鲤鱼种群来说，其他鲤鱼是主体的一部分，环境由其他物种和非生物的周围条件构成；对池塘群落来说，环境只有非生物的部分。环境的大小也各不相同，从整个宇宙（太阳、宇宙辐射）到一个细胞的紧邻周围。

### 2.1.2. 大环境与小环境

**定义 2.1.2（大气候与小气候）** 大环境是一个区域、地球或宇宙的环境；它的气候即**大气候**（macroclimate），是近地层之上的气候（通常在 1.5–2 m 高度测量），由大气环流、纬度、距海远近和大地形等大尺度因子决定。小环境是生物紧邻的周围，是大环境中一个小而具体的地点；它的气候即**小气候**（microclimate），是近地面小范围内的气候，在短距离内变化强烈，并受局部地形、植被、土壤和水体的改变。

大气候决定一个区域可以生长哪些类型的植被，从而决定群落的主要类型，即生物群系（热带雨林、温带草原、苔原等，7.19.41）；反过来，一个区域的生物群系也指示它的气候。然而生物感受到的是小气候，它可能与大气候有显著差异。在晴朗的夜晚，谷底的空气可能比高 100 m 的山坡冷 30 °C，因为冷而致密的空气顺坡下泄；冬日阳光下，树干南侧可达 30 °C，而空气温度在冰点以下；在森林冠层下，气温日较差比邻近的田野小，湿度更高。生物也会选择小气候：黎明时在悬枝下的巢中孵卵的雌蜂鸟，比在暴露的巢中孵卵的雌蜂鸟向寒冷夜空辐射散失的热量少（Calder 1973）。小气候的定量处理见 7.19.3。

### 2.1.3. 生境

**定义 2.1.3（生境）** 生物、种群或物种的**生境**（habitat）是它生活的场所，由作用于该处的一组环境因子表征。

肠道细菌的生境是宿主的消化道，啄木鸟的生境是林地，梭子鱼的生境是湖泊的沿岸带。生境是一个场所；**生态位**（[7.10.15](/7.10.15)）则不是。生态位是使物种能够维持一个种群的条件和资源的集合，同一个生境（一个湖泊）包含许多生态位，由生活方式迥异的物种占据（Begon 和 Townsend 2021）。生态位在 7.19.23 中完整展开。

## 2.2. 生态因子

### 2.2.1. 定义

**定义 2.2.1（生态因子）** **生态因子**（ecological factor）是环境中作用于生物的任何要素，如温度、光、水、氧、二氧化碳、养分、食物和其他生物。

一个生物所有的生态因子合在一起构成它的生态环境，某个地点的生态环境就是它的生境。生物不可缺少的因子有时称为生存条件：对绿色植物是光、二氧化碳、水和矿质养分；对动物是食物、氧和适宜的温度。

### 2.2.2. 分类

生态因子有几种互补的分类方式。

| 依据 | 类别 | 例子 |
|---|---|---|
| 性质 | 气候因子 | 温度、光、水、风、气压、雷电 |
| | 土壤因子 | 土壤结构、质地、化学性质、土壤生物 |
| | 地形因子 | 海拔、坡度、坡向、山脉、陆地与海洋 |
| | 生物因子 | 与其他生物的相互作用：食物、捕食者、寄生物、竞争者、互利共生者 |
| | 人为因子 | 污染、土地利用、物种引入、收获 |
| 有无生命 | 生物因子与非生物因子 | |
| 对种群大小的影响 | 密度制约因子 | 食物、捕食者、寄生物、疾病：它们对每个个体出生率或死亡率的影响强度随种群密度改变 |
| | 非密度制约因子 | 天气、灾变：对每个个体的影响与密度无关 |
| 稳定性 | 稳定因子 | 重力、地磁、太阳常数 |
| | 周期性变动因子 | 季节、昼夜、潮汐 |
| | 非周期性变动因子 | 风、火、捕食者的暴发 |
| 是否被消耗 | 条件 | 温度、pH、盐度、湿度：它们影响生物但不被消耗 |
| | 资源 | 光、水、养分、食物、空间：它们被消耗，可被其他生物耗尽 |

其中两种区分对本课程的其余部分至关重要。

密度制约因子与非密度制约因子的区分（Smith 1935）关系到种群调节。对每个个体的效应随密度增大的因子，如食物由更多个体分享时出现的饥饿，可以阻止种群增长并使之保持在某一水平附近；不论个体数多少都杀死同样比例个体的因子，如严重的霜冻，可以使种群减少，但不能单独调节种群。生物因子通常是密度制约的，气候因子通常是非密度制约的，但也有例外：如果庇护所的数量有限，使超出庇护所数量的个体死亡，那么霜冻的效应就是密度制约的。加拿大北方森林中美洲雪兔和猞猁的十年周期是密度制约的生物相互作用的教科书式例子。20 世纪 50 年代 Nicholson（主张种群由密度制约因子调节）与 Andrewartha 和 Birch（强调天气的作用）之间的争论及其现代的解决，在 7.19.13 中讨论。

条件与资源的区分（Begon 和 Townsend 2021）关系到生态位维度的种类。条件如温度不会被用掉：一个生物经历某个温度并不会减少留给另一个生物的部分，尽管生物可以改变条件（森林冠层降低其下的温度）。资源则被消耗，所以生物为之竞争。水两者兼是：作为资源它被根吸收，作为条件（湿度）它影响蒸发。条件是 7.19.3–7.19.5 的主题，资源是 7.19.6 的主题。

### 2.2.3. 生态因子如何起作用

生态因子的作用有若干一般特征。

- 综合作用。因子不是孤立地起作用：每个因子都与其他因子联系，一个因子的改变会引起其他因子的改变。森林冠层同时改变光、温度、湿度和风；海拔的改变同时改变温度、气压、辐射和降水。
- 主导因子。在作用于某个过程的因子中，往往有一个起决定作用。冬季的低温是使冬小麦开花的主导因子（**春化作用**，[7.13.22](/7.13.22)）；日长是诱导许多昆虫滞育的主导因子（7.19.3）。
- 不可替代性与补偿作用。每个必需因子都是必要的，没有哪个能被另一个完全替代；但当一个因子不足时，相关因子的增加可以对它起部分补偿作用。软体动物需要钙来构建壳；在锶丰富的地方，一些物种用锶取代一部分钙（Odum 的例子）。在植物中，高光强部分补偿低 CO₂ 浓度，反之亦然。
- 直接作用与间接作用。光和温度直接作用于生理；地点的坡度、坡向和海拔通过对光、温度和水的影响间接起作用。间接因子往往最容易制图，因此出现在分布的研究中。
- 阶段性作用。生物在发育的不同阶段需要不同的因子，或同一因子的不同水平。繁殖阶段通常最敏感：种子、卵、幼虫和幼苗的耐受极限比成体窄（第 2.4.3 节），许多动物只在其分布区的一部分繁殖。

## 2.3. 生物与环境的相互作用

### 2.3.1. 作用、反作用与相互作用

生物与环境的关系是双向的。Clements 提出的三个术语描述了它。

- 作用：非生物环境对生物的影响，涉及其生长、发育、繁殖、行为、存活和分布。
- 反作用：生物对其非生物环境的影响。森林创造自己的小气候，土壤生物改变土壤的结构和养分含量，河狸把溪流变成池塘。
- 相互作用（coaction）：生物之间的相互影响。在捕食者与猎物或寄生物与宿主之间，说谁在作用、谁在反作用是没有意义的：这种关系是相互的，在演化时间尺度上导致**协同演化**（[7.10.17](/7.10.17)）。两个物种之间按各自所受影响的符号（+、− 或 0）分类的相互作用类型，是 7.19.22–7.19.29 的主题。

地球历史上最大的反作用是光合作用使大气氧化。蓝细菌是真核藻类出现之前唯一进行放氧光合作用的生物，它释放的氧起初被还原态的铁和硫化合物消耗；在约 24 亿至 21 亿年前的**大氧化事件**中，游离氧首次在大气中积累，从几乎为零升至现今水平的约 1–10%（[7.10.27](/7.10.27)）。氧反过来使有氧呼吸和臭氧层成为可能，从而使后来复杂生命的演化成为可能。今天，一个物种，即我们人类，造成了影响相当的反作用：工业革命以来二氧化碳和全球温度的上升（7.19.47）。

### 2.3.2. 适应

生物不是被动的。通过自然选择，它们获得了减轻环境限制作用的形态、生理和行为性状：这就是**适应**（[7.10.3](/7.10.3)）。植物主要通过形态和生理来适应；动物还通过行为，例如迁往更好的地点或时间。所有适应都有遗传基础，尽管表型可塑性，即同一基因型在不同环境中产生不同表型的能力，本身也是可遗传的、适应性的。

一个经典的例子是桦尺蛾 *Biston betularia* 的工业黑化：在英国工业区被煤烟熏黑的林地中，在深色树皮上较不易被鸟发现的深色（*carbonaria*）型在 19 世纪上升到 90% 以上；20 世纪 50 年代起清洁空气立法使烟雾减少，其频率再度下降，与冬季烟雾浓度的下降密切同步（[7.10.5](/7.10.5)、[7.4.23](/7.4.23)）。

适应有两种常见模式。生活在相似条件下的不同物种往往趋同于相似的形态；这样的物种类群称为**生活型**（[7.12.32](/7.12.32)），例如鲸、海豹和鱼类的流线型身体，或按休眠芽位置分类的植物 Raunkiær 生活型（7.19.32）。生活在不同条件下的同一物种的各个种群则往往分化成遗传上不同的**生态型**（[7.10.11](/7.10.11)），例如适应不同日长和温度的气候生态型水稻（中国农业中的早稻、中稻和晚稻）、陆稻与水稻等土壤生态型，以及抗病与感病品系等生物生态型。生物还可以在时间上通过休眠和**滞育**，或在空间上通过**迁徙**（7.19.19、[7.18.20](/7.18.20)）逃避不利条件。

## 2.4. 限制与耐受定律

### 2.4.1. Liebig 最小因子定律

德国农业化学家 Justus von Liebig（1803–1873）在 19 世纪 40 年代观察到，作物产量往往不是受限于需要量大的养分（如二氧化碳和水，它们通常很充足），而是受限于土壤中稀缺的、需要量小的元素，如硼、镁或铁。Carl Sprengel 在 1828 年就指出过同一点，这一原理有时称为 Sprengel–Liebig 定律。通常用一只木板高低不一的木桶来说明：水只能装到最短那块木板的高度。

**最小因子定律**（[7.13.4](/7.13.4)）指出，植物的生长受相对于需要而言存在量最小的必需因子控制；更一般地说，低于物种所需最小量的因子，是决定其存活与分布的因子。Odum 补充了两点限定。第一，该定律严格地只适用于稳态，即能量和物质的流入与流出平衡时；在过渡期间，许多因子可能迅速相继变化，没有哪个会长期起限制作用。第二，因子之间相互作用：一个因子的高浓度可能改变对另一个因子的需求（第 2.2.3 节的补偿作用），因此最小值不是固定的。

最简单的数学形式是，产量 $y$ 通过下式依赖于 $n$ 个因子的供应量 $x_1, \dots, x_n$：

$$
y = \min\{f_1(x_1), f_2(x_2), \dots, f_n(x_n)\},
$$
其中 $f_i(x_i)$ 是仅因子 $i$ 所允许的产量。如果土壤氮可支持 250 kg 的产量，钾 350 kg，磷 500 kg，则 Liebig 定律预测产量约为 250 kg，不加氮而只加钾或磷则毫无作用。这一模型在双因子平面上的等产量曲线（等倾线）是直角（下图）：沿竖直的一臂只有第一个因子起作用，沿水平的一臂只有第二个因子起作用。

另有两种备择模型。在乘积模型中，每个因子使另一个因子的效应成比例缩放，

$$
y = y_{\max}\, g_1(x_1)\, g_2(x_2), \qquad g_i(x_i) = \frac{x_i}{k_i + x_i},
$$
其中 $g_i$ 是带半饱和常数 $k_i$ 的饱和函数（Monod 或 **Michaelis–Menten 方程**型）；在加和模型中，各因子可相互替代，$y = a_1 g_1(x_1) + a_2 g_2(x_2)$。两种情形下等倾线都是类似双曲线的曲线，且在每一点上两个因子都影响产量。

![双资源（氮 N 与磷 P）限制的三种模型，饱和响应分别为 N/(1 + N) 和 1.5P/(1 + 1.5P)（示意参数）。上：等产量的等倾线。在 Liebig 最小因子定律下，等倾线是直角，因此只有较稀缺的资源起作用；在乘积模型（每个因子使另一个因子的效应成比例缩放）和加和模型（因子可相互替代）中，等倾线是平滑曲线。下：产量对氮供应量的曲线，分别对应低（红）和高（蓝）的磷供应。在 Liebig 定律下，产量随氮增加，直到磷成为限制因子，然后保持在由磷决定的平台；在乘积模型中，氮总是提高产量，在磷充足时提高得更多。](./plots/limitation-models.py)

这些模型对析因施肥实验作出不同的预测：实验中各小区不施肥（对照）、只施氮、只施磷或两者都施。在氮的单一限制（Liebig）下，只有 N 和 N + P 处理使生长增加，且增加量相同，直到磷成为限制因子。在乘积式共同限制（co-limitation）下，单独的 N 和 P 都使生长增加，而 N + P 使之增加的量大于两个单独效应之和（协同）。对陆地、淡水和海洋系统中 641 个 N × P 析因实验的荟萃分析（Harpole 等 2011）发现，N 与 P 同时添加最常给出比任一单独添加大得多的响应；严格的单一限制比 Liebig 定律的简单形式所暗示的更少见。Liebig 的洞见在以下意义上仍然正确：供应不足的必需资源无法被替代；但在整株植物和群落的尺度上，往往有几种资源同时起限制作用，因为生物会调整其分配（缺氮的植物向根投入更多），也因为群落中包含受不同资源限制的物种。生态化学计量学（7.19.6）发展了这一主题。

### 2.4.2. Blackman 限制因子定律

英国植物生理学家 Frederick Blackman（1866–1947）研究了光合速率如何依赖于光、二氧化碳和温度。在论文《最适值与限制因子》（1905）中，他提出：当一个过程依赖于多个因子时，其速率受最短缺的因子（"最慢"因子）限制，增加该因子可使速率增加，直到另一个因子成为限制因子。因此，光合作用在低光强下随光线性增加，然后达到一个平台，平台的高度由二氧化碳浓度决定：这就是上图左下面板中的 Liebig 曲线。Blackman 还表明，表观的最适值可以由因子的相互作用产生：在高温下光合作用起初很快，但随时间下降，因为机构受到损伤，因此测得的"最适"温度取决于测量的持续时间。叶片真实的光响应曲线有圆滑的肩部而不是 Blackman 的尖角，通常用非直角双曲线描述，其曲率参数 $\theta$ 在极限 $\theta \to 1$ 时给出 Blackman 曲线（[7.13.9](/7.13.9)）。

Liebig 和 Blackman 的思想后来与另一观察结合起来：一个因子既可以因不足、也可以因过量（过热、过强的光或过多的水）而起限制作用。由此得到限制因子的一般概念。

**定义 2.4.1（限制因子）** **限制因子**（limiting factor）是当接近或超出生物的耐受极限时，限制其存活、生长、繁殖或扩散的生态因子。一个因子可以因不足或过量而起限制作用。

这一概念是实用的：要理解或管理一个种群，就要寻找其改变产生最大效应的因子。当发现冬季补饲后保护区内鹿的存活率上升、数量增加时，冬季食物就被确定为限制因子。非洲化蜜蜂在美洲的扩散，从 1956 年引入巴西到 1990 年到达得克萨斯，在南北美洲相似的纬度附近减慢并停止，那里寒冷的冬季限制了没有储存足够蜂蜜的蜂群：低温在两端都限制了它的分布范围。

### 2.4.3. Shelford 耐受性定律

美国生态学家 Victor Shelford（1877–1968）把限制因子的概念推广到每个梯度的两端。

**定义 2.4.2（耐受性定律）** **耐受性定律**（law of tolerance；Shelford 1913）指出：生物的存在和成功受每个生态因子的不足与过量两方面的限制：当某一因子在量上或质上接近或达到生物的耐受极限时，生物就会衰退或无法生存。

**定义 2.4.3（生态幅）** 对每个生态因子，生物都有耐受的下限和上限。两者之间的范围是它对该因子的耐受范围，即**生态幅**（ecological amplitude）。其中有一个较窄的最适范围，两侧是生理胁迫区，在其之外是不耐受区。

这个定律通常画成沿因子梯度的钟形耐受曲线（下图，面板 A）：表现或多度在最适范围内最高，在胁迫区较低，在耐受极限之外为零。沿地理梯度测量时，种群在最适区丰富，在胁迫区稀少，在区外缺失。并非所有生命过程的范围都相同：生物通常能存活的范围比允许其生长的范围宽，能生长的范围又比允许其繁殖的范围宽（面板 A 中的 S、G 和 R）。毒素的响应是单侧的（低浓度下无影响，超过阈值则有害乃至致死），而铜和锌等微量营养素在低浓度下是必需的，在高浓度下有毒。

生态幅的宽窄用前缀 eury-（广）和 steno-（狭）表示：广温性与狭温性（温度）、广湿性与狭湿性（水）、**广盐性**（[7.14.21](/7.14.21)）与狭盐性（盐度）、广食性与狭食性（食物）、广光性与狭光性（光）、广栖性与狭栖性（生境）。狭温性物种可适应寒冷（低温狭温性）或温暖（高温狭温性）。生活在约 −1.9 °C 的南极鱼 *Trematomus bernacchii*，被加热到约 6 °C 时死亡（Somero 和 DeVries 1967）：它是极端的狭温性生物。金鱼视驯化情况可耐受从接近冰点到约 40 °C 的温度（第 2.5.1 节），是已知最广温的鱼类之一。

后来的工作从几个方向发展了 Shelford 定律（Odum 1971；Pianka 1978）：

1. 一个物种可能对某一因子的耐受范围宽，而对另一因子的耐受范围窄。
2. 耐受性在发育过程中变化；繁殖期通常是关键的，极限最窄，因此繁殖往往限于分布区的一部分。
3. 不同物种对同一因子的耐受范围不同；对所有因子耐受范围都宽的物种可能分布广泛。
4. 当一个因子的条件不是最适时，对其他因子的耐受极限会缩小（第 2.4.5 节）。
5. 物种常常并不生活在生理上最适的条件下，因为其他物种把它们排挤出去（第 2.4.6 节）。

### 2.4.4. 作为表现函数的耐受性

耐受曲线可以写成函数。设 $x$ 为某因子的水平，$P(x) \geq 0$ 为暴露于该水平的生物的表现（生长率、存活率、繁殖力）。一个方便的模型是 Gauss 曲线

$$
P(x) = P_{\max} \exp\left(-\frac{(x - \mu)^2}{2\sigma^2}\right),
$$
其中最适值为 $\mu$，最大值为 $P_{\max}$，耐受幅度为 $\sigma$；生态幅定义为 $P$ 超过其最大值的比例 $q$ 的范围，为 $\mu \pm \sigma\sqrt{-2\ln q}$。热性能曲线是不对称的，用不同的方式建模（7.19.4），但 Gauss 曲线抓住了本质的权衡。

人们常常观察到，耐受范围宽的物种在任何特定点上的表现不如特化种在其最适点上的表现："样样通，样样松"。表达这一点最简单的方法是假定耐受曲线下的面积固定，$\int P(x)\,\mathrm{d}x = P_{\max}\sigma\sqrt{2\pi} = c$，于是 $P_{\max} = c/(\sigma\sqrt{2\pi})$：幅度加倍，峰值减半（下图，面板 B）。食性狭窄的食草动物和泛化的杂食动物是熟悉的例子。哪种幅度最好，则取决于环境的变动程度。

![耐受曲线（示意模型）。A：Shelford 耐受性定律。沿环境梯度的表现（Gauss 曲线）；最适范围（绿色）两侧是生理胁迫区，在耐受下限和上限之外是不耐受区（红色）；两个极限之间的范围是生态幅。曲线下方的条带表示存活（S）的范围比生长（G）宽，生长的范围又比繁殖（R）宽。B：泛化种与特化种的权衡：面积相同的三条耐受曲线；狭适性特化种（红色）峰高而窄，广适性泛化种（蓝色）峰低而宽。](./plots/tolerance-curves.py)

**命题 2.4.1（最优耐受幅度）** 设一个个体具有面积固定为 $c$ 的 Gauss 耐受曲线，所经历的因子 $X$ 逐代变化，均值为 $m$，方差为 $s^2$，并以表现的对数 $\ln P(X)$ 的期望度量其谱系的长期增长。则期望对数表现为

$$
\mathbb{E}[\ln P(X)] = \ln\frac{c}{\sqrt{2\pi}} - \ln\sigma - \frac{s^2 + (m - \mu)^2}{2\sigma^2},
$$
并在耐受幅度 $\sigma^* = \sqrt{s^2 + (m - \mu)^2}$ 处达到最大。特别地，若最适值与平均环境相符（$\mu = m$），则最佳幅度等于环境的标准差，$\sigma^* = s$。

**证明** 由 $\ln P(x) = \ln P_{\max} - (x - \mu)^2/(2\sigma^2)$、$P_{\max} = c/(\sigma\sqrt{2\pi})$ 以及 $\mathbb{E}[(X - \mu)^2] = \operatorname{Var}(X) + (\mathbb{E}X - \mu)^2 = s^2 + (m - \mu)^2$，得到该表达式。记 $D^2 = s^2 + (m - \mu)^2$，对 $\sigma$ 求导，

$$
\frac{\mathrm{d}}{\mathrm{d}\sigma}\,\mathbb{E}[\ln P(X)] = -\frac{1}{\sigma} + \frac{D^2}{\sigma^3},
$$
当 $\sigma < D$ 时为正，$\sigma > D$ 时为负；故最大值在 $\sigma = D$ 处。$\square$

采用对数是因为谱系在许多世代中的增长是乘性的：经过 $T$ 代后其大小正比于 $\prod_t P(X_t)$，其 $T$ 次方根（几何平均）由大数定律收敛于 $\exp\mathbb{E}[\ln P(X)]$。峰值很高的特化种在平均年份表现很好，在极端年份表现很差，而一个极坏的年份（表现接近零）对**几何均数**有不成比例的影响。该命题表达了演化生态学的一个一般结果：环境的变动性选择宽的耐受性，稳定的环境则选择特化。它也解释了为什么经历的季节温度变动很小的热带变温动物，其热耐受范围往往比温带的窄（7.19.4）。**赌注分散**（7.19.18）也基于同样的几何平均适合度的逻辑。

### 2.4.5. 双因子：响应面

由于因子相互作用，对一个因子的耐受性取决于其他因子的水平。Pianka（1978）用一个适合度同时取决于相对湿度和温度的生物来说明这一点：最适温度取决于湿度，最适湿度取决于温度，高适合度的区域是双因子平面上的一个区域，而不是两个独立范围的乘积。Haefner（1970）测量了沙虾 *Crangon septemspinosa* 在不同温度和盐度组合下的存活率；高存活区在两者的中间值处最大，在远离最适温度时，可耐受的盐度范围更窄。两个因子定义了生态位的一个二维截面，许多因子合在一起则定义了 Hutchinson 的 $n$ 维生态位（7.19.23）。

这种相互作用的一个简单模型是

$$
s(T, S) = \exp\left(-\frac{(T - T_0)^2}{2\sigma_T^2}\right)\exp\left(-\frac{(S - S_0)^2}{2w(T)^2}\right), \qquad w(T) = w_0\exp\left(-\frac{(T - T_0)^2}{2\tau^2}\right),
$$
其中盐度耐受幅度 $w(T)$ 在最适温度处最宽，并随温度偏离最适值而变窄。如果 $w$ 是常数，曲面就可以因式分解，$s(T, S) = s_T(T)\,s_S(S)$，对每个因子的响应将与另一个因子无关；$w$ 对 $T$ 的依赖使因子发生相互作用，并再现了第 2.4.3 节的第 4 点。

![存活率作为温度和盐度的联合函数（模拟的响应面，模仿 Haefner 对沙虾 Crangon septemspinosa 的实验；示意参数 T₀ = 15 °C，S₀ = 25‰）。A：存活率百分比的等值线；高存活区在最适温度处盐度方向最宽，向两个温度极端变窄。B：曲面在三个温度处的截面（A 中的虚线）：在 8 °C 和 24 °C 下，不仅最大存活率低于 15 °C，可耐受的盐度范围也更窄。](./plots/response-surface.py)

### 2.4.6. 生理最适与生态最适

在实验室中单独培养一个物种所测得的最适值是生理最适；物种在自然界中最丰富的条件是它的生态最适。两者常常不同，因为竞争者、捕食者和寄生物把物种排挤出其生理范围的一部分。在 Ellenberg 的实验（1953）中，几种草地禾草沿地下水位深度的梯度生长。单独种植时，它们都在相近的中等地下水位下生长最好；混合种植时，各自被位于中间的竞争优势者推向梯度的不同部分，有的到潮湿一端，有的到干旱一端。沿土壤 pH 梯度对草本植物的野外调查也显示同样的格局：在纯培养中在近中性 pH 下生长最好的物种，在野外却出现在酸性或钙质土壤上，在那里它们不受更强竞争者的影响。生理范围对应于基础生态位，生态范围对应于实际生态位，这两个概念在 7.19.23 中展开。

### 2.4.7. 适应组合

对严酷环境的适应通常涉及的不是单个性状，而是一套协调的形态、生理和行为性状，即适应组合。单峰驼（*Camelus dromedarius*）以缺水为例说明了这一点：

- 它以多汁植物和带露水的植物为食，冬季可以两周或更长时间不饮水。
- 它的肾产生浓缩的尿，粪便干燥。
- 脱水时，它让体温从黎明时的约 34 °C 升到傍晚的约 41 °C，白天贮存热量，在凉爽的夜晚通过传导和辐射而不是出汗散失热量；这每天节省数升水（Schmidt-Nielsen 1964）。
- 它能耐受失去约四分之一的体内水分，而且水分主要从组织而不是血液中失去，因此血液不会变黏稠；它椭圆形的红细胞能承受数分钟内饮水 100 L 以上时的渗透膨胀。
- 驼峰贮存脂肪作为能量储备。氧化这些脂肪产生的代谢水常被说成水源，但它在很大程度上被获取氧化所需氧气而额外增加的呼吸失水所抵消，因此驼峰是能量库，而不是水库。

## 2.5. 耐受极限的调整

### 2.5.1. 实验驯化与气候驯化

耐受极限不是固定的。在演化时间尺度上，它们通过选择而移动；在一生之内，它们通过对近期条件的生理调整而移动。

**定义 2.5.1（实验驯化与气候驯化）** 如果让生物在偏向其范围一侧的条件下生活一段时间，它的耐受曲线会移动：最适值以及下限和上限朝所经历条件的方向移动。这样的调整如果是通过实验诱导的，通常只改变一个因子，就称为**实验驯化**（acclimation）；同样的过程发生在自然界中，是对许多因子联合的季节性或地理性变化的响应，就称为**气候驯化**（acclimatization）。

在 5 °C 下驯化的青蛙，在任何测试温度下消耗的氧都比在 25 °C 下驯化的青蛙多，部分补偿了低温对代谢的减慢作用。夏季在 −15 至 −20 °C 死亡的桦树幼苗，经秋季锻炼后可存活 −35 °C；冬季能存活 −15 °C 的柳枝，夏季在 −5 °C 就被冻死（**低温锻炼**，[7.13.27](/7.13.27)）。

驯化对热耐受性的影响用耐受多边形概括（Fry 1947；下图，面板 A）。让鱼在不同温度 $T_{\mathrm{a}}$ 下驯化，测量其上、下致死温度 $U(T_{\mathrm{a}})$ 和 $L(T_{\mathrm{a}})$，即在固定时间内一半的鱼死亡的温度。对金鱼来说，两者几乎都随驯化温度线性上升：在 20 °C 下驯化时，金鱼耐受 2.5–34 °C；在 30 °C 下驯化时为 9–38 °C。上限最终达到一个任何驯化都无法提高的上限值（金鱼约 41 °C），即极限上致死温度，而下限不能低于水的冰点。多边形的面积

$$
A = \int \max\{U(T_{\mathrm{a}}) - L(T_{\mathrm{a}}), 0\}\,\mathrm{d}T_{\mathrm{a}},
$$
单位 $^\circ\mathrm{C}^2$，是物种整体热耐受性的度量：金鱼约 1200 °C²，是已知最大者之一，而狭温性的鲑科鱼类只有几百（Brett 1956）。

![A：广温鱼类的热耐受多边形，仿照 Fry、Brett 和 Clawson（1942）的金鱼数据绘制：上致死温度（红）和下致死温度（蓝）随驯化温度上升（20 °C 下为 2.5–34 °C，30 °C 下为 9–38 °C）；下限以 0 °C 为界，上限以 41 °C 为上限值；阴影面积约 1200 °C²，是耐受区。B：调节者与顺应者（示意）。顺应者的内部状态随外部状态变化（斜率 1）；调节者在其调节范围（阴影）内把内部状态保持在设定点，超出该范围时同样顺应；部分调节者的内部状态变化小于环境的变化（斜率 0.3）。](./plots/acclimation-and-regulation.py)

### 2.5.2. 稳态：调节者与顺应者

扩展耐受性的第二种方式是在外部环境变化时保持内部环境恒定，即**稳态**（[7.14.1](/7.14.1)）。可以按生物的响应对它们分类。

**定义 2.5.2（调节者与顺应者）** 就某个环境因子而言，在外部状态变化时保持相对恒定的内部状态（体温、渗透浓度、离子组成、pH）的生物，称为**调节者**（regulator，稳态生物）；内部状态随外部状态变化的生物，称为**顺应者**（conformer，非稳态生物）。

这些术语针对具体的因子：一只海蟹可以同时是**渗透顺应者**（[7.14.21](/7.14.21)）和温度顺应者，而淡水鱼调节其渗透浓度，但在温度上是顺应的。许多生物是部分调节者（上图，面板 B）：它们的内部状态会变化，但变化小于环境的变化。如果内部状态 $y$ 在设定点 $y^*$ 附近对外部状态 $x$ 的响应为 $y = y^* + \beta(x - y^*)$，则系数 $\beta$ 的范围从完美调节者的 0 到完美顺应者的 1。调节从来不是无限的：在其调节范围之外，调节者变为顺应，然后死亡。因此稳态拓宽了生态幅，却不能使生物摆脱环境的限制；调节者对被调节的因子通常是广适性的。

调节是有代价的。把体温保持在 37 °C 的恒温动物在 0 °C 的环境中，散热与温差成正比，必须靠代谢补充（7.19.4）；体液浓度高于水的淡水鱼必须逆梯度泵出离子。调节的代价与收益之间的平衡，解释了为什么在环境稳定的地方，如深海和大部分开阔海洋，顺应者很常见。

调节不一定是生理性的。最简单也最普遍的机制是行为：迁往更好的小气候。荒漠蜥蜴早晨以侧腹垂直于阳光并紧贴温暖的岩石晒太阳，中午面向太阳以减少受照面积并抬起身体迎着微风，或退入阴凉处和洞穴；这样它们在一天的大部分时间里把体温保持在偏好值的几度之内（**行为性体温调节**，7.19.4）。不能移动的植物调整叶片的角度，许多花追踪太阳或在夜间闭合。

## 小结

- 环境是主体周围对它有影响的一切事物（定义 2.1.1）；大气候由大尺度因子决定，小气候由局部地形、植被和土壤决定（定义 2.1.2）。生境是生物生活的场所（定义 2.1.3），生态位是它所需的条件和资源的集合。
- 生态因子（定义 2.2.1）按性质（气候、土壤、地形、生物、人为）、按对密度的依赖（密度制约因子可以调节种群，非密度制约因子不能）以及按条件（不被消耗）或资源（被消耗）分类。它们综合作用，有主导因子，不可替代但可部分补偿，直接或间接起作用，且在生命的不同阶段作用不同。
- 生物受环境作用，对环境起反作用（大氧化事件、森林小气候），并彼此相互作用；它们通过趋同（生活型）和分化（生态型）来适应。

| 定律 | 内容 | 模型 |
|---|---|---|
| Liebig（1840） | 相对于需要而言供应最短缺的必需因子控制生长 | $y = \min_i f_i(x_i)$，L 形等倾线 |
| Blackman（1905） | 一个过程受其最慢的因子限制，直到另一个因子成为限制因子 | 线性上升至平台 |
| Shelford（1913） | 不足与过量都起限制作用（定义 2.4.2） | 钟形耐受曲线；生态幅（定义 2.4.3） |
| 共同限制 | 几个因子同时起限制作用 | $y = y_{\max}\prod_i g_i(x_i)$，平滑等倾线 |

- 限制因子（定义 2.4.1）可因不足或过量而起限制作用。对每个因子，物种是广适性或狭适性的；宽的耐受性以牺牲峰值表现为代价，在面积相等的权衡下，使长期（几何均数）表现最大的耐受幅度，等于环境偏离最适值的均方根偏差（命题 2.4.1）。
- 因子相互作用（响应面）；物种常因竞争者而生活在远离其生理最适的地方（生态最适与生理最适）；对恶劣环境的适应涉及成套的性状（骆驼）。
- 耐受极限通过实验驯化和气候驯化移动（定义 2.5.1；耐受多边形）；稳态区分调节者与顺应者（定义 2.5.2），它拓宽但不能消除限制，且消耗能量；行为是最简单的调节。

## 思考题

1. 某土壤上的作物获得的氮足以产 250 kg，钾足以产 350 kg，磷足以产 500 kg。Liebig 定律预测的产量是多少？农民只加钾能得到什么？如果各因子是乘积式共同限制，答案有何不同？

   **答** Liebig 定律预测约 250 kg，即最受限制的养分氮所允许的产量；只加钾一无所获，而加氮可使产量上升，直到钾在 350 kg 处成为限制因子。在乘积式共同限制下，每种养分使其他养分的效应成比例缩放，所以只加钾会使产量有所提高，但远不如加氮，而两者都加得到的产量大于各自增益之和。析因实验（对照、N、K、N + K）可以区分这两种情形。

2. 解释为什么当庇护所数量有限时，杀死所有不在庇护所中的个体的霜冻是密度制约因子。

   **答** 设有 $H$ 个庇护所和 $N$ 个个体，只有在庇护所中的个体存活。被杀死的比例为 $\max(0, 1 - H/N)$，随 $N$ 增大：低密度时所有个体都找到庇护所，无一死亡；高密度时大部分死亡。因此每个个体的死亡率取决于密度，所以（通过有限的庇护所）霜冻可以调节种群，尽管它是气候因子。密度制约是效应的性质，而不是因子种类的性质。

3. 用命题 2.4.1 比较一种热带低地昆虫和一种温带昆虫的最优热耐受幅度：前者活动季节的平均温度在世代间的标准差为 1 °C，后者为 4 °C。如果温带昆虫的最适温度比平均温度高 2 °C，会怎样？

   **答** 最适值与平均温度一致时，$\sigma^* = s$：热带为 1 °C，温带为 4 °C。如果温带的最适值偏移 2 °C，则 $\sigma^* = \sqrt{4^2 + 2^2} \approx 4.5$ °C：最适值与环境的失配与变动性一样有利于更宽的耐受性。该模型预测热带的热耐受性较窄，与观察到的纬度格局一致（7.19.4），并意味着热带特化种对平均温度的变化更脆弱。

4. 为什么繁殖阶段往往是限制物种分布的阶段？举一个例子。

   **答** 卵、胚胎、幼虫和幼苗的耐受极限比成体窄（它们体型小、不能离开，发育需要精确的条件），而且繁殖比存活需要更多的能量和更好的条件。因此物种可能作为成体存活在不能繁殖的地方。例如：许多鱼类和两栖类，其卵比成体耐受的温度和氧范围更窄；海龟，其胚胎在约 33–35 °C 以上死亡（7.19.4）；在结实范围以外仍以成体存活的植物，如英格兰海拔 600 m 以上的灯心草 *Juncus squarrosus*，其种子不能成熟，进而限制了以其种子为食的灯心草蛾。

5. 在 1000 和 1100 mOsm kg⁻¹ 的海水中，蟹 A 的血液渗透压为 960 和 1050 mOsm kg⁻¹，蟹 B 为 600 和 620 mOsm kg⁻¹。估计各自的系数 $\beta$ 并分类。哪一种更可能生活在河口？

   **答** $\beta_A = (1050 - 960)/(1100 - 1000) = 0.9$：蟹 A 近乎渗透顺应者。$\beta_B = (620 - 600)/100 = 0.2$：蟹 B 是部分调节者，使血液远低于外界浓度。顺应者是稳定的开阔海洋的典型，在那里无需调节；部分或强调节者是河口、盐沼等盐度随潮汐和降雨波动的环境的典型，因为那里调节使内部环境保持在可耐受的范围内。蟹 B 是河口物种。

6. 为什么驯化不能无限地提高上致死温度？

   **答** 驯化通过在基因组所允许的范围内调整酶、膜脂、热休克蛋白和其他组分起作用，但蛋白质和膜的稳定性有由其化学性质决定的上限：超过一定温度，必需的蛋白质变性，膜变得过于流动，氧供应无法满足需求（7.19.4）。耐受多边形的上限（金鱼约 41 °C）反映了这些极限；要提高它需要多代的遗传变化，而不是驯化。
