RNA 是这样一类生物序列：它的三维行为可以在一定程度上仅由序列、并在多项式时间内预测。原因在于，折叠自由能的大部分来自相互堆叠的碱基对，而二级结构中的碱基对若排除交叉，就像括号一样嵌套：结构分解为相互独立的子问题，因此适用**动态规划**（[4.3.1](/4.3.1)）。本章讲这些计算：结构如何记录，Zuker 算法（Zuker's algorithm）的递推及其表格的含义，配分函数与碱基对概率，化学探测数据如何作为约束加入，通向协方差模型以及在序列数据库中搜索 RNA 家族成员的文法观点，比对中的共变如何揭示结构，以及 RNA–RNA 相互作用（包括微 RNA 靶向）如何预测。物理部分属于生物物理学，这里不再重复：最近邻模型、最简形式的 Nussinov 与 McCaskill 递推、动力学与三级结构见 [7.6.15](/7.6.15#sec-15.6) 与 [7.6.16](/7.6.16#sec-16.7)，碱基的化学见 [7.1.11](/7.1.11)。协方差模型是轮廓隐 Markov 模型在文法上的类似物，后者见 [7.8.5](/7.8.5)，非编码 RNA 本身见 [7.2](/7.2)。贯穿全章的例子是酵母 tRNA-Phe，它是第一个解出结构的 RNA，至今仍是检验折叠程序的最佳测试。

## 16.1. 结构的表示

**非编码 RNA** 在三个层次上被描述：序列、二级结构（碱基对的集合）与三级结构（空间排布）。二级结构是有用的中间层次：它承载了大部分自由能，在进化中比序列保守得更久，并且可以计算。

**定义 16.1.1（二级结构与点括号表示）** 序列 $x_1\cdots x_n$ 的二级结构是满足 $i + 4 \le j$ 的数对 $(i, j)$ 的集合 $S$，其中每个核苷酸至多属于一对，且任意两对不交叉：若 $(i, j), (k, l) \in S$ 且 $i < k < j$，则 $k < l < j$。碱基对是 Watson–Crick 对（A–U、G–C）或摆动对（G–U）。在**点括号表示**中，结构写成一个字符串：每对的 $5'$ 端配偶处写左括号，$3'$ 端配偶处写右括号，每个未配对的核苷酸处写一个点。若碱基对集合包含两个交叉的对，则称为**假结**，这种记法无法表示它，下面的算法也将其排除在外。

最小距离 $j - i \ge 4$ 表示发夹环至少需要三个核苷酸。常见的显示方式有三种：点括号字符串；弧图（序列排成一条线，每个碱基对画成其上的一条弧，其中交叉的弧恰好就是假结）；以及传统的三叶草图或平面图。假结是真实存在的——它们出现在**端粒酶** RNA、**核糖开关**与病毒的移码信号中——而预测含任意假结的最优结构是 NP 难的（Lyngsø 与 Pedersen，2000），不过受限的类型可以在 $O(n^5)$ 或 $O(n^6)$ 时间内求出（Rivas 与 Eddy，1999）。因此，一般问题的程序先预测无假结的结构，再用启发式方法添加假结。

结构被分解为若干*环*，能量模型给每个环而不是每个碱基对指定一个自由能。碱基对 $(i, j)$ 闭合一个环，该环的其他边界是紧挨着它内部的碱基对：没有（发夹环）、一个（相邻时为堆叠对，否则为凸起或内部环），或两个及以上（多分支环）。这些环的自由能由短寡核苷酸的光学熔解测得，就是 [7.6.15](/7.6.15#sec-15.6.1) 的最近邻参数（Turner 1999 与 2004 参数集，其后又加入了对特殊发夹、悬挂末端与同轴堆叠的测量）。

## 16.2. 最小自由能折叠

### 16.2.1. Zuker 递推

Nussinov 算法用一张表使碱基对数目最大（[7.6.15](/7.6.15#sec-15.6.2)）。基于环的能量模型需要几张表，因为一个碱基对的能量取决于它内部有什么。

**算法 16.2.1（Zuker）** 设 $V(i, j)$ 为子序列 $x_i\cdots x_j$ 在*$(i, j)$ 配对*的条件下的最小自由能，$WM(i, j)$ 为 $x_i \cdots x_j$ 作为含至少一个分支的多分支环的一部分时的最小能量，$WM1(i, j)$ 为同样情形下恰有一个起于 $i$ 的分支时的最小能量，$W(j)$ 为前缀 $x_1\cdots x_j$ 的最小能量。设发夹环能量为 $H$，内部环能量为 $I$（包括堆叠与凸起），多分支环参数为 $a$（闭合）、$b$（每个分支）与 $c$（每个未配对核苷酸），则

$$
\begin{aligned}
V(i, j) &= \min\Bigl\{H(i, j),\ \min_{i<k<l<j}\bigl[I(i, j, k, l) + V(k, l)\bigr],\ \min_{i<u<j}\bigl[a + b + WM(i+1, u-1) + WM1(u, j-1)\bigr]\Bigr\},\\
WM1(i, j) &= \min_{l}\bigl[V(i, l) + b + c\,(j - l)\bigr],\\
WM(i, j) &= \min_{u}\min\bigl\{c\,(u - i) + WM1(u, j),\ WM(i, u-1) + WM1(u, j)\bigr\},\\
W(j) &= \min\Bigl\{W(j-1),\ \min_{i<j}\bigl[W(i-1) + V(i, j)\bigr]\Bigr\},
\end{aligned} \tag{16.1}
$$
按 $j - i$ 递增计算，当 $(i, j)$ 不能配对时 $V = \infty$。整条序列的最小自由能是 $W(n)$，通过回溯每个最小值由哪一项取得，可以恢复出结构。

**定理 16.2.1（复杂度）** 算法 16.2.1 的递推可在 $O(n^4)$ 时间和 $O(n^2)$ 内存中算出；把内部环限制为至多 $L$ 个未配对核苷酸（所有实现都取 $L = 30$），时间降为 $O(n^2L^2) = O(n^2)$（$L$ 固定），而多分支环与外部情形总共花费 $O(n^3)$，所以运行时间为 $O(n^3)$。

**证明** 每张表有 $O(n^2)$ 个元素。$V$ 的内部环情形要检查 $(i, j)$ 内部的所有对 $(k, l)$，每个元素 $O(n^2)$，总共 $O(n^4)$；两侧至多有 $L$ 个未配对核苷酸时，每个元素只有 $O(L^2)$ 个候选。$V$ 的多分支环情形，以及 $WM$、$WM1$ 与 $W$ 的两种情形，都在一个位置把区间分成两段，每个元素 $O(n)$，总共 $O(n^3)$。每张表有 $O(n^2)$ 个元素，即为内存。$\square$

每个结构必须恰好由递推中的一条路径生成，否则最小化仍然正确，但 16.2.3 的配分函数会把结构多算几次；这就是 $WM1$ 固定多分支环的第一个分支、$W$ 的外部情形按最后一个分支来写的原因。实现中还加入了一些在实际中很重要的改进：悬挂末端与末端错配，对末端 A–U 与 G–U 对的罚分，四核苷酸环与其他常见发夹的特殊能量，多分支环中螺旋的同轴堆叠，以及用仿射而不是线性的多分支环模型。Mfold、RNAfold（ViennaRNA 软件包）与 RNAstructure 都实现了这些。

### 16.2.2. 一个实现及其正确之处

**例 16.2.1（折叠 tRNA-Phe）** 我们用 numpy 以简化的模型实现了算法 16.2.1：Xia 等（1998）的 Watson–Crick 堆叠能量，所有涉及 G–U 对的堆叠取同一个值，对数形式的环罚分，末端 A–U 罚分与线性的多分支环项，没有悬挂末端、四核苷酸环奖励、同轴堆叠或修饰核苷酸。结果用对至多 $23$ 个核苷酸的随机序列的所有结构穷举来核对：最小能量与配分函数完全一致。对酵母 tRNA-Phe（$76$ nt），最小自由能结构有 $23$ 个碱基对，其中 $12$ 个是天然的：受体茎与反密码子茎都找到了，但 D 臂与 T 臂被一个长螺旋取代，按模型自身的单位相差 $-13$ kJ/mol（预测结构为 $-58.8$ kJ/mol，天然三叶草为 $-45.6$ kJ/mol）。灵敏度为 $12/21 = 57\,\%$。这个错误有物理原因，是任何二级结构模型都不包含的：三叶草由 L 形分子的三级相互作用与修饰核苷酸维系，能量模型看不到它们。

### 16.2.3. 系综

对一个会经历许多构象的分子，单个结构是很差的概括。在同样的递推中，以求和代替取最小值、以 Boltzmann 因子代替能量，就得到**配分函数** $Z$（McCaskill，1990；[7.6.15](/7.6.15#sec-15.6.3)），由它得出系综自由能 $-RT\ln Z$，再用外向递推或抽样得出每个碱基对的概率。

**算法 16.2.2（随机回溯）** 给定配分函数的各张表，像最小化那样回溯来生成结构，但每一步在各个选项中按其对相应表项的贡献成比例的概率来选择（Ding 与 Lawrence，2003）。这样生成的结构是从 **Boltzmann 分布**中精确的独立抽样；碱基对的概率用它在 $N$ 个样本中的频率估计，标准误至多为 $1/(2\sqrt{N})$。

**例 16.2.2** 对例 16.2.1 模型中的 tRNA-Phe，系综自由能是 $-64.3$ kJ/mol，而单个最佳结构为 $-58.8$，所以最小自由能结构只占系综的 $\exp(-5.5/RT) = 12\,\%$。在 $1000$ 个抽样结构中，受体茎的碱基对出现的概率为 $0.89$ 到 $0.97$，反密码子茎的为 $0.70$ 到 $0.74$，而天然 T 茎的碱基对出现的概率为 $0.05$，D 茎的则从未出现。所以这些概率不需要知道答案，就能正确地说明预测的哪些部分可信：几乎在每个抽样结构中都出现的螺旋是可靠的预测，而模型出错的区域恰好也是它没有把握的区域。

碱基对概率是最大期望准确度结构的输入，该结构使 $\sum_{(i,j) \in S}2\gamma P_{ij} + \sum_{i \text{ 未配对}}q_i$ 最大（$q_i$ 为 $i$ 未配对的概率，$\gamma$ 为权重），用同类的动态规划求出，通常比最小自由能结构稍准确一些。它们还给出一段序列未配对的概率，这决定了它对**微 RNA**、核糖体或反义寡核苷酸的可及性（16.6）。其他系综量也由 $Z$ 得出：系综多样性（两个抽样结构之间的平均碱基对距离）、由几个温度下的 $Z$ 得到的熔解曲线，以及给定结构相对于系综的能量。


```python
import RNA                                     # the ViennaRNA Python interface

```

准确度随长度下降：单序列预测对几百个核苷酸的 RNA，大约恢复 $70\,\%$ 的碱基对，对几千个核苷酸的 RNA 则低得多，部分是因为误差累积，部分是因为长 RNA 在转录的同时折叠，并与蛋白质结合（[7.6.16](/7.6.16#sec-16.7.5)）。常用三种补救办法，它们是后面几节的主题：实验约束、比较分析与学习模型。

## 16.3. 作为约束的化学探测

化学探测测量溶液中或细胞内 RNA 的每个核苷酸的可及性或柔性。在 SHAPE 化学（引物延伸分析的选择性 $2'$-羟基酰化）中，试剂酰化构象柔性的核苷酸的 $2'$-OH，这些核苷酸大多是未配对的；硫酸二甲酯使未配对的 A 与 C 甲基化。加合物通过逆转录读出：酶在加合物处停止，或者在突变谱变体（SHAPE-MaP、DMS-MaPseq）中写入一个错配，所以测序读段中某个位置的错配率，与未处理的对照相比，度量它的反应性。同样的读出方法也用于细胞内的结构探测与 RNA 结合蛋白的足迹（[7.9.4](/7.9.4)）。

**公式 16.3.1（伪能量约束）** 归一化的反应性 $S_i$ 被转换为伪能量，加到每个含核苷酸 $i$ 的堆叠对上：

$$
\Delta G_i = m\ln(S_i + 1) + b, \tag{16.2}
$$
其中 $m > 0$，$b < 0$（Deigan 等，2009；对 $37\,^\circ\mathrm{C}$ 的 SHAPE 数据，$m = 2.6$、$b = -0.8$ kcal/mol，即 $10.9$ 与 $-3.3$ kJ/mol）。反应性为零的核苷酸在配对时得到奖励 $b$，反应性高的则受到按对数增长的罚分；没有任何东西被禁止，所以数据使折叠产生偏向，而不是绝对地约束它。

**例 16.3.1** 我们为 tRNA-Phe 模拟了反应性：三叶草中已配对的核苷酸取均值为 $0.2$ 的指数分布变量，未配对的取均值为 $1.0$ 的，并用式 (16.2) 折叠。灵敏度从没有数据时的 $57\,\%$ 升到有数据时的 $99\,\%$，在 $12$ 条模拟谱中有 $10$ 条恢复出精确的三叶草。真实的探测数据没有这么干净，因为三级接触与堆叠保护了许多环中的核苷酸：当有一部分未配对核苷酸改从受保护的分布抽取时，受保护 $40\,\%$ 时平均灵敏度降到 $85\,\%$，$60\,\%$ 时为 $76\,\%$，$80\,\%$ 时为 $54\,\%$，不比只用序列好。所以探测数据的用处取决于试剂对手头这个分子中配对与未配对核苷酸的区分有多特异。

![作为折叠约束的化学探测数据（模拟的反应性，tRNA-Phe，例 16.2.1 的模型）。A：一条有 20 % 环核苷酸受保护的模拟谱；柱按天然配对状态着色。B：没有数据（虚线）与有数据时恢复的天然碱基对的比例，为 12 条模拟谱的均值与第 10 至第 90 百分位数，横轴是受保护的环核苷酸的比例。能干净区分配对与未配对核苷酸的数据几乎决定了结构；许多未配对核苷酸受保护的数据则没有增益](./plots/shape-constraints.py)

探测数据也可以不经过折叠而使用：细胞内与体外测得的反应性之差，可以定位蛋白质结合与共转录折叠；不同条件之间的差，可以定位**核糖开关**的重排；反应性模式本身也是学习模型的特征。

## 16.4. 文法与协方差模型

### 16.4.1. 随机上下文无关文法

16.2 的递推有一个形式上的对应物。嵌套结构恰好是**上下文无关文法**生成的（[4.8.2](/4.8.2#sec-2.1)），其中有一条规则一次发出两个相关的字母。

**定义 16.4.1（RNA 的随机上下文无关文法）** 随机上下文无关文法（stochastic context-free grammar）是这样的上下文无关文法：非终结符的每个产生式都带有概率，每个非终结符的各产生式的概率之和为一；一个推导的概率是所用产生式的概率之积，序列的概率是对其所有推导求和。对 RNA，最简单的文法是

$$
S \to aSb \mid aS \mid Sa \mid SS \mid \varepsilon,
$$
其中 $aSb$ 发出一个碱基对，$aS$ 与 $Sa$ 发出一个未配对的核苷酸，$SS$ 把序列分成两段；序列的一个推导对应一个二级结构。

给定序列的最可能推导由 **CYK 算法**（[4.8.8](/4.8.8#sec-8.5)）求得，它与算法 16.2.1 是同一个动态规划，只是以 $-\log$ 概率代替能量：概率模型与能量模型的对应关系是 $p \propto \mathrm{e}^{-\Delta G/RT}$。对推导求和而不是取最大，得到内向算法，即文法的配分函数；内向–外向算法计算每个碱基对的后验概率，并用 **EM 算法**（[3.5.6](/3.5.6)）训练产生式的概率，恰如前向–后向与 Baum–Welch 算法之于隐 Markov 模型（[4.6.8](/4.6.8)）。隐 Markov 模型是随机的*正则*文法；升级到上下文无关文法，换来了描述嵌套配对的能力，代价是每条序列的时间从 $O(n)$ 变为 $O(n^3)$。

### 16.4.2. 协方差模型

轮廓隐 Markov 模型逐列描述一个序列家族（[7.8.5](/7.8.5#sec-5.5)）。协方差模型（covariance model；Eddy 与 Durbin，1994）对二级结构保守的家族做同样的事：它是一个随机上下文无关文法，其非终结符沿着共有结构排列，每个共有位置或碱基对一个状态。

**定义 16.4.2（协方差模型）** RNA 家族的**协方差模型**是由结构比对构建的随机上下文无关文法，它有两种匹配状态——发出两个核苷酸、对 $16$ 种组合有联合分布的配对状态，和发出一个核苷酸、对 $4$ 种有分布的单状态——以及与轮廓隐 Markov 模型相同的插入与缺失状态，它们沿着遵循共有结构的引导树排列。

配对状态把两列联合打分，这就是协方差模型与轮廓的区别：G–C 对被 A–U 取代时仍保持高分，而把两列独立处理的轮廓则损失两次。Rfam（Kalvari 等）就建立在这套机制上：每个家族有带共有结构的种子比对，由 `cmbuild` 据此构建的协方差模型，校准过的得分阈值，以及序列数据库中所有命中的完整比对。用协方差模型搜索基因组（Infernal 软件包中的 `cmsearch`）的代价比轮廓搜索大得多，Infernal 1.1 通过一系列过滤使之可行：先由只含序列的轮廓隐 Markov 模型丢弃基因组的大部分，只有幸存者才用完整的模型打分。

```bash
cmbuild trna.cm trna-seed.sto        # build a covariance model from a structural alignment
cmcalibrate trna.cm                  # fit the score distribution for E-values
cmsearch --cut_ga trna.cm genome.fa  # search a genome; --cut_ga uses the curated threshold
cmscan --rfam --tblout hits.tbl Rfam.cm query.fa      # annotate a sequence with all Rfam families
```

专用的搜索可以比通用的家族模型做得更好：tRNAscan-SE 把对启动子元件与 tRNA 不变位置的快速扫描和协方差模型结合起来，是新基因组中 tRNA 基因的标准注释方法（[7.8.11](/7.8.11)）。

## 16.5. 比较分析

转运 RNA、核糖体 RNA 与核糖核酸酶 P 的 RNA 组分的二级结构，在任何晶体结构出现之前就已通过比较同源序列确立：在比对中，保守碱基对的两列一起变化，从 G–C 变为 A–U 或 C–G，同时保持互补。

**定义 16.5.1（补偿突变）** **补偿突变**（compensatory mutation）是 RNA 中两个位置上的一对替换，合起来保持碱基配对（G–C 变为 A–U）；与之相对的是一致突变，它用一个替换保持配对（G–C 变为 G–U），以及破坏配对的单个替换。同源序列之间补偿变化与一致变化的过量，是这两个位置配对的证据。

所用的统计量是两个比对列的**互信息**，与蛋白质中的**共进化**（[7.6.15](/7.6.15#sec-15.5.4)）相同，区别是碱基对把两个位置限制在互补的组合上，而不是物理化学上相容的组合上，所以信号强，所需序列数少。

**例 16.5.1（由比对得到三叶草）** Rfam 家族 RF00005 的种子比对包含来自所有生命域的 $954$ 条 tRNA 序列；限制在其 $71$ 个共有列后，按 $62\,\%$ 一致性下近邻数的倒数给序列加权（有效样本量为 $112$），我们计算了每对列的互信息，并作平均乘积校正，即减去由每列总体变异性解释的部分。得分最高的 $24$ 对中，$21$ 对是共有结构的碱基对，而共有结构的 $21$ 对中有 $20$ 对在得分最高的 $21$ 个之内：仅凭比对、不用任何能量模型就恢复了三叶草。不在共有结构中的得分最高的一对，即第 $18$ 列与第 $54$ 列，在 $723$ 条序列中是 G–C，$44$ 条中是 U–A，$21$ 条中是 A–U——这是在 L 形分子肘部连接 D 环与 T 环的共变三级配对——其次是第 $15$ 列与第 $46$ 列，在 $460$ 条序列中是 G–C，$323$ 条中是 A–U，即 Levitt 对。于是比较分析看到了二级结构模型看不到的相互作用，而这些相互作用正是例 16.2.1 中热力学预测失败的原因。

![转运 RNA 比对中的共变恢复三叶草。Rfam 家族 RF00005 的种子比对（954 条序列，71 个共有列），序列按 62 % 一致性下近邻数的倒数加权。A：每对列的校正互信息（下三角）对该家族的共有二级结构（上三角，每个茎一种颜色）。B：得分最高的 24 对列；除三对外都是共有的碱基对，例外是肘部的三级接触](./plots/covariation.py)

由此有两种用途。给定比对，同时折叠所有序列：RNAalifold 使对齐序列的折叠能量之和加上共变奖励最小，比折叠单条序列准确得多；Pfold 用随机上下文无关文法，并对配对与未配对位置采用系统发生的替换模型。给定结构，检验共变是否真实：相关序列不是独立的观测，所以两列可能仅仅因为序列有共同的祖先而共变。R-scape（Rivas 等，2017）在由比对的系统发生建立的零模型下，对每个碱基对计算共变统计量，并报告哪些对是显著的。把它用于已发表的长非编码 RNA 结构，发现许多根本没有显著的共变，这意味着所提出的结构只是预测，而不是证据；用于核糖体 RNA 与转运 RNA，则几乎确认了每个螺旋。若得不到比对，可以边折叠边比对来建立一个（Sankoff 算法，时间 $O(n^6)$，由 Foldalign、Dynalign 与 LocARNA 近似）。

## 16.6. RNA–RNA 相互作用与微 RNA 靶标

### 16.6.1. 杂交与可及性

两个相互配对的 RNA 提出同一个问题，只是有两条序列：反义寡核苷酸，细菌的小 RNA 及其信使，RNA 双链体的两条链。相互作用的能量有两部分：形成分子间螺旋所得到的能量，与为打开覆盖该位点的分子内结构而必须付出的能量。

**公式 16.6.1（含可及性的相互作用能量）** 对用到一个 RNA 的区域 $[i, j]$ 与另一个的 $[k, l]$ 的相互作用，

$$
\Delta G_{\mathrm{total}} = \Delta G_{\mathrm{hybrid}} + \Delta G_{\mathrm{open}}^{(1)}[i, j] + \Delta G_{\mathrm{open}}^{(2)}[k, l],
$$
其中打开能量由每个分子单独的配分函数算出，$\Delta G_{\mathrm{open}}[i, j] = -RT\ln\mathbb{P}([i, j] \text{ 未配对})$，它非负。RNAup 与 IntaRNA 对相互作用位点使这个和最小。

可及性通常比杂交能量更重要：完全互补、却藏在稳定发夹之内的位点不会被使用，而单链环中较短的位点则会。

### 16.6.2. 微 RNA 靶标预测

**微 RNA** 引导沉默复合体到与它配对的信使 RNA 上，配对规则异常简单：在多数功能位点中，微 RNA 的第 $2$ 到 $7$ 个核苷酸，即**种子序列**，必须完全配对，而 $3'$ 半段的配对除了在补偿位点以外贡献很小。因此靶标预测从精确匹配而不是折叠开始。

**定义 16.6.1（种子位点类型）** 对种子为第 $2$–$8$ 位核苷酸的微 RNA，靶标中的位点若匹配第 $2$–$7$ 位，则为 *6mer*；若匹配第 $2$–$7$ 位并且在第 $1$ 位核苷酸的对面是 A，则为 *7mer-A1*；若匹配第 $2$–$8$ 位，则为 *7mer-m8*；若匹配第 $2$–$8$ 位并且在第 $1$ 位核苷酸对面是 A，则为 *8mer*。它们的效力按 6mer < 7mer-A1 < 7mer-m8 < 8mer 的次序增加；第 $1$ 位对面的 A 是被 Argonaute 蛋白的一个口袋识别的，而不是与微 RNA 配对。

精确匹配的数目太多，单凭它们没有用处：给定的 7mer 在序列中偶然出现的频率约为每 $16$ kb 一次，所以转录组中每个微 RNA 有数万个匹配。因此预测器给每个位点的上下文打分。TargetScan 的上下文得分综合了位点类型、局部 AU 含量（AU 丰富的侧翼更有效，既因为位点更易与微 RNA 接触，又因为它们与调控性的 $3'$ 非翻译区相关）、在非翻译区中的位置（靠近两端、远离长区中心的位点更有效）、微 RNA $3'$ 半段的配对，以及跨物种的保守性——这是信息量最大的单个特征，因为在哺乳动物中保守的位点不太可能是偶然的（[7.8.8](/7.8.8#sec-8.6)）。

**例 16.6.1（HMGA2 中的 let-7 位点）** 人类 *HMGA2* 的 $3'$ 非翻译区在典型转录本中长 $2999$ nt，对 let-7a-5p 的种子含有一个 8mer、三个 7mer-m8 位点、三个 7mer-A1 位点与一个 6mer：有效类型的位点共七个，这就是 *HMGA2* 被 let-7 强烈抑制的原因，也是截短这个非翻译区的染色体重排会消除这种抑制、并促成间充质肿瘤的原因（[7.4.15](/7.4.15)）。每个位点两侧 $30$ nt 的 AU 含量在 $0.48$ 到 $0.70$ 之间，整个区域为 $0.64$，所以上下文有利于三个 7mer-A1 位点而不利于 8mer，提醒我们仅凭位点类型无法给位点排序。这类预测通过转染或删除微 RNA 后测量转录本与蛋白质来检验，吻合程度一般：单个位点通常使其靶标的水平改变百分之几十。

![微 RNA let-7 在人类 HMGA2 的 3' 非翻译区（2999 nt，Ensembl 典型转录本）中的靶位点。A：8mer 位点与 let-7a-5p 的配对；第 2 至 8 位核苷酸与靶标配对，靶标的 A 位于第 1 位核苷酸对面，由 Argonaute 的口袋识别而不配对。B：所有种子位点沿非翻译区的位置，按类型区分。C：每个位点两侧各 30 nt 的 AU 含量（效力的决定因素）对整个区域的 AU 含量（虚线）](./plots/mirna-sites.py)

不遵循这些规则的位点也存在：带凸起的非经典位点，编码区中的位点，以及种子错配但 $3'$ 半段广泛配对的位点。捕获 Argonaute 及其靶标的交联方法（CLIP 及其嵌合变体，[7.9.4](/7.9.4)）直接测量这些位点，结果表明多数功能位点是经典的，而许多经典匹配从未被结合。微 RNA 在细胞中实际控制哪些信使，以及这对网络有什么影响，属于 [7.9](/7.9)。

## 16.7. RNA 结构的学习模型

在已知结构上训练的网络，把二级结构预测成配对概率的矩阵：SPOT-RNA（Singh 等，2019）使用残差层与循环层，能预测假结与非经典碱基对，而热力学模型在构造上就排除了它们；UFold 等把问题当作对所有可能配对的 $L \times L$ 表示作图像分割；MXfold2 用热力学参数约束一个学习模型。在训练数据中出现过的家族内，这些模型以很大的优势胜过能量最小化；在留出的家族上，若干研究发现这种优势基本消失（Flamm 等，2022；Szikszai 等，2022），这与 [7.8.15](/7.8.15#sec-15.6.1) 描述的是同一种同源泄漏：标准基准在训练集与测试集中都包含这些家族，所以度量的是对已知结构的回忆。按家族划分的评估，以及保留物理并只学习修正的混合方法，是目前的标准。

三级结构比蛋白质更难，因为已知的 RNA 结构少得多：蛋白质数据库含有二十多万个蛋白质结构，而 RNA 只有几千个。片段组装（FARFAR2）、带统计势的粗粒化模型（SimRNA）与深度网络（trRosettaRNA、DRfold，AlphaFold 3 与 RoseTTAFold All-Atom 的 RNA 模式）对折叠有较好代表的小 RNA 能给出有用的模型，对大 RNA 与没有同源物的折叠则失败，盲测的 RNA-Puzzles 与 CASP15 的 RNA 类别都表明了这一点。其物理原因——二级结构的主导地位、$\ce{Mg^2+}$ 离子的作用、连接处的柔性——在 [7.6.15](/7.6.15#sec-15.6.4) 与 [7.6.16](/7.6.16#sec-16.7) 中讨论。

## 思考题

1. 字符串 `((..((...))..)).((...))` 对与其等长的序列是不是有效的点括号结构？结构 `((..[[..))..]]` 表示什么？

   **答** 第一个是有效的：括号平衡且嵌套，每个发夹环至少有三个未配对核苷酸（三个与三个），两个外侧螺旋不重叠。第二个用了第二种括号，因为它的碱基对交叉——用圆括号写的碱基对所跨的位置，被用方括号写的碱基对进入又离开——所以它是假结，超出了定义 16.1.1 与 16.2 的算法所处理的范围。检验有效性是一次栈遍历：遇到左括号入栈，遇到右括号出栈，当且仅当一个栈就够用时结构是嵌套的。

2. 算法 16.2.1 为什么需要两张多分支环的表 $WM$ 与 $WM1$ 而不是一张？分别给出适用于最小化与适用于配分函数的回答。

   **答** $WM1$ 要求分支恰好从 $i$ 开始，所以多分支环被分解为“直到最后一个分支之前的全部”加“最后一个分支及其后的未配对核苷酸”，每种分支排布恰好以一种方式产生。对最小化，冗余的分解仍给出正确的最小值，但回溯会有歧义，每个分支项与每个未配对项可能被不一致地计算。对配分函数，冗余是致命的：$Z$ 是对结构求和，所以由两条不同路径生成的结构被计算两次，概率就错了，随机回溯也不再对 Boltzmann 分布抽样。这与随机文法中无歧义性的要求相同（16.4.1）。

3. 用 $O(n^3)$ 的实现折叠 $200$ 个核苷酸的序列需要 $0.2$ s。估计 $2000$ 与 $20\,000$ 个核苷酸所需的时间，并给出后一种情形下四张双精度数表所需的内存。

   **答** 三次方的标度使长度每增大十倍，时间乘以 $10^3 = 1000$：$2000$ nt 约需 $200$ s，$20\,000$ nt 约需 $2\times10^5$ s，即两天多。内存按 $n^2$ 增长：四张各有 $20\,000^2$ 个元素、每个 $8$ 字节的表，共 $4 \times 4\times10^8 \times 8 = 1.3\times10^{10}$ 字节，约 $13$ GB，所以程序只存储上三角，或用单精度，或在一两千碱基的重叠窗口中折叠长 RNA。

4. 在例 16.2.2 的系综中（$Z$ 已知，$-RT\ln Z = -64.3$ kJ/mol），一个能量比最小值 $-58.8$ kJ/mol 高 $4$ kJ/mol 的特定结构的概率是多少？这对报告单个结构说明了什么？

   **答** $\mathbb{P} = \mathrm{e}^{-(\Delta G - \Delta G_{\mathrm{ens}})/RT}$，$37\,^\circ\mathrm{C}$ 时 $RT = 2.58$ kJ/mol：对 $\Delta G = -54.8$，$\mathbb{P} = \mathrm{e}^{-9.5/2.58} = 2.5\,\%$，而最小值是 $12\,\%$。差 $4$ kJ/mol 的结构只是概率低五倍，而参数本身的不确定度就超过这个数，所以单个最佳结构只是许多相当的结构之一；诚实的输出是碱基对概率或一组样本，并且只应在概率集中的地方信任预测。

5. 用式 (16.2)（$m = 10.9$，$b = -3.3$ kJ/mol）把反应性 $S = 0$、$0.3$ 与 $2.0$ 转换为伪能量，并说明各自对螺旋有什么作用。

   **答** $\Delta G = -3.3$，$10.9\ln1.3 - 3.3 = -0.44$，$10.9\ln3 - 3.3 = +8.67$ kJ/mol。无反应性的核苷酸给含它的每个堆叠对 $3.3$ kJ/mol 的奖励，所以一个五对的螺旋，若各处核苷酸都无反应性，就得到约 $33$ kJ/mol（每个堆叠含两个核苷酸）——足以推翻基于序列的预测。中等反应性的核苷酸几乎是中性的，高反应性的则每个堆叠花费 $8.7$ kJ/mol，通常能阻止配对而并不禁止它；所以单个错误的测量使预测弯曲而不会使它崩溃。

6. 针对一个未配对概率为 $0.05$ 的靶位点设计反义寡核苷酸。在 $37\,^\circ\mathrm{C}$ 时，打开结构要花掉多少结合能？应如何选择位点？

   **答** $\Delta G_{\mathrm{open}} = -RT\ln0.05 = 2.58 \times 3.0 = 7.7$ kJ/mol，约 $1.8$ kcal/mol，抵消了大约两个碱基对带来的收益。应当根据配分函数预测的未配对概率来选位点，而不只是依据互补性：$\mathbb{P} = 0.8$ 的位点只花费 $0.6$ kJ/mol。由于长 RNA 只能近似地折叠，应当在窗口中计算概率并对照探测数据检查，并检验几个候选位点。

7. 一个含 $400$ 条序列的比对中有两列强烈共变，但序列分成两个分支，在每个分支内这两列都不变。问题在哪里？R-scape 怎样处理它？

   **答** 表面的共变来自一个分支的共同祖先中的一次替换事件，而不是 $400$ 个独立的观测；序列因共同祖先而相关，所以有效样本量是树上独立变化的数目，这里是一。按序列独立计算的互信息于是被严重夸大——这与例 16.5.1 中需要对序列加权的系统发生夸大是同一回事。R-scape 从比对本身的系统发生，沿树按无配对的替换模型模拟序列，估计共变统计量的零分布，并且只有当某对的统计量超过仅由树产生的程度时才报告它，这同时也控制了被检验的众多碱基对。

8. 对给定种子的微 RNA，在 $3$ kb 的 $3'$ 非翻译区中偶然出现的 7mer-m8 匹配的期望数是多少？在含 $3.5\times10^7$ 个这类区域核苷酸的转录组中呢？这对预测意味着什么？

   **答** 在均匀模型下，特定的 $7$-mer 在每个位置的概率为 $4^{-7} = 1/16\,384$，所以一个区域中期望有 $3000/16\,384 = 0.18$ 个匹配，整个转录组中有 $3.5\times10^7/16\,384 = 2100$ 个；6mer 匹配的频率高四倍，约 $8500$ 个。由于一个微 RNA 可测地抑制的信使约为几百个，多数匹配一定是无功能的，预测器不能只依靠匹配：需要跨物种的保守性、位点类型、AU 上下文与位置，以及结合的直接证据，与转录因子基序的情形完全一样（[7.8.8](/7.8.8#sec-8.3.1)）。碱基组成也有影响：AU 丰富的非翻译区中，AU 丰富的种子的匹配比均匀估计所示的多。

9. （设计）有人提出一条 $2$ kb 的新长非编码 RNA 通过保守结构起作用。用本章的方法设计一项分析来支持或反驳这个说法。

   **答** 先通过在近缘基因组中作序列搜索（[7.8.4](/7.8.4)）收集同源物并建立比对；若同源物只在近亲中能检出，总枝长可能太小，共变没有信息，必须说明这一点。用配分函数在重叠窗口中折叠序列，并报告碱基对概率而不是单个结构，因为 $2$ kb 超出了最小自由能结构可靠的长度。用 RNAalifold 折叠比对，并用 R-scape 检验每个所提出的螺旋：显著的共变是最强的证据，而在较深的比对中没有共变则是反对保守结构的证据。用 SHAPE-MaP 在体外与细胞内探测 RNA，并以反应性作伪能量重新折叠（公式 16.3.1），检查在声称有结构的地方，细胞内与体外的谱是否一致。把折叠能量与保持二核苷酸组成的打乱序列比较，这是一个较弱但标准的对照。最后检验功能：突变所提出的螺旋的一侧以及互补的另一侧，表明单突变体丧失功能，而双突变体恢复功能——这是补偿突变的实验对应。

10. （开放）为什么 RNA 二级结构的深度学习预测器在标准基准上胜过热力学折叠，在新家族上却不行？怎样比较才公平？

    **答** 标准基准由已知结构构建，它们由少数家族（转运 RNA、核糖体 RNA、I 类内含子、核糖开关）主导，这些家族的成员同时出现在训练集与测试集中；容量足够的网络可以学到家族而不是折叠规则，而由序列识别一个家族，比折叠它容易得多（[7.8.15](/7.8.15#sec-15.6.1) 的泄漏）。热力学模型由对短双链体的熔解实验拟合，没有这种优势，也没有这种泄漏。公平的比较应当按家族或 Rfam 的簇划分，分别报告在训练中见过与没见过的家族上的准确度，并包含一个最近邻基线，它只是复制最相似的训练序列的结构——若学习模型在留出的家族上胜不过这个基线，它学到的就是回忆而不是折叠。泛化更好的方法要么保留物理，只学习对参数的修正，要么在根本不是结构的数据上训练，例如来自许多转录本的探测谱，这类数据量大，而且并不集中在少数几个家族。
