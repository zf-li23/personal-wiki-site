前面各章的模型用少数明确的假设描述序列：位置权重矩阵把位点的各位置看作相互独立（[7.8.8](/7.8.8)），隐 Markov 模型让下一个状态只依赖当前状态（[7.8.7](/7.8.7)），轮廓独立地给家族的每一列打分（[7.8.5](/7.8.5)）。约从 2015 年起，假设少得多的模型被拟合到测序产生的大规模数据上：数百万条染色质谱、结合测量、剪接位点与蛋白质序列。这些模型是深度神经网络，在若干领域已成为标杆，包括突变对剪接的影响、一段 DNA 的染色质与表达信号，以及蛋白质的结构。本章讲这类网络如何读取序列、学到了什么以及如何看出来，蛋白质与基因组的预训练语言模型，变异效应的预测，使已发表的准确度不可靠的方法学陷阱，以及 [7.2.24](/7.2.24) 与 [7.8.10](/7.8.10#sec-10.6) 中预告的一项应用：CRISPR 向导的设计。一般理论不在这里重复：多层网络与**反向传播**见 [4.7.2](/4.7.2)，卷积网络见 [4.7.3](/4.7.3)，注意力与 Transformer 见 [4.7.6](/4.7.6)，预训练见 [4.7.7](/4.7.7)，评估见 [4.6.2](/4.6.2)。RNA 结构由 [7.8.16](/7.8.16) 的动态规划预测，蛋白质结构（学习方法取得最大成功之处）见 [7.8.17](/7.8.17) 与 [7.6.15](/7.6.15#sec-15.5.5)。贯穿全章的例子是 [7.8.8](/7.8.8) 中 CTCF 的结合基序：先让一个小网络把它发现出来，再问它是看了哪里。

## 15.1. 作为输入的序列

### 15.1.1. 编码与任务

网络对向量进行计算，所以序列必须编码。DNA 的标准编码是**独热向量**（[7.8.7](/7.8.7#sec-7.6)）：位置 $i$ 上的碱基 $b$ 成为 $L \times 4$ 二值矩阵 $X$ 的第 $i$ 行，仅第 $b$ 列为 $1$；蛋白质用 $L \times 20$，加上未知符号则为 $21$。这种编码不损失信息，也不强加字母之间的相似性，让网络自己去学习哪些字母行为相近。语言模型则把序列切分为词元：单个残基、重叠或不重叠的 $k$-mer，或者由**字节对编码**（[4.7.5](/4.7.5#sec-5.7.2)）找出的变长单元，并把每个词元映射为一个学得的向量。

**定义 15.1.1（序列到功能模型）** **序列到功能模型**是一个参数化函数 $f_{\boldsymbol{\theta}}$，它把序列 $x$ 或其编码 $X$ 映射为分子或基因座的可测性质：一个标量（结合与否、是否剪接位点），一个跨检测与细胞类型的向量，一条沿序列的谱（某种分辨率下的覆盖度轨迹），或另一条序列。其参数通过在训练对 $(x_n, \boldsymbol{y}_n)$ 上最小化损失来估计，通常用随机梯度下降。

输出决定损失：类别用**交叉熵损失**，读段计数用 Poisson 或多项对数似然，变换后的信号用平方误差。目标是测量值时为监督学习；目标是输入自身的一部分时为自监督学习，如 15.4 的语言模型。

### 15.1.2. 作为可学习权重矩阵的卷积

多数序列网络的第一层是一维卷积（[4.7.3](/4.7.3#sec-3.2.2)）：宽为 $w$、带偏置 $c$ 的滤波器 $F \in \mathbb{R}^{w \times 4}$ 沿序列滑动，在位置 $p$ 处产生

$$
a_p = c + \sum_{j=1}^{w}\sum_{b}F_{jb}X_{p+j-1,b} = c + \sum_{j=1}^{w}F_{j,x_{p+j-1}}. \tag{15.1}
$$

**定理 15.1.1（卷积与权重矩阵）** 在独热编码的 DNA 上，宽度为 $w$ 的卷积滤波器在每个位置计算一个长度为 $w$ 的权重矩阵的得分再加一个常数。反过来，每个**位置权重矩阵** $W_{jb} = \log(p_{jb}/q_b)$ 都是这样的滤波器，取 $F = W$，$c = 0$。滤波器之后接全局**最大池化**，返回序列中最佳位点的得分；接 $\log\sum_p\exp(a_p)$，则返回（相差一个加性常数）在均匀分布的位置上含一个位点的基序模型的对数似然比。

**证明** 由于 $X_{ib} = \boldsymbol{1}[x_i = b]$，式 (15.1) 的内层求和在每一行选出一个元素 $F_{j,x_{p+j-1}}$，这就是从 $p$ 开始的窗口的权重矩阵得分（[7.8.8](/7.8.8#sec-8.2.1)）；偏置加上一个常数。最大池化取这些得分中的最大者。若 $F = W$ 以自然对数为单位，则 $\exp(a_p)$ 是位点在 $p$ 处相对于背景的似然比，所以在 $M$ 个窗口上的平均值是 [7.8.8](/7.8.8#sec-8.4.3) 的“每条序列出现一次”模型的似然比，其对数与 $\log\sum_p\exp(a_p)$ 相差 $\log M$。$\square$

与权重矩阵不同的是各元素的来源。矩阵由对齐的位点计数得到；滤波器则由带标签的序列通过反向传播学得，事先并不告诉它位点在哪里、是什么样子，并且许多滤波器与其上的各层一起学习，这些层把它们组合成单个矩阵表达不了的规则：偏好特定间距与取向的位点对、阻遏位点的缺失、周围的碱基组成。有了整流线性单元、池化与更多的层，网络就成为学得的、分层的、非线性的基序及其排布的扫描器。

## 15.2. 调控序列的卷积网络

### 15.2.1. 一个最小的网络

**算法 15.2.1（训练卷积基序分类器）** 输入：长为 $L$ 的独热序列 $X_n$ 及标签 $y_n \in \{0, 1\}$。

1. 模型：$K$ 个宽为 $w$ 的滤波器 $F_k$，偏置为 $c_k$；激活值 $a_{kp}$ 由式 (15.1) 给出；池化特征 $h_k = \max_p\max(a_{kp}, 0)$；logit $z = v_0 + \sum_kv_kh_k$，概率为 $\sigma(z)$。
2. 损失：$\ell = -\frac{1}{N}\sum_n[y_n\log\sigma(z_n) + (1 - y_n)\log(1 - \sigma(z_n))] + \frac{\lambda}{2}(\|F\|^2 + \|\boldsymbol{v}\|^2)$。
3. 用反向传播求梯度：$\partial\ell/\partial z_n = (\sigma(z_n) - y_n)/N$，$\partial z/\partial h_k = v_k$；$h_k$ 的梯度只传到取得最大值的窗口 $p^*_k$，并且仅当 $a_{kp^*_k} > 0$ 时才传，其中 $\partial a_{kp}/\partial F_{k,jb} = X_{p+j-1,b}$。
4. 用小批量随机梯度下降或 Adam（[4.7.4](/4.7.4#sec-4.3.3)）更新所有参数，训练若干轮，保留验证损失最小的参数。

一轮训练的代价是 $O(NLKw)$ 次运算，即用 $K$ 个矩阵扫描训练集的代价。

**例 15.2.1（重新发现 CTCF 基序）** 我们模拟了 $7000$ 条长 $120$ bp、碱基频率取人类值的随机序列，并在其中一半序列里的随机位置、随机链上放入一个从 [7.8.8](/7.8.8) 的 CTCF 矩阵抽样得到的位点。一个有 $8$ 个宽为 $24$ 的滤波器（$785$ 个参数）的网络，按算法 15.2.1 用 numpy 写成，在其中 $4000$ 条上训练 $15$ 轮。验证集 AUROC 从第一轮后的 $0.977$ 升到 $0.988$；训练损失持续下降，从 $0.38$ 降到 $0.075$，而验证损失在大约十轮后不再改善（约 $0.14$），这是**过拟合**的开始。在 $2000$ 条测试序列上，AUROC 为 $0.988$，准确率为 $94.1\,\%$。这里可能的最好分类器是在两条链上扫描真实矩阵，AUROC 可达 $0.998$：剩下的错误是所放入的位点恰好较弱的序列。输出权重最大的两个滤波器，用验证集中使其激活超过最大值一半的窗口转换为频率矩阵，分别是 CTCF 基序及其反向互补，与所放入的频率的相关系数为 $0.96$ 与 $0.97$——它们是在从未被展示过位点的情况下学得的。

![一个小卷积网络从带标签的序列中学习结合基序（模拟数据）。序列长 120 bp，碱基频率取人类值，其中一半在随机链上带有一个从 CTCF 矩阵抽样得到的位点；分类器为一个含 8 个宽 24 的滤波器的卷积层，加 ReLU、全局最大池化与逻辑输出，用 Adam 在 4000 条序列上训练（算法 15.2.1）。A：训练与验证损失及验证 AUROC 随轮数的变化；验证损失在约十轮后不再改善。B：所放入的矩阵的序列标识图。C、D：输出权重最大的两个滤波器，表示为使其激活超过最大值一半的验证窗口的频率矩阵，与所放入的基序对齐（C 是其反向互补，前几个位置落在滤波器之外）；它们与所放入频率的相关系数为 0.97 与 0.96](./plots/cnn-motif.py)

这类模型通常用带自动微分的框架编写。例 15.2.1 的网络用 PyTorch 写成

```python
import torch
import torch.nn as nn


class MotifCNN(nn.Module):
    def __init__(self, n_filters=8, width=24):
        super().__init__()
        self.conv = nn.Conv1d(4, n_filters, kernel_size=width)   # input: batch x 4 x L, one-hot
        self.out = nn.Linear(n_filters, 1)

    def forward(self, x):
        h = torch.relu(self.conv(x)).amax(dim=2)                 # global max pooling over positions
        return self.out(h).squeeze(1)                            # logit


model = MotifCNN()
opt = torch.optim.AdamW(model.parameters(), lr=1e-2, weight_decay=1e-3)
loss_fn = nn.BCEWithLogitsLoss()
for epoch in range(15):
    for x, y in train_loader:                                    # x: float tensor, y: 0/1 labels
        opt.zero_grad()
        loss_fn(model(x), y.float()).backward()
        opt.step()
```

### 15.2.2. 从标签到谱

最早的调控 DNA 深度模型对短序列分类。DeepBind（Alipanahi 等，2015）对每种蛋白质，用来自蛋白质结合芯片、HT-SELEX 与 ChIP-seq 的结合数据训练一个小网络。DeepSEA（Zhou 与 Troyanskaya，2015）读取 $1000$ bp，同时对中间的 $200$ bp 预测 $919$ 个二值染色质特征（来自 ENCODE 与 Roadmap 的转录因子 ChIP-seq、DNase I 与组蛋白修饰）；Basset（Kelley 等，2016）预测 $600$ bp 序列在 $164$ 种细胞类型中的可及性。联合预测多个输出，使所有任务共享第一层的基序检测器；两个等位基因之间预测特征的差，成为最早的全基因组调控变异评分之一。

分类器舍弃了信号的形状，后来的模型则预测谱。Basenji（Kelley 等，2018）读取 $131\,072$ bp，以 $128$ bp 为一格预测数千种检测的覆盖度；BPNet（Avsec 等，2021）由 $1$ kb 预测多能性因子 Oct4、Sox2、Nanog 与 Klf4 的单碱基分辨率 ChIP-nexus 谱，并由此读出基序间距的规则；Enformer（Avsec 等，2021）加入**自注意力**层（[4.7.6](/4.7.6)），读取 $196\,608$ bp，并在 $896$ 格中预测 $5313$ 条人类轨迹，使得约 $100$ kb 以外的增强子也能影响基因的预测表达；Borzoi（Linder 等，2025）读取 $524$ kb，以 $32$ bp 分辨率预测 RNA-seq 覆盖度，使剪接与多聚腺苷酸化清晰可见。对于剪接，SpliceAI（Jaganathan 等，2019）由 $10$ kb 的上下文预测每个位置是供体、受体还是都不是，两个等位基因之间这些概率的变化用来解释产生或破坏剪接位点的变异（[7.8.12](/7.8.12#sec-12.8.2)）。

![已发表的调控 DNA 序列到功能模型的输入长度与输出分辨率（数值取自原始文献）。输入是模型一次预测所读取的序列；输出分辨率是一个预测值所概括的序列长度。虚线对角线上的点表示每个输入作一次预测；远低于它的点沿输入预测一条谱。2015 年以来，输入越来越长，以捕捉远端调控；输出越来越精细，以捕捉结合、剪接与转录信号的形状](./plots/model-scales.py)

长输入只有在网络能把相距很远的位置联系起来时才有用。在卷积的堆叠中，输出依赖于随深度增长的窗口，即**感受野**（[4.7.3](/4.7.3#sec-3.4.2)）。

**公式 15.2.1（空洞卷积的感受野）** 由核宽为 $k$、空洞率为 $d_1, \dots, d_m$（抽头相隔 $d_\ell$ 个位置）的卷积堆叠而成的网络，其感受野是

$$
R = 1 + (k - 1)\sum_{\ell=1}^{m}d_\ell
$$
个输入位置；当 $d_\ell = 2^{\ell-1}$ 时，$R = 1 + (k - 1)(2^m - 1)$，随深度呈指数增长，而参数数目只线性增长。

**例 15.2.2** 宽为 $3$ 的无空洞卷积给出 $R = 2m + 1$，所以要覆盖 $4095$ 个位置需要 $2047$ 层。取空洞率 $1, 2, \dots, 2^{10}$，十一层即可达到 $R = 1 + 2(2^{11} - 1) = 4095$ 个位置；若用于已经按 $128$ bp 池化成格的序列，覆盖 $524\,160$ bp，这就是 Basenji 看到输入的方式。注意力在一层中把每个位置与其他每个位置相连，代价与位置数的平方成正比；Enformer 通过在 $1536$ 个 $128$ bp 的格之间而不是碱基之间做注意力来控制代价（$1536 \times 128 = 196\,608$）。

深度学习以同样的形式进入了本课程的其他部分。DeepVariant 把读段堆叠的图像分类为基因型（[7.8.12](/7.8.12#sec-12.2.3)）；Helixer 与 Tiberius 等基因发现程序把每个碱基标记为编码、内含子或基因间区，有时再叠加一个隐 Markov 模型来保证基因结构有效（[7.8.7](/7.8.7)）；碱基识别器把纳米孔电流翻译为碱基（[7.8.9](/7.8.9)）。每一种都用学得的模型取代手工构造的概率模型，并且都要求训练数据涵盖它将遇到的情形。

## 15.3. 看清模型学到了什么

预测良好的网络是有用的；其理由可以读出来的网络还是发现的工具。归因方法给每个输入位置一个数，度量它对输出的贡献。

**定义 15.3.1（in silico 饱和突变）** 序列 $x$ 在模型 $f$ 下的 **in silico 饱和突变**，对每个位置 $i$ 与每个替代残基 $b \ne x_i$，计算该单个替换的预测效应 $\Delta_{ib} = f(x^{(i \to b)}) - f(x)$。矩阵 $(\Delta_{ib})$ 是饱和突变实验的计算对应物，对 $b$ 取平均就是位置 $i$ 的重要性。

对长为 $L$ 的 DNA，这种方法需要 $3L$ 次模型评估：对小模型代价低，对 Enformer 一类的大模型代价高。梯度方法只需一次反向传播。梯度 $\partial f/\partial X_{ib}$ 是显著性图；*梯度 × 输入*只保留所观测碱基的那一项 $X_{ix_i}\,\partial f/\partial X_{ix_i}$。由于线性化只是局部的，通常有两种改进：DeepLIFT（Shrikumar 等，2017）用修改后的规则从参考输入传播差值；积分梯度（Sundararajan 等，2017）则沿从参考输入 $X'$（打乱的序列或背景序列）到 $X$ 的路径平均梯度，

$$
\operatorname{IG}_{ib} = (X_{ib} - X'_{ib})\int_0^1\frac{\partial f}{\partial X_{ib}}\bigl(X' + \alpha(X - X')\bigr)\,\mathrm{d}\alpha, \qquad \sum_{i,b}\operatorname{IG}_{ib} = f(X) - f(X'),
$$
其中第二个等式由沿路径的微积分基本定理得出。

**例 15.3.1** 对例 15.2.1 中的一条测试序列，所放入的位点给出的预测概率为 $0.996$。饱和突变表明网络依赖这个位点：总绝对重要性的 $73\,\%$ 落在它的 $19$ bp 内，最重要的五个位置是基序的位置 $4$、$5$、$10$、$13$ 与 $14$，正是 CTCF 序列标识图中信息量最大的几列。最大的单个效应是基序位置 $13$ 上的一个替换，使 logit 降低 $5.1$；少数替换使它升高，最多 $2.4$，因为它们使位点更接近共有序列。梯度 × 输入只用一次反向传播就复现了这条谱（相关系数 $0.96$），而不需要 $360$ 次前向评估。位点之外的归因很小，且局限在输出权重为负的滤波器所选的窗口内。

![例 15.2.1 的网络在一条带有 CTCF 位点的测试序列上的 in silico 饱和突变与梯度乘输入归因。A：每个位置上三种替换各自引起的输出 logit 的变化（蓝：下降，红：上升）；圆点标出所放入位点的碱基，这些格子按定义为零。B：每个位置的重要性，以突变时 logit 的平均下降（柱）与梯度 × 输入（线）表示；阴影带是所放入的位点。由于全局最大池化，只有某个滤波器的最大激活窗口之内的位置才可能有非零归因](./plots/ism.py)

许多序列的归因图含有反复出现的短模式。TF-MoDISco（Shrikumar 等，2018）把所有序列中归因高的片段切出来，聚类，再把每一类汇总成带序列标识图的基序，这与 [7.8.8](/7.8.8) 首尾相接：基序来自功能而不是来自对齐位点的计数，并且可以把成对的基序放入合成序列并预测输出，来测量它们的偏好组合与间距。有三点要注意。归因解释的是模型而不是细胞：学到了结合的某个相关量（如 GC 含量或辅因子基序）的模型就会把它显示出来。在相互作用强的地方，不同方法的结果不一致，因为每个位置一个数无法描述相互作用。此外，在基因组序列上训练的网络是在基因组的分布之内作预测的，对人工设计或大量突变的序列可能有把握地出错。

## 15.4. 序列的语言模型

### 15.4.1. 蛋白质语言模型

带标签的数据很少：一种折叠只有几千个结构，一个蛋白质只有几百个测得的突变体。无标签的序列则极其丰富：UniProt 收录了数亿条（[7.8.2](/7.8.2)）。**语言模型**（[4.7.5](/4.7.5#sec-5.4.1)）学习序列本身的分布，因而捕捉到进化加在序列上的约束。

**定义 15.4.1（蛋白质语言模型）** **蛋白质语言模型**是一种神经网络，通常是 Transformer，在大量天然蛋白质序列上用**自监督学习**训练，由上下文预测残基：由序列其余部分预测被掩盖的残基（**掩码语言建模**），或由前面的残基预测下一个残基。它对残基与序列的表示，以及所预测的残基概率，随后被用于其他任务。

对于掩码建模，随机隐藏一个约占 $15\,\%$ 的位置子集 $M$，参数使

$$
\mathcal{L}(\boldsymbol{\theta}) = -\mathbb{E}_{x}\,\mathbb{E}_{M}\sum_{i \in M}\log p_{\boldsymbol{\theta}}(x_i \mid x_{\setminus M}). \tag{15.2}
$$

最小。ESM 模型（Rives 等，2021；ESM-2，Lin 等，2023）是以这种方式在聚类的 UniRef 序列上训练的编码器 Transformer，参数从 $8$ 百万到 $150$ 亿不等；ProtT5（Elnaggar 等，2022）是编码器–解码器的替代方案。要填好一个被掩盖的残基，模型必须学会每个家族的每个位置容许哪些残基，以及哪些位置一起变化，因而也就学到了一些关于结构的东西。这类模型的注意力图确实无需监督就能预测残基接触（Rao 等，2021）：对注意力权重作逻辑回归，恢复接触的效果，与对**多序列比对**拟合的 **Potts 模型**（[7.6.15](/7.6.15#sec-15.5.4)）相当，后者是**共进化**的统计表达，而语言模型一次只看一条序列。ESMFold 不用比对，由 ESM-2 的表示预测结构（[7.8.17](/7.8.17)）。对残基取平均的嵌入，可作为特征，配一个小的监督头来预测定位、功能或溶解度，这是**迁移学习**的一种形式；对整个模型在带标签任务上**微调**则是另一种选择（[4.7.7](/4.7.7#sec-7.5.1)）。

### 15.4.2. 基因组语言模型

**定义 15.4.2（基因组语言模型）** **基因组语言模型**是在 DNA 上训练的语言模型，通常用一个或多个物种的全基因组，预测被掩盖的或后续的核苷酸，并用作基因组任务的表示或似然的来源。

DNABERT（Ji 等，2021）以重叠的 $k$-mer 为词元；Nucleotide Transformer（Dalla-Torre 等，2024）用不重叠的 $6$-mer 与数百个物种的基因组；HyenaDNA（Nguyen 等，2023）用长卷积取代注意力，达到一百万个单核苷酸的上下文；Evo（Nguyen 等，2024）有 $70$ 亿个参数，上下文为 $131$ kb，在细菌、古菌与噬菌体基因组上训练，能生成合理的操纵子与 CRISPR 基因座，Evo 2（2025）则把训练扩展到所有生命域。DNA 比蛋白质更难建模。哺乳动物基因组的大部分不受选择，所以模型把容量花在重复序列与中性序列上；功能元件短而稀疏；调控序列的作用取决于细胞，而仅凭序列无法确定这一点。对调控任务的独立评估发现，预训练 DNA 模型的表示往往并不比直接在该任务上训练的监督模型或独热基线更好（Tang 与 Koo，2024）；它们在进化约束本身就是信号的地方帮助最大，如编码序列、剪接位点与紧凑的微生物基因组。

## 15.5. 预测变异的效应

**定义 15.5.1（变异效应预测）** **变异效应预测**是由序列，可能还有结构与保守性，对遗传变异对分子表型（蛋白质稳定性或活性、结合、剪接、表达）或对适合度与疾病的后果作的计算估计。监督预测器在带标签的变异上训练；零样本预测器用天然序列的模型给变异打分，不用标签。

监督预测器从 ClinVar（[7.8.12](/7.8.12#sec-12.8.2)）中已分类的变异学习，并继承了它的偏差：研究充分的基因被过度代表，有些标签反映的是更早的预测，测试变异往往是训练变异的近亲。零样本预测器完全避开标签。它们的前提是，进化已经做了数亿年的诱变实验，被容许的替换就是今天序列中所见的替换。

**公式 15.5.1（掩码边缘得分）** 对位置 $i$ 的野生型残基被 $b$ 替换，掩码语言模型给出

$$
s(i, b) = \log p_{\boldsymbol{\theta}}(x_i = b \mid x_{\setminus i}) - \log p_{\boldsymbol{\theta}}(x_i = \mathrm{wt} \mid x_{\setminus i}), \tag{15.3}
$$
即位置 $i$ 被掩盖时突变型相对于野生型的对数优势；负的得分预测有害的替换。多个替换用求和来打分，这假定它们的效应是可加的。

**例 15.5.1** 设在一个埋藏的位置上，模型给野生型亮氨酸的概率为 $0.62$，异亮氨酸为 $0.20$，天冬氨酸为 $0.004$。得分为：L→I 是 $\ln(0.20/0.62) = -1.13$，L→D 是 $\ln(0.004/0.62) = -5.04$：保守替换受到轻度不利，核心中的带电残基则受到强烈不利，在此上下文中突变型的概率比野生型低 $\mathrm{e}^{5.04} \approx 155$ 倍。

这就是 ESM-1v（Meier 等，2021）的方法。EVE（Frazer 等，2021）对每个蛋白质家族的比对拟合一个变分自编码器，用近似对数似然的变化给变异打分，是 [7.8.5](/7.8.5) 轮廓传统中家族特异的模型。AlphaMissense（Cheng 等，2023）以语言建模目标改造 AlphaFold 的架构，并对照群体频率校准输出，把在人类与其他灵长类中常见的变异视为良性；它把全部 $7100$ 万个可能的人类错义替换中的 $89\,\%$ 分类为可能致病（$32\,\%$）或可能良性（$57\,\%$）。在 ACMG/AMP 框架中，这类得分是辅助性的计算证据，而不是诊断（[7.8.12](/7.8.12#sec-12.8.3)）。

衡量的标准是实验。在深度突变扫描（deep mutational scanning）中，把一个蛋白质的全部或大部分单突变体文库表达出来，按某种功能（生长、结合、荧光）筛选，在筛选前后测序，各变异频率的变化即估计它的效应。ProteinGym（Notin 等，2023）收集了许多这样的检测，按预测效应与测得效应的 Spearman 相关系数给预测器排名；最好的零样本模型平均约为 $0.4$ 到 $0.5$，且在不同蛋白质之间差别很大，因为一次检测只在一种选择下测量一种功能，而进化把所有功能都综合在内。

对于非编码变异，把序列到功能模型分别用于两个等位基因，再把预测相减：预测的可及性、某因子的结合谱、剪接位点概率或基因表达的变化。这类预测可用于在精细定位的关联区间中给变异排序（[7.4.25](/7.4.25)），并且可以通过编辑删除所预测的增强子。但是，像 Enformer 这样在参考基因组上跨细胞类型训练的模型，对以**表达数量性状基因座**效应度量的个体间表达差异几乎无法解释，而且常常预测错方向（Sasse 等，2023；Huang 等，2023）：从一个基因组学习每条序列在每种细胞类型中的作用，与学习基因组之间的微小差异如何改变这种作用，是两回事。对于 [7.8.8](/7.8.8#sec-8.3.2) 的乳糖酶持续性变异，应当尝试的工具是肠道细胞中的可及性模型，而不是矩阵扫描。

## 15.6. 评估的陷阱

### 15.6.1. 同源泄漏

通常假设训练样本与测试样本是来自同一分布的独立抽样（[4.7.1](/4.7.1#sec-1.4.2)），这对因共同祖先而相关的生物序列并不成立。随机划分会把几乎每条测试序列的近缘同源物放进训练集，于是模型可以靠识别亲属而不是学习联系序列与功能的规则来取得高分：这是一种**数据泄漏**（[4.6.2](/4.6.2#sec-2.5)）。

**例 15.6.1（同源造成的泄漏）** 我们模拟了 $1200$ 条长 $150$ bp 的序列，分成 $40$ 个超家族，每个含 $5$ 个家族，每个家族 $6$ 个成员：家族祖先与其超家族祖先在 $25\,\%$ 的位点上不同，成员与其家族祖先在 $5\,\%$ 的位点上不同，于是同一家族内的序列对平均共有 $90\,\%$ 的位置，同一超家族内的序列对共有 $54\,\%$，不相关的序列对共有 $25\,\%$。标签是对每个超家族抛一次硬币得到的，所以没有任何规则联系序列与标签，在新超家族上的真实准确率是 $50\,\%$。最近邻分类器代表任何能够记忆的模型，在随机划分上达到 $100\,\%$。改用在一定阈值下的单连接聚类来划分：阈值到 $65\,\%$ 一致性时仍为 $100\,\%$，$60\,\%$ 时为 $83\,\%$，$55\,\%$ 一致性时为 $50\,\%$，此时聚类终于与超家族重合（$40$ 个超家族得到 $44$ 个聚类）。因此估计的准确率是划分方式的性质，只有分开进化单元的划分才能度量泛化。

![同源泄漏（模拟）。1200 条序列分成 40 个超家族，每个超家族 5 个家族、每个家族 6 个成员；标签是超家族的随机性质，所以在新超家族上的真实准确率是 50 %。A：家族内、超家族内与超家族间的成对一致性分布。B：最近邻分类器在随机划分与按单连接一致性聚类划分下的测试准确率（20 次划分、保留 20 % 的均值与标准差）；点下方的数字是每个阈值所得的聚类数。估计值在聚类达到超家族之前一直是 100 %](./plots/leakage.py)

因此生物信息学的基准测试建立在聚类划分上：训练与测试序列按选定的一致性聚类（CD-HIT 或 MMseqs2 linclust，[7.8.4](/7.8.4#sec-4.6)），整个聚类被分到同一侧；或者按家族、按折叠（如 CASP 与 CAFA，[7.8.17](/7.8.17））、对基因组模型按染色体、或按留出的物种来划分。蛋白质使用 $25$ 到 $30\,\%$ 的一致性阈值，因为序列相似性到这里就检测不出来了（[7.8.3](/7.8.3)）。泄漏还有其他形式：重叠的基因组窗口分在划分的两侧，基因的旁系同源物，来自同一个体或同一实验的数据同时出现在两个集合中，或在划分之前就做了过滤与归一化。

### 15.6.2. 不平衡、度量与基线

功能位点是稀少的。训练集常通过对负例子抽样来平衡，这使报告的准确率对基因组毫无用处，因为基因组上正负比例是千比一。AUROC 几乎不受类别比例影响，这是报告它的原因；**精确率–召回率曲线**及其下面积（[4.6.2](/4.6.2#sec-2.3.4)）则受影响，它们才是诚实的概括。

**例 15.6.2** 把例 15.2.1 的网络用于序列相同、但流行率为 $1\,\%$（$20\,000$ 条中有 $200$ 条正例）的测试集。AUROC 不变，仍为 $0.988$，但平均精确率从平衡数据上的 $0.988$ 降到 $0.78$；在默认阈值下找到 $91\,\%$ 的位点，精确率只有 $26\,\%$：$182$ 个真阳性对应 $508$ 个假阳性。当全基因组的流行率为十万分之一时，同一分类器返回的将主要是假阳性，这是 [7.8.8](/7.8.8#sec-8.3.1) 中针对矩阵扫描的论证的定量形式。

深度模型还应与能够胜任的最简单模型比较：矩阵扫描、$k$-mer 逻辑回归、基于少数手工特征的梯度提升树，或按序列一致性的最近邻。在例 15.2.1 中，真实的矩阵胜过网络，这是必然的，因为数据就是由它生成的；在真实数据上差距的方向相反，但往往很小，已发表的改进中有多少来自更大的训练集、更好的划分或更多的调参，而不是来自架构，只有基线与模型调得一样仔细才看得出来。报告在多次随机初始化与划分下的变异也是这一纪律的一部分。

## 15.7. 基因组编辑的序列模型

用 **CRISPR–Cas9** 设计实验，需要由序列作出三个预测：向导还可能在基因组的哪些别处切割，它切割靶标的效率多高，以及修复会留下什么。第一个是搜索问题，由 [7.8.10](/7.8.10#sec-10.6) 的索引方法解决；另外两个是学习问题。

*活性。* 靶向同一基因的向导，编辑效率可以相差一个数量级，原因部分在于间隔序列本身：它的 GC 含量、PAM 旁的核苷酸、单向导 RNA 中与骨架竞争的二级结构，以及使 U6 启动子的转录终止的胸腺嘧啶连串。Rule Set 2（Doench 等，2016）是基于这类特征的梯度提升回归，拟合数千个在混合检测中测得的向导；DeepSpCas9（Kim 等，2019）及后来的卷积模型则从 $30$ nt 的靶标上下文中自己学习特征。这些模型对同一基因座的向导排序足够可靠，有实用价值；但绝对效率在不同细胞类型与递送方式之间转移得很差，因为染色质与表达与序列同样重要（[7.2.24](/7.2.24#sec-24.4)）。

*修复结局。* 平末端双链断裂可由**非同源末端连接**修复，常常是精确的；或由微同源介导的末端连接修复，它把两侧短的相同序列退火，并删除它们之间的序列（[7.2.8](/7.2.8)）。后一条途径使结局仅从序列就可预测，因为一个位点上可用的微同源序列是该位点的性质。

**算法 15.7.1（微同源缺失模式）** 对位于侧翼 $\mathrm{L}$ 与 $\mathrm{R}$ 之间的切口：对每个长度 $k \ge 2$ 与每对相同的 $k$-mer（一个终止于 $\mathrm{L}$，一个起始于 $\mathrm{R}$），记录保留一份微同源序列的缺失，其长度 $D$ 等于两份拷贝之间的距离；给它的模式得分为

$$
100\,\mathrm{e}^{-D/20}\,(2n_{\mathrm{GC}} + n_{\mathrm{AT}})
$$
其中 $n_{\mathrm{GC}}$ 与 $n_{\mathrm{AT}}$ 是微同源序列的组成（Bae 等，2014），对每种产物只保留其最长的微同源序列。一种产物的预测频率是它在总得分中所占的份额，移码得分是长度不是三的倍数的产物所占的份额。

**例 15.7.1** 取一个虚构的靶标，其原间隔序列 AGTTCGGCATCCAGTGGCAG 之后是 PAM TGG，Cas9 在 PAM 上游三个碱基对处切割，两侧的侧翼含有 $35$ 对微同源序列。最好的是六碱基的 CAGTGG，两侧都有，相距六个碱基，给出 $6$ bp 的缺失，占总得分的 $17.3\,\%$；其次是 GTG 上 $9$ bp 的缺失（$7.5\,\%$）与 CCA 上 $16$ bp 的缺失（$5.3\,\%$）。移码得分为 $61\,\%$，所以在此位点作敲除尝试，大约五个等位基因中有三个产生移码，而最可能的单一结局保持了阅读框。对于敲除应选移码得分高的向导；对于精确缺失，则选有一个占优势的微同源序列的位点。

![预测 Cas9 切口处微同源介导的末端连接所产生的缺失（虚构的靶序列，算法 15.7.1）。A：靶标及其原间隔序列、PAM 与切口位置，以及得分最高的四种缺失产物；保留的微同源序列用方框标出，虚线跨越被删除的序列。B：得分最高的十二种产物在总模式得分中的份额，按缺失长度与微同源序列标注，并按产物是否保持阅读框着色；该位点的移码得分为 61 %](./plots/repair-outcomes.py)

学习得到的模型超越了得分。inDelphi（Shen 等，2018）把微同源介导缺失的模型与单碱基插入的学习模型（插入的碱基以切口前的碱基为模板）结合起来，预测结局的完整分布；FORECasT（Allen 等，2019）则从数千个合成靶位点的测量中学习同样的分布。两者都发现，同一位点的结局在不同实验之间是可重复的，这使预测成为可能；它们也被反过来使用：在切割某位点的各个向导中，选出其主要产物就是所需等位基因的那一个。引导编辑又带来新一轮预测：根据其间隔序列、引物结合位点与逆转录模板预测 pegRNA 的效率（[7.2.24](/7.2.24#sec-24.5)）。混合筛选的统计（在不同条件之间比较向导的计数）属于 [7.9](/7.9)，其中用到的负二项模型属于 [7.7](/7.7)。

|---|---|
| 编码 | 独热的 DNA（$L\times4$）与蛋白质（$L\times20$）；语言模型用词元与嵌入；输出：标量、多任务向量、谱（定义 15.1.1） |
| 卷积 | 滤波器是权重矩阵加一个常数；最大池化 = 最佳位点，log-sum-exp = 单位点模型（定理 15.1.1）；与组合基序的各层联合学习 |
| 小模型 | $8$ 个滤波器，$785$ 个参数，恢复 CTCF 基序及其反向互补（$r = 0.96$、$0.97$），测试 AUROC 为 $0.988$，真实矩阵为 $0.998$（算法 15.2.1、例 15.2.1） |
| 调控 DNA 的模型 | DeepBind、DeepSEA（$919$ 个特征）、Basset；谱：BPNet（单碱基分辨率）、Basenji、Enformer（$197$ kb，$128$ bp 的格）、Borzoi（$524$ kb，$32$ bp）、SpliceAI（$10$ kb） |
| 长程 | 感受野 $1 + (k-1)\sum_\ell d_\ell$；空洞使其指数增长（公式 15.2.1、例 15.2.2）；注意力的代价与格数的平方成正比 |
| 解释 | 饱和突变（$3L$ 次评估，定义 15.3.1）、梯度 × 输入、满足完备性的积分梯度；TF-MoDISco 把归因变回基序；$73\,\%$ 的重要性落在所放入的位点内（例 15.3.1） |
| 语言模型 | 掩码目标式 (15.2)；ESM-2、ProtT5；注意力图无监督地给出接触；DNABERT、Nucleotide Transformer、HyenaDNA、Evo；在调控 DNA 上增益较弱（定义 15.4.1、15.4.2） |

## 思考题

1. 宽为 $6$ 的卷积滤波器，对 TATAAT 在每个位置上的碱基，权重 $F_{j,b}$ 为 $2$，对其余三种碱基为 $-1$，偏置 $c = 0$。这个滤波器计算什么？全局最大池化之后网络看到什么？

   **答** 由定理 15.1.1，这个滤波器是一个权重矩阵：与 TATAAT 完全匹配的窗口得分为 $6 \times 2 = 12$，有 $m$ 个错配的窗口得分为 $12 - 3m$。经过整流线性单元与全局最大池化之后，特征为 $\max(0, 12 - 3m_{\min})$，其中 $m_{\min}$ 是序列中最少的错配数，所以网络只看到最佳匹配的吻合程度，而看不到它在哪里，也看不到有多少个匹配。对所有错配同样加权，使这个滤波器成为共有序列匹配器；训练出来的滤波器像真正的权重矩阵一样，权重依赖位置与碱基，要对位点计数或利用位点的位置，还需要额外的滤波器或跨多个窗口的池化。

2. 计算五个宽为 $5$、空洞率为 $1, 2, 4, 8, 16$ 的空洞卷积的感受野。若序列按 $128$ bp 分格，空洞率逐层加倍、宽为 $3$ 的卷积，需要多少层才能看到 $100$ kb 的序列？

   **答** $R = 1 + (5 - 1)(1 + 2 + 4 + 8 + 16) = 1 + 4 \times 31 = 253$ 个位置。宽为 $3$ 时，$R = 1 + 2(2^m - 1)$ 格，而 $100\,000/128 = 782$ 格要求 $2^m \ge 391.5$，所以需要 $m = 9$ 层（$R = 1023$ 格 $= 131$ kb）。这就是为什么达到 $100$ kb 的模型先用带步长的卷积把序列分格，再用十几个空洞层或注意力，而不用数百个普通卷积。

3. 为什么例 15.2.1 的网络对序列作饱和突变时，滤波器所选窗口之外的每个位置都恰好为零？

   **答** 输出是池化特征 $h_k = \max_p\max(a_{kp}, 0)$ 的加权和。改变滤波器 $k$ 的取最大值的窗口之外的一个碱基，会改变其他位置的激活值，而最大值不会变，除非修改后的窗口超过了原来的最大值；对于很小的单碱基改变，这很少发生。所以 logit 不变，ISM 值为零；梯度也因同样的原因为零：最大值的次梯度只流向取最大值的位置。输出对位置的池化更平滑的模型（log-sum-exp、平均池化、谱输出头）把归因分散到整条序列，这是谱模型更容易解释的原因之一。

4. 一个掩码蛋白质语言模型在野生型残基为甘氨酸的位置上，给 G 的概率为 $0.45$，A 为 $0.25$，S 为 $0.02$，W 为 $0.001$。按式 (15.3) 给 G→A、G→S 与 G→W 打分，并说明这个模式提示该位置的什么性质。

   **答** $\ln(0.25/0.45) = -0.59$，$\ln(0.02/0.45) = -3.11$，$\ln(0.001/0.45) = -6.11$。丙氨酸几乎与甘氨酸一样可以接受，丝氨酸差得多，色氨酸极不可能，呈按大小的梯度：模型学到的是这个位置只容许小的残基，如在紧密的转角或拥挤的界面中。这些得分是天然序列模型下的相对似然，而不是自由能，尽管它们与测得的效应相关；它们还假定序列的其余部分是野生型，所以多重突变只能用求和近似地打分。

5. 一个结合位点分类器的灵敏度为 $0.9$，用于一个每 $1000$ 个窗口中有一个真实位点的基因组。在假阳性率为 $10^{-2}$、$10^{-3}$ 与 $10^{-4}$ 时，它的精确率各是多少？这对应当报告的度量意味着什么？

   **答** 取 $\mathbb{P}(\text{位点}) = 10^{-3}$，精确率 $= 0.9 \times 10^{-3}/(0.9\times10^{-3} + \mathrm{FPR} \times 0.999)$，分别为 $8.3\,\%$、$47.4\,\%$ 与 $90.0\,\%$。所以 ROC 曲线上的一个点，其含义随流行率完全不同，而 ROC 曲线本身不受流行率影响。对于罕见事件，在应用的流行率下计算的精确率–召回率曲线及其面积才是有信息量的概括，在平衡数据上训练的模型在全基因组使用之前必须重新校准或重设阈值。

6. 在例 15.6.1 中，尽管标签无法从序列预测，随机划分的准确率却是 $100\,\%$。信息究竟从哪里来？为什么 $65\,\%$ 一致性下的聚类划分不能去掉它？

   **答** 标签在一个超家族内是常数，而随机划分几乎对每条测试序列，都在训练集中留下了它自己家族的若干成员（一致性约 $90\,\%$）；最近邻于是是带有相同标签的亲属，分类器实际是在识别超家族，测试集度量的是对亲属的记忆而不是泛化。在 $65\,\%$ 一致性下聚类可以分开家族，却分不开超家族，因为同一超家族内不同家族的成员只共有约 $54\,\%$ 的位置，不会连成一个聚类；训练集中仍含有同一超家族及其相同的标签。只有把超家族并成一个聚类的阈值（这里约 $55\,\%$），或者显式地按超家族划分，才给出真实的 $50\,\%$。

7. 比较两个增强子活性模型：一个深度网络，在随机划分上 AUROC 为 $0.93$；一个对 $6$-mer 计数的逻辑回归，在同一划分上 AUROC 为 $0.90$。在断定网络更好之前应当做什么？

   **答** 在分开同源与重叠区域的划分（按染色体或按序列一致性的聚类）上把两者重做一遍，因为深度模型有更强的记忆能力，在严格划分下损失更大；确保负例在 GC 含量与长度上匹配，否则两个模型可能都只是在对组成分类；除 AUROC 外，还报告在目标应用的流行率下的平均精确率；基线与网络同样仔细地调参（$k$-mer 长度、正则化），并在同样的数据上训练两者；在多次初始化与划分上重复，并报告波动，对于几千条序列的数据集，波动往往与所声称的差异同一量级。如果差异依然存在，就问网络用到了什么是基线无法表示的东西（间距、取向、长程上下文），并用归因与设计的序列来检验。

8. 在一个 Cas9 切口处，两侧侧翼为 GGCCTTGAAGCCTGAAGG 与 CCTGAAGGTACCTTGCAT。按算法 15.7.1 找出占优势的微同源缺失，并判断这个位点是否适合做敲除。

   **答** 最长的微同源序列是 CCTGAAGG，出现在左侧侧翼的末端与右侧侧翼的起始处；保留一份拷贝，缺失 $8$ bp，取 $n_{\mathrm{GC}} = 5$、$n_{\mathrm{AT}} = 3$，得分为 $100\,\mathrm{e}^{-8/20}(10 + 3) = 871$，占全部九种产物总得分的 $38\,\%$；其次是 TGAAG 上 $15$ bp 的缺失（$14\,\%$）与 CCT 上 $16$ bp 的缺失（$10\,\%$）。移码得分为 $72\,\%$，高于例 15.7.1 的 $61\,\%$，因为占优势的 $8$ bp 缺失本身就是移码：这个位点很适合做敲除，且被编辑的等位基因中有很大一部分带有同样的、易于基因分型的 $8$ bp 缺失。对于精确的框内编辑，同样的性质则是缺点。

9. （设计）一个实验室有某转录因子在一种细胞类型中的 ChIP-seq 峰（$15\,000$ 个），想要一个由序列预测结合、并找出基序及其辅因子的模型。描述数据、模型、评估与解释。

   **答** 取峰顶周围 $200$–$1000$ bp 作正例；负例取在 GC 含量、长度、重复含量与到转录起始位点的距离上匹配的基因组区域，或者正例的二核苷酸打乱版本，这可以防止模型学习组成（[7.8.8](/7.8.8#sec-8.4.5)）；屏蔽重复序列，或有意保留并稍后检查它们的贡献。按染色体划分，并去掉各折之间重叠的区域，使任一峰都不出现在两个集合中。先从基线开始：若有已知矩阵则用它扫描，以及 $k$-mer 逻辑回归。然后训练一个卷积网络：几十个宽 $15$–$25$ 的滤波器，加池化与一两个后续的层，用验证染色体做早停，并报告 AUROC 与在现实流行率下的平均精确率。解释时对预测强的峰作饱和突变，对归因用 TF-MoDISco：应当出现主要基序，其他反复出现的模式是候选的辅因子基序。把主要基序与候选基序以不同间距一起放入随机序列并预测输出，检验它们的相关性，并对照独立证据验证：候选基序在峰中的富集（AME）、在峰顶的集中程度、候选因子在该细胞类型中的表达，以及该因子的 ChIP-seq。

10. （开放）Enformer 一类的模型由参考基因组跨细胞类型预测染色质与表达的效果很好，却很难解释个体间的表达差异。给出可能的原因，并给出一个能区分这些原因的实验或分析。

    **答** 有几种可能的原因。(a) 驱动训练损失的信号是基因座之间的差异，它由启动子组成、CpG 岛与基因结构主导；同一基因座上个体之间的变异小得多，对损失几乎没有贡献。(b) 因果变异往往离基因很远，在增强子中，模型可能把它们的贡献归于错误的元件，许多 eQTL 关联指向的是标签变异而不是因果变异（[7.4.25](/7.4.25)）。(c) 测得的变异包含模型看不到的效应：*trans* 效应、环境、样本的细胞组成以及技术协变量。(d) 在一个参考基因组上训练，没有给出单个替换如何改变输出的例子，所以模型从不因错误的导数而受到惩罚。要区分它们，应在因果变异已知且效应被直接测量的数据上评估：等位基因对的大规模平行报告基因检测、杂合子中的等位基因特异表达与可及性（排除了 *trans* 与环境效应），以及在单个位点上编辑的序列。把模型预测的差异与测得的差异比较，分别针对位于主要预测元件之内与之外的变异；并与在个人基因组与个体表达上微调过的模型比较；如果在变异上微调能修复预测，那么受限的是目标函数而不是架构。
