比对好的读段文件（[7.8.10](/7.8.10)）是一份观测列表；基因组研究需要的则是与参考序列的差异列表及其意义。这个任务的两半性质不同。检出变异是统计推断：给定某位置的读段、碱基质量值与比对质量值，判断样本携带何种基因型，并给出概率。解读变异是证据综合：给定一个变异以及关于该基因、人群与患者的一切已知信息，判断它能否解释某种疾病。遗传学背景见 [7.4.14](/7.4.14#sec-14.7)（变异的类别、外显子组测序、Mendel 病）、[7.4.12](/7.4.12)（突变如何产生）、[7.4.21](/7.4.21)（癌症中的体细胞变异）与 [7.4.22](/7.4.22)（等位基因频率）；对所得基因型作群体规模的处理见 [7.8.13](/7.8.13)。本章依次讲述检出（12.2–12.3）、文件格式及其陷阱（12.4）、用基准集评价（12.5）、结构变异与拷贝数变异（12.6）、体细胞变异（12.7）、注释与分类（12.8）以及罕见病诊断（12.9）。例子是 HG002（其变异可由公开的基准得知），以及承接 [7.8.2](/7.8.2) 的、*MCM6* 中的乳糖酶持续性变异 rs4988235。

## 12.1. 检出的是什么

变异按大小以及是否遗传来分类。**单核苷酸多态性**、至多约 $50$ 个碱基的**插入缺失**、大于此的**结构变异**和**拷贝数变异**，已在 [7.4.14](/7.4.14#sec-14.7.1) 中定义；本章的方法沿用这一划分，因为数据对每一类携带的信号不同。另一种划分是种系变异与**体细胞突变**：前者存在于每个细胞中并可遗传，后者只存在于部分细胞中。对种系变异，二倍体位点可能的基因型有三种，对应的比例为 $0$、$1/2$ 或 $1$，这是一个很强的约束；而体细胞变异可以出现在任何比例，所以必须靠深度与配对的正常样本把它与错误区分开。

典型的人类基因组在约 $4$–$5$ 百万个位置上与 GRCh38 不同：约 $3.5\times10^6$ 个单核苷酸变异、$5$–$6\times10^5$ 个短插入缺失，以及 $2$–$3\times10^4$ 个结构变异，后者影响的碱基比所有单核苷酸变异加起来还多。其中几万个改变蛋白质序列，少数几个是亲代没有的新突变。

## 12.2. 从读段到基因型

### 12.2.1. 堆叠与基因型似然

在一个位置上，数据是重叠读段的碱基及其质量值，称为*堆叠*。最早的检出程序把非参考碱基的比例与阈值作比较，这浪费了质量值中的信息，也无法表达不确定性。

**定义 12.2.1（基因型似然）** 设二倍体位点的参考等位基因为 $A_0$，替代等位基因为 $A_1$，各读段贡献的碱基为 $b_1, \dots, b_n$，错误概率为 $\varepsilon_1, \dots, \varepsilon_n$。基因型 $G$ 的替代等位基因比例为 $f_G$（$A_0A_0$ 为 $f = 0$，$A_0A_1$ 为 $1/2$，$A_1A_1$ 为 $1$），其**基因型似然**为
$$
\mathbb{P}(\text{reads} \mid G) = \prod_{i=1}^{n}\Bigl[f_G\,\mathbb{P}(b_i \mid A_1) + (1 - f_G)\,\mathbb{P}(b_i \mid A_0)\Bigr],
$$
其中，当 $b_i = A$ 时 $\mathbb{P}(b_i \mid A) = 1 - \varepsilon_i$，否则为 $\varepsilon_i/3$；假定每条读段以概率 $1/2$ 来自任一条单倍型，且各读段独立地出错。

**公式 12.2.1（Bayes 基因分型）** 由杂合度 $\theta$ 构建基因型的先验（对人类位点，$\mathbb{P}(A_0A_1) = \theta \approx 10^{-3}$，$\mathbb{P}(A_1A_1) = \theta/2$，$\mathbb{P}(A_0A_0) = 1 - 3\theta/2$，因为在稀有等位基因的 Hardy–Weinberg 比例下，杂合子的可能性是稀有纯合子的两倍），则后验概率为
$$
\mathbb{P}(G \mid \text{reads}) = \frac{\mathbb{P}(\text{reads} \mid G)\,\mathbb{P}(G)}{\sum_{G'}\mathbb{P}(\text{reads} \mid G')\,\mathbb{P}(G')}.
$$
所检出的基因型是后验概率最大者；其*基因型质量*为 $\mathrm{GQ} = -10\log_{10}[1 - \mathbb{P}(\hat G \mid \text{reads})]$（实践中是与次佳基因型之差的 Phred 标度值），变异位点的质量为 $\mathrm{QUAL} = -10\log_{10}\mathbb{P}(A_0A_0 \mid \text{reads})$，即该位点不是参考纯合的证据。

```python
import numpy as np

EPS, THETA = 1e-3, 1e-3            # per-base error probability and heterozygosity
FRAC = np.array([0.0, 0.5, 1.0])   # alternative-allele fraction of 0/0, 0/1, 1/1
PRIOR = np.array([1 - 1.5 * THETA, THETA, THETA / 2])

def genotype(n_ref, n_alt):
    """Posterior, Phred-scaled likelihoods (PL), called genotype, GQ and QUAL at a biallelic site."""
    p_alt = FRAC * (1 - EPS) + (1 - FRAC) * EPS / 3
    p_ref = FRAC * EPS / 3 + (1 - FRAC) * (1 - EPS)
    loglik = n_ref * np.log(p_ref) + n_alt * np.log(p_alt)
    post = np.exp(loglik + np.log(PRIOR) - (loglik + np.log(PRIOR)).max())
    post /= post.sum()
    pl = np.round(-10 * (loglik - loglik.max()) / np.log(10)).astype(int)
    g = int(np.argmax(post))
    return post, pl, ["0/0", "0/1", "1/1"][g], -10 * np.log10(1 - post[g]), -10 * np.log10(post[0])

post, pl, gt, gq, qual = genotype(6, 4)
print(gt, pl, round(gq, 1), round(qual, 1))       # 0/1 [109 0 179] 79.0 79.0
print(genotype(18, 2)[2:])                        # ('0/0', 20.7, 0.04), values rounded
```

**例 12.2.1** 在深度 $10$ 且有四条质量为 Q$30$ 的替代读段时，杂合子的后验概率为 $1 - 1.3\times10^{-8}$：该位点被检出为 $0/1$，GQ 为 $79$，QUAL 为 $79$，VCF 字段 `PL` 为 $109,0,179$。在深度 $20$ 而只有两条替代读段时，杂合子的后验概率为 $0.0086$，该位点被检出为参考纯合：二十条读段中的两条，用错误来解释（期望错误数为 $20 \times 10^{-3}$，但碰巧集中出现）并结合先验，比用本应给出约十条的基因型来解释更合理。在深度 $4$ 而有一条替代读段时，杂合子的后验概率为 $0.16$，GQ 为 $8$：这样的检出会被过滤。这就是低覆盖度的数据不逐位点基因分型，而要借助参考面板的单倍型信息的原因（[7.8.13](/7.8.13)）。

### 12.2.2. 为什么不能把各位点看作相互独立

逐位置检出在插入缺失附近会失败。带有缺失的读段，常被比对成缺失落在重复序列中的另一位置，或者代之以若干错配，所以证据被摊散到相邻的位置上；同一条单倍型上两个变异靠得很近时也是如此。补救的办法是检出单倍型，而不是碱基。

**算法 12.2.1（基于单倍型的检出）** 对基因组中读段显示有变异证据（错配、插入缺失、超过阈值的软剪切）的每个*活跃区域*：

1. 把该区域的读段组装成 de Bruijn 图（[7.8.11](/7.8.11)），并枚举合理的路径；每条路径是一个候选单倍型，用 **Smith–Waterman 算法**把它与参考序列比对，得到它的变异集合。
2. 对每条读段 $r$ 与候选单倍型 $H$，用配对隐 Markov 模型计算 $\mathbb{P}(r \mid H)$，模型的发射概率来自碱基质量值，插入缺失的转移来自聚合酶滑动的模型（配对 HMM 见 [7.8.5](/7.8.5#sec-5.5.1)）。
3. 对每个候选变异位点，对单倍型边缘化，得到定义 12.2.1 的基因型似然，再按公式 12.2.1 做基因分型。

这是 GATK HaplotypeCaller 的方案；freebayes 采用另一种方式，它在一个窗口内评估单倍型而不是组装它们。它的好处在插入缺失、成簇的变异以及比对把读段放得不够好的区域最大，因为第 2 步是把每条读段与整个候选单倍型比较，而不是逐碱基与参考序列比较。

### 12.2.3. 深度学习检出程序

DeepVariant 把候选位点的堆叠转成类似图像的张量（各通道为碱基身份、碱基质量值、比对质量值、链、碱基是否与参考序列一致），用卷积网络把它分类为三种基因型，用基准样本训练（此类模型见 [7.8.15](/7.8.15)）。它能学到手工构建的模型漏掉的错误模式，所以最先被用于错误最难建模的平台：PacBio HiFi 与纳米孔读段，Clair3 与 PEPPER-DeepVariant 也是如此。代价是，学习得到的检出程序只和训练它的样本与平台一样好，而且它的判断比似然更难审核。

## 12.3. 种系变异的流程

从比对好的读段到过滤后的检出结果集，各步骤在不同的流程中是稳定的：

1. *标记重复*（[7.8.9](/7.8.9)、[7.8.10](/7.8.10)）：同一分子的拷贝不能当作独立的证据。
2. *碱基质量值重校准*：由已知非变异位点上的错配，得到按循环与上下文的经验质量值（[7.8.9](/7.8.9#sec-9.2.3)）。这很重要，因为定义 12.2.1 的似然直接把这些概率相乘。
3. *对每个样本检出并输出 GVCF*：基因组 VCF 除记录变异位点外，还记录与参考序列一致的位置块，并给出无变异的置信度。这使下一步成为可能。
4. *联合基因分型*：把所有样本的 GVCF 合并，每个位点在所有样本中同时分型，先验由队列中的等位基因频率提供。联合分析能区分“参考纯合”与“无数据”，这是单样本检出做不到的，并且为低覆盖度的样本增加功效。
5. *过滤*：对各注释（深度、链偏好、支持读段的比对质量值、变异在读段中的位置）设硬阈值，或训练一个模型，以已知位点为正例，把真假检出区分开（VQSR 以及较新的学习型过滤器）。过滤的实现是在 FILTER 列写一个值，而不是删除记录。

```bash
gatk MarkDuplicates -I HG002.bam -O HG002.md.bam -M dup_metrics.txt
gatk BaseRecalibrator -I HG002.md.bam -R GRCh38.fa --known-sites dbsnp.vcf.gz -O recal.table
gatk ApplyBQSR -I HG002.md.bam -R GRCh38.fa --bqsr-recal-file recal.table -O HG002.bqsr.bam
gatk HaplotypeCaller -R GRCh38.fa -I HG002.bqsr.bam -O HG002.g.vcf.gz -ERC GVCF
gatk GenomicsDBImport --genomicsdb-workspace-path db -L chr2 -V HG002.g.vcf.gz -V HG003.g.vcf.gz
gatk GenotypeGVCFs -R GRCh38.fa -V gendb://db -O trio.vcf.gz
# A lighter alternative for one sample, and a deep-learning caller
bcftools mpileup -f GRCh38.fa -q 20 -Q 20 -a AD,DP HG002.md.bam | bcftools call -mv -Oz -o bcf.vcf.gz
run_deepvariant --model_type=WGS --ref=GRCh38.fa --reads=HG002.md.bam --output_vcf=dv.vcf.gz
```

对于 [7.8.10](/7.8.10) 的扩增子面板，靶标少而且已知，只需一个限定在靶区间内的单样本检出程序，而且必须把引物位置排除在检出之外：引物下方的变异被引物自身的序列取代，变得不可见。

## 12.4. VCF 格式

**定义 12.4.1（VCF）** 把变异存为以制表符分隔的文本的格式称为 **VCF 格式**：头部为若干 `##` 行，声明参考序列、重叠群以及每个 INFO、FORMAT 与 FILTER 键的含义；一行 `#CHROM` 给出各样本的名称；然后每个变异位点一行，含字段 CHROM、POS（从 1 起始）、ID、REF、ALT（以逗号分隔的替代等位基因）、QUAL、FILTER、INFO、FORMAT，以及每个样本一列。BCF 是它的二进制形式。

```text
##fileformat=VCFv4.3
##reference=GRCh38
##FORMAT=<ID=GT,Number=1,Type=String,Description="Genotype">
##FORMAT=<ID=AD,Number=R,Type=Integer,Description="Read depth per allele">
##FORMAT=<ID=PL,Number=G,Type=Integer,Description="Phred-scaled genotype likelihoods">
#CHROM POS       ID        REF ALT QUAL FILTER INFO          FORMAT       sample1
chr2   135851076 rs4988235 G   A   790  PASS   DP=32;AF=0.5  GT:AD:DP:GQ:PL 0/1:16,16:32:99:790,0,780
```

基因型 `0/1` 对等位基因编号（$0$ 为 REF，$1$ 为第一个 ALT）；用 `|` 代替 `/` 表示基因型已定相，即每条定相记录的第一个等位基因位于同一条单倍型上。`AD` 给出每个等位基因的读段数，`PL` 是 Phred 标度的基因型似然，已归一化使最佳者为 $0$（即例 12.2.1 的 `PL`），`GQ` 是最佳两者之差。

比较或合并 VCF 之前必须做两种操作。*左对齐*把重复序列中的插入缺失尽可能向左移动，同时不改变它所隐含的序列，因为 `POS=1000 REF=GAA ALT=G` 与 `POS=1001 REF=AAA ALT=A` 可以描述同一个缺失（三个连续 A 中的两个碱基）；*分解*把多等位记录拆成双等位记录，并去掉 REF 与 ALT 共有的碱基。`bcftools norm -f ref.fa -m -any` 两件事都做。若不做，两个流程检出的、或在两个样本中看到的同一个变异，会被计为两个不同的变异。

```bash
bcftools norm -f GRCh38.fa -m -any -Oz -o norm.vcf.gz calls.vcf.gz && bcftools index norm.vcf.gz
bcftools view -i 'FILTER="PASS" && FMT/GQ>=20 && FMT/DP>=10' -Oz -o pass.vcf.gz norm.vcf.gz
bcftools query -f '%CHROM\t%POS\t%REF\t%ALT[\t%GT\t%AD]\n' -r chr2:135851076 pass.vcf.gz
```

## 12.5. 检出结果集好不好？

**定义 12.5.1（基准集）** 某个样本的*基准*（真值）集是一份变异列表与一组区域，其中的变异是已知可信度很高的，由数种技术与流程相结合而确立，Genome in a Bottle 的样本 HG001–HG007 就是如此。检出结果只在可信区域内与它比较。

比较必须考虑表示方式：同一事件可以写成多种形式，所以比较工具（hap.py、vcfeval）按检出结果所隐含的单倍型序列而不是按其记录来匹配。结果是精确率（检出中为真的比例）、召回率（真变异中被检出的比例）及二者的调和平均，对单核苷酸变异与插入缺失分别报告，因为检出插入缺失要难得多。当前的短读长流程，在可信区域内对单核苷酸变异的这两个指标都超过 $99.5\,\%$，对插入缺失则较低，尤其是在同聚物中；可信区域之外含有基因组中最难的 $5$–$10\,\%$，那里的错误率按构造就是未知的。

有三种内部检查不需要基准。

**定义 12.5.2（转换/颠换比）** 检出结果集的**转换/颠换比**（Ti/Tv）是**转换**型替换（嘌呤变嘌呤或嘧啶变嘧啶）的个数除以**颠换**型替换的个数。

随机替换会给出 $\mathrm{Ti/Tv} = 0.5$，因为每个碱基有一个转换的伙伴和两个颠换的伙伴。真实的人类全基因组检出结果集给出 $2.0$–$2.1$，主要因为 CpG 二核苷酸中甲基化胞嘧啶的脱氨很频繁（[7.4.12](/7.4.12#sec-12.6.1)）；外显子组约为 $3.0$，因为遗传密码与选择（[7.2.2](/7.2.2#sec-2.4.2)）使转换更常是同义的。Ti/Tv 被拉向 $0.5$ 的集合含有假阳性，其亏欠可以估计假阳性的数量：设含 $N$ 个检出的集合比值为 $r$，真实的比值为 $r_0$，假检出的比值为 $0.5$，则假检出比例 $\phi$ 满足 $r = [(1-\phi)r_0/(1+r_0) + \phi/3]/[(1-\phi)/(1+r_0) + 2\phi/3]$。

杂合与纯合替代检出的比值是第二项检查：人类基因组约为 $1.5$–$2.0$，非洲血统的样本较高，近交或近亲的样本较低；比值远大于 $2$ 提示被另一个样本污染，因为混合会产生表观的杂合子。

**定义 12.5.3（Mendel 一致性）** 在母亲–父亲–孩子的三联体中，若孩子的基因型无法由双亲的基因型各传一个等位基因产生，例如 $0/0$ 的亲本生出 $1/1$ 的孩子，则该基因型检出是一个 *Mendel 违例*。

真实的违例是新突变，一个孩子全基因组约有 $60$–$80$ 个；超出的都是错误。每个基因组有 $4$–$5\times10^6$ 个变异位点，每个位点要正确分出三种基因型，即使每个基因型的错误率只有 $10^{-4}$，也会产生约一千个违例，所以违例率是基因分型准确度的灵敏度量，而且对任何三联体都可得到，不需要基准。

## 12.6. 结构变异与拷贝数变异

结构变异是短读段检出得最差的一类，也是造成两个基因组之间大部分差异碱基的一类。比对之后有四种信号可用。

| 信号 | 表现 | 检出 |
|---|---|---|

**算法 12.6.1（深度的二分分段）** 给定沿基因组各窗口的对数比 $x_1, \dots, x_n$：找出使 $x_1, \dots, x_k$ 与 $x_{k+1}, \dots, x_n$ 之间的双样本 $t$ 统计量最大的分割点 $k$；若统计量超过阈值，就接受该分割并对两部分递归，否则返回该段。环形二分分段（Olshen 等，2004）改为检验最佳*区间*与其补集，这样能找到单侧分割漏掉的短的局灶性变化，并用置换检验评估显著性。

## 12.7. 体细胞变异

在肿瘤样本中，三种基因型的约束不再成立：亚克隆中的突变可以出现在任何等位基因比例上，而且样本中还含有正常细胞。所以体细胞变异的检出，把肿瘤与来自同一个体的配对正常样本作比较（Mutect2、Strelka2），这样能去掉种系变异以及两者共有的反复出现的人为假象。

**公式 12.7.1（期望的变异等位基因比例）** 设样本中有比例 $p$ 的细胞携带某突变（肿瘤纯度与该克隆中肿瘤细胞比例的乘积），该位点在这些细胞中有 $C_{\mathrm{T}}$ 个拷贝，其中 $m$ 个携带该突变，在其他细胞中有 $2$ 个拷贝。则支持该突变的读段的期望比例为
$$
f = \frac{p\,m}{p\,C_{\mathrm{T}} + 2(1 - p)}.
$$

**例 12.7.1** 在纯度为 $0.6$ 的样本中，二倍体位点上有一个杂合突变，$f = 0.6/(1.2 + 0.8) = 0.30$。若另一个等位基因已丢失（$C_{\mathrm{T}} = 1$，$m = 1$），$f = 0.6/(0.6 + 0.8) = 0.43$；若突变等位基因被重复（$C_{\mathrm{T}} = 3$，$m = 2$），$f = 1.2/(1.8 + 0.8) = 0.46$。同一样本中只存在于一半肿瘤细胞的突变，$p = 0.3$，$f = 0.15$。把公式反过来用，并代入由算法 12.6.1 得到的拷贝数，就得到携带每个突变的细胞比例，肿瘤的克隆结构就是这样重建的（[7.4.21](/7.4.21#sec-21.1.1)）。

![检出体细胞变异。A：期望的变异等位基因比例（公式 12.7.1）随携带突变的细胞比例 p 的变化，分别对应二倍体位点的杂合突变、另一等位基因丢失后，以及突变等位基因被重复；点线表示比例为 0.05。B：观察到至少五条支持读段的概率 1 − P(Bin(n, f) ≤ 4) 随深度的变化，等位基因比例为 0.02 到 0.25。在 100× 时，f = 0.05 的变异被看到的概率为 0.56，f = 0.10 时为 0.98；f = 0.02 需要约 400× 才有 0.9 的概率。虚线是五条或更多读段在 Q30 上带同一个错误碱基的概率：深度 100 时为 3 × 10⁻¹⁰，深度 1000 时为 3 × 10⁻⁵，所以非常深的测序需要按上下文的错误模型或分子标识符，而不是固定的读段阈值](./plots/somatic-detection.py)

体细胞检出还有两个特有的问题。克隆性造血使真实的体细胞突变出现在“正常”的血液样本中，它们被误认为人为假象，更糟的是会使一个真实的肿瘤变异被过滤；正常样本被肿瘤轻度污染也有同样的效果。此外，在低等位基因比例下，文库的错误过程（片段化时的氧化损伤、福尔马林固定组织中的脱氨）占主导，所以液体活检的测定使用**唯一分子标识符**与双链一致读段（[7.8.9](/7.8.9#sec-9.3.3)）。

## 12.8. 注释与解读

### 12.8.1. 命名与后果

**定义 12.8.1（HGVS 命名）** **HGVS 命名**相对于一条给出了版本的参考序列来命名变异：基因组上是 `NC_000002.12:g.135851076G>A`，编码序列上是 `NM_004006.2:c.4375C>T`（位置从起始密码子的 A 起算；上游为负，进入内含子用 `+`/`−` 偏移），蛋白质上是 `NP_003997.1:p.Arg1459Ter`。缺失、重复、插入与组合写作 `c.4375_4379del`、`c.4375_4385dup`、`c.4375_4376insACCT`、`c.4375_4376delinsAGTT`。

由于名称依赖于转录本，同一变异在基因的不同转录本上有不同的 `c.` 名称，在同一转录本的新版本上又有另一个名称；所以临床报告要写明带版本的转录本，各项目也要商定一组临床参考转录本（MANE Select）。注释工具（Ensembl VEP、ANNOVAR、SnpEff）把每个变异放到每个与之重叠的转录本上，并用 Sequence Ontology 术语的受控词汇报告其后果（**错义突变**、**无义突变**、**移码突变**、同义、剪接位点、内含子、调控），同时给出由 [7.8.2](/7.8.2) 各数据库汇集的频率、预测与临床注释。

**例 12.8.1** rs4988235 是 `NC_000002.12:g.135851076G>A`，相对于 *MCM6* 转录本是 `NM_005915.6:c.1917+326C>T`：它位于 *MCM6* 第 13 内含子的深处，对蛋白质毫无影响。它的作用在相距 $13.9\,\mathrm{kb}$ 的另一个基因 *LCT* 上，它改变了该基因的增强子（[7.8.2](/7.8.2)），所以较早的文献把它写作 `LCT:c.-13910C>T`。后果注释为“内含子变异”的变异并不因此无害，把非编码变异滤掉的流程，会丢掉人类基因组中最著名的调控变异。

### 12.8.2. 关于效应的证据

- *人群频率。* 比疾病所能允许的更常见的变异，不是该病的病因。对于患病率为 $P$ 的显性疾病，若该变异解释其中的比例 $A$ 的病例，有等位基因异质性与**外显率** $\pi$，则可信的最大等位基因频率约为 $PA/(2\pi)$：当 $P = 1/500$、$A = 0.02$、$\pi = 0.5$ 时为 $4\times10^{-5}$，所以在 gnomAD 的任何人群中频率为 $10^{-3}$ 的变异都被排除。频率必须在祖先匹配的人群中读取，而不是看全体。
- *约束。* 基因容忍变异的程度各不相同；gnomAD 报告每个基因中功能丧失变异的缺乏程度（LOEUF），受到高度约束的基因中的有害变异分量更重。
- *保守性与计算预测。* 保守性分数（[7.8.8](/7.8.8)）说明某个位置是否被选择所保存。错义效应的预测程序综合保守性、理化性质变化与结构（SIFT、PolyPhen-2），集成方法综合各预测程序（REVEL，以及也覆盖非编码变异的 CADD），无监督模型学习该家族序列的分布，按变异在此分布下有多不可能来打分（EVE、AlphaMissense；[7.8.15](/7.8.15)）。SpliceAI 由序列预测剪接位点的获得与丧失，从而找回那些因为同义或位于内含子而被其他工具判为良性的致病变异。
- *功能测定。* 变异效应的多重测定在一次实验中测量一个基因的每一种可能变异（饱和**基因组编辑**，[7.4.19](/7.4.19)）；对 *BRCA1*，它们已重新分类了大部分此前意义不明的变异（[7.4.21](/7.4.21#sec-21.4.2)）。

各预测程序彼此相关，又是用它们随后所评价的同样的临床数据库训练的，所以报告的准确度是乐观的，“五个工具中有四个一致”并不是四条独立的证据。分类框架把计算证据当作支持性的，而不是决定性的。

### 12.8.3. ACMG/AMP 分类

美国医学遗传学与基因组学学会和分子病理学会的指南（Richards 等，2015）把变异分为五类：致病、可能致病、意义不明、可能良性、良性，方法是综合各条强度已定的标准：极强（功能丧失可致病的基因中的无效变异）、强（与已知致病变异的氨基酸改变相同；公认的功能测定）、中等（亲子关系未经确认的新发突变；在人群数据库中不存在）、支持（计算预测；共分离），以及镜像的良性标准，直至独立标准（频率对该病而言过高）。

**公式 12.8.1（点数系统）** 在对这些规则的 Bayes 重构中（Tavtigian 等，2018），一个支持点的致病比值为 $O_{\mathrm{PVSt}}^{1/8}$，其中 $O_{\mathrm{PVSt}} = 350$，中等算 $2$ 点，强算 $4$ 点，极强算 $8$ 点，良性标准计为负，累加 $P$ 点、先验为 $\pi$ 之后的致病后验概率为
$$
\mathbb{P} = \frac{\mathrm{odds}}{1 + \mathrm{odds}}, \qquad \mathrm{odds} = 350^{P/8}\,\frac{\pi}{1 - \pi}.
$$

**例 12.8.2** 取作者所用的先验 $\pi = 0.1$，类别的边界 $0.99$、$0.90$、$0.10$ 与 $0.001$ 落在 $+10$、$+6$、$-1$ 与 $-7$ 点：$+10$ 给出 $0.994$，$+6$ 给出 $0.900$，$-1$ 给出 $0.051$，$-7$ 给出 $0.00066$。2015 年指南列出的各种组合（一条极强加一条强；一条强加三条中等）总和都至少为 $10$ 点；两条强的标准只有 $8$ 点（$0.975$，可能致病），所以文字规则与算术除这一组合之外是一致的，点数系统还能判定规则中没有定义的组合。这一重构的价值在于使假设显现出来：先验与每条标准的强度可以由数据估计并修订，而不相互独立的标准（几个相关的预测程序）不得重复计数。

![对 ACMG/AMP 规则的 Bayes 解读。A：变异致病的后验概率随累加证据点数的变化（公式 12.8.1），给出三种先验概率；点线是类别边界 0.99、0.90、0.10 与 0.001，先验为 0.1 时它们落在 +10、+6、−1 与 −7 点。纵轴取 logit 标度，曲线在其上是直线：每一点证据使比值乘以 350^(1/8) = 2.08。B：按强度赋给各标准的点数；良性标准计为负](./plots/acmg-points.py)

大多数变异收集到的证据太少，仍是*意义不明的变异*，不能用于临床决策。对于祖先在数据库中代表性不足的人，这一比例更高，因为他们的人群频率与共分离证据更弱。ClinVar 汇集提交的分类及其证据，并标出各实验室之间的冲突；ClinGen 专家组撰写针对具体基因的规则，这是应对通用指南对任一基因都过于宽松的实际办法。

## 12.9. 诊断罕见病

对患者做外显子组或基因组测序，会得到约 $4\times10^6$ 个变异，其中可能有一两个能解释疾病。分析是一连串的过滤，每一步都由遗传学而不是便利来论证：在匹配人群中常见的变异被排除（12.8.2 节）；要求后果与基因同表型相符；家系中的遗传模式必须成立，即散发的显性疾病是新发变异，隐性疾病是反式的两个变异（定相很重要，可由双亲或长读段确定），近亲家系中是纯合（[7.4.14](/7.4.14#sec-14.11)）。

**例 12.9.1** 对于严重的散发疾病，三联体是最有力的设计。每个孩子全基因组携带约 $74$ 个新的单核苷酸突变（$6.2\times10^9$ 个碱基对，每代每碱基对 $1.2\times10^{-8}$），其中约 $0.8$ 个落在 $35\,\mathrm{Mb}$ 的编码外显子中。所以，位于受约束的、功能与表型相符的基因中的有害新突变，本身就是强证据。过滤的好坏取决于基因型：如 12.5 节所示，基因分型错误产生的 Mendel 违例，数量远远超过真正的新发突变数，所以候选变异要通过检查读段并用独立的测定来确认。

表型驱动的工具（Exomiser 及类似工具）按患者的 Human Phenotype Ontology 术语与每个基因（在人类与模式生物中）所记录的表型之间的语义相似度对候选基因排序，并结合变异水平的证据；这把医生的观察转成了基因上的先验。若未能诊断，原因依次是：变异属于不易检出的类别（结构变异、重复扩增、深内含子变异、嵌合），该基因尚未被知道会致病，或表型并非按假设的方式由遗传决定。对未解决的病例在一两年后重新分析，仍能以不可忽视的比率得到新的诊断，纯粹是因为基因–疾病知识增长了，这支持把数据存成可重新分析的形式（[7.8.1](/7.8.1#sec-1.6)）。

NGLY1 缺陷症的故事展示了这条流程在能力极限处的表现。一名患有未确诊的多系统疾病的男孩，表现为发育迟缓、肝脏异常、几乎没有眼泪，在多年的代谢检测没有结论之后，与双亲一起接受了测序；他携带 *NGLY1* 中的两个不同的功能丧失变异，各来自一位亲本，该基因当时与任何人类疾病都无关联，它编码的酶在错误折叠的糖蛋白被降解之前，把 N-聚糖从其上移除。证据是生化功能与表型相符，尤其是又发现了更多患者，这是家属发表病例后，其他临床医生认出了同样不寻常的特征组合而找到的。在第二个家庭使它们可以被解读之前，这些变异一直是意义不明的：单个基因组本身很少能够确诊，罕见病基因组学中的限制性资源是患者的匹配，而不是测序。

## 思考题

1. 某位点深度为 $12$，有 $3$ 条替代读段，所有碱基均为 Q$30$。计算三个基因型似然，以及 $\theta = 10^{-3}$ 时的后验概率。检出的是什么？

   **答** $\varepsilon = 10^{-3}$ 时，每条读段看到替代碱基的概率分别为 $\varepsilon/3 = 3.33\times10^{-4}$（$0/0$）、$0.5$（$0/1$）与 $1 - \varepsilon$（$1/1$），看到参考碱基的概率分别为 $1 - \varepsilon$、$0.5$ 与 $\varepsilon/3$。对数似然：$0/0$：$9\ln(0.999) + 3\ln(3.33\times10^{-4}) = -24.02$；$0/1$：$12\ln 0.5 = -8.32$；$1/1$：$9\ln(3.33\times10^{-4}) + 3\ln(0.999) = -72.1$。加上先验的对数 $\ln(0.9985)$、$\ln(10^{-3})$、$\ln(5\times10^{-4})$，得 $-24.02$、$-15.23$、$-79.7$，所以杂合子胜出，后验概率为 $1/(1 + \mathrm{e}^{-8.79}) = 0.99985$：检出为 $0/1$，GQ 为 $38$。十二条读段中有三条，对杂合子是不寻常的比例，但比三个独立的错误可能得多。

2. 为什么基于单倍型的检出程序在同聚物中的插入缺失上优于逐位置的检出程序？配对 HMM 起什么作用？

   **答** 在同聚物中，比对程序可以把一个碱基的缺失放在这段连续序列的任何位置，所以支持同一事件的读段分散在若干位置，没有一个达到显著；而带有插入缺失的读段还可能被比对成错配，把它隐藏起来。单倍型检出程序组装该区域的读段，提出两种候选序列（有与没有被缺失的碱基），把每条读段作为整体对它们打分，所以无论读段最初如何比对，证据都被汇集起来。配对 HMM 提供 $\mathbb{P}(\text{read} \mid \text{haplotype})$，其插入与缺失状态的概率依赖于局部上下文，这正是使同聚物中的插入缺失常见的滑动过程；固定的空位罚分无法表达同一个缺失在八个 A 的连续序列中很可能而在别处不可能。

3. 一个检出结果集含 $4.0\times10^6$ 个单核苷酸变异，Ti/Tv $= 1.8$。假设真实的比值是 $2.1$，假检出的 Ti/Tv $= 0.5$，估计假阳性的个数。

   **答** 设 $\phi$ 为假检出的比例。比值为 $r$ 的集合中，转换占 $r/(1 + r)$：真变异为 $0.677$，假检出为 $1/3$。于是 $\mathrm{Ti/Tv} = [(1-\phi)0.677 + \phi/3]/[(1-\phi)0.323 + 2\phi/3] = 1.8$。求解：分子 $= 0.677 - 0.344\phi$，分母 $= 0.323 + 0.344\phi$，所以 $0.677 - 0.344\phi = 0.581 + 0.619\phi$，$\phi = 0.096/0.963 = 0.0997$。约有 $4.0\times10^5$ 个假检出，占集合的十分之一，这是过滤过于宽松的强烈信号。

4. 解释为什么对队列做联合基因分型比分别对每个样本分型能得到更好的检出结果，以及 GVCF 存储了 VCF 所没有的什么内容。

   **答** 单样本 VCF 只列出变异位点，所以当样本 A 在某位点有变异而样本 B 在该位点没有记录时，无法判断 B 是参考纯合，还是只是没有覆盖。GVCF 额外存储无变异位置的块及其无变异的似然，所以信息得以保留。联合基因分型再把队列的等位基因频率用作先验：在一个样本中太弱的证据（十二条中有两条替代读段），若该等位基因在其他样本中常见，就变得令人信服，反之，被队列范围内的缺失包围的孤立的弱检出就会受到惩罚。它还为群体分析提供完整的基因型矩阵（[7.8.13](/7.8.13)），并使过滤的校准更好，因为数千个样本的注释可用来训练模型。

5. 一个 $30\times$ 测序、读段为 $2\times150$、插入片段为 $350 \pm 90$ nt 的样本，其一条染色体上有一个 $4$ kb 的缺失。四种信号中哪些会显示它？各大约有多少条支持读段？

   **答** 不一致的读段对：若一条配对读段落在缺失两侧，即片段覆盖连接处，则该读段对跨越缺失；有效窗口是插入片段长度，所以跨越它的片段的期望个数约为 $c \cdot I/(2\ell) \cdot$（来自缺失单倍型的比例），$c = 30$、$I = 350$、$\ell = 150$：约 $35$ 个片段跨越连接处，其中一半来自缺失的单倍型，给出约 $17$ 个不一致的读段对，插入片段约为 $4350$ 而不是 $350$。分裂读段：一条读段若其 $150$ 个碱基跨越连接处，则越过它，约有 $30 \times 150/150 /2 \approx 15$ 条，其中两侧各有足够碱基（比如 $\ge 20$）的可用，约 $12$ 条。深度：$4$ kb 的区间深度是正常的一半，在 $4000$ 个碱基上这是明显的信号（读段起点数约 $400$，而期望为 $800$，远在 Poisson 噪声之外）。局部组装也能恢复出连接处。相反，对 $50$ 个碱基的缺失，插入片段的偏移落在正常的涨落之内，只有分裂读段与组装有效。

6. 肿瘤纯度为 $0.4$。二倍体位点上的克隆性杂合突变，等位基因比例是多少？要以概率 $0.95$ 看到至少五条支持读段，需要多大的深度？

   **答** $f = 0.4/(0.8 + 1.2) = 0.20$。支持读段数服从 $\mathrm{Bin}(n, 0.2)$；$\mathbb{P}(\ge 5)$ 在 $n = 44$ 时达到 $0.95$（$43$ 时为 $0.949$，$44$ 时为 $0.956$）。三分之一肿瘤细胞中的亚克隆突变，$p = 0.133$，$f = 0.067$，需要约 $135\times$；这就是肿瘤要测到 $60$–$100\times$ 或更深的原因，也是亚克隆结构只有在高深度下才能分辨的原因。

7. 某显性疾病基因中的一个错义变异：在 gnomAD 中不存在（中等）；新发且亲子关系已确认（强）；计算预测程序一致认为有害（支持）；公认的功能测定显示功能丧失（强）。用公式 12.8.1 对它分类，并说明若该功能测定未经验证会有什么变化。

   **答** 点数：$2 + 4 + 1 + 4 = 11$。$\pi = 0.1$ 时，odds $= 350^{11/8}\times(1/9) = 0.111 \times 350^{1.375}$。因 $350^{1.375} = \mathrm{e}^{1.375 \times 5.858} = \mathrm{e}^{8.05} = 3140$，odds $= 349$，$\mathbb{P} = 0.997$：致病（高于 $+10$ 点的阈值）。若该测定没有用已知的致病与良性变异验证，这条标准降为支持（$1$ 点），共 $8$ 点，$\mathbb{P} = 0.975$：可能致病而非致病。功能标准的强度取决于测定区分已知类别的已证实的能力，这是 ClinGen 专家组撰写针对具体测定的规则的主要原因。

8. 同一个基因组位置，在一个实验室被报告为 `NM_004006.2:c.4375C>T`，而另一个流程则报告为“内含子，无后果”。给出报告可能不同的两个原因，并说明如何解决。

   **答** 第一，转录本：在基因的某个转录本上是外显子的位置，在另一个转录本上可能是内含子，各工具默认的转录本集合不同（RefSeq、Ensembl、MANE Select），多个后果同时适用时选择报告哪一个的规则也不同。第二，版本：`c.` 记法中的位置是在转录本的特定版本上计数的，所以 `NM_004006.2` 与更新的版本可能对同一个碱基编号不同，而在不同组装版本之间的坐标转换也可能移动了基因组坐标。解决办法是比较带版本的染色体记录上的基因组 HGVS 名称（`NC_…:g.…`），它是没有歧义的，然后用同一份明确给出的转录本集合重新注释两者，优先选择临床参考转录本；只给出 `c.` 名称而没有转录本版本的报告无法核对。

9. 为什么滤掉非编码变异在罕见病中实践上效果很好，对 rs4988235 这样的变异却不行？

   **答** 它有效，是因为基因组的编码部分占 $1$–$2\,\%$，却含有绝大多数已知的 Mendel 病变异，而且编码后果可以由序列可靠地预测，非编码变异的效应通常不能。当机制是调控性的时，它就失效：rs4988235 位于 *MCM6* 的一个内含子中，改变的是相邻基因 *LCT* 的一个增强子中的结合位点，所以它所有的编码后果注释都是“内含子变异，蛋白质无改变”，基因归属与效应都是错的。非编码变异需要不同的证据：保守性、染色质与增强子注释、转录因子结合的预测变化（[7.8.8](/7.8.8)），以及把该元件与其靶基因联系起来的表达数据（[7.9](/7.9)）；这也是目前基因组测序的诊断率只比外显子组测序高几个百分点，而差距预期会增大的原因之一。

10. （设计题）你要建立一条流程，对 $500$ 名患者的靶向测序数据，检出 $400$ 个癌症易感基因的面板中的种系变异，并报告分类后的变异。描述各步骤、质量检查，以及你的流程可能造成危害的地方。

    **答** 步骤：对读段做样本拆分与质量控制（[7.8.9](/7.8.9)）；用 BWA-MEM 比对到 GRCh38，并明确处理替代重叠群；标记重复（扩增子设计中读段起点相同，不能标记，要核实面板用的是哪种化学）并重校准质量值；用限定在靶区间及侧翼碱基的、基于单倍型的检出程序检出并生成 GVCF，对 $500$ 个样本联合基因分型，使队列的频率为先验提供信息，并使在各样本中反复出现的假象变得可见；由面板内的深度检出拷贝数变异（*BRCA1*、*MSH2* 等基因的外显子水平缺失占致病变异的相当大一部分，小变异检出程序会漏掉）；规范化，并用明确给出的转录本集合注释；在有针对具体基因的 ClinGen 规则时，按其分类。检查：对每个样本的每个靶碱基的覆盖度，规定最低值（比如 $20\times$），并明确列出无法检出的位置；由基因型确认样本身份与性别；估计污染；每次运行都带一个基准样本（GIAB 基因组之一），并报告精确率与召回率；每个样本的 Ti/Tv 与杂合/纯合比；记录每份报告所用的流程与数据库版本。危害：假阳性会导致手术；假阴性给出虚假的安心，而无声的失败模式是某个靶区域没有覆盖却从不被如此报告，所以可检出区域的报告与变异列表同样重要。意义不明的变异必须如实报告，不得据此采取行动，在代表性不足的祖先人群中其比率更高，而且实验室需要有分类变更时重新联系患者的程序，因为这些基因中的重新分类很频繁。
