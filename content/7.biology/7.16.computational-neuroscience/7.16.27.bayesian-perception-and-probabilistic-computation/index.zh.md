[7.16.26 章](/7.16.26)把解码当作由实验者所作的推断，实验者知道刺激，想知道神经元携带了多少信息。本章采取大脑的视角，大脑只有感觉证据，必须判断外面有什么。感觉证据是含噪且有歧义的：同一个视网膜像由许多场景产生，同一种声音来自不同声源，每次测量都被神经噪声所污染。Helmholtz 的提议，即知觉是从感觉数据到其可能原因的无意识推断，已经通过**贝叶斯推断**（[3.2.7](/3.2.7)，[3.7.1](/3.7.1)）成为一个精确的定量理论。它预测知觉应当如何依赖证据的可靠性、以往的经验和环境的结构，这些预测可以在心理物理学中检验，并在一定程度上在神经记录中检验。我们从它最简单的推论，即按可靠性对线索加权以及向先验的偏差，一路讲到一群发放脉冲的神经元如何表示概率分布并用它进行计算，最后以对这一框架的批评收尾。与运动系统状态估计的联系，即以同样的方式结合预测与感觉，在 [7.16.29](/7.16.29) 中建立。

全章中，世界的状态记为 $s$，线索的感觉测量（内部表征）记为 $x$，似然为 $p(x \mid s)$，通常是正态的，$x \sim \mathcal{N}(s, \sigma^2)$。先验为 $p(s)$，后验为 $p(s \mid x)$。线索的可靠性或精度为 $1/\sigma^2$。

## 27.1. 作为推断的知觉

### 27.1.1. Bayes 观察者

观察者的问题就是 26.1 节的问题：用 **Bayes 公式**由 $x$ 推断 $s$。除数据之外还需要两个要素：测量如何由世界产生的模型，以及对各种世界的先验。

**定义 27.1.1（Bayes 观察者）** **贝叶斯观察者**持有一个生成模型，即对世界状态的先验 $p(s)$ 和感觉测量的似然 $p(x \mid s)$，计算后验 $p(s \mid x) \propto p(x \mid s)\,p(s)$，并报告使后验下期望代价最小的知觉或决策：对平方误差是后验均值，对命中或不中的代价是后验众数（**最大后验估计**）。

正态分布的先验与似然是共轭的（[3.7.4](/3.7.4)），给出闭式的答案，涵盖了大部分定性行为，本章通篇使用。

**定理 27.1.1（Gaussian 后验）** 设先验为 $s \sim \mathcal{N}(\mu_0, \sigma_0^2)$，测量为 $x \mid s \sim \mathcal{N}(s, \sigma^2)$。则后验是正态的，$s \mid x \sim \mathcal{N}(\mu_{\mathrm{post}}, \sigma_{\mathrm{post}}^2)$，其中

$$
\mu_{\mathrm{post}} = \frac{x/\sigma^2 + \mu_0/\sigma_0^2}{1/\sigma^2 + 1/\sigma_0^2} = \mu_0 + k\,(x - \mu_0),\qquad \frac{1}{\sigma_{\mathrm{post}}^2} = \frac{1}{\sigma^2} + \frac{1}{\sigma_0^2}, \tag{27.1}
$$
这里 $k = \sigma_0^2/(\sigma_0^2 + \sigma^2)$。

**证明** 对数后验在相差一个常数的意义下为 $-\frac{(x - s)^2}{2\sigma^2} - \frac{(s - \mu_0)^2}{2\sigma_0^2}$，是 $s$ 的二次函数，首项系数为 $-\frac12(1/\sigma^2 + 1/\sigma_0^2)$；配方即得具有所述精度和均值的正态分布。$\square$

式 (27.1) 说明了两件事。后验均值是测量与先验均值的精度加权平均，并且精度相加：后验总是比似然或先验都更窄。估计偏向先验：对固定的真值 $s$，$\mu_{\mathrm{post}}$ 的期望为 $s + (1 - k)(\mu_0 - s)$，其方差 $k^2\sigma^2$ 小于 $\sigma^2$。观察者以偏差换取方差，这一交换就均方误差而言是有利的（[3.7.2](/3.7.2) 的收缩）；噪声越强，偏差越大。27.3 与 27.4 节的实验利用了这一性质：知觉的偏差看起来像误差，却是先验的标志。

## 27.2. 线索整合

### 27.2.1. 两条线索的最优结合

世界的大多数性质可以用不止一种方式感知：物体的大小由视觉和触觉，声音的位置由听觉和视觉，自身运动的方向由视觉流和前庭器官。把这样的测量结合成单一的估计，就是线索整合（cue integration）。先验平坦时，方差分别为 $\sigma_1^2$ 与 $\sigma_2^2$ 的两个独立测量 $x_1$ 与 $x_2$ 给出的似然是两个正态似然的乘积。

**定理 27.2.1（线索的最优结合）** 对独立的 Gaussian 线索 $x_i \sim \mathcal{N}(s, \sigma_i^2)$（$i = 1, 2$）和平坦的先验，后验是正态的，其均值与方差为

$$
\hat s = w_1x_1 + w_2x_2,\quad w_i = \frac{1/\sigma_i^2}{1/\sigma_1^2 + 1/\sigma_2^2},\qquad \sigma_{12}^2 = \frac{\sigma_1^2\sigma_2^2}{\sigma_1^2 + \sigma_2^2}. \tag{27.2}
$$
结合后的估计是各线索的最小方差无偏线性组合，其方差小于 $\min(\sigma_1^2, \sigma_2^2)$，在两条线索同样可靠时等于 $\sigma^2/2$。

**证明** 对定理 27.1.1，取第一条线索为测量，第二条为"先验" $\mathcal{N}(x_2, \sigma_2^2)$（平坦先验与 Gaussian 的乘积），或直接把似然相乘。对于第二个陈述，对 $w$ 最小化 $w^2\sigma_1^2 + (1 - w)^2\sigma_2^2$（无偏组合的权重之和为一），得到式 (27.2) 的 $w_1$。$\square$

该理论根据只用每条线索单独所作的测量，预测结合后知觉的权重、方差和偏差，不含自由参数。Ernst 与 Banks（2002）用视觉–触觉任务检验了它。受试者判断一条脊的高度，他们以立体点图的形式看到它，并用力反馈装置感受它；视觉线索可以通过给点的位置加噪声而变差。根据单一模态的辨别阈值，作者预测了结合条件下视觉的权重（式 (27.2)），并由视觉与触觉高度冲突的刺激的主观相等点测量了它。当视觉噪声从 $0$ 升到 $200\,\%$ 时，测得的权重遵循预测，视觉可靠时视觉占主导，不可靠时触觉占主导。两种线索同时存在时的辨别阈值接近预测的 $\sigma_{12}$，且低于较好线索的阈值（见图）。

![两条 Gaussian 线索的整合（定理 27.2.1）。A：视觉线索（标准差 1.0，观测值 52）与触觉线索（标准差 2.0，观测值 56）的似然以及结合后的后验（平坦先验），其均值 52.8 更接近更可靠的线索（权重 0.80 与 0.20），宽度比两者都小。B：触觉噪声为 2.0 时，视觉与触觉的权重随视觉噪声的变化：线为式 (27.2)，点来自 4000 次有线索冲突的模拟试验。视觉越嘈杂，其权重越下降。C：仅视觉、仅触觉和结合后估计的标准差；结合后的估计总是优于任何一个，在两条线索同样可靠时改善最大](./plots/cue-integration.py)

同样的加权把经典错觉解释为最优的知觉。在腹语术效应（ventriloquist effect）中，声音看起来来自木偶运动的嘴，因为视觉的定位远比听觉精确，所以视觉的权重很大，知觉移到视觉位置。Alais 与 Burr（2004）表明，若把视觉刺激模糊化，使其可靠性低于声音，效应就反转：声音捕获视觉位置。权重在一次试验之内就根据每条线索的瞬时可靠性调整，因此系统也必须表示这种可靠性（27.5 节）。

### 27.2.2. 神经相关

在猕猴中，背内侧上颞区（MSTd）和腹侧顶内区的神经元既响应视觉光流，也响应自身运动产生的前庭信号，并对前进方向调谐。Gu、Angelaki 与 DeAngelis（2008）在动物用视觉线索、前庭线索以及两者同时辨别前进方向时，记录了 MSTd 神经元。视觉与前庭偏好前进方向一致的神经元在结合条件下灵敏度更高，接近式 (27.2) 的最优预测，而偏好相反的神经元灵敏度更低；动物的阈值也接近最优预测。Morgan、DeAngelis 与 Angelaki（2008）表明，神经元对结合刺激的响应可以很好地近似为它对两条线索单独响应的加权和，随着视觉相干度下降，权重从视觉移向前庭。这些发现表明，**发放率**的加权和（权重取决于可靠性）可以实现线索整合；27.5 节说明为什么线性求和对类 Poisson 神经元群体恰好正确。

### 27.2.3. 因果推断：何时结合

式 (27.2) 假定两条线索来自同一个来源。当声和光在空间中相距很远时，观察者不应把它们融合：它们很可能由不同的物体引起，结合它们会产生介于二者之间的错误知觉。因此，大脑还必须推断线索是否有共同的原因。

**定义 27.2.1（因果推断模型）** 在**因果推断模型**（Körding 等，2007）中，观察者接收视觉位置和听觉位置的测量 $x_{\mathrm{v}}$ 与 $x_{\mathrm{a}}$，并考虑两种假设：$C = 1$，一个来源 $s \sim \mathcal{N}(\mu_0, \sigma_0^2)$ 产生了两个测量；$C = 2$，两个独立的来源 $s_{\mathrm{v}}, s_{\mathrm{a}}$，均来自同一先验，各产生一个测量。共同原因的先验概率为 $p_{\mathrm{c}}$。

线索噪声为 $\sigma_{\mathrm{v}}, \sigma_{\mathrm{a}}$ 时，对未知来源积分，得到似然

$$
\begin{aligned}
\mathbb{P}(x_{\mathrm{v}}, x_{\mathrm{a}} \mid C = 1) &= \frac{1}{2\pi\sqrt{V}}\exp\Bigl[-\frac{(x_{\mathrm{v}} - x_{\mathrm{a}})^2\sigma_0^2 + (x_{\mathrm{v}} - \mu_0)^2\sigma_{\mathrm{a}}^2 + (x_{\mathrm{a}} - \mu_0)^2\sigma_{\mathrm{v}}^2}{2V}\Bigr],\\
\mathbb{P}(x_{\mathrm{v}}, x_{\mathrm{a}} \mid C = 2) &= \frac{1}{2\pi\sqrt{(\sigma_{\mathrm{v}}^2 + \sigma_0^2)(\sigma_{\mathrm{a}}^2 + \sigma_0^2)}}\exp\Bigl[-\frac{(x_{\mathrm{v}} - \mu_0)^2}{2(\sigma_{\mathrm{v}}^2 + \sigma_0^2)} - \frac{(x_{\mathrm{a}} - \mu_0)^2}{2(\sigma_{\mathrm{a}}^2 + \sigma_0^2)}\Bigr],
\end{aligned} \tag{27.3}
$$
其中 $V = \sigma_{\mathrm{v}}^2\sigma_{\mathrm{a}}^2 + \sigma_{\mathrm{v}}^2\sigma_0^2 + \sigma_{\mathrm{a}}^2\sigma_0^2$，共同原因的后验概率为 $\mathbb{P}(C = 1 \mid x) = p_{\mathrm{c}}\mathbb{P}(x \mid C = 1)\big/\bigl[p_{\mathrm{c}}\mathbb{P}(x \mid C = 1) + (1 - p_{\mathrm{c}})\mathbb{P}(x \mid C = 2)\bigr]$。平方误差下听觉位置的最优估计是模型平均

$$
\hat s_{\mathrm{a}} = \mathbb{P}(C = 1 \mid x)\,\hat s_{C=1} + \mathbb{P}(C = 2 \mid x)\,\hat s_{\mathrm{a},C=2}, \tag{27.4}
$$
其中 $\hat s_{C=1} = \dfrac{x_{\mathrm{v}}/\sigma_{\mathrm{v}}^2 + x_{\mathrm{a}}/\sigma_{\mathrm{a}}^2 + \mu_0/\sigma_0^2}{1/\sigma_{\mathrm{v}}^2 + 1/\sigma_{\mathrm{a}}^2 + 1/\sigma_0^2}$ 是融合后的估计，$\hat s_{\mathrm{a},C=2}$ 是定理 27.1.1 的仅听觉估计。

当两个测量接近时，$\mathbb{P}(C = 1 \mid x)$ 很大，听觉估计被拉向视觉估计；当它们相差超过合成噪声时，共同原因的证据崩塌，声音被单独定位。视觉对听觉知觉的影响先随视听差异上升，然后又下降（见图），如对腹语术效应的测量：这是强制融合的模型（其影响无界增长）作不出的预测。Körding 等把该模型拟合到成对闪光与噪声爆发的定位上，发现它优于总是融合或从不融合的模型。因果推断可以推广到观察者必须判断哪些感觉事件属于一起的任何问题：把特征分组为物体，以及把声音与看得见的说话者绑定。

![视听定位的因果推断（Körding 等 2007 的模型；先验 N(0, 15²) 度，视觉噪声 2 度，听觉噪声 8 度，p_c = 0.5；视觉位置为 0，听觉位置等于视听差异；每个差异 20000 次含噪试验）。A：共同原因的平均后验概率随差异下降。B：听觉估计向视觉的偏移，相对于没有视觉线索时的估计。强制融合时偏移与差异成比例增长（虚线）；有因果推断时（实线），它先上升，当线索相距太远而不能共享原因时降到零](./plots/causal-inference.py)

## 27.3. 先验与偏差

### 27.3.1. 慢速先验

先验是关于世界统计的陈述，知觉应当偏向最常出现的刺激。在视觉运动中，慢速运动比快速运动更常见：世界中静止的物体在视网膜上运动缓慢，稳定场景的视网膜运动只是眼睛的运动。Weiss、Simoncelli 与 Adelson（2002）提出，视觉系统使用以零为中心的速度先验。

于是式 (27.1) 预测对比度依赖性：低对比度时测量噪声更大，$\sigma$ 更大，收缩因子 $k = \sigma_0^2/(\sigma_0^2 + \sigma^2)$ 下降，知觉到的速度降低（见图）。这与观察相符：低对比度图案看起来比同一速度的高对比度图案运动得更慢，在雾中或夜里看到的物体似乎运动得更慢（在模拟的雾中，驾驶员低估自己的速度；Snowden 等，1998）。同一先验也解释了低对比度运动线条和格栅的方向被错误知觉，即二维速度先验与孔径问题的结合。Stocker 与 Simoncelli（2006）把论证倒过来：他们根据几种对比度下的心理物理测量估计出先验的形状，而不预先假定它，得到近似为速度幂律、尾部比 Gaussian 更重、随速度增加而下降的先验。

### 27.3.2. 集中趋势

第二种无处不在的偏差，是判断向实验中呈现的刺激均值的回归，即 Hollingworth 在 1910 年描述的判断的集中趋势：小的量被高估，大的量被低估。在 Bayes 的解释中，观察者学到了实验中刺激的分布并把它当作先验。Jazayeri 与 Shadlen（2010）训练参与者复现取自较短或较长范围的时间间隔；复现的间隔向范围的中间回归，所以同一个间隔复现的结果取决于它所处的范围。时间内部测量的噪声随间隔增长，$\sigma = w\,t$，Weber 分数 $w \approx 0.1$（标量变异性，时间的 Weber 定律；比较 **Weber–Fechner 定律**），所以在测量不太可靠的长间隔处回归更大。均匀先验与标量噪声下的后验均值再现了这一模式（图的 C 图），只有一个自由参数，即 Weber 分数，它可以在单独的实验中测量。

## 27.4. 序列依赖

知觉也取决于刚才看到的东西。Fischer 与 Whitney（2014）让观察者在每次试验中通过转动反应条复现短暂呈现的光栅的朝向。尽管刺激是相互独立的，报告仍被拉向前面若干次试验（最早至几秒前）看到的朝向。当前知觉对最近刺激的这种依赖称为序列依赖（serial dependence）。偏差是差 $\Delta = s_{\mathrm{prev}} - s$ 的函数，形状为 Gaussian 的一阶导数：两个朝向相等时为零，在差达到约 $20^\circ$ 之前增长，对大的差则降为零。吸引性的序列依赖已在朝向、位置、数量、面孔、面孔身份和吸引力中发现，当前刺激不确定时以及前一个刺激受到注意时更强。

Bayes 的解释来自世界的连续性：视觉场景变化缓慢，前一刻的刺激是当前刺激的有用先验，但前提是二者属于同一物体或场景。设对当前刺激的先验是一个混合，

$$
p(s \mid s_{\mathrm{prev}}) = (1 - q)\,p_0(s) + q\,\mathcal{N}(s;\, s_{\mathrm{prev}}, \tau^2), \tag{27.5}
$$
以概率 $1 - q$ 取宽的背景先验 $p_0$，以概率 $q$ 取围绕前一刺激的窄分布。对方差为 $\sigma^2$ 的 Gaussian 测量 $x$，后验仍是一个混合，连续性成分上的权重正比于 $q\,\mathcal{N}(x;\, s_{\mathrm{prev}}, \sigma^2 + \tau^2)$，后验均值是两个成分估计的加权平均（如式 (27.4)）。若测量接近 $s_{\mathrm{prev}}$，连续性成分占优，估计被拉向 $s_{\mathrm{prev}}$；若远离它，该成分的权重可以忽略，先验不起作用。因此，偏差作为 $\Delta$ 的函数随 $\Delta$ 上升，在 $\sqrt{\sigma^2 + \tau^2}$ 量级的差处达到峰值，然后衰减到零，即 Gaussian 导数的形状（见图）。测量噪声越大，偏差越大，这与实验中对刺激不确定性的依赖相符。

大脑中是什么机制产生这种偏差？已有两类提议得到检验。一类认为前一个刺激留存在潜在的记忆痕迹中：Barbosa 等（2020）在猴子前额叶皮层和网络模型中发现，前一项目的短时突触痕迹（[7.16.12](/7.16.12)）在发放沉默时持续存在，并在工作记忆（[7.16.45](/7.16.45)）期间使下一项目引起的活动产生偏差。另一类认为序列依赖是感觉性的：早期视皮层水平的适应在短间隔上产生排斥性偏差，而吸引性效应是较晚的、更高水平的过程；这两种效应有不同的时间进程和刺激依赖性，并在观察到的偏差中结合在一起。Bayes 的解释并不在二者之间作选择；它说明机制必须实现什么计算，并预测对不确定性的依赖，任何机制都必须再现这一点。

## 27.5. 神经群体中的概率

Bayes 知觉要求大脑表示的不止是单个估计：式 (27.2) 的权重取决于每条线索的可靠性，后验是一个分布。一群神经元如何表示概率分布，又如何完成 Bayes 公式中的乘法与归一化？存在两类提议，区别在于神经元的变异性意味着什么。

### 27.5.1. 概率群体编码

在 Ma、Beck、Latham 与 Pouget（2006）的概率群体编码中，神经元的变异性是解码器必须考虑的噪声，刺激的似然函数由群体读出：响应 $\boldsymbol{r}$ 决定似然 $\mathbb{P}(\boldsymbol{r} \mid s)$，后验随之得出。取 26.3 节的 Poisson 群体，Gaussian 调谐，共同增益 $g$，$f_i(s) = g\exp[-(s - s_i)^2/2\sigma_f^2]$，偏好值均匀平铺刺激空间。

**定义 27.5.1（概率群体编码）** **概率群体编码**是这样一种**群体编码**：响应 $\boldsymbol{r}$ 表示刺激上的整个分布，即似然 $\mathbb{P}(\boldsymbol{r} \mid s)$（有先验时即后验），而不是单个估计。对类 Poisson 的变异性，$\mathbb{P}(\boldsymbol{r} \mid s) = \phi(\boldsymbol{r})\exp[\boldsymbol{h}(s)^{\mathsf T}\boldsymbol{r} - a(s)]$，对数似然是响应的线性函数；对独立的 Poisson 神经元，$h_i(s) = \ln f_i(s)$，$a(s) = \sum_i f_i(s)$。响应于是是基函数 $h_i(s)$ 上的一组权重，由此计算每个刺激的似然。

**定理 27.5.1（增益编码可靠性）** 对具有共同宽度 $\sigma_f$ 的 Gaussian **调谐曲线**和均匀分布的偏好值的独立 Poisson 神经元，响应 $\boldsymbol{r}$ 下 $s$ 的似然是 $s$ 的正态函数，均值为 $\hat s = \sum_i r_is_i/\sum_i r_i$，方差为 $\sigma_f^2/\sum_i r_i$。

**证明** 这就是式 (26.5) 与式 (26.4) 的曲率，其中 $\ln f_i(s) = \ln g - (s - s_i)^2/2\sigma_f^2$，且 $\sum_if_i(s)$ 与 $s$ 无关：$\ln\mathbb{P}(\boldsymbol{r} \mid s) = -\sum_ir_i(s - s_i)^2/2\sigma_f^2 + \mathrm{const}$，是 $s$ 的二次函数，最大值在 $\hat s$，曲率为 $\sum_ir_i/\sigma_f^2$。$\square$

似然的精度正比于群体中的脉冲总数。更高对比度或更多注意的刺激会提高增益，自动以更窄的似然表示，所以线索的可靠性由群体响应的幅度承载，不需要单独的信号（下图 C 图验证了估计在各次试验之间的方差等于由总计数读出的似然的宽度）。同一原理解释了线索的相乘。

**定理 27.5.2（求响应和实现线索结合）** 设两个具有相同调谐曲线 $f_i(s)$（至多相差增益）的群体接收关于 $s$ 的两条独立线索，其响应为 $\boldsymbol{r}^{\mathrm{a}}$ 与 $\boldsymbol{r}^{\mathrm{b}}$。响应为和 $\boldsymbol{r} = \boldsymbol{r}^{\mathrm{a}} + \boldsymbol{r}^{\mathrm{b}}$ 的第三个群体，其似然为 $\mathbb{P}(\boldsymbol{r} \mid s) \propto \mathbb{P}(\boldsymbol{r}^{\mathrm{a}} \mid s)\,\mathbb{P}(\boldsymbol{r}^{\mathrm{b}} \mid s)$，即两条线索似然的乘积。

**证明** 以式 (26.4) 的形式，对数似然关于响应是线性的：$\ln\mathbb{P}(\boldsymbol{r}^{\mathrm{a}} \mid s) + \ln\mathbb{P}(\boldsymbol{r}^{\mathrm{b}} \mid s) = \sum_i(r_i^{\mathrm{a}} + r_i^{\mathrm{b}})\ln f_i(s) - \sum_if^{\mathrm{a}}_i(s) - \sum_if_i^{\mathrm{b}}(s) + \mathrm{const}$，这是响应为 $\boldsymbol{r}$、增益等于增益之和的群体的对数似然（对均匀分布的调谐曲线，$\sum f_i$ 项与 $s$ 无关）。$\square$

因此，结合线索只需要脉冲计数的相加，神经元通过对突触输入求和就自然完成这一点，与 MSTd 中发现的响应线性组合相一致（27.2.2 节）。图中显示了两个增益不同的群体及其和群体，后者的似然与二者之积相同。式 (27.2) 的权重来自脉冲数的不等，因为脉冲更多的群体更可靠，对和的贡献更大。类 Poisson 的变异性，即方差正比于均值，是关键假设，皮层神经元的响应往往可以很好地用它描述（[7.16.16](/7.16.16#sec-16.4.3)）。非线性的计算，如对冗余变量的边缘化，需要对群体作非线性运算，**除法归一化**（[7.16.23](/7.16.23#sec-23.4.2)）是候选者之一。

### 27.5.2. 采样假说

在另一种提议中，神经变异性不是噪声，而是不确定性的表征：网络在每一时刻的活动是对后验分布的一个样本（Hoyer 与 Hyvärinen，2003；Fiser 等，2010）。$s$ 某个值的概率是网络停留在其附近的时间比例，所以窄的后验产生很小的变异性，宽的后验产生很大的变异性；多峰的后验由在几个状态之间游荡的活动表示，这是只有单峰的群体编码做不到的。这样的编码需要网络的动力学实现马尔可夫链 Monte Carlo 类型的采样器（[3.5.9](/3.5.9)），随机神经元的循环网络可以做到这一点（Pecevski 等，2011）。

支持的证据包括：雪貂视皮层在没有刺激时记录的自发活动，在发育过程中与自然图像引起的平均活动越来越相似（Berkes 等，2011），如果自发活动对先验采样，这正是所预期的。V1 神经元的变异性对对比度的依赖，也与刺激是存在性不确定的图像特征之和的模型所预测的一致（Orbán 等，2016）。

| | 概率群体编码 | 采样 |
|---|---|---|
| 不确定性由什么承载 | 群体响应的幅度（增益） | 活动随时间的变异性 |
| 变异性的含义 | 噪声（污染测量） | 信号（被采样的分布） |
| 线索的结合 | 脉冲计数相加 | 从各线索分布的乘积中采样 |
| 速度 | 快：一次响应 | 慢：需要许多样本 |
| 多峰后验 | 困难 | 自然 |
| 典型预测 | 可靠性越高，脉冲越多 | 可靠性越高，变异性越低 |

两种提议并不互斥：群体响应可以在短时间尺度上编码证据的幅度，而较长时间上的变异性编码剩余的不确定性。第三类编码，即分布式分布编码，用一组基函数的期望值来表示后验，这些期望值由神经元的**发放率**估计。

## 27.6. Bayes 框架的局限与检验

Bayes 框架是最成功的知觉定量理论，但也受到批评，这些批评界定了证据的标准。

第一，一个先验、似然和代价函数可以自由选取的模型可以拟合任何行为；若这些成分事后调整，这种解释就是一个"原来如此的故事"（Bowers 与 Davis，2012；Jones 与 Love，2011）。补救办法是这些成分应当独立测量：Ernst 与 Banks 由单一模态的数据导出结合后的阈值和权重，没有自由参数；Stocker 与 Simoncelli 由一组条件估计先验，并在其他条件上检验；Jazayeri 与 Shadlen 单独测量了 Weber 分数。模型还要与参数个数相同的替代模型比较，如因果推断模型与融合和分离模型的比较。

第二，行为并不总是最优的。文献综述发现有系统性的偏离：线索结合中的次优权重、先验的非最优使用，以及近似 Bayes 解的启发式方法（Rahnev 与 Denison，2018）。如果大脑使用资源有限的近似推断，这些偏离是预期之中的，而且有信息量：作出哪种近似，说明哪种计算是可行的。理想的 Bayes 观察者于是是度量偏离的基准，而不是大脑是最优的主张。

第三，该框架描述的是计算了什么（按 [7.16.1](/7.16.1) 中分析层次的意义），对如何计算则说得很少。27.5 节的神经实现作出不同的预测，仍未解决；框架对先验如何习得、生成模型在发育中如何获得、以及复杂的生成模型（如自然场景）如何在可用的几毫秒内被反演，也保持沉默。由数据学习生成模型的模型（如变分自编码器），以及反馈连接承载先验、前馈连接承载预测误差的预测编码理论，是试图解决这些问题的尝试（[7.16.48](/7.16.48)）。

## 小结

- 知觉被建模为推断（定义 27.1.1）。对 Gaussian 先验与似然，后验均值是测量与先验均值的精度加权平均，且精度相加（定理 27.1.1）；估计偏向先验，方差更小。
- 两条独立的 Gaussian 线索按正比于其可靠性的权重结合，结合后的方差低于任何一条（定理 27.2.1）。人类的视觉–触觉判断定量地遵循这一点；权重随可靠性移动，如在腹语术效应和 MSTd 神经元的响应中。
- 因果推断（定义 27.2.1，式 (27.4)）推断线索是否共享来源：一条线索对另一条的影响随差异先上升后下降。
- 先验造成偏差：慢速先验使低对比度刺激看起来更慢，判断的集中趋势来自由实验刺激习得的先验和标量测量噪声。序列依赖来自连续性先验（式 (27.5)），具有 Gaussian 导数的形状。
- 在具有类 Poisson 变异性的概率群体编码中，增益编码可靠性（定理 27.5.1），求响应和就是把似然相乘（定理 27.5.2）。在采样假说中，变异性本身表示不确定性。
- 该框架需要独立测量的成分，是度量偏离的基准；大脑如何实现和学习这些计算尚无定论。

## 思考题

1. 一个 Bayes 观察者的先验为 $s \sim \mathcal{N}(0, 10^2)$，测量为 $x = 8$，噪声 $\sigma = 5$。计算后验均值和标准差，以及测量上的权重。

   **答** 由定理 27.1.1，$k = \sigma_0^2/(\sigma_0^2 + \sigma^2) = 100/125 = 0.8$，这就是测量上的权重；$\mu_{\mathrm{post}} = 0.8\times8 = 6.4$（先验均值为 $0$），$\sigma_{\mathrm{post}}^2 = (1/25 + 1/100)^{-1} = 20$，所以 $\sigma_{\mathrm{post}} = 4.47$，比测量噪声 $5$ 更窄。
2. 视觉和触觉的标准差为 $1$ 和 $2$（以所判断的大小为单位）。计算权重和结合后的标准差。若视觉噪声加倍到 $2$，结果如何？哪种情形下相对于最佳单一线索的改善最大？

   **答** $w_{\mathrm{v}} = (1/1)/(1/1 + 1/4) = 0.8$，$w_{\mathrm{h}} = 0.2$，$\sigma_{12}^2 = 1\cdot4/(1 + 4) = 0.8$，$\sigma_{12} = 0.89$，比仅视觉改善 $11\,\%$。当 $\sigma_{\mathrm{v}} = 2$：权重为 $0.5$ 与 $0.5$，$\sigma_{12}^2 = 4\cdot4/8 = 2$，$\sigma_{12} = 1.41$，比任一线索好 $\sqrt2$ 倍。改善在两条线索同样可靠时最大（定理 27.2.1）；当一条线索可靠得多时，另一条几乎没有增加什么。
3. 一个 Gaussian 先验在平均间隔附近的标准差为 $\sigma_0 = 0.1\,\mathrm{s}$，间隔的测量标准差为 $0.1\,\mathrm{s}$。复现间隔对呈现间隔的斜率是多少？若观察者先在较窄的范围上受训，斜率会如何变化？

   **答** 斜率就是收缩因子 $k = \sigma_0^2/(\sigma_0^2 + \sigma^2) = 0.01/0.02 = 0.5$：比均值长 $0.1\,\mathrm{s}$ 的间隔只被复现为长 $0.05\,\mathrm{s}$。范围较窄时先验更尖锐（$\sigma_0$ 更小），$k$ 减小，向均值的回归更强；范围较宽时则减弱，这就是 Jazayeri 与 Shadlen 所见的对范围的依赖。
4. 两个具有相同**调谐曲线**、增益分别为 $1.5$ 和 $5$ 的 Poisson 群体接收两条线索。群体 b 在求和群体中的期望权重是多少？为什么单次试验的权重会偏离这一值？

   **答** 由定理 27.5.1，来自一个群体的似然的精度为 $\sum_ir_i/\sigma_f^2$，期望总计数正比于增益，所以期望权重为 a 的 $1.5/6.5 = 0.23$ 和 b 的 $5/6.5 = 0.77$（定理 27.5.2：求和响应以脉冲数为权重对两个似然加权）。在单次试验中，总计数是 Poisson 的，在图的例子中期望值约为 $15$ 与 $50$（41 个神经元，间隔 $2$，宽度 $8$：$\sum_i f_i \approx g\sqrt{2\pi}\,\sigma_f/2$），标准差约为 $4$ 与 $7$；图中所示的试验里它们是 $20$ 与 $48$，所以实际权重（$20/68 = 0.29$ 与 $0.71$）逐次试验涨落：大脑的权重追踪每次试验中证据的可靠性，而不是平均可靠性。
5. （开放题）设计一个实验，在视皮层中区分概率群体编码与采样编码。

   **答** 两种提议赋予变异性相反的角色，并预测操纵刺激不确定性的不同效应。呈现不确定性独立于平均驱动而受控的刺激，例如朝向固定但噪声或模糊可变的光栅，并记录 V1 或 V2 中的一个群体。概率群体编码预测不确定性改变响应的幅度（总计数），变异性为类 Poisson，Fano 因子保持在 $1$ 附近；由单次试验解码的似然应当预测动物报告分布的宽度。采样编码预测更高的不确定性使一次试验内的活动变异性更大、状态的分布更宽，例如在均值固定时群体活动的方差更大，以及持续整个试验的随时间的缓慢涨落（[7.16.16](/7.16.16#sec-16.4.3)），并且自发活动的分布与诱发活动的平均相符。试验内变异性的时间进程及其对不确定性的依赖方面的差异是区分性的测量；刺激的选择必须避免对比度同时改变不确定性和增益这一混杂。
