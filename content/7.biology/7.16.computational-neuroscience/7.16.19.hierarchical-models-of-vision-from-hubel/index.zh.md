上一章沿着视觉信号从 V1 走到 IT，发现神经元的选择性与不变性逐级增强（[7.16.18](/7.16.18)）。本章要问的是：能否用在每一级重复的同一个计算原理来解释整个层级。Hubel 和 Wiesel 提出**复杂细胞**汇聚**简单细胞**，由此产生了一系列层级模型，从 Fukushima 的 Neocognitron（1980）到现代机器学习的**卷积神经网络**，后者又成为目前最好的腹侧通路模型。卷积网络的结构、训练与优化见 [4.7.3](/4.7.3) 和 [4.7.4](/4.7.4)，此处不再重复；本章把它们当作关于大脑的假说来处理：它们如何与神经数据比较，在哪里一致，在哪里失败。

## 19.1. 选择性–不变性问题

物体识别必须调和两个相反的要求。表征必须有选择性：它必须把一张脸与相似的脸区分开，把"7"与"1"区分开。它又必须有不变性：同一个物体在不同的位置、大小、姿态、光照下，或被部分遮挡时，必须给出同样的结果。在像素空间中这两个要求相互冲突。一个物体在其所有变换下的图像，在像素强度空间中形成一个弯曲的低维流形，而不同物体的流形相互缠绕：同一位置上两张不同的脸的图像，在像素空间中可能比同一张脸在不同位置的两张图像更接近。

DiCarlo 和 Cox（2007）提出，腹侧通路的工作方式是解开这些流形，使得到 IT 一级时不同物体的流形线性可分：下游神经元于是可以用 IT 响应的加权和再加阈值读出物体的身份，IT 群体的线性解码也提示了这一点（[7.16.18](/7.16.18#sec-18.5.3)）。每一级都必须产生一个表征，它既稍微更有选择性（通过组合前一级的特征，一种类似 AND 的运算），又稍微更不变（通过在位置或尺度上汇聚特征，一种类似 OR 的运算）。Hubel 和 Wiesel 的简单细胞与复杂细胞是这两种运算的最初实例。

## 19.2. Neocognitron 与 HMAX

### 19.2.1. S 层与 C 层的交替

**定义 19.2.1（简单–复杂层级）** 简单–复杂层级交替使用两种层。S 层（"简单"）中的单元计算下一层局部单元块的活动 $\boldsymbol{x}$ 的调谐函数，当 $\boldsymbol{x}$ 与存储的模板 $\boldsymbol{w}$ 匹配时最大；同一模板在所有位置复制。C 层（"复杂"）中的单元在相邻位置或尺度上汇聚具有相同模板的 S 单元，汇聚方式为求和、平方和或取最大值。

在 Neocognitron（Fukushima 1980）中，S 单元是由无监督竞争规则学习得到的阈值线性滤波器，C 单元是局部平均；该网络能识别有平移和畸变的手写数字。HMAX（Riesenhuber 和 Poggio 1999）使汇聚运算明确化：

$$
r_{\mathrm{S}} = \exp\Bigl(-\frac{\|\boldsymbol{x} - \boldsymbol{w}\|^2}{2\sigma^2}\Bigr), \qquad r_{\mathrm{C}} = \max_{j \in \text{pool}} r_{\mathrm{S},j}. \tag{19.1}
$$

HMAX 的第一个 S 层由 **Gabor 滤波器**（V1 简单细胞）组成，第一个 C 层是它们的局部最大值（复杂细胞），更高的 S 层把 C1 的输出组合成从自然图像中学到的中等复杂度的模板（V4），它们在整个视野上的最大值给出位置不变的单元（后部 IT）。取最大值而不是求和，在**感受野**内含有杂乱背景时保持选择性：对偏好刺激的响应不会被其他刺激稀释。与此一致，猫 V1 中约一半的复杂细胞对感受野内两根条的响应，与单独对较强的那一根的响应近似相同（Lampl 等，2004）。[7.16.18](/7.16.18#sec-18.2.3) 的**能量模型**就是对一对正交对做平方和的 C 运算。

### 19.2.2. 感受野的增长

重复的局部运算使感受野沿层级增大。对于核大小为 $K_l$、步长为 $s_l$ 的层堆叠（汇聚层是步长大于 1 的层），第 $l$ 层单元的感受野 $r_l$（以输入像素度量）满足

$$
r_l = r_{l-1} + (K_l - 1)\,j_{l-1}, \qquad j_l = j_{l-1}s_l, \qquad r_0 = j_0 = 1, \tag{19.2}
$$
其中 $j_l$ 是第 $l$ 层相邻单元在输入中的距离。在步长均为 1 时感受野只线性增长，$r_L = 1 + L(K - 1)$；有汇聚时 $j_l$ 几何增长，$r_l$ 也是。在猕猴腹侧通路中，偏心度几度处的感受野直径从 V1 的不到 $1^\circ$，经 V4 的几度，增大到 IT 的 $10^\circ$ 以上，这样的增长需要下采样，大脑与网络都是如此。

![层级网络中感受野的增长，式 (19.2)。A：感受野大小随层数的变化，分别为步长 1 的 3 × 3 卷积（线性增长，$1 + 2L$）、每两个卷积后加 2 × 2 汇聚（几何增长），以及第一层核为 11 像素、步长为 4 的类 AlexNet 堆叠。B：核宽为 3 的网络中第 3 层一个单元对其下各单元的依赖：其感受野覆盖 $1 + 3(3 - 1) = 7$ 个输入单元](./plots/receptive-field-growth.py)

## 19.3. 作为腹侧通路模型的卷积网络

### 19.3.1. 任务优化的模型

HMAX 的早期阶段是固定的、手工设计的，在困难的识别任务上达不到灵长类的表现。从 2012 年起，用**反向传播**在数百万张带标签的照片上训练的卷积网络，在这类任务上达到了人类水平的准确率（[4.7.3](/4.7.3)）。它们是简单–复杂层级，其中每一层的模板都是为优化某个任务而学习得到的，其第一层滤波器在没有任何此类指令的情况下，类似于 Gabor 函数和颜色拮抗斑。

Yamins、DiCarlo 及其同事（2014）问这类网络是否也能解释神经响应。他们把同一组几千张物体图像呈现给猴子（用多电极阵列记录 V4 和 IT）以及许多网络变体。每个被记录神经元的响应由网络某一层单元的交叉验证线性回归预测（回归映射）。有三个突出的结果：

1. 网络在物体分类上做得越好，其顶层解释的 IT 响应方差就越多，尽管没有网络是用神经数据训练的。
2. 最好的网络解释了 IT 位点约一半的可解释方差，大约是此前模型的两倍。
3. 顶层最能预测 IT，中间层最能预测 V4：网络的层级与皮层的层级对齐。

这种方法称为目标驱动或任务优化建模。它用针对某一行为优化模型取代了把模型拟合到神经元，然后用大脑检验其内部表征。同样的策略产生了听觉皮层模型（训练用于识别单词和音乐类型的网络，Kell 等，2018）、背侧通路模型（19.6 节）以及运动系统模型（[7.16.32](/7.16.32)）。拟合 V4 的网络还被用于控制：合成出使某个 V4 位点的预测响应最大化的图像，驱动真实神经元产生了超过它对任何自然图像的响应（Bashivan、Kar 和 DiCarlo 2019），这是检验模型是否抓住了神经元所计算内容的有力证据。

### 19.3.2. 表征相似性分析

回归把一个单元映射到一个神经元，并且需要很多刺激。第二种方法不拟合任何映射就比较表征。

**定义 19.3.1（表征相似性分析）** 设 $\boldsymbol{r}_i$ 是某个系统（用记录或 fMRI 测量的脑区，或模型的一层）对刺激 $i$（$i = 1, \dots, n$）的响应模式。该系统的表征相异矩阵（RDM）是 $n\times n$ 矩阵，元素为

$$
D_{ij} = 1 - \operatorname{Corr}(\boldsymbol{r}_i, \boldsymbol{r}_j),
$$
或响应模式之间的其他距离。**表征相似性分析**（representational similarity analysis，RSA）用两个系统 RDM 的上三角之间的秩相关来比较它们（Kriegeskorte、Mur 和 Bandettini 2008）。

RDM 抽象掉了单元的身份与数目：猴子 IT 中 $100$ 个神经元的群体、人类 fMRI 的体素模式和有 $4096$ 个单元的网络层，都可以在同一基础上比较，不同物种之间也一样。人类与猴子的 IT 对同样的图像有惊人相似的 RDM，主要分为有生命与无生命物体，并进一步细分出面孔与身体（Kriegeskorte 等，2008），深度网络各层的 RDM 随着网络为分类而训练得越充分，就越接近 IT 的 RDM（Khaligh-Razavi 和 Kriegeskorte 2014）。统计推断把观察到的相关与噪声上限比较，噪声上限是真实 RDM 与由含噪数据估计的 RDM 之间预期的相关，它限定了任何模型能做到的程度。

![用一个小型卷积层级做的表征相似性分析（定义 19.3.1）。刺激为 48 张合成图像，分四类（水平、垂直和对角的条，十字；H、V、D、X），每个样本在 ±8 像素内随机取位置，并带随机对比度和噪声。第 1 层是每个位置上四个方向 Gabor 滤波器的能量，第 2 层是 4 × 4 块上的最大值，第 3 层是整幅图像上的最大值。一个由 60 个整流单元组成的合成"IT"群体把第 3 层特征与噪声混合。A：像素、第 3 层和合成 IT 的 RDM（深色：相似）。在像素空间中，同一类别在不同位置的图像与不同类别的图像一样相异；在对位置不变的第 3 层中，四个类别形成块。B：各阶段 RDM 与 IT 的 RDM 的 Spearman 相关；它沿层级增大，因为不变性逐步建立](./plots/rsa-demo.py)

### 19.3.3. 比较显示了什么，没有显示什么

任务优化网络的成功常常被误解。它并不表明大脑使用反向传播（学习算法是另一个问题，[7.16.50](/7.16.50)），也不表明网络的单个单元对应神经元。它表明的是，任务的约束加上层级的卷积结构，在很大程度上决定了每一级的表征。这些网络的预测能力也只是部分的：IT 可解释方差中相当一部分仍未被解释，而且架构差别很大但性能相近的网络可以有同样的预测能力，所以这种方法很难在它们之间做出区分。

## 19.4. 网络与大脑的差异

### 19.4.1. 对抗样本

一个正确分类某张图像的网络，可以通过加上人眼看不见的扰动，被诱使以高置信度错误分类（Szegedy 等，2014）。Goodfellow、Shlens 和 Szegedy（2015）认为，这类对抗样本是高维中近似线性的结果，而不是过拟合的结果。

**定理 19.4.1（高维中的线性脆弱性）** 设一个单元计算 $z = \boldsymbol{w}\cdot\boldsymbol{x}$，$\boldsymbol{w} \in \mathbb{R}^n$，扰动 $\boldsymbol{\eta}$ 的每个分量有界，$\|\boldsymbol{\eta}\|_\infty \leq \varepsilon$。$z$ 可达到的最大变化为 $\varepsilon\|\boldsymbol{w}\|_1$，在 $\boldsymbol{\eta} = \varepsilon\operatorname{sgn}(\boldsymbol{w})$ 时取到。若 $\boldsymbol{w}$ 的各分量大小相当，且 $\|\boldsymbol{w}\|_2 = 1$，则对 Gaussian 权重 $\|\boldsymbol{w}\|_1 \approx \sqrt{2n/\pi}$，而符号随机的扰动只使 $z$ 改变约 $\varepsilon\|\boldsymbol{w}\|_2 = \varepsilon$。

**证明** $\lvert\boldsymbol{w}\cdot\boldsymbol{\eta}\rvert \leq \sum_i \lvert w_i\rvert\lvert\eta_i\rvert \leq \varepsilon\|\boldsymbol{w}\|_1$，当 $\eta_i = \varepsilon\operatorname{sgn}(w_i)$ 时取等号。对于独立的、方差为 $1/n$ 的正态 $w_i$，$\mathbb{E}\lvert w_i\rvert = \sqrt{2/(\pi n)}$，所以 $\|\boldsymbol{w}\|_1 \approx n\sqrt{2/(\pi n)} = \sqrt{2n/\pi}$。对于随机符号 $\varepsilon_i = \pm 1$，$\boldsymbol{w}\cdot\boldsymbol{\eta} = \varepsilon\sum_i \varepsilon_i w_i$ 的均值为零，方差为 $\varepsilon^2\sum_i w_i^2 = \varepsilon^2$。$\square$

因此，远低于可见阈值的逐像素改变，在数十万个像素上累加起来，会使单元输入的变化大到越过决策边界，只要它与梯度对齐。快速梯度符号法 $\boldsymbol{x}' = \boldsymbol{x} + \varepsilon\operatorname{sgn}\nabla_{\boldsymbol{x}}L$ 正是利用这一点。

![高维中的线性脆弱性（定理 19.4.1）。A：使 $\|\boldsymbol{w}\|_2 = 1$ 的线性单元的输入改变一个单位所需的逐分量扰动预算 $\varepsilon$，随输入维数 $n$ 的变化。与权重符号对齐的扰动需要 $\varepsilon = 1/\|\boldsymbol{w}\|_1 \approx \sqrt{\pi/2n}$（点线），当 $n > 10^4$ 时它低于 0.01；符号随机的扰动无论 $n$ 多大都需要 $\varepsilon \approx 1$。B：对于 $n = 784$（28 × 28 的图像）和每像素 $\varepsilon = 0.05$，5000 个随机符号扰动产生的变化（直方图，标准差 0.05）与对抗扰动产生的变化（线，约 −1.1）的对比](./plots/adversarial-linear.py)

人类也并非完全免疫：针对一组网络设计的扰动，短暂呈现后会使人的判断略有偏向（Elsayed 等，2018）。但差距很大，它指向大脑具有而标准网络缺乏的性质：早期处理中的噪声与随机性、**除法归一化**、视网膜的低通滤波与中央凹化，以及循环处理。第一阶段是带有 Gabor 滤波器、归一化和噪声的 V1 模型的网络（VOneNet）明显更稳健（Dapello 等，2020）。

### 19.4.2. 纹理与形状

在 ImageNet 上训练的网络，会把有猫的形状而有象皮纹理的图像分类为大象，而人类则称之为猫（Geirhos 等，2019）。标准网络依赖局部纹理统计，这对训练集已经足够；用风格迁移把纹理随机化的图像来训练，会增加形状偏向，也增加对畸变的稳健性。这种差异表明，网络可以匹配一项任务而不匹配视觉系统的策略，训练数据与目标的选择和架构一样塑造表征。

### 19.4.3. 循环与反馈

腹侧通路不是前馈的流水线。每个前馈投射都有对应的反馈投射，每个区域内部的循环连接多于前馈输入（[7.16.18](/7.16.18#sec-18.4)）。核心物体识别，即一瞥之间识别物体，是很快的（猴子大约在 $200$–$250\,\mathrm{ms}$ 内完成分类，IT 响应在刺激开始后约 $100\,\mathrm{ms}$ 就携带类别信息），这使前馈解释显得合理。

但对于前馈网络失败而猴子能解决的图像，物体身份在 IT 中比简单图像晚约 $30\,\mathrm{ms}$ 出现，给网络模型加上循环连接可以抓住这一晚到的信息（Kar 等，2019）；使反馈的一个来源前额叶皮层失活，则会削弱它。循环还能补全被遮挡的物体并实现注意（[7.16.18](/7.16.18#sec-18.7)），层数更少的循环网络通过沿时间展开可以匹配深的前馈网络。反馈也是预测编码理论的基础，在这类理论中高级区域发送预测，低级区域发送预测误差（[7.16.48](/7.16.48)）。

## 19.5. 自监督模型

用数百万张带标签的图像做监督训练，并不是灵长类学会看的方式：婴儿几乎得不到标签。**自监督学习**（[4.6.1](/4.6.1)；其方法见 [4.7.7](/4.7.7)）通过解决一个借口任务，从无标签数据中学习表征，例如使同一张图像的两个增强视图的表征相似、不同图像的表征相异（对比学习）。以这种方式训练的网络，预测腹侧通路响应的效果与监督网络大致相当：Zhuang 等（2021）发现，对比嵌入目标在无监督方法中给出了最好的 V4 和 IT 模型，与监督模型相当，即使用从一名儿童头戴相机记录的视频（SAYCam 数据集）来训练也是如此。这一结果削弱了关于标签的反对意见：塑造腹侧通路的任务可能就是视觉输入本身的预测或一致性。自监督目标、生成模型与作为推断的知觉理论之间的关系在 [7.16.48](/7.16.48) 展开。

## 19.6. 背侧通路的模型

同样的策略适用于运动。一个经典的 MT 机制模型汇聚 V1 的运动能量单元（[7.16.18](/7.16.18#sec-18.2.3)），这些单元的时空频率调谐位于频率空间中对应于给定速度的平面上，并对它们做除法归一化；它再现了 MT 细胞的模式方向选择性及其速度调谐（Simoncelli 和 Heeger 1998）。训练用于从视频估计光流或自身运动的网络，会产生具有类 MT 和类 MST 调谐的单元，而外观与运动分开成两个通路的网络，识别动作的效果优于单通路网络，这是对两个皮层通路分工的一个计算论据。背侧通路还服务于行动，它的模型与感觉运动控制一起在 [7.16.29](/7.16.29) 中讨论。

| 模型族 | 机制 | 优点 | 主要局限 |
|---|---|---|---|
| Neocognitron、HMAX | 手工设计的 S 与 C 阶段，最大汇聚 | 与简单、复杂细胞有明确联系；不变性由设计保证 | 在自然图像上表现差 |
| 监督 CNN | 学习得到的 S 阶段，汇聚，为分类而训练 | 对 V4/IT 响应的最佳预测；层–区对应 | 对抗脆弱性、纹理偏向、需要标签、前馈 |
| 循环 CNN | 加上侧向与反馈连接 | 抓住困难图像上晚到的信息 | 参数更多，更难解释 |
| 自监督 CNN | 从一致性或预测中无标签学习 | 预测能力相当；训练信号合理 | 架构上的局限相同 |

## 小结

- 物体识别既需要选择性又需要不变性；腹侧通路可以看作不断解开物体流形，直到身份在 IT 中可线性解码（19.1 节）。
- 简单–复杂层级（定义 19.2.1）交替进行模板匹配与汇聚；HMAX 使用最大值，式 (19.1)，它在杂乱背景中保持选择性。感受野按式 (19.2) 增长，无下采样时线性增长，有下采样时几何增长。
- 任务优化的卷积网络对 V4 和 IT 响应的预测与其性能成正比，并有层–区对应（19.3.1 节）；表征相似性分析（定义 19.3.1）通过相异矩阵比较系统，与单元无关。
- 网络与大脑的差异在于：对抗脆弱性（由高维中的线性解释，定理 19.4.1）、纹理偏向，以及缺少循环（循环携带了困难图像的信息）（19.4 节）。
- 自监督网络对腹侧通路的预测与监督网络一样好（19.5 节）；运动能量模型与任务优化模型可以解释 MT（19.6 节）。

## 思考题

1. 利用式 (19.2)，计算五层 $5\times5$ 卷积（每层之后接步长为 $2$ 的 $2\times2$ 汇聚）之后一个单元的感受野。与没有汇聚的五层 $5\times5$ 卷积比较。

   **答** 把每个卷积（$K = 5$，$s = 1$）和每个汇聚（$K = 2$，$s = 2$）都当作一层。从 $r = j = 1$ 开始。卷积 1：$r = 5$，$j = 1$；汇聚：$r = 6$，$j = 2$。卷积 2：$r = 6 + 4\cdot2 = 14$；汇聚：$r = 16$，$j = 4$。卷积 3：$r = 32$；汇聚：$r = 36$，$j = 8$。卷积 4：$r = 68$；汇聚：$r = 76$，$j = 16$。卷积 5：$r = 140$；汇聚：$r = 156$，$j = 32$。没有汇聚时，$r = 1 + 5\cdot4 = 21$。汇聚使感受野增大约七倍，并使单元数减少 $4^5 \approx 1000$ 倍。

2. 为什么基于 RDM 的比较不依赖于哪个网络单元对应哪个神经元？举出两个 RDM 相同但单单元调谐不同的表征的例子。

   **答** RDM 只取决于对成对刺激的响应模式之间的相关（或距离）。任何保持这些量的变换，例如单元的置换，或对欧氏距离而言响应空间的正交旋转，都使 RDM 不变。例子：一个由各自调谐于一个特征维度的神经元组成的群体，与一个其单元是这些维度的随机标准正交混合的群体，具有相同的欧氏 RDM，尽管后一群体的单个单元具有混合的、无法解释的调谐。因此 RSA 检验的是表征的几何结构，而不是其元素的调谐。

3. 证明定理 19.4.1 那种对抗脆弱性并不依赖于网络的非线性，但可以被非线性削弱。V1 中神经响应的哪种性质会限制它？

   **答** 定理只用到单元的线性部分；一个其单元大多工作在线性范围的深度网络（ReLU 是分段线性的）继承了这一点，因为此时输入的梯度在邻域内是一个固定向量，沿其符号的扰动会累积。饱和或归一化的非线性（除法归一化，即把每个响应除以其邻居的汇聚活动）降低了分散在许多输入上的扰动的有效增益，而早期阶段的噪声使梯度方向不可靠。V1 响应随对比度饱和、被归一化而且有噪声；这些性质限制了 $\|\nabla_{\boldsymbol{x}}r\|_1$，也是使受 V1 启发的前端更稳健的特征之一。

4. （开放题）架构差别很大的任务优化网络对 IT 响应的解释程度大致相同。提出一个能区分两个这样的模型的实验或分析。

   **答** 可能的方法：(a) 模型驱动的刺激合成，生成使两个模型做出最大不同预测的图像（有争议的刺激），并记录神经元对它们的响应；(b) 逐图像比较行为（跨图像的错误模式，而不只是准确率），这能区分平均意义上一致的模型；(c) 因果检验：使一个脑区失活，把行为的变化与在各模型中去掉对应层的效果比较；(d) 时间动力学：把神经响应的时间进程与模型的循环版本比较。这些方法都超越了自然图像上的平均预测准确率，而当前的模型正是在那里趋同的。
