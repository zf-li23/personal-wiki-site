[7.16.21 章](/7.16.21)说明了视觉系统的连线由相关活动精修，**NMDA 受体**报告突触前后活动的巧合，而两眼的分离和**眼优势柱**的形成依赖竞争。本章把这些观察转化为数学：只使用局部信息（所连接的两个神经元的活动）的突触规则，在暴露于统计输入系综的群体中能做到什么？答案出人意料地丰富：这类规则能提取主成分、发展出选择性的感受野并生成功能图。长时程可塑性的细胞机制，包括**脉冲时间依赖可塑性**的实验基础，见 [7.16.14](/7.16.14)。

记号：突触前活动构成向量 $\boldsymbol{u} = (u_1, \dots, u_{N_u})$，分量是非负或减去均值后的**发放率**；输出率为 $r = \boldsymbol{w}\cdot\boldsymbol{u}$，$\boldsymbol{w}$ 为权重向量（即 [7.16.15](/7.16.15) 的线性率模型，取 $r$ 瞬时跟随输入的极限）；$\langle\cdot\rangle$ 表示对输入系综的平均，$Q = \langle\boldsymbol{u}\boldsymbol{u}^{\mathsf T}\rangle$ 为相关矩阵。其特征值记作 $\lambda_\mu$，特征向量为 $\boldsymbol{e}_\mu$，按 $\lambda_1 \ge \lambda_2 \ge \dots$ 排序（这里 $\lambda$ 是特征值，不是长度常数）。可塑性比 $r$ 的动力学和刺激的呈现都慢，因此权重的变化可以用其对输入系综的平均来代替。

## 22.1. Hebb 规则及其不稳定性

**公式 22.1.1（基本 Hebb 规则）** 在基本 **Hebb 规则**中，突触权重的变化与突触前、后活动的乘积成正比：

$$
\tau_w\frac{\mathrm{d}\boldsymbol{w}}{\mathrm{d}t} = r\,\boldsymbol{u}, \qquad \text{平均后：}\quad \tau_w\frac{\mathrm{d}\boldsymbol{w}}{\mathrm{d}t} = \langle r\,\boldsymbol{u}\rangle = Q\boldsymbol{w}, \tag{22.1}
$$
其中时间常数 $\tau_w$ 远大于 $r$ 的时间尺度和单个刺激的持续时间，因此权重对许多刺激积分（实验中可塑性在数分钟至数小时内形成）。

$\langle r\boldsymbol{u}\rangle = Q\boldsymbol{w}$ 的形式表明，Hebb 规则是基于相关的规则：它只通过 $Q$ 依赖于输入。它是一个正反馈过程，因为增强的突触使 $r$ 增大，从而促进进一步增强。

**定理 22.1.1（Hebb 规则的不稳定性）** 记 $\boldsymbol{w}(0) = \sum_\mu c_\mu(0)\boldsymbol{e}_\mu$。式 (22.1) 的解为 $\boldsymbol{w}(t) = \sum_\mu c_\mu(0)\,\mathrm{e}^{\lambda_\mu t/\tau_w}\boldsymbol{e}_\mu$。若 $c_1(0) \ne 0$，则 $\boldsymbol{w}(t)$ 的方向收敛到 $Q$ 的主特征向量 $\boldsymbol{e}_1$，而其长度无界增长，$\lvert\boldsymbol{w}\rvert \propto \mathrm{e}^{\lambda_1 t/\tau_w}$。

**证明** $Q$ 对称半正定，故其特征向量构成正交基，特征值非负。在这组基下，式 (22.1) 化为 $\tau_w\dot c_\mu = \lambda_\mu c_\mu$，由此得到解。比值 $c_\mu/c_1 = (c_\mu(0)/c_1(0))\,\mathrm{e}^{-(\lambda_1 - \lambda_\mu)t/\tau_w}$ 在 $\lambda_1 > \lambda_\mu$ 时对 $\mu \ne 1$ 趋于零。$\square$

该规则有两个缺陷，任何可用的模型都必须修补。其一，权重无限增长，而 **LTP** 会饱和，突触也不会变号。其二，若输入为正且相关，所有权重会同时被增强，神经元因而丧失选择性：非负活动的相关矩阵的主特征向量，其分量全为正。简单的限制（$0 \le w \le w_{\max}$，即饱和）能阻止增长，却不能阻止选择性的丧失，也不产生竞争。竞争，即一些突触增强时另一些必须减弱，正是 [7.16.21](/7.16.21#sec-21.4) 中实验所显示、而我们希望得到的性质。

## 22.2. 约束、归一化与 Oja 规则

### 22.2.1. 突触归一化

**定义 22.2.1（突触归一化）** **突触归一化**是使一个神经元上突触的总强度（或其范数）保持不变的约束。若从所有突触中减去相同的量，使 $\sum_b w_b$ 不变，则称为减法归一化；若所有突触乘以相同的因子，使 $\lvert\boldsymbol{w}\rvert$ 不变，则称为乘法归一化。

减法归一化为 $\tau_w\,\mathrm{d}\boldsymbol{w}/\mathrm{d}t = Q\boldsymbol{w} - \bigl(\boldsymbol{n}\cdot Q\boldsymbol{w}/N_u\bigr)\boldsymbol{n}$，其中 $\boldsymbol{n} = (1, \dots, 1)$：变化中沿 $\boldsymbol{n}$ 的分量被去除。若 $\boldsymbol{n}$ 是 $Q$ 的特征向量（如平移不变的相关），均值模式被消除，其余本征模式照常增长，于是在均值为零的模式中特征值最大的那个得到发展，直到权重达到上下界，结果是每个权重要么为 $0$，要么为 $w_{\max}$（尖锐的二值结果）。

乘法归一化让 $\boldsymbol{w}$ 的方向像 **Hebb 规则**那样演化，只是对其缩放，得到渐变的结果，即 $Q$ 的主特征向量（Miller 与 MacKay 1994）。两种规则都需要非局部信号，即同一神经元其他突触的信息。生物学上的候选机制是资源在突触之间的再分配（如 **AMPA 受体**的供应）和**突触缩放**（[7.16.14](/7.16.14)）。

### 22.2.2. Oja 规则

**定义 22.2.2（Oja 规则）** 在 **Oja 规则**中，Hebb 规则上加入一个与输出平方成正比的衰减项：

$$
\tau_w\frac{\mathrm{d}\boldsymbol{w}}{\mathrm{d}t} = r\,\boldsymbol{u} - \alpha r^2\boldsymbol{w}, \tag{22.2}
$$
其中 $\alpha$ 为正常数。衰减只依赖突触处可得的量（$r$ 与权重 $w_b$ 本身），它以局部形式实现了乘法归一化。

**定理 22.2.1（Oja 规则计算第一主成分）** 若 $\lambda_1 > \lambda_2$，则式 (22.2) 的平均形式 $\tau_w\dot{\boldsymbol{w}} = Q\boldsymbol{w} - \alpha(\boldsymbol{w}^{\mathsf T}Q\boldsymbol{w})\boldsymbol{w}$ 有稳定不动点 $\boldsymbol{w} = \pm\boldsymbol{e}_1/\sqrt{\alpha}$，其余不动点都不稳定。

**证明** 在不动点处 $Q\boldsymbol{w} = \alpha(\boldsymbol{w}^{\mathsf T}Q\boldsymbol{w})\boldsymbol{w}$，所以 $\boldsymbol{w}$ 是特征向量 $\boldsymbol{e}_\mu$，其特征值满足 $\lambda_\mu = \alpha\lambda_\mu\lvert\boldsymbol{w}\rvert^2$，从而 $\lvert\boldsymbol{w}\rvert^2 = 1/\alpha$（或 $\boldsymbol{w} = 0$）。为判断稳定性，展开 $\boldsymbol{w} = \sum_\mu c_\mu\boldsymbol{e}_\mu$：$\tau_w\dot c_\mu = \lambda_\mu c_\mu - \alpha\bigl(\sum_\nu\lambda_\nu c_\nu^2\bigr)c_\mu$。于是 $\tau_w\,\mathrm{d}\ln\lvert c_\mu/c_1\rvert/\mathrm{d}t = \lambda_\mu - \lambda_1 < 0$，所以所有 $\mu \ne 1$ 的分量 $c_\mu/c_1$ 衰减，而长度被三次项驱动到 $1/\sqrt\alpha$。位于 $\boldsymbol{e}_\mu$（$\mu \ne 1$）的不动点不稳定，因为比值 $c_1/c_\mu$ 增长。$\square$

这一结果把 Hebb 可塑性与**主成分分析**（[3.4.5](/3.4.5)）联系起来：带有 Hebb 突触和局部归一化的神经元学会计算输入在最大方差方向上的投影，这是均方误差意义下对输入的最优线性压缩；再加上侧向去相关规则，一个神经元群体就能学到前几个主成分（Sanger 1989；Oja 1992）。对于具有自然图像统计的输入，主成分是类 Fourier 的图案，而不是 V1 中局部化的 Gabor 形状（[7.16.20](/7.16.20#sec-20.5)）：仅有二阶相关是不够的，这正是引入稀疏规则和类协方差规则的动机。

## 22.3. 协方差规则与 BCM 规则

### 22.3.1. 协方差规则

**Hebb 规则**的一个弱点是，只要输出不为零它就增强突触，因此没有长时程抑制。实验中 LTD 出现在突触后活动较低时（它与 LTP 一起构成 [7.16.14](/7.16.14) 中 Ca$^{2+}$ 控制假说的基础）。一个简单的修补是相对于阈值来度量活动。

**定义 22.3.1（协方差规则）** 在**协方差规则**中，突触前活动相对于其均值来度量，$\tau_w\,\mathrm{d}\boldsymbol{w}/\mathrm{d}t = r\,(\boldsymbol{u} - \langle\boldsymbol{u}\rangle)$，其平均为

$$
\tau_w\frac{\mathrm{d}\boldsymbol{w}}{\mathrm{d}t} = C\boldsymbol{w}, \qquad C = \langle(\boldsymbol{u} - \langle\boldsymbol{u}\rangle)(\boldsymbol{u} - \langle\boldsymbol{u}\rangle)^{\mathsf T}\rangle,
$$
即输入的协方差矩阵。（在突触后一侧设阈值 $(r - \theta_r)\boldsymbol{u}$，当 $\theta_r = \langle r\rangle$ 时给出相同的平均。）

平均后的规则与式 (22.1) 形式相同，只是以 $C$ 代替 $Q$，所以定理 22.1.1 适用：权重朝协方差的主特征向量演化，并且与 $Q$ 不同，这个特征向量的分量有正有负，因而可以具有选择性。该规则既有 LTP 又有 LTD，但仍不稳定，需要 22.2 节的约束。

### 22.3.2. 带滑动阈值的 BCM 规则

Bienenstock、Cooper 与 Munro（1982）的规则让阈值本身成为动态量，因而无需对权重施加显式约束，就能得到稳定性和选择性。

**定义 22.3.2（BCM 规则）** 在 **BCM 规则**中，权重的变化是突触后活动的非线性函数，在阈值 $\theta$ 处变号：

$$
\tau_w\frac{\mathrm{d}\boldsymbol{w}}{\mathrm{d}t} = r\,(r - \theta)\,\boldsymbol{u}, \qquad \theta = \frac{\langle r^2\rangle}{r_0}, \tag{22.3}
$$
其中 $r_0$ 为常数；模拟中 $\theta$ 取 $r^2$ 的滑动平均，时间常数 $\tau_\theta$ 远大于单个刺激的呈现时间，但小于 $\tau_w$；若阈值滑动得比权重变化更慢，规则就会振荡或失稳。当 $r > \theta$ 时突触被增强，当 $0 < r < \theta$ 时被压抑。

函数 $\phi(r, \theta) = r(r - \theta)$ 在图中给出，它与 LTP、LTD 的频率依赖性相符：低频时抑制，高频时增强；$\theta$ 随突触后活动历史的滑动对应于**元可塑性**（[7.16.14](/7.16.14)）。$\theta$ 的反馈是稳定性的来源：若神经元变得更活跃，$\theta$ 上升，增强就转为抑制。

**定理 22.3.1（BCM 规则的选择性）** 以相等的概率向神经元呈现 $K$ 个线性无关的模式 $\boldsymbol{u}^{(k)}$，并记 $r^{(k)} = \boldsymbol{w}\cdot\boldsymbol{u}^{(k)}$。平均后的规则 (22.3) 的不动点对每个 $k$ 都有 $r^{(k)} \in \{0, \theta\}$；若有 $m$ 个模式满足 $r^{(k)} = \theta$，则 $\theta = Kr_0/m$。只有 $m = 1$ 的不动点是稳定的：神经元恰好只响应一个模式，$r = \theta = Kr_0$，而对其他 $K - 1$ 个模式完全不响应。

**证明** 我们证明不动点条件。由于各模式线性无关，平均变化为零当且仅当对每个 $k$ 有 $r^{(k)}(r^{(k)} - \theta) = 0$。设有 $m$ 个模式处于 $r = \theta$，则 $\theta = \langle r^2\rangle/r_0 = m\theta^2/(Kr_0)$，所以 $\theta = Kr_0/m$。稳定性分析表明 $m \ge 2$ 的不动点有一个不稳定方向，这归功于 Intrator 与 Cooper（1992）。$\square$

结论是，BCM 神经元对其输入之一变得有选择性，具体是哪一个由初始条件决定，并且最具选择性的状态是稳定的。图中，四个模式与 $r_0 = 1$ 给出获胜模式的 $r = \theta = 4$，其余模式为 $0$。BCM 理论解释了剥夺对**关键期**的影响：单眼闭合后，被剥夺输入的活动微弱且不相关，其响应低于 $\theta$ 而被压抑；而双眼闭合后 $\theta$ 向下滑动，抑制没有那么强，这正是 [7.16.21](/7.16.21#sec-21.4.2) 中的观察。暗饲养使 $\theta$ 保持在低位，从而延长了高可塑性时期，与观察一致（Cooper 与 Bear 2012）。

## 22.4. 脉冲时间依赖可塑性与相关学习

对相连神经元对的实验表明，可塑性的符号取决于脉冲的先后次序：突触前脉冲比突触后脉冲早几毫秒时增强，反过来则抑制，时间常数为 $10$–$30\,\mathrm{ms}$（[7.16.14](/7.16.14)）。上述率规则可以通过对这种**脉冲时间依赖可塑性**（STDP）取平均而得到。

**公式 22.4.1（成对 STDP）** 设 $s = t_{\mathrm{post}} - t_{\mathrm{pre}}$ 为一对脉冲的时间差。取窗口

$$
W(s) = \begin{cases} A_+\mathrm{e}^{-s/\tau_+}, & s > 0 \quad \text{（突触前在先：增强）},\\ -A_-\mathrm{e}^{s/\tau_-}, & s < 0 \quad \text{（突触后在先：抑制）},\end{cases} \tag{22.4}
$$
每一对脉冲使权重改变 $W(s)$（以最大权重为单位），所有脉冲对的改变相加（全对全相互作用）。

**定理 22.4.1（平均 STDP）** 设 $\rho_{\mathrm{pre}}(t)$ 与 $\rho_{\mathrm{post}}(t)$ 为**脉冲序列**。权重的期望变化率为

$$
\Bigl\langle\frac{\mathrm{d}w}{\mathrm{d}t}\Bigr\rangle = \int_{-\infty}^{\infty}W(s)\,\Gamma(s)\,\mathrm{d}s, \qquad \Gamma(s) = \langle\rho_{\mathrm{pre}}(t)\rho_{\mathrm{post}}(t + s)\rangle .
$$
对于速率分别为 $r_{\mathrm{pre}}$ 与 $r_{\mathrm{post}}$ 的独立 Poisson 序列，$\Gamma(s) = r_{\mathrm{pre}}r_{\mathrm{post}}$，漂移为 $r_{\mathrm{pre}}r_{\mathrm{post}}(A_+\tau_+ - A_-\tau_-)$。若 $A_-\tau_- > A_+\tau_+$，则不相关的突触平均而言被削弱。

**证明** 权重的变化是所有脉冲对上 $W(t_{\mathrm{post}} - t_{\mathrm{pre}})$ 之和，即单位时间内为 $\int\!\!\int\rho_{\mathrm{pre}}(t)\rho_{\mathrm{post}}(t')W(t' - t)\,\mathrm{d}t\,\mathrm{d}t'$，取平均即得相关函数。对独立 Poisson 序列，$\Gamma$ 为常数，$W$ 的积分为 $A_+\tau_+ - A_-\tau_-$。$\square$

由此得到两条性质。第一，若窗口的净面积为负，使不相关输入的漂移为负，突触之间就会竞争：突触后**发放率**被弱突触的抑制所压制，只有彼此相关的输入（它们使神经元发放，因而在窗口内后面跟着突触后脉冲）才被增强（Song、Miller 与 Abbott 2000）。第二，由于增强施加于突触前在先的情形，STDP 对次序敏感，而不仅仅对相关性敏感：它偏爱最先发放的输入，即那些预测突触后脉冲的输入，在群体中可以使响应向更早的输入偏移。当速率缓慢变化时，该规则化为式 (22.1) 形式的相关规则，并多出一项与 $W$ 的积分成正比的项（[7.16.14](/7.16.14)）。

## 22.5. 眼优势的发育

[7.16.21 章](/7.16.21#sec-21.4)描述了两眼对皮层领地的竞争。在 Miller、Keller 与 Stryker（1989）的模型及其简化版本中，这是带归一化的基于相关的学习的结果。设一维皮层中的皮层细胞 $x$ 接受来自左眼和右眼传入纤维的输入，这些传入纤维位于一个树状区内，位置为 $x + a$，$\lvert a\rvert \le A$。同一眼的传入纤维彼此相关，$Q(d)$ 随它们在视网膜或 LGN 中的距离 $d$ 而减小；不同眼的传入纤维不相关。皮层细胞通过函数 $B(x - x')$ 相互作用，该函数是短程兴奋、较长程抑制。两眼在传入纤维位置上的权重为 $w^{\mathrm{R}}$ 与 $w^{\mathrm{L}}$；由于和 $w^{\mathrm{R}} + w^{\mathrm{L}}$ 受归一化控制，我们将其固定为常数，只考察差 $D = w^{\mathrm{R}} - w^{\mathrm{L}} \in [-1, 1]$。

**公式 22.5.1（眼优势模型）** 对皮层活动应用 22.1 节的相关规则（输入通过皮层相互作用 $B$ 滤波），差 $D$ 按下式演化：

$$
\tau_w\frac{\partial D(x, a)}{\partial t} = \sum_{x'}B(x - x')\sum_{a'}Q\bigl(x + a - x' - a'\bigr)D(x', a'), \tag{22.5}
$$
其中 $D$ 被限制在 $[-1, 1]$ 内（饱和）。初始时 $D$ 很小且随机。

**定理 22.5.1（条纹周期）** 若树状区相对于相关距离很宽，使得对每个偏移 $d$ 有 $\sum_{a'}Q(d + a - a') \approx Q_{\mathrm{tot}}$，则模式 $D(x, a) = \mathrm{e}^{\mathrm{i}kx}$ 以速率 $Q_{\mathrm{tot}}\hat B(k)/\tau_w$ 增长，其中 $\hat B$ 是 $B$ 的 Fourier 变换。增长最快的模式其波数 $k^*$ 使 $\hat B$ 取最大值，眼优势条纹的初始周期为 $2\pi/k^*$。

**证明** 把该模式代入式 (22.5) 并对 $a'$ 求和，得 $Q_{\mathrm{tot}}\sum_{x'}B(x - x')\mathrm{e}^{\mathrm{i}kx'} = Q_{\mathrm{tot}}\hat B(k)\,\mathrm{e}^{\mathrm{i}kx}$。线性增长为 $\mathrm{e}^{Q_{\mathrm{tot}}\hat B(k)t/\tau_w}$。$\square$

当 $B$ 是**差分高斯**，兴奋的宽度为 $\sigma_e$、抑制的宽度为 $\sigma_i > \sigma_e$ 时，$\hat B(k)$ 在某个非零的 $k^*$ 处取最大值，这就是条纹有偏好周期的原因：周期由皮层内相互作用的范围决定，而不由传入纤维的相关性决定（后者只决定总体增长率），并且侧向抑制防止一只眼占据整个皮层。$D$ 的均值是 $k = 0$ 的模式，在这种情形下其增长率低于 $k^*$。随后饱和把条纹固定下来，边界锐利，取值为 $\pm1$。

![眼优势条纹的发育（公式 22.5.1；环上 96 个皮层细胞，树状区含 17 个传入位置，传入相关为宽度 2.5 的 Gaussian，皮层相互作用为宽度 2 与 7 的差分高斯，相对抑制强度 0.25，$D$ 截断在 $[-1, 1]$ 内）。A：各皮层细胞在起始和之后各时刻的眼优势指数：微弱的随机差异增长为右眼与左眼交替的优势条纹。B：每个皮层细胞（纵向）与传入偏移（横向）的最终差 $D(x, a)$：各眼的区域边界锐利，因树状区重叠而略有倾斜。C：眼优势指数的功率谱：峰值在 0.04–0.07 周期每细胞的空间频率，周期为 14 到 25。线性理论（定理 22.5.1）对这些宽度预测 $k^* = 0.325$，周期 19.4 个细胞；终态条纹的平均周期约为 16，因为树状区只是适度地宽](./plots/ocular-dominance.py)

该模型再现了真实皮层的三个特征：条纹从两眼之间微小的随机差异中自发出现，与关键期之前的分离相符；条纹宽度是回路的性质；若给一只眼以优势（相关较弱或活动较低），另一只眼的条纹会扩大，如同单眼剥夺。两眼之间的正相关会削弱分离，完全相关的输入则没有分离；反之，斜视使两眼去相关，造成几乎所有细胞都是单眼性的皮层（Hubel 与 Wiesel 1965）。眼特异性传入相关的发育来源是 [7.16.21](/7.16.21#sec-21.5) 的**视网膜波**。

## 22.6. 方位选择性与自组织映射

### 22.6.1. 由相关产生的感受野

同一原理解释了感受野的空间结构如何产生。Linsker（1986）在具有局部 Gaussian 连接的分层前馈网络中证明，仅由空间相关的随机活动驱动，采用减法归一化的 **Hebb 规则**逐层产生中心–周边细胞，进而产生具有取向性兴奋与抑制区的细胞，而无需任何有结构的输入。

其机制是定理 22.1.1 的特征向量问题：感受野是 $Q$ 在允许的模式中特征值最大的特征向量，$Q$ 的对称性由树状区的形状打破。Miller（1994）把分析推广到来自 LGN、供给同一皮层细胞的 ON 中心与 OFF 中心传入纤维：两条通路之间的竞争导致它们分离为并排的 ON 与 OFF 子区，这正是**简单细胞**的结构（[7.16.18](/7.16.18#sec-18.2.4)）。

在雪貂中，方位选择性与方位图在睁眼时就已出现，早于任何有图案的视觉经验，随后由经验精修和维持，这与自发活动建立最初结构的图景一致。

### 22.6.2. Kohonen 映射

带**风车中心**的偏好方位图（[7.16.18](/7.16.18#sec-18.3.2)）可以借助一个抽象的功能图形成模型来理解。皮层平面被建模为单元网格，每个单元在刺激特征空间中有一个权重向量 $\boldsymbol{w}_i$。

**定义 22.6.1（自组织映射）** 在**自组织映射**（Kohonen 1982）中，每个刺激 $\boldsymbol{u}$ 选出权重向量最近的单元 $c = \arg\min_i\lVert\boldsymbol{u} - \boldsymbol{w}_i\rVert$，所有单元按其在平面上与获胜者的接近程度成比例地向刺激移动：

$$
\boldsymbol{w}_i \leftarrow \boldsymbol{w}_i + \eta\,h(\lVert\boldsymbol{\xi}_i - \boldsymbol{\xi}_c\rVert)\,(\boldsymbol{u} - \boldsymbol{w}_i), \qquad h(d) = \mathrm{e}^{-d^2/2\sigma_h^2}, \tag{22.6}
$$
其中 $\boldsymbol{\xi}_i$ 为单元 $i$ 在平面上的位置。

邻域函数 $h$ 所起的作用与皮层相互作用 $B$ 相同：相邻单元从同样的刺激中学习，因而变得相似。所得的映射保持刺激空间的拓扑：当刺激空间的维数高于平面（如视觉刺激的位置、方位、眼别和空间频率）时，映射折叠以覆盖该空间，奇点（风车中心）就是特征在很小的距离内变化其全部范围的地方（Durbin 与 Mitchison 1990；Obermayer、Ritter 与 Schulten 1990）。

自组织映射是抽象的：获胜者通过全局比较选出，更新 (22.6) 是非局部的。它们与 Hebb 规则的关系是：胜者通吃式的选择可由侧向抑制实现，更新可由带衰减的 Hebb 规则（如式 (22.2)）在获胜单元处实现。这类模型再现了接近每平方柱间距 $\pi$ 的风车中心密度，以及方位图与眼优势图之间的关系（等方位线与眼优势条纹的边界成直角相交）。

## 22.7. 竞争学习与监督学习

上述无监督规则在没有教师的情况下发现输入中的结构。在竞争学习（competitive learning）中，即定义 22.6.1 的规则在没有邻域时的极端情形，只有侧向竞争的获胜者把权重移向输入，$\Delta\boldsymbol{w}_c = \eta(\boldsymbol{u} - \boldsymbol{w}_c)$：这是 $k$ 均值算法（[3.4.11](/3.4.11)）的在线版本，把刺激空间划分为由单个单元表示的类别。其生物学基础是皮层网络中的抑制性竞争（[7.16.15](/7.16.15)），在获胜者处配以 Hebb 型规则。

在监督学习中，权重的改变是为了减小输出与期望目标之间的误差，如目标为 $r^{\ast}$ 的 delta 规则 $\Delta\boldsymbol{w} = \eta(r^{\ast} - r)\boldsymbol{u}$，它与**感知机**（[4.7.2](/4.7.2)）的学习规则近似。它需要教学信号。生物学上的候选者有小脑的攀缘纤维，它把误差信号传给 Purkinje 细胞（[7.16.33](/7.16.33)），以及传递奖励预测误差并作为第三因子门控可塑性的**神经调质**（[7.16.39](/7.16.39)）；皮层是否以及如何跨多层实现误差反向传播，见 [7.16.50](/7.16.50)。

三种学习范式的差别在于突触所需的信息。纯 Hebb 突触需要突触前、后细胞的活动；竞争学习需要标识获胜者的信号；监督学习需要误差。视觉系统的发育中，所有信息都来自自发活动与感觉活动的相关，是前两者的最佳例子。

## 小结

| 主题 | 核心关系 |
|---|---|
| 基本 Hebb 规则（公式 22.1.1，定理 22.1.1） | $\tau_w\dot{\boldsymbol{w}} = Q\boldsymbol{w}$；方向收敛到 $Q$ 的主特征向量，长度发散 |
| 归一化（定义 22.2.1） | 减法：去除均值模式，给出带竞争的二值权重；乘法：保持 $\lvert\boldsymbol{w}\rvert$，给出渐变的结果 |
| Oja 规则（定义 22.2.2，定理 22.2.1） | $\tau_w\dot{\boldsymbol{w}} = r\boldsymbol{u} - \alpha r^2\boldsymbol{w}$ 收敛到 $\boldsymbol{e}_1/\sqrt\alpha$：主成分分析 |
| 协方差规则（定义 22.3.1） | 以协方差 $C$ 代替 $Q$；有 LTP 和 LTD，但仍不稳定 |
| BCM 规则（定义 22.3.2，定理 22.3.1） | $r(r - \theta)$，$\theta = \langle r^2\rangle/r_0$：稳定且有选择性；神经元响应 $K$ 个模式之一，$r = \theta = Kr_0$ |
| STDP（公式 22.4.1，定理 22.4.1） | 平均漂移 $\int W(s)\Gamma(s)\,\mathrm{d}s$；当 $A_-\tau_- > A_+\tau_+$ 时不相关的突触衰减，相关输入获胜 |
| 眼优势（公式 22.5.1，定理 22.5.1） | 条纹由 $\hat B(k)$ 最大的模式增长；周期 $2\pi/k^*$ 由皮层内相互作用决定 |
| 方位与功能图（定义 22.6.1） | 感受野是输入相关的特征向量；Kohonen 映射（邻域 $h$）保持拓扑并产生风车中心 |
| 学习范式（22.7 节） | Hebb 型：突触前后活动；竞争：获胜者；监督：误差信号 |

## 思考题

1. 一个神经元的输入具有相关矩阵 $Q = \begin{bmatrix}2 & 1\\ 1 & 2\end{bmatrix}$。求 $\alpha = 1$ 的 Oja 规则以及带减法归一化（$\boldsymbol{n} = (1, 1)$）的基本 **Hebb 规则**的长期权重向量。

   **答** $Q$ 的特征值为 $3$（对应 $\boldsymbol{e}_1 = (1, 1)/\sqrt2$）和 $1$（对应 $\boldsymbol{e}_2 = (1, -1)/\sqrt2$）。Oja 规则给出 $\boldsymbol{w} = \pm(1, 1)/\sqrt2$，$\lvert\boldsymbol{w}\rvert = 1$。对减法归一化，均值模式 $\boldsymbol{n} \propto \boldsymbol{e}_1$ 被去除，所以 $\boldsymbol{w}$ 沿 $\boldsymbol{e}_2$ 演化：和 $s = w_1 + w_2$ 守恒，而差 $w_1 - w_2$ 按 $\mathrm{e}^{t/\tau_w}$ 增长，因此在权重以 $0$ 为下界时，规则终止于 $(s, 0)$ 或 $(0, s)$，取决于初始差的符号（若 $s \le w_{\max}$）：一个突触独占，这就是两个突触之间的竞争。

2. 一个 BCM 神经元接受 $K = 3$ 个出现频率相等、线性无关的模式，$r_0 = 1$。存在哪些不动点？每种情形下 $\theta$ 与 $\langle r^2\rangle$ 各是多少？

   **答** 由定理 22.3.1，$m$ 个模式处于 $r = \theta$、其余处于 $r = 0$ 时，$\theta = K r_0/m = 3/m$。$m = 1$：$\theta = 3$，$\langle r^2\rangle = \tfrac13\cdot9 = 3$，有选择性且稳定。$m = 2$：$\theta = 3/2$，两个模式的 $r = 3/2$，$\langle r^2\rangle = \tfrac23\cdot\tfrac94 = 3/2$（不稳定）。$m = 3$：$\theta = 1$，$\langle r^2\rangle = 1$（不稳定）。所有情形都满足 $\theta = \langle r^2\rangle/r_0$，与要求一致。

3. 取 $A_+ = 0.005$，$A_- = 1.05A_+$，$\tau_+ = \tau_- = 20\,\mathrm{ms}$，突触前与突触后均为 $15\,\mathrm{Hz}$ 的独立 Poisson 序列，权重每秒的平均漂移（以 $g_{\max}$ 为单位）是多少？若突触后速率加倍，会怎样变化？

   **答** 窗口的积分为 $A_+\tau_+ - A_-\tau_- = 0.005\cdot20\,\mathrm{ms}\,(1 - 1.05) = -0.005\,\mathrm{ms}$。取 $r_{\mathrm{pre}}r_{\mathrm{post}} = (0.015\,\mathrm{ms^{-1}})^2$，漂移为 $-1.1\times10^{-6}\,\mathrm{ms^{-1}} = -1.1\times10^{-3}\,\mathrm{s^{-1}}$。若 $r_{\mathrm{post}}$ 加倍，漂移也加倍（它正比于 $r_{\mathrm{post}}$）：更高的突触后活动加强对不相关突触的抑制，这是稳定发放率的负反馈。

4. 对 22.5 节的皮层相互作用（$\sigma_e = 2$，$\sigma_i = 7$，抑制幅度 $0.25$），推导使 $\hat B(k) \propto 2\mathrm{e}^{-2k^2} - 0.25\cdot7\,\mathrm{e}^{-49k^2/2}$ 取最大值的波数 $k^*$，并求条纹周期。

   **答** 宽度为 $\sigma$、幅度为 1 的 Gaussian 的 Fourier 变换为 $\sigma\sqrt{2\pi}\,\mathrm{e}^{-\sigma^2k^2/2}$，所以 $\hat B \propto 2\mathrm{e}^{-2k^2} - 1.75\,\mathrm{e}^{-24.5k^2}$。导数为零当且仅当 $8k\,\mathrm{e}^{-2k^2} = 85.75\,k\,\mathrm{e}^{-24.5k^2}$（因子为 $1.75\times49$），即 $\mathrm{e}^{22.5k^2} = 85.75/8 = 10.72$，$k^{*2} = \ln 10.72/22.5 = 0.1054$。因此 $k^* = 0.325$，周期为 $2\pi/k^* = 19.4$ 个细胞，即图中给出的值。

5. （开放题）基于相关的模型与 Kohonen 映射都能产生带**风车中心**的**方位图**。哪些实验观察可以区分二者？

   **答** 两个模型的假设不同。在基于相关的模型中，感受野与功能图来自作用于 LGN 输入相关的线性局部规则，功能图取决于传入纤维树状区的空间结构和皮层内相互作用的范围；Kohonen 模型则假设有获胜者的选择，并把特征嵌入到特征空间中。可以区分二者的观察包括：功能图的波长对皮层相互作用范围和树状区大小（以 LGN 轴突的扩散范围度量）的依赖；在暗中饲养的动物中去除有图案的输入对功能图的影响（相关模型预测功能图来自自发相关；Kohonen 模型需要特征空间中的刺激系综）；方位边界与眼优势边界之间的关系；以及视觉统计改变（条纹饲养）下功能图的变化。由于两个模型在许多参数下给出相似的功能图，风车中心密度与功能图的功率谱等定量统计量是常用的区分指标。
