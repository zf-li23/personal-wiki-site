**强化学习**是从行动的后果中学习该做什么：智能体处在环境中，观察状态、采取行动并获得奖赏，需要找到一种行动方式，使长期累积的奖赏最大。它是条件反射（[7.16.38](/7.16.38#sec-38.2)）的计算理论；自从发现多巴胺神经元编码**奖赏预测误差**（[7.16.37](/7.16.37#sec-37.4)）以来，它又成为算法与其神经实现之间最成功的桥梁之一。其一般思想及在博弈中的应用见 [4.5.3](/4.5.3#sec-3.6)；由于站内没有页面系统地展开这套理论，本章完整定义其核心对象：Markov 决策过程、价值函数与 Bellman 方程、动态规划，以及无模型算法 TD 学习、SARSA 和 Q 学习。我们沿着历史的顺序，先从 Pavlov 学习的心理学出发，沿时序差分的思想走到多巴胺数据，再建立形式理论。直接学习策略、基于模型的规划与元学习见 [7.16.41](/7.16.41)；利用这些信号的基底神经节回路见 [7.16.40](/7.16.40)。

## 39.1. 从心理学到算法：Rescorla–Wagner 规则

### 39.1.1. 规则

人们曾认为 Pavlov 条件反射取决于条件刺激（CS）与无条件刺激（US）在时间上的邻近。20 世纪 60 年代的实验表明，邻近并不充分：关键在于 CS 是否提供了关于 US 的信息。在阻断效应（Kamin，1969）中，动物先学会声音预示电击；之后在声音上再加一个灯光，复合刺激与同一电击配对，动物对灯光几乎什么也没学到，尽管灯光与电击配对的次数和声音一样多。电击已经被预测，灯光没有增加任何信息。

**定义 39.1.1（Rescorla–Wagner 规则）** 在 **Rescorla–Wagner 规则**（1972）中，每个条件刺激 $i$ 有一个联想强度 $V_i$，每次试验中，出现的所有刺激的强度都按下式变化：
$$
\Delta V_i = \alpha_i \beta \Bigl(\lambda - \sum_{j \in \text{present}} V_j\Bigr),
$$
其中 $\lambda$ 是 US 所能支持的最大强度（无 US 的试验中 $\lambda = 0$），$\alpha_i$ 是刺激 $i$ 的显著性，$\beta$ 是由 US 决定的学习率。

这条规则有三个关键特征：变化由预测误差驱动，即结果 $\lambda$ 与总预测之差；预测由所有出现的刺激共同分担，因而它们竞争联想强度；规则与自适应滤波的 delta 规则（最小均方规则）相同，也等价于对线性特征下的平方误差 $\frac12(\lambda - \sum_j V_j)^2$ 做**随机梯度下降**（[3.5.5](/3.5.5)），这把条件反射与监督学习联系了起来。

![Rescorla–Wagner 规则（定义 39.1.1，$\alpha\beta = 0.2$）。A：30 次 CS–US 配对中联想强度的获得，以及 30 次仅给 CS 的试验中的消退；二者都按指数趋近渐近值。B：阻断效应。经过 A+ 预训练后，对复合刺激 AX 强化时新加入的刺激 X 几乎不获得强度（红）；而经过无关刺激 B 的预训练后，它获得一半的可用强度（蓝）。](./plots/rescorla-wagner.py)

### 39.1.2. 能解释什么，不能解释什么

这条规则可以解释阻断、遮蔽（更显著的刺激获得更多共享强度）、条件抑制（预示本应出现的 US 不会出现的刺激获得负强度）、US 大小对渐近值的影响，以及部分强化：当 $\lambda$ 时而为 0、时而为 1 时，$V$ 在强化概率附近波动。它无法解释消退后的自发恢复（[7.16.37](/7.16.37#sec-37.2.3)）、潜伏抑制（预先暴露于 CS 会减慢之后的学习），而最重要的是，它无法解释一切依赖于试验内部时间的现象：规则把一次试验当作单个事件，因此无法解释为什么 CS 必须先于 US，为什么 CS–US 间隔越长学习越弱，也无法解释二级条件反射，即与已被条件化的 CS 配对（而从未与 US 配对）的 CS 也获得价值。这些都需要一种关于时间中预测的理论。

## 39.2. 时序差分学习

### 39.2.1. 预测未来奖赏之和

Sutton 与 Barto（1990）把条件反射重新表述为这样一个问题：在每个时刻 $t$ 预测未来奖赏的折扣和
$$
G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty}\gamma^k R_{t+k+1}, \tag{39.1}
$$
其中 $0 \le \gamma \le 1$ 是折扣因子。这个量满足递推关系 $G_t = R_{t+1} + \gamma G_{t+1}$：时刻 $t$ 的预测应当等于下一个奖赏加上时刻 $t + 1$ 的预测的折扣值。这一关系被违反的程度就是学习信号。

**定义 39.2.1（时序差分误差）** 设 $\hat v(s)$ 是对从状态 $s$ 出发的未来折扣奖赏期望的估计。在从 $S_t$ 到 $S_{t+1}$、得到奖赏 $R_{t+1}$ 的转移上，**时序差分误差**（TD 误差）为
$$
\delta_t = R_{t+1} + \gamma\,\hat v(S_{t+1}) - \hat v(S_t),
$$
而**时序差分学习**按 $\hat v(S_t) \leftarrow \hat v(S_t) + \alpha\,\delta_t$ 更新刚离开的状态的估计，$\alpha$ 为学习率（TD(0) 规则）。

TD 学习是自举的：它用另一个预测来改进当前预测，而不必等待最终结果。在条件反射中，“状态”是试验内的刺激历史。一种常用的表示是完全串行复合刺激，即抽头延迟线，它为 CS 起始后的每个时间步分配一个特征，使 CS 后 $t$ 时刻的价值是对应 $k = t - t_{\mathrm{CS}}$ 的学得权重 $w_k$。

### 39.2.2. 条件反射中的 TD 学习

在下面的模拟中，每次试验里线索出现 2 s 后给予奖赏。第一次试验中奖赏无法预测，奖赏时刻的 $\delta$ 为正。更新抬高了奖赏前一时间步的价值，于是下一次试验中，一个较小的正误差提前一步出现，位于转入该状态的转移处；随着试验推进，误差向后传播，直到线索处。由于线索出现的时刻本身不可预测（线索前状态的价值为 0），线索处的误差保持为正，$\delta = \gamma\,\hat v(\text{cue})$，而奖赏处的误差消失。如果此后奖赏被省略，奖赏前状态的价值之后没有奖赏跟随，于是在预期的奖赏时刻出现 $\delta = 0 - \hat v < 0$。这正是**多巴胺**反应的三个性质（[7.16.37](/7.16.37#sec-37.4)）。

![线索–奖赏联想的时序差分学习（带抽头延迟线的 TD(0)，$\gamma = 0.98$，$\alpha = 0.2$，时间步 $0.1\,\mathrm{s}$；线索在 0 时刻，奖赏 $R = 1$ 在 $2\,\mathrm{s}$ 时）。A：200 次训练试验中每次试验的 TD 误差（红为正，蓝为负）；误差一步一步从奖赏移向线索。B：单次试验；第一次试验中误差出现在奖赏处（灰），训练后出现在线索处（$\delta = \gamma^{20} \approx 0.67$，蓝），训练后若省略奖赏，则在预期奖赏时刻出现负误差（红，虚线）。](./plots/td-dopamine.py)

TD 学习还能解释击败了 Rescorla–Wagner 规则的那些现象。二级条件反射之所以出现，是因为预示有价值线索的线索在自己出现时产生正的 TD 误差，从而不借助任何奖赏获得价值；CS–US 间隔越长学习越弱，是因为折扣和时间的表示把预测分散到更多状态上；CS 必须先于 US，是因为只有奖赏之前的状态才被更新。有两个预测是 TD 所特有的。第一，学习过程中误差的向后传播，在抽头延迟线模型中每次试验一步，应当能在训练期间的多巴胺反应中看到；对在线索–奖赏任务中受训小鼠的多巴胺轴突的记录发现了这样的逐步迁移（Amo 等，2022），不过其形式取决于时间的表示。第二，如果奖赏比预期提前出现，应当在新时刻出现正误差、在通常的时刻出现负误差，Hollerman 与 Schultz（1998）正是这样发现的。

## 39.3. 多巴胺与 TD 误差

**注 39.3.1（多巴胺 TD 假说）** 中脑多巴胺神经元相对于基线的相位性发放，近似于脑内其他地方计算出的未来奖赏估计 $\hat v$ 的 TD 误差 $\delta_t$；纹状体与皮层中的多巴胺释放充当第三因子，门控编码当前状态的活动的突触的可塑性，借助资格迹 $e$ 实现 $w \leftarrow w + \alpha\,\delta_t\,e$（Schultz、Dayan 与 Montague，1997）。

证据是 [7.16.37](/7.16.37#sec-37.4) 中描述的一系列实验：反应从奖赏转移到线索、奖赏省略时的发放暂停、随概率与幅度的变化、对被阻断刺激无反应，以及用光遗传学的爆发与暂停代替预测误差的因果效应。机制上的联系是带有**资格迹**的**三因子学习规则**（[7.16.14](/7.16.14#sec-14.9)）：在某状态下活动的皮层–纹状体突触留下痕迹，约一秒之内到达的**多巴胺**则通过 $\mathrm{D_1}$ 与 $\mathrm{D_2}$ 受体把它转化为增强（$\delta$ 为正）或抑制（$\delta$ 为负）（[7.16.40](/7.16.40)）。该假说是一个工作模型，而不是已确立的事实：多巴胺神经元也编码新异性、显著性和运动，有些神经元在接近目标时发放逐渐增强（可以解读为状态不确定下的 TD 误差，或价值信号），而它们对完全被预测的奖赏的反应减弱但往往没有消失。

## 39.4. Markov 决策过程

### 39.4.1. 定义

条件反射是只预测而不控制。要选择行动，智能体需要一个关于其行动如何影响状态与奖赏的模型。

**定义 39.4.1（Markov 决策过程）** **Markov 决策过程**（MDP）由状态集 $\mathcal{S}$、行动集 $\mathcal{A}$ 以及转移与奖赏分布 $p(s', r \mid s, a) = \mathbb{P}(S_{t+1} = s', R_{t+1} = r \mid S_t = s, A_t = a)$ 组成，它满足 Markov 性：下一状态与奖赏的分布只依赖于当前状态与行动，而不依赖更早的历史。**策略** $\pi(a \mid s)$ 是在状态 $s$ 选择行动 $a$ 的概率。

交互产生一条轨迹 $S_0, A_0, R_1, S_1, A_1, R_2, \dots$。以终止状态结束的任务称为分段式任务，其余称为持续式任务。回报（return） $G_t$ 是未来奖赏的折扣和，见式 (39.1)；折扣因子 $\gamma < 1$ 使持续式任务中的回报保持有限，并表达对较早奖赏的偏好（这是指数折扣，而人和动物往往按双曲线折扣）。

**定义 39.4.2（价值函数）** 策略 $\pi$ 的**价值函数**是从每个状态出发的期望回报，$v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$；**动作价值函数**是在状态 $s$ 采取行动 $a$、此后遵循 $\pi$ 的期望回报，$q_\pi(s, a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a]$；二者满足 $v_\pi(s) = \sum_a \pi(a \mid s)\,q_\pi(s, a)$。

我们沿用 Sutton 与 Barto 的写法，用小写字母表示价值函数，以免与膜电位 $V$ 混淆；学得的估计记作 $\hat v$ 与 $\hat q$。

### 39.4.2. Bellman 方程

**定理 39.4.1（Bellman 方程）** 对任意策略 $\pi$，价值函数满足
$$
v_\pi(s) = \sum_a \pi(a \mid s) \sum_{s', r} p(s', r \mid s, a)\,\bigl[r + \gamma\,v_\pi(s')\bigr] \quad \text{对所有 } s \in \mathcal{S}, \tag{39.2}
$$
并且当 $\mathcal{S}$ 有限且 $\gamma < 1$ 时，$v_\pi$ 是它的唯一解。

**证明** 由 $G_t = R_{t+1} + \gamma G_{t+1}$ 与 Markov 性，$v_\pi(s) = \mathbb{E}_\pi[R_{t+1} + \gamma G_{t+1} \mid S_t = s] = \sum_a \pi(a \mid s)\sum_{s', r}p(s', r \mid s, a)\,(r + \gamma\,\mathbb{E}_\pi[G_{t+1} \mid S_{t+1} = s'])$，而内层期望就是 $v_\pi(s')$。写成向量形式，式 (39.2) 为 $\boldsymbol{v} = \boldsymbol{r}_\pi + \gamma P_\pi \boldsymbol{v}$，其中 $P_\pi$ 是策略 $\pi$ 下的状态转移矩阵（随机矩阵），$\boldsymbol{r}_\pi$ 是期望的单步奖赏。映射 $T\boldsymbol{v} = \boldsymbol{r}_\pi + \gamma P_\pi\boldsymbol{v}$ 在最大范数下是压缩映射，$\|T\boldsymbol{u} - T\boldsymbol{v}\|_\infty \le \gamma\|\boldsymbol{u} - \boldsymbol{v}\|_\infty$，因为 $P_\pi$ 的每一行都是概率分布；由 Banach 不动点定理它有唯一的不动点，等价地 $\boldsymbol{v} = (I - \gamma P_\pi)^{-1}\boldsymbol{r}_\pi$。$\square$

若对所有 $s$ 与所有 $\pi$ 都有 $v_{\pi_*}(s) \ge v_\pi(s)$，则称策略 $\pi_*$ 是最优的。有限 MDP 存在最优策略，且它们共享最优价值函数 $v_*(s) = \max_\pi v_\pi(s)$ 与 $q_*(s, a) = \max_\pi q_\pi(s, a)$。

**定理 39.4.2（Bellman 最优方程）** 最优价值函数满足
$$
v_*(s) = \max_a \sum_{s', r} p(s', r \mid s, a)\,\bigl[r + \gamma\,v_*(s')\bigr], \qquad q_*(s, a) = \sum_{s', r} p(s', r \mid s, a)\,\Bigl[r + \gamma \max_{a'} q_*(s', a')\Bigr], \tag{39.3}
$$
并且任何对 $q_*$ 贪心的策略，即在每个状态选择使 $q_*(s, a)$ 最大的行动，都是最优的。

最优方程把对策略的平均换成了取最大值。它同样是压缩映射（模数相同的压缩映射取最大仍是压缩），因此有唯一解，但它是非线性的。它的重要性在于把对策略的搜索变成了局部的一致性条件：知道 $q_*$，智能体只需一步选择即可最优地行动，无需向前展望。

**定理 39.4.3（策略改进定理）** 若两个策略满足对所有状态 $s$ 都有 $q_\pi(s, \pi'(s)) \ge v_\pi(s)$，其中 $\pi'$ 是确定性的，则对所有 $s$ 有 $v_{\pi'}(s) \ge v_\pi(s)$。特别地，对 $q_\pi$ 贪心的策略至少与 $\pi$ 一样好。

**证明** 反复展开，$v_\pi(s) \le q_\pi(s, \pi'(s)) = \mathbb{E}[R_{t+1} + \gamma v_\pi(S_{t+1}) \mid S_t = s, A_t = \pi'(s)] \le \mathbb{E}_{\pi'}[R_{t+1} + \gamma\,q_\pi(S_{t+1}, \pi'(S_{t+1})) \mid S_t = s] \le \cdots \le \mathbb{E}_{\pi'}[R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots \mid S_t = s] = v_{\pi'}(s)$。$\square$

### 39.4.3. 动态规划

当模型 $p(s', r \mid s, a)$ 已知时，可以用**动态规划**求解 Bellman 方程，把它们当作更新规则来迭代。

**算法 39.4.1（策略迭代）** 从任意策略 $\pi_0$ 出发，重复：(1) 策略评估，求解式 (39.2) 得到 $v_{\pi_k}$（精确求解，或迭代 $\hat v \leftarrow \boldsymbol{r}_{\pi_k} + \gamma P_{\pi_k}\hat v$ 至收敛）；(2) 策略改进，令 $\pi_{k+1}(s) = \arg\max_a \sum_{s', r}p(s', r \mid s, a)[r + \gamma v_{\pi_k}(s')]$；策略不再变化时停止。

**算法 39.4.2（价值迭代）** 从任意 $\hat v_0$ 出发，对所有状态重复 $\hat v_{k+1}(s) = \max_a \sum_{s', r}p(s', r \mid s, a)[r + \gamma\,\hat v_k(s')]$，直到变化很小；然后对最终估计取贪心行动。

由定理 39.4.3，策略迭代的每一步改进所给出的策略至少与上一个一样好；而有限 MDP 只有有限多个确定性策略，所以策略迭代会在一个最优策略处终止，通常只需很少的迭代。价值迭代是对式 (39.3) 中压缩映射的迭代，几何收敛，误差按 $\gamma^k$ 下降。在只有一个奖赏目标的网格世界中，价值迭代每扫描一遍就把价值从目标向外扩散一步，如同 39.2.2 节中 TD 误差在时间上向后扩散：动态规划是 TD 学习的基于模型的对应物。

## 39.5. 无模型学习

### 39.5.1. 蒙特卡洛与 TD 预测

动物很少知道其世界的转移概率。无模型方法直接从经历的转移中学习价值。**蒙特卡洛方法**把每个被访问状态的估计推向实际获得的回报，$\hat v(S_t) \leftarrow \hat v(S_t) + \alpha[G_t - \hat v(S_t)]$；它需要完整的回合，方差很大，因为 $G_t$ 是许多随机奖赏之和，但它是无偏的。TD(0)（定义 39.2.1）把 $G_t$ 换成单步目标 $R_{t+1} + \gamma\,\hat v(S_{t+1})$；它可以在线学习，方差较低，但其目标被当前估计所偏倚。二者是一个族的两个极端：TD($\lambda$) 使用 $n$ 步回报的指数加权混合，借助每个状态的**资格迹** $e(s)$ 在线实现，访问时增加，每步按 $\gamma\lambda$ 衰减，于是每个 TD 误差按各近期访问状态的迹的大小成比例地更新它们（Sutton，1988）。资格迹正是脑内三因子突触规则所提供的东西（[7.16.14](/7.16.14#sec-14.9)）。

| 方法 | 目标 | 需要模型 | 偏差 | 方差 | 在线 |
|---|---|---|---|---|---|
| 动态规划 | $\sum p(s', r \mid s, a)[r + \gamma\,\hat v(s')]$ | 是 | 自举 | 无 | — |
| 蒙特卡洛 | $G_t$ | 否 | 无 | 高 | 否 |
| TD(0) | $R_{t+1} + \gamma\,\hat v(S_{t+1})$ | 否 | 自举 | 低 | 是 |
| TD($\lambda$) | $n$ 步回报的混合 | 否 | 居中 | 居中 | 是（借助迹） |

### 39.5.2. 控制：SARSA 与 Q 学习

要在没有模型时选择行动，智能体必须学习动作价值，因为状态价值只有通过需要模型的单步前瞻才能给出策略。

**算法 39.5.1（SARSA）** 每一步，在状态 $S_t$ 根据当前估计 $\hat q$ 选择行动 $A_t$（例如 ε-贪心地），观察 $R_{t+1}$ 与 $S_{t+1}$，以同样方式选择 $A_{t+1}$，并更新
$$
\hat q(S_t, A_t) \leftarrow \hat q(S_t, A_t) + \alpha\bigl[R_{t+1} + \gamma\,\hat q(S_{t+1}, A_{t+1}) - \hat q(S_t, A_t)\bigr].
$$

**算法 39.5.2（Q 学习）** 每一步，在状态 $S_t$ 按任一保持探索的策略（例如对 $\hat q$ 作 ε-贪心）选择行动 $A_t$，观察 $R_{t+1}$ 与 $S_{t+1}$，并更新
$$
\hat q(S_t, A_t) \leftarrow \hat q(S_t, A_t) + \alpha\Bigl[R_{t+1} + \gamma \max_{a'}\hat q(S_{t+1}, a') - \hat q(S_t, A_t)\Bigr]
$$
（Watkins，1989）。

SARSA（得名于五元组 $S_t, A_t, R_{t+1}, S_{t+1}, A_{t+1}$）是同策略的：它学习所遵循策略的价值，包括其中的探索性行动。Q 学习是异策略的：其目标使用最佳的下一行动，无论实际采取了什么行动，因此它通过对式 (39.3) 采样来学习 $q_*$。对有限 MDP，只要每个状态–行动对被无限次访问，且学习率满足 $\sum_t \alpha_t = \infty$、$\sum_t \alpha_t^2 < \infty$（Watkins 与 Dayan，1992），这是随机逼近的条件，Q 学习就以概率 1 收敛到 $q_*$。当探索代价高昂时二者的差别就显现出来：在悬崖旁边，SARSA 学到一条更安全、考虑了自己偶尔随机一步的路径，Q 学习学到最优路径，却偶尔从上面掉下去。

### 39.5.3. 探索

一个总是对当前估计贪心行动的智能体，可能永远发现不了更好的行动。在利用现有知识与收集新信息之间取得平衡，就是探索–利用权衡（exploration–exploitation trade-off），其最简单的形式在**多臂老虎机**（[4.5.3](/4.5.3#sec-3.5.1)）中研究。

**定义 39.5.1（ε-贪心策略与 softmax 策略）** **ε-贪心策略**以概率 $1 - \varepsilon$ 选择估计价值最大的行动，以概率 $\varepsilon$ 均匀随机地选择行动。**softmax 策略**以概率 $\pi(a \mid s) = \mathrm{e}^{\beta \hat q(s, a)}/\sum_{b}\mathrm{e}^{\beta \hat q(s, b)}$ 选择行动 $a$，其中逆温度 $\beta$ 决定利用的程度。

softmax 规则（即 [4.5.4](/4.5.4) 的 **softmax 函数**）按价值的比例探索：价值接近的选项被几乎同样频繁地选择，明显更差的则很少被选。它能很好地拟合人和动物在老虎机任务中的选择，其参数 $\alpha$ 与 $\beta$ 是计算精神病学中常规估计的量。更有方向性的策略为不确定的选项加上探索奖励（置信上界），或按各行动成为最优的后验概率来采样行动（Thompson 采样）；人类同时使用随机探索与有方向的探索，并有人提出**神经调质**，尤其是**去甲肾上腺素**，决定二者的平衡。

## 39.6. 函数逼近与深度 Q 网络

状态很多时，数值表毫无用处：围棋约有 $10^{170}$ 种合法局面，动物的感觉状态是连续的，也从不会精确重复。此时必须用参数化函数 $\hat q(s, a; \boldsymbol{w})$ 来表示价值，使之在相似状态之间泛化。对线性特征 $\boldsymbol{x}(s, a)$，$\hat q = \boldsymbol{w}^{\mathsf T}\boldsymbol{x}$，TD 更新变为 $\boldsymbol{w} \leftarrow \boldsymbol{w} + \alpha\,\delta_t\,\boldsymbol{x}(S_t, A_t)$，这是一条三因子规则：$\boldsymbol{x}$ 是突触前活动，所选行动是突触后因子，$\delta_t$ 是神经调质性的第三因子。对非线性网络，TD 学习不再保证收敛：目标随权重变化而移动（“射击移动的靶子”），相继样本强相关，而函数逼近、自举与异策略学习三者结合可能发散。

**定义 39.6.1（深度 Q 网络与经验回放）** **深度 Q 网络**（DQN）是一个把状态（例如视频游戏的屏幕像素）映射为估计动作价值 $\hat q(s, \cdot\,; \boldsymbol{w})$ 的深度神经网络，用 Q 学习训练，并带有两种稳定手段：**经验回放**，即把转移 $(S_t, A_t, R_{t+1}, S_{t+1})$ 存入记忆缓冲区，网络在从中随机抽取的小批量上训练；以及目标网络，即定期更新的权重副本 $\boldsymbol{w}^-$，用来计算目标 $R_{t+1} + \gamma\max_{a'}\hat q(S_{t+1}, a'; \boldsymbol{w}^-)$。

借助这些手段，同一个架构仅凭像素与得分就学会了 49 种 Atari 游戏，其中许多达到了人类水平（Mnih 等，2015）。回放使训练样本去相关，并重复利用罕见的经验；目标网络使回归问题近似平稳。它的设计中明确借鉴了与脑的类比：在休息与睡眠时，海马**位置细胞**以压缩的形式重放过去经验的序列（Wilson 与 McNaughton，1994；Lee 与 Wilson，2002），并有人提出**重放**可用于离线训练皮层与纹状体的价值表征，就像机器学习中的优先回放那样优先重放出人意料的经验。回放及其在规划中的作用见 [7.16.46](/7.16.46) 与 [7.16.41](/7.16.41)。网络本身的基于梯度的训练（**反向传播**，[4.5.4](/4.5.4)）在生物学上尚无公认的对应物，这一问题在 [7.16.50](/7.16.50) 讨论。

## 39.7. 分布式强化学习

价值函数是一个期望，而回报是一个随机变量：同样的期望值，可以来自一个确定的中等奖赏，也可以来自在零与大额奖赏之间的赌博。学习回报的整个分布可以改进深度强化学习（Bellemare、Dabney 与 Munos，2017），而实现它的一种简单机制竟存在于多巴胺神经元中。

**定义 39.7.1（分布式时序差分学习）** 在带有不对称学习率的**分布式时序差分学习**中，一群价值预测器 $\hat v_i$ 用 TD 误差 $\delta_{i,t} = R_{t+1} + \gamma\,\hat v_{j}(S_{t+1}) - \hat v_i(S_t)$ 更新（$\hat v_j$ 是从该群体中抽取的样本），每个预测器把正误差乘以 $\alpha_i^+$、负误差乘以 $\alpha_i^-$；不对称度 $\tau_i = \alpha_i^+/(\alpha_i^+ + \alpha_i^-)$ 使预测器 $i$ 乐观（$\tau_i > 1/2$）或悲观（$\tau_i < 1/2$）。

**命题 39.7.1** 对单个状态中固定的奖赏分布，不对称度为 $\tau$ 的预测器在期望意义下收敛到该分布的 $\tau$ 期望分位数 $e_\tau$，它是
$$
\tau\,\mathbb{E}\bigl[(R - e_\tau)_+\bigr] = (1 - \tau)\,\mathbb{E}\bigl[(e_\tau - R)_+\bigr]
$$
的唯一解；$e_{1/2}$ 是均值，且当 $\tau$ 从 0 增至 1 时，$e_\tau$ 从分布的最小值增至最大值。

**证明** 期望更新为 $\mathbb{E}[\Delta\hat v] = \alpha^+\mathbb{E}[(R - \hat v)_+] - \alpha^-\mathbb{E}[(\hat v - R)_+]$，除以 $\alpha^+ + \alpha^-$ 后，它恰在所述方程处为零。方程左边随 $\hat v$ 递减、右边随 $\hat v$ 递增，所以零点唯一且不动点稳定；$\tau = 1/2$ 时方程化为 $\mathbb{E}[R - e] = 0$。$\square$

![双峰奖赏分布的分布式 TD 学习（定义 39.7.1）（概率 0.6 得到接近 0.1 的小奖赏，否则得到接近 0.8 的奖赏）。A：该分布，以及 15 个预测器学得的值，它们的不对称度 $\tau_i$ 从 0.05（蓝，悲观）到 0.95（红，乐观）；预测器分散在整个分布上，而均值（虚线）落在几乎不出现奖赏之处。B：学得的值与分布的精确期望分位数一致（命题 39.7.1）。](./plots/distributional.py)

Dabney 等（2020）在接受不同大小奖赏的小鼠 VTA 多巴胺神经元中检验了这一点。每个神经元有一个反转点，即其反应由兴奋转为抑制时的奖赏大小；在经典 TD 模型中所有神经元应当共享同一个反转点，即均值。实际上反转点是分散的，并且如命题 39.7.1 所预测的那样，它们与每个神经元对正误差和负误差的反应的不对称相关：对正误差反应比对负误差更强的神经元反转点更高。把群体解码为一组期望分位数，可以恢复奖赏分布的形状，包括它的双峰性。多巴胺神经元之间的多样性，此前被当作噪声，现在成了不确定性的一种表征。这一想法已被推广到多维奖赏分布，并有人提出它是乐观程度的个体差异及其在抑郁症中受到扰乱的基础。

## 小结

- Rescorla–Wagner 规则（定义 39.1.1）是带共享预测的误差驱动学习；它能解释阻断与遮蔽，但不能解释时间关系、二级条件反射或自发恢复。
- TD 学习（定义 39.2.1）通过自举预测折扣的未来奖赏（式 (39.1)）；TD 误差从奖赏移到最早的预测线索，并在被预测的奖赏省略时变为负值，与多巴胺的反应一致（注 39.3.1），三因子可塑性是其机制。
- MDP（定义 39.4.1）定义了价值函数（定义 39.4.2），它们满足 Bellman 方程（定理 39.4.1，唯一解的压缩映射）与 Bellman 最优方程（定理 39.4.2）；贪心改进不会使策略变差（定理 39.4.3）。策略迭代与价值迭代（算法 39.4.1–39.4.2）求解已知的 MDP。
- 无模型方法从样本中学习：蒙特卡洛（无偏、高方差）、TD(0)（有偏、低方差）、带资格迹的 TD($\lambda$)；SARSA（同策略）与 Q 学习（异策略，收敛到 $q_*$）学习动作价值（算法 39.5.1–39.5.2）；ε-贪心与 softmax 策略（定义 39.5.1）负责探索。
- 函数逼近使价值在状态间泛化，但会破坏自举的稳定性；深度 Q 网络（定义 39.6.1）使用经验回放与目标网络，并与海马重放相类比。
- 带不对称学习率的分布式 TD 学习（定义 39.7.1）用期望分位数表示回报分布（命题 39.7.1），这解释了多巴胺神经元反转点的分散。

| 算法 | 学习对象 | 更新目标 | 神经对应物（假设） |
|---|---|---|---|
| Rescorla–Wagner | CS 的强度 | $\lambda$ | US 驱动的预测误差 |
| TD(0) | $v_\pi$ | $R_{t+1} + \gamma\,\hat v(S_{t+1})$ | 多巴胺的爆发与暂停，皮层–纹状体可塑性 |
| SARSA | $q_\pi$ | $R_{t+1} + \gamma\,\hat q(S_{t+1}, A_{t+1})$ | 纹状体的动作价值编码 |
| Q 学习 | $q_*$ | $R_{t+1} + \gamma\max_{a'}\hat q(S_{t+1}, a')$ | 部分多巴胺反应反映最佳选项而非所选选项 |
| 价值迭代 | $v_*$ | 基于模型的回溯 | 规划、重放（[7.16.41](/7.16.41)） |
| 分布式 TD | 回报分布 | 不对称的 TD 误差 | 多巴胺神经元的多样性 |

## 思考题

1. 证明 Rescorla–Wagner 规则是对平方预测误差的随机梯度下降，并用它解释遮蔽：显著性 $\alpha_A > \alpha_B$ 的两个刺激 A 与 B 总是一起呈现并被强化，渐近强度各是多少？

   **答** 取特征 $x_i$：刺激 $i$ 出现时为 1，否则为 0，则预测为 $\sum_i V_i x_i$，损失为 $L = \frac12(\lambda - \sum_i V_i x_i)^2$；$-\partial L/\partial V_i = (\lambda - \sum_j V_j x_j)x_i$，所以该规则是带刺激特异学习率 $\alpha_i\beta$ 的梯度步。对复合刺激 AB，二者以同一误差 $\lambda - V_A - V_B$ 更新；渐近时误差为零，$V_A + V_B = \lambda$。增量之比恒定，$\Delta V_A/\Delta V_B = \alpha_A/\alpha_B$，所以从零出发时始终有 $V_A/V_B = \alpha_A/\alpha_B$，于是 $V_A = \lambda\alpha_A/(\alpha_A + \alpha_B)$，$V_B = \lambda\alpha_B/(\alpha_A + \alpha_B)$：更显著的刺激遮蔽了另一个。

2. 在 TD 模拟（39.2.2 节）中，为什么线索处的误差收敛到 $\gamma^{20}$ 而不是 1？如果线索本身被更早的、完全可靠的警告信号所预测，会发生什么？

   **答** 学习之后，奖赏前 20 步中，线索后 $k$ 步处的 $\hat v$ 等于 $\gamma^{19 - k}$（奖赏在线索后第 20 步，从收到它的那一步算起），所以线索状态的价值是 $\gamma^{19}$，从无预测性的线索前状态（价值 0）转入线索状态的 TD 误差为 $0 + \gamma\,\hat v(\text{cue}) = \gamma^{20} \approx 0.67$：线索值的是折扣后的奖赏。如果更早的警告信号可靠地预测了线索，线索前状态就会获得价值，线索处的误差消失并转移到警告信号处：误差总是出现在最早的可靠预测者上，这与多巴胺在序列线索实验中的反应一致。

3. 对一个两状态的 MDP，每个状态只有一个行动，$s_1 \to s_2$ 奖赏为 0，$s_2 \to s_2$ 奖赏为 1，取 $\gamma = 0.9$，通过解 Bellman 方程求 $v(s_1)$ 与 $v(s_2)$，并说明从 $\hat v = 0$ 出发的价值迭代需要扫描多少遍才能使 $\hat v(s_2)$ 达到其值的 1% 以内。

   **答** $v(s_2) = 1 + 0.9\,v(s_2)$ 给出 $v(s_2) = 10$，$v(s_1) = 0 + 0.9\cdot10 = 9$。价值迭代给出 $\hat v_k(s_2) = 1 + 0.9\,\hat v_{k-1}(s_2) = 10(1 - 0.9^k)$；误差为 $10 \cdot 0.9^k$，当 $0.9^k < 0.01$ 即 $k \ge 44$ 时小于 $0.1$。收敛速率 $\gamma^k$ 就是定理 39.4.1 中压缩映射的模数。

4. 某多巴胺神经元的不对称度 $\tau = 0.8$。线索以相等概率预示奖赏 0 或 1。它的反转点是多少？它在奖赏时刻的反应与 $\tau = 0.5$ 的神经元有何不同？

   **答** 期望分位数满足 $0.8\cdot\frac12(1 - e) = 0.2\cdot\frac12 e$，即 $0.8(1 - e) = 0.2e$，$e = 0.8$。乐观神经元的预测为 0.8：奖赏 1 引起较小的正误差（$+0.2$，乘以 $\alpha^+$），无奖赏引起较大的负误差（$-0.8$，乘以 $\alpha^-$，它较小）。均衡神经元（$e = 0.5$）的反应为 $+0.5$ 与 $-0.5$。跨试验平均，乐观神经元的反应平均为零，因为其对正误差更大的学习率补偿了正误差更小的幅度；它的反转点 0.8 高于均值 0.5，这正是 Dabney 等在对正误差反应更强的神经元中所观察到的。
