一个皮层锥体神经元接收约一万个突触，几乎全部位于距胞体几百微米到一毫米的树突上。一个输入是否对输出有贡献，取决于它落在哪里，相对于其他输入何时到达，以及树突沿途含有哪些电压门控通道。本章先把树突当作被动电缆来处理，沿用 Wilfrid Rall 的做法，他在 1957 至 1970 年间奠定了这一理论；然后把它当作能够进行局部非线性运算的、主动的、区室化的结构，使单个神经元的行为更像一个小网络而不是一个点。电缆方程本身的推导见 [7.6.30](/7.6.30#sec-30.5)，关于衰减、总和与分支直径规则的基本事实见 [7.14.5](/7.14.5#sec-5.3)；这里我们对树突求解该方程并引出其推论。被动膜参数取自 [7.16.4](/7.16.4)，突触电导取自 [7.16.12](/7.16.12)，本章的树突 $\ce{Ca^2+}$ 信号是 [7.16.14](/7.16.14) 中长时程可塑性的触发器。

## 13.1. 树突树与突触的位置

树突很细（从胞体附近约 $5\,\mu\mathrm{m}$ 到末梢的 $0.5\,\mu\mathrm{m}$），有分支，在许多神经元中布满树突棘，即约 $1\,\mu\mathrm{m}$ 的突起，由体积为 $0.01$–$0.5\,\mu\mathrm{m^3}$ 的棘头与直径 $0.1\,\mu\mathrm{m}$ 的棘颈构成。几乎每个棘都带有一个兴奋性突触，其棘头的体积与其**突触后致密区**中的 **AMPA 受体**数目成正比（[7.16.9](/7.16.9#sec-9.2.3)）。大鼠新皮层的一个第 5 层锥体细胞在大约 $10\,\mathrm{mm}$ 的树突上有约 $10^4$ 个棘；小脑浦肯野细胞在一个单平面的树上有 $10^5$ 个棘。

突触不是随机分布的。来自不同来源的兴奋性输入按树突区域分开，各类抑制性中间神经元则靶向不同的区室：

| 神经元 | 区域 | 主要输入 |
|---|---|---|
| CA1 锥体细胞 | 基底树突与近端顶树突（起始层与辐射层） | 来自 CA3 的 Schaffer 侧支 |
| | 远端顶树突丛（腔隙分子层） | 来自内嗅皮层第 III 层的穿通通路 |
| 第 5 层锥体细胞 | 基底与斜向树突 | 局部与前馈的皮层输入 |
| | 第 1 层的顶树突丛 | 来自更高级皮层区域与高级丘脑的反馈 |
| 抑制性靶标 | 胞体与近端树突 | 表达小清蛋白的篮状细胞 |
| | 轴突起始段 | 吊灯细胞 |
| | 远端树突与树突丛 | 表达生长抑素的细胞（Martinotti、O-LM） |

这种布局意味着，对来自不同来源的输入的整合，是一个关于树突的问题。到达第 1 层、距大型锥体细胞胞体超过一毫米的反馈，究竟能否影响其输出，正是 13.6 的主动性质所要处理的问题。

## 13.2. 电缆方程的解

### 13.2.1. 电紧张单位与稳态

对于直径为 $d$、比膜电阻为 $R_{\mathrm{m}}$、轴向电阻率为 $R_{\mathrm{i}}$、电容为 $c_{\mathrm{m}}$ 的被动圆柱，电位偏离静息的量 $V(x, t)$ 服从**电缆方程** $\lambda^2\partial_x^2V = \tau_{\mathrm{m}}\partial_tV + V$（[定理 30.5.1](/7.6.30#thm-30.5.1)），其中**长度常数** $\lambda = \sqrt{dR_{\mathrm{m}}/(4R_{\mathrm{i}})}$，$\tau_{\mathrm{m}} = R_{\mathrm{m}}c_{\mathrm{m}}$。在无量纲的电紧张坐标 $X = x/\lambda$ 与 $T = t/\tau_{\mathrm{m}}$ 中，它变为
$$
\frac{\partial V}{\partial T} = \frac{\partial^2V}{\partial X^2} - V. \tag{13.1}
$$
由于 $\lambda \propto \sqrt d$，直径为四分之一的分支，长度常数为一半；从电紧张的角度看，细的树突是长的。

**定义 13.2.1（电紧张长度）** 物理长度为 $\ell$ 的电缆段的**电紧张长度**为 $L = \ell/\lambda$；树突上两点之间的电紧张距离是它们之间各段 $\Delta x/\lambda$ 之和。

在稳态下，式 (13.1) 化为 $V'' = V$，通解为 $V(X) = c_1\mathrm{e}^{-X} + c_2\mathrm{e}^{X}$，远端的边界条件选出具体的解。对在 $X = 0$ 处施加的电压 $V_0$：

| 远端在 $X = L$ | 条件 | 稳态解 | 输入电导 |
|---|---|---|---|
| 半无限电缆 | $V \to 0$ | $V_0\,\mathrm{e}^{-X}$ | $G_\infty$ |
| 封闭端（无轴向电流） | $\partial_XV = 0$ | $V_0\dfrac{\cosh(L - X)}{\cosh L}$ | $G_\infty\tanh L$ |
| 切除端（短路） | $V = 0$ | $V_0\dfrac{\sinh(L - X)}{\sinh L}$ | $G_\infty\coth L$ |

这里 $G_\infty = 1/(r_{\mathrm{i}}\lambda) = \pi d^{3/2}/(2\sqrt{R_{\mathrm{m}}R_{\mathrm{i}}})$ 是半无限电缆的输入电导，**Rall 3/2 律**即建立在这个量上（[命题 5.3.1](/7.14.5#prop-5.3.1)）。封闭端是树突末梢的天然终结，它把电流反射回来，使电压比在无限电缆中保持得更高：取 $L = 1$，远端仍有 $V_0$ 的 $1/\cosh 1 = 65\%$，而在无限电缆中同样距离处为 $37\%$。大多数神经元的树突 $L$ 在约 $0.3$ 到 $1.5$ 之间，所以在稳态下它们相当紧凑；强烈衰减的是瞬态信号。

**例 13.2.1** 一个锥体细胞的基底树突有 $d = 1\,\mu\mathrm{m}$，$R_{\mathrm{m}} = 20\,\mathrm{k\Omega\,cm^2}$，$R_{\mathrm{i}} = 150\,\Omega\,\mathrm{cm}$。则 $\lambda = \sqrt{(10^{-4}\,\mathrm{cm})(2\times10^4\,\Omega\,\mathrm{cm^2})/(600\,\Omega\,\mathrm{cm})} = 0.058\,\mathrm{cm} = 580\,\mu\mathrm{m}$，$200\,\mu\mathrm{m}$ 的分支有 $L = 0.35$；若电流从基部流入，其末梢的稳态电压到达分支点时只衰减为 $1/\cosh 0.35 = 0.94$。相反的方向则不同：注入封闭末梢的电流必须给树的其余部分充电，而其余部分的输入电导远大于这根细分支的，所以末梢处的电压很大，基部的电压则小得多（13.3.3）。

### 13.2.2. 瞬态信号

突触电位持续几毫秒，与 $\tau_{\mathrm{m}}$ 相当或更短，对它们而言电缆是低通滤波器。半无限电缆一端的角频率为 $\omega$ 的正弦输入按 $\exp\bigl(-X\operatorname{Re}\sqrt{1 + \mathrm{i}\omega\tau_{\mathrm{m}}}\bigr)$ 衰减，这可由把 $V = \hat V(X)\mathrm{e}^{\mathrm{i}\omega t}$ 代入式 (13.1) 得出。对 $\tau_{\mathrm{m}} = 20\,\mathrm{ms}$，有效长度常数在 $10\,\mathrm{Hz}$ 时为 $\lambda/1.14$，在 $100\,\mathrm{Hz}$ 时为 $\lambda/2.61$。因此，上升时间约一毫秒、能量大部分在 $50\,\mathrm{Hz}$ 以上的 EPSP，比稳态电压衰减得多得多（在 $X = 1$ 处峰值降到约 $15\%$，而稳态为 $37\%$），到达得更晚，也更宽。这就是早期只从胞体记录的电生理学家低估远端输入的原因。

## 13.3. Rall 的树突树理论

### 13.3.1. 等效圆柱

Rall 的核心洞见是：在真实树近似满足的条件下，树突树的复杂几何可以塌缩成一根电缆。

**定义 13.3.1（等效圆柱）** 被动树突树的**等效圆柱**是一个单圆柱，直径等于主干，在电紧张长度 $L$ 处有一个封闭端，其中电压随离胞体的电紧张距离的变化与树中相同。

**定理 13.3.1（Rall 等价性）** 设被动树突树具有均匀的 $R_{\mathrm{m}}$ 与 $R_{\mathrm{i}}$，在每个分支点直径满足 $d_{\mathrm{p}}^{3/2} = \sum_k d_k^{3/2}$，且所有终末分支都以封闭端结束于离胞体相同的电紧张距离 $L$ 处。则对胞体处的输入，或在同一电紧张距离处均匀分布于所有分支的输入，树中电压随电紧张距离的变化与单个电紧张长度为 $L$、直径等于主干的封闭圆柱中相同：该树有一个等效圆柱（定义 13.3.1）。

**证明**（概要）在电紧张坐标中，每个分支都服从式 (13.1)。在分支点，电压连续，轴向电流相加；由于圆柱的轴向电流为 $-G_\infty(d)\,\partial_XV$，且 $G_\infty \propto d^{3/2}$，3/2 条件使各子支电流之和等于母支延续的电流，只要各子支具有相同的 $V(X)$。对称的输入与相等的终端距离使所有子支具有相同的 $V(X)$，而由给定边界与初始条件下电缆方程解的唯一性，树与圆柱有相同的解。$\square$

该定理使树突变得可处理：一个运动神经元或锥体细胞可以用三个数来刻画，即胞体、$L$ 与 $\tau_{\mathrm{m}}$，任何对称输入的效应都可以解析地算出。它的条件是近似的。实测的分支指数散布在 $3/2$ 到 $3$ 之间（[7.14.5](/7.14.5#sec-5.3.3)），终末结束于不同的距离，突触输入也不对称；对单个分支上的输入，等效圆柱不再适用，衰减的不对称性（13.3.3）便出现了。

### 13.3.2. 电紧张长度的估计

对与等电位胞体耦合的有限封闭圆柱，短暂电流脉冲之后的电压瞬变是指数之和，
$$
V(T) = \sum_{n \ge 0} C_n\,\mathrm{e}^{-t/\tau_n}, \qquad \tau_n = \frac{\tau_0}{1 + (\alpha_n/L)^2}, \tag{13.2}
$$
其中 $\tau_0 = \tau_{\mathrm{m}}$，由在式 (13.1) 中分离变量得到。对两端都封闭的圆柱（胞体比树突小），$\alpha_n = n\pi$；对大胞体，$\alpha_n$ 满足一个超越方程，介于 $(n - \tfrac12)\pi$ 与 $n\pi$ 之间。

**命题 13.3.1（$L$ 的 Rall 公式）** 对两端封闭的圆柱，瞬变中最慢的两个时间常数之比确定电紧张长度：
$$
L = \frac{\pi}{\sqrt{\tau_0/\tau_1 - 1}}. \tag{13.3}
$$

**证明** 在式 (13.2) 中取 $n = 1$、$\alpha_1 = \pi$：$\tau_0/\tau_1 = 1 + \pi^2/L^2$，解出 $L$。$\square$

时间常数通过"剥离"测量：在半对数图上，瞬变的晚期部分是斜率为 $-1/\tau_0$ 的直线；减去它便显出 $\tau_1$。应用于猫的运动神经元，式 (13.3) 给出 $L \approx 1$–$1.5$，这是树突在电紧张上足够紧凑、远端突触有意义的第一个定量证据。较快的成分 $\tau_n$（$n \ge 1$）描述胞体与树突之间的电荷均衡；它们是带有树突的神经元的胞体被电流阶跃充电比用 $\tau_{\mathrm{m}}$ 的单指数更快的原因。该方法假定 $R_{\mathrm{m}}$ 均匀且电极封接良好；电极漏电与不均匀的膜曾使较早的测量低估了 $\tau_{\mathrm{m}}$，现代的估计把形态学重建与树突记录结合起来。

### 13.3.3. 距离、形状与方向

电缆理论的三个推论决定了神经元如何读取它的输入。

1. *形状指数。* 靠近胞体的突触给出上升快、半宽短的胞体 EPSP；远端突触给出缓慢而宽的 EPSP。Rall（1967）提议从这一对数值读出突触的电紧张位置，在树突记录成为可能之前，半宽对上升时间的图（"形状指数图"）曾用来定位 Ia 传入纤维在运动神经元上的突触。
2. *局部幅度。* 细的远端分支输入阻抗高，所以一个突触电流产生的局部去极化比在胞体处大得多（几个同步突触可达几十毫伏），这使远端树突进入 NMDA 受体与电压门控通道的电压范围；与此同时，胞体 EPSP 很小。
3. *不对称性。* 从远端末梢到胞体的电压衰减，比从胞体到末梢的强得多，因为末梢驱动的是大的电导负载，而胞体驱动的是以封闭端结束的分支。胞体的信号，如**动作电位**，扩散到树突的效果远好于树突信号扩散到胞体。若 3/2 律成立，则对从母支到子支的传播，分支点是"透明的"，但从子支进入母支及其姊妹支的传播总会遇到阻抗的增加。

## 13.4. 电导与抑制的位置

突触通过电导注入电流，而远离胞体的电导不只是使信号衰减，还会与其他输入相互作用。这种效应对**分流抑制**（$E_{\mathrm{inh}} = E_{\mathrm{L}}$）最为清楚，它自身不产生电位，只通过降低别处兴奋所引起的去极化起作用（命题 10.4.1）。这样的抑制性突触应放在树上何处，才能最有效地否决某个给定的兴奋性输入？

设 $K_{ab}$ 为被动树的稳态转移阻抗，即在 $b$ 处注入单位电流时 $a$ 处的电压；它是对称的，$K_{ab} = K_{ba}$，$K_{aa}$ 是 $a$ 处的输入阻抗。设位于 $e$ 的兴奋性突触注入电流 $I_e$（对小的去极化视为固定），分流电导 $g$ 位于 $i$ 处。

**命题 13.4.1（路径上的抑制）** 分流使稳态胞体去极化的相对降低为
$$
\frac{\Delta V_s}{V_s} = \frac{gK_{ii}}{1 + gK_{ii}}\,\rho, \qquad \rho = \frac{K_{si}K_{ie}}{K_{se}K_{ii}}. \tag{13.4}
$$
若 $i$ 位于从 $e$ 到胞体 $s$ 的路径上，则 $\rho = 1$；若它位于该路径之外，且其分支在点 $p$ 处并入该路径，则 $\rho = K_{pi}^2/(K_{pp}K_{ii}) = A_{i\to p}A_{p\to i} < 1$，即从 $i$ 到 $p$ 及返回的电压衰减之积。

**证明** 由线性，分流抽走电流 $gV_i$，而 $V_i = K_{ie}I_e - K_{ii}gV_i$，故 $V_i = K_{ie}I_e/(1 + gK_{ii})$。胞体电位为 $V_s = K_{se}I_e - K_{si}gV_i$，它给出相对于 $K_{se}I_e$ 的降低 $K_{si}gK_{ie}/((1 + gK_{ii})K_{se})$，即式 (13.4)。在树中，两个位点 $a$ 与 $b$ 之间唯一路径上的点 $p$ 把它们分开，$a$ 处的电流在 $b$ 处产生的电压只通过 $V_p$ 依赖于该电流；因此 $K_{ba} = K_{bp}K_{pa}/K_{pp}$。若 $i$ 在从 $e$ 到 $s$ 的路径上，取 $p = i$：$K_{se}K_{ii} = K_{si}K_{ie}$，$\rho = 1$。否则 $K_{si} = K_{sp}K_{pi}/K_{pp}$，$K_{ie} = K_{ip}K_{pe}/K_{pp}$，$K_{se} = K_{sp}K_{pe}/K_{pp}$，所以 $\rho = K_{pi}^2/(K_{pp}K_{ii})$，而 $A_{i\to p} = K_{pi}/K_{ii}$，$A_{p\to i} = K_{ip}/K_{pp}$ 都小于 1。$\square$

该命题是 Koch、Poggio 与 Torre（1983）的"路径上"定理，以及电导的有效衰减是两个方向电压衰减之积这一结果（Koch，1984）的稳态形式。兴奋性突触与胞体之间任何位置的抑制，包括胞体本身，都是最有效的；兴奋远端的抑制，或姊妹支上的抑制，则被双向衰减因子削弱。

由于输入阻抗 $K_{ii}$ 在细的远端分支中较大，紧靠兴奋近端、位于同一分支上的路径上的分流可以用很小的电导否决它，同时不影响其他分支：抑制可以作用于单个分支。这是对表达生长抑素的中间神经元为何靶向远端树突的一种解释，它们在那里可以门控特定的输入流（例如 13.1 的树突丛输入）或树突锋电位，而位于胞体上的表达小清蛋白的篮状细胞则全局地控制输出。

![分流抑制在何处最有效（稳态，命题 13.4.1）。A：一棵被动树，有胞体、$3\,\mu\mathrm{m}$ 的 $300\,\mu\mathrm{m}$ 主干和满足 3/2 律的两根 $500\,\mu\mathrm{m}$ 子支；分支 A 上有 $1\,\mathrm{nS}$ 的兴奋性电导（三角形），以及分流电导的五个可能位点（方块，胞体为圆）。B：胞体 EPSP 的降低对抑制性电导的曲线：位于从突触到胞体的路径上的位点（胞体、主干、分支 A 近端；几乎重合）最有效；突触远端的位点与姊妹支上的位点按衰减因子 $\rho$ 变弱。](./plots/on-path-inhibition.py)

## 13.5. 多室模型

真实的树违背等效圆柱的条件，有电压门控通道，并接收不对称的输入。对它们的模拟，是把树分成短的室，每个室等电位，由轴向电导连接，这是电缆方程的空间离散化（Dayan 与 Abbott，第 6 章）。

**公式 13.5.1（多室模型）** 对室 $j = 1, \dots, M$，膜面积为 $A_j$，电位服从
$$
c_{\mathrm{m}}A_j\frac{\mathrm{d}V_j}{\mathrm{d}t} = -\sum_{\mathrm{ion}}g_{\mathrm{ion},j}(V_j - E_{\mathrm{ion}}) - g_{\mathrm{syn},j}(t)(V_j - E_{\mathrm{syn}}) + \sum_{k \sim j}g_{jk}(V_k - V_j) + I_{\mathrm{ext},j}, \tag{13.5}
$$
其中 $k \sim j$ 遍历 $j$ 的邻居，直径为 $d_j, d_k$、长度为 $\ell_j, \ell_k$ 的两个圆柱形室之间的轴向电导是其中心之间电阻的倒数，$g_{jk} = 1/\bigl(2R_{\mathrm{i}}\ell_j/(\pi d_j^2) + 2R_{\mathrm{i}}\ell_k/(\pi d_k^2)\bigr)$。

式 (13.5) 的线性部分是 $C\dot{\boldsymbol{V}} = -G\boldsymbol{V} + \dots$，其中电导矩阵 $G$ 稀疏、对称，具有树的结构。由电缆方程得出两条实用规则：室应当短于最高关注频率下约 $0.1\lambda$（模拟器 NEURON 的"$d_\lambda$ 规则"），并需要隐式积分，因为短室之间的耦合是刚性的；对树而言，隐式线性系统用从末梢到根排序的 Gauss 消元在 $O(M)$ 次运算内求解（Hines，1984）。带有几千个室和十几种通道的详细重建能很好地再现树突记录，在另一极端，二室模型（胞体加树突，Pinsky 与 Rinzel，1994）捕捉由树突 $\ce{Ca^2+}$ 电流引起的**簇放电**。选择取决于所问的问题，与建模中处处一样（[7.16.1](/7.16.1)）。

## 13.6. 主动树突与非线性整合

### 13.6.1. 反向传播动作电位

树突含有电压门控的 $\ce{Na+}$、$\ce{K+}$ 与 $\ce{Ca^2+}$ 通道以及 HCN 通道，其密度随距离系统地变化。对第 5 层锥体细胞的胞体与顶树突的同步膜片钳记录（Stuart 与 Sakmann，1994）表明，动作电位起始于轴突，并向后传入树突，由树突 $\ce{Na+}$ 通道主动支持，但幅度随距离下降并变宽。

**定义 13.6.1（反向传播动作电位）** **反向传播动作电位**（bAP）是起始于轴突起始段的动作电位从胞体扩散进入树突树，由树突电压门控 $\ce{Na+}$ 通道支持。

bAP 把神经元输出的信息带回每个突触：在许多突触中，它是**脉冲时间依赖可塑性**的突触后信号（[7.16.14](/7.16.14)）。它的效能是受调节的。在 CA1 锥体细胞中，A 型 $\ce{K+}$ 通道的密度沿顶树突增加约五倍（Hoffman 及同事，1997），这限制了反向传播；使这些通道失活的局部去极化，或激酶对它们的磷酸化，会增强 bAP，这是突触输入控制自身可塑性的一种方式。分支点是第二种控制：如 13.3.3 所述，脉冲容易从母支传向子支。

### 13.6.2. 树突锋电位

**定义 13.6.2（树突锋电位）** **树突锋电位**是由局部电压门控通道或 NMDA 受体在树突中产生的再生性去极化，可以在没有胞体动作电位的情况下发生：快速的 $\ce{Na+}$ 脉冲（约 $1$–$2\,\mathrm{ms}$）、$\ce{Ca^2+}$ 脉冲（几十毫秒）或 NMDA 脉冲（$50$–$100\,\mathrm{ms}$ 的平台）。

NMDA 脉冲来自**镁阻断**所产生的负斜率电导（[7.16.10](/7.16.10#sec-10.3.2)）。在输入阻抗很高的细基底树突与树突丛中，成簇分布于约 $20$–$40\,\mu\mathrm{m}$ 之内的大约 10–20 个突触所释放的谷氨酸，使分支去极化到足以解除阻断，NMDA 电流增大，分支跃升到 $-20\,\mathrm{mV}$ 附近的平台，只要谷氨酸仍然结合就持续（Schiller 及同事，2000；Major 及同事，2008）。同样数目的突触散布在树上时，总和几乎是线性的。CA1 细胞斜向树突中的快速 $\ce{Na+}$ 脉冲同样响应同步的成簇输入，其强度本身也是可塑的（Losonczy、Makara 与 Magee，2008）。树突因此能检测空间上成簇、时间上同步的模式；代表相关特征的输入是否像计算所要求的那样聚集在同一分支上，在体内对一些输入已经发现，但并不普遍。

一个大的 $\ce{Ca^2+}$ 脉冲由高阈值 $\ce{Ca^2+}$ 通道在第 5 层锥体细胞顶树突主分叉附近的"起始区"产生，该处距胞体约 $700\,\mu\mathrm{m}$。Larkum、Zhu 与 Sakmann（1999）发现，当树突丛被远端输入去极化时到达的 bAP 降低了这个 $\ce{Ca^2+}$ 脉冲的阈值，后者进而驱动胞体动作电位的一次簇放电：*BAC 发放*（反向传播激活的 $\ce{Ca^2+}$ 脉冲发放）。单独的胞体脉冲或单独的远端输入都不产生这种簇放电；二者在几毫秒的窗口内一起出现时才会。

由于树突丛接收来自更高级皮层区域的反馈，而基底树突接收前馈输入，BAC 发放是把这两个输入流关联起来的细胞机制：当神经元自下而上的输入被自上而下的情境证实时，它便发放一次簇（Larkum，2013）。

CA1 中类似的巧合机制，即当内嗅皮层对树突丛的输入与 CA3 输入重合时触发的树突平台电位，驱动 [7.16.14](/7.16.14#sec-14.8) 所述的位置野的一次性形成。远端输入也可以反方向起门控作用：在 CA1 中，同时到达的 Schaffer 侧支输入使由穿通通路在树突丛中引发的树突锋电位得以传到胞体（Jarsky 及同事，2005）。

### 13.6.3. 作为双层网络的神经元

若每个细分支对自己的输入取阈值，有 $B$ 个分支的神经元计算的大致是
$$
r = f_{\mathrm{soma}}\Bigl(\sum_{b=1}^{B}\sigma\bigl(\textstyle\sum_{j \in b}w_j u_j\bigr)\Bigr), \tag{13.6}
$$
其中 $\sigma$ 为 S 形的分支非线性（NMDA 脉冲），$f_{\mathrm{soma}}$ 为胞体非线性。Poirazi、Brannon 与 Mel（2003）表明，对于突触空间排布不同的刺激，带拟合 $\sigma$ 的式 (13.6) 对一个 CA1 细胞详细多室模型发放率的预测，远好于单一求和（$r = f(\sum_jw_ju_j)$，即点神经元），而且成簇输入比同样数目的分散输入更能驱动细胞。在这种观点下，单个神经元是机器学习中使用的那类双层网络（[7.16.19](/7.16.19)），其存储容量取决于哪些突触共享一个分支。

更近的工作用深度网络拟合一个详细的第 5 层锥体细胞模型在毫秒分辨率下的输入–输出关系：树突中有 NMDA 受体时，需要五到八层的时间卷积网络，没有时则一个隐藏层就够了（Beniaguev、Segev 与 London，2021）。这些是关于模型的陈述，但它们显示了树突非线性可能增加多大的计算能力。

![神经元的双层模型（式 (13.6)）：八个分支，每个把其活动突触数（单位权重）通过阈值为 10、斜率为 1.5 的 sigmoid，并在胞体求和。A：一个分支的输出对共同活动突触数的曲线（实线），以及单突触响应的线性和（虚线）：阈值之上为超线性，高驱动时饱和。B：$N$ 个活动突触成簇（逐个分支填满）或散布于所有分支时的总输出：只要成簇使分支越过阈值，它就有效得多。C：一个分支上 20 个突触、两个分支上各 10 个，或八个分支上各 2–3 个：同样数目的输入给出大不相同的输出。](./plots/two-layer-model.py)

## 13.7. 树突中的化学信号

树突也传递化学信号：通过 NMDA 受体与电压门控通道进入的 $\ce{Ca^2+}$，以及由代谢型受体产生的 cAMP 与 $\mathrm{IP_3}$ 等**第二信使**（[7.16.11](/7.16.11)）。扩散系数为 $D$、被时间常数为 $\tau_c$ 的一阶过程（缓冲、泵出、降解）移除的物质，服从
$$
\frac{\partial c}{\partial t} = D\frac{\partial^2c}{\partial x^2} - \frac{c}{\tau_c} + J(x, t), \tag{13.7}
$$
其中 $J$ 是局部源：这是一个**反应扩散方程**，它在数学上与电缆方程相同，以 $\lambda_c^2 = D\tau_c$ 代替 $\lambda^2$，以 $\tau_c$ 代替 $\tau_{\mathrm{m}}$。因此化学信号的稳态扩散以长度常数 $\lambda_c = \sqrt{D\tau_c}$ 衰减，13.2 的所有结果都适用。

数值与电的情形大不相同。游离 $\ce{Ca^2+}$ 以 $D \approx 220\,\mu\mathrm{m^2\,s^{-1}}$ 扩散，但在充满缓冲剂的胞质中，它的有效扩散系数约为 $10$–$50\,\mu\mathrm{m^2\,s^{-1}}$，并在 $10$–$100\,\mathrm{ms}$ 内被移除；因此 $\lambda_c \approx 1$–$2\,\mu\mathrm{m}$，比 $\lambda$ 短几百倍。因此 $\ce{Ca^2+}$ 信号是局部的，而棘又增加了第二道屏障：细的棘颈减慢棘头与树突之间的交换，时间常数为几十到几百毫秒，所以经 NMDA 受体进入一个棘的 $\ce{Ca^2+}$ 留在那里（Svoboda、Tank 与 Denk，1996；Yuste 与 Denk，1995）。这种**区室化**是长时程增强的**输入特异性**的基础（[7.16.14](/7.16.14#sec-14.2)）。寿命更长的分子扩散得更远：活化的 Ras 与 RhoA 从被增强的棘扩散约 $10\,\mu\mathrm{m}$，并可促进邻近突触的可塑性（Harvey 及同事，2008），cAMP 与 $\mathrm{IP_3}$ 则扩散几十微米。因此树突有一个区室的层级，由扩散与移除的比值决定：棘头对应 $\ce{Ca^2+}$，分支段对应较慢的信使，整个细胞对应电压。

## 小结

- 来自不同来源的突触与各类抑制性中间神经元靶向不同的树突区域（13.1）；输入落在何处决定它如何被整合。
- 在电紧张单位下，电缆方程为 $\partial_TV = \partial_X^2V - V$（式 (13.1)）；其稳态解依赖于边界条件（13.2.1 的表），而瞬态比稳态电压衰减得多得多，因为电缆是低通滤波器。

| 量 | 公式 | 典型值 |
|---|---|---|
| 长度常数 | $\lambda = \sqrt{dR_{\mathrm{m}}/(4R_{\mathrm{i}})}$ | $0.3$–$1\,\mathrm{mm}$ |
| 电紧张长度（定义 13.2.1） | $L = \ell/\lambda$ | $0.3$–$1.5$ |
| 输入电导，封闭电缆 | $G_\infty\tanh L$，$G_\infty \propto d^{3/2}$ | — |
| 由瞬变得到的电紧张长度 | $L = \pi/\sqrt{\tau_0/\tau_1 - 1}$（命题 13.3.1） | — |
| 化学长度常数 | $\lambda_c = \sqrt{D\tau_c}$ | $\ce{Ca^2+}$ 约 $1\,\mu\mathrm{m}$ |

- 遵守 3/2 律且终端距离相等的树等价于一根圆柱（定理 13.3.1）；远端输入给出小、慢、宽的胞体 EPSP，却有大的局部去极化，朝胞体的衰减强于背离胞体的衰减。
- 分流电导在兴奋与胞体之间的路径上最有效；在路径之外，其效应被两个方向电压衰减之积降低（命题 13.4.1）。
- 多室模型（公式 13.5.1）把电缆离散化；室短于 $0.1\lambda$，隐式积分。
- 主动树突支持反向传播动作电位（定义 13.6.1）与树突锋电位（定义 13.6.2）；BAC 发放把前馈与反馈输入关联起来，分支非线性使神经元类似于双层网络（式 (13.6)）。
- 化学信号服从同样的方程，$\lambda_c = \sqrt{D\tau_c}$，并在棘与分支中区室化（13.7）。

## 思考题

1. 两根树突有相同的 $R_{\mathrm{m}}$ 与 $R_{\mathrm{i}}$；一根直径 $4\,\mu\mathrm{m}$、长 $800\,\mu\mathrm{m}$，另一根 $1\,\mu\mathrm{m}$、$400\,\mu\mathrm{m}$。哪一根在电紧张上更长？若两者末端都封闭，设粗树突的 $\lambda = 1\,\mathrm{mm}$，则基部所施加稳态电压的多大比例到达末梢？

   **答** $\lambda \propto \sqrt d$，所以细树突的 $\lambda = 0.5\,\mathrm{mm}$。于是粗树突 $L = 0.8$，细树突也是 $L = 0.8$：它们在电紧张上相等，尽管细的只有一半长。两者末梢处的比例都是 $1/\cosh 0.8 = 0.75$。

2. 一个胞体很小、树突近似为封闭圆柱的神经元，给出 $\tau_0 = 25\,\mathrm{ms}$、$\tau_1 = 5\,\mathrm{ms}$ 的电压瞬变。估计 $L$。若实验者不知道胞体膜的电阻比树突低（例如由于电极漏电），估计会怎样变化？

   **答** 由式 (13.3)，$L = \pi/\sqrt{25/5 - 1} = \pi/2 = 1.57$。胞体漏电使膜不均匀：最慢的时间常数 $\tau_0$ 此时比真实的树突 $\tau_{\mathrm{m}}$ 短，不再与之相等，而对均匀膜推导的式 (13.3) 给出有偏的 $L$。这就是为什么较早用尖电极的测量低估了 $\tau_{\mathrm{m}}$ 并误判了 $L$。

3. 用命题 13.4.1 解释：为什么胞体上的抑制性突触使来自每个兴奋性突触的胞体 EPSP 降低同样的比例，而远端分支上的抑制性突触则是选择性地起作用。

   **答** 胞体位于从每个兴奋性位点到胞体的路径上，所以对它们都有 $\rho = 1$，对每个输入降低量都是 $gK_{ss}/(1 + gK_{ss})$：胞体抑制按比例缩小整个胞体响应（全局增益变化）。远端抑制位点只对同一分支上更靠外的兴奋性突触位于路径上；对它们 $\rho = 1$，而由于 $K_{ii}$ 在细分支中很大，很小的 $g$ 就够了。对其他分支上的兴奋性突触，$\rho = A_{i\to p}A_{p\to i}$ 很小，因为电压从远端位点到分支点 $p$ 衰减强烈，所以它们几乎不受影响。因此远端抑制可以否决一个输入流或一个分支的树突锋电位。

4. 估计树突中 cAMP 的化学长度常数（$D \approx 300\,\mu\mathrm{m^2\,s^{-1}}$，由磷酸二酯酶移除，$\tau_c \approx 1\,\mathrm{s}$），并与 $\ce{Ca^2+}$ 的比较。这对由这两种信使介导的可塑性的特异性意味着什么？

   **答** $\lambda_c = \sqrt{300\cdot1}\,\mu\mathrm{m} \approx 17\,\mu\mathrm{m}$，是 $\ce{Ca^2+}$（$\approx 1$–$2\,\mu\mathrm{m}$）的十倍以上。在一个棘产生的 cAMP 信号会到达树突干和几十个邻近的棘，所以只依赖 cAMP 的可塑性不会是突触特异性的；突触特异性需要被激活的棘处有一个依赖 $\ce{Ca^2+}$ 的步骤（或一个局部标记，[7.16.14](/7.16.14#sec-14.7)），而 cAMP 与其他可扩散的信使则可以在一段树突内协调可塑性。实际上，cAMP 的区室化被锚定蛋白与局部降解进一步锐化，所以该估计是上限。
