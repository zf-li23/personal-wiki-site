运动皮层是 [7.16.29](/7.16.29) 的各项计算（估计身体状态、选择目标、计算反馈律）与 [7.16.30](/7.16.30) 中把指令变成力的脊髓回路相会合之处。运动区的解剖、初级运动皮层的躯体定位图、**皮质脊髓束**，以及方向调谐与**群体向量**的经典描述，见 [7.14.45](/7.14.45#sec-45.1)。本章追随五十年来运动皮层研究所经历的视角转变。最初的问题是表征性的：神经元编码运动的哪个参数（力、方向、速度还是肌肉活动）？各种答案都部分正确，这个问题随后让位于一个动力学的问题：神经元群体如何产生运动随时间变化的指令，又如何在不运动的情况下准备这些指令？动力学观点使用 [7.16.28](/7.16.28) 的工具（**群体状态空间**、**jPCA**）和 [7.16.31](/7.16.31) 的训练后循环网络。同样的群体信号，经计算机读出，驱动着为瘫痪患者恢复运动与言语的脑机接口，这是本章后半部分的主题。

## 32.1. 运动皮层区

额叶运动区包括初级运动皮层（M1，4 区）、位于 6 区外侧面的背侧与腹侧运动前皮层（PMd、PMv）、内侧面的辅助运动区与前辅助运动区，以及其下方的扣带运动区（[7.14.45](/7.14.45#sec-45.1.2)）。它们都向皮层脊髓束发出轴突，初级体感皮层与后顶叶皮层也是如此；M1 贡献约三分之一的纤维。在灵长类中，该束含有皮层运动神经元细胞，其轴突与脊髓运动神经元形成单突触接触。它们位于 M1 尾部、中央沟的壁上（"新 M1"；Rathelot 与 Strick，2009），对手部肌肉最多，它们在各物种中的数目与手的灵巧程度相关：猫和啮齿类中没有它们，那里的皮层脊髓轴突终止于中间神经元。在小鼠中，发育期间会形成短暂的皮层运动神经元突触，并通过 semaphorin–plexin 信号被消除；阻止其消除可改善精细抓握（Gu 等，2017）。即使在灵长类中，大部分皮层脊髓输出也通过脊髓中间神经元起作用，这正是产生行走运动的那些运动前网络（[7.16.30](/7.16.30#sec-30.2)）。

M1 的图是粗糙的。某个手指运动时活跃的神经元，在整个手区与其他手指的神经元相互混杂，每个神经元对几个手指都活跃（Schieber 与 Hibbard，1993）。短暂的微刺激引起几块肌肉的抽动，但 $500\,\mathrm{ms}$ 的刺激串引起协调的、类似目标的运动，如把手带到嘴边并伴有抓握与张嘴、防御姿势或伸向空间中某个区域，它们在运动皮层与运动前皮层上组织成行为学动作类别的图（Graziano、Taylor 与 Moore，2002）。并非每个运动都需要运动皮层。损毁运动皮层的大鼠仍能行走、攀爬与进食；Kawai 等（2015）发现，运动皮层对学习精确定时的按杆序列是必需的，但对学会之后的执行并不必需，此时由皮层下回路执行。相反，在灵长类中，M1 或皮层脊髓束的损毁导致手指独立运动的持久丧失。

## 32.2. 运动皮层神经元编码什么？

### 32.2.1. 力、方向与肌肉

Evarts（1968）记录了猴子在对抗或辅助运动的负荷下屈伸手腕时的锥体束神经元。许多神经元的发放随负荷变化，因而反映的是要产生的力而不是位移。随后 Georgopoulos 等（1982）发现，对从中心位置向不同方向的伸手运动，大多数手臂区神经元的发放率随运动方向与偏好方向之间夹角的余弦而变化（[式 (45.1)](/7.14.45#eq-45.1)）。这两个结果并不矛盾，因为余弦调谐是向量的任何线性编码的性质。

**命题 32.2.1（线性编码导致余弦调谐）** 若神经元的发放率是向量 $\boldsymbol{v}$（手的速度、力，或沿不同方向作用的肌肉的激活）的仿射函数 $r = b + \boldsymbol{c}\cdot\boldsymbol{v}$，则对模长固定为 $v$、方向为 $\theta$ 的 $\boldsymbol{v}$，它是余弦调谐的，$r(\theta) = b + \lVert\boldsymbol{c}\rVert v\cos(\theta - \theta_{\mathrm{pd}})$，其偏好方向 $\theta_{\mathrm{pd}}$ 为 $\boldsymbol{c}$ 的方向，调制深度正比于 $v$。

**证明** $\boldsymbol{c}\cdot\boldsymbol{v} = \lVert\boldsymbol{c}\rVert\lVert\boldsymbol{v}\rVert\cos\angle(\boldsymbol{c}, \boldsymbol{v})$。$\square$

因此余弦调谐不能告诉我们神经元编码的是哪个变量；起决定作用的实验是改变变量之间的关系。当猴子在前臂旋前、中位和旋后时做同样的腕运动，肌肉的偏好方向随前臂旋转；一些 M1 神经元的偏好方向以同样的方式旋转（"肌肉样"），另一些则在外部空间中保持不变（"外在样"），而在腹侧运动前皮层几乎都是外在样的（Kakei、Hoffman 与 Strick，1999）。对全臂的伸手运动，M1 神经元的偏好方向随姿势以及施加于肩与肘的负荷而改变，并且聚集在两个相反的方向上，即关节力矩最大的方向（Scott、Gribble、Graham 与 Cabel，2001）。Todorov（2000）表明，M1 直接规定肌肉激活的模型，结合肌肉力对长度与速度的依赖（[7.14.9](/7.14.9)），就能再现 M1 活动与运动学的大部分相关性。真实神经元的调谐在时间上也不是固定的：偏好方向与调制深度在单次伸手的过程中就会改变，而没有任何固定的运动学或动力学参数模型能够刻画（Churchland 与 Shenoy，2007）。

### 32.2.2. 解码群体

只有当读出无偏时，**群体编码**才有用。对余弦调谐的神经元，除非偏好方向分布合适，否则[式 (45.2)](/7.14.45#eq-45.2) 的**群体向量**是有偏的。

**命题 32.2.2（群体向量的偏差）** 设 $N$ 个偏好方向为 $\theta_i$ 的神经元的平均响应为 $r_i - b_i = k_i\cos(\theta - \theta_i)$，并令 $\boldsymbol{P} = \sum_i\frac{r_i - b_i}{k_i}\boldsymbol{u}_i$，其中 $\boldsymbol{u}_i = (\cos\theta_i, \sin\theta_i)$。把 $\boldsymbol{P}$ 与各方向写成复数，
$$
\mathbb{E}[P] = \frac N2\Bigl(\mathrm{e}^{\mathrm{i}\theta} + \rho_2\,\mathrm{e}^{\mathrm{i}(2\psi - \theta)}\Bigr), \qquad \rho_2\,\mathrm{e}^{2\mathrm{i}\psi} = \frac1N\sum_{i=1}^N\mathrm{e}^{2\mathrm{i}\theta_i}. \tag{32.1}
$$
群体向量对每个 $\theta$ 都指向运动方向，当且仅当偏好方向的二阶圆矩 $\rho_2$ 为零；均匀分布是充分条件但不是必要条件。

**证明** $\cos(\theta - \theta_i)\,\mathrm{e}^{\mathrm{i}\theta_i} = \tfrac12\bigl(\mathrm{e}^{\mathrm{i}\theta} + \mathrm{e}^{-\mathrm{i}\theta}\mathrm{e}^{2\mathrm{i}\theta_i}\bigr)$；对 $i$ 求和。第二项对所有 $\theta$ 为零，仅当 $\rho_2 = 0$；若 $\rho_2 > 0$，它把 $\boldsymbol{P}$ 拉向轴 $\psi$，除非 $\theta = \psi$ 或 $\theta = \psi + \pi/2$（模 $\pi$）。$\square$

这种偏差不随神经元数目增加而减小。*最优线性估计器*（Salinas 与 Abbott，1994）可以消除它，它选择 $\hat{\boldsymbol{v}} = \sum_i(r_i - b_i)\boldsymbol{D}_i$ 中的解码向量 $\boldsymbol{D}_i$，使运动分布上的均方误差最小。解为 $D = LQ^{-1}$，其中 $Q_{ij} = \mathbb{E}[(r_i - b_i)(r_j - b_j)]$ 包含噪声协方差，$L_{\cdot j} = \mathbb{E}[\boldsymbol{v}(r_j - b_j)]$；实践中它就是运动对发放率的最小二乘回归，即脑机接口的**岭回归**（32.5）。在各神经元噪声相互独立时，它的误差按 $N^{-1/2}$ 减小（见下图）。这两种解码器都不意味着脑是这样读出运动皮层的：群体向量是对群体所携带信息的一种度量，而下游的读出是脊髓，其"解码器"是皮层脊髓通路到中间神经元与运动神经元的权重集合。

## 32.3. 准备活动

### 32.3.1. 没有运动的准备

在指令延迟任务中，伸手的目标被显示出来，只有在经过可变延迟的开始信号之后才允许运动。PMd 与 M1 中许多神经元在延迟期内改变发放，其方式特定于即将进行的运动，尽管没有任何运动（Tanji 与 Evarts，1976；Weinrich 与 Wise，1982）。准备是有用的：有延迟时的反应时间比没有延迟时短约 $100\,\mathrm{ms}$，而在延迟期活动远离该目标的典型值的试验中，反应时间更长（Churchland、Yu、Ryu、Santhanam 与 Shenoy，2006）。在延迟期对 PMd 施加阈下微刺激会扰乱这一活动，使运动延迟几十毫秒，而同样的刺激在开始信号时影响较小（Churchland 与 Shenoy，2007）。目标的出现还降低许多皮层区神经元发放的试验间变异（**Fano 因子**下降），就像群体状态收敛到状态空间中的一个准备区域（Churchland 等，2010）。即使没有延迟，运动之前也有约 $50\,\mathrm{ms}$ 的短暂准备阶段（Lara、Elsayed、Zimnik、Cunningham 与 Churchland，2018）。

**定义 32.3.1（准备活动）** **准备活动**是运动前皮层与运动皮层（以及相连的区域）中神经元在运动被规定到运动被发起之间的、特定于该运动的活动；它不伴随运动或肌肉活动，并设定产生运动的起始状态。

### 32.3.2. 输出零空间假说

为什么投射到脊髓的神经元中的准备活动不引起运动？早先的一个提议是门控，即在开始信号之前抑制阻断输出，但推测的抑制性中间神经元在延迟期并不更活跃，而且许多神经元在延迟期比在运动期更活跃。Kaufman、Churchland、Ryu 与 Shenoy（2014）提出了一个几何学的回答。

**定义 32.3.2（输出零空间）** 设肌肉活动 $\boldsymbol{m}$ 通过线性读出依赖于群体发放率 $\boldsymbol{r} \in \mathbb{R}^N$，$\boldsymbol{m} = C(\boldsymbol{r} - \bar{\boldsymbol{r}})$，$C \in \mathbb{R}^{M\times N}$，$M < N$。**输出零空间**是零空间 $\mathcal{N}(C)$，即不改变输出的群体活动方向；其正交补，即 $C$ 的行空间，是*输出效能空间*。限于输出零空间内的活动变化不产生运动。

对通过发放率之和驱动一块肌肉的两个神经元，任何使一个发放率升高、另一个降低相同量的变化都是输出零的。对 $N$ 个神经元和 $M$ 块肌肉，零空间有 $N - M$ 维，占据状态空间的大部分。Kaufman 等通过在运动期间把肌肉活动对群体活动回归来估计 $C$，发现在延迟期活动主要在输出零空间中变化，只在运动开始前后才进入输出效能空间。准备活动与运动活动占据几乎正交的子空间，二者之间的转变是迅速的（Elsayed、Lara、Kaufman、Churchland 与 Cunningham，2016）。因此准备并不是被抑制，而是对脊髓不可见，开始信号改变的是动力学，而不是输出权重。下图展示了这类模型，其中准备状态被置于零空间中，开始信号之后的旋转动力学把它带入效能空间（32.4）。

### 32.3.3. 啮齿类中的因果检验

啮齿类中的光遗传学方法检验了准备活动是否必要。大鼠被训练在延迟之后，根据一串咔嗒声的速率向左或向右定向，其额定向区的神经元的延迟期活动预测方向，在延迟期沉默该区域会损害向对侧的定向（Erlich、Bialek 与 Brody，2011）。小鼠被训练在延迟之后，根据用胡须触到的杆的位置向左或向右舔舐，它们依赖前外侧运动皮层（ALM）：一项筛选通过激活抑制性中间神经元依次沉默每个皮层区，发现只有在延迟期沉默 ALM 才使随后的选择产生偏向（Guo 等，2014）。ALM 中的准备活动由锥体束神经元和投射到另一半球的端脑内神经元携带，并由与运动丘脑的环路维持，沉默运动丘脑会使之消失（Li、Chen、Guo、Gerfen 与 Svoboda，2015；Guo 等，2017）。短暂的单侧沉默之后，延迟期活动在几百毫秒内通过来自另一半球的输入恢复其扰动前的模式：准备状态表现为一个点吸引子，对沿某些方向的扰动稳健而对沿另一些方向的不稳健（Li、Daie、Svoboda 与 Druckmann，2016；Inagaki、Fontolan、Romani 与 Svoboda，2019），这就是 [7.16.43](/7.16.43) 与 [7.16.45](/7.16.45) 所分析的那类离散**吸引子**。

## 32.4. 作为动力系统的运动皮层

### 32.4.1. 初始条件与旋转

动力系统观点（Shenoy、Sahani 与 Churchland，2013）把运动皮层的群体状态 $\boldsymbol{x}$ 看作服从 $\dot{\boldsymbol{x}} = \boldsymbol{f}(\boldsymbol{x}) + \boldsymbol{u}(t)$，其中输入 $\boldsymbol{u}$ 来自丘脑与其他皮层区，并问是哪种动力学产生了指令。准备设定一个初始条件，运动由它展开。对开始信号之后的线性动力学 $\dot{\boldsymbol{x}} = A\boldsymbol{x}$，输出 $\boldsymbol{m}(t) = C\mathrm{e}^{At}\boldsymbol{x}_0$ 是准备状态 $\boldsymbol{x}_0$ 的线性函数：不同的初始条件选择同一组时间基函数（$A$ 的模式）的不同组合，而 $C\boldsymbol{x}_0 = \boldsymbol{0}$ 的要求就是输出零条件。由于伸手运动的肌肉指令是多相的，基的自然选择是一组阻尼振荡。

**定义 32.4.1（旋转动力学）** 神经群体的**旋转动力学**是这样一种模式：在准备的初始状态之后，群体状态在状态空间的一个或多个平面中旋转，各条件的旋转方向相同，因而其时间进程能被反对称 $M$ 的线性动力系统 $\dot{\boldsymbol{x}} = M\boldsymbol{x}$ 很好地拟合（定理 28.5.1）。

Churchland 等（2012）在做非节律性伸手的猴子的运动皮层与运动前皮层中，用 **jPCA**（定义 28.5.2）找到了这种旋转：状态在伸手期间以 $1$–$3\,\mathrm{Hz}$ 旋转一到两个周期，相位与幅度由准备状态决定。在人的节律性循环运动与言语期间，旋转在运动皮层中也很突出，而由输入驱动的视觉皮层的群体结构属于另一种类型（Seely 等，2016）。旋转本身并不证明存在动力学机制：活动序列（不同神经元在不同时间达峰）同样产生旋转，因此需要用保留响应光滑性与相关性的替代数据做对照（[7.16.28](/7.16.28#sec-28.5.1)；Lebedev 等，2019，以及 Churchland 等的回应）。

### 32.4.2. 训练后的网络与缠结度

Sussillo、Churchland、Kaufman 与 Shenoy（2015）训练循环网络，使其对许多伸手运动产生所记录的猴子肌肉活动，起点是各次伸手不同的准备输入（[7.16.31](/7.16.31#sec-31.5)）。当训练被正则化以倾向于简单、光滑的动力学时，网络发展出了旋转的群体动力学和单元响应，后者比肌肉更像 M1 神经元，尽管它们只在肌肉上训练。具有强而平衡的兴奋与抑制的稳定性优化网络通过**非正规放大**产生类似的暂态（[7.16.15](/7.16.15#sec-15.2.3)；Hennequin、Vogels 与 Gerstner，2014）。为什么发生器的动力学应当与它的输出不同？Russo 等（2018）给出了定量的回答。

**定义 32.4.2（轨迹缠结度）** 对群体轨迹 $\boldsymbol{x}(t)$，时刻 $t$ 的**轨迹缠结度**为
$$
Q(t) = \max_{t'}\frac{\lVert\dot{\boldsymbol{x}}(t) - \dot{\boldsymbol{x}}(t')\rVert^2}{\lVert\boldsymbol{x}(t) - \boldsymbol{x}(t')\rVert^2 + \varepsilon}, \tag{32.2}
$$
其中 $\varepsilon$ 是一个小常数；当两个邻近状态的导数很不相同时 $Q$ 很大。

由光滑的自治流场 $\dot{\boldsymbol{x}} = \boldsymbol{f}(\boldsymbol{x})$ 产生的轨迹不能以不同的方向自我交叉，所以缠结度低，叠加在其状态上的噪声会被流修正而不是被放大。相反，循环运动期间的肌肉活动是高度缠结的（同一肌肉状态在正向与反向循环中以相反的导数重复出现），由肢体驱动的体感皮层的活动也是如此。运动皮层的活动缠结度低，这是通过增加使正向与反向循环分离的维度实现的。因此低缠结度是群体靠内部动力学产生输出的标志。这些动力学并不是完全自治的：在小鼠中沉默运动丘脑会立即中断伸手，皮层活动在运动期间需要持续的丘脑输入（Sauerbrei 等，2020），所以"动力系统"是丘脑皮层环路，并有小脑与基底神经节的贡献。运动皮层还产生快速的、依赖任务的反馈修正（Pruszynski 等，2011），这正是**最优反馈控制**的反馈控制器（[7.16.29](/7.16.29#sec-29.5.2)）。

## 32.5. 脑机接口

### 32.5.1. 原理

**定义 32.5.1（脑机接口）** **脑机接口**（BMI，也称脑–计算机接口）是这样一个系统：它记录神经活动，实时从中解码出控制信号（光标的速度、机械臂或经电刺激的瘫痪肢体的运动、字符或言语），并在闭环中作用于世界，用户在其中看到结果并从中学习。向神经系统写入信息的刺激型接口在 32.6 讨论。

单个神经元可以被置于随意控制之下，这由 Fetz（1969）证明，他奖励猴子提高以仪表显示的 M1 神经元的发放：发放率在几分钟内升高，这是对神经元的一种**操作性条件反射**。对机械臂的实时控制先后在大鼠（Chapin、Moxon、Markowitz 与 Nicolelis，1999）和猴子（Wessberg 等，2000；Taylor、Tillery 与 Schwartz，2002；Serruya 等，2002）中由神经元群体实现。猴子用群体向量解码器控制带夹爪的机械臂自己进食（Velliste、Perel、Spalding、Whitford 与 Schwartz，2008）。在四肢瘫痪的人中，植入 M1 手区的 $96$ 通道硅阵列（Utah 阵列）实现了光标控制（Hochberg 等，2006），后来又实现了用机械臂（Hochberg 等，2012；Collinger 等，2013）以及用患者自己的、由肌肉功能性电刺激移动的手臂（Ajiboye 等，2017）伸取与抓握。

### 32.5.2. 解码器

解码器把所记录单元的分箱脉冲计数 $\boldsymbol{y}_t$ 映射为运动学状态 $\boldsymbol{x}_t$，通常是光标的速度。标准的有三类。

- **群体向量**：[式 (45.2)](/7.14.45#eq-45.2) 的方向读出，带有命题 32.2.2 的偏差。
- 线性滤波器：$\hat{\boldsymbol{x}}_t = \sum_{l=0}^{L-1}D_l\boldsymbol{y}_{t-l} + \boldsymbol{d}$，用最小二乘（或**岭回归**）在用户观看或尝试运动的训练数据上拟合；带多个滞后时它就是离散的 **Wiener 滤波**。
- **Kalman 滤波**：把运动学建模为线性动力系统 $\boldsymbol{x}_{t+1} = A\boldsymbol{x}_t + \boldsymbol{w}_t$，把脉冲计数建模为运动学的带噪声线性函数 $\boldsymbol{y}_t = H\boldsymbol{x}_t + \boldsymbol{d} + \boldsymbol{q}_t$（对速度做余弦调谐的**编码模型**），并用算法 29.4.1 递推地估计运动学（Wu 等，2006）。

线性滤波器把神经元直接映射到运动；Kalman 滤波器则对神经元如何依赖运动的模型求逆，并把它与运动如何演化的先验结合起来，使估计更平滑，并按各神经元的可靠性加权。脑估计肢体状态所用的同一原理（[7.16.29](/7.16.29#sec-29.4)）使它成为更好的解码器，特别是在神经元较少时（见下图）。Gilja 等（2012）进一步改进了 Kalman 解码器，把它重新拟合到用户的*意图*：在闭环使用期间，把解码的速度旋转到指向目标，再在这些意图速度上重新训练解码器（ReFIT）；此后光标控制接近了天然手臂的速度与准确性。当前的解码器包括循环网络和群体的隐动力学模型（LFADS；Pandarinath 等，2018），它们利用了 32.4 的低维性与动力学。

### 32.5.3. 环路中的学习

BMI 是一种新的效应器，脑会学习使用它。Ganguly 与 Carmena（2009）让解码器在数天内保持固定，猴子的表现提高，所记录神经元出现了稳定的调谐模式，每天都能立即回忆起来，就像运动记忆；解码器改变时，形成新的模式而不抹去第一个。当解码器给一部分神经元分配了旋转后的偏好方向时，这些神经元比其他神经元更多地改变了调谐（Jarosiewicz 等，2008）。能快速学会什么，受群体活动已有结构的约束。Sadtler 等（2014）记录了 M1 中约 $90$ 个单元，识别出它们的活动通常所在的低维**神经流形**（定义 28.5.1）。然后他们改变解码器，使光标控制需要流形内的活动模式的新组合，或需要流形之外的模式。猴子在一次实验中学会了流形内的扰动，而流形外的扰动则需要许多天的训练才学会（Oby 等，2019）。因此短期学习重复利用群体活动已有的库，这与"该库由网络的动力学决定"的看法一致。

### 32.5.4. 交流假体

对不能运动或说话的人，交流是 BMI 最重要的功能。用指向–点击光标打字达到每分钟约 $40$ 个正确字符（Pandarinath 等，2017）。改为解码尝试的手写，用循环网络对每个尝试字符的神经活动分类，在语言模型校正之前将其提高到每分钟 $90$ 个字符、准确率 $94\,\%$（Willett、Avansino、Hochberg、Henderson 与 Shenoy，2021），因为手写产生的模式比直线光标运动更不相同、更有时间结构。言语神经假体从腹侧运动前皮层的阵列（Willett 等，2023：每分钟 $62$ 个词，词汇量 $125\,000$ 时词错误率 $24\,\%$）或从言语皮层上的皮层电图（Metzger 等，2023：每分钟 $78$ 个词，带合成语音与动画面孔）解码尝试的言语，这类系统的准确性随使用时间延长和语言模型增大而不断提高。这些系统表明，运动皮层中构音的表征在瘫痪多年之后仍保持完好。

感觉反馈使环路闭合。没有它，BMI 用户必须盯着设备；用体感皮层的皮层内微刺激可以引起瘫痪手上局部的触觉，借此控制机械臂的人完成抓握任务的时间约缩短一半（Flesher 等，2016，2021）。

## 32.6. 刺激与神经调制接口

刺激型接口比记录型接口更古老、更普及。人工耳蜗是耳蜗中的一排电极，根据声音在各频带中的能量刺激听神经（**部位原理**，[7.16.24](/7.16.24)），已使超过一百万人恢复了言语感知。深部脑刺激（DBS）通过位于丘脑底核或苍白球内侧部的电极施加持续的高频脉冲（约 $130\,\mathrm{Hz}$），治疗 **Parkinson 病**的运动症状，通过位于丘脑腹中间核的电极治疗特发性震颤；它也用于肌张力障碍与强迫症。它的机制不是简单的损毁：高频刺激打乱**基底神经节**环路中病理性的同步 beta 振荡（$13$–$30\,\mathrm{Hz}$），代之以规则的、信息贫乏的活动（[7.16.40](/7.16.40)）。由于 beta 功率跟踪症状的严重程度，适应性 DBS 在 beta 功率升高时才开启刺激，以更低的能量获得相同或更好的效果（Little 等，2013），这类闭环系统已进入临床使用。治疗**癫痫**的响应式神经刺激从植入电极的记录中检测**癫痫发作**的开始并刺激以中止之（[7.16.52](/7.16.52)）。用时空模式对腰髓做硬膜外刺激，针对各块肌肉的运动池并与预期的运动定时，使慢性脊髓损伤患者恢复了拄拐杖或用助行器行走（Wagner 等，2018），与皮层解码器耦合后，它构成脑–脊髓接口，恢复了对迈步时机的随意控制（Lorach 等，2023），这调动了 [7.16.30](/7.16.30) 的脊髓运动网络。

每个接口都提出超出工程之外的问题：植入物数十年的耐久性与安全性、被解码的神经数据的隐私、其运动或言语部分由算法产生的用户的能动性与身份，以及公平的可及性。这些不是停止的理由，而是负责任地发展的条件。

## 小结

| 问题 | 回答 | 出处 |
|---|---|---|
| 神经元编码什么？ | 余弦调谐由任何线性编码推出；肌肉样与外在样细胞共存；调谐在伸手期间改变 | 命题 32.2.1 |
| 群体向量准确吗？ | 仅当偏好方向的二阶圆矩为零；最优线性估计器消除偏差 | 命题 32.2.2，式 (32.1) |
| 活动如何在不运动时准备？ | 准备活动位于读出的输出零空间中 | 定义 32.3.1、32.3.2 |
| 运动如何产生？ | 由准备的初始条件出发，经具有旋转结构与低缠结度的动力学 | 定义 32.4.1、32.4.2 |
| 活动如何变成控制？ | 线性解码器或 Kalman 解码器，重新拟合到意图；脑在其神经流形内学习 | 定义 32.5.1 |

- 运动区并行地投射到皮层脊髓束；灵长类 M1 中的皮层运动神经元细胞支持灵巧性，但大部分输出通过脊髓中间神经元起作用。长时间的微刺激引起行为学动作。
- 余弦调谐（命题 32.2.1）不能确定被编码的变量；分离肌肉与运动学的实验发现两类神经元都存在。群体向量会被非均匀的偏好方向所偏倚（命题 32.2.2）；最优线性估计器则不会。
- 准备活动（定义 32.3.1）缩短反应时间，且在因果上是必需的（ALM、额定向区）；它位于输出零空间中（定义 32.3.2），并由具有类吸引子稳健性的丘脑皮层环路维持。
- 在动力学观点中，准备设定初始条件，动力学产生运动；运动皮层表现出旋转动力学（定义 32.4.1）与低缠结度（定义 32.4.2），被训练产生肌肉活动的网络亦然。
- 脑机接口（定义 32.5.1）用线性滤波器或 Kalman 滤波器解码运动；用户在神经流形内快速学会新的解码器，在流形外则缓慢；手写与言语解码器恢复交流；刺激型接口（人工耳蜗、深部脑刺激与脊髓刺激）向神经系统写入信息。

## 思考题

1. 三个神经元的偏好方向为 $0^\circ$、$90^\circ$ 与 $180^\circ$。计算二阶圆矩 $\rho_2$，以及对 $45^\circ$ 方向的运动所期望的群体向量。它指向哪个方向？

   **答** $\frac13(\mathrm{e}^{0} + \mathrm{e}^{\mathrm{i}\pi} + \mathrm{e}^{2\mathrm{i}\pi}) = \frac13$，所以 $\rho_2 = 1/3$，$\psi = 0$。由式 (32.1)，$\mathbb{E}[P] = \frac32\bigl(\mathrm{e}^{\mathrm{i}\pi/4} + \tfrac13\mathrm{e}^{-\mathrm{i}\pi/4}\bigr) = \frac32\cdot\frac{\sqrt2}{2}\bigl(\tfrac43 + \tfrac23\mathrm{i}\bigr)$，其角度为 $\arctan(1/2) = 26.6^\circ$：该向量被拉向 $0^\circ$–$180^\circ$ 轴，三个偏好方向中有两个在此轴上。直接计算：响应为 $\cos45^\circ$、$\cos45^\circ$ 与 $-\cos45^\circ$，$\boldsymbol{P} = \frac{\sqrt2}{2}\bigl[(1, 0) + (0, 1) - (-1, 0)\bigr] = \frac{\sqrt2}{2}(2, 1)$，方向相同。

2. $100$ 个神经元的群体通过秩为 2 的线性读出 $C$ 驱动两块肌肉。输出零空间有多少维？如果准备活动各向同性地分布在所有方向上，它的方差有多大比例到达肌肉？Kaufman 等实际发现了什么？

   **答** $\dim\mathcal{N}(C) = 100 - 2 = 98$。各向同性的活动会把其方差的 $2/100 = 2\,\%$ 放在效能空间，所以即使随机的准备模式也只会使肌肉略微运动；使这一假说有信息量的是与运动活动的比较。Kaufman 等发现，效能方差与零方差之比在准备期间远低于运动期间，并且低于随机子空间的预期，所以准备活动特意回避效能方向，而运动活动集中在其中。

3. 为什么用同样的神经元，Kalman 滤波解码器比线性滤波器更平滑、更准确？线性滤波器何时可能更可取？

   **答** Kalman 滤波器结合两种信息来源：运动平滑演化的先验（$\boldsymbol{x}_{t+1} = A\boldsymbol{x}_t + \boldsymbol{w}_t$）和给定运动时脉冲计数的似然；每次更新都按新脉冲相对于预测的可靠性加权（Kalman 增益），所以孤立的带噪声计数对估计的改变很小。带少数几个滞后的线性滤波器用固定权重在短窗口内对计数取平均，没有运动模型；神经元少时它的输出带噪声。当假设的动力学有误（突然停止与开始，平滑先验会使之延迟）、当调谐模型强烈非线性，或当其简单性与无滞后很重要时，线性滤波器可能更可取；在闭环中把任一种解码器重新拟合到用户的意图（ReFIT）往往比二者的选择更重要。

4. Sadtler 等发现，BMI 解码器在流形内的扰动几小时就能学会，而流形外的扰动则不能。这对短期运动学习的机制意味着什么？32.4 的网络动力学如何解释它？

   **答** 短期学习似乎是把已有的活动模式重新分配给新的输出（改变产生哪些模式，或选择它们的输入），而不是创造新的模式，后者需要改变把活动限制在流形上的循环连接。如果流形是循环动力学能从可用输入到达的状态的集合，那么流形内的学习可以通过改变运动皮层的输入（来自运动前区、丘脑或小脑）来实现，这是一个快过程；而流形外的学习需要运动皮层内改变动力学的突触变化，这是一个慢过程。流形外的扰动可以在数天训练中学会、并伴随新的活动模式出现，这一发现符合这种双时间尺度的观点。

5. （开放题）运动皮层的活动缠结度低，而肌肉活动高度缠结。解释为什么由自身动力学产生输出的网络需要低缠结度，并提出如何检验某个脑区是发生器还是中继站。

   **答** 在自治动力系统中，导数是状态的函数，$\dot{\boldsymbol{x}} = \boldsymbol{f}(\boldsymbol{x})$；若两个邻近状态需要很不相同的导数，$\boldsymbol{f}$ 就必须急剧变化，状态中的微小噪声会把轨迹送上错误的分支。因此发生器需要额外的维度，在其中把输出中看起来相似的状态分开，这降低了缠结度。由外部输入驱动的区域（感觉反馈的中继站，或跟随下游发生器的区域）没有这种约束，因为它的导数由外部设定。检验方法：对该区域及其候选的输入与输出计算跨行为的缠结度；短暂扰动该区域，看轨迹是回到同一路径（发生器）还是跟随输入；沉默它的输入（如对运动丘脑所做的）以度量动力学的自治程度；并与被训练产生同样输出的网络比较，后者为了对噪声稳健必须具有低缠结度。
