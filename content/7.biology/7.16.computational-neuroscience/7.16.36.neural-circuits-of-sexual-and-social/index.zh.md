社会行为（求偶、攻击、育幼、亲和）是动物中最刻板的行为之一，许多是先天的：孤养长大的雄性小鼠第一次遇到入侵者就会攻击它。它们为回答“基因如何构建产生行为的回路”这一问题提供了一条途径。有两个特点使它们富有启发。它们在两性之间不同，因此**性别决定**（[7.5.26](/7.5.26)）的遗传开关为我们提供了追踪相关神经元的抓手；它们还由**下丘脑**及其在昆虫中的对应结构里少数几种可由遗传方法鉴定的神经元类型控制，这些神经元的活动可以被记录和操控（[7.16.3](/7.16.3)）。本章在细胞类型、发育和动力学的层面讨论这些回路。下丘脑的调节逻辑已在 [7.16.34](/7.16.34) 介绍；社会行为的生态学和演化属于动物行为学，这里不讨论。

## 36.1. 果蝇中一种行为的遗传开关

### 36.1.1. fruitless 与 doublesex

雄性果蝇通过一套刻板的序列向雌蝇求偶：朝向、跟随、用前足尝接触性信息素，并发出翅振的歌声；每一步都依赖伴侣的线索，并提高下一步的概率。果蝇的性别由 X 染色体的数目以细胞自主的方式决定，经由一连串**可变剪接**：在雌性中，蛋白 Sex-lethal 指导 *tra* mRNA 的雌性特异剪接，Tra 蛋白又反过来指导两个转录因子基因 *fruitless*（*fru*）和 *doublesex*（*dsx*）的剪接（[7.5.26](/7.5.26#sec-26.5)）。

**定义 36.1.1（Fruitless 与 Doublesex）** **Fruitless**（FruM）是只在雄性中产生的 BTB–锌指转录因子，来自 *fru* 基因一个启动子转录本的默认剪接；它表达于约 2000 个神经元（占神经系统的 2%），是雄性求偶所必需的。**Doublesex** 是一种转录因子，其雄性（DsxM）和雌性（DsxF）异构体由性别特异的剪接产生，控制身体和一部分神经元的性分化。

遗传实验确立了 FruM 的作用。缺乏它的雄蝇不向雌蝇求偶；被改造成以雄性方式剪接 *fru*、因而表达 FruM 的雌蝇，会对其他雌蝇做出雄性的求偶序列（Demir 与 Dickson，2005）。因此，一个基因中的单次剪接决定就规定了一种复杂行为的大部分。FruM 在发育过程中起作用，规定 Fru⁺ 神经元的数目、分支和连接。在雄性中，一簇称为 P1 的中间神经元因 FruM 和 DsxM 而存活并广泛分支；在雌性中，同源的细胞通过凋亡死去。在嗅觉系统中，Fru⁺ 神经元的雄性特异分支把由**气味受体** Or67d 检测到的雄性信息素乙酸顺-11-十八碳烯酯（cis-vaccenyl acetate）传到抑制对其他雄蝇求偶的回路。

### 36.1.2. P1 神经元与持续状态

Fru⁺ 神经元构成一条回路：从感觉神经元（前足检测雌性信息素的味觉神经元、嗅觉和视觉神经元）经整合性中间神经元，到下行神经元和腹神经索的运动回路。每个半球约 20 个 P1 神经元是其决策节点：它们被雌性线索兴奋，被雄性线索抑制，激活它们会使孤独的雄蝇对着虚空唱歌。它们的输出经一个下行神经元到达构建歌声模式的胸部回路，这些回路起**中枢模式发生器**的作用。短暂激活 P1 神经元还会使雄蝇处于增强求偶和攻击的状态，在刺激之后持续数分钟（Hoopfer 等，2015），远长于 P1 本身的响应。因此 P1 神经元不仅指挥一个动作，还设定一种内部状态：一个可缩放的、持续的变量，对之后的行为产生偏置，这一性质在哺乳动物的社会回路中再次出现（36.3.2 节）。

## 36.2. 哺乳动物脑的性分化

### 36.2.1. 激素的组织与激活作用

在哺乳动物中，性腺由 Y 染色体上的 *Sry* 决定（[7.5.26](/7.5.26#sec-26.2)），脑主要在性腺激素而不是自身性染色体的影响下分化。Phoenix、Goy、Gerall 与 Young（1959）发现，出生前暴露于睾酮的雌性豚鼠，成年后表现出雄性典型而非雌性典型的行为，即使给予适合成年雌性的激素也是如此，而给成年雌性睾酮则没有持久效应。

**定义 36.2.1（组织–激活假说）** **组织–激活假说**（organizational–activational hypothesis）认为，性腺类固醇在敏感期作用于发育中的脑，永久性地组织性二型的神经回路（组织效应），并作用于成年脑，短暂而可逆地激活这些回路所支持的行为（激活效应）。

在啮齿类中，组织期跨越妊娠晚期和出生后第一周，此时雄性的睾丸产生睾酮激增。啮齿类脑中大多数男性化效应由雌二醇产生：进入神经元的睾酮被芳香化酶转化为雌二醇，雌二醇通过雌激素受体 α（Esr1）起作用。雌性胎儿受到保护而不受母体雌激素影响，因为其血浆中的甲胎蛋白结合雌二醇而不结合睾酮。在包括人在内的灵长类中，雄激素受体起更大的作用：完全性**雄激素不敏感综合征**（XY，有睾丸但雄激素受体无功能）的人发育出雌性典型的性别认同。

### 36.2.2. 性二型核团

**定义 36.2.2（性二型核团）** **性二型核团**（sexually dimorphic nucleus）是大小、细胞数目或细胞组成在两性之间有一致差异的脑核团；经典的例子是大鼠视前区的性二型核团（SDN-POA），雄性的比雌性大数倍（Gorski 等，1978）。

SDN-POA 说明了组织作用的机制：围产期雌二醇阻止其神经元凋亡，因此出生时用睾酮处理的雌性发育出雄性大小的核团，出生时被阉割的雄性则发育出雌性大小的核团。二型性可以朝任一方向：前腹侧室周核在雌性中更大，含有触发排卵前黄体生成素激增的 kisspeptin 神经元。许多二型性不在大小，而在基因表达和连接：同一核团含有比例不同的神经元类型，或有性别特异的受体表达。因此社会行为主要由在两性中调谐不同的共享回路构建，刺激合适的神经元常常能在另一性别中唤起性别典型行为。通过**犁鼻器**的信息素感知表明了这一点：缺乏犁鼻器通道 TRPC2 的雌性小鼠表现出雄性典型的社会行为（Kimchi、Xu 与 Dulac，2007），所以这些行为的回路在雌性中同样存在，只是通常被感觉输入抑制。

## 36.3. 攻击与腹内侧下丘脑

### 36.3.1. 分级活动选择行为

小鼠腹内侧下丘脑的腹外侧部（VMHvl）含有表达 Esr1 和孕酮受体的神经元。在雄性中，这些神经元在与两性的社会接触期间都活跃，光遗传学激活 VMHvl 会立即引起攻击，甚至对不合适的目标也是如此（Lin 等，2011）。对 VMHvl 的 Esr1⁺ 神经元做分级激活揭示了一个连续谱：弱刺激引起社会探查和与交配相关的行为，强刺激引起攻击（Lee 等，2014），沉默该群体则减少攻击。同一群神经元因此支持性质相反的行为，表达哪一种取决于活动水平和感觉情境，仿佛这些行为是同一个变量上的不同阈值。在雌性中，VMHvl 的 Esr1⁺ 神经元分为参与生殖行为的内侧亚群和促进攻击的外侧亚群，后者在哺乳期雌性中很高（Hashikawa 等，2017）。

![雄性小鼠中分级光遗传学激活 VMHvl Esr1$^+$ 神经元所引起的行为（示意 Lee 等 2014 年结果的定性特征；曲线为示意）。弱激活引起社会探查和与交配相关的行为；随着激活增加，这些行为让位于攻击。](./plots/vmhvl-intensity.py)

### 36.3.2. 近似线吸引子

攻击具有内部状态的性质：它在反复的接触中升级，在对手离开后持续数十秒到数分钟，并泛化到新的目标。对接触期间数百个 VMHvl Esr1⁺ 神经元做**钙成像**，再用拟合群体活动的动力系统模型分析，发现了一个缓慢衰减的维度，它整合接触并预测攻击的概率（Nair 等，2023）。该群体表现得像一个近似**线吸引子**（[7.16.33](/7.16.33)）：状态空间中的一个方向，沿着它活动既不增长也不快速衰减，因此网络存储一个分级的值。

**例 36.3.1（持续的攻击状态）** 一个由 $N = 50$ 个单元组成的线性发放率网络 $\tau\,\dot{\boldsymbol{r}} = -\boldsymbol{r} + W\boldsymbol{r} + \boldsymbol{b}\,u(t)$，$\tau = 1\,\mathrm{s}$，其对称权重矩阵 $W$ 的主特征向量 $\boldsymbol{q}$ 的特征值为 $\lambda$，其余特征值在 0 与 0.3 之间。沿 $\boldsymbol{q}$ 的活动 $x = \boldsymbol{q}^{\mathsf T}\boldsymbol{r}$ 满足 $\tau\,\dot x = -(1 - \lambda)x + (\boldsymbol{q}^{\mathsf T}\boldsymbol{b})\,u$，因此其时间常数为 $\tau/(1 - \lambda)$：$\lambda = 0.99$ 时为 $100\,\mathrm{s}$，$\lambda = 0.8$ 时为 $5\,\mathrm{s}$，而所有其他方向在约 $1.4\,\mathrm{s}$ 内衰减。短暂的输入 $u(t)$（与入侵者的接触）只有在 $\lambda$ 接近 1 时才沿 $\boldsymbol{q}$ 累积。如果攻击概率是 $x$ 的 sigmoid 函数，近似积分器网络在三次接触中不断升级，并保持攻击状态数分钟；对照网络则在接触之间回到基线。

:::

![攻击状态的近似线吸引子（例 36.3.1）。上：在 $\lambda = 0.99$（红）和 $\lambda = 0.8$（蓝）的网络中，三次 2 s 接触（黄）期间沿慢模的活动。下：攻击概率，慢模活动的 logistic 函数（阈值 1.5，斜率 0.3）。只有近似积分器网络升级，并在最后一次接触后保持攻击状态数分钟。](./plots/line-attractor.py)

该模型做出可检验的预测：沿慢方向的扰动应使状态持续偏移，而沿其他方向的扰动应迅速衰减；慢时间常数应取决于提供有效循环兴奋的因素。对 VMHvl 神经元的光遗传学扰动确实产生沿整合维度的持续偏移，其时间常数取决于神经肽信号；慢动力学究竟来自循环连接、缓慢的肽类作用还是内在性质，尚无定论。

## 36.4. 育幼行为

未交配的雄性小鼠常常攻击幼崽，而父亲和雌鼠则照料它们：筑巢、叼回幼崽并为之梳理。Wu、Autry、Bergan、Watabe-Uchida 与 Dulac（2014）鉴定出视前内侧区（MPOA）中表达甘丙肽的神经元是一个关键节点。这些神经元在两性的育幼期间都活跃；消融它们损害育幼，光遗传学激活它们则使未交配的雄鼠停止攻击幼崽并为其梳理。靶标不同的甘丙肽神经元亚群控制育幼的不同成分：投射到导水管周围灰质的控制幼崽梳理，投射到 VTA 的控制接近幼崽的动机，投射到内侧**杏仁核**的控制对竞争性社会互动的抑制（Kohl 等，2018）。与果蝇的回路一样，行为由一个中央节点把模块组装起来，该节点向运动和动机靶标分派。育幼行为与针对幼崽的攻击行为相互竞争，它们的平衡随社会经验和激素状态在数周的时间里发生变化。

## 36.5. 催产素、血管升压素与社会联结

**催产素**和**血管升压素**是 PVH 与 SON 大细胞神经元的九肽**神经肽**（[7.14.34](/7.14.34#sec-34.4)）；除外周的激素作用外，它们还在脑中作为从树突和轴突侧支释放的**神经调质**起作用。

它们在社会联结中作用的最清楚的证据来自田鼠。草原田鼠形成持久的配偶联结，双亲都照料幼崽；亲缘关系很近的山地田鼠和草甸田鼠则不然。这些物种的差别不在肽，而在受体的分布：草原田鼠在伏隔核中有密集的催产素受体，在腹侧苍白球中有血管升压素 V1a 受体，这两个区域都属于奖赏系统（[7.16.37](/7.16.37)）。这些区域中的受体拮抗剂阻止伴侣偏好的形成，在雄性草甸田鼠的腹侧苍白球中用病毒过表达 V1a 受体则诱导出伴侣偏好（Lim 等，2004）。当伴侣的线索通过这些受体与奖赏系统的激活相联系时，联结似乎就形成了，这是一种奖赏学习（[7.16.39](/7.16.39)）。

催产素还调节社会行为的感觉处理。在小鼠中，它通过短暂减少抑制，增强左侧听觉皮层对幼崽痛苦叫声的反应，并使未交配的雌鼠能够叼回幼崽（Marlin 等，2015）。关于鼻内催产素对人的信任和社会认知的效应，已报道的结果重复性很差，应当谨慎对待。

## 36.6. 鸟鸣

鸣禽学习它们的歌声，在许多物种中只有雄性鸣唱。学习分两个阶段：感觉期，幼鸟在**关键期**内记住成年导师的歌声；感觉运动期，幼鸟练习，并利用听觉反馈逐渐使自己的歌声与记住的模板相匹配。在感觉期之后、练习之前被致聋的鸟从不产生正常的歌声，孤养长大的鸟产生异常的歌声，但仍具有物种典型的特征，因此学习受到先天模板的限制。

鸣唱系统是一组离散的前脑核团。从 HVC 到弓状皮质粗核（RA）再到发声器官的脑干运动神经元的运动通路产生歌声：投射到 RA 的 HVC 神经元在每首歌的某一时刻发放一次短暂的簇，因此群体像时钟一样在时间上平铺整首歌，而 RA 神经元编码音节的声学特征。前脑前通路与皮层–基底神经节–丘脑环路同源（Area X、DLM、LMAN），学习需要它，唱出已学会的歌则不需要。LMAN 向 RA 注入变异性，起探索的作用，而对 Area X 的**多巴胺**信号报告某次演唱比预期更好还是更差，因此歌声学习是**基底神经节**回路中的一种**强化学习**（[7.16.40](/7.16.40)）。斑胸草雀的 HVC 和 RA 在雄性中比雌性大数倍（Nottebohm 与 Arnold，1976），这是最早发现的脑核团性二型。给雌性孵化幼鸟雌二醇可使其部分男性化，但一只身体一侧遗传上为雄性、另一侧为雌性的斑胸草雀，在相同的激素环境中，其雄性一侧的鸣唱系统更男性化（Agate 等，2003）：在鸟类中，神经元自身的性染色体基因也有贡献。

## 小结

- 在*果蝇*中，性别特异的剪接在雄性中产生 FruM（定义 36.1.1）；FruM 是求偶所必需的，足以使雌蝇求偶，FruM 和 DsxM 规定 P1 神经元的存活和连线，P1 神经元指挥求偶并设定持续的内部状态。
- 在哺乳动物中，性腺类固醇在敏感窗口中组织发育中的脑，并在成年期激活行为（定义 36.2.1）；在啮齿类中，男性化主要由芳香化酶把睾酮转化而成的雌二醇完成，在灵长类中更多依赖雄激素受体。性二型核团（定义 36.2.2）通过激素调节的细胞存活产生，但大多数二型性是共享回路内调谐的差异。
- VMHvl Esr1⁺ 神经元的分级活动在从探查到攻击的社会行为之间做出选择；它们的群体活动含有一个缓慢的整合维度，即攻击状态的近似线吸引子（例 36.3.1）。
- MPOA 甘丙肽神经元是育幼行为的核心，由投射定义的亚群控制其各个成分。
- 奖赏区的催产素和血管升压素受体是草原田鼠配偶联结所必需的；物种差别在受体分布而不在肽。
- 鸟鸣在关键期通过运动通路（HVC–RA）和实现强化学习的基底神经节环路学会；鸣唱核团通过激素和细胞自主的遗传因素呈性二型。

| 系统 | 关键神经元 | 发育开关 | 原理 |
|---|---|---|---|
| 果蝇求偶 | P1，Fru⁺ 回路 | *fru*、*dsx* 剪接 | 一个基因规定先天行为的回路；指令神经元设定状态 |
| 啮齿类攻击 | VMHvl Esr1⁺ | 围产期雌二醇，成年类固醇 | 分级活动选择行为；缓慢整合 |
| 啮齿类育幼 | MPOA 甘丙肽 | 社会经验，激素 | 中央节点向模块化输出分派 |
| 社会联结 | 奖赏区的催产素与 V1a 受体 | 受体分布 | 与奖赏相联系的社会线索 |
| 鸟鸣 | HVC、RA、Area X | 雌二醇与性染色体 | 关键期学习与基底神经节环路 |

## 思考题

1. 表达 FruM 的雌蝇向其他雌蝇求偶，缺乏 FruM 的雄蝇有雄性的身体但不求偶。这些结果说明了果蝇性分化中身体与脑的什么关系？与哺乳动物有何对比？

   **答** 在果蝇中，性别身份是细胞自主的：每个细胞读取自己的染色体性别，神经元通过自身对 *fru* 和 *dsx* 的剪接获得雄性或雌性身份，与身体的其余部分无关。行为遵循神经元的基因型，而不是身体的基因型。在哺乳动物中，脑主要由来自性腺的激素分化，因此按其激素暴露而发育；性染色体基因的细胞自主效应存在（在鸟类中更突出），但居于次要地位。

2. 在例 36.3.1 中，当相邻接触之间的间隔为 $T$ 时，推导第 $n$ 次接触刚结束时的慢模活动。$\lambda$ 与 $T$ 如何决定阈值 $\theta$ 是否会被达到？

   **答** 每次短暂的接触增加一个增量 $\Delta$（约为 $\boldsymbol{q}^{\mathsf T}\boldsymbol{b}$ 乘以脉冲持续时间除以 $\tau$），在接触之间 $x$ 按因子 $\rho = \mathrm{e}^{-(1-\lambda)T/\tau}$ 衰减。$n$ 次接触后 $x_n = \Delta(1 + \rho + \dots + \rho^{n-1}) = \Delta(1 - \rho^n)/(1 - \rho)$，趋近 $\Delta/(1 - \rho)$。只有当 $\Delta/(1 - \rho) > \theta$ 时才能到达阈值，需要 $n = \lceil \ln(1 - \theta(1 - \rho)/\Delta)/\ln\rho \rceil$ 次接触。当 $\lambda = 0.99$、$T = 30\,\mathrm{s}$ 时，$\rho = \mathrm{e}^{-0.3} \approx 0.74$，渐近值约为 $3.9\Delta$；当 $\lambda = 0.8$ 时，$\rho = \mathrm{e}^{-6} \approx 0$，活动从不超过约 $\Delta$。$\lambda$ 越大、接触越频繁，升级越快。

3. 给新生雌性大鼠睾酮会产生雄性大小的 SDN-POA，给雌二醇也一样；给缺乏芳香化酶的新生雌性小鼠睾酮则不会。每个结果说明什么？为什么雌性胎儿不会被母体雌二醇男性化？

   **答** 前两个结果表明，男性化信号在新生期的敏感期起作用，雌二醇是充分的。芳香化酶敲除的结果表明，睾酮是通过在脑内转化为雌二醇起作用的。雌性胎儿受到保护，是因为胎儿血浆中的甲胎蛋白结合雌二醇并使其不能进入脑，而睾酮不被结合，进入脑并在局部被芳香化；因此，尽管活性分子是一种雌激素，男性化信号仍被限制在雄性中。

4. （开放题）草原田鼠的配偶联结需要奖赏区的催产素和血管升压素受体。提出一个把社会联结视为习得关联的模型，并设计一个实验，把它与肽不经学习而产生偏好的模型区分开。

   **答** 学习模型：在与伴侣的社会互动中，伏隔核中的多巴胺释放与催产素和血管升压素受体的激活以及伴侣的感觉特征（它的气味）同时发生；三因子可塑性规则增强把这一特征传到奖赏回路的突触，于是伴侣成为条件性的奖赏刺激。预测：偏好应当特异于互动期间出现的线索，应当要求同时激活多巴胺受体，并应在互动期间而非之后阻止伏隔核的可塑性时被阻断。检验：在没有任何社会互动的情况下，把肽受体的激活（例如局部输注激动剂）与一个个体的气味配对而不与另一个个体配对，检验是否形成特异于配对气味的偏好；然后在配对期间加用多巴胺受体拮抗剂重复实验。学习模型预测依赖多巴胺的、气味特异的偏好；直接的非联想模型则预测对任何个体的社交性普遍增加。
