前面各章所讨论的全部加工都服务于一个目的：脑作用于世界的唯一方式是收缩肌肉。本章开启课程中关于运动的部分，所问的是：无论在神经系统的哪个位置实现，任何运动系统都必须完成哪些计算。感觉信号到达得晚而且带有噪声；身体的自由度远多于任务所需；肌肉带来的噪声随其产生的力增大；肢体的动力学随生长、疲劳和每一件拿起的工具而改变。控制理论与 Bayes 统计给出了一组简洁的回答：用内部模型预测自身指令的后果，把这些预测与感觉证据结合起来估计身体的状态，在噪声存在时选择最优的指令，并通过学习不断重新校准模型。这一切所依托的反射回路，即牵张反射与运动控制的层级，见 [7.14.44](/7.14.44)；线索的 Bayes 整合是 [7.16.27](/7.16.27) 的主题。后续各章把这些原理定位到脊髓（[7.16.30](/7.16.30)）、运动皮层（[7.16.32](/7.16.32)）、小脑（[7.16.33](/7.16.33)）和基底神经节（[7.16.40](/7.16.40)）。

## 29.1. 运动控制的问题

### 29.1.1. 冗余、延迟、噪声与变化

身体的四个特性使运动成为一个困难的计算问题。

| 问题 | 例子 | 后果 |
|---|---|---|
| 冗余 | 约 600 块肌肉、200 多个关节；空间中的一点可以用无穷多种手臂姿势、轨迹和肌肉激活到达 | 脑必须选定一个解（Bernstein 的自由度问题） |
| 延迟 | 脊髓反射 $25$–$50\,\mathrm{ms}$，长潜伏期（经皮层）反应 $50$–$100\,\mathrm{ms}$，视觉反馈 $100$–$200\,\mathrm{ms}$ | 仅靠反馈无法控制快速运动 |
| 噪声 | 感觉噪声、运动神经元的变异性、随力增大的力噪声 | 重复的运动会散开，散布的程度取决于运动计划 |
| 非线性与变化 | 关节间的相互作用力矩，肌肉力对长度与速度的依赖（[7.14.9](/7.14.9)），生长、疲劳、工具 | 从指令到运动的映射必须不断学习、重新学习 |

冗余既是问题也是机会：由于存在许多解，脑可以选择受噪声影响最小或耗费力气最少的那个（29.5）。延迟是最根本的约束，因为它限制了反馈所能达到的效果，并迫使脑进行预测。

### 29.1.2. 感觉运动环路的层级

运动反应形成一个层级，速度与精细程度在其中互相交换。最快的是脊髓反射，其连接是固定的，但增益由下行通路设定（[7.14.44](/7.14.44#sec-44.1)）。行走、呼吸、咀嚼等节律性运动由脊髓和脑干中的**中枢模式发生器**产生，并由上位中枢启动、停止和调制（[7.16.30](/7.16.30)）。随意运动由皮层网络规划和发起，它们接收最丰富的感觉信息，但响应最慢。即使是手臂受到机械扰动后 $50$–$100\,\mathrm{ms}$ 的长潜伏期反应，也已经是灵活的：它取决于任务和运动的目标（Pruszynski 与 Scott，2012），这正是最优反馈控制的一个预言（29.5.2）。

## 29.2. 前馈控制与反馈控制

**定义 29.2.1（前馈控制与反馈控制）** 在*前馈*（开环）控制中，运动指令事先根据期望的运动和身体的模型算出，运动进行过程中不使用关于它的感觉信息。在*反馈*（闭环）控制中，指令根据期望状态与感知到的状态之差连续计算。

前馈控制快但盲：模型有误或运动受到扰动时它就会失败。反馈控制无论误差由什么引起都能纠正，但只能在误差被感知之后。**前庭眼反射**几乎是纯粹的前馈控制，因为靠视觉反馈来稳定视网膜像会太迟（头部转动后眼睛约 $10\,\mathrm{ms}$ 就开始反向转动；[7.16.33](/7.16.33)）；抓握物体则把前馈的握力与物体滑动时的反馈修正结合起来。多数运动两者并用。

反馈的困难在于延迟。最简单的情形能把这种效应准确地显示出来。

**命题 29.2.1（延迟的比例反馈）** 对被控对象 $\dot x = u$ 与延迟反馈律 $u(t) = -k\,[x(t - T) - x^*]$，$k > 0$，误差 $\varepsilon = x - x^*$ 满足 $\dot\varepsilon(t) = -k\,\varepsilon(t - T)$。不动点 $\varepsilon = 0$ 渐近稳定当且仅当 $kT < \pi/2$。在 $kT = \pi/2$ 时系统以周期 $4T$ 振荡；当 $1/\mathrm{e} < kT < \pi/2$ 时系统以衰减振荡的方式趋近目标。

**证明** 形如 $\mathrm{e}^{\lambda t}$ 的解满足特征方程 $\lambda = -k\,\mathrm{e}^{-\lambda T}$。$T = 0$ 时唯一的根是 $\lambda = -k < 0$；随着 $kT$ 增大，根只能穿过虚轴进入右半平面。令 $\lambda = \mathrm{i}\omega$，得 $\mathrm{i}\omega = -k(\cos\omega T - \mathrm{i}\sin\omega T)$，故 $\cos\omega T = 0$ 且 $\omega = k\sin\omega T$；第一次穿越时 $\omega T = \pi/2$、$\omega = k$，从而 $kT = \pi/2$，周期为 $2\pi/\omega = 4T$。实根仅当 $kT \le 1/\mathrm{e}$ 时存在（函数 $\lambda\mathrm{e}^{\lambda T}$ 的最小值为 $-1/(\mathrm{e}T)$）；超过这个值，主导根是复数，趋近过程是振荡的。$\square$

这一结果可以推广到所有反馈环路：增益与延迟的乘积是受限的，接近极限运行的环路会以几个延迟的周期振铃。对于 $T = 100\,\mathrm{ms}$ 的视觉环路，临界增益只有 $16\,\mathrm{s^{-1}}$，所以仅靠视觉修正的运动，若不振荡，不可能快于几百毫秒。生理性震颤与病理性阵挛就是这类短反射环路的振荡（[7.14.44](/7.14.44#sec-44.3.2)，那里对带二阶肢体的**牵张反射**做了同样的分析）。

补救的办法是预测。如果控制器知道被控对象如何响应其指令，它就能算出仍在"飞行途中"的指令生效之后，延迟的感觉信号将显示什么。

**定义 29.2.2（Smith 预估器）** **Smith 预估器**（O. J. M. Smith，1957）是针对已知延迟 $T$ 的被控对象的一种反馈控制器，它用作反馈信号的是延迟的测量值加上被控对象内部模型的输出，该模型由最近 $T$ 时间内发出的指令驱动：$\hat x(t) = x(t - T) + \int_{t-T}^{t}\dot{\hat x}(s)\,\mathrm{d}s$。模型精确时 $\hat x(t) = x(t)$，延迟被从环路中去除。

对命题 29.2.1 中的被控对象 $\dot x = u$，内部模型就是积分器的一个副本，闭环变为 $\dot\varepsilon = -k\varepsilon$，对任何增益都稳定（下图 B）。代价是对模型的依赖：增益有误的模型在误差适中时仍能收敛，但不再那么快、那么平滑。Miall、Weir、Wolpert 与 Stein（1993）提出小脑对视觉引导的运动起 Smith 预估器的作用，这一假说直接引向下一节的内部模型。

![延迟反馈与预测（被控对象 $\dot x = u$，目标 $10\,\mathrm{cm}$；命题 29.2.1 与定义 29.2.2）。A：经过延迟 $T = 100\,\mathrm{ms}$ 的比例反馈：$kT = 0.5$ 时手无过冲地趋近目标，$kT = 1.2$ 时振铃，$kT = 1.8 > \pi/2$ 时振荡增长。B：同样的高增益（$kT = 1.8$）加上 Smith 预估器：内部模型正确时，趋近过程就是无延迟的指数曲线；增益偏差为 $0.7$ 倍或 $1.4$ 倍的模型仍然收敛，分别带有过冲或趋近较慢；没有预估器（虚线）时环路不稳定。C：临界增益 $k_c = \pi/(2T)$（实线，对数坐标）和边界处振荡频率 $1/(4T)$（虚线）随环路延迟的变化；点线标出典型的脊髓环路（$30\,\mathrm{ms}$）和视觉环路（$100\,\mathrm{ms}$）。](./plots/delayed-feedback.py)

## 29.3. 内部模型

### 29.3.1. 正向模型与逆向模型

**定义 29.3.1（内部模型）** **内部模型**是对身体或物体的输入–输出关系的神经表征，用于预测或控制。正向模型把当前状态和运动指令映射为预测的下一状态及其感觉后果，它刻画因果关系，即从指令到后果；逆向模型把期望的状态或轨迹映射为产生它的运动指令，这是前馈控制所需要的。

两者是互补的。逆向模型是控制器；正向模型是预测器，用于三个目的：克服延迟（如 Smith 预估器）；把预测与感觉信号结合起来估计身体的状态（29.4）；区分自身行动的感觉后果与外部事件。它还可以用来训练逆向模型，因为预测的后果与实际后果之差是感觉坐标中的误差信号，可以转换为指令坐标中的误差（Jordan 与 Rumelhart，1992；Kawato，1999）。小脑是这两类模型所在之处的最佳候选（[7.16.33](/7.16.33)）。

内部模型最有力的证据是预期。我们提起一件物体上下移动时，手指间的握力与加速度产生的负荷力同相地升降，没有反馈会引入的滞后（Flanagan 与 Wing，1997）；实验者把重物放到受试者伸出的手上时，握力在撞击之后才增大，但若是受试者用另一只手放下它，握力则在撞击之前增大。可见神经系统根据自己的指令预测了负荷。

### 29.3.2. 传出副本与自身产生的感觉的抵消

**定义 29.3.2（传出副本）** **传出副本**（伴随放电）是运动指令的一份内部拷贝，送往感觉或其他脑区，在那里通常经由正向模型预测运动的感觉后果。von Holst 与 Mittelstaedt（1950）把自身运动引起的感觉信号称为*再传入*（reafference），把外部事件引起的称为*外传入*（exafference）；从感觉输入中减去预测，就分离出外传入。

每个运动的动物都面临这个问题。眼睛做**扫视**时，像在视网膜上扫过，世界看起来却是稳定的；轻按眼睑使眼球在没有指令的情况下移动，世界就会跳动。一条从上丘经丘脑背内侧核到额眼区的通路携带每次扫视的伴随放电，将它失活，会损害在第一次扫视之前闪现的目标上做第二次扫视的能力（Sommer 与 Wurtz，2002）。在鸣叫的蟋蟀中，一个伴随放电中间神经元在每次鸣叫时抑制听觉通路，使动物不会被自己的歌声震聋（Poulet 与 Hedwig，2006）。在弱电鱼中，一个类小脑结构学习鱼自身放电的电感觉后果的"负像"，并将其减去（Bell，1981；[7.16.33](/7.16.33)）。

同一机制解释了为什么人不能挠自己的痒。自己产生的触碰被评为比他人产生的同样触碰更弱、更不痒，而当两手之间插入的机器人加入 $100$–$300\,\mathrm{ms}$ 的延迟或旋转抚摸的方向时，这种衰减就减小（Blakemore、Frith 与 Wolpert，1999）：预测与感觉越吻合，被抵消得就越多。一个后果是力的逐步升级：两个人轮流按压对方的手指，要求与刚感觉到的力相等，每个人都低估了自己产生的力，力每轮增大约 $40\,\%$（Shergill 等，2003）。有人提出，无法把自身产生的信号归于自己，是精神分裂症中幻觉与被控制妄想的基础（[7.16.52](/7.16.52)）。

## 29.4. 状态估计

### 29.4.1. 结合预测与感觉

要控制身体，脑需要知道它当前的状态：肢体的位置与速度，以及手中物体的性质。没有哪一个来源能单独提供。感觉信号延迟而且有噪声；由传出副本驱动的正向模型的预测是即时的，但会累积误差，因为运动噪声是未知的。如同两条感觉线索的结合（**线索整合**，[7.16.27](/7.16.27#sec-27.2.1) 的定理 27.2.1），最优估计按可靠性对两者加权，对带 Gaussian 噪声的线性系统，这个权重由 **Kalman 滤波**递推地计算。

**算法 29.4.1（Kalman 滤波）** 设状态按 $\boldsymbol{x}_{t+1} = A\boldsymbol{x}_t + B\boldsymbol{u}_t + \boldsymbol{w}_t$ 演化，运动噪声 $\boldsymbol{w}_t \sim \mathcal{N}(\boldsymbol{0}, Q)$，感觉信号为 $\boldsymbol{y}_t = H\boldsymbol{x}_t + \boldsymbol{v}_t$，$\boldsymbol{v}_t \sim \mathcal{N}(\boldsymbol{0}, R)$。从先验均值 $\hat{\boldsymbol{x}}_0$ 与协方差 $\Sigma_0$ 出发，对 $t = 0, 1, \dots$ 重复：

1. 用测量更新：$K_t = \Sigma_tH^{\mathsf T}(H\Sigma_tH^{\mathsf T} + R)^{-1}$，$\hat{\boldsymbol{x}}_t^+ = \hat{\boldsymbol{x}}_t + K_t(\boldsymbol{y}_t - H\hat{\boldsymbol{x}}_t)$，$\Sigma_t^+ = (I - K_tH)\Sigma_t$。
2. 用正向模型与传出副本预测：$\hat{\boldsymbol{x}}_{t+1} = A\hat{\boldsymbol{x}}_t^+ + B\boldsymbol{u}_t$，$\Sigma_{t+1} = A\Sigma_t^+A^{\mathsf T} + Q$。

对线性 Gaussian 系统，$\hat{\boldsymbol{x}}_t^+$ 与 $\Sigma_t^+$ 恰是 $\boldsymbol{x}_t$ 在给定直到 $t$ 的全部测量后的后验分布的均值与协方差；该估计是最小均方误差估计（Kalman，1960）。

更新步骤就是以预测为先验的 Bayes 公式，所以对标量状态它化为式 (27.2) 的线索整合权重：先验方差为 $\sigma_{\mathrm{p}}^2$、测量方差为 $\sigma_{\mathrm{y}}^2$ 时，增益为 $K = \sigma_{\mathrm{p}}^2/(\sigma_{\mathrm{p}}^2 + \sigma_{\mathrm{y}}^2)$，即测量的权重。预测不确定时增益大，测量不确定时增益小。延迟的处理办法是让正向模型向前运行：延迟的测量更新对过去状态的估计，然后模型用其间发出的指令把它推进到现在，这就是统计形式的 Smith 预估器。

Wolpert、Ghahramani 与 Jordan（1995）让受试者在不同的时间长度内移动看不见的手，然后指出手的位置。估计的偏差随运动时间增长，直到约一秒后下降，而它的方差先增长后趋于平稳，这正是 Kalman 滤波所预测的图景，其中正向模型略微高估了运动：预测误差不断累积，直到本体感觉的修正与之平衡。下图展示了三种估计器在模拟伸手运动上的表现。

### 29.4.2. 运动行为中的先验

先验不必只来自正向模型。Körding 与 Wolpert（2004）把手的视觉反馈平移一个取自 Gaussian 分布的量，并在伸手中途只短暂地显示手的位置，模糊程度或大或小。受试者学会了平移的分布并加以补偿，在反馈模糊时更重地加权先验，正如一个 **贝叶斯观察者**（[7.16.27](/7.16.27)）所应做的那样。可见 Bayes 估计既适用于世界，也适用于身体，同样的按可靠性加权的结合出现在姿势、由大小估计物体重量以及拦截的时机判断中。

## 29.5. 最优控制

### 29.5.1. 信号依赖噪声与最小方差

既然有无穷多条轨迹能到达目标，为什么我们伸手时走的是近乎直线的路径，速度曲线光滑呈钟形？早先的建议是最小化某种光滑性代价，例如加加速度的平方积分（Flash 与 Hogan，1985），但没有说明脑为什么要在意加加速度。Harris 与 Wolpert（1998）的回答基于肌肉的一种性质。

**定义 29.5.1（信号依赖噪声）** **信号依赖噪声**是肌肉所产生的力的变异，其标准差与平均力成正比（变异系数恒定），因此指令 $u$ 产生输出 $u(1 + \kappa\xi)$，其中 $\xi$ 的均值为零、方差为 1。

变异系数恒定源自运动单位募集的**尺寸法则**：更大的力通过募集更大的**运动单位**产生，每个单位增加的力阶跃也更大（[7.16.30](/7.16.30#sec-30.1)）。存在信号依赖噪声时，用大指令做出的运动是不精确的，而运动的精度取决于指令的整个时间过程，而不只是它的终点。

**命题 29.5.1（最小方差指令）** 设状态为 $\boldsymbol{x}_t$ 的线性被控对象由指令 $u_1, \dots, u_N$ 驱动，指令受独立的信号依赖噪声的污染，并要求时刻 $N$ 的平均状态等于 $\boldsymbol{x}^*$。平均终态为 $G\boldsymbol{u}$，运动后一段时间内累积的位置方差为 $\sum_t c_tu_t^2$，其中常数 $c_t > 0$ 只取决于被控对象。在 $G\boldsymbol{u} = \boldsymbol{x}^*$ 的约束下使该方差最小的指令是
$$
\boldsymbol{u}^* = C^{-1}G^{\mathsf T}\bigl(GC^{-1}G^{\mathsf T}\bigr)^{-1}\boldsymbol{x}^*, \qquad C = \operatorname{diag}(c_1, \dots, c_N), \tag{29.1}
$$
且最小标准差与距离 $\lVert\boldsymbol{x}^*\rVert$ 成正比。

**证明** 线性被控对象的均值与噪声可以叠加：终态为 $\sum_tG_t u_t(1 + \kappa\xi_t)$，均值为 $G\boldsymbol{u}$，较晚时刻 $s$ 的位置方差为 $\kappa^2\sum_t g_{st}^2u_t^2$；对运动后的时间段求和得 $c_t = \kappa^2\sum_s g_{st}^2$。在线性约束下用 Lagrange 乘子 $\boldsymbol{\lambda}$ 最小化正定二次型 $\boldsymbol{u}^{\mathsf T}C\boldsymbol{u}$，得 $C\boldsymbol{u} = G^{\mathsf T}\boldsymbol{\lambda}$，代入约束即得式 (29.1)。解关于 $\boldsymbol{x}^*$ 是线性的，所以方差是距离的二次函数。$\square$

最优指令避免大的峰值，因为方差随指令的平方增长；它们也避免运动后期的指令，因为这些指令的噪声来不及被肢体的惯性平均掉。结果是人的伸手和扫视那样光滑的钟形速度曲线，无需任何光滑性假设（下图 A）。由于缩短运动需要更大的指令，最小的终点散布随时长缩短而急剧上升（B）：**速度–准确性权衡**，在经验上由 Fitts 定律描述（对幅度 $A$ 与目标宽度 $W$，运动时间随 $\log_2(2A/W)$ 线性增加），在这里表现为噪声的后果，而不是一条独立的原理。同一模型还预言了扫视的主序，以及有障碍物时手臂轨迹的形状。

![信号依赖噪声下的最小方差规划（命题 29.5.1；质量 $1\,\mathrm{kg}$ 的质点经二阶肌肉滤波器驱动，时间常数为 $40$ 与 $30\,\mathrm{ms}$，指令噪声的变异系数 $\kappa = 0.2$，位置方差在运动后 $200\,\mathrm{ms}$ 的保持期内最小化）。A：$10\,\mathrm{cm}$ 运动、时长 $300$、$450$ 与 $600\,\mathrm{ms}$ 的最优速度曲线：光滑、钟形，略偏向末端。B：最小终点标准差随时长的变化（对数坐标）：越快的运动越不准确。C：对 $450\,\mathrm{ms}$ 的最优指令的二十次带噪声执行；末端的散布就是被最小化的方差。](./plots/min-variance.py)

### 29.5.2. 最优反馈控制

最小方差规划事先算出一条轨迹。Todorov 与 Jordan（2002）则提出，脑计算的是一条反馈律：从估计状态到指令的映射，它使整个运动的期望代价最小，代价是任务误差与力气耗费的加权和。

**定义 29.5.2（最优反馈控制）** 在**最优反馈控制**中，每个时刻的运动指令是估计状态的函数 $\boldsymbol{u}_t = \pi_t(\hat{\boldsymbol{x}}_t)$，它的选择使惩罚偏离任务目标与运动耗费的代价的期望最小，例如 $\mathbb{E}\bigl[\sum_t(\boldsymbol{x}_t^{\mathsf T}Q_t\boldsymbol{x}_t + \boldsymbol{u}_t^{\mathsf T}R\boldsymbol{u}_t)\bigr]$。对线性被控对象、二次代价与 Gaussian 噪声（线性–二次–Gaussian 问题），最优律是线性的 $\boldsymbol{u}_t = -L_t\hat{\boldsymbol{x}}_t$，增益 $L_t$ 由 **Riccati 方程**沿时间反向求得，而 $\hat{\boldsymbol{x}}_t$ 由 Kalman 滤波给出（算法 29.4.1）。

把问题分成估计器与控制器，对线性–二次–Gaussian 的情形是精确的（分离原理），也是正向模型、状态估计器与反馈控制器协同工作的方案的基础。代价函数规定了任务是什么，最重要的结论由此而来。

**定义 29.5.3（最小干预原则）** **最小干预原则**指出，最优反馈控制器只纠正状态中妨碍任务目标的偏差，而对与任务无关的方向上的偏差不予纠正，因为纠正它们既要耗费力气，又会增加信号依赖噪声。

**例 29.5.1** 两根手指一起按压，使它们的力之和 $f_1 + f_2$ 与目标相符。每个力带有独立的噪声而波动。和的偏差妨碍任务；差 $f_1 - f_2$ 的偏差则不然。因此带力气代价的最优控制器只对和施加反馈，差的变异在各次试验中不断增大，直到只受力气耗费的限制，而和的变异保持很小。这一预言得到证实：在多指力的产生与有冗余手臂姿势的指向运动中，试验间的方差在不改变任务变量的方向上，即 Scholz 与 Schöner（1999）的"不受控流形"，远大于任务相关的方向。

:::

最优反馈控制解释了为什么运动的变异是有结构的，为什么对扰动的反应取决于目标（把手臂推向宽目标时几乎不修正，推向窄目标时修正强烈），以及为什么运动皮层的长潜伏期反应是灵活的（[7.16.32](/7.16.32)）。它还消解了自由度问题：脑选择的不是一条轨迹，而是一个利用冗余的**策略**。这类最优控制就是模型已知的**强化学习**，两种理论在 [7.16.39](/7.16.39) 相遇。

## 29.6. 运动学习

### 29.6.1. 适应

**定义 29.6.1（运动适应）** **运动适应**是对系统性扰动逐次试验地重新校准运动，由预测的与实际的感觉后果之间的误差（感觉预测误差）驱动，使表现回到未受扰动时的水平；其标志是后效应，即扰动撤除时出现方向相反的误差。

经典的范式有使视野平移的棱镜眼镜、光标与手成一定角度移动的视觉运动旋转，以及由机器人操纵器施加的速度依赖力场（Shadmehr 与 Mussa-Ivaldi，1994）。在力场中，伸手运动起初被力弄弯；一百次试验之内它们重新变直，而力场关闭后它们向镜像方向弯曲。后效应表明，脑并非简单地使手臂变硬，而是建立了新动力学的内部模型，它以揭示其表征方式的形式推广到其他运动（例如在关节坐标而不是手的坐标中）。适应依赖小脑：小脑变性的患者几乎不适应或完全不适应，而基底神经节损伤的患者适应正常（[7.16.33](/7.16.33)）。

状态空间模型逐次试验地描述适应。设 $x_n$ 是第 $n$ 次试验中对扰动的内部估计，$p_n$ 是扰动，故误差为 $e_n = p_n - x_n$；则 $x_{n+1} = Ax_n + Be_n$，其中保持因子 $A \le 1$，误差敏感度 $B$。扰动恒定时，误差几何地衰减到残余值 $(1 - A)p/(1 - A + B)$，因为遗忘与学习相互平衡。

### 29.6.2. 双状态模型

单一的过程无法解释适应的若干特征。第二次学习更快（节省），即使后效应已被洗除；学习了许多次试验后又反转几次试验的扰动，在误差被消除后会重新出现（自发恢复）；适应还随时间衰减。Smith、Ghazizadeh 与 Shadmehr（2006）表明，两个时间尺度不同的过程可以解释所有这些现象。

**公式 29.6.1（运动适应的双状态模型）** 第 $n$ 次试验的适应 $x_n = x_{\mathrm{f},n} + x_{\mathrm{s},n}$ 是由同一误差 $e_n = p_n - x_n$ 驱动的快状态与慢状态之和：
$$
x_{\mathrm{f},n+1} = A_{\mathrm{f}}x_{\mathrm{f},n} + B_{\mathrm{f}}e_n, \qquad x_{\mathrm{s},n+1} = A_{\mathrm{s}}x_{\mathrm{s},n} + B_{\mathrm{s}}e_n, \tag{29.2}
$$
其中 $A_{\mathrm{f}} < A_{\mathrm{s}} < 1$，$B_{\mathrm{f}} > B_{\mathrm{s}}$：快状态学得快、忘得快，慢状态学得慢、保持久。

在长时间训练中，慢状态逐渐取代快状态。短暂的反转使快状态被强烈地推向负值，而学得慢的慢状态只被部分地削减，于是净适应回到零。如果随后把误差钳制为零（无论手怎么动，光标都被设为直接走向目标），学习停止，只有保持起作用：快状态在几次试验内衰减，剩下的慢状态使旧的适应重新出现（下图 A）。该模型定量地预言了自发恢复的量，而慢状态预言了一天之后的长期保持（Joiner 与 Smith，2008）。

![适应的双状态模型（公式 29.6.1；$A_{\mathrm{f}} = 0.59$，$B_{\mathrm{f}} = 0.21$，$A_{\mathrm{s}} = 0.992$，$B_{\mathrm{s}} = 0.02$）。A：$300$ 次带扰动（力场，$p = 1$）的试验，随后是反转的力场（$p = -1$），直到净适应回到零，再是 $200$ 次误差钳制试验（阴影）：净适应（黑色）在反转期间回到零，因为快状态（红色）变为负值，并在误差钳制中重新出现，因为快状态衰减而慢状态（蓝色）保留，即自发恢复。B：节省：经过 $300$ 次训练试验与 $20$ 次无扰动的洗除试验后，重新学习（蓝色）比第一次学习（灰色）更快，因为一部分慢状态在洗除中保留下来。](./plots/two-rate.py)

### 29.6.3. 误差敏感度与其他形式的学习

误差敏感度 $B$ 并不固定。对大的误差它减小，神经系统把这类误差归因于外部原因而不是自身校准不当；当误差在各次试验中保持一致时它增大，当误差交替出现时它减小（Herzfeld 等，2014）：脑学会了从误差中学多少，这是一种元学习，不需要第二个状态就能解释节省。适应只是运动学习的一种形式。使用依赖的学习使运动偏向最近重复过的运动；强化学习从行动的成败中改进技能，无需有方向的误差，并依赖**基底神经节**与**多巴胺**（[7.16.39](/7.16.39)、[7.16.40](/7.16.40)）；显式策略，例如为补偿旋转而瞄向目标之外，速度快但费力，并与缓慢的内隐重新校准结合（Mazzoni 与 Krakauer，2006；Taylor、Krakauer 与 Ivry，2014）。技能学习把它们全部结合起来，并在多年的练习中继续提高速度与准确性。

## 29.7. 顶叶与额叶皮层中的规划

运动在被控制之前必须先被选定和规划，在这里，知觉、决策与行动之间的界线消失了。后顶叶皮层位于视觉、体感区与额叶运动区之间，把感觉信息转换为行动的坐标，即"为行动而视觉"的背侧通路（[7.14.41](/7.14.41)）。Mountcastle 等（1975）在那里发现，猴子伸手去够或看向感兴趣的物体时，有些神经元发放，而在没有这种意图的同样运动中则不发放。它的亚区按效应器特化：顶内沟外侧区（LIP）管扫视，顶叶伸手区管手臂运动，顶内沟前区管抓握；在一项任务中，猴子被提示规划向同一位置的扫视或伸手，LIP 神经元在规划扫视时活跃，顶叶伸手区神经元在规划伸手时活跃（Snyder、Batista 与 Andersen，1997）。LIP 的活动在知觉决策中还会累积证据，这是 [7.16.47](/7.16.47) 的主题。

后顶叶皮层的损伤引起视觉性共济失调（对看得很清楚的物体够不准）与对一侧空间的忽视。电刺激人的后顶叶皮层引起有意识的运动意图，强度更高时引起已经运动的信念，尽管并没有发生运动；而刺激运动前区皮层引起患者并不察觉的运动（Desmurget 等，2009）。额叶运动区（运动前区皮层、辅助运动区，在啮齿类中还有前外侧运动皮层）在延迟期内保持计划，并在相互竞争的行动之间做选择；按照可供性竞争假说，几个潜在的行动在顶叶和运动前区皮层中并行地被规定，并相互竞争直到其中一个被选中，输入来自前额叶皮层与基底神经节（Cisek，2007）。运动皮层中这种准备与执行的神经动力学是 [7.16.32](/7.16.32) 的主题。

## 小结

| 问题 | 计算上的解决办法 | 小节 |
|---|---|---|
| 感觉延迟 | 预测：Smith 预估器、正向模型 | 命题 29.2.1、定义 29.2.2 |
| 区分自身与世界 | 传出副本与再传入的抵消 | 定义 29.3.2 |
| 身体状态的不确定性 | Kalman 滤波：按可靠性加权的预测与感觉 | 算法 29.4.1 |
| 冗余与噪声 | 最小方差规划；最优反馈控制 | 命题 29.5.1、定义 29.5.2 |
| 动力学的变化 | 由误差驱动、含快慢两个过程的适应 | 公式 29.6.1 |

- 延迟反馈只有在增益乘以延迟较小时才稳定（对积分器 $kT < \pi/2$，命题 29.2.1）；因此快速运动依赖前馈控制与预测（定义 29.2.1）。
- 内部模型（定义 29.3.1）预测指令的后果并对其求逆；传出副本（定义 29.3.2）抵消自身产生的感觉，这就是人不能挠自己痒的原因。
- Kalman 滤波（算法 29.4.1）把正向模型的预测与感觉反馈结合起来，按各自的可靠性加权；它的增益就是定理 27.2.1 中的线索整合权重。
- 信号依赖噪声（定义 29.5.1）使运动的精度取决于其计划；最小化终点方差（命题 29.5.1）给出钟形速度曲线与速度–准确性权衡。最优反馈控制（定义 29.5.2）只纠正任务相关的误差（定义 29.5.3，例 29.5.1）。
- 运动适应（定义 29.6.1）可以很好地用一个快过程与一个慢过程描述（公式 29.6.1），它们解释了节省与自发恢复；适应依赖小脑，而基于强化的学习依赖基底神经节。
- 后顶叶与额叶皮层把感觉信息转换为特定效应器的计划，并在潜在的行动之间做选择。

## 思考题

1. 一个延迟为 $T = 40\,\mathrm{ms}$ 的环路用比例反馈控制被控对象 $\dot x = u$。环路稳定的最大增益是多少，在该增益下以什么频率振荡？延迟加倍会怎样改变这两个答案？

   **答** 由命题 29.2.1，$k_c = \pi/(2T) = 39\,\mathrm{s^{-1}}$，边界处的振荡周期为 $4T = 160\,\mathrm{ms}$，频率为 $6.25\,\mathrm{Hz}$。延迟加倍使临界增益减半（$20\,\mathrm{s^{-1}}$），频率也减半（$3.1\,\mathrm{Hz}$）：越长的环路越慢，振荡频率越低，这就是踝阵挛比手指震颤慢的原因。

2. 在标量 Kalman 滤波中，预测的方差为 $4\,\mathrm{cm^2}$，本体感觉测量的方差为 $1\,\mathrm{cm^2}$。求 Kalman 增益与更新后的方差。如果除此之外还能看到手（方差 $0.25\,\mathrm{cm^2}$），增益会怎样？

   **答** $K = 4/(4 + 1) = 0.8$，后验方差为 $(1 - K)\cdot4 = 0.8\,\mathrm{cm^2}$，等于 $4\cdot1/(4 + 1)$，即线索整合的结果。加入视觉后，两个测量合并为一个方差为 $1\cdot0.25/1.25 = 0.2\,\mathrm{cm^2}$ 的测量；对这个合并测量的增益为 $4/4.2 = 0.95$，后验方差为 $0.19\,\mathrm{cm^2}$。感觉精确时，估计几乎完全跟随测量；在黑暗中则更多依赖预测。

3. 用最小干预原则解释，为什么重复指向运动中关节角的变异大于指尖位置的变异，并设计一个实验来检验这种结构是由反馈而不是由计划产生的。

   **答** 许多关节构型给出同一个指尖位置；不改变指尖的偏差不影响任务，带力气代价的最优反馈控制器对它们不予纠正（定义 29.5.3），所以方差在不受控流形的关节空间方向上累积，而指尖的方差保持很小。要证明反馈起作用，可在运动中沿任务相关与任务无关的方向对手臂施加机械扰动：最优反馈控制预言前者引起强烈的修正，后者几乎没有或完全没有，且在长潜伏期反应中就已如此，并且任务改变时这一模式也应改变（例如从小的圆形目标改为长条，使某一方向变得与任务无关）。

4. 在双状态模型中，为什么短暂地反转扰动能使净适应回到零而不抹去记忆？如果反转阶段持续 300 次试验，而不是抵消适应所需的几次，预测会发生什么？

   **答** 反转产生大的负误差，驱动具有大 $B_{\mathrm{f}}$ 的快状态在几次试验内被强烈推向负值，而具有小 $B_{\mathrm{s}}$ 的慢状态只略有下降；净适应为零是因为两个状态相互抵消，而不是因为二者都为零。在误差钳制中快状态按 $A_{\mathrm{f}}$ 衰减，慢状态显露出来。300 次试验的反转之后，慢状态本身也发生反转，快状态回到一个小的值；此时钳制显示的是对反转力场的适应，对原来力场的恢复很少或没有。

5. （开放题）既然控制最终需要逆向模型，为什么正向模型对估计和学习更有用？

   **答** 正向模型可以直接用监督学习训练，因为脑既观察到指令（传出副本），又观察到它的后果（感觉反馈）；每次运动中都有其预测的误差可用。逆向模型需要正确的指令作为目标，而这从未被观察到；它必须间接训练，例如通过正向模型把感觉误差转换为指令误差（远端教师），或通过反馈误差学习（以反馈控制器的输出作为误差），或通过强化。正向模型还用于估计（Kalman 滤波）、抵消再传入以及行动的心理模拟，所以一个学得的模型有多种用途。
