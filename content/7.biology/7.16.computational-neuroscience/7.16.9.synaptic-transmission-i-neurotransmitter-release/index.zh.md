神经元主要通过**化学突触**与靶细胞通信：到达突触前终末的**动作电位**被转换为少数几个突触囊泡的融合，囊泡中的递质又在突触后细胞中被转换回电流。本章讲述这一转换的突触前半部分。其核心结论是：释放是一个概率性的、量子化的、受 $\ce{Ca^2+}$ 控制的过程；一个简单统计模型的三个参数，即释放位点数 $N$、释放概率 $p$ 与量子大小 $q$，几乎组织了关于释放的全部已知知识，从 20 世纪 50 年代 Katz 的实验直到活性区的分子机器。突触的基本生理学与蛙**神经肌肉接头**的经典量子实验见 [7.14.5](/7.14.5#sec-5.4) 与 [7.14.8](/7.14.8#sec-8.3.3)，膜的电学性质见 [7.16.4](/7.16.4) 与 [7.16.5](/7.16.5)；这里我们定量地处理释放，并讨论中枢突触。突触后受体见 [7.16.10](/7.16.10)，缓慢的代谢型信号见 [7.16.11](/7.16.11)，本章末引入的**短时程可塑性**现象在 [7.16.12](/7.16.12) 中被建成动力学模型。

## 9.1. 化学突触及其时间预算

在电子显微镜下，每个化学突触都有相同的组成部分（Luo，Kandel）：一个充满直径约 $40\,\mathrm{nm}$ 的清亮突触囊泡的突触前膨体，一块有少数囊泡停靠的突触前膜，宽度在中枢突触为 $20\,\mathrm{nm}$（在神经肌肉接头为 $50\,\mathrm{nm}$，其中含基膜）的突触间隙，以及与之相对的突触后膜增厚，即锚定受体的**突触后致密区**。海马 CA1 区的典型膨体含约 200 个囊泡，有一个面积为 $0.04$–$0.1\,\mu\mathrm{m^2}$ 的活性区，停靠着五到十个囊泡；一条肌纤维上的运动神经终末则有数百个活性区。

**定义 9.1.1（活性区）** **活性区**是突触前质膜上突触囊泡停靠并融合的特化区域；它由致密的蛋白基质（RIM、Munc13、RIM 结合蛋白、ELKS、liprin-α、Bassoon 与 Piccolo）界定，这一基质使电压门控 $\ce{Ca^2+}$ 通道成簇并把囊泡固定在通道旁，它恰好位于突触后致密区的正对面。

突触前动作电位与突触后电流起始之间约 $0.5\,\mathrm{ms}$ 的**突触延搁**可以分成若干步骤，其时长由大型突触（鱿鱼巨突触、听觉脑干的 Held 花萼、海马的苔藓纤维膨体）上的成对记录以及电容与成像测量得知：

| 步骤 | $35$–$37^\circ\mathrm{C}$ 下的时长 | 依据 |
|---|---|---|
| 动作电位侵入终末 | $\approx 0.1\,\mathrm{ms}$ | 膨体与花萼的记录 |
| 电压门控 $\ce{Ca^2+}$ 通道开放（主要是 $\mathrm{Ca_V2.1}$，即 P/Q 型，与 $\mathrm{Ca_V2.2}$，即 N 型） | $0.1$–$0.3\,\mathrm{ms}$；多数 $\ce{Ca^2+}$ 在脉冲复极化期间进入 | 突触前电压钳 |
| $\ce{Ca^2+}$ 与感受器结合及囊泡融合 | $50$–$200\,\mu\mathrm{s}$ | 从 $\ce{Ca^2+}$ 电流到突触后电流的延迟（Sabatini 与 Regehr，1996） |
| 递质越过间隙的扩散 | 约 $1\,\mu\mathrm{s}$ | $t \approx x^2/2D$（[7.14.5](/7.14.5#sec-5.4.2)） |
| 突触后受体结合并开放 | $0.1$–$0.2\,\mathrm{ms}$ | 对切下膜片的快速给药 |

在室温下，每一步都慢两到三倍（$Q_{10} \approx 2$–$3$），这就是在蛙与鱿鱼标本上测得的经典延搁为 $1$–$2\,\mathrm{ms}$ 的原因。这一预算显示了时间花在哪里：不是花在扩散上，而是花在通道开放与膜融合上。分离出 $\ce{Ca^2+}$ 步骤的实验是在鱿鱼巨突触上完成的，两侧都做电压钳，并阻断 $\ce{Na+}$ 与 $\ce{K+}$ 通道（Llinás；Augustine、Charlton 与 Smith，1985）。把突触前膜阶跃到 $-25\,\mathrm{mV}$ 时 $\ce{Ca^2+}$ 通道打开，$\ce{Ca^2+}$ 流入，随后出现突触后电流。阶跃到接近 $\ce{Ca^2+}$ **平衡电位**的 $+50\,\mathrm{mV}$ 时，开放的通道更多，却几乎没有内流，也没有释放；复极化时，$\ce{Ca^2+}$ 电流的"尾电流"通过仍然开放的通道流入，约 $0.2\,\mathrm{ms}$ 内就出现释放。因此触发释放的不是去极化本身，而是 $\ce{Ca^2+}$ 的进入。

## 9.2. 量子假说

### 9.2.1. 量子与二项模型

在蛙的神经肌肉接头，Fatt 与 Katz 发现了约 $0.5\,\mathrm{mV}$ 的自发*微小终板电位*（miniature end-plate potential，mEPP），del Castillo 与 Katz 则表明，在低 $\ce{Ca^2+}$ 下，诱发的**终板电位**只取接近 mEPP 整数倍的值（[7.14.8](/7.14.8#sec-8.3.3)）。随后电子显微镜提供了物理上的量子，即突触囊泡，Heuser 与 Reese（1979）的冰冻断裂图像取自刺激后 $3$–$5\,\mathrm{ms}$ 冻结的接头，捕捉到了正在融合的囊泡。蛙接头的一个量子含约 7000 个乙酰胆碱分子；中枢突触的一个谷氨酸能囊泡含几千个谷氨酸分子。量子假说背后的统计模型是一般性的，也是本节的出发点。

**定义 9.2.1（释放的二项模型）** 一个突触连接由 $N$ 个独立的释放位点描述，动作电位到达时每个位点以概率 $p$ 释放一个囊泡。于是释放的囊泡数为 $K \sim \mathrm{Bin}(N, p)$，突触后响应为 $A = \sum_{j=1}^{K} Q_j$，其中量子幅度 $Q_j$ 相互独立，均值为 $q$（量子大小），变异系数为 $C_V^{(q)}$。释放量子的平均数 $Np$ 称为该连接的**量子含量**。

该模型把 [7.14.8](/7.14.8) 的 Poisson 模型作为极限包含在内：当 $N \to \infty$、$p \to 0$ 而 $Np$ 固定时，**二项分布**趋于均值为 $Np$ 的 **Poisson 分布**（7.14.8 把这个均值记作 $m$；我们把 $m$ 留给 [7.16.5](/7.16.5) 的门控变量）。在有数百个活性区、$\ce{Ca^2+}$ 又低的神经肌肉接头，Poisson 极限是准确的；在由一到十个活性区构成的中枢连接，则不然，有限的 $N$ 会在统计中显现。

**命题 9.2.1（量子响应的矩）** 在二项模型中，
$$
\mathbb{E}[A] = Npq, \qquad \operatorname{Var}(A) = Npq^2\left(1 - p + (C_V^{(q)})^2\right), \qquad \mathbb{P}(A = 0) = (1 - p)^N. \tag{9.1}
$$

**证明** 对 $K$ 取条件。给定 $K$，$A$ 是 $K$ 个独立量子之和，故 $\mathbb{E}[A \mid K] = Kq$，$\operatorname{Var}(A \mid K) = K(C_V^{(q)}q)^2$。由全期望公式 $\mathbb{E}[A] = q\,\mathbb{E}[K] = Npq$，由全方差公式 $\operatorname{Var}(A) = \mathbb{E}[\operatorname{Var}(A\mid K)] + \operatorname{Var}(\mathbb{E}[A\mid K]) = Np(C_V^{(q)})^2q^2 + Np(1-p)q^2$。失败意味着 $K = 0$，其概率为 $(1-p)^N$。$\square$

幅度分布是位于 $0, q, 2q, \dots, Nq$ 的 $N + 1$ 个峰的混合，权重为二项权重，每个峰因量子变异（宽度 $\propto \sqrt{k}$）与记录噪声而展宽（见下图 A）。只有当 $C_V^{(q)}$ 与噪声都很小时才能看到清晰的峰，这就是大多数中枢突触上量子峰难以捉摸的原因；此时由式 (9.1) 的矩来承载信息。

### 9.2.2. 方差–均值分析

在式 (9.1) 的均值 $\mu = Npq$ 与方差之间消去 $p$，得到一个对任何释放概率都成立的关系。

**命题 9.2.2（方差–均值抛物线）** 若 $N$ 与 $q$ 保持不变而 $p$ 改变（例如改变细胞外 $\ce{Ca^2+}$ 浓度），则响应的均值 $\mu$ 与方差 $\sigma^2$ 落在抛物线
$$
\sigma^2 = q'\mu - \frac{\mu^2}{N}, \qquad q' = q\left(1 + (C_V^{(q)})^2\right) \tag{9.2}
$$
上。其初始斜率为 $q'$，在 $\mu = Nq'/2$ 处取最大值 $Nq'^2/4$（当 $C_V^{(q)}$ 可忽略时即 $p = 1/2$），并在 $\mu = Nq'$ 处回到零。

这就是多概率涨落分析（Silver、Clements 及同事，1998–2000）：在三个或更多 $\ce{Ca^2+}$ 浓度下记录许多响应，作方差对均值的图，并用式 (9.2) 过原点拟合。初始斜率给出量子大小，曲率给出位点数，然后在每个浓度下 $p = \mu/(Nq)$。该分析不需要可见的量子峰，只要求记录期间 $N$ 与 $q$ 保持平稳。

**例 9.2.1** 在一个小脑连接上，在三个 $\ce{Ca^2+}$ 浓度下测得 EPSC 的均值与方差（已减去基线噪声的方差）：$\mu = 32$、$80$ 与 $128\,\mathrm{pA}$，$\sigma^2 = 512$、$800$ 与 $512\,\mathrm{pA^2}$。第一点与第三点方差相等，因此由抛物线的对称性，其最大值位于 $\mu = 80\,\mathrm{pA} = Nq'/2$；最大值 $800 = Nq'^2/4$，于是 $q' = 4\cdot 800/160 = 20\,\mathrm{pA}$，$N = 160/20 = 8$。用第一点检验：$20\cdot 32 - 32^2/8 = 640 - 128 = 512$。三个浓度下的释放概率为 $32/160 = 0.2$、$0.5$ 与 $0.8$，最高浓度下的量子含量为 $Np = 6.4$。

### 9.2.3. 突触后通道的涨落

同样的二项运算也适用于突触后一侧，只是以通道代替囊泡。若 $N_{\mathrm{ch}}$ 个通道各以概率 $p_{\mathrm{o}}$ 开放并通过单通道电流 $i$，则宏观电流的均值为 $I = N_{\mathrm{ch}}p_{\mathrm{o}}i$，方差为 $\sigma_I^2 = N_{\mathrm{ch}}p_{\mathrm{o}}(1-p_{\mathrm{o}})i^2$，故
$$
\sigma_I^2 = iI - \frac{I^2}{N_{\mathrm{ch}}}. \tag{9.3}
$$
Katz 与 Miledi（1970）最先使用了这一思想：对终板施加乙酰胆碱使膜的电压噪声增大（"散粒噪声"），并从方差与均值之比估计出量级为 $10^{-10}\,\mathrm{S}$、持续约一毫秒的基本电导，这比能用**膜片钳**记录单通道早了许多年。在非稳态涨落分析（Sigworth，1980）中，开放概率随时间变化，发生在突触电流衰减或电压门控电流激活的过程中，同一响应的许多次重复给出每一时刻的均值与方差；把二者相互作图便描出式 (9.3)，并得到 $i$（从而得到**单通道电导** $\gamma = i/(V - E_{\mathrm{rev}})$）与 $N_{\mathrm{ch}}$。把它用于双光子解笼谷氨酸作用到单个树突棘上所诱发的电流，表明一个突触上的 **AMPA 受体**数目与棘头的体积成正比，从几个到一百多个（Matsuzaki 及同事，2001）。被 [7.16.4](/7.16.4) 的宏观方程平均掉的涨落，就这样成了计数分子的显微镜。

## 9.3. 钙与释放

### 9.3.1. Ca²⁺ 感受器的协同性

释放随细胞外 $\ce{Ca^2+}$ 陡峭地增长，在低浓度下近似与其四次方成正比（Dodge 与 Rahamimoff，1967；[命题 5.4.1](/7.14.5#prop-5.4.1)）。这一测量混合了两步：$\ce{Ca^2+}$ 的进入，以及感受器对胞内浓度的响应。第二步是在 Held 花萼上直接测量的，这种终末足够大，可以做膜片钳并装载笼锁 $\ce{Ca^2+}$：一次紫外闪光把 $[\ce{Ca^2+}]_{\mathrm{i}}$ 均匀升高到由荧光指示剂读出的值，由突触后电流或突触前电容报告释放（Bollmann、Sakmann 与 Borst，2000；Schneggenburger 与 Neher，2000）。释放速率随 $[\ce{Ca^2+}]_{\mathrm{i}}$ 的四到五次方上升，并需要约 $10$–$25\,\mu\mathrm{M}$ 才能在几毫秒内释放易释放池，这一浓度在胞质主体中从未达到，却在开放通道近旁存在几分之一毫秒。

**公式 9.3.1（五位点感受器模型）** 设一个囊泡带有一个具有五个 $\ce{Ca^2+}$ 结合位点的感受器，并以 $V_j$ 表示 $j$ 个位点被占据的状态。结合是按顺序进行的，
$$
V_0 \underset{k_{\mathrm{off}}}{\overset{5k_{\mathrm{on}}c}{\rightleftharpoons}} V_1 \underset{2bk_{\mathrm{off}}}{\overset{4k_{\mathrm{on}}c}{\rightleftharpoons}} V_2 \underset{3b^2k_{\mathrm{off}}}{\overset{3k_{\mathrm{on}}c}{\rightleftharpoons}} V_3 \underset{4b^3k_{\mathrm{off}}}{\overset{2k_{\mathrm{on}}c}{\rightleftharpoons}} V_4 \underset{5b^4k_{\mathrm{off}}}{\overset{k_{\mathrm{on}}c}{\rightleftharpoons}} V_5 \overset{\gamma}{\longrightarrow} \text{融合},
$$
其中 $c = [\ce{Ca^2+}]_{\mathrm{i}}$，因子 $b < 1$ 使每个已结合的离子都减慢其他离子的解离（协同性）。对花萼数据的拟合给出 $k_{\mathrm{on}} \approx 9\times10^7\,\mathrm{M^{-1}\,s^{-1}}$，$k_{\mathrm{off}} \approx 9500\,\mathrm{s^{-1}}$，$b \approx 0.25$，融合速率 $\gamma \approx 6000\,\mathrm{s^{-1}}$（Schneggenburger 与 Neher，2000）。

在低 $c$ 时，$V_5$ 的占据与 $c^5$ 成正比，而表观幂次随位点饱和而降向 4，再降向 0（见下图 A），这就使细胞外滴定中观察到的约为四的协同性与五个结合位点相协调。后来的模型加入了从部分结合状态出发的、缓慢而不依赖 $\ce{Ca^2+}$ 的融合以解释自发释放，以及一种变构的变体（Lou、Scheuss 与 Schneggenburger，2005），其中每个结合的离子都使融合速率成倍增加，而不要求五个全部结合。两者描述的是同一个本质事实：融合是局部 $\ce{Ca^2+}$ 的高度非线性函数，是由**协同性**构成的**超敏性**的一个例子。

### 9.3.2. 纳米域与微米域

由于感受器需要几十微摩尔的浓度，开放通道与囊泡之间的距离和通道的数目同样重要。在一个开放通道的口周围，$\ce{Ca^2+}$ 向胞质扩散，同时缓冲剂将其结合；在线性化缓冲近似（Neher，1986）下，在微秒内建立的稳态分布为
$$
c(r) = c_0 + \frac{i_{\mathrm{Ca}}}{4\pi zFDr}\,\mathrm{e}^{-r/\lambda_{\mathrm{B}}}, \qquad \lambda_{\mathrm{B}} = \sqrt{\frac{D}{k_{\mathrm{on}}^{\mathrm{B}}[\mathrm{B}]}}, \tag{9.4}
$$
其中 $i_{\mathrm{Ca}}$ 是单通道电流，$z = 2$，$D \approx 220\,\mu\mathrm{m^2\,s^{-1}}$ 是 $\ce{Ca^2+}$ 的扩散系数，$\lambda_{\mathrm{B}}$ 是浓度为 $[\mathrm{B}]$、结合速率为 $k_{\mathrm{on}}^{\mathrm{B}}$ 的缓冲剂捕获离子的长度。没有缓冲剂时，分布按 $1/r$ 下降，这是点源周围扩散方程的稳态解（[7.6.35](/7.6.35)）。对于 $i_{\mathrm{Ca}} = 0.3\,\mathrm{pA}$（外部 $\ce{Ca^2+}$ 为 $2\,\mathrm{mM}$ 时动作电位期间的典型值），式 (9.4) 给出 $20\,\mathrm{nm}$ 处约 $28\,\mu\mathrm{M}$，$100\,\mathrm{nm}$ 处约 $6\,\mu\mathrm{M}$。

**定义 9.3.1（纳米域耦合与微米域耦合）** 当囊泡的感受器位于一个或几个 $\ce{Ca^2+}$ 通道约 $10$–$30\,\mathrm{nm}$ 以内，仅这些通道的局部 $\ce{Ca^2+}$ 就能触发融合时，称释放具有**纳米域耦合**；当感受器距离一簇通道 $100\,\mathrm{nm}$ 或更远、这些通道重叠的 $\ce{Ca^2+}$ 域相加时，称之为**微米域耦合**。

这两种状态在实验上用不同速度的外源缓冲剂加以区分（Adler 及同事，1991；Eggermann 及同事，2012）。BAPTA 与 EGTA 的亲和力相近，但 BAPTA 结合 $\ce{Ca^2+}$ 约快 40 倍。在式 (9.4) 中，$10\,\mathrm{mM}$ BAPTA 使 $\lambda_{\mathrm{B}}$ 缩短到约 $7\,\mathrm{nm}$，在两种状态下都阻断释放；而 $10\,\mathrm{mM}$ EGTA 给出 $\lambda_{\mathrm{B}} \approx 50\,\mathrm{nm}$，只阻断微米域释放（见下图 B 和 C）。按这一检验，快速发放的篮状细胞突触、鱿鱼巨突触与成熟的 Held 花萼使用纳米域耦合，而未成熟的花萼与一些皮层突触的耦合则较为松散。紧密耦合使传递快速、时间精确且节能，因为每个囊泡只需少数通道开放；这也意味着单个通道的开放就能决定一个囊泡是否融合，从而助长了释放的随机性。

## 9.4. 释放的分子机器

### 9.4.1. SNARE

膜融合由 **SNARE 蛋白**驱动，其拉链式组装的一般机制见 [7.3.8](/7.3.8#sec-8.4.2)：囊泡上的突触小泡蛋白（synaptobrevin，VAMP2）与质膜上的 syntaxin-1 和 SNAP-25 形成四螺旋束，把两层膜拉到一起；融合后，NSF 与 α-SNAP 把复合物拆开。突触上的决定性证据来自毒素：梭菌神经毒素是蛋白酶，每种在一个位置切断一种 SNARE（[7.14.5](/7.14.5#sec-5.4.2)），并且每种都阻断释放。每次融合事件所需的 SNARE 复合物数目估计为一到三个，其组装释放的能量（每个复合物几十 $k_{\mathrm{B}}T$）与融合两层膜的势垒相当。单靠 SNARE 融合脂质体需要几分钟；突触融合不到一毫秒，并由 $\ce{Ca^2+}$ 触发。速度与 $\ce{Ca^2+}$ 控制由另外的蛋白质提供。

### 9.4.2. 突触结合蛋白，Ca²⁺ 感受器

**定义 9.4.1（突触结合蛋白）** **突触结合蛋白**-1 是一种囊泡膜蛋白，具有两个胞质侧的 $\ce{Ca^2+}$ 结合 C2 结构域（C2A 结合三个、C2B 结合两个 $\ce{Ca^2+}$ 离子），是快速同步释放的 $\ce{Ca^2+}$ 感受器：结合 $\ce{Ca^2+}$ 后，其 C2 结构域插入磷脂膜，并作用于部分拉链化的 SNARE 复合物以触发融合。

有三条证据确定它就是感受器（Südhof 及同事）。缺失突触结合蛋白-1 的敲除小鼠丧失了由动作电位触发的释放的快速同步成分，而自发释放与缓慢的异步释放依然存在，甚至增加（Geppert 及同事，1994）。C2A 中的点突变（R233Q）在体外使该蛋白的 $\ce{Ca^2+}$ 亲和力减半，把它敲入小鼠后，释放的表观 $\ce{Ca^2+}$ 亲和力也减半，而协同性不变（Fernández-Chacón 及同事，2001）：生化常数与生理常数在定量上相符，这是分子机制所能得到的最强的一类证据。而且两个 C2 结构域所结合的五个 $\ce{Ca^2+}$ 离子对应于公式 9.3.1 的五个位点。突触结合蛋白-2 在 Held 花萼与神经肌肉接头起相同作用；亲和力更高、更慢的突触结合蛋白-7 介导异步释放并促成易化（9.6）；复合素（complexin）钳制 SNARE 复合物，使自发融合在 $\ce{Ca^2+}$ 到来之前很少发生。

### 9.4.3. 预备与活性区

囊泡必须先停靠并被预备，$\ce{Ca^2+}$ 才能使其释放。

**定义 9.4.2（易释放池）** 终末的**易释放池**（RRP）是已停靠并已预备、可以在强 $\ce{Ca^2+}$ 信号的几毫秒内融合的囊泡的集合；它用高渗蔗糖溶液、长时间去极化或高频串刺激所诱发的释放来测量，在小型中枢突触上每个活性区含约五到十个囊泡。

预备由 Munc18-1 与 Munc13 完成。Munc18-1 结合 syntaxin-1 并为 SNARE 复合物的组装提供模板，Munc13 打开 syntaxin 的闭合构象，使复合物得以形成。删除其中任何一种蛋白都会使诱发与自发释放消失；引人注目的是，缺失 Munc18-1 的小鼠在出生时死亡之前，仍然构建出了具有正常分层结构和突触的脑（Verhage 及同事，2000），这把递质释放的作用与突触形成的作用区分开来。在活性区，RIM 结合 Munc13（促进预备）、结合 RIM 结合蛋白与 $\ce{Ca^2+}$ 通道（把通道招募到释放位点），并结合囊泡蛋白 Rab3；活性区因此既决定 RRP 的大小（$N$），也决定决定 $p$ 的耦合距离（9.3.2）。超分辨成像表明，释放位点与突触后受体簇排列成约 $80\,\mathrm{nm}$ 的"纳米柱"（Tang 及同事，2016），使一个囊泡的递质落在受体最密集之处。

| 蛋白 | 位置 | 作用 | 功能丧失 |
|---|---|---|---|
| Synaptobrevin、syntaxin-1、SNAP-25 | 囊泡；质膜 | 融合（SNARE 复合物） | 被梭菌毒素切断；释放被阻断 |
| 突触结合蛋白-1 / -2 | 囊泡 | 同步释放的 $\ce{Ca^2+}$ 感受器 | 同步释放丧失，异步释放保留 |
| 复合素 | 胞质，位于 SNARE 上 | 钳制与激活 | 自发释放增加，诱发释放减少 |
| Munc18-1 | 胞质，位于 syntaxin 上 | SNARE 组装，预备 | 无释放 |
| Munc13 | 活性区 | 打开 syntaxin，预备 | 无释放 |
| RIM、RIM-BP | 活性区 | 招募 Munc13 与 $\ce{Ca^2+}$ 通道 | 预备的囊泡减少，耦合变松 |

## 9.5. 清除与囊泡循环

融合之后，递质必须从间隙中清除，囊泡膜必须回收并重新充填。**神经递质**通过扩散离开间隙、通过酶促水解（胆碱能突触处的乙酰胆碱酯酶，[7.14.8](/7.14.8#sec-8.4.2)）以及**转运蛋白**被清除：由 $\ce{Na+}$ 梯度驱动的质膜转运蛋白摄取谷氨酸（主要经 EAAT2 进入星形胶质细胞）、GABA、甘氨酸与单胺。间隙中谷氨酸的时间进程是由一种快速解离的拮抗剂的位移估计出来的：一个囊泡释放后，浓度峰值约为 $1$–$3\,\mathrm{mM}$，以约 $1\,\mathrm{ms}$ 的时间常数衰减（Clements 及同事，1992）。转运蛋白结合谷氨酸很快，转运却很慢（每个循环几十毫秒），因此它们的首要作用是缓冲；它们的密度决定有多少谷氨酸溢出到邻近突触以及突触外的 NMDA 与代谢型受体。

囊泡由囊泡转运蛋白（VGLUT 转运谷氨酸，VGAT 转运 GABA 与甘氨酸，VMAT 转运单胺，VAChT 转运乙酰胆碱）重新充填，其驱动力是液泡型 $\ce{H+}$-ATP 酶在囊泡膜两侧建立的质子梯度；神经元表达哪种囊泡转运蛋白，就决定了它的递质身份。膜通过速度各异的几种途径回收：

- 网格蛋白介导的**内吞作用**，由**网格蛋白**外被包被，由**发动蛋白**切断，需 $10$–$20\,\mathrm{s}$；果蝇（*Drosophila*）的温度敏感型发动蛋白突变体 *shibire* 在 $29^\circ\mathrm{C}$ 下几分钟内终末就被抽空囊泡并发生麻痹，这是循环利用对于维持传递所必需的经典证明；
- 超快内吞，发生在活性区边缘、融合后 $50$–$100\,\mathrm{ms}$ 内（Watanabe 及同事，2013，用"闪光–冷冻"电子显微镜），随后由内体再生出囊泡；
- "kiss-and-run"，一种瞬时的融合孔，重新闭合而囊泡没有完全塌陷，它在中枢突触上的重要性尚有争论。

终末的囊泡通常分为 RRP、在中等活动时补充它的循环池（约占囊泡的 10–20%）以及只被强烈刺激动员的储备池。海马膨体的 RRP 在静息时以数秒的时间常数补充，$\ce{Ca^2+}$ 升高时更快，这一补充速率限制了传递可持续的速率。

## 9.6. 短时程可塑性

一个动作电位所释放的递质量，取决于终末在之前几毫秒到几分钟内的历史。这些变化是一种不需要突触后细胞或基因表达发生改变的**突触可塑性**；它们来自突触前 $\ce{Ca^2+}$ 与囊泡池的动力学。

**定义 9.6.1（双脉冲比）** 当两个动作电位相隔 $\Delta t$ 到达突触时，第二个与第一个突触后响应的平均幅度之比 $A_2/A_1$ 称为**双脉冲比**（PPR）。若该比值大于 1，则突触表现出**双脉冲易化**；若小于 1，则表现出**双脉冲压抑**。

**定义 9.6.2（易化、压抑与强直后增强）** **突触易化**是一个或几个动作电位之后持续几十到几百毫秒的释放增加；**突触压抑**是重复活动期间及之后的释放减少，在几百毫秒到数秒内恢复；**强直后增强**是高频串刺激（强直）之后持续几十秒到几分钟的释放增加；增强（augmentation）是衰减时间约 $5$–$10\,\mathrm{s}$ 的中间成分。

| 成分 | 衰减时间常数 | 主要机制 |
|---|---|---|
| 易化 | $10$–$300\,\mathrm{ms}$ | 残余 $\ce{Ca^2+}$ 作用于高亲和力感受器（突触结合蛋白-7）；局部缓冲剂的饱和 |
| 压抑 | $0.1$–$10\,\mathrm{s}$ | RRP 的耗竭；还有 $\ce{Ca^2+}$ 通道与释放位点的失活、突触后受体的**脱敏** |
| 增强 | $5$–$10\,\mathrm{s}$ | 累积的 $\ce{Ca^2+}$ |
| 强直后增强 | $30\,\mathrm{s}$ 至数分钟 | 线粒体缓慢释放的 $\ce{Ca^2+}$；**蛋白激酶 C** 的激活使 $p$ 与 RRP 大小增加 |

Katz 与 Miledi（1968）提出，易化是由于第一个脉冲遗留在终末中的残余 $\ce{Ca^2+}$，它与第二个脉冲的 $\ce{Ca^2+}$ 相加。由于释放约与 $\ce{Ca^2+}$ 的四次方成正比，一个小的残余就可能有很大的效应。定量上的困难在于，残余的胞质主体 $\ce{Ca^2+}$（低于 $1\,\mu\mathrm{M}$）与感受器处的几十微摩尔相比可以忽略；目前的看法是，它作用于另一个高亲和力、缓慢的感受器，因此易化仍然是"残余 $\ce{Ca^2+}$"，只是由另一种分子读出（Jackman 及同事，2016）。反过来，压抑反映的是有限的 RRP：在第一个脉冲上就释放了大部分停靠囊泡的突触，留给第二个脉冲的就更少。

这两种机制预言初始释放概率与双脉冲比之间存在反比关系。设每个位点在第一个脉冲上以概率 $p$ 释放；若池中有比例 $p$ 被用掉并以时间常数 $\tau_{\mathrm{rec}}$ 恢复，而残余 $\ce{Ca^2+}$ 使释放概率增加 $f(1 - p)$，以 $\tau_{\mathrm{F}}$ 衰减，则
$$
\mathrm{PPR} = \frac{\left(1 - p\,\mathrm{e}^{-\Delta t/\tau_{\mathrm{rec}}}\right)\left(p + f(1-p)\,\mathrm{e}^{-\Delta t/\tau_{\mathrm{F}}}\right)}{p}. \tag{9.5}
$$
当 $p$ 较小时该比值大于 1（易化占主导）；当 $p$ 较大时它小于 1（耗竭占主导）。在单个海马膨体上的实验中，同一轴突上相邻终末的 $p$ 差别很大，实验证实了这一反比关系（Dobrunz 与 Stevens，1997），而降低细胞外 $\ce{Ca^2+}$ 浓度会把压抑的突触变成易化的突触（见下图）。因此 PPR 被常规地用作 $p$ 的指标：改变 PPR 的操作被怀疑作用于突触前。式 (9.5) 对脉冲串的动力学版本，即 **Tsodyks–Markram 模型**，是 [7.16.12](/7.16.12) 的主题。

**例 9.6.1** 对于 $p = 0.1$、$\Delta t = 20\,\mathrm{ms}$、$f = 0.3$、$\tau_{\mathrm{F}} = 50\,\mathrm{ms}$、$\tau_{\mathrm{rec}} = 500\,\mathrm{ms}$ 的突触，式 (9.5) 给出 $\mathrm{e}^{-0.4} = 0.67$，$p_2 = 0.1 + 0.3\cdot0.9\cdot0.67 = 0.281$，$x_2 = 1 - 0.1\cdot0.96 = 0.904$，$\mathrm{PPR} = 0.904\cdot0.281/0.1 \approx 2.5$。取 $p = 0.7$，同样的参数给出 $p_2 = 0.76$，$x_2 = 0.33$，$\mathrm{PPR} \approx 0.36$。若第二个突触的位点少七倍，两个突触可以有相同的平均第一响应；它们在一串脉冲中传递的信息仍会大不相同：第一个强调一串脉冲中靠后的脉冲，第二个强调沉默之后的第一个脉冲。

短时程可塑性不是叠加在传递上的干扰，而是一种滤波器。压抑的突触主要传递突触前速率的变化（其稳态输出随速率饱和），易化的突触主要传递持续的高频脉冲串；同一条轴突可以在一个靶标上形成压抑突触，在另一个靶标上形成易化突触，取决于每个终末的分子组成（Markram 及同事，1998）。它的计算作用，从增益控制到 [7.16.45](/7.16.45) 的活动静默型工作记忆，在 [7.16.12](/7.16.12) 中展开。

## 小结

- 约 $0.5\,\mathrm{ms}$ 的突触延搁花在 $\ce{Ca^2+}$ 通道的开放与 $\ce{Ca^2+}$ 触发的融合上，而不是扩散上；触发释放的是 $\ce{Ca^2+}$ 的进入，而不是去极化（9.1）。
- 释放是量子化且概率性的。在二项模型（定义 9.2.1）中，响应的均值为 $Npq$，方差为 $Npq^2(1 - p + (C_V^{(q)})^2)$（命题 9.2.1）；改变 $p$ 描出方差–均值抛物线（命题 9.2.2），其斜率与曲率给出 $q$ 与 $N$。同样的运算用于通道，得到单通道电导与受体数目（式 (9.3)）。
- 融合的感受器以协同性结合约五个 $\ce{Ca^2+}$ 离子（公式 9.3.1），需要几十微摩尔，而这只有在开放通道周围的域中才有；耦合距离（定义 9.3.1）用快、慢缓冲剂 BAPTA 与 EGTA 探测，决定速度与释放概率。
- 融合由 SNARE 驱动，由突触结合蛋白触发（定义 9.4.1），并由活性区（定义 9.1.1）的 Munc18 与 Munc13 预备，活性区还负责安放 $\ce{Ca^2+}$ 通道；易释放池（定义 9.4.2）经几条内吞途径在数秒内得到补充。
- 易化（残余 $\ce{Ca^2+}$）、压抑（耗竭）与强直后增强（定义 9.6.2）使传递依赖于历史；双脉冲比（定义 9.6.1）随初始释放概率升高而下降（式 (9.5)）。

| 量 | 典型的中枢突触 | 神经肌肉接头 |
|---|---|---|
| 释放位点 $N$ | 每个连接 $1$–$10$ | 数百 |
| 释放概率 $p$ | $0.05$–$0.9$，常为 $0.1$–$0.4$ | 每个位点较低，但位点很多 |
| 量子大小 $q$ | $5$–$30\,\mathrm{pA}$ | $\approx 0.5\,\mathrm{mV}$（mEPP） |
| 量子含量 $Np$ | $\lesssim 5$ | $50$–$300$ |
| 短时程可塑性 | 易化或压抑 | 压抑 |

## 思考题

1. 证明在二项模型中响应的变异系数为 $C_V(A) = \sqrt{(1 - p + (C_V^{(q)})^2)/(Np)}$。若某操作只改变 $q$、只改变 $p$ 或只改变 $N$，$1/C_V(A)^2$ 会怎样变化？为什么这是检验某操作作用位点的有用方法？

   **答** 由式 (9.1)，$C_V(A)^2 = \operatorname{Var}(A)/\mathbb{E}[A]^2 = Npq^2(1 - p + (C_V^{(q)})^2)/(Npq)^2$，即得公式。它与 $q$ 无关：纯粹突触后的量子大小改变（例如受体增多）改变均值而不改变 $C_V$，故 $1/C_V^2$ 保持不变。$N$ 或 $p$ 的增加会使 $1/C_V^2 = Np/(1 - p + (C_V^{(q)})^2)$ 与均值一起增大。因此，把 $1/C_V^2$ 的相对变化对均值的相对变化作图，可以区分突触前的变化（点位于对角线附近或其上方）与 $q$ 的突触后变化（点位于水平线上）；这曾被用来争论长时程增强的表达位点（7.16.14）。该检验假定二项模型成立，且操作不会同时改变几个参数。

2. 在一次方差–均值分析中，三个 $\ce{Ca^2+}$ 浓度给出 $(\mu, \sigma^2) = (15\,\mathrm{pA}, 180\,\mathrm{pA^2})$、$(40, 320)$ 与 $(60, 288)$。估计 $q'$、$N$ 与三个释放概率。

   **答** 令 $\sigma^2 = a\mu + b\mu^2$：由前两点，$180 = 15a + 225b$，$320 = 40a + 1600b$。除以 $\mu$：$12 = a + 15b$，$8 = a + 40b$，故 $b = -4/25 = -0.16$，$a = 14.4$。第三点检验：$14.4 - 0.16\cdot60 = 4.8 = 288/60$（对真实数据应当对所有点做最小二乘拟合）。于是 $q' \approx 14\,\mathrm{pA}$，$N = 1/0.16 \approx 6$；最大响应 $Nq' \approx 90\,\mathrm{pA}$，所以 $p \approx 15/90 = 0.17$、$40/90 = 0.44$、$60/90 = 0.67$。

3. 用式 (9.4) 估计在没有外源缓冲剂时，距单个开放通道多远处局部 $[\ce{Ca^2+}]$ 降到 $10\,\mu\mathrm{M}$ 以下，并解释为什么 $10\,\mathrm{mM}$ EGTA 对篮状细胞突触的释放几乎没有影响，却强烈降低未成熟 Held 花萼的释放。

   **答** 没有缓冲剂时 $c(r) \approx i_{\mathrm{Ca}}/(4\pi zFDr)$。取 $i_{\mathrm{Ca}} = 0.3\,\mathrm{pA}$：$4\pi\cdot 2\cdot 96485\,\mathrm{C\,mol^{-1}}\cdot 2.2\times10^{-10}\,\mathrm{m^2\,s^{-1}} = 5.3\times10^{-4}\,\mathrm{C\,m^2\,s^{-1}\,mol^{-1}}$，所以 $c(r) = 0.3\times10^{-12}/(5.3\times10^{-4}\,r)\,\mathrm{mol\,m^{-3}}$，而 $c = 10\,\mu\mathrm{M} = 10^{-2}\,\mathrm{mol\,m^{-3}}$ 出现在 $r \approx 57\,\mathrm{nm}$。EGTA 结合 $\ce{Ca^2+}$ 很慢（$10\,\mathrm{mM}$ 时 $\lambda_{\mathrm{B}} \approx 50\,\mathrm{nm}$）：在距通道 $20\,\mathrm{nm}$ 以内，多数离子在被 EGTA 捕获之前就已到达感受器（$\mathrm{e}^{-20/50} = 0.67$），而且由于释放约与 $c$ 的四次方成正比，降低是适度的。在 $100$–$200\,\mathrm{nm}$ 处，$c$ 的因子为 $\mathrm{e}^{-2}$ 到 $\mathrm{e}^{-4}$，因而释放的降低为 $10^{-3}$ 或更多。篮状细胞终末把通道与感受器耦合在约 $20\,\mathrm{nm}$ 以内（纳米域），未成熟的花萼则在 $100\,\mathrm{nm}$ 或更远（微米域）。

4. 某药物使平均 EPSC 降低 50%，并使双脉冲比从 1.1 升到 1.6，而不改变自发微小 EPSC 的幅度。它作用于何处？举一个这类药物作用的例子。

   **答** 微小幅度不变意味着 $q$ 不变（突触后受体未受影响）；均值降低而 PPR 升高，是释放概率降低的特征（式 (9.5) 以及 $p$ 与 PPR 之间的反比关系）。药物作用于突触前，最可能是减少 $\ce{Ca^2+}$ 内流，例如激活突触前的 $\mathrm{GABA_B}$ 受体、腺苷 $\mathrm{A_1}$ 受体或大麻素 $\mathrm{CB_1}$ 受体，它们的 $\mathrm{G}\beta\gamma$ 亚基抑制 $\mathrm{Ca_V2}$ 通道（7.16.11）；由于释放约与 $\ce{Ca^2+}$ 内流的四次方成正比，内流减少约 16% 就足以使释放减半。
