## 41.1. 基于价值的方法的局限

基于价值的智能体通过选择 $\arg\max_a \hat q(s, a)$ 来行动。由此产生三个问题。

1. *大的和连续的行动空间。* 最大化在每一步都是一次搜索。对伸手运动，即肌肉指令的连续向量，无法通过枚举找到 $\hat q$ 在行动上的最大值。
2. *随机的最优策略。* 贪心策略是确定性的，而 **ε-贪心策略**或 softmax 探索添加的随机性并未针对任务调节。但当智能体无法区分状态（部分可观察）或与对手博弈时，最优策略可能是随机的。
3. *不连续性。* $\hat q$ 任意小的改变都可能切换贪心行动，所以用函数逼近学习时，策略之间可能来回振荡而不是收敛。

**例 41.1.1（混叠走廊）** 一条走廊有三个非终止状态和一个目标，每步奖赏为 $-1$（Sutton 与 Barto 的例子）。在第一和第三个状态中，“右”向右移动，“左”向左移动（或在墙边不动），而在第二个状态中行动的效果相反。智能体无法区分这些状态，所以任何策略在所有状态中都以同一概率 $p$ 选择“右”。把 $v(s_1)$ 作为 $p$ 的函数解 Bellman 方程，得到最优值 $v = -(6 + 4\sqrt2) \approx -11.7$，在 $p = 2 - \sqrt2 \approx 0.59$ 时取得。$\varepsilon = 0.1$ 的 ε-贪心智能体只能实现 $p = 0.95$ 或 $p = 0.05$，对应的值是 $-44$ 与 $-82$；确定性策略则永远到不了目标。

:::

补救办法是把策略本身参数化，$\pi(a \mid s; \boldsymbol{\theta})$，记作 $\pi_{\boldsymbol{\theta}}$，并调整 $\boldsymbol{\theta}$ 以提高期望回报。常见的参数化是：对离散行动，在偏好 $h(s, a; \boldsymbol{\theta})$ 上取 softmax；对连续行动，取均值与方差可学习的 Gauss 分布。

## 41.2. 策略梯度定理

### 41.2.1. 定理

考虑起始状态为 $s_0$ 的分段式任务，目标为 $J(\boldsymbol{\theta}) = v_{\pi_{\boldsymbol{\theta}}}(s_0)$。改变 $\boldsymbol{\theta}$ 既改变每个状态中所采取的行动，也通过它们改变所访问状态的分布，而后者依赖于未知的环境。该定理表明，梯度不需要状态分布的导数。

**定理 41.2.1（策略梯度定理）** 设 $\eta(s) = \sum_{k=0}^{\infty}\gamma^k\,\mathbb{P}(S_k = s \mid S_0 = s_0, \pi_{\boldsymbol{\theta}})$ 为对状态 $s$ 的折扣期望访问次数。则
$$
\nabla_{\boldsymbol{\theta}} J(\boldsymbol{\theta}) = \sum_s \eta(s) \sum_a q_\pi(s, a)\,\nabla_{\boldsymbol{\theta}}\pi(a \mid s; \boldsymbol{\theta}) = \mathbb{E}_\pi\Bigl[\sum_{t \ge 0}\gamma^t\,q_\pi(S_t, A_t)\,\nabla_{\boldsymbol{\theta}}\ln\pi(A_t \mid S_t; \boldsymbol{\theta})\Bigr]. \tag{41.1}
$$

**证明** 记 $\nabla$ 为 $\nabla_{\boldsymbol{\theta}}$，$p(s' \mid s, a) = \sum_r p(s', r \mid s, a)$。由 $v_\pi(s) = \sum_a \pi(a \mid s)\,q_\pi(s, a)$ 与乘积法则，
$$
\nabla v_\pi(s) = \sum_a \nabla\pi(a \mid s)\,q_\pi(s, a) + \sum_a \pi(a \mid s)\,\nabla q_\pi(s, a).
$$
由于 $q_\pi(s, a) = \sum_{s', r}p(s', r \mid s, a)[r + \gamma v_\pi(s')]$ 且环境不依赖于 $\boldsymbol{\theta}$，$\nabla q_\pi(s, a) = \gamma\sum_{s'}p(s' \mid s, a)\,\nabla v_\pi(s')$。记 $\phi(s) = \sum_a \nabla\pi(a \mid s)\,q_\pi(s, a)$ 与 $P_\pi(s' \mid s) = \sum_a \pi(a \mid s)p(s' \mid s, a)$，这就是递推关系 $\nabla v_\pi(s) = \phi(s) + \gamma\sum_{s'}P_\pi(s' \mid s)\,\nabla v_\pi(s')$，即梯度的一个 Bellman 方程。从 $s_0$ 出发展开，
$$
\nabla v_\pi(s_0) = \sum_{k=0}^{\infty}\gamma^k\sum_s \mathbb{P}(S_k = s \mid s_0)\,\phi(s) = \sum_s \eta(s)\,\phi(s),
$$
这就是第一种形式（余项 $\gamma^k\,\mathbb{E}[\nabla v_\pi(S_k)]$ 在 $\gamma < 1$ 且梯度有界时、或因回合终止而消失）。对第二种形式，写 $\nabla\pi = \pi\,\nabla\ln\pi$：则 $\phi(s) = \mathbb{E}_{A \sim \pi(\cdot \mid s)}[q_\pi(s, A)\,\nabla\ln\pi(A \mid s)]$，以 $\eta(s)$ 为权重对 $s$ 求和，就是对轨迹取 $\sum_t\gamma^t(\cdot)$ 在 $(S_t, A_t)$ 处取值的期望。$\square$

项 $\nabla\ln\pi(A_t \mid S_t; \boldsymbol{\theta})$ 是策略的**得分函数**：参数空间中使所采取行动的概率增加最多的方向。式 (41.1) 说：按每个行动的好坏程度成比例地增加其对数概率。由于 $q_\pi(S_t, A_t) = \mathbb{E}[G_t \mid S_t, A_t]$，可以用采样的回报代替它。

**算法 41.2.1（REINFORCE）** 用 $\pi_{\boldsymbol{\theta}}$ 生成一个回合 $S_0, A_0, R_1, \dots, S_{T-1}, A_{T-1}, R_T$。对每个 $t = 0, \dots, T - 1$，计算 $G_t = \sum_{k=t+1}^{T}\gamma^{k-t-1}R_k$ 并更新
$$
\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} + \alpha\,\gamma^t\,(G_t - b(S_t))\,\nabla_{\boldsymbol{\theta}}\ln\pi(A_t \mid S_t; \boldsymbol{\theta}),
$$
其中 $b(s)$ 是基线，即任何不依赖于行动的状态函数（原始形式中 $b = 0$；Williams，1992）。

REINFORCE 是对 $J$ 的随机梯度上升：期望更新为 $\alpha\nabla J$，所以步长适当递减时它收敛到局部极大。它是一种蒙特卡洛方法，需要完整的回合，并且回合中的每个行动都被归功于此后的整个回报。对 softmax 策略，$\nabla_{\boldsymbol{\theta}}\ln\pi(a \mid s) = \nabla h(s, a) - \sum_b \pi(b \mid s)\nabla h(s, b)$：所选行动的偏好上升，其他行动的偏好按其概率成比例地下降。

### 41.2.2. 基线与方差

**命题 41.2.2（基线不使梯度产生偏差）** 对任何不依赖于行动的函数 $b(s)$，有 $\sum_a b(s)\,\nabla\pi(a \mid s; \boldsymbol{\theta}) = 0$，所以在式 (41.1) 中把 $q_\pi(s, a)$ 换成 $q_\pi(s, a) - b(s)$ 不改变梯度。

**证明** $\sum_a b(s)\,\nabla\pi(a \mid s) = b(s)\,\nabla\sum_a\pi(a \mid s) = b(s)\,\nabla 1 = 0$。$\square$

基线不改变期望更新，却可以大幅改变其方差。如果所有回报都是正的，例如奖赏含有一个常数偏移时，所采取的每个行动都得到强化，策略的改进仅仅是因为更好的行动被强化得稍多一些；估计被这个偏移所主导。减去一个接近 $v_\pi(s)$ 的基线，使好于平均的行动得到正的更新、差于平均的得到负的更新。使方差最小的基线是回报的加权平均，接近 $v_\pi(s)$，这就是评价者学得的状态价值成为自然选择的原因。

**例 41.2.1（双臂老虎机）** 臂 1 的回报服从 $\mathcal{N}(6, 1)$，臂 2 服从 $\mathcal{N}(5, 1)$；策略为 $\pi(\text{arm }1) = \sigma(\theta)$，其中 $\sigma$ 是 logistic 函数。得分对臂 1 为 $1 - \pi$，对臂 2 为 $-\pi$，真实梯度为 $\pi(1 - \pi)(\mu_1 - \mu_2)$，至多为 $0.25$。在 $\pi = 0.5$ 处，无基线的单样本估计的标准差为 $2.8$，比梯度大十倍以上；取基线 $b = v_\pi$ 时为 $0.5$。在 300 次试验中取 $\alpha = 0.05$，无基线的智能体平均达到 $\pi(\text{arm }1) \approx 0.83$，各次运行之间分散很大，而取滑动平均基线的智能体达到 $0.91$，分散很小。

## 41.3. 行动者–评价者方法

### 41.3.1. 优势

**定义 41.3.1（优势函数）** 策略 $\pi$ 的**优势函数**是 $\operatorname{adv}_\pi(s, a) = q_\pi(s, a) - v_\pi(s)$，即在状态 $s$ 采取行动 $a$、此后遵循 $\pi$，比从 $s$ 起遵循 $\pi$ 好出的量。

取基线 $b = v_\pi$，策略梯度成为 $\mathbb{E}_\pi[\sum_t\gamma^t\operatorname{adv}_\pi(S_t, A_t)\nabla\ln\pi(A_t \mid S_t)]$，并且优势在行动上平均为零，$\sum_a\pi(a \mid s)\operatorname{adv}_\pi(s, a) = 0$。它不需要单独学习：**TD 误差**就估计了它。

**命题 41.3.1** 若 $\hat v = v_\pi$，则 TD 误差 $\delta_t = R_{t+1} + \gamma\,v_\pi(S_{t+1}) - v_\pi(S_t)$ 满足 $\mathbb{E}[\delta_t \mid S_t = s, A_t = a] = \operatorname{adv}_\pi(s, a)$。

**证明** $\mathbb{E}[R_{t+1} + \gamma v_\pi(S_{t+1}) \mid S_t = s, A_t = a] = \sum_{s', r}p(s', r \mid s, a)[r + \gamma v_\pi(s')] = q_\pi(s, a)$，而 $v_\pi(S_t) = v_\pi(s)$ 由条件所固定。$\square$

该命题为 [7.16.40](/7.16.40) 的行动者–评价者算法（算法 40.4.1）提供了依据：用 $\alpha_{\mathrm{a}}\delta_t$ 更新所选行动的偏好，是以评价者的价值为基线的策略梯度的单步自举估计。在脑的版本中，同一个多巴胺预测误差会同时充当行动者的优势信号和评价者的 TD 误差，这与送往腹侧和背侧纹状体的相位性多巴胺信号大体相似相一致。

**算法 41.3.1（单步优势行动者–评价者）** 设策略参数为 $\boldsymbol{\theta}$、价值参数为 $\boldsymbol{w}$，每一步选择 $A_t \sim \pi(\cdot \mid S_t; \boldsymbol{\theta})$，观察 $R_{t+1}, S_{t+1}$，并计算 $\delta_t = R_{t+1} + \gamma\,\hat v(S_{t+1}; \boldsymbol{w}) - \hat v(S_t; \boldsymbol{w})$（终止状态处 $\hat v = 0$）。然后更新
$$
\boldsymbol{w} \leftarrow \boldsymbol{w} + \alpha_{\boldsymbol{w}}\,\delta_t\,\nabla_{\boldsymbol{w}}\hat v(S_t; \boldsymbol{w}), \qquad \boldsymbol{\theta} \leftarrow \boldsymbol{\theta} + \alpha_{\boldsymbol{\theta}}\,\delta_t\,\nabla_{\boldsymbol{\theta}}\ln\pi(A_t \mid S_t; \boldsymbol{\theta}).
$$

单步 TD 误差方差低，但在 $\hat v$ 有误时有偏；$n$ 步回报与资格迹在它与蒙特卡洛回报之间插值，与预测的情形（[7.16.39](/7.16.39#sec-39.5.1)）完全相同。在并行环境中运行智能体的许多副本并平均其梯度（A2C、A3C；Mnih 等，2016），可以使样本去相关，其方式类似于**经验回放**对 **Q 学习**所起的作用。

### 41.3.2. 信任域与 PPO

过大的梯度步可能使策略改变得如此之大，以至于估计所依据的样本不再描述它，性能随之崩溃。信任域方法限制策略的变化，用比值 $\rho_t = \pi_{\boldsymbol{\theta}}(A_t \mid S_t)/\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(A_t \mid S_t)$ 或新旧策略之间的 Kullback–Leibler 散度来度量。**近端策略优化**最大化截断目标 $\mathbb{E}_t[\min(\rho_t\hat a_t, \operatorname{clip}(\rho_t, 1 - \varepsilon, 1 + \varepsilon)\hat a_t)]$，其中 $\hat a_t$ 估计优势，使得任何一轮更新都不会使某行动的概率改变超过因子 $1 \pm \varepsilon$（Schulman 等，2017）。它是语言模型的**基于人类反馈的强化学习**（[4.7.9](/4.7.9#sec-9.3.3)）的标准算法，其中“行动”是词元，优势来自学得的奖赏模型。脑中没有显式的信任域，但有界的学习率与突触权重的饱和以类似的方式限制了策略的变化。

## 41.4. 脑中的策略梯度

### 41.4.1. 随机神经元与三因子规则

Williams（1992）为随机单元网络引入了 REINFORCE，在那种形式下，它就是一条突触学习规则。

**命题 41.4.1（随机神经元的 REINFORCE）** 设一个二值神经元在突触前活动 $x_j$ 的作用下以概率 $p = \sigma(\sum_j w_j x_j)$ 放电（$y = 1$），并设网络得到依赖于其输出的奖赏 $R$。则带有与 $y$ 无关的基线 $b$ 的更新
$$
\Delta w_j = \eta\,(R - b)\,(y - p)\,x_j
$$
在期望意义下沿 $\mathbb{E}[R]$ 的梯度方向。

**证明** $\ln\mathbb{P}(y) = y\ln p + (1 - y)\ln(1 - p)$，利用 $\partial p/\partial w_j = p(1 - p)x_j$ 得 $\partial\ln\mathbb{P}(y)/\partial w_j = (y - p)x_j$。该更新就是单步回合的 REINFORCE 更新；由定理 41.2.1 与命题 41.2.2，其期望为 $\eta\,\partial\mathbb{E}[R]/\partial w_j$。$\square$

这条规则具有**三因子学习规则**（[7.16.14](/7.16.14#sec-14.9)）的三个因子：突触前活动 $x_j$，把实际脉冲与其预期概率比较的突触后项 $y - p$，以及全局调制信号 $R - b$，即**奖赏预测误差**。由于奖赏到达得比引起它们的脉冲晚，乘积 $(y - p)x_j$ 必须保存在**资格迹**中，于是该规则就成了在皮层–纹状体突触处测得的那一条。对脉冲神经元，相应的项是脉冲序列对数似然的导数，由此得到奖赏调制的 **STDP**（Pfister、Toyoizumi、Barber 与 Gerstner，2006；Izhikevich，2007）。

一条相关的规则直接扰动活动。在*节点扰动*中，每个神经元的输出为 $y_i = \sum_j w_{ij}x_j + \xi_i$，其中独立噪声 $\xi_i \sim \mathcal{N}(0, \sigma^2)$，而 $\Delta w_{ij} = \eta\,(R - b)\,\xi_i\,x_j/\sigma^2$，这就是对 Gauss 策略的 REINFORCE。噪声必须为突触所知，即作为与信号分开的注入扰动。鸣禽似乎使用这种设计：基底神经节–前脑核团 LMAN 向鸣唱运动核团 RA 注入变异性，送往 X 区的多巴胺信号评价每一次演唱，于是鸣唱通过试错被塑造得趋向模板（[7.16.36](/7.16.36#sec-36.6)；Fiete、Fee 与 Seung，2007）。所有扰动规则的局限是梯度估计的方差随被扰动单元的数目增长，所以学习按网络大小的比例变慢（Werfel、Xie 与 Seung，2005）；它们适用于低维的技能，而不适用于训练大型网络，这一问题在 [7.16.50](/7.16.50) 中讨论。

### 41.4.2. 多巴胺教的是价值还是策略？

在标准解释中，多巴胺是用来学习价值的 TD 误差（[7.16.39](/7.16.39#sec-39.3)）；在行动者–评价者中它还训练策略。这两种作用在学习早期、价值尚未知晓时，预测多巴胺与行为之间的关系不同。Coddington、Lindo 与 Dudman（2021）在幼稚小鼠学习做出一个行动以获取奖赏时，记录并操纵了中脑边缘多巴胺。线索与行动时刻的多巴胺活动，比起与价值学习模型的奖赏预测误差相匹配，更好地预测了每只小鼠行为改变得有多快，即策略学习的速率，而光遗传学操纵改变了这一速率。他们把多巴胺解释为调节策略梯度学习者的学习率。基于价值与基于策略的解释之间的争论尚无定论；二者使用同一个广播信号和同一套突触机制。

## 41.5. 基于模型与无模型的学习

### 41.5.1. 模型与规划

**定义 41.5.1（基于模型与无模型的强化学习）** 环境的*模型*是对转移与奖赏分布 $p(s', r \mid s, a)$、或其因子 $p(s' \mid s, a)$ 与 $\mathbb{E}[R \mid s, a]$ 的估计。**基于模型的强化学习**学习一个模型，并通过规划（动态规划、树搜索或模拟展开）从中计算价值或行动；**无模型强化学习**直接从经历的奖赏中学习价值或策略，而不表征行动的后果。

**TD 学习**、**Q 学习**与**行动者–评价者**是无模型的：它们的价值是过去奖赏的缓存摘要。一个无模型智能体学到杠杆产生食物后，若食物被贬值，就必须重新学习它的价值，办法是在按压之后经历被贬值的食物；基于模型的智能体则立即重新计算价值，因为它的价值来自“杠杆导致食物”与“食物现在毫无价值”。这就是目标导向行动与习惯之间差别的计算解释（[7.16.40](/7.16.40#sec-40.5)）。基于模型的控制灵活但昂贵：规划需要在决策时进行计算，计算量随搜索的深度增长。无模型控制在决策时廉价，但适应缓慢。

动物具有模型的行为学证据由来已久。在潜伏学习中，无奖赏地探索过迷宫、之后在终点得到奖赏的大鼠几乎立即学会了路线，远快于从未探索过的大鼠（Tolman 与 Honzik，1930）：探索在没有奖赏的情况下建立了一个模型，即**认知地图**（[7.16.46](/7.16.46)）。在选择点，大鼠停顿并左右张望，在这些停顿期间，海马**位置细胞**沿每条可能的路径向前扫过（“替代性试错”；Johnson 与 Redish，2007），仿佛通过模拟来评价各个选项。

### 41.5.2. 两步任务

**定义 41.5.2（两步任务）** **两步任务**（Daw、Gershman、Seymour、Dayan 与 Dolan，2011）是一种序贯选择任务：第一阶段在两个选项之间作选择，以概率方式导向两个第二阶段状态之一，每个选项以概率 $0.7$ 通向一个状态（常见转移）、以 $0.3$ 通向另一个（罕见转移）；在每个第二阶段状态中，被试在两个选项之间选择，它们给出奖赏的概率随试验缓慢漂移。

该任务通过一次试验的结果如何影响下一次试验的第一阶段选择，把两种控制形式分开。无模型学习者把得到的奖赏归功于第一阶段的选择，不论转移如何：它倾向于重复得到奖赏的选择。基于模型的学习者知道转移结构。如果一次罕见转移导致了奖赏，这个奖赏说明所到达的状态好，而再次到达它的最好办法是*另一个*第一阶段选择，它常见地通向那里。因此基于模型的控制使重复（“停留于”）第一阶段选择的概率中出现奖赏与转移的交互作用，而无模型控制只产生奖赏的主效应。

![模拟智能体在两步任务（定义 41.5.2）中的停留概率（200 个智能体，每个 1000 次试验；学习率 0.3，逆温度 5；奖赏概率在 $[0.25, 0.75]$ 内漂移）。A：无模型智能体（带资格迹的 SARSA，$\lambda = 1$）重复得到奖赏的选择，与转移无关。B：基于模型的智能体根据已知转移与学得的第二阶段价值计算第一阶段价值，在常见转移后获得奖赏时重复选择，在罕见转移后获得奖赏时转换选择，无奖赏时则相反。C：对两种价值等权重的混合智能体既表现出奖赏的主效应，也表现出交互作用，这是人类被试的典型模式。](./plots/two-step.py)

人类表现出两种模式的混合，由混合模型中基于模型价值的权重 $w$ 描述（Daw 等，2011）。这种平衡不是固定的。基于模型的控制因并发的工作记忆负荷和应激而减弱，因 L-DOPA 而增强（Wunderlich、Smittenaar 与 Dolan，2012），并与 PET 测得的腹侧纹状体多巴胺相关；它在一系列强迫性障碍中降低（Gillan 等，2016）。用该任务的一个版本训练的大鼠基本上是基于模型的，抑制眶额皮层或背侧海马会取消基于模型的成分而保留无模型学习（Miller、Botvinick 与 Brody，2017）。甚至纹状体的预测误差也携带基于模型的信息：在两步任务中，腹侧纹状体中与预测误差相关的 BOLD 信号同时反映无模型与基于模型的预测（Daw 等，2011），而学习中性刺激之间的联想需要多巴胺的瞬时变化，这是纯粹的价值信号所无法教会的（Sharpe 等，2017）。

### 41.5.3. 规划的基质

模型在哪里，又如何被使用？有几个结构起作用。

| 成分 | 候选基质 | 证据 |
|---|---|---|
| 状态空间与转移 | 海马与内嗅皮层（认知地图，[7.16.46](/7.16.46)） | **位置细胞**，前瞻性扫描，海马失活后基于模型选择的缺陷 |
| 结果的身份与价值 | 眶额皮层 | 贬值敏感性以及推断未经历组合的价值所必需 |
| 模拟 | 休息时与选择点处的海马**重放**与预播 | 在走向目标之前对到达目标的路径的重放（[7.16.46](/7.16.46#sec-46.6)） |
| 规划与工作记忆的控制 | 背外侧与内侧前额叶皮层 | 活动随规划深度而增大，例如在伦敦塔任务中 |

通过模拟的规划把模型与无模型学习联系了起来。在 Dyna 架构（Sutton，1990）中，由模型生成的模拟转移像真实经历过的一样训练缓存的价值，于是规划与学习使用同一个更新；休息时的重放是一种候选的实现（[7.16.46](/7.16.46#sec-46.6)）。最近的模型把规划本身变成学得的行动。Jensen、Hennequin 与 Mattar（2024）用强化学习训练一个循环网络在迷宫中导航，允许它在行动之前从学得的模型中采样想象的展开来“思考”；当规划有用时，智能体学会了更多地规划，它的展开类似于海马重放，而在智能体进行更多展开的同样情形下，人类被试停顿的时间也更长。第三条途径是**后继表征**（[7.16.46](/7.16.46)），它缓存对未来状态而非奖赏的预测，因此对奖赏的变化立即适应而对转移的变化则不然，介于两个系统之间。

## 41.6. 元强化学习

### 41.6.1. 学会学习

Harlow（1949）让猴子做数百个物体辨别问题：每个问题中，两个新物体呈现若干次试验，其中一个总是藏着葡萄干。在早期的问题上，猴子逐渐学会，每个问题需要许多次试验。几百个问题之后，它们能在一次试验内解决每个新问题：如果第一次选择得到奖赏，就继续选择该物体；如果没有，就转换（对物体的“赢则留、输则换”），第 2 次试验的正确率超过 95%。猴子形成了*学习定势*（learning set）：它们学会了这些问题共有的结构，并由此得到在一个问题内学习的快速策略。

**定义 41.6.1（元强化学习）** **元强化学习**是在一系列相关任务的分布上、在两个时间尺度上的学习：缓慢的外层过程跨许多任务调整学习系统的参数以使奖赏最大，其结果是系统获得一种快速的内层学习过程，能在新任务内根据少数几次经历调整其行为，而无需进一步改变缓慢的参数。

在机器学习中，内层过程常常是一个循环网络的活动：该网络把自己上一步的行动和奖赏作为输入，用标准的强化学习算法在许多任务上训练，学会把它的活动用作当前任务的记忆，并据此行动（Duan 等，2016；Wang 等，2016）。权重编码各任务共有的内容；活动编码当前任务特有的内容。在活动中学习不需要突触改变，而且很快；它是大型语言模型的**上下文学习**在强化学习中的对应物。

![Harlow 问题中的学会学习，用两层学习者。每个问题有两个新物体，其中一个总是得到奖赏，共六次试验。内层学习者是对物体价值（从 0.5 开始）的 delta 规则，学习率为 $\alpha$，用 softmax 选择（$\beta = 6$）；外层循环用进化策略（对随机扰动下平均奖赏作梯度上升）跨问题调整 $\alpha$。A：外层学习的四个阶段中在新问题内的正确率；学习曲线逐渐变陡，直到一次试验即解决问题，这是 Harlow 的猴子的模式。B：外层循环把 $\alpha$ 推向 1，即对这族问题最优的值，随之第 2 次试验的正确率上升。在真正的元强化学习中，内层学习者是循环网络的活动，外层循环塑造其权重。](./plots/learning-set.py)

该图是一个最小的示例：外层循环调节的是一条固定学习规则的单个参数。使元学习强大的是，内层过程并非事先固定，所以外层循环可以发现固定规则所不包含的策略，如赢则留、输则换，探索奖励，或对隐藏任务状态的推断。

### 41.6.2. 作为元学习者的前额叶皮层

Wang 等（2018）提出，前额叶皮层就是这样一个系统。它的循环回路能把活动维持数秒（[7.16.45](/7.16.45)），它的输入包括上一步的行动与奖赏，其突触由多巴胺驱动的无模型强化学习缓慢训练（外层循环）。他们用优势行动者–评价者（算法 41.3.1）在若干族任务上训练一个循环网络，并把训练后、权重冻结时它的行为与动物的行为作比较。

- *老虎机。* 在奖赏概率随机抽取的双臂老虎机上训练后，网络仅凭其活动解决了新的老虎机，接近 Bayes 最优性能；当在以不同速率变化的环境中训练时，它的有效学习率在多变时期更高，与人类相同（Behrens 等，2007）。
- *两步任务。* 仅用权重的无模型更新训练，网络的行为就表现出 41.5.2 节的基于模型特征（奖赏 × 转移的交互作用），因为它的活动学到了训练任务共有的转移结构：基于模型的行为可以在较慢的时间尺度上从无模型学习中涌现。
- *Harlow 任务。* 在以图像为物体的模拟三维环境中，网络获得了 Harlow 的猴子那样的一次试验学习。
- *多巴胺。* 评价者计算的预测误差反映了网络对隐藏任务状态的推断，正如反转任务中的多巴胺反应。

该模型对分工提出了强有力的主张：依赖多巴胺的突触可塑性，缓慢而无模型，训练前额叶网络，而网络的活动实现第二种更快的学习算法，它不必像 TD 学习。猴子前额叶皮层中独立于所应用的刺激来编码抽象规则的神经元，例如“选择相同的物体”与“选择不同的物体”（Wallis、Anderson 与 Miller，2001），以及追踪适应性选择所需奖赏历史的背外侧前额叶神经元，与之一致。同样的结构，即建立归纳偏置的慢学习者与利用它的快学习者，在演化与个体学习之间、在人工网络的预训练与上下文学习之间重复出现。

## 小结

- 基于价值的方法难以处理连续行动、随机最优策略与不连续的策略变化（例 41.1.1）；基于策略的方法直接把 $\pi(a \mid s; \boldsymbol{\theta})$ 参数化。
- 策略梯度定理（定理 41.2.1）通过动作价值与得分函数表示 $\nabla J$，而不需要状态分布的导数；REINFORCE（算法 41.2.1）用回报对它采样。依赖状态的基线使它保持无偏（命题 41.2.2），并能把方差降低一个数量级（例 41.2.1）。
- 优势函数（定义 41.3.1）由 TD 误差估计（命题 41.3.1），这使行动者–评价者成为一种策略梯度方法（算法 41.3.1）；PPO 限制每次更新中策略的变化。
- 对随机神经元，REINFORCE 是一条三因子规则：突触前活动、突触后反应偏离其期望的程度、以及奖赏预测误差（命题 41.4.1）；节点扰动与鸣唱学习相符，但其方差随网络大小增长。
- 基于模型的学习（定义 41.5.1）用学得的模型进行规划；两步任务（定义 41.5.2）通过停留概率中奖赏 × 转移的交互作用把它与无模型学习区分开。海马、眶额与前额叶皮层支持基于模型的控制；重放与学得的展开实现规划。
- 元强化学习（定义 41.6.1）用跨任务的慢学习建立任务内的快学习，如 Harlow 的学习定势；由多巴胺训练的前额叶皮层可能在其活动中实现一种学得的学习算法。

| 方法 | 学习对象 | 更新信号 | 神经解释 |
|---|---|---|---|
| REINFORCE | 策略 | $(G_t - b)\nabla\ln\pi$ | 随机神经元的奖赏调制可塑性；鸣唱学习中的节点扰动 |
| 行动者–评价者，A2C | 策略与 $v_\pi$ | 作为优势的 TD 误差 | 多巴胺送往背侧（行动者）与腹侧（评价者）纹状体 |
| PPO | 信任域内的策略 | 截断的优势加权比值 | 用于语言模型的 RLHF |
| 基于模型 | 模型，再通过规划得到价值 | 状态与奖赏的预测误差 | 海马、OFC、PFC；重放与展开 |
| 元强化学习 | 跨任务的权重，任务内的活动 | 权重上的慢强化学习；活动中的推断 | 由多巴胺训练的前额叶循环动力学 |

## 思考题

1. 对例 41.1.1 的混叠走廊，推导 $v(s_1)$ 作为 $p$ 的函数，并求其最大值。

   **答** 设 $v_1, v_2, v_3$ 为三个状态的值。智能体以概率 $p$ 向右：$v_1 = -1 + p v_2 + (1 - p)v_1$，$v_2 = -1 + p v_1 + (1 - p)v_3$（行动效果相反），$v_3 = -1 + (1 - p)v_2$（向右到达价值为 0 的目标）。第一式给出 $v_2 = v_1 + 1/p$，第三式给出 $v_3 = -1 + (1 - p)v_2$；代入第二式，$v_1 + 1/p = -1 + p v_1 + (1 - p)[-1 + (1 - p)(v_1 + 1/p)]$，解得 $v_1 = -\frac{2(2 - p)}{p(1 - p)}$。令导数为零得 $p^2 - 4p + 2 = 0$，所以 $p = 2 - \sqrt2 \approx 0.586$，$v_1 = -(6 + 4\sqrt2) \approx -11.66$。$p = 0.95$ 时的值为 $-44.2$，$p = 0.05$ 时为 $-82.1$。

2. 证明对得分为 $s(A) = \nabla\ln\pi(A)$（单个参数）的单步问题，使方差最小的常数基线为 $b^* = \mathbb{E}[R\,s(A)^2]/\mathbb{E}[s(A)^2]$，并对例 41.2.1 在 $\pi = 0.5$ 处计算它。

   **答** 估计量为 $g = (R - b)s(A)$，其均值与 $b$ 无关，所以最小化 $\operatorname{Var}(g)$ 就是最小化 $\mathbb{E}[(R - b)^2 s^2] = \mathbb{E}[R^2 s^2] - 2b\,\mathbb{E}[R s^2] + b^2\,\mathbb{E}[s^2]$，其最小值在 $b^* = \mathbb{E}[R s^2]/\mathbb{E}[s^2]$ 处：即以得分平方为权重的奖赏平均。在 $\pi = 0.5$ 处两个得分的绝对值都是 $0.5$，所以 $b^* = \mathbb{E}[R] = 5.5 = v_\pi$。当策略偏斜时，稀有行动的得分大，权重也大，所以 $b^*$ 向它们的奖赏移动。

3. 在命题 41.4.1 中，假设基线 $b$ 被换成依赖于神经元自身输出 $y$ 的量，例如 $b = c\,y$。更新还是无偏的吗？这对奖赏预测误差的生物学实现意味着什么？

   **答** 不再无偏。期望更新多出一项 $-\eta\,c\,\mathbb{E}[y(y - p)]x_j = -\eta\,c\,p(1 - p)x_j$，它不为零：它把权重驱向与奖赏无关的方向。基线不能依赖于其概率正被改变的那个行动。像多巴胺信号这样的全局预测误差，根据行动之前的状态（评价者的价值）计算，满足这一点；部分反映每个神经元自身放电的教学信号则会使学习产生偏差。这是预测应当由一个独立的评价者来计算的一条理由。

4. 在两步任务中，基于模型的智能体选择 $a_1$ 并经历罕见转移到状态 C 之后得到奖赏。解释它为什么现在更可能选择 $a_2$，而 $\lambda = 1$ 的无模型智能体为什么更可能选择 $a_1$。$\lambda = 0$ 的无模型智能体会怎么做？

   **答** 基于模型的智能体更新在 C 中所选选项的价值；由于 $a_2$ 以 0.7 的概率通向 C 而 $a_1$ 只有 0.3，规划得到的价值 $\sum_s P(s \mid a)\max_b \hat q(s, b)$ 对 $a_2$ 升高更多，所以它转换。$\lambda = 1$ 的无模型智能体把 $\hat q(a_1)$ 直接向奖赏更新，并重复 $a_1$。$\lambda = 0$ 时，$\hat q(a_1)$ 在收到奖赏之前向第二阶段价值 $\hat q(C, b)$ 更新，所以奖赏只在后来的试验中才影响第一阶段选择，即在它传播进 $\hat q(C, b)$、并在以后一次访问中传播进导致 C 的那个行动的第一阶段价值之后；这种效应延迟而且较弱，但仍不依赖于转移结构。

5. （开放题）元强化学习的解释主张多巴胺驱动的可塑性缓慢地训练前额叶皮层，而前额叶的活动学得很快。提出实验，把这一解释与另一种说法区分开：任务内的快速学习本身由前额叶皮层的突触可塑性实现。

   **答** 思路：分离时间尺度与基质。(i) 在一族老虎机或反转任务上训练动物直到它们表现出一次试验的适应；然后在新任务期间局部阻断前额叶皮层的突触可塑性（例如用 NMDA 受体拮抗剂或蛋白质合成阻断剂）。元强化学习的解释预测任务内的适应得以保留，因为它由活动承载，而学习一族新任务则受损；另一种说法预测相反。(ii) 在任务切换期间记录群体：元强化学习预测任务状态编码在持续活动中，这种活动在出乎意料的结果之后的那次试验上发生变化，并且扰动这种活动（在试验之间短暂光遗传沉默）应当抹去任务内的学习，而不影响之后在熟悉任务上的表现。(iii) 在漫长的训练阶段与新任务期间分别操纵多巴胺：元强化学习预测多巴胺对获得学习定势是必需的，而对已获得之后的任务内适应则不那么必需。(iv) 把循环网络模型与突触可塑性模型都拟合到神经数据上，比较各自对群体状态逐试验变化的预测程度。
