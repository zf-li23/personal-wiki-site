处于静息的神经元接受缓慢增大的电流，最终会开始发放。用 [7.16.6](/7.16.6) 的语言说，代表静息的稳定平衡点要么消失，要么失去稳定性，轨迹移向代表重复发放的极限环。动力系统理论的一个惊人事实是：对于依赖一个参数的系统，稳定平衡点这样做的一般方式只有四种。每一种在神经元的行为中都有自己的指纹：发放是从零频率还是从有限频率开始，静息与发放是否共存，是否存在阈下振荡。因此，决定神经元计算性质的是分岔，而不是离子电流的细节（Izhikevich 2007）。

本章对静息与发放之间的转变分类，然后用同样的工具解释*簇放电*，即脉冲簇与静息交替出现的现象，它是节律性运动模式、睡眠振荡和激素分泌的基础。平面上分岔的一般理论，包括 **Hopf 分岔**，见 [2.4.11](/2.4.11#sec-11.6.4) 和 [7.6.33](/7.6.33#sec-33.5.2)；这里所有的例子都使用 $I_{\mathrm{Na,p}} + I_{\mathrm{K}}$ 模型（[7.16.6](/7.16.6#sec-6.2) 的式 (6.2)），只是参数值不同。

## 7.1. 静息态的分岔

### 7.1.1. 失去稳定性的四种方式

当 Jacobi 矩阵的某个特征值穿过虚轴时，平衡点失去稳定性。单个实特征值穿过零，导致**鞍结分岔**：稳定结点与鞍点碰撞，两者都消失。一对复共轭特征值穿过虚轴，导致 **Andronov–Hopf 分岔**：平衡点仍然存在，但变成不稳定焦点，一个小振幅的**极限环**出现或消失。每种情形又按全局发生的事情分成两种（图 1）。

**定义 7.1.1（不变圆上的鞍结分岔）** **不变圆上的鞍结分岔**（SNIC）是这样一种鞍结分岔：稳定结点与鞍点位于由鞍点的不稳定流形构成的闭不变曲线上；当它们合并并消失时，该不变曲线变成极限环。

**定义 7.1.2（超临界与亚临界 Andronov–Hopf 分岔）** 在**超临界 Andronov–Hopf 分岔**中，稳定焦点变得不稳定，其周围产生一个稳定极限环，其振幅按到分岔距离的平方根从零增长。在**亚临界 Andronov–Hopf 分岔**中，围绕稳定焦点的一个不稳定极限环收缩到该焦点，焦点变得不稳定；轨迹随后跳到远处的吸引子。

四种情形可以从图 1 中读出：

1. *不变圆上的鞍结分岔*（子图 A，带高阈值 $\ce{K+}$ 电流的 $I_{\mathrm{Na,p}} + I_{\mathrm{K}}$ 模型）。静息与阈值在 $I = 4.51\,\mu\mathrm{A\,cm^{-2}}$ 处合并；穿过鞍点的不变圆就是未来的脉冲轨迹。恰在分岔之上，轨迹缓慢地通过已消失平衡点的幽灵，所以周期发散，**发放率**从零开始按 $\sqrt{I - I_{\mathrm{c}}}$ 上升（[7.16.6](/7.16.6) 的思考题 1）。
2. *不在不变圆上的鞍结*（子图 D，同一模型但 $\ce{K+}$ 电流更快，$\tau_n = 0.16\,\mathrm{ms}$）。结点与鞍点同样在 $I = 4.51$ 处合并，但远离它们已存在一个极限环，在 $I = 3.1$ 处产生；静息消失时，状态跳到这个环上，以有限频率发放。在 3.1 与 4.51 之间，静息与发放共存。
3. *超临界 Andronov–Hopf*（子图 B，低阈值 $\ce{K+}$ 电流）。静息焦点在 $I = 14.6$ 处失去稳定性；小振荡出现并连续地增长为脉冲。起始时的频率由特征值的虚部决定，在这个快速模型中约为 340 Hz。
4. *亚临界 Andronov–Hopf*（子图 C）。在 $I = 48.8$ 处一个不稳定环坍缩到静息焦点上，焦点变得不稳定，轨迹跳到大振幅的发放环，该环从 $I = 42.5$ 起向上与静息共存。

![$I_\mathrm{Na,p}+I_\mathrm{K}$ 模型中静息态的四种分岔。每个子图显示平衡点电压对注入电流的关系（实线：稳定；虚线：不稳定），并在神经元发放处显示极限环上 $V$ 的最大值和最小值（圆点），由从静息和从去极化状态出发的模拟得到。A：4.5 µA cm⁻² 处不变圆上的鞍结分岔：静息消失与发放出现发生在同一电流。B：14.6 µA cm⁻² 处的超临界 Andronov–Hopf 分岔：振荡幅度从零增长。C：48.8 µA cm⁻² 处的亚临界 Andronov–Hopf 分岔：大脉冲突然出现，并与稳定静息态共存直到 42.5 µA cm⁻²。D：4.5 µA cm⁻² 处不在不变圆上的鞍结（更快的 K⁺ 电流）：发放环从 3.1 µA cm⁻² 起就已存在，所以静息与发放共存](./plots/rest-bifurcations.py)

### 7.1.2. 指纹

这四种分岔有各不相同的实验特征，总结在下表中。在神经元中可以用三种测量来区分它们：起始附近的 f–I 曲线、对小脉冲的响应（阻尼振荡还是单调衰减），以及是否有滞后（短暂脉冲能否在同一电流下使细胞从静息转为发放并再转回）。

| 静息的分岔 | 分岔处的特征值 | 发放开始于 | 阈下振荡 | 静息与发放共存 |
|---|---|---|---|---|
| 不变圆上的鞍结分岔 | $\lambda = 0$ | 零频率 | 无 | 否 |
| 鞍结（不在圆上） | $\lambda = 0$ | 有限频率 | 无 | 是 |
| 超临界 Andronov–Hopf | $\lambda = \pm\mathrm{i}\omega$ | 有限频率，零振幅 | 有 | 否 |
| 亚临界 Andronov–Hopf | $\lambda = \pm\mathrm{i}\omega$ | 有限频率与有限振幅 | 有 | 是 |

在每种分岔附近，每个模型，不论其电流如何，（经变量替换后）都等价于一个只取决于分岔类型的*正规形*。对于鞍结，它是二次式 $\dot x = I + x^2$，这是 [7.16.8](/7.16.8#sec-8.3) 的二次整合发放神经元的来源；对于 Andronov–Hopf 分岔，它是复变量 $z$ 的 $\dot z = (\mu + \mathrm{i}\omega)z + \sigma z\lvert z\rvert^2$，$\sigma < 0$ 时为超临界，$\sigma > 0$ 时为亚临界。这种普适性是分类有用的原因：它能从一个定性的事实预测神经元在发放起始附近的响应。

## 7.2. 发放态的分岔

当电流再次减小时，发放极限环必然消失，这也以几种一般的方式发生：

- *不变圆上的鞍结分岔*：上述分岔的逆过程；周期按 $1/\sqrt{I - I_{\mathrm{c}}}$ 发散，速率趋于零。
- *超临界 Andronov–Hopf*：极限环收缩到平衡点；振幅趋于零，频率保持有限。
- *极限环的折叠*（环的鞍结）：稳定的发放环与不稳定环碰撞，两者都消失，此时振幅和频率都有限。它是亚临界 Andronov–Hopf 分岔的伴随分岔（图 1C，$I = 42.5$ 处）。
- *鞍点同宿轨*：环不断增大，直到接触鞍点，成为同宿轨道，即离开鞍点又回到它的轨迹。

**定义 7.2.1（鞍点同宿轨分岔）** 当极限环穿过鞍点平衡点、形成同宿于该鞍点的轨道时，发生**鞍点同宿轨分岔**；在分岔的另一侧，该环不再存在。由于轨迹在鞍点附近变慢，趋近分岔时环的周期按对数发散，$T \propto -\ln\lvert I - I_{\mathrm{h}}\rvert$。

同宿分岔解释了图 1 的子图 D：$I = 3.1$ 以上存在的环，是在它脱离鞍点时产生的。周期的对数发散比 SNIC 的平方根温和得多，所以速率只在极其接近分岔时才陡然下降。

当静息与发放的分岔发生在不同的电流时，二者在其间共存，神经元的状态取决于它的历史：这就是**滞后**。图 2A 以电流阶梯的形式展示了带亚临界 Andronov–Hopf 分岔的模型中的滞后：在 $45\,\mu\mathrm{A\,cm^{-2}}$ 时，神经元在上升过程中沉默，在下降过程中发放。在双稳范围内，短暂脉冲使神经元从静息转为发放，而在脉冲周期的适当相位给出的相同脉冲又使它关闭（图 2B），因为静息态的吸引域是由不稳定环围成的小区域（图 2C）。这种**双稳态**使单个神经元对其输入有短时记忆。例如具有持续内向电流的脊髓运动神经元中就出现这种现象（平台电位，[7.16.30](/7.16.30)），它还被提出作为工作记忆中持续活动的细胞基础（[7.16.45](/7.16.45)）。

![亚临界 Andronov–Hopf 分岔附近的双稳态（与图 1C 相同的模型）。A：电流阶梯（灰色，标签单位 µA cm⁻²）：在 45 时，神经元在上升过程中停留在静息，而在下降过程中继续发放；发放在 Hopf 点（48.8）以上开始，在极限环折叠点（42.5）以下停止。B：在恒定的 45 µA cm⁻² 下，短暂的去极化脉冲使神经元从静息转为发放，在适当相位的相同脉冲经由阻尼振荡使它转回静息。C：45 µA cm⁻² 时的相平面：稳定焦点（静息）被一个小的不稳定极限环（虚线）包围，该环是静息吸引域与大发放环吸引域之间的边界](./plots/hysteresis.py)

## 7.3. 神经计算类别

[7.16.6](/7.16.6) 引入的两种性质现在可以追溯到分岔上。神经元是**整合器**还是**共振器**（定义 6.5.1），取决于其静息态在分岔附近的特征值是实的（鞍结）还是复的（Andronov–Hopf）。它是单稳还是双稳，取决于静息的分岔是否与发放环的产生重合。因此四种分岔填满一张二乘二的表（Izhikevich 2007，第 7 章）：

| | 静息与发放共存（双稳） | 不共存（单稳） |
|---|---|---|
| 整合器（无阈下振荡） | 鞍结 | 不变圆上的鞍结 |
| 共振器（有阈下振荡） | 亚临界 Andronov–Hopf | 超临界 Andronov–Hopf |

Hodgkin 的类别（定义 6.4.1）是第三种、部分重叠的性质。只有 SNIC 给出 1 类兴奋性，即从零频率发放；其他三种给出 2 类。（发放环的鞍点同宿轨分岔也可以产生从接近零开始的速率，但这在神经元中很少见。）典型的皮层锥体神经元，1 类整合器，接近 SNIC；枪乌贼轴突和 HH 模型，双稳范围很窄的 2 类共振器，接近亚临界 Andronov–Hopf 分岔；快速发放的中间神经元常表现为 2 类共振器，或双稳范围很窄的 1 类神经元。使神经元在类别之间移动的电导，如 **A 电流**（[7.16.5](/7.16.5#sec-5.4)）或低阈值 $\ce{K+}$ 电流，是通过改变分岔来做到这一点的，而改变这些电导的神经调质可以切换神经元的计算类别。

**例 7.3.1（诊断分岔）** 向神经元注入缓慢的电流斜坡。发放在上升过程中从 3 Hz 开始，在下降过程中于同一电流停止；静息时的小脉冲产生单调的响应。该分岔是 SNIC：单稳（无滞后），整合器（无振荡），1 类（起始速率接近零）。若相反，发放从 40 Hz 开始，阈下有 40 Hz 的阻尼振铃，并且在下降过程中于较低电流停止，则该分岔是亚临界 Andronov–Hopf，可以预期该神经元对约 40 Hz 的输入有选择性响应。

## 7.4. 簇放电

### 7.4.1. 快–慢分解

许多神经元以簇的方式发放：由静息期隔开的脉冲簇（图 3A）。其决定性特征是两个时间尺度：快速的脉冲产生子系统（时间常数为毫秒）和使发放开启与关闭的慢变量（数十毫秒到数秒）。

**定义 7.4.1（簇放电与快–慢分解）** **簇放电**是神经元在重复发放与静息之间交替的动力学状态。快–慢簇放电器具有形式 $\dot{\boldsymbol{x}} = \boldsymbol{f}(\boldsymbol{x}, y)$，$\dot y = \mu\,g(\boldsymbol{x}, y)$，$\mu \ll 1$，其中 $\boldsymbol{x}$ 描述产生脉冲的电流，$y$ 是缓慢的电流或浓度。在**快慢分解**中，慢变量被冻结，作为快速子系统 $\dot{\boldsymbol{x}} = \boldsymbol{f}(\boldsymbol{x}, y)$ 的参数，然后由 $y$ 的缓慢漂移描绘该子系统对 $y$ 的分岔图。

要发生簇放电，快速子系统必须在 $y$ 的某个范围内同时具有稳定的静息态和发放环，而且慢变量必须使系统在这一范围内来回移动：发放把 $y$ 朝一个方向推，直到发放态丧失，静息又把它推回，直到静息丧失。因此，一次簇放电以快速子系统静息态的分岔开始，以其发放态的分岔结束，Izhikevich 就是用这一对分岔来命名簇放电的类型。静息的分岔有四种、发放的分岔有四种，在平面快速子系统中就有十六种"点–环"簇放电器；其中少数是常见的。

### 7.4.2. 折叠/同宿簇放电

带快速 $\ce{K+}$ 电流（$g_{\mathrm{K}} = 9$，$\tau_n = 0.152\,\mathrm{ms}$）的 $I_{\mathrm{Na,p}} + I_{\mathrm{K}}$ 模型，像图 1 的子图 D 一样，在一定电流范围内是双稳的。加上缓慢的 M 型 $\ce{K+}$ 电流 $g_{\mathrm{slow}}\,n_{\mathrm{s}}(V - E_{\mathrm{K}})$，$\tau_{\mathrm{slow}} = 20\,\mathrm{ms}$，就把它变成了簇放电器（图 3）。几何结构从子图 B 读出，其中慢门 $n_{\mathrm{s}}$ 是快速子系统的分岔参数：

- 快速子系统的平衡点构成一条 Z 形曲线。其下分支（静息）终止于折点，即 $n_{\mathrm{s}} = 0.0035$ 处的鞍结分岔。
- 发放环在 $n_{\mathrm{s}}$ 低于约 0.066 时存在，在中间分支上终止于鞍点同宿轨分岔。在 $0.0035 < n_{\mathrm{s}} < 0.066$ 时静息与发放共存。
- 静息期间 $V$ 较低，$n_{\mathrm{s}}$ 衰减，状态沿静息分支向左漂移，直到从折点掉下：簇开始。发放期间 $n_{\mathrm{s}}$ 随每个脉冲增大，直到环碰到鞍点：簇结束，状态落回静息分支。

因此，簇是由慢变量驱动的、快速子系统的一个滞后环。在 $I = 5\,\mu\mathrm{A\,cm^{-2}}$ 时，每个簇含九个脉冲，簇每 85 ms 重复一次。簇内的**峰间间隔**从 0.9 ms 增大到 2.1 ms，这是环趋近同宿分岔时的对数减慢（定义 7.2.1）。这种"折叠/同宿"模式，因其平台而又称方波簇放电，最先在胰腺 β 细胞模型中得到分析（Chay 和 Keizer 1983；Rinzel 1987）。

![$I = 5$ µA cm⁻² 时 $I_\mathrm{Na,p}+I_\mathrm{K}+I_\mathrm{K(M)}$ 模型中的折叠/同宿（方波）簇放电。A：膜电位（上）与慢 K⁺ 门 $n_\mathrm{s}$（下），后者在每个簇期间上升、在簇间衰减。B：快–慢分析。冻结 $n_\mathrm{s}$ 后，快速子系统有一条 Z 形平衡点曲线（实线：稳定静息；虚线：不稳定），在 $n_\mathrm{s}$ 较小时还有一个发放极限环（圆点：$V$ 的最大值与最小值）。簇的轨迹（细线）在其下拐点，即折叠（鞍结）分岔处离开静息分支，在 $n_\mathrm{s}$ 增大时发放，并在环终止于鞍点同宿轨分岔时停止](./plots/bursting.py)

### 7.4.3. 其他类型

另有三种类型很常见，已有经典名称。

| 类型（Izhikevich） | 经典名称 | 簇开始 / 结束于 | 特征 | 例子 |
|---|---|---|---|---|
| 折叠 / 同宿 | 方波 | 鞍结 / 鞍点同宿轨 | 双稳；簇内峰间间隔向末尾变长 | 胰腺 β 细胞、前包钦格神经元 |
| 圆 / 圆 | 抛物线型 | SNIC / SNIC | 簇内速率先升后降（峰间间隔呈抛物线）；需要两个慢变量 | 海兔（*Aplysia*）R15 神经元 |
| 亚 Hopf / 极限环折叠 | 椭圆型 | 亚临界 Andronov–Hopf / 极限环折叠 | 双稳；增长的阈下振荡启动簇，衰减的振荡跟随其后 | 啮齿类三叉神经中间神经元、背根神经节与中脑 V 神经元 |
| 折叠 / 圆 | 三角型 | 鞍结 / SNIC | 速率在簇末尾下降 | 丘脑皮层中继神经元模型 |

圆/圆簇放电器在平面快速子系统中不能由单个慢变量驱动，因为 SNIC 曲线不产生所需的双稳性；需要两个慢变量，其中一个振荡（在 R15 中，是缓慢的内向 $\ce{Ca^2+}$ 电流和 $\ce{Ca^2+}$ 激活的 $\ce{K+}$ 电流）。相反，椭圆型簇放电器是共振器：它们的簇可以由与阈下振荡同步的输入来启动或停止。经典名称指的是电压波形的形状，这并不可靠（许多亚 Hopf/极限环折叠簇放电器看起来并不呈椭圆形），所以优先使用按分岔命名的名称。

## 7.5. 生理学中的簇放电

*丘脑中继神经元。* T 型 $\ce{Ca^2+}$ 电流与 $I_{\mathrm{h}}$（[7.16.5](/7.16.5#sec-5.4)）的相互作用，在神经元超极化时产生 0.5–4 Hz 的节律性簇放电：$I_{\mathrm{h}}$ 缓慢地使细胞去极化，触发由 $\ce{Na+}$ 脉冲簇拥的低阈值 $\ce{Ca^2+}$ 脉冲；去极化使 $I_{\mathrm{h}}$ 去激活、$I_{\mathrm{T}}$ 失活，细胞超极化，$I_{\mathrm{h}}$ 重新激活，周期重复。脑干唤醒系统的神经调质（**乙酰胆碱**、**去甲肾上腺素**、**5-羟色胺**）使中继神经元去极化并移动 $I_{\mathrm{h}}$，在觉醒时把它们从簇放电模式切换到紧张模式（[7.16.35](/7.16.35)）。簇放电不只是睡眠现象：在清醒状态下，短暂超极化之后的簇以很高的可靠性标示刺激的起始，起到向皮层"唤醒"的作用。

*胰腺 β 细胞。* 在胰岛（[7.14.35](/7.14.35#sec-35.7)）的 β 细胞中，葡萄糖代谢提高 ATP/ADP 比值，关闭 $\mathrm{K_{ATP}}$ 通道，使细胞去极化进入方波簇放电状态，$\ce{Ca^2+}$ 脉冲位于持续数秒的平台上；平台期间进入的 $\ce{Ca^2+}$ 触发胰岛素分泌。慢变量是细胞内 $\ce{Ca^2+}$（作用于 $\ce{Ca^2+}$ 激活的 $\ce{K+}$ 通道）与 ATP/ADP 比值的组合。处于活动期的时间比例随葡萄糖增加，所以细胞用其平台比例编码葡萄糖浓度（Chay 和 Keizer 1983）。治疗 2 型糖尿病的磺脲类药物通过关闭 $\mathrm{K_{ATP}}$ 通道起作用，从而使细胞进一步移入簇放电状态。

*节律行为的起搏器。* 脑干中产生吸气节律的前包钦格复合体的神经元，经由带慢失活的持续 $\ce{Na+}$ 电流（以及 $\ce{Ca^2+}$ 激活的非选择性阳离子电流）发放簇，这是一种折叠/同宿机制，其中 $I_{\mathrm{Na,p}}$ 的慢失活是慢变量（Butera、Rinzel 和 Smith 1999）。这种内在簇放电为许多**中枢模式发生器**提供节律，在蟹的口胃神经节中，AB 神经元是条件性簇放电器，其簇放电取决于神经调质。簇放电神经元与交互抑制如何产生运动节律，是 [7.16.30](/7.16.30) 的主题。

簇携带信息的方式不同于单个脉冲。簇在释放概率低的突触上传递得更可靠，因为易化使簇中后面的脉冲变得有效（[7.16.12](/7.16.12)），它还可能以所含脉冲的个数编码刺激特征。簇也是突触可塑性的有力触发因素（[7.16.14](/7.16.14)）。

## 小结

- 稳定的静息态可以通过四种一般方式丧失：鞍结、不变圆上的鞍结、超临界与亚临界 Andronov–Hopf（定义 7.1.1 与 7.1.2）；发放环可以通过逆分岔、极限环折叠或鞍点同宿轨丧失（定义 7.2.1）。
- 分岔决定神经元的计算类别：整合器或共振器（实特征值或复特征值），单稳或双稳（分岔是否重合），1 类（只有 SNIC）或 2 类。

| | 双稳 | 单稳 |
|---|---|---|
| 整合器 | 鞍结 | SNIC（1 类） |
| 共振器 | 亚临界 Andronov–Hopf | 超临界 Andronov–Hopf |

- 双稳态产生滞后，使短暂脉冲能让神经元在静息与发放之间切换（图 2）。
- 簇放电是由慢变量驱动的快速子系统的滞后环（定义 7.4.1），按开始和结束簇的分岔命名：折叠/同宿（方波）、圆/圆（抛物线型）、亚 Hopf/极限环折叠（椭圆型）、折叠/圆。
- 丘脑中继神经元、β 细胞和呼吸起搏器经由不同的电流发放簇，但遵循同样的几何机制。

## 思考题

1. 在鞍点同宿轨分岔附近，环的周期近似为 $T \approx -\lambda_{\mathrm{u}}^{-1}\ln(I - I_{\mathrm{h}}) + T_0$，其中 $\lambda_{\mathrm{u}}$ 是鞍点的不稳定特征值。取 $\lambda_{\mathrm{u}} = 1$、$T_0 = 1$，比较 $I - I_{\mathrm{h}} = 10^{-2}$ 与 $10^{-4}$（以电流尺度为单位）时的速率，以及周期为 $\pi/\sqrt{I - I_{\mathrm{c}}}$ 的 SNIC 的速率。

   **答** 同宿：$T = \ln 100 + 1 = 5.6$ 和 $\ln 10^4 + 1 = 10.2$，速率为 $0.18$ 和 $0.10$。SNIC：$T = \pi/0.1 = 31$ 和 $\pi/0.01 = 314$，速率为 $0.032$ 和 $0.0032$。把距离缩小到 1/100，SNIC 的速率降低到十分之一，而同宿的速率降低不到一半；同宿的起始实际上是一个跳变，这就是它在实践中不算作 1 类的原因。

2. 某神经元在接通电流时以 15 Hz 周期性发放，静息时的小电流脉冲引起 12 Hz 的阻尼振荡。在发放期间的某个特定相位给出的短暂脉冲使神经元永久沉默。判断分岔类型与神经计算类别。

   **答** 静息时的阻尼振荡意味着稳定焦点：它是共振器，因此分岔属于 Andronov–Hopf 类型。脉冲可以在同一电流下使发放沉默，所以静息与发放共存：神经元是双稳的。该分岔是亚临界 Andronov–Hopf，而在有限频率（15 Hz，接近振荡频率）起始，使该神经元为 2 类。

3. 在图 3 的折叠/同宿簇放电器中，假设快速子系统的分岔图不变，预测 $\tau_{\mathrm{slow}}$ 加倍时每个簇的脉冲数和簇间间隔如何变化。

   **答** 快速子系统，因而折点（0.0035）和同宿分岔（0.066）处的 $n_{\mathrm{s}}$ 值，不依赖于 $\tau_{\mathrm{slow}}$。$\tau_{\mathrm{slow}}$ 加倍使 $n_{\mathrm{s}}$ 在发放期间上升、在静息期间衰减的速率减半。于是簇需要约两倍的时间把 $n_{\mathrm{s}}$ 从折点推到同宿点，所以它含有约两倍的脉冲（簇内速率几乎相同），沉默期也持续约两倍长。簇的周期与脉冲数都大致加倍。

4. （开放题）解释为什么当快速子系统是二维时，簇放电至少需要三个状态变量，并给出一个慢变量不是门控变量的生理例子。

   **答** 脉冲需要二维的快速子系统（一个放大变量和一个恢复变量，如 [7.16.6](/7.16.6)），静息与发放的交替至少需要一个使快速子系统穿过其双稳范围的慢变量，所以至少需要 $2 + 1 = 3$ 个变量。（平面系统不能产生簇放电：其轨迹不能相交，所以不能在不动点与环之间交替。）在胰腺 β 细胞和许多神经元中，慢变量是细胞内 $\ce{Ca^2+}$ 浓度，它在活动期上升并激活 $\ce{Ca^2+}$ 依赖的 $\ce{K+}$ 通道；在呼吸起搏器中，作用于 $\ce{Na+}/\ce{K+}$ 泵的细胞外或细胞内 $\ce{Na+}$ 浓度可以起同样的作用。
