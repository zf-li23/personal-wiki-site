## 17.1. 代谢的化学逻辑

### 17.1.1. 两条原则

两条化学原则解释了代谢中的大部分反应。第一，共价键可以用两种方式断裂。均裂中每个原子保留一个电子，产生**自由基**；异裂在生物化学中常见得多，其中一个原子保留两个电子。C–C 键和 C–H 键的异裂产生**碳负离子**和**碳正离子**，或一个质子和一个氢负离子；碳和氢的这三种阴离子与阳离子都极不稳定，代谢化学的许多内容就是避免它们的各种技巧。第二，大多数反应是**亲核试剂**（富电子的基团：羟基、氨基、硫醇盐、咪唑、碳负离子）与**亲电试剂**（缺电子的中心：羰基碳、磷酸的磷、质子化的亚胺碳、$\ce{H+}$）的结合；碳原子既可以是亲核的，也可以是亲电的，取决于它的邻居。

### 17.1.2. 五类反应

Lehninger 把活细胞中的反应分为五类。它们并不互相排斥（异构化可以经由自由基进行），但 7.1.18–7.1.29 的通路中几乎每一步都属于其中之一。

| 类别 | 发生什么 | 细胞怎样使之可能 | 实例 |
|---|---|---|---|
| 形成或断裂 C–C 键 | C–C 键的异裂或形成 | 反应碳旁边的羰基（或亚胺，或辅酶）稳定碳负离子；良好的离去基团（$\mathrm{PP_i}$）产生碳正离子 | 醛缩酶（**羟醛反应**）、柠檬酸合酶和硫解酶（**Claisen 缩合**）、β-酮酸的**脱羧**、羧化反应（生物素、**核酮糖-1,5-二磷酸羧化酶/加氧酶**）、异戊烯基转移酶（碳正离子） |
| 内部重排、异构化、消除 | 电子重新分布而总氧化态不变 | **广义酸碱催化**；烯二醇和烯醇负离子中间体 | 磷酸己糖异构酶（醛糖 ⇌ 酮糖）、磷酸丙糖异构酶、变位酶、顺反异构酶、脱水（烯醇化酶、延胡索酸酶、顺乌头酸酶） |
| 自由基反应 | 均裂 | 由辅酶或金属引发、并保持在**活性部位**内的自由基 | 辅酶 $\mathrm{B_{12}}$ 变位酶、自由基 SAM 酶、**核糖核苷酸还原酶**（7.1.28）、**DNA** 光解酶 |
| 基团转移 | 酰基、糖基或磷酰基从一个亲核试剂传给另一个 | 由良好的离去基团（磷酸、焦磷酸、硫酯）活化；亲核取代 | 激酶与磷酸酶、酰基转移酶、糖基转移酶、**转氨酶**（7.1.22） |
| 氧化与还原 | 失去或得到电子 | 通用的电子载体（**NAD**、**NADP**、**FAD**、**FMN**；[7.1.16](/7.1.16#sec-16.5)） | 脱氢酶、氧化酶、加氧酶、还原酶 |

形成和断裂 C–C 键。羰基的碳是亲电的，羰基还通过把电荷离域为**烯醇负离子**，稳定相邻碳上的碳负离子。三类 C–C 反应利用了这一点：羟醛反应（及其逆反应，即**糖酵解**的醛缩酶步骤）、Claisen 缩合（其中碳负离子由相邻的硫酯稳定，如柠檬酸的合成，[6.5.22](/6.5.22#sec-22.10.2)），以及脱羧（其中 $\ce{CO2}$ 离去时形成的碳负离子由相隔两个原子的羰基稳定，如乙酰乙酸脱羧酶，7.1.21）。质子化的**亚胺**（Schiff 碱）是比羰基更强的电子汇，这就是为什么 I 类醛缩酶和**转醛醇酶**以 Schiff 碱的形式与 Lys **残基**结合其**底物**（7.1.18），也是磷酸吡哆醛起作用的原因（17.2.3）。金属离子和广义酸进一步增强羰基的吸电子能力。整条通路都围绕着把羰基放在合适的位置而组织，以便下一个 C–C 键能被形成或断裂：葡萄糖在裂解之前先异构化为果糖（7.1.18），**脂肪酸**在硫解裂解之前先在 β 碳上被氧化（7.1.21）。碳正离子较少见；它们由**类异戊二烯**合成的异戊烯基转移酶反应中焦磷酸的离去产生（7.1.26）。

重排与消除。在葡萄糖 6-磷酸异构化为果糖 6-磷酸的反应中，C-1 被还原（醛变为醇），C-2 被氧化（醇变为酮），经过烯二醇中间体，酶的两个可电离基团分别作广义酸和广义碱；整个分子既未被氧化也未被还原。从醇上消除水引入 C=C 键（烯醇化酶、延胡索酸酶）；水加到 C=C 键上则是其逆反应。

自由基反应。自由基机理曾被认为很罕见，现在发现它们出现在不可能有极性机理的地方：在相邻碳上交换氢原子和一个基团的重排（辅酶 $\mathrm{B_{12}}$，17.2.5）、核糖核苷酸还原为脱氧核糖核苷酸，以及由"自由基 SAM"酶从 S-腺苷甲硫氨酸产生的 5′-脱氧腺苷自由基引发的许多反应。

基团转移。酰基转移通过亲核试剂加到羰基碳上进行，生成**四面体中间体**（**亲核酰基取代**；[7.1.8](/7.1.8#sec-8.4.1) 的胰凝乳蛋白酶机理是一例）。糖基转移是在异头碳，即缩醛碳上的取代。磷酰基转移是在磷上的同线取代，经过五价共价的过渡态（[7.1.16](/7.1.16#sec-16.3.4)）。一个普遍的主题是活化：—OH 这样不好的离去基团在取代之前被转变为好的离去基团（磷酸、焦磷酸、AMP、辅酶 A 硫酯）。

氧化与还原。许多生物氧化是脱氢，其中两个电子和两个质子被移走并传给 NAD⁺ 或 FAD；大多数分解代谢通路的能量就是在这样的步骤中释放的（[7.1.16](/7.1.16#sec-16.4)）。

### 17.1.3. 反复出现的三步反应序列

有一个三步反应序列出现在至少三条核心通路中：把羰基旁边的亚甲基氧化为新的羰基，

$$
\ce{-CH2-CH2-} \xrightarrow{\text{FAD}} \ce{-CH=CH-} \xrightarrow{\ce{H2O}} \ce{-CH(OH)-CH2-} \xrightarrow{\ce{NAD+}} \ce{-C(=O)-CH2-}.
$$
它构成**柠檬酸循环**的最后三步（琥珀酸 → 延胡索酸 → 苹果酸 → 草酰乙酸，7.1.20）和 **β 氧化**每一圈的四步中的前三步，之后由硫解酶切割 β-酮硫酯（7.1.21）；脂肪酸的合成以相反的方向运行同一序列，两次还原都以 NADPH 为还原剂（7.1.26）。它的化学解释了电子受体的选择：第一次氧化，即饱和 C–C 键的氧化，还原电势接近 0 V（延胡索酸/琥珀酸为 $+0.031\,\mathrm{V}$），对还原 $\ce{NAD+}$ 来说太正（$\Delta_{\mathrm{r}}G'^{\circ} \approx +68\,\mathrm{kJ\,mol^{-1}}$），由结合的 FAD 的电势与底物接近的**黄素蛋白**催化；第三次，即仲醇的氧化，还原性已足以使用 $\ce{NAD+}$（[7.1.16](/7.1.16#sec-16.5.2)）。

![反复出现的三步氧化。上：一般序列，其中羰基（或硫酯）β 位的亚甲基变成羰基：黄素蛋白（FAD → FADH₂）使 –CH₂–CH₂– 脱氢成反式双键，双键水合，再由依赖 NAD⁺ 的脱氢酶把羟基氧化成酮。各列：柠檬酸循环（琥珀酸 → 延胡索酸 → 苹果酸 → 草酰乙酸；琥珀酸脱氢酶、延胡索酸酶、苹果酸脱氢酶）、脂酰辅酶 A 的 β 氧化（脂酰辅酶 A 脱氢酶、烯酰辅酶 A 水合酶、β-羟脂酰辅酶 A 脱氢酶）以及脂肪酸合成，后者在酰基载体蛋白上反向运行这一序列，两次还原都以 NADPH 为还原剂](./plots/recurring-reactions.py)

### 17.1.4. 生化方程式与酶的名称

生物化学家把方程式写成物种之和。ATP + $\ce{H2O}$ → ADP + $\mathrm{P_i}$ 中的"ATP"代表在给定 pH 和 $[\ce{Mg^2+}]$ 下存在的 $\ce{ATP^4-}$、$\ce{HATP^3-}$、$\ce{MgATP^2-}$ 和其他形式的混合物；这样的生化方程式使 C、N、O 和 P 配平，但不配平 H、Mg 和电荷，其 $K'$ 取决于 pH 和 $[\ce{Mg^2+}]$（[7.1.16](/7.1.16#sec-16.2.1)）。化学方程式 $\ce{ATP^4- + H2O -> ADP^3- + HPO4^2- + H+}$ 使每个原子和电荷都配平，讨论机理时应使用它。遵循 Lehninger，除了以机理为主题的地方，我们使用生化方程式。

酶的命名遵循值得一次学会的约定（Lehninger 第 8 版，框 13-1）：

| 名称 | 反应 | 实例 |
|---|---|---|
| 激酶 | 磷酰基从核苷三磷酸转移到受体上 | 己糖激酶、PEP 羧激酶、**蛋白激酶** |
| 磷酸酶 | 磷酰基的水解脱除（水进攻） | 果糖 1,6-二磷酸酶、**蛋白磷酸酶** |
| 磷酸化酶 | **磷酸解**：由 $\mathrm{P_i}$ 进攻使键断裂，$\mathrm{P_i}$ 被连上 | **糖原磷酸化酶**（葡萄糖 1-磷酸） |
| 合酶 / 合成酶 | 不用 / 用核苷三磷酸作能源的缩合 | 柠檬酸合酶 / 琥珀酰辅酶 A 合成酶 |
| 连接酶 | 利用 ATP（或 NAD）的能量把两个分子连接；合成酶是连接酶 | **DNA 连接酶** |
| 裂合酶 | 通过消除（或其逆反应，加成），而不是水解或氧化，实现裂解 | 醛缩酶、延胡索酸酶、丙酮酸脱羧酶 |
| 变位酶、异构酶、差向异构酶 | 分子内的基团转移；异构化；在一个立体中心的翻转 | 磷酸甘油酸变位酶；磷酸丙糖异构酶；UDP-葡萄糖 4-差向异构酶 |
| 脱氢酶 | 以 NAD⁺、NADP⁺ 或 FAD 为受体（不是 $\ce{O2}$）的氧化 | 乳酸脱氢酶 |
| 氧化酶 | 以 $\ce{O2}$ 为受体的氧化，O 不并入产物 | **细胞色素氧化酶**、**黄嘌呤氧化酶** |
| 加氧酶（单、双） | $\ce{O2}$ 的一个或两个 O 原子并入产物 | **细胞色素 P-450** 单加氧酶、**环加氧酶** |
| 羧化酶 / 脱羧酶 | 加上 / 去除 $\ce{CO2}$ | 丙酮酸羧化酶（生物素）/ 丙酮酸脱羧酶（TPP） |
| 转氨酶 / 酰胺转移酶 | 氨基的转移（PLP）/ Gln 酰胺 N 的转移 | 天冬氨酸转氨酶 / 谷氨酰胺–**5-磷酸核糖-1-焦磷酸**酰胺转移酶 |

许多酶保留了它们最初被测定的反应的名称，即使它们在细胞中向相反的方向工作：丙酮酸激酶把磷酰基从 PEP 转移给 ADP，而乳酸脱氢酶通常还原丙酮酸。

## 17.2. 辅酶与维生素

### 17.2.1. 维生素与辅酶表

氨基酸侧链可以起酸、碱和亲核试剂的作用，但它们不能携带氢负离子，不能稳定脱羧的酮酸的碳负离子，也不能转移单碳单元。这些工作由**辅酶**完成，辅酶是与酶结合、每次周转之后再生的有机**辅因子**（[7.1.3](/7.1.3)、[7.1.8](/7.1.8#sec-8.1.2)）。大多数辅酶参与范围狭窄的一组相关反应，所以一种酶的辅酶常常是了解其化学的好线索。动物已丧失合成其中许多种的能力，必须从膳食中获得它们的前体。

**定义 17.2.1（维生素）** **维生素**是动物膳食中少量需要的有机化合物，因为动物不能合成足够的量。水溶性维生素（B 族维生素和维生素 C）大多是辅酶的前体；脂溶性维生素（A、D、E、K）分别是发色团、激素、抗氧化剂和辅因子的前体（[7.1.12](/7.1.12#sec-12.5.4)）。

### 17.2.2. 酰基与醛的载体：辅酶 A、硫辛酸与 TPP

**定义 17.2.2（辅酶 A）** **辅酶 A**（CoA、CoA-SH）由 β-巯基乙胺、泛酸（维生素 $\mathrm{B_5}$）和 3′-磷酸-ADP 组成；它末端的巯基与酰基形成硫酯，如乙酰辅酶 A。

```smiles
CC(C)(COP(=O)([O-])OP(=O)([O-])OC[C@H]1O[C@@H](n2cnc3c(N)ncnc32)[C@H](O)[C@@H]1OP(=O)([O-])[O-])[C@@H](O)C(=O)NCCC(=O)NCCS CoA-SH
```

硫酯以两种方式活化酰基（[7.1.16](/7.1.16#sec-16.3.3)、[6.5.22](/6.5.22#sec-22.10.2)）：羰基碳是好的亲电试剂，带有好的离去基团硫醇盐（酰基转移；乙酰辅酶 A 水解的 $\Delta_{\mathrm{r}}G'^{\circ}$ 为 $-31.4\,\mathrm{kJ\,mol^{-1}}$）；而且 α-氢的酸性比氧酯的更强，所以 α 碳可以成为亲核试剂（Claisen 缩合）。连在 Ser 残基上的同样的磷酸泛酰巯基乙胺臂构成脂肪酸合成的**酰基载体蛋白**（7.1.26）。腺苷部分不起化学作用；它是结合的把手（[7.1.11](/7.1.11#sec-11.5)）。

**定义 17.2.3（硫辛酸）** **硫辛酸**（lipoic acid，6,8-二硫辛酸）是以酰胺键结合在 Lys 残基上的辅酶（硫辛酰胺），其环状二硫键接受两个电子，还原后的二硫醇接受酰基；它是 α-酮酸脱氢酶复合体的摆臂。

```smiles
O=C(O)CCCC[C@@H]1CCSS1 lipoate
```

**定义 17.2.4（硫胺素焦磷酸）** **硫胺素焦磷酸**（TPP，硫胺素二磷酸）是硫胺素（维生素 $\mathrm{B_1}$）的辅酶形式；它的噻唑鎓环上位于 N 与 S 之间的碳 C-2 去质子成为碳负离子（叶立德）后，加到羰基上，带正电的环稳定了先前羰基旁边的 C–C 键断裂时形成的碳负离子。

```smiles
Cc1ncc(C[n+]2csc(CCOP(=O)([O-])OP(=O)([O-])[O-])c2C)c(N)n1 TPP
```

TPP 解决了断裂羰基碳与相邻碳之间的键的问题，例如 α-酮酸的脱羧，那里没有相隔两个原子的羰基来稳定正在形成的电荷。噻唑鎓环的 C-2 质子酸性异常强，因为相邻的带正电的 N 和 S 原子稳定叶立德。叶立德进攻丙酮酸的酮羰基碳；$\ce{CO2}$ 离去，电子流入环中，生成共振稳定的烯胺（羟乙基-TPP，"活性乙醛"）。这一中间体随后被质子化并释放乙醛（丙酮酸脱羧酶，7.1.18），或被氧化并把它的二碳单元转移给硫辛酰胺（丙酮酸脱氢酶，7.1.20），或加到醛糖上（转酮醇酶，7.1.18）。在每种情形中，TPP 都以亲核试剂的身份携带醛基，这使羰基碳通常的亲电反应性反转（"极性反转"，umpolung）。

![丙酮酸脱羧（丙酮酸脱羧酶）中的硫胺素焦磷酸。噻唑鎓环的 C-2 碳负离子（叶立德）进攻丙酮酸的羰基碳；在加合物中 C–COO⁻ 键断裂，电子流入带正电的噻唑鎓环（它起电子汇的作用），生成烯胺羟乙基-TPP 和 CO₂。质子化和乙醛的释放使叶立德再生。R 和 R′ 是氨基嘧啶和焦磷酰乙基取代基](./plots/tpp-decarboxylation.py)

### 17.2.3. 磷酸吡哆醛

**定义 17.2.5（磷酸吡哆醛）** **磷酸吡哆醛**（PLP）是维生素 $\mathrm{B_6}$ 的辅酶形式，在静息的酶中以 Schiff 碱（内醛亚胺）的形式与 Lys 的 ε-氨基结合；氨基酸底物取代 Lys 形成外醛亚胺，其中质子化的吡啶环对 α 碳上的反应起电子汇的作用。

```smiles
Cc1ncc(COP(=O)([O-])[O-])c(C=O)c1O PLP
```

PLP 是用途最广的辅酶。在外醛亚胺中，氨基酸 α 碳上的三个键（与 H、羧基或侧链相连的键）中的任何一个都可以断裂，因为产生的碳负离子离域到吡啶鎓环中（醌型中间体）。哪个键断裂由酶决定，酶使该键垂直于共轭体系的平面，使它与 π 体系重叠（Dunathan 假说）。C–H 键断裂导致**转氨基作用**（7.1.22）和消旋；C–$\ce{COO-}$ 键断裂导致脱羧（**生物胺**，7.1.27）；C–R 键断裂导致羟醛型的裂解（丝氨酸羟甲基转移酶）。在糖原磷酸化酶中，PLP 起完全不同的作用：它的磷酸基起广义酸的作用（7.1.19）。按 EC 分类的所有酶活性中，约 4 % 依赖 PLP。

### 17.2.4. 单碳单元的载体：生物素、四氢叶酸与 S-腺苷甲硫氨酸

代谢使用三种单碳基团的载体，对应三种氧化水平。

**定义 17.2.6（生物素）** **生物素**（维生素 $\mathrm{B_7}$）是以酰胺键连接在羧化酶的 Lys 残基上（生物胞素）的辅酶；它以羧基的形式把由 ATP 活化为羧基磷酸的 $\ce{CO2}$ 携带在其脲基环的 N-1′ 上，这是氧化程度最高的单碳单元。

```smiles
O=C(O)CCCC[C@@H]1SC[C@@H]2NC(=O)N[C@H]12 biotin
```

依赖生物素的羧化酶在两个活性位点上分两个半反应工作：用碳酸氢盐和 ATP 使生物素羧化，以及把羧基转移给底物（丙酮酸、乙酰辅酶 A、丙酰辅酶 A）。约 1.4 nm 长的生物素酰-Lys 臂在两个位点之间携带 $\ce{CO2}$。蛋清含有抗生物素蛋白，它结合生物素的 $K_{\mathrm{d}} \approx 10^{-15}\,\mathrm{M}$，是已知最强的**非共价相互作用**之一（因此吃很多生鸡蛋后会出现生物素缺乏，实验室也有生物素–链霉亲和素标签）。

**定义 17.2.7（四氢叶酸）** **四氢叶酸**（THF，$\mathrm{H_4}$folate）是叶酸（维生素 $\mathrm{B_9}$）的辅酶形式，由还原的蝶呤、对氨基苯甲酸和一个或多个谷氨酸残基构成；它在 N-5、N-10 或二者上携带单碳单元，氧化水平相当于甲醇（甲基）、甲醛（亚甲基）和甲酸（甲酰基、亚氨甲基、次甲基）。

```smiles
Nc1nc2c(c(=O)[nH]1)N[C@@H](CNc1ccc(cc1)C(=O)N[C@@H](CCC(=O)O)C(=O)O)CN2 THF
```

THF 上的单碳单元通过氧化和还原（用 NADP）相互转化，并用于嘌呤、胸苷酸、甲硫氨酸以及丝氨酸/甘氨酸的合成（7.1.27–7.1.28）。由于 DNA 合成需要叶酸，它的**拮抗剂**（甲氨蝶呤，一种**二氢叶酸还原酶**的抑制剂）是抗癌药物，阻断细菌叶酸合成的磺胺类药物是抗生素；缺乏引起巨幼细胞贫血，在妊娠期引起神经管缺陷，这就是许多国家在面粉中强化叶酸的原因。

**定义 17.2.8（S-腺苷甲硫氨酸）** **S-腺苷甲硫氨酸**（SAM、AdoMet）由甲硫氨酸和 ATP 通过把腺苷基转移到硫上形成（三个磷酸全部以 $\mathrm{P_i}$ 和 $\mathrm{PP_i}$ 的形式释放）；它的锍离子使甲基成为强亲电试剂，SAM 是几乎所有生物甲基化的供体。

```smiles
C[S+](CC[C@H](N)C(=O)O)C[C@H]1O[C@@H](n2cnc3c(N)ncnc32)[C@H](O)[C@@H]1O SAM
```

甲基从 SAM 转移给亲核试剂（DNA 碱基的 O、N、S 或 C 原子，**组蛋白**的 Lys，儿茶酚胺）比从 $\mathrm{N^5}$-甲基-THF 转移快得多（SAM 作为甲基供体的反应性高约 1000 倍）。产物 S-腺苷高半胱氨酸被水解为高半胱氨酸，后者由甲硫氨酸合酶利用甲基-THF 和辅酶 $\mathrm{B_{12}}$ 重新甲基化（活化的甲基循环，7.1.22）。在自由基 SAM 酶中，还原的铁硫簇使 SAM 裂解为甲硫氨酸和 5′-脱氧腺苷自由基，后者在 100 000 多个已知的蛋白质序列中启动自由基反应。

### 17.2.5. 辅酶 B12

**定义 17.2.9（钴胺素）** **钴胺素**（维生素 $\mathrm{B_{12}}$）是咕啉环，中心钴离子被二甲基苯并咪唑核苷酸配位；在其辅酶形式中，钴通过 Co–C 键结合一个 5′-脱氧腺苷基（5′-脱氧腺苷钴胺素，辅酶 $\mathrm{B_{12}}$）或一个甲基（甲基钴胺素）。

腺苷钴胺素的 Co–C 键很弱（键解离能约 $130\,\mathrm{kJ\,mol^{-1}}$），在活性部位中均裂为 $\ce{Co^{2+}}$ 和 5′-脱氧腺苷自由基，后者从底物上夺取一个氢原子；底物自由基发生重排（一个基团移到相邻的碳上），并把氢夺回去。甲基丙二酰辅酶 A 变位酶就是这样在奇数碳脂肪酸的氧化中把甲基丙二酰辅酶 A 转变为琥珀酰辅酶 A 的（7.1.21）。在甲硫氨酸合酶中，甲基钴胺素以异裂的方式转移其甲基，留下的 $\ce{Co^+}$ 是很强的亲核试剂，从甲基-THF 取走下一个甲基。$\mathrm{B_{12}}$ 只由细菌和古菌制造；人类从动物性食物中获得它，并借助胃的内因子吸收它。吸收失败（恶性贫血，通常是自身免疫性的）或没有补充剂的严格素食，会导致巨幼细胞贫血（因为叶酸被困在甲基-THF 中）和神经损伤。它含有 180 多个原子的结构由 Dorothy Hodgkin 用 X 射线晶体学解出（1964 年诺贝尔奖）。

脂溶性维生素已在讲**脂质**时介绍（[7.1.12](/7.1.12#sec-12.5.4)）：维生素 A 是**视紫红质**的发色团视黄醛（7.1.14），又是**激素**视黄酸；维生素 D 是激素骨化三醇的前体，维生素 E 是膜抗氧化剂，维生素 K 是凝血因子 γ-羧化的辅因子（[7.1.9](/7.1.9#sec-9.5.5)）。维生素 C（抗坏血酸）是还原剂，而不是基团的载体。

```smiles
OC[C@H](O)[C@H]1OC(=O)C(O)=C1O ascorbate
```

## 17.3. 代谢通路的调节

### 17.3.1. 通路、通量与稳态

把代谢分成通路是为了方便；在细胞中，每条通路都通过共同的代谢物与许多其他通路相连。肝细胞中的葡萄糖 6-磷酸可以通过糖酵解降解，在**磷酸戊糖途径**中氧化，作为**糖原**储存，水解为葡萄糖而输出，或转变为其他糖用于**糖基化**；每次以某种方式利用它的"决定"都会改变通过所有其他途径的流量。

**定义 17.3.1（代谢途径、代谢通量与定向步骤）** **代谢途径**是一系列酶催化的反应，其中一个反应的产物是下一个反应的底物，从确定的起始化合物导向确定的产物；其中间体是代谢物。稳态下通过一条途径的**代谢通量** $J$ 是底物转变为产物的净速率（以单位体积或单位质量组织的 $\mathrm{mol\,s^{-1}}$ 计），等于每一步的净速率。途径的**定向步骤**是在细胞条件下基本不可逆、且其产物除了该途径之外别无他用的第一个反应。

在稳态下，每个中间体的形成与消耗速率相同，所以它的浓度保持恒定，而通过它的通量可以变化许多倍：在**动态稳态**（[7.1.1](/7.1.1#sec-1.3.1)）中，无论从肠道摄取、肝脏释放和组织利用的速率如何，血糖都保持在约 5 mM。区分代谢调节和代谢控制是有用的：前者在通量变化时使某个量（浓度）保持恒定，后者响应外部信号改变途径的输出。二者依赖相同的分子机制；任何一种失败都是许多疾病的基础，其中最常见的是葡萄糖稳态的失败，即**糖尿病**（7.1.29）。约 12 % 的人类**基因**编码调节蛋白，其中有 500 多种蛋白激酶。

### 17.3.2. 调节的层次与时间尺度

酶催化的反应的速率是酶分子数目与每个分子活性的乘积，二者都可以改变。这些机制的差别首先在于速度。

### 17.3.3. 近平衡与远离平衡的步骤

并非通路的每一步都能控制其通量。考虑一步 S ⇌ P，单向速率为 $J_{+}$（正向）和 $J_{-}$（逆向），净速率为 $J = J_{+} - J_{-}$。对任何酶催化的反应，单向通量之比（可以用同位素示踪测量）由它的实际 Gibbs 能决定（[7.1.16](/7.1.16#sec-16.2.2)）：

**公式 17.3.1（通量–力关系）**

$$
\frac{J_{-}}{J_{+}} = \frac{Q}{K'} = \mathrm{e}^{\Delta_{\mathrm{r}}G/RT}, \qquad \frac{J}{J_{+}} = 1 - \mathrm{e}^{\Delta_{\mathrm{r}}G/RT}. \tag{17.1}
$$
在 $37\,^\circ\mathrm{C}$ 时，$\Delta_{\mathrm{r}}G = -2\,\mathrm{kJ\,mol^{-1}}$ 的步骤以其正向速率的 46 % 逆向进行，所以它的净通量只有正向通量的一半；$\Delta_{\mathrm{r}}G = -20\,\mathrm{kJ\,mol^{-1}}$ 的步骤 $J_{-}/J_{+} = 4 \times 10^{-4}$，实际上是不可逆的。实际上，$Q$ 与 $K'$ 相差在一到两个数量级之内，或 $\lvert\Delta_{\mathrm{r}}G\rvert$ 小于几 kJ mol⁻¹ 的步骤，称为近平衡的。

这两类步骤的行为不同。近平衡步骤的酶通常容量远大于通量；它的净速率是两个大的单向速率之间的小差值，随其底物或产物浓度的任何变化而变化。它把相邻步骤强加的通量，不论哪个方向，都传递下去，所以它不可能是设定通量的地方（它的通量控制系数很小，17.4）。远离平衡的步骤受其酶活性的限制，其速率对产物浓度不敏感，改变其酶的活性就会改变通过通路的通量。因此，受调节的酶催化远离平衡的反应，通路在需要它们的地方有这样的酶：在定向步骤、在**分支点**，以及在必须防止通量逆转的任何地方。

### 17.3.4. 相反的通路与底物循环

一条通路与它的逆向通路（糖酵解与**糖异生**，脂肪酸氧化与合成，糖原分解与合成）共用其近平衡的步骤，但在不可逆的步骤使用不同的酶，使每个方向都放能。在每一对这样的步骤上，两种酶都存在于同一个细胞中。

**定义 17.3.2（底物循环）** 由不同的酶催化的一对相反的不可逆反应，如果糖 6-磷酸 + ATP → 果糖 1,6-二磷酸 + ADP（PFK-1）和果糖 1,6-二磷酸 + $\ce{H2O}$ → 果糖 6-磷酸 + $\mathrm{P_i}$（FBPase-1），构成**底物循环**；它的净结果是 ATP 的水解。当它的运行没有代谢目的时，称为无效循环。

细胞对底物循环的两种酶进行相互调节，使同一个信号激活一个而抑制另一个（AMP 和**果糖-2,6-二磷酸**激活 PFK-1 并抑制 FBPase-1，7.1.18–7.1.19）；否则 ATP 就会作为热而浪费。尽管如此，适度的循环速率仍是有用的，因为它放大净通量的灵敏度。设正向速率为 $v_{\mathrm{f}}$，逆向速率为 $v_{\mathrm{r}}$，净通量为 $J = v_{\mathrm{f}} - v_{\mathrm{r}}$。使 $v_{\mathrm{f}}$ 增加、$v_{\mathrm{r}}$ 减少相同分数 $a$ 的效应物，使 $J$ 改变

$$
\frac{\Delta J}{J} = a\,\frac{v_{\mathrm{f}} + v_{\mathrm{r}}}{v_{\mathrm{f}} - v_{\mathrm{r}}}, \tag{17.2}
$$
所以当 $v_{\mathrm{r}} = 0.8\,v_{\mathrm{f}}$ 时，每种酶活性 10 % 的变化使净通量改变 90 %。代价是循环所水解的 ATP，在某些情况下所释放的热得到了利用（熊蜂的飞行肌；棕色脂肪使用另一种机制，7.1.23）。定量模型见 [7.1.19](/7.1.19)。区室化是分开相反通路的另一种方式：脂肪酸在线粒体基质中氧化，在胞质溶胶中合成，两个烟酰胺核苷酸库保持在不同的氧化还原状态（[7.1.16](/7.1.16#sec-16.5.1)）。

### 17.3.5. 腺嘌呤核苷酸与能荷

除了保护 DNA 之外，对细胞来说也许没有什么比持续供应 ATP 更重要了。许多利用 ATP 的酶对 ATP 的 $K_{\mathrm{M}}$ 值为 0.1 到 1 mM，而典型细胞中的 [ATP] 为 2 到 10 mM。因此 [ATP] 的大幅下降会同时降低数百个反应的速率（动力学效应），也会降低磷酸化势（热力学效应，[7.1.16](/7.1.16#sec-16.3.2)）。腺嘌呤核苷酸是代谢中最重要的别构效应物之一，这并不奇怪。

Atkinson（1968）仿照电池的电量，提出了描述腺苷酸库能量状态的单一数值。

**定义 17.3.3（能荷）** 腺苷酸系统的**能荷**为

$$
\mathrm{EC} = \frac{[\mathrm{ATP}] + \tfrac12[\mathrm{ADP}]}{[\mathrm{ATP}] + [\mathrm{ADP}] + [\mathrm{AMP}]}, \tag{17.3}
$$
即每个腺嘌呤核苷酸的磷酸酐键数除以二；它的范围从 0（全部为 AMP）到 1（全部为 ATP）。

大多数细胞使能荷保持在约 0.8 到 0.95 之间。Atkinson 观察到酶对它的两类响应。产生 ATP 的（分解代谢）序列的酶，如 PFK-1 和丙酮酸激酶，随 EC 升高而受抑制（R 型，代表再生，regenerating）；利用 ATP 的（生物合成）序列的酶则被激活（U 型，代表利用，utilizing）。两条曲线在工作范围附近陡峭地相交，使能荷得到稳定：如果它下降，ATP 的产生加快，ATP 的消耗减慢。

AMP 是比 ATP 更灵敏的指标。**腺苷酸激酶**使反应 2 ADP ⇌ ATP + AMP 保持近平衡（$K' = [\mathrm{ATP}][\mathrm{AMP}]/[\mathrm{ADP}]^2 \approx 1$；[7.1.16](/7.1.16#sec-16.3.5)），所以

$$
[\mathrm{AMP}] = K'\,\frac{[\mathrm{ADP}]^2}{[\mathrm{ATP}]}. \tag{17.4}
$$
由于 [ATP] 是 [ADP] 的几倍，二者又都远大于 [AMP]，[ATP] 的一个小的分数下降 $\delta$（腺苷酸总量不变）使 [ADP] 增加约 $1 + \delta[\mathrm{ATP}]/[\mathrm{ADP}]$ 倍，使 [AMP] 增加约该因子的平方。当 [ATP]/[ADP] = 10 时，ATP 下降 10 % 使 [ADP] 几乎加倍，使 [AMP] 增加约四倍；游离 ATP 与游离 ADP 之比越高，放大越大。这就是细胞能量的主要传感器，即 **AMP 活化蛋白激酶**（7.1.29），响应 AMP（和 ADP）的原因，也是 AMP 激活肌肉中 PFK-1 和糖原磷酸化酶的原因。氧化还原比值 $[\ce{NAD+}]/[\mathrm{NADH}]$ 和 $[\ce{NADP+}]/[\mathrm{NADPH}]$、乙酰辅酶 A 和柠檬酸是燃料状态的其他常见信号。

![腺苷酸系统。A：ATP、ADP 和 AMP 的比例对能荷（定义 17.3.3）的曲线，腺苷酸激酶处于平衡（K′ = 1）；阴影带是大多数细胞维持的范围。B：R 型酶（在再生 ATP 的通路中；一种在调节位点被 ATP 抑制、被 AMP 激活的 MWC 酶）和 U 型酶（在利用 ATP 的通路中；对 ATP 呈 Michaelis–Menten 型、ADP 为竞争性抑制剂）对能荷的模型响应；参数仅为示意，参照 Atkinson 的曲线。C：腺苷酸激酶对 AMP 信号的放大：总腺苷酸恒定时，[AMP] 的增加倍数对 [ATP] 的分数下降的曲线，初始 [ATP]/[ADP] 之比为 5、10 和 30](./plots/energy-charge.py)

## 17.4. 代谢控制分析

### 17.4.1. 限速步骤及其问题

人们长期以来认为每条通路都有一个限速酶，通常是第一个定向步骤，仅它的活性就决定通量。这一假设预言，过量生产该酶应使通量成比例地增加。当 Schaaff、Heinisch 和 Zimmermann（1989）在酵母中使磷酸果糖激酶，即糖酵解的"限速酶"，以及其他糖酵解酶过表达几倍时，生成乙醇的糖酵解通量没有改变。对许多通路也得到了类似的结果。通量的控制通常由几个步骤分担，并且在条件变化时可以从一步转移到另一步。由 Kacser 和 Burns（1973）以及 Heinrich 和 Rapoport（1974）分别提出的代谢控制分析（metabolic control analysis），简称 MCA使这一点精确化。

**定义 17.4.1（通量控制系数与弹性系数）** 对于通量为 $J$ 的稳态通路，酶 $i$ 的**通量控制系数**是该酶浓度（活性）$E_i$ 的小的分数变化所引起的通量的分数变化，其余一切自由调整：

$$
C^{J}_{i} = \frac{\partial\ln J}{\partial\ln E_i}.
$$
酶 $i$ 的速率 $v_i$ 对代谢物 S 的**弹性系数**是在所有其他浓度保持不变时，[S] 的分数变化所引起的 $v_i$ 的分数变化：

$$
\varepsilon^{v_i}_{\mathrm{S}} = \frac{\partial\ln v_i}{\partial\ln[\mathrm{S}]}.
$$

通量控制系数是整个系统的性质：它说明在所有其他酶存在时，通量在多大程度上依赖于一种酶。弹性是一种酶的局部性质，可以由它的速率方程算出：对远离平衡的 Michaelis–Menten 酶，$\varepsilon^{v}_{\mathrm{S}} = K_{\mathrm{M}}/(K_{\mathrm{M}} + [\mathrm{S}])$，介于 1（不饱和）和 0（饱和）之间；产物或反馈抑制剂给出负的弹性；近平衡的酶有很大的弹性，因为由公式 17.3.1，它的净速率正比于 $1 - Q/K'$，并随 $Q$ 的微小变化而大幅变化。经典意义上的"限速酶"就是 $C^J_i \approx 1$ 的酶。

### 17.4.2. 定理

有两个定理把整体系数与局部系数联系起来。它们对每个速率都正比于其酶浓度的任何通路成立。

**定理 17.4.1（加和定理）** 一条通路中所有酶的通量控制系数之和为一：

$$
\sum_i C^{J}_{i} = 1.
$$

**证明** 把所有酶的浓度都乘以同一个因子 $\lambda$。每个速率都乘以 $\lambda$；满足稳态条件（所有速率相等）的代谢物浓度仍然满足，所以不变，而通量变为 $\lambda J$。因此 $J$ 是酶浓度的一次齐次函数，由齐次函数的 Euler 定理得 $\sum_i E_i\,\partial J/\partial E_i = J$，这就是所要的结论。$\square$

**定理 17.4.2（连通性定理）** 对通路的每个代谢物 S，

$$
\sum_i C^{J}_{i}\,\varepsilon^{v_i}_{\mathrm{S}} = 0.
$$

**证明**（概要） 使酶浓度改变小的分数 $\delta_i = \varepsilon^{v_i}_{\mathrm{S}}\,\delta$，其选取使得，如果 [S] 同时下降分数 $\delta$，则每个速率保持不变：$\delta_i$ 对 $v_i$ 的直接效应被 [S] 变化的效应 $-\varepsilon^{v_i}_{\mathrm{S}}\delta$ 抵消。于是 [S] 降低 $\delta$ 的原状态是受扰系统的一个通量不变的稳态，所以 $\Delta\ln J = \sum_i C^J_i\delta_i = \delta\sum_i C^J_i\varepsilon^{v_i}_{\mathrm{S}} = 0$。$\square$

对由酶 1 和酶 2 构成的两步通路 X → S → P，这两个定理给出 $C^J_1 + C^J_2 = 1$ 和 $C^J_1\varepsilon^{v_1}_{\mathrm{S}} + C^J_2\varepsilon^{v_2}_{\mathrm{S}} = 0$，因此

$$
C^{J}_{1} = \frac{\varepsilon^{v_2}_{\mathrm{S}}}{\varepsilon^{v_2}_{\mathrm{S}} - \varepsilon^{v_1}_{\mathrm{S}}}, \qquad C^{J}_{2} = \frac{-\varepsilon^{v_1}_{\mathrm{S}}}{\varepsilon^{v_2}_{\mathrm{S}} - \varepsilon^{v_1}_{\mathrm{S}}}. \tag{17.5}
$$
由于 S 是酶 1 的产物（$\varepsilon^{v_1}_{\mathrm{S}} \le 0$）和酶 2 的底物（$\varepsilon^{v_2}_{\mathrm{S}} > 0$），两个系数都在 0 和 1 之间。经典的限速步骤是酶 1 对其产物不敏感（$\varepsilon^{v_1}_{\mathrm{S}} = 0$）的特殊情形：此时 $C^J_1 = 1$，第二个酶没有控制作用。如果酶 1 近平衡，$\lvert\varepsilon^{v_1}_{\mathrm{S}}\rvert$ 就很大，它的控制系数很小，这是 17.3.3 的陈述的定量形式。所以控制是按弹性分布的，而弹性取决于浓度；它不是酶的固定性质。

### 17.4.3. 一个数值例子

考虑从固定的源 $\mathrm{X_0}$（1 mM）经过两个中间体到汇 $\mathrm{X_3}$（0.01 mM）的三步通路，每一步由一个可逆的 Michaelis–Menten 酶催化，

$$
v_i = e_i\,\frac{(V_i/K_{\mathrm{S},i})\,([\mathrm{S}_{i-1}] - [\mathrm{S}_i]/K'_i)}{1 + [\mathrm{S}_{i-1}]/K_{\mathrm{S},i} + [\mathrm{S}_i]/K_{\mathrm{P},i}}, \qquad \mathrm{X_0} \xrightarrow{v_1} \mathrm{S_1} \xrightarrow{v_2} \mathrm{S_2} \xrightarrow{v_3} \mathrm{X_3},
$$
其中 $e_i$ 是酶 $i$ 的相对量（参考状态下为 1）。第一个酶（$V_1 = 2\,\mathrm{mM\,s^{-1}}$，$K'_1 = 10$）提供中间体，第二个酶快且近平衡（$V_2 = 10$，$K'_2 = 5$），第三个酶消耗 $\mathrm{S_2}$（$V_3 = 3$，$K'_3 = 100$）；所有 $K_{\mathrm{S}} = 0.5\,\mathrm{mM}$，$K_{\mathrm{P}} = 1\,\mathrm{mM}$。在第二个版本中，通路供应分支的终产物 $\mathrm{S_2}$ 别构地抑制第一个酶，$v_1 \to v_1/(1 + ([\mathrm{S_2}]/K_{\mathrm{I}})^4)$，$K_{\mathrm{I}} = 0.1\,\mathrm{mM}$（**反馈抑制**，[7.1.9](/7.1.9#sec-9.5.1)）。用 `fsolve`（[4.4.4](/4.4.4)）数值求解稳态方程 $v_1 = v_2 = v_3$，并使每个 $e_i$ 改变一个小的分数，得到控制系数：

| | $C^J_1$（供应） | $C^J_2$（近平衡） | $C^J_3$（需求） | $\sum C^J_i$ |
|---|---|---|---|---|
| 无反馈 | 0.89 | 0.04 | 0.07 | 1.00 |
| 酶 1 受 $\mathrm{S_2}$ 的**反馈抑制** | 0.26 | 0.004 | 0.74 | 1.00 |

![三步通路的代谢控制分析（17.4.3）。A：通路 X₀ → S₁ → S₂ → X₃，带有酶 1（供应）、近平衡的酶 2 和酶 3（需求）；虚线抑制弧是第二个版本中 S₂ 对酶 1 的反馈抑制。B 和 C：一种酶的量从其参考值的 0.25 倍变到 4 倍时，相对于参考状态的稳态通量（对数坐标），无反馈（B）和有反馈（C）；每条曲线在参考点（圆圈）处的斜率就是通量控制系数。D：两个版本中的通量控制系数；每组之和为一（加和定理）。反馈抑制使大部分通量控制从供应酶转移到需求酶，而近平衡的酶在两种情形下几乎都没有控制作用](./plots/mca-linear-pathway.py)

由此得到三点启示。两种情形下控制系数之和都为一，如定理 17.4.1 所要求。近平衡的酶几乎没有控制作用，无论使它变大还是变小。而且反馈抑制并不使被抑制的酶成为"限速"酶；它起相反的作用：当第一个酶被终产物抑制时，它的量的任何增加都使 $[\mathrm{S_2}]$ 升高，从而再次抑制它，大部分控制转移到消耗 $\mathrm{S_2}$ 的酶上。

### 17.4.4. 供应与需求

这个例子可以推广。Hofmeyr 和 Cornish-Bowden（2000）提出把代谢当作由一个中间体（ATP、氨基酸、NADPH）连接的供应块与需求块的经济体来分析。连接中间体对供应块的反馈抑制使供应响应需求：通量由需求块控制，受调节的供应酶的作用是使中间体的浓度保持恒定（稳态），而不是设定通量。按照这一观点，ATP 和 AMP 对 PFK-1 的别构调节（7.1.18）使糖酵解通量与 ATP 消耗速率相匹配，同时使 [ATP] 几乎保持恒定，而过表达 PFK-1 几乎没有改变，是因为通量由细胞的 ATP 需求决定。酵母和肌肉糖酵解中控制系数的实验估计确实把大部分控制放在葡萄糖运输、己糖激酶和 ATP 消耗上，而放在 PFK-1 上的相对较少。

MCA 有实际的后果：在代谢工程中，要增加通向某种产物的通量，通常必须同时提高几种酶的活性，或解除反馈并增加需求，而不是过表达"关键酶"；抑制控制系数小的酶的药物，必须几乎完全抑制它，通量才会下降。更大的网络、分支通路以及外部效应物的响应系数（$R^J_X = C^J_i\,\varepsilon^{v_i}_X$，即组合响应定理）见[系统生物学](/7.9)。

## 思考题

1. 把每个反应归入五类之一，并说出辅酶（如果有）：(a) α-酮戊二酸 → 琥珀酰辅酶 A + $\ce{CO2}$；(b) 3-磷酸甘油酸 → 2-磷酸甘油酸；(c) 谷氨酸 + 丙酮酸 → α-酮戊二酸 + 丙氨酸；(d) 甲基丙二酰辅酶 A → 琥珀酰辅酶 A；(e) 乙酰辅酶 A + $\ce{HCO3-}$ + ATP → **丙二酸单酰 CoA**。

   **答** (a) 氧化脱羧：C–C 键断裂与氧化相结合；TPP、硫辛酸、辅酶 A、FAD 和 NAD（α-酮戊二酸脱氢酶）。(b) 内部重排（基团转移），由以 2,3-二磷酸甘油酸为辅因子的变位酶催化，没有维生素衍生的辅酶。(c) 氨基的基团转移；PLP。(d) 自由基重排；辅酶 $\mathrm{B_{12}}$。(e) C–C 键的形成（羧化）；生物素。
2. 解释为什么乙酰乙酸的脱羧需要相隔两个碳的羰基，而丙酮酸这种 α-酮酸的脱羧需要 TPP。

   **答** $\ce{CO2}$ 离去时，C–C 键的电子对留在碳上。在乙酰乙酸（β-酮酸）中，这个碳与酮羰基相邻，所以电荷离域成烯醇负离子，反应容易进行。在丙酮酸中，离去的羧基直接连在羰基碳上；电子会留在羰基碳本身上，生成不稳定的酰基负离子。TPP 加到羰基上，把它转变为与噻唑鎓环相连的碳；$\ce{CO2}$ 留下的电子于是离域到带正电的环中（烯胺），所以 TPP 起了缺失的 β 羰基的作用。
3. 通路的某一步在 $37\,^\circ\mathrm{C}$ 时 $\Delta_{\mathrm{r}}G = -1.5\,\mathrm{kJ\,mol^{-1}}$，净通量为 $1\,\mathrm{\mu mol\,g^{-1}\,min^{-1}}$。它的正向和逆向单向通量各是多少？如果这个酶的量加倍，你预计通路的通量会怎样？

   **答** $J_{-}/J_{+} = \mathrm{e}^{-1.5/2.58} = 0.56$，所以由 $J = J_{+}(1 - 0.56)$ 得 $J_{+} = 2.27$，$J_{-} = 1.27\,\mathrm{\mu mol\,g^{-1}\,min^{-1}}$。酶加倍会使这一步更接近平衡（两个单向通量都增加，其底物和产物的浓度略作调整），通路的通量几乎不变：近平衡的酶的通量控制系数接近零（17.4.2）。
4. 计算 [ATP] = 5.0、[ADP] = 0.5、[AMP] = 0.05 mM 的细胞的能荷。如果 $K' = 1$，腺苷酸激酶处于平衡吗？如果 ATP 降到 4.5 mM，总量不变，腺苷酸激酶处于平衡，估算 [ADP] 和 [AMP]。

   **答** EC = (5.0 + 0.25)/5.55 = 0.946。$[\mathrm{ATP}][\mathrm{AMP}]/[\mathrm{ADP}]^2 = 5.0 \times 0.05/0.25 = 1.0$：处于平衡。当 [ATP] = 4.5、[ADP] + [AMP] = 1.05 时：$4.5[\mathrm{AMP}] = [\mathrm{ADP}]^2$，所以 $[\mathrm{ADP}]^2 + 4.5[\mathrm{ADP}] - 4.725 = 0$，$[\mathrm{ADP}] = 0.88\,\mathrm{mM}$，$[\mathrm{AMP}] = 0.17\,\mathrm{mM}$。ATP 下降 10 % 使 ADP 升高 1.8 倍，AMP 升高 3.5 倍。
5. 在一条两步通路中，酶 1 对其产物 S 的弹性为 $-0.5$，酶 2 对其底物 S 的弹性为 $0.25$。计算通量控制系数。如果酶 1 变得对 S 完全不敏感，它们会怎样变化？

   **答** 由式 (17.5)，$C^J_1 = 0.25/(0.25 + 0.5) = 1/3$，$C^J_2 = 0.5/0.75 = 2/3$。当 $\varepsilon^{v_1}_{\mathrm{S}} = 0$ 时：$C^J_1 = 1$，$C^J_2 = 0$；于是酶 1 在经典意义上是限速的，因为下游的任何东西都不能对它反馈。
6. （开放题）一家公司想使某种细菌的一种氨基酸产量加倍，该细菌中通路的第一个酶受到产物的反馈抑制。利用 17.4 的思想，比较三种策略：(a) 使第一个酶过表达十倍，(b) 引入第一个酶的抗反馈突变体，(c) 在 (b) 的基础上增加产物的输出（需求）。

   **答** 思路：(a) 反馈保持完好时，额外的酶被累积的产物抑制，其通量控制系数很小（如 17.4.3 的例子），通量增加很少。(b) 抗反馈的酶消除了对产物的负弹性；控制回到第一个酶，所以它的活性现在能提高通量，但产物在细胞内积累，其他步骤或输出可能成为限制，并可能出现有毒的浓度。(c) 把解除调节的供应与增加的需求（输出或汇）结合起来，使变化分布在整条通路上，这与加和定理一致：大幅度增加通量需要几个步骤协调变化。工业赖氨酸和谷氨酸生产菌（*Corynebacterium glutamicum*）就是这样发展起来的；这一策略可以在动力学模型上通过计算每种修饰前后的控制系数来检验。
