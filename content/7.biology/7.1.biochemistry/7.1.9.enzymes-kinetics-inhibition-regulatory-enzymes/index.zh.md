上一章解释了酶如何实现其速率增强（[7.1.8](/7.1.8)）；本章说明它在给定条件下工作得有多快，以及这一速率如何受到控制。理论的核心是在物理化学中发展出来的：用**稳态近似**导出的 **Michaelis–Menten 方程** $v_0 = v_{\max}[\ce{S}]/(K_{\mathrm{M}} + [\ce{S}])$，以及其中的**米氏常数** $K_{\mathrm{M}}$、**催化常数** $k_{\mathrm{cat}} = v_{\max}/[\ce{E}]_{\mathrm{t}}$ 和**专一性常数** $k_{\mathrm{cat}}/K_{\mathrm{M}}$、**Lineweaver–Burk 作图**，以及用**非线性回归**拟合的理由，全都见 [6.3.17](/6.3.17#sec-17.3.5)。我们不再推导它们，而是像生物化学家那样使用：解释动力学参数，区分有两个**底物**的机理，对抑制剂分类（大多数药物是酶抑制剂），并描述决定**代谢途径**速率的调节**酶**。变构酶使用与血红蛋白相同的**协同模型**（[7.1.7](/7.1.7#sec-7.3.5)）；共价修饰与级联通向**信号转导**（[7.1.14](/7.1.14)、[7.1.15](/7.1.15)），定量上则通向系统生物学（[7.9](/7.9)）。第二部分（[7.1.17](/7.1.17) 起）各条途径中的每一个调节步骤，都是 9.5 中机制的实例。

## 9.1. 稳态动力学的应用

### 9.1.1. 初速度与进程曲线

动力学测量反应速率如何依赖于实验参数：酶、底物、产物、抑制剂和调节物的浓度，pH 以及温度。它是研究酶机理最古老的方法，至今仍是确定底物结合顺序、寻找有效抑制剂和理解调节的途径。

**定义 9.1.1（初速度）** 酶催化反应的**初速度** $v_0$ 是 $t = 0$ 附近产物形成的速率，此时底物浓度基本上仍是 $[\ce{S}]_0$，产物浓度还低到逆反应或产物抑制可以忽略。

在固定的酶浓度下测量几个 $[\ce{S}]$ 处的 $v_0$，得到 [6.3.17](/6.3.17#sec-17.3.5) 的双曲线型饱和曲线。在更长的时间内，速率随底物的消耗而下降，整条进程曲线含有同样的信息。

**公式 9.1.1（积分形式的 Michaelis–Menten 方程）** 如果 Michaelis–Menten 方程在整个反应中都成立（$-\mathrm{d}[\ce{S}]/\mathrm{d}t = v_{\max}[\ce{S}]/(K_{\mathrm{M}} + [\ce{S}])$，无产物抑制，不可逆反应），则

$$
v_{\max}t = [\ce{S}]_0 - [\ce{S}] + K_{\mathrm{M}}\ln\frac{[\ce{S}]_0}{[\ce{S}]}, \qquad [\ce{S}](t) = K_{\mathrm{M}}\,W\!\left(\frac{[\ce{S}]_0}{K_{\mathrm{M}}}\exp\frac{[\ce{S}]_0 - v_{\max}t}{K_{\mathrm{M}}}\right),
$$
其中 $W$ 是 Lambert $W$ 函数，即 $x \mapsto x\mathrm{e}^{x}$ 的反函数（Schnell 和 Mendoza，1997）。

第一种形式由分离变量 $\left(1 + K_{\mathrm{M}}/[\ce{S}]\right)\mathrm{d}[\ce{S}] = -v_{\max}\,\mathrm{d}t$ 得到；第二种由记 $u = [\ce{S}]/K_{\mathrm{M}}$，使 $u\,\mathrm{e}^{u} = ([\ce{S}]_0/K_{\mathrm{M}})\,\mathrm{e}^{([\ce{S}]_0 - v_{\max}t)/K_{\mathrm{M}}}$ 得到。只要其假设成立，用 `scipy.optimize.curve_fit`（[4.4.4](/4.4.4)）把进程曲线拟合到公式 9.1.1，就可以从一次实验估计 $v_{\max}$ 和 $K_{\mathrm{M}}$；但在实践中初速度仍是标准的，要在底物反应不到约 5–10% 时测量。

![A：由积分速率定律（公式 9.1.1）得到的 Michaelis–Menten 酶的进程曲线，[S]₀ = 0.5、2 和 8 K_M；浓度以 K_M 为单位，时间以 K_M/v_max 为单位。t = 0 处的虚线切线的斜率是初速度；曲线随底物被消耗而偏离它们，[S]₀ 低时更快。B：两种催化同一反应、v_max 相同的同工酶：低 K_M 的形式（像线粒体乙醛脱氢酶 ALDH2，K_M 取 0.2 µM）和高 K_M 的形式（像胞质的 ALDH1A1，50 µM；示意值）。在 1 µM 乙醛时，前者以其能力的 83 % 工作，后者只有 2 %](./plots/progress-curves.py)

### 9.1.2. $K_{\mathrm{M}}$ 与 $k_{\mathrm{cat}}$ 的含义

$K_{\mathrm{M}}$ 总是 $v_0 = v_{\max}/2$ 时的底物浓度，已知它时，被填充的**活性部位**的比例为 $f_{\mathrm{ES}} = [\ce{S}]/(K_{\mathrm{M}} + [\ce{S}])$。但它在机理上的意义取决于机理本身。对于两步方案，$K_{\mathrm{M}} = (k_{-1} + k_2)/k_1$。当 $k_2 \ll k_{-1}$ 时，它化为 ES 的**解离常数** $K_{\mathrm{d}} = k_{-1}/k_1$（**前平衡近似**），只有此时它才是亲和力的度量；当 $k_2 \gg k_{-1}$ 时，$K_{\mathrm{M}} \approx k_2/k_1$；ES 之后有更多步骤时，它成为许多速率常数的复杂函数。

同样，$k_{\mathrm{cat}}$ 是饱和时速控步的速率常数。对于产物释放缓慢的 $\ce{E + S <=> ES <=> EP -> E + P}$，饱和时大部分酶是 EP，$k_{\mathrm{cat}} = k_3$；对有酰基–酶的胰凝乳蛋白酶，$k_{\mathrm{cat}} = k_2k_3/(k_2 + k_3)$（公式 8.4.1）；当几个步骤部分地起速控作用时，$k_{\mathrm{cat}}$ 结合了它们的速率常数。典型值（Lehninger 第 8 版，表 6-6 至 6-8）：

| 酶 | 底物 | $K_{\mathrm{M}}$ / mM | $k_{\mathrm{cat}}$ / $\mathrm{s^{-1}}$ | $k_{\mathrm{cat}}/K_{\mathrm{M}}$ / $\mathrm{M^{-1}\,s^{-1}}$ |
|---|---|---|---|---|
| 己糖激酶（脑） | ATP / D-葡萄糖 / D-果糖 | 0.4 / 0.05 / 1.5 | | |
| 胰凝乳蛋白酶 | 甘氨酰酪氨酰甘氨酸 / *N*-苯甲酰酪氨酰胺 | 108 / 2.5 | | |
| β-半乳糖苷酶 | D-乳糖 | 4.0 | | |
| 过氧化氢酶 | $\ce{H2O2}$ | 1100 | $4\times10^{7}$ | $4\times10^{7}$ |
| 碳酸酐酶 | $\ce{CO2}$ / $\ce{HCO3-}$ | 12 / 26 | $1\times10^{6}$ / $4\times10^{5}$ | $8.3\times10^{7}$ / $1.5\times10^{7}$ |
| 乙酰胆碱酯酶 | 乙酰胆碱 | 0.09 | $1.4\times10^{4}$ | $1.6\times10^{8}$ |
| β-内酰胺酶 | 苯青霉素 | 0.02 | $2.0\times10^{3}$ | $1\times10^{8}$ |
| 延胡索酸酶 | 延胡索酸 | 0.005 | $8\times10^{2}$ | $1.6\times10^{8}$ |
| RecA（一种 ATP 酶） | ATP | | 0.5 | |

单独哪一个参数都不能度量催化效率。两种 $k_{\mathrm{cat}}$ 相同的酶所催化的反应，其无催化速率可以相差几个数量级；而 $K_{\mathrm{M}}$ 往往与底物在细胞中的浓度相近，作用于稀有底物的酶则较低。最好的度量是 $k_{\mathrm{cat}}/K_{\mathrm{M}}$，即 $\ce{E + S -> E + P}$ 在低 $[\ce{S}]$ 时表观的二级速率常数。它不能超过酶与底物靠扩散相遇的速率，约 $10^8$–$10^9\,\mathrm{M^{-1}\,s^{-1}}$（**扩散控制反应**，[6.3.17](/6.3.17#sec-17.1.3)），达到这一极限的酶（表的最后几行，磷酸丙糖异构酶、巴豆酸酶）已达到催化的完美：它们只受底物到达速度的限制。$k_{\mathrm{cat}}$ 和 $K_{\mathrm{M}}$ 的不同组合可以给出相同的最大比值。

教科书常说生理条件下 $[\ce{S}]/K_{\mathrm{M}}$ 在 0.01 到 1 之间。对 *E. coli* 中代谢物绝对浓度的直接测量表明这并不是普遍规律：对大多数底物–酶对，底物浓度高于 $K_{\mathrm{M}}$，只有下段糖酵解的中间物（其反应接近平衡）浓度与消耗它们的酶的 $K_{\mathrm{M}}$ 相近（Bennett 等，2009）。接近饱和的酶充分利用了酶蛋白，但对底物的响应较弱；在 $[\ce{S}] \lesssim K_{\mathrm{M}}$ 处，速率仍几乎与底物浓度成比例，使途径的通量能跟随底物的供应。无论哪种情形，$K_{\mathrm{M}}$ 都是衡量底物浓度的尺度，这就是它具有生理意义的原因。

### 9.1.3. 同工酶：乙醛脱氢酶与饮酒脸红

**定义 9.1.2（同工酶）** **同工酶**是通常由不同基因编码、催化同一反应的不同蛋白质；它们在动力学参数、调节、组织分布或亚细胞定位上有所不同。

乙醇在肝脏中被氧化为乙醛，高浓度的乙醛引起面部潮红、心率加快和恶心；乙醛通常被乙醛脱氢酶（ALDH）立即氧化为乙酸。人类在这一步有两种主要的同工酶：线粒体形式 ALDH2，对乙醛的 $K_{\mathrm{M}}$ 低于 $1\,\mu\mathrm{M}$；以及胞质形式 ALDH1A1，$K_{\mathrm{M}}$ 为几十微摩尔或更高。在适度饮酒后达到的低乙醛浓度下，只有 ALDH2 接近其能力工作（9.1.1 的图，B 部分）。世界人口中约 8%，多数在东亚，携带 *ALDH2\*2* 等位基因（Glu504Lys），其产物几乎没有活性，而且由于该酶是四聚体，在杂合子中还毒害正常的**亚基**。在这些人中，乙醛必须积累到高 $K_{\mathrm{M}}$ 的胞质形式能够清除它的程度，于是出现饮酒脸红反应；积累的乙醛是致癌物，也使他们饮酒时患食管癌的风险增加。

## 9.2. 双底物反应

### 9.2.1. 序列机制与乒乓机制

近三分之二的酶促反应有两个底物和两个产物（"bi bi"反应），通常是把基团从一个底物转移给另一个，或氧化一个同时还原另一个；己糖激酶（ATP 和葡萄糖）就是例子。每个底物都有自己的 $K_{\mathrm{M}}$（9.1.2 的表），底物结合与产物离开的顺序决定了动力学机理。

**定义 9.2.1（序列机制与乒乓机制）** 在**序列机制**中，两个底物都先结合到酶上，然后才释放任何产物，形成三元复合物；结合可以是有序的（底物 A 必须先结合，B 才能有效结合，往往因为 A 诱导产生了 B 的位点的构象），也可以是随机的。在**乒乓机制**（双置换机制）中，第一个底物发生反应，其产物离开之后第二个底物才结合：基团从 A 转移到酶上，得到修饰的酶形式 F，再从 F 转移到 B，所以 A 和 B 从不在酶上相遇。

| 机理 | 方案（Cleland 记号） | 实例 |
|---|---|---|
| 有序序列 | $\ce{E ->[A] EA ->[B] EAB <=> EPQ ->[-P] EQ ->[-Q] E}$ | 乳酸脱氢酶和乙醇脱氢酶（**烟酰胺腺嘌呤二核苷酸**，即 NADH 或 $\ce{NAD+}$ 先结合） |
| 随机序列 | A 和 B 以任意顺序结合；P 和 Q 以任意顺序离开 | 肌酸激酶、哺乳动物己糖激酶 |
| 乒乓 | $\ce{E ->[A] EA <=> FP ->[-P] F ->[B] FB <=> EQ ->[-Q] E}$ | **转氨酶**（以酶–磷酸吡哆胺为 F，[7.1.22](/7.1.22)）、**核苷二磷酸激酶**（磷酸化 His）、与酯和水反应的胰凝乳蛋白酶 |

在 Cleland 记号中，底物按结合顺序记为 A、B、C，产物按释放顺序记为 P、Q、R，修饰的酶形式记为 F、G。

### 9.2.2. 速率方程与诊断作图

**公式 9.2.1（双底物速率定律）** 在稳态下，取初速度且无产物存在，

$$
\text{sequential:}\quad v_0 = \frac{v_{\max}[\ce{A}][\ce{B}]}{K_{\mathrm{iA}}K_{\mathrm{B}} + K_{\mathrm{B}}[\ce{A}] + K_{\mathrm{A}}[\ce{B}] + [\ce{A}][\ce{B}]}, \qquad \text{ping-pong:}\quad v_0 = \frac{v_{\max}[\ce{A}][\ce{B}]}{K_{\mathrm{B}}[\ce{A}] + K_{\mathrm{A}}[\ce{B}] + [\ce{A}][\ce{B}]},
$$
其中 $K_{\mathrm{A}}$、$K_{\mathrm{B}}$ 是另一底物饱和时 A 和 B 的 Michaelis 常数，$K_{\mathrm{iA}}$ 是 EA 的解离常数（有序机理和快速平衡的随机机理都给出序列形式）。

在固定的 $[\ce{B}]$ 下取倒数，

$$
\text{sequential:}\quad \frac{1}{v_0} = \frac{K_{\mathrm{A}}}{v_{\max}}\left(1 + \frac{K_{\mathrm{iA}}K_{\mathrm{B}}}{K_{\mathrm{A}}[\ce{B}]}\right)\frac{1}{[\ce{A}]} + \frac{1}{v_{\max}}\left(1 + \frac{K_{\mathrm{B}}}{[\ce{B}]}\right), \qquad \text{ping-pong:}\quad \frac{1}{v_0} = \frac{K_{\mathrm{A}}}{v_{\max}}\frac{1}{[\ce{A}]} + \frac{1}{v_{\max}}\left(1 + \frac{K_{\mathrm{B}}}{[\ce{B}]}\right).
$$
在序列机理中，斜率依赖于 $[\ce{B}]$，不同 $[\ce{B}]$ 的直线相交（在 $1/[\ce{A}] = -1/K_{\mathrm{iA}}$ 处）；在乒乓机理中，斜率与 $[\ce{B}]$ 无关，直线平行。双倒数作图是估计参数的拙劣工具，却是显示这类模式的好工具。

![双底物反应 A + B → P + Q 的双倒数图：四个固定 B 浓度下 1/v₀ 对 1/[A] 的曲线（公式 9.2.1，v_max = 1，K_A = 1 mM，K_B = 0.5 mM，K_iA = 2 mM）。A：在形成三元复合物的序列机理中，斜率依赖于 [B]，直线相交，这里在 1/[A] = −1/K_iA 处。B：在乒乓机理中，斜率 K_A/v_max 对每个 [B] 都相同，直线平行](./plots/bisubstrate-patterns.py)

稳态动力学还可以通过 9.4.1 节的抑制模式区分有序结合与随机结合。产物抑制尤其能提供信息：只有一个产物存在时没有逆反应发生，但产物结合活性部位的一部分而产生抑制；它对 A 还是对 B 是竞争性的，取决于结合与释放的顺序。

## 9.3. 前稳态动力学

稳态动力学给出 $k_{\mathrm{cat}}$ 和 $K_{\mathrm{M}}$，但很少给出各个步骤的速率常数或哪一步是慢的。这些要在前稳态中找到，即 ES 和其他中间体达到稳态水平之前的第一次周转，通常持续毫秒到秒。

**定义 9.3.1（前稳态动力学）** 酶的**前稳态动力学**是稳态建立之前反应的时间进程，通过酶与底物的快速混合来测量（带光学检测的停流装置，或淬灭流装置，其中反应在编程的时间之后被释放所有结合分子的变性酸终止）。

前稳态有多长，什么时候可以忽略？用 $[\ce{E}] = [\ce{E}]_{\mathrm{t}} - [\ce{ES}]$ 写出两步方案完整的质量作用模型，它是关于 $[\ce{S}]$ 和 $[\ce{ES}]$ 的一对常微分方程（[2.4](/2.4)），有两个时间尺度：$[\ce{ES}]$ 在 $t_{\mathrm{c}} = 1/(k_1([\ce{S}]_0 + K_{\mathrm{M}}))$ 之内趋近其稳态值，而底物在 $t_S = ([\ce{S}]_0 + K_{\mathrm{M}})/(k_2[\ce{E}]_{\mathrm{t}})$ 的尺度上被消耗。由于 $k_2/k_1 \le K_{\mathrm{M}}$，

$$
\frac{t_{\mathrm{c}}}{t_S} = \frac{k_2}{k_1}\cdot\frac{[\ce{E}]_{\mathrm{t}}}{([\ce{S}]_0 + K_{\mathrm{M}})^2} \le \varepsilon = \frac{[\ce{E}]_{\mathrm{t}}}{[\ce{S}]_0 + K_{\mathrm{M}}} ,
$$
所以 Segel 判据 $\varepsilon \ll 1$（[6.3.17](/6.3.17#sec-17.3.5)）同时保证暂态很短、暂态期间底物的损失可以忽略（Segel 和 Slemrod，1989）。用相平面的语言说，稳态公式是一条慢流形：轨线几乎立刻落到它上面，然后沿着它运动。细胞中某些酶的浓度与其底物相当（$\varepsilon$ 为 1 的量级），此时针对总底物而不是游离底物写出的总准稳态近似仍然准确（Borghans、de Boer 和 Segel，1996）。

![E + S ⇌ ES → E + P 完整的质量作用模型与稳态近似的比较（k₁ = k₋₁ = k₂ = 1，于是 K_M = 2；浓度以 K_M 为单位，时间以 1/k₂ 为单位）。A：[E]_t = 0.02 K_M，[S]₀ = 2 K_M：[ES] 在 t_c 之内升到稳态公式给出的值，然后跟随它（虚线，按模拟的 [S] 计算），而底物在长得多的尺度 t_S 上被消耗。B：相平面：从每个 [S]₀ 出发，轨线先几乎竖直地（快速结合）落到曲线 [ES]/[E]_t = [S]/(K_M + [S]) 上，再沿它滑动。C：[S]₀ = K_M、三个 ε = [E]_t/([S]₀ + K_M) 值下生成的产物，时间以 t_S 为单位，此时积分形式的 Michaelis–Menten 方程（公式 9.1.1，虚线）是同一条曲线：ε = 0.01 时准确，0.1 时略有偏差，ε = 1 时失效](./plots/quasi-steady-state.py)

如果所观察产物形成之后的某一步是速控步，第一次周转就很快，产物以每个活性部位约一个分子的爆发形式出现，随后是较慢的稳态速率。爆发由公式 8.4.1 定量，该式是为胰凝乳蛋白酶导出的，那里的慢步骤是脱酰化（[7.1.8](/7.1.8#sec-8.4.1)）。把稳态直线外推到 $t = 0$ 得到的振幅度量活性部位的浓度；其速率给出化学步骤的速率常数。对许多酶，产物释放是速控的：例如催化性 **RNA** **核糖核酸酶 P** 表现出每个酶分子约一个被切割产物的爆发，所以产物的释放是它的慢步骤。爆发本身并不说明后面哪一步是慢的（产物释放、构象变化或另一个化学步骤）；需要进一步的实验来确定每一步的速率。

## 9.4. 酶抑制

### 9.4.1. 可逆抑制

**定义 9.4.1（酶抑制剂）** **酶抑制剂**是干扰催化、使反应变慢或停止的分子。可逆抑制剂结合并解离；不可逆抑制剂（9.4.4）使酶永久失活。

酶催化几乎所有细胞过程，所以酶抑制剂是最重要的药物之一（例如，阿司匹林抑制**前列腺素**合成的第一种酶），也是阐明机理和途径的工具。

**定义 9.4.2（可逆抑制的类型）** 可逆抑制剂 I 可以结合游离的酶 E、复合物 ES 或两者；相应的解离常数是**抑制常数** $K_{\mathrm{I}} = [\ce{E}][\ce{I}]/[\ce{EI}]$ 和 $K_{\mathrm{I}}' = [\ce{ES}][\ce{I}]/[\ce{ESI}]$。抑制是

- **竞争性抑制**，若 I 只结合 E，通常在活性部位，使 I 与 S 相互排斥；
- **反竞争性抑制**，若 I 只结合 ES，结合在不同于活性部位的位点；
- **混合型抑制**，若 I 结合 E 和 ES，结合在不同于活性部位的位点；$K_{\mathrm{I}} = K_{\mathrm{I}}'$ 的特例称为**非竞争性抑制**。

假定 EI 和 ESI 没有催化活性。

**定理 9.4.1（可逆抑制的一般速率定律）** 设抑制剂的结合处于平衡，ES 处于稳态，记 $\alpha = 1 + [\ce{I}]/K_{\mathrm{I}}$，$\alpha' = 1 + [\ce{I}]/K_{\mathrm{I}}'$。则

$$
v_0 = \frac{v_{\max}[\ce{S}]}{\alpha K_{\mathrm{M}} + \alpha'[\ce{S}]},
$$
它以竞争性（$\alpha' = 1$）、反竞争性（$\alpha = 1$）和混合型抑制作为特例。表观参数为 $v_{\max}^{\mathrm{app}} = v_{\max}/\alpha'$ 和 $K_{\mathrm{M}}^{\mathrm{app}} = \alpha K_{\mathrm{M}}/\alpha'$。

**证明** ES 的稳态 $k_1[\ce{E}][\ce{S}] = (k_{-1} + k_2)[\ce{ES}]$ 给出 $[\ce{E}] = K_{\mathrm{M}}[\ce{ES}]/[\ce{S}]$，无论抑制剂如何作用，因为 EI 和 ESI 只通过快平衡形成。酶分布在四种形式中：

$$
[\ce{E}]_{\mathrm{t}} = [\ce{E}] + [\ce{EI}] + [\ce{ES}] + [\ce{ESI}] = [\ce{E}]\,\alpha + [\ce{ES}]\,\alpha' = [\ce{ES}]\left(\frac{\alpha K_{\mathrm{M}}}{[\ce{S}]} + \alpha'\right).
$$
由 $v_0 = k_2[\ce{ES}]$ 和 $v_{\max} = k_2[\ce{E}]_{\mathrm{t}}$ 得速率定律。当 $[\ce{S}] \to \infty$ 时，$v_0 \to v_{\max}/\alpha'$；当 $[\ce{S}] = \alpha K_{\mathrm{M}}/\alpha'$ 时，$v_0$ 为其一半。$\square$

| 抑制剂 | 结合 | $v_{\max}^{\mathrm{app}}$ | $K_{\mathrm{M}}^{\mathrm{app}}$ | $[\ce{I}]$ 增大时的 Lineweaver–Burk 直线 |
|---|---|---|---|---|
| 无 | | $v_{\max}$ | $K_{\mathrm{M}}$ | |
| 竞争性 | E | $v_{\max}$ | $\alpha K_{\mathrm{M}}$ | 相交于 $1/v_0$ 轴 |
| 反竞争性 | ES | $v_{\max}/\alpha'$ | $K_{\mathrm{M}}/\alpha'$ | 平行 |
| 混合型 | E 和 ES | $v_{\max}/\alpha'$ | $\alpha K_{\mathrm{M}}/\alpha'$ | 相交于 $1/v_0$ 轴的左侧；若 $K_{\mathrm{I}} < K_{\mathrm{I}}'$（$\alpha > \alpha'$）在 $1/[\ce{S}]$ 轴上方，若 $K_{\mathrm{I}} > K_{\mathrm{I}}'$ 在其下方 |
| 非竞争性 | E 和 ES 相同 | $v_{\max}/\alpha$ | $K_{\mathrm{M}}$ | 相交于 $1/[\ce{S}]$ 轴 |

表后面的直观理解：竞争性抑制剂可以被足够多的底物所战胜，所以 $v_{\max}$ 不变，只是需要更多底物才能达到它。反竞争性抑制剂移走一部分 ES，使 $v_{\max}$ 降低；因为它只结合 ES，它也把 $\ce{E + S <=> ES}$ 拉向右侧，$K_{\mathrm{M}}$ 按同样的因子下降。混合型抑制剂总是使 $v_{\max}$ 降低，而 $K_{\mathrm{M}}$ 升高还是降低取决于它偏好 E 还是 ES。对混合型抑制，所有直线都经过 $1/[\ce{S}] = -K_{\mathrm{I}}/(K_{\mathrm{M}}K_{\mathrm{I}}')$；把斜率或截距对 $[\ce{I}]$ 作图可得 $K_{\mathrm{I}}$ 和 $K_{\mathrm{I}}'$。如今所有参数最好是把定理 9.4.1 的速率定律直接拟合到数据得到。

![由一般速率定律（定理 9.4.1）得到的可逆抑制，K_M = 1，v_max = 1，[I] = 0、1 和 3 K_I。上：v₀ 对 [S]；下：双倒数图（坐标轴按 K_M 和 v_max 缩放）。A：竞争性抑制：v_max 不变，K_M 增大；直线相交于 1/v₀ 轴。B：反竞争性抑制（K_I′ = K_I）：v_max 和 K_M 都按因子 α′ 减小；直线平行。C：K_I′ = 3 K_I 的混合型抑制（抑制剂偏好游离酶）：v_max 减小，K_M 增大；直线相交于 1/v₀ 轴的左侧、水平轴的上方](./plots/inhibition-kinetics.py)

反竞争性和混合型抑制可以对单底物酶定义，但在实践中见于有两个或更多底物的酶。占据 $\ce{S1}$ 位点的抑制剂，当 $[\ce{S1}]$ 变化时是竞争性的，但对 $\ce{S2}$ 则可能是混合型或反竞争性的，取决于结合是有序的还是随机的；与产物抑制和前稳态数据结合，这样的模式可以确定双底物酶的机理。异促的变构调节物（9.5.2）不应与反竞争性或混合型抑制剂混淆：后者结合第二个位点，但不一定使酶在不同的构象之间转换，它们的动力学效应也不同。

### 9.4.2. $\mathrm{IC_{50}}$ 与 Cheng–Prusoff 关系

在药物发现中，抑制剂常按其 $\mathrm{IC_{50}}$，即在测定条件下使速率减半的抑制剂浓度排序。与 $K_{\mathrm{I}}$ 不同，它依赖于底物浓度。

**公式 9.4.1（Cheng–Prusoff 关系）** 在定理 9.4.1 中令 $v_0([\ce{I}])/v_0(0) = 1/2$，当游离抑制剂浓度接近总浓度时，得

$$
\mathrm{IC_{50}} = \frac{K_{\mathrm{M}} + [\ce{S}]}{K_{\mathrm{M}}/K_{\mathrm{I}} + [\ce{S}]/K_{\mathrm{I}}'}; \qquad \text{competitive:}\ \ \mathrm{IC_{50}} = K_{\mathrm{I}}\left(1 + \frac{[\ce{S}]}{K_{\mathrm{M}}}\right), \qquad \text{uncompetitive:}\ \ \mathrm{IC_{50}} = K_{\mathrm{I}}'\left(1 + \frac{K_{\mathrm{M}}}{[\ce{S}]}\right).
$$

竞争性的形式就是 Cheng 和 Prusoff（1973）的关系。在高底物浓度下进行的测定中，竞争性抑制剂显得更弱，反竞争性的则显得更强；只有在相同的 $[\ce{S}]/K_{\mathrm{M}}$ 下比较 $\mathrm{IC_{50}}$ 才有意义。对于 $K_{\mathrm{I}}$ 与酶浓度相当的非常紧密结合的抑制剂，游离抑制剂浓度不再等于总浓度，上面的公式失效（此时适用 Morrison 方程）：$\mathrm{IC_{50}}$ 不能低于酶浓度的一半。

### 9.4.4. 不可逆抑制

**定义 9.4.3（不可逆抑制剂与自杀性失活剂）** **不可逆抑制剂**与酶中对活性必不可少的官能团共价结合或将其破坏，或形成稳定到几乎永不解离的非共价复合物。**自杀性失活剂**（基于机理的失活剂）是一种不可逆抑制剂，它在与靶酶活性部位结合之前没有反应性，结合后经历正常反应的最初几步，转变为与酶不可逆结合的反应性化合物。

不可逆抑制剂可以鉴别催化**残基**。二异丙基氟磷酸（DIFP）通过使单个残基 Ser195 磷酸化而使胰凝乳蛋白酶失活，这就是该 Ser 被鉴定为**催化三联体**的亲核试剂的方式（[7.1.8](/7.1.8#sec-8.4.1)）。有机磷神经毒剂和杀虫剂以同样的方式抑制乙酰胆碱酯酶，这是另一种丝氨酸水解酶。

因为自杀性失活剂只在某一种酶的活性部位内才变得有反应性，基于这一原理的药物可以很少有副作用，这使它们成为合理药物设计的目标。一个经典的例子是非洲昏睡病（非洲锥虫病）的治疗。锥虫通过反复转换其唯一的表面被膜**蛋白质**而逃避免疫系统，所以疫苗无效。它需要大量多胺亚精胺和精胺，其合成从鸟氨酸脱羧酶开始，这是一种**磷酸吡哆醛**（PLP）酶（[7.1.17](/7.1.17)）。PLP 与鸟氨酸形成 Schiff 碱，并在脱羧中充当电子汇。二氟甲基鸟氨酸（DFMO，依氟鸟氨酸）在溶液中是惰性的，但在酶上，其脱羧使一个离去的氟离子靠近 PLP 加合物；电子不流入 PLP 环，而是排出一个氟，所得的反应性共轭加合物被活性部位的 Cys 不可逆地进攻。这种药物有选择性，因为哺乳动物的鸟氨酸脱羧酶周转迅速并被替换，而 *Trypanosoma brucei gambiense* 的这种酶是稳定的。依氟鸟氨酸如今与硝呋莫司联合使用，而口服药物 fexinidazole（2018）已越来越多地取代注射治疗。克拉维酸，即 [7.1.8](/7.1.8#sec-8.4.5) 的 β-内酰胺酶失活剂，原理相同。

抑制剂不必是共价的才能实际上不可逆：过渡态类似物（定义 8.3.2）和某些天然的蛋白质抑制剂（9.5.4）结合得如此之紧，以致很少解离。

## 9.5. 调节酶

### 9.5.1. 调节酶与反馈抑制

在**代谢**中，酶在序列中工作，其中一个酶的产物是下一个酶的底物。它们大多遵循 9.1 的动力学，但每条途径含有一个或几个对总速率影响更大的酶，往往是途径或分支的第一个酶。

**定义 9.5.1（调节酶）** **调节酶**是催化活性随信号而增大或减小，从而调整代谢序列速率的酶。在**变构酶**中，活性由**变构调节物**（变构效应物），通常是小的代谢物或辅因子，与调节位点的可逆非共价结合而调节；其他调节酶受可逆共价修饰（9.5.3）、独立的调节蛋白的结合或不可逆的蛋白水解活化（9.5.4）控制。

变构的词汇是在 [7.1.7](/7.1.7#sec-7.3.4) 中为血红蛋白引入的：调节物是底物本身时为同促的，是另一种分子时为异促的，而且在大多数情形下，结合把活性较低的 **T 态**转变为活性较高的 **R 态**。调节物可以是**激活因子**，也可以是抑制剂。在异促酶中，每种调节物有其特定的调节位点，往往位于与催化亚基（C）不同的独立调节亚基（R）上；在同促酶中，活性部位同时也是调节位点。调节酶通常比其他酶更大，有两个或更多的亚基。

**定义 9.5.2（反馈抑制）** **反馈抑制**是途径中靠前的酶，通常是第一个定向步骤的酶，被该途径的终产物所抑制。

在 *Escherichia coli* 中，L-苏氨酸经五步转变为 L-异亮氨酸，异亮氨酸是第一个酶，即苏氨酸脱水酶（E1）的变构抑制剂。于是细胞合成异亮氨酸的速度只与其使用的速度一样快，中间体不积累，这是贯穿整个第二部分（[7.1.17](/7.1.17)）的负反馈的最简单形式。

```mermaid
flowchart LR
  A[L-苏氨酸] -->|E1| B[α-酮丁酸] -->|E2| C[α-乙酰-α-羟基丁酸] -->|E3| D["α,β-二羟基-β-甲基戊酸"] -->|E4| E[α-酮-β-甲基戊酸] -->|E5| F[L-异亮氨酸]
  F -. "抑制 E1（苏氨酸脱水酶）" .-> A
```

### 9.5.2. 变构动力学与天冬氨酸转氨甲酰酶

变构酶在高底物浓度下饱和，但 $v_0$ 对 $[\ce{S}]$ 的曲线通常是 S 形而不是双曲线形。半饱和浓度记为 $K_{0.5}$（或 $[\ce{S}]_{0.5}$），而不是 $K_{\mathrm{M}}$，因为曲线不是 Michaelis–Menten 形式的。S 形动力学反映亚基之间的协同相互作用，由它们界面上的非共价接触介导，与血红蛋白的氧结合（[7.1.7](/7.1.7#sec-7.3.4)）完全一样；经验的描述是 Hill 形式 $v_0 = v_{\max}[\ce{S}]^{n}/(K_{0.5}^{n} + [\ce{S}]^{n})$。其意义在于灵敏度：双曲线型的酶要使 $v_{\max}$ 从 10% 升到 90% 需要 $[\ce{S}]$ 增大 81 倍，而协同的酶只需 $81^{1/n}$ 倍（$n = 2$ 时 9 倍，$n = 3$ 时 4.3 倍），所以在曲线陡峭部分，底物或调节物浓度的微小变化就能使活性发生大的变化。

[7.1.7](/7.1.7#sec-7.3.5) 的协同（MWC）模型描述变构酶，只增加一点：两种状态可以在底物亲和力、催化速率常数或两者上不同。

**公式 9.5.1（变构酶的 MWC 模型）** 对具有 $n$ 个相同催化位点的酶，状态 R 与 T 平衡，$L = [\mathrm{T_0}]/[\mathrm{R_0}]$，底物解离常数为 $K_{\mathrm{R}}$ 和 $K_{\mathrm{T}} = K_{\mathrm{R}}/c$，催化常数为 $k_{\mathrm{R}}$ 和 $k_{\mathrm{T}}$，$\alpha = [\ce{S}]/K_{\mathrm{R}}$，

$$
v_0 = n[\ce{E}]_{\mathrm{t}}\,\frac{k_{\mathrm{R}}\,\alpha(1 + \alpha)^{n-1} + k_{\mathrm{T}}\,Lc\alpha(1 + c\alpha)^{n-1}}{(1 + \alpha)^{n} + L(1 + c\alpha)^{n}}.
$$
只结合 R 态的异促激活剂 A 和只结合 T 态的抑制剂 I（解离常数为 $K_{\mathrm{A}}$、$K_{\mathrm{I}}$，每个**原聚体**一个位点），通过改变表观变构常数起作用：

$$
L_{\mathrm{app}} = L\,\frac{(1 + [\ce{I}]/K_{\mathrm{I}})^{n}}{(1 + [\ce{A}]/K_{\mathrm{A}})^{n}}.
$$

Monod 命名的两种极限情形，对应于观察到的两类异促调节。

- K 系统（$k_{\mathrm{T}} = k_{\mathrm{R}}$，$c < 1$）：两种状态在亲和力上不同；$v_0$ 与 [7.1.7](/7.1.7#sec-7.3.5) 的饱和函数成正比，曲线是 S 形的，调节物改变 $K_{0.5}$ 而不改变 $v_{\max}$。激活剂使曲线更接近双曲线，$K_{0.5}$ 降低；抑制剂使它更趋于 S 形，$K_{0.5}$ 升高。这是常见的类型（ATCase、[7.1.18](/7.1.18) 中的磷酸果糖激酶-1）。
- V 系统（$c = 1$，$k_{\mathrm{T}} < k_{\mathrm{R}}$）：两种状态结合底物的能力相同，所以底物结合不移动 T ⇌ R 平衡，曲线是 $K_{0.5} = K_{\mathrm{R}}$ 的双曲线，调节物改变 $v_{\max}$。这一类型较少见。

![协同（MWC）模型中具有四个催化位点的变构酶（公式 9.5.1）。A：K 系统（c = 0.01，两种状态的 k_cat 相等）：L = 10³ 时曲线是 S 形的；结合 R 的激活剂（这里使 L 降到 10）使之移向较低的 [S] 并使之近乎双曲线，结合 T 的抑制剂（L = 10⁵）使之移向较高的 [S] 并使之更趋于 S 形；v_max 不变。虚线双曲线的 K_0.5 与未经调节的曲线相同，陡峭程度低得多。B：V 系统（c = 1，k_T = 0.05 k_R）：所有曲线都是 K_0.5 = K_R 的双曲线，调节物通过改变处于 R 态的酶的比例来改变 v_max](./plots/allosteric-kinetics.py)

*E. coli* 的天冬氨酸转氨甲酰酶（ATCase）是经典的变构酶。它催化嘧啶核苷酸合成的第一个**定向步骤**（[7.1.28](/7.1.28)），即**氨基甲酰磷酸**与天冬氨酸缩合为 *N*-氨甲酰天冬氨酸和 $\mathrm{P_i}$。它有 12 条**多肽**链，$\mathrm{c_6r_6}$：两个相互堆叠的催化三聚体和围绕它们的三个调节二聚体。催化亚基协同地起作用：天冬氨酸和氨基甲酰磷酸结合，并使酶逐步由 T 态转变为 R 态，后者沿三重轴扩展约 1.1 nm，给出 S 形动力学（同促调节）。调节亚基结合核苷酸（异促调节）。该途径的终产物 CTP 是负调节物：它升高 $K_{0.5}$，并在 CTP 丰富时限制 ATCase 的作用，UTP 增强这种抑制。ATP 表示细胞在生长且能量供应充足，并使嘌呤与嘧啶的合成保持平衡，是正调节物，使 $K_{0.5}$ 降低。两者都作用于 $K_{0.5}$，对 $v_{\max}$ 几乎没有影响：ATCase 是 K 系统。双底物类似物 *N*-（膦酰乙酰基）-L-天冬氨酸（PALA）类似于该反应的过渡态（定义 8.3.2），结合紧密并把酶锁定在 R 态；它被用来测定该状态的结构。

### 9.5.3. 可逆共价修饰

蛋白质中已知有 500 多种共价修饰。每个修饰基团由不同的酶添加和去除，所以两个方向可以独立调节。被修饰的残基实际上是一种新的氨基酸：增加的电荷可以改变局部的结构和构象，增加的疏水基团可以把蛋白质锚定到膜上。

| 修饰 | 残基 | 添加与去除者 | 实例 |
|---|---|---|---|
| 磷酸化 | Ser、Thr、Tyr（细菌中还有 His、Asp） | 蛋白激酶 / 蛋白磷酸酶 | **糖原磷酸化酶**和**糖原合酶**（[7.1.19](/7.1.19)）、信号传递（[7.1.14](/7.1.14)） |
| 乙酰化 | Lys、N 端 | 乙酰转移酶 / 去乙酰化酶 | 约 80% 的可溶性真核蛋白质 N 端被乙酰化；**组蛋白**（[7.2](/7.2)）；代谢酶（[7.1.29](/7.1.29)） |
| 甲基化 | Lys、Arg、Glu | 甲基转移酶（以 **S-腺苷甲硫氨酸**为供体）/ 去甲基化酶 | 细菌趋化性**受体**（Glu）、组蛋白 |
| 腺苷酰化、尿苷酰化 | Tyr | 腺苷酰转移酶 / 尿苷酰转移酶 | 细菌的**谷氨酰胺合成酶**及其调节蛋白 PII（[7.1.27](/7.1.27)） |
| ADP-核糖基化 | Arg、Cys 等 | ADP-核糖基转移酶（以 NAD 为供体） | 固氮酶还原酶；霍乱毒素和白喉毒素使宿主蛋白质失活 |
| **泛素**化、SUMO 化 | Lys | E1–E2–E3 连接酶级联 / 去泛素化酶 | 靶向蛋白酶体降解，**转录**和 **DNA** 修复的调节（[7.2](/7.2)） |
| 脂化（肉豆蔻酰化、棕榈酰化、异戊二烯化） | N 端 Gly、Cys | 酰基转移酶与异戊二烯基转移酶 | 膜锚定（[7.1.13](/7.1.13)） |

到目前为止最常见的调节性修饰是磷酸化：真核细胞中约三分之一的蛋白质被磷酸化，磷酸化是几乎每一个调节过程的一部分。

**定义 9.5.3（蛋白激酶与蛋白磷酸酶）** **蛋白激酶**把核苷三磷酸（通常是 ATP）的 γ-磷酰基转移给靶蛋白特定的 Ser、Thr 或 Tyr 残基（偶尔是 His）；**蛋白磷酸酶**（磷蛋白磷酸酶）水解磷酸酯并释放 $\mathrm{P_i}$。

人类**基因组**编码 500 多种蛋白激酶和约 200 种蛋白磷酸酶；总的说来，磷酸酶的特异性较低。磷酰基体积大，在生理 pH 下带两个负电荷。它能接受来自 **α 螺旋** N 端主链酰胺或 Arg **侧链**的氢键，并排斥 Asp 和 Glu；在结构上重要的位置，这会改变构象，进而改变底物结合与催化。

糖原磷酸化酶说明了这一效应。它以活性较高的磷酸化酶 *a*（其两个亚基各在 Ser14 被磷酸化）和活性较低的磷酸化酶 *b* 两种形式存在。**磷酸化酶激酶**把 *b* 转变为 *a*（$\ce{2 ATP} + \text{phosphorylase } b \to \ce{2 ADP} + \text{phosphorylase } a$），磷蛋白磷酸酶 1（PP1）把 *a* 转变回 *b*。在磷酸化酶 *b* 中，含有几个碱性残基的 20 个 N 端残基紧贴蛋白质的一个酸性区；Ser14 的磷酸化破坏了这一相互作用，并使 N 端片段移到使磷酸-Ser 与 Arg 侧链相互作用的构象，酶的活性大大增高。变构调节和**激素**也作用于这种酶（[7.1.19](/7.1.19)）。

激酶在短的**共有序列**内识别其靶残基；三维结构进一步决定残基是否可及。

| 激酶 | **共有序列**（被磷酸化的残基 S/T/Y） |
|---|---|
| **蛋白激酶 A** | `-x-R-[RK]-x-[ST]-B-` |
| **蛋白激酶 C** | `-[RK](2)-x-[ST]-B-[RK](2)-` |
| **周期蛋白依赖性激酶**（cdc2） | `-x-[ST]-P-x-[KR]-` |
| ERK（一种 MAP 激酶） | `-P-x-[ST]-P-` |
| 酪蛋白激酶 II | `-x-[ST]-x(2)-[ED]-x-` |
| 酪蛋白激酶 I | `-[SpTp]-x(2)-[ST]-B`（需要事先磷酸化） |
| EGF **受体酪氨酸激酶** | `-E(4)-Y-F-E-L-V-` |

x：任意氨基酸；B：疏水氨基酸；(n)：n 次重复；Sp、Tp：必须已被磷酸化的残基（来源：Lehninger 第 8 版，表 6-10）。

多位点磷酸化允许分级的控制。糖原合酶在五个区域中至少有九个位点，由几种激酶磷酸化，效应各不相同，有些是累加的。这种磷酸化是分层的：**糖原合酶激酶 3**（GSK3）只在酪蛋白激酶 II 使邻近的"引发"位点磷酸化之后才起作用。结果不是二元开关，而是响应几种信号对活性在很宽范围内的精细调节。

### 9.5.4. 酶原的蛋白水解活化

**定义 9.5.4（酶原）** **酶原**是酶的无活性前体，经蛋白水解切割而被活化；以这种方式活化的其他蛋白质的前体称为蛋白质原（或酶原）。

胃和胰的许多蛋白酶以酶原形式合成，使它们不会消化产生它们的细胞。胰凝乳蛋白酶原是 245 个残基的单链，由胰蛋白酶活化，后者切割 Arg15–Ile16 键，得到有活性的 π-胰凝乳蛋白酶。π-胰凝乳蛋白酶随后从其他胰凝乳蛋白酶分子上除去两个二肽（Ser14–Arg15 和 Thr147–Asn148），得到 α-胰凝乳蛋白酶，它是由二硫键连在一起的三条链（残基 1–13、16–146 和 149–245）；这就是为什么残基 14、15、147 和 148 在活性酶中缺失。新的 N 端 Ile16 与 Asp194 形成离子对，引起构象变化，产生**氧负离子穴**和特异性口袋（[7.1.8](/7.1.8#sec-8.5)）。胰蛋白酶原在小肠中由肠肽酶（肠激酶）活化，后者除去 N 端的六肽 Val–Asp–Asp–Asp–Asp–Lys；胰蛋白酶然后活化更多的胰蛋白酶原和其他胰酶原（胰凝乳蛋白酶原、前弹性蛋白酶、前羧肽酶），这是一个自我放大的步骤。胃蛋白酶原在胃的低 pH 下自我活化。胰蛋白酶原在胰内过早活化会引起急性胰腺炎。

蛋白水解活化是不可逆的；有活性的蛋白酶由与其活性部位结合得极紧的蛋白质抑制剂关闭。胰蛋白酶抑制剂（$M_{\mathrm{r}}$ 6000）保护胰腺不受误在那里活化的胰蛋白酶的损害；$\alpha_1$-抗蛋白酶（$M_{\mathrm{r}}$ 53 000）是中性粒细胞弹性蛋白酶的主要抑制剂，保护肺，它的缺乏，无论是遗传的还是由香烟烟雾的氧化引起的，都会导致肺气肿。蛋白水解活化并不限于蛋白酶：**胶原蛋白**以前胶原的形式合成，**胰岛素**以胰岛素原的形式合成（[7.1.3](/7.1.3#sec-3.5.2)）。

### 9.5.5. 血液凝固级联

**定义 9.5.5（调节级联）** 在**调节级联**中，一个信号活化酶 X，X 活化许多分子的酶 Y，每个 Y 又活化许多分子的 Z，依此类推，于是信号在每一步都被放大。活化可以是不可逆的（蛋白水解），也可以是可逆的（磷酸化）。

级联控制血液凝固、视网膜视杆细胞对光的检测（[7.1.14](/7.1.14)）、**细胞凋亡**（[7.1.15](/7.1.15)）、发育的某些部分，以及激素对糖原磷酸化酶的活化（[7.1.19](/7.1.19)）。血液凝固结合了蛋白水解活化、调节蛋白（结合并活化特定蛋白酶的**辅因子**）和反馈。

血凝块由聚集的血小板（无细胞核的细胞碎片）构成，由纤维蛋白的纤维把它们固定在一起。血管受伤时，血小板主要被内皮下暴露的胶原活化；它们在表面呈现阴离子磷脂，并释放血栓素等信号来招募更多的血小板，形成松散的栓塞。要使它稳定需要纤维蛋白。纤维蛋白原 $(\mathrm{A\alpha B\beta\gamma})_2$ 是血浆中含量仅次于白蛋白和球蛋白的第三多的蛋白质，由**丝氨酸蛋白酶**凝血酶转变为纤维蛋白，凝血酶从每条 α 链上除去 16 个残基（纤维蛋白肽 A），从每条 β 链上除去 14 个残基（纤维蛋白肽 B）。新暴露的 N 端嵌入相邻分子 C 端球状**结构域**上的**结合部位**，聚合成软的血凝块；然后因子 XIIIa，一种转谷氨酰胺酶，使相邻纤维蛋白分子的 Lys 和 Gln 侧链交联，形成硬的血凝块。

纤维蛋白原的活化是两个相互关联的级联的终点。大多数因子用罗马数字表示（酶原），"a"表示活性形式；大多数是类胰凝乳蛋白酶的丝氨酸蛋白酶或调节蛋白，在肝脏中合成。

1. 起始（外源性或组织因子途径）。组织损伤使内皮下细胞的膜蛋白组织因子（TF）暴露于血浆。血液中始终存在的痕量因子 VIIa 结合 TF，TF–VIIa 复合物把因子 X 切割为 Xa；Xa 反过来使更多的 VII 转变为 VIIa，这是正反馈环。Xa 与其调节蛋白 Va 一起把凝血酶原切割成第一波凝血酶。TF–VIIa 很快被组织因子途径抑制物（TFPI）关闭。
2. 扩增（内源性或接触活化途径，其所有成分都在血浆中）。TF–VIIa 还把 IX 切割为 IXa，凝血酶使 XI 活化为 XIa（反馈），XIa 产生更多的 IXa。IXa 与其辅因子 VIIIa 形成稳定的另一种 X 活化剂。凝血酶还活化辅因子 V 和 VIII 以及因子 XIII，所以它自身的产生加速。
3. 终止。结合在完整内皮上凝血酶调节蛋白的凝血酶活化蛋白 C；活化的蛋白 C 与蛋白 S 一起切割并灭活 Va 和 VIIIa。抗凝血酶是一种丝氨酸蛋白酶抑制剂（serpin），与凝血酶和 Xa 的活性部位 Ser 形成共价的 1:1 复合物。与 TFPI 一起，这些系统设定了组织因子暴露的阈值，低于它就不形成血凝块，并把凝固限制在伤口处；蛋白 C 或抗凝血酶的遗传缺陷大大增加血栓形成的风险。

凝血是医学的主要靶标。因子 VII、IX、X、凝血酶原以及蛋白 C 和 S 在其 N 端附近有由 γ-羧基谷氨酸（Gla）残基形成的 Ca²⁺ 结合位点（[7.1.3](/7.1.3#sec-3.3.1)）；羧化需要**维生素** K（[7.1.12](/7.1.12)），而结合的 $\ce{Ca^2+}$ 使这些因子附着在活化血小板的阴离子磷脂上，即伤口处。因此华法林等维生素 K **拮抗剂**是抗凝药。肝素是高度硫酸化的多糖（[7.1.10](/7.1.10)），能提高抗凝血酶对凝血酶和 Xa 的亲和力。阿司匹林抑制环加氧酶，减少血栓素的合成，从而减少血小板聚集。大多数凝血因子的缺乏引起严重程度不一的出血性疾病，即血友病。甲型血友病（因子 VIII 缺乏，约每 5000 名男婴 1 例）和乙型血友病（因子 IX 缺乏，约每 25 000 名 1 例）是 X 连锁的（[7.4](/7.4)）；维多利亚女王是乙型血友病的携带者，她的后代把它传给了欧洲的几个王室，2009 年对俄罗斯皇室遗骸的 DNA 研究证实了这一点。

### 9.5.6. 有几种调节机制的酶

位于代谢十字路口的酶往往结合了几种机制。把还原性氮引入代谢的细菌谷氨酰胺合成酶，受至少八种调节物的变构调节、可逆腺苷酰化以及调节蛋白的调节（[7.1.27](/7.1.27)）；糖原磷酸化酶受变构效应物、磷酸化和激素级联的控制（[7.1.19](/7.1.19)）。如果所有可能的反应都同时被催化，**生物大分子**和代谢物就会降解为简单的化合物；调节使细胞只催化它们需要的反应，在资源丰富时储存燃料，在资源匮乏时使用它。

## 9.6. 调节的定量后果

### 9.6.1. 零级超敏

共价修饰循环（一种使蛋白质 W 磷酸化的激酶和一种使之去磷酸化的磷酸酶）对激酶或磷酸酶活性变化的响应，可以比任何单个 Michaelis–Menten 酶陡峭得多，尽管两种酶都不是协同的。Goldbeter 和 Koshland（1981）证明，当两种酶都被其蛋白质底物饱和时就会发生这种情形。

**定义 9.6.1（零级超敏）** **零级超敏**是被修饰蛋白质的稳态比例对修饰酶与去修饰酶活性之比的开关样依赖性，它在两种酶对其所修饰的蛋白质都接近饱和（处于零级区域）时出现。

**公式 9.6.1（Goldbeter–Koshland 稳态）** 设激酶以最大速率 $V_1$ 和 Michaelis 常数 $K_1$ 作用于 W，磷酸酶以 $V_2$ 和 $K_2$ 作用于 W–P，总量 $W_{\mathrm{T}} = [\mathrm{W}] + [\mathrm{W{-}P}]$ 远大于酶浓度，并记 $w = [\mathrm{W{-}P}]/W_{\mathrm{T}}$，$J_1 = K_1/W_{\mathrm{T}}$，$J_2 = K_2/W_{\mathrm{T}}$。稳态 $V_1(1 - w)/(J_1 + 1 - w) = V_2w/(J_2 + w)$ 给出

$$
\frac{V_1}{V_2} = \frac{w\,(J_1 + 1 - w)}{(1 - w)(J_2 + w)}.
$$
对 $J_1 = J_2 = J$，使 $w$ 从 $0.1$ 变到 $0.9$ 所需的 $V_1/V_2$ 之比（响应系数）为

$$
R = 81\left(\frac{J + 0.1}{J + 0.9}\right)^{2},
$$
它从 $J \gg 1$ 时的 81（双曲线形，像单个 Michaelis–Menten 酶）下降到 $J \ll 1$ 时趋近于 1（开关）。

稳态方程可以显式地解出 $w$（Goldbeter–Koshland 函数），但画出响应只需要上面的反函数形式。这一机制是直观的：当两种酶都饱和时，每一种都以其最大速率工作，几乎与底物的量无关。如果 $V_1 > V_2$，激酶总是获胜，几乎所有 W 最终被磷酸化；如果 $V_1 < V_2$，则几乎没有；只有在 $V_1 = V_2$ 附近的窄带内两种形式才同时存在。等效的 **Hill 系数**是 $\ln 81/\ln R$：$J = 0.1$（$R = 3.24$）时已有约 3.7，$J = 0.01$（$R = 1.18$）时约为 26，远远超出几个**配体**的**协同性**结合所能给出的。$W_{\mathrm{T}}$ 远大于酶的条件很重要：如果酶隔离了其底物的相当大一部分，开关就会变钝。

### 9.6.2. 级联放大

在级联中，每一步的增益是一个上游酶在其活性寿命期间所活化的下游分子数；总增益是所有步骤的乘积。在最简单的线性模型中，阶段 $i$ 以速率常数 $k$ 被阶段 $i - 1$ 活化，并以速率常数 $d$ 失活：

$$
\frac{\mathrm{d}x_i}{\mathrm{d}t} = k\,x_{i-1} - d\,x_i,
$$
这是一个线性系统（[2.4](/2.4)），其每阶段的稳态增益为 $x_i/x_{i-1} = k/d$。四个阶段、$k/d = 10$，使信号放大 $10^4$ 倍。代价是延迟：输入阶跃之后，阶段 $n$ 起初按 $t^{n}$ 上升，所以深的级联先有一段滞后，然后爆发式上升，这有助于抑制来自短暂、微弱刺激的噪声；失活（$d$，在凝血中由 TFPI、抗凝血酶和蛋白 C 提供）使响应保持局部和短暂。凝血酶活化其自身的活化因子之类的正反馈使阈值进一步变陡，因此级联可以把分级的刺激变成全或无的事件。

## 思考题

1. 一种酶（$[\ce{E}]_{\mathrm{t}} = 1\,\mathrm{nM}$）的 $v_{\max} = 2\,\mu\mathrm{M\,s^{-1}}$，$K_{\mathrm{M}} = 4\,\mu\mathrm{M}$。（a）计算 $k_{\mathrm{cat}}$ 和 $k_{\mathrm{cat}}/K_{\mathrm{M}}$。该酶是否催化完美？（b）加入浓度使 $\alpha' = 2$ 的反竞争性抑制剂后，表观 $v_{\max}$ 和 $K_{\mathrm{M}}$ 是多少？

   **答** （a）$k_{\mathrm{cat}} = v_{\max}/[\ce{E}]_{\mathrm{t}} = 2\times10^{-6}/10^{-9} = 2000\,\mathrm{s^{-1}}$；$k_{\mathrm{cat}}/K_{\mathrm{M}} = 2000/(4\times10^{-6}) = 5\times10^{8}\,\mathrm{M^{-1}\,s^{-1}}$，在扩散控制的范围之内，所以催化是完美的。（b）两者都除以 $\alpha'$：$v_{\max}^{\mathrm{app}} = 1\,\mu\mathrm{M\,s^{-1}}$，$K_{\mathrm{M}}^{\mathrm{app}} = 2\,\mu\mathrm{M}$。
2. 一份酶制剂被一种可逆抑制剂污染。除去它之后，$v_{\max}$ 从 $1.6$ 升到 $4.8\,\mu\mathrm{M\,s^{-1}}$，$K_{\mathrm{M}}$ 从表观值 $K_{\mathrm{M}}^{\mathrm{app}} = 30\,\mu\mathrm{M}$ 降到 $15\,\mu\mathrm{M}$。求 $\alpha$ 和 $\alpha'$，并对抑制剂分类。

   **答** $\alpha' = 4.8/1.6 = 3$。由 $K_{\mathrm{M}}^{\mathrm{app}} = \alpha K_{\mathrm{M}}/\alpha'$：$\alpha = 30 \times 3/15 = 6$。两者都大于 1 且不相等，所以抑制剂是混合型的；由于 $\alpha > \alpha'$，它与游离酶结合更紧（$K_{\mathrm{I}} < K_{\mathrm{I}}'$，具体地，$K_{\mathrm{I}}' / K_{\mathrm{I}} = (\alpha - 1)/(\alpha' - 1) = 2.5$）。
3. 一种竞争性抑制剂的 $K_{\mathrm{I}} = 10\,\mathrm{nM}$。在 $[\ce{S}] = K_{\mathrm{M}}$ 和 $[\ce{S}] = 10K_{\mathrm{M}}$ 时测得的 $\mathrm{IC_{50}}$ 各是多少？为什么药理学家报告 $K_{\mathrm{I}}$ 而不是 $\mathrm{IC_{50}}$？

   **答** 由公式 9.4.1，$\mathrm{IC_{50}} = K_{\mathrm{I}}(1 + [\ce{S}]/K_{\mathrm{M}})$：20 nM 和 110 nM。$\mathrm{IC_{50}}$ 依赖于测定的底物浓度（对紧密结合者还依赖于酶浓度），而 $K_{\mathrm{I}}$ 是抑制剂–酶这一对的性质；只有 $K_{\mathrm{I}}$ 可以在不同实验室之间或与组织中预期的底物浓度作比较。
4. 在一个双底物反应中，不同固定 [B] 下 1/v₀ 对 1/[A] 的图给出平行线。这对机理意味着什么？预期是哪一类酶？序列机理会给出什么模式？

   **答** 平行线意味着斜率 $K_{\mathrm{A}}/v_{\max}$ 与 [B] 无关：不形成三元复合物，第一个产物在 B 结合之前就离开，是带共价修饰的酶中间体的乒乓机理，如转氨酶（磷酸吡哆胺形式）或核苷二磷酸激酶（磷酸化 His）。序列机理在 $1/v_0$ 中有项 $K_{\mathrm{iA}}K_{\mathrm{B}}/([\ce{A}][\ce{B}])$，所以其斜率依赖于 [B]，直线相交（公式 9.2.1）。
5. 对遵循 Hill 形式且 $n_{\mathrm{H}} = 3$ 的酶，要使 $v_0$ 从 $v_{\max}$ 的 10% 升到 90%，$[\ce{S}]$ 必须增大多少倍？与 Michaelis–Menten 酶比较，并解释为什么调节酶通常是变构的。

   **答** 由 $v_0/v_{\max} = [\ce{S}]^n/(K_{0.5}^n + [\ce{S}]^n)$，$[\ce{S}] = K_{0.5}(y/(1-y))^{1/n}$，所以 $[\ce{S}]_{0.9}/[\ce{S}]_{0.1} = 81^{1/n} = 81^{1/3} \approx 4.3$，而 $n = 1$ 时为 81。因此协同的酶把底物或调节物浓度的适度变化转变为通量的大变化，使 $K_{0.5}$ 移动的调节物在细胞中通行的浓度下作用强烈；双曲线型的酶则在两个数量级的范围内响应迟钝。
6. （开放题）利用公式 9.6.1，解释为什么只有当两种酶都饱和时，激酶–磷酸酶对才能起开关的作用，以及为什么底物被酶隔离会削弱开关。

   **答** 思路：当 $J \ll 1$ 时，每种酶几乎都以其最大速率运转，无论其底物的量多少，所以净通量 $V_1 - V_2$ 对几乎所有的 $w$ 都有相同的符号，并把系统驱向一个极端；只有在 $V_1 \approx V_2$ 时才可能有中间的稳态，转变的宽度由 $J$ 决定（$R = 81((J + 0.1)/(J + 0.9))^2$）。如果 $J \gtrsim 1$，速率与底物成正比，响应是双曲线形的。推导假设与酶结合的 W 可以忽略；如果酶的量与 W 相当，W 的大部分被保持在酶复合物中，游离底物不再使酶饱和，有效的 $J$ 增大，于是曲线变为分级的。数值检验：用 `solve_ivp`（[4.4.4](/4.4.4)）对递增的酶浓度积分完整的质量作用方案，并比较稳态曲线。
