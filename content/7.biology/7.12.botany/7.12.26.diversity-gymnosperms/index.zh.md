现存裸子植物只有一千余种，不到被子植物的百分之一，却在寒温带与高山形成大面积的针叶林，提供了世界上大部分的木材与纸浆，也包括地球上最高（北美红杉）、最大（巨杉）和最长寿（狐尾松）的生物。我国是裸子植物最丰富的国家之一，也是银杏、水杉、银杉、金钱松等孑遗植物的故乡。上一章以松为代表讲了裸子植物的生殖（[7.12.25](/7.12.25)）；本章讲它们的多样性：先讲分类系统的演变与现行的 Christenhusz 等（2011）系统（§26.1），然后按这一系统依次讲苏铁类（§26.2）、银杏（§26.3）、买麻藤类（§26.4）和松柏类的三个目（§26.5–§26.7），最后讲中国的裸子植物资源（§26.8）。每科给出识别特征、代表属种、经济意义和与旧系统的对应（科属变动）。裸子植物的营养器官（管胞木材、树脂道、针叶的结构）已在 [7.12.21](/7.12.21)–[7.12.23](/7.12.23) 中讲过。

## 26.1. 分类系统

### 26.1.1. 传统的纲目系统

我国的裸子植物分类长期采用郑万钧在《中国植物志》第 7 卷（1978）中的系统，把**裸子植物**作为一个门，分为 4 纲 9 目 12 科、71 属近 800 种：

| 纲 | 目 | 科 |
|---|---|---|
| 苏铁纲 Cycadopsida | 苏铁目 | 苏铁科 |
| 银杏纲 Ginkgopsida | 银杏目 | 银杏科 |
| 松杉纲 Coniferopsida | 松杉目 | 松科、杉科、柏科、南洋杉科 |
| | 罗汉松目 | 罗汉松科 |
| | 三尖杉目 | 三尖杉科（粗榧科） |
| | 红豆杉目 | 红豆杉科（紫杉科） |
| 买麻藤纲 Gnetopsida | 麻黄目、买麻藤目、百岁兰目 | 麻黄科、买麻藤科、百岁兰科 |

吴国芳等的《植物学》下册把罗汉松科、三尖杉科与红豆杉科从松柏纲中分出，另立红豆杉纲（紫杉纲，Taxopsida），理由是它们的大孢子叶特化为珠托或套被、不形成球果、种子有肉质的假种皮或外种皮，于是成为 5 纲；买麻藤纲又称盖子植物纲（Chlamydospermopsida）。这些系统主要依据形态，纲的划分把"有没有球果"看得很重。

### 26.1.2. Christenhusz 等（2011）的系统

分子系统发生研究改变了这一图景：

- 杉科（Taxodiaceae）不是**单系群**：柏科（狭义）嵌在杉科之中，二者合并为广义的柏科（Cupressaceae s.l.）；原属杉科的日本金松与其他各属关系较远，独立为金松科。
- 罗汉松科、三尖杉科与红豆杉科并不构成一支：三尖杉科与红豆杉科是姐妹群，二者合并为广义的红豆杉科，与柏科同属一支；罗汉松科则是南洋杉科的姐妹群。"红豆杉纲"因此不成立，有没有球果是在松柏类中多次变化的性状。
- 松柏类分为两支：松科，以及其余各科组成的"柏类"（Cupressophyta，又称 conifer II）。

Christenhusz 等（2011，*Phytotaxa* 19: 55–70）据此为现存裸子植物给出了一个线性排列的分类，把它们作为一个类群下的 4 个亚纲、8 目、12 科、84 属：

| 亚纲 | 目 | 科 | 属/种（约） |
|---|---|---|---|
| 苏铁亚纲 Cycadidae | 苏铁目 Cycadales | 苏铁科 Cycadaceae | 1/120 |
| | | 泽米铁科 Zamiaceae | 9/250 |
| 银杏亚纲 Ginkgoidae | 银杏目 Ginkgoales | 银杏科 Ginkgoaceae | 1/1 |
| 买麻藤亚纲 Gnetidae | 百岁兰目 Welwitschiales | 百岁兰科 Welwitschiaceae | 1/1 |
| | 买麻藤目 Gnetales | 买麻藤科 Gnetaceae | 1/40 |
| | 麻黄目 Ephedrales | 麻黄科 Ephedraceae | 1/70 |
| 松亚纲 Pinidae | 松目 Pinales | 松科 Pinaceae | 11/230 |
| | 南洋杉目 Araucariales | 南洋杉科 Araucariaceae | 3/40 |
| | | 罗汉松科 Podocarpaceae | 19/190 |
| | 柏目 Cupressales | 金松科 Sciadopityaceae | 1/1 |
| | | 柏科 Cupressaceae | 30/160 |
| | | 红豆杉科 Taxaceae | 6/30 |

种数是现行的约数（苏铁类按 The World List of Cycads，其余参考 POWO 与 Christenhusz 等的统计），不同来源相差较大。本章各节按这一顺序排列；也有教学上把它简化为苏铁目、银杏目、球果目与买麻藤目四目的。

### 26.1.3. 买麻藤类的位置

各亚纲之间的关系仍有争议的只有买麻藤类。苏铁类与银杏组成一支，位于现存裸子植物的基部，这一点各分析一致；买麻藤类则可能是全部松柏类的**姐妹群**（gnetifer 假说），也可能嵌在松柏类之内、是松科的姐妹群（gnepine 假说），甚至是柏类的姐妹群。Ran 等（2018）用大量核基因的系统基因组分析支持 gnepine 假说，并指出买麻藤类与被子植物之间的相似性状（导管、类似花被的盖被、无颈卵器）是部分趋同或同塑的结果；但不同基因与分析方法之间存在明显的冲突，问题尚未完全解决。Christenhusz 等把买麻藤类保留为独立的亚纲，是一种不依赖具体假说的稳妥处理。如果 gnepine 假说成立，"松柏类"就是一个**并系群**。

## 26.2. 苏铁类

### 26.2.1. 苏铁目的特征

苏铁类是现存种子植物中最原始的一类，二叠纪兴起，侏罗纪极盛（与外形相似的本内苏铁一起，中生代因此常被称为"苏铁时代"），以后衰退，现存约 370 种，分布于热带与亚热带。

- 常绿木本，茎粗壮，常不分枝（"厚茎"），髓与皮层很厚，木质部只占一狭圈；形成层活动期短，有些种以皮层中相继发生的形成层环进行异常次生生长；叶基宿存，茎表面满布叶痕。
- 叶螺旋状排列，有两种：小而密被褐色毡毛的鳞叶，和大型一回羽状（稀二回）的营养叶，二者相间成环着生；营养叶集生茎顶，坚硬革质；苏铁属的幼叶与小叶拳卷，如蕨类。
- 侧根中有向上生长、反复二叉分枝的**珊瑚状根**，皮层中有一圈共生的**蓝细菌**（主要是念珠藻属 *Nostoc*，也报道有鱼腥藻属 *Anabaena*），能固氮（中文教材称之为"菌根"，不确切：苏铁另有丛枝**菌根**，珊瑚状根则是与蓝细菌的共生，见 [7.11.31](/7.11.31)）。
- **雌雄异株**；雄球花大，由许多小孢子叶组成，小孢子叶背面生许多小孢子囊群；精子多鞭毛（[7.12.25](/7.12.25#sec-25.5.1)）。
- 许多苏铁由甲虫（象甲等）或蓟马传粉，雄球花发热、散发气味吸引昆虫，这是虫媒传粉在种子植物中的古老例子。
- 种子大，种皮外层肉质、常红色或橙色，中层坚硬；种子与茎髓富含淀粉，但含苏铁苷（cycasin）等毒素，须经长时间浸泡、发酵才能食用。

### 26.2.2. 苏铁科与泽米铁科

| | 苏铁科 Cycadaceae | 泽米铁科 Zamiaceae |
|---|---|---|
| 属 | 只有苏铁属 *Cycas* | 9 属：泽米铁属 *Zamia*、非洲铁属 *Encephalartos*、双子铁属 *Dioon*、大泽米属 *Macrozamia*、角果泽米属 *Ceratozamia*、蕨铁属 *Stangeria* 等 |
| 分布 | 东亚、东南亚、澳大利亚、马达加斯加与东非 | 美洲、非洲、澳大利亚 |
| 小叶 | 有中脉，无侧脉 | 多为平行脉，无中脉（蕨铁属有中脉与羽状侧脉） |
| 大孢子叶 | 叶状，上部羽裂，下部两侧生 2–10 个胚珠，丛生茎顶，不形成雌球花 | 盾状，每片两个胚珠，聚成雌球花 |

苏铁属 *Cycas* 约 120 种，是苏铁类中最大的属，也是我国唯一的属（Flora of China 收录 16 种，以后又发表了若干新种），产西南至东南，福建、广东、广西、云南、四川、贵州、台湾都有分布。常见的苏铁（铁树，*C. revoluta*）原产福建、台湾与日本南部，各地广泛栽培，北方盆栽。攀枝花苏铁（*C. panzhihuaensis*）1981 年才发表，产四川攀枝花与云南北部金沙江干热河谷，是分布最北的苏铁之一，形成成片的天然林，攀枝花苏铁国家级自然保护区即为保护它而设。

![苏铁、银杏与买麻藤类的特征结构（示意）。A 苏铁属的大孢子叶：叶状，上部羽状分裂，柄的两侧生胚珠，不形成雌球花。B 苏铁的珊瑚状根：向上生长、反复二叉分枝，横切面皮层中有一圈蓝细菌。C 银杏生胚珠的短枝：长柄顶端分叉，各有一个珠领与一个胚珠，通常只有一个成熟。D 银杏种子纵切：肉质外种皮、有 2–3 条纵脊的骨质中种皮、膜质内种皮、雌配子体与胚，没有果皮。E 麻黄的雌球花：交互对生的苞片，顶端的胚珠被盖被包围，珠被延长成珠孔管，管口有传粉滴。F 百岁兰：终生只有一对带状叶，由基部的分生组织持续生长。](./plots/cycad-ginkgo-gnetophytes.py)

## 26.3. 银杏

### 26.3.1. 银杏科

银杏科（Ginkgoaceae）只有银杏属一属一种：银杏（*Ginkgo biloba*，又称白果、公孙树）。

- 落叶乔木，高可达 40 m；枝有长枝与短枝之分：长枝（营养枝）生长快，每年可长约 0.5 m，叶螺旋状散生；短枝（生殖枝）生长极慢，数年只长几厘米，叶簇生枝顶，球花也生于短枝上。两种枝的解剖不同：长枝髓小、皮层薄、木质部厚，短枝则相反。
- 叶扇形，有长柄，叶脉多次二叉分枝，没有中脉；长枝上的叶常在中间二裂（种加词 *biloba* 即"二裂"），短枝上的叶多为波状缺刻。秋叶金黄。
- 各器官有分泌腔；木质部由管胞组成，有明显的年轮。
- **雌雄异株**。雄球花柔荑花序状；雌球花有长柄，顶端两个珠领，各生一个直生胚珠（[7.12.25](/7.12.25#sec-25.5.2)）。
- 种子核果状，外种皮肉质、有臭味，中种皮骨质，内种皮膜质；胚乳（雌配子体）丰富，子叶两枚，萌发时不出土。

中文教材列有雌、雄株营养体的区别（雄株树冠较窄、长枝斜上、叶多裂、叶柄横切无树脂隙，雌株树冠宽、长枝开展下垂等），这些差别是统计性的，实际鉴别雌雄要等开花；近年已有基于性别相关 DNA 标记的幼苗性别鉴定方法。城市行道树多选用雄株，以免肉质外种皮落地发臭。

### 26.3.2. 活化石与野生种群

**定义 26.3.1（活化石）** 在化石记录中出现很早、形态长期变化很小，而现存只有极少数种类、分布范围狭小的生物，称为**活化石**（living fossil）。植物学中常与**孑遗植物**（relict plants，在地质历史上曾经繁盛、分布广泛，后来大部分灭绝、只在局部地区残存的植物）通用。

银杏是最著名的活化石。银杏目在早二叠世已经出现（如 *Trichopitys*），中生代种类繁多、遍布北半球，侏罗纪的义马银杏（*Ginkgo yimaensis*，河南义马，约 1.7 亿年前）的胚珠已与现代银杏很接近；新生代逐渐衰退，晚中新世以后在欧洲、北美相继消失，第四纪冰期后只在我国残存。化石银杏的小孢子叶有 5–6 个花粉囊、胚珠较多，现代银杏的生殖结构是经过"简化"的结果。"活化石"是一种描述，并不意味着形态完全停滞：银杏的基因组在长期的演化中仍有大量变化（[7.10.32](/7.10.32)）。

银杏是否还有真正的野生种群，长期有争议。中文教材称"仅浙江西天目山有野生状态的树木"，但天目山的银杏多生于寺庙附近，遗传多样性并不高，很可能是半野生或古代栽培后逸生的。Zhao 等（2019）对 545 株银杏进行全基因组重测序，认为我国西南（重庆金佛山、贵州务川一带）、华南（南岭）和东部（天目山）可能各有一个冰期避难所，西南的种群遗传多样性最高；但人类栽培的影响很难完全排除。野生银杏种群已列为国家一级重点保护野生植物。

银杏的木材优良；种仁（白果）可食用和药用，但含银杏毒素（4′-O-甲基吡哆醇），生食或多食易引起中毒，儿童尤甚；叶的提取物含银杏内酯与黄酮类，被开发为药物与保健品。银杏也是世界各地常见的园林树种，对污染与病虫害抗性很强。

## 26.4. 买麻藤类

买麻藤类（买麻藤亚纲）只有三科三属，彼此形态差别极大，但都有次生木质部中的**导管**、交互对生或轮生的叶与具节的茎、有盖被的球花、延长成珠孔管的珠被和无鞭毛的精子（[7.12.25](/7.12.25#sec-25.6)）。它们没有树脂道。

### 26.4.1. 麻黄科

麻黄科（Ephedraceae）只有麻黄属（*Ephedra*），约 70 种，分布于亚洲、欧洲东南部、北非与美洲的干旱、荒漠地区；我国 14 种（Flora of China），以西北和内蒙古、西南高原为多。

- 灌木、亚灌木或草本状，多分枝，小枝对生或轮生，绿色，有节，节间有细纵槽，横切面髓部常为棕红色；外形与木贼很像，但是木本，次生木质部有导管。
- 叶退化成膜质鳞片，2–3 片对生或轮生，基部合生成鞘，光合作用主要由绿色的幼枝进行。
- 雌雄异株，稀同株；雌球花成熟时苞片变红、肉质，包在种子外，呈浆果状（"麻黄果"）。

麻黄的茎含麻黄碱（ephedrine）与伪麻黄碱等**生物碱**，1885 年日本的长井长义从麻黄中分离出麻黄碱。草麻黄（*E. sinica*）、中麻黄（*E. intermedia*）与木贼麻黄（*E. equisetina*）是我国药典收载的麻黄来源，用于平喘、发汗；麻黄碱也是合成甲基苯丙胺的前体，因此麻黄草与麻黄碱的生产和流通受到严格管制。麻黄生于荒漠与沙地，有固沙作用。

### 26.4.2. 买麻藤科

买麻藤科（Gnetaceae）只有买麻藤属（*Gnetum*），约 40 种，分布于亚洲、非洲与南美的热带雨林，多为常绿木质大藤本，少数为灌木或小乔木（如东南亚栽培的显轴买麻藤 *G. gnemon*）。茎节膨大，次生木质部导管粗大，射线宽；单叶对生，椭圆形，有羽状侧脉与网状细脉，极似双子叶植物。雌雄异株，球花组成细长的穗状花序，有多轮杯状总苞。种子核果状，包在红色的肉质假种皮中。我国 7–9 种，产福建、广东、广西、海南、云南等地，常见的有买麻藤（*G. montanum*）与小叶买麻藤（*G. parvifolium*）；茎皮纤维可织麻袋、渔网，种子可炒食或榨油。

### 26.4.3. 百岁兰科

百岁兰科（Welwitschiaceae）只有一种百岁兰（*Welwitschia mirabilis*，中文教材用的 *W. bainesii* 是它的异名），产非洲西南部纳米布沙漠（纳米比亚与安哥拉）的近海地带。茎粗短、块状，深埋地下，有很深的直根；子叶脱落后，植株终生只有一对带状叶，长可达数米，由叶基部的分生组织不断生长，先端在风沙中枯裂，因此看起来像许多条叶。大的个体据放射性碳测年超过一千年（中文教材的"可生存百年以上"太保守）。百岁兰靠沿海的雾获得水分，是典型的旱生植物；球花鲜红色，雌雄异株，主要由昆虫传粉。

## 26.5. 松科

### 26.5.1. 松科的特征

松科（Pinaceae）是松柏类中最大、经济上最重要的科，约 11 属 230 种，几乎全部分布在北半球，从亚热带山地到北极林线、从海平面到海拔 4800 m 都有，北方针叶林主要由松科的落叶松、云杉、冷杉与松组成。我国 10 属约 110 种（Flora of China；是否承认长苞铁杉属 *Nothotsuga* 造成 10 属与 11 属的差别），遍布全国，多为森林树种与用材树种，并有许多特有属种与孑遗种。

- 乔木，稀灌木，大多常绿（落叶松属与金钱松属落叶）；枝轮生，常有长、短枝；木材与叶中有树脂道，树皮与叶常有芳香。
- 叶条形或针形：条形叶扁平，稀四棱，在长枝上螺旋状散生、在短枝上簇生；针形叶 2–5 针一束，生于极度退化的短枝顶端，基部包有叶鞘（松属）。
- 雌雄同株；雄球花的小孢子叶螺旋状排列，每个小孢子叶有 2 个花粉囊，花粉多有两个气囊（雪松属、落叶松属、黄杉属与多数铁杉属无气囊）。
- 雌球花由多数螺旋状排列的苞鳞–珠鳞复合体组成，苞鳞与珠鳞离生（仅基部结合），每个珠鳞腹面基部有 2 个倒生胚珠；受精后珠鳞发育为木质或革质的种鳞，**球果**直立或下垂，当年或第二年成熟。
- 种子上端通常有一个由种鳞表皮组织形成的长翅；子叶 2–18 枚。染色体基数多为 $x = 12$。

松科的识别要点因此是：针形或条形叶、叶与种鳞螺旋状排列、苞鳞与种鳞离生、每种鳞两粒有翅的种子。倒生的胚珠、种子顶端的长翅、特殊的原胚发育方式与筛分子中的蛋白质型质体是松科的共衍征，分子系统发生把松科放在其余松柏类（柏类）的姐妹群位置（或与买麻藤类组成一支，§26.1.3）。

### 26.5.2. 两亚科与各属

形态与分子证据把松科分为两亚科：冷杉亚科（Abietoideae：雪松属、冷杉属、油杉属、金钱松属、铁杉属、长苞铁杉属）与松亚科（Pinoideae：黄杉属、落叶松属、银杉属、云杉属、松属）。松亚科的种皮中没有树脂道，幼根的维管柱中有两个树脂道；雪松属位于冷杉亚科的基部。

### 26.5.3. 松属

松属（*Pinus*）约 110 种，是裸子植物中最大的属之一，广布北半球，我国 20 余种，是森林的主要树种。常绿乔木，稀灌木，冬芽显著。叶两型：鳞叶（原生叶）螺旋状着生，幼苗时为扁平条形，后退化成膜质苞片状；针叶（次生叶）2、3 或 5 针一束（少数种 1 或 6–8 针），基部有叶鞘。小孢子叶球多数，集生于新枝下部；大孢子叶球单生或 2–4 个生于新枝近顶端；球果第二年秋季成熟。

松属分为两亚属，区别首先在针叶中的维管束数目：

| | 单维管束亚属（软松亚属，subg. *Strobus*） | 双维管束亚属（硬松亚属，subg. *Pinus*） |
|---|---|---|
| 针叶的维管束 | 1 条 | 2 条 |
| 叶鞘 | 早落 | 宿存 |
| 针叶基部的鳞叶 | 不下延 | 下延 |
| 木材 | 较软，色淡，树脂较少 | 较硬，色深，树脂多 |
| 鳞脐 | 多为顶生，无刺（白皮松背生、有刺） | 背生，常有刺 |
| 代表种 | 红松 *P. koraiensis*（5 针，东北）、华山松 *P. armandii*（5 针）、白皮松 *P. bungeana*（3 针，特有，老树皮块状脱落成白色斑块）、乔松 *P. wallichiana*（5 针，喜马拉雅） | 油松 *P. tabuliformis*（2 针，特有，华北）、马尾松 *P. massoniana*（2 针，稀 3 针，长江流域以南）、黄山松 *P. taiwanensis*（2 针）、樟子松 *P. sylvestris* var. *mongholica*（2 针，东北与内蒙古沙地）、黑松 *P. thunbergii*（2 针，原产日本、朝鲜）、云南松 *P. yunnanensis*（3 针，稀 2 针）、火炬松 *P. taeda* 与湿地松 *P. elliottii*（北美引种） |

北京地区常见的松科植物有：油松（北京山地的主要针叶树与园林树种）、白皮松（古典园林中的名木，如北海团城的"白袍将军"）、华山松、乔松（栽培）、白杄与青杄、雪松、华北落叶松（海拔较高的山地）。

松属的经济价值最大：木材供建筑、枕木、矿柱、造纸；树干割取松脂，蒸馏得松节油（turpentine），残余为松香（rosin），我国是世界上最大的松香生产国，主要采自马尾松与湿地松；红松、华山松等的大粒种子（松子）可食；松针、松花粉、松节可入药。

## 26.6. 南洋杉目

### 26.6.1. 南洋杉科

南洋杉科（Araucariaceae）有 3 属约 40 种，主要分布在南半球（南美、澳大利亚、新西兰、新喀里多尼亚与东南亚），中生代曾广布南北两半球。常绿大乔木，枝常轮生；叶螺旋状排列，钻形、鳞形或宽阔的披针形；雌雄异株或同株；苞鳞与珠鳞合生（贝壳杉属几乎只有苞鳞），每个种鳞只有 1 粒种子；球果大，成熟时种鳞从中轴上脱落；花粉无气囊。木材的结构（管胞上的具缘纹孔多列、互相挤压成多角形）与古生代的科达类相似。

- 南洋杉属（*Araucaria*，约 20 种）：南洋杉（*A. cunninghamii*，原产澳大利亚东部）与异叶南洋杉（*A. heterophylla*，原产诺福克岛）在我国南方常栽培作庭园树，北方盆栽；智利南洋杉（*A. araucana*）的种子可食。
- 贝壳杉属（*Agathis*，约 20 种）：叶宽阔，有多条平行脉；新西兰的贝壳杉（kauri，*A. australis*）是巨大的用材树，其树脂（贝壳杉脂）曾大量开采。
- 瓦勒迈杉属（*Wollemia*）：只有瓦勒迈杉（*W. nobilis*）一种，1994 年在澳大利亚悉尼以西的瓦勒迈国家公园的峡谷中被发现，野生成年个体不足 100 株，此前只知道它的近缘类型的化石，是又一个"活化石"。

### 26.6.2. 罗汉松科

罗汉松科（Podocarpaceae）约 19 属 190 种，主要分布在南半球与热带山地，是南半球最大的松柏类科。常绿乔木或灌木；叶条形、披针形或鳞形，稀为扁平的阔叶状（竹柏）或退化成叶状枝；雌雄多异株；雌球花退化，只有一个或少数几个能育的珠鳞，每个珠鳞包着一个倒生胚珠，这个变态的珠鳞称为套被（epimatium），种子成熟时套被成为肉质或革质的外层；许多属的苞片与轴愈合，膨大成肉质、颜色鲜艳的种托，吸引鸟类取食传播种子。小孢子叶有两个花粉囊，花粉通常有气囊。

我国 4 属 12 种（Flora of China），产长江以南：

- 罗汉松属（*Podocarpus*，约 100 种）：罗汉松（*P. macrophyllus*），叶条状披针形，中脉显著隆起；种子卵圆形，成熟时紫色，下面的肉质种托紫红色，形似披着袈裟的罗汉，故名，是常见的庭园树与盆景树；百日青（*P. neriifolius*）。
- 竹柏属（*Nageia*）：竹柏（*N. nagi*），叶对生，卵形，有多数并行细脉而无中脉，像竹叶；木材优良，种子可榨油。中文教材把它放在罗汉松属（*Podocarpus nagi*）。
- 陆均松属（*Dacrydium*）：陆均松（*D. pectinatum*），产海南，套被与珠被离生，种子坚果状，只有基部被杯状的假种皮包围，苞片不发育成肉质种托。中文教材用的学名 *D. pierrei* 是它的异名。
- 鸡毛松属（*Dacrycarpus*）：鸡毛松（*D. imbricatus*），叶二型，钻状条形叶排成两列，鳞状叶覆瓦状；产海南、广西、云南。中文教材放在罗汉松属（*Podocarpus imbricatus*）。

## 26.7. 柏目

### 26.7.1. 金松科

金松科（Sciadopityaceae）只有日本金松（*Sciadopitys verticillata*，又称金松）一种，日本特产，中生代以来的化石遍布北半球。常绿乔木；长枝上生膜质鳞叶，其腋内的短枝上各生一枚长条形、两面有沟的"双针"，许多双针在枝顶轮生如伞骨；双针被认为是由两枚针叶愈合而成，或是一个扁化的短枝（叶状枝）。球果的苞鳞与种鳞大部合生，每个种鳞有 5–9 粒有翅的种子。传统上放在杉科，分子证据表明它是柏科与红豆杉科共同的姐妹群。日本金松与雪松、南洋杉、金钱松、巨杉（或北美红杉）常被并称为"世界五大庭园树种"。

### 26.7.2. 柏科

广义的柏科（Cupressaceae s.l.）约 30 属 160 种，分布于南北两半球，包括传统的杉科与狭义的柏科。

- 乔木或灌木；叶鳞形、刺形、条形或钻形，螺旋状排列（原杉科多数属），或交互对生、三叶轮生（原柏科），同一植株上常有两型叶；叶的基部多下延，老叶常连同小枝一起脱落；
- 雌雄同株或异株；小孢子叶有 2–9 个花粉囊（狭义柏科多为 3–6 个），花粉无气囊；
- 苞鳞与珠鳞半合生到完全合生，每个种鳞有 1–9 粒（有的多达 20 粒）直立或倒生的种子；球果木质或革质，熟时张开，刺柏属的种鳞肉质而合生，呈浆果状；
- 种子两侧或周围有窄翅，或无翅。染色体基数 $x = 11$。

苞鳞与种鳞的愈合程度在柏科中构成一个系列（下图），这是把杉科与柏科合并的形态依据之一：杉木的苞鳞大、种鳞小而只在基部与苞鳞合生；柳杉的种鳞只有上部的齿裂离生；水杉、北美红杉与柏木属的种鳞盾形，与苞鳞完全合生，只在中部留一个小尖头；刺柏属则合生成肉质的"浆果"。

![松柏类球果的苞鳞–种鳞复合体（从中轴一侧看，示意）。苞鳞（绿色）是叶，它腋部的种鳞（褐色）是一个变态的短枝。松科二者离生，每个种鳞有两粒顶端有翅的种子；南洋杉科二者合生，只有一粒种子。在广义柏科中，愈合程度从杉木（苞鳞大、种鳞小而三裂，三粒种子）、柳杉（只有种鳞顶端的齿离生，2–5 粒种子），到落羽杉、北美红杉与柏木（盾形、完全合生）依次增加；侧柏的种鳞扁平，顶端有反曲的钩状尖头，种子无翅；刺柏属的种鳞肉质，合生成浆果状的球果。](./plots/bract-scale-fusion.py)

分子系统发生把柏科分为 7 个亚科（Gadek 等 2000），依次为：

| 亚科 | 主要属 | 特点 |
|---|---|---|
| 杉木亚科 Cunninghamioideae | 杉木属 *Cunninghamia* | 叶条状披针形，有锯齿；苞鳞大，种鳞小、先端三裂，每种鳞 3 粒种子 |
| 台湾杉亚科 Taiwanioideae | 台湾杉属 *Taiwania* | 叶钻形；球果小；台湾杉（秃杉）*T. cryptomerioides* 产台湾与西南 |
| 密叶杉亚科 Athrotaxidoideae | 密叶杉属 *Athrotaxis*（塔斯马尼亚） | |

| 落羽杉亚科 Taxodioideae | 柳杉属 *Cryptomeria*、水松属 *Glyptostrobus*、落羽杉属 *Taxodium* | 多生于湿地；落羽杉有膝状呼吸根 |

前五个亚科就是传统的杉科，它们依次在柏亚科与澳柏亚科之外分出，所以杉科是一个**并系群**。

我国原属杉科的有 5 属 7 种，另引入 4 属 7 种：

- 杉木（*Cunninghamia lanceolata*）：常绿乔木，叶条状披针形，边缘有细锯齿，在侧枝上基部扭转成二列，两面有气孔线；球果近球形，苞鳞大、边缘有细齿，种鳞小、先端三裂，腹面生三粒种子，种子两侧有窄翅。主产我国（老挝、越南北部可能也有天然分布），秦岭以南广泛栽培，是南方面积最大的人工用材林树种，生长快，材质轻软、耐腐、易加工。中文教材的台湾杉木（*C. konishii*）现多作为杉木的变种或异名。
- 柳杉（*Cryptomeria japonica* var. *sinensis*，中文教材作 *C. fortunei*）：叶钻形，螺旋状略排成五列，先端向内弯；球果近球形，种鳞上部有 4–5 个齿裂，每种鳞 2 粒种子，产浙江天目山、福建、江西；原种日本柳杉每种鳞 2–5 粒种子。
- 水松（*Glyptostrobus pensilis*）：叶三型（鳞形叶宿存，条形与条状钻形叶连同侧生短枝一起脱落）；球果直立，种鳞木质，上部边缘有 6–10 个尖齿，种子有向下的长翅。白垩纪与新生代广布北半球，第四纪冰期后只残存于我国华南与越南北部，野生个体很少，为国家一级重点保护野生植物；生于水边，根部膨大，材质轻，可作救生用品与瓶塞。
- 落羽杉（*Taxodium distichum*）与池杉（*T. distichum* var. *imbricarium*，中文教材作 *T. ascendens*）：原产北美东南部，落叶，侧生小枝冬季与叶一起脱落；我国长江流域广泛引种于水网地区。
- 水杉（*Metasequoia glyptostroboides*）：落叶乔木，小枝、叶与种鳞都交互对生（这一点又像柏亚科），条形叶基部扭转排成二列，冬季与侧生小枝一同脱落；球果种鳞盾形，每种鳞 5–9 粒种子。
- 北美红杉（*Sequoia sempervirens*）与巨杉（*Sequoiadendron giganteum*，又称世界爷）：原产美国加利福尼亚，均为单种属，我国有引种。

水杉的发现是 20 世纪植物学的一件大事。1941 年，日本古植物学家三木茂（Miki Shigeru）根据日本与其他地区的化石建立了水杉属（*Metasequoia*），当时认为它早已灭绝；1940 年代初，我国林学家在湖北利川磨刀溪（当时属四川万县）发现了一种巨大的落叶杉类，1946 年采得完整的标本，1948 年胡先骕与郑万钧将它定名为水杉，证明三木茂的化石属仍有活的种。水杉在白垩纪与新生代曾广布北美、欧亚，现在的野生分布只限于湖北、湖南与重庆交界处，野生种群为国家一级重点保护野生植物；它已被引种到世界五十多个国家，是著名的"活化石"。

柏亚科在我国有 8 属 40 余种：

- 侧柏（*Platycladus orientalis*）：生鳞叶的小枝扁平，排成一平面，直展；叶鳞形交互对生；球果当年成熟，熟时开裂，种鳞木质、扁平，背部近顶端有反曲的钩状尖头，种子无翅。我国特有的单种属，除新疆、青海外几乎遍布全国，耐干旱、耐瘠薄，是北方荒山造林与古典园林、陵园的主要树种（北京的古柏多为侧柏）。
- 柏木属（*Cupressus*）：生鳞叶的小枝四棱形或圆柱形，不排成平面（柏木例外）；球果第二年成熟，种鳞 4–8 对，盾形，种子有棱、两侧有窄翅。柏木（*C. funebris*，小枝下垂，我国特有）、干香柏（*C. duclouxiana*）、巨柏（*C. gigantea*，西藏雅鲁藏布江河谷）。
- 刺柏属（*Juniperus*）：球果肉质，熟时种鳞合生、不张开，种子无翅。中文教材分为两属：圆柏属（*Sabina*，叶刺形或鳞形，或两型兼有）与刺柏属（狭义，叶全为刺形，三叶轮生，基部有关节）；分子证据表明狭义的刺柏属与圆柏属互为姐妹群、合起来是单系群，现行系统合并为广义的刺柏属，圆柏属作为其中的一个组。圆柏（*J. chinensis*，又称桧柏，幼树多刺叶、老树多鳞叶，中年树两型兼有）、刺柏（*J. formosana*）。
- 福建柏（*Fokienia hodginsii*）、日本花柏（*Chamaecyparis pisifera*）与日本扁柏（*C. obtusa*，引种）、崖柏（*Thuja sutchuenensis*，重庆城口，曾被认为已灭绝，1999 年重新发现）。

柏亚科的识别要点：叶交互对生或三叶轮生，鳞形或刺形，常两型；苞鳞与种鳞完全合生；种鳞交互对生或 3–4 片轮生；胚珠直立。

### 26.7.3. 红豆杉科

广义的红豆杉科（Taxaceae s.l.）有 6 属约 30 种，主要分布在北半球，包括传统的红豆杉科与三尖杉科。

- 常绿乔木或灌木；管胞内壁有螺纹加厚；叶条形或披针形，螺旋状排列或交互对生，叶背中脉两侧各有一条气孔带；
- 多雌雄异株；小孢子叶有 3–9 个花粉囊（盾状），花粉无气囊；
- 不形成球果：雌球花只有一个（三尖杉属为成对的）胚珠，生于短枝顶端，基部有盘状或漏斗状的珠托；
- 种子核果状或坚果状，部分或全部包在肉质、颜色鲜艳的**假种皮**中（假种皮由胚珠基部的珠托发育而成），由鸟类传播。

各属：

| 属 | 特征 | 代表 |
|---|---|---|
| 红豆杉属 *Taxus*（约 11 种） | 叶螺旋状着生，背面有两条淡黄或淡灰绿色气孔带，叶内无树脂道；种子坚果状，生于红色杯状的肉质假种皮中，上部露出 | 红豆杉 *T. wallichiana* var. *chinensis*（中文教材作 *T. chinensis*）、南方红豆杉 *T. wallichiana* var. *mairei*、东北红豆杉 *T. cuspidata* |
| 白豆杉属 *Pseudotaxus* | 小枝近对生或轮生，叶背两条白色气孔带；假种皮白色 | 白豆杉 *P. chienii*，我国特有的单种属 |
| 穗花杉属 *Amentotaxus* | 叶交互对生，有树脂道；雄球花多数组成穗状；种子几乎全包在鲜红色的囊状假种皮中 | 穗花杉 *A. argotaenia* |
| 榧属 *Torreya* | 叶交互对生，先端有刺状尖头，有树脂道；种子第二年成熟，全部包在假种皮中 | 榧树 *T. grandis*，其栽培品种香榧是著名的干果（浙江诸暨、绍兴一带） |
| 三尖杉属 *Cephalotaxus*（原三尖杉科） | 叶在侧枝上排成二列，背面有两条白色气孔带；小孢子叶球聚生成头状；胚珠成对生于苞片腋内，种子第二年成熟，全部包在肉质的外层中（传统称为假种皮，近年多认为是肉质的外种皮） | 三尖杉 *C. fortunei*、粗榧 *C. sinensis*，均为我国特有 |
| *Austrotaxus* | 新喀里多尼亚特有 | |

红豆杉属的树皮与枝叶含紫杉醇（paclitaxel，Taxol）。紫杉醇 1971 年由 Wani 与 Wall 等从短叶红豆杉（*T. brevifolia*）的树皮中分离并确定结构，它能稳定微管、阻止有丝分裂，1992 年被批准用于治疗卵巢癌，以后又用于乳腺癌、肺癌等（作用机制见 [7.3.14](/7.3.14)）。早期从树皮提取严重破坏了野生资源，现在主要用栽培红豆杉的枝叶中的前体半合成或用细胞培养生产；我国的红豆杉属所有种均为国家一级重点保护野生植物。三尖杉属植物含三尖杉酯碱与高三尖杉酯碱等**生物碱**，我国在 1970 年代把它们用于治疗白血病，高三尖杉酯碱（omacetaxine）2012 年在美国被批准用于慢性髓细胞白血病。

## 26.8. 中国的裸子植物

我国是世界上裸子植物最丰富的国家之一：《中国植物志》（1978）记载 11 科 41 属 236 种（含引种栽培的 1 科 7 属 51 种），以后又发表了许多新种。按现行系统，我国原产 8 科（苏铁科、银杏科、麻黄科、买麻藤科、松科、罗汉松科、柏科与红豆杉科），另有南洋杉科、金松科、泽米铁科等引种栽培；除百岁兰科以外的各科在我国都能见到。

第四纪冰期中，欧洲与北美的许多裸子植物灭绝，而我国西南、华中与华南山地受冰川影响较小，成为它们的避难所。因此我国有许多中国特有或近于特有的孑遗属种：银杏、水杉、水松、银杉、金钱松、白豆杉、杉木（属）、侧柏（属）、台湾杉，以及攀枝花苏铁、百山祖冷杉、崖柏、巨柏等珍稀种。2021 年发布的《国家重点保护野生植物名录》把苏铁属所有种、银杏（野生种群）、银杉、百山祖冷杉、水松、水杉（野生种群）、红豆杉属所有种等列为一级保护。

我国裸子植物的主要用途见下表：

| 用途 | 主要植物 |
|---|---|
| 用材 | 杉木、马尾松、油松、云南松、落叶松、红松、云杉、冷杉、柏木（建筑、家具、造纸）；裸子植物的木材常称"软材"（softwood） |
| 树脂 | 马尾松、湿地松等割脂，蒸馏得松节油与松香，用于涂料、油墨、胶黏剂、造纸施胶等 |
| 食用 | 红松、华山松等的松子，香榧，银杏种仁（白果），麻黄的"麻黄果"，买麻藤种子 |
| 药用 | 紫杉醇（红豆杉属）、三尖杉酯碱（三尖杉属）、麻黄碱（麻黄属）、银杏叶提取物；松花粉 |
| 园林 | 雪松、金钱松、日本金松、南洋杉、圆柏、侧柏、白皮松、油松、罗汉松、苏铁、银杏、水杉 |

松、杉、柏三类（原三科）的速记：松科叶螺旋状、种鳞与苞鳞离生、每鳞 2 粒种子；原杉科叶多螺旋状（水杉对生）、半合生、每鳞 2–9 粒；柏亚科叶对生或轮生、完全合生、每鳞 1 至多粒。

## 思考题

1. 为什么现行系统要把杉科并入柏科、把三尖杉科并入红豆杉科，并取消"红豆杉纲"？

   **答** 分子系统发生表明，狭义的柏科嵌在传统杉科的各属之中（杉木亚科、台湾杉亚科等依次分出），杉科是并系群，只有与柏科合并才成为单系群；三尖杉属是红豆杉科其余各属的姐妹群，合并后的红豆杉科才是单系群。罗汉松科则与南洋杉科最近缘，与红豆杉科并不构成一支，所以以"不形成球果、有肉质种子外层"为依据的红豆杉纲是多系群，不能成立。苞鳞与种鳞愈合的连续系列（杉木—柳杉—水杉—柏木）也说明杉、柏之间没有截然的界限。

2. 如何区分松科的常见属？试编一个以球果和叶为依据的简明检索表。

   **答** 参考：1. 针叶 2–5 针一束，基部有叶鞘，球果第二年成熟，种鳞有鳞盾与鳞脐……松属；1. 叶单生或簇生。2. 叶在短枝上簇生：3. 常绿，叶坚硬……雪松属；3. 落叶：4. 球果种鳞宿存……落叶松属；4. 种鳞成熟后脱落，叶辐射平展成圆盘状……金钱松属。2. 叶在长枝上单生：5. 球果直立：6. 种鳞脱落，叶痕圆形……冷杉属；6. 种鳞宿存……油杉属。5. 球果下垂：7. 苞鳞三裂、伸出……黄杉属；7. 苞鳞不伸出：8. 叶四棱，生于隆起的叶枕上……云杉属；8. 叶扁平有短柄……铁杉属（叶在节间顶端密集、球果腋生的为银杉属）。

3. 松属两亚属的区别是什么？为什么不能只看针叶的束数？

   **答** 单维管束亚属针叶内 1 条维管束，叶鞘早落，鳞叶不下延，木材较软，鳞脐多顶生；双维管束亚属针叶内 2 条维管束，叶鞘宿存，鳞叶下延，木材较硬，鳞脐背生。束数在两亚属中都有重叠：我国五针一束的松都属单维管束亚属（墨西哥的一些硬松也是五针），两针一束的多属双维管束亚属，但三针一束的既有白皮松（单维管束），也有云南松、火炬松（双维管束），所以要结合维管束数与叶鞘来判断。

4. 银杏和水杉都被称为"活化石"。它们的发现与研究在生物学上有什么意义？

   **答** 二者都在中生代或新生代曾广布北半球，第四纪冰期后只在我国残存。银杏保留着多鞭毛的游动精子（平濑作五郎 1896），证明种子植物来自蕨类式的祖先，也是研究种子植物早期生殖的活材料；水杉先由三木茂（1941）根据化石建属，1940 年代才在湖北利川发现活树，使化石植物的形态、生态与解剖得以与现存植物直接对照，也说明我国西南、华中山地是第三纪植物的重要避难所。它们都提醒我们保护孑遗植物的野生种群与遗传多样性。

5. 红豆杉、三尖杉与麻黄提供了哪些重要药物？利用这些资源时要注意什么？

   **答** 红豆杉属含紫杉醇，用于卵巢癌、乳腺癌等；三尖杉属含三尖杉酯碱与高三尖杉酯碱，用于白血病；麻黄含麻黄碱与伪麻黄碱，用于平喘和发汗。红豆杉生长缓慢，早期剥树皮提取严重破坏了野生资源，现应以人工栽培的枝叶为原料、发展半合成与细胞培养，野生红豆杉属已列为国家一级保护；麻黄碱是毒品的前体，麻黄的采收与流通受到严格管制；三尖杉属多为特有种，也要以栽培代替采挖。
